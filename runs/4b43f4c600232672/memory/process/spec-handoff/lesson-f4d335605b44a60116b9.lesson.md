# 规格提取时为每个导航目的地写页面入参契约：参数名、类型、是否可空或默认值与源端读取方式，不只留深链占位

ID：`lesson-f4d335605b44a60116b9` · 版本：1

[本主题](index.md)

## 何时使用

规格提取阶段写导航图与分页页面规格时

## 适用情境

源端 nav_graph 为目的地声明 <argument>（必填 id 等）并带 deep link 占位，Fragment 用 requireArguments().getString(ARG_X)、SafeArgs 等读取；规格模板的导航图只列目的地、起始页与深链。

## 原因

导航图只剩深链占位时，下游实现者看不到“此页必须从入参取 id”，发送端与接收端的参数契约都失去依据，接收页容易写成无来源的字段。来源中规格作者已读到 nav_graph 的必填 argument 与 Fragment 取参代码，写导航总览与分页规格时都丢掉了。

## 做法

1. 为每个目的地写“页面入参”：参数名、类型、是否 nullable/默认值、源端读取位置，以及各入口从哪里取值传入；导航总览同样标出。
