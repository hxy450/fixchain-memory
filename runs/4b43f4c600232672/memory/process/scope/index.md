迁移范围的确定：截图或清单与源码可达页面的取舍，源模块入口能力（如深链）写入契约或登记 skip，范围类必问项的处理，平台替代页的入口位置，未纳入范围的入口如何呈现与汇报

## 本级经验

- [写应用壳契约与实施计划时枚举源导航模块的全部入口能力（含深链解析与 scheme 注册），不做的登记 skip](lesson-3348c580951ef82a9737.lesson.md)
  - 时机：规格与计划阶段，编排者撰写应用壳/导航的共享契约、实施计划或压缩前交接摘要，确定路由表、启动入口与 module 配置要承载哪些源端导航能力时
  - 情境：源导航模块除路由表和顶层 Tab 外，还含深链路由器（解析器类、深链基址常量、Manifest 的 scheme 或 App Links intent-filter）；目标用 Navigation + NavPathStack 字符串路由重建应用壳；契约先于 feature spec 写出并被后续实现重读，会话中途可能发生上下文压缩。
- [决策把系统表面（桌面 Widget 等）替换为应用内页面时写明入口位置与形式；受保护的对等页面不新增可见控件](lesson-238588d3cceaf707ccfe.lesson.md)
  - 时机：决策与规格阶段批准平台替代方案时；巡检与修复阶段为替代页补可达入口时
  - 情境：源端某能力依附系统表面（桌面 Widget、快捷方式等），决策降级为新的应用内页面；源应用内没有对应入口；决策账本限定该替代只作用于本功能，不得改变其他已对等复刻页面的布局与导航。
  - 例外：决策明确批准在某个对等页面加可见入口
- [用户只给出部分页面截图时，迁移范围包含这些页面入口直达的二级页面；范围类必问项无法询问时不自行取最窄解释](lesson-91c89aff3f8c5c47bd2a.lesson.md)
  - 时机：规格提取阶段，确定本轮迁移范围并处置截图页入口直达的清单外 Activity 时；以及实现、交付阶段遇到被排除在范围外的入口时
  - 情境：用户附若干页面截图，要求“按图片和源码迁移、修到可交付”并跳过确认；截图页上的按钮、菜单在源码中 startActivity 到说明页、记录页、关于/反馈、设备连接等独立页面；覆盖检查对这些被引用的 Activity 报未计入。
  - 例外：用户明确限定只迁移截图中的页面本身；此时仍按最后一条汇报未实现入口
