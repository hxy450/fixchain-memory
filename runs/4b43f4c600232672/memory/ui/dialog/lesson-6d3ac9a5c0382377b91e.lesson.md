# 源端把入口委托给跨页面共享组件（详情弹窗、公共分享弹层）时，目标检索并复用同职责的共享组件，不保留页内副本

ID：`lesson-6d3ac9a5c0382377b91e` · 版本：1

[本主题](index.md)

## 何时使用

功能实现与审计阶段，接线页面中调用源端共享组件（XxxDialog.show、公共分享弹层）的入口，并决定这些入口背后的动作由谁实现时

## 适用情境

源端列表项点击或按钮调用跨页面共享的对话框或弹层（带实体键参数），分享走公共底部分享弹层；目标工程已有同名或同职责的共享组件及其宿主接线，当前页面里却有一份自绘副本，副本中的部分动作尚未接通。

## 例外与边界

- 源端该入口本身是页面私有实现，没有委托给共享组件

## 原因

保留页内副本就要在副本里逐个重做共享组件已有的动作，做不完的动作被包装成不可用占位，界面表现为多个可见操作点击后只提示“不可用”。来源中实现者读到了源端委托共享详情弹窗与分享弹层，自己的检索结果也列出了目标同名组件，仍保留自绘副本并把五个动作改到“契约未确认”兜底；此前的审计按页面自有接口逐项判定缺契约，给出了同一方向的建议。

## 做法

1. 遇到源端调用共享组件时，先在目标工程检索同名或同职责组件及其现有宿主接线（组件名、onAction 或 show 的调用方），优先复用并把它的动作回调接到本页，不保留或扩写页内副本。
2. 审计与真值整理阶段，对源端委托给共享组件的入口，把“复用目标共享组件及其动作”写成实现契约，不按当前页面自有接口逐项判定缺契约。
