# data

数据层：网络请求与鉴权（含请求体编码）、数据同步调度与事件发布、本地数据库的建表与版本迁移、预置数据播种、JSON 解析（资源与接口响应层级）、手写二进制编解码（protobuf wire 格式）、模型类型映射与查询层派生状态（含 64 位整数与字段单位）、文件系统操作

[上一级](../index.md)

## 子主题

- [codec](codec/index.md) — 手写二进制编解码（protobuf wire 格式）：字段 wire type 与读写方法的对称，varint 与负数补码的字节拆分
- [files](files/index.md) — 文件系统操作：fileIo 建目录、移动与复制在目标已存在时的行为与幂等写法
- [model](model/index.md) — 模型类型之间的映射：持久化枚举字符串与页面本地类型，大整数 id（源端 Long 或 String 承接）的保精度解析，跨模型数值字段的单位，保存与查询的关联键（如按月份），以及查询层按源端判定函数派生完成态等状态，展示型 UI 模型字段的 code/ID 转换与缺省回退，协作完成态与子任务状态的写入键和撤销范围
- [network](network/index.md) — 网络层：服务地址与环境、运行配置的构建期注入、URL 拼接、拦截器注入的公共请求头、请求体字段与编码（表单或 JSON）、登录凭证来源与失效踢登，加解密工具的前置返回与异常回退、网关加密传输到 cryptoFramework 的移植，以及多路请求聚合结果的缓存写入与命中，拦截器读取的公共参数（设备标识、当前分组）的生产者
- [parsing](parsing/index.md) — JSON 解析：打包资源的字段必填与空值语义，源解析器（如 Gson）的标量宽松转换与源数据实际类型，接口响应容器 Bean 的取值层级
- [schema](schema/index.md) — Room 到 relationalStore 的库名、schema 版本、建表语句（含标识符加引号与关键字列名）与升级路径
- [seeding](seeding/index.md) — 预置、演示与参考数据：内容逐字段取自源端种子类或 assets 数据文件，资产覆盖范围与算法库实时计算字段的取舍，播种时机（建库回调或首次启动标记）与重置入口，主键写入与补充插入
- [sync](sync/index.md) — 数据同步：多次触发的并发语义（排队、合并与尾随补跑）、失败队列的重推范围、同步进度与终态事件的发布粒度和前置条件，同步保存之后的当前选中项校验与持久化
