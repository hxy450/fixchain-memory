# data/model

模型类型之间的映射：持久化枚举字符串与页面本地类型，大整数 id（源端 Long 或 String 承接）的保精度解析，跨模型数值字段的单位，保存与查询的关联键（如按月份），以及查询层按源端判定函数派生完成态等状态，展示型 UI 模型字段的 code/ID 转换与缺省回退，协作完成态与子任务状态的写入键和撤销范围

## 本级经验

- [完成态等协作状态的派生与写入逐分支移植源端函数：审计摘要或审查意见只作线索，不用更严的重算或更宽的改动覆盖源端语义](lesson-4ad956bab5fca6d7f418.lesson.md)
  - 时机：数据层实现、复核或按审查意见修正阶段，在列表查询中派生完成态、完成人数，或修改完成态与子任务状态的写入键、撤销删除范围时
  - 情境：源端按完成模式（如任一成员/全部成员）、是否重复事件和发生日期组合判定完成态；目标在查询仓库里重算该状态，手头有审计或交接摘要（如“按模式 + 发生日 + 当前用户派生”）以及仓内已有的判定实现。也包括审查意见只要求收窄某个范围（如重复事件撤销时加实例日期条件），修正者在同一改动里把“任一成员完成”的共享状态写入键改成当前用户。
- [宿主或适配层给展示型 UI 模型赋值时逐字段按源端绑定取值：code/ID 经源端格式化器或本地目录转换，颜色随图标一起下传，无源数据时保留构建器回退](lesson-22f5100f6718eaecc66f.lesson.md)
  - 时机：界面接线与数据适配阶段，把仓库层领域数据映射成弹窗、列表项、页头等 UI 模型的展示字段（文案、图标、颜色、头像）时
  - 情境：目标 UI 模型用字符串或图片字段直接渲染；数据层保存的是提醒 code 数组、重复规则类型与数据、分组图标或颜色 ID、成员 JSON；源端在详情页或适配器里经工具函数（code → 文案、规则 → 文案）或本地目录查表（ID → 图片、颜色）转换，并以布局中的静态文案作缺省。
- [带“本月”一类关联语义的保存与读取，按源端实体构造参数和查询条件建模关联键](lesson-6a95a3ae5f47a15892fc.lesson.md)
  - 时机：数据层实现阶段，把源端实体的保存与查询迁移为目标模型字段和仓储方法参数时
  - 情境：源端以 Budget(month, associated, classify) 一类构造保存，并按 getBudgetByTimestamp(month, classify) 查询当月记录；目标准备在已有模型上加一个单值字段。
- [把以字符串持久化的模型枚举映射到页面本地类型时，按模型枚举成员逐一 switch，不用成员名字符串变换去匹配](lesson-b92a8a56aee6db5e9c52.lesson.md)
  - 时机：实现阶段把共享模型枚举（持久化为字符串）映射成页面本地枚举或资源时
  - 情境：模型枚举的持久化值是带下划线的大写串（如 FRENCH_PRESS），页面本地枚举用驼峰成员名。
- [服务器下发的大整数 id 在 JSON.parse 之前保住原文：源端 Long 用 bigint，源端 String 承接的数值 id 保真为字符串](lesson-c066489fcf35ab37378c.lesson.md)
  - 时机：数据模型与网络层实现阶段，映射 Kotlin Long 字段或以 String 承接的数值标识、编写全局响应解析入口与序列化时；规格提取阶段写服务层签名与接口字段类型时
  - 情境：服务器生成的 id、hash、userId 以 JSON 数字下发，取值可达 19 位；源端用 Kotlin Long（Flutter 侧 Dart int）承载，或用 String 字段承接（Gson 把数值 token 直接读成字符串）；目标端 ArkTS 的 number 是双精度，JSON.parse 遇到超过 2^53 的整数直接舍入。
- [逐字段搬运 Builder 或构造调用时，同时核对两端模型字段的单位](lesson-c73deaf6f27d3426c4e9.lesson.md)
  - 时机：功能实现阶段，把源端模型 Builder 或构造调用逐字段翻译成目标端模型构造参数时
  - 情境：目标端两个模型对同名数值字段声明了不同单位（如本地音频时长为毫秒、播放队列时长为秒），源端在同一处直接传值；目标消费方按各自单位显示或换算。
