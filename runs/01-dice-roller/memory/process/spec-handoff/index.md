规格与实现之间的交接：规格概括出错、与源端冲突时的处理与回报

[上一级](../index.md)

## 本级经验

- [规格写法与写前读到的源码、主题或映射参考冲突时，按源端语义实现并标注冲突](lesson-7a065e8fe384b8c462cc.lesson.md)
  - 时机：页面实现阶段，规格给出的容器、样式或类型写法与写前读到的源码、主题或映射参考不一致时
  - 情境：实现者同时读到页面规格与源布局、主题文件、映射参考或 SDK 声明，规格的具体写法与源端可观察行为或参考映射不符，而规格对该处只有概括性理由（如“无相对约束需求”“零硬编码色值”）或没有理由。
  - 例外：规格或决策记录（如 decision ledger）对该差异写明了有意取舍的理由，此时按该决策实现
