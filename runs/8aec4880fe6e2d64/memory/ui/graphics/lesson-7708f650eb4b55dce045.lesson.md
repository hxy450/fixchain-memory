# android:background 的整屏背景位图按拉伸铺满映射，不默认用 ImageFit.Cover 裁切

ID：`lesson-7708f650eb4b55dce045` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把源根布局的 android:background 背景图转换为 ArkUI 背景 Image 或背景图属性时

## 适用情境

源根容器以 android:background=@drawable/xxx 铺设整屏背景位图，背景上画有需要完整显示的图文；目标用 Stack 底层 Image 或背景图属性重建。

## 例外与边界

- 源端是 ImageView 且显式 scaleType=centerCrop 一类裁切语义，按该 scaleType 映射

## 原因

View 背景位图按视图边界拉伸铺满、不裁切；Cover 等比铺满会裁掉上下或左右，背景上的关键图文被截掉。来源中生成者读到根布局背景与资源尺寸，仍写 objectFit(ImageFit.Cover)，顶部图文被裁，修复改为 ImageFit.Fill。

## 做法

1. 源 android:background 的位图背景用 ImageFit.Fill（或等效铺满方式）映射；确需等比裁切时，先用资源宽高比与目标屏幕比例核对关键图文不会被裁。
