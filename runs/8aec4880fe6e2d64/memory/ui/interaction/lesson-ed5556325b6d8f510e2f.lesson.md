# Button 内按状态切换图标时写成一个 if/else 或单个 Image 按状态选资源，不写两个互斥的独立 if

ID：`lesson-ed5556325b6d8f510e2f` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，为播放/暂停一类两态按钮编写 Button 的子内容时

## 适用情境

源端按钮按状态切换图标，目标用 Button() { ... } 包裹图标，准备按两个状态分别写条件分支。

## 原因

Button 只允许一个子组件；两个互斥的独立 if 在编译期仍按两个子节点计算，报 The 'Button' component can have only one child component。来源写者自检以“if/else 算一个条件子组件”放行，实际输出却是两个独立的 if。

## 做法

1. 写成 if (isOn) { Image(A) } else { Image(B) }，或一个 Image 由状态三元表达式选择资源；自检对照实际输出的子节点结构，而不是对照计划。
