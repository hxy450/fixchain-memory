# process

迁移流程中的阶段交接与写前输入：迁移范围的确定，规格与二手产物的核对，必读材料与源布局是否读全，跨任务移交的登记与兑现，结构检查与自愈脚本的收口

[上一级](../index.md)

## 子主题

- [gates](gates/index.md) — 结构检查与自动修复的收口：会改写源码的自愈脚本运行后审阅改动，按关键字判定的检查要真实落实而不是迎合检查器
- [input-loading](input-loading/index.md) — 写前输入是否真的进入上下文：必读 skill、规格、参考与源码片段的读取方式，派工要求的源码核对，辅助谓词与 getter 的定义，以及编排者接手切片时要加载的输入
- [scope](scope/index.md) — 迁移范围的确定：截图或清单与源码可达页面的取舍，范围类必问项的处理，未纳入范围的入口如何呈现与汇报
- [spec-handoff](spec-handoff/index.md) — 规格、已生成代码等二手输入与源码之间的交接：规格条目的写法、上游产物缺值时如何收口、概括出错、照搬前核对与冲突回报，多模块同名布局的解析，合成快照清单的可信度
- [task-handoff](task-handoff/index.md) — 跨任务移交：留给别的文件、切片或编排者兑现的工作如何登记、分派、接收与闭合，以及各类占位的使用边界
