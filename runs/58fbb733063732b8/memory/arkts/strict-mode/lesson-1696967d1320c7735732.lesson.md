# ArkTS 里给对象字面量写显式 class/interface 类型；去掉 Record 时键已知用具名字段类、键不定用 Map，不改成索引签名

ID：`lesson-1696967d1320c7735732` · 版本：1

[本主题](index.md)

## 何时使用

编码或返修阶段，为一组命名常量、主题令牌或键值集合确定类型声明，或按规范替换 Record/Object 时

## 适用情境

代码用对象字面量承载间距、圆角等令牌，或用键值集合保存偏好、设置；目标文件可能还没被页面或 Ability 导入，或者并发 worker 被要求不跑全量构建，编译器暂时检查不到这些写法。

## 原因

ArkTS 严格模式不接受无类型对象字面量（arkts-no-untyped-obj-literals），也禁止 [key: string] 索引签名（arkts-no-indexed-signatures）；没被任何页面或 Ability 导入的文件不进入全量编译，错误会潜伏到第一次接线时才暴露。来源中编排者照搬 skill 里 static readonly X = {…} 的无类型示例写主题令牌，因为没有文件导入它，终态编译照样通过；返修 worker 按“禁用 Record”把类型改成索引签名，两人都怀疑过是否受支持但没验证，汇总构建时报出一批编译错误。

## 做法

1. 新建令牌或常量类时给每个对象字面量一个具名 class 或 interface 类型（如 class ThemeSpacing { small: number = 4 }），不照搬无类型示例。
2. 替换 Record 时，键集合已知就改成具名字段类，键不固定就用 Map；不要写成 [key: string]: T。
3. 新建但尚未被导入的 .ets 文件，落盘后临时接一处导入或单独跑一次 ArkTS 检查，再据构建结果报告通过。
