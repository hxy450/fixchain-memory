# 引用 style 的控件先展开 style 的全部 item 再叠加元素覆写；圆角不按半高推，也不照抄相邻控件

ID：`lesson-bc5b8558ab086168b462` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段（含返修期重写弹窗或按钮），为通过 style 继承形状、尺寸与渐变的控件确定修饰链时

## 适用情境

源 XML 控件以 style="@style/X" 继承圆角、高度、渐变等属性，元素本身只覆写部分项；同一或相邻布局里有圆角更大的卡片，或同 style 但显式覆写成胶囊的按钮。

## 原因

style 里的形状值不在元素上，不展开就只能猜：按高度一半推成胶囊、照抄外层卡片或相邻按钮的圆角；把某处的显式覆写当成 style 默认值也会扩散错误。来源中三处按钮的写者输入不同（有人读过 styles.xml 仍未应用，有人没读，返修时自问默认值却没有查），结果都写成胶囊。

## 做法

1. 遇到 style 引用先展开其全部 item（圆角、高度、渐变起止色），再逐项叠加元素上的显式属性；元素没覆写的形状值取 style 值。
2. 在注释里写明每个形状值来自 style 还是哪一行覆写；写不出来源就先读 styles.xml，不用估算值占位。
3. 同一 style 多处复用时逐个控件核对有无显式覆写，覆写处保持覆写值，不把某处覆写当成 style 默认值。
