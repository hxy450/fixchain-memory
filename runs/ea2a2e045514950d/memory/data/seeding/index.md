## 本级经验

- [源端在应用启动时按标记首次播种、设置中可重置时，目标在启动路径落实际调用并保留门控，重置入口另接](lesson-dc3f2589254d02893b0e.lesson.md)
  - 时机：计划与实现阶段，迁移 Application.onCreate 里的首次启动初始化（如演示数据播种）并确定目标调用点时；执行总结声称“首次运行自动初始化”前
  - 情境：源端 Application.onCreate 调用 seedDemoDataOnFirstLaunch 一类方法，按偏好标记（如 has_seeded_demo_data）只播一次；同一数据集在设置页可手动重置；目标端用自建数据管理器（单例、KV 或数据库）替代 Room 等持久化。
  - 例外：源端在数据库首次创建回调里播种：按建库分支与同一事务处理，见同主题的建库播种经验
- [源端在首次建库回调里播种时，目标把播种放进建表分支的同一事务并写入种子主键；手动补充按不带 id 的新行插入](lesson-488a3bd782acef92f5cf.lesson.md)
  - 时机：数据层实现阶段，确定预置数据何时播种、种子主键如何写入，以及“添加默认项”这类补充入口如何插入与列出时
  - 情境：源端 Room 在 onCreate 回调里按固定 id 插入预置数据，另有补充对话框列出全部预置项并以 copy(id = 0) 重新插入；目标用 relationalStore 自行建表与播种。
- [演示、预置与参考数据逐字段取自源端种子工厂、模板常量或 assets 数据文件，不按功能名自拟样例，也不以少量硬编码代替全量](lesson-1c513fdf2cf212354aa0.lesson.md)
  - 时机：数据层或演示数据切片实现阶段编写演示、预置数据内容时；规格提取阶段描述固定演示数据时；实现依赖 assets 参考数据（行政区划、城市列表等）的页面与仓储时
  - 情境：源端用种子工厂（如 DemoDataFactory）及其引用的清单模板、主题常量构造固定演示数据：标题、目的地、相对今天的日期偏移、主题 key、备注、条目标题/分类/优先级/顺序、完成集合与完成时间；目标端要重建同一数据集，手边可能只有依赖类名或规格里的数量概括。或源端从 assets 文本（如行政区划文件）按解析规则生成层级参考数据，目标准备先用少量硬编码条目顶替。
  - 例外：当前任务明确批准使用与源端不同的演示内容
