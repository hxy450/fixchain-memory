# 布局引用的 @drawable（progressDrawable、背景 shape、标签背景）先打开取数值：高度、圆角、轨道色、渐变与描边写进规格与实现

ID：`lesson-771d1ba1a032b769097a` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与界面实现阶段，为进度条、搜索框、分组标签等引用 drawable 的控件确定高度、圆角、颜色与描边时

## 适用情境

源布局以 progressDrawable=@drawable/xxx、background=@drawable/bg_xxx 引用 layer-list/shape 资源，尺寸、圆角、轨道色、渐变和描边写在被引用文件里；目标工程可能已有名称相近、含义不同的颜色资源。

## 原因

不打开被引用的 drawable，就只能自定高度或沿用工程里已有的颜色，样式与源端不符。来源两例：启动页规格作者列 drawable 目录的命令因 -LiteralPath 不支持通配符报错后未重试，进度条写成 4vp 高并沿用浅灰轨道色，而源端是 12dp、浅蓝轨道、圆角与渐变；城市选择页修复未读搜索框与分组标签的背景文件，分组标题色、搜索框描边与图标、网格外边距到第二轮才对齐。

## 做法

1. 遇到 @drawable 引用就打开被引用文件，把高度、圆角、轨道/前景色、渐变与描边值写进规格和修饰链；不自定高度，不按名称套用工程里含义不同的颜色。
2. 列目录或读取命令报错（如 -LiteralPath 带通配符）时改用 -Path/-Filter 重试，未读到资源前不定稿；写后才读到的数值回写到已生成片段。
