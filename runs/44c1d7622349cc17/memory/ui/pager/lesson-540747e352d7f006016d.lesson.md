# 只有一页或禁用了滑动的 ViewPager2 不写成可滑的 Swiper

ID：`lesson-540747e352d7f006016d` · 版本：1

[本主题](index.md)

## 何时使用

规格提取阶段为 ViewPager/ViewPager2 选择目标容器并写明手势行为时；实现阶段落地该容器时

## 适用情境

源页面用 ViewPager2 + FragmentStateAdapter，但适配器实际只有 1 页（或 isUserInputEnabled=false），切页入口隐藏或无效；通用映射表或页面元数据只按类型给出 ViewPager2 → Swiper。

## 原因

按类型映射会把静态单页写成 Swiper，而 ArkUI 单页 Swiper 仍有横拖手势（可见平移回弹），源端实机不可滑；规格若还为不存在的页预置 index，实现者更会照写。来源中规格作者和实现者都读到了只有一页的源码，仍按类型映射。

## 做法

1. 规格提取时核适配器实际页数、isUserInputEnabled 以及切页入口是否可见有效，按运行时行为写契约；页数恒为 1 时写明“静态单页、不可横滑”，目标用普通容器直嵌。
2. 实现时对照源码确认容器确实可滑；不可滑就不用 Swiper，或显式禁用滑动（如 disableSwipe(true)），并检查上层 Transparent 是否把触摸透传到这个手势面。

## 可选检查

仅在适用条件不确定、与当前输入冲突或需要验证关键假设时按需执行；优先复用已有证据和正常测试。
不因读取本条经验而额外启动验证流程；项目原有必需测试照常执行。

- 真机横滑页面主体，内容无位移、无回弹。
