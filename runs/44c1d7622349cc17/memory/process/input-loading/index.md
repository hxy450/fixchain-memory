# process/input-loading

## 本级经验

- [派工指定的必读 skill、规格与参考文档要读全再写码：批量读取被截断、只读前 N 行或跳过参考时，规则并未进入上下文](lesson-42df1ac4d4030421da34.lesson.md)
  - 时机：写码 worker 或规格作者开工时加载 skill、功能规格、预生成参考文档与源码，长会话压缩上下文后继续写码时，以及在回报中填写 loaded_skills 时
  - 情境：派工列出多份前置 skill（常见十几份 SKILL.md）或多份规格、参考文档，读取者用一次命令批量 cat，或用 sed -n '1,Np' 按固定行数读取；工具对单次输出有长度上限，超出时会省略中段并给出 truncated 提示。也包括已加载的 skill 要求先读某份参考（如迁移陷阱表），读取者没有读，或只在 grep 回执里碰到片段、之后上下文被压缩。
- [派工要求按源码确认的内容（字段类型、请求体、凭证来源、码值、地址），规格看似完整或指定数据源查不到时都回源码核对；没读到就标未核实](lesson-93214f5a49c4d1d82316.lesson.md)
  - 时机：写码 worker 开工时：派工要求读 Android 源码确认字段、请求体或响应处理，手头的规格、锚点或上游产物却看似已给出签名；或规格指定的数据源里查不到具体值时
  - 情境：规格给出接口签名与源码锚点，没写字段类型、请求体字段、凭证来源或错误码取值；Kotlin 可以在一个 .kt 文件里定义多个类，kapt stub 按类拆分。
- [源端分支条件或文案插值依赖的辅助谓词、getter，要读到定义再翻译，不按名字推断](lesson-b3f534eb740a768d95a6.lesson.md)
  - 时机：业务逻辑与界面实现阶段，翻译以辅助谓词分派的切换方法（playPause/toggle），或转写把观察值插进文案模板的显示时；规格提取阶段写这类状态契约时
  - 情境：源码以 isPlayingState() 一类谓词分派 pause/play，或把 text 前缀的 LiveData&lt;String&gt;（格式化结果）拼进文案；读到的源码片段只含调用或相邻 getter，没有定义；同一 ViewModel 另有同名的原始数值字段。
- [编排者因子代理不可用而亲自实现切片时，先加载切片 worker 本应拿到的全部输入，不凭占位登记表的一行触发文本写代码](lesson-b90d7f55409a3a34253d.lesson.md)
  - 时机：执行编排阶段，子代理额度耗尽、限流或失败后，编排者决定自己完成 Base/切片实现、接线或解决前向引用时
  - 情境：编排会话原本只负责派工与收口，手上是占位登记表、feature-plan 的指针和子任务回报这类摘要；切片 worker 派工里列出的切片计划文件、功能规格验收条目、决策账本正文和源码锚点，编排会话并没有打开过。
