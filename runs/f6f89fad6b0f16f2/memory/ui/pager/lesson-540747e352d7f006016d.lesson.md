# 只有一页或禁用了滑动的 ViewPager2 不写成可滑的 Swiper；禁滑用 disableSwipe(true)，不用 enabled(false)

ID：`lesson-540747e352d7f006016d` · 版本：2

[本主题](index.md)

## 何时使用

规格提取阶段为 ViewPager/ViewPager2 选择目标容器并写明手势行为时；实现阶段落地该容器时

## 适用情境

源页面用 ViewPager2（+FragmentStateAdapter），但适配器实际只有 1 页，或以 isUserInputEnabled=false 只关手势、由 Tab 点击 setCurrentItem 切页、子页仍可交互；通用映射表或页面元数据只按类型给出 ViewPager2 → Swiper。

## 原因

按类型映射会把静态单页写成 Swiper，而 ArkUI 单页 Swiper 仍有横拖手势（可见平移回弹），源端实机不可滑；规格若还为不存在的页预置 index，实现者更会照写。另一方面，isUserInputEnabled=false 只关用户滑动手势，ArkUI 的 enabled(false) 却让 Swiper 连同全部子页不可交互。来源一中规格作者和实现者都读到了只有一页的源码，仍按类型映射；来源二中转换者读到 isUserInputEnabled=false 与 Tab 点击切页，却给 Swiper 写 enabled(false)，当时 Tab 页是空 Stack 未显现，后续写者放入真实页面时保留了该属性，真机整页不可点。

## 做法

1. 规格提取时核适配器实际页数、isUserInputEnabled 以及切页入口是否可见有效，按运行时行为写契约；页数恒为 1 时写明“静态单页、不可横滑”，目标用普通容器直嵌。
2. 实现时对照源码确认容器确实可滑；不可滑就不用 Swiper，或用 disableSwipe(true) 只关手势。不要用 enabled(false) 表达禁滑：它作用于整个子树，承载可交互子页的 Swiper 会整页不可点。并检查上层 Transparent 是否把触摸透传到这个手势面。

## 可选检查

- 真机横滑页面主体，内容无位移、无回弹。
- 子页放入禁滑容器后，真机 UI dump 中容器 enabled=true，并实际点击子页控件有响应。
