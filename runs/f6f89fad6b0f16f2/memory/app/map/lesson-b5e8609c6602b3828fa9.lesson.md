# 用原生地图 SDK 替换占位地图时，把页面已有的定位出口接到相机与当前位置显示，并在系统定位与高德底图之间做坐标转换

ID：`lesson-b5e8609c6602b3828fa9` · 版本：1

[本主题](index.md)

## 何时使用

三方地图接入阶段，用高德等原生地图组件替换占位地图、决定定位结果如何驱动地图相机与当前位置显示时；从参考桥接裁剪能力时

## 适用情境

页面原先只有占位地图，定位按钮调用的地图 provider 只缓存中心坐标；定位来源是系统 geoLocationManager（WGS-84），新底图为高德（GCJ-02）；参考工程的桥接类含 recenter/moveCamera、就绪前暂存中心与坐标适配器。

## 原因

替换底图只接了初始化与生命周期时，页面的定位出口仍指向缓存型 provider，按钮看似没有反应；接上相机后若不转换坐标，中心点会与蓝点偏移。来源中移植者读到了参考桥接的 recenter、就绪前暂存中心和完整的 WGS-84→GCJ-02 适配器，也读到“地图服务只是保存中心点”的核查结论，写出的桥接仍刻意只保留生命周期，页面定位路径没有改。

## 做法

1. 列出页面现有的地图状态出口（中心更新、定位按钮回调、标记），逐一接到原生地图：定位成功后 moveCamera(newLatLngZoom(...)) 并启用当前位置显示（MyLocationStyle 与 setMyLocationEnabled）；地图尚未就绪时暂存中心，就绪后再应用。
2. 定位来源为系统定位（WGS-84）而底图为高德（GCJ-02）时，进入相机前用 SDK 的 CoordinateConverter（GPS 类型）或参考工程的坐标适配器转换。
3. 从参考桥接有意裁剪能力时，按用户可见入口逐项确认裁剪后仍有效；页面仍依赖的 recenter、坐标适配要保留，或登记为未完成。
