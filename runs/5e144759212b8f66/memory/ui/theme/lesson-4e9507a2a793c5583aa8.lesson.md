# 按源端控件的实际色值在颜色资源里反查同值键，不按 accent、primary 等名称选键

ID：`lesson-4e9507a2a793c5583aa8` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，为按钮、背景、文字设置颜色资源引用时

## 适用情境

源端颜色以 shapeSolidColor、background、textColor 等硬编码色值或色值资源给出；目标工程已有多组语义名相近但色值不同的颜色资源（如脚手架留下的 color_accent 与迁移出的 brand_accent）。

## 原因

资源名只表达意图，模板或脚手架生成的 accent 可能是默认蓝；按名字选键时代码看似引用了主题色，渲染出的颜色却与源端不同，编译和结构检查都发现不了。来源中实现者照抄了按钮高度、圆角与字色，唯独背景按名字选了蓝色 accent，而工程里另有与源端色值相同的键，直到视觉回归才被发现。

## 做法

1. 取源端控件的实际色值（展开 shape、selector、style 后的最终值），在 color.json 中找同值键引用并核对该键的值；没有同值键就新增语义资源，不借用名字相近的键。

## 来源（按需复核）

经验是有适用范围的历史建议。核查来源时同时看结论与 unknown；来源卡未随阅读包复制。
