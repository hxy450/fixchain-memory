# process/task-handoff

跨任务移交：留给别的文件、切片或编排者兑现的工作如何登记、分派、接收与闭合，以及各类占位的使用边界

## 本级经验

- [“不确定”“待补资源”“延期”这类占位只登记输入确实缺值的情况；源码已写明、能实现的行为当场实现](lesson-a2f6a4ae9a72be740de6.lesson.md)
  - 时机：页面转换阶段决定是否登记 forward-ref-uncertain、resource-pending-asset 等占位，以及收口或验收阶段把这些占位改成 deferred 时
  - 情境：工程提供多种占位类型（不确定值、待补资源、延期），页面规格置信度为 medium 或同名资源看似存在；源码和规格其实已给出行为或所需图形。
  - 例外：缺的确实是输入里没有的值，例如合成快照缺少尺寸、资源映射表里没有对应资产
- [派工转述编码禁令时连同原文里的替代写法一起下发；禁止并发构建的 worker 改动，汇总后立即全量构建](lesson-73a7dd4f78cb747f7e7e.lesson.md)
  - 时机：编排或返修阶段，把规则清单转述进 worker 派工，并决定 worker 能否自行构建时
  - 情境：编排者收到的规则原文带有替代写法（例如“禁止 Record，改用具名字段或 HashMap”），派给多个并发 worker 时压缩成一句禁令，并要求 worker 不跑全量构建。
- [编排者推进阶段或派发下游前，先核对子任务的约定产物和回报里的待接事项，再逐项兑现规范划给自己的步骤与点名给别人的事项](lesson-5754b7be28238f1bdf57.lesson.md)
  - 时机：执行编排阶段，子任务返回后决定推进到下一阶段，为下游切片、接线任务写派工时，以及处理巡检报告中的阻断项时
  - 情境：执行规范把某些收尾步骤（如资源阶段之后的应用身份落地）留给编排者亲自调用；子任务返回的 open_questions、风险项或文件头说明，把某项工作指给另一个阶段、切片或编排者本人；也包括后台子任务回报 completed，但约定产物（如清单 JSON）没有落盘、回报文字被截断，或回报提到一个需要在别处调用的入口（如网络初始化函数）却没写调用点；以及巡检报告列出多个 BLOCKER，编排者派发修复失败（如线程上限）或只修其中一部分。
- [要靠其他文件或任务补实现的功能，登记成带负责方、验证方式和源端确定值的移交项，不只写在注释或动作摘要里](lesson-4f81eeea17b94190c2de.lesson.md)
  - 时机：页面转换、切片实现、基础设施实现或接线阶段，本文件的功能需要别的文件补调用点、或要由后续步骤补值才完整时（包括留下前向引用、TODO 占位、需要在入口调用的初始化函数），以及读到上游留给本文件的移交说明时
  - 情境：写码者确认某项行为在当前文件里无法闭合（例如非入口组件的平台回调要由入口页转发、宿主回调留给接线切片、脚手架身份值留给后续步骤、新建的 init 要由入口调用、UI 转换阶段先留业务占位），工程提供了移交登记约定（如带 owner/what/verify 的 HANDOFF 标记、前向引用登记表、返回信封中的字段）；或接线者在上游文件头读到要求本文件转发的说明。
- [解决前向占位时按登记的触发文本逐项兑现：只接一半、写成常量或删掉标记都不算闭合](lesson-eb4de4fd7452308a0483.lesson.md)
  - 时机：切片实现或接线阶段，把页面转换留下的前向占位（FWD-REF、TODO）替换成实现并删除标记时
  - 情境：页面转换阶段按“只输出 UI”约束留下前向占位，登记表或 TODO、文件头注释写有触发文本，例如“持久化并触发主题立即切换”“切换步骤时重触觉”“由服务提供版本号”“通知授权由平台服务实现”“游客登录（登录成功跳主页）”，由后续切片或接手者实现。
