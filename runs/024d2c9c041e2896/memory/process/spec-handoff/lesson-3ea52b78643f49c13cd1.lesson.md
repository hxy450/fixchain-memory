# 合成快照里空的点击或导航清单不能当作“无交互”：按源布局点击绑定与规格导航表实现，目标页未建就登记前向引用

ID：`lesson-3ea52b78643f49c13cd1` · 版本：1

[本主题](index.md)

## 何时使用

页面转换阶段，把源布局的按钮点击落实为 onClick 与页面跳转（或前向引用占位）时；规格提取阶段生成页面快照的点击清单时

## 适用情境

页面 UI 快照由布局合成（view_xml_synthesized=true），meta.json 的 clickable_elements、navigation_targets 为空或标注部分置信；Android 用 DataBinding android:onClick=“@{page::onClickXxx}”绑定点击，跳转写在 Fragment 方法里；页面规格的导航关系表列出代码触发的目标页，目标页可能尚未生成。

## 原因

合成快照识别不了 DataBinding 点击，空清单只说明提取失败，不说明源端没有交互；据此写出没有 onClick 的可见按钮且不登记前向引用，后续按标记接线时也找不到它。来源中转换者读到了带 onClick 的源布局、规格导航表和“目标未建由前向引用兜底”的规则，仍按空清单判定无交互，回执声明“没有引入 forward-ref”。

## 做法

1. 写页面前在源布局检索 android:onClick、@{page::...} 等点击绑定，把规格导航关系表逐条对应到页面 handler；快照清单为空不作为省略依据。
2. 目标页已存在就经注入的 NavPathStack pushPathByName 到已注册路由；未建就写已登记的前向引用标记（含 resolve_by），不留下没有 onClick 的可见按钮。
3. 规格提取合成点击清单时计入 DataBinding 的 onClick；解析不出时标为未知，不写空数组。
