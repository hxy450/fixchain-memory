# match_parent/0dp 加同轴 margin 表示“父尺寸减边距”：不写成百分比加 margin，等权重兄弟的间距改用 space

ID：`lesson-75f4743dff663f50966b` · 版本：2

[本主题](index.md)

## 何时使用

界面实现阶段，把 match_parent 或两侧约束 0dp 且带同轴 margin 的视图、或带 margin 的等权重兄弟翻译成 ArkUI 尺寸与间距时；按要求调整左右边距时

## 适用情境

源元素 match_parent（或约束到父两侧的 0dp）同时设 layout_marginHorizontal/Start/End 或 marginTop/Bottom；或水平 LinearLayout 中等权重（0dp + weight）的子项以 marginStart 作间距；目标用 width/height('100%') 或 layoutWeight。

## 原因

Android 中这类元素的尺寸是父尺寸减去同轴边距，权重也在扣除 margin 后分配；ArkUI 的百分比尺寸按父尺寸计算、margin 再向外扩，layoutWeight 的份额也包含子项自身 margin。结果是横向右溢（没有右边距、行尾截断、贴屏）、纵向在 Stack 中超高并被默认居中顶穿、等权重卡片不等宽。映射参考只做逐属性对应、没有这条规则时，多个页面会重复同一偏差；用户要求加大边距时改子项 margin，溢出会更明显。又一应用的首页统计卡同样由 match_parent + 左右 18dp 写成 width('100%') 加左右 margin，修复改为 calc(100% - 36vp)。

## 做法

1. 同轴有 margin 时，把边距放到父容器或新增包装容器的 padding 上，子项只保留 '100%'；父级还有需要贴边的兄弟时，用包装容器、layoutWeight 或 calc(100% - 边距之和)。
2. Stack 叠层中 match_parent 加纵向 margin 的层，用外包容器的 padding 承接内缩，内层 '100%' 相对其内容区。
3. 等权重兄弟以 margin 作间距时，删掉 margin，改用父 Row/Column 的 space（或固定宽的 Blank），让 layoutWeight 只分配扣除间距后的空间。
4. 写完 grep 同一修饰链里 width/height('100%') 与同轴 margin 的组合；意识到这条规则后把同页的按钮、卡片、列表行一起改；按要求加大边距时改容器 padding 的数值。

## 可选检查

- 用布局 dump 或截图核对左右间距对称、右缘不越出父容器、等权重项宽度相等。
