# 源端独立窗口的对话框改成页内覆盖层后，在宿主 onBackPressed 里自顶向下逐层关闭，全部关闭后才进未保存门禁或出栈

ID：`lesson-396d54479492828eeea3` · 版本：1

[本主题](index.md)

## 何时使用

页面转换阶段，把 BackHandler 与 AlertDialog/ModalBottomSheet 改写成 NavDestination.onBackPressed 加页内覆盖层时

## 适用情境

源页用 BackHandler 处理行内编辑器或未保存门禁，另有 AlertDialog、Dialog 或 ModalBottomSheet 以 onDismissRequest 关闭；目标把这些弹层做成页内 Stack 覆盖层或由 activeDialog 一类状态驱动的组件，系统返回统一交给宿主。

## 原因

Compose 的对话框是独立窗口，系统返回先触发它的 onDismissRequest，BackHandler 只在没有对话框时才收到。只翻译显式的 BackHandler，页内覆盖层打开时按返回会走到保存或丢弃门禁，甚至直接出栈。来源中转换者读过源端 BackHandler 和各对话框的 onDismissRequest，把对话框搬进页面树后，onBackPressed 只处理了编辑器和门禁两支。

## 做法

1. 列出本页所有可叠加的层（页内对话框、自绘底部弹窗、行内编辑器），onBackPressed 按从上到下判断：最上层可见就只调用它的关闭回调并 return true。
2. 所有层都关闭后才进入未保存门禁或出栈。
3. 输出前对 activeDialog 的每个取值和打开的编辑器各模拟一次返回，确认不会触发保存、丢弃或 pop。
