# 全屏窗口的底部避让：导航指示条取 bottomRect，贴底按钮与 bindSheet 内容都要叠加避让值

ID：`lesson-0e1c846868f2683cc280` · 版本：1

[本主题](index.md)

## 何时使用

沉浸式安全区实现阶段，测量导航指示条避让区，并为底部按钮行或贴底弹层确定底部间距时

## 适用情境

目标页面在 setWindowLayoutFullScreen(true) 下用 getWindowAvoidArea 测避让值，写入页面或全局窗口模型；Android 源布局的底部按钮行、底部 sheet 没有导航栏间距（源窗口不延伸到导航栏下，BottomSheetDialog 由系统处理 inset）。

## 原因

TYPE_NAVIGATION_INDICATOR 的避让区在窗口底部，值在 bottomRect；复制 TYPE_SYSTEM 那一行只改常量会读成 topRect（恒为 0），这种写法一旦被收敛进全局窗口模型，所有页面的底部避让都变成 0。另一方面，源 XML 没有底部间距是因为源窗口不延伸到导航栏，目标全屏窗口会延伸，照 XML 写就贴屏底；bindSheet 内容贴屏底布局，也不会自动避让。来源中页面写者以“视频铺满、源端也没有底部避让”为由不消费底部值，sheet 写者照抄了 XML 的 paddingBottom。

## 做法

1. 按避让区方位取矩形：TYPE_SYSTEM 取 topRect.height，TYPE_NAVIGATION_INDICATOR 取 bottomRect.height；复制测量代码时同时核对矩形字段。
2. 把页面测量收敛成共享窗口模型前，对照沉浸式参考或工程内已正确的实现逐字段核语义，不直接照搬现有页面片段。
3. 全屏页的底部 CTA、贴底浮层与 bindSheet 内容都叠加底部避让值（子组件由宿主经 @Param 注入），不因源 XML 没有底部间距就判定无需避让。
