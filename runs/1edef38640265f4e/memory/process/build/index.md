# process/build

编译修复循环与构建结果判定：只改报错定位处、整文件重写时保留未报错写法，读全错误输出，失败构建不以警告或部分通过放行

[上一级](../index.md)

## 本级经验

- [编译修复只改报错定位的行与符号；必须整文件重写时逐段对照上一版，未报错的写法原样保留](lesson-29744eb694376e8acaca.lesson.md)
  - 时机：编译修复阶段，为修某条编译错误决定局部修改还是整文件重写时
  - 情境：修复循环用 here-string 或 Write 整文件重写页面来处理导入导出、@Entry 等报错，文件里还有未被报错的组件用法（页签 builder、状态绑定、导入等）。
- [编译检查按完整构建结果判定：读全 ERROR 列表与 COMPILE RESULT，构建失败只记 FAIL，不以“仅警告”“部分通过”放行](lesson-7426a20525e52e34c2e7.lesson.md)
  - 时机：验证阶段执行编译检查并决定是否标记阶段完成时；编译修复循环查看构建输出时
  - 情境：hvigor 构建输出重定向到文件，WARN 常排在 ERROR 之前；修复循环只截取错误文件前若干行；验收规范规定编译通过才 PASS、否则 FAIL 并继续修复循环。
