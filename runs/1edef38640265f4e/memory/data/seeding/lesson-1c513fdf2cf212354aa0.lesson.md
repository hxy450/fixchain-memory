# 演示/预置数据逐字段取自源端种子工厂与模板常量，不按功能名自拟样例

ID：`lesson-1c513fdf2cf212354aa0` · 版本：1

[本主题](index.md)

## 何时使用

数据层或演示数据切片实现阶段编写演示、预置数据内容时；规格提取阶段描述固定演示数据时

## 适用情境

源端用种子工厂（如 DemoDataFactory）及其引用的清单模板、主题常量构造固定演示数据：标题、目的地、相对今天的日期偏移、主题 key、备注、条目标题/分类/优先级/顺序、完成集合与完成时间；目标端要重建同一数据集，手边可能只有依赖类名或规格里的数量概括。

## 例外与边界

- 当前任务明确批准使用与源端不同的演示内容

## 原因

演示数据是首次打开即可见的行为，统计、进度、首页待办等派生展示都随它变化。只凭“演示数据”功能名或“2 条行程、10 项”的概括去写，会整套自拟：标题、日期、主题值与完成比例都偏离源端。来源中实现者手上有种子类名与规格指针却没打开，写出另一组行程、以颜色值代替主题 key、全部未完成的条目。

## 做法

1. 打开种子工厂及其引用的模板与主题常量，逐字段搬运：标题、目的地、日期偏移、主题 key 原值（不换成颜色值或译名）、备注、条目标题/分类/优先级/排序、完成集合与完成时间偏移；源端按“今天±N”生成的，目标也按运行时的今天计算。
2. 规格提取时把这份数据表完整写进规格（每项的值，而非只写数量与比例），供实现阶段直接对照。
