# 第三方单页 H5 切状态时 URL 可能不变，用 runJavaScript 探测页面标记判状态

审的是：代码
触发（任一种）：
- 读到：安卓端 WebView 加载第三方单页 H5，H5 内部切换状态时地址栏不一定变化；写错的样子：H5 状态只在 onOverrideUrlLoading / onPageEnd 里按 url.includes(...) 这类 URL 子串判定，没有 runJavaScript 探测页面内容
- 写错的样子：runJavaScript 探测脚本已能返回几种状态标记，处理分支却只处理其中一部分（某个标记没有对应的显隐赋值）
适用范围：Web 组件里的第三方单页 H5，宿主要按 H5 当前状态调整原生界面时
做法：
- 用 this.controller.runJavaScript(script) 让脚本返回页面特征（标题文字、DOM 标记）字符串，按返回值映射成状态；脚本能返回的每个标记都要有处理分支
- 在页面事件（onPageEnd）和短周期探测（setInterval，卡里收敛到 100ms）里都执行这次探测，覆盖进入新状态的瞬间
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- runJavaScript(script: string): Promise<string>：WebviewController 在当前页面异步执行脚本，Promise 结果是脚本返回值；执行失败或没有返回值时是 null（出处：鸿蒙 SDK 的 ets/api/@ohos.web.webview.d.ts，WebviewController.runJavaScript）
- runJavaScript(script: string, callback: AsyncCallback<string>): void：同族接口：WebviewController.runJavaScript 的回调重载（出处：鸿蒙 SDK 的 ets/api/@ohos.web.webview.d.ts，WebviewController.runJavaScript）
- onPageEnd(callback: Callback<OnPageEndEvent>): WebAttribute：页面加载结束时回调，只对主框架触发（出处：鸿蒙 SDK 的 ets/component/web.d.ts，WebAttribute.onPageEnd）
- onOverrideUrlLoading(callback: OnOverrideUrlLoadingCallback): WebAttribute：URL 即将加载时回调；URL 不变的单页切换不经过它（出处：鸿蒙 SDK 的 ets/component/web.d.ts，WebAttribute.onOverrideUrlLoading）
- 800ms 探测时进入子状态的瞬间出现双返回；改成 100ms 并识别页面标题特征后消除：探测周期要短，标记要覆盖每个状态（出处：卡里修好并验证过）
针对本应用要查的：
- 各 H5 状态能稳定识别的页面标记：目标运行时 H5 页面的 DOM（标题元素文字、各状态特有的文字或节点）；为每个状态挑一个只在该状态出现的标记，写进探测脚本的返回值
未核实：卡里没记鸿蒙 SDK 版本；签名按本机 API 23 核对，100ms 探测的效果出自卡里那次运行的版本
