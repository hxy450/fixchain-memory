# Web 页宿主返回/标题栏按 H5 各状态逐一给出显隐，回到首页态要恢复

审的是：代码
触发（任一种）：
- 读到：安卓页面在 WebView 上方放原生返回和标题栏（Toolbar），WebView 加载第三方单页 H5；写错的样子：为消除顶栏重复，把 Web 组件上方的原生返回 / 标题 Row 整行删掉；H5 首页没有自带导航栏时页面上就没有返回和标题
- 写错的样子：宿主栏显隐用一个 @State 布尔控制，只在命中某些子页时置 false，没有任何分支把它置回 true
适用范围：鸿蒙页面用 Web 组件加载第三方 H5、宿主自带原生返回和标题栏，H5 有的状态自带导航栏、有的没有时
做法：
- 先列出 H5 各状态（首页、结果、查单、选择页等）哪些自带导航栏、哪些只靠宿主栏；宿主返回 / 标题 Row 保留，用 @State 布尔包成 if (visible) { Row() { … } }，只在自带导航栏的状态隐藏
- 显隐写成「当前 H5 状态 → 显示或隐藏」的完整映射：每次判定都显式赋值（如 switch 的每个分支都写 visible = true / false），首页态赋 true，不写只会置 false 的单向分支
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 逐状态双向映射：每个探测到的状态都明确给出宿主栏显示或隐藏，从子状态返回首页时恢复显示：修好后保留的显隐写法（出处：卡里修好并验证过）
针对本应用要查的：
- H5 各状态里哪些自带返回 / 标题栏：源端安卓页面加载的 H5 地址，以及参考截图里各状态的顶栏；逐个状态记下顶栏来自宿主还是 H5，自带导航栏的状态隐藏宿主栏，其余显示
