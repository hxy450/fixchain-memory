# 闭合「等价于源端谓词」的占位时，打开谓词源码逐条复刻全部条件

审的是：代码
触发（任一种）：
- 写错的样子：闭合「等价于源端某谓词」的占位后，实现只剩一个 id 相等比较，传给行组件 `@Param` 的在播或选中标志漏了源谓词里的其他条件，注释却写「等价，已闭合」
适用范围：接线阶段闭合占位登记里「等价于源端某谓词（类名.方法名）」的条目时
做法：
- 先打开源码里这个谓词的定义，把它的每个条件（类型判断、id 匹配、服务是否在运行、当前状态是否为播放中等）逐条列出，目标表达式用 && 全部写上
- 同一任务里已有按全部条件判定的 helper 时直接复用，不按同类页先例另写只比 id 的表达式；写完全仓搜同名判定，核对各页口径一致
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 只比 id 的在播判定在暂停后仍得到同一 id，行和卡片继续显示暂停按钮并高亮；补上「服务在运行且状态为播放中」后暂停即恢复：漏掉条件的实际后果（出处：卡里修好并验证过）
针对本应用要查的：
- 源端谓词的完整条件：源工程里按占位登记写的类名.方法名找到方法体；把 return 表达式拆成各个条件，逐个对应到目标端能拿到的状态
