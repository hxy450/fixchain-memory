# 指定为唯一尺寸来源的布局信息

agent 会看到什么：读到用户或派工指定某个布局信息为预览尺寸唯一来源、源端 Kotlin 按尺寸类型 when 分支返回固定宽高；产物里尺寸函数在取布局盒之前先按内容比例另行 return，并有单测锁定这个旁路

## 规矩

- rule-1ff4cce19697｜指定某布局信息为尺寸唯一来源时，所有分支先取该布局盒，不保留按内容比例的旁路｜读到：用户或派工指定某个布局信息为预览尺寸唯一来源，源端 Kotlin 里它按尺寸类型 `when` 分支返回固定宽高；写错：目标尺寸函数在取布局盒之前先按内容比例 `return` 另一套尺寸，并新增单测（`it(` / `expect(`）锁定这个旁路
