# 指定某布局信息为尺寸唯一来源时，所有分支先取该布局盒，不保留按内容比例的旁路

审的是：代码
触发（任一种）：
- 读到：用户或派工指定某个布局信息为预览尺寸唯一来源，源端 Kotlin 里它按尺寸类型 `when` 分支返回固定宽高；写错的样子：目标尺寸函数在取布局盒之前先按内容比例 `return` 另一套尺寸，并新增单测（`it(` / `expect(`）锁定这个旁路
适用范围：预览或容器尺寸已被用户、输入指定以某布局信息为唯一来源时的尺寸计算代码
做法：
- 所有分支（包括动态内容比例）都先取该布局盒的宽高，再在盒内适配内容
- 删掉旁路分支，也不新增锁定旁路的测试
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 修好后该尺寸类型直接返回布局信息里的宽高：动态内容不再走固定宽乘比例（出处：卡里修好并验证过）
