# 把指向平台切片的 FWD-REF 标为已解决前，核对它是真接线还是已登记审批的占位

审的是：代码
触发（任一种）：
- 读到：页面里有指向平台切片的 `FWD-REF` 标记，占位登记写明由平台服务实现，决策账本对应条目 approved；写错的样子：删掉 `FWD-REF` 标记后，对应的 @State / @Local 状态字段没有任何地方赋值；或把它解成恒 false、开启即复位 false
适用范围：接线阶段解决页面里指向平台能力的前向引用时
做法：
- 动手前先读决策账本里该条目选定的方案、所属功能规格和切片计划，按选定方案接线
- 标为 resolved 前逐项核对：字段由真实能力或服务状态驱动，或者是按规则登记并已审批的占位；两者都不是的不删标记
