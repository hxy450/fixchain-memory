# 解决外链或常量类 FWD-REF 时从源码行或验收条目取值，取不到登记缺口，不写推测值

审的是：代码
触发（任一种）：
- 读到：注册表或 FWD-REF 只给了外链或常量的泛称，api-inventory 或验收条目里有指向源码 openUri 那一行的证据；写错的样子：解决 FWD-REF 时写进的网址或常量在源码、注册表、验收条目里都找不到原文（例如把更新日志链接猜成发布页链接）
适用范围：实现阶段解决涉及外链、常量的前向引用时
做法：
- 先打开注册表、api-inventory 指向的源码行或对应验收条目，照抄原值写进代码
- 取不到确切值就在注册表登记缺口，不写推测值
针对本应用要查的：
- 这个外链或常量的确切原值：源工程里 api-inventory 证据指针指向的 .kt 文件，按 openUri( 搜；或规格里写这个点击目标的验收条目；读出字符串字面量原样照抄
