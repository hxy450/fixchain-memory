# 替换页面壳的 FWD-REF 时，以壳上声明的展示字段为清单逐项接数据，源模型有的必须映射

审的是：代码
触发（任一种）：
- 读到：界面转换者生成的 UI 壳里展示项的 `class` / `interface` 已声明一组字段（如温度区间、天气图标和文案、定位项），源模型或目标数据模型已带对应的原始字段（天气码、最低最高温度）；写错的样子：切片实现者替换 `FWD-REF` 时写的映射函数只赋了 id、名称、选中等少数字段，壳上声明的展示字段留空或始终为空
适用范围：功能切片实现阶段把数据模型映射成 UI 壳的展示项、替换 FWD-REF 占位时
做法：
- 以 UI 壳展示项已声明的字段为清单，逐项写出数据来源；源模型已带的字段必须映射到展示项（如天气码转成图标和文案，最低最高温度映射成区间）
