# 解除 FWD-REF 时按登记表和页面 spec 的完整触发条件逐项实现，只做了一部分不删标记

审的是：代码
触发（任一种）：
- 读到：占位登记表里这个 P-ID 的 `forward-ref` 条目写着几项触发条件（如「合成、保存并路由到结果页」），页面 spec 的导航表写了成功后的去向；写错的样子：代码里删掉了 `FWD-REF` 标记，但只实现了其中一部分（如只把结果写进 Store，没有跳转）
适用范围：功能切片接线时，解除代码里的前向引用（FWD-REF）标记时
做法：
- 解除前读出这个 P-ID 在占位登记表和页面 spec 里的完整触发条件，逐项实现（如合成、保存、进入结果页）
- 只完成其中一部分时保留 `FWD-REF` 标记，不报告为 resolved
