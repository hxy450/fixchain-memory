# 派工要的槽位在源布局里没有对应节点时，不自行放到常见位置，在返回报告列冲突

审的是：代码
触发（任一种）：
- 读到：派工要求本页生成某组件的 `@Builder` 空槽位并登记 FWD-REF 占位，而读到的源 Activity 布局 XML 里没有对应的容器或 include；写错的样子：页面的 build() 里在内容区和 Tab 栏之间多了一个槽位方法的调用、一个空的 `@Builder` 方法和占位登记（后来又被填成组件调用并 import），返回报告里没有冲突项
适用范围：页面转换阶段，派工指定的槽位或嵌入组件在源布局里找不到对应节点时
做法：
- 返回报告里把它列为 conflict：写明派工要求的槽位、源布局里缺的节点，请求确认
- 不把槽位自行放到「常见位置」；确认源页面没有这个组件的，删掉 build() 里的槽位调用、对应的 @Builder 方法和组件的 import
