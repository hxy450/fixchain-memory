# 接不了的跨切片方法登记 FWD-REF 并写对属主，收口时委托属主核心，不留空本体

审的是：代码
触发（任一种）：
- 读到：规格要求各清理序列（打开设置、onPause、相机关闭）调用停止方法，并真正停止；写错的样子：停止方法本体为空，只有自由文本注释「由某切片接线」，没有 FWD-REF，属主也写错
- 读到：属主模块里已有停止核心方法（如 finish(cancelled) 里取消时丢批）；写错的样子：收口时只给空方法加 void fromUser; 消除未用参数告警，本体仍为空
适用范围：切片 worker 写跨切片调用、closer 解除占位时
做法：
- 接不了的跨切片方法登记 FWD-REF（占位登记表加一行），属主写成真正持有该逻辑的 feature / 模块
- 收口时把方法委托给属主的停止核心，如 stopX(fromUser: boolean) { this.owner.stopX(fromUser) }，不以 void 参数了事
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 停止方法改为委托编排器的停止核心后，各清理路径真正停止会话：委托而不是空实现（出处：卡里修好并验证过）
