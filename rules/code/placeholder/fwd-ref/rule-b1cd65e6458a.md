# 解除设置占位时把字段块里全部字段逐项接线，grep 不到本地默认值再标已接线

审的是：代码
触发（任一种）：
- 读到：移交表的 P-S… 占位写「设置存储消费接线」，占位所在页面有一整段本地设置字段块；写错的样子：收尾者只给其中一个字段加 collect，就在注释里标「P-S…（已接线）」，其余字段仍是本地写死值
适用范围：收尾阶段解除设置类接线占位时
做法：
- 以占位所在字段块的全部字段为接线清单逐项改成读设置存储；解除后 grep 该块不再有本地默认值，再标记已接线
来源：1 张卡，1 个应用
