# 结构闸报 naked-TODO 时，补 marker 或登记 registry，不改写成普通注释

审的是：代码
触发（任一种）：
- 读到：结构闸报 naked-TODO FAIL，suggested_action 写的是补 marker 或登记 registry；写错的样子：代码里标着功能缺口的 `TODO(...)` 被改写成普通说明注释（如「视觉差异注记」），功能仍缺失，既没补 marker 也没在 registry 登记
适用范围：编译修复和收尾阶段处理代码里的 TODO 和结构闸的 naked-TODO 报告时
做法：
- 按 suggested_action 处理：给这个 TODO 补上流水线要求的 marker，或在 registry 里登记这个缺口；不把 TODO 改写成普通注释绕过门禁
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- TODO 被改写成普通注释后缺口通过了债务门禁，生成结束时功能仍缺失：改写注释的后果（出处：卡里修好并验证过）
