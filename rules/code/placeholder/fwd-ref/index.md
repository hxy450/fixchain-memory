# 代码里的 FWD-REF 占位

agent 会看到什么：读到派工、占位登记表或代码注释里的 FWD-REF 标记（P-ID 条目、要实现的源方法、外链常量、平台切片、页面壳的钩子），交回的代码生成、替换或删掉了这个标记

## 规矩

- rule-b57c0be502dd｜解除 FWD-REF 时按登记表和页面 spec 的完整触发条件逐项实现，只做了一部分不删标记｜读到：占位登记表里这个 P-ID 的 `forward-ref` 条目写着几项触发条件（如「合成、保存并路由到结果页」），页面 spec 的导航表写了成功后的去向；写错：代码里删掉了 `FWD-REF` 标记，但只实现了其中一部分（如只把结果写进 Store，没有跳转）
- rule-c75cc666f48b｜把指向平台切片的 FWD-REF 标为已解决前，核对它是真接线还是已登记审批的占位｜读到：页面里有指向平台切片的 `FWD-REF` 标记，占位登记写明由平台服务实现，决策账本对应条目 approved；写错：删掉 `FWD-REF` 标记后，对应的 @State / @Local 状态字段没有任何地方赋值；或把它解成恒 false、开启即复位 false
- rule-853c6f26f2cf｜替换页面壳的 FWD-REF 时，以壳上声明的展示字段为清单逐项接数据，源模型有的必须映射｜读到：界面转换者生成的 UI 壳里展示项的 `class` / `interface` 已声明一组字段（如温度区间、天气图标和文案、定位项），源模型或目标数据模型已带对应的原始字段（天气码、最低最高温度）；写错：切片实现者替换 `FWD-REF` 时写的映射函数只赋了 id、名称、选中等少数字段，壳上声明的展示字段留空或始终为空
- rule-a7784bc06877｜实现共享快照的加载钩子时只合并本切片字段，不新建快照整体替换，失败只局部重试｜读到：组件的 @State 快照里有账户、开关、提醒等不归本切片的字段，本切片的 `FWD-REF` 钩子只负责某个远端接口；写错：钩子里整段放进本切片运行时调用的 try { … } 中，新建快照对象只映射本切片字段再整体赋给 this.snapshot；catch 里把整块区域换成错误和重试
- rule-716d2eae5317｜解决外链或常量类 FWD-REF 时从源码行或验收条目取值，取不到登记缺口，不写推测值｜读到：注册表或 FWD-REF 只给了外链或常量的泛称，api-inventory 或验收条目里有指向源码 openUri 那一行的证据；写错：解决 FWD-REF 时写进的网址或常量在源码、注册表、验收条目里都找不到原文（例如把更新日志链接猜成发布页链接）
- rule-8392458839f8｜源码调用工程内的取值辅助方法时，目标按它的源定义逐分支移植兜底链｜读到：源码在显示文案或可见性判断里调用工程自己模型类或工具类的取值辅助方法，方法体是多级兜底，每级用 isNotBlank( 之类做空白判断；写错：目标里对应的函数兜底顺序或字段和源定义不同、少了一级，或只判 `!== null` 而源端判的是空白；目标模型缺这个方法时在调用处内联了一个按方法名猜的简化表达式
- rule-3e57607aa9bf｜派工要的槽位在源布局里没有对应节点时，不自行放到常见位置，在返回报告列冲突｜读到：派工要求本页生成某组件的 `@Builder` 空槽位并登记 FWD-REF 占位，而读到的源 Activity 布局 XML 里没有对应的容器或 include；写错：页面的 build() 里在内容区和 Tab 栏之间多了一个槽位方法的调用、一个空的 `@Builder` 方法和占位登记（后来又被填成组件调用并 import），返回报告里没有冲突项
- rule-443ee7f34442｜源页面自带权限检查、申请、授权跳转和拒绝提示时，目标本页实现完整链路，不写成只有注释的 FWD-REF｜读到：源 Activity 页内自带 isGranted(...) 校验 → 确认弹窗 → request(...) → onGranted 跳转下一页、onDenied 弹 Toast 的流程，只依赖本页；写错：目标的 aboutToAppear 权限校验和申请方法只有注释的 `FWD-REF`，确认弹窗的「确定」调用空方法，授权状态变量永远不会置 true
- rule-ce4213c69082｜接不了的跨切片方法登记 FWD-REF 并写对属主，收口时委托属主核心，不留空本体｜读到：规格要求各清理序列（打开设置、onPause、相机关闭）调用停止方法，并真正停止；写错：停止方法本体为空，只有自由文本注释「由某切片接线」，没有 FWD-REF，属主也写错
- rule-b1cd65e6458a｜解除设置占位时把字段块里全部字段逐项接线，grep 不到本地默认值再标已接线｜读到：移交表的 P-S… 占位写「设置存储消费接线」，占位所在页面有一整段本地设置字段块；写错：收尾者只给其中一个字段加 collect，就在注释里标「P-S…（已接线）」，其余字段仍是本地写死值
- rule-4c4c09041045｜结构闸报 naked-TODO 时，补 marker 或登记 registry，不改写成普通注释｜读到：结构闸报 naked-TODO FAIL，suggested_action 写的是补 marker 或登记 registry；写错：代码里标着功能缺口的 `TODO(...)` 被改写成普通说明注释（如「视觉差异注记」），功能仍缺失，既没补 marker 也没在 registry 登记
