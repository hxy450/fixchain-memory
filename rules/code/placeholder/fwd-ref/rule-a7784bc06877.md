# 实现共享快照的加载钩子时只合并本切片字段，不新建快照整体替换，失败只局部重试

审的是：代码
触发（任一种）：
- 读到：组件的 @State 快照里有账户、开关、提醒等不归本切片的字段，本切片的 `FWD-REF` 钩子只负责某个远端接口；写错的样子：钩子里整段放进本切片运行时调用的 try { … } 中，新建快照对象只映射本切片字段再整体赋给 this.snapshot；catch 里把整块区域换成错误和重试
适用范围：功能切片接线阶段实现多来源共享快照的加载钩子时
做法：
- 只把本切片负责的字段合并进现有快照（逐字段赋值或展开合并），不新建快照整体替换；账户等其他来源的加载放在本切片运行时调用之外
- 本切片失败时保留已渲染内容，只在本切片的区域给出可重试提示；写完逐个核对快照字段都有赋值来源
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 账户加载放到远端 try 之前独立执行，远端失败时保留已有快照，只给局部重试：修好的写法（出处：卡里修好并验证过）
