# 派工或壳注释点名要接通的控件

agent 会看到什么：读到派工的 cross_slice_edits、壳页 handler 注释或 FWD-REF 登记点名了源端 ImageButton 一类控件要接通；产物里只有 handler 函数和能力门控，build() 里没有调用它的 Button 或显隐分支

## 规矩

- rule-8eaedb734192｜规格或壳注释点名的按钮要在 build 里实际渲染并按门控显隐，不只实现 handler｜读到：派工的 cross_slice_edits 要求接通录像中拍照快照；壳页 handler 注释点名源端 ImageButton 控件，并带 FWD-REF 登记；写错：只写了 handler 函数和能力门控，build() 里录制控件组没有调用它的 Button
