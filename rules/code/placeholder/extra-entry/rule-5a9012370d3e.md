# 执行「按 Android 可达入口补 UI」前先找到源端控件，找不到就回报不适用，不新增按钮

审的是：代码
触发（任一种）：
- 读到：修复条目要求「按 Android 可达入口补 UI」，源布局 XML 和 Fragment 的 setOnClickListener 里找不到对应控件；写错的样子：ArkTS 页面新增源端没有的按钮行（如 `if (!isAuthenticated) { Row { Button(...) } }`），修复报告记为 FIXED
适用范围：巡检修复阶段按条目给页面补入口、补 UI 时
做法：
- 动手前定位源端的具体控件：布局里的 android:id、绑定它的点击监听、它所在的页面
- 该页找不到时把条目回报为不适用，不新增源端没有的按钮
- 改完后用 page spec 的组件表逐项核对页面的一级子节点，多出来的删掉
