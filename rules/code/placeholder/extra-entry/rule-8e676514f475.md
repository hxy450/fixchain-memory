# 在对等页面补替代页入口时不加源端没有的可见控件，改用已有区域的 LongPressGesture

审的是：代码
触发（任一种）：
- 写错的样子：对等页面的组件里新增源端没有的 Button / Image 入口（onClick 跳到替代页），挤压原有内容；源端该组件只有固定几个子元素（如地址文本 + 下拉箭头），台账又限定不得改变该页布局；输出里自称「未越界」
适用范围：为平台替代页在已对等复刻的页面上补入口时
做法：
- 加入口前逐项比对该组件的 Android 源子元素；出现源端没有的可见控件即视为越过作用域
- 改用隐式入口：在已有区域上写 .gesture(LongPressGesture().onAction(() => 跳转替代页))，布局和 padding 保持与源端一致；做不到就上报
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- (value?: { fingers?: number; repeat?: boolean; duration?: number }): LongPressGestureInterface：LongPressGesture 的参数，duration 是最短按住时长（毫秒）（出处：鸿蒙 SDK 的 ets/component/gesture.d.ts，LongPressGestureInterface）
- onAction(event: (event: GestureEvent) => void): LongPressGestureInterface：长按识别成功时的回调（出处：鸿蒙 SDK 的 ets/component/gesture.d.ts，LongPressGestureInterface.onAction）
- gesture(gesture: GestureType, mask?: GestureMask): T：给已有组件绑定手势，不改变可见结构（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.gesture）
- 移除新增按钮、padding 改回原值，把入口改为原区域上的 LongPressGesture：修好的写法，视觉复核标记 Fixed（出处：卡里修好并验证过）
