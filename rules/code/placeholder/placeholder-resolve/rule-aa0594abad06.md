# 解除 FWD-REF 时逐项兑现注释里的动画和共享元素，做不了的登记缺口

审的是：代码
触发（任一种）：
- 读到：代码里待解除的 `FWD-REF` 注释写着要兑现的内容（如「含缩放动画与共享元素」）；写错的样子：解除后只剩路由 pushPathByName(...)，注释里点名的动画、共享元素没有对应实现，也没有登记缺口，只留了注释或被删掉
适用范围：接线或收尾阶段解除 forward-ref 占位的代码
做法：
- 解除 `FWD-REF` 时把被引用注释里的每个名词逐项对到实现（缩放动画 → 缩放层或 customTransition，淡出 → animateTo，共享元素 → 对应写法）；路由 push 完成不等于这一项已解除
- 本片实现不了的那一项，在占位登记里显式登记成缺口（写明是哪个名词、源端出处），不静默删除
