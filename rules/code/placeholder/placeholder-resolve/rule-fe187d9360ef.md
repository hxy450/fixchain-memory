# 解除 FWD-REF 占位时不沿用本地取反，启停按真实监听状态，图标只由状态回调更新

审的是：代码
触发（任一种）：
- 读到：FWD-REF 占位只对图标激活态做本地取反，占位注释或登记写明激活态应由启动/停止回调写入；写错的样子：解除占位时保留取反（称「乐观更新」，`active = !active`），按取反后的图标态选启停；VM 门面没有启动/停止回调成员，页面没把状态转发给图标控制器，登记却标成 resolved
适用范围：跨切片接线阶段，解除图标、开关类 FWD-REF 占位，把它接到真实服务时
做法：
- 启停判断用真实监听状态（是否已有监听，或启动中标志），不用占位里的本地取反
- 图标只由启动/停止回调更新：VM 门面缺这些回调时先补门面成员，再在页面把它们转发到图标控制器
- 门面成员、页面转发、图标回调都接好后，才把占位登记项标为 resolved
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 门面增加启动中/已启动/已停止三项回调，页面转发三项状态，图标按「已激活或启动中」决定释放或启动：修复后的接线（出处：卡里修好并验证过）
