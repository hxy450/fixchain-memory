# 华为账号登录通道用 AccountKit 实现真实授权调用链，可见性门绑定配置条件，不恒返 null

审的是：代码
触发（任一种）：
- 读到：规格写着「Account Kit vs 占位，待裁决」，UI 规格写「可映射华为 Account Kit」，占位登记的 forward-ref 要求本切片建立鸿蒙等价入口；写错的样子：华为账号登录方法恒 `return null`，注释写「账号体系形态未定」「SDK 未入仓」
适用范围：实现源端华为账号授权登录通道、目标是 HarmonyOS 时
做法：
- 先查决策账本有无结论，再检索 SDK 的 hms/ets/kits 确认能力随系统提供
- 写真实调用链：const req = new authentication.HuaweiIDProvider().createAuthorizationWithHuaweiIDRequest(); req.scopes = ['openid']; const resp = await new authentication.AuthenticationController(context).executeRequest(req); 取 resp.data?.authorizationCode 交后端
- 运行期还依赖 AGC client_id、证书指纹等配置的，把渠道可见性门绑定到配置条件，不用恒 null 代替调用链
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- createAuthorizationWithHuaweiIDRequest(): AuthorizationWithHuaweiIDRequest：HuaweiIDProvider 上创建授权请求（出处：鸿蒙 SDK 的 hms/ets/api/@hms.core.authentication.d.ts，authentication.HuaweiIDProvider.createAuthorizationWithHuaweiIDRequest）
- AuthorizationWithHuaweiIDRequest.scopes?: string[]：请求的用户信息范围（出处：鸿蒙 SDK 的 hms/ets/api/@hms.core.authentication.d.ts，AuthorizationWithHuaweiIDRequest.scopes）
- AuthenticationController：constructor(context?: common.Context)；executeRequest(request: AuthenticationRequest): Promise<AuthenticationResponse>：执行授权请求（出处：鸿蒙 SDK 的 hms/ets/api/@hms.core.authentication.d.ts，authentication.AuthenticationController）
- AuthorizationWithHuaweiIDResponse.data?: AuthorizationWithHuaweiIDCredential，其中 authorizationCode?: string：从响应里取授权码（出处：鸿蒙 SDK 的 hms/ets/api/@hms.core.authentication.d.ts，AuthorizationWithHuaweiIDResponse.data）
- scopes=['openid'] → executeRequest → authorizationCode 的调用链构建通过；AGC client_id 和证书指纹未配置时渠道可见性保持关闭：卡里的修法（出处：卡里修好并验证过）
针对本应用要查的：
- 运行期依赖的配置：目标工程里 AGC client_id 的配置处和签名证书指纹的登记（按工程的配置方式找）；确认有无配置，决定渠道可见性门的条件
