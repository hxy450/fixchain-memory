# 接线把 FWD-REF 换成实现时，标记和规格里的每个守卫条件都写进代码

审的是：代码
触发（任一种）：
- 读到：FWD-REF 标记或规格写了守卫条件（某状态成功且账号非匿名已就绪才执行、只对失败态作废、加载中不动、按某字段小写排序）；写错的样子：实现只判一个条件、`else` 分支（含加载中）一律执行；注释照抄了条件或写「已规约」「已在被调函数处理」，代码却没做；调用参数和标记不一致
适用范围：接线阶段把 FWD-REF 标记替换成真实实现时
做法：
- 逐条把标记和规格里的守卫条件写成代码判断，每个状态分支各自处理，不用 else 兜住加载中等其余状态
- 用「已在被调函数中处理（如已排序）」省略逻辑前，先读被调函数确认它确实做了
- 标记和规格对同一调用的参数写法不一致时，回源码调用处核实后再写
