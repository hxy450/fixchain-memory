# 代码替换 FWD-REF 桩时，逐条对上登记指向的切片计划和验收项

审的是：代码
触发（任一种）：
- 读到：占位登记里的 `FWD-REF` 条目带 resolve_by，指向某个切片计划的某一步；功能计划里写着该切片的细则在哪个切片计划文件；写错的样子：代码里 `FWD-REF` 桩已换成实现，但状态机是自拟的：初始态、完成态、对话框出现条件、派生量的重算与切片计划引用的 AC 不符或相反
适用范围：实现阶段把 UI 转换留下的 `FWD-REF` 占位桩换成真实逻辑时，含编排者自己接手切片的情形
做法：
- 按登记的 resolve_by 打开指向的切片计划和它引用的验收项，把每条 AC 对到实现里的初始状态、转换、完成状态和弹窗条件，缺的、相反的照 AC 改
- 再对照源端实现这些行为的函数全文核对；读到的源码输出被截断的，按行号分段补读被截掉的函数体，不凭截断前的片段推想
针对本应用要查的：
- 这个桩该满足的验收项：计划与派工文档里的占位登记（找该 `FWD-REF` 条目的 resolve_by），顺着它找到切片计划，再找切片计划引用的规格验收项；逐条列出 AC 要求的状态和条件，作为核对实现的清单
