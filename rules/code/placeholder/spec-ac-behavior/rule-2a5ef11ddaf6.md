# 验收条目列出几项触发守卫时，每项都写成代码分支，不只抄进注释

审的是：代码
触发（任一种）：
- 写错的样子：规格验收条目列了一组守卫（如弹窗打开、相机在后台、正在拍照或计时、正在录像时都不触发拍照），触发函数的注释照抄了全部守卫，`if` 分支只写了其中几项；同次新增的弹窗探测方法没被调用
适用范围：功能实现阶段，按验收条目实现带守卫的触发逻辑（声控、快捷键等触发拍照或操作）时
做法：
- 验收条目里的每项守卫写成一个分支，任一成立就直接 return；工程里已有对应的探测方法（如弹窗是否打开）就调用它
- 写完逐项对照注释列出的条件和代码分支；可补一条单测：弹窗打开时调用触发函数不产生拍照
