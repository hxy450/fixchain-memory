# 规格 AC 写明的引擎调用要逐条落进 VM 方法体，不能只写偏好再重置

审的是：代码
触发（任一种）：
- 读到：规格的 AC 写明界面动作要经引擎完成会话切换（「完成某引擎调用后恢复」「重置 → 引擎方法 → 图标刷新」）；写错的样子：VM 的动作方法体只写偏好、再重置并翻转 UI 镜像状态，没有调用 AC 里写的引擎方法；方法上的注释写着「→ 引擎方法」，方法体里却找不到
适用范围：ViewModel 实现阶段，把源 Activity 的按钮动作落到目标 VM、而目标把会话切换放在独立引擎里时
做法：
- 把 AC 写明的引擎调用逐条写进方法体：动作直接调引擎的对应方法完成切换，切换后的模式从引擎回读，不用「写偏好 + 重置」代替
- 交付前逐条核对方法注释里写到的每一步都已出现在方法体中
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 动作改为调用引擎的切换方法，并从引擎回读模式：修好后切换镜头、切换录像真正改变相机会话（出处：卡里修好并验证过）
