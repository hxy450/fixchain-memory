# 规格 AC 给出端点和门控且 service 归本切片时，先在 service 里建好端点

审的是：代码
触发（任一种）：
- 读到：规格 AC 写明调用的 POST 端点和门控（成功后置单次标志、写全局配置、进程内只发一次）；写错的样子：本切片拥有的 service 里只建了别的端点，没有 AC 里的这个 POST 端点和门控标志，调用随 P-S… 占位留给后续切片
适用范围：规格 AC 已写清端点与门控、对应 service 归当前切片时
做法：
- 在 service 里按 AC 建好端点方法和门控（成功后置标志、只发一次），再按源端顺序接到调用处
- 只把跨切片的调用点留给 closer 接线，端点本身不留占位
