# 规格写了多步交互的面板，要实现每一步的状态和切换，只改字数上限和文案不算对齐

审的是：代码
触发（任一种）：
- 读到：规格或行为文档写面板是多步交互：先在底部对话框（Dialog）里编辑文字，再到内容图上拖动定位，最后确认或取消；写错的样子：面板只改了 TextArea 的 maxLength、placeholder 或标题，仍是输入后直接发送的单步流程，没有定位层和确认、取消
适用范围：界面实现或修复阶段，修改规格里写明多步交互的面板时
做法：
- 为每一步建状态（编辑中、定位中）和切换：编辑完进入覆盖在内容上的拖动定位层，确认才提交，取消退出定位
- 标题、字数上限、占位文案按规格改，但不把它们当成对齐的全部
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 改为编辑框、拖动定位层和确认/取消三步后保留：修好的做法（出处：卡里修好并验证过）
