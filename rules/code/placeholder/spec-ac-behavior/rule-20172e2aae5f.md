# 把页面逻辑下沉到服务层时逐条对照规格 AC 和源码，不把已有偏差写成服务契约注释

审的是：代码
触发（任一种）：
- 读到：规格的 AC 写着「两侧齐备才渲染（缺任一为空操作）」这类说法，源码守卫没有 else；写错的样子：新建的 Service 方法对 null 输入返回空结果，注释写「页面据此复位 UI 态」「等价 Android 无动作 + 清空渲染」这类和 AC 相悖的契约
适用范围：重构或下沉已有页面逻辑到服务层、模型类原样迁入时
做法：
- 迁入的每个分支逐条和规格 AC 及源码核对，已有实现里不符的先改正再迁；不把已有实现的偏差写成新服务的契约注释
来源：1 张卡，1 个应用
