触发（任一种）：
- 读到：源方法按偏好取值分多支（如 SharedPreferences.getString 读出的四个取值各自 setBackgroundColor 或只给标记上色），规格 AC 已逐条写了每个取值或每个分支的效果；写错的样子：目标的 if/switch 只区分其中一两个取值，注释写「…降级为…」并登记占位；或 if 条件换成别的变量、丢了某支里的赋值
适用范围：功能实现阶段，规格 AC 已列出的偏好矩阵、多分支逻辑在目标代码里的写法

- 分支要扩展另一片或共享组件才能完整时，在本片内扩展该组件（加 @Param 把取值传进去），不用降级实现加占位了事
