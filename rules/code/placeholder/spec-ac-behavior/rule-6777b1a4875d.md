# 对接点和已读源码的入口跳转冲突时，按源码接线并在回执里报冲突

审的是：代码
触发（任一种）：
- 读到：规格的对接点把列表项点击接到详情页，已读的源码里该按钮的 `onItemChildClick` 却先调查询接口、再 `startActivity` 进另一个结果页（只有 `setOnBannerListener` 进详情页）；写错的样子：替换 `FWD-REF` 占位时照规格在列表项按钮回调里用 `NavPathStack` 跳详情页；源码那条「查询 → 结果页」链路只接到别的页面，或没接
适用范围：功能切片实现阶段，按规格对接点给列表项按钮、Banner 等点击入口接线时
做法：
- 接线前在源文件里搜 setOnBannerListener|onItemChildClick|startActivity，核对页面每个入口的目标；和对接点冲突时按源码监听器的调用链接线（查询 → 首条结果进结果页，空结果提示）
- 在回执里写明规格对接点和源码的冲突、按源码接线的结果
