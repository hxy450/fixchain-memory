# AC 与已读源码语义冲突时按源码实现，并在迁移报告登记规格差异

审的是：代码
触发（任一种）：
- 读到：规格 AC 要求只列缺失项，而已读源码用 items(<全部预置项>) 列出全部；写错的样子：实现按 AC 用名称集合 filter 剔除已存在项，没有与源码对照，也没登记差异
适用范围：页面实现阶段落实列表、对话框类 AC，手里同时有源码时
做法：
- 按源码语义实现（始终列出全部默认项），不照 AC 写 filter
- 在迁移报告里登记这条规格差异：AC 原文、源码语义、实现取了哪一边
