# 规格状态有 error 且验收要求失败报错时，build 里每个结果态都要有渲染分支

审的是：代码
触发（任一种）：
- 读到：规格状态接口写 `'idle' | 'success' | 'error'`，验收标准要求失败时报错且不留成功状态；写错的样子：状态枚举里定义了 Error，build() 里没有消费它的分支；catch 里写了 Error 状态，但没有任何地方显示失败提示
适用范围：页面状态接口列出 error 等结果态、验收标准又要求失败可见时（源端失败路径没有界面也一样）
做法：
- 逐个结果枚举值确认 build() 里有渲染分支：Error 显示失败提示，同时清掉成功态，不留部分成功的状态
- 每个 catch 里写入的状态，都要在 build() 里找到消费它的分支；按验收条目把各操作的选择器失败、读写失败、解析失败各走一遍，各有可见提示
