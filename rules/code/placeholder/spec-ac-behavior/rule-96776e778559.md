# 按规格新增弹窗或权限请求前核对源端分支可达，三态条件和源码非空类型冲突时照源端行为

触发（任一种）：
- 读到：规格要求「无权限且设置未初始化」时弹窗，服务契约的参数是 boolean | null；源端该变量由 collectAsState(initial = false) 收集、非空；写错的样子：页面新增 @Local 状态 boolean | null，aboutToAppear 里读三态偏好后以 === null 为条件弹出对话框或请求权限，或新建只服务这一分支的协调服务

- 把规格三态条件和源码非空类型的冲突回报规格
