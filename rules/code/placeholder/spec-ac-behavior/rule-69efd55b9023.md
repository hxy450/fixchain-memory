# 注释只凭源码行号论证先后时，读被引用的源组件核对触发时机，冲突写进 decision_gaps

审的是：代码
触发（任一种）：
- 读到：上游契约注释要求「自增须挂在判定之后」，依据只有源码行号，被引用的判定其实在 Composable 的 LifecycleEventEffect 里；写错的样子：新写的注释用源码行号论证先后（「源序 :N 判定先于 :M 自增」这类），沿用了上游次序却没写进 decision_gaps
适用范围：实现阶段沿用上游代码契约注释里的先后要求时
做法：
- 先后只有行号依据时，打开被引用的源组件核对触发时机（如 LifecycleEventEffect(ON_CREATE) 在 onCreate 返回后首次组合时才执行）
- 与源码实际时机冲突时写进 decision_gaps，不在注释里补行号依据
