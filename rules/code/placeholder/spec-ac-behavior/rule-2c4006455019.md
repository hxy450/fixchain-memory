# 自研等价清单组件逐条落实规格 AC：读偏好键传档位、拖拽排序、hint 为真实子项，不加源端没有的行为

审的是：代码
触发（任一种）：
- 读到：源端 ChecklistManager 配置链 showCheckMarks / keepChecked / moveCheckedOnBottom / newEntryHint，勾选移动档位由偏好设置决定；规格 AC 写了偏好档位映射、拖拽排序、hint 为真实子项；写错的样子：自研组件只有 Checkbox + TextInput 行和底部独立的 hint 草稿 TextInput，没有勾选移动档位和拖拽排序；页面不读该偏好键；或多了源端没有的行为（如转换后弹撤销条）
适用范围：目标端无直替、要自研与源端三方控件一比一等价的组件和它的页面接线
做法：
- 把规格里每条 AC 对应到代码位置：勾选移动档位、拖拽排序、hint 作为列表里真实的一项
- 页面层读取相关偏好键并作为参数传给组件
- 不新增源端没有的行为，如转换时的撤销条
