# 目标数据模型的多值枚举字段写枚举类型，注释不写 0|1

审的是：代码
触发（任一种）：
- 读到：源端设置是 Int 列，按 toEnum<枚举>() 转成三值枚举使用；写错的样子：目标模型写 @Trace 字段: number，注释「(0|1)」「Int 0/1」
适用范围：目标端设置数据模型里承载源端整型枚举的字段
做法：
- 定义 enum（值按源端 ordinal：如 Auto = 0、Always = 1、Never = 2），字段注释引用 feature 规格的枚举表，不写 0|1
针对本应用要查的：
- 枚举各值的 ordinal：源工程里这个枚举类的声明；按声明顺序从 0 编号
