# 共享模型的枚举成员和持久化值

agent 会看到什么：读到共享模型的 enum 成员名是驼峰、持久化值是 'A_B' 这种带下划线的大写串，页面另有自己的本地 enum；产物里映射函数拿成员名字符串和持久化值比较，或写成 name.toUpperCase() === value

## 规矩

- rule-6371a3627dc2｜共享模型枚举映射到页面本地枚举时按成员逐一 switch，不用成员名字符串变换比持久化值｜读到：共享模型的 enum 成员用带下划线的大写字符串作持久化值（成员名是驼峰，取值是 'A_B' 这种写法），页面另有自己的本地 enum；写错：映射函数拿驼峰成员名数组和持久化值做字符串相等比较，或写成 name.toUpperCase() === value，带下划线的值匹配不上而落到 default
