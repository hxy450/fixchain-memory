# 共享模型枚举映射到页面本地枚举时按成员逐一 switch，不用成员名字符串变换比持久化值

审的是：代码
触发（任一种）：
- 读到：共享模型的 enum 成员用带下划线的大写字符串作持久化值（成员名是驼峰，取值是 'A_B' 这种写法），页面另有自己的本地 enum；写错的样子：映射函数拿驼峰成员名数组和持久化值做字符串相等比较，或写成 name.toUpperCase() === value，带下划线的值匹配不上而落到 default
适用范围：实现阶段把共享模型的字符串枚举映射成页面本地枚举或图标资源时
做法：
- 按模型枚举成员逐一 switch：switch (value) { case 模型枚举.成员A: return 本地枚举.成员A; … default: return 默认 }；已有按成员 switch 的映射函数时直接复用
- 最小检查：遍历模型枚举全部成员跑一遍映射，断言只有本该走默认的那个成员落到 default 分支
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 驼峰成员名大写后缺下划线，对不上带下划线的持久化值；改成按成员 switch 后全部命中：字符串变换匹配为什么会漏（出处：卡里修好并验证过）
针对本应用要查的：
- 共享模型枚举每个成员的持久化字符串：目标工程里定义共享模型的 .ets 文件中的 enum 声明；逐个成员读出等号右边的字符串，映射按成员名写 case，不按字符串拼
