# 规格表写了构造缺省值（如当前毫秒）时，模型构造器照写，不改成 null 留给落库补

审的是：代码
触发（任一种）：
- 读到：规格字段表的缺省列写了构造缺省值（如 id 缺省「当前毫秒」），Java 无参构造只有 `super()`；写错的样子：ArkTS 模型写成 `id: number | null = null`，注释把缺省解释成落库侧补值
适用范围：按规格字段表实现模型字段的缺省值时
做法：
- 规格表的缺省值就是构造时的缺省值：缺省「当前毫秒」写成构造器里 `Date.now()`
- 要改成由仓储层补值，先回源码（含基类字节码）确认无参构造不赋值，并在注释里写出处
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 基类无参构造即取构造时刻毫秒，目标构造器缺省改为 Date.now()：子类只写 super() 时，缺省值在基类构造里（出处：卡里修好并验证过）
