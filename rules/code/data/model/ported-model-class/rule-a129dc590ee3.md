# 移植类的构造器初值只照这个类自己的源构造器写，不套相邻类的初值

审的是：代码
触发（任一种）：
- 读到：被移植类的源构造器给结果或状态字段赋初值（含 `null`），同一任务里还读了相邻类的构造器，那里的初值不同；写错的样子：目标类构造器里的字段初值和源类自身的构造器不一样，例如源端是 `null`，目标却写成某个错误码和一段错误文案
适用范围：把安卓的类（下载器、任务、结果对象等）移植成 ArkTS 类、写构造器初值时
做法：
- 打开被移植类自己的构造器，逐字段照源初值写；相邻类的初值不拿来用
- 目标类型允许空的字段，源是 `null` 就写 `null`；目标类型不允许空的字段，用注释写明替代值和原因，其余字段保留源值
针对本应用要查的：
- 被移植类构造器里各字段的初值：源工程里这个类的 Java/Kotlin 源文件，按类名找构造器（含它调用的 super(…) 和 new 出来的结果对象的参数）；逐个参数对上字段名，记下源初值，再写进目标构造器
