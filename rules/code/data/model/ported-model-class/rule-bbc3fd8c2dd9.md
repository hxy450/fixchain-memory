# 同一目录出现两套模型文件、同名导出重复时，按计划留一套删另一套并核对构造参数顺序

审的是：代码
触发（任一种）：
- 读到：计划或派工写明 `models/` 下的模型按职责拆成几个文件，由一个 worker 负责产出；写错的样子：`models/` 下同一个类型在两个文件里都有 `export class` 定义（一个汇总文件和几个按职责拆分的文件并存），两版构造参数顺序不同
适用范围：同一份契约产物（如模型目录）被两个写者并行写出、目标工程里出现重复定义时
做法：
- 按计划要求留一套（如按职责拆分的那几个文件），删除另一套
- 删完用 rg 搜每个导出名的 `export class` / `export interface` 定义，确认各只有一处；再核对构造参数顺序与所有调用方一致
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 删除汇总文件、保留按职责拆分的文件后，rg 显示每个类型只有一处定义：处理并行产物后的核对结果（出处：卡里修好并验证过）
针对本应用要查的：
- 计划要求的是哪一套文件划分：执行计划或派工说明里这个契约产物的文件清单；按清单留对应的文件，清单外的那套删除
来源：1 张卡，1 个应用
