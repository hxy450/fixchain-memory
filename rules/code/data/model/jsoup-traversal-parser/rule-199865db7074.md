# 源端线性元素带 ids、按元素 ids 建锚点下标时，目标模型保留 ids，不用比例映射

审的是：代码
触发（任一种）：
- 读到：源端遍历时对每个元素 pushId(element.id())，线性元素构造时带 ids；锚点表按 elements.mapIndexed 取每个元素的 ids() 映射到它的真实下标；写错的样子：目标的线性元素类型没有 `ids` 字段；下游另写函数把 HTML 里的 id 按出现顺序、按比例映射到元素下标，差异清单里也没记
适用范围：迁移带页内锚点（按元素 id 跳转）的 HTML 线性化模型时，含公共模型和下游使用方
做法：
- 目标线性元素类型加 `ids: string[]` 字段，在源端 pushId 的同一位置把 id 挂到产出元素上
- 锚点表按元素自身的 ids 取真实下标，不按出现顺序或比例推算
- 下游发现公共模型缺源端字段时，登记缺口交公共组件补；确需近似时写进差异清单
