# 自研解析器替代 Jsoup 遍历时，计数和截断检查放在源码相同位置、所有上限一起查

审的是：代码
触发（任一种）：
- 读到：源端遍历 Jsoup 节点时对每个 `TextNode` 先累加 wholeText 的长度、再按块样式（pre、table）分支；追加元素时同一处同时判断元素数上限和字符数上限；写错的样子：目标 appendText 在 pre / table 分支 return 之后才累加字符数；pushElement 只查元素数上限，不查字符数上限
适用范围：用自研 HTML 解析代码替代源端基于 Jsoup 的遍历、源端带截断上限时
做法：
- 所有文本节点（含 pre、table 里的）在进分支前累加字符数，位置和源端一致
- 每次追加元素时同时检查元素数上限和字符数上限，任一超出就停止，和源端追加函数的条件一致
针对本应用要查的：
- 源端的计数位置和截断条件：源工程里基于 Jsoup 的遍历类，找处理 TextNode 的分支和追加元素的函数；记下计数语句在分支之前还是之后、追加时判断了哪几个上限，目标按同样位置和条件写
