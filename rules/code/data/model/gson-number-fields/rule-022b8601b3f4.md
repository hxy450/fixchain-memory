# 用正则加引号和 reviver 转 BigInt 时，范围限定到已知的 64 位字段名

审的是：代码
触发（任一种）：
- 写错的样子：预处理用 `\d{16,}` 一类正则把响应里所有 16 位以上整数加引号，reviver 把所有 16 位以上的纯数字字符串都 BigInt(…) 成 bigint
适用范围：网络层或持久化层用「正则预处理 + reviver」全局方案保 64 位精度时
做法：
- 正则和 reviver 只匹配已知的 64 位字段名（按 "<字段名>"\s*:\s*\d+ 这样带键名的写法），reviver 里按 key 判断再转 BigInt
- replacer 把 bigint 以字符串发出前，先确认后端接受字符串形式的数字；确认不了就按字段单独处理
针对本应用要查的：
- 哪些字段是 64 位整数：源工程的响应 bean 和 Retrofit 接口声明里类型为 Long / long 的字段和参数；把这些字段名列成白名单，正则和 reviver 只认这些键
未核实：后端是否接受字符串形式的 64 位数字，卡里没有核验
