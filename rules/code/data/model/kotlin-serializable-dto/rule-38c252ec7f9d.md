# 编译报「属性不存在，是否指 X」时，先核源模型语义，字段属于源模型就补 DTO 声明

审的是：代码
触发（任一种）：
- 读到：编译错误 `does not exist on type` 并提示 `Did you mean`，被提示的字段名字相近但在源模型里语义不同；写错的样子：按提示把赋值改成名字相近的字段（如作者字段换成当前用户字段），源模型有的字段没补进 DTO 的 class 声明
适用范围：编译门修复里遇到 DTO 缺字段的属性不存在错误时
做法：
- 先在源模型（Kotlin data class）里查这个字段的语义；字段确属源模型，就在目标 DTO 的 class 里补上同名声明，赋值保持原字段，不改用提示的相近字段
针对本应用要查的：
- 报错字段在源模型里是否存在、什么语义：源工程里对应的 Kotlin data class（序列化模型）声明；找到同名属性和它的注释或使用处，确认和提示的相近字段是否同义
