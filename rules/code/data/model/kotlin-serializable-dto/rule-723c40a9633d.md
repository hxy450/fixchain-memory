# 页面映射源端字段时 DTO 缺字段，按源端字段名窄化读取，不改用名称相近的字段

审的是：代码
触发（任一种）：
- 读到：源端读的是某个字段（如 commentView.creator_banned_from_community、copy(creator_banned_from_community = …)），目标 DTO 里没有它，只有名称相近、语义不同的字段；写错的样子：页面写成 creator_banned_from_community: cv.banned_from_community 或 copy.banned_from_community = …，把语义不同的字段当成源端字段；或 DTO 的嵌套路径和源端访问路径不一致时照 DTO 路径读
适用范围：页面实现阶段，把源端字段访问映射到目标 DTO 字段时
做法：
- 按源端字段名窄化读取：声明一个 extends DTO 接口、补上源端字段（可选）的扩展 interface，从它读这个字段，并登记 DTO 缺口
- DTO 声明的嵌套路径和源端访问路径不一致时，同样按源端路径读取并上报
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 修复新增按线格式窄化的接口和取值函数，页面改由它读取作者封禁字段：不再把当前用户封禁当成作者封禁（出处：卡里修好并验证过）
