# Java 构造路径显式传 null 的引用字段，目标模型保留 T | null，不用 '' 兼表

审的是：代码
触发（任一种）：
- 读到：Java 构造器或委托调用 `this(…, null, …)` 对某个 String 字段显式传 `null`，另有路径传真实值；写错的样子：ArkTS 模型把字段写成非空 `string = ''`，工厂方法传 `''`，null 与空串从此混同
适用范围：Java 实体的引用类型字段迁成 ArkTS 模型字段时
做法：
- 按源构造器和调用点区分：有路径显式传 null 的字段写成 `string | null`（或另加 `T | null` 的原值字段），工厂方法照传 null
- 落库写 NULL、JSON 省略键都按这个原值判定，不按 '' 判定
