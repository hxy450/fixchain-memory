# 模型类的 equals 和脏检查方法

agent 会看到什么：读到源端用 equals(...)、hashCode 或另一个「有没有改过」的比较方法决定是否写库、是否刷新修改时间；产物里只比较标题、正文等可见字段的脏检查函数或 equals

## 规矩

- rule-5b22902c9a05｜翻译 equals 或脏检查方法时，按源对象全部持久字段逐一列对照，不从调用点推断｜读到：源端用 equals(...) 或另一个「有没有改过」的比较方法决定是否写库、是否刷新修改时间；写错：目标的脏检查函数或 equals 只比较标题、正文这类「用户可见」字段，漏了地址、creation / lastModification 时间戳、归档回收锁定这类标志位或分类；或者几个标志位只在另一个比较函数里补
