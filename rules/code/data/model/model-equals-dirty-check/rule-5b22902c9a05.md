# 翻译 equals 或脏检查方法时，按源对象全部持久字段逐一列对照，不从调用点推断

审的是：代码
触发（任一种）：
- 读到：源端用 equals(...) 或另一个「有没有改过」的比较方法决定是否写库、是否刷新修改时间；写错的样子：目标的脏检查函数或 equals 只比较标题、正文这类「用户可见」字段，漏了地址、creation / lastModification 时间戳、归档回收锁定这类标志位或分类；或者几个标志位只在另一个比较函数里补
适用范围：把源端实体类的 equals / 脏检查方法翻译成目标实现时
做法：
- 打开源方法的定义，按源对象的全部持久字段逐一列对照表（含地址、创建和修改时间、各标志位、附件列表），目标逐项比较，一个比较函数覆盖全部字段
针对本应用要查的：
- 源端 equals / 脏检查方法实际比较的字段集：源工程里这个实体类及其父类的定义；父类来自依赖库时，看 Gradle 缓存 modules-2/files-2.1/<group>/<artifact>/<version>/ 下的 jar 或 -sources.jar；读方法体里逐个比较的字段；只有字节码时反编译后读，逐个列进对照表
