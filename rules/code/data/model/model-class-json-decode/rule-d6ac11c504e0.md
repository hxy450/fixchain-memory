# 源端没有序列化代码而自行补 fromJson 时，注释写明缺字段、null、类型不符三种输入的结果

审的是：代码
触发（任一种）：
- 读到：源模型 Kotlin data class 文件里没有任何序列化代码（没有 fromJson / toJson）；写错的样子：目标模型里新补的 fromJson 没有注释（或交回说明里没有）写明缺字段、值为 null、类型不符三种输入各自得到什么
适用范围：源端没有可照搬的序列化代码、由迁移者自行为 ArkTS 模型补 fromJson 时
做法：
- 在 fromJson 上方的注释里逐字段写明三种输入的结果，例如「缺字段→默认值 0；null→默认值 0；类型不符（如传字符串）→默认值 0」，交回说明里同样写一遍
