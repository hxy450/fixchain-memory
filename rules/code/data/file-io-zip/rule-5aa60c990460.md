# Uint8Array 交给写入接口时按 byteOffset/byteLength 切片，不直接传 .buffer

审的是：代码
触发（任一种）：
- 读到：字节以 Uint8Array 视图传递，可能是 subarray 等返回的视图（如 EXIF 处理后的结果）；写错的样子：写入或提交媒体资源时直接传 bytes.buffer
适用范围：把 Uint8Array 交给只收 ArrayBuffer 的接口（如 fileIo.writeSync）时
做法：
- 传 bytes.buffer.slice(bytes.byteOffset, bytes.byteOffset + bytes.byteLength)，只取视图覆盖的那一段
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- writeSync(fd: number, buffer: ArrayBuffer | string, options?: WriteOptions): number：写入接口收 ArrayBuffer，Uint8Array 要先转（出处：鸿蒙 SDK 的 ets/api/@ohos.file.fs.d.ts，fileIo.writeSync）
- 返修新增精确切片后保留到最终：返修后的写法（出处：卡里修好并验证过）
