# 关闭某模式时要求移除偏好键的，目标用 deleteSync，不写成 putSync(键, false)

审的是：代码
触发（任一种）：
- 读到：规格或源码写明关闭某模式时移除该键（SharedPreferences.Editor.remove）；写错的样子：目标关闭分支写 putSync(<键>, false)，键仍然存在
适用范围：源端关闭某模式时移除偏好键的那个分支
做法：
- 关闭分支写 prefs.deleteSync(<键>) 再 flush()，让各读点自己的缺省值生效
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- deleteSync(key: string): void：同步删除键（出处：鸿蒙 SDK 的 ets/api/@ohos.data.preferences.d.ts，Preferences.deleteSync）
