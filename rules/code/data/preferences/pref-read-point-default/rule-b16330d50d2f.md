# 改某个偏好读点的缺省值前回到该读点的源码行核对，不按 spec 摘要或键常量的单一默认改

审的是：代码
触发（任一种）：
- 读到：spec 摘要或键常量注释给这个偏好键只写一个默认值（如 `(boolean, false)`），页面已有的读点按另一个缺省值读（如 getSync(<键>, true)）；写错的样子：原本 getSync(<键>, true) 的读点被改成按 false 读，注释引键常量或 spec 摘要里的单一默认
适用范围：页面实现者修改偏好读点的缺省值时
做法：
- 改某读点的缺省值前，回到该读点的源码行核对，不以 spec 摘要或键常量注释里的单一默认为准
