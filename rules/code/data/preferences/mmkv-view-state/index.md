# MMKV 里持久化的界面切换状态

agent 会看到什么：读过的源码切换视图时把位置写进 MMKV 的键、启动时读回恢复；交回的 ViewModel 只改内存状态不写 preferences，或页面在偏好加载完之前就读了默认值

## 规矩

- rule-c268c53b568a｜源端视图切换写进持久化键时，目标切换先写偏好，启动时等偏好加载完再恢复｜读到：安卓切换视图时把视图位置写进 MMKV 的键，只接受几个固定取值，启动时读回恢复；写错：目标 ViewModel 的视图切换方法只改内存里的模式状态，没写偏好；页面在 `await` 偏好加载完成之前就读取默认值，重启总回到默认视图
