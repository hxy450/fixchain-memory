# 演示和种子数据

agent 会看到什么：读到计划或 feature-index 写明演示数据依赖源端的种子类、模板类，并给出 spec_ref 指向的功能 spec；产物里写演示行的代码，标题、日期偏移、主题 key、清单项和完成状态是自拟的，主题 key 换成了 #RRGGBB 颜色串

## 规矩

- rule-5023a9df5eea｜写演示/种子数据时照 spec_ref 和源端种子类逐字段搬运，不按功能名自拟样例｜读到：计划或 feature-index 写明演示数据依赖源端的种子类、模板类，并给出 spec_ref 指向的功能 spec；写错：写演示行的代码里行程标题、日期偏移、主题 key、note、清单项和完成状态都是自拟的，和 spec、源端种子类对不上：主题 key 原值被换成 `#RRGGBB` 颜色串，清单项条数不同、全部未完成
