# 照源码移植的 Repository / DAO 写方法没有调用者时，回查源流程哪一步该调用它

审的是：代码
触发（任一种）：
- 读到：源端流程里有对 Repository / DAO 写方法的调用；写错的样子：目标里定义了照源码移植的 Repository / DAO 写方法（注释写「对齐 …」），在目标工程里 grep 不到调用者
适用范围：目标端已移植数据层写方法、但流程调用方是另外写的时
做法：
- 移植写方法后在目标工程 grep 它的调用点，和源码里的调用点逐一对照；定义了却没有调用者时，回查源流程哪一步应调用它并补上
