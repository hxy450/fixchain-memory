# 某操作的 catch 写了别的操作的状态时，改成写本操作自己的失败态

审的是：代码
触发（任一种）：
- 写错的样子：`catch` 块里把一个操作的失败写进另一个操作的状态字段（备份失败也写成恢复状态的 Error）
适用范围：页面上有多个操作（如备份、恢复）各自有结果状态，接线时给它们补失败处理
做法：
- 每个操作的失败写进它自己的失败态（独立的操作失败态，或规格状态表里属于这个操作的那个状态），不借用别的操作的状态
针对本应用要查的：
- 每个操作对应哪个状态字段：规格的状态表；按状态表里各操作的状态名对应到页面字段
