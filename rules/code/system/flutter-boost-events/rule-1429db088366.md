# Flutter 宿主挂的是自定义 FlutterBoostFragment 子类时，目标页逐项实现它的事件通道

审的是：代码
触发（任一种）：
- 读到：源宿主挂的是 `FlutterBoostFragment` 子类（如经 `CachedEngineFragmentBuilder(<子类>::class.java)` 构造），子类里 `addEventListener(通道名, …)` 分发事件、`sendEventToFlutter(...)` 推数据；写错的样子：目标宿主页只挂 `FlutterUIComponent({ uri: … })`，没有 `addEventListener` 监听和 `sendEventToFlutter` 推送，也没标缺口
- 读到：读到过事件常量表（通道名和各事件名），Flutter 端 dart 监听该通道并 `sendEventToNative`；写错的样子：宿主页没有对应通道的 `addEventListener`，也没登记缺口
适用范围：把经 flutter_boost 嵌入 Flutter 页面的 Activity/Fragment 宿主迁成 ArkTS 宿主页时
做法：
- 打开宿主实际挂载的容器子类源文件，列出 addEventListener 的通道名和每个事件分支、sendEventToFlutter 的推送点
- 目标宿主页注册同名通道的 `addEventListener('<通道名>', …)` 按事件名分发，推送点写 `sendEventToFlutter('<通道名>', …)`；目标页没迁的分支写 `hilog.warn(...)` 加 TODO
- 写完 grep 源宿主和目标页的 addEventListener / sendEventToFlutter 逐条对应；读到过事件常量表的，至少注册对应通道或显式登记缺口
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 宿主页 addEventListener('<通道名>') 分发各类事件，页面显示时 sendEventToFlutter('<通道名>') 推数据，未迁目标页的事件写 hilog.warn + TODO：修好后的宿主页写法（出处：卡里修好并验证过）
- function warn(domain: number, tag: string, format: string, ...args: any[]): void：占位分支打警告日志；domain 取 0x0 到 0xFFFF，tag 不超过 32 字节（出处：鸿蒙 SDK 的 ets/api/@ohos.hilog.d.ts，hilog.warn）
针对本应用要查的：
- 宿主的通道名、事件清单和推送点：源工程里宿主挂载的 FlutterBoostFragment 子类源文件、事件常量定义文件，以及 Flutter 端 dart 里的监听和 sendEventToNative，按 addEventListener / sendEventToFlutter 搜；记下通道名字符串、每个事件名及参数、推送发生的时机，逐项写到目标宿主页
