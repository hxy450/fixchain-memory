# 源端无权限或无坐标仍按城市查询时，目标数据层照分支保留城市查询，不用 return [] 短路

审的是：代码
触发（任一种）：
- 读到：源端附近检索按当前城市建查询（如 PoiSearchV2.Query 带城市编码），只在有定位权限且有坐标时才附加 SearchBound 半径；写错的样子：目标 Repository 的附近查询开头写坐标未知就 `return []`，只剩按坐标搜索，按城市查询的分支没了
适用范围：迁移依赖定位的附近、周边列表的数据层，源端在不同权限、坐标状态下走不同查询时
做法：
- 把源端附近查询按「有权限且有坐标 / 无权限 / 坐标未知 / 定位失败」逐分支列出实际行为，逐一映射到目标 Repository：有坐标按坐标加半径（按距离排序），无权限或坐标未知照源端按当前城市查询
- 不在查询入口用「坐标未知」把整条查询短路成空数组
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 有坐标按距离排序、无坐标按城市查询：修好后的数据层分支（出处：卡里修好并验证过）
针对本应用要查的：
- 源端附近查询在各权限、坐标状态下实际走哪种查询：源工程里发起附近检索的 Fragment / Activity 源码，按建查询对象（如 PoiSearchV2.Query）和附加 SearchBound 的条件找；把附加半径的 if 条件和不附加时用的城市参数逐分支抄成表，再对到目标 Repository 的分支
未核实：有坐标时目标端按坐标检索的返回质量
