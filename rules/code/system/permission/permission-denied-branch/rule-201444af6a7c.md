# 定位入口不只写成功分支，拒绝、关闭和失败时展示错误并保留手动兜底

审的是：代码
触发（任一种）：
- 读到：源端 PermissionX 拒绝、永久拒绝和服务关闭时都有反馈（弹说明框、跳应用设置或位置设置）；规格验收要求这些情况不能静默，台账写定位失败开放手动选择；写错的样子：UI 里 await 定位结果后只有 if (result) { … } 成功分支，ViewModel 已置的 errorMessage 没有展示
适用范围：UI 接线阶段，定位入口处理定位结果时
做法：
- 结果为空时展示 ViewModel 的 errorMessage（或「定位失败，可手动选择」之类提示，如 promptAction.showToast），并保留手动选择入口；拒绝、永久拒绝、服务关闭、定位失败四种都要有反馈
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 定位结果为空时 toast errorMessage 或「定位失败，可手动选择」提示后，拒绝和关闭不再静默：失败分支要有反馈（出处：卡里修好并验证过）
