# 源端入口无定位权限时转别的页，目标入口照样设门槛，不让无坐标状态以空列表进附近页

审的是：代码
触发（任一种）：
- 读到：源端入口的 setOnClickListener 里先判定位权限，无权限时转去选城页面，不进附近列表；写错的样子：目标入口的 onClick 里直接跳附近页，没有判定位权限或坐标是否可用
适用范围：迁移进入依赖定位的页面的入口（首页卡片、按钮）时
做法：
- 核对源端入口门槛，目标入口照写：没有定位权限（或没有可用坐标）时走源端同一去向，或者带着定位不可用的状态进页面，不以空列表进附近页
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- checkAccessTokenSync(tokenID: number, permissionName: Permissions): GrantStatus：AtManager 上同步查当前应用是否已获某项权限，返回 GrantStatus（出处：鸿蒙 SDK 的 ets/api/@ohos.abilityAccessCtrl.d.ts，AtManager.checkAccessTokenSync）
- GrantStatus.PERMISSION_GRANTED = 0、GrantStatus.PERMISSION_DENIED = -1：权限查询结果的两个取值（出处：鸿蒙 SDK 的 ets/api/@ohos.abilityAccessCtrl.d.ts，GrantStatus）
- 'ohos.permission.APPROXIMATELY_LOCATION'：模糊定位权限名，是 Permissions 的取值之一（出处：鸿蒙 SDK 的 ets/api/permissions.d.ts，Permissions）
- checkAccessToken(tokenID: number, permissionName: Permissions): Promise<GrantStatus>：同族接口：AtManager 的异步版本（出处：鸿蒙 SDK 的 ets/api/@ohos.abilityAccessCtrl.d.ts，AtManager.checkAccessToken）
- getSelfPermissionStatus(permissionName: Permissions): PermissionStatus：同族接口：AtManager 上查当前应用的权限状态，声明 @since 20（出处：鸿蒙 SDK 的 ets/api/@ohos.abilityAccessCtrl.d.ts，AtManager.getSelfPermissionStatus）
针对本应用要查的：
- 源端入口在无定位权限时去哪：源工程里入口控件的 setOnClickListener 回调，按权限判断后的 startActivity / 导航调用找；读出无权限分支跳转的目标页，目标入口的无权限分支跳同一类页面
