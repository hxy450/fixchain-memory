# 用应用内计时替代后台 Worker 时，持久化恢复和后台 tick 共用按步骤扣减的函数

审的是：代码
触发（任一种）：
- 读到：源端后台 Worker（WorkManager）跨步骤推进计时，回到前台时按 Worker 进度里的步骤 id 直接设当前步；写错的样子：持久化恢复另写一支：把全部停机时长加到当前步，满一步只前进一次、余量丢弃（源端 Worker 会连续推进多步），没有复用后台 tick 的跨步扣减函数
适用范围：目标端用应用内计时加长时任务替代安卓后台 Worker 的多步骤计时，所有恢复入口
做法：
- 写一个按有序步骤扣减经过时间的函数：从当前步剩余时间起逐步扣减，遇手动步骤停下，越过末步进入完成态；后台 tick 和持久化恢复都调它
- 用跨两个步骤的停机时长手算一次恢复结果，和函数输出核对
来源：1 张卡，1 个应用
