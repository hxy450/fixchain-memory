# 只在源端真正调用通知的回调里发布通知，二级页不新增通知发布者

审的是：代码
触发（任一种）：
- 读到：二级页 Activity 的监听回调只刷新列表或弹连接成功框，不调用通知帮助类，onDestroy 里注销监听；写错的样子：二级页的 ViewModel 回调里也调通知更新（如连接变化时以电量 -1 覆盖电量文本），出现第二个通知发布者
适用范围：同一设备事件被主页面和二级页同时监听、只有主页面发通知时
做法：
- 通知只经唯一发布服务、在源端真正调用通知的回调对应处发布；二级页对应的 ViewModel 不调通知服务
