# 图片复制到剪贴板写 MIMETYPE_PIXELMAP 并补 Toast，不写沙箱 file URI

审的是：代码
触发（任一种）：
- 读到：源端复制图片时用 FileProvider 生成的 URI 放进剪贴板（接收方凭跨应用授权读取）；写错的样子：pasteboard.createData(pasteboard.MIMETYPE_TEXT_URI, 应用沙箱的 file:// URI)，成功后没有任何提示
适用范围：把图片复制到系统剪贴板时
做法：
- 把图片解码成 PixelMap，写 pasteboard.getSystemPasteboard().setData(pasteboard.createData(pasteboard.MIMETYPE_PIXELMAP, pixelMap))
- 写入成功后补一个成功 Toast：鸿蒙没有系统的「已复制」提示
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- const MIMETYPE_PIXELMAP = 'pixelMap'：PixelMap 的 MIME 类型（出处：鸿蒙 SDK 的 ets/api/@ohos.pasteboard.d.ts，pasteboard.MIMETYPE_PIXELMAP）
- function createData(mimeType: string, value: ValueType): PasteData：按 MIME 类型创建剪贴板数据；ValueType = string | image.PixelMap | Want | ArrayBuffer（出处：鸿蒙 SDK 的 ets/api/@ohos.pasteboard.d.ts，pasteboard.createData、pasteboard.ValueType）
- setData(data: PasteData): Promise<void>：写入系统剪贴板；系统剪贴板由 getSystemPasteboard(): SystemPasteboard 取得（出处：鸿蒙 SDK 的 ets/api/@ohos.pasteboard.d.ts，SystemPasteboard.setData）
- function createImageSource(uri: string): ImageSource；createPixelMap(options?: DecodingOptions): Promise<PixelMap>：从沙箱文件解码出 PixelMap 的接口（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.image.d.ts，image.createImageSource、ImageSource.createPixelMap）
- 解码为 PixelMap 以 MIMETYPE_PIXELMAP 写入并 Toast：修好的写法（出处：卡里修好并验证过）
