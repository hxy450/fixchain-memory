# 源端条件受系统开关限制而目标读不到时，按开关默认态退化，不改用计费网络判定

审的是：代码
触发（任一种）：
- 读到：源端 Auto 档只按系统 Data Saver 开关判定（经 connectivityManager）；写错的样子：目标把 Auto 改成「没有 NET_CAPABILITY_NOT_METERED 即计费网络 → 开启」
适用范围：源端判定依赖某个系统开关、目标平台没有对应读取接口时
做法：
- 按该开关的默认态退化（读不到 Data Saver 时 Auto 按未开启），不改用会扩大触发范围、源端已明确放弃的条件
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Auto 因读不到 Data Saver 按未开启：修复时采用的退化方式（出处：卡里修好并验证过）
- RESTRICT_BACKGROUND_STATUS_ENABLED = 3：安卓 Data Saver 开启时的状态：限制后台的计费网络使用；它和「当前是计费网络」不是同一个条件（出处：android.net.ConnectivityManager#RESTRICT_BACKGROUND_STATUS_ENABLED）
