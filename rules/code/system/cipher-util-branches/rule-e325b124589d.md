# 目标端用 String(value ?? '') 归一化空值时，核对源端 toString() 后进哪个分支

审的是：代码
触发（任一种）：
- 读到：安卓请求拦截对每个业务值调用加密工具，参数写成 value.toString()；写错的样子：目标端请求中间件写 String(value ?? '') 把 null / undefined 统一成空串再送进加密封装，没核对源端同一个值进的是哪个分支
适用范围：网络层请求组装里，对业务参数做 null / undefined 归一化再加密时
做法：
- 对每种缺值情形，核对源端这个值经过 value.toString() 后实际进入加密工具的哪个分支、得到什么输出，目标端的归一化和封装分支要得出同一个结果
针对本应用要查的：
- 源端缺值时送进加密工具的字符串是什么：源工程请求拦截器里拼参数、调加密工具的那段 .kt / .java：看参数值的类型是否可空，缺值时是被跳过、给了空串还是别的默认值；按源端实际得到的字符串决定：得到空串的走空串分支返回 ''；得到其他字符串的照样加密；目标端 String(value ?? '') 的结果要和它一致
