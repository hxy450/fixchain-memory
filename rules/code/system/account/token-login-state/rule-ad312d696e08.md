# 安卓启动固定进主页、登录按需跳转时，鸿蒙也固定进主页，登录页压在主页之上

审的是：代码
触发（任一种）：
- 读到：安卓启动 Activity 同意隐私后清栈固定进入主页 Activity，不看 token；登录只在触发受保护功能时按需跳转；写错的样子：启动目标写成 token.length > 0 ? 主页 : 登录页，登录页替换了根页面，返回时白屏
适用范围：迁移启动与隐私门禁、确定同意隐私后的启动目标时
做法：
- 启动路由和功能级登录门禁分开：同意隐私后固定返回主页；token 只用来同步登录状态；受保护功能触发时把登录页压在主页之上，不让登录页替换根页面
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 启动目标固定返回主页、token 只用于更新登录状态、受保护功能由登录门禁把登录页压在主页上后，未登录冷启动进主页，返回不再白屏：修好的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 安卓启动后固定进哪一页、登录在哪里触发：源工程启动 Activity 里同意隐私后的跳转方法（startActivity 的目标和清栈标志），以及受保护功能入口处的登录检查；跳转目标不随 token 变的，目标端启动目标写成固定的主页；登录检查所在的功能入口就是目标端压登录页的地方
