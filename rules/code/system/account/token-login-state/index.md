# 按 token 判定的登录态

agent 会看到什么：读到源端按 token（hasToken 一类）判登录、启动固定进主页、退出登录还清本地数据库业务表；交回的启动写成 token.length > 0 ? 主页 : 登录页、用昵称判空决定显示「未登录」，或退出只清 preferences

## 规矩

- rule-ad312d696e08｜安卓启动固定进主页、登录按需跳转时，鸿蒙也固定进主页，登录页压在主页之上｜读到：安卓启动 Activity 同意隐私后清栈固定进入主页 Activity，不看 token；登录只在触发受保护功能时按需跳转；写错：启动目标写成 token.length > 0 ? 主页 : 登录页，登录页替换了根页面，返回时白屏
- rule-71a564612e01｜身份文案按 token 判登录、按源端 getter 回退链显示，未登录占位只进未登录分支｜读到：源端按 token 判定登录（hasToken 一类），已登录时显示名字 getter 的结果，getter 在昵称为空时有回退分支（如回退成「用户」加 id），只有未登录的 else 分支才写「未登录」；写错：目标表达式写成 昵称.length > 0 ? 昵称 : $r('app.string.…')（未登录占位资源），或 isLoggedIn && 昵称.length > 0 ? … : $r(…)，让昵称判空决定是否显示「未登录」
- rule-43c76bbcf576｜退出登录钩子先停并等同步，再单事务清账号业务表，最后广播数据变化｜读到：安卓源的退出登录方法除清 token 和账号 SharedPreferences 外，还调用本地数据库的 removeAll 清业务表；或者读到的旧目标实现的会话清理只清 preferences 和登录态；写错：目标的退出/会话清理钩子只清 preferences、登录态、网络缓存并发登录状态事件，没有先停止并等待同步，没有在 RdbStore 里清按账号归属的业务表，也没有广播数据变化
