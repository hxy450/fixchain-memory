# 单会话授权回调的 state 校验

agent 会看到什么：读到每次请求带随机 state 的 SDK 授权（SendAuthReq 一类）、规格写「state 错配拒绝」「旧回调必须失效」「迟到回调」；产物里回调处理的判断顺序和它的契约测试

## 规矩

- rule-9ba54a3fdb86｜单会话授权回调先比 state 判归属，不匹配直接忽略，匹配后才判成功、取消或失败｜读到：规格或审计写「旧回调必须失效」「state 错配拒绝」「迟到回调不换账号」，每次请求生成随机 state 写进 SendAuthReq 等 SDK 请求；写错：回调处理只查有没有当前会话和命令类型，没有先比 `state`，就把 `state` 不一致和错误码、空 `code` 放进同一个校验一起抛错，catch 后结束当前会话
- rule-157da509b69f｜单会话授权的测试要投递上一请求的迟到回调，断言新请求仍在等待｜读到：规格的验收要求覆盖 `state` 错配拒绝、离开页面后的迟到回调；写错：契约测试只断言校验函数拒绝过期的 `state`，没有「新会话等待期间收到旧 `state` 回调」的时序用例
