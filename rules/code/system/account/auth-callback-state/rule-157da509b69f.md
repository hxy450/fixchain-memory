# 单会话授权的测试要投递上一请求的迟到回调，断言新请求仍在等待

审的是：代码
触发（任一种）：
- 读到：规格的验收要求覆盖 `state` 错配拒绝、离开页面后的迟到回调；写错的样子：契约测试只断言校验函数拒绝过期的 `state`，没有「新会话等待期间收到旧 `state` 回调」的时序用例
适用范围：同一时刻只保留一个待处理授权会话的第三方登录服务的测试
做法：
- 补时序用例：发起请求 A → 取消或超时 → 发起请求 B → 投递 A 的回调，断言 B 仍在等待；再投递 B 的回调，断言 B 按自身结果完成
