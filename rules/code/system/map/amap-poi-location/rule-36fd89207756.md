# 移植时换掉参考实现的查询 API，就按新 API 的声明补齐它要求的参数

审的是：代码
触发（任一种）：
- 读到：参考实现的关键词搜索走 InputtipsQuery(keyword, city)，周边搜索的 PoiQueryV2 同时设置了 location 和 bound；写错的样子：移植代码换用了别的查询 API（如关键词搜索改成 new PoiQueryV2），新 API 要求的参数（city，或周边搜索的 location、bound）没补
适用范围：参照现成实现移植高德搜索的查询路径时
做法：
- 逐条对照参考实现的查询路径：沿用参考的 API 时照参考带参数（InputtipsQuery 带 city，周边 PoiQueryV2 带 location 和 bound）
- 改用其他 API 时打开它的声明，把标了必设的参数都补上
