# 源定位 SDK 直接给行政区名而目标只给坐标时，用 getAddressesFromLocation 取名，不写空名

审的是：代码
触发（任一种）：
- 读到：源端定位回调取 AMapLocation 的 district（为空取 city）作为地名，再用经纬度在本地城市库粗筛；规格要求匹配失败时保留定位名称；写错的样子：目标定位服务只返回 getCurrentLocation 的坐标，粗筛为空时城市对象名称写成 ''；「已定位」只按本地城市 ID > 0 判断
适用范围：把带地址的第三方定位结果迁成 HarmonyOS LocationKit 定位、再映射到本地城市对象时
做法：
- 拿到坐标后调用 geoLocationManager.getAddressesFromLocation({ latitude, longitude, maxItems: 1 })，名称按 subLocality → locality → subAdministrativeArea → administrativeArea 取第一个非空值
- 规格要求保留定位名称时不以空名称占位；用该名称回查本地城市库补全城市 ID，坐标粗筛仍作候选
- 界面的「已定位」判断以是否已有定位名称或坐标为准，不只看本地城市 ID > 0
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- function getAddressesFromLocation(request: ReverseGeoCodeRequest): Promise<Array<GeoAddress>>：逆地理编码：由坐标取地址（出处：鸿蒙 SDK 的 ets/api/@ohos.geoLocationManager.d.ts，geoLocationManager.getAddressesFromLocation）
- ReverseGeoCodeRequest { latitude: number; longitude: number; maxItems?: number; locale?: string }：请求参数（出处：鸿蒙 SDK 的 ets/api/@ohos.geoLocationManager.d.ts，ReverseGeoCodeRequest）
- GeoAddress 的 subLocality?、locality?、subAdministrativeArea?、administrativeArea?: string：区县、城市、地级区划、省级区划名（出处：鸿蒙 SDK 的 ets/api/@ohos.geoLocationManager.d.ts，GeoAddress）
- 按 subLocality → locality → subAdministrativeArea → administrativeArea 取名、再按名称回查城市库后，城市卡显示定位区名：取名顺序和名称优先匹配（出处：卡里修好并验证过）
