# 源端是地图 SDK 的 MapView 区域时，目标落成真实地图组件并绑定定位坐标

审的是：代码
触发（任一种）：
- 读到：源布局里有第三方地图 SDK 的 MapView（如 com.tencent.tencentmap.mapsdk.maps.MapView），代码在定位回调里 addMarker 当前位置并 moveCamera 到真实坐标；写错的样子：定位成功分支写成白色 Blank / Row 加 marker Image 的 Stack，没有任何地图组件，也没把定位坐标绑到相机和 marker
适用范围：把源端地图视图区域迁成 ArkUI 页面、确定定位成功态的承载组件时
做法：
- 地图区域写成真实地图组件：平台 Map Kit 的 MapComponent({ mapOptions, mapCallback })，或决策里已定的三方地图 SDK 组件；在 mapCallback 拿到的 MapComponentController 上 addMarker 当前位置并 moveCamera 到定位坐标，缩放级别照源端
- 白色容器加 marker 图片不能作为地图态交付
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- struct MapComponent { mapOptions: mapCommon.MapOptions; mapCallback: AsyncCallback<map.MapComponentController> }：Map Kit 的地图组件，初始化后经回调拿到控制器（出处：鸿蒙 SDK 的 hms/ets/api/@hms.core.map.MapComponent.d.ets，MapComponent）
- addMarker(options: mapCommon.MarkerOptions): Promise<Marker>：加当前位置标记（出处：鸿蒙 SDK 的 hms/ets/api/@hms.core.map.map.d.ts，MapComponentController.addMarker）
- moveCamera(update: CameraUpdate): void：把相机移到定位坐标（出处：鸿蒙 SDK 的 hms/ets/api/@hms.core.map.map.d.ts，MapComponentController.moveCamera）
- convertCoordinate(fromType, toType, location): Promise<mapCommon.LatLng>，目前只支持 WGS84 转 GCJ02：定位坐标和地图坐标系不一致时先转换（出处：鸿蒙 SDK 的 hms/ets/api/@hms.core.map.map.d.ts，map.convertCoordinate）
- 接入地图组件后，用连续定位坐标放当前位置 marker 并设缩放，地图态正常显示：修好后的接法（先接 Map Kit，后按用户要求改用三方地图的 ArkTS 组件）（出处：卡里修好并验证过）
针对本应用要查的：
- 源端地图的缩放、坐标系和标记：源工程里初始化地图视图的代码（initMapView 一类方法、定位回调里的 addMarker / moveCamera），以及决策台账里地图迁移的那一条；记下缩放级别、源端 SDK 用的坐标系和 marker 图，目标按同样的值设；决策选定的组件是哪个就接哪个
