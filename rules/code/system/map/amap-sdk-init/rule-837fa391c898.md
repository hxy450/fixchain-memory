# 高德各单例分别初始化、分别判成败，搜索就绪不和 MapsInitializer.initialize 同一个 try

审的是：代码
触发（任一种）：
- 写错的样子：桥接的初始化把 MapsInitializer.initialize、定位和 ServiceSettings 的设置放在同一个 try 里，用同一个就绪标志决定搜索能不能用，任何一步抛错搜索都静默返回 []
- 写错的样子：多个页面或 ViewModel 各自 new 一个桥接实例并各自 initialize，重复的 MapsInitializer.initialize 出错连带搜索不可用
适用范围：鸿蒙工程在一个桥接类里同时初始化高德地图、定位、搜索时
做法：
- ServiceSettings 的隐私、Key（及语言、HTTPS）单独设置并单独判定搜索就绪；MapsInitializer 与 AMapLocationManagerImpl 的初始化各放各的 try，失败只影响各自功能
- 确认桥接实例会不会被多个页面重复创建和初始化；会的话，重复的 MapsInitializer.initialize 出错也不能把搜索标成未就绪
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ServiceSettings 独立设置隐私、Key、语言、HTTPS；地图与定位初始化降为各自 best-effort：修好后的初始化结构（出处：卡里修好并验证过）
