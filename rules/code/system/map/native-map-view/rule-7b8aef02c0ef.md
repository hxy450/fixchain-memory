# 功能切片给已转换页面接线时保留原布局骨架，只换数据绑定和事件，不删掉重写

审的是：代码
触发（任一种）：
- 读到：已有目标页面是全屏 Stack 底层加按 ViewModel 布尔状态切换的两套前景覆盖层；源布局 XML 以铺满全屏的 MapView 等视图为底层；写错的样子：切片先删页面再整页重写：全屏 Stack 底层没了，改成常驻标题栏加灰底的 Column 和单一居中卡片，源端两种状态下的可见节点缺失
适用范围：功能切片为页面转换阶段已生成的页面接入 ViewModel、Service 和跳转时
做法：
- 默认保留页面转换阶段的骨架（全屏背景层 + 按状态切换的前景覆盖层），只替换数据绑定与事件
- 确需重写时，先对照源布局 XML 和 ViewModel 列出每个状态下可见的节点，写完新文件逐项核对
针对本应用要查的：
- 每个状态下可见的节点：源工程的布局 XML（按 android:visibility 和 ViewModel 绑定找）和对应 ViewModel 的布尔状态；按状态列出节点清单，与重写后的页面逐项对照
