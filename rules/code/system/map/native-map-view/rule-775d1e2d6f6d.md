# 地图 SDK、key 或配置缺失接不上时，显示真实的未配置状态，不用静态图冒充地图

审的是：代码
触发（任一种）：
- 读到：决策台账写「三方地图不迁 SDK 二进制，用平台定位与可验证的地图承载」「定位失败不写伪坐标」；目标工程没有地图组件依赖、key 或 client_id 配置；写错的样子：地图区在配置缺失时仍显示白底 Blank 加 marker Image 的假地图态，或写了伪坐标
适用范围：目标工程还接不上地图服务（缺依赖、key、AGC 配置）时，地图区域的显示
做法：
- 按失败降级决策显示真实状态（如「地图服务未配置」的提示态），不显示伪地图、不写伪坐标
针对本应用要查的：
- 失败降级的显示要求：决策台账里地图、定位失败降级的条目和页面规格里的空态、失败态描述；照决策写出的状态文案和样式实现，不另造
