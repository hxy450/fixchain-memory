# 目标地图或导航 SDK 不可用时，地图承载仍放全屏底层用占位面，不改成固定高的地图卡

审的是：代码
触发（任一种）：
- 读到：源布局里 MapView / AMapNaviView 铺满全屏作底层，前景是覆盖层；或巡检发现写明「全屏底层」「缺少全屏地图承载」；写错的样子：目标在覆盖层里插入一个固定高度（如 .height(180)）的圆角「地图卡」或「map-like」自绘面，代替全屏承载
适用范围：目标端地图、导航 SDK 暂不可用，页面要先用占位承载，以及巡检修复处理地图承载的发现时
做法：
- 写成 Stack() { 占位面或显式失败提示.width('100%').height('100%')；前景覆盖层 }，前景覆盖层结构不变
- 巡检发现写明「全屏底层」时按这一层级修，不在覆盖层里加小卡
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 地图未就绪时用全屏黑色面兜底，前景两态覆盖层照源：返修后与源端结构一致的写法（出处：卡里修好并验证过）
