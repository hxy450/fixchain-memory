# 地图服务层同时暴露初始化、暂停/恢复和完整释放，不以释放代替暂停

审的是：代码
触发（任一种）：
- 读到：参考 SDK 桥接里激活 → MapView.onResume、暂停 → MapView.onPause、释放 → 注销创建回调并 MapView.onDestroy，是三个不同接口；写错的样子：服务层只有初始化和完整释放两个方法，桥接层的激活/暂停（MapView.onResume / onPause）没有暴露给页面，页面消失时只能调释放
适用范围：接入第三方原生地图 SDK 时，页面和 SDK 桥接之间的服务层接口
做法：
- 服务层加暂停、恢复两个方法，分别转调桥接的暂停（MapView.onPause）和激活（MapView.onResume）；完整释放单独一个方法，页面按可见性调对应的那个
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 修复给服务层新增暂停方法，转调桥接的 deactivate（MapView.onPause），页面消失时调它而不是完整释放：卡里补上的接口（出处：卡里修好并验证过）
针对本应用要查的：
- SDK 的暂停、恢复、销毁接口名：参考工程或 SDK 包里 MapView 的声明文件（.d.ets），找 onResume / onPause / onDestroy；按声明注释区分「暂停」和「销毁地图」，分别接到服务层的暂停和释放方法
未核实：高德鸿蒙 SDK 的 MapView 声明不在三类来源里，接口名按卡写
