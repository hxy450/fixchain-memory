# 源 Activity 有默认切换动画时，目标 @Entry 页按源端写 pageTransition 四段

审的是：代码
触发（任一种）：
- 读到：源 Activity 由 startActivity 打开、finish 返回，没调 overridePendingTransition，切换动画来自主题 windowAnimationStyle；写错的样子：目标 @Entry 页没有 pageTransition()，进出沿用 router 默认横滑；或 PageTransitionEnter / PageTransitionExit 没写 duration（默认 1000ms）
适用范围：目标用 router.pushUrl 的 @Entry 页承接源端 Activity 时
做法：
- 先看规格有没有给切换动画；没给时查源端的 overridePendingTransition 和主题 windowAnimationStyle，按源端写；查不到目标值就作为规格缺口回报，不默认保留鸿蒙横滑
- 写 pageTransition() { PageTransitionEnter({ type: RouteType.Push, duration, curve }).scale({ x, y }).opacity(…); PageTransitionExit({ type: RouteType.Push, … }); PageTransitionEnter({ type: RouteType.Pop, … }); PageTransitionExit({ type: RouteType.Pop, … }) }，依次对应源端 activity_open_enter、open_exit、close_enter、close_exit
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- (value: PageTransitionOptions): PageTransitionEnterInterface：PageTransitionEnter 的构造（出处：鸿蒙 SDK 的 ets/component/page_transition.d.ts，PageTransitionEnterInterface）
- (value: PageTransitionOptions): PageTransitionExitInterface：同族接口：PageTransitionExit 的构造（出处：鸿蒙 SDK 的 ets/component/page_transition.d.ts，PageTransitionExitInterface）
- PageTransitionOptions：type 默认 RouteType.None；duration 单位 ms，默认 1000；curve 默认 Curve.Linear；delay 默认 0：不写 duration 时转场是 1 秒（出处：鸿蒙 SDK 的 ets/component/page_transition.d.ts，PageTransitionOptions）
- Push：A 的 PageTransitionExit 和 B 的 PageTransitionEnter（type 为 None 或 Push）生效；Pop：B 的 Exit 和 A 的 Enter（type 为 None 或 Pop）生效：Push Enter 对 open_enter、Push Exit 对 open_exit、Pop Enter 对 close_enter、Pop Exit 对 close_exit（出处：ts-page-transition-animation.md，RouteType枚举说明）
- scale(value: ScaleOptions): T；opacity(value: number): T；translate(value: TranslateOptions): T：CommonTransition 的效果，值是入场时起点和退场时终点（出处：鸿蒙 SDK 的 ets/component/page_transition.d.ts，CommonTransition；ts-page-transition-animation.md，CommonTransition）
- 三页各加 pageTransition()，按 RouteType.Push / Pop 分别写 Enter / Exit，编译通过并和源端录屏对照：修好后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 四段动画的目标值：规格里的导航契约；没有时去 Android SDK platforms/android-<参照机 API>/data/res/anim/activity_{open,close}_{enter,exit}.xml；alpha 的 from 写进 opacity，scale 的 from（入场）或 to（退场）写进 scale，translate 写进 translate，duration、interpolator 写进 duration、curve
