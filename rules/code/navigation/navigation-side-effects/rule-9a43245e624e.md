# 源端点击浮层只跳转、不动队列时，目标点击回调里不清空剩余队列

审的是：代码
触发（任一种）：
- 读到：源端浮层根布局的 setOnClickListener 里只埋点并 startActivity(intent) 跳详情，不改队列 List；写错的样子：目标的 onClick 回调里先清掉当前项和剩余队列，再跳转
适用范围：迁移逐个播放的全局广播、飘屏队列时，点击浮层的处理
做法：
- 点击回调只做埋点和跳转（目标页和参数照源端），不清当前项、不清剩余队列；剩余项照常逐个播放
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 源端点击后保留剩余队列；修复后点击只记录导航、不清队列：点击清队会让剩余广播丢失（出处：卡里修好并验证过）
