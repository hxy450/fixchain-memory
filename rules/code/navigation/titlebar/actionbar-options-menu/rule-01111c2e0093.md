# 多页共享平台 ActionBar 时建一个共享组件，Up 和溢出用平台原图，不在各页手绘

审的是：代码
触发（任一种）：
- 读到：多个 Activity 共用 android:Theme.Holo 提供的 ActionBar，各页 setDisplayHomeAsUpEnabled(true)；写错的样子：各页各写一个标题栏 @Builder；Up 用 Text('<')、Polyline 或 Circle 画，标题字号各页不同，没有 manifest 图标
适用范围：多个并行转换的页面共享源端平台 ActionBar 外观时
做法：
- 先建一个共享 ActionBar 组件，各页只传 icon（Activity 或 application 的 manifest android:icon）、title、showUp 与动作项
- Up 尖角和溢出按钮用从 SDK 复制的原图 Image($r('app.media.…'))，不用 Polyline、Circle 或字符自绘
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 共享组件：高 48vp，透明底加顶线和蓝色底线，显示 manifest 图标 32vp，Up 与溢出用 SDK 原图，标题 18fp：修复后各页统一用的组件外观（出处：卡里修好并验证过）
