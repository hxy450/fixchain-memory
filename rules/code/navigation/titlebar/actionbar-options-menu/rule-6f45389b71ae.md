# 带图标的溢出菜单项转 MenuItem 时，图标字段写 startIcon，不写 startImage

审的是：代码
触发（任一种）：
- 读到：菜单 XML 的 <item> 带 android:icon，规格要求溢出菜单项带图标；写错的样子：MenuItem({ startImage: …, content: … }) 用了不存在的 startImage 字段
适用范围：把带图标的安卓菜单项迁成 ArkUI MenuItem 时
做法：
- 写成 MenuItem({ startIcon: $r('app.media.…'), content: <标题> })，图标取源 item 的 android:icon
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- MenuItemOptions.startIcon?: ResourceStr：菜单项起始图标（出处：鸿蒙 SDK 的 ets/component/menu_item.d.ts，MenuItemOptions.startIcon）
- MenuItemOptions.content?: ResourceStr：菜单项文字（出处：鸿蒙 SDK 的 ets/component/menu_item.d.ts，MenuItemOptions.content）
- MenuItemOptions.symbolStartIcon?: SymbolGlyphModifier：用 HMSymbol 图标时的起始图标字段（出处：鸿蒙 SDK 的 ets/component/menu_item.d.ts，MenuItemOptions.symbolStartIcon）
