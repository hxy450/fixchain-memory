# 源页 ActionBar 由框架主题着色且计划列了共享顶栏时，页面 hideTitleBar(true) 接共享标题栏

审的是：代码
触发（任一种）：
- 读到：Activity 主题（values-vXX 覆盖优先）的父链到 android:Theme.Material.Light.DarkActionBar 这类带窗口 ActionBar 的框架主题，colorPrimary 指向应用色；计划或公共组件表列了共享顶栏组件；写错的样子：NavDestination 上写 .title(...).menus(...) 用系统标题栏顶替（白底灰圆钮，没有主题底色和标题色），也没登记 `FWD-REF` 或 `HANDOFF` 指向共享件
- 读到：共享顶栏组件的契约头注或公共组件表把这个 NavDestination 页列为消费页；写错的样子：收口后页面仍用 .title()/.menus()，以「形态不同」跳过
适用范围：源 Activity（android.app.Activity，非 AppCompat）的窗口 ActionBar 由框架主题提供、计划列了共享顶栏，迁成 NavDestination 子页时
做法：
- 页面写 NavDestination() { Column() { 共享标题栏.zIndex(1); 内容.layoutWeight(1) } }.hideTitleBar(true)；共享件尚未就绪时登记 `FWD-REF` 或 `HANDOFF` 指向它，不用 .title()/.menus() 顶替
- 收口时按契约头注和公共组件表列出的消费页逐页核对；用系统标题栏顶替共享件的页面也算页内等价实现，按源比对后改接共享件
- 写完逐项对照：栏底色是主题 colorPrimary 的解析值，标题色是 actionBarTheme 下 textColorPrimary 的解析值，图标钮外形同源
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- hideTitleBar(value: boolean): NavDestinationAttribute（默认 false）：隐藏 NavDestination 自带的系统标题栏（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.hideTitleBar）
- hideTitleBar(value: boolean): NavigationAttribute：同族接口：Navigation 根容器的标题栏隐藏（出处：鸿蒙 SDK 的 ets/component/navigation.d.ts，NavigationAttribute.hideTitleBar）
- NavDestination 的 .title()/.menus() 系统标题栏显示为白底、灰色圆底按钮，没有主题底色和白色标题：系统标题栏不跟源端主题着色（出处：卡里修好并验证过）
- Theme.Material.Light.DarkActionBar：actionBarTheme = @style/ThemeOverlay.Material.Dark.ActionBar：浅色内容配深色栏，栏内文字按深色覆盖层取色（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material.Light.DarkActionBar（按应用的 compileSdk 取对应平台））
- Widget.Material.ActionBar.Solid：background = ?attr/colorPrimary（Theme.Material.Light 的 actionBarStyle 是它的子样式）：栏底色就是主题的 colorPrimary（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.ActionBar.Solid；themes_material.xml，Theme.Material.Light 的 actionBarStyle）
- TextAppearance.Material.Widget.ActionBar.Title：textColor = ?attr/textColorPrimary：标题色取 actionBarTheme 下的 textColorPrimary（出处：Android SDK 平台资源 data/res/values/styles_material.xml，TextAppearance.Material.Widget.ActionBar.Title）
针对本应用要查的：
- 窗口 ActionBar 的提供方和栏底色：源工程 AndroidManifest.xml 里 Activity（没有就 application）的 android:theme；res/values-vXX/styles.xml（版本限定高的优先）和 res/values/styles.xml 里同名 style 的 parent 链和 colorPrimary 项；parent 链到 android:Theme.Material.*（非 NoActionBar）即有窗口 ActionBar；栏底色取 colorPrimary 顺着 @color 解析出的值（例：values-v21 覆盖继承 DarkActionBar 时，以 v21 里的 colorPrimary 为准）
- 栏内标题色：Android SDK 平台资源 data/res/values/themes_material.xml 里 actionBarTheme 指向的 ThemeOverlay 的 textColorPrimary，再到 data/res/color/ 下对应的选择器；取默认（非禁用）状态的颜色，写成共享标题栏的标题色
