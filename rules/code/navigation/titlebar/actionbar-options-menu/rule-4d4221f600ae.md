# 菜单项 showAsAction 含 ifRoom/always 且有 icon 时，放标题栏图标位，不进溢出菜单

审的是：代码
触发（任一种）：
- 读到：菜单 XML 的 <item> 带 android:icon，且 app:showAsAction 或 android:showAsAction 含 ifRoom 或 always；写错的样子：这一项和其余项一起放进溢出按钮 bindMenu 的 Menu 里，标题栏只有返回和溢出图标
适用范围：把安卓菜单资源（Toolbar / ActionBar 的 options menu）迁成 ArkUI 标题栏和溢出菜单时
做法：
- showAsAction 含 ifRoom 或 always 且有 icon 的项，写成标题栏里的图标按钮（Image 或 SymbolGlyph 加 onClick，图标取该项的 android:icon）
- 只有 never 或只有 collapseActionView 的项才进溢出按钮绑定的 Menu / MenuItem
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- showAsAction 标志：never = 0、ifRoom = 1、always = 2、withText = 4、collapseActionView = 8：never 进溢出；ifRoom、always 显示在操作栏；可与 collapseActionView 组合（出处：Android SDK 平台资源 data/res/values/attrs.xml，MenuItem 的 showAsAction（按应用的 compileSdk 取对应平台））
- ifRoom|collapseActionView 且带 icon 的项移到标题栏图标位后与源端一致：组合里含 ifRoom 就按显示在标题栏处理（出处：卡里修好并验证过）
