# 安卓顶栏有编辑/完成切换、底栏随模式换控件时，目标写出编辑态和两套底栏

审的是：代码
触发（任一种）：
- 读到：安卓 Compose Screen 的 `TopAppBar` 动作在编辑/完成间切换，底栏 Composable 按编辑态显示删除、普通态显示合计和结算；写错的样子：目标页面没有编辑态的 `@State`，顶栏只有单一动作（如只有清空），底栏只有一套结算控件
适用范围：按「对比安卓还原」实现带选择和批量操作的列表页面时
做法：
- 加一个编辑态 @State，顶栏按钮在「编辑」「完成」间切换它；底栏按它分支：编辑态显示「已选 N 件」和删除选中，普通态显示合计和结算
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 顶栏编辑/完成切换；编辑态底栏显示已选件数和删除选中，普通态显示合计和结算：修复后的模式切换（出处：卡里修好并验证过）
针对本应用要查的：
- 安卓页面有哪些模式、各模式下顶栏和底栏的控件：源工程里对应页面的 Compose Screen 和 ViewModel（.kt），找顶栏 actions 和底栏 Composable 里按状态分支的 if/when；每个状态分支列出显示的控件和点击动作，目标按同样的状态分支写
