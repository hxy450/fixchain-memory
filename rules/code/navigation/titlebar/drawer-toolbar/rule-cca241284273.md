# NavigationView 没写 item 样式时，抽屉行按 Material 默认样式逐项复刻，不只做二值变色

审的是：代码
触发（任一种）：
- 读到：DrawerLayout 里的 com.google.android.material.navigation.NavigationView 只给 app:menu、app:headerLayout，没写 itemIconTint、itemTextColor、itemBackground、itemTextAppearance；menu 分组带 android:checkableBehavior；写错的样子：目标菜单行只按选中切换 fontColor / fillColor（选中 colorPrimary、未选纯黑），没有选中底色和加粗，未选图标不着灰；组间 Divider 左右内缩、借近名灰色；List 没有顶部留白
适用范围：源 NavigationView 的菜单项外观全部来自 Material 默认样式（主题也没设 navigationViewStyle），目标用自定义 List 行复刻抽屉时
做法：
- 选中行：通栏高亮底（白底约 #E0E0E0），图标和文字 colorPrimary，fontWeight(FontWeight.Bold)；未选行：14fp Medium、主文字色（白底近 #212121），图标按次要文字色着色（约 60% 黑）；行高 48vp
- 组间写 1vp 通栏分隔线（不左右内缩），上下各 8vp；菜单 List 顶部留白 8vp
- 库的资源或源码不在手边时，逐项标待核并在报告里列出，不写「NavigationView 样式」这类没有出处的注释
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 选中：#E0E0E0 通栏底 + colorPrimary + Bold；未选：Medium + 主文字色，图标 #99000000；分隔 1dp 通栏、上下 8dp；列表顶 8dp；行 48dp、14sp：返修按安卓实测复刻后的取值（出处：卡里修好并验证过）
- Widget.Design.NavigationView 不设 itemIconTint、itemTextColor、itemBackground、itemTextAppearance：AppCompat 主题下这些默认外观由 NavigationView 代码生成，不在样式里（出处：com.google.android.material:material 包内 res/values/values.xml，Widget.Design.NavigationView（按应用依赖的版本））
- 菜单项 minHeight = ?attr/listPreferredItemHeightSmall；AppCompat 里 abc_list_item_height_small_material = 48dp：行高 48（出处：material 包内 res/layout/design_navigation_item.xml；androidx.appcompat:appcompat 包内 res/values/values.xml，abc_list_item_height_small_material）
- 菜单文字 CheckedTextView 的 textAppearance = TextAppearance.AppCompat.Body2（14sp，textColor ?android:textColorPrimary）：未选文字的字号和颜色来源（出处：material 包内 res/layout/design_navigation_menu_item.xml；appcompat 包内 res/values/values.xml，Base.TextAppearance.AppCompat.Body2）
- design_navigation_separator_vertical_padding = 8dp；design_navigation_padding_bottom = 8dp：分隔线上下间距和列表底部留白（出处：material 包内 res/values/values.xml，design_navigation_separator_vertical_padding、design_navigation_padding_bottom）
- 分隔项是 match_parent 宽、1dp 高的 View，背景 ?android:attr/listDivider：分隔线通栏，不内缩（出处：material 包内 res/layout/design_navigation_item_separator.xml）
- listDivider = list_divider_material：tint ?attr/colorListDivider（= colorForeground，浅色为黑），solid 取 list_divider_opacity_material #1f000000：分隔线颜色约为 12% 黑（出处：Android SDK 平台资源 data/res/drawable/list_divider_material.xml；data/res/values/themes_material.xml，colorListDivider；data/res/values/colors_material.xml，list_divider_opacity_material（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 主题有没有覆盖抽屉外观：源工程 res/values*/styles.xml、themes.xml 里应用主题的 navigationViewStyle、colorPrimary、android:textColorPrimary、android:textColorSecondary；有 navigationViewStyle 就按它的 item* 项取值；colorPrimary 取主题里的值作选中色
未核实：分隔线着色按 Drawable 默认的 SRC_IN 着色推断为 #1F000000，没有上机核对
