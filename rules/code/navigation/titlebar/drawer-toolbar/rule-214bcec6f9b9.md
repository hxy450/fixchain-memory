# 共享基座遇到先行页面的页内草稿时，把它当待收敛对象，不当取值来源

审的是：代码
触发（任一种）：
- 读到：工程里先行页面已有页内等价草稿（如页内抽屉），注释写着它自己的取值，例如「checked → colorPrimary，默认 → 黑」；写错的样子：共享组件照草稿取值（注释写 precedent、沿用某页先例），只剩 fontColor / fillColor 二值切换；和源库默认或自己原先的推导（选中项有底色、未选图标偏灰）不一致时也跟草稿走
适用范围：写共享基座或公共组件、工程里已有先行页面的页内等价实现时
做法：
- 草稿值与源库默认样式或自己的推导不一致时，以源为准
- 在报告里列出页面草稿需要收敛的差异，作为待收敛项
