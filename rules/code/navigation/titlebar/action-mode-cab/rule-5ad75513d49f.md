# 同一菜单复用于 ActionMode/CAB 时，未声明 showAsAction 的项按两种缺省分别填充

审的是：代码
触发（任一种）：
- 读到：ActionMode.Callback 的 onCreateActionMode 里用 mode.getMenuInflater().inflate(...) 复用页面菜单，有 <item> 没写 app:showAsAction；写错的样子：CAB 栏和 CAB 溢出复制一份固定清单，或两种填充用同一个缺省值（未声明项在 CAB 里也一律进溢出）
适用范围：安卓选项菜单与多选 CAB 复用同一份 menu XML，迁成自绘工具栏和自绘 CAB 时
做法：
- 菜单填充函数带缺省值参数：选项菜单缺省 SHOW_AS_ACTION_NEVER，ActionMode/CAB 缺省 SHOW_AS_ACTION_IF_ROOM；只对未声明 showAsAction 的项用缺省，两种填充再走同一个宽度布局函数
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- private int mDefaultShowAsAction = MenuItem.SHOW_AS_ACTION_NEVER：普通菜单里未声明 showAsAction 的项缺省进溢出（出处：com.android.internal.view.menu.MenuBuilder（框架版））
- new MenuBuilder(...).setDefaultShowAsAction(MenuItem.SHOW_AS_ACTION_IF_ROOM)：ActionMode 的菜单缺省是 ifRoom（出处：com.android.internal.view.StandaloneActionMode（框架版，AppCompat 同名类本机只有编译产物））
- XML 没写 showAsAction 时读出 -1，不调 setShowAsAction，沿用菜单的缺省值：缺省值由填充进哪种菜单决定，不由 XML 决定（出处：android.view.MenuInflater#readItem）
- 填充时按菜单种类传缺省值后，横屏 CAB 里未声明 showAsAction 的项以文字键上栏，与源端一致：两种缺省分开传的做法（出处：卡里修好并验证过）
未核实：AppCompat 的 SupportMenuInflater / StandaloneActionMode 本机只有编译产物，缺省值按框架同名类核对
