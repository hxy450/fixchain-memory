# 用共享组件替换页面里已实现的片段前，逐项对比标题色、尾部图标和内边距，不一致先修组件

审的是：代码
触发（任一种）：
- 写错的样子：页面里原本自写的 @Builder 片段（带标题色、尾部图标）被换成共享 @Component 的调用，组件的标题颜色、尾部图标或 padding 和原片段不一致
适用范围：接线复用阶段，用公共组件替换页面中已经实现的同类片段时
做法：
- 替换前把原片段和共享组件逐项对比标题颜色、尾部图标与内边距；不一致时先修共享组件，再替换
