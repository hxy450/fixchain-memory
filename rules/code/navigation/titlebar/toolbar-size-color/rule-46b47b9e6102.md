# ?attr/actionBarSize 等主题取值先沿 parent 链定 Material 代际再取默认值

审的是：代码
触发（任一种）：
- 读到：MaterialToolbar 的 android:layout_height="?attr/actionBarSize"、BottomNavigationView，布局不写具体数值；styles.xml 里主题 parent=Theme.Material3.* 或 Theme.MaterialComponents.*；写错的样子：代码或 float 资源写成 56（「Material 默认 56dp」），理由只是 grep 不到 actionBarSize 的显式覆写
- 读到：兄弟页 .ets 里已有的工具栏写法（.fontSize(20).fontWeight(FontWeight.Medium)、.margin({ left: 16 })）；写错的样子：注释写「与兄弟页逐值一致」「match the nearest sibling」，照搬兄弟页的 .height(...)、.fontSize(...) 等数值，没回主题核对
适用范围：由主题属性和组件默认样式决定的高度、字号、字重、内缩，迁成 ArkUI 自绘组件或 float 资源时
做法：
- 读源工程的 styles.xml / themes.xml，沿应用主题和 toolbarStyle 等的 parent 链追到根主题：Theme.Material3.*，还是 Theme.MaterialComponents.* / Theme.AppCompat.*
- 按该代际在依赖库 values.xml 里的定义取值（如 Theme.Material3 的 actionBarSize 解析到 64dp）；grep 不到显式覆写不等于用 M2 默认；兄弟页的数值也这样核对后再沿用
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Base.V14.Theme.Material3.Light 的 actionBarSize = @dimen/m3_appbar_size_compact → @dimen/m3_comp_top_app_bar_small_container_height = 64dp：Material3 主题下 ?attr/actionBarSize 是 64dp（出处：com.google.android.material:material 包内 res/values/values.xml，Base.V14.Theme.Material3.Light 的 actionBarSize、m3_comp_top_app_bar_small_container_height（按应用依赖的版本））
- mtrl_toolbar_default_height = 56dp：MaterialComponents（M2）主题下 actionBarSize 用的值（出处：com.google.android.material:material 包内 res/values/values.xml，mtrl_toolbar_default_height（按应用依赖的版本））
- abc_action_bar_default_height_material = 56dp：AppCompat 的默认工具栏高度（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，abc_action_bar_default_height_material（按应用依赖的版本））
- 按 56 写的 float 资源和代码常量改成 64、标题改成 22 Normal 后与安卓一致：验证过的取值（出处：卡里修好并验证过）
针对本应用要查的：
- 应用主题的组件库代际：源工程 res/values 下的 styles.xml、themes.xml：AndroidManifest 里 android:theme 指的主题，以及 toolbarStyle、bottomNavigationStyle 指的样式；沿 parent 一直追到 Theme.Material3.* / Theme.MaterialComponents.* / Theme.AppCompat.* 为止；例：parent 链到 Theme.Material3.DynamicColors.* 时是 Material3
- 该代际下的具体默认值：依赖库 com.google.android.material:material 包内 res/values/values.xml（按应用依赖的版本），按主题名找 actionBarSize，按 Widget.Material3.Toolbar 等组件样式找 titleTextAppearance；顺着 @dimen、?attr、@macro 引用一路解析到具体的 dp / sp 值
未核实：卡里没记 Material 库版本，用本机缓存的 material 1.12.0 和 appcompat 1.7.1 核实
