# 标题栏高度写 ?attr/actionBarSize 时，目标引用分方向的资源键，不写 56 / 20 字面量

审的是：代码
触发（任一种）：
- 读到：源布局 Toolbar 的 android:layout_height="?attr/actionBarSize"，标题没写 textAppearance / textSize，主题继承 Theme.AppCompat.*（窗口 ActionBar 或 Toolbar），Activity 没锁定方向；写错的样子：目标标题栏写成 `const …: number = 56` 常量、.height(56)、标题 .fontSize(20) 这类不随方向变化的字面量
- 读到：要复用的共享标题栏先例（页面基座一类共享 @Component）里是 .height(56)、.fontSize(20) 这类字面量；写错的样子：新页面照抄先例的 .fontSize(20) / 56，没有引用带限定目录的资源键
适用范围：自绘标题栏或 ActionBar 代体的高度和标题字号，源端由 AppCompat / Material 主题属性按配置解析时
做法：
- 先按主题提供方（AppCompat / Material 及其版本）列出各配置限定词下的值，再落实；高度写 .height($r('app.float.…')) 这类资源引用，标题写 .fontSize($r('app.float.…'))，键在 base 与 horizontal 下同名，不写 TS 常量或字面量
- 复用共享件的标题栏数值前，看它是否引用了带限定目录的资源键；先例是字面量时，改成引用同一资源键，不复制字面量
- 已在转 layout-land 变体的页面同样检查共享标题栏和 ActionBar 代体的横屏尺寸；应用 res 没有横屏覆盖不等于两向同值，查不到时在报告里把横屏工具栏尺寸标为待核
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- abc_action_bar_default_height_material：values 56dp、values-land 48dp、values-sw600dp-v13 64dp：AppCompat 主题的 actionBarSize 引用它，横屏变矮（出处：androidx.appcompat:appcompat 包内 res/values/values.xml、res/values-land/values-land.xml、res/values-sw600dp-v13/values-sw600dp-v13.xml，abc_action_bar_default_height_material（按应用依赖的版本））
- abc_text_size_title_material_toolbar：values 20dp、values-land 14dp：Toolbar / ActionBar 标题字号，横屏变小；单位是 dp（出处：androidx.appcompat:appcompat 包内 res/values/values.xml、res/values-land/values-land.xml，abc_text_size_title_material_toolbar（按应用依赖的版本））
- Base.V7.Theme.AppCompat：actionBarSize = @dimen/abc_action_bar_default_height_material；Base.V7.Widget.AppCompat.Toolbar：titleTextAppearance = @style/TextAppearance.Widget.AppCompat.Toolbar.Title，其 textSize = @dimen/abc_text_size_title_material_toolbar：主题属性到这两个尺寸的解析链（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Base.V7.Theme.AppCompat、Base.V7.Widget.AppCompat.Toolbar、Base.TextAppearance.AppCompat.Widget.ActionBar.Title（按应用依赖的版本））
- 安卓横屏实测工具栏 48dp、标题约 14sp；base 与 horizontal 同名 float 资源承载后两端一致：修好后上机核对的结果（出处：卡里修好并验证过）
针对本应用要查的：
- 这个应用的主题提供方和版本下 actionBarSize、标题字号在各限定目录的值：源工程 styles.xml / themes.xml 的主题 parent 链，以及依赖库（androidx.appcompat:appcompat、com.google.android.material:material）包内 res/values*/ 下的 abc_action_bar_default_height_material、abc_text_size_title_material_toolbar；按应用依赖的版本逐个限定目录读出数值；应用自己 res 里有同名覆盖的以应用为准
未核实：values-sw600dp 的 64dp 对应到目标哪个限定词卡里没有验证
