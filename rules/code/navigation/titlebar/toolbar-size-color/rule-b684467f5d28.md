# 源主题是 Material3 时，自绘工具栏高 64、标题 22 号 Normal、标题起点 16

审的是：代码
触发（任一种）：
- 读到：styles.xml 的主题 parent 链到 Theme.Material3.*，toolbarStyle parent=Widget.Material3.Toolbar，布局用 MaterialToolbar；写错的样子：自绘工具栏写成 Row 高 56、标题 .fontSize(20).fontWeight(FontWeight.Medium)、.margin({ left: 16 }) 加 Row padding 12 这类 AppCompat / M2 默认
适用范围：源主题为 Material3、把 MaterialToolbar 迁成 ArkUI 自绘 Row 工具栏时
做法：
- Row 高 64；标题 Text(...).fontSize(22).fontWeight(FontWeight.Normal)；没有导航图标时标题起点 16
- 有导航图标时图标占 16..40 的位置，标题起点约 60
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Material3 主题的 actionBarSize 解析到 m3_comp_top_app_bar_small_container_height = 64dp：工具栏高度（出处：com.google.android.material:material 包内 res/values/values.xml，m3_comp_top_app_bar_small_container_height（按应用依赖的版本））
- Widget.Material3.Toolbar 的 titleTextAppearance = @macro/m3_comp_top_app_bar_small_headline_type = ?attr/textAppearanceTitleLarge：标题用 TitleLarge（出处：com.google.android.material:material 包内 res/values/values.xml，Widget.Material3.Toolbar、m3_comp_top_app_bar_small_headline_type（按应用依赖的版本））
- TextAppearance.M3.Sys.Typescale.TitleLarge：android:textSize 22sp，fontFamily = m3_ref_typeface_brand_regular = sans-serif：标题 22sp、常规字重（不是 Medium）（出处：com.google.android.material:material 包内 res/values/values.xml，TextAppearance.M3.Sys.Typescale.TitleLarge（按应用依赖的版本））
- Widget.Material3.Toolbar 的 contentInsetStartWithNavigation = 0dp：M3 有导航图标时不再用 AppCompat 的 72dp 起点（出处：com.google.android.material:material 包内 res/values/values.xml，Widget.Material3.Toolbar（按应用依赖的版本））
- Base.V7.Widget.AppCompat.Toolbar：contentInsetStart 16dp，titleMargin 4dp：标题起点 16dp 的来源（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Base.V7.Widget.AppCompat.Toolbar（按应用依赖的版本））
- abc_text_size_title_material_toolbar = 20dp：AppCompat / M2 工具栏标题的 20 号，Material3 下不用（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，abc_text_size_title_material_toolbar（按应用依赖的版本））
- FontWeight.Normal 相当于 400，FontWeight.Bold 相当于 700：常规字重写 FontWeight.Normal（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，FontWeight）
- 11 处标题栏改为 22fp Normal、高度改为 64 后和安卓截图一致：验证过的取值（出处：卡里修好并验证过）
未核实：有导航图标时「图标 16..40、标题约 60」出自卡里的测量，库资源里没有直接对应的单个值；卡里没记 Material 库版本，用本机缓存的 material 1.12.0 和 appcompat 1.7.1 核实
