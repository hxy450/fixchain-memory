# 自绘栏复刻框架 ActionBar 时，按 elevation 加 shadow，宿主用 zIndex 压在内容上

审的是：代码
触发（任一种）：
- 读到：源端用窗口 ActionBar（生效主题的 actionBarStyle 属 Widget.Material.ActionBar 一族），布局里看不到它的 elevation；写错的样子：复刻 ActionBar 的共享标题栏 Row 只有 .backgroundColor(...)，没有 .shadow(...)；宿主页面放它时没有 .zIndex(...)，投影被下面的内容盖住
适用范围：用自绘共享组件复刻框架窗口 ActionBar 时，组件本身和放置它的宿主页面
做法：
- 标题栏 Row 加 .shadow({ radius, color, offsetX: 0, offsetY })，取值由 Widget.Material.ActionBar 的 elevation（action_bar_elevation_material）换算成 px
- 在组件接口说明里要求宿主把标题栏层叠在内容之上，宿主调用处加 .zIndex(1)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Widget.Material.ActionBar 的 elevation = @dimen/action_bar_elevation_material = 4dp：框架 ActionBar 的投影高度（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.ActionBar；data/res/values/dimens_material.xml，action_bar_elevation_material（按应用的 compileSdk 取对应平台））
- Widget.Material.Light.ActionBar.Solid → Widget.Material.ActionBar.Solid → Widget.Material.ActionBar：Material.Light 主题的 actionBarStyle 沿这条链继承到 elevation（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.Light.ActionBar.Solid（按应用的 compileSdk 取对应平台））
- shadow(value: ShadowOptions | ShadowStyle): T：组件框阴影（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.shadow）
- ShadowOptions.radius 的单位是 px：dp 的 elevation 要先乘密度换成 px（出处：鸿蒙 SDK 的 ets/component/common.d.ts，ShadowOptions.radius）
- zIndex(value: number): T，值大的在同一容器的兄弟组件之上：宿主用它让标题栏压在内容上（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.zIndex）
- 栏 Row 加 shadow（px）、宿主调用处加 zIndex(1) 后投影与源端对齐：修好后的接法（出处：卡里修好并验证过）
针对本应用要查的：
- 生效主题下 ActionBar 的全部默认外观：平台 themes_material.xml 里生效主题的 actionBarStyle，再到 styles_material.xml 里那个 style 及其父 style；读整个 style 的 item 列表（背景、标题色、elevation 等），不只 grep 记得的几个 dimen 名，逐项迁到标题栏组件
未核实：elevation 和 ShadowOptions.radius 之间没有确定的换算，卡里是对照截图的渐隐宽度校准的
