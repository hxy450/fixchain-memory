# 标题栏 Up 区按 Material 的 Toolbar 导航钮样式取宽和标题起点，不凑近似值

审的是：代码
触发（任一种）：
- 读到：源主题是 Theme.Material 系的窗口 ActionBar，页面 setDisplayHomeAsUpEnabled(true)；写错的样子：Up 区写成 minWidth 加对称 padding、标题左距凑数并注「近似」
适用范围：自绘标题栏还原 Material 窗口 ActionBar 的 Up 导航区时
做法：
- Up 区宽取 Toolbar 导航钮样式的 minWidth，图标居中；标题起点取 contentInsetStartWithNavigation
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Widget.Material.Toolbar.Button.Navigation：minWidth=56dp，scaleType=center：Up 区宽 56dp、图标居中（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.Toolbar.Button.Navigation（按应用的 compileSdk 取对应平台））
- Widget.Material.ActionBar：contentInsetStartWithNavigation=@dimen/action_bar_content_inset_with_nav（72dp）：有 Up 时标题起点（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.ActionBar；data/res/values/dimens_material.xml，action_bar_content_inset_with_nav）
- Theme.Material.Light：windowActionBarFullscreenDecorLayout=@layout/screen_toolbar：Material 窗口 ActionBar 由 Toolbar 实现，导航钮按 Toolbar 样式取（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material.Light；data/res/layout/screen_toolbar.xml，Toolbar）
