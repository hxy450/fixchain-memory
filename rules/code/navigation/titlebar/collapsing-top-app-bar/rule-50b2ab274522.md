# 折叠顶栏的代码用列表 onScrollFrameBegin 联动顶栏高度，不写固定高度顶栏只变色

审的是：代码
触发（任一种）：
- 读到：Compose 源码 LargeFlexibleTopAppBar 配 TopAppBarDefaults.exitUntilCollapsedScrollBehavior(...)，有 collapse() 动画；写错的样子：目标顶栏是固定高度（如 64vp）的 Row，只在 onDidScroll 里按滚动量变色；或各页另写页内顶栏、注释「列表短，折叠行为不迁移」
适用范围：把 Compose 折叠大标题顶栏迁成 ArkUI 自绘顶栏时
做法：
- List(...).onScrollFrameBegin((offset: number, state: ScrollState) => { 上滑先把 offset 用于折叠顶栏高度、下滑到顶时先展开；return { offsetRemain: 剩下的量 } })
- 松手停在中间态时用弹簧动画吸附到展开或折叠，collapse() 用高度动画实现；顶栏写成共享组件，各页接入自己的列表滚动
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onScrollFrameBegin(event: OnScrollFrameBeginCallback): ListAttribute：列表每帧滚动前回调，返回实际滚动量（出处：鸿蒙 SDK 的 ets/component/list.d.ts，ListAttribute.onScrollFrameBegin）
- (offset: number, state: ScrollState) => OnScrollFrameBeginHandlerResult，offset 单位 vp，返回 { offsetRemain }：回调的参数和返回（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，OnScrollFrameBeginCallback）
- onScrollFrameBegin(event: OnScrollFrameBeginCallback): ScrollAttribute：同族接口：Scroll 的同名回调（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，ScrollAttribute.onScrollFrameBegin）
- onScrollFrameBegin(event: OnScrollFrameBeginCallback): GridAttribute：同族接口：Grid 的同名回调（出处：鸿蒙 SDK 的 ets/component/grid.d.ts，GridAttribute.onScrollFrameBegin）
- 先折叠后滚动、余量展开、中间态弹簧吸附、collapse() 动画的共享顶栏替换各页固定顶栏后行为对上：卡里的修法（出处：卡里修好并验证过）
针对本应用要查的：
- 展开和折叠两态的高度：依赖库 androidx.compose.material3:material3（按应用依赖的版本）里大标题顶栏的高度常量，或源端截图量出；展开高度和折叠高度分别作顶栏高度的上下限
未核实：卡里环境是 API 24，按本机 API 23 的声明核实
