# 自绘替代 M3 底栏或模态抽屉时，按 material3 版本逐项列默认值并实现

审的是：代码
触发（任一种）：
- 读到：Compose `NavigationBar` / `NavigationBarItem` 多数参数取库默认值；写错的样子：自定义 Row 底栏的容器色、项间距、指示器尺寸、选中图标/标签色是自定的近似值，没有按 material3 版本核
- 读到：Compose `ModalNavigationDrawer(gesturesEnabled = true)` + `ModalDrawerSheet`；写错的样子：自定义滑出面板只有左缘热区、过阈值即切换不跟手，固定遮罩色、线性转场，`if (drawerOpen)` 条件渲染（关闭即销毁），面板直角固定宽
适用范围：源端用 Material3 底栏、模态抽屉且取库默认值，目标改成 ArkUI 自定义实现时
做法：
- 先查源工程的 compose-bom / material3 版本，按该版本列实现清单：容器色角色、项间距、指示器尺寸、选中图标/标签色、面板色/形状/最大宽度、开合动画时长与曲线、scrim 透明度×展开比例、拖拽区域与速度阈值、关闭时内容是否常驻；逐项实现或登记差异，不用近似值
- 抽屉写成常驻面板（不用 if 条件渲染），根 Stack 挂 PanGesture({ direction: PanDirection.Horizontal }) 跟手改展开比例；onActionEnd 按 velocityX 是否过速度阈值或是否过半宽吸附，再用 animateTo({ duration, curve: Curve.FastOutSlowIn }) 开合；遮罩透明度 = 源 scrim 不透明度 × 展开比例
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 常驻面板 + 根 Stack 的 PanGesture 跟手，速度阈值或半宽吸附，FastOutSlowIn 开合，scrim 不透明度乘展开比例：修复后的抽屉做法，复审通过（出处：卡里修好并验证过）
- (value?: { fingers?: number; direction?: PanDirection; distance?: number } | PanGestureOptions): PanGestureInterface：拖拽手势的构造，direction 传 PanDirection.Horizontal（出处：鸿蒙 SDK 的 ets/component/gesture.d.ts，PanGestureInterface）
- GestureEvent.offsetX 单位 vp；velocityX 单位 vp/s，从左往右为正：跟手位移和离手速度的单位，和源端 dp、dp/s 阈值同量纲（出处：鸿蒙 SDK 的 ets/component/gesture.d.ts，GestureEvent.offsetX；ts-gesture-common.md，GestureEvent对象说明）
- Curve.FastOutSlowIn：动画曲线枚举里对应 Compose FastOutSlowInEasing 的一项（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，Curve.FastOutSlowIn）
- animateTo(value: AnimateParam, event: () => void): void：UIContext 上的显式动画，开合时长和曲线在 AnimateParam 里给（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.animateTo）
针对本应用要查的：
- 源工程用的 material3 版本：源工程的版本目录 gradle/libs.versions.toml 或 app 模块 Gradle 构建脚本里的 compose-bom、material3 坐标；读出 bom 版本，再查这个 bom 对应的 material3 版本；默认值按这个版本取
- 该 material3 版本的底栏和抽屉默认值：该版本 material3 的 NavigationBarDefaults、NavigationBarItemDefaults、DrawerDefaults 及对应 tokens（本机依赖缓存里只有编译产物，看 sources jar 或官方源码）；逐项读出清单里的容器色角色、尺寸、动画时长与曲线、scrim 不透明度、速度阈值。例：compose-bom 2026.08.00 下修复取底栏 surfaceContainer、项间 8dp、指示器 56×32、选中标签 secondary；抽屉 surfaceContainerLow、右侧 16 圆角、宽 min(360, 屏宽)、256ms、scrim 0.32、400dp/s
未核实：卡里的行为出自鸿蒙 SDK API 24，本机核实用的是 API 23
