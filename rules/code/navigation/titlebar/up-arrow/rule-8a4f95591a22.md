# 主题带窗口 ActionBar、Manifest 有 parentActivityName 时，自绘标题条画 Up 箭头

审的是：代码
触发（任一种）：
- 读到：Manifest 里 Activity 有 android:parentActivityName 或 android.support.PARENT_ACTIVITY meta-data，主题是带窗口 ActionBar 的 Theme.AppCompat（如 DarkActionBar），代码没调 setDisplayHomeAsUpEnabled，onOptionsItemSelected 处理 android.R.id.home；写错的样子：自绘标题条里没有返回箭头，注释写「源端未调 setDisplayHomeAsUpEnabled，无返回箭头」，返回只靠系统返回键
适用范围：源 Activity 用带窗口 ActionBar 的 AppCompat 主题、目标端用自绘标题条代替 ActionBar 时，决定画不画 Up 箭头
做法：
- 按顺序判定：①主题带窗口 ActionBar（windowActionBar 为 true）②Manifest 有 parentActivityName 或 PARENT_ACTIVITY meta-data ③代码里有没有显式 setDisplayHomeAsUpEnabled(true/false)；①②成立且没有显式调用时，Up 默认显示，要画箭头
- 标题条起始处放 56vp 宽的导航区画返回箭头，标题从 72vp 起；点击执行 android.R.id.home 分支的同一段逻辑（如先保存）再返回上一页
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Activity#onCreate 里 mActivityInfo.parentActivityName != null 时，ActionBar 的默认 Up 设为开启（setDefaultDisplayHomeAsUpEnabled(true)）：声明了 parentActivityName 就默认显示 Up，不需要代码调用（出处：android.app.Activity#onCreate）
- setDefaultDisplayHomeAsUpEnabled 只在没有显式设过 DISPLAY_HOME_AS_UP 时生效：代码显式调 setDisplayHomeAsUpEnabled(true/false) 时以显式调用为准（出处：com.android.internal.app.WindowDecorActionBar#setDefaultDisplayHomeAsUpEnabled）
- Base.V7.Theme.AppCompat 的 windowActionBar = true；Theme.AppCompat.NoActionBar 的 windowActionBar = false：主题是否带窗口 ActionBar 看 parent 链落到哪一族（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Base.V7.Theme.AppCompat、Theme.AppCompat.NoActionBar（按应用依赖的版本））
- Base.Widget.AppCompat.Toolbar.Button.Navigation 的 android:minWidth = 56dp：Up 箭头所在导航按钮的宽度，迁成 56vp（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Base.Widget.AppCompat.Toolbar.Button.Navigation（按应用依赖的版本））
- abc_action_bar_content_inset_with_nav = 72dp：有导航按钮时标题的起始缩进（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，abc_action_bar_content_inset_with_nav（按应用依赖的版本））
- homeAsUpIndicator = @drawable/abc_ic_ab_back_material：AppCompat 主题默认的 Up 箭头图（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Base.V7.Theme.AppCompat 的 homeAsUpIndicator（按应用依赖的版本））
- 主题带窗口 ActionBar 且 Manifest 声明 parentActivityName 时，不调 setDisplayHomeAsUpEnabled 也显示 Up；自绘标题条补上 56vp 导航区箭头、点击走 home 分支逻辑后返回：修好后的做法（出处：卡里修好并验证过）
针对本应用要查的：
- 这个 Activity 实际用的主题带不带窗口 ActionBar：源工程 AndroidManifest 里这个 Activity 的 android:theme（没有就看 application 的 android:theme），再到源工程 res/values 的 styles、themes 文件里顺着 parent 链找；parent 链落到 Theme.AppCompat.*.NoActionBar 或 windowActionBar 为 false 的，没有窗口 ActionBar；落到 Theme.AppCompat、Theme.AppCompat.Light.DarkActionBar 这一族且没改 windowActionBar 的，有窗口 ActionBar
未核实：AppCompat 窗口 ActionBar 的默认 Up 逻辑本机只核对了框架 android.app.Activity 的同一段，AppCompat 库代码按卡写
