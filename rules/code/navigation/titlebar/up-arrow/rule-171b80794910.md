# homeAsUp 返回箭头用 Image 加 matchTextDirection(true)，不换系统符号

审的是：代码
触发（任一种）：
- 读到：源码 `setDisplayHomeAsUpEnabled(true)`，默认箭头 `abc_ic_ab_back_material` 带 `android:autoMirrored="true"`；写错的样子：目标返回按钮写成 `SymbolGlyph($r('sys.symbol.chevron_left'))`，或 Image 没写 `.matchTextDirection(true)`
适用范围：源工具栏用 AppCompat 默认 Up 箭头，迁成目标页面的返回按钮时
做法：
- Image($r('app.media.<箭头 svg>')).width(24).height(24).matchTextDirection(true)，svg 由 AppCompat 的 abc_ic_ab_back_material 生成
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- matchTextDirection(value: boolean): ImageAttribute，默认 false：图片随系统语言方向镜像，对应源端 autoMirrored="true"（出处：鸿蒙 SDK 的 ets/component/image.d.ts，ImageAttribute.matchTextDirection）
- android:autoMirrored="true"：源端箭头在 RTL 下镜像（出处：androidx.appcompat:appcompat 包内 res/drawable/abc_ic_ab_back_material.xml（按应用依赖的版本））
- Image + media svg + matchTextDirection(true) 替换 SymbolGlyph 后，箭头形状与源端一致：验证过的写法（出处：卡里修好并验证过）
未核实：卡里的效果在目标 API 24 上验证，本机核对用的是 API 23 的声明
