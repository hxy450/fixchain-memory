# 源端无 parentActivityName 和 setDisplayHomeAsUpEnabled 时，不画返回箭头

审的是：代码
触发（任一种）：
- 读到：Manifest 的 <activity> 没有 android:parentActivityName，Activity 代码里没有 setDisplayHomeAsUpEnabled(true) / getSupportActionBar()；写错的样子：自绘标题栏开头画了返回箭头（ic_back 图标、showBack 选项，或注释写 up affordance）
适用范围：目标页 hideTitleBar 自绘 ActionBar、源端是 AppCompat Activity 时
做法：
- 自绘前查 Manifest 的 parentActivityName 和代码里的 setDisplayHomeAsUpEnabled / getSupportActionBar；都没有就不画返回箭头、不提供 showBack，返回交给系统返回键和手势
- 复用 skill 模板或兄弟页的标题栏时，按当前源核对返回箭头，不照搬模板自带的返回图标
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- setDisplayHomeAsUpEnabled：Set whether home should be displayed as an "up" affordance：返回箭头要源端显式打开（出处：android.app.ActionBar#setDisplayHomeAsUpEnabled）
- parentActivityName：The name of the logical parent of the activity as it appears in the manifest：Manifest 里声明的逻辑上级（出处：Android SDK 平台资源 data/res/values/attrs_manifest.xml，parentActivityName（按应用的 compileSdk 取对应平台））
- 修复用统一的自绘 ActionBar 替换各页标题栏：无返回箭头，右上 ⋮ 弹层：去掉凭空的返回箭头后和源端一致（出处：卡里修好并验证过）
