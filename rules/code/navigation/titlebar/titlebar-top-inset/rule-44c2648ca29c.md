# 全屏自绘标题栏时，状态栏避让单独成块再接 56vp 栏，不在 height(56) 里加 top

审的是：代码
触发（任一种）：
- 读到：源端是 AppCompat ActionBar（默认高 56dp），目标页 hideTitleBar 自绘标题栏、在全屏窗口内做安全区避让；写错的样子：标题栏写成 .height(56).padding({ top: 顶部避让 }) 一行，避让挤占栏内高度，状态栏区域没有底色
适用范围：全屏窗口里自绘 ActionBar 标题栏时，含公共骨架和 skill 模板
做法：
- 状态栏条单独一块：高 = 顶部避让，底色用状态栏 token
- 下面再接 .height(56) 的 ActionBar 行（底色用 ActionBar token），这一行不加 top padding
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- abc_action_bar_default_height_material = 56dp：AppCompat ActionBar 的默认高度（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，abc_action_bar_default_height_material（按应用依赖的版本））
- getWindowAvoidArea(type: AvoidAreaType): AvoidArea；AvoidAreaType.TYPE_SYSTEM = 0；AvoidArea.topRect: Rect：取顶部避让区域（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.getWindowAvoidArea、AvoidAreaType.TYPE_SYSTEM、AvoidArea.topRect）
- Rect.height 单位为 px：作为状态栏条高度前要换成 vp（出处：arkts-apis-window-i.md，Rect）
- px2vp(value: number): number：把 px 换成 vp（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.px2vp）
- 状态栏条单独绘制（高 = 顶部避让）+ 56vp ActionBar，去掉 showBack：栏内高度不再被压缩，状态栏有底色（出处：卡里修好并验证过）
未核实：卡里的环境是 HarmonyOS 6.1.1（API 24），本机是 API 23
