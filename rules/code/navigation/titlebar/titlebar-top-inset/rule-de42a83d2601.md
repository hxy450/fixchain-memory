# 全屏窗口加根 Navigation expandSafeArea 下，NavDestination 页不靠原生标题栏避让

审的是：代码
触发（任一种）：
- 读到：页面规格 needs_immersive_safearea=true，转换决策把源端 TopAppBar 映射为 NavDestination 原生标题栏；写错的样子：NavDestination 用 .title() 原生标题栏且没有 windowTopPadding，注释写「原生标题栏自动避让，无需手写 padding」
适用范围：目标架构为 setWindowLayoutFullScreen(true) 加根 Navigation expandSafeArea 的 NavDestination 路由页
做法：
- 按全屏窗口加根 Navigation expandSafeArea 的目标架构判断避让，不以「L1/L2 尚未落地」推断原生标题栏会避让
- 写成 NavDestination().hideTitleBar(true)，自绘顶栏外层 .padding({ top: windowTopPadding })，页面底部 .padding({ bottom: windowBottomPadding })
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- hideTitleBar(value: boolean): NavDestinationAttribute：隐藏原生标题栏，默认 false（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.hideTitleBar）
- hideTitleBar(hide: boolean, animated: boolean): NavDestinationAttribute：同族接口：带显隐动画的重载，@since 13（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.hideTitleBar）
- hideTitleBar(value: boolean): NavigationAttribute：同族接口：Navigation 的标题栏隐藏（出处：鸿蒙 SDK 的 ets/component/navigation.d.ts，NavigationAttribute.hideTitleBar）
- setWindowLayoutFullScreen(isLayoutFullScreen: boolean): Promise<void>：窗口全屏布局，目标架构的第一层（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.setWindowLayoutFullScreen）
- hideTitleBar + 自绘顶栏顶部避让 + 底部避让：修复后的路由页写法（出处：卡里修好并验证过）
未核实：原生标题栏在根 Navigation expandSafeArea 下的避让表现，卡里没在设备上单独复核；卡里的行为出自目标 SDK 6.1.1(24)，声明按本机 API 23 核实
