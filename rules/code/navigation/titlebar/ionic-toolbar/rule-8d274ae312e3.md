# 源工具栏无返回键、标题居中或带右侧动作时，用 hideTitleBar(true) 加页内头部

审的是：代码
触发（任一种）：
- 读到：源页面 IonHeader > IonToolbar 里没有 IonBackButton，IonTitle 在 Ionic mode: "ios" 下居中，IonButtons slot="end" 放一组图标 IonButton；写错的样子：目标端用 NavDestination 的 .title(this.builder) 和 .menus(this.builder) 自定义槽拼整条工具栏，保留了源端没有的系统返回键，标题左对齐；运行时标题栏塌缩，标题和动作按钮不可见
适用范围：把源端页面工具栏迁成 Navigation 下 push 的 NavDestination 子页头部时
不适用的情形：源头部和系统标题栏语义一致（有返回键、普通文本标题）时，用系统标题栏 .title('文本')
做法：
- 写成 NavDestination() { Column() { 头部; Scroll() { … }.layoutWeight(1) } }.hideTitleBar(true)；头部用 Stack：标题居中，右侧动作按钮放一个靠右的 Row，顶部按安全区补 padding
- 不用 .title / .menus 的 CustomBuilder 槽拼装源工具栏，也不加源端没有的返回键
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- hideTitleBar(value: boolean): NavDestinationAttribute，默认 false：隐藏系统标题栏（连同返回键）（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.hideTitleBar）
- title(value: string | CustomBuilder | NavDestinationCommonTitle | NavDestinationCustomTitle | Resource, options?: NavigationTitleOptions): NavDestinationAttribute：系统标题栏的标题槽，例外情形下传普通文本（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.title）
- menus(value: Array<NavigationMenuItem> | CustomBuilder): NavDestinationAttribute：系统标题栏右侧菜单槽（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.menus）
- 同一组 builder 放进 title / menus 槽时，引用、() 调用、NavDestinationCustomTitle、闭包、bind 几种传参都不渲染；改成 hideTitleBar(true) + Column 内 Stack 头部后标题居中、动作按钮跳转正常：问题出在挂载位置，不在 builder 内容（出处：卡里修好并验证过）
- hideTitleBar(value: boolean): NavigationAttribute：同族接口：Navigation 自身的标题栏隐藏（出处：鸿蒙 SDK 的 ets/component/navigation.d.ts，NavigationAttribute.hideTitleBar）
针对本应用要查的：
- 头部顶部要补的安全区高度：目标工程里已有的窗口避让处理（EntryAbility 里 window.getWindowAvoidArea 的结果、AppStorage 里存的状态栏高度，或其他自绘头部页的 padding 写法）；沿用同一来源取状态栏高度，单位是 px 的先换成 vp，作为头部的 padding top
未核实：自定义槽不渲染的根因卡里没查明，不能排除应用级布局因素，也不断言是平台缺陷；卡里环境是 API 26，本机声明是 API 23
