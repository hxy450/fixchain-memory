# 代码里镜像资源数值（如工具栏高度常量）时，和资源取同一个已核定的值并注明来源主题

审的是：代码
触发（任一种）：
- 读到：布局里折叠工具栏、头部 marginTop 等也用 ?attr/actionBarSize 参与计算；写错的样子：代码里另写 `private readonly` 的 number 常量（= 56）参与折叠阈值和头部高度运算，和 float 资源各写各的，或照抄兄弟页的常量，没注明来源
适用范围：资源值无法直接参与运算、要在 ArkTS 代码里镜像一份数值时
做法：
- 常量和 float 资源取同一个核定值（Theme.Material3 下 actionBarSize 为 64），注释写明「= ?attr/actionBarSize，来源主题 Theme.Material3」；资源值本身先按主题继承链核定
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- float 资源和两处代码常量都从 56 改成 64 后，折叠阈值和头部高度正确：验证过的取值（出处：卡里修好并验证过）
- Material3 主题的 actionBarSize 解析到 64dp：常量要镜像的值（出处：com.google.android.material:material 包内 res/values/values.xml，m3_comp_top_app_bar_small_container_height（按应用依赖的版本））
来源：1 张卡，1 个应用
