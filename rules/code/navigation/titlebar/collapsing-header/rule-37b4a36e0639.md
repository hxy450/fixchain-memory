# 复用同族页先例时当草稿逐项核对，标 UNC 的近似不当已验证手法照抄

审的是：代码
触发（任一种）：
- 读到：规格要求复用另一页已写好的同款实现（「同 page_… 方案」），先例代码或登记里带 forward-ref-uncertain / `UNC` 编号的近似；写错的样子：新页照抄先例的近似（如背景 .height('100%')、无 blur、图标固定次要色、.align 定位），注释称「沿先例已验证手法」，自检没跑已加载 pitfall 条目的 grep
适用范围：界面实现阶段照同族页面先例写本页相同结构（如折叠头部）时
做法：
- 把先例当待核草稿：逐项对照本页源布局和源码（尺寸、模糊压暗、图标着色、定位、文字阴影、字重、图片缩放和占位、层叠顺序）和已加载的 pitfall 条目，并跑条目里给的自检；标着 forward-ref-uncertain / UNC 的近似不当作已验证手法照抄
