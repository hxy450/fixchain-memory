# 规格锚点列了工具栏着色的实现类时，写前读它取阈值和颜色，不以近似占位推迟

审的是：代码
触发（任一种）：
- 读到：CollapsingToolbarLayout 折叠头部，规格的源码锚点列了负责工具栏图标着色和折叠切换的实现类；写错的样子：目标用固定的次要文字色图标和 opacity = 折叠比例的实底近似工具栏变色，并登记 UNC 占位推迟
适用范围：迁移折叠头部的工具栏着色、标题和遮罩联动行为时
做法：
- 写前读规格锚点里的实现类，取出折叠阈值和展开、折叠两态的图标颜色
- 按读到的阈值切换折叠状态布尔值，并联动遮罩、标题和图标色
针对本应用要查的：
- 折叠阈值和工具栏两态颜色：源工程里规格锚点列出的那个实现类（Java/Kotlin），找它挂在折叠回调上的判断；读出阈值（例：以工具栏高度的倍数表示）和展开态、折叠态各自的图标与标题颜色
