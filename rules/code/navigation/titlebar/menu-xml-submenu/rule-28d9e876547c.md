# 源菜单项带 <menu/> 子菜单时，溢出行画子菜单箭头，从溢出打开的子菜单带标题头

审的是：代码
触发（任一种）：
- 读到：菜单 XML 的 <item> 里内嵌 <menu> 子菜单；写错的样子：子菜单做成普通单选弹层：溢出列表里该项行尾没有 subMenuArrow 那样的子菜单箭头，从溢出项打开时没有 headerTitle 标题头
适用范围：把带子菜单的安卓菜单迁成 ArkUI 自绘溢出弹层时
做法：
- 溢出弹层里带子菜单的项在行尾画子菜单箭头（对应 ListMenuItemView 的 subMenuArrow）
- 由溢出项打开的子菜单顶部带标题头（该菜单项的标题）；只有动作键直接打开时才省略标题头
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- mSubMenuArrowView.setVisibility(hasSubmenu ? View.VISIBLE : View.GONE)：列表菜单行有子菜单时显示箭头（出处：com.android.internal.view.menu.ListMenuItemView#setSubMenuArrowVisible）
- Base.Widget.AppCompat.ListMenuView 的 subMenuArrow = @drawable/abc_ic_arrow_drop_right_black_24dp：AppCompat 菜单行用的子菜单箭头图（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Base.Widget.AppCompat.ListMenuView（按应用依赖的版本））
- tryShow() → showPopup(0, 0, false, false)；tryShow(x, y) → showPopup(x, y, true, true)，末位参数是 showTitle：带偏移打开（从溢出弹层开子菜单）时显示标题，不带偏移打开时不显示（出处：com.android.internal.view.menu.MenuPopupHelper#tryShow）
- 溢出弹层开子菜单走 subPopup.tryShow(horizontalOffset, verticalOffset)；动作键开子菜单走 mActionButtonPopup.show()：从溢出打开带标题头，从动作键直接打开不带（出处：com.android.internal.view.menu.StandardMenuPopup#onSubMenuSelected；android.widget.ActionMenuPresenter#onSubMenuSelected）
- if (mShowTitle && mMenu.getHeaderTitle() != null) 时加标题头：标题头的文字是子菜单的 headerTitle（出处：com.android.internal.view.menu.StandardMenuPopup#tryShow）
针对本应用要查的：
- 子菜单箭头用的图：应用依赖的 androidx.appcompat:appcompat 包内 res/values/values.xml 的 Base.Widget.AppCompat.ListMenuView，以及应用主题对 subMenuArrow 的覆盖；读出 subMenuArrow 指向的 drawable，迁成目标的箭头图标
未核实：AppCompat 的菜单弹层类本机只有编译产物，标题头规则按框架同名类核对
