# 启动路由决策仍等于当前首屏时按失败处理，显示可重试的错误，不再 push 自身

审的是：代码
触发（任一种）：
- 读到：启动 ViewModel 里下一路由的默认值就是首屏自己的路由名；写错的样子：首屏 load().then 后照常 pushPathByName(决策路由)，决策没变时仍是首屏自己，界面停在启动页且没有报错
适用范围：首屏按启动决策跳转、决策有默认值时
做法：
- 路由前判断：决策路由等于当前首屏路由名时按失败处理，显示可重试的错误（如「启动失败，请重试」），不再 pushPathByName
