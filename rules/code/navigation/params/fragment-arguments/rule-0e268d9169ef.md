# 源 Fragment 用 newInstance 参数按实例持有键时，目标组件要有对应入参并在插槽里传入

审的是：代码
触发（任一种）：
- 读到：Fragment.newInstance(参数) 把键写进 Bundle（setArguments），加载时从 getArguments() 取出再按它请求数据；写错的样子：目标组件没有对应入参、用本地默认值；@Builder 插槽已按 ForEach 当前项传参，却调用无参 Builder，参数被丢掉
适用范围：源端按实例参数创建多个 Fragment 页面（如每个城市一页），目标用组件加 Builder 插槽承载时
做法：
- 组件按源端的实例参数声明入参（如 ID、名称、经纬度），Builder 和插槽调用时把当前项的这些值传进去
- 数据加载用组件自己的入参，不改成读全局单例；多页同时存在时只让当前激活页加载
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Builder 改为带 ID、名称、经纬度和是否激活的入参，移除容器侧的统一加载，只让激活页加载：修好后的做法（出处：卡里修好并验证过）
