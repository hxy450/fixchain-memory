# 宿主挂载带 @Param/@Event 的子组件时逐项传入真实数据源，不新增无参 Builder

审的是：代码
触发（任一种）：
- 读到：源 Fragment 由宿主注入参数（如宿主调用 setter 传入当前城市、id、经纬度）；目标子组件声明了 `@Param`（默认 '' 或 0，组件据此进入错误态）和 `@Event` 回调，宿主里有待替换的 `FWD-REF` 占位；写错的样子：替换 `FWD-REF` 时新增一个无参 `@Builder`，里面直接调用子组件、不传任何 `@Param` 和 `@Event`，宿主只调用这个 Builder
适用范围：UI 集成阶段把需要参数的子组件挂到宿主（主 Tab、页面）上时
做法：
- 逐项对照子组件的 @Param / @Event 声明；默认值为空或 0、组件会据此报错的参数，在宿主里找到真实数据源（当前选择的状态和切换事件）
- Builder 透传这些参数和回调：Child({ <每个 @Param>: <宿主数据源>, <每个 @Event>: <宿主回调> })；宿主监听切换事件更新数据源
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- @Param 允许本地初始化；同时有本地初始值和外部传入值时优先用外部值，数据源变化时同步给子组件：不传参时子组件只拿到本地默认值（如 '' 或 0）（出处：arkts-new-param.md，装饰器说明）
- @Event 没有初始化时，自动生成一个空函数作为默认回调：不传回调时子组件里的导航等事件静默失效（出处：arkts-new-event.md，装饰器使用规则说明）
- 按引用传递只在传入一个参数且直接传对象字面量时支持 @Builder 内 UI 刷新，多个参数时不支持：Builder 透传会变化的参数（如切城）时，用一个对象字面量参数，否则切换后子组件不刷新（出处：arkts-builder.md，参数传递规则）
- 宿主读取当前选择并监听切换、Builder 透传参数和回调后，子组件正常请求数据，导航回调可用：验证过的接线（出处：卡里修好并验证过）
针对本应用要查的：
- 每个 @Param 在宿主里的数据源：源端宿主 Activity / Fragment 里给子 Fragment 注入参数的调用（setter、arguments），以及规格状态管理一节写的数据来源；目标宿主里对应的状态变量和事件订阅；逐个参数对上来源，写进 Builder 的透传
