# 目标页参数字段注明由接收端固定时，发起页不用自身状态覆盖，不赋值或写该固定值

审的是：代码
触发（任一种）：
- 读到：目标页已转换的参数类里，字段注释写明对应 Fragment.newInstance(...) 的某个参数、由 Activity 固定传值（如「Activity 固定传 false」），默认值就是这个固定值；写错的样子：发起页构造目标页参数时照源端 putExtra 把自身同名状态赋给这个字段，覆盖了默认的固定值
适用范围：功能接线阶段，为跨页跳转构造目标页路由参数时
做法：
- 先读目标参数类每个字段的注释和默认值；注明由接收端固定的字段，发起端不赋值，或显式写那个固定值
- 已经写了透传赋值的，删掉这一行，保留参数类的默认值，并加注释写明接收端固定传值的依据
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 删除透传赋值、保留参数类默认的固定值后，目标页按接收端的固定值显示：修法（出处：卡里修好并验证过）
未核实：卡里上机所用 SDK 是 API 24（6.1.1）
