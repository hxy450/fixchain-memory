# 路由参数的有效性判定和错误态

agent 会看到什么：产物里页面从路由参数取 id 的默认值和有效性判定（id < 0、id <= 0），以及 build() 里错误态 if 分支和分支外的操作入口

## 规矩

- rule-a3f5e384ba95｜路由参数缺 id 的默认值必须落在有效性判定的无效区间里｜写错：路由参数类里 id 的默认值是 0，有效性判定却只写 `id < 0`，不带 id 的参数对象以默认值通过校验
- rule-325445a9b555｜无效路由错误态下，开始按钮等操作入口也受同一错误判定控制｜写错：build() 里只把内容区放进错误态的 if 分支，悬浮的开始按钮等操作入口写在分支外，错误态下仍显示可点
