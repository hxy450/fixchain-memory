# 无效路由错误态下，开始按钮等操作入口也受同一错误判定控制

审的是：代码
触发（任一种）：
- 写错的样子：build() 里只把内容区放进错误态的 if 分支，悬浮的开始按钮等操作入口写在分支外，错误态下仍显示可点
适用范围：规格验收项要求缺失或无效 id 时进入无效路由错误态、不渲染假内容的页面
做法：
- 把开始按钮等针对内容的操作入口放进与内容区同一个错误态判断里：错误态只渲染错误提示，不渲染这些入口
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 错误态不渲染开始按钮：按此改后通过验收（出处：卡里修好并验证过）
