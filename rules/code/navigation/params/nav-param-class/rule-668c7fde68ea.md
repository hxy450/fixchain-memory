# 路由参数类的字段名照源路由参数名写，不另起名

审的是：代码
触发（任一种）：
- 读到：源端路由带参数，如模板里 [routerLink]=['/路径', 值]、矩阵参数 ;id=，规格写明「;id= 语义保留」；写错的样子：参数类字段改成了别的名字（如 id 写成 userId），发送方赋 param.userId，接收方读的是 obj.id
适用范围：把源端带参数的路由跳转迁成 ArkTS Navigation 的 pushPathByName 加参数类时
做法：
- 参数类字段名按源路由参数名取（;id= 对应字段 id），发送方和接收方的 onReady 读写同一个字段名
针对本应用要查的：
- 这个路由在源端的参数名：源工程里发起跳转的模板（routerLink 数组或 ;key= 矩阵参数）和规格里这条跳转的参数说明；取参数名原样作参数类的字段名；规格写了「语义保留」的照规格
