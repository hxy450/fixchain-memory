# 构造设置能力快照时按源端 bundle.put 清单逐键赋值，声明了没赋值的字段补齐或登记

审的是：代码
触发（任一种）：
- 读到：源端打开设置页前用数十个 bundle.put(...) 把尺寸数组、曝光/ISO/白平衡范围、zoom、视频质量和 fps、多摄标志等交给设置子屏，子屏各自 bundle.get(...) 读；写错的样子：目标端构造快照的方法只给 cameraId 和几个 supports 布尔字段赋值，快照模型里已声明的尺寸数组、数值范围、闪光/对焦值、视频质量和 fps 等字段留着默认值，也没有登记缺口
适用范围：实现阶段，作为快照生产方构造交给设置页的能力快照时
做法：
- 以源端 bundle.put 清单和各设置子屏的 bundle.get 清单为准逐键赋值；手头已经探测到的值直接填
- 交付前把源端 bundle.put 的键名和目标端赋值的字段求差集，结果应为空，或者每一项都登记了缺口
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 快照模型补齐缺的字段、构造方法全量填充后，设置子屏改用整包消费：修好的做法（出处：卡里修好并验证过）
