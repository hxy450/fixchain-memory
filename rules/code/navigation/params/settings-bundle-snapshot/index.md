# 打开设置子屏时经 Bundle 传的能力快照

agent 会看到什么：读到源端打开设置页前用一串 bundle.put…(...) 把尺寸数组、取值范围、能力标志交给设置子屏，子屏各自 bundle.get…(...) 读；产物里构造快照的方法给哪些字段赋了值，子屏读不到某个键时是扩展共享模型、登记占位还是传空数组降级

## 规矩

- rule-47d3afec8cd3｜构造设置能力快照时按源端 bundle.put 清单逐键赋值，声明了没赋值的字段补齐或登记｜读到：源端打开设置页前用数十个 bundle.put(...) 把尺寸数组、曝光/ISO/白平衡范围、zoom、视频质量和 fps、多摄标志等交给设置子屏，子屏各自 bundle.get(...) 读；写错：目标端构造快照的方法只给 cameraId 和几个 supports 布尔字段赋值，快照模型里已声明的尺寸数组、数值范围、闪光/对焦值、视频质量和 fps 等字段留着默认值，也没有登记缺口
- rule-7a2d0761bdcb｜设置子屏发现快照缺源端会传的键时，扩展共享模型或登记占位，不传空数组降级｜读到：源设置子屏用 bundle.get(...) 读一组键（视频质量串、fps、高速 fps、强制 4K、物理摄像头 id 等）；写错：子屏代码注释承认快照「未携带」某些键，随后传空数组 `[]`、条目回退原串或只留 default，并把本页对应的占位（P-S…）标成已解除
