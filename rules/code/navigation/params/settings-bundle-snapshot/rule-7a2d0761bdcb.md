# 设置子屏发现快照缺源端会传的键时，扩展共享模型或登记占位，不传空数组降级

审的是：代码
触发（任一种）：
- 读到：源设置子屏用 bundle.get(...) 读一组键（视频质量串、fps、高速 fps、强制 4K、物理摄像头 id 等）；写错的样子：子屏代码注释承认快照「未携带」某些键，随后传空数组 `[]`、条目回退原串或只留 default，并把本页对应的占位（P-S…）标成已解除
适用范围：实现阶段，作为快照消费方的设置子屏读取宿主传来的能力快照时
做法：
- 扩展共享的快照模型，把缺的键加上并交给生产方赋值；或者给生产方登记 FWD-REF
- 缺口补上之前，本页的占位不标成已解除
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 快照模型补上视频质量串、fps、物理摄像头 id 等字段后，视频设置页按整包消费：修好的做法（出处：卡里修好并验证过）
