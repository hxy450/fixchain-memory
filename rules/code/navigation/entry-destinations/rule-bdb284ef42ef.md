# 替换或重排已有工具栏按钮时，按安卓监听代码的按钮→目标表逐个改 onClick，不沿用旧槽位回调

审的是：代码
触发（任一种）：
- 读到：安卓 Activity 给顶栏每个按钮分别 setOnClickListener，目标各不相同（同一面板的不同 tab、另一个 Activity、评论列表）；行为说明里给出了按钮→目标的绑定表；写错的样子：目标工具栏里只换了 SymbolGlyph / Image / Text 的显示内容，.onClick(...) 还是被替换占位槽位原来的回调；两个不同按钮跳同一个 router.pushUrl 目标，或某个 sheet 分支已没有按钮能打开
适用范围：目标页面已有占位按钮（各带点击回调），其数量、顺序和安卓布局不一致，要按安卓顺序换图标、补按钮或改文字时
做法：
- 先按安卓 Activity 的监听代码列出「按钮→点击目标」表（面板写到 tab 序号，跳转写到目标页），再给每个按钮按表写 .onClick(() => …)；换图标或文字时一并改回调
- 只改一个按钮的动作时，查清它原来承担的动作在安卓里属于哪个按钮，把那个动作同步迁到该按钮上
- 交付前按顺序列出工具栏 builder 里每个按钮的资源名和 onClick 目标，与安卓绑定表逐行对照；两个按钮同目标或某个分支无入口，回安卓源码复核
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onClick(event: (event: ClickEvent) => void): T：每个按钮各自的点击回调，替换显示内容不会自动换掉它（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onClick）
- 按安卓绑定表逐个改 onClick 后，各按钮目标和安卓一致，原来没有入口的面板 tab 重新可达：修好后的做法（出处：卡里修好并验证过）
针对本应用要查的：
- 每个按钮的点击目标：源工程里这个页面的 Activity 源文件，按顶栏各按钮的 setOnClickListener（或 onClick 分支里的 view id）找；监听里调用的方法和参数就是目标：打开面板的记下 tab 序号，startActivity 的记下目标 Activity
