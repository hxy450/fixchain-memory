# 源页面里每个 setOnClickListener 在目标都有对应 onClick，含非 initView 函数里的

审的是：代码
触发（任一种）：
- 读到：源 Activity / Fragment 的 lazyLoadData、initListener 等非 initView 函数里有 setOnClickListener，或 currentItem / setCurrentItem 一类交互调用；写错的样子：目标对应的组件没有 .onClick，交互只按布局 XML 和页面回调转写
适用范围：把 Activity / Fragment 页面转写成 ArkUI 页面时的交互接线
做法：
- 写页面前在源文件全文搜 setOnClickListener、currentItem、setCurrentItem 等交互调用（不只看 initView），逐条映射到目标组件的 .onClick(() => { … })
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onClick(event: (event: ClickEvent) => void): T：组件点击事件（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onClick）
