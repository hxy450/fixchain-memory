# 源列表首项是调色盘、相册、图库入口时，接到对应页面并把结果写进编辑配置

审的是：代码
触发（任一种）：
- 读到：源 Fragment 的 onItemClick 里第 0 项（或特殊项）弹调色盘对话框、打开相册或图库，其余项把选中的 bean 写入编辑配置；写错的样子：目标列表项 onClick 里只切换选中标记，首项不打开调色盘或图库，选中结果也没写进编辑会话的配置
适用范围：迁移带动作入口项的选项列表（调色盘、相册、图库）时
做法：
- 首项或特殊项按源接到工程里已有的对应页面（调色盘对话框、图库页），取回结果后和普通项一样写入编辑会话配置，随保存一起持久化、重进时恢复
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 调色盘项经调色盘对话框取色、图库项接图库页，选择经编辑配置保存和恢复：修好后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 源端特殊项接到哪个页面、结果写进哪项配置：源 Fragment 的 onItemClick（或适配器的点击回调）里按 position 分支的代码，以及保存配置的工具类里对应的字段；找出每个特殊项打开的对话框或页面和回填的字段，在目标端接到同等页面并写同一字段
来源：1 张卡，1 个应用
