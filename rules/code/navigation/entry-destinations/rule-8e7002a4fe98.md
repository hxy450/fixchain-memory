# onClick 回调体不能只有注释；实现不了的写 TODO: 占位并登记，或报未完成

审的是：代码
触发（任一种）：
- 写错的样子：`.onClick(() => { // Navigate … })` 这类回调体只有注释或为空，注释里也没有 `TODO:`，占位登记里没有它
适用范围：目标页面里所有点击、跳转类回调
做法：
- 回调体里写实际调用（跳转就写 router.pushUrl({ url, params })），不写只有注释的回调
- 暂时实现不了的，按流程写成带 `TODO:` 的占位并登记到占位登记，或在报告里如实写未完成
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onClick(event: (event: ClickEvent) => void): T：组件的点击回调；回调体为空或只有注释时点击没有任何效果（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onClick）
- 验证阶段只搜 `TODO:` 并核对占位登记，只有 // 注释、不含 `TODO:` 的回调体查不出来：只有注释的回调会绕过检查，被当成已完成（出处：卡里修好并验证过）
