# 源 Activity 用透明主题时，NavDestination 设 DIALOG 模式和透明背景，遮罩只作页内一层

审的是：代码
触发（任一种）：
- 读到：源 Activity 的主题里 `android:windowIsTranslucent` 为 true、`android:windowBackground` 为 `@android:color/transparent`，并有 `android:backgroundDimEnabled`；写错的样子：目标 `NavDestination` 没设 `.mode(...)`（默认 STANDARD）、页背景不透明，只在页内铺一层半透明 `Stack` 遮罩，下层页面透不出来
适用范围：源 Activity（含它的主题链）声明窗口透明、压暗下层的半透明页，迁成 Navigation 下的 NavDestination 时
做法：
- 写成 `NavDestination() { … }.mode(NavDestinationMode.DIALOG).backgroundColor(Color.Transparent)`，遮罩只作页内最底下的一层
- 遮罩颜色取源主题的 backgroundDimAmount：黑色、透明度等于该值（如 0.32 写 `#52000000`）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- mode(value: NavDestinationMode): NavDestinationAttribute：设置 NavDestination 的模式，不支持动态修改（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.mode）
- NavDestinationMode.STANDARD = 0（默认）；NavDestinationMode.DIALOG = 1：DIALOG 模式下页面默认透明，入栈出栈不影响下层页面的生命周期（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationMode）
- Color.Transparent：透明色（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，Color.Transparent）
- 平台 Theme.Material 的 backgroundDimAmount 是 0.6：应用主题直接继承平台 Material 主题时的压暗程度（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material 的 backgroundDimAmount（按应用的 compileSdk 取对应平台））
- Material3 主题的 android:backgroundDimAmount = @dimen/m3_comp_scrim_container_opacity = 0.32：应用主题是 Material3 一族时的压暗程度（出处：com.google.android.material:material 包内 res/values/values.xml，m3_comp_scrim_container_opacity（按应用依赖的版本））
- 改为 DIALOG 模式、透明背景，遮罩 #52000000（Material3 dim 0.32）后下层页面可见、仅被压暗：修好后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 源主题的 backgroundDimAmount：源工程 res/values 下 styles.xml、themes.xml 里该 Activity 的主题，顺 parent 链找 android:backgroundDimAmount；没写时看链上的库主题或平台主题；读出 0–1 的透明度，遮罩色写成黑色、alpha = round(值 × 255)；例：继承 Material3 主题时是 0.32，即 #52000000
