# 用条件渲染或下标切 tab 时，在 @Entry 的 onBackPress 里实现非起始 tab 返回回起始 tab

审的是：代码
触发（任一种）：
- 读到：底部导航切 tab 用 popUpTo(startDestination) { saveState = true }，源注释说在其他底部 tab 按返回回到起始目的地；写错的样子：@Entry 页没有 onBackPress，tab 切换注释写「popUpTo saveState 的状态保持由条件渲染承接」，非起始 tab 按系统返回直接退出
适用范围：目标端用单 Navigation 加条件渲染或下标切 tab、没有 tab 返回栈时
做法：
- @Entry 页写 onBackPress(): boolean { if (navPathStack.size() === 0 && 当前 tab !== 起始 tab) { 切到起始 tab; return true } return false }，tab 状态不重置
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onBackPress?(): void | boolean：只对 @Entry 组件生效；返回 true 表示页面自己处理返回，false 或不返回走默认逻辑（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CustomComponent.onBackPress）
- size(): number：NavPathStack 的栈深，为 0 说明没有压着详情页（出处：鸿蒙 SDK 的 ets/component/navigation.d.ts，NavPathStack.size）
- 详情栈空且不在起始 tab 时切回起始 tab 并消费返回，@Entry onBackPress 调用它：修复后的写法（出处：卡里修好并验证过）
