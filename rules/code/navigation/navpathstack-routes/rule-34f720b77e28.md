# 移交项写「同款」的其他 onPop 消费点时，改判型要一并 grep 修改

审的是：代码
触发（任一种）：
- 读到：brief 或移交项列出某个 pushPathByName(..., onPop) 消费点的 instanceof 判型，并写「…同款」指向别的调用点；写错的样子：只改了一处 onPop 里的 instanceof 类型，同款的其他 pushPathByName(..., onPop) 调用点仍判旧类型，和生产端 pop(result) 的类型对不上
适用范围：收尾对账时调整回传类型，同一目标页有多个打开入口时
做法：
- 对每个 pushPathByName(..., onPop) 调用，列出目标页全部成功出栈点，确认都带 result，且类型与 onPop 中 instanceof 判的一致
- brief 里写「同款」的其他调用点一并 grep 出来同样修改
