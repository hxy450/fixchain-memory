# 通道内确需取密钥时，门的基址与请求 URL 或调用方握手基址一致，不依赖可变的默认基址

审的是：代码
触发（任一种）：
- 写错的样子：通道内的取密钥门不传基址、取默认的 `baseUrl`，默认基址会被切服逻辑改写，与调用方握手用的基址不同；判断基址相同只看了静态初值
适用范围：会话密钥按基址缓存、默认基址在运行期可变的网络层里给通道加取密钥门时
做法：
- 门的基址显式传入调用方握手用的那个基址，或由请求 URL 推导，不用默认基址
- 判断两个基址是否相同时，查遍所有赋值点（切服、登录后覆盖等），不只看常量的静态初值
针对本应用要查的：
- 默认基址在运行期被改写的位置：目标工程网络配置里基址常量的所有赋值点：切服、选区域、登录成功后的回调；有任何一处会改写默认基址，就不能把它当作和固定基址恒等
