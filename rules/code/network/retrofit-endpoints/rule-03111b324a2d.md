# 目标调用的接口路径只取自安卓 Service 注解或已有服务，不按语义拼统一的 save

审的是：代码
触发（任一种）：
- 读到：安卓 Service 用 Retrofit 注解分接口声明，如 @POST(".../add")、@POST(".../update")、@POST(".../delete")、@GET(".../page")，实体字段含省市区、默认开关等；写错的样子：目标请求调用里的路径字符串（如按语义拼的 ".../save"）在安卓 Service 的 @POST / @GET 注解里找不到，请求体字段比安卓实体少
适用范围：增量功能实现阶段，为页面决定调用哪些后端接口和请求体字段时
做法：
- 写页面前打开规格点名的安卓 Service 和实体类，列出每页要用的接口（路径加方法）和实体字段
- 目标 Service 每个安卓接口一个方法，路径、方法和字段照抄；新增和修改分别调 add、update 这类各自的接口
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 返修按安卓 Service 补齐 7 个分接口（增、改、删、分页、列表、详情、设默认），表单补齐省市区和默认开关：返修后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 每个接口的路径、方法和字段：源工程里 Retrofit 接口文件（带 @GET、@POST、@Body、@Query 注解的 interface）和对应的实体 data class；注解里的字符串就是路径，注解名就是方法；实体的属性名就是请求体或响应字段
