# 移植错误数据类时逐字段照搬：message 取原因短语，code: message 只给 description

审的是：代码
触发（任一种）：
- 读到：Kotlin 错误类构造 HttpError(code, message = response.message)，description 默认值 "$code: $message"；写错的样子：目标错误类的 message 和 description 都写成 `code + ': ' + message`
适用范围：把源端带默认值的错误数据类（如 HTTP 错误）移植成目标错误类时
做法：
- 逐字段对照源端构造和默认值：message = 原因短语，description 默认 `${code}: ${message}`；不把 description 的拼接格式同时写进 message
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 带原因短语 'Not Found' 的 404 → message = 'Not Found'，description = '404: Not Found'：写完用来自查的最小样例；修好后单测通过（出处：卡里修好并验证过）
