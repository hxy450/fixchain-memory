# 实现 token 失效判定时，码值照源端拦截器分支写全，不照规格举例只判一个码

审的是：代码
触发（任一种）：
- 读到：规格写的失效码在它指定的数据源里查不到，源端有处理错误码的 okhttp3.Interceptor；写错的样子：目标端自写的 HTTP 客户端只按 HTTP 401（`=== 401`）或单个业务码判失效踢登，源端拦截器里其余踢登码落到普通业务错误分支
适用范围：目标端自写 HTTP 客户端统一判定鉴权失效、替代源端响应拦截器时
做法：
- 在规格指定的位置查不到具体码值时，回源码读错误码枚举定义和使用它的响应拦截器，再写判定
- 目标的错误码枚举补全拦截器分支里的每个码，判定里逐个命中：token 失效类发踢登，异地登录类按异地登录踢登，动作和源端分支一一对应
针对本应用要查的：
- 踢登码集合和各自动作：源工程里实现 okhttp3.Interceptor 的响应拦截器类的 intercept 方法和它引用的错误码枚举；读出每个分支的码值和动作，照着写目标的判定分支
