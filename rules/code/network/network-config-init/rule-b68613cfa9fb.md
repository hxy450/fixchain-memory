# 装配根不用空字符串构造网络配置，接入构建期生成的配置，缺失就显式失败

审的是：代码
触发（任一种）：
- 读到：源端 gradle / BuildConfig 已有服务端地址和签名材料，决策要求私有注入；写错的样子：装配根写 new …Config('', …, '') 这类以空 baseUrl、空签名密钥构造客户端、不传解码器，靠网络层的空配置守卫返回失败
适用范围：装配根（应用启动时组装网络客户端的地方）注入网络配置时
做法：
- 装配前先查配置来源：源端已有地址与材料、决策要求私有注入时，用构建期生成的配置模块里的常量构造客户端并传入解码器；缺键让构建或启动显式失败并登记阻断项，不用空字符串占位
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 装配根改用构建期生成的地址、签名密钥常量和 AES 解码器构造配置后，真机登录不再报网络配置不可用：修好后的写法（出处：卡里修好并验证过）
