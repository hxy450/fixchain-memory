# OkHttp 的 maxStale 迁成 max-stale，不用 stale-while-revalidate 代替

审的是：代码
触发（任一种）：
- 读到：OkHttp 的 CacheControl.Builder().maxAge(7, DAYS).maxStale(30, DAYS) 控制图片缓存；规格写「7 天 max-age / 30 天 max-stale」；写错的样子：目标缓存头写成 `public, max-age=604800, stale-while-revalidate=2592000`，max-stale 被换成别的指令
适用范围：把 OkHttp CacheControl 指令迁成目标端请求缓存头时
做法：
- 逐项保持指令名：maxAge → max-age，maxStale → max-stale，值换成秒，例如 'max-age=604800, max-stale=2592000'（7 天、30 天）；不加源端没有的指令
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- max-age=604800, max-stale=2592000：maxAge(7, DAYS)、maxStale(30, DAYS) 换成秒后的请求缓存头，修复后相关用例通过（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
