# request.agent 下载在 create 和注册回调之后要调 task.start()

审的是：代码
触发（任一种）：
- 读到：源端用 OkHttp 或 getInputStream 下载到缓存；参考模板按 request.agent.create → on('completed') → await task.start() 落码；写错的样子：代码里有 request.agent.create(...) 和 task.on('completed' / 'failed', ...)，却没有 task.start()；后续保存、分享、复制一直等不到完成
适用范围：用 @ohos.request 的 request.agent 把文件下载到缓存等目录时
做法：
- 按完整生命周期写：const task = await request.agent.create(context, config)；task.on('response', r => 校验 r.statusCode 在 2xx)；task.on('completed' / 'failed', …)；await task.start()；结束后 request.agent.remove(task.tid) 清理
- 参考模板只截到一半时先读全或加载专项下载 skill，写完核对代码里确有 start()
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- function create(context: BaseContext, config: Config): Promise<Task>：创建上传或下载任务并入队；不调 start() 时卡里观察到任务一直不完成（出处：鸿蒙 SDK 的 ets/api/@ohos.request.d.ts，request.agent.create）
- start(): Promise<void>：启动刚创建的任务，或已停止、失败的下载任务；需要 ohos.permission.INTERNET（出处：鸿蒙 SDK 的 ets/api/@ohos.request.d.ts，request.agent.Task.start）
- on(event: 'response', callback: Callback<HttpResponse>): void：收到 HTTP 响应头时回调，HttpResponse.statusCode 是 HTTP 状态码（出处：鸿蒙 SDK 的 ets/api/@ohos.request.d.ts，request.agent.Task.on('response')、HttpResponse.statusCode）
- on(event: 'completed', callback: (progress: Progress) => void): void：任务完成回调；'failed' 同形（出处：鸿蒙 SDK 的 ets/api/@ohos.request.d.ts，request.agent.Task.on('completed')）
- function remove(id: string): Promise<void>：按任务 id（Task.tid）移除任务（出处：鸿蒙 SDK 的 ets/api/@ohos.request.d.ts，request.agent.remove）
- create 后 task.start()、监听 response 校验 2xx、remove 清理：修好的写法（出处：卡里修好并验证过）
