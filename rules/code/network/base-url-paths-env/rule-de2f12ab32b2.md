# 环境默认值照源端环境工具的分支映射到目标构建模式，各处引用同一个常量

审的是：代码
触发（任一种）：
- 读到：源端 getCurrentEnv 一类桥接返回环境工具的 getEnv()，环境工具按 BuildConfig.BUILD_TYPE 分支给默认值；写错的样子：桥接、偏好封装、网络配置各写一份默认值 `'prod'`，环境词表 dev/staging/prod 取自脚手架 TODO 注释
适用范围：网络配置、MethodChannel 一类桥接、偏好封装里写当前环境和它的默认值时
做法：
- 打开源端环境工具，环境枚举和各构建类型下的默认值照它写，按构建类型映射到目标的构建模式；不用脚手架注释里的示例值
- 默认环境定义成一处常量，网络配置、桥接、偏好封装都引用它
针对本应用要查的：
- 环境枚举值和各构建类型下的默认环境：源端桥接里 getEnv() 指向的环境工具类，以及 app 模块 Gradle 构建脚本里的 buildTypes；读出环境工具的全部取值和按构建类型的默认分支（例：某些应用 debug 构建默认测试环境、其余默认正式环境）
