# 规格和清单都没给 host 时，代码回源码查地址常量，查不到留待核标记，不写推测域名

审的是：代码
触发（任一种）：
- 读到：规格和 API 清单只有 BASE_URL 这类键名、没有 host；派工要求地址从清单或源码提取；写错的样子：网络配置里写出源工程里搜不到的推测域名（https://api.…、dev-api.…、staging-api.…）作为 BASE_URL，没有待核标记，回报里也没列
适用范围：基础设施实现阶段写网络配置里的服务地址和环境分支时
做法：
- 按派工回源码查地址常量和取址方法，把查到的 host 原样写进配置，环境分支照源端取址逻辑写
- 仍查不到就留显式待核标记（TODO 加要查的源文件），并在回报里列出，不写推测域名
针对本应用要查的：
- 各环境的 host 常量：源工程里定义服务地址的常量类和引用它的取址方法（按 BuildConfig.BUILD_TYPE 或环境工具选址）；读出每个常量的字符串值和它对应的环境，原样写进目标配置
