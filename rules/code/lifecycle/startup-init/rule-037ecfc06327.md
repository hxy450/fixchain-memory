# 启动入口接线时，带缺失即抛错守卫的 static configure/init 逐一在 onCreate 调用

审的是：代码
触发（任一种）：
- 读到：基础模块里有 static configure( 或 static init(，取配置时未配置就抛「configuration is missing」一类错误；写错的样子：EntryAbility.onCreate 或 bootstrap 里没有调用这些 configure / init，业务请求在生成 URL 前就抛配置缺失
适用范围：启动入口（EntryAbility 或 bootstrap）接线、宣布启动链闭合前
做法：
- 检索「static configure(」「static init(」「configuration is missing」，列出全部带缺失即抛错守卫的入口，逐一确认已在 onCreate 或 bootstrap 里调用
- 在 onCreate 开头调用 configure，承接安卓 BuildConfig 的值：环境由 BuildProfile.DEBUG 选 debug / release，版本取 BuildProfile.VERSION_NAME，设备型号取 deviceInfo.productModel，敏感字段保持空值并 fail-fast
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- deviceInfo.productModel: string：设备的产品型号（出处：鸿蒙 SDK 的 ets/api/@ohos.deviceInfo.d.ts，deviceInfo.productModel）
- 在 onCreate 开头补上 configure 调用后，请求不再抛配置缺失：修好后的行为（出处：卡里修好并验证过）
