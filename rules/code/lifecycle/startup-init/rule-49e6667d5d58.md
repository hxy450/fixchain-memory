# 迁启动链时打开闪屏每个路由目标页的初始化入口，已登录冷启动的请求逐项落到 ViewModel

审的是：代码
触发（任一种）：
- 读到：闪屏 Activity 按登录态 navigation() / startActivity(Intent) 进入已登录目标 Activity，目标 Activity 的 onCreate 初始化里发刷新 token、拉配置、检查版本等请求；写错的样子：目标端启动 ViewModel 的路由方法在已登录分支直接返回主页目标，没有发起这些请求（例如没有先刷新 token）
适用范围：迁移启动链路、目标端用启动 ViewModel 承载闪屏路由时
做法：
- 闪屏路由的每个目标页都打开，读它的初始化入口，列出已登录冷启动的请求清单
- 清单逐项落到对应 ViewModel 或标为未迁；刷新 token 放在已登录分支里，先 await 刷新完成再进主页
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 已登录分支先 await 刷新 token，再返回主页路由：补上源端目标页初始化里的启动刷新（出处：卡里修好并验证过）
针对本应用要查的：
- 已登录冷启动要发的初始化请求和先后：源工程闪屏 Activity 路由分支指向的每个目标 Activity：onCreate 和它调用的初始化方法，以及对应 ViewModel 里的请求方法；逐个记下请求、是否依赖登录态、是否要等刷新 token 完成后再发
