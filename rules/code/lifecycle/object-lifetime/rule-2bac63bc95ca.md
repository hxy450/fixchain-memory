# 服务持有 Activity 实例会话态时，页面 new 一个服务实例，不用 getInstance() 单例

审的是：代码
触发（任一种）：
- 读到：源 Activity 的实例字段存会话数据，服务逻辑直接读写这些字段；写错的样子：页面从服务类的 getInstance() 取单例，把 Activity 字段搬进单例，靠 attach / reset 复位近似实例重建
适用范围：目标端由页面把会话态交给共享服务执行时
做法：
- 页面持有自己的服务实例：private service = new <服务类>()，在页面初始化时复位；只有源端本就是静态全局的状态才放进单例
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 页面改为 new 服务实例并在 attach 时复位：修好的写法（出处：卡里修好并验证过）
未核实：多个页面实例同时存在的实际路由卡里没有复现
来源：1 张卡，1 个应用
