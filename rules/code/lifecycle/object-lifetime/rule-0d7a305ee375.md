# 多个源对象并进静态引擎时，复位函数的每条赋值都要对得上源端每局路径里的赋值

审的是：代码
触发（任一种）：
- 读到：源端类的 `static` 字段、宿主 View / Activity 的实例字段，在每局重开函数和其中 new 出的对象构造里都没有赋值；写错的样子：目标模块级静态引擎的每局复位函数里给这类字段重新赋初值（把计数设回常量、把 boolean 标记设回 `false`），源端每局路径里找不到对应赋值
适用范围：实现阶段把多个源对象（类静态、宿主实例、每局新建对象）的字段合并到一个模块级静态引擎、用一个复位函数模拟每局重开时
做法：
- 复位函数里的每条赋值都要能指到源端每局路径中的一条赋值（重开函数体，或其中 new 出对象的构造和字段初始化器）；指不到的按源端删掉，或登记待批决策
- 规格要求的复位与源码不符时，不照写，在交回报告（handback）里报规格缺口
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 删掉源端没有的两处复位（类静态计数、宿主实例的 boolean 标记）后，跨局的残留计数和在飞对象与源端一致：多出的复位会改变跨局可观察行为（出处：卡里修好并验证过）
