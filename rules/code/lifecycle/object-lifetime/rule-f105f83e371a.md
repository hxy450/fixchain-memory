# 源端只注册不注销的监听，迁移时先查目标壳层的真实存活期，不机械补「离页注销」

审的是：代码
触发（任一种）：
- 读到：源端 Fragment 只注册监听，没有对应的注销调用（onDestroyView、onDestroy 里都没有）；写错的样子：目标页面在 aboutToDisappear 里补了源端没有的注销，而主壳用 if (currentTab === n) 条件渲染这个页面，切 Tab 就销毁
适用范围：把安卓 Fragment / Activity 里的监听迁成目标页面级订阅时
做法：
- 写页面级订阅前先查目标壳层：Tabs 是否用 if/else 条件渲染、页面是否随 NavDestination 出栈销毁；页面生命周期比源端监听短时，不把订阅挂在页面上
- 源端只注册、没有注销时，不在 aboutToDisappear 里机械补注销
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- if 分支变化时先移除此前构建的所有子组件，再执行新分支的构造函数：条件渲染切走的页面会被销毁、触发 aboutToDisappear（出处：arkts-rendering-control-ifelse.md，更新机制）
针对本应用要查的：
- 目标壳层怎么承载这个页面：目标工程入口页或主壳组件的 build 里装载该页面的那段；看是 if/else 条件渲染、Tabs 的 TabContent 还是 NavDestination；条件渲染和出栈都会销毁页面
