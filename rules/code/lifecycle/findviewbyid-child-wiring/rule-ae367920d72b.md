# 只执行一次的接线点不用 ?. 静默跳过，取不到实例时由登记回调补接或打错误日志

审的是：代码
触发（任一种）：
- 读到：源端 onCreate 里 findViewById 后只接线一次；写错的样子：一次性的初始化（onReady、init）里用可选链 ?. 调子组件实例的 setter，实例为 null 时静默跳过、之后再无接线点
适用范围：目标代码里只执行一次的接线点（首次设置状态、注册监听）
做法：
- 取不到子组件实例时，要么由登记回调补接，要么用 hilog.error 打错误日志，不用 ?. 静默跳过
- 可选链只留给登记后会反复触发的调用（重绘、度量）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- function error(domain: number, tag: string, format: string, ...args: any[]): void：输出 error 级日志（出处：鸿蒙 SDK 的 ets/api/@ohos.hilog.d.ts，hilog.error）
来源：1 张卡，1 个应用
