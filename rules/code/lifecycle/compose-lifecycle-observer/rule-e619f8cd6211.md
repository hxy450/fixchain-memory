# Lifecycle ON_PAUSE/ON_RESUME 暂停恢复，目标同时接应用前后台和页面显隐两类回调

审的是：代码
触发（任一种）：
- 读到：源端观察 Lifecycle.Event.ON_PAUSE / ON_RESUME 暂停、恢复播放；写错的样子：只接了 NavDestination 的 onHidden / onShown（或 onPageHide / onPageShow），应用切后台时不暂停
适用范围：源端按 Activity / Fragment 生命周期暂停恢复播放或其他前台任务的迁移
做法：
- 同时接两类：ApplicationContext 的 on('applicationStateChange', { onApplicationForeground, onApplicationBackground }) 管应用前后台；NavDestination 的 onHidden / onShown 或 uiObserver.on('navDestinationSwitch', …) 管页面被覆盖
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- on(type: 'applicationStateChange', callback: ApplicationStateChangeCallback): void（ApplicationContext，声明里 @since 18）：注册应用前后台切换回调（出处：鸿蒙 SDK 的 ets/api/application/ApplicationContext.d.ts，ApplicationContext.on('applicationStateChange')）
- onApplicationForeground(): void；onApplicationBackground(): void：ApplicationStateChangeCallback 的两个回调（出处：鸿蒙 SDK 的 ets/api/@ohos.app.ability.ApplicationStateChangeCallback.d.ts，ApplicationStateChangeCallback）
- onShown(callback: Callback<VisibilityChangeReason>): NavDestinationAttribute；onHidden(callback: Callback<VisibilityChangeReason>): NavDestinationAttribute：页面显示、隐藏回调（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.onShown / onHidden）
- on(type: 'navDestinationSwitch', context: UIAbilityContext | UIContext, callback: Callback<NavDestinationSwitchInfo>): void：监听 NavDestination 切换（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.observer.d.ts，uiObserver.on('navDestinationSwitch')）
未核实：NavDestination onHidden 不覆盖应用切后台依据返修报告的判定，卡里没有真机对照记录
