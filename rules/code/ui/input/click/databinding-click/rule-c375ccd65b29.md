# 页面转换前核对布局 <data> 变量类型与规格里的页面类全名，不一致就回报规格缺陷

审的是：代码
触发（任一种）：
- 读到：规格指向的布局 XML 里 <data><variable type="…"> 的类全名（包名）和规格里的 Activity/Fragment 全名不同，或源页面类用的 .databinding 绑定类不在这个布局所在的模块；写错的样子：目标页面照另一个模块的布局写出源页面没有的入口（多出的点击行、卡片），和源页面类实际绑定的布局里的 android:onClick 点击对不上
适用范围：页面转换阶段按分页规格选定源布局、写目标页面之前
做法：
- 写前比对三处：布局 <data> 里 <variable> 的 type 包名、规格里的页面类全名、源页面类 import 的绑定类包名；三者应属同一个模块
- 不一致时在报告里回报规格缺陷，并改按页面类所在模块的布局核对入口，不照规格指向的布局实现
针对本应用要查的：
- 页面类实际绑定的布局里有哪些入口：页面类所在模块 src/main/res/layout 下的同名布局 XML，按 android:onClick 或 @{…} 点击绑定搜；列出入口清单，与目标页面的可点击行逐项对照
