# setOnClickListener 只绑行内子 TextView 时，只给对应 Text 加 onClick

审的是：代码
触发（任一种）：
- 读到：Java/Kotlin 里 setOnClickListener 只绑在行内某个子 TextView（如右侧值文本）上；同页别的行才把整行 layout 设为可点；写错的样子：对应的 Row 整行挂了 .onClick(...)，不是只给那个 Text 挂；或者注释写着某个子视图可点，.onClick 却挂在 Row 上
适用范围：把源端的点击绑定逐行迁成 ArkUI 组件的 onClick，或重写已有行块时
做法：
- 只绑定行内子 TextView 时，只给对应的 Text 加 .onClick(...)；整行 layout 被绑定时才给 Row 加
- 重写行块时核对 .onClick 挂的位置和注释里说的可点视图一致
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- setOnClickListener(@Nullable OnClickListener l)：给这个 View 注册点击回调，不可点的 View 会变成可点：点击区就是被调用的那个 View，不会扩到父布局（出处：android.view.View#setOnClickListener）
- onClick(event: (event: ClickEvent) => void): T：ArkUI 组件的点击事件，挂在哪个组件上就只有它响应（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onClick）
- 把整行 Row 上的 onClick 移到右侧值 Text：修好的做法（出处：卡里修好并验证过）
