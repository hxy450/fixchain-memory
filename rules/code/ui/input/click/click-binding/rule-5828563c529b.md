# 源端 setOnClickListener 回调体为空或调用被注释时，目标不接 onClick，按死按钮迁

审的是：代码
触发（任一种）：
- 读到：源码 setOnClickListener(…) 的 onClick 回调体为空，或里面唯一的调用被 // 注释掉；写错的样子：目标在对应组件上接了 .onClick(() => …) 并做成可用功能（弹菜单、选图等），注释自述「源码已注释为死码——按集成点接线」
适用范围：项目要求 1:1 忠实复刻、源码缺陷一并迁移时，迁移或重写带点击接线的组件
做法：
- 核点击行为时打开监听回调体全文；回调为空或调用被注释就判定为点击无响应，不凭注册行、XML 的 android:clickable 或被调方法存在推断可点击
- 判定为死按钮的，目标删掉对应的 .onClick 及只为它服务的处理函数和 import，注释写明「死按钮」
- 重写含交互修饰的组件结构时，对随行搬运的 onClick 等接线逐个找源码依据；和文件注释、审计结论里「源码死码」的说法冲突时，先回读源码再决定保留或摘除
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- View#setOnClickListener：注册点击回调，view 原来不可点时会被设成 clickable：注册行只说明 view 变成可点、会吃掉点击，不说明点击有动作（出处：android.view.View#setOnClickListener）
