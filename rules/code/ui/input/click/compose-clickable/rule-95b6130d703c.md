# 带 Modifier.clickable 的 Card，卡片级 onClick 放根容器，和内部关闭按钮分开

审的是：代码
触发（任一种）：
- 读到：Compose 的 Card 带 Modifier.clickable(onClick = onClick)（合成的 view.xml 里该节点 clickable="true"），卡片内另有关闭/忽略按钮；写错的样子：ArkUI 卡片根 Row/Column 上没有 .onClick，只有内部关闭图标写了 onClick
适用范围：把 Compose 中整张可点的 Card 转成 ArkUI 容器时
做法：
- 卡片级点击写在 ArkUI 根容器上：Row() { … }.onClick(() => { 打开对应对话框或页面 })；内部关闭/忽略按钮各写各的 .onClick，内部按钮不能替代卡片本身的点击入口
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onClick(event: (event: ClickEvent) => void): T：组件的点击事件，挂在根容器上即整卡可点（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onClick）
来源：1 张卡，1 个应用
