# 复用先例页接线时以本页源码为准，不照搬先例里的确认弹窗和门控

审的是：代码
触发（任一种）：
- 读到：本页源码的批量动作监听里没有弹 AlertDialog 确认、直接执行，懒加载页的选中由基类标志门控；写错的样子：照先例页拷入按数量阈值的 showAlertDialog 确认；懒加载追加选中只用多选态判断，与注释和源码门控相反；剩余页循环被省掉
适用范围：页面转换或接线时拿另一页的实现当先例复用多选、批量动作逻辑
做法：
- 以本页源码逐条对照先例：源码没有的确认弹窗不加；源码有的剩余页循环要移植；懒加载追加选中按源端同一个标志门控，注释与代码一致
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 去掉确认弹窗、加上懒加载标志门控、移植剩余页循环后与源端一致：按此改后保留（出处：卡里修好并验证过）
