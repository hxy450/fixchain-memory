# 页面有按键分发时，根容器设 focusable、defaultFocus 并接 onKeyPreIme

审的是：代码
触发（任一种）：
- 读到：源端 Activity 覆写 onKeyDown 分发硬件键；写错的样子：目标有按键分发方法，但页面根容器没有 `.focusable(true)`、`.defaultFocus(true)`，也没有 .onKeyPreIme(...) / .onKeyEvent(...)，分发方法在页面上没有入口
适用范围：ArkUI 页面要接收硬件键、键盘或遥控按键时
做法：
- 页面根容器写 .focusable(true).defaultFocus(true).onKeyPreIme((event: KeyEvent) => …)，回调里按 keyCode 交给分发方法，只对已处理的键返回 true，其余返回 false
- 页面隐藏或销毁时（onHidden / aboutToDisappear）清理按键相关状态
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- focusable(value: boolean): T；Text、Image 等默认不可获焦，只有可获焦组件能触发焦点事件：根容器要先能获焦（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.focusable）
- defaultFocus(value: boolean): T，true 表示页面创建时默认获焦：让页面一打开就由根容器接键（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.defaultFocus）
- onKeyPreIme(event: Callback<KeyEvent, boolean>): T：输入法之前先收到按键，返回 true 表示已消费（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onKeyPreIme）
- onKeyEvent(event: Callback<KeyEvent, boolean>): T（@since 15），返回 true 消费按键、阻止冒泡：同族接口：获焦组件的按键回调（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onKeyEvent；ts-universal-events-key.md，onKeyEvent）
- onKeyEventDispatch(event: Callback<KeyEvent, boolean>): T：同族接口：按键分发回调（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onKeyEventDispatch）
- 页面设 focusable / defaultFocus / onKeyPreIme、只消费已处理的键、隐藏和销毁时清理后，按键分发生效：卡里的修法（出处：卡里修好并验证过）
未核实：卡的环境是 API 24，本机按 API 23 的声明核实
