# 作拖拽柄或按钮的 Image 一律写 .draggable(false)

审的是：代码
触发（任一种）：
- 读到：拖拽柄的 OnTouchListener 只在 ACTION_DOWN 里 startDrag，没有长按分支；写错的样子：拖拽柄写成 Image($r(...)) 加 onTouch / priorityGesture(PanGesture) 自绘拖拽，没有 .draggable(false)；长按时系统图片拖拽接管，自绘拖拽收到 Cancel
适用范围：Image 用作拖拽柄、按钮或挂自定义手势时
做法：
- 这类 Image 写 .draggable(false)；源码用 ACTION_DOWN / onTouch 起拖的手势不叠在可系统拖拽的 Image 上
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Image 的 draggable 从 API 10 起默认 true，设为 true 时绑定的长按手势不生效；要用自定义手势须设 false：Image 缺省可拖拽（出处：ts-basic-components-image.md，draggable）
- draggable(value: boolean): T：通用的拖拽开关（一般组件默认 false，Image 等例外）（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.draggable；ts-universal-attributes-drag-drop.md，draggable）
- 补 .draggable(false) 后长按拖拽柄不再被系统拖拽接管：修复后的写法（出处：卡里修好并验证过）
