# 置了加载状态的路径要提前 return 时，先把加载状态复位

审的是：代码
触发（任一种）：
- 读到：源码先 progressBar.setVisibility(View.VISIBLE) 显示进度，再调用遇到空查询等情况会提前 return 的查询方法；写错的样子：目标代码先把控制进度显示的布尔 @Local 状态置 true，之后某个分支直接 `return`，没有把它复位为 false
适用范围：迁移带进度显示的查询或加载流程时，从置加载状态到结束的每条路径
做法：
- 凡是置了加载状态的路径，每个提前 return 的分支先写 this.<加载状态> = false 再 return
