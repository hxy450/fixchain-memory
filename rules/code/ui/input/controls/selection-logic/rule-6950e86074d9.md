# 安卓按钮 enabled 依赖选中数时，目标按钮写 .enabled(选中数 > 0)

审的是：代码
触发（任一种）：
- 读到：Compose `Button(enabled = …)` 的条件是选中数大于 0（空选时禁用结算或删除）；写错的样子：目标对应的 `Button` 没有 `.enabled(`，空选时仍可点
适用范围：按「对比安卓还原」实现带选择操作的按钮时
做法：
- 目标按钮写 .enabled(<选中列表>.length > 0)，条件照源端 enabled 的表达式
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- enabled(value: boolean): T：true 时组件可用、可响应点击；false 时不响应点击（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.enabled）
- 结算按钮 .enabled(selected.length > 0)：修复后的写法（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
- case-38718a95ad1839df7084（青商城）：做法第 1 步 ← 诊断、建议 1；取值 2 ← 诊断
