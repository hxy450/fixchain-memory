# ImageButton/Button 转成 Image 时补 focusable(true)，焦点框设透明

审的是：代码
触发（任一种）：
- 读到：布局 XML 里的 <ImageButton> 或 <Button>（安卓缺省可获焦）；写错的样子：目标端写成只有 .onClick(...) 的 Image(...)，没有 .focusable(true)
适用范围：把安卓缺省可获焦的按钮类控件转成 ArkUI 缺省不可获焦的组件（Image 等）时
做法：
- 写成 Image(...).onClick(...).focusable(true)，保持和源端一样可获焦
- 源端看不到焦点态时加 .focusBox({ strokeColor: ColorMetrics.rgba(0, 0, 0, 0) })，让焦点框透明、外观不变
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ImageButton 的构造里调用 setFocusable(true)：源端 ImageButton 缺省可获焦（出处：android.widget.ImageButton#ImageButton）
- focusable(value: boolean): T；Text、Image 等默认不可获焦：Image 要显式设 focusable(true)（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.focusable）
- focusBox(style: FocusBoxStyle): T（@since 12）：设焦点框样式（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.focusBox）
- FocusBoxStyle { margin?: LengthMetrics; strokeColor?: ColorMetrics; strokeWidth?: LengthMetrics }：strokeColor 用 ColorMetrics（出处：鸿蒙 SDK 的 ets/component/focus.d.ts，FocusBoxStyle）
- static rgba(red: number, green: number, blue: number, alpha?: number): ColorMetrics；alpha 取 0.0–1.0，默认 1.0：rgba(0, 0, 0, 0) 是全透明（出处：鸿蒙 SDK 的 ets/api/arkui/Graphics.d.ts，ColorMetrics.rgba）
- 重开和撤销对应的 Image 加 focusable(true) 和透明 focusBox 后，按键经焦点链到达页面，外观不变：验证过的写法（出处：卡里修好并验证过）
- focusBox(style: FocusBoxStyle): T：同族接口：安全控件上的 focusBox（出处：鸿蒙 SDK 的 ets/component/security_component.d.ts，SecurityComponentMethod.focusBox）
