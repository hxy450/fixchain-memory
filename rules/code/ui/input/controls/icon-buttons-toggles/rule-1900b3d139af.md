# 给状态驱动图标的按钮写回归时，断言改状态后重渲染的图标和文案，并覆盖双向切换

审的是：代码
触发（任一种）：
- 读到：安卓源码在状态变化后调用 setImageResource 或刷新图标的方法重设按钮图标；写错的样子：回归测试只断言控件布局坐标，或只用正则确认源码里有点击处理方法，没有「改状态后再取 Image 资源和 accessibilityText」的断言
适用范围：为图标或文案随状态切换的按钮写回归测试时
做法：
- 测试先改状态，再重跑同一渲染回调或刷新设备 UI 树，断言图标资源与文案已变；再改回原状态，断言变回
