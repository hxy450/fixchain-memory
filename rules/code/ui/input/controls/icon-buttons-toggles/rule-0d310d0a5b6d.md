# 源端按选中数量切换图标和文字颜色的操作栏，目标成组映射每个状态的图和色

审的是：代码
触发（任一种）：
- 读到：Java 里按选中数量对按钮调 setImageResource(R.drawable....) 在灰图和高亮图之间切换、setTextColor(...) 切换文字颜色，删除文字另有颜色，置顶按钮在两张图之间切换；写错的样子：目标的批量操作底栏只有文字，只按选中状态切换文字颜色，没有 Image 或 Image 不随状态切换
适用范围：源端操作栏按选中状态成组切换图标和文字颜色时
做法：
- 每个按钮写成 Column() { Image(<选中 ? 高亮图 : 灰图>).width(<源 dp>).height(<源 dp>); Text(...).fontColor(<选中 ? 选中色 : 未选中灰色>) }，未选中、选中各一套，删除文字的单独颜色和置顶 / 取消置顶两张图都要映射
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 批量底栏改为随选中状态切换图标的 Column（24vp 图标加文字）后与源端一致：修复后的形态（出处：卡里修好并验证过）
针对本应用要查的：
- 每个状态下的图名和颜色：源工程里切换按钮状态的那个 Java 方法：每个分支里的 setImageResource 和 setTextColor 参数；逐个按钮列成「状态 → 图名、文字颜色」表，图名对应 $r('app.media.图名')，颜色照搬
