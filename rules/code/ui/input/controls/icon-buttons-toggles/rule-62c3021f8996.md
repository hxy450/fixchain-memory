# Button 内做两态图标切换时写一个 if/else 或单个 Image 选资源，不写两个独立 if

审的是：代码
触发（任一种）：
- 读到：源端按钮按状态切换图标（如播放 / 暂停的 ImageButton、setImageResource）；写错的样子：Button() { if (!isPlaying) { Image(…) } if (isPlaying) { Image(…) } } 两个互斥的独立 if
适用范围：在 Button 等只允许单个子组件的容器里做状态切换时
做法：
- 写成 Button() { if (cond) { Image(a) } else { Image(b) } }，或 Button() { Image(cond ? a : b) }；自检对照实际输出文本，不对照计划
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Button 可以包含单个子组件：两个独立 if 会被当成两个子组件（出处：ts-basic-components-button.md，子组件）
