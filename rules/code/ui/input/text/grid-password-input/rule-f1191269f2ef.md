# 透明 TextInput 叠在掩码格上时，显式设成源控件尺寸或铺满 Stack

审的是：代码
触发（任一种）：
- 读到：格子式密码输入控件（EditText 子类）在布局 XML 里写死 android:layout_width / android:layout_height（dp），带 android:maxLength、android:inputType="number"、android:focusableInTouchMode；写错的样子：Stack 里的透明 TextInput 只设了透明 fontColor / backgroundColor 和 padding(0)，修饰链里没有 width / height，注释却写「覆在格子上承接点击」
适用范围：把源端格子式密码输入控件转成「透明 TextInput + 掩码格」叠层时的输入层
做法：
- 透明 TextInput 写 .width('100%').height('100%') 铺满承载格区的 Stack，或写 .width(源 layout_width 的 dp 数值).height(源 layout_height 的 dp 数值)
- 写完核对 TextInput 完整的修饰链里确实有这两项尺寸，不以注释代替
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Length 为 number 时默认单位 vp；字符串可写百分比如 '100%'：源端 dp 数值直接写成 number 即可（出处：ts-types.md，Length）
- TextInput 补 width / height 100% 后格区可点：修复后保留的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 源控件的宽高：源工程弹窗布局 XML 里这个密码输入控件的 android:layout_width、android:layout_height；读出 dp 数值；若是 @dimen 引用，到 res/values/dimens.xml 里按名字找到数值
未核实：卡里观察到的行为出自 API 24 目标 SDK，本机按 API 23 核实
