# 源 EditText 没写 textCursorDrawable 时，TextInput 光标不照搬别的字段或别页的配置

审的是：代码
触发（任一种）：
- 读到：这个 EditText 没写 android:textCursorDrawable，而同一布局或工程里别的 EditText 显式设了 textCursorDrawable（颜色或宽度不同）；写错的样子：TextInput 上的 .caretColor(...) / .caretStyle(...) 照搬别的字段或别的页面的光标配置或取样，注释写「安卓实测」却不写基准来自哪个页面
适用范围：安卓 EditText 没有自定义光标、外观由所在 Activity 的主题决定，迁成或修复 ArkUI TextInput 的光标时
做法：
- 不为了和别的字段、别的页面一致而补上它们的 caretColor / caretStyle；源里没有的属性不带入，别的页面显式配置的光标不能拿来代用
- 一张卡的修法：以同一 Activity（同一主题）里的输入框为基准取光标颜色和宽度，写成 .caretStyle({ width: 2, color: <主题色> })；借用别的页面前先核对两个 Activity 的 android:theme 和控件着色相同，并在注释和报告里写明基准来自哪个页面
- 另一张卡的修法：去掉这个 TextInput 上的 .caretColor(...)，用鸿蒙默认光标色（两说冲突，见未核实）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- caretColor(value: ResourceColor): TextInputAttribute，默认 '#007DFF'：不写时用这个默认光标色（出处：鸿蒙 SDK 的 ets/component/text_input.d.ts，TextInputAttribute.caretColor）
- 没写 textCursorDrawable 的字段去掉显式光标色：一张卡修复时就是这样改的（出处：卡里修好并验证过）
- 没写 textCursorDrawable 的输入框按所在页面实测是 2dp 宽、主题色的光标，写成 .caretStyle({ width: 2, color: <主题色> })：另一张卡以正确页面为基准后的写法（出处：卡里修好并验证过）
- <item name="textCursorDrawable">@drawable/text_cursor_material</item>：平台 Material 主题给输入框的默认光标（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material 的 textCursorDrawable（按应用的 compileSdk 取对应平台））
- text_cursor_material：<size android:width="2dp">，android:tint="?attr/colorControlActivated"：默认光标 2dp 宽，颜色取主题的 colorControlActivated（出处：Android SDK 平台资源 data/res/drawable/text_cursor_material.xml（按应用的 compileSdk 取对应平台））
- <item name="colorControlActivated">?attr/colorAccent</item>：Material 主题没覆盖时，colorControlActivated 等于 colorAccent（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material 的 colorControlActivated（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 源输入框所在 Activity 的主题，以及它给光标的宽度和颜色：源工程 AndroidManifest.xml 里这个 <activity> 的 android:theme（没写就看 <application android:theme>），再顺着 res/values*/ 下 styles、themes XML 的 parent 链找 textCursorDrawable、colorControlActivated、colorAccent；主题继承 AppCompat 或 MaterialComponents 的，去 Gradle 缓存里对应库包内 res/values/values.xml 按同名项查；链上离控件最近的那一项给出值；没覆盖 textCursorDrawable 时光标是 text_cursor_material（2dp 宽，颜色是 colorControlActivated 解析出的颜色）；两个 Activity 解析出同一结果才能互相借用
未核实：源 EditText 没写 textCursorDrawable 时两张卡的修法冲突：case-84754321501fb68838ca 去掉显式 caretColor、用鸿蒙默认光标色；case-f6c7146888f4d05c7874 按同一 Activity 的安卓实测写 .caretStyle({ width: 2, color: <主题色> })；不写 caretColor 时鸿蒙默认 '#007DFF'，和安卓主题给的默认光标色是否一致未核实；卡里没核实两个页面光标不同的主题成因；默认光标由 text_cursor_material 和 colorControlActivated 决定，是按平台资源推出的，卡里没验证；两张卡上机所用 SDK 都是 API 22（6.0.2），声明按本机 API 23 核实
