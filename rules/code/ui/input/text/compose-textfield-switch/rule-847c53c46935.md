# 源 Switch 有 thumbContent 勾选图标时，不用原生 Toggle 了事，用工程图标资源自绘

审的是：代码
触发（任一种）：
- 读到：源端 material3 Switch 写 thumbContent = { if (checked) Icon(Icons.Rounded.Check) }；写错的样子：目标只写 Toggle({ type: ToggleType.Switch }) 加颜色，注释里假定原生开关选中时会显示勾选图标
适用范围：源组件带显式子内容（如 Switch 的 thumbContent），迁成 ArkUI 开关时
做法：
- 不假定原生 Toggle 会画 thumb 内的图标：自绘开关（轨道加圆点），选中时在圆点里放 Image($r('app.media.<勾选图标>'))，用工程已有的勾选图标资源
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- SwitchStyle 只有 pointRadius、unselectedColor、pointColor、trackBorderRadius 四项：原生开关样式里没有 thumb 内容或图标（出处：鸿蒙 SDK 的 ets/component/toggle.d.ts，SwitchStyle）
- switchStyle(value: SwitchStyle): ToggleAttribute：Toggle 唯一带 SwitchStyle 的样式接口（出处：鸿蒙 SDK 的 ets/component/toggle.d.ts，ToggleAttribute.switchStyle）
- 改为自绘 M3 Switch，thumb 内用工程已有的勾选图标：修复后选中态显示勾选（出处：卡里修好并验证过）
针对本应用要查的：
- 目标工程里和源端勾选图标对应的图标资源：目标工程 resources/base/media 下的图标；源工程 res/drawable 下的 check 矢量图；找到已迁的那张，用 $r('app.media.<名字>') 引用；没有就先迁源端那张矢量图
来源：1 张卡，1 个应用
