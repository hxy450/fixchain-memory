# AppCompat EditText 迁成 TextInput 时，补上背景的 inset 和下划线

审的是：代码
触发（任一种）：
- 读到：源布局里的 EditText 在 AppCompat 主题下（AppCompatEditText），背景取 ?attr/editTextBackground，没有自定义 android:background；写错的样子：目标 TextInput 写 backgroundColor(Color.Transparent)，没有 abc_edit_text_material 的上、下、左右 inset，也没有底部下划线
适用范围：源端输入框用 AppCompat 默认背景（含对话框里的输入框）、目标用 ArkUI TextInput 一比一还原时
做法：
- TextInput 外面按 abc_edit_text_material 的 inset 留白：左右 abc_edit_text_inset_horizontal_material、上 abc_edit_text_inset_top_material、下 abc_edit_text_inset_bottom_material
- 在 inset 内画底部下划线：未聚焦用主题的 colorControlNormal，聚焦用 colorControlActivated
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- abc_edit_text_inset_top_material = 10dp，abc_edit_text_inset_bottom_material = 7dp，abc_edit_text_inset_horizontal_material = 4dp：AppCompat 输入框背景的四边 inset（appcompat 1.7.1）（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，abc_edit_text_inset_top_material 等（按应用依赖的版本））
- abc_edit_text_material 是 inset 包着 abc_textfield_default_mtrl_alpha（tint ?attr/colorControlNormal）和 abc_textfield_activated_mtrl_alpha（tint ?attr/colorControlActivated）：下划线来自这两个九宫图，颜色随主题（出处：androidx.appcompat:appcompat 包内 res/drawable-v21/abc_edit_text_material.xml（按应用依赖的版本））
- editTextBackground = @drawable/abc_edit_text_material：AppCompat 主题给 EditText 的默认背景（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，editTextBackground（按应用依赖的版本））
- 返修后输入框 inset 上 10 / 下 7 / 左右 4：返修后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 下划线的两种颜色：源工程 res/values 的主题（及其 parent 链）里的 colorControlNormal、colorControlActivated；没写时到 androidx.appcompat:appcompat 包内 res/values/values.xml 按主题名找；读出颜色值或解析到 @color；colorControlActivated 没写时多半取 colorAccent
未核实：colorControlActivated 缺省取 colorAccent 是常见主题写法，未逐个主题核对
