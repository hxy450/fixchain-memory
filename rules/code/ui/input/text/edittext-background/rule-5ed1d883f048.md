# 源 EditText 是密码掩码且无显隐切换时，TextInput 写 .showPasswordIcon(false)

审的是：代码
触发（任一种）：
- 读到：EditText（或其子类）写 android:password="true" 或 android:inputType="textPassword" / "numberPassword"，外面没有 TextInputLayout 的 passwordToggleEnabled，也没有自绘的显隐按钮；写错的样子：TextInput 只写了 .type(InputType.Password) 或 .type(InputType.NUMBER_PASSWORD)，没有 .showPasswordIcon(false)（或写成 .showPasswordIcon(true)），输入框末尾多出小眼睛图标
适用范围：源端密码框、数字掩码的验证码框迁成 ArkUI TextInput 的密码输入模式时
做法：
- 在 .type(InputType.Password)（数字掩码用 InputType.NUMBER_PASSWORD）旁同时写 .showPasswordIcon(false)
- 改一处时在工程里搜 InputType.Password、InputType.NUMBER_PASSWORD，源端同样没有显隐切换的输入框一并加上
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- showPasswordIcon(value: boolean): TextInputAttribute，默认 true；只在 Password、NEW_PASSWORD、NUMBER_PASSWORD 模式下生效：密码模式下末尾的显隐图标默认显示，要显式关掉（出处：鸿蒙 SDK 的 ets/component/text_input.d.ts，TextInputAttribute.showPasswordIcon）
- InputType.Password、InputType.NUMBER_PASSWORD = 8：都带显示或隐藏密码的眼睛图标；TV 设备默认不显示，其他设备默认显示：数字掩码框同样会出小眼睛（出处：鸿蒙 SDK 的 ets/component/text_input.d.ts，InputType；ts-basic-components-textinput.md，InputType枚举说明）
- password 的 format 是 boolean；inputType 的 textPassword = 0x00000081、numberPassword = 0x00000012：源端这几种写法都是密码掩码（出处：Android SDK 平台资源 data/res/values/attrs.xml，password、inputType（按应用的 compileSdk 取对应平台））
- 加 .showPasswordIcon(false) 后小眼睛消失，与源端一致：返修后的结果（出处：卡里修好并验证过）
