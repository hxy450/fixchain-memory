# Material 主题 EditText 的下划线按背景 inset 定位，inset 不当文字内距

审的是：代码
触发（任一种）：
- 读到：EditText 没写 android:background，主题是 Theme.Material 系（editTextBackground = @drawable/edit_text_material，外层 <inset> 包着随聚焦切换的 9-patch selector）；写错的样子：`TextInput` / `TextArea` 写 .padding({ left: 4, top: 10, right: 4, bottom: 7 })，下划线 Divider().width('100%') 贴在 Stack 底边
适用范围：运行期主题是 Theme.Material 系、EditText 未声明 background，迁成 TextInput / TextArea 加 Divider 复刻下划线时
做法：
- 下划线只画在 inset 之内：Divider 设 margin 左右各 4、离框底 7（edit_text_inset_horizontal / bottom_material），未聚焦用 colorControlNormal、聚焦用 colorControlActivated
- 文字内距 = inset + 9-patch 内容区（Theme.Material.Light 下实测 4/10/4/14，单行框高 45.1vp），不把 inset 直接写成 padding
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- edit_text_material：<inset> 的 insetLeft / Right = edit_text_inset_horizontal_material，insetTop / Bottom = edit_text_inset_top / bottom_material，里面是 selector（未聚焦 textfield_default_mtrl_alpha 着 colorControlNormal，其余 textfield_activated_mtrl_alpha 着 colorControlActivated）：Material 输入框背景的结构（出处：Android SDK 平台资源 data/res/drawable/edit_text_material.xml（按应用的 compileSdk 取对应平台））
- edit_text_inset_horizontal_material 4dp、edit_text_inset_top_material 10dp、edit_text_inset_bottom_material 7dp：下划线左右各缩 4、离框底 7（出处：Android SDK 平台资源 data/res/values/dimens_material.xml，edit_text_inset_*_material（按应用的 compileSdk 取对应平台））
- Theme.Material.Light 的 editTextBackground 是 @drawable/edit_text_material：未声明 background 的 EditText 用这个背景（出处：Android SDK 平台资源 data/res/values/themes_material.xml，editTextBackground（按应用的 compileSdk 取对应平台））
- 文字内距实测 4/10/4/14，单行框高 45.1dp：inset 加 9-patch 内容区的结果（Theme.Material.Light）（出处：卡里修好并验证过）
针对本应用要查的：
- 运行期主题的 editTextBackground：源工程主题定义（含 values-v21 等限定目录），顺父主题到平台 themes*.xml 的 editTextBackground；是 edit_text_material 这类 <inset> 外壳的按本条做；是裸 9-patch（Holo）的内距直接取 9-patch 内容区
