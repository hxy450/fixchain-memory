# 收键盘的调用方依赖焦点态时，把收键盘引起的失焦排除在焦点变化之外

审的是：代码
触发（任一种）：
- 读到：源端 hideSoftInputFromWindow 只收键盘、焦点不变，提交后工具栏仍按聚焦状态显示菜单；写错的样子：提交时收键盘后 .onBlur 分支照常把焦点态置 false，工具栏退回非聚焦的菜单
适用范围：鸿蒙端焦点态驱动菜单或工具栏、又要在提交等时机收键盘时
做法：
- 收键盘走一个保持焦点态的入口：调 hideTextInput 时标记「这次失焦来自收键盘」，.onBlur 看到这个标记就不进焦点变化分支
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 收键盘入口把它引发的失焦排除在焦点变化之外：修好后提交收键盘时工具栏保持聚焦菜单（出处：卡里修好并验证过）
