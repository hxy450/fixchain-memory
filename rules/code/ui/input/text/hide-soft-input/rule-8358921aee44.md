# 只收键盘时用 hideTextInput，不用 hideSoftKeyboard 或 stopInputSession

审的是：代码
触发（任一种）：
- 读到：源端 InputMethodManager.hideSoftInputFromWindow(...) 只收键盘、不改焦点；规格写 inputMethodController（@kit.IMEKit）的方法名「实现期复核后钉死」；写错的样子：鸿蒙端用 inputMethodController 的 showSoftKeyboard / hideSoftKeyboard 弹收键盘，或用 stopInputSession 收键盘
- 写错的样子：IME 调用外包 try/catch 吞掉拒绝，注释成「isActive 短路」之类，掩盖调用无效
适用范围：三方应用用 @kit.IMEKit 的 inputMethodController 弹出、收起输入框键盘时
做法：
- 收键盘写 await inputMethod.getController().hideTextInput()，弹键盘写 showTextInput()（编辑框须已取焦）；不用 showSoftKeyboard / hideSoftKeyboard（只给系统应用，要 ohos.permission.CONNECT_IME_ABILITY），也不用 stopInputSession（会让编辑框失焦）
- 规格要求实现期核实方法名而参考里查不到时，接着查 SDK 的 @ohos.inputMethod.d.ts 里该方法的权限和说明，不用 catch 吞错代替核对
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- hideTextInput(): Promise<void>：InputMethodController：退出文本编辑状态，软键盘显示时会被隐藏，不解除与输入法的绑定（出处：鸿蒙 SDK 的 ets/api/@ohos.inputMethod.d.ts，InputMethodController.hideTextInput；js-apis-inputmethod.md，hideTextInput）
- showTextInput(): Promise<void>：InputMethodController：进入文本编辑状态；编辑框没取焦时抛 12800003（出处：鸿蒙 SDK 的 ets/api/@ohos.inputMethod.d.ts，InputMethodController.showTextInput）
- hideSoftKeyboard(): Promise<void> / showSoftKeyboard(): Promise<void>，@permission ohos.permission.CONNECT_IME_ABILITY：只能由系统应用调用，三方应用调用会被拒（201 权限检查失败）（出处：鸿蒙 SDK 的 ets/api/@ohos.inputMethod.d.ts，InputMethodController.hideSoftKeyboard）
- stopInputSession(): Promise<boolean>：InputMethodController：结束输入会话（出处：鸿蒙 SDK 的 ets/api/@ohos.inputMethod.d.ts，InputMethodController.stopInputSession）
- stopInputSession 会让编辑框失焦；hideTextInput 只收键盘：源端只收键盘不清焦点，对应 hideTextInput（出处：卡里修好并验证过）
- getController(): InputMethodController：inputMethod 模块取输入法控制器（出处：鸿蒙 SDK 的 ets/api/@ohos.inputMethod.d.ts，inputMethod.getController）
- hideSoftInputFromWindow 是从当前接收输入的窗口请求隐藏软键盘：源端只收键盘，不清焦点（出处：android.view.inputmethod.InputMethodManager#hideSoftInputFromWindow）
未核实：卡里环境是 API 24（6.1.1），本机按 API 23 的声明核对
