# 弹层输入框只需获焦、不弹键盘时，设 enableKeyboardOnFocus(false)

审的是：代码
触发（任一种）：
- 读到：源端对话框 EditText 只有 <requestFocus/>，没有 showSoftInput / setSoftInputMode；写错的样子：目标 TextInput / TextArea 写了 .defaultFocus(true) 或由宿主 focusControl.requestFocus 获焦，但没写 .enableKeyboardOnFocus(false)
适用范围：openCustomDialog 等弹层里的输入框、源端只获焦不弹键盘时
做法：
- 这类 TextInput / TextArea 一律写 .enableKeyboardOnFocus(false)，获焦方式（defaultFocus 或 requestFocus）照旧
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- enableKeyboardOnFocus(value: boolean): TextInputAttribute，默认 true；非点击方式获焦时是否拉起输入法：不关时 defaultFocus、requestFocus 获焦都会绑定输入法（出处：鸿蒙 SDK 的 ets/component/text_input.d.ts，TextInputAttribute.enableKeyboardOnFocus）
- enableKeyboardOnFocus(value: boolean): TextAreaAttribute：同族接口：TextArea 的同一开关（出处：鸿蒙 SDK 的 ets/component/text_area.d.ts，TextAreaAttribute.enableKeyboardOnFocus）
- enableKeyboardOnFocus(value: boolean): SearchAttribute：同族接口：Search 的同一开关（出处：鸿蒙 SDK 的 ets/component/search.d.ts，SearchAttribute.enableKeyboardOnFocus）
- 不关时首次打开可能不弹、再次打开就弹；三框和 TextArea 加 enableKeyboardOnFocus(false) 后都只获焦：修复后与源端一致（出处：卡里修好并验证过）
