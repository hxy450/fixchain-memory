# 源端多段输入各是独立 Dialog 时，目标按段拆成独立分支节点，不用阶段标志复用同一 TextInput

审的是：代码
触发（任一种）：
- 读到：两段流程各自建一个 Dialog（如 CustomDialog）、各自 inflate 布局并 findViewById 取自己的 EditText，第一段输满后 dismiss 再弹第二段；写错的样子：目标只有一个受控 TextInput 节点，用阶段标志切换文案，并在 onChange 同一拍里清空输入值进入下一段
适用范围：源端多段输入（设置再确认等）每段是独立弹窗、各带新输入框，迁到同一个目标弹层组件时
做法：
- 按段写成 if / else 两个独立分支，各自一个 TextInput；两段可共用一个 @Builder，分别传入不同的 key 与格间距
- 不在同一节点的 onChange 里同拍清空输入值来切段
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 两段拆成 if/else 独立节点、共用 builder 传 key 与格间距后，再次确认能输入：修复后保留的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 每段的格间距等差异：源工程每段弹窗各自的布局 XML；逐份比对密码控件的属性和间距 dimen，有差异的作为 builder 参数传入
未核实：「同节点受控清空导致失联」是修复者的判断，卡里没单独验证
