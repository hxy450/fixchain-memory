# EditText 为 number 时，目标设 InputType.Number 并加 [0-9] 过滤，不只加正则

审的是：代码
触发（任一种）：
- 读到：EditText 的 android:inputType 是 number（不带 numberSigned）；写错的样子：对应的 TextInput 只加了 inputFilter 数字正则、键盘仍是默认 InputType.Normal，或者没设 .type(InputType.Number)
适用范围：安卓非负整数输入框迁成 ArkUI TextInput 时
做法：
- 写成 TextInput(...).type(InputType.Number).inputFilter('[0-9]')
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- type(value: InputType): TextInputAttribute；InputType.Number 是纯数字输入模式，不支持负数、小数：TextInput 的数字键盘（出处：鸿蒙 SDK 的 ets/component/text_input.d.ts，TextInputAttribute.type；ts-basic-components-textinput.md，InputType枚举说明）
- number = 0x00000002，对应 TYPE_CLASS_NUMBER | TYPE_NUMBER_VARIATION_NORMAL：源端是只收数字的数值框（出处：Android SDK 平台资源 data/res/values/attrs.xml，inputType 的 number（按应用的 compileSdk 取对应平台））
- type(value: TextAreaType): TextAreaAttribute；TextAreaType.NUMBER = 2：同族接口：多行输入用 TextArea 时的数字键盘（出处：鸿蒙 SDK 的 ets/component/text_area.d.ts，TextAreaAttribute.type、TextAreaType）
未核实：卡里的行为出自 API 24（HarmonyOS 6.1.1），本机声明是 API 23
