# 源端挂 InputFilter.AllCaps 时，在 aboutToIMEInput 里转大写自行插入

审的是：代码
触发（任一种）：
- 读到：源端 EditText 设了 setFilters(new InputFilter[]{ new InputFilter.AllCaps() })；写错的样子：目标输入时不转大写，toUpperCase 放在保存或校验时（ViewModel 里），粘贴进来的小写也原样保留
适用范围：源端用 InputFilter 在输入时改写字符、目标是 RichEditor 时
做法：
- .aboutToIMEInput((value: RichEditorInsertValue) => { 把 value.insertValue.toUpperCase() 用 addTextSpan 插到 value.insertOffset（有选区时先替换选区）；return false })
- 粘贴同样处理：.onPaste((event?: PasteEvent) => { event?.preventDefault?.(); 读剪贴板文本转大写后自行插入 })
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- aboutToIMEInput(callback: Callback<RichEditorInsertValue, boolean>): RichEditorAttribute：输入法输入前回调；返回 true 组件照常插入，false 不插入（出处：鸿蒙 SDK 的 ets/component/rich_editor.d.ts，RichEditorAttribute.aboutToIMEInput；ts-basic-components-richeditor.md，aboutToIMEInput）
- RichEditorInsertValue.insertOffset: number；RichEditorInsertValue.insertValue: string：将要插入的位置和内容（出处：鸿蒙 SDK 的 ets/component/rich_editor.d.ts，RichEditorInsertValue）
- onPaste(callback: PasteEventCallback): RichEditorAttribute；PasteEvent.preventDefault?: Callback<void>：拦下系统粘贴后自行插入（出处：鸿蒙 SDK 的 ets/component/rich_editor.d.ts，RichEditorAttribute.onPaste、PasteEvent.preventDefault）
- 用 RichEditorStyledStringOptions 构建的 RichEditor 不支持 aboutToIMEInput：要用 RichEditorController 那一路（出处：ts-basic-components-richeditor.md，aboutToIMEInput）
- aboutToIMEInput 转大写并替换选区后，输入即为大写：卡里的修法（出处：卡里修好并验证过）
未核实：粘贴的处理是卡的建议，卡里没写修复时是否做了；卡里环境是 API 24，按本机 API 23 的声明核实
