# 源码对 EditText 调 setError 时，目标用尾部错误图标加获焦浮层、输入即清，不用行内红字

审的是：代码
触发（任一种）：
- 读到：源码对 EditText 调用 setError(...)（多在字段校验处）；写错的样子：目标在 TextInput 下面条件渲染错误 Text（if (…Error) Text(...) 小字号红字，出错时撑高弹窗或表单），或用 TextInput 的 .showError(...)；没有尾部错误图标和获焦浮层
适用范围：源端用 TextView/EditText 的 setError 提示字段错误、目标用 ArkUI TextInput 时
做法：
- 出错时在 TextInput 尾部（右端）显示错误图标；错误文案放在不参与布局的浮层（绝对定位）或气泡里，只在该框获焦时显示，不撑高容器；框内文本一改就清掉图标和浮层
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- setError 把右侧 compound drawable 设成错误图标，错误文案在 TextView 获焦时以弹出窗显示，任何改动文本的按键都会清掉图标和文案：源端 setError 的呈现形态，目标要复刻的语义（出处：android.widget.TextView#setError）
- private static class ErrorPopup extends PopupWindow：错误信息是一个 PopupWindow 浮层，不在布局里（出处：android.widget.Editor.ErrorPopup）
- 错误图标 com.android.internal.R.drawable.indicator_input_error：setError 用的平台错误图标（出处：android.widget.TextView#setError）
- showError(value?: ResourceStr | undefined): TextInputAttribute：ArkUI 的错误文本显示在输入框下方，是行内形态，不能直接当 setError 的对应物（出处：鸿蒙 SDK 的 ets/component/text_input.d.ts，TextInputAttribute.showError）
- 返修改为 setError 图标 + 绝对定位浮层：返修后的写法（出处：卡里修好并验证过）
- 重写为错误气泡加 20vp 尾部图标：修复后的呈现（出处：卡里修好并验证过）
