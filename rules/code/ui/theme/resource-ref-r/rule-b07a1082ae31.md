# 派工要求尺寸走 $r 时，blur、Swiper.itemSpace 仍写数值常量，不传 $r

审的是：代码
触发（任一种）：
- 读到：派工或主题说明写「颜色、尺寸全部绑定资源」「尺寸经 $r('app.float.*')」；同布局已有页面写的是 .blur(<数值常量>)、.itemSpace(<数值>)；写错的样子：页面里写成 .blur($r('app.float.…')) 或 .itemSpace($r('app.float.…'))
- 读到：rg 到并发生成、尚未编译的兄弟页里 .blur($r(…)、.itemSpace($r(…) 的写法；写错的样子：把首稿里与已有页面一致的 .blur(<常量>)、.itemSpace(<数值>) 改成兄弟页的 $r 写法
适用范围：ArkUI 页面转换时，把资源绑定纪律套到组件属性的参数上
做法：
- 资源绑定只用于签名接受 Resource / Length / ResourceColor 的属性；blur 和 Swiper 的 itemSpace 写数值常量，可直接沿用同布局已有页面的常量：.blur(<半径常量>)、.itemSpace(<数值>)
- 已有页面和并发生成、未编译的兄弟页写法不一致时，先按声明的参数类型取舍，不用兄弟页覆盖与已有页面一致的写法
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- blur(value: number, options?: BlurOptions): T；since 19 另有 blur(blurRadius: Optional<number>, options?: BlurOptions, sysOptions?: SystemAdaptiveOptions): T：内容模糊半径只收 number，不收 Resource（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.blur）
- itemSpace(value: number | string): SwiperAttribute：Swiper 子组件间距；number 默认单位 vp，string 要显式带单位如 '10px'，不带单位按 vp；默认 0（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.itemSpace）
- backdropBlur(value: number, options?: BlurOptions): T：同族接口：背景模糊半径，同样只收 number（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.backdropBlur）
- linearGradientBlur(value: number, options: LinearGradientBlurOptions): T：同族接口：线性渐变模糊半径，同样只收 number（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.linearGradientBlur）
- blur、itemSpace 改回数值常量后编译通过：修好后的写法（出处：卡里修好并验证过）
未核实：卡里的编译报错出自 API 26（target_sdk 26.0.0），本机核对用的是 API 23
