# 资源引用写成没有 $r 包裹的 'app.float.…' 字符串时，改回 $r(...)，批量替换用单引号脚本并读回

审的是：代码
触发（任一种）：
- 读到：改写前的原行是 $r('app.float.…') 这类资源引用；写错的样子：改写后成了 .margin({ top: ('app.float.dp_89') }) 这类没有 $r 包裹的资源键字符串（'app.类型.名字'），编译照样通过
适用范围：目标代码里所有资源引用，尤其是用 shell 一行命令批量改写过的文件
做法：
- 把裸字符串改回 $r('app.float.…')；对改动过的文件搜没有被 $r 包裹的 ('app.(float|color|string|media).…') 形态逐个改
- 用 perl / sed 改写含 $ 的片段时把脚本放在单引号里，或改用 Edit、Python 字面替换；替换后读回每一行被改的代码，确认 $r( 还在，不以编译通过为准
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- declare function $r(value: string, ...params: any[]): Resource；value 格式是 'belonging.type.name'：只有经 $r 才解析成资源（出处：鸿蒙 SDK 的 ets/component/common.d.ts，$r）
- declare type Length = string | number | Resource：裸字符串也是合法的 Length，所以编译不报错，但不会当成资源解析（出处：鸿蒙 SDK 的 ets/component/units.d.ts，Length）
- declare type ResourceColor = Color | number | string | Resource：颜色参数同样收字符串，裸资源键一样静默失效（出处：鸿蒙 SDK 的 ets/component/units.d.ts，ResourceColor）
- margin(value: Margin | Length | LocalizedMargin): T：ArkUI 没有 marginTop，单边外边距写 .margin({ top: $r(...) })（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.margin）
