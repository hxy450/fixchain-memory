# 控件经 style 继承的圆角和形状值

agent 会看到什么：读到布局 XML 里控件写 style="@style/…"，圆角、高度写在样式的 <item> 里，元素本身没覆写或别处元素覆写了；产物里对应组件的 .borderRadius(...) 取了外层卡片、相邻按钮、别处覆写的值，或按半高写成胶囊

## 规矩

- rule-87faebd627cc｜控件经 style 继承圆角、元素没覆写时，borderRadius 取样式里的值，不按半高或邻近控件推｜读到：布局 XML 里控件写 `style="@style/…"`，圆角、高度等形状值写在样式的 `<item>` 里，元素本身没有写圆角覆写；写错：对应组件的 `.borderRadius(...)` 用了外层卡片、相邻按钮或别处显式覆写的值，或按高度一半写成胶囊；注释里写不出圆角来自样式还是哪一处覆写
