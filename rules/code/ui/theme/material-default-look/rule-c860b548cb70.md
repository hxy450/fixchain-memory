# Activity 用库主题时，颜色 attr 取库主题默认值，不复用应用 color.json 的同名 token

审的是：代码
触发（任一种）：
- 读到：清单或规格写明 Activity 的 `android:theme` 是库主题（如 `Theme.MaterialComponents.Light.Dialog`、`Theme.AppCompat.*`），控件样式继承 `Widget.MaterialComponents.Button.TextButton` 且没覆盖 `android:textColor`；写错的样子：目标写 `.fontColor($r('app.color.colorPrimary'))`，用的是应用主题里同名 token 的值
适用范围：源 Activity 的主题是 Material / AppCompat 库主题、控件颜色由主题 attr 决定时
做法：
- 按库主题解析颜色 attr：TextButton 的文字色是 mtrl_text_btn_text_color_selector，启用态取 ?attr/colorPrimary；库主题没覆盖时 colorPrimary 是 @color/design_default_color_primary
- 目标写解析出的色值（例：Theme.MaterialComponents.Light.Dialog 下 .fontColor('#FF6200EE')），不引用应用 color.json 里的 colorPrimary
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Base.V14.Theme.MaterialComponents.Light.Dialog：colorPrimary = @color/design_default_color_primary：Theme.MaterialComponents.Light.Dialog 经 Base 主题继承到的 colorPrimary（出处：com.google.android.material:material 包内 res/values/values.xml，Base.V14.Theme.MaterialComponents.Light.Dialog（按应用依赖的版本））
- design_default_color_primary = #6200EE：库主题默认的 colorPrimary 色值（出处：com.google.android.material:material 包内 res/values/values.xml，design_default_color_primary（按应用依赖的版本））
- Widget.MaterialComponents.Button.TextButton：android:textColor = @color/mtrl_text_btn_text_color_selector：TextButton 的文字色是一个状态选择器（出处：com.google.android.material:material 包内 res/values/values.xml，Widget.MaterialComponents.Button.TextButton（按应用依赖的版本））
- 启用态：?attr/colorPrimary，alpha 1.00；不可用：?attr/colorOnSurface，alpha 0.38：mtrl_text_btn_text_color_selector 的取值（出处：com.google.android.material:material 包内 res/color/mtrl_text_btn_text_color_selector.xml（按应用依赖的版本））
- 库 Dialog 主题下按钮文字色改为 #6200EE 后与源端一致：验证过的取值（出处：卡里修好并验证过）
针对本应用要查的：
- Activity 实际用的主题和它提供的颜色 attr：源工程 AndroidManifest.xml 里该 <activity> 的 android:theme（没写看 <application>）；依赖声明里 com.google.android.material:material（或 appcompat）的版本，到该版本 AAR 的 res/values/values.xml 里顺着主题的 parent 链找；主题自己覆盖了的取覆盖值；没覆盖的顺着 parent 找到提供 colorPrimary 等 attr 的那一项，再把 @color 引用解析成色值
未核实：卡里没写 material 库版本，本机核对用的是 1.8.0；卡里的效果在目标 API 24 上验证
