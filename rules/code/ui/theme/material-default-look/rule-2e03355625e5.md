# 源 Button 外观来自 Material 主题时，目标用语义色补 backgroundColor、fontColor

审的是：代码
触发（任一种）：
- 读到：源布局 Button 没写 android:background、backgroundTint、textColor，主题父主题是 Theme.MaterialComponents.*；目标 color.json 已有 colorPrimary、colorOnPrimary 同名资源；写错的样子：目标 Button 修饰链只有 fontSize、margin、onClick，没有 .backgroundColor(...) 和 .fontColor(...)，显示平台默认的蓝色按钮
适用范围：页面实现阶段，源 Button 的外观由 MaterialComponents 系主题的默认按钮样式提供，即使规格没列样式
做法：
- Button 上写 .backgroundColor($r('app.color.colorPrimary')).fontColor($r('app.color.colorOnPrimary')).borderRadius(4).constraintSize({ minHeight: 48 })，颜色用已迁移的语义色资源，深浅色由 base / dark 资源切换
- 写出前对照源主题的 colorPrimary / colorOnPrimary 和目标 color.json 的同名令牌，确认修饰链里有对应的 backgroundColor 与 fontColor；规格写“零硬编码色值”时资源引用照样要写
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- backgroundColor(value: ResourceColor): T：组件背景色，传 $r('app.color.…')（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.backgroundColor）
- fontColor(value: ResourceColor): ButtonAttribute：Button 的文字颜色（出处：鸿蒙 SDK 的 ets/component/button.d.ts，ButtonAttribute.fontColor）
- borderRadius(value: Length | BorderRadiuses | LocalizedBorderRadiuses): T；constraintSize(value: ConstraintSizeOptions): T：圆角和最小高度的写法（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.borderRadius / CommonMethod.constraintSize）
- Widget.MaterialComponents.Button：backgroundTint 启用态取 ?attr/colorPrimary，android:textColor 启用态取 ?attr/colorOnPrimary：源端底色、字色的来源（出处：com.google.android.material:material 包内 res/color/mtrl_btn_bg_color_selector.xml、res/color/mtrl_btn_text_color_selector.xml（按应用依赖的版本））
- 圆角 mtrl_shape_corner_size_small_component = 4dp；Base.Widget.AppCompat.Button 的 android:minHeight = 48dip：源端圆角、最小高度的来源（出处：com.google.android.material:material 包内 res/values/values.xml，mtrl_shape_corner_size_small_component；androidx.appcompat:appcompat 包内 res/values/values.xml，Base.Widget.AppCompat.Button（按应用依赖的版本））
- ButtonOptions.type 默认 ButtonType.ROUNDED_RECTANGLE（API 18 之前默认 Capsule）：不设样式时目标按钮是平台默认形状和强调色（出处：ts-basic-components-button.md，ButtonOptions）
- 补上 backgroundColor、fontColor、borderRadius(4)、constraintSize({ minHeight: 48 }) 后，复测底色与源主题 colorPrimary 一致：返修后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 主题的 colorPrimary、colorOnPrimary 和目标同名资源：源工程 res/values/themes.xml、values-night/themes.xml 里应用主题；目标工程 resources/base/element/color.json 和 dark/element/color.json；确认两边同名令牌都在，修饰链里用 $r('app.color.<令牌名>')
