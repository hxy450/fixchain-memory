# Material 按钮没写 style 和 backgroundTint 时，目标背景设主题 colorPrimary

审的是：代码
触发（任一种）：
- 读到：布局 XML 里 `<Button>` 没写 `style` 和 `app:backgroundTint`，应用主题是 MaterialComponents 或 Material3 一族；写错的样子：对应 ArkUI `Button` 只写了文本、`fontSize`、`height`，没有 `.backgroundColor(...)`，显示成 ArkUI 默认强调色
适用范围：应用主题是 Material 组件库主题、按钮没有自定样式和着色时
做法：
- 写成 `Button(...).backgroundColor($r('app.color.<主题 colorPrimary 对应的 token>'))`，不依赖 ArkUI Button 的默认强调色
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Widget.MaterialComponents.Button 的 backgroundTint = @color/mtrl_btn_bg_color_selector，可用态取 ?attr/colorPrimary：MaterialComponents 主题下默认按钮的填充色是主题 colorPrimary（出处：com.google.android.material:material 包内 res/values/values.xml，Widget.MaterialComponents.Button；res/color/mtrl_btn_bg_color_selector.xml（按应用依赖的版本））
- Widget.Material3.Button 的 backgroundTint 取 ?attr/colorContainer，ThemeOverlay.Material3.Button 把它设为 m3_comp_filled_button_container_color = ?attr/colorPrimary：Material3 主题下默认按钮的填充色也是主题 colorPrimary（出处：com.google.android.material:material 包内 res/values/values.xml，Widget.Material3.Button、ThemeOverlay.Material3.Button、m3_comp_filled_button_container_color；res/color/m3_button_background_color_selector.xml（按应用依赖的版本））
- ArkUI Button 的 buttonStyle 默认 ButtonStyleMode.EMPHASIZED，系统按它调背景色；backgroundColor 可覆盖，以最后一次设置为准：不写 backgroundColor 时显示系统强调色（出处：ts-basic-components-button.md，ButtonOptions 对象说明）
- 订阅/恢复按钮补 backgroundColor(主题主色 token) 后与源端一致：修好后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 主题 colorPrimary 的值：源工程 res/values 下 styles.xml、themes.xml 里应用或该 Activity 的主题，顺 parent 链找 colorPrimary（或 android:colorPrimary）；解析到 @color/… 后，在目标工程的 color 资源里找对应 token 填进 backgroundColor
未核实：写者 grep 主题只看到 colorAccent，没看到 colorPrimary；按钮主色是隐含的主题默认值
