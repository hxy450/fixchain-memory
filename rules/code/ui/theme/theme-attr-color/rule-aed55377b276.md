# 源端取主题色或窗口底的位置，目标绑主题成对键，不写 colorPrimary、colorAccent、white 常量

审的是：代码
触发（任一种）：
- 读到：Toolbar android:background="?attr/colorPrimary"；ActionBar、抽屉选中项取 colorPrimary；平台 AlertDialog 按钮、开关、单选、链接取 colorAccent；页面或列表没设底色、取主题的 android:windowBackground；写错的样子：目标写成 .backgroundColor($r('app.color.colorPrimary'))、.fontColor($r('app.color.colorAccent'))、.backgroundColor($r('app.color.white')) 这类直迁常量
适用范围：源主题的主题属性色日夜不同、目标已有（或应有）主题属性成对键时的界面实现
做法：
- 工具栏、ActionBar、抽屉选中项绑 theme_primary 这类成对键；状态栏区绑 theme_primary_dark；弹窗按钮、开关、单选、Tab 指示条、链接绑 theme_accent；页面、抽屉、列表底绑 window_background
- 源布局里写死 @color/ 的位置仍用单态常量（例：某个 Toolbar 的 android:background 写死了 @color/colorPrimaryDark，就传这个常量）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Base.Widget.AppCompat.ActionBar.Solid：background=?attr/colorPrimary：ActionBar 底色取主题的 colorPrimary（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Base.Widget.AppCompat.ActionBar.Solid（按应用依赖的版本））
- Base.V7.Theme.AppCompat：colorControlActivated=?attr/colorAccent：开关、单选等控件选中态取 colorAccent（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Base.V7.Theme.AppCompat（按应用依赖的版本））
- Platform.AppCompat：android:textColorLink=?attr/colorAccent：链接文字色取 colorAccent（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Platform.AppCompat（按应用依赖的版本））
针对本应用要查的：
- 某个控件的颜色是主题属性还是写死：源工程布局 XML 里这个控件的 android:background、textColor 等属性，没写的看它的 style 和主题；?attr/ 开头或没写而取主题默认的，绑成对键；@color/ 开头的用单态常量
