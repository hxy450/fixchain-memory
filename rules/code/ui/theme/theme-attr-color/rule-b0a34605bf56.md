# 源端主题是 DayNight 时，页面颜色只引用 base/dark 成对 token，不写死某一模式的色

审的是：代码
触发（任一种）：
- 读到：styles.xml 里 AppTheme 只继承 Theme.AppCompat.DayNight；写错的样子：页面的 .backgroundColor / .fontColor 写死某一模式的调色板色（Color.White、白色或深灰的 $r('app.color.…')），或注释写「深色留待以后」
适用范围：源工程主题是 AppCompat DayNight，写页面背景、文字、菜单颜色时
做法：
- 背景、文字、菜单颜色都写成 $r('app.color.<token>')，token 在 base/element 和 dark/element 的 color.json 里成对存在；不按某一模式选 white、dark_gray 这类色，也不把深色适配留到以后
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 在两个 color.json 里定义同名配色并赋予不同色值，系统切换深浅色时自动取对应的值：页面只要引用同名 token 就会随深浅色切换（出处：ui-dark-light-color-adaptation.md，应用跟随系统的深浅色模式）
- 页面改引随深浅色切换的成对 token 后，浅色和深色下窗口、文字、菜单颜色都对：写死深色或写死白色两种做法都被这样修掉（出处：卡里修好并验证过）
