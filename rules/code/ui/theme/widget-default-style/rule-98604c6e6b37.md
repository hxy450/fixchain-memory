# textAllCaps 全大写时，目标按 locale 调 toLocaleUpperCase，不用 textCase

审的是：代码
触发（任一种）：
- 读到：android:textAllCaps="true"，或 Button / AlertDialog 按钮用 TextAppearance.AppCompat.Button、TextAppearance.Material.Button 默认样式；写错的样子：目标写成 .textCase(TextCase.UpperCase)，或把原注释「不以 textCase 仿造」改掉
- 读到：Button 或 AlertDialog 的 setPositiveButton / setNegativeButton，Material / AppCompat 主题、没设 textAllCaps="false"；写错的样子：按钮直接渲染资源原样（Button($r('app.string.…'))），注释写「textAllCaps 差异不仿造、记档」
适用范围：源端文字由 textAllCaps 转全大写（显式或主题默认），迁成 ArkUI 文案时
做法：
- Resource 先取串 ctx.resourceManager.getStringSync(res.id)（ctx 由 UIContext.getHostContext() 取），再 .toLocaleUpperCase(<当前资源 locale>)，封装成共享 allCaps(ctx, text)，语言变化时重算
- 不用 .textCase(TextCase.UpperCase) 代替，也不按资源原样渲染、差异记报告
- 先搜工程里已有的 toLocaleUpperCase 实现并复用；读到「按 locale」「不以 textCase 仿造」注释先弄清原因再改
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- textCase(TextCase.UpperCase) 在德语下显示 ZURüCKSETZEN（安卓为 ZURÜCKSETZEN）；改成 getStringSync 后 toLocaleUpperCase 显示正确：textCase 不按语言规则转非 ASCII 字母（出处：卡里修好并验证过）
- TextCase.UpperCase 不转换西里尔等非拉丁字母；取资源串后 toLocaleUpperCase 的共享 allCaps 实现在俄语和运行时切换语言下都正确，最终保留：上机看到的行为和修好的写法（出处：卡里修好并验证过）
- return TextUtils.toUpperCase(locale, source, copySpans)；locale 取 TextView#getTextLocale()，没有时取资源配置 getLocales().get(0)：源端全大写按当前 locale 做（出处：android.text.method.AllCapsTransformationMethod#getTransformation）
- TextAppearance.Material.Button 和 Base.TextAppearance.AppCompat.Button（TextAppearance.AppCompat.Button 继承它）里 textAllCaps = true：平台 Material 和 AppCompat 主题下按钮文字默认全大写（出处：Android SDK 平台资源 data/res/values/styles_material.xml，TextAppearance.Material.Button（按应用的 compileSdk 取对应平台）；androidx.appcompat:appcompat 包内 res/values/values.xml，Base.TextAppearance.AppCompat.Button（按应用依赖的版本））
- getStringSync(resId: number): string；getStringSync(resource: Resource): string 自 API 20 起 @deprecated：同步取资源串，按资源 id 的重载不废弃（出处：鸿蒙 SDK 的 ets/api/@ohos.resourceManager.d.ts，ResourceManager.getStringSync）
- getHostContext(): Context | undefined：UIContext 拿宿主 context，再取它的 resourceManager（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.getHostContext）
- Configuration.locale: string（如 zh-Hans-CN），由 getConfigurationSync() 取：当前语言，作 toLocaleUpperCase 的参数（出处：鸿蒙 SDK 的 ets/api/@ohos.resourceManager.d.ts，Configuration.locale、ResourceManager.getConfigurationSync）
- textCase(value: TextCase): TextAttribute；TextCase.UpperCase 注释只写「The text is all uppercase.」：声明没说明对非 ASCII 字母和 locale 的处理，不能代替 textAllCaps（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.textCase；ets/component/enums.d.ts，TextCase.UpperCase）
针对本应用要查的：
- 源端这段文字是不是由主题默认全大写：源工程布局 XML 里这个控件的 style、android:textAppearance、android:textAllCaps，再往上到 Activity 或应用主题（AndroidManifest.xml 的 android:theme）；主题是 AppCompat 或 Material 一族且控件没写 android:textAllCaps="false" 时，按钮文字默认全大写
