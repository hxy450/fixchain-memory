# 继承 AppCompatButton 只换背景的自定义块，目标组件用 .shadow 补按钮默认投影

审的是：代码
触发（任一种）：
- 读到：自定义块 extends AppCompatButton / Button，只调 setBackgroundResource 换背景，没有 setStateListAnimator(null) 或 setElevation(0)；写错的样子：目标组件只有背景色和圆角，没有 .shadow(...)
适用范围：继承按钮的自定义块迁成 ArkUI 组件时，应用主题是按钮带 stateListAnimator 的 Material / AppCompat 一族
不适用的情形：源码有 setStateListAnimator(null)、setElevation(0) 或用了 borderless 样式时，没有这份默认投影
做法：
- 给组件加 .shadow({ radius: …, offsetY: …, color: … })，数值按源端按钮样式的静止态 elevation 推出，dp 来源的数先 vp2px 换算成 px
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- shadow(value: ShadowOptions | ShadowStyle): T；ShadowOptions 的 radius、offsetX、offsetY 单位是 px：组件投影（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.shadow、ShadowOptions）
- button_elevation_material = 2dp，button_pressed_z_material = 4dp：平台 Material 按钮静止态投影 2dp，按下再抬 4dp（出处：Android SDK 平台资源 data/res/values/dimens_material.xml，button_elevation_material、button_pressed_z_material（按应用的 compileSdk 取对应平台））
- 返修加了按钮投影常量和 .shadow：修好后补上投影（出处：卡里修好并验证过）
针对本应用要查的：
- 按钮的静止态 elevation：源工程主题 XML 里 buttonStyle 的取值，顺着 style parent 找到 android:stateListAnimator 指向的动画文件和它引用的 dimen；读出启用态的 elevation（dp），换算后写进 ShadowOptions；例：AppCompat 主题、v21 以上是 2dp
未核实：卡里没给投影常量的具体数值和 ShadowOptions 写法
