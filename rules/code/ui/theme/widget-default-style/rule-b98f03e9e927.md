# 未声明颜色的 TextView 转成 Text 时，显式写 fontColor 取主题次要文字色

审的是：代码
触发（任一种）：
- 读到：TextView 没写 android:textColor、android:textAppearance、style，主题继承 Theme.AppCompat / Theme.Material；写错的样子：.fontColor(...) 绑主文字色（textColorPrimary、#DE000000），或链上没有 .fontColor(...)
- 读到：同一适配器的另一个行布局显式写了 android:textColor="@android:color/black"；写错的样子：没写颜色的子项 Text 也写成黑色 fontColor
适用范围：源 TextView 的字色只来自控件默认样式和主题，迁成 ArkUI Text 时
不适用的情形：EditText、Button 等控件默认 textAppearance 不同，各自解析；TextView 显式 textAppearance 指向主文字色时用主文字色
做法：
- 先查主题（含 values-night）有没有覆盖 textViewStyle、textAppearanceSmall、textColorTertiary / Secondary；没覆盖就走默认链 Widget.TextView → ?attr/textAppearanceSmall → ?attr/textColorTertiary
- Text 显式写 .fontColor($r('app.color.<次级文字色>'))，base / dark 成对（浅色 #8A000000、深色 #B3FFFFFF），字号 14；不留空，也不套 textColorPrimary
- 同一列表里组头显式写的颜色只用在组头，不外推到没写颜色的子项
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Widget.TextView：textAppearance = ?attr/textAppearanceSmall；Widget.Material.TextView 和 AppCompat 的 Base.Widget.AppCompat.TextView 都继承 Widget.TextView：TextView 没写 textAppearance/style 时，文字外观取主题的 textAppearanceSmall（出处：Android SDK 平台资源 data/res/values/styles.xml，Widget.TextView；data/res/values/styles_material.xml，Widget.Material.TextView（按应用的 compileSdk 取对应平台）；androidx.appcompat:appcompat 包内 res/values/values.xml，Base.Widget.AppCompat.TextView（按应用依赖的版本））
- Theme.Material.Light：textAppearanceSmall = TextAppearance.Material.Small（textSize 14sp，textColor ?attr/textColorTertiary）；textColorTertiary = @color/secondary_text_material_light（Theme.Material 为 secondary_text_material_dark）：Material 主题（AppCompat 浅色主题在 API 21+ 的父主题是 android:Theme.Material.Light.NoActionBar）下的缺省字号和字色属性（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material.Light；data/res/values/styles_material.xml，TextAppearance.Material.Small；androidx.appcompat:appcompat 包内 res/values-v21/values-v21.xml，Platform.V21.AppCompat.Light（按应用依赖的版本））
- Base.TextAppearance.AppCompat.Small：android:textColor = ?android:attr/textColorTertiary；AppCompat 浅色主题 android:textColorTertiary = @color/abc_secondary_text_material_light（深色为 abc_secondary_text_material_dark）：AppCompat 下 textAppearanceSmall 的字色属性和选择器（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Base.TextAppearance.AppCompat.Small、Platform.AppCompat.Light 的 android:textColorTertiary（按应用依赖的版本））
- secondary_text_default_material_light = #8a000000；secondary_text_default_material_dark = #b3ffffff：次级文字色选择器默认（可用）状态的浅色、深色值（出处：Android SDK 平台资源 data/res/values/colors_material.xml，secondary_text_default_material_light / _dark；appcompat 包内 res/values/values.xml 同名颜色）
- TextAppearance.Small：textSize 14sp，textColor ?textColorSecondary：非 Material 老主题下 textAppearanceSmall 的文字色（出处：Android SDK 平台资源 data/res/values/styles.xml，TextAppearance.Small（按应用的 compileSdk 取对应平台））
- Theme.Material.Light 的 editTextColor = ?attr/textColorPrimary，primary_text_default_material_light #de000000：EditText 才取主文字色（出处：Android SDK 平台资源 data/res/values/themes_material.xml，editTextColor；values/colors_material.xml，primary_text_default_material_light（按应用的 compileSdk 取对应平台））
- fontColor(value: ResourceColor): TextAttribute，默认值 '#e6182431'：Text 的文字色；不写时用这个近黑默认色（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.fontColor）
- 未设色 TextView 全部改绑次文字色 token 后与源端一致；白底上实测色 #757575（117,117,117，即 #8A000000 叠白）：卡里修好的写法和核对用的观察值（出处：卡里修好并验证过）
针对本应用要查的：
- 主题有没有覆盖默认链上的属性，未写颜色的 TextView 的实际字色：源工程 AndroidManifest.xml 里 application / activity 的 android:theme，到 res/values*/（含 values-night）的 styles.xml、themes.xml 顺 parent 链找 textViewStyle、android:textAppearanceSmall、android:textColorTertiary、android:textColorSecondary；没覆盖的到 Android SDK 平台资源 themes_material.xml 和 appcompat 包内 values.xml；有覆盖就顺着 style → ?attr → @color 解析到色值，浅、深色各取一份；都没覆盖就取主题族默认（例：继承 Theme.AppCompat.Light / DayNight 且都没覆盖时，浅色 #8A000000、夜间 #B3FFFFFF）
未核实：卡里没记安卓 compileSdk 和 appcompat 版本，取值按本机 android-36 平台资源和 appcompat 1.7.1 核实
