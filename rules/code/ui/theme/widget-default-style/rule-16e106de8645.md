# Button 只显式写了背景、字色、字号时，其余 Widget 默认外观逐项补齐

审的是：代码
触发（任一种）：
- 读到：源 `<Button>` 在 `Theme.AppCompat` 主题下只写了 `android:background`（无 pressed 态的 shape）、`android:textColor`、`android:textSize` 等部分属性，没写 `style=`、`android:textAllCaps`、`android:fontFamily`、`android:stateListAnimator`、`android:elevation`；写错的样子：目标 `Button` 只有 `fontSize`、`fontColor`、背景和 `borderRadius`：文字没转大写、没有 `FontWeight.Medium`、没有投影，按压沿用默认 `stateEffect` 变暗
适用范围：安卓 Button / AppCompatButton 迁成 ArkUI Button，且源控件只覆写了部分外观属性时
做法：
- 按下面的查法列出控件默认样式的属性清单，和源 XML 已声明的属性做差集，差集逐项落实；部分属性显式不等于整控件显式
- 写成 Button({ type: ButtonType.Normal, stateEffect: false }) { Text(文字).fontWeight(FontWeight.Medium) }，文字按当前 locale 转大写；常态 2dp 投影，stateStyles 的 pressed 里换成 6dp 投影（stateEffect:false 只在源背景无 pressed 态时）
- 父布局 clipToPadding 是默认 true 时，给按钮组容器加 .clip(true)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- AppCompat 主题的 buttonStyle 是 Widget.AppCompat.Button；API 21+ 下 Base.Widget.AppCompat.Button 的 parent 是 android:Widget.Material.Button：AppCompat 主题下按钮默认样式最终落到平台的 Widget.Material.Button（出处：androidx.appcompat:appcompat 包内 res/values/values.xml 的 buttonStyle、res/values-v21/values-v21.xml 的 Base.Widget.AppCompat.Button（按应用依赖的版本））
- Widget.Material.Button：minHeight 48dip、minWidth 88dip、stateListAnimator = @anim/button_state_list_anim_material：按钮默认最小尺寸和投影动画（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.Button（按应用的 compileSdk 取对应平台））
- TextAppearance.Material.Button：textAllCaps = true，fontFamily = sans-serif-medium（font_family_button_material）：默认全大写、Medium 字重（出处：Android SDK 平台资源 data/res/values/styles_material.xml，TextAppearance.Material.Button；data/res/values/donottranslate_material.xml，font_family_button_material）
- 常态 elevation = button_elevation_material（2dp）；按下另加 translationZ = button_pressed_z_material（4dp）；禁用时都为 0：所以常态 2dp 投影、按下 6dp 投影（出处：Android SDK 平台资源 data/res/anim/button_state_list_anim_material.xml；data/res/values/dimens_material.xml，button_elevation_material、button_pressed_z_material）
- stateEffect(value: boolean): ButtonAttribute；ButtonOptions.stateEffect?: boolean，false 时关闭按下的切换效果：源背景没有 pressed 态时关掉 ArkUI 默认的按压变暗（出处：鸿蒙 SDK 的 ets/component/button.d.ts，ButtonAttribute.stateEffect）
- textAllCaps 由 AllCapsTransformationMethod 按当前 locale 转大写（TextUtils.toUpperCase(locale, …)）：全大写要随语言规则转换，不是简单的 ASCII 大写（出处：android.text.method.AllCapsTransformationMethod#getTransformation）
- Button({ type: Normal, stateEffect: false }) { Text().fontWeight(Medium) } 加 2dp / 按压 6dp 投影、按钮组 clip(true)，全大写改为按 locale 后与源端一致：返修后保留的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 源 Button 实际套用的默认样式：源工程 res/values*/styles.xml 里应用或 Activity 主题的 parent 链 → 主题的 buttonStyle（AppCompat 在 appcompat 包内 res/values/values.xml，API 21+ 看 res/values-v21/values-v21.xml）→ 平台 data/res/values/styles_material.xml 的对应 Widget 样式；读出 textAppearance（textAllCaps、fontFamily、textSize）、stateListAnimator、minHeight / minWidth，和源 XML 已写的属性做差集。例：Theme.AppCompat.* 在 API 21+ 下是 Widget.Material.Button，全大写、sans-serif-medium、2dp 投影按下 +4dp、最小 48×88dp
未核实：2dp / 6dp elevation 换成 ShadowOptions 的哪组 radius、offset，卡里没写；卡里只写全大写最终改为按 locale，没写用的是哪个接口
