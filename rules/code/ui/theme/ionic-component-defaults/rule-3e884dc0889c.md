# 翻译 Ionic 组件时三层样式合并后再写 ArkUI，-reverse 容器按渲染序排子组件

审的是：代码
触发（任一种）：
- 读到：源端 setupIonicReact({ mode: 'ios' })，IonCardHeader 里 DOM 序是 IonCardSubtitle → IonCardTitle，inline style 只写了 fontSize；写错的样子：目标按 DOM 序先写副标题 Text 再写标题 Text；副标题没有 .textCase(TextCase.UpperCase)、.fontWeight(...)、.letterSpacing(...)；卡片只有 .borderRadius(...)，没有 .shadow(...)
适用范围：界面实现阶段把 Ionic 组件翻译成 ArkUI 的 Column / Text 结构时
做法：
- 按「组件 mode 的 host 样式 → 应用 css → inline style」三层合并出最终样式再写；容器 flex-direction 是 *-reverse 时按渲染序排子组件，并在注释里写出依据的 css 规则
- 对应写法：text-transform: uppercase → .textCase(TextCase.UpperCase)；font-weight: 700 → .fontWeight(FontWeight.Bold)；letter-spacing: Npx → .letterSpacing(N)；卡片的圆角、阴影写 .borderRadius(...) 和 .shadow(...)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- textCase(value: TextCase): TextAttribute，默认 TextCase.Normal：Text 的大小写（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.textCase）
- TextCase.UpperCase：全部大写，对应 text-transform: uppercase（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，TextCase.UpperCase）
- FontWeight.Bold：等于数值 700：对应 font-weight: 700（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，FontWeight.Bold）
- letterSpacing(value: number | ResourceStr): TextAttribute；number 的单位是 fp，默认 0：字距（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.letterSpacing；ts-basic-components-text.md，letterSpacing）
- textCase(value: TextCase): SpanAttribute：同族接口：Span 的大小写（出处：鸿蒙 SDK 的 ets/component/span.d.ts，SpanAttribute.textCase）
- 日期行补 textCase(UpperCase) + Bold + letterSpacing(0.4)；卡片改圆角 8 加阴影；交换标题和副标题的渲染序并注明 column-reverse；标题补 Bold：卡里的修法（出处：卡里修好并验证过）
针对本应用要查的：
- 组件 mode 的 host 样式：源工程 node_modules/@ionic/core/dist/collection/components/<组件>/<组件>.<mode>.css 的 :host 规则；和应用 css、inline style 合并，取每个属性最后生效的值
