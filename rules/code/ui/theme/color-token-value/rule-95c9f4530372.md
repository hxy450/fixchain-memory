# 代码里 Color.GREEN 等框架颜色常量按色值对令牌，没有同值令牌就新增

审的是：代码
触发（任一种）：
- 读到：Java / Kotlin 里 setTextColor(Color.GREEN)、Color.RED 等 android.graphics.Color 常量；写错的样子：目标对应处写 $r('app.color.…') 引用名字相近但色值不同的令牌（如淡绿），报告说是规格指定的令牌
适用范围：把 android.graphics.Color 常量着色迁成 ArkUI fontColor / backgroundColor 等时
做法：
- 按常量的 ARGB 值找同值令牌；没有就在 resources/base/element/color.json 新增一个该值的颜色（如 #FF00FF00）再用 $r('app.color.<新令牌>') 引用
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- RED 0xFFFF0000、GREEN 0xFF00FF00、BLUE 0xFF0000FF、YELLOW 0xFFFFFF00、CYAN 0xFF00FFFF、MAGENTA 0xFFFF00FF、BLACK 0xFF000000、WHITE 0xFFFFFFFF、GRAY 0xFF888888：常用框架颜色常量的 ARGB 值（出处：android.graphics.Color 的常量（RED、GREEN …））
