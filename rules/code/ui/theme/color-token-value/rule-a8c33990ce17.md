# 把字面色值换成 $r('app.color.*') 时，引用条目的 value 要等于原色值，没有就先补

审的是：代码
触发（任一种）：
- 读到：代码或源端里是字面色值（8 位 '#AARRGGBB' 串、Color(0xAARRGGBB)），工程要求颜色一律走 $r('app.color.*')，而 color.json 里没有同值的条目；写错的样子：换成了名称相近或同为品牌色的已有令牌 $r('app.color.…')，它在 color.json 里的 value 和原色值不同
适用范围：去掉渐变、背景、文字等处的颜色裸值，改成资源引用时
做法：
- 每个要替换的色值，先在 resources/base/element/color.json 里查候选名称的 value，和原色值逐位比（8 位十六进制，前两位是透明度，不分大小写），相等才引用
- 找不到同值条目时，先按源端调色板的名字在 color.json 新增同值条目，再写 $r('app.color.新名字')；不借用名称相近或同为品牌色的已有令牌
- 改完对 diff 里新增的每个 $r('app.color.*') 做一次「名称 → color.json 的 value → 源色值」对账
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- color.json 的 value 是 8 位十六进制，前两位透明度、后六位颜色：源端 0xAARRGGBB 去掉 0x 就是同一个值，可以逐位比（出处：resource-categories-and-access.md，资源文件示例）
- 按调色板名新增色阶条目并改引用后，渐变各色阶恢复成源端颜色：借用值不同的已有令牌会改掉色阶，整套渐变变色（出处：卡里修好并验证过）
针对本应用要查的：
- 源端调色板每个名字的色值：源工程主题目录下定义颜色常量的 Kotlin 文件，按 val 名字 = Color(0x…) 找；0xAARRGGBB 去掉 0x 写成 #aarrggbb，和 color.json 里候选条目的 value 比
