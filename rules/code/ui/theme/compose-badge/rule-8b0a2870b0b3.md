# 源角标是 Text(count.toString()) 时，ArkUI Badge 显式写 maxCount 和字色字号

审的是：代码
触发（任一种）：
- 读到：Compose `Badge(containerColor = …) { Text(count.toString()) }`（在 BadgedBox 里）；写错的样子：ArkUI `Badge({ count, style: { badgeColor } })` 没写 maxCount（超过 99 显示 99+），字色、字号、badgeSize 用默认；或者自绘文本加 offset 当角标
适用范围：源端 M3 Badge 显示完整计数，迁成 ArkUI Badge 时
做法：
- 写 Badge({ count: <计数>, maxCount: <不小于计数上限>, style: { badgeColor: <源 containerColor>, color: <源内容色，tertiary 容器配 onTertiary>, fontSize: <源字号>, badgeSize: <源角标高> } })
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- (value: BadgeParamWithNumber): BadgeAttribute：数字角标的构造，参数里有 count、maxCount、position、style（出处：鸿蒙 SDK 的 ets/component/badge.d.ts，BadgeInterface）
- maxCount 的 @default 是 99，超过时只显示 maxCount+：不写 maxCount 时大计数被截成 99+（出处：鸿蒙 SDK 的 ets/component/badge.d.ts，BadgeParamWithNumber.maxCount）
- BadgeStyle.color 默认 Color.White；badgeColor 默认 Color.Red：字色和底色都要按源端显式写（出处：鸿蒙 SDK 的 ets/component/badge.d.ts，BadgeStyle.color、BadgeStyle.badgeColor）
- BadgeStyle.fontSize 默认 10，单位 fp；badgeSize 默认 16，单位 vp：源端 sp、dp 值照数值填（出处：鸿蒙 SDK 的 ets/component/badge.d.ts，BadgeStyle.fontSize、BadgeStyle.badgeSize）
- Badge 全量计数 + onTertiary 字色：修复后的角标，复审通过（出处：卡里修好并验证过）
- (value: BadgeParamWithString): BadgeAttribute：同族接口：文字角标的构造，value 是 ResourceStr（出处：鸿蒙 SDK 的 ets/component/badge.d.ts，BadgeInterface）
针对本应用要查的：
- 源角标的字号和高度：该 material3 版本 Badge 的默认 tokens（源码没写时）；源码里 Text 显式写了 style 的看那个 style；读出字号（sp）和带数字角标的高度（dp），填进 fontSize、badgeSize。例：compose-bom 2026.08.00 下修复取 11fp、16vp
未核实：卡里的行为出自鸿蒙 SDK API 24，本机核实用的是 API 23
