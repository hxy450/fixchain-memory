# LargeFloatingActionButton 图标按 36vp、取容器内容色，不加写死语言的无障碍文案

审的是：代码
触发（任一种）：
- 读到：Compose 源用 LargeFloatingActionButton，Icon 尺寸 FloatingActionButtonDefaults.LargeIconSize，tint 没写或被注释掉（取默认内容色），contentDescription = null；容器色在 primaryContainer 和 primary 间切换；写错的样子：目标图标写成 SymbolGlyph().fontSize(24)、固定 primary 或其他写死颜色，并加写死中文的 accessibilityText
适用范围：把 Material3 LargeFloatingActionButton 迁成 ArkUI 按钮时
做法：
- 容器按大号 FAB 写 96 的尺寸，图标写 36vp（LargeIconSize）；图标色取容器对应的内容色：容器 primaryContainer 时用 onPrimaryContainer，容器 primary 时用 onPrimary
- 源端 contentDescription = null 时不加写死语言的 accessibilityText；需要时用资源字符串 accessibilityText($r('app.string.…'))
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- LargeIconSize = 36vp；大号 FAB 容器 96：大号 FAB 的图标槽和容器尺寸（出处：卡里修好并验证过）
- fontSize(value: number | string | Resource): SymbolGlyphAttribute：SymbolGlyph 图标的尺寸（出处：鸿蒙 SDK 的 ets/component/symbolglyph.d.ts，SymbolGlyphAttribute.fontSize）
- fontColor(value: Array<ResourceColor>): SymbolGlyphAttribute：SymbolGlyph 图标的颜色（出处：鸿蒙 SDK 的 ets/component/symbolglyph.d.ts，SymbolGlyphAttribute.fontColor）
- accessibilityText(text: Resource): T：CommonMethod 的无障碍文本可以传资源字符串（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.accessibilityText）
未核实：LargeIconSize = 36dp、大号 FAB 96 出自卡，本机只有 material3 编译产物，没查到原文
