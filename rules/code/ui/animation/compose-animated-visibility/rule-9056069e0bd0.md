# fadeIn / fadeOut 包住的块要加 OPACITY 弹簧转场，不用 if 瞬显

审的是：代码
触发（任一种）：
- 读到：AnimatedVisibility(enter = fadeIn(), exit = fadeOut()) 包住徽标等小块；写错的样子：目标对应块只用 if 条件渲染，没有 .transition(TransitionEffect.OPACITY…)
适用范围：源端用 fadeIn / fadeOut 做可见性动画的块
做法：
- 块上加 .transition(TransitionEffect.OPACITY.animation({ curve: curves.springMotion(2 * Math.PI / Math.sqrt(400), 1.0) }))
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- static readonly OPACITY: TransitionEffect<"opacity">：透明度转场（出处：鸿蒙 SDK 的 ets/component/common.d.ts，TransitionEffect.OPACITY）
- 徽标改成弹簧淡入淡出：修好后的写法（出处：卡里修好并验证过）
