# 后写的一端与已写好的一端配对时，核对对方的键和有无嵌套，发现嵌套不照样镜像

审的是：代码
触发（任一种）：
- 读到：已写好的对端文件里外层容器有 .geometryTransition(`${id}-bounds`)，它的子组件里又有 .geometryTransition(id)；写错的样子：后写的一端照样镜像成外层加内层两处 .geometryTransition，交回报告里没提对端嵌套
适用范围：共享转场的两端由不同写者先后完成，后写者读对端代码来配对时
做法：
- 读对端时同时核对它用的键，以及同一配对子树里有没有第二个 geometryTransition
- 对端嵌套了第二对的，本端只按外层那一个键配对，并在交回报告（handback）里写明对端嵌套、需要删掉内层那对
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 同一个 id 只能有两个组件绑定，且是 in/out 不同角色：两端各一个组件用同一个键（出处：ts-transition-animation-geometrytransition.md，geometryTransition）
