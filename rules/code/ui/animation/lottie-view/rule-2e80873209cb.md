# 源布局有 LottieAnimationView 或按状态切动画时，目标接 @ohos/lottie 并迁动画文件

审的是：代码
触发（任一种）：
- 读到：布局里有 `com.airbnb.lottie.LottieAnimationView`（常与静态 ImageView 同尺寸叠在一起），代码调用 setAnimation("json/...") 或按数据状态切换动画；写错的样子：ArkTS 只写一张静态 Image($r('app.media.x')) 作为唯一的图，没有 Lottie 动画层、@ohos/lottie 依赖、迁过来的 json 文件，也没有占位登记
适用范围：安卓界面里由 Lottie 播放的动画层迁到 ArkUI 时
做法：
- 接入 @ohos/lottie（import lottie from '@ohos/lottie'），在 Canvas 上加载动画，叠在静态背景图之上，尺寸照源布局
- 把源端 assets/json 下用到的动画文件迁进目标工程，按源码复刻「状态 → 动画文件」的选择表
- 这一处做不完时登记占位，不用静态兜底图静默替代
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- import lottie from '@ohos/lottie'：在 Canvas 上加载 Lottie 动画前要先装这个三方库（出处：arkts-drawing-customization-on-canvas.md，使用画布组件绘制自定义图形）
- lottie_fileName（string）、lottie_rawRes（reference）、lottie_autoPlay（boolean）、lottie_loop（boolean）：LottieAnimationView 在布局里指定动画文件和播放方式的属性，动画来源也可能写在这里（出处：com.airbnb.android:lottie 包内 res/values/values.xml，LottieAnimationView 的 lottie_fileName 等（按应用依赖的版本））
针对本应用要查的：
- 每个状态对应的动画文件：源工程里调用 setAnimation 的代码（常在按状态 switch/when 分支的工具方法里），以及布局里 LottieAnimationView 的 app:lottie_fileName / app:lottie_rawRes；逐个状态读出 json 路径，连同文件一起迁进目标工程，选择表照搬
