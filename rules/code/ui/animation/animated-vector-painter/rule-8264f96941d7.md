# rememberAnimatedVectorPainter 按 atEnd 切帧时，目标按同一状态分支给起点和终点图形

审的是：代码
触发（任一种）：
- 读到：Compose 里 rememberAnimatedVectorPainter(AnimatedImageVector.animatedVectorResource(R.drawable.…), atEnd)，atEnd 由步骤完成、计时运行等状态决定；写错的样子：各状态都写同一个 Image($r('app.media.…'))（资源迁移导出的同名静态 SVG），atEnd 的状态条件没有落到输出
适用范围：Compose 的 AnimatedImageVector（源 XML 是 animated-vector）按状态显示起点或终点帧，迁成 ArkUI 时
做法：
- 读 atEnd 由哪个状态决定，读源 XML 里 objectAnimator 的 valueFrom（起点帧）和 valueTo（终点帧）；打开同名媒体核对它画的是哪一帧，只含起始帧的静态 SVG 不能代表所有状态
- 按同一状态分支切图形：<atEnd 的条件> ? <终点帧图形> : <起点帧图形>；规格写了 equivalent symbol animation 时选语义相符的 SymbolGlyph($r('sys.symbol.…'))，或把终点 path 画成独立图形
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 完成态写 SymbolGlyph($r('sys.symbol.checkmark_circle_fill'))，播放 FAB 写 SymbolGlyph($r('sys.symbol.play_fill'))：修好后用系统 symbol 代替只含起始帧的静态 SVG（出处：卡里修好并验证过）
- SymbolGlyph(this.isPause ? $r('sys.symbol.pause') : $r('sys.symbol.play_fill'))：按状态在播放、暂停两个系统 symbol 之间切换的写法（出处：arkts-common-components-video-player.md，其他说明）
- (value?: Resource): SymbolGlyphAttribute：SymbolGlyph 传系统 symbol 资源 $r('sys.symbol.…')（出处：鸿蒙 SDK 的 ets/component/symbolglyph.d.ts，SymbolGlyphInterface）
- fontColor(value: Array<ResourceColor>): SymbolGlyphAttribute：SymbolGlyph 的颜色传数组（出处：鸿蒙 SDK 的 ets/component/symbolglyph.d.ts，SymbolGlyphAttribute.fontColor）
- valueFrom 是动画起始值，valueTo 是动画终止值；valueType="pathType" 表示值是 path 字符串，用于 AnimatedVectorDrawable 的 path morphing：起点帧看 valueFrom（或内嵌 vector 的 pathData），终点帧看 valueTo（出处：Android SDK 平台资源 data/res/values/attrs.xml，Animator 的 valueFrom、valueTo、valueType（按应用的 compileSdk 取对应平台））
- AnimatedVectorDrawable 的 android:drawable 是静态 vector：从它导出的 SVG 只是起点帧（出处：Android SDK 平台资源 data/res/values/attrs.xml，AnimatedVectorDrawable 的 drawable（按应用的 compileSdk 取对应平台））
- (value: Resource): SymbolSpanAttribute：同族接口：文字里内嵌系统 symbol 用 SymbolSpan（出处：鸿蒙 SDK 的 ets/component/symbol_span.d.ts，SymbolSpanInterface）
针对本应用要查的：
- 起点帧和终点帧各画的是什么：源工程 res/drawable 下 animated-vector 的 XML，以及它的 <target> 引用的 objectAnimator（内联的 <aapt:attr> 或 res/animator 下的文件）；内嵌 vector 的 pathData 或 objectAnimator 的 valueFrom 是起点，valueTo 是终点；读出图形含义（如播放三角→暂停竖条、三角→圆内对勾），选语义相符的系统 symbol
