# 吸顶分支里判断内容是否超出视口时，测量挂在 ListItemGroup 上把头部一起算

审的是：代码
触发（任一种）：
- 读到：源端 LazyColumn 带 stickyHeader，外层折叠顶栏有「内容未满不折叠」一类判断（如 enabledWhenBodyUnfilled = false）；写错的样子：吸顶分支里决定是否折叠的内容高度测量只挂在 ListItem 里的 Column 上，没把 ListItemGroup 的 header 算进去
适用范围：stickyHeader 已迁成 ListItemGroup header 的吸顶分支里，依赖内容高度是否超出视口的逻辑
做法：
- 把内容高度的测量从 ListItem 内的容器移到 ListItemGroup（或同时包住头部和其余项的容器）上，判断用这个总高度
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 内容高度测量从 ListItem 内的 Column 移到 ListItemGroup 后，「内容未满不折叠」的判断计入头部，编译通过、真机复核：修好的测量口径（出处：卡里修好并验证过）
未核实：enabledWhenBodyUnfilled 出自哪个公共库，本机没查到
来源：1 张卡，1 个应用
