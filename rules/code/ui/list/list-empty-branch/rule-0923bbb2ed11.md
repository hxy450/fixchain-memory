# 截图空态文案落在并列列表区域时，在列表组件的空数据分支里显示 Text

审的是：代码
触发（任一种）：
- 读到：页面由图表与固定宽度的侧栏并列组成（图表 `layoutWeight` 撑满、侧栏放五档或明细列表）；截图里空态文案位于侧栏区域，列表有 empty view 或空态字符串的引用；写错的样子：目标的列表组件在数据为空时什么都不显示（只有 `ForEach` / `List`，没有 `if` 空数据分支），空态文案却出现在别的组件里
适用范围：按参考截图补空态，文案按布局归属于与图表并列的列表组件时
做法：
- 在列表组件的构建函数里加空数据分支：if (<列表数据>.length === 0) { Text(<空态文案>) 居中 } else { 原来的列表 }，列表数据用状态变量
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- if / else if 的条件可以用状态变量或常规变量；状态变量变化时实时重新渲染，常规变量变化不会：空数据分支的条件要用状态变量，数据到达后才会切回列表（出处：arkts-rendering-control-ifelse.md，使用规则）
- 列表数据为空时显示居中的 Text 空态文案，与参考截图一致：空态文案放在它所属的列表组件里（出处：卡里修好并验证过）
针对本应用要查的：
- 源端列表空态显示什么、放在哪：源工程里这个列表的布局 XML（empty view、空态字符串的 @string 引用）和填充列表的代码里数据为空的分支；读出空态文案（取字符串资源的值）和它的位置，迁到目标列表组件的空数据分支
未核实：卡里没有读到安卓成交明细列表空态实现的记录，源端列表空态的具体写法未核
