# 列表区域的空数据分支

agent 会看到什么：读到页面里图表与侧栏列表并列、截图里空态文案在列表区域，列表有 empty view 或空态字符串；交回的 List / ForEach 没有 if 空数据分支，空态文案放在了别的组件里

## 规矩

- rule-0923bbb2ed11｜截图空态文案落在并列列表区域时，在列表组件的空数据分支里显示 Text｜读到：页面由图表与固定宽度的侧栏并列组成（图表 `layoutWeight` 撑满、侧栏放五档或明细列表）；截图里空态文案位于侧栏区域，列表有 empty view 或空态字符串的引用；写错：目标的列表组件在数据为空时什么都不显示（只有 `ForEach` / `List`，没有 `if` 空数据分支），空态文案却出现在别的组件里
