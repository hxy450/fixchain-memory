# SwitchPreference 的开关不可点：目标开关设 hitTestBehavior(None)，由整行切换

审的是：代码
触发（任一种）：
- 读到：SwitchPreference（框架 preference_widget_switch 里的 Switch 写着 android:clickable="false"）；写错的样子：行内 Toggle 自身可点，整行 .onClick 也切换：Toggle 的 onChange 和行 onClick 两条路径，靠同值守卫去重
适用范围：SwitchPreference 迁成「整行 + 右侧开关」的设置行时
做法：
- 开关组件（自绘或 Toggle）加 .hitTestBehavior(HitTestMode.None)，不再接自己的 onChange；整行 .onClick 里把状态取反并写回偏好，只留这一条点击路径
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- <Switch android:focusable="false" android:clickable="false" />：SwitchPreference 右侧的开关自身不接收点击和焦点，点击由整行处理（出处：Android SDK 平台资源 data/res/layout/preference_widget_switch.xml，Switch（按应用的 compileSdk 取对应平台））
- hitTestBehavior(value: HitTestMode): T：设置组件在触摸命中测试中的行为，默认 HitTestMode.Default（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.hitTestBehavior）
- HitTestMode.None：自身不响应触摸命中测试，子节点仍响应：开关不接点击，点击落到外层整行（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，HitTestMode.None）
