# 设置页出现时按偏好 XML 顺序缺键写默认值并落盘，不只在读取时回退默认

审的是：代码
触发（任一种）：
- 读到：PreferenceFragment 里 addPreferencesFromResource(R.xml.x)，偏好 XML 带 android:defaultValue；写错的样子：目标设置页 aboutToAppear 里只用 getSync(key, 默认值) 读回默认值，没有 putSync 写入、也没 flush
适用范围：源端 PreferenceScreen 设置页迁成 ArkUI 设置页、偏好迁成 @ohos.data.preferences 时
做法：
- 设置页出现时按 XML 顺序逐键判断：!prefs.hasSync(key) 时 prefs.putSync(key, 默认值)，全部写完 prefs.flushSync()
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- putSync(key: string, value: ValueType): void；写进缓存的 Preferences 实例，调 flush 才存到文件：写默认值（出处：鸿蒙 SDK 的 ets/api/@ohos.data.preferences.d.ts，Preferences.putSync）
- flushSync(): void（@since 14）：把实例存到文件（出处：鸿蒙 SDK 的 ets/api/@ohos.data.preferences.d.ts，Preferences.flushSync）
- 设置页出现时按 XML 顺序补写四个缺失键后与源端一致：修法（出处：卡里修好并验证过）
针对本应用要查的：
- 要补写的键、默认值和顺序：源工程 res/xml 下被 addPreferencesFromResource 加载的偏好 XML；按出现顺序读出 android:key、android:defaultValue 和值类型
