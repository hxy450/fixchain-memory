# 带 android:icon 的 Preference 写成 48dp 图标框加标题，不加源端没有的尾部箭头

审的是：代码
触发（任一种）：
- 读到：res/xml 里 <Preference android:icon="@drawable/…">，没有任何箭头元素；派工或转换表写「箭头行」；写错的样子：行尾加了 Text('›') 或 chevron 箭头 Image；图标按 24vp 画
适用范围：PreferenceActivity 里带图标的普通 Preference 迁成 ArkUI 列表行时
做法：
- 行内只放图标框和标题：图标框 48×48、图标按固有尺寸居中（ImageView centerInside），图标右侧留 8dp
- 源 XML 里没有的元素，派工或转换表提到也不加，按源移除并在报告里回报冲突
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ImageView android:layout_width="48dp" android:layout_height="48dp" android:scaleType="centerInside" android:layout_marginEnd="@dimen/preference_item_padding_inner"（8dip）：偏好行的图标框（出处：Android SDK 平台资源 data/res/layout/preference_holo.xml，@android:id/icon（按应用的 compileSdk 取对应平台））
- ImageFit.ScaleDown：保持宽高比，图片缩小或保持不变：对应 centerInside，图标不放大（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，ImageFit.ScaleDown）
