# ListView 用主题分隔线时，每个 ListItem 末尾加 Divider，末行那条按底边条件显示

审的是：代码
触发（任一种）：
- 读到：<ListView> 没写 android:divider，主题 listDivider 隐式画行间线（如 Theme.Holo 的 list_divider_holo_dark）；写错的样子：List 的 ForEach 行里没有 Divider，也没有 .divider(...)；color.json 里没有列表分隔线颜色
- 读到：源 <ListView> 或 ListActivity 没声明 android:divider，分隔线来自主题 listDivider；写错的样子：List 上写 .divider({ strokeWidth: …, color: … })，ListItem 里没有 Divider()，也没有末行那条的条件
适用范围：源端 ListView（含 ListActivity）没声明 android:divider、用主题 listDivider，迁成 ArkUI List 时
做法：
- List 上不写 divider；每个 ListItem 内容末尾加 Divider().strokeWidth(<分隔线高度 vp>).color($r('app.color.…'))，粗细和颜色取源值
- 末行那条只在末行底边 < List 高度时显示：末行和 List 各用 .onAreaChange((oldValue, newValue) => …) 记下底边和高度；行序会变时，ForEach 的键里带上判断末行要用的 index
- 在 resources/base/element/color.json 新增这条分隔线的颜色键（Theme.Holo 暗色是 #26FFFFFF）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- List 的分割线画在主轴方向两个子组件之间，第一个上方和最后一个下方不画：只写 List.divider 会丢末行之后那条（出处：ts-container-list.md，divider）
- if (drawDividers && (bottom < listBottom) && !(drawOverscrollFooter && isLastItem))：源端末行之后也画线，条件是末行底边低于列表底边（出处：android.widget.ListView#dispatchDraw）
- strokeWidth(value: number | string): DividerAttribute：Divider 线宽，number 单位 vp，默认 1px；要显式写源端高度（出处：鸿蒙 SDK 的 ets/component/divider.d.ts，DividerAttribute.strokeWidth；ts-basic-components-divider.md，strokeWidth）
- color(value: ResourceColor): DividerAttribute：Divider 颜色，默认 '#33182431'；要显式写源端颜色（出处：鸿蒙 SDK 的 ets/component/divider.d.ts，DividerAttribute.color；ts-basic-components-divider.md，color）
- onAreaChange(event: (oldValue: Area, newValue: Area) => void): T：取末行底边和 List 高度用的区域变化回调（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onAreaChange）
- 每行末尾 Divider().strokeWidth(0.76).color(<分隔线色>)，配 color.json 新增 #26FFFFFF，与 Theme.Holo 暗色源端一致：Theme.Holo 暗色、xxhdpi 下的实际写法（出处：卡里修好并验证过）
- 删掉 List.divider；每个 ListItem 内容下方一条 Divider；末行那条仅在 lastRowBottom < listViewHeight 时显示（Theme.Material.Light 下 1vp、#1F000000）：返修后两端分隔线条数和位置一致的写法（出处：卡里修好并验证过）
- divider(value: ListDividerOptions | null): ListItemGroupAttribute：同族接口：ListItemGroup 的分割线，同样用 ListDividerOptions；是否画末项之后卡里没验证（出处：鸿蒙 SDK 的 ets/component/list_item_group.d.ts，ListItemGroupAttribute.divider）
针对本应用要查的：
- 分隔线的颜色和高度：源工程主题的 parent → 对应平台 data/res/values/themes_*.xml 的 listDivider → data/res/drawable-<密度>/ 下的图；读像素颜色和高度，px 除以密度系数得 vp 填进 strokeWidth
- 源端框架默认外观的绘制规则（画几条、画在哪）：Android SDK 框架源码 android/widget/ListView.java 的 dispatchDraw（按应用的 compileSdk 取对应版本）；读出画线的条件，和目标组件同名属性的文档对照，不按名字相同推定两者等价
