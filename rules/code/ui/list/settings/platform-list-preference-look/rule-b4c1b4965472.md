# 复刻偏好对话框时，尺寸、字号、颜色和图片从 SDK 的平台布局与主题取，不凭记忆自拟

审的是：代码
触发（任一种）：
- 读到：<EditTextPreference> / <ListPreference> 由框架弹平台对话框，应用主题是 Theme.Holo 一族；写错的样子：目标自绘面板写死自拟数值：标题字号、面板底色、带圆角填充底的 TextInput、按钮颜色，代码里找不到平台出处
适用范围：页面实现时用 ArkUI 复刻 DialogPreference 弹出的平台对话框
做法：
- 先读 Android SDK 平台资源（按 compileSdk 取 platforms/android-<api>/data/res）的 layout/preference_dialog_edittext.xml、layout/select_dialog_singlechoice_holo.xml、alert_dialog_holo 布局及相关 style 和 drawable，尺寸、字号、颜色、图片（textfield_*_holo_dark 9-patch、btn_radio_*_holo_dark 四态）都从这里取
- 主题属性（?android:attr/…）顺着应用主题解析到具体值；查不到的项登记为待核，不自拟
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- preference_dialog_edittext：ScrollView 上下 margin 48dp；容器 padding 5dip；消息 TextView 用 ?android:attr/textAppearanceSmall、textColorSecondary，下接 48dp：EditTextPreference 对话框内容区的平台布局（出处：Android SDK 平台资源 data/res/layout/preference_dialog_edittext.xml（按应用的 compileSdk 取对应平台））
- select_dialog_singlechoice_holo：CheckedTextView，minHeight=?android:attr/listPreferredItemHeightSmall，textAppearanceMedium，左右 padding 16dip，checkMark=?android:attr/listChoiceIndicatorSingle：ListPreference 单选行的平台布局（出处：Android SDK 平台资源 data/res/layout/select_dialog_singlechoice_holo.xml（按应用的 compileSdk 取对应平台））
- 复刻件改用 Holo textfield 9-patch 输入框、48vp 行 18fp 字的单选行和 btn_radio_*_holo_dark 四态后与源端一致：修好的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 布局里引用的主题属性的具体值（行高、单选图、文字色、字号）：Android SDK 平台资源 data/res/values/themes_holo.xml 里应用主题对应的 style，以及 values/styles.xml 的 TextAppearance；按属性名找 item，再顺着 @drawable / @color 引用读到图片和颜色；例：Theme.Holo 下 listPreferredItemHeightSmall 是 48dip、listChoiceIndicatorSingle 是 btn_radio_holo_dark
