# CheckBoxPreference 写成平台六态图的方形复选框，不写成 Toggle 开关

审的是：代码
触发（任一种）：
- 读到：res/xml 里有 <CheckBoxPreference>；规格写 Row + Checkbox（Holo 方形勾选），映射参考写 CheckBox→Checkbox；派工却写 CheckboxPreference→Toggle；写错的样子：行内控件写成 Toggle({ type: ToggleType.Switch })，或把规格的 Checkbox 方案改写成 Toggle 并注明覆盖原方案
适用范围：Theme.Holo 下的 PreferenceActivity 复选偏好项迁成 ArkUI 列表行时
做法：
- 迁入平台的 btn_check_on/off(_pressed/_disabled)_holo_dark 图，行内用 Image 按选中、按下、禁用状态切换这几张图，画成方形复选框
- 派工和规格对控件类型说法冲突时，用源 XML 的控件类、meta.json 的 class 和映射参考核对，按源端事实写；不回写规格迎合派工，冲突写进报告交编排者裁决
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 选中/未选中 × 正常、按下、聚焦、禁用各对应一张图：btn_check_on_holo_dark、btn_check_off_holo_dark、btn_check_on_pressed_holo_dark、btn_check_off_pressed_holo_dark、btn_check_on_disabled_holo_dark、btn_check_off_disabled_holo_dark 等：Holo 暗色复选框的状态图（出处：Android SDK 平台资源 data/res/drawable/btn_check_holo_dark.xml（按应用的 compileSdk 取对应平台））
- 改用平台六态复选框图后，复选行外观与源端一致：方形复选框用平台原图（出处：卡里修好并验证过）
针对本应用要查的：
- 复选框图的密度和明暗变体：Android SDK 平台资源 platforms/android-<compileSdk>/data/res 的 drawable-*dpi 目录；按应用主题取 *_holo_dark 或 *_holo_light，按目标密度取对应 dpi 的 png 迁进 media
