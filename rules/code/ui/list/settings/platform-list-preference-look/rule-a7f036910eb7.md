# ExpandableListView 的分隔线迁到 ArkUI 时，组内另设 ListItemGroup.divider

审的是：代码
触发（任一种）：
- 读到：ExpandableListView 写了 android:divider / android:dividerHeight，没写 android:childDivider；写错的样子：只设了 List.divider(...)，组头与子项之间、子项之间没有分隔线；或组内分隔线也用了 divider 的颜色
适用范围：把 ExpandableListView 迁成 List + ListItemGroup 时
做法：
- 组间用 List.divider({ strokeWidth, color })，组内另设 ListItemGroup.divider({ strokeWidth, color })
- 组内颜色按 childDivider 取（没写时是主题 listDivider），和 android:divider 的颜色分开取
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- divider(value: ListDividerOptions | null): ListAttribute：List 的分割线画在主轴方向两个子组件之间，不进入 ListItemGroup 内部（出处：鸿蒙 SDK 的 ets/component/list.d.ts，ListAttribute.divider；ts-container-list.md，divider）
- divider(value: ListDividerOptions | null): ListItemGroupAttribute：同族接口：ListItemGroup 内 ListItem 之间的分割线，默认无（出处：鸿蒙 SDK 的 ets/component/list_item_group.d.ts，ListItemGroupAttribute.divider）
- Widget.Material.ExpandableListView 的 childDivider = ?attr/listDivider；Theme.Material 的 listDivider = @drawable/list_divider_material：源端没写 childDivider 时组内分隔线的来源（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.ExpandableListView；data/res/values/themes_material.xml，listDivider（按应用的 compileSdk 取对应平台））
- 修复先把组内分隔线也用了 divider 色，再按 childDivider 规则改成单独的组内分隔色：组内、组间两种颜色要分开（出处：卡里修好并验证过）
针对本应用要查的：
- 组内分隔线的颜色：应用主题链上的 listDivider：Android SDK 平台资源 data/res/values/themes_material.xml，再到 data/res/drawable/ 下对应的 drawable；读出 drawable 的颜色或着色属性，再按主题解析到色值
