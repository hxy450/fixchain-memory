# 源端用五星评分控件时，目标画出五颗星，不写成「好评 x.0」文本

审的是：代码
触发（任一种）：
- 写错的样子：目标条目把评分写成 `Text('好评 ' + …)` 这类文本，而源端条目是星形评分控件
适用范围：源端评价、评分类列表条目用星形评分控件（五颗星按分数点亮），迁到 ArkUI 时
做法：
- 写一个五星 @Builder，按分数点亮对应颗数的星，替换评分文本
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 五星 Builder 替换评分文本后与安卓一致：修复后的评分写法（出处：卡里修好并验证过）
针对本应用要查的：
- 源端评分控件的星数、点亮规则和尺寸：源工程里该列表条目的 Composable 或布局 XML 中的评分控件；读出星数、分数到点亮颗数的换算和星的大小，目标 Builder 照写
来源：1 张卡，1 个应用
