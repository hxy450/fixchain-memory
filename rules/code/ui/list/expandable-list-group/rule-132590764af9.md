# ExpandableListView 未设组点击监听时，组头仍要 onClick 切换展开，箭头随状态变

审的是：代码
触发（任一种）：
- 读到：ExpandableListView 只调 expandGroup(n)，全文没有 setOnGroupClickListener（或 OnGroupClickListener.onGroupClick 返回 false）；写错的样子：组头没有 .onClick、没有展开状态，注释写「源码未设组点击监听，组头不可点，保真」，只渲染固定那一组的子项
- 读到：BaseExpandableListAdapter.getGroupView 按 isExpanded 切换上下箭头等资源；写错的样子：箭头和子项渲染写成 groupPos === 0 这类下标常量表达式
适用范围：把 ExpandableListView + BaseExpandableListAdapter 迁成 ArkUI List/ForEach 时
做法：
- 没注册组点击监听（或监听返回 false）按框架默认处理：组头加 .onClick(() => 切换本组展开/折叠)，expandGroup(n) 只作初始展开
- 用可变的展开集合（状态变量里的 Set 或数组）同时驱动子项渲染和箭头，不用下标常量；数据重载后照源端再展开初始组
- 旧代码注释里「源码未设…，保真」这类结论当作待核实的假设，按源码和框架默认行为重核后再保留
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 组点击先交给 OnGroupClickListener，只有它返回 true 才拦截；否则已展开就 collapseGroup，未展开就 expandGroup：不注册监听时组头点击默认切换展开/折叠（出处：android.widget.ExpandableListView#handleItemClick）
- 新增展开集合、组头 onClick 切换、按是否展开渲染子项和箭头后，与源端交互一致：修法（出处：卡里修好并验证过）
未核实：卡里环境是 HarmonyOS 6.0.2(22)，本机声明是 API 23
