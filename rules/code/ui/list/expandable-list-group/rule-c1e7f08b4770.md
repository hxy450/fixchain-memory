# ExpandableListView 用默认 groupIndicator 时，组头左侧画平台 expander 图形

审的是：代码
触发（任一种）：
- 读到：ExpandableListView 没自定义 android:groupIndicator，只写 android:indicatorLeft="?android:attr/expandableListPreferredItemIndicatorLeft"；适配器 getGroupView 不画箭头；写错的样子：组头 Row 右端放了 SymbolGlyph（chevron_right / chevron_down）或其他系统符号，颜色写成黑色
适用范围：把只靠平台默认外观的 ExpandableListView 迁成 ArkUI List / ListItemGroup 自绘组头时
做法：
- 指示器是列表自己的 groupIndicator：画在组头左侧 indicatorLeft 区间，组头文字起点留出 expandableListPreferredItemPaddingLeft；不移到行尾
- 图形从平台资源取（Material 为 expander_group_material 的收起/展开两态，按 colorControlNormal 着色），转成目标端 media 资源；不用 SymbolGlyph 或黑色代替
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Widget.Material.ExpandableListView：groupIndicator = @drawable/expander_group_material，childDivider = ?attr/listDivider：Material 主题下默认指示器和组内分隔线（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.ExpandableListView（按应用的 compileSdk 取对应平台））
- expander_group_material：state_expanded 时 expander_close_mtrl_alpha，否则 expander_open_mtrl_alpha，tint = ?attr/colorControlNormal：两态图形和着色来源（出处：Android SDK 平台资源 data/res/drawable/expander_group_material.xml（按应用的 compileSdk 取对应平台））
- expandableListPreferredItemIndicatorLeft = 3dip；expandableListPreferredItemPaddingLeft = 40dip：指示器左边距和组头文字缩进（Theme.Material 系）（出处：Android SDK 平台资源 data/res/values/themes_material.xml，expandableListPreferredItemPaddingLeft（按应用的 compileSdk 取对应平台））
- 修复后组头为左侧 24vp 指示器 + 40vp 缩进、可折行，图形用平台 expander 转成的 SVG：改回框架默认外观后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 指示器的着色：应用主题链上的 colorControlNormal：Android SDK 平台资源 data/res/values/themes_material.xml（或 appcompat 包内 res/values/values.xml）；顺着 ?attr/colorControlNormal → ?attr/textColorSecondary → @color/… 解析到色值；按应用主题的浅/深色各取一份
