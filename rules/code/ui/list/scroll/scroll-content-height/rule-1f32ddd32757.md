# 滚动页转 Scroll 且源内容贴顶时，子容器写 constraintSize({minHeight:'100%'})

审的是：代码
触发（任一种）：
- 读到：match_parent 的 NestedScrollView/ScrollView 里放 wrap_content 内容，首块用 app:layout_constraintTop_toTopOf="parent" 贴顶，内容常不满一屏；写错的样子：Scroll 的子 Column 只写 .width('100%')，没有 .constraintSize({ minHeight: '100%' }) 这类约束，内容不满一屏时整块垂直居中
适用范围：安卓 ScrollView/NestedScrollView 迁成 ArkUI Scroll、源内容从顶部排起且可能不满一屏时
做法：
- 给 Scroll 的子容器加 .constraintSize({ minHeight: '100%' })，让不满一屏的内容从顶部排起
- 同时确认内容超出一屏后仍能滚动（minHeight 只定下限，不写死高度）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- constraintSize(value: ConstraintSizeOptions): T，默认 {minWidth: 0, maxWidth: Infinity, minHeight: 0, maxHeight: Infinity}：组件布局时的尺寸范围，只设 minHeight 不影响内容变高（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.constraintSize）
- minHeight?: Length：ConstraintSizeOptions 的最小高度，可写 '100%'（出处：鸿蒙 SDK 的 ets/component/units.d.ts，ConstraintSizeOptions.minHeight）
- Scroll 支持单个子组件：约束加在这唯一的子容器上（出处：ts-container-scroll.md，子组件）
- 子 Column 只写 width('100%') 时短内容垂直居中；补上 constraintSize({minHeight:'100%'}) 后首块贴顶：Scroll 对不满一屏内容的默认摆放和修法（出处：卡里修好并验证过）
未核实：卡里上机结果出自 HarmonyOS 6.1.1(24)，本机声明是 API 23
