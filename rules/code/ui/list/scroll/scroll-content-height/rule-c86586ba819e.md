# ScrollView 转 Scroll 时，内容 Column 写 minHeight 100% 并顶对齐

审的是：代码
触发（任一种）：
- 读到：ScrollView 或 NestedScrollView 包纵向 LinearLayout，LinearLayout 没写 android:gravity，子项自上而下，内容可能不足一屏；写错的样子：目标 Scroll() { Column() { … } } 的 Column 没写 constraintSize({ minHeight: '100%' }) 和 justifyContent(FlexAlign.Start)，短内容整体纵向居中、首块离开顶部
适用范围：安卓 ScrollView/NestedScrollView 的子布局自上而下排列、迁成 ArkUI Scroll 时
做法：
- 内容 Column 写 .constraintSize({ minHeight: '100%' }).justifyContent(FlexAlign.Start)，内容不足一屏时也贴顶
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- constraintSize(value: ConstraintSizeOptions): T，默认 {minWidth: 0, maxWidth: Infinity, minHeight: 0, maxHeight: Infinity}：限制组件布局尺寸范围，minHeight 撑满 Scroll 视口（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.constraintSize）
- justifyContent(value: FlexAlign): ColumnAttribute：Column 子项在纵向的对齐（出处：鸿蒙 SDK 的 ets/component/column.d.ts，ColumnAttribute.justifyContent）
- FlexAlign.Start：主轴头部对齐，首个子项贴头（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，FlexAlign）
- align(value: Alignment): T，默认 Alignment.Center：组件内容在绘制区内的对齐，默认居中（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.align）
- Scroll 内容不足一屏时纵向居中，源端 ScrollView 贴顶；内容 Column 加 minHeight 100% 与 FlexAlign.Start 后首块紧贴工具栏：默认差异与改法的效果（出处：卡里修好并验证过）
