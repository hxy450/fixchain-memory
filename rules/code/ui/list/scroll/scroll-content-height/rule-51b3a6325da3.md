# 权重剩余区里居中的空态放进 layoutWeight(1) 区居中，不靠 Scroll 内的 100% 高

审的是：代码
触发（任一种）：
- 读到：android:layout_height="0dp" + android:layout_weight="1" 的容器里，RecyclerView 与 match_parent、android:gravity="center" 的空态 TextView 叠放，空态按数据显隐；写错的样子：空态 Text 写在 Scroll 的内容 Column 里并设 .height('100%')，空态贴顶不居中；weight=1 的剩余区没有对应的 layoutWeight(1)
适用范围：源端权重剩余区里叠放列表和居中空态、迁成 ArkUI 时
做法：
- 源端 0dp + layout_weight=1 的容器映射成 .layoutWeight(1) 的区域（列表 Scroll 或包它的 Column）
- 空态放在这个有确定高度的区域里居中：Stack 叠放，或 Column() { Text(空态) }.layoutWeight(1).justifyContent(FlexAlign.Center)；Scroll 的内容 Column 要撑满时加 .constraintSize({ minHeight: '100%' })
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- layoutWeight(value: number | string): T：对应源端 layout_weight，占主轴剩余空间（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.layoutWeight）
- constraintSize(value: ConstraintSizeOptions): T；ConstraintSizeOptions.minHeight?: Length：给 Scroll 内容 Column 设最小高度 '100%'，让内容至少撑满视口（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.constraintSize；ets/component/units.d.ts，ConstraintSizeOptions.minHeight）
- justifyContent(value: FlexAlign): ColumnAttribute：Column 主轴（纵向）居中用 FlexAlign.Center（出处：鸿蒙 SDK 的 ets/component/column.d.ts，ColumnAttribute.justifyContent）
- justifyContent(value: FlexAlign): RowAttribute：同族接口：Row 的主轴对齐（出处：鸿蒙 SDK 的 ets/component/row.d.ts，RowAttribute.justifyContent）
- 列表 Scroll 改 layoutWeight(1)、内容 Column 加 constraintSize({ minHeight: '100%' })、空态放进 layoutWeight(1) + justifyContent(Center) 的 Column 后空态在剩余区居中：修复用的写法（出处：卡里修好并验证过）
