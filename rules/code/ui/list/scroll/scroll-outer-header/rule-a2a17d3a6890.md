# 固定高度标题栏与滚动列表同级时，标题栏放在 Scroll 外的外层 Column 里

审的是：代码
触发（任一种）：
- 读到：纵向 LinearLayout 下固定高度的标题栏（FrameLayout / Toolbar）与装 RecyclerView 或 ScrollView 的容器同级；规格写「标题栏 + 剩余空间列表」；写错的样子：页面写成 Scroll() { Column() { 标题栏 @Builder … 列表或空态 } }，标题栏进了滚动内容，随列表一起滚走
- 读到：源布局根是纵向 LinearLayout，顶部用户栏或工具栏在 NestedScrollView / ScrollView 开标签之前（常带固定 android:layout_marginTop），下面的滚动容器带 android:layout_weight="1"；写错的样子：目标写成 Column { Scroll { Column { header(); … } } }，把源端滚动区外的顶部栏放进了 Scroll；或者层级不改，只调 padding({ top }) 补偿位置
适用范围：安卓纵向布局里固定节点与可滚动区同级、迁成 ArkUI 页面骨架时
做法：
- 按源布局层级写骨架：只有源端滚动容器（RecyclerView / ScrollView / NestedScrollView）开、闭标签之间的子节点进 List / Scroll；在它之前的标题栏等固定节点放在外层 Column() 里、Scroll 之外，如 Column() { 标题行.height(源标题栏高度)；Scroll() {…}.layoutWeight(1) }
- 借用相邻页面的骨架（如单一根 Scroll）前，先核对本页规格的结构节和属性表是否也是整页滚动
- 顶部区块位置不对时先看它是否在滚动容器里；层级错了就改层级，不用 padding 偏移补偿
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Scroll 支持单个子组件；当子组件的布局尺寸超过父组件的尺寸时，内容可以滚动：放进 Scroll 的节点都会随内容滚动（出处：ts-container-scroll.md，子组件）
- layoutWeight(value: number | string): T，默认 0：在父容器（Row、Column、Flex）主轴上按权重分剩余空间，对应源端 layout_weight；Scroll 在外层 Column 里占固定栏之外的剩余高度（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.layoutWeight）
- 标题栏移出 Scroll、由外层 Column 固定标题行，列表 Scroll 改 layoutWeight(1) 后标题不再滚走：修复用的骨架（出处：卡里修好并验证过）
- 顶部栏移出 Scroll 固定在顶部、Scroll 只包滚动区内容后，内容不足一屏时顶部栏不再被下推：修好后的层级（出处：卡里修好并验证过）
针对本应用要查的：
- 滚动容器包含哪些子节点：源工程这个页面的布局 XML，按 NestedScrollView / ScrollView 所在行找开、闭标签；开闭标签之间的是 Scroll 的内容；在开标签之前、同属根 LinearLayout 的是固定区
