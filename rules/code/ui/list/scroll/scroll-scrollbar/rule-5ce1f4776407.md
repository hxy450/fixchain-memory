# 滚动视图没写滚动条外观时，Scroll 按源主题写 scrollBarWidth 和 scrollBarColor

审的是：代码
触发（任一种）：
- 读到：源 `HorizontalScrollView` / `ScrollView` 没写 android:scrollbarSize、android:scrollbarThumbHorizontal / scrollbarThumbVertical，外观取自 Activity 主题（如 `Theme.Material.Light` 一族，不一定是 Holo）；写错的样子：目标 `Scroll` 只写了 .scrollBar( 和 .edgeEffect(，没有 .scrollBarWidth( / .scrollBarColor(，转换报告里也没登记这项近似
适用范围：安卓滚动视图转成 ArkUI Scroll 时，源端滚动条宽度和颜色都来自主题的情形
做法：
- 按源主题查出 scrollbarSize，以及和滚动方向对应的 scrollbarThumbHorizontal / scrollbarThumbVertical，追到 drawable 和 tint 算出合成色
- 写成 .scrollBarWidth(<scrollbarSize 的 dp 数>)（dp 数原样作 vp）和 .scrollBarColor('#AARRGGBB')（合成后的颜色）
- 确实查不到时，在转换报告里登记这项缺口，不静默沿用目标默认
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- scrollBarWidth(value: number | string): ScrollAttribute，默认 4，单位 vp：Scroll 的滚动条宽度（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，ScrollAttribute.scrollBarWidth）
- scrollBarColor(color: Color | number | string): ScrollAttribute，默认 '#182431'（40% 不透明度）；@since 22 另有带 Resource 的重载：Scroll 的滚动条颜色；不写就是这个目标默认，不是安卓主题的颜色（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，ScrollAttribute.scrollBarColor）
- scrollbarSize 用 getDimensionPixelSize 读（format dimension），没设时取 ViewConfiguration 的缩放默认；横向滑块读 scrollbarThumbHorizontal（format reference）：源端宽度和滑块图在哪个属性上（出处：android.view.View#initializeScrollbarsInternal；Android SDK 平台资源 data/res/values/attrs.xml，scrollbarSize、scrollbarThumbHorizontal（按应用的 compileSdk 取对应平台））
- 按 Material Light 主题算出的宽 4、色约 #47000000，和返修时在机上量到的一致：dp 数原样作 vp、drawable 颜色经 tint 合成的算法成立（出处：卡里修好并验证过）
- ScrollableCommonMethod<T>.scrollBarWidth(value: number | string): T、scrollBarColor(color: Color | number | string): T：同族接口：List、Grid、WaterFlow 等可滚动组件共有的同名属性（出处：鸿蒙 SDK 的 ets/component/common.d.ts，ScrollableCommonMethod.scrollBarWidth）
- scrollBarWidth(value: number | string): GridAttribute：同族接口：Grid 自己声明的滚动条宽度（出处：鸿蒙 SDK 的 ets/component/grid.d.ts，GridAttribute.scrollBarWidth）
针对本应用要查的：
- 源主题给的滚动条宽度：源工程 Activity 或应用主题的 parent 链，到 Android SDK 平台资源 data/res/values/themes_*.xml 里该主题的 scrollbarSize 项，再到 values/config.xml 或 dimens*.xml 解析 @dimen 引用（按应用的 compileSdk 取平台）；读出 dp 数原样写进 scrollBarWidth。例：Theme.Material.Light 下是 @dimen/config_scrollbarSize，为 4dp
- 源主题给的滑块颜色：同一主题里和滚动方向对应的 scrollbarThumbHorizontal / scrollbarThumbVertical，到平台资源 data/res/drawable 下那个 drawable 的 solid 颜色和 android:tint，再按主题解析 tint 引用的 ?attr；用 tint 的颜色、drawable 的 alpha 乘 tint 的 alpha 得合成 ARGB，写成 '#AARRGGBB'。例：Theme.Material.Light 下是 scrollbar_handle_material（#84ffffff，tint ?attr/colorControlNormal，黑×0.54），约 #47000000
