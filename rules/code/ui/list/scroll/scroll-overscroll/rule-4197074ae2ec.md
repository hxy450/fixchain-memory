# ScrollView 转 Scroll 时按源端越界模式写 edgeEffect，未声明也要写

审的是：代码
触发（任一种）：
- 读到：<ScrollView> 没写 android:overScrollMode（默认 ifContentScrolls），或写了 always / never；写错的样子：Scroll 没有 .edgeEffect(...)；或写了 .edgeEffect(EdgeEffect.Spring) 却没带 { alwaysEnabled: false }，内容不满一屏也回弹
适用范围：把安卓 ScrollView（含对话框里的）转成 ArkUI Scroll 时
做法：
- 没写或 ifContentScrolls：.edgeEffect(EdgeEffect.Spring, { alwaysEnabled: false })；always：.edgeEffect(EdgeEffect.Spring, { alwaysEnabled: true })；never：.edgeEffect(EdgeEffect.None)；对话框里的 Scroll 同样处理
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- edgeEffect(edgeEffect: EdgeEffect, options?: EdgeEffectOptions): ScrollAttribute；Scroll 默认 EdgeEffect.None，options 默认 { alwaysEnabled: true }：Scroll 不写 edgeEffect 就没有越界效果，只写 Spring 时内容不满也回弹（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，ScrollAttribute.edgeEffect）
- alwaysEnabled: boolean：内容比组件小时是否仍启用越界效果（出处：鸿蒙 SDK 的 ets/component/common.d.ts，EdgeEffectOptions.alwaysEnabled）
- View 构造时 setOverScrollMode(OVER_SCROLL_IF_CONTENT_SCROLLS)；IF_CONTENT_SCROLLS 只在内容大到能滚动时允许越界：源端不写 overScrollMode 时的默认行为（出处：android.view.View#View(Context)、android.view.View#OVER_SCROLL_IF_CONTENT_SCROLLS）
- edgeEffect(edgeEffect: EdgeEffect, options?: EdgeEffectOptions): T；List 默认 EdgeEffect.Spring，Grid、WaterFlow 默认 EdgeEffect.None，三者 options 默认 { alwaysEnabled: false }：同族接口：可滚动组件公共的 edgeEffect，默认值和 Scroll 不同（出处：鸿蒙 SDK 的 ets/component/common.d.ts，ScrollableCommonMethod.edgeEffect）
