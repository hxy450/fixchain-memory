# 源 LazyColumn 无滚动条修饰符时，List 显式写 scrollBar(BarState.Off)

审的是：代码
触发（任一种）：
- 读到：Compose `LazyColumn` / `Modifier.verticalScroll` 的 modifier 上没有任何滚动条修饰符（Compose 默认不显示滚动条）；写错的样子：目标 `List` / `Scroll` 没写 `.scrollBar(...)`，或写了 `.scrollBar(BarState.Auto)`，显示出系统滚动条
适用范围：Compose 的 LazyColumn、verticalScroll 迁成 ArkUI List、Scroll 时
做法：
- 目标 List / Scroll 上写 .scrollBar(BarState.Off)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- scrollBar(value: BarState): ListAttribute，默认 BarState.Auto：List 不写 scrollBar 也会显示系统滚动条（出处：鸿蒙 SDK 的 ets/component/list.d.ts，ListAttribute.scrollBar）
- scrollBar(barState: BarState): ScrollAttribute，默认 BarState.Auto：同族接口：Scroll 的滚动条（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，ScrollAttribute.scrollBar）
- scrollBar(barState: BarState): T；List、Grid、Scroll 默认 BarState.Auto，WaterFlow 默认 BarState.Off：同族接口：滚动容器公共的 scrollBar（出处：鸿蒙 SDK 的 ets/component/common.d.ts，ScrollableCommonMethod.scrollBar）
- Compose LazyColumn 默认没有滚动条；目标改成 BarState.Off 后与源端一致：源端默认行为（出处：卡里修好并验证过）
未核实：Compose LazyColumn 默认不显示滚动条出自卡，本机只有 Compose 的编译产物，没核到原文
