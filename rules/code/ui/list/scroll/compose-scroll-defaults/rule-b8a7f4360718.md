# 源列表挂了自定义滚动条修饰符时，目标按它的参数自绘滚动条，不交给系统滚动条

审的是：代码
触发（任一种）：
- 读到：Compose `LazyColumn` 的 modifier 上挂了源工程自定义的滚动条修饰符（传入 `LazyListState`，带宽度、颜色、滚动中和停止时的 α 与动画时长，按项数算 thumb）；写错的样子：目标 `List` 没有对应的自绘滚动条：注释写「无 ArkUI 等价」交给系统滚动条，或写 `.scrollBar(BarState.Off)` 直接丢掉
适用范围：源端列表用自定义 Modifier 画滚动条，迁成 ArkUI List 时
做法：
- 做共享的自绘滚动条组件叠在 List 右侧：宽度、颜色、滚动中和停止时的 α、动画时长照源端修饰符的参数，thumb 位置和高度按可见项序号与总项数算
- 由 List 的 .onScrollIndex((start: number, end: number) => …) 更新 thumb，.onScrollStart / .onScrollStop 切换显隐动画；List 本身写 .scrollBar(BarState.Off)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onScrollIndex(event: (start: number, end: number, center: number) => void): ListAttribute：列表可见项序号变化时回调，用来算 thumb 位置（出处：鸿蒙 SDK 的 ets/component/list.d.ts，ListAttribute.onScrollIndex）
- onScrollStart(event: () => void): ListAttribute；onScrollStop(event: () => void): ListAttribute：滚动开始、停止时回调，用来切换滚动条的 α 动画（出处：鸿蒙 SDK 的 ets/component/list.d.ts，ListAttribute.onScrollStart、ListAttribute.onScrollStop）
- onScrollIndex(event: (first: number, last: number) => void): GridAttribute：同族接口：Grid 的可见项回调（WaterFlowAttribute 同签名）（出处：鸿蒙 SDK 的 ets/component/grid.d.ts，GridAttribute.onScrollIndex）
- 自绘滚动条由 onScrollIndex / onScrollStart / onScrollStop 驱动，复刻源端宽度、颜色、α 和时长后与源端一致：验证过的复刻方式（出处：卡里修好并验证过）
针对本应用要查的：
- 源端滚动条修饰符的各项参数：源工程里这个 Modifier 扩展函数的定义（在页面源码里按修饰符名跳到公共文件）；读出宽度（dp 换 vp）、颜色（主题颜色角色按应用主题解析到色值）、滚动中与停止时的 α 和动画时长、thumb 位置与高度的算式
未核实：卡里的效果在目标 API 24 上验证，本机核对用的是 API 23 的声明
