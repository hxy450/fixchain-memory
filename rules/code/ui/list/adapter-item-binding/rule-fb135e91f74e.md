# 子类 adapter 在 afterBindViewHolder 改配按钮时，图标、文案和点击一起迁

审的是：代码
触发（任一种）：
- 读到：子类 adapter 的 afterBindViewHolder 里按条件用另一个 ActionButton 的 configure(按钮, 图标) 改配次级按钮；写错的样子：目标只在 onClick 回调里改成新动作，共享行组件仍按默认画原来的图标和文案
适用范围：列表页复用共享行组件、源端子类 adapter 改配了按钮时
做法：
- 给共享行组件加覆盖按钮外观和动作的参数（图标、文案、点击一起），消费页在该条件下传入新动作
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 共享行组件增加次级按钮覆盖参数，消费页传入删除动作：修复后按钮图标和点击一致（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
