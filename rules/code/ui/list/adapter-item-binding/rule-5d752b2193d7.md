# 目标行项新增地址副行时，主行名称为空的回退改成「未知设备」，不再回退到地址

审的是：代码
触发（任一种）：
- 读到：源列表项只有一个名称 `TextView`：适配器里 name 非空显示 name、否则 `setText` 地址；布局里没有单独的地址行；写错的样子：目标行项首行写 `Text(device.name.length > 0 ? device.name : device.address)`，次行又固定 `Text(device.address)`，名称为空时两行都是同一个 MAC
适用范围：迁移设备列表一类的行项，目标布局在源端单行名称之外另加了地址或 ID 副行时
做法：
- 主行写 Text(name.length > 0 ? name : '未知设备')（占位文案放字符串资源），副行保留 Text(address)；主行回退不再用副行已展示的同一字段
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 主行回退改为「未知设备」、次行保留 MAC 后，真机列表里两行重复 MAC 的设备由 8 个降为 0：修法已上机验证（出处：卡里修好并验证过）
