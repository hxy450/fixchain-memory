# Adapter 有默认状态分支时，按默认分支实现首屏，切换要真的换渲染内容

审的是：代码
触发（任一种）：
- 读到：Adapter 绑定代码里有默认选中（如趋势/列表切换默认选中趋势、用横向列表画折线），或数据为空时补默认项（如 GridLayoutManager(4) 的网格补 8 个默认项）；写错的样子：目标切换只改文字颜色，两种状态都渲染同一份固定高度的列表；Grid 数据为空时不补默认项，显示空网格
适用范围：把带默认状态分支的 Adapter 区块转成 ArkUI 组件时
做法：
- 首屏按默认分支实现：默认选中的那一态、数据为空时补的默认项都照源端写
- 切换状态用状态变量加 if/else 渲染不同内容（如趋势折线和纵向列表），不只改文字颜色
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 趋势/列表双态和 4×2 生活指数网格按默认分支重建后与源端一致：修好后的做法（出处：卡里修好并验证过）
