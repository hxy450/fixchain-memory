# 列表或翻页网格的选中、当天、周末样式，沿适配器链追到 item 适配器的 convert() 取

审的是：代码
触发（任一种）：
- 读到：`ViewPager` / `RecyclerView` 的外层适配器里构造内层适配器并传 `R.layout.` 的 item 布局，选中、当天、周末、节日的样式分支写在内层适配器的 `convert()` 里；写错的样子：目标网格的选中态、当天、周末样式是自拟的（如统一灰色星期行、浅色圆形加红字），和 `convert()` 里的分支不符
适用范围：把 RecyclerView/ViewPager 类网格迁成 ArkUI 的 Grid、List 等时
做法：
- 沿适配器链追到实际渲染格子的 item 适配器，从它的 `convert()`（或 onBindViewHolder）里逐个确认选中、当天、周末、节日的样式分支，照分支写目标格子的条件样式
针对本应用要查的：
- 格子各状态的颜色、背景和字号：源工程里 item 适配器类的 convert() / onBindViewHolder，以及它用的 item 布局 XML；读各条件分支里 setTextColor、setBackgroundResource 等调用的取值，再到 res/values、res/drawable 里取具体值
来源：1 张卡，1 个应用
