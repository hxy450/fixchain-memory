# Adapter 里 setText 用模板拼接文案时，目标照搬模板和全部分支，不只输出数值

审的是：代码
触发（任一种）：
- 读到：RecyclerView.Adapter 的绑定方法里 setText 用字符串模板拼接文案（数值前后带固定文字），并按数据取值走不同模板分支（如几个计数都为 0 时换成另一句）；写错的样子：目标里只写数值的 toString() 或只有 `${…}` 插值，缺了源端模板里的固定文字，或少了某个分支
适用范围：按安卓 RecyclerView 多类型 Adapter 和 item 布局重建 ArkUI 区块时
做法：
- 逐个核对源 Adapter 绑定方法里每处 setText 的拼接模板和全部 if/else 分支，在目标里写出同样的模板串（固定文字加插值）和同样的分支条件，包括数值为 0 或为空时的那一句
针对本应用要查的：
- 每个区块的文案模板和分支条件：源工程 Adapter 的 Kotlin/Java 文件里，对应 item 类型的绑定方法中所有 setText 调用；模板里的固定文字若是 R.string 引用，再到源工程 res/values/strings.xml 按资源名找；把每处 setText 的参数拆成固定文字和插值变量，连同外面的 if/else 条件一起抄成目标端的模板串和条件
