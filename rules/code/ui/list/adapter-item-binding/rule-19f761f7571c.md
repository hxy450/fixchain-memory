# 源端 Adapter 按 ID 查本地表取图标时，宿主映射也按 ID 解析图标和颜色，不直接用接口 icon

审的是：代码
触发（任一种）：
- 读到：源端 Adapter 绑定条目时调用显示工具传的是条目里关联对象的 ID（外键），由工具查本地表得到图标和颜色并着色，没有直接用接口返回的图标字段；写错的样子：宿主把列表数据映射成子组件 UI 项时直接取接口返回的 .icon 字段（空值回退默认图），没按 ID 查本地表，也没给子组件传颜色
适用范围：页面宿主接线时把列表数据映射成子页面 UI 项，源端条目图标经本地数据解析得到时
做法：
- 逐项对照源端 Adapter 实际传给显示工具的参数：传的是 ID，就在宿主里按这个 ID 查本地缓存的同一张表取图标和颜色，查不到才回退接口图标
- UI 项里同时带上 ID 和颜色字段，交给子组件按颜色给图标着色
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 宿主缓存本地表，UI 项按 ID 查表取 icon / color（缺失才回退接口图标），并新增 ID 和颜色字段，图标按颜色着色：修复后的映射方式（出处：卡里修好并验证过）
针对本应用要查的：
- 源端显示工具从 ID 解析出的图标和颜色来自哪张表、哪两个字段：源工程里 Adapter 调用的那个显示工具方法，以及它查询的本地数据库实体；读出按 ID 查询的实体和取图标、颜色的字段，目标宿主用同一来源的数据做映射
