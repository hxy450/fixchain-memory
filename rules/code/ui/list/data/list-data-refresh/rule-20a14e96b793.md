# 实现 IDataSource 时计数成员写 totalCount()，不写 getTotalCount()

审的是：代码
触发（任一种）：
- 读到：源端 RecyclerView.Adapter 的 getItemCount()；映射参考只写「RecyclerView.Adapter → LazyForEach + IDataSource」，没列成员；写错的样子：实现 IDataSource 的类写了 getTotalCount()，调用点也用 getTotalCount()
适用范围：实现 LazyForEach 的数据源类时
做法：
- 先读 SDK 的 component/lazy_for_each.d.ts 里 IDataSource 的接口体再写类；计数方法写 totalCount(): number，所有调用点统一用 totalCount()

- totalCount(): number：IDataSource 的数据总数成员（出处：鸿蒙 SDK 的 ets/component/lazy_for_each.d.ts，IDataSource.totalCount）
