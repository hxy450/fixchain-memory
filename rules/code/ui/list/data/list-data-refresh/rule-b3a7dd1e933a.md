# 分页列表的返回刷新等批量异步查询，按列表代次放弃过期结果、只按 ID 修补当前列表

审的是：代码
触发（任一种）：
- 读到：源端列表由分页回调追加、下拉时 `clear()` 后替换，`onResume` 不整表刷新；单项状态要逐条 await 本地数据库查询；写错的样子：`onPageShow` 里新增的刷新先 `const current = this.list.slice()`，逐项 await 后 `this.list = current` 整体回写；同文件的分页加载已用请求序号丢弃过期回调，这个入口却没有
适用范围：异步分页（触底追加、下拉整体替换）的列表页，新增返回刷新这类跨多次 await 的批量异步查询时
做法：
- 进入批量查询前记下列表代次（沿用页面分页加载已有的请求序号），每次 await 之后序号变了或列表已被替换就退出
- 查到的结果按条目 ID 修补当前列表（在 this.list 里按 id 找到那一项改字段），不在 await 前复制整张列表、结束后整体赋回
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 返回刷新记录请求序号、列表被替换即退出，只按 ID 修补当前列表：修好的写法（出处：卡里修好并验证过）
- onPageShow?(): void（@Entry 组件每次页面显示时调用）：返回页面时的刷新入口，和分页、下拉回调并发（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CustomComponent.onPageShow）
