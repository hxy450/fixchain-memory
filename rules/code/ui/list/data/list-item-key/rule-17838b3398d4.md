# ForEach/Repeat 的键不含位置时，位置相关值在渲染时按 indexOf 取当前位置

审的是：代码
触发（任一种）：
- 读到：Compose `itemsIndexed` 每次重组把当前 index 传给 isFirst / isLast / 序号等位置相关参数；写错的样子：ForEach 的键是实例 id + 内容（不含位置），却在 itemGenerator 里把闭包 index（或 Repeat 的 ri.index）写进 isFirst / isLast / 序号和行形状
适用范围：列表项可换位（上移、下移、删除），且项上有依赖位置的显示或可用态时
做法：
- 位置相关值在渲染时按当前数组位置计算：const i = this.steps.indexOf(item)，由 i 推 isFirst（i === 0）、isLast（i === this.steps.length - 1）、序号和行形状
- 换位后检查上移、下移按钮的可用态
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 键值没变时 ForEach 不会把数据更新同步给子组件，子组件仍绑定旧的数组项：同键项换位后，构造时传入的位置参数不刷新（出处：arkts-rendering-control-foreach.md，数据变化不渲染）
- itemGenerator 声明了 index 而 keyGenerator 没声明时，框架在键值后拼接 index：键是否含位置还取决于 keyGenerator 有没有声明 index（出处：arkts-rendering-control-foreach.md，键值生成规则）
- 改用 this.steps.indexOf(ri.item) 取当前位置后，上移、下移恢复有效：卡里的修法（出处：卡里修好并验证过）
未核实：ForEach 闭包 index 过期没有在生成态构建上直接运行，依据同键复用语义和修复期 Repeat 的运行观察
