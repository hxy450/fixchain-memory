# 源调用点把触底 helper 的重试参数写成字面 false 时，目标不照搬别的列表的失败态抑制

审的是：代码
触发（任一种）：
- 读到：源端调用点给触底 helper 传字面 false 作重试参数（helper 内是 derivedStateOf + LaunchedEffect）；写错的样子：目标该列表的 .onReachEnd / onScrollIndex 回调里加了「追加失败态时不自动加载」的判断，照搬自源端传重试变量的另一个列表
适用范围：多个列表共用一个触底 helper、各调用点实参不同时
做法：
- 逐个调用点照源端实参写：字面 false 的不加失败态抑制，传变量的才按该变量抑制
- 已有共享的触底控制器时，各列表复用同一个控制器，只换实参，不各自另写回调
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 评论列表的重试参数改回 false：修复后失败态不再拦截自动加载，与源端一致（出处：卡里修好并验证过）
