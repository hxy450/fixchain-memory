# 稳定 ForEach/Repeat 的 key 时，条目模型改成 @ObservedV2/@Trace 并原位更新

审的是：代码
触发（任一种）：
- 读到：ForEach / Repeat 的 key 里拼了请求状态或数据（如 requestId、loadState、条目内容），条目模型是普通 interface，更新时用新对象整体替换数组项；写错的样子：key 改成只含稳定标识后，模型仍是普通 interface、仍整体替换；子组件以 @Param 接普通对象，或把 RepeatItem.item 解包后往下传
适用范围：为消除列表或 Swiper 页的重建抖动而稳定 ForEach / Repeat 的 key，数据靠异步结果整体替换时
做法：
- 稳定 key 前先定新数据怎么到达已建节点：普通 interface 整体替换只能靠 key 变化触发重建，key 稳定后就到不了
- 要稳定 key，就把条目模型改成 @ObservedV2 class 并给要变的字段加 @Trace，原位改字段；@Builder 和子组件 @Param 链路都传这个可观察实例或完整 RepeatItem
- 在注释或测试断言里写明禁止替换该实例，后续修改不对它做不可变替换
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 替换数组项后新项生成的 key 没变，ForEach 不会把数据更新同步给子组件，组件仍绑定旧数组项：稳定 key + 整体替换 = 新数据进不了已建节点（出处：arkts-rendering-control-foreach.md，数据变化不渲染）
- @ObservedV2 类中被 @Trace 装饰的属性值变化时，会触发该属性绑定的 UI 组件刷新；未被 @Trace 装饰的属性无法触发 UI 刷新：原位更新要靠 @Trace 字段（出处：arkts-new-observedV2-and-trace.md，观察变化）
- 页模型改为 @ObservedV2 class + @Trace 字段并原位更新后数据显示；再改回不可变替换又无数据，回退为稳定实例 + @Trace 字段更新：修好后的写法，以及替换实例会复发（出处：卡里修好并验证过）
