# 页面状态分派时已有内容优先于刷新错误，错误用提示条，加载用局部指示，不加全屏遮罩

审的是：代码
触发（任一种）：
- 写错的样子：页面里 `if (this.errorMessage.length > 0)` 优先、整块替换已有列表，或在 Refresh 外叠一层 `if (this.isLoading)` 的全屏遮罩，遮住其他分区
适用范围：目标端列表页在刷新、失败时的显示分支，决策要求失败时保留最近成功数据的
做法：
- 有保留的最近成功列表时先显示列表（地图页连同 Marker），刷新错误用列表上方的提示条显示并带重试，不整块替换内容
- 刷新中的加载用局部指示（如 Refresh({ refreshing: … }) 自带的刷新指示），去掉遮住其他分区的全屏遮罩
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Refresh(value: RefreshOptions)，RefreshOptions.refreshing: boolean：Refresh 是否处于刷新中，支持 $$ 双向绑定；刷新中由组件自己显示指示（出处：鸿蒙 SDK 的 ets/component/refresh.d.ts，RefreshInterface、RefreshOptions.refreshing）
