# 列表项文案随语言或状态变化时，ForEach 的 keyGenerator 要把可变显示字段编进 key

审的是：代码
触发（任一种）：
- 读到：列表项显示的文案改成渲染期按语言（或其他 `@Trace` 状态）经 `t(key)` 取值，数组在切换时整体替换；写错的样子：`ForEach(options, …, (opt) => opt.value)` 一类只返回恒定 id 的 keyGenerator，项内 `Text(opt.label)` 显示可变文案
适用范围：ForEach / LazyForEach / Repeat 渲染的列表项显示随状态变化的字段时
做法：
- keyGenerator 返回包含所有影响显示的可变字段的键，如 (opt) => opt.value + '|' + opt.label；LazyForEach 的 keyGenerator、Repeat 的 .key() 同样处理
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- (arr: Array<any>, itemGenerator: (item: any, index: number) => void, keyGenerator?: (item: any, index: number) => string): ForEachAttribute：ForEach 的第三个参数生成键值（出处：鸿蒙 SDK 的 ets/component/for_each.d.ts，ForEachInterface）
- 非首次渲染时键值已存在就不创建新组件，直接渲染该键值对应的组件：键不变时复用旧项，itemBuilder 不重跑，新文案被吞（出处：arkts-rendering-control-foreach.md，非首次渲染）
- (dataSource: IDataSource, itemGenerator: (item: any, index: number) => void, keyGenerator?: (item: any, index: number) => string): LazyForEachAttribute：同族接口：LazyForEach 的键值生成（出处：鸿蒙 SDK 的 ets/component/lazy_for_each.d.ts，LazyForEachInterface）
- key(keyGenerator: (item: T, index: number) => string): RepeatAttribute<T>：同族接口：Repeat 的键值生成（出处：鸿蒙 SDK 的 ets/component/repeat.d.ts，RepeatAttribute.key）
- key 改为 opt.value + '|' + opt.label 后，切换语言列表项文案刷新：修法已在设备上复验（出处：卡里修好并验证过）
未核实：卡里环境是 SDK 26.0.0，声明按本机 API 23 核实
