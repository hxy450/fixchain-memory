# LazyRow(SpaceEvenly) 写成横向 Scroll 包 minWidth 100% 的 Row，槽位恒在

审的是：代码
触发（任一种）：
- 读到：LazyRow(horizontalArrangement = Arrangement.SpaceEvenly) 里放固定几个 item，item 内用 AnimatedVisibility 控制显隐；写错的样子：写成 Row().width('100%').justifyContent(FlexAlign.SpaceEvenly)，子项用 if 增删，外面没有 Scroll
适用范围：Compose LazyRow 带 SpaceEvenly 排列、item 个数固定，迁成 ArkUI 时
做法：
- 写成 Scroll() { Row() { …槽位… }.constraintSize({ minWidth: '100%' }).justifyContent(FlexAlign.SpaceEvenly) }.scrollable(ScrollDirection.Horizontal)
- 每个 item 对应一个恒在的槽位容器，只有槽位里的内容按条件出现（对应 AnimatedVisibility）；写完核对窄宽或大字体下能否横滑
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- (scroller?: Scroller): ScrollAttribute：Scroll 的构造只收 Scroller，不收方向（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，ScrollInterface）
- scrollable(value: ScrollDirection): ScrollAttribute，默认 ScrollDirection.Vertical：横滑要显式写 ScrollDirection.Horizontal（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，ScrollAttribute.scrollable）
- constraintSize(value: ConstraintSizeOptions): T，默认 {minWidth: 0, maxWidth: Infinity, minHeight: 0, maxHeight: Infinity}：minWidth: '100%' 让内容不足一屏时仍铺满宽度、SpaceEvenly 生效，超出时可滚（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.constraintSize）
- justifyContent(value: FlexAlign): RowAttribute；FlexAlign.SpaceEvenly 首尾与相邻间距相等：Arrangement.SpaceEvenly 的对应（出处：鸿蒙 SDK 的 ets/component/row.d.ts，RowAttribute.justifyContent；ets/component/enums.d.ts，FlexAlign.SpaceEvenly）
- justifyContent(value: FlexAlign): ColumnAttribute：同族接口：Column 的主轴排列（LazyColumn 带 verticalArrangement 时用）（出处：鸿蒙 SDK 的 ets/component/column.d.ts，ColumnAttribute.justifyContent）
- Scroll(Horizontal) + Row(minWidth 100%, SpaceEvenly) + 三个恒在槽位后，可横滑、隐藏值保留零宽：修好后的结构（出处：卡里修好并验证过）
