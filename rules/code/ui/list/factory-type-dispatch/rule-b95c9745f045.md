# 源端工厂的 else 落到空 Fragment 时，目标未匹配类型空渲染，不显示占位文案

审的是：代码
触发（任一种）：
- 读到：源端工厂的 else 分支 create 一个什么都不显示的空 Fragment；写错的样子：目标把非工厂 type 映射成 `'unsupported'` 之类，用 Text(...) 在界面上显示「暂不支持」一类 fallback 文案
适用范围：迁移按 type 派发的配置驱动界面，处理没匹配上的类型时
做法：
- 工厂 else / 空 Fragment 分支实现为空渲染（该项不出任何组件）
- 和「迁移未实现」分开：工厂里有、目标还没接的已知类型写进交付报告，不在界面上显示 fallback
