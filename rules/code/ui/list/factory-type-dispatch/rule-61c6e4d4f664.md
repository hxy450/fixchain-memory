# 删除或替换某 type 的替代入口时，一并移除列表里与该 type 相关的排除条件

审的是：代码
触发（任一种）：
- 写错的样子：改动删掉了某个 type 的页内替代入口（如页内文本编辑器），列表提供函数里 item.type !== '<该 type>' 或「选中子模块才放行」的条件还留着
适用范围：目标端调整某个编辑项 type 的承载入口（删页内入口、改走列表或专用页面）时
做法：
- 删除或替换替代入口时，检索列表提供函数里与该 type 相关的排除条件（type !== '…'、按选中状态放行），一并移除，确保该 type 仍有且只有一个入口
