# 页面把接口响应 JSON.stringify 后塞进 Text 时视同占位，改成解析成模型、按 AC 渲染

审的是：代码
触发（任一种）：
- 读到：安卓对应 Screen 渲染列表卡片、表单字段、状态 Tab 和操作按钮；规格 AC 列了分页、默认、增删改或状态筛选、领取等；写错的样子：页面请求后 Text(JSON.stringify(await …)) 回显整段响应，没有模型、列表项、状态筛选和操作按钮；或照抄了同类回显壳的兄弟页面
适用范围：增量功能实现阶段，替换占位子页、决定页面渲染结构时
做法：
- 按 UI → Model(fromJson) → Service 分层：Service 方法返回解析后的模型，页面按 AC 渲染列表项、表单字段、状态 Tab 和操作按钮
- 拿兄弟页面当模板前先核它是否已满足本页 AC，回显壳不当作项目惯例复用
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 返修新增模型类和 Service，三页删除重建为卡片列表、完整表单、状态筛选加领取：返修后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 这一页要渲染的字段和操作：规格里这一页的验收条目，以及它点名的安卓 Screen、ViewModel（Compose 或 Activity/Fragment 源文件）；逐条列出列表项字段、表单字段、Tab 和按钮，各对到目标页面的一个组件
