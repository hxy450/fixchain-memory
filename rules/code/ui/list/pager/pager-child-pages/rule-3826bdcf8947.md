# 决定页面是否创建的解析结果，区分服务端返回空和取值路径未命中，并用样例验证非空

审的是：代码
触发（任一种）：
- 读到：源端拿解析出的分类列表决定建几个子页（如 Tab、二层 Swiper 的子页）；写错的样子：取值键未命中时默默返回 `[]`，和服务端真返回空走同一分支，Tabs / Swiper 既没有子页也没有空态
适用范围：解析结果直接决定后续页面或组件是否创建的端点
做法：
- 取值时区分两种空：键不存在（路径未命中）记错误日志或报错，键存在但数组为空才走空态
- 用一次真实响应或 mock 样例跑一遍解析，断言结果非空
