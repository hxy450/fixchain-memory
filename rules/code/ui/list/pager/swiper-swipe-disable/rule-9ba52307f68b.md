# ViewPager2 只禁手势滑动时，Swiper 用 disableSwipe(true) 不用 enabled

审的是：代码
触发（任一种）：
- 读到：ViewPager2 上写了 isUserInputEnabled = false，子页是可交互的 Fragment；写错的样子：对应的 Swiper 上写了 .enabled(false)
- 读到：ViewPager 靠拦截 onTouchEvent / onInterceptTouchEvent 禁止用户滑动；写错的样子：对应的 Swiper 上写了 .enabled(false)
适用范围：安卓 ViewPager / ViewPager2 只关闭用户滑动手势、子页仍要可点，迁成 ArkUI Swiper 时
做法：
- Swiper 上写 .disableSwipe(true) 关闭手势滑动，删掉 .enabled(false)
- 改完后在 Swiper 上显式写 .enabled(true)，保证容器和子页可交互
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- disableSwipe(value: boolean): SwiperAttribute：是否禁止滑动，默认 false；只关手势，不影响子页点击（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.disableSwipe）
- enabled(value: boolean): T：false 时组件不响应点击等操作（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.enabled）
- Swiper 上 .enabled(false) 让 Swiper 和全部子页都点不动；改成 .disableSwipe(true).enabled(true) 后 UI dump 显示 enabled=true：enabled 作用于整个子树，禁滑要用专门属性（出处：卡里修好并验证过）
未核实：卡里的行为出自 API 24（6.1.1），本机用 API 23 的声明核实；只把 .enabled(false) 换成 .disableSwipe(true) 后 dump 仍显示 enabled=false，原因卡里没查明，显式补 .enabled(true) 后才正常
