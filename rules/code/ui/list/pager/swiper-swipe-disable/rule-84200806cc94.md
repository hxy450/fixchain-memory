# 源端 ViewPager2 不可滑时，目标不用 Swiper，或显式写 disableSwipe(true)

审的是：代码
触发（任一种）：
- 读到：源端 ViewPager2 的适配器只有 1 页，或 isUserInputEnabled = false；规格、派工或映射表写 ViewPager2 → Swiper；写错的样子：Swiper(controller){ 单个内容 }.index(0).indicator(false).loop(false)，没有 disableSwipe(true)，还留着 changeIndex 切页
- 写错的样子：覆盖在 Swiper 上的层写 .hitTestBehavior(HitTestMode.Transparent)，把空白区触摸透传给底下的 Swiper
适用范围：实现阶段落地源端 ViewPager / ViewPager2 的目标容器时
做法：
- 对照源码确认容器确实可滑（多于 1 页且没禁用用户输入）；单页时把 Swiper 换成 Column 直嵌内容，删掉 SwiperController 和 changeIndex 切页
- 保留 Swiper 时至少写 .disableSwipe(true)，并检查覆盖层的 HitTestMode.Transparent 有没有把触摸透传到这个手势面
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- disableSwipe(value: boolean): SwiperAttribute，默认 false：Swiper 禁用手势滑动（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.disableSwipe）
- HitTestMode.Transparent：自身和子组件响应触摸，同时允许被它遮住的其他节点也做命中测试：覆盖层用它时触摸会落到底下的 Swiper（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，HitTestMode.Transparent）
- hitTestBehavior(value: HitTestMode): T：设置组件的触摸命中模式（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.hitTestBehavior）
- 单页 Swiper 仍有横拖手势面，会平移回弹；换成 Column 后横滑内容 bounds 不变：不改的后果和修好后的表现（出处：卡里修好并验证过）
- scrollable(value: boolean): TabsAttribute，默认 true：同族接口：Tabs 的内容区是否可滑（出处：鸿蒙 SDK 的 ets/component/tabs.d.ts，TabsAttribute.scrollable）
未核实：卡里环境是 API 24（兼容 API 12），本机声明按 API 23 核实；disableSwipe(true) 的写法出自建议，卡里实际修复用的是换成 Column
