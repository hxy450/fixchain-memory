# 源端 color 只绑在部分元素上时，只给这些元素用 accent，库控件留库默认主题色

审的是：代码
触发（任一种）：
- 读到：源组件的 color={...} 只出现在部分 IonButton 上，Swiper 本身没有 color 属性或主题变量；写错的样子：目标端把应用 accent 用在导航箭头或分页激活点上（fillColor(...)、backgroundColor(...) 传的是 accent），或注释把 accent 写成导航前景色
适用范围：源端组件的 color / accent 属性只传给部分子元素，目标端给整组控件配色时
做法：
- 逐个核对源里 color / accent 实际绑定到哪些元素，只给这些元素用 accent；Swiper 的导航箭头和分页点用库默认主题色
针对本应用要查的：
- 库控件的默认主题色：源工程 package.json 里锁定的 swiper 版本，node_modules 里同版本 swiper 的 CSS，按 --swiper-theme-color 找；读出颜色值写成目标端的显式颜色；例：swiper 12.2.0 下是 #007aff
