# 父子双向同步选中索引时，子组件回调父级前先比较目标与当前选中，同一项不重复回调

审的是：代码
触发（任一种）：
- 读到：源端 selectItem 遇到同一项直接 return、不回调父级；写错的样子：子组件的 @Event 选中回调不比较目标索引与当前 selectedIndex，父级改了 selectedIndex 再传回时又触发回调，形成回环
适用范围：子组件既接收父级的 selectedIndex（@Param）又以 @Event 回调父级切页时
做法：
- 回调父级前判断：目标索引等于当前选中就直接返回，不调 @Event 回调；只有用户改选了不同项才回调
