# 源端按持久化选中项恢复页并在切页时回写的，Swiper 要按它设 index、在 onChange 里回写

审的是：代码
触发（任一种）：
- 读到：ViewPager2 容器在列表加载完成的观察者里按持久化的选中项算出下标再 setCurrentItem，OnPageChangeCallback.onPageSelected 里把当前项写回持久化；写错的样子：Swiper 的 .index(...) 绑定的下标停在初值 0，加载后没按持久化选中项重算；.onChange(...) 里只按新页拉数据，没有调用写回当前选中项的接口
适用范围：ViewPager2（每页一个 Fragment）迁成 ArkUI Swiper、源端有当前页恢复和切页回写时，含填充别人留下的 `FWD-REF` 钩子
做法：
- 列表加载完成后，取持久化的当前选中项，在新列表里 findIndex 出下标，赋给绑定到 Swiper(...).index(...) 的状态变量（找不到时取 0）
- 在 .onChange((index: number) => { … }) 里，按新页加载数据之外，再调用写持久化选中项的接口，把该页的标识写回
- 目标端已有读、写当前选中项的仓库接口时，加载回调接读接口、切页回调接写接口，不要只接数据加载
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- index(value: number): SwiperAttribute：设当前显示的子组件下标，默认 0；小于 0 或不小于子组件个数时取 0（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.index）
- onChange(event: Callback<number>): SwiperAttribute：当前显示的子组件下标变化时触发，参数是新下标；动画引起的变化在动画结束时回调（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.onChange；ts-container-swiper.md，onChange）
- index 从 API 10 起支持 $$ 双向绑定变量：绑定后滑动会同步改状态变量，但不会替代写回持久化（出处：ts-container-swiper.md，index）
- 加载完成后以仓库的当前选中项恢复 Swiper 下标；切页回调里在加载数据之外追加写回当前选中项：修好后的接法（出处：卡里修好并验证过）
- onChange(event: Callback<number>): TabsAttribute：同族接口：Tabs 的页签切换回调（出处：鸿蒙 SDK 的 ets/component/tabs.d.ts，TabsAttribute.onChange）
- onChange(event: Callback<number>): IndicatorComponentAttribute：同族接口：独立导航点组件的下标变化回调（出处：鸿蒙 SDK 的 ets/component/indicatorcomponent.d.ts，IndicatorComponentAttribute.onChange）
针对本应用要查的：
- 持久化选中项的读写接口和标识字段：目标工程里对应数据仓库的 .ets 文件，按读当前选中项、写当前选中项的方法找；源端对照容器 Fragment 里读写持久化选中项的调用；读接口接到加载完成后的下标计算，写接口接到 onChange，标识字段用源端比较时用的那个键
