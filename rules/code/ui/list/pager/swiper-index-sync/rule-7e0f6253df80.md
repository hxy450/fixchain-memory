# 规格写列表随轮播当前项过滤时，Swiper 接 onChange 更新选中项，列表按它过滤

审的是：代码
触发（任一种）：
- 读到：页面规格写列表内容随轮播当前项变化（如「待办为当前选中项的未完成项」），UiState 含选中项的 id 字段；写错的样子：Swiper 上没有 .onChange(...)，ViewModel 没有选中项字段和切换方法，列表直接显示全部数据
适用范围：用 ArkUI Swiper 实现带轮播的页面，轮播当前项驱动别的列表时（onChange 声明 @since 18 的写法）
做法：
- Swiper 上接 .onChange((index: number) => { 调用 ViewModel 的选中方法，传 index 对应项的 id })
- ViewModel 保存选中项 id，列表数据按它过滤
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onChange(event: Callback<number>): SwiperAttribute：当前显示的子组件索引变化时触发，参数是新索引（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.onChange）
- index(value: number): SwiperAttribute；默认 0，越界时用 0：初始当前项；选中项 id 的初值要和它对应（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.index）
- Swiper onChange 调选中方法，ViewModel 按选中项过滤待办：修好的做法（出处：卡里修好并验证过）
