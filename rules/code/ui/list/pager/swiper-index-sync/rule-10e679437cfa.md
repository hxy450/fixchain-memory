# 自绘 tab 加受控 Swiper 时双向都接：onChange 更新高亮，tab 项 onClick 写回 index

审的是：代码
触发（任一种）：
- 读到：源端用普通 TextView 当 tab，Fragment 代码里有 tv….setOnClickListener { viewPager2.currentItem = N }，onPageSelected 只切选中样式；写错的样子：目标 Swiper 只接了 .index(状态) 和 .onChange 更新高亮，@Builder 的 tab 项只有 Text 和选中样式、没有 .onClick
适用范围：把自定义 tab 行加 ViewPager2 转成 ArkUI 自绘 Row / @Builder tab 加受控 Swiper 时
做法：
- 页→tab：Swiper(...).index(this.tabIndex).onChange((index: number) => { this.tabIndex = index })，选中样式按 tabIndex 渲染
- tab→页：每个 tab 项加 .onClick(() => { this.tabIndex = index })，经受控的 Swiper.index 切页；不要把 .index(state) 加 .onChange 当成双向同步已完成
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- index(value: number): SwiperAttribute，默认 0，越界时用 0：受控的当前页序号（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.index）
- onChange(event: Callback<number>): SwiperAttribute：当前页序号变化时回调，用于页→tab（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.onChange）
- onClick(event: (event: ClickEvent) => void): T：tab 项的点击，用于 tab→页（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onClick）
- tab 项补 .onClick(() => this.changeTab(index))，经父层状态回写受控 Swiper.index 后点击能切页并联动高亮：卡里的修法（出处：卡里修好并验证过）
未核实：卡里环境是 API 24，按本机 API 23 的声明核实
