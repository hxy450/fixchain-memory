# 源端用 ViewPager2 逐页承载自绘月/周视图时，目标用 Swiper 三页各放一个 Canvas

审的是：代码
触发（任一种）：
- 读到：布局里 `androidx.viewpager2.widget.ViewPager2`（或 RecyclerView）逐页承载月、周视图，registerOnPageChangeCallback / onPageSelected 里切月；写错的样子：ArkTS 只有一个 Canvas，用 PanGesture 改 pageOffsetX 手动翻页，修复时只调拖动阈值、回弹曲线和动画时长
适用范围：源端逐页翻页的自绘日历、月历迁成 ArkUI Canvas 时
做法：
- 外层用 Swiper 承载三页（cachedCount 缓存前后页），每页放一个 Canvas 只画该页月格；删掉 Canvas 上改 pageOffsetX 的横向 PanGesture。「自绘」只要求月格绘制，不排斥 Swiper 做翻页容器
- 需求点名 ViewPager 或 Swiper 效果时，先确认现有手动翻页能否在拖动中同时显示相邻页、支持快滑切页和回弹；做不到就换翻页容器
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- cachedCount(value: number): SwiperAttribute，默认 1，指当前页前后各缓存的页数：预加载相邻页（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.cachedCount）
- onGestureSwipe(event: OnSwiperGestureSwipeCallback): SwiperAttribute，手势翻页时逐帧触发：拖动中的进度回调，可用来联动高度（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.onGestureSwipe）
