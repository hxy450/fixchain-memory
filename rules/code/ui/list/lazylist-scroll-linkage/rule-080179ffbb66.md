# animateScrollToItem 迁成 scrollToIndex，对齐用 ScrollAlign.START

审的是：代码
触发（任一种）：
- 读到：源端 lazyListState.animateScrollToItem(index)，同一处还调顶栏的 collapse()；写错的样子：目标写 scrollToIndex(index, true, ScrollAlign.CENTER)，或漏了顶栏收起
适用范围：把 Compose LazyListState 的滚动定位迁成 ArkUI List 的 Scroller 时
做法：
- 写成 this.scroller.scrollToIndex(index, true, ScrollAlign.START)，目标项滚到列表顶部
- 源码同时 collapse 顶栏时一并实现收起；做不到就登记为偏差
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- scrollToIndex(value: number, smooth?: boolean, align?: ScrollAlign, options?: ScrollToIndexOptions)：滚到指定下标；容器是 List 时 align 默认 ScrollAlign.START，smooth 默认 false（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，Scroller.scrollToIndex）
- ScrollAlign.START：列表项的起始边与列表起始边对齐；ScrollAlign.CENTER：列表项在主轴居中：源端滚到顶部对应 START（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，ScrollAlign）
- scrollToItemInGroup(index: number, indexInGroup: number, smooth?: boolean, align?: ScrollAlign): void：同族接口：ListScroller 滚到分组内的项（出处：鸿蒙 SDK 的 ets/component/list.d.ts，ListScroller.scrollToItemInGroup）
