# 源端评价图片最多 9 张、3 列九宫格时，目标用 Grid 三列并截取前 9 张

审的是：代码
触发（任一种）：
- 写错的样子：目标条目图片写成 `Row` + `Repeat` 固定尺寸横排，没有张数上限和列数，而源端是九宫格
适用范围：源端列表条目的多图按网格排列（最多 9 张、每行 3 列），迁到 ArkUI 时
做法：
- 用 Grid 并 .columnsTemplate('1fr 1fr 1fr')，数据取 pics.slice(0, 9)，每张图一个 GridItem
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- columnsTemplate(value: string): GridAttribute：设当前网格布局的列数，'1fr 1fr 1fr' 为三等分列（出处：鸿蒙 SDK 的 ets/component/grid.d.ts，GridAttribute.columnsTemplate）
- Grid 三列 + slice(0, 9)：修复后的九宫格写法（出处：卡里修好并验证过）
- columnsTemplate(value: string): WaterFlowAttribute：同族接口：WaterFlow 的列模板（出处：鸿蒙 SDK 的 ets/component/water_flow.d.ts，WaterFlowAttribute.columnsTemplate）
针对本应用要查的：
- 源端图片上限和列数：源工程里该条目的 Composable（LazyVerticalGrid 的 columns、take 之类）或布局 XML（GridLayout 的 columnCount）；读出最多几张、几列，目标 slice 和 columnsTemplate 照写
