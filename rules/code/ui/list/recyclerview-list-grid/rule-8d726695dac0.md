# 滑动操作转 swipeAction 时挂在 ListItem 上，不挂在 @Builder 行的根组件上

审的是：代码
触发（任一种）：
- 读到：源端用 ItemTouchHelper 或滑动操作类给 RecyclerView 行加滑动按钮，规格和映射写「→ ListItem.swipeAction」；写错的样子：.swipeAction(...) 接在行内容 @Builder 根 Row 的属性链末尾，LazyForEach / ForEach 里的 ListItem 只调用 this.行Builder(item)
适用范围：把行内容抽成 @Builder、再给列表项加滑动操作时
做法：
- 写成 ListItem() { this.行Builder(item) }.swipeAction({ end: … })，属性挂在 ListItem 上；抽 @Builder 后核对属性链末端实际挂在哪个组件上，与规格和计划里的宿主一致
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- swipeAction(value: SwipeActionOptions): ListItemAttribute：只是 ListItem 的属性，挂在别的组件上不生效（出处：鸿蒙 SDK 的 ets/component/list_item.d.ts，ListItemAttribute.swipeAction）
