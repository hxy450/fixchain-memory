# 源多列网格里通栏的广告位在目标恒为空时，Grid 不为它生成 GridItem，ForEach 只渲染内容项

审的是：代码
触发（任一种）：
- 读到：源端 GridLayoutManager 多列，SpanSizeLookup.getSpanSize 对广告或占位项返回满列数，广告在数据层按固定间隔插入；派工或规格把广告定为 no-op 空容器；写错的样子：目标 Grid 的 ForEach 仍为恒空广告位生成 GridItem（零高 Row 或空组件），并用 columnStart/columnEnd、GridLayoutOptions 的 irregularIndexes / onGetIrregularSizeByIndex 让它通栏，注释称零高塌陷与 Android 一致
适用范围：源端多列网格（GridLayoutManager + SpanSizeLookup）里有通栏的广告或占位项、而目标端这些项恒为空（no-op）时
做法：
- Grid 的 ForEach 数据源只给内容项（先把广告位过滤掉），不为恒空占位生成 GridItem，也不为它写 irregularIndexes / onGetIrregularSizeByIndex
- 数据层的广告位可以保留，条目点击时按过滤后的列表重算下标
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 通栏项高度为 0 也照样独占一行、强制换行：它前面是奇数个内容项时，最后一个内容项独占一行，留下半行空格：零高不能消除通栏造成的换行；要保留通栏项先按插入规则推一遍它落在哪一列（出处：卡里修好并验证过）
- irregularIndexes?: number[]；不设 onGetIrregularSizeByIndex 时，这些项占满一整行：GridLayoutOptions 里的通栏写法，恒空广告位不要放进去（出处：鸿蒙 SDK 的 ets/component/grid.d.ts，GridLayoutOptions.irregularIndexes / GridLayoutOptions.onGetIrregularSizeByIndex）
- (scroller?: Scroller, layoutOptions?: GridLayoutOptions): GridAttribute：Grid 的构造，layoutOptions 是第二个参数（出处：鸿蒙 SDK 的 ets/component/grid.d.ts，GridInterface）
- columnStart(value: number): GridItemAttribute；columnEnd(value: number): GridItemAttribute（GridItemAttribute 没有 columnSpan）：GridItem 跨列只能用起止列号（出处：鸿蒙 SDK 的 ets/component/gridItem.d.ts，GridItemAttribute.columnStart / GridItemAttribute.columnEnd）
针对本应用要查的：
- 广告或占位项插在第几个内容项之后、跨几列：源工程的网格页 Fragment 里 GridLayoutManager 的列数和 SpanSizeLookup，以及插入广告的 ViewModel 或适配器；读出 getSpanSize 对广告项返回的列数和插入间隔，按列数推算每个通栏项前面内容项的个数是否整除列数
未核实：卡里观察到的排布出自 API 24 目标 SDK，本机按 API 23 的声明核实；源端广告未加载时原版是否同样留半行空格，卡里没有截图；GridLayoutOptions 是否随状态变化重新求值，卡里没核实
