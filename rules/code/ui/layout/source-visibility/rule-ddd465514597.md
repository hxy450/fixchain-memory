# 源 XML 容器 visibility=invisible 且带 margin 时，目标在所有状态下都保留这块占位

审的是：代码
触发（任一种）：
- 读到：源布局里容器写 `android:visibility="invisible"`，并带 `android:layout_marginTop` 一类的边距（如广告位）；写错的样子：目标组件只在加载成功、失败等部分状态的 `if` 分支里渲染这个容器，默认态什么都不渲染，边距留白丢失
适用范围：界面转换阶段处理源端不可见但占位的容器时
做法：
- 这个容器在所有状态（含默认、隐藏态）都渲染，保留源端的边距留白（卡里修好的做法是给该区块固定高度）；里面的内容只在有内容的状态才放进去
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- View.INVISIBLE：不可见，但仍占布局空间：源端 invisible 容器连同 margin 一起占位（出处：android.view.View#INVISIBLE）
- 区块在所有状态下固定为源端留白的高度后，页面间距和安卓一致：修好的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 占位容器的边距和尺寸：源工程 res/layout 下页面布局 XML 里 visibility 为 invisible 的那个容器；读它的 layout_margin*、layout_height，引用 @dimen/ 的到 res/values 里取值
