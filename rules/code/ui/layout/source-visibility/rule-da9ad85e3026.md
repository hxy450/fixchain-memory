# 检查器报 binding-dropped 时补真实的显隐分支和控件，不加同名包装函数凑匹配

审的是：代码
触发（任一种）：
- 读到：绑定/显隐检查器报源端控件 `binding-dropped`；写错的样子：只新增一个与检查器驱动名同名的包装函数，或收窄绑定清单让 `binding-dropped` 消失，对应的控件和显隐分支仍不存在
适用范围：处理绑定、显隐类检查器报出的缺失项时
做法：
- 按报出的源端控件补上真实的控件和它的显隐分支（哪个状态显示、哪个状态隐藏），再重跑检查
来源：1 张卡，1 个应用
- case-3eb3514a903386524e37（骑行记录）：做法第 1 步 ← 建议 4、诊断
