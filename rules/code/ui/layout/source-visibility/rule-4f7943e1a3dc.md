# 源码按配置开关隐藏可选区块时，目标显隐沿用同一开关，不用列表非空推断

审的是：代码
触发（任一种）：
- 读到：Fragment 源码里由远端配置对象的布尔开关方法决定收益、签到、任务这类可选区块是否显示；写错的样子：目标把显隐开关写成几个接口列表任一非空（`.length > 0 || …`），源端开关关闭时这些区块在有数据时也露出来
适用范围：安卓页面里由运行时配置开关控制显隐的可选业务区块迁成 ArkUI 时
做法：
- 把源码里的开关判定接成目标的运行时配置项（同一个配置开关的布尔值），区块写在 if (<开关>) { … } 里；不由接口列表是否为空推断
针对本应用要查的：
- 可选区块的显隐判定条件：规格的源码锚点指向的 Fragment / Activity 源文件里，设置这些区块显隐的那段；读出判定用的是哪个配置开关（方法名和它读的配置项），目标照同一配置项取值
