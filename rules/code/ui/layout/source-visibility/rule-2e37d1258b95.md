# 源 XML 里 visibility="gone" 的节点不无条件渲染，与规格快照冲突时以源 XML 为准

审的是：代码
触发（任一种）：
- 读到：源布局里 TextView 等控件写 android:visibility="gone"，页面规格的快照却把它的文字列为可见文本；写错的样子：鸿蒙页 build 里无条件画出这个节点（如一个总在显示的标题 Text）
适用范围：UI 转换阶段把安卓布局 XML 翻成 ArkUI 页面时
做法：
- 源 XML 里 android:visibility="gone" 的节点默认不画，不无条件写进 build
- 页面规格的快照把它列为可见文本时，以源 XML 的 visibility 为准
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- visibility 的 gone = 2：完全隐藏，就像这个 View 没被加进来，不占位（出处：Android SDK 平台资源 data/res/values/attrs.xml，View 的 visibility 枚举 gone（按应用的 compileSdk 取对应平台））
- 去掉无条件渲染的标题后与源端一致：gone 节点在鸿蒙端不显示（出处：卡里修好并验证过）
