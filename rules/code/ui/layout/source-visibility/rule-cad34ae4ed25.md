# 展示条件和展示列表照源端：按源端字段决定显示与否，不自行往列表里插当前用户

审的是：代码
触发（任一种）：
- 读到：源端详情页对源数据的成员列表用 `for` 循环原样逐个构造头像，并按规则字段决定某一行（如重复结束）是否显示、无结束日期时写固定文案；写错的样子：目标端在成员列表缺当前用户时 .unshift(当前用户)，或把某行的显示条件改成另一个字段非空（如只在结束日期非空时显示）
适用范围：界面接线阶段，给详情 UiModel 的显隐条件和列表字段赋值时
做法：
- 显隐条件和列表都对照源端：某行按源端用的字段决定是否显示，源端在缺值时显示的固定文案照写；源端原样展示的列表按原序展示，不自行插入当前用户
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 成员非空时直接返回源数据的列表，不再插入当前用户：修好的做法（出处：卡里修好并验证过）
