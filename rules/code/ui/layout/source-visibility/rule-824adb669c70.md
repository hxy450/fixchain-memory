# ViewHolder.bind 对子控件分别 setVisibility 时逐个照搬条件，不包进一个共同条件

审的是：代码
触发（任一种）：
- 读到：ViewHolder.bind 里同一行的几个子控件各自 setVisibility(…)，条件不同；写错的样子：目标把整行包进一个 if (…) { Row() {…} }，该单独显示的控件也跟着隐藏
适用范围：移植 ViewHolder / Adapter 的绑定逻辑到 ArkUI 行组件时
做法：
- 每个子控件各写自己的显隐条件（if 或 .visibility(Visibility.None)），条件照源端 setVisibility 逐个搬
