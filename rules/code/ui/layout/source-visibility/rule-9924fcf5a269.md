# 源 Adapter 按条件显隐的子卡，目标都要建出，显示条件照源端写

审的是：代码
触发（任一种）：
- 读到：Adapter 绑定方法里按条件设子布局的 visibility（View.VISIBLE / View.GONE），控制一块附属子卡显不显示；写错的样子：目标区块里没有这块子卡对应的组件，也没有对应的 if 条件或 .visibility(...)；或者删掉了旧骨架里的入口，却没用等价组件替换
适用范围：按安卓 Adapter 重建 ArkUI 区块，源端有按条件显隐的附属子卡时
做法：
- 列出源 Adapter 里每个由 visibility 控制的子卡，逐个在目标区块里建出等价组件；显示条件照源端写：View.GONE 对应 if 不渲染或 .visibility(Visibility.None)，View.INVISIBLE 对应 .visibility(Visibility.Hidden)
- 删掉旧骨架里的入口前，先在源端找到它对应的完整区块，用等价组件替换，不留空
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- visibility(value: Visibility): T：组件的显隐属性（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.visibility）
- Visibility.Hidden：隐藏但占位；Visibility.None：隐藏且不占位：Hidden 对应安卓 View.INVISIBLE，None 对应 View.GONE（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，Visibility）
- View.INVISIBLE 不可见但仍占布局空间；View.GONE 不可见且不占空间：源端两种隐藏的区别（出处：android.view.View#INVISIBLE、android.view.View#GONE）
针对本应用要查的：
- 每块子卡的显示条件：源工程 Adapter 对应 item 类型的绑定方法里，对子布局设 visibility 的语句和它外面的条件；把条件原样写成目标端 if 的条件，或 .visibility 三元表达式的条件
