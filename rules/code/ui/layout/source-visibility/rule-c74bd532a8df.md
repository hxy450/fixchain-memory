# 规格规定按钮随某状态出现或隐藏时，状态层暴露该状态标志并在回调里置位刷新

审的是：代码
触发（任一种）：
- 读到：规格的 AC 条目写「某状态且某计数归零 → 按钮出现」「退出该状态 → 隐藏」；写错的样子：会话状态里只加了计数字段，没有这个状态的标志；进入状态的回调不置位、不刷新布局，build() 里没有按两个条件显示按钮的分支
适用范围：实现 ViewModel 或会话状态层，规格把按钮显隐挂在某个运行状态上时
做法：
- 会话状态里加一个可观察的状态标志，在进入、退出该状态的回调里置位或清除，并刷新布局
- build() 里按规格写的全部条件共同决定显隐（例：状态标志为真且待存计数为 0 时显示按钮），每个条件在状态层都有对应字段
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 会话状态新增暂停标志，进入暂停时置位并刷新布局；页面在暂停且真实待存数为 0 时显示两个按钮：卡里的修法（出处：卡里修好并验证过）
