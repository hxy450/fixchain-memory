# 源端按状态切换控件显隐时，目标照分支隐藏和显示对应区块，不以换文字替代

审的是：代码
触发（任一种）：
- 读到：源 Fragment 按登录等状态切换可见性：某个文字控件 `View.GONE`、另一块区域 `View.VISIBLE`，原来的 `setText` 赋值被注释掉；写错的样子：目标只改了 `Text(...)` 的内容（如登录时显示昵称、否则显示「未登录」），该状态下没有隐藏那个控件，也没有渲染应显示的区块
适用范围：迁移源端按状态切换控件显隐的头部、卡片等区域时（含巡检修复）
做法：
- 同时看源端的 setText 和 setVisibility：每个状态写一个分支，`if (状态) { 该显示的区块 } else { 另一状态的控件 }`，GONE 的控件在该分支里不渲染
- 被注释掉的赋值加上 GONE 表示该状态不显示这个控件，不回退成显示昵称或占位文字；巡检项写了「隐藏什么、显示什么」的，逐项落实
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- View.GONE：不可见且不占布局空间：源端该状态下这个控件完全不出现（出处：android.view.View#GONE）
针对本应用要查的：
- 每个状态下哪些控件隐藏、哪些显示：源工程里该页面 Fragment/Activity 的状态处理方法（按登录态等更新界面的方法）；逐个读 setVisibility 的参数和 setText 的赋值（含被注释掉的），列成「状态 → 隐藏、显示的控件」
