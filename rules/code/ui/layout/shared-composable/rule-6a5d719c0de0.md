# 用共享包装组件替换页内副本、去掉宿主显式高度前，先查组件 build() 里的 '100%'

审的是：代码
触发（任一种）：
- 写错的样子：宿主外层原来写死的 .height(N) 被删掉、改用共享包装组件，而组件 build() 里有 .height('100%') / .width('100%') 的节点，父级没有确定尺寸
适用范围：收口阶段用共享组件替换页内副本、调整宿主尺寸时
做法：
- 逐个检查组件 build() 里的 '100%'；父级未定尺寸就先修组件（按实测尺寸定数值），或保留宿主按源端测量的显式高度，不以「Stack 随内容定高」推断 '100%' 等于内容高
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 尺寸用百分比设置时，参考最近设置了固定大小的祖先节点的尺寸：宿主去掉显式高度后，组件里的 '100%' 会改按更外层祖先解析（出处：ts-universal-attributes-size.md，尺寸设置（说明））
