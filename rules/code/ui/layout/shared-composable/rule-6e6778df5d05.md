# 页面源码用了共享组件时，复用目标共享件，不内联近似版、不照搬先例

审的是：代码
触发（任一种）：
- 读到：页面源码调用了源工程公共文件里定义的共享组件或修饰符（如包着 `LinearProgressIndicator()` 的加载条、自定义滚动条 Modifier）；写错的样子：页面里内联了近似版（如 `Progress({ value: 30 })`、24vp 的 `LoadingProgress`），或注释写照兄弟页写法、「既有决策」「无 ArkUI 等价」后照搬
适用范围：页面转换时遇到源端共享组件，目标端已有或应有对应共享件
做法：
- 先读这个共享组件在源端的定义，再 import 目标端对应的共享件使用；目标端还没有的，补进共享组件，不在页面里内联
- 兄弟页或注释里的先例只作参考：先例是静止条、换了形状的替代件或写着「无等价」的，按源端定义纠正
针对本应用要查的：
- 共享组件在源端的定义：页面源码里按组件名跳到源工程的公共 UI 文件，读函数体；看它实际用的库组件和参数（是否不定进度、是否叠放、滚动条参数），对照目标共享件是否一致
