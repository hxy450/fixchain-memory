# 共享组件已存在且验收目标指向它时，页内副本要替换成共享组件，不能两套并存到交付

审的是：代码
触发（任一种）：
- 读到：规格的验收目标是 components 下的共享组件，页内却有一份等价的 @Component / @Builder 副本；写错的样子：交付时页内副本仍在用，components 下的共享 @Component 没有任何页面 import；理由写成修改范围只有本页、只解除标记
适用范围：切片实现阶段，页面里有转换期留下的页内副本、同名职责的共享组件已经实现时
做法：
- 先逐项比较页内副本与共享组件（格式、字重、行数等），把页面改为使用共享组件并删掉页内副本
- 修改范围不允许替换时，登记两者的差异和回收任务，不让两套实现并存到交付
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 删除页内副本和页内格式化函数，改用共享组件：修好后步骤行与源一致，只剩一套实现（出处：卡里修好并验证过）
