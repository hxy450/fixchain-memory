# 按计划把页面局部实现换成共享组件前，先比对被删的 builder，缺的补进共享组件

审的是：代码
触发（任一种）：
- 读到：计划或派工要求把页面里局部的 @Builder 实现换成共享组件调用；写错的样子：改动删掉了页面里原有的 @Builder 调用、换成共享组件，被删的 builder 里有共享组件对应变体没有的子节点（如勾选、第二行文案）
适用范围：接线或收口阶段按计划用共享组件替换页面局部实现时
做法：
- 替换前完整读取将被删除调用的 @Builder，逐个子节点和共享组件的对应变体比对
- 局部实现更完整时，先把差异补进共享组件的这个变体，或在回执里报缺口，再切换调用
来源：1 张卡，1 个应用
- case-a3404675917f8a352eb9（话费流量查询助手）：做法第 1 步 ← 建议 3；做法第 2 步 ← 建议 3
