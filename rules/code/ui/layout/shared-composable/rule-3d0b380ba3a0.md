# 把共享组件替换进已有页面时按源码调用点和组件默认，不为旧外观覆写形状参数

审的是：代码
触发（任一种）：
- 读到：源码调用点没有传形状参数，组件定义里默认 CircleShape；写错的样子：给共享组件新增 `cornerRadius` 参数并在调用处传 `cornerRadius: 0`，沿用旧页面的矩形外观
适用范围：修复或接线阶段用共享组件替换页面里已有的内联实现时
做法：
- 替换时以源码调用点和组件默认为准，不新增或覆写形状参数；确需覆写先核对源码该调用点是否真有不同形状
