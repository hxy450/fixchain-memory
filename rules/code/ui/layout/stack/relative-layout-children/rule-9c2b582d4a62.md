# Stack 里要钉在顶部或角落的子节点用 .position 或父级 alignContent，不用 .align

审的是：代码
触发（任一种）：
- 读到：MaterialToolbar 带 app:layout_collapseMode="pin" 或 android:layout_alignParentTop 钉在顶部；子 View 用 android:layout_gravity / layout_alignParentBottom 贴父边或角；写错的样子：工具栏写 .align(Alignment.Top)、装饰写 .align(Alignment.BottomStart)，所在 Stack 没设 alignContent，仍被居中
- 读到：FrameLayout 叠层子项 android:layout_gravity="top" / "bottom|center"；映射参考写 layout_gravity → .align()；写错的样子：Stack 子项写 .align(Alignment.Top) / .align(Alignment.Bottom)，根 Stack 默认居中，这些子项都落在中间
适用范围：源端子视图贴父布局边或角，目标放进 ArkUI Stack 叠层时
做法：
- 贴顶写 .position({ x: 0, y: 0 })，贴底写 .position({ left: 0, bottom: 0 })，角落按父级尺寸算坐标；整组子层贴同一边时，父级写 Stack({ alignContent: Alignment.Top }) 这类
- .align() 只对齐组件自身的内容，不用它定位组件本身；也可用 markAnchor，或满尺寸外包容器（满宽 Row）的 justifyContent
- 转换后按源布局逐个核对叠层子项在根 Stack 里的位置
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- align(value: Alignment): T，默认 Alignment.Center；设置组件内容在绘制区域内的对齐方式：只管自身内容，不改组件在 Stack 里的位置（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.align；ts-universal-attributes-location.md，align）
- position(value: Position | Edges | LocalizedEdges): T（Edges 写法 @since 12）：相对父组件的绝对定位，可用 x / y 或 top / bottom / left / right（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.position）
- markAnchor(value: Position | LocalizedPosition): T：定位锚点，配合 position 使用（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.markAnchor）
- Stack(options?: StackOptions)，StackOptions.alignContent 默认 Alignment.Center：不设 alignContent 也不 position 时，子组件在 Stack 里居中叠放（出处：鸿蒙 SDK 的 ets/component/stack.d.ts，StackOptions.alignContent；ts-container-stack.md，StackOptions）
- alignContent(value: Alignment): StackAttribute：同族接口：Stack 设置容器内所有子项的对齐，是容器级的一个值（出处：鸿蒙 SDK 的 ets/component/stack.d.ts，StackAttribute.alignContent）
- alignContent(value: Alignment): FolderStackAttribute：同族接口：FolderStack 的对齐属性（出处：鸿蒙 SDK 的 ets/component/folder_stack.d.ts，FolderStackAttribute.alignContent）
- 工具栏改成 .position({ x: 0, y: 0 })、控制栏改成 .position({ left: 0, bottom: 0 }) 后回到顶部和底部：position 定位是上机核对过的写法（出处：卡里修好并验证过）
