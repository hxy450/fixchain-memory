# RelativeLayout 带 gravity 时子项整组平移，alignParentTop 不抵消居中

审的是：代码
触发（任一种）：
- 读到：RelativeLayout 设 android:gravity="center_vertical"，子 TextView 同时声明 android:layout_alignParentTop / android:layout_alignParentStart；写错的样子：目标容器写成 Stack().alignContent(Alignment.TopStart)，把子项钉在顶部；理由是 gravity 对带 align 规则的子项无效
适用范围：界面实现阶段把带 android:gravity 的 RelativeLayout（如横屏布局的一列）映射为 ArkUI 容器对齐时
做法：
- 按 RelativeLayout.onMeasure 的语义：先按 alignParent* 和 margin 排好子项，再把全部可见子项（ignoreGravity 指定的除外）作为一组按 gravity 平移，alignParentTop 不会抵消 center_vertical
- ArkUI 侧用容器内容对齐让整组居中、保留组内相对偏移：如 Stack().alignContent(Alignment.Start)（纵向居中、横向起始），或 Column().justifyContent(FlexAlign.Center)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- if (horizontalGravity || verticalGravity) { Gravity.apply(mGravity, …); 对每个 child != ignore 且非 GONE 的子项 params.mTop += verticalOffset … }：onMeasure 末尾按 gravity 算整组包围盒的偏移，平移全部可见子项，只有 ignoreGravity 指定的除外（出处：android.widget.RelativeLayout#onMeasure）
- alignContent(value: Alignment): StackAttribute，默认 Alignment.Center：Stack 里所有子组件在容器内的对齐方式（出处：鸿蒙 SDK 的 ets/component/stack.d.ts，StackAttribute.alignContent；ts-container-stack.md，alignContent）
- Alignment.Start：起始端纵向居中：对应 center_vertical + 起始端（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，Alignment.Start）
- justifyContent(value: FlexAlign): ColumnAttribute：Column 子组件在纵向的对齐方式，FlexAlign.Center 整组纵向居中（出处：鸿蒙 SDK 的 ets/component/column.d.ts，ColumnAttribute.justifyContent）
- alignContent(value: Alignment): FolderStackAttribute：同族接口：FolderStack 的子组件对齐（出处：鸿蒙 SDK 的 ets/component/folder_stack.d.ts，FolderStackAttribute.alignContent）
- 横屏左列改为 alignContent(Alignment.Start)：返修后标题在左列纵向居中，与安卓一致（出处：卡里修好并验证过）
