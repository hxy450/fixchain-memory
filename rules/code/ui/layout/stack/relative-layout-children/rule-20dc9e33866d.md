# layout_centerVertical 按钮带 layout_below 标签时，按钮保持源尺寸、标签做下挂层

审的是：代码
触发（任一种）：
- 读到：RelativeLayout 里按钮 android:layout_centerVertical="true"、尺寸各不相同（如侧键 48dp、主键 64dp），TextView 标签 android:layout_below 指向按钮，兄弟之间有 android:layout_marginStart 等固定 margin；写错的样子：每个按钮连同标签包进统一大小的 Column 槽位竖排居中，带标签的图标被顶高、各键不在同一高度；按钮上源端的 margin 没写
适用范围：安卓 RelativeLayout 控件排里按钮按竖直居中排、文字标签挂在按钮下方，转写成 ArkUI Row 时
做法：
- 按钮本体保持源尺寸（源 dp 数值写成 vp），所在 Row 设 .alignItems(VerticalAlign.Center) 对齐
- 标签做成不占行高的下挂层：按钮和标签放进与按钮同尺寸的 Stack，标签用 .position({ x: …, y: <按钮高> }) 挂到按钮下方；或放进 RelativeContainer，用 .alignRules 把标签的 top 锚到按钮的 bottom
- 逐个兄弟补齐源 margin（如源 layout_marginStart 12dp，对应组件上写 12vp 的起始外边距），不用统一的大槽位撑间距
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- alignItems(value: VerticalAlign): RowAttribute：Row 里子项的竖直对齐（出处：鸿蒙 SDK 的 ets/component/row.d.ts，RowAttribute.alignItems）
- VerticalAlign.Center：竖直居中，是默认的对齐方式（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，VerticalAlign.Center）
- position(value: Position | Edges | LocalizedEdges): T：相对父组件的绝对定位；标签用它下挂后不占 Row 的行高（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.position）
- alignRules(value: AlignRuleOption): T：RelativeContainer 子组件的锚点对齐规则（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.alignRules）
- 侧键 48vp 的 Stack、标签用 position 下挂且不占行高、补 marginStart、Row 设 alignItems Center 后各键同一高度、间距与源一致：修好后的结构（出处：卡里修好并验证过）
- offset(value: Position | Edges | LocalizedEdges): T：同族接口：相对自身原位置的偏移，同样不改变布局占位（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.offset）
