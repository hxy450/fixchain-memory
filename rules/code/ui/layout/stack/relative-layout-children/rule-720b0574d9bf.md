# RelativeLayout 里在滚动容器外的兄弟视图要放在 Scroll 外，不用 Blank 占位塞进 Scroll

审的是：代码
触发（任一种）：
- 读到：RelativeLayout 里有兄弟视图位于 ScrollView / NestedScrollView 之外，滚动容器用 android:layout_below="@+id/…" 排在它下面；写错的样子：目标把这个固定视图连同 Blank().height(N) 占位一起放进 Scroll 内的 Column 首部，随内容一起滚动
适用范围：安卓 RelativeLayout 页面里固定区和滚动区是兄弟关系，迁成 ArkUI Scroll 页面时
做法：
- 先列出哪些兄弟视图在 ScrollView / NestedScrollView 之外、滚动区 layout_below 哪个锚点；只把滚动容器里的子视图放进 Scroll
- 固定视图放在 Scroll 外：分区 Column（固定视图在前、Scroll 在后），或在 Stack 上层用 .position({ x: <左偏移>, y: <源 marginTop> }) 加 .zIndex(1) 定位，Scroll 内首部用 Blank().height(<固定区下沿>) 给它留位
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- position(value: Position | Edges | LocalizedEdges): T：相对父组件的绝对定位，用于把固定视图钉在 Stack 上层（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.position）
- zIndex(value: number): T，同一容器的兄弟组件按值分层，值大的在上：让固定视图压在 Scroll 上面（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.zIndex）
- 固定视图移出 Scroll，用 position 和 zIndex 钉在 Stack 上层，Scroll 内用 Blank 留出固定区高度，构建通过、页面滚动时固定区不动：修好的写法（出处：卡里修好并验证过）
