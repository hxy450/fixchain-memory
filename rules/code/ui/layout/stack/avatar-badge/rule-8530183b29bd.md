# 从现有 ArkTS 片段抽取共享组件时，把旧片段当待验证草稿，逐项对照已读的源 XML

审的是：代码
触发（任一种）：
- 读到：同时读到了源布局 XML（如角标 `android:layout_gravity`、头像无 stroke）和现有 ArkTS 列表项里的同一片段；写错的样子：新共享组件照搬旧片段里与源 XML 不符的写法（如角标 `.align(Alignment.BottomEnd)`、头像 `.border`），注释却写「严格复用 Android 的尺寸和策略」
适用范围：从目标工程已有实现中提取公共组件时
做法：
- 复用旧片段前逐项对照已读取的源 XML：位置、尺寸、描边、缩放方式、重叠步距；不一致处按源 XML 改，不以旧片段为真值
