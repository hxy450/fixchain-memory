# 要把 Stack 子项钉到顶或底时，不写子项的 .align()，改用 position 或外包全屏容器

审的是：代码
触发（任一种）：
- 读到：Compose `Box` 子项上的 `Modifier.align(Alignment.BottomCenter)`，把底栏钉在底部；写错的样子：Stack 子项上写 `.align(Alignment.Top)` / `.align(Alignment.Bottom)`，或把 `.align(Alignment.Bottom)` 写进子项 @Builder 里 Row 的修饰链，想把它定到顶部或底部
适用范围：ArkUI Stack 的子项需要各自贴顶、贴底时
做法：
- .align() 只对齐组件自身的内容，不改变它在 Stack 里的位置；Stack 子项按 alignContent（默认 Alignment.Center）摆放。要贴顶贴底的子项改用 position、alignContent 或 alignRules
- 验证过的写法：顶栏 .position({ x: 0, y: 0 }).zIndex(<高于内容的层级>)；底栏外包 Column() { Blank().layoutWeight(1); 底栏 }.width('100%').height('100%').hitTestBehavior(HitTestMode.Transparent)
- 定位属性写在包住 @Builder 调用的容器上：@Builder 调用点后面不能链式调用属性方法，编译报错
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- align(value: Alignment): T，默认 Alignment.Center：设置组件绘制区域内内容的对齐方式，不是自身在父容器里的位置（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.align）
- 在 Stack 中 align 与 alignContent 效果一致，只能设置子组件在当前组件内的对齐方式：写在 Stack 子项上的 .align() 只影响这个子项自己的内容（出处：ts-universal-attributes-location.md，align）
- alignContent(value: Alignment): StackAttribute；StackOptions.alignContent 默认 Alignment.Center：Stack 用一个对齐方式摆放全部子项（出处：鸿蒙 SDK 的 ets/component/stack.d.ts，StackAttribute.alignContent、StackOptions.alignContent）
- alignContent(value: Alignment): FolderStackAttribute：同族接口：FolderStack 的子项对齐（出处：鸿蒙 SDK 的 ets/component/folder_stack.d.ts，FolderStackAttribute.alignContent）
- 子项写 .align(Alignment.Bottom) 后两栏都按 Stack 默认居中，底栏显示在页面中间：子项 .align() 不起定位作用的上机现象（出处：卡里修好并验证过）
