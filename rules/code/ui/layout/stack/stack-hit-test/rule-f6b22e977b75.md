# 给自定义组件实例加 margin 等通用属性时，同时写 hitTestBehavior

审的是：代码
触发（任一种）：
- 写错的样子：自定义组件实例上直接写 .margin({ top: ... }) / .padding / .position，没有 .hitTestBehavior，提示条显示期间挡住其下工具栏
适用范围：在父组件里给自定义组件实例加通用属性，且这个实例叠在其他可交互内容上（如源端不拦截触摸的提示条容器）时
做法：
- 给实例加 margin / padding / position 等通用属性时，同时写 .hitTestBehavior(HitTestMode.None) 或 HitTestMode.Transparent；或者像外包一个 Column 承载 margin 并显式 Transparent
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 自定义组件实例上的通用属性会生成一个缺省命中的包装节点；给实例补 hitTestBehavior(HitTestMode.None) 后不再遮挡工具栏：问题的来源和修复（出处：卡里修好并验证过）
- hitTestBehavior(value: HitTestMode): T；缺省 Default 挡住兄弟节点：包装节点不设时就按 Default 命中（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.hitTestBehavior）
未核实：包装节点（__Common__）是卡里上机看到的节点名，本机声明和文档里没查到说明
