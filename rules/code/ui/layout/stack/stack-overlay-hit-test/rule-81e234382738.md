# Stack 里盖在可点内容上的全尺寸浮层容器按开合写 hitTestBehavior，关闭态 Transparent

审的是：代码
触发（任一种）：
- 读到：Compose 的 ModalNavigationDrawer(drawerState)：关闭态下内容照常可交互，打开时由遮罩拦截；写错的样子：Stack 里 width('100%').height('100%') 的抽屉浮层容器没写 hitTestBehavior（缺省 Default），只给里面的唤起条或旁边的 Snackbar 宿主层写了 HitTestMode.Transparent
适用范围：Stack 中叠在可点击内容之上的全尺寸容器，包括只承载条件遮罩和平移到屏外的面板的抽屉浮层容器
做法：
- 在浮层容器本身写 .hitTestBehavior(isOpen ? HitTestMode.Default : HitTestMode.Transparent)：打开时拦截，关闭时点击交给下层
- Stack 里每个位于可点击内容之上的全尺寸容器都显式写命中模式，不能只写在它的子节点或相邻宿主层上
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- hitTestBehavior(value: HitTestMode): T：组件在触摸命中测试中的行为（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.hitTestBehavior）
- HitTestMode.Default：自身和子节点响应，挡住被它遮住的其他节点：不写 hitTestBehavior 时的缺省，全尺寸容器会挡住下层兄弟（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，HitTestMode.Default）
- HitTestMode.Transparent：自身和子节点响应，同时放行被它遮住的其他节点：关闭态浮层用它，下层照常可点（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，HitTestMode.Transparent）
- 浮层 Stack 写 hitTestBehavior(isOpen ? Default : Transparent) 后，关闭态下层页面恢复可点：命中模式要写在浮层容器本身（出处：卡里修好并验证过）
