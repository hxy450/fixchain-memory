# 接入或替换共享组件时保留挂载点的 hitTestBehavior，实例带通用属性就写 Transparent

审的是：代码
触发（任一种）：
- 读到：原挂载点写着 .width('100%').height('100%').zIndex(...).hitTestBehavior(HitTestMode.None)，组件头注释称组件自身不拦截；写错的样子：换装后删掉了挂载点的 .hitTestBehavior(...)，实例上仍保留 width / height / zIndex 等通用属性
适用范围：页面挂载、接入或替换叠在可点击内容之上的共享组件时
做法：
- 保留挂载点已有的 hitTestBehavior；实例上带通用属性时写成 组件实例().width('100%').height('100%').zIndex(n).hitTestBehavior(HitTestMode.Transparent)
- 组件契约里说组件自身不拦截，不作为删掉挂载点命中设置的依据；只在播放期间条件挂载也不能代替实例上的 Transparent
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 已按播放期间条件挂载，播放期间仍点不动；挂载实例上加 Transparent 后修好：条件挂载只解决空闲期，播放期间要靠实例上的命中设置（出处：卡里修好并验证过）
- 给自定义组件设通用属性时，相当于给它套了一个不可见的容器组件，属性设在这个容器上：实例上写的 hitTestBehavior 落在这个外层容器上（出处：arkts-create-custom-components.md，自定义组件通用样式）
