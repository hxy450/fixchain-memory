# 用共享组件替换页内浮层片段时核对层叠关系，改了面板挂载方式要重核宿主的全尺寸层

审的是：代码
触发（任一种）：
- 读到：被替换的页内片段是 Stack 里全幅透明捕获层后接面板的 @Builder 调用，注释写「面板 z 序居上」；写错的样子：接线时删掉面板调用、保留后声明的全幅捕获层，注释改成「浮层本体由组件 overlay 渲染」；组件里的面板已改挂 .overlay()，与宿主捕获层重叠
适用范围：结构收口阶段用共享组件替换页面里已实现的标题栏与浮层片段时
做法：
- 比对项除颜色、图标、形状、内边距外，还列被删片段的层叠和事件关系：浮层与点外关闭层的声明顺序、注释里的 z 序约束、点外和返回两条关闭路径；替换后逐项仍成立
- 按「组件不符先修组件」改了面板的几何或挂载方式（.overlay()、position、移出原容器）后，逐个检查宿主里保留的、后声明的全尺寸层是否与面板重叠；重叠的改成遮罩与面板同层、面板在上
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 右子树（后声明的兄弟）显示在上方；HitTestMode.Default 的组件命中后阻塞兄弟组件：宿主后声明的全尺寸层盖住面板时，面板收不到点击（出处：arkts-interaction-basic-principles.md，事件响应链、干预命中）
- overlay(value: string | CustomBuilder | ComponentContent, options?: OverlayOptions): T：.overlay() 是给当前组件加的浮层，挂在这个组件节点上，跟着它在兄弟层里的先后（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.overlay）
未核实：.overlay() 浮出部分与宿主后声明兄弟层的命中先后，是按卡里实测现象和文档的兄弟层规则推断的
