# 共享组件的层契约不声称自身不拦截，写明挂载实例上写 Transparent

审的是：代码
触发（任一种）：
- 读到：源端 KonfettiView 这类一次性动效层不处理指针输入，叠在可点击内容之上；写错的样子：自定义组件只在 build 根节点（如 Canvas）写 .hitTestBehavior(HitTestMode.Transparent)，头注释写成「组件根节点 Transparent，遮不住底层」
适用范围：编写会被叠在可点击内容之上的共享自定义组件，并在组件里写层契约注释时
做法：
- 契约注释写明：调用处写 width / height / zIndex 等通用属性会在实例外生成缺省 Default 命中的外层节点，组件内部设不到它；挂载实例上要写 .hitTestBehavior(HitTestMode.Transparent)，或者调用处不写通用属性
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 给自定义组件设通用属性时，相当于给它套了一个不可见的容器组件，属性设在这个容器上：调用处的 width / height / zIndex 落在外层容器上，组件内部根节点的命中设置管不到它（出处：arkts-create-custom-components.md，自定义组件通用样式）
- 只在组件内部 Canvas 上写 Transparent、调用处带 width/height/zIndex 时，播放期间外层节点按 Default 拦截；在挂载实例上加 Transparent 后修好：命中设置要写在调用处的实例上（出处：卡里修好并验证过）
