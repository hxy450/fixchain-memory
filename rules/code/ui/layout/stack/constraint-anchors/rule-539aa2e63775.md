# ConstraintLayout 子块约束到 parent 首尾时，目标居中叠放，不放进带 Blank() 的 Row

审的是：代码
触发（任一种）：
- 读到：ConstraintLayout 里一个子 View 同时写 app:layout_constraintStart_toStartOf="parent" 和 app:layout_constraintEnd_toEndOf="parent"，在整卡中水平居中，另有元素贴 parent 末端；写错的样子：目标把这个块放进横向 Row，排在 Blank() 之后、紧挨贴末端的元素，块被推到右侧
适用范围：把 ConstraintLayout 列表项或卡片迁成 ArkUI 时，逐个子 View 核对首尾约束
做法：
- 逐个子 View 核对约束；同时约束到 parent 首尾的块，放进 Stack（默认 alignContent 为 Alignment.Center）居中叠放，贴末端的元素另用 .align / 定位放到末端
- 或者用 RelativeContainer：这个块写 .alignRules({ middle: { anchor: '__container__', align: HorizontalAlign.Center } }) 居中对齐容器
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- StackOptions.alignContent 默认 Alignment.Center：不写对齐时 Stack 里的子组件居中叠放（出处：鸿蒙 SDK 的 ets/component/stack.d.ts，StackOptions.alignContent）
- alignRules(value: AlignRuleOption): T：RelativeContainer 子组件的相对对齐规则，AlignRuleOption 有 left、right、middle、top、bottom、center、bias（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.alignRules、AlignRuleOption.middle）
- __container__：RelativeContainer 父容器作锚点时的组件标识（出处：arkts-layout-development-relative-layout.md，锚点设置）
