# 贴末端加 marginEnd 的约束改用 Row + Blank，不用百分比 position x

审的是：代码
触发（任一种）：
- 读到：ConstraintLayout 里的控件 app:layout_constraintEnd_toEndOf="parent" 加 android:layout_marginEnd；写错的样子：目标写成 .position({ x: '72%', y: … }) 这类按宽度百分比算的横坐标
适用范围：把 ConstraintLayout 里贴父容器末端并带末端间距的控件转成 ArkUI 时
做法：
- 写成 Row() { 左侧内容; Blank(); 控件.margin({ right: 源 marginEnd 的数值 }) }，也可用 alignRules 等末端锚定；保留源端末端间距，不换成百分比 x
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- (min?: number | string): BlankAttribute：Blank 在 Row/Column/Flex 主轴上填满剩余空间，min 默认 0（出处：鸿蒙 SDK 的 ets/component/blank.d.ts，BlankInterface）
- 空白填充组件，在容器主轴方向上具有自动填充容器空余部分的能力，仅当父组件为 Row/Column/Flex 时生效：Blank 的生效条件（出处：ts-basic-components-blank.md，Blank）
- margin(value: Margin | Length | LocalizedMargin): T：给控件留末端间距（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.margin）
- alignRules(value: AlignRuleOption): T：RelativeContainer 子组件的锚点对齐规则（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.alignRules）
- 会员行改为 Row + Blank：修好的写法（出处：卡里修好并验证过）
