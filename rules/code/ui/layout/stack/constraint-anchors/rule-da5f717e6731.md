# ConstraintLayout 标题栏左右入口约束到 start/end 时，用 Row 三段槽位，不用 Stack

审的是：代码
触发（任一种）：
- 读到：ConstraintLayout 标题栏：返回入口 app:layout_constraintStart_toStartOf="parent"，右侧文字或图标 app:layout_constraintEnd_toEndOf="parent"，标题 android:layout_width="0dp" 两端约束到 parent 并带 android:layout_marginStart / layout_marginEnd；写错的样子：写成 Stack({ alignContent: Alignment.Center })，返回 Image 只加 .align(Alignment.Start)、右侧加 .align(Alignment.End)，标题 Text 用 .width('100%') 加左右 padding
适用范围：把「左返回、居中标题、右操作」的 ConstraintLayout 标题栏（含 include 的公共标题栏）转成 ArkUI 页面或公共组件时
做法：
- Row 建互斥的水平槽位：左侧固定宽槽（宽取源标题的 marginStart）放 start 约束的返回入口、槽内靠左；中间标题 .layoutWeight(1) 居中；右侧固定宽槽（宽取 marginEnd）放 end 约束的入口、槽内靠右；底部分隔线放在 Row 下方
- 也可用 RelativeContainer，子组件用 .alignRules 对应源端的 start / end 约束
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- layoutWeight(value: number | string): T：在 Row / Column / Flex 主轴上按权重分剩余空间，标题槽用 1（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.layoutWeight）
- alignRules(value: AlignRuleOption): T：RelativeContainer 子组件的对齐规则，只在父容器是 RelativeContainer 时生效（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.alignRules）
- Row：左槽（宽 = 源 marginStart，Start）+ layoutWeight(1) 标题 + 右槽（宽 = 源 marginEnd，End），分隔线在 Row 下方：修好后返回、标题、右侧入口互不重叠（出处：卡里修好并验证过）
针对本应用要查的：
- 左右槽宽度：源工程标题栏布局 XML 里标题控件的 android:layout_marginStart / layout_marginEnd；读出 dp 值，按 vp 写成左右槽的宽度
