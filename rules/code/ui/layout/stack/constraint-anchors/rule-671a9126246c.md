# Stack 里要贴边的子组件不靠自身 .align()，改放 Row 槽位或用 position/offset

审的是：代码
触发（任一种）：
- 读到：源布局里子控件约束到父容器的一边（app:layout_constraintStart_toStartOf / layout_constraintEnd_toEndOf / layout_constraintBottom_toBottomOf="parent"）；写错的样子：Stack 的子组件上写 .align(Alignment.Start)、.align(Alignment.End) 或 .align(Alignment.Bottom)，想让它贴左、贴右或贴底
适用范围：目标用 Stack 叠放、其中有子组件需要贴边定位时
做法：
- 逐个核对 Stack 内需要贴边的子组件：放进 Row 的左右槽位，或用 .position / .offset 定位，或改用 RelativeContainer + alignRules；Stack 子组件的位置只由 Stack 的 alignContent 决定
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- align(value: Alignment): T：设置当前组件绘制区域内子组件的对齐方式，默认 Alignment.Center；不移动组件自身（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.align）
- 在 Stack 中 align 与 alignContent 效果一致，只能设置子组件在当前组件内的对齐方式：给 Stack 的子组件写 .align 不会让它在 Stack 里贴边（出处：ts-universal-attributes-location.md，align）
- alignContent(value: Alignment): StackAttribute：Stack 内所有子组件的对齐方式（出处：鸿蒙 SDK 的 ets/component/stack.d.ts，StackAttribute.alignContent）
