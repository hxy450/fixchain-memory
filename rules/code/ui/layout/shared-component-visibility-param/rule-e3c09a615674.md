# 源 Fragment 自带第二轮装载再定显隐时，目标组件内也做这一轮，不等宿主

审的是：代码
触发（任一种）：
- 读到：源 Fragment 的 `Maybe` 装载链在首轮成功后某项数据仍为 null 就再装载一次，装完再重算控件显隐；第二轮完成前只用一个临时字段兜底；写错的样子：目标组件注释写「装载链不在此重复」，数据为 null 时一直用临时字段，重算只挂在 `@Monitor` 宿主换新实例上，组件内没有第二轮装载，也没有登记 `FWD-REF`
适用范围：迁移在组件内部有两轮装载、按第二轮结果重算显隐的 Fragment 时
做法：
- 在目标组件内补上第二轮装载，装完按真实数据重算显隐；宿主没有约定交付新实例时，不靠宿主触发
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 组件内补一轮装载后重算按钮显隐，临时字段为真而实际没有数据的条目不再显示按钮：修好的写法（出处：卡里修好并验证过）
