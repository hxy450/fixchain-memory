# 组件来源列了 Adapter 时，显隐按它的 setVisibility 分支定，不按 XML 初值

审的是：代码
触发（任一种）：
- 读到：共享组件表把某个 `Adapter` 列为组件来源，Adapter 的 `getView` / bind 方法里对 TextView 按状态 `setText`、`setVisibility(...)`；写错的样子：组件的显隐条件只按 XML 里 `android:visibility` 的初值或按空串判断写，和 Adapter 各分支（如某些类型文件名为空也 VISIBLE）不符
适用范围：把带 Adapter 的列表项、网格项迁成 ArkUI 公共组件时
做法：
- 写组件前读 Adapter 的 getView / bind 中对该 TextView 的 setText、setVisibility 分支，按每个状态的分支写组件的显隐（VISIBLE → Visible，INVISIBLE → Hidden，GONE → 不渲染），不以 XML 初值代替
针对本应用要查的：
- 每种状态下控件的显隐和文本：源工程里共享组件表列出的 Adapter 类，getView / onBindViewHolder / 自定义 bind 方法；逐个分支读 setVisibility 的参数和 setText 的来源，列成「状态 → 显隐、文本」
