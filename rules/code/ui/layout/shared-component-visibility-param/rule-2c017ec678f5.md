# 共享组件的构造态与绘制后状态不同时，加构造态参数，只在已绘制且值为 0 时隐藏

审的是：代码
触发（任一种）：
- 读到：源控件构造时就设好背景、保持 View.VISIBLE，只有绘制方法在值为 0 时 setVisibility(View.INVISIBLE)；有的层只构造、从不调绘制方法；写错的样子：共享组件写成 .visibility(值 === 0 ? Visibility.Hidden : Visibility.Visible)，没有参数能表示「构造后没绘制」的可见空格
适用范围：把同一个源控件的多个使用层交给一个共享 ArkUI 组件渲染时
做法：
- 给组件加一个表示已绘制 / 构造态的参数（如 drawn，默认 true），写成 .visibility(drawn && 值 === 0 ? Visibility.Hidden : Visibility.Visible)，只构造的那一层传 drawn: false
- 对规格列出的每个使用层（底格层、活动层）各核一次渲染结果
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- visibility(value: Visibility): T：组件可见性（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.visibility）
- Visibility.Hidden：隐藏但参与布局占位；Visibility.None：隐藏且不参与布局：Hidden 对应源端 INVISIBLE（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，Visibility）
- drawn 参数默认 true，只有 drawn && number === 0 才隐藏，底格层传 drawn: false 后整片底格恢复：修好后的写法（出处：卡里修好并验证过）
