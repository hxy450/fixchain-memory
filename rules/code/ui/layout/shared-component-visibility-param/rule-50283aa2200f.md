# 子页面带默认值的 @Param 都要由宿主给出真实来源，撤掉传参时改派生或在回执列未决

审的是：代码
触发（任一种）：
- 读到：子页面声明了带默认值的 @Param（类型为 number、默认 0 这类），取默认值时拦截新增或切换条目元信息；源端按当前所选对象的 type 控制新增按钮显隐和条目元信息；写错的样子：宿主创建子页面时没传这个 @Param，或传了又删掉，子页面一直落在默认值上；回执里也没列为未决
适用范围：页面宿主接线、决定给子页面传哪些参数时
做法：
- 接线前列出子页面所有带默认值的 @Param，逐个写明宿主里的真实来源；源端按当前对象 type 切换显示的，按宿主当前模型的 type（或已约定的「全部」标识）派生后传入
- 撤掉某个传参时，同时改成别的派生来源（如改用当前 ID 是否为空控制显示和校验），或在回执里列为未决
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- @Param 装饰的变量支持本地初始化，能在初始化自定义组件时从外部传入，但不允许在组件内部直接修改：宿主不传时子组件只能一直用本地初始化的默认值（出处：arkts-new-param.md，概述）
