# 安卓 dp 尺寸写成 ArkUI 数字（vp），不写 'px' 字符串；1dp 细线也按 1vp

审的是：代码
触发（任一种）：
- 读到：源端尺寸以 dp 给出（如 `list_divider_material` 的 `android:height="1dp"`）；写错的样子：ArkUI 写成 `'1px'` 这类 px 字符串（物理像素）
适用范围：把安卓尺寸写成 ArkUI 长度值时，源端没有明确写 px 的情形
做法：
- 按 dp→vp 写数字（如 strokeWidth: 1），只有源端明确写 px 时才写 'Npx'
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Length 为 number 时默认单位 vp；string 要显式写像素单位，不写单位也按 vp：直接写数字即 vp（出处：ts-types.md，Length）
- px 是屏幕物理像素单位；vp 按屏幕像素密度换算成物理像素：'1px' 在高密度屏上只有 1dp 的几分之一（出处：ts-pixel-units.md，像素单位）
- 1px 改为 1（vp）后与安卓 1dp=3px 的实测一致：修复时的观察（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
