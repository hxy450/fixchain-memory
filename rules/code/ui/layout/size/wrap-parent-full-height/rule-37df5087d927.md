# bindSheet 内容组件的根 Scroll / Column 不写 height('100%')，随内容高度

审的是：代码
触发（任一种）：
- 读到：源弹层根布局 android:layout_height="wrap_content"，或是 match_parent 但位于 BottomSheet 的 wrap_content 容器里；写错的样子：bindSheet 内容组件的根 Scroll 或 Column 写了 .height('100%')
适用范围：实现嵌入 bindSheet 的内容组件、源端是 BottomSheetDialogFragment 时
做法：
- 内容根 Scroll / Column 去掉 .height('100%')，不写高度让它随内容；内容超出时由弹层高度上限约束后在 Scroll 里滚动
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 宿主为 SheetSize.FIT_CONTENT 时，内容根写 height('100%') 会把弹层撑到上限；去掉后按内容高度显示：返修后的写法（出处：卡里修好并验证过）
- SheetSize.FIT_CONTENT = 2：弹层高度自适应内容：内容根有确定的内容高度时这一档才按内容显示（出处：鸿蒙 SDK 的 ets/component/common.d.ts，SheetSize.FIT_CONTENT）
未核实：卡里的实测分别出自 HarmonyOS 6.1.0（API 23）和 6.0.2（API 22）两个环境
