# marginEnd 转 margin 时各边用 LengthMetrics，或改 left/right

审的是：代码
触发（任一种）：
- 读到：源布局写了 android:layout_marginEnd / layout_marginStart（映射参考示例写 .margin({ end: 10 })）；写错的样子：.margin({ bottom: 16, end: 16 }) 这类对象里 start / end 和数字混用，编译报 number 不能赋给 LengthMetrics
适用范围：把带 start / end 的边距迁成 ArkUI margin、padding 时
做法：
- 需要 RTL 时写 LocalizedMargin，同一对象内各边都用 LengthMetrics：.margin({ bottom: LengthMetrics.vp(16), end: LengthMetrics.vp(16) })，并从 @kit.ArkUI 导入 LengthMetrics
- 不需要 RTL 时统一用 left / right 数值：.margin({ bottom: 16, right: 16 })
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- margin(value: Margin | Length | LocalizedMargin): T：数字对象走 Margin（top/right/bottom/left），start / end 对象走 LocalizedMargin（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.margin）
- LocalizedPadding { top?: LengthMetrics; end?: LengthMetrics; bottom?: LengthMetrics; start?: LengthMetrics }；LocalizedMargin = LocalizedPadding：带 start / end 的对象里四边都只收 LengthMetrics（出处：鸿蒙 SDK 的 ets/component/units.d.ts，LocalizedPadding、LocalizedMargin）
- static vp(value: number): LengthMetrics：把 vp 数值包成 LengthMetrics（出处：鸿蒙 SDK 的 ets/api/arkui/Graphics.d.ts，LengthMetrics.vp）
- padding(value: Padding | Length | LocalizedPadding): T：同族接口：padding 的 start / end 写法同样要 LengthMetrics（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.padding）
