# match_parent 加 layout_margin 不写成 100% 加 margin，尺寸要扣掉边距

审的是：代码
触发（任一种）：
- 读到：容器或按钮 android:layout_width / layout_height="match_parent"，同时带 android:layout_marginHorizontal / layout_margin；写错的样子：目标写成 .width('100%') / .height('100%') 再加 .margin(…)，居中后外边距对称溢出，真机上贴边、行间无留白
适用范围：把 Android match_parent 加外边距的控件迁成 ArkUI Row / Column / Flex 里的子组件时
做法：
- 尺寸扣掉两侧外边距：如 .height('calc(100% - 14vp)')（上下各 7vp），或按比例宽加 .alignSelf(ItemAlign.Center) 居中，或改在父容器上写 .padding(…)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- width 和 height 设百分比时以父容器的 width 和 height 为基础值：百分比不扣除自己的 margin（出处：ts-universal-attributes-size.md，width / height 示例）
- 在 Row、Column、Flex 交叉轴上布局时，子组件交叉轴的大小与 margin 的和为整体：100% 再加 margin 会超出父容器（出处：ts-universal-attributes-size.md，margin）
- 按键高改成 calc(100% - 14vp)、卡片改成按比例宽并 alignSelf 居中后，左右和行间留白与源一致；只把 margin 改大无效：修好后的写法（出处：卡里修好并验证过）
