# item 和 Fragment 布局给了固定 dp 时，尺寸、颜色、圆角逐项照抄，不近似、不加分隔线

审的是：代码
触发（任一种）：
- 读到：item 或 Fragment 布局 XML 给出固定尺寸：`android:layout_width` / `layout_height`、`android:minWidth`、`android:padding*`、圆角 shape 背景；写错的样子：目标用近似值（如固定 `height(…)` 代替内容加上下 padding、圆角写成别的值），或多加了 XML 里没有的 `Divider`、列表左右 padding
适用范围：把安卓 Fragment 和 RecyclerView item 布局转写成 ArkUI 组件时的尺寸、颜色和圆角
做法：
- 逐项从 XML 抄录尺寸、颜色、圆角，dp 按数字写成 vp；内容高加上下 padding 的照写成内容高和 padding，不合成一个近似高度；XML 没有的分隔线和 padding 不加
- 写完按 XML 逐个 dp 值对照目标代码
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 36×16 圆角 8 胶囊、35+10+10 指标行、去掉列表 padding 和多加的竖线：修复后照 XML 抄录的结果（出处：卡里修好并验证过）
针对本应用要查的：
- 背景圆角和颜色：源工程 res/drawable 下被 android:background 引用的 shape XML；读 <corners android:radius> 写成 borderRadius，<solid android:color> 写成 backgroundColor
