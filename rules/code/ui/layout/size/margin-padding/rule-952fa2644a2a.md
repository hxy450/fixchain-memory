# 带 padding 的 ImageView 背景改纯色形状时，宽高取减去 padding 后的可见尺寸

审的是：代码
触发（任一种）：
- 读到：ImageView 的 layout_width / layout_height 加 android:padding，背景是圆形 drawable，外面还有 android:layout_margin；写错的样子：目标按 layout 尺寸画纯色圆（.width / .height / .borderRadius 按原尺寸），丢了 padding，可见圆垫偏大
适用范围：把带 padding 的图形 ImageView 换成 ArkUI 纯色形状或带背景的容器时
做法：
- 形状宽高 = layout 尺寸 − 2 × padding，圆角取一半；padding 并入外边距（margin + padding），让它与同位的热区和进度环同心
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 48dp、padding 4dp、margin 4dp 的圆垫改成 40vp、margin 8：修复时的换算例子（出处：卡里修好并验证过）
