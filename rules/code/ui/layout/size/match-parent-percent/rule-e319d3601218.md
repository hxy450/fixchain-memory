# layout_width=match_parent 转宽度：有左右 margin 用 calc 扣除，文本条写满宽

审的是：代码
触发（任一种）：
- 读到：layout_width="match_parent" 同时有 layout_marginHorizontal（或 marginStart、marginEnd）；写错的样子：目标写 .width('100%') 再加左右 .margin(...)，组件超出父容器
- 读到：TextView 的 layout_width="match_parent"，文字靠起始边，放在竖向容器里；写错的样子：对应 Text 没写 .width('100%')，在 Column 里被居中
适用范围：把安卓 match_parent 宽度迁成 ArkUI Row / Column / Stack 子组件宽度时
做法：
- 有左右 margin：写 .width('calc(100% - <左+右>vp)') 并保留 .margin({ left, right })，运算符两边留空格
- 没有 margin 的 match_parent 文本条：写 .width('100%') 和 .textAlign(TextAlign.Start)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 百分比宽度参考最近设置了固定大小的祖先节点的尺寸，不扣除自身 margin：100% 加 margin 会超出 2×margin（出处：ts-universal-attributes-size.md，开头说明）
- width(value: Length) 从 API 10 起支持 calc，运算符与数值之间要用空格隔开：calc(100% - 32vp) 这种写法可用（出处：ts-universal-attributes-size.md，width）
- Column.alignItems 默认 HorizontalAlign.Center：不写满宽的 Text 在 Column 里居中（出处：ts-container-column.md，alignItems）
- Text.textAlign 默认 TextAlign.Start（Wearable 上默认 Center）：满宽后文字靠起始边；显式写 Start 不受设备默认影响（出处：ts-basic-components-text.md，textAlign）
- 100% 加左右 margin 会溢出左右 margin 之和；改成 calc(100% - 左右之和) 后正常：margin 不从百分比宽度里扣（出处：卡里修好并验证过）
