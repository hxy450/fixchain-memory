# 页面视觉样式逐项取自源布局和 include 布局，读到的回执被截断时补读后再写

审的是：代码
触发（任一种）：
- 读到：页面规格只给源布局清单和合成的 view.xml（只有类名、id、文本，没有 `android:background`、`android:textColor`、`android:textSize`），样式在 `<include layout="@layout/…">` 的各个布局里；写错的样子：组件的 `.backgroundColor(...)`、`.fontColor(...)`、`.fontSize(...)` 是通用白底卡片或自拟配色，在源布局里找不到对应的属性值
- 读到：子代理一次输出多个源文件，工具回执带 `truncated` 警告，被截去的中段里有页面的源布局；写错的样子：截去的那几个布局对应的标题栏、日期区等样式照样写出了 `.backgroundColor(...)`、`.fontColor(...)`，值不是来自已读到的内容
适用范围：界面转换阶段按源布局 XML 确定标题栏、文字、列表格子等视觉样式时
做法：
- 写样式前从源布局（含 include 的布局）逐项摘出标题栏背景、主要文字颜色和字号、周末颜色、格子与选中态样式，按摘出的值写组件属性
- 某项在已读内容里找不到、或回执有 truncated 警告时，列出被截去的文件逐个单独补读，补齐后再写；不以通用白底卡片或自拟配色代替
针对本应用要查的：
- 页面各区块的背景色、文字颜色、字号：源工程 res/layout 下页面布局及它 `<include>` 的布局 XML，按控件 id 找；读控件的 android:background、android:textColor、android:textSize，引用 @color/、@dimen/ 的再到 res/values 里取值
