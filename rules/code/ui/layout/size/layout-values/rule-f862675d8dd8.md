# 读 include 或 item 布局前先确认源码所在的 flavor/源集，不取递归搜索的第一个结果

审的是：代码
触发（任一种）：
- 读到：源工程有多个 productFlavors 或源集（`src/main` 和各 flavor 目录），同名布局在几个源集里各有一份；Fragment / Adapter 用 `<include layout="@layout/…">` 或按名字引用；写错的样子：目标照另一 flavor 的同名布局实现，`width` / `height` 和装饰线与源码所在源集的那份不一致
适用范围：迁移带多个 flavor 或源集的安卓工程，读取 include、item 布局时
做法：
- 先确认引用这个布局的 Adapter、Fragment 在哪个源集；同名布局优先取同一 flavor 或 main 源集的那份，不直接用递归搜索取第一个结果
针对本应用要查的：
- 要迁的 flavor 和各源集里的同名布局：源工程 app 模块 Gradle 构建脚本里的 productFlavors / sourceSets，以及 src/<源集>/res/layout 下同名文件；列出同名文件所在的源集，取和引用它的代码同一源集（或同一 flavor）的那份
