# Compose Surface/Box 没设尺寸时，按钮尺寸等于内容尺寸，不自加 16 或套 40/48

审的是：代码
触发（任一种）：
- 读到：Compose Surface / Box 只加 clickable、clip、border、background，没有 size / width / height，内容是没写 size 的 Icon；调用方只传 Modifier.align 这类不改尺寸的修饰；写错的样子：外层 .width(...) / .height(...) 写成图标尺寸加 16，或套用 IconButton 的 40、48vp
适用范围：Compose 容器没有显式尺寸、由内容撑开的按钮，迁成 ArkUI 时
做法：
- 外层尺寸等于内容尺寸：Icon 没写 size 时按 24dp，目标写 .width(24).height(24)（数值照搬为 vp）
- grep 每个调用方传进来的 modifier，只有它带 size、padding 时才在目标里照加，并和 .width / .height 对照
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 按钮改成图标尺寸 24 后与安卓一致；原先写成 40×40 时比安卓的 24×24 大：Surface 不设尺寸时由 24dp 的 Icon 撑开（出处：卡里修好并验证过）
