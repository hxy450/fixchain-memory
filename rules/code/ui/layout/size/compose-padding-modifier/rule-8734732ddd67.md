# 源端每行各自 padding(horizontal) 时逐行复制，不提到外层，也不自行补内距

审的是：代码
触发（任一种）：
- 读到：Compose 里每个子 Row 各自 Modifier.padding(horizontal = …)，分隔线在行外全宽；写错的样子：目标把各行和分隔线包进一个 .padding({ start, end, top }) 的 Column，分隔线跟着缩进、顶部多出一段
- 读到：M3 TopAppBar 的 title 槽里放 Row，源码没给这个 Row 右内距；写错的样子：目标的标题 Row 自行写了 .padding({ end: … })
适用范围：Compose 列表摘要、卡片行这类按行加内距的结构，以及 TopAppBar title 槽内的行
做法：
- padding 按源码所在的层级逐行写，分隔线保持全宽，不把 padding 提到外层容器
- TopAppBar title 槽内的 Row 不自行补右内距
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 逐行 padding、分隔线全宽、去掉额外 top、目的地栏删去右内距：修复后文本锚点误差约 0.5dp（出处：卡里修好并验证过）
