# 二级页由布局 XML 和自定义绘制 View 决定视觉时，读全两者再写，截断就分段重读

审的是：代码
触发（任一种）：
- 读到：规格映射写明「Activity + 自定义 View → 目标页」，读取回执里布局 XML 和自定义 `View` 的内容落在 `truncated` 截断区，只看到 Activity 里的 `setContentView`、控件 id 和方法调用；写错的样子：目标页结构是自拟的（文字上月/下月、没有星期偏移的 1..N 网格），缺少源端布局和 `onDraw` 画出的圆盘、卡片、月历网格等
适用范围：迁移由布局 XML 与自定义绘制 View 共同决定视觉的二级页面时
做法：
- 写页面前完整读对应的布局 XML 和自定义 View（onDraw、onMeasure 和它的 set 方法）；回执出现 truncated 时按文件分段重读，拿到结构后再写
- 读不到时在交回里标注视觉缺口，不按自拟结构交付
针对本应用要查的：
- 页面的视觉结构：源工程 res/layout 下 Activity 用 setContentView 指定的布局 XML，以及布局里引用的自定义 View 类；布局里读层级和尺寸；自定义 View 读 onDraw 里画了什么、网格的行列数和首列是星期几
