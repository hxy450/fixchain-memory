# 列表控件带 tools:listitem 时打开那个 item 布局，按它写列表行结构

审的是：代码
触发（任一种）：
- 读到：源布局里列表控件写 tools:listitem="@layout/…"，行结构在被引用的 item 布局 XML 里；写错的样子：鸿蒙端 ListItem 里只写了几行文字，缺 item 布局里的图标、文字层级和右侧列
适用范围：UI 转换阶段迁移列表页、写列表行时
做法：
- 打开 tools:listitem 引用的 item 布局 XML，照它写 ListItem 的内容：图标、各行文字的层级和右侧的列都要有
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 按 item 布局补上地址图标和右侧距离列后，结果行与源端一致：行结构以 item 布局为准（出处：卡里修好并验证过）
