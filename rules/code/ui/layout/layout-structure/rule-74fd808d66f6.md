# 布局 XML 的标题栏、底部按钮和列表项内容，在 ArkUI 页面里逐项写出对应节点

审的是：代码
触发（任一种）：
- 读到：布局 XML 标题栏容器里有返回图标、居中的标题 TextView、右侧编辑/取消色块，底部有固定高度和边距的按钮；列表项数据是实体加异步加载的摘要（Pair<实体, 摘要?>）；写错的样子：ArkUI 标题用 layoutWeight 左对齐、没有返回图标、编辑写成纯文字；底部按钮高度、边距与源不同；列表项只显示名称和编码，没有摘要
适用范围：把安卓 Activity 布局（标题栏、底部按钮、列表项）迁成 ArkUI 页面时
做法：
- 对照布局 XML 列出结构清单：返回图标、居中标题、右侧操作色块、底部按钮的 android:layout_height 和 margin、列表项要显示的每个字段（含异步摘要）；交回前逐项核对 ArkUI 里都有对应节点
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 补上返回图标、居中标题栏、底部按钮高度，列表项加上温度和天气图标后与源一致：修好的结果：结构清单里的每一项都要有节点（出处：卡里修好并验证过）
针对本应用要查的：
- 标题栏和列表项里的每个子节点及其尺寸：源工程 res/layout 下这个页面的布局 XML 和列表项布局 XML，以及 adapter 里给每个子控件赋值的代码；逐个子控件记下类型、对齐方式、android:layout_height / layout_margin 和显示的数据字段
来源：1 张卡，1 个应用
- case-7d027e7b2cd42e741308（android-train-ticket-vest7）：做法第 1 步 ← 建议 3；取值 1 ← 诊断
