# 按钮层的渲染分支对照源布局控件清单，数据缺省时的默认入口也要渲染

审的是：代码
触发（任一种）：
- 读到：源布局 XML 里按钮层的全部控件（各自的 android:id）；目标布局状态的摆位表；写错的样子：按钮层少了摆位表里某些键的渲染分支，或入口只在缩略图 PixelMap 存在时才渲染，没有数据时不显示
适用范围：页面集成收尾时，核对由摆位驱动的按钮层是否覆盖源端全部控件
做法：
- 用摆位表的键集合和源布局 XML 的控件清单逐个对照，每个 id 都要有渲染分支；数据缺省时（如没有缩略图）也渲染默认入口
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 页面补齐全部控件的定位渲染，并从安卓 drawable 复制缺的图标：修复后的结果（出处：卡里修好并验证过）
