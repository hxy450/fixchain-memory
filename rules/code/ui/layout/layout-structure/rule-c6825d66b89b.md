# 照源布局逐控件核类型和文案：tv_ 开头的 ImageView 照写关闭图标，hint 取 android:hint

审的是：代码
触发（任一种）：
- 读到：源布局里 id 像文本控件（如 tv_ 前缀）的其实是 <ImageView>（右上关闭图标）；<EditText> 写了 android:hint；写错的样子：目标把它写成「取消」文字 Button 并和「确定」组成双按钮；TextInput 的 placeholder 用了 toast 文案而不是 android:hint
适用范围：按源布局 XML 转写弹窗或页面控件时
做法：
- 逐控件按 XML 标签定类型和数量：<ImageView> 关闭图标写成 Image 关闭 X（尺寸、alpha 照源），不按 id 名猜成文字按钮
- TextInput({ placeholder: <EditText 的 android:hint> })，文案、字号、颜色逐个照源布局核对
