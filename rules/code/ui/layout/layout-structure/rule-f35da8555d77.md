# 对齐已有页面时按源布局 XML 列组件清单逐项比对，源端没有的区块替换掉而不是只调尺寸

审的是：代码
触发（任一种）：
- 读到：源布局 XML 有背景 ImageView、固定高度的标题栏、统计卡片的各个子 TextView、主按钮文案、TabLayout / ViewPager、空态；写错的样子：已有 ArkTS 页面保留了 XML 里没有的区块（linearGradient 渐变头、多出的统计项、列表区和按钮），改动只落在 .height(...)、.margin(...)、按钮宽度上
适用范围：把已读的安卓布局 XML 落实到一个结构和源端不同的既有 ArkTS 页面上（要求和安卓 1:1 对齐）时
做法：
- 按源布局 XML 列出组件清单：背景 ImageView、标题栏、统计卡片的每个子元素、主按钮文案、TabLayout / ViewPager、空态，逐项对到 ArkTS 组件树上
- 源端不存在的区块（多出的渐变头、统计项、列表区、按钮）删掉，换成源端的结构；不保留后只改高度和边距
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 只把标题栏、卡片高度和按钮边距调到 XML 数值、保留骨架时页面结构仍和源端不同；按组件清单整体重写后才对齐：“1:1 对齐”要先对结构，再对尺寸（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
