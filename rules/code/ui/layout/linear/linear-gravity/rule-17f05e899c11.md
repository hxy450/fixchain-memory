# 源内容区 wrap_content 自上而下排列时，目标分了高也设 FlexAlign.Start

审的是：代码
触发（任一种）：
- 读到：显示卡片 android:layout_height="wrap_content"，里面输入框在上、结果在下自上而下排列，带 paddingVertical；写错的样子：目标显示卡片用 .layoutWeight(1) 撑高，内容列写 .justifyContent(FlexAlign.End) 只给 bottom 内边距，数值贴在显示区底部
适用范围：源端内容区是 wrap_content、子项从顶部排起，目标为了分高给容器加了 layoutWeight 或固定高度时
做法：
- 内容列写 .justifyContent(FlexAlign.Start)，保持源的子项顺序，并沿用源的上内边距（如 paddingVertical 写成 .padding({ top: n, bottom: n })）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- justifyContent(value: FlexAlign): ColumnAttribute：Column 主轴（竖直）方向的对齐（出处：鸿蒙 SDK 的 ets/component/column.d.ts，ColumnAttribute.justifyContent）
- justifyContent(value: FlexAlign): RowAttribute：同族接口：Row 主轴（水平）方向的对齐（出处：鸿蒙 SDK 的 ets/component/row.d.ts，RowAttribute.justifyContent）
