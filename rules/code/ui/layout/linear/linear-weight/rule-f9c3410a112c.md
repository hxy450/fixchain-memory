# weightSum 与子权重和不等时按 LinearLayout 算法算尺寸，不用 layoutWeight

审的是：代码
触发（任一种）：
- 读到：LinearLayout 写了 android:weightSum，且和子项 android:layout_weight 之和不等（子权重和大于或小于 weightSum）；写错的样子：子项照各自权重写成 .layoutWeight(w)，等于按权重和归一化、丢掉 weightSum；或注释写着「按相对比例复现」
适用范围：安卓 LinearLayout 带 weightSum 的权重分配迁成 ArkUI Row/Column 时
做法：
- 按 LinearLayout 算法算：余量 = 可用尺寸 − 各子项自然尺寸之和；子项依次分得 余量 × w / 剩余 weightSum，每分一项余量和剩余 weightSum 都减去已分的；剩余 weightSum 分完后的子项只保留自然尺寸；权重和超过 weightSum 的末块按剩余空间裁切
- 写法二选一：按容器实测尺寸算出各块位置后绝对定位；或在权重和小于 weightSum 时，加一个空占位组件 .layoutWeight(weightSum − 权重和) 补足余下的份额
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- remainingWeightSum = mWeightSum > 0.0f ? mWeightSum : totalWeight；share = (int) (childWeight * remainingExcess / remainingWeightSum)；remainingExcess -= share；remainingWeightSum -= childWeight：安卓按子项顺序分余量：分母从 weightSum 起逐项减去已分的权重（出处：android.widget.LinearLayout#measureVertical（measureHorizontal 同样））
- weightSum 的 format 是 float：Defines the maximum weight sum. If unspecified, the sum is computed by adding the layout_weight of all of the children.：weightSum 是权重总和的上限，没写时才等于子权重之和（出处：Android SDK 平台资源 data/res/values/attrs.xml，LinearLayout 的 weightSum（按应用的 compileSdk 取对应平台））
- layoutWeight(value: number | string): T；默认 0：按权重占比分配主轴剩余空间、忽略元素本身尺寸，没有 weightSum 这一参数（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.layoutWeight；ts-universal-attributes-size.md，layoutWeight）
- 按容器实测尺寸复刻 LinearLayout 算法后绝对定位（含份额耗尽、weightSum 溢出），与安卓一致：修好后的写法（出处：卡里修好并验证过）
