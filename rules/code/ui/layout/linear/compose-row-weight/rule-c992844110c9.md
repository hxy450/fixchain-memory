# alignBy(LastBaseline) 一端是自定义组件时，不用 Flex ItemAlign.Baseline

审的是：代码
触发（任一种）：
- 读到：Compose Row 里 Text 和自定义组件都写 Modifier.alignBy(LastBaseline)；写错的样子：目标写成 Flex({ alignItems: ItemAlign.Baseline })，自定义组件取不到基线被排到文本下方
适用范围：单行文本与自定义控件按基线对齐的行
做法：
- 改写成 Row() { … }.alignItems(VerticalAlign.Center)，文本一侧 .layoutWeight(1)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ItemAlign.Baseline：Flex 容器里按交叉轴方向的文本基线对齐：只对有文本基线的子项有意义，自定义组件不一定提供（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，ItemAlign.Baseline）
- 价格行改 Row + alignItems(Center) + layoutWeight(1) 后，数量选择器回到同一行：修复时用的写法（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
