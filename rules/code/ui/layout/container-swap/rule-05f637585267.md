# Column 换成 Scroll 时，尾部的 justifyContent/alignItems 移进内部 Column

审的是：代码
触发（任一种）：
- 读到：原容器 `Column() {…}` 尾部挂着 `.layoutWeight(1).justifyContent(FlexAlign.Center).alignItems(HorizontalAlign.Center)` 一类的修饰链；写错的样子：换成 `Scroll() { Column() {…} }` 时只替换了容器头和子项，`.justifyContent(...)`、`.alignItems(...)` 落到了 Scroll 上，编译报 Property 'justifyContent' does not exist on type 'ScrollAttribute'
适用范围：ArkUI 页面替换容器类型（Column/Row 换成 Scroll 等非线性容器）时
做法：
- 把原容器尾部整条修饰链纳入同一处修改，逐项核对新容器是否支持
- Column/Row 专属的 `.justifyContent(...)`、`.alignItems(...)` 移到 Scroll 内部的 Column 上或删除，Scroll 上只保留 `.layoutWeight(1)` 等通用属性
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- justifyContent(value: FlexAlign): ColumnAttribute：Column 的主轴（竖直）对齐，属于 ColumnAttribute（出处：鸿蒙 SDK 的 ets/component/column.d.ts，ColumnAttribute.justifyContent）
- alignItems(value: HorizontalAlign): ColumnAttribute：Column 的交叉轴（水平）对齐，属于 ColumnAttribute（出处：鸿蒙 SDK 的 ets/component/column.d.ts，ColumnAttribute.alignItems）
- justifyContent(value: FlexAlign): RowAttribute；alignItems(value: VerticalAlign): RowAttribute：同族接口：Row 的两种对齐，交叉轴参数是 VerticalAlign（出处：鸿蒙 SDK 的 ets/component/row.d.ts，RowAttribute.justifyContent / RowAttribute.alignItems）
- justifyContent?: FlexAlign：同族接口：Flex 的主轴对齐写在构造参数 FlexOptions 里，不是属性方法（出处：鸿蒙 SDK 的 ets/component/flex.d.ts，FlexOptions.justifyContent）
- Scroll 上写 justifyContent 编译报 Property 'justifyContent' does not exist on type 'ScrollAttribute'；删掉后保留 layoutWeight 编译通过：Scroll 不支持这两个对齐属性（出处：卡里修好并验证过）
