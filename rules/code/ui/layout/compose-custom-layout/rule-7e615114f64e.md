# placeRelative 纵向居中的文字进 TopStart 的 Stack 时，用满高容器居中

审的是：代码
触发（任一种）：
- 读到：Compose 自定义 `Layout` 里文字用 `placeRelative` 放置，y 取 `(maxHeight - height) / 2`（纵向居中）；写错的样子：目标写成 `Stack({ alignContent: Alignment.TopStart })`，内容高的 `Text` 没有满高的框，只加了 `.align(...)` 想纵向居中，文字落到左上角
- 写错的样子：修复或编译清理删掉了 Text 的 `height('100%')` 或 `.align(...)`，没有别的约束接替原来的纵向居中
适用范围：源端自定义 Layout 用 placeRelative 纵向居中文字，目标改成 Stack（alignContent 为 TopStart 一类）或删改居中手段时
做法：
- 用 `Column() { Text(...).width('100%') }.height('100%').justifyContent(FlexAlign.Center).alignItems(HorizontalAlign.Start)` 包住文字（Column 宽度照源端给文字的约束），或给 Text 一个满高的框 `height('100%')`
- Text 的 `.align()` 只在 Text 自身框内对齐文字，不能代替它在 Stack 里的定位
- 删掉 `height('100%')`、`.align()` 这类居中手段时，同时确认替代的约束仍让文字纵向居中
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- StackOptions.alignContent?: Alignment，默认 Alignment.Center：Stack 按 alignContent 放置子组件；写成 TopStart 后内容高的子组件落在左上角（出处：鸿蒙 SDK 的 ets/component/stack.d.ts，StackOptions.alignContent）
- align(value: Alignment): T：设置组件内容在自身绘制区内的对齐，默认 Alignment.Center；不移动组件本身（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.align）
- Text 上的 align 只控制文字在 Text 框内的纵向位置：Start、Center、End 效果相同，都是纵向居中：Text 没有满高的框时 align 看不出效果（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.textAlign）
- justifyContent(value: FlexAlign): ColumnAttribute，默认 FlexAlign.Start：Column 子组件在垂直方向（主轴）上的对齐，居中写 FlexAlign.Center（出处：鸿蒙 SDK 的 ets/component/column.d.ts，ColumnAttribute.justifyContent；ts-container-column.md，justifyContent）
- justifyContent(value: FlexAlign): RowAttribute：同族接口：Row 子组件在主轴（水平）上的对齐（出处：鸿蒙 SDK 的 ets/component/row.d.ts，RowAttribute.justifyContent）
- 满高 Column + justifyContent(FlexAlign.Center) + alignItems(HorizontalAlign.Start)，内层 Text 写 width('100%')：修好后文字在给定区域内纵向居中、靠起始边（出处：卡里修好并验证过）
针对本应用要查的：
- 源端给文字的宽度约束和纵向位置公式：源工程里自定义 Layout 的 measure/place 代码，找给文字的 Constraints 和 placeRelative 的 x、y；宽度约束写成外层 Column 的 width，y 若是 (maxHeight - height) / 2 就用满高 Column 加 FlexAlign.Center
