# 根容器 android:background 整屏背景图迁成 Image 时用 ImageFit.Fill

审的是：代码
触发（任一种）：
- 读到：根布局（如 RelativeLayout）写 android:background="@drawable/…" 铺整屏背景图；写错的样子：目标在 Stack 底层用 Image(…).objectFit(ImageFit.Cover) 铺背景，背景上下被裁掉
适用范围：安卓根容器以 android:background 的 View 背景铺整屏背景图，迁成 ArkUI Stack 底层 Image 时
不适用的情形：确需等比裁切时可以用 Cover，但要先用资源实际宽高比和目标屏幕比例核对顶部、底部的关键图文不会被裁掉
做法：
- 写成 Image($r('app.media.<背景图>')).width('100%').height('100%').objectFit(ImageFit.Fill)，放在 Stack 最底层，按容器边界拉伸铺满
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- objectFit(value: ImageFit): ImageAttribute：Image 的缩放模式（出处：鸿蒙 SDK 的 ets/component/image.d.ts，ImageAttribute.objectFit）
- ImageFit.Fill：不保持宽高比缩放，图片填满显示边界；ImageFit.Cover：保持宽高比缩放，使两边都大于等于显示边界（超出部分被裁）：Fill 对应安卓 View 背景的拉伸铺满，Cover 会裁掉一部分（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，ImageFit.Fill、ImageFit.Cover）
- View 背景 drawable 的 bounds 设为 (0, 0, mRight - mLeft, mBottom - mTop)；BitmapDrawable 默认 gravity 是 Gravity.FILL：源端整屏背景按容器边界拉伸铺满，不保持宽高比（出处：android.view.View#setBackgroundBounds；android.graphics.drawable.BitmapDrawable 的 BitmapState.mGravity）
- 改成 ImageFit.Fill 后背景顶部图文完整显示：修好的写法（出处：卡里修好并验证过）
- objectFit(value: ImageFit): ImageSpanAttribute：同族接口：ImageSpan 的缩放模式（出处：鸿蒙 SDK 的 ets/component/image_span.d.ts，ImageSpanAttribute.objectFit）
- objectFit(value: ImageFit): VideoAttribute：同族接口：Video 的缩放模式（出处：鸿蒙 SDK 的 ets/component/video.d.ts，VideoAttribute.objectFit）
