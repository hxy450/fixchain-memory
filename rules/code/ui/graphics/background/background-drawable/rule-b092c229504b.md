# 控件叠在带装饰的背景图上时，按装饰在图中的位置用百分比留安全区

审的是：代码
触发（任一种）：
- 读到：格子用 android:background 引用带装饰的图片（票券存根、竖虚线等），内容 LinearLayout 用固定 android:layout_marginLeft 加 android:gravity="center" 避开装饰；写错的样子：Row 只写固定的 .padding({ left: … })，没有居中，内容压到背景图上的装饰线
适用范围：目标端控件叠在随容器缩放的装饰背景图上、装饰元素位置按图宽比例变化时
做法：
- 量出装饰元素在背景图里的相对位置（占图宽的比例），左右安全区写成百分比 .padding({ left: '<比例>%', right: '<比例>%' })，内容仍居中
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- padding(value: Padding | Length | LocalizedPadding): T：Length 可写百分比字符串（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.padding）
- padding 设百分比时，上下左右都以父容器的 width 为基础值：比例要按父容器宽度算，不是按组件自己的宽度（出处：ts-universal-attributes-size.md，padding）
- Row 改成左右百分比 padding 并居中后，选中、未选中状态下都不再压线：按比例留安全区能随格子宽度变化（出处：卡里修好并验证过）
针对本应用要查的：
- 装饰元素在背景图中的相对位置：源工程 drawable 目录里被 android:background 引用的那张图（png 或 .9.png）；用装饰元素右缘的 x 坐标除以图宽得到比例，安全区再留一点余量；例：竖虚线在约两成宽处时，左侧留比这个比例稍大的百分比
