# 主题窗口背景是渐变 drawable 时，页面内容区根用共享常量加 .linearGradient，不压成单色键

审的是：代码
触发（任一种）：
- 读到：页面规格写「Holo 默认，取不到精确值标待核」，styles.xml 里 parent="android:Theme.Holo"；写错的样子：凭记忆写 .backgroundColor('#FF000000')，或往 color.json 新加 #FF000000 的颜色键给根 Column / NavDestination 用，没查 SDK 也没标待核
- 读到：SurfaceView / Canvas 透明（android:background="@null"），布局根没有 android:background；写错的样子：透明 Canvas 页的根另用了一个颜色 .backgroundColor($r('app.color.…'))，没有沿用窗口背景
适用范围：源页面底色来自平台主题的 windowBackground、且它解析出来是渐变 drawable 时
做法：
- 先在 Android SDK 平台资源里把 windowBackground 解析到最终 drawable，查过仍缺才标待核，不凭记忆补 #000000 一类的值
- 定义共享常量 { direction: GradientDirection.Bottom, colors: [[startColor, 0], [endColor, 1]] }，在页面内容区根写 .linearGradient(常量)；Android angle 270 对应 GradientDirection.Bottom
- 透明 Canvas 页的根沿用同一个常量
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- linearGradient(value: LinearGradientOptions): T：组件的线性渐变背景（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.linearGradient）
- LinearGradientOptions：angle?（默认 180）、direction?（默认 GradientDirection.Bottom）、colors: Array<[ResourceColor, number]>：colors 每项是 [颜色, 位置 0–1]（出处：鸿蒙 SDK 的 ets/component/common.d.ts，LinearGradientOptions）
- GradientDirection.Bottom：From the top down：从上到下渐变（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，GradientDirection.Bottom）
- android:angle="270" → Orientation.TOP_BOTTOM：源端 angle 270 是从上到下，对应 GradientDirection.Bottom（出处：android.graphics.drawable.GradientDrawable#updateGradientDrawableGradient）
- constructor(options: LinearGradientOptions)：同族接口：LinearGradientStyle（文字着色用的渐变），参数同为 LinearGradientOptions（出处：鸿蒙 SDK 的 ets/component/text_common.d.ts，LinearGradientStyle.constructor）
- 内容区根 .linearGradient(共享常量，GradientDirection.Bottom，起止色取自 SDK 的渐变)；NavDestination 保留黑底作为系统栏区域的底色：修复后各页与源端窗口背景一致（出处：卡里修好并验证过）
针对本应用要查的：
- 这个平台主题 windowBackground 最终 drawable 的起止色和 angle：Android SDK 平台资源 platforms/android-<compileSdk>/data/res：values/themes*.xml 的 windowBackground → drawable/ 下的 selector → shape；读 shape 里 <gradient> 的 startColor、endColor、angle；例：Theme.Holo 下是 #ff000000→#ff272d33、angle 270
