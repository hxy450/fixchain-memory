# drawRect 用 BlendMode.Plus/Darken 给图标叠渐变时，图标和渐变层放进同一个离屏组

审的是：代码
触发（任一种）：
- 读到：Compose drawWithContent { drawContent(); drawRect(brush, blendMode = BlendMode.Plus / Darken) } 给 Icon 着色；写错的样子：Icon 写成 .fillColor(渐变首色) 单色，没有 .blendMode(...)
- 写错的样子：渐变 Column 作为 Image 的兄弟节点单独 .blendMode(BlendMode.PLUS / DARKEN, BlendApplyType.OFFSCREEN)
适用范围：Compose 用 BlendMode 把渐变混到图标上，迁成 ArkUI 时
做法：
- 图标和渐变层放进同一个离屏组 Stack() { Image; 渐变 Column }.blendMode(BlendMode.SRC_OVER, BlendApplyType.OFFSCREEN)，按压态圆盘等不染色的层放组外；有对应模式就不改成单色
- 组内写法一：渐变层 .blendMode(BlendMode.SRC_IN, BlendApplyType.OFFSCREEN)、删 PLUS / DARKEN；要复刻 Plus 的字形底色时 Image .fillColor(Color.Black)，Plus 色标预混成 min(255, glyph + stop)，Darken 保持原色标，浅深分别核对
- 组内写法二：Image .fillColor(<源 tint 色>)，渐变层 .blendMode(isDark ? BlendMode.DARKEN : BlendMode.PLUS, BlendApplyType.FAST)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- blendMode(value: BlendMode, type?: BlendApplyType): T：组件内容（含子组件）与下方画布已有内容混合；type 默认 BlendApplyType.FAST，value 为 BlendMode.NONE 时按 SRC_OVER 且 type 不生效（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.blendMode）
- BlendApplyType.FAST = 0；BlendApplyType.OFFSCREEN = 1：组件和子组件先画到离屏画布，再与画布已有内容混合：外层用 .blendMode(BlendMode.SRC_OVER, BlendApplyType.OFFSCREEN) 形成离屏组（文档示例同样这样做隔离）（出处：鸿蒙 SDK 的 ets/component/common.d.ts，BlendApplyType；ts-universal-attributes-background.md，示例6（设置文字异形模糊效果））
- BlendMode.SRC_IN = 6：r = s * da：只按目标 alpha 取形，颜色全由渐变色标决定（出处：鸿蒙 SDK 的 ets/component/common.d.ts，BlendMode.SRC_IN）
- BlendMode.PLUS = 13：r = min(s + d, 1)；BlendMode.DARKEN = 17；安卓平台 PLUS 同为 C_out = max(0, min(C_src + C_dst, 1))：源 Plus、Darken 对应的枚举和算式，Plus 的被加数是已画好的字形像素（出处：鸿蒙 SDK 的 ets/component/common.d.ts，BlendMode.PLUS、BlendMode.DARKEN；android.graphics.BlendMode#PLUS）
- linearGradient(value: LinearGradientOptions): T；angle 默认 180，0 度为从下往上，顺时针为正：渐变层的写法和角度约定（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.linearGradient、LinearGradientOptions.angle；ts-universal-attributes-gradient-color.md，linearGradient）
- 删兄弟节点 PLUS/DARKEN 层、改成离屏组内 Image 加 SRC_IN 渐变后，淡色方块消失、截图比对通过：写法一不预混时的结果（出处：卡里修好并验证过）
- 改成 plusOver(stop, compositeOver(contentColor, 背景)) 预混、fillColor(Color.Black) 后浅色主题字形色对上：写法一预混后的结果；深色主题保持原色标（出处：卡里修好并验证过）
- 内圆 OFFSCREEN 隔离层里 Icon 按 fillColor(原内容色) 绘制，上叠 135° 渐变层并设 .blendMode(isDark ? DARKEN : PLUS, BlendApplyType.FAST)，浅色下颜色与源端一致：写法二的结果（出处：卡里修好并验证过）
针对本应用要查的：
- 源渐变的颜色和方向：源工程里那个 Modifier 扩展的定义，Brush.linearGradient 的 colors 和 start / end；颜色照搬；起止点从左上到右下对应 angle 135，其他方向按 0 度从下往上、顺时针为正换算
- 字形底色（写法一预混时用）：源工程主题里图标用的 LocalContentColor（或 tint）颜色和它所在的背景色；按 alpha 把内容色合成到背景上（例：#de000000 合到白底得 #212121），作为算式里的 glyph
