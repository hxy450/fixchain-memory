# HitTestMode.None 只管写它的节点，渐隐遮罩条把 None 写在有尺寸的绘制节点上

审的是：代码
触发（任一种）：
- 写错的样子：外包定位的 Row / Column 上写了 .hitTestBehavior(HitTestMode.None) 并注释成整组不参与命中，里面有尺寸的渐变 Column 等子节点仍是缺省 Default，盖住下层可点控件
适用范围：纯展示的遮罩条、渐隐边缘等绘制层外包了定位用的 Row / Column，叠在可点击内容之上时
做法：
- 在每个实际有尺寸的绘制节点上写 .hitTestBehavior(HitTestMode.None)，不用父层的 None 代表整组不参与命中
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- HitTestMode.None：自身不响应触摸命中，子节点照常响应：None 只作用于写它的节点，子节点仍按自己的模式命中并可挡住兄弟（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，HitTestMode.None）
- 给两条有尺寸的渐变 Column 各写 HitTestMode.None 后，被盖住的边缘控件恢复可点：None 要写在实际有尺寸的节点上（出处：卡里修好并验证过）
- hitTestBehavior(value: HitTestMode): T：设命中模式的通用方法（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.hitTestBehavior）
