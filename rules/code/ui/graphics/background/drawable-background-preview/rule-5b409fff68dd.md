# 在预览 Stack 底部新增背景层时，上方不透明的占位层随所选背景改成透明

审的是：代码
触发（任一种）：
- 读到：源端选中背景后改的是组件自身的背景 Drawable，再触发重绘（invalidate），背景是组件渲染的一部分；写错的样子：目标在 Stack 第一层新建背景层，上面原样叠着铺满的 Row().backgroundColor(白色) 占位层或其他不透明层，已选背景时这些层仍不透明
适用范围：组件详情、编辑页的预览区接入用户可选背景，新背景层与现有预览内容叠放时
做法：
- 新增背景层前先逐一列出叠在它上面的各层（静态预览图、占位底、动态渲染），确认已选背景时每层是否透明
- 不透明的占位层随选中状态切换：.backgroundColor(已选背景 ? Color.Transparent : 原底色)；不能只把背景放到最底层就算接入完成
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 无预览源时白色占位按所选背景切成透明色：修好后所选背景可见（出处：卡里修好并验证过）
- Color.Transparent：透明色（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，Color.Transparent）
