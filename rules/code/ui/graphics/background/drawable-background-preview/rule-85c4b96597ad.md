# 外观选项的测试要覆盖每个兜底分支，断言已选背景时占位层 backgroundColor 跟着切换

审的是：代码
触发（任一种）：
- 写错的样子：外观选项的测试只断言调用了设置背景的方法、状态写回、透明度不作用于预览图，没有断言兜底分支上方不透明层的 backgroundColor 随所选背景切换
适用范围：给可选背景、配色这类外观选项写回归测试时
做法：
- 回归检查覆盖每个兜底分支（有预览图、无预览源等）：断言已选背景时背景层上方的占位层 backgroundColor 随 appearance.background 切成透明，不只验证状态写回
