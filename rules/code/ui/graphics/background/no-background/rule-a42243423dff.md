# 规格给的底色和源布局冲突时先回源核对引用，不能确认就登记差异，不照写颜色键

审的是：代码
触发（任一种）：
- 读到：源布局根没有 android:background、SurfaceView 为 android:background="@null"，规格却写某个颜色「透出」；写错的样子：页面根写 .backgroundColor($r('app.color.…')) 用规格里的颜色键，注释写这个颜色 shows through
适用范围：页面实现时，规格给出的页面底色与源布局里看到的背景来源不一致
做法：
- 在源 layout、style、Java 里检索规格那个颜色的引用；查不到就在差异登记里记下规格与源布局的冲突，不照规格写死颜色键
- 布局根没有 android:background 时，页面根按 Activity 主题的 windowBackground 写
