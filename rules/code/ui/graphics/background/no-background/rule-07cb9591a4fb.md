# 无来源兜底预览不加源端没有的描边，未选择时所有预览分支都不画边框

审的是：代码
触发（任一种）：
- 读到：源端预览容器是 wrap_content 的空 FrameLayout，没有 stroke 或背景；编辑状态里选中的边框默认为 null，边框只在选择后由 Drawable 绘制；写错的样子：无预览源分支把 Blank() 换成带 .border({ width: …, color: … }) 的占位
适用范围：为无来源、无数据状态补兜底预览，或改动编辑项默认态时
做法：
- 兜底分支不加源端不存在的描边、外框等装饰；边框、选中态这类可选择的视觉属性，未选择时不由兜底层画出来，删去无条件的 .border(...)
- 改了默认态后逐个核对：选中项为 null 时，主预览所有分支（含无来源兜底、动态预览）都不绘制边框
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- border(value: BorderOptions): T：组件描边（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.border）
- 删除兜底分支里无条件的 .border 后，未选边框时不再显示描边：修好的写法（出处：卡里修好并验证过）
