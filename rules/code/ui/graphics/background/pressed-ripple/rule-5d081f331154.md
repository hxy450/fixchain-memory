# 涟漪按压的不透明度按对照设备实测或登记待测，不挑某一 SDK 的 highlight_alpha

审的是：代码
触发（任一种）：
- 读到：平台资源 ripple_material_light = highlight_alpha_material_light × foreground_material_light，各 android-NN 平台的 highlight_alpha 不同；写错的样子：按压色写成 highlight_alpha 原值乘前景色（如 '#33000000'、'#80000000'），注释写取某个 android-NN 的值或「与兄弟页同源同值」；同一组件里混用不同版本的值
适用范围：按 Material 主题涟漪确定目标按压层颜色或不透明度时
做法：
- 按对照设备的 Android 版本实测按住稳态的不透明度写入；没有实测时在报告里登记待实测
- 不按「与兄弟页同源同值」挑某一 SDK 版本的值，同一组件里不混用不同版本的值
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- highlight_alpha_material_light：android-30 为 0.10、android-34 为 0.5、android-35 与 android-36 为 0.20：原值随平台版本变化，只是涟漪着色输入（出处：Android SDK 平台资源 data/res/values/colors_material.xml，highlight_alpha_material_light（各平台目录分别查））
- ripple_material_light：<selector> 里 alpha=@dimen/highlight_alpha_material_light、color=@color/foreground_material_light：colorControlHighlight 的定义（出处：Android SDK 平台资源 data/res/color/ripple_material_light.xml（按应用的 compileSdk 取对应平台））
- Android 12 对照设备上有界涟漪稳态中部约 8.6%、边缘约 6%，不等于任何一版 highlight_alpha 原值：屏上不透明度由该版本 RippleDrawable 的绘制决定（出处：卡里修好并验证过）
针对本应用要查的：
- 对照设备上的涟漪稳态不透明度：对照设备（按源端要对齐的 Android 版本）按住控件截屏取样；分圆心到边缘取几个点的不透明度写进径向层的 colors；取不到就登记待实测
