# 源控件按压背景是有界 <ripple> 时，按压态画径向层，不按高亮色整块平铺

审的是：代码
触发（任一种）：
- 读到：控件按压背景经主题属性解析到带 mask 或内容层的 <ripple>：Widget.Material.ListView 的 listSelector → ?attr/listChoiceBackgroundIndicator，或 Widget.Material.Button.Borderless 的 background → btn_borderless_material；写错的样子：stateStyles({ pressed: … }) 里写 .backgroundColor('#33000000') 这类 colorControlHighlight / highlight_alpha 原值，整块平铺
- 读到：兄弟页或共享组件里已有 stateStyles pressed 的按压常量；写错的样子：注释写「与兄弟页同源同值」「对齐兄弟页口径」，直接沿用按压常量 backgroundColor，没回到源主题核对这个控件的 drawable 类型
适用范围：Material 主题（API 21+ 走 Theme.Material*）下列表行、偏好行、对话框按钮等控件的按压态迁成 ArkUI 时
做法：
- 沿控件实际用的主题属性打开 drawable 本体看根元素：<selector> 的纯色按压项才取色写 backgroundColor；<ripple> 时 colorControlHighlight、highlight_alpha 只是涟漪着色输入，不当屏上按压色平铺
- 有界 <ripple>：在 stateStyles 的 pressed 块里写 .radialGradient({ center: [宽 / 2, 高 / 2], radius: 视图半对角线, colors: [...] })，只画在视图边界内
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Widget.Material.ListView：listSelector = ?attr/listChoiceBackgroundIndicator；Theme.Material：listChoiceBackgroundIndicator = @drawable/list_choice_background_material：列表行按压背景的解析链（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.ListView；data/res/values/themes_material.xml，listChoiceBackgroundIndicator（按应用的 compileSdk 取对应平台））
- list_choice_background_material 是 <ripple>，带 id=mask 的 item：有界涟漪（出处：Android SDK 平台资源 data/res/drawable/list_choice_background_material.xml（按应用的 compileSdk 取对应平台））
- Widget.Material.Button.Borderless 的 background = @drawable/btn_borderless_material，后者是带 mask 的 <ripple>：无边框按钮（含对话框按钮）也是有界涟漪（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.Button.Borderless；data/res/drawable/btn_borderless_material.xml（按应用的 compileSdk 取对应平台））
- RippleDrawable 没有 mask 层时按子层的合成形状遮罩：有 mask 或内容层的涟漪画在视图边界内（出处：android.graphics.drawable.RippleDrawable）
- radialGradient(value: RadialGradientOptions): T；center 是相对组件左上角的坐标，radius 取值 [0, +∞)：目标画径向层（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.radialGradient）
- Android 12 对照设备按住稳态：以视图中心为圆心、R=视图半对角线的径向层，r≤0.6R 约 8.6%，R 处约 6%；各行改为 stateStyles 里 radialGradient 后与源端一致：有界涟漪屏上形状和修法（不透明度随设备 Android 版本变）（出处：卡里修好并验证过）
针对本应用要查的：
- 控件的按压 drawable 及其类型：源工程布局或样式里控件的 style、background、listSelector，及 values-v21 父主题；再到 Android SDK 平台资源 themes_material.xml 找对应主题属性，打开 data/res/drawable 下的 xml；看根元素是 <ripple> 还是 <selector>、有无 mask 或内容层、有无 android:radius
未核实：涟漪稳态不透明度只在 Android 12 对照设备上实测过
