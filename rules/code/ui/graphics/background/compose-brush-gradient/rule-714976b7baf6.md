# Compose 端点渐变的面板比周期长时，linearGradient 的 stop 按周期/面板长缩放

审的是：代码
触发（任一种）：
- 读到：Brush.horizontalGradient(colors, startX = …, endX = …, tileMode = …) 或 Brush.linearGradient(start = Offset(…), end = Offset(…))：渐变长度由端点距离给出，不是组件尺寸；写错的样子：linearGradient({ direction / angle, repeating: true, colors }) 挂在为覆盖而加宽的面板上，colors 的位置仍从 0 铺到 1（末 stop 是 1）
适用范围：把 Compose 以像素或 dp 端点定义长度的 Brush 渐变译成 ArkUI linearGradient，且目标面板长度和图案周期不同时
做法：
- 先按源端点距离算出图案周期（startX 到 endX，或 start 到 end 沿渐变方向的距离，换成目标单位），每个 stop 位置写成「原位置 × 周期 / 该组件渐变线长」；面板为覆盖而加宽时 stop 跟着缩小
- 写完核一遍「末 stop × 面板长 = 周期」，末 stop < 1 时 repeating: true 才会平铺；平移相位取模用的也是这个周期
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- colors: Array<[ResourceColor, number]>，number 取值 [0, 1.0]，0 是渐变的开始处，1.0 是结束处：stop 位置是相对这个组件自身渐变线长的比例（出处：ts-universal-attributes-gradient-color.md，LinearGradientOptions 对象说明）
- repeating 默认 false：要平铺必须显式写 repeating: true，且末 stop 小于 1（出处：鸿蒙 SDK 的 ets/component/common.d.ts，LinearGradientOptions.repeating）
- linearGradient(value: LinearGradientOptions): T：组件的线性渐变背景（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.linearGradient）
- stop 乘以「周期 / 面板宽」的比例后 repeating 生效、周期和相位取模对上：修好后的写法（出处：卡里修好并验证过）
- constructor(options: LinearGradientOptions)：同族接口：LinearGradientStyle（文字着色用的线性渐变）的构造，stop 同样按自身渐变线长取比例（出处：鸿蒙 SDK 的 ets/component/text_common.d.ts，LinearGradientStyle.constructor）
