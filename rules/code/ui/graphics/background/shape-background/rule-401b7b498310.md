# 背景 drawable 是 <shape> 时转成圆角、底色和边框，不用 backgroundImage

审的是：代码
触发（任一种）：
- 读到：android:background="@drawable/…" 指向的 drawable XML 根标签是 <shape>，里面有 <solid android:color>、<corners android:radius>（可能还有 <stroke>）；写错的样子：目标写成 .backgroundImage($r('app.media.…')) 加 .backgroundImageSize(ImageSize.Cover)，把 shape 当位图，铺的是目标工程里同名的小尺寸圆角 SVG
适用范围：安卓控件背景引用 drawable 资源、迁成 ArkUI 组件背景时
做法：
- 先打开源 drawable 判断类型：<shape> 写成 .backgroundColor(<solid 的 color>).borderRadius(<corners 的 radius>，数值 vp)；有 <stroke> 再加 .border({ width: <stroke 的 width>, color: <stroke 的 color>, radius: <corners 的 radius> })
- 只有位图或九宫格才用 backgroundImage；目标工程里同名的小尺寸 SVG 不要用 ImageSize.Cover 铺满整张卡
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- backgroundColor(value: ResourceColor): T：<solid android:color> 落在这里（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.backgroundColor）
- borderRadius(value: Length | BorderRadiuses | LocalizedBorderRadiuses): T：<corners> 的圆角落在这里（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.borderRadius）
- border(value: BorderOptions): T：<stroke> 的宽度和颜色落在这里（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.border）
- DrawableCorners 的 radius 是 dimension；GradientDrawableSolid 的 color 是 color；GradientDrawableStroke 有 width、color：shape 里各子标签的属性和格式，分别对应到 borderRadius、backgroundColor、border（出处：Android SDK 平台资源 data/res/values/attrs.xml，DrawableCorners、GradientDrawableSolid、GradientDrawableStroke（按应用的 compileSdk 取对应平台））
- ImageSize.Cover：保持宽高比缩放，使图片两边都大于或等于显示边界：非方形容器上会放大并裁掉一部分，圆角跟着变形或被裁（出处：ts-appendix-enums.md，ImageSize）
- 背景改为 backgroundColor + borderRadius 后圆角底色正常：修好的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 背景 drawable 的类型和 shape 里的取值：源工程 res/drawable*/ 下与 @drawable/ 引用同名的 XML 或图片文件；根标签是 <shape> 的读 corners、solid、stroke 的值；是 .png/.jpg/.9.png 才按位图处理；选中态切换的另一份 drawable 同样读
