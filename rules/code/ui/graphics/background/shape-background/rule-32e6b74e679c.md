# borderRadius 后接不带 radius 的 border() 时，圆角写进 border 的 radius

审的是：代码
触发（任一种）：
- 写错的样子：同一个组件先 .borderRadius(…) 再 .border({ width: …, color: … })，border 的参数里没有 radius
适用范围：ArkUI 组件同时要圆角和描边时
做法：
- 写成 .border({ width: <宽>, color: <色>, radius: <圆角> })，圆角和描边放在同一个 border 里
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- border(value: BorderOptions): T：组件的描边，一次设宽、色、圆角、样式（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.border）
- BorderOptions.radius?: BorderRadiuses | Length | LocalizedBorderRadiuses：border 里的圆角字段（出处：鸿蒙 SDK 的 ets/component/units.d.ts，BorderOptions.radius）
- border() 不带 radius 时，前面 borderRadius 设的圆角被重置；给 border 带上 radius 后圆角恢复：调用顺序和参数缺省会互相覆盖（出处：卡里修好并验证过）
