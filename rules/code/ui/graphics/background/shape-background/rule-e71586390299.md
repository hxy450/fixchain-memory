# 源码运行时 setBackgroundResource 只覆盖被调用的控件，其余控件按各布局变体 XML 的背景取形状

审的是：代码
触发（任一种）：
- 读到：Activity 代码只对部分控件变量调用 setBackgroundResource / setBackground；layout-land 变体里同一控件 android:background="@color/…"（纯色），竖屏变体是带 <corners> 的 shape drawable；写错的样子：目标组件对所有按钮无条件写 .borderRadius(6)，没被运行时代码改背景的控件在横屏也成了圆角；注释写「运行时覆盖了两套 XML 背景」
适用范围：合并竖屏与 layout-land 等布局变体、确定控件背景形状（圆角或直角）时
做法：
- 逐个列出 setBackgroundResource / setBackground 实际调用的控件变量，只有这些控件改用运行时背景
- 其余控件在每个变体里按该变体 XML 的 background 取形状和颜色：@color 纯色是直角，shape 的 <corners android:radius> 给圆角；变体不同就按方向分支，如 .borderRadius(this.isLandscape ? 0 : <竖屏半径>)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- public void setBackgroundResource(@DrawableRes int resid)：只改调用它的那个 View 的背景（出处：android.view.View#setBackgroundResource）
- ColorDrawable：用指定颜色填满画布，XML 里对应 <color> 元素：background 引用 @color 时是无圆角的纯色（出处：android.graphics.drawable.ColorDrawable）
- <attr name="radius" format="dimension" />（DrawableCorners，四角半径）：shape drawable 的圆角来自 <corners android:radius>，单位 dp 对应目标 vp（出处：Android SDK 平台资源 data/res/values/attrs.xml，DrawableCorners 的 radius（按应用的 compileSdk 取对应平台））
- borderRadius(value: Length | BorderRadiuses | LocalizedBorderRadiuses): T：目标组件的圆角（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.borderRadius）
- 改成 borderRadius(this.isLandscape ? 0 : 6) 后横屏直角、竖屏圆角，与源端一致：修好后的写法（6 是该源 shape 的半径）（出处：卡里修好并验证过）
针对本应用要查的：
- 每个布局变体里控件背景的形状和颜色：源工程 res/layout*/ 下同名布局里该控件的 android:background；引用 drawable 时看 res/drawable*/ 下那个 shape 的 <corners> 和 <solid>；@color 或颜色值 → 直角纯色；shape 带 corners → 取 radius 的 dp 值作 borderRadius 的 vp 值，solid 的颜色作 backgroundColor
