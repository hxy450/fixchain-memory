# px 画布上下文里拿触点和 vp 窗口避让值比几何时，先 vp2px；vp 上下文不换

审的是：代码
触发（任一种）：
- 写错的样子：上下文按 LengthMetricsUnit.PX 构造，onTouch 里 TouchObject.x / y 或以 vp 保存的窗口避让值没 vp2px 就和画布几何比较；或上下文是默认 vp 构造，却对触点做了 vp2px
适用范围：Canvas 的触摸命中判断、按窗口避让值偏移画布内容时
做法：
- PX 上下文：命中判断先写 const x = uiContext.vp2px(touch.x)、const y = uiContext.vp2px(touch.y)，vp 的窗口避让值也 vp2px 后再参与几何；默认 vp 上下文：触点和 vp 值直接与几何比较，不做 vp2px
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- TouchObject.x / y：组件坐标系中的坐标，单位 vp：触点是 vp，与 px 几何比较前要换算（出处：ts-universal-events-touch.md，TouchObject 属性）
- vp2px(value: number): number：UIContext 的 vp 转 px（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.vp2px）
- 已 vp2px 的触点与 vp 几何比较时点不中；上下文改成 PX 后 vp2px 的触点与 px 几何同域：触点换不换取决于上下文单位（出处：卡里修好并验证过）
