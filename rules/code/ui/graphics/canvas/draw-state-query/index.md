# onDraw 里向别的类查询的状态和位置

agent 会看到什么：读到源端 onDraw 一路先问别的类有没有某个状态、有才取它的位置（public 读方法、经 Matrix 重投影），否则用画布中心；产物里目标类只有 private 字段没有公开读方法，或 Canvas 绘制无条件取 width / 2、height / 2

## 规矩

- rule-78729a0145fc｜源类的公开读方法被别的类调用时，目标类连同存储字段一起移植成公开方法｜读到：源类存着状态（如对焦区的相机坐标），它的 public 读方法被别的类调用，例如绘制类在 onDraw 一路里先问有没有、再取位置，取位置时经 Matrix 重投影；写错：目标类只把对应字段写成 `private`，没有同语义的公开方法；消费方在目标里搜不到这个读面
- rule-bee8176a24f6｜验收写「有 X 时用其位置否则默认」时，目标保留条件分支，缺读面就登记跨切片占位｜读到：源端绘制代码在 Canvas 上画时先判断有没有该状态（`if` 分支），有才取它的位置，否则才用画布中心；规格验收条目写「有 X 时用其位置，否则用默认值」；写错：目标 Canvas 绘制代码无条件取画布中心（`width / 2`、`height / 2` 一类），没有条件分支；注释或笔记把它写成验收允许的降级、已知近似，占位登记里没有这一项
