# 验收写「有 X 时用其位置否则默认」时，目标保留条件分支，缺读面就登记跨切片占位

审的是：代码
触发（任一种）：
- 读到：源端绘制代码在 Canvas 上画时先判断有没有该状态（`if` 分支），有才取它的位置，否则才用画布中心；规格验收条目写「有 X 时用其位置，否则用默认值」；写错的样子：目标 Canvas 绘制代码无条件取画布中心（`width / 2`、`height / 2` 一类），没有条件分支；注释或笔记把它写成验收允许的降级、已知近似，占位登记里没有这一项
适用范围：消费方（覆盖层、绘制）实现「有 X 时用其位置，否则用默认值」的验收条目，而 X 的读面属于别的切片时
做法：
- 照源端写成条件分支：有该状态时取上游读面给的位置，否则才用默认值；默认值只对应没有该状态的情形
- 上游还没有这个读面时，在占位登记里登记跨切片占位，交给读面所属的切片补；不把无条件默认值记成验收允许的近似
