# 源类的公开读方法被别的类调用时，目标类连同存储字段一起移植成公开方法

审的是：代码
触发（任一种）：
- 读到：源类存着状态（如对焦区的相机坐标），它的 public 读方法被别的类调用，例如绘制类在 onDraw 一路里先问有没有、再取位置，取位置时经 Matrix 重投影；写错的样子：目标类只把对应字段写成 `private`，没有同语义的公开方法；消费方在目标里搜不到这个读面
适用范围：移植一个源类、而源端别的组件（绘制、覆盖层等）调用它的公开读方法时
做法：
- 列一份「源端外部调用点 ↔ 目标公开方法」清单：在源工程里搜这个类每个 public 方法在别的类里的调用点，目标类逐个给出同语义的公开方法，连同它读的存储字段和读时的换算（如存相机坐标、读时按矩形和偏移重投影到预览坐标）一起移植
- 按这份清单核对读面是否齐全，不只按本 feature 的对接点核对
