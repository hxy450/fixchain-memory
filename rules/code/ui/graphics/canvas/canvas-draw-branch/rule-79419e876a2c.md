# 复刻 ItemDecoration 折线时点和标签共用原点，点已含留白就不再给 Polyline 设 position

审的是：代码
触发（任一种）：
- 读到：源端 RecyclerView.ItemDecoration 在同一个 Canvas 上用同一个 y 换算（已含 paddingTop 和文字高度）画折线和节点温度标签；写错的样子：Polyline 的 points 用的是已含顶部留白的绝对 y，又给 Polyline 设了 .position({ y: <留白> })，折线相对标签整体下移、超出容器被裁
适用范围：用 ArkUI Polyline / Shape 加绝对定位的 Text 复刻源端在同一画布上画的折线与标签时
做法：
- 点坐标和标签用同一原点：点 y 已按源端换算含顶部留白和文字高度时，Polyline 不再设 position 偏移；要给 Polyline 设 .position({ x, y }) 就从每个点的 y 里扣掉同一个偏移
- 提交前用最高温、最低温两组边界值算出屏幕 y，确认都在容器高度内，且和对应标签对齐
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- points(value: Array<any>): PolylineAttribute：折线经过的坐标点列表，坐标相对 Polyline 自身（出处：鸿蒙 SDK 的 ets/component/polyline.d.ts，PolylineAttribute.points）
- position(value: Position | Edges | LocalizedEdges): T：组件相对父容器的绝对定位；给 Polyline 设了它，点坐标整体再平移这么多（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.position）
- 点 y 已含顶部留白时又 position 下移同一留白，折线落到容器外被裁；去掉重复偏移后与标签对齐：双重偏移的样子和修法（出处：卡里修好并验证过）
- points(value: Array<any>): PolygonAttribute：同族接口：Polygon 的顶点列表（出处：鸿蒙 SDK 的 ets/component/polygon.d.ts，PolygonAttribute.points）
针对本应用要查的：
- 源端的 y 换算公式：源工程 ItemDecoration 子类的 onDraw / onDrawOver 里把数值换成 y 的那个函数；读出顶部留白、底部留白、文字高度在公式里怎么加，确定目标点坐标是否已含这些量
