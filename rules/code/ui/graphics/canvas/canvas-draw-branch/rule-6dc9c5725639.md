# 临时诊断可以按 key 加条件，样式修复不绑在诊断条件上，交付前清掉诊断日志和 key 特判

审的是：代码
触发（任一种）：
- 写错的样子：交付的绘制代码里还留着 TEMP-DIAG 前缀的临时诊断日志，或样式赋值和诊断用的同一个 key 条件绑在一起（if (key === '某指标') { 打日志; 改 ctx.lineWidth }）
适用范围：为定位单个指标的显示差异加了临时诊断、随后修样式的绘制代码
做法：
- 样式修复写成不依赖诊断条件的通用赋值；交付前搜一遍 TEMP-DIAG 之类的诊断标记和按 key 的特判，全部删掉
