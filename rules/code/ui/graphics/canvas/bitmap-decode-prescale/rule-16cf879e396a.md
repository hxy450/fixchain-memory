# 预缩放尺寸依赖运行时几何时，放在几何计算之后、按源端时机每个视图实例重做，不用进程级守护

审的是：代码
触发（任一种）：
- 读到：源端视图构造器里先算几何（由屏宽算出格径之类），再调用预缩放方法 createScaledBitmap(raw, 格径, 格径, …)；写错的样子：位图装载放在几何计算之前，或用模块级的 `loaded` 布尔守护只做一次，后续页面复用旧尺寸的位图
适用范围：渲染实现阶段，预缩放的目标尺寸由运行时几何决定时
做法：
- 把预缩放放在几何计算之后调用，按源端时机（每次构造视图实例）用当时的尺寸重做；去掉进程级的一次性守护
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 预缩放移到几何初始化之后，去掉进程级守护，每个游戏页按当时的格径重做：修好后的时序（出处：卡里修好并验证过）
