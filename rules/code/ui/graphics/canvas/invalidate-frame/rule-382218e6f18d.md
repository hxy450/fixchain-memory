# 源 onPause/onResume 里启停自绘 View 的 tick 时，目标引擎向覆盖层发启停通知

审的是：代码
触发（任一种）：
- 读到：源预览类的 onPause / onResume 里调用自绘 View 的 onPause() / onResume()（移除或重启 tick）；写错的样子：目标引擎的 onPause / onResume 只调预览 surface 的空 onPause / onResume，没有通知覆盖层停止或重启绘制
适用范围：源端由预览控制类管理覆盖层 tick 生命周期，目标端拆成引擎类和 Canvas 覆盖层组件时
做法：
- 引擎提供「当前是否允许覆盖层绘制」的查询和一个生命周期监听，在 onResume / onPause / onDestroy 里发通知；覆盖层订阅后据此启停 tick
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 引擎新增绘制开关查询和生命周期监听，onResume / onPause / onDestroy 中发通知，覆盖层据此启停 tick：修好后的接线，暂停态不再按周期绘制（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
