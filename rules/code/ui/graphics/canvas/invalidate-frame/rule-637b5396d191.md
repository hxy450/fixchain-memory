# 依赖绘制结果的状态在使用时直读渲染器字段，不在请求重绘后立刻镜像

审的是：代码
触发（任一种）：
- 读到：源端在 onDraw 里算出的状态（如某个按钮是否可用）存在 View 字段里，事件处理时直接读；写错的样子：页面调用渲染器的重绘请求后，立刻把渲染器字段复制到 @Local 或 @State 镜像变量，后续逻辑读镜像
适用范围：Canvas 自绘视图的重绘改为下一帧异步执行后，页面读取绘制过程中算出的状态时
做法：
- 删去镜像变量，在消费时刻（如手指抬起的事件回调里）直接读渲染器上的字段
来源：1 张卡，1 个应用
