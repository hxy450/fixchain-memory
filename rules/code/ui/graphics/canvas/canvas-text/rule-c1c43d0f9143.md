# 截图里的空态文案在源图表绘制代码里找不到时，不在目标 Canvas 里补画

审的是：代码
触发（任一种）：
- 读到：参考截图里图表附近有空态文案，但安卓图表 View 的绘制代码里没有画它：存这句文案的字段只被赋值、没有被绘制代码读取；用户文字只列出要画边框和图例名；写错的样子：目标图表的 Canvas 绘制里新增了空态提示（如在副图面板里用 `fillText` 右对齐、垂直居中画一句无数据提示），并为它加了空数据标志参数
适用范围：按参考截图给图表补无数据空态，页面由图表 Canvas 与并列的列表、侧栏组件组成时
做法：
- 图表的空态只画用户文字列出的元素（边框和图例里的指标名），删掉 Canvas 里补画的空态提示和为它加的标志参数
- 截图里多出的文案先按页面布局对到它所在的组件，到相邻组件的空态实现里去迁（见下方要查的）；对不上时不进 Canvas
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- fillText(text: string, x: number, y: number, maxWidth?: number): void：Canvas 上画文字的接口；目标图表里每处 fillText 都要在源端绘制代码里有对应的画文字调用（出处：鸿蒙 SDK 的 ets/component/canvas.d.ts，CanvasRenderer.fillText）
- strokeText(text: string, x: number, y: number, maxWidth?: number): void：同族接口：CanvasRenderer.strokeText，描边文字（出处：鸿蒙 SDK 的 ets/component/canvas.d.ts，CanvasRenderer.strokeText）
- 图表空态只保留边框和图例名、空态文案移到并列列表组件后，与参考截图一致：空态文案归属并列组件的修法（出处：卡里修好并验证过）
针对本应用要查的：
- 截图里的空态文案属于页面上哪个组件：源工程里这个页面的布局（布局 XML 或组装页面的代码）里图表与侧栏、列表的排布，以及在源码里全仓搜这句文案或存它的字段；按截图里文案所在区域对上布局里的组件；字段只被赋值、没有绘制代码读它的，说明图表不画它，去相邻组件里找真正显示它的地方
未核实：两张参考截图只留了地址，文案的像素位置没能直接核对
