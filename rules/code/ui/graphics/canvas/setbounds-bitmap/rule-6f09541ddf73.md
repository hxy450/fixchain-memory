# 源端坐标有 (int) 强转时，目标用 Math.trunc 截断后再绘制，不用 Math.floor

审的是：代码
触发（任一种）：
- 读到：源端坐标表达式里有 `(int)` 强转，如 `setBounds((int)(...), ...)`、`int dX = (int)(...)`；写错的样子：目标对应的边界或位移保留浮点直接绘制，或者用了 `Math.floor` / `Math.round`
适用范围：把安卓自绘 View 的绘制边界和位移（出生、合并缩放、移动动画等）迁到 ArkUI Canvas 时
做法：
- 逐个对照源端坐标表达式里的 (int)，目标在同一位置写 Math.trunc(表达式)，截断后再交给绘制调用
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Java 的 (int) 强转向零截断；合并扩张和反向位移时表达式会出现负数：所以要用向零截断的 Math.trunc，负数时 Math.floor 会多减 1（出处：卡里修好并验证过）
- Math.trunc(x: number): number：去掉小数部分，取整数部分（向零）（出处：鸿蒙 SDK 的 ets/build-tools/ets-loader/node_modules/typescript/lib/lib.es2015.core.d.ts，Math.trunc）
- Math.floor(x: number): number：取不大于 x 的最大整数，负数时和截断结果不同（出处：鸿蒙 SDK 的 ets/build-tools/ets-loader/node_modules/typescript/lib/lib.es5.d.ts，Math.floor）
- setBounds(int left, int top, int right, int bottom)：源端边界本身就是 int（出处：android.graphics.drawable.Drawable#setBounds）
