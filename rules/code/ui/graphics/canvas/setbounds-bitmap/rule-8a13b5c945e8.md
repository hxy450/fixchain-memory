# 矢量重绘替代被 setBounds 拉伸的位图时，圆角、字号、基线一起乘缩放比

审的是：代码
触发（任一种）：
- 读到：源端把圆角底 drawable 和文字一起画进固定尺寸的 `Bitmap`，动画期用 `Drawable.setBounds(...)` 把位图整体拉伸到新边界；写错的样子：目标改成逐帧 `roundRect` + `fillText` 矢量绘制，只把字号乘了缩放比，`roundRect` 的圆角半径仍是常量
适用范围：用 ArkUI Canvas 逐帧矢量绘制，替代源端预烘焙、再用 setBounds 拉伸的位图缓存时
做法：
- 缩放比 s = (右 − 左) / 烘焙尺寸，从当帧的绘制边界推出，不另传参数
- 先列出位图里烘焙的全部尺寸属性（圆角半径、字号、基线修正、描边宽等），统一乘 s：ctx.roundRect(x, y, w, h, 基准圆角 * s)，字号、基线同比缩放
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- roundRect(x: number, y: number, w: number, h: number, radii?: number | Array<number>): void，radii 默认 0：画圆角矩形路径；第五个参数就是要乘 s 的圆角半径（出处：鸿蒙 SDK 的 ets/component/canvas.d.ts，CanvasPath.roundRect）
- fillText(text: string, x: number, y: number, maxWidth?: number): void：画文字；字号在 ctx.font 里，和基线一起乘 s（出处：鸿蒙 SDK 的 ets/component/canvas.d.ts，CanvasRenderer.fillText）
- setBounds(int left, int top, int right, int bottom)：源端拉伸位图的边界；位图里的圆角和文字随边界等比缩放（出处：android.graphics.drawable.Drawable#setBounds）
- 由 (右 − 左) / 烘焙尺寸 推出缩放比，圆角 = 基准圆角 × 比例，字号和基线同比缩放后，出生和合并帧与源端一致：改法已在返修时逐帧插桩对照（出处：卡里修好并验证过）
