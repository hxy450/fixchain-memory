# elevation 配 outlineProvider=background 且无背景时，目标不加 .shadow

审的是：代码
触发（任一种）：
- 读到：同一节点写了 android:elevation 和 android:outlineProvider="background"（或没写 outlineProvider），且没有 android:background；写错的样子：目标组件按 elevation 直译加了 .shadow({ radius: …, offsetY: … })
适用范围：源 View 写了 android:elevation、迁成 ArkUI 组件阴影时
做法：
- 先看同一节点的 outlineProvider 和 background：outlineProvider 是 background 且节点没有背景时不投影，目标不写 .shadow
- elevation 只在源端确实投影时才转成 .shadow，不按映射表「android:elevation → .shadow()」无条件直译
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ViewOutlineProvider.BACKGROUND：没有背景时生成 alpha 为 0 的矩形轮廓：outlineProvider=background 且无背景，阴影轮廓是透明的（出处：android.view.ViewOutlineProvider#BACKGROUND）
- View 的默认 outlineProvider 就是 ViewOutlineProvider.BACKGROUND：没写 outlineProvider 时同样按背景取轮廓（出处：android.view.View#setOutlineProvider）
- ViewOutlineProvider.BOUNDS：按矩形边界、alpha 1 生成轮廓：源端写 bounds 时没有背景也投影（出处：android.view.ViewOutlineProvider#BOUNDS）
- 写了 elevation 和 outlineProvider=background、没有背景的图片，删掉 .shadow 后与源端一致：这种组合在源端不投影（出处：卡里修好并验证过）
- shadow(value: ShadowOptions | ShadowStyle): T：确有投影时用的组件阴影接口（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.shadow）
