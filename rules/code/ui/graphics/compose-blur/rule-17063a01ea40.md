# Modifier.blur 没写 edgeTreatment 时，模糊层大于显示区并由外层 clip 裁掉

审的是：代码
触发（任一种）：
- 读到：Modifier.blur(…) 没写 edgeTreatment（默认 BlurredEdgeTreatment.Rectangle，边缘不淡出）；写错的样子：被 .blur(…) 的组件和显示区一样大，外层容器没有 .clip(true)
适用范围：Compose 模糊层译成 ArkUI blur、源端边缘不淡出时
做法：
- 让被模糊的层比显示区大，外层 Stack 写 .clip(true) 裁到显示区
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 外层 Stack clip 避免模糊边缘淡出：修好后的写法（出处：卡里修好并验证过）
- clip(value: boolean): T：裁掉超出本组件边界的子组件（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.clip）
未核实：Compose 默认 BlurredEdgeTreatment.Rectangle 按卡写，本机没有 Compose 源码核实
