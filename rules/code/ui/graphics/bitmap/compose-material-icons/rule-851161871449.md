# Icons.AutoMirrored 图标转 Image 时写 matchTextDirection(true)

审的是：代码
触发（任一种）：
- 读到：Compose 里用 Icons.AutoMirrored.*（如 Icons.AutoMirrored.Rounded.ArrowBack）；写错的样子：转成普通 Image($r('app.media.…'))，没有 .matchTextDirection(true)
适用范围：迁移随布局方向镜像的图标时
做法：
- 写成 Image(...).matchTextDirection(true)，或经已有的镜像图标按钮组件渲染
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- matchTextDirection(value: boolean): ImageAttribute：按系统语言方向显示图片，默认 false（出处：鸿蒙 SDK 的 ets/component/image.d.ts，ImageAttribute.matchTextDirection）
