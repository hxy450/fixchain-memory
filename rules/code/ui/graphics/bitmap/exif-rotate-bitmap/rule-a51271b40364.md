# 源端用 Matrix 旋转位图、目标手写像素平面旋转时，索引按新行乘输出宽加新列写

审的是：代码
触发（任一种）：
- 读到：源端经 `Matrix` 按 EXIF 方向旋转 `Bitmap`；写错的样子：手写平面旋转 90° 写成 `out[(H-1-y)*out.width + x]`、270° 写成 `out[y*out.width + (W-1-x)]`，把新 x 当成行号
适用范围：把安卓的位图旋转迁到鸿蒙、改用手写像素平面旋转时
做法：
- 能用平台 `pixelMap.rotate(angle)` 时优先复用
- 手写时目标索引按 newY*outWidth+newX：输出宽为原高 H；90° 是 (x,y)→(H−1−y, x)，写 `out[x*outW + (H-1-y)]`；270° 是 (x,y)→(y, W−1−x)，写 `out[(W-1-x)*outW + y]`
- 用非正方形小图（如 2×3）给 90° 和 270° 各写一个单测
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- rotate(angle: number): Promise<void>：PixelMap 的旋转（声明 @since 12 起带 @crossplatform）（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.image.d.ts，PixelMap.rotate）
- 90°：out[x*outW + (H-1-y)]；270°：out[(W-1-x)*outW + y]：修好后的索引，旋转单测通过（出处：卡里修好并验证过）
- rotate(angle: number, callback: AsyncCallback<void>): void：同族接口：PixelMap 旋转的回调版（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.image.d.ts，PixelMap.rotate）
