# 读 EXIF 方向用 getImageProperty(ORIENTATION) 时按描述字符串映射角度，不当数字解析

审的是：代码
触发（任一种）：
- 读到：源端 ExifInterface 按整数读 TAG_ORIENTATION（ORIENTATION_ROTATE_90 等）再旋转；写错的样子：目标对 getImageProperty(image.PropertyKey.ORIENTATION) 的结果写 Number(...) / parseInt(...)，拿不到角度
适用范围：把源端 EXIF 方向校正迁成 ImageSource.getImageProperty 时
做法：
- 把返回的描述字符串映射成角度：'Top-left' → 0，'Right-top' → 90，'Bottom-right' → 180，'Left-bottom' → 270（比较时忽略大小写）；返回的是 1–8 的数字串时按 1→0、6→90、3→180、8→270 兼容
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ORIENTATION = 'Orientation'：读取时以字符串返回，"Top-left" 不旋转、"Right-top" 顺时针 90°、"Bottom-right" 180°、"Left-bottom" 顺时针 270°：读出的是描述值，不是数字；未定义值读成 "Unknown Value <number>"（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.image.d.ts，PropertyKey.ORIENTATION）
- getImageProperty(key: PropertyKey, options?: ImagePropertyOptions): Promise<string>：读 EXIF 属性，返回字符串（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.image.d.ts，ImageSource.getImageProperty）
- ORIENTATION_NORMAL = 1，ORIENTATION_ROTATE_180 = 3，ORIENTATION_ROTATE_90 = 6，ORIENTATION_ROTATE_270 = 8：源端整数取值，对应数字串兼容分支（出处：android.media.ExifInterface#ORIENTATION_ROTATE_90）
- ORIENTATION 改按 'right-top' 等描述值映射后，旋转正确：返修的落法（出处：卡里修好并验证过）
