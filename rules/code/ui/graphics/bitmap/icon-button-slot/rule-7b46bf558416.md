# 照已完成页面范式复用图标控件行时，按本页源 XML 重核 scaleType 和盒尺寸

审的是：代码
触发（任一种）：
- 读到：派工写「可参考已完成的同域页面」，范式页里图标是盒尺寸 Image 加 objectFit(ImageFit.Contain)；写错的样子：本页 Image 的宽高和 objectFit 与范式页逐字相同，没按本页源 XML 的 android:scaleType 和盒尺寸重核；或某页已修好图标尺寸，别的页面同一图标仍是旧写法
适用范围：以已完成页面为范式复用控件行，或修过某页图标尺寸之后
做法：
- 复用范式页的控件行时，逐个按本页源 XML 的 android:scaleType、layout_width / layout_height 和图标资源重算 Image 尺寸，不照抄范式页的数值
- 修好某页的图标尺寸后，按同一图标资源名或同一控件行搜其他页面，一并改
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 满盒 Contain 的错误经范式文件传到另一页，之后整页重写只做接线、原样保留：不重核时偏差会跟着范式扩散（出处：卡里修好并验证过）
