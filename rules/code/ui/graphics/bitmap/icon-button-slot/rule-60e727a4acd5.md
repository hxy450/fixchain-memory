# 工具栏点击槽宽取源布局承载区宽度，与图标尺寸分开核对

审的是：代码
触发（任一种）：
- 读到：源工具栏布局里每个按钮的承载区有固定 android:layout_width（返回键与其余按钮可能不同），ImageView 在其中居中；写错的样子：目标端槽位的 .width(…) 沿用旧代码的值，与源布局承载区宽度不符，或者没有和图标分开的槽位
适用范围：转换工具栏、每个按钮都有固定宽度承载区时
做法：
- 从源布局逐个读出承载区宽度（dp 数值照搬为 vp），写到外层槽位的 .width(…)，高度取主栏高度；图标绘制尺寸另按像素换算，两者分开核对
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 槽位宽取源布局承载区宽、高取主栏高，槽内放按像素换算的图标后与源端一致：按此改后保留（出处：卡里修好并验证过）
针对本应用要查的：
- 每个按钮承载区的宽度：源工程工具栏布局 XML 里包住每个 ImageView 的容器（或 ImageView 自身）的 android:layout_width；dp 数值照搬成 vp；返回键等与其余按钮不同宽时分别写
