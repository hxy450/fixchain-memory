# 源端一个编码对多个资源、各处绑定不同字段时，目标按字段拆映射函数，每处按源端绑定选

审的是：代码
触发（任一种）：
- 读到：源端枚举或映射为每个编码返回几个资源（如 Triple(背景图, 白色图标, 蓝色图标)），布局里不同位置绑定不同字段（data binding 的 viewModel 字段，选中与非选中取不同变体）；写错的样子：目标只有一个映射函数，各处共用同一资源：背景图被当成小图标，或该用另一变体的地方用了同一个 $r('app.media.…')
适用范围：迁移按使用场景区分变体的图标资源映射时
做法：
- 按源端的取值字段各写一个映射函数（背景、图标变体一、图标变体二各一个），都返回 $r('app.media.<名>')
- 每个使用处按 Android 布局或代码绑定的字段选函数；源端按选中态在变体间切换的，目标也按同一条件切换
针对本应用要查的：
- 每个使用处绑定的是哪个字段：源工程布局 XML 里 ImageView 的 android:src / app:srcCompat 数据绑定表达式（如 @{viewModel.…}），以及给这些字段赋值的实体类；逐处记下绑定字段和取值条件（选中、非选中、列表类型），再对到目标的映射函数
