# 源端用位图图标时，目标引用原名资源，不用近名图标、sys.symbol 或 Unicode 占位

审的是：代码
触发（任一种）：
- 读到：规格的元素→资源表或源布局给出 @drawable/… 原图；写错的样子：菜单里写的是 $r('app.media.…') 指向别的模块的同类近名图标（带 1 / 2 后缀等），而不是原名
- 读到：源端按钮是 ImageView / ImageButton 加位图；写错的样子：现有或新写的代码用 SymbolGlyph($r('sys.symbol.…')) 占位，只改了 fontColor 或字号
- 读到：源端悬浮入口是位图背景加嵌套 ImageView 图标；写错的样子：目标写成 Text('⇥') 这类 Unicode 字形
适用范围：迁移或对齐页面时，源端用位图资源的工具栏、底栏按钮和悬浮入口
做法：
- 写成 Image($r('app.media.<原名>'))，原名照规格或源布局里的 drawable 名
- 现有代码里对应 Android 位图的 SymbolGlyph 或 Unicode 占位，换成原图资源；只改颜色或字号不算完成对齐
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 顶部和底栏最终都改为原名位图、去掉全部着色，悬浮入口改为复制进来的原图标：修好的结果（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
