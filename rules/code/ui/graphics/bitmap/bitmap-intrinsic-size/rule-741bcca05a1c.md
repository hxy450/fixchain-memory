# 多个页面共用同一种卡片角标时抽成一个公共 @Builder 或组件，在一处定尺寸

审的是：代码
触发（任一种）：
- 读到：多个列表、搜索页的安卓源码共用同一个卡片 item 布局 XML，里面的角标 ImageView 是 wrap_content；写错的样子：几个鸿蒙页各有一份逐行相同的 @Builder 拷贝，缺的尺寸约束随拷贝传播
适用范围：界面转换时多个页面复用同一种卡片或角标布局
做法：
- 抽成一个公共 @Builder 或 @Component，宽高、objectFit 和 margin 只在这一处按安卓布局定好，各页引用它
来源：1 张卡，1 个应用
