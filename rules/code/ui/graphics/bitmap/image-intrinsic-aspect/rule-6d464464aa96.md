# 源图片没有宽高约束时，读出素材像素比例，用满宽加 aspectRatio 定高

审的是：代码
触发（任一种）：
- 读到：源 IonImg / <img> 没有 width、height 约束（满宽、按素材固有比例）；写错的样子：目标写 Image(…).objectFit(ImageFit.Contain).layoutWeight(1)，图片在撑满的框里内缩；或按「截图」之类的推测定比例
适用范围：源端图片按固有比例进入内容流、目标用 ArkUI Image 时
做法：
- 写布局前读出素材的实际像素宽高，写 .width('100%').aspectRatio(宽 / 高)，或放进同比例的容器里 .objectFit(ImageFit.Cover) 满幅
- objectFit 只决定内容怎么缩放，不拿它代替尺寸约束
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- aspectRatio(value: number): T：组件宽高比（宽 / 高），配合 width 定出高度（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.aspectRatio）
- objectFit(value: ImageFit): ImageAttribute，默认 ImageFit.Cover：图片在容器里的缩放方式，不决定容器尺寸（出处：鸿蒙 SDK 的 ets/component/image.d.ts，ImageAttribute.objectFit）
- aspectRatio(1) 方图满宽；之后改为等比方形容器内 Cover 满幅：修复时先后用过的两种写法，插图都不再内缩（出处：卡里修好并验证过）
针对本应用要查的：
- 素材的像素宽高：源工程里这个图片引用的素材文件（png / jpg / webp）；读文件头里的宽、高像素数，比例写成 aspectRatio(宽 / 高)；只看文件字节数不够
