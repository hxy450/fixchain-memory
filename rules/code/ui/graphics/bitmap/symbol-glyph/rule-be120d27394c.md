# 把 Text 换成 SymbolGlyph 时，fontColor 传 ResourceColor 数组，不沿用单值

审的是：代码
触发（任一种）：
- 读到：审计或派工要求把 Text('✓') 这类 Unicode 符号换成 SymbolGlyph($r('sys.symbol.…'))；写错的样子：SymbolGlyph(...) 后面保留原 Text 的单值 .fontColor($r('app.color.…'))，没包成数组
适用范围：把 Text 等组件换成 SymbolGlyph（或 SymbolSpan）并沿用原修饰链时
做法：
- 写成 SymbolGlyph($r('sys.symbol.<名>')).fontColor([<原颜色>])，原单值颜色包进数组
- 沿用的其他修饰器逐个对照 SymbolGlyphAttribute 的签名再保留
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- fontColor(value: Array<ResourceColor>): SymbolGlyphAttribute：SymbolGlyph 的颜色只收数组（出处：鸿蒙 SDK 的 ets/component/symbolglyph.d.ts，SymbolGlyphAttribute.fontColor）
- fontSize(value: number | string | Resource): SymbolGlyphAttribute：SymbolGlyph 的字号可收 Resource，单值沿用即可（出处：鸿蒙 SDK 的 ets/component/symbolglyph.d.ts，SymbolGlyphAttribute.fontSize）
- fontWeight(value: number | FontWeight | string): SymbolGlyphAttribute：SymbolGlyph 的字重不收 Resource（出处：鸿蒙 SDK 的 ets/component/symbolglyph.d.ts，SymbolGlyphAttribute.fontWeight）
- fontColor(value: Array<ResourceColor>): SymbolSpanAttribute：同族接口：SymbolSpan 的颜色同样只收数组（出处：鸿蒙 SDK 的 ets/component/symbol_span.d.ts，SymbolSpanAttribute.fontColor）
- fontColor?: Array<ResourceColor>：同族接口：RichEditor 里符号 span 样式的颜色也是数组（出处：鸿蒙 SDK 的 ets/component/rich_editor.d.ts，RichEditorSymbolSpanStyle.fontColor）
- 颜色改为 [$r(…)] 数组后编译通过：修好后的写法（出处：卡里修好并验证过）
未核实：卡里的编译报错出自 API 26（target_sdk 26.0.0），本机核对用的是 API 23
