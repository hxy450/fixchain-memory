# 测量内容自然高度的副本放进 Scroll，不放在受父容器高度约束的 Stack/Column 里

审的是：代码
触发（任一种）：
- 写错的样子：用来测内容自然高度、判断快照是否被截断的隐形副本放在高度受限的 Stack 或 Column 里（如 .height(0) 的 Stack），测得高度被父容器可用高度夹紧，与被截断的快照「一致」，分段从不触发
适用范围：需要测量内容不受父容器约束的自然高度时（如长图导出前判断是否截断）
做法：
- 测量副本和分段视口都放进 Scroll（主轴不限测量），不放在受父容器可用高度约束的 Stack / Column 里
- 校验通过与降级到分段两条路径都打日志（hilog），便于确认走了哪条
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Scroll 单个子组件宽高最大 16777216px（API 21 起；API 20 及之前 1000000px）：放进 Scroll 的测量副本可以超出父容器高度，但不能超过这个上限（出处：ts-container-scroll.md，子组件）
未核实：Scroll 主轴不限测量这一点出自卡里修复的第二轮，最终版本没上机验证
