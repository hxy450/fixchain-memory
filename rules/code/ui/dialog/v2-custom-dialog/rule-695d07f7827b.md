# 弹窗和宿主各持一个 ViewModel 时，弹窗改的持久化偏好要同步到宿主的状态来源

审的是：代码
触发（任一种）：
- 读到：弹窗组件里 `new` 了自己的 ViewModel 实例，改偏好后经它持久化，再只用回调通知宿主；宿主刷新时把自己 ViewModel 的字段回填到 @Local；写错的样子：宿主回调里只改 @Local，删掉了调用宿主 ViewModel 的 setter；关闭后刷新用旧快照覆盖 @Local，下次打开把旧值当初始值传给弹窗
适用范围：把弹窗接入宿主页、两边各自持有 ViewModel 实例，且弹窗会改持久化偏好时
做法：
- 弹窗里改的持久化偏好同步到宿主的状态来源：回调里调用宿主 ViewModel 的 setter，或每次打开弹窗前经宿主 ViewModel 从持久化重读，不只改宿主 @Local
- 接线前检查宿主的刷新路径会不会用 ViewModel 快照回填本地状态，会的话先保证快照已更新
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 每次打开弹窗前经宿主 ViewModel 重读该偏好后，重开弹窗显示的是修改后的状态：打开前重读是返修后核对过的写法（出处：卡里修好并验证过）
