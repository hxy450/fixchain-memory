# 弹窗组件和宿主之间的接线

agent 会看到什么：读到弹窗 show 时带 onDismiss 或结果回调，或多个页面共用同一个详情对话框、底部面板；产物里遮罩、返回键、页面离开的关闭路径和结果回传，以及共享组件的 @Event 在各宿主调用点有没有接上

## 规矩

- rule-39ef56996aa5｜弹窗接线时核对遮罩点击、返回键、页面离开都能关闭且回调只走一次｜读到：安卓端弹窗 show 时带 onDismiss / dismissCallback，关闭后推进后续弹窗队列；写错：页面叠层的遮罩 Column 没有 .onClick，宿主没有 onBackPressed 拦截；或关闭结果回调可能走多次
- rule-722b4e900cb0｜源端带结果回调的选择器改成 Navigation 打开时，同一改动里接通结果回传｜读到：源端用 DialogFragment.show(..., 当前值) { result -> … } 这类带结果回调的选择器，回调里把结果写回控件（setText、刷新预览）；写错：调用页只写 pushPathByName('目标页', new 参数类(当前值))，参数类没有结果回调、也没用 onPop，写回编辑状态的方法没接到任何返回路径
- rule-84d605ef4172｜源端入口调用跨页面共享的对话框或分享弹层时，目标复用工程里的同职责组件并接动作回调｜读到：源端列表项点击调用跨页面共享的详情对话框（DialogFragment 子类的静态 show(supportFragmentManager, …)），分享按钮弹公共底部分享弹层；写错：页面里保留或扩写一份自绘的详情副本（自己的 Sheet / @Component），目标工程里已有的同名共享组件没被复用，副本里的动作只接了一部分
- rule-f5e2d3d7eaac｜给共享面板组件新增宿主要接的 @Event 时，逐个接上它的全部宿主调用点｜写错：共享组件新增了 @Event 回调（默认空函数），只有当前切片的宿主传了它；别的宿主里对这个组件仍是不传参数的调用，条目点击在那些宿主里没有反应
