# 弹窗接线时核对遮罩点击、返回键、页面离开都能关闭且回调只走一次

审的是：代码
触发（任一种）：
- 读到：安卓端弹窗 show 时带 onDismiss / dismissCallback，关闭后推进后续弹窗队列；写错的样子：页面叠层的遮罩 Column 没有 .onClick，宿主没有 onBackPressed 拦截；或关闭结果回调可能走多次
适用范围：目标端为弹窗接触发、宿主或关闭回调时；onDidDisappear 按声明从 API 19 起有
做法：
- 逐项核对：遮罩/空白点击、返回键、页面离开都会关闭，且结果回调只走一次
- 叠层遮罩没有 onClick、宿主没有返回拦截时，改成真弹窗 API：autoCancel: true（点外部关闭）、返回关闭（卡里写的 backCancel），在 onDidDisappear 里做单次清理和回调
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- autoCancel?: boolean：点弹窗外部是否自动关闭（出处：鸿蒙 SDK 的 ets/component/custom_dialog_controller.d.ts，CustomDialogControllerOptions.autoCancel）
- onDidDisappear?: Callback<void>：弹窗消失后的回调，放单次清理和结果回调（@since 19）（出处：鸿蒙 SDK 的 ets/component/custom_dialog_controller.d.ts，CustomDialogControllerOptions.onDidDisappear）
未核实：backCancel 不在鸿蒙 SDK 的 CustomDialogControllerOptions 里，应是项目所用弹窗库的选项，没查实
