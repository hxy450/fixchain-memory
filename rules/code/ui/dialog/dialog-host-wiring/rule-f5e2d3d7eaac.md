# 给共享面板组件新增宿主要接的 @Event 时，逐个接上它的全部宿主调用点

审的是：代码
触发（任一种）：
- 写错的样子：共享组件新增了 @Event 回调（默认空函数），只有当前切片的宿主传了它；别的宿主里对这个组件仍是不传参数的调用，条目点击在那些宿主里没有反应
适用范围：给被多个页面复用的面板或列表组件新增要由宿主接线的 @Event 时
做法：
- 新增 @Event 前 grep 这个组件在目标工程里的全部调用点，每处都传入回调；当前切片不负责的宿主登记交办项
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- @Event 没有初始化时，会自动生成一个空的函数作为默认回调：宿主不传就静默不响应，编译不报错（出处：arkts-new-event.md，概述）
