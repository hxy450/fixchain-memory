# 源端入口调用跨页面共享的对话框或分享弹层时，目标复用工程里的同职责组件并接动作回调

审的是：代码
触发（任一种）：
- 读到：源端列表项点击调用跨页面共享的详情对话框（DialogFragment 子类的静态 show(supportFragmentManager, …)），分享按钮弹公共底部分享弹层；写错的样子：页面里保留或扩写一份自绘的详情副本（自己的 Sheet / @Component），目标工程里已有的同名共享组件没被复用，副本里的动作只接了一部分
适用范围：功能实现阶段接线页面里调用源端共享组件（详情弹窗、公共分享弹层）的入口时
做法：
- 先在目标工程 rg 同名或同职责组件及其现有宿主接线（组件名、它的 onAction 回调、弹出它的调用方），优先复用并接上它的动作回调；删掉页面内副本，不再扩写
- 分享同样改用目标工程里公共分享弹层的控制器，走完分享闭环
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 删除页面内详情副本，改用共享详情组件并以 onAction 覆盖全部动作类别；分享改用公共分享弹层的控制器：修好后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 目标工程里有没有对应的共享组件、别的页面怎么接它：目标工程 .ets 源码：按源端组件名和职责（详情、分享）rg 组件定义，再 rg 它的宿主（谁弹出它、谁传 onAction）；照现有宿主的接法传参和接动作回调；它的动作枚举就是要覆盖的动作清单
