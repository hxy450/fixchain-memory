# 复刻框架 Material AlertDialog 时，标题和按钮的字号字重按主题取，不按印象写 Bold

审的是：代码
触发（任一种）：
- 读到：源端 android.app.AlertDialog.Builder 只设 setTitle / setMessage / setPositiveButton / setNegativeButton，没有自定义布局或样式，应用主题是框架 Material 一族；写错的样子：目标的标题写成 .fontWeight(FontWeight.Bold)，或字号、字重与计划值不一致；按钮字号字重是估的
适用范围：用 ArkUI 自绘卡片复刻安卓框架默认 AlertDialog、主题为框架 Material 一族时
做法：
- 标题写 .fontSize(20).fontWeight(FontWeight.Medium)，按钮写 .fontSize(14).fontWeight(FontWeight.Medium)，按钮文字色取主题的 colorAccent
- 计划值和写出值不一致时，以主题里的出处为准
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- TextAppearance.Material.DialogWindowTitle 继承 TextAppearance.Material.Title：textSize = @dimen/text_size_title_material（20sp），fontFamily = @string/font_family_title_material（sans-serif-medium）：框架 Material 对话框标题是 20sp、Medium 字重（出处：Android SDK 平台资源 data/res/values/styles_material.xml，TextAppearance.Material.Title；dimens_material.xml，text_size_title_material；donottranslate_material.xml，font_family_title_material（按应用的 compileSdk 取对应平台））
- TextAppearance.Material.Button：textSize = @dimen/text_size_button_material（14sp），fontFamily = @string/font_family_button_material（sans-serif-medium），textAllCaps = true：框架 Material 按钮是 14sp、Medium 字重、全大写（出处：Android SDK 平台资源 data/res/values/styles_material.xml，TextAppearance.Material.Button；dimens_material.xml，text_size_button_material（按应用的 compileSdk 取对应平台））
- fontWeight(value: number | FontWeight | ResourceStr): TextAttribute：Text 字重；字符串 "medium" 对应 FontWeight.Medium（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.fontWeight；ts-basic-components-text.md，fontWeight）
针对本应用要查的：
- 按钮文字色 colorAccent 的具体值：源工程 res/values 下应用主题的 style（AndroidManifest 里 application / activity 的 android:theme 指向的那个），没有覆盖时取 Android SDK 平台资源 data/res/values/themes_material.xml 里对应主题的 colorAccent；顺着 @color/… 或 ?attr/… 解析到色值，写成按钮的 fontColor
