# AlertDialog 按钮的 minHeight 不是渲染高度，不写成 .height(48)

审的是：代码
触发（任一种）：
- 读到：对话框按钮样式 Widget.Material.Button.ButtonBar.AlertDialog 的 minHeight 是 @dimen/alert_dialog_button_bar_height（48dip）；写错的样子：目标按钮写成 .height(48)，没有水平内距和 minWidth
适用范围：自绘卡片复刻框架 Material AlertDialog 的按钮条时
做法：
- 按钮高度取实测或完整样式链的结果，不把 minHeight 当高度；Material.Light 下照卡里实测写：按钮条上下 4vp、按钮高 54vp、constraintSize({ minWidth: 64 })、文字左右各 12vp，做成共享按钮组件
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Widget.Material.Button.ButtonBar.AlertDialog：minWidth @dimen/alert_dialog_button_bar_width，minHeight @dimen/alert_dialog_button_bar_height：样式里给的是最小值，不是渲染尺寸（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.Button.ButtonBar.AlertDialog（按应用的 compileSdk 取对应平台））
- alert_dialog_button_bar_height = 48dip：按钮最小高度（出处：Android SDK 平台资源 data/res/values/dimens.xml，alert_dialog_button_bar_height（按应用的 compileSdk 取对应平台））
- Material.Light 对话框参照机实测：按钮 54dp 高、minWidth 64dp、按钮条上下 4dp、文字左右 12dp：渲染尺寸，按它写后与源端一致（出处：卡里修好并验证过）
针对本应用要查的：
- 主题不是 Material.Light 时的按钮实际尺寸：应用主题链里的 buttonBarButtonStyle 和 alertDialogTheme，按 Android SDK 平台资源 styles_material.xml、dimens*.xml 解析；解析 minHeight、minWidth、padding 和背景 inset；渲染高度以参照机实测为准
未核实：按钮实测 54dp 与样式 minHeight 48dp 的差额来自哪一层框架测量，卡里没从源码确认
