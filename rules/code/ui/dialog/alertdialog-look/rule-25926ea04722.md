# setView 对话框的标题与内容间距按 AlertController.setupView 定，不凭记忆加垫片

审的是：代码
触发（任一种）：
- 读到：对话框布局里 visibility="gone" 的 Space（Material 的 titleDividerNoCustom，contentPanel 里的 textSpacerNoTitle、textSpacerNoButtons），对话框用 setView 注入自定义视图；写错的样子：目标在标题和自定义内容之间、内容下方加了垫片（如 .padding({ top: 18, bottom: 8 })）
适用范围：用自绘卡片复刻框架 AlertDialog、有 setView 自定义视图时
做法：
- gone 的 Space 是否显示看 AlertController.setupView：有自定义视图时不打开 titleDividerNoCustom，改找 titleDivider（Material 标题布局没有这一项），消息区 Space 随 contentPanel 一起隐藏；所以自定义视图紧接标题、下方也不加垫片
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 有标题且有消息、列表或自定义视图时：没有自定义视图才找 titleDividerNoCustom，否则找 titleDivider：标题下间隔的显示条件（出处：com.android.internal.app.AlertController#setupView）
- 没有消息也没有列表时 contentPanel.setVisibility(View.GONE)：消息区里的 Space 跟着隐藏（出处：com.android.internal.app.AlertController#setupContent）
- titleDividerNoCustom、textSpacerNoTitle、textSpacerNoButtons 在布局里都是 android:visibility="gone"：布局里默认不显示，只由代码打开（出处：Android SDK 平台资源 data/res/layout/alert_dialog_title_material.xml、alert_dialog_material.xml（按应用的 compileSdk 取对应平台））
