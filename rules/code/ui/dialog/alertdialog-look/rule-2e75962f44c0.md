# M3 主题的 Material 对话框转卡片时，圆角 28、底色取主题值、宽度窗宽减 48vp

审的是：代码
触发（任一种）：
- 读到：源码用 `MaterialAlertDialogBuilder`（setView、单选列表或消息），应用主题沿 styles.xml 的 parent 链继承 `Theme.Material3.*`；写错的样子：对话框卡片写成 `borderRadius(4)`、`width('85%')` 或不设宽度，`backgroundColor` 用的是工程先例 token 而不是主题 colorSurfaceContainerHigh 解析出的颜色
适用范围：应用主题基底是 Theme.Material3.* 时，把 MaterialAlertDialog 转成 ArkUI 自绘对话框卡片
做法：
- 先沿 styles.xml 的 parent 链确认主题基底是 Theme.Material3.* 还是 Theme.MaterialComponents.*，不凭控件 style 名（如 Widget.MaterialComponents.TextInputLayout）或旧版经验推断
- M3 基底写 .borderRadius(28)；.backgroundColor 用主题 colorSurfaceContainerHigh 解析出的颜色（应用覆写了就取覆写值）
- 宽度为窗宽减左右 backgroundInset 各 24dp，限制在 280–560vp：写 .width('calc(95% - 48vp)')，并保留最小 280、最大 560 的宽度约束
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- MaterialAlertDialog.Material3 的 backgroundTint = ?attr/colorSurfaceContainerHigh：M3 对话框底色取主题的 colorSurfaceContainerHigh（出处：com.google.android.material:material 包内 res/values/values.xml，MaterialAlertDialog.Material3、macro m3_comp_dialog_container_color（按应用依赖的版本））
- shapeAppearance = ?attr/shapeAppearanceCornerExtraLarge，ShapeAppearance.M3.Sys.Shape.Corner.ExtraLarge 的 cornerSize 28dp：M3 对话框圆角 28dp（出处：com.google.android.material:material 包内 res/values/values.xml，macro m3_comp_dialog_container_shape、ShapeAppearance.M3.Sys.Shape.Corner.ExtraLarge（按应用依赖的版本））
- backgroundInsetStart / backgroundInsetEnd = 24dp：对话框卡片左右各缩进 24dp，宽度要减 48（出处：com.google.android.material:material 包内 res/values/values.xml，mtrl_alert_dialog_background_inset_start / _end（按应用依赖的版本））
- MaterialAlertDialog.MaterialComponents 的 backgroundTint = ?attr/colorSurface，shapeAppearance = ?attr/shapeAppearanceMediumComponent：M2 基底的底色和圆角来源不同，所以要先认基底（出处：com.google.android.material:material 包内 res/values/values.xml，MaterialAlertDialog.MaterialComponents（按应用依赖的版本））
- abc_dialog_min_width_minor = 95%：AppCompat 对话框竖屏最小宽度占比（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，abc_dialog_min_width_minor（按应用依赖的版本））
- width('calc(95% - 48vp)')、borderRadius(28)、底色取主题覆写的 colorSurfaceContainerHigh，保留 min 280 / max 560：返修后保留的卡片写法（出处：卡里修好并验证过）
- constraintSize(value: ConstraintSizeOptions): T：最小、最大宽度约束写在这里（minWidth / maxWidth）（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.constraintSize）
针对本应用要查的：
- colorSurfaceContainerHigh 的具体颜色（浅色、深色）：源工程 res/values 与 values-night 下 styles / themes 里应用主题对 colorSurfaceContainerHigh 的覆写；没覆写时查 Material 库 values.xml 里 Theme.Material3.Light / Dark 的 colorSurfaceContainerHigh；顺着 @color/… 解析到 #RRGGBB，浅色、深色各写一个颜色资源，卡片底色引用它；用动态取色主题时颜色随系统变化，记为近似
未核实：95% 是否就来自 windowMinWidthMinor 未核到 Material 对话框实际用的那条主题链；280–560dp 的宽度上下限在 Material 库资源里没查到对应 dimen，按卡写
