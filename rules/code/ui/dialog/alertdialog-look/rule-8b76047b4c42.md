# 复刻对话框时内容组件自己设卡片和内容区的最大高度，超高时框内滚动

审的是：代码
触发（任一种）：
- 读到：源端框架对话框里的 EditText 或内容行数没有上限（超高时由窗口收束、内容框内滚动）；写错的样子：目标卡片和 `TextArea` 都没有最大高度（没有 constraintSize({ maxHeight })），注释写「内容超出后内部滚动」，报告把越屏列为真机核对项
适用范围：用 openCustomDialog 承载自绘卡片复刻框架对话框、内容可能超过屏高时
做法：
- 卡片 maxHeight = 窗口高 − 状态栏避让高 − max(导航栏, 导航指示条避让高) − 2×16vp（对话框背景上下 inset）；内容区限高 = 卡片上限 − 标题高 − 按钮条高 − 其余固定间距，超出后在框内滚动
- 源端行为已经查清的当场实现，不留成报告里的真机核对项
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- getWindowAvoidArea(type: AvoidAreaType): AvoidArea：取系统栏、导航指示条的避让区（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.getWindowAvoidArea）
- AvoidAreaType.TYPE_SYSTEM = 0、TYPE_NAVIGATION_INDICATOR = 4：系统默认区域（状态栏、导航栏）和导航指示条（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，AvoidAreaType）
- dialog_background_material 的 android:inset 是 16dp：公式里扣掉的 2×16（出处：Android SDK 平台资源 data/res/drawable/dialog_background_material.xml（按应用的 compileSdk 取对应平台））
- 按窗口高减系统栏、导航指示条避让再减 2×16vp 设卡片上限，TextArea 限高后框内滚动：卡里的修法（出处：卡里修好并验证过）
