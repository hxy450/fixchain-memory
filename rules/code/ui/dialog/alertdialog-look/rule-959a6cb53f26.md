# 复刻 AlertDialog 内容区时写上 contentPanel 的最小高 48dp

审的是：代码
触发（任一种）：
- 读到：平台 alert_dialog_material.xml 里 id=contentPanel 写着 android:minHeight="48dp"；写错的样子：自绘对话框的消息或列表区域没有 .constraintSize({ minHeight: 48 })，内容短时区域被压扁
适用范围：自绘卡片复刻框架 Material AlertDialog 的消息区或列表区时
做法：
- 内容区容器写 .constraintSize({ minHeight: 48 })（单位 vp，对应源端 48dp）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- contentPanel：android:minHeight="48dp"：源端内容区的最小高度（出处：Android SDK 平台资源 data/res/layout/alert_dialog_material.xml，contentPanel（按应用的 compileSdk 取对应平台））
- constraintSize(value: ConstraintSizeOptions): T：目标设最小高度（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.constraintSize）
- 返修补上内容区 minHeight 48 后与源端一致：修法（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
