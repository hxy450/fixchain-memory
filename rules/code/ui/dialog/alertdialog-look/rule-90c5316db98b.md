# 自绘弹窗面板的容器和标题、消息、按钮条各区都要落底色，声明的颜色常量都要被引用

审的是：代码
触发（任一种）：
- 读到：规格或派工给了对话框面板底色（如源端默认 AlertDialog 的深色面板）；写错的样子：面板 Column 没有 .backgroundColor(...)，只有标题区上了色，消息区和按钮条透明；或者声明了面板底色常量却没被引用
适用范围：用页内自绘面板复刻对话框时
做法：
- 面板容器本身写 .backgroundColor(<面板底色>)；标题、消息、按钮条各区按契约的底色写在各自的容器上
- 写完核对声明过的颜色常量都被引用，没引用的要么用上、要么说明为什么不用
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- backgroundColor(value: ResourceColor): T：组件背景色（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.backgroundColor）
- ResourceColor 的 string 支持 '#ffffff'、'#ff000000'（argb）、'rgba(255, 100, 255, 0.5)'：面板底色的写法（出处：ts-types.md，ResourceColor）
