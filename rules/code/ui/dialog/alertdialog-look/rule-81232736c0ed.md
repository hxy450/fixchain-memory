# AlertDialog 有标题且有消息或列表时，标题下补 8vp 间隔，自定义视图框不加

审的是：代码
触发（任一种）：
- 读到：源对话框由 AlertDialog.Builder 生成（setTitle 加 setMessage / setItems / setAdapter），平台 alert_dialog_title_material.xml 里 id=titleDividerNoCustom 的 Space 写着 android:visibility="gone"、高 @dimen/dialog_title_divider_material；写错的样子：openCustomDialog 自绘卡片的标题 Text 和消息或列表之间没有间隔，注释或登记写「Material 无标题分隔线」
适用范围：用 openCustomDialog 等自绘卡片复刻框架 Material AlertDialog 的标题区时
不适用的情形：setView 自定义视图的对话框不加这段间隔（框架有自定义视图时不显示 titleDividerNoCustom）
做法：
- 有标题、且有消息或列表、且没有自定义视图时，在标题下加一个高 8vp 的空白（如 Blank().height(8) 或标题区 padding({ bottom: 8 })）；布局 XML 里的 gone 只是初值，不能据此判为不显示
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- AlertController.setupView：有标题时，若有消息或列表且没有自定义视图，把 titleDividerNoCustom 设为 VISIBLE：gone 的 Space 由框架代码在运行期按槽位组合显示（出处：com.android.internal.app.AlertController#setupView）
- titleDividerNoCustom：Space，初值 gone，高 @dimen/dialog_title_divider_material：间隔的资源定义（出处：Android SDK 平台资源 data/res/layout/alert_dialog_title_material.xml，titleDividerNoCustom（按应用的 compileSdk 取对应平台））
- dialog_title_divider_material = 8dp：间隔高度（出处：Android SDK 平台资源 data/res/values/dimens_material.xml，dialog_title_divider_material（按应用的 compileSdk 取对应平台））
- 列表框补上 8vp 间隔后与源端一致；setView 框不画间隔是对的：修法和例外（出处：卡里修好并验证过）
