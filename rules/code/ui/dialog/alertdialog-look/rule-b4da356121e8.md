# 源主题推出的弹窗取值与工程先例冲突时按源主题写，不复制登记为 UNC 的近似值

审的是：代码
触发（任一种）：
- 读到：读过的工程先例文件里弹窗卡片的注释写「弹窗族先例」「同款」，或它的取值出自登记为 `UNC`、「需真机校对」的近似推断；写错的样子：新写的弹窗卡片照抄先例的 borderRadius、backgroundColor、width、maxHeight，注释写「沿 … 弹窗家族语言」「`UNC` 定值」，与源主题推出的值不同
适用范围：转换对话框、弹层时参考工程里已写好的弹窗卡片
做法：
- 源主题推出的值与先例冲突时按源主题实现，在转换报告里标出先例与源主题的偏差
- 复用先例前核对它的出处；出处是登记为 `UNC` 或写着「需真机校对」的近似，不当族定值复制，回到源主题推值
来源：1 张卡，1 个应用
