# 弹层和手写遮罩都显式设 maskColor，统一引用源主题推出的遮罩色

审的是：代码
触发（任一种）：
- 读到：源端用 `MaterialAlertDialogBuilder` 或 `BottomSheetDialog` 弹出，主题 parent 链是 `Theme.Material3.*` 或主题里设了 `android:backgroundDimAmount`；写错的样子：openCustomDialog 的 options 里没有 maskColor、bindSheet 的 SheetOptions 里没有 maskColor，或页内 Stack 手写遮罩用的颜色和弹层不是同一个 token
适用范围：把源端对话框、底部面板转成 openCustomDialog、bindSheet 或页内手写遮罩时
做法：
- openCustomDialog(content, { maskColor: $r('app.color.<遮罩 token>'), … })；bindSheet(isShow, builder, { maskColor: 同一 token, … })；页内手写遮罩层 .backgroundColor(同一 token)
- 这个 token 的取值来自源主题的 backgroundDimAmount，不依赖 ArkUI 默认遮罩，也不用平台旧默认 0.6
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- openCustomDialog<T extends Object>(dialogContent: ComponentContent<T>, options?: promptAction.BaseDialogOptions): Promise<void>：UIContext 的 PromptAction 打开自定义弹窗，遮罩在 options 里设（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，PromptAction.openCustomDialog）
- BaseDialogOptions.maskColor?: ResourceColor，默认值 0x33000000：不设时是约 20% 黑，比 M3 的 0.32 浅（出处：鸿蒙 SDK 的 ets/api/@ohos.promptAction.d.ts，promptAction.BaseDialogOptions.maskColor；js-apis-promptAction.md，BaseDialogOptions）
- bindSheet(isShow: boolean, builder: CustomBuilder, options?: SheetOptions): T；SheetOptions.maskColor?: ResourceColor，默认 $r('sys.color.ohos_id_color_mask_thin')：同族接口：半模态的遮罩色（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.bindSheet、SheetOptions.maskColor；ts-universal-attributes-sheet-transition.md，SheetOptions）
- CustomDialogControllerOptions.maskColor?: ResourceColor：同族接口：CustomDialogController 写法的遮罩色（出处：鸿蒙 SDK 的 ets/component/custom_dialog_controller.d.ts，CustomDialogControllerOptions.maskColor）
- 新增遮罩 token #52000000，openCustomDialog、bindSheet 和手写遮罩都改用它：返修后保留的统一遮罩（出处：卡里修好并验证过）
