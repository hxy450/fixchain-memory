# Column 卡片里复刻左对齐标题、靠右按钮条时，子项设 width('100%') 再用 Start / End

审的是：代码
触发（任一种）：
- 读到：源端 AlertDialog.Builder 的平台默认外观（标题、正文左对齐，按钮条靠右），或规格、派工写明「标题左对齐、按钮右排」；写错的样子：Column 里的标题、正文 Text 只加了 .textAlign(TextAlign.Start)，按钮 Row 只加了 .justifyContent(FlexAlign.End)，都没设 width('100%')，父 Column 也没设 .alignItems(HorizontalAlign.Start)
适用范围：在 ArkUI Column 里自绘卡片（复刻对话框等），要让标题、正文靠起始边、按钮条靠末端时
做法：
- 给标题、正文 Text 和按钮 Row 都设 .width('100%')，再分别用 .textAlign(TextAlign.Start) 和 .justifyContent(FlexAlign.End)
- 或者给 Column 设 .alignItems(HorizontalAlign.Start)，按钮 Row 仍单独 .width('100%') 撑满再 justifyContent(FlexAlign.End)；写完逐个子项核对宽度或父容器的 alignItems
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- alignItems(value: HorizontalAlign): ColumnAttribute，默认值 HorizontalAlign.Center：Column 默认把内容宽度的子项水平居中（出处：鸿蒙 SDK 的 ets/component/column.d.ts，ColumnAttribute.alignItems；默认值见 ts-container-column.md，alignItems）
- textAlign(value: TextAlign): TextAttribute：只在 Text 自身宽度内对齐段落；Text 是内容宽度时设 Start 看不出效果（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.textAlign；ts-basic-components-text.md，textAlign）
- justifyContent(value: FlexAlign): RowAttribute：只在 Row 自身宽度内排子项；Row 是内容宽度时 End 不会靠右（出处：鸿蒙 SDK 的 ets/component/row.d.ts，RowAttribute.justifyContent）
- 标题、正文、按钮条都设 width('100%') 后分别用 Start 对齐和 End 排列，与平台默认外观一致：修好的写法（出处：卡里修好并验证过）
