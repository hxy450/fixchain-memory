# MaterialAlertDialog 转成的弹窗自带限高：卡片和内容 Scroll 都写 constraintSize

审的是：代码
触发（任一种）：
- 读到：源对话框是 DialogFragment + MaterialAlertDialogBuilder.setView(ScrollView …)，高度由 AlertDialog 框架自动封顶；写错的样子：弹窗组件的卡片只有 width('100%') 和不带 maxHeight 的 constraintSize，内容 Scroll 用 .layoutWeight(1)，注释写高度边界由宿主承担；改成窗口级弹窗后卡片撑满全窗、标题被压
适用范围：弹窗组件转换阶段，把 MaterialAlertDialog 类对话框转成 ArkUI 自定义弹窗内容时，不论呈现外壳定没定
做法：
- 卡片写 .constraintSize({ maxHeight: 窗口高 − 顶部和底部系统栏 − 上下 inset })（卡里 inset 取 2×80vp），卡片内容顶部对齐
- 内容 Scroll 用 .constraintSize({ maxHeight: 卡片上限减去标题和按钮区 }) 限高，不用 .layoutWeight(1) 把高度边界留给宿主
- 呈现外壳还没定时，组件也随附一个 show 封装（用 openCustomDialog 打开自己），宿主直接调用
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- constraintSize(value: ConstraintSizeOptions): T，默认 {minWidth: 0, maxWidth: Infinity, minHeight: 0, maxHeight: Infinity}：不写 maxHeight 时高度没有上限（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.constraintSize）
- getWindowAvoidArea(type: AvoidAreaType): AvoidArea；AvoidAreaType.TYPE_SYSTEM = 0、TYPE_NAVIGATION_INDICATOR = 4：取系统栏（状态栏）和底部导航条区域，用来从窗口高里扣掉（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.getWindowAvoidArea、AvoidAreaType）
- 卡片按屏高 − 系统栏 − 2×80vp 封顶、alignItems 顶部、内容 Scroll 用 constraintSize maxHeight：返修后卡片不再撑满全窗，长条目时按钮不溢出（出处：卡里修好并验证过）
