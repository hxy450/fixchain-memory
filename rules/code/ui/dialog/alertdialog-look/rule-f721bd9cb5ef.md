审的是：代码
触发（任一种）：
- 读到：源端多处 AlertDialog.Builder / DialogFragment.onCreateDialog，都没有自定义样式，外观来自同一份平台 AlertDialog；写错的样子：每个页面各自用 Stack 浮层加 Column 面板手绘对话框，标题、宽度、字号、按钮行各写各的

- 按 SDK 资源和安卓实测建一个通用对话框组件，依次替换各页手绘面板：修好后的结构（出处：卡里修好并验证过）
