# 对话框接口带多个回调参数时，页面把每个回调接到可点的项上，不用 void 丢弃

审的是：代码
触发（任一种）：
- 读到：ViewModel 或 presenter 接口的对话框方法带条目列表和多个回调参数（选中某项、清空、另选、onCancel），注释写「N 个条目 + 固定尾项」；写错的样子：页面实现里写 `void onPick` 这类 void 表达式丢弃回调，或用 showAlertDialog 只显示 entries.join('\n') 和一个确认按钮
适用范围：页面收口阶段实现 ViewModel 暴露的对话框 presenter 接口，尤其是「N 个条目 + 固定尾项、单选」的列表对话框
做法：
- 用 ActionSheet 列出每个条目：sheets 里每项 { title: <条目的可读名>, action: () => onPick(entry) }；清空、另选各占一项接到各自回调；cancel 接 onCancel
- 写完在 presenter 实现里搜 void on，确认没有被消音的回调
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- showActionSheet(value: ActionSheetOptions): void：UIContext 上弹出 ActionSheet（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.showActionSheet）
- ActionSheetOptions：title: string | Resource、message: string | Resource 必填；sheets: Array<SheetInfo>；cancel?: VoidCallback：条目放 sheets，取消回调接 cancel（出处：鸿蒙 SDK 的 ets/component/action_sheet.d.ts，ActionSheetOptions）
- SheetInfo { title: string | Resource; icon?: string | Resource; action: VoidCallback }：每个条目的标题和点击回调（出处：鸿蒙 SDK 的 ets/component/action_sheet.d.ts，SheetInfo）
- static show(value: ActionSheetOptions)：同族接口：ActionSheet.show，同样接收 ActionSheetOptions（出处：鸿蒙 SDK 的 ets/component/action_sheet.d.ts，ActionSheet.show）
- presenter 改为 showActionSheet，列出可读目录名，并加入清空历史、另选目录和取消回调：卡里的修法（出处：卡里修好并验证过）
