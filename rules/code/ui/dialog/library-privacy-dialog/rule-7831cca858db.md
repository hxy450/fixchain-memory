# 源端弹窗由库加配置对象弹出时，按配置字段逐项实现弹层，不用现成控件简化

审的是：代码
触发（任一种）：
- 读到：源端 Kotlin/Java 里构造一个弹窗配置对象（标题、说明条目及图标、勾选两态图、协议链接回调、拒绝回调）交给库的 Helper 弹出，页面 layout XML 和规格的 layout_sources 里都没有这个弹窗；写错的样子：目标写成居中白色圆角卡片：标题和正文借用其他页面的 $r('app.string.…')，只有通用取消/确定两个按钮，缺说明条目、勾选控件和协议链接，同意/拒绝的语义丢失；报告的 uncertain_regions 也没提这处简化
适用范围：页面实现阶段，迁移由 Helper/配置对象生成、布局不在页面 XML 里的弹窗（如首启隐私概要）
做法：
- 先把配置字段逐项列成目标弹层清单：标题、说明条目、勾选控件及两态图、协议链接、同意/拒绝两个分支，再逐项落到 UI 里
- 库渲染弹窗的定位和正文在源码里看不到时，在报告里列为待截图或真机核对的差异（uncertain_regions），不自行定成居中简化形态
针对本应用要查的：
- 弹窗配置对象里的全部字段：源工程 Kotlin/Java 里弹出该弹窗的方法（构造配置对象并调用 Helper 的那段），同一弹窗在别的 Activity 里的配置也一起看；逐个读出标题、说明条目、图标、勾选两态图、链接回调、拒绝回调和样式参数（按钮渐变色、圆角），每项在目标弹层里对应一处
