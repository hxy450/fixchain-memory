# 按接口返回数据条件弹出的弹窗

agent 会看到什么：读到源端弹窗函数先判 token 为空 return、再 POST 专用接口、按返回对象和必填字段、当日次数决定是否展示；交回的只判了每日次数，或改调同名内容的列表接口取 items[0] 就弹

## 规矩

- rule-7b7d61ddee5d｜源端弹窗带显示守卫时，把登录门禁、字段完整性、频次逐条写进目标实现｜读到：源端弹窗函数里有多道守卫：`token` 为空 `return`、返回对象为空或必填字段有空值不展示、按当日次数限制展示；写错：目标只在打开弹窗前判了每日次数，没有 `token` 门禁，也没有返回对象字段完整性判定
- rule-0dcad8b66e0e｜复刻「数据到达后条件弹窗」时，目标用源函数调用的同一接口取数，不换成同名内容的列表接口｜读到：源端弹窗函数先判 `token` 为空就返回，再带 token `POST` 一个专用接口（如启动接口），按返回对象决定是否打开弹窗；写错：目标的弹窗任务改调目标端已有的同名内容列表或分页接口，取第一页 `items[0]` 就打开弹窗
