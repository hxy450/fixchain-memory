# 源弹层跳过半展开时，bindSheet 写 height: SheetSize.FIT_CONTENT

审的是：代码
触发（任一种）：
- 读到：源端 rememberModalBottomSheetState(skipPartiallyExpanded = true)；或规格写「bindSheet 半模态（全展开 detent）」；写错的样子：目标 bindSheet 的 options 写 detents: [SheetSize.LARGE]，或没写 height（默认 LARGE）
适用范围：把 Compose ModalBottomSheet 迁成 ArkUI bindSheet 时
做法：
- 写成 .bindSheet($$this.show, this.sheetBuilder(), { height: SheetSize.FIT_CONTENT })，去掉 detents: [SheetSize.LARGE]
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- bindSheet(isShow: boolean, builder: CustomBuilder, options?: SheetOptions): T：半模态弹层的绑定接口（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.bindSheet）
- SheetSize.FIT_CONTENT = 2（@since 12）：弹层高度随内容自适应（出处：鸿蒙 SDK 的 ets/component/common.d.ts，SheetSize.FIT_CONTENT）
- SheetOptions.height?: SheetSize | Length，@default SheetSize.LARGE：不写 height 时就是 LARGE（出处：鸿蒙 SDK 的 ets/component/common.d.ts，SheetOptions.height）
- openBindSheet<T extends Object>(bindSheetContent: ComponentContent<T>, sheetOptions?: SheetOptions, targetId?: number): Promise<void>：同族接口：UIContext 上用命令式打开半模态，同样用 SheetOptions.height（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.openBindSheet）
