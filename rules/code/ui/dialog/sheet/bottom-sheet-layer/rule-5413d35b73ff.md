# 规格写「日历弹层」时放在根 Stack 顶层盖住面板和键盘，不在内容列里内嵌切换

审的是：代码
触发（任一种）：
- 读到：源端点日期再 show 一个同类底部日历 Dialog；规格或计划写「日历弹层」；写错的样子：目标用 `if (…Visible) { 日历块 }` 插在 layoutWeight(1) 的内容列里、键盘面板之上的流式布局中，日历被挤压、不覆盖键盘
适用范围：面板里再弹日历一类二级弹层的实现
做法：
- 日历放在根 Stack 顶层：一层遮罩加一个底部半屏容器（高度约屏高一半，不写 100%），盖住下层面板和键盘
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- layoutWeight(value: number | string): T：按权重分父容器（Row、Column、Flex）主轴剩余空间，放在这里的块会被挤压（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.layoutWeight）
- 内嵌日历只加 zIndex/Blank 解决不了；改成根 Stack 顶层遮罩加底部弹层后完整显示；高度写 100% 被看成新页面，改为约半屏：卡里修复过程验证过的（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
