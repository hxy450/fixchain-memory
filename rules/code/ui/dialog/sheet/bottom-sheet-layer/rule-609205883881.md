# 弹层内会跳页且要保留弹层时，半模态用 SheetMode.EMBEDDED，不照搬 OVERLAY

审的是：代码
触发（任一种）：
- 读到：源端弹窗（PopupWindow、Dialog 等）里的条目点击直接 startActivity 打开整页，弹窗不先 dismiss；写错的样子：目标半模态的 SheetOptions 照选择器类模板写 mode: SheetMode.OVERLAY，弹层内动作又走 NavPathStack 压栈，新页面显示在弹窗下面
适用范围：把页面内弹层改成 bindSheet / openBindSheet 系统半模态、弹层内条目会打开新页面时
做法：
- 先列出弹层内会触发的跳转；会压入 Navigation 页面且要求新页面盖住弹层、返回后弹层仍在时，写 mode: SheetMode.EMBEDDED，并按 EMBEDDED 的挂载要求传 targetId
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- SheetMode.OVERLAY = 0：显示在当前 UIContext 窗口顶层，高于所有页面，与对话框同层：OVERLAY 下新压入的页面盖不住弹窗（出处：鸿蒙 SDK 的 ets/component/common.d.ts，SheetMode.OVERLAY）
- SheetMode.EMBEDDED = 1：显示在当前页顶层，只能挂在 Page 或 NavDestination 节点上；新页面可覆盖弹窗，返回后弹窗仍在：弹层内跳页要的就是这种层级（出处：鸿蒙 SDK 的 ets/component/common.d.ts，SheetMode.EMBEDDED）
- mode?: SheetMode，@default SheetMode.OVERLAY：不写 mode 时就是 OVERLAY（出处：鸿蒙 SDK 的 ets/component/common.d.ts，SheetOptions.mode）
- 改为 EMBEDDED 并传入宿主页组件的 targetId 后，节日页等新页面覆盖弹窗，返回后弹窗保留：修复后的层级（出处：卡里修好并验证过）
