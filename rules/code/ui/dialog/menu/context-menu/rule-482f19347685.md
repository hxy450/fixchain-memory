# 菜单 XML 里默认隐藏的项，目标只在源端 setVisible(true) 的宿主里显示

审的是：代码
触发（任一种）：
- 读到：菜单 XML 的某个 <item> 写了 android:visible="false"，只有某个子类的 onCreateContextMenu 里 setVisible(true)；写错的样子：目标菜单在源端没有这句 setVisible(true) 的宿主（如首页区段）里也渲染了这一项（例如「多选」），点了只收起菜单
适用范围：源菜单 XML 里默认隐藏、由个别子类打开的菜单项，迁到多个宿主共用的目标菜单组件时
做法：
- 默认隐藏的项在菜单组件里默认不渲染，只有对应源端那个 setVisible(true) 子类的宿主才打开；宿主不开放多选时不渲染「多选」项
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- itemVisible = a.getBoolean(MenuItem_visible, groupVisible)；defaultItemVisible = true：没写 android:visible 的项默认可见，写了 false 的项膨胀后就是隐藏的，要代码 setVisible(true) 才出现（出处：android.view.MenuInflater（MenuState#readItem））
- <attr name="visible" />（MenuItem）：菜单项是否显示（出处：Android SDK 平台资源 data/res/values/attrs.xml，declare-styleable MenuItem 的 visible（按应用的 compileSdk 取对应平台））
- 菜单组件按宿主是否开放多选决定是否显示「多选」项：修复后保留的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 哪些宿主会打开默认隐藏的项：源工程里调 onCreateContextMenu 的各个适配器或 Fragment 子类；搜 setVisible(true)，记下是哪个子类、打开的是哪一项；没有这句的宿主就不显示
