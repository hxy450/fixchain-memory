# 源端局部派生值迁成模型字段时，使用点写成判空后的对象字段，不当组件成员

审的是：代码
触发（任一种）：
- 读到：源方法里有局部派生值 `boolean 名 = 当前对象 instanceof 某类`，再用它 `setVisible(...)` 控制菜单项；规格的状态接口里没有这个状态；写错的样子：目标在组件里用 `this.` 加源端局部变量名引用它，而组件只声明了可空的 `@Local` 对象，这个值是对象上的字段
适用范围：把源码里由当前对象派生的局部值迁成目标模型字段、再在页面里使用时
做法：
- 每个使用点改成判空后的持有对象访问：this.对象 !== null && this.对象.字段；或在组件里显式声明派生 getter；不保留源局部变量名作组件成员
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 改成 this.对象 !== null && this.对象.字段 后，菜单可见性按当前对象派生，文件编译通过：返修后的写法（出处：卡里修好并验证过）
