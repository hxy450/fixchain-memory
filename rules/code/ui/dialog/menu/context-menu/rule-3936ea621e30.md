# 区段组件承载长按菜单时用 openCustomDialog，不用区段内 Stack 浮层或 bindSheet

审的是：代码
触发（任一种）：
- 读到：首页区段等嵌入式 Fragment 走 registerForContextMenu / onCreateContextMenu 弹浮动上下文菜单；写错的样子：区段组件 build 尾部插 if (...) Stack{遮罩+菜单卡} 页内浮层，或用 bindSheet 半模态承载菜单，或菜单做成 justifyContent(FlexAlign.End) 贴底面板
适用范围：目标端区段、卡片这类只占页面一部分的组件要弹窗口级上下文菜单时
做法：
- 用 this.getUIContext().getPromptAction().openCustomDialog(...) 把菜单卡作为全局弹层打开（卡片居中），关闭用对应的 closeCustomDialog；沿用工程里已登记的区段宿主形态
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- openCustomDialog<T extends Object>(dialogContent: ComponentContent<T>, options?: promptAction.BaseDialogOptions): Promise<void>：PromptAction 用 ComponentContent 打开自定义弹窗，关闭用 closeCustomDialog(dialogContent)（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，PromptAction.openCustomDialog）
- openCustomDialog(options: promptAction.CustomDialogOptions): Promise<number>；closeCustomDialog(dialogId: number): void：同族接口：用 builder 打开，返回的 id 交给 closeCustomDialog（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，PromptAction.openCustomDialog / PromptAction.closeCustomDialog）
- getPromptAction(): PromptAction：从 UIContext 取 PromptAction（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.getPromptAction）
- promptAction.openCustomDialog(options) 自 API 18 起废弃，改用 UIContext.PromptAction#openCustomDialog：同族接口：全局函数版本，不要再用（出处：鸿蒙 SDK 的 ets/api/@ohos.promptAction.d.ts，promptAction.openCustomDialog）
- alignment?: DialogAlignment（BaseDialogOptions）；DialogAlignment.Center 垂直居中：弹层位置；菜单卡居中（出处：鸿蒙 SDK 的 ets/api/@ohos.promptAction.d.ts，BaseDialogOptions.alignment；ets/component/alert_dialog.d.ts，DialogAlignment.Center）
- bindSheet(isShow: boolean, builder: CustomBuilder, options?: SheetOptions): T 绑定的是半模态页：不是浮动菜单的承载形态（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.bindSheet）
- 区段改用 openCustomDialog 承载菜单卡：修复后保留的写法（出处：卡里修好并验证过）
