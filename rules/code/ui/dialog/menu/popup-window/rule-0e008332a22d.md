# PopupWindow 自定义布局锚定下拉，目标用 bindPopup 自定义菜单，不用 Select

审的是：代码
触发（任一种）：
- 读到：源端点击触发控件时 new PopupWindow，inflate 一个自定义布局（固定宽度、固定行高、背景图、箭头图、选中项勾选图），再 showAsDropDown(anchor) 锚在触发控件下方；写错的样子：目标把这个下拉写成原生 Select([...]) 或系统菜单，只改了字色和背景；或者做成整页替换的视图；自定义的宽度、行高、勾选图都没落地
适用范围：安卓用 PopupWindow + 自定义布局 + showAsDropDown 实现的锚定下拉，迁成 ArkUI 时
做法：
- 先从弹出布局 XML 列出宽度、行高、左右边距、背景、箭头和勾选资源，从 Java 列出锚点控件和 xoff/yoff
- 在锚点对应的组件上写 .bindPopup(this.showMenu, { builder: this.menuBuilder, placement: Placement.Bottom, width: <PopupWindow 宽度>, radius: <源背景圆角>, popupColor: <源背景色>, onStateChange: (e) => { if (!e.isVisible) { this.showMenu = false } } })，builder 里按源布局的行高、边距画每一行，当前项显示勾选图；也可用 Stack 覆盖层按同样的值实现
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- bindPopup(show: boolean, popup: PopupOptions | CustomPopupOptions): T：所有组件都有的弹层绑定；传 CustomPopupOptions 时内容由 builder 自定义（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.bindPopup）
- builder: CustomBuilder；placement?: Placement，默认 Placement.Bottom：自定义弹层的内容和首选位置，默认在目标组件下方（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CustomPopupOptions.builder / CustomPopupOptions.placement）
- width?: Dimension：弹层宽度，源 PopupWindow 的固定宽度写在这里（dp 数值写成 vp）（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CustomPopupOptions.width）
- radius 默认 20.0_vp；popupColor 默认 TRANSPARENT plus COMPONENT_ULTRA_THICK；enableArrow 默认 true：不显式写时弹层带系统圆角、模糊底和系统箭头，和源端自定义背景不一样（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CustomPopupOptions.radius / popupColor / enableArrow）
- autoCancel?: boolean，默认 true；onStateChange?: (event: { isVisible: boolean }) => void：页面上有操作时弹层自动收起；收起时在 onStateChange 里把 show 状态变量改回 false（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CustomPopupOptions.autoCancel / CustomPopupOptions.onStateChange）
- showAsDropDown(View anchor, int xoff, int yoff)：弹窗锚在 anchor 的左下角，xoff、yoff 是像素偏移：源端下拉的位置语义（出处：android.widget.PopupWindow#showAsDropDown）
- 把原生 Select 换成 bindPopup 的自定义菜单（宽度、圆角、白底、行高、勾选图、箭头按源布局）后，样式与安卓一致：返修后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 弹出菜单的宽度、行高、边距、背景、箭头和勾选图：源工程里被 PopupWindow inflate 的布局 XML（res/layout 下），以及背景引用的 drawable；读根布局的 android:layout_width、每行的 android:layout_height 和 padding/margin、android:background 和 ImageView 的 android:src，dp 数值写成 vp
- 锚点和偏移：源工程 Java/Kotlin 里调 showAsDropDown 的那一行；第一个参数是锚点控件，后两个是 x、y 偏移（像素）
