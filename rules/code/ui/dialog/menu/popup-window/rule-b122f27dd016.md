# 源端几个工具面板容器各不相同时，不共用一个 bindSheet 只改底色文字，按面板拆开

审的是：代码
触发（任一种）：
- 读到：源端工具面板各用不同容器：底部 PopupWindow 面板（图标按钮切换选项）、锚定在标题栏右上角带箭头的弹出菜单（固定宽度）、多步覆盖层；写错的样子：目标用同一个 .bindSheet(...)（固定 height、dragBar、showClose、SheetType.BOTTOM）承载全部面板，只按面板改了 backgroundColor、文字颜色和文案
适用范围：界面实现阶段对齐页面工具面板（设置、更多、输入类面板）的容器类型、锚点和打开方式时
做法：
- 按源端逐个面板列出容器类型（底部面板、锚定弹出菜单、全屏覆盖层）、锚点、宽高，以及有没有标题、拖动条和关闭按钮
- 这些都一致时才共用一个弹窗组件；不一致就拆成各自的布局和打开方式：锚定菜单从右上角弹出并带箭头，底部面板不带源端没有的拖动条和关闭按钮
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- bindSheet(isShow: boolean, builder: CustomBuilder, options?: SheetOptions): T：半模态面板（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.bindSheet）
- SheetOptions.showClose 默认 true；dragBar 默认 true（多档 detents 生效时才显示）：不显式关掉时，面板会带源端没有的关闭按钮（出处：鸿蒙 SDK 的 ets/component/common.d.ts，SheetOptions.showClose、SheetOptions.dragBar）
- SheetOptions.preferType：窗口宽 < 600vp 时只支持 bottom：手机上 bindSheet 做不出锚定在右上角的弹出菜单（出处：鸿蒙 SDK 的 ets/component/common.d.ts，SheetOptions.preferType）
- openBindSheet<T extends Object>(bindSheetContent: ComponentContent<T>, sheetOptions?: SheetOptions, targetId?: number): Promise<void>：同族接口：UIContext 上打开半模态，同样受 SheetOptions 约束（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.openBindSheet）
- 三个面板移出共用 bindSheet：设置改深色底部面板加原图切换按钮，更多改右上角带箭头的菜单，输入类面板改编辑框加定位层：修好的做法（出处：卡里修好并验证过）
