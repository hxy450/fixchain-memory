# MATCH_PARENT 的 PopupWindow 用 showAsDropDown 弹出时，目标只占锚点以下高度

审的是：代码
触发（任一种）：
- 读到：安卓 PopupWindow 设了 setHeight(MATCH_PARENT)（或布局 match_parent），用 showAsDropDown(标题栏) 挂在锚点下方弹出；写错的样子：目标端把 match_parent 译成相对父容器的 .height('100%')，再和标题栏等兄弟节点在同一 Column 里相加
适用范围：把安卓 PopupWindow 的下拉弹层迁成 ArkUI 页面内区域或覆盖层时
做法：
- 区分 MATCH_PARENT 配合 showAsDropDown(锚点) 与整屏弹出：前者对应锚点以下的剩余高度，写成标题之后 .layoutWeight(1) 的区域，或从锚点下沿开始的带偏移覆盖层
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- showAsDropDown(View anchor)：把弹窗挂在锚点的左下角显示：弹层从锚点下沿开始，锚点（标题栏）保留可见（出处：android.widget.PopupWindow#showAsDropDown）
- layoutWeight 大于 0 的子元素从主轴剩余空间按权重分配尺寸，分配时忽略元素本身的尺寸设置：标题栏之后的 layoutWeight(1) 区域就是锚点以下的剩余高度（出处：ts-universal-attributes-size.md，layoutWeight）
