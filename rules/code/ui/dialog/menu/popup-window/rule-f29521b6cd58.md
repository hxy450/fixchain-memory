# 嵌入根节点 height('100%') 的面板时，不在同一 Column 里再叠固定高度的兄弟节点

审的是：代码
触发（任一种）：
- 读到：被嵌入的自定义组件 build 根节点写 .height('100%')，自带标题行、layoutWeight(1) 的 Scroll 和底部操作栏；写错的样子：宿主页根 Column(height('100%')) 里先放固定高度的标题栏，再在 if 分支里直接放这个面板，面板槽位没有 layoutWeight(1)，也没有外包有界容器或改成覆盖层；底栏被挤出屏幕
适用范围：界面实现阶段，宿主页嵌入自带满高根布局的面板或弹层组件时
做法：
- 集成前先读组件根节点的尺寸声明；根节点是 height('100%') 时，给面板槽位外包 Column() { 面板() }.layoutWeight(1) 这类有界容器，让它只占标题栏以下的剩余空间
- 或者把面板放到外层 Stack 里作为全屏覆盖层，并去掉与面板自带标题重复的宿主标题栏
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 外层改成 Stack，面板在 Column 之外全屏承载、不再叠加宿主标题栏后，底栏完整显示在手势导航条上方：修好的写法（出处：卡里修好并验证过）
- layoutWeight(value: number | string): T，默认 0：在 Row / Column / Flex 主轴上按权重分配剩余空间（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.layoutWeight）
- layoutWeight 大于 0 的子元素从主轴剩余空间按权重分配尺寸，分配时忽略元素本身的尺寸设置；只在 Row / Column / Flex 中生效：固定高度的兄弟先占位，带 layoutWeight 的槽位只拿剩下的高度（出处：ts-universal-attributes-size.md，layoutWeight）
