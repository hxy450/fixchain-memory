# 共享弹层组件只有遮罩点击关闭时，注释写明宿主须在 onBackPressed 关闭它

审的是：代码
触发（任一种）：
- 读到：要复用的共享弹层组件只提供遮罩点击的 onDismiss 回调，靠宿主页的 Stack 承载；写错的样子：共享弹层组件的注释和接口没写「宿主页须在 onBackPressed 关闭本弹层」；复用它的页面 NavDestination 上没有 .onBackPressed
适用范围：写或复用页内弹层的共享组件时
做法：
- 在共享弹层组件的注释或接口里写明「宿主页须在 onBackPressed 关闭本弹层」
- 复用该组件的页面逐一核对：宿主 NavDestination 的 .onBackPressed 里有关闭它的分支并返回 true
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onBackPressed(callback: () => boolean): NavDestinationAttribute：宿主页关闭弹层的入口（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.onBackPressed）
来源：1 张卡，1 个应用
