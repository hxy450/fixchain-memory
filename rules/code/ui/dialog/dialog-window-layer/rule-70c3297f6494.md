# Dialog 主题窗口的遮罩、底色、圆角按主题值写，不拿语义不同的颜色资源凑

审的是：代码
触发（任一种）：
- 读到：Activity 的 android:theme 是 Theme.*.Dialog，工程 colors.xml 里另有半透明黑色等颜色资源；写错的样子：遮罩写 .backgroundColor($r('app.color.…')) 借用语义不同的颜色资源，卡片底色和 .borderRadius(...) 取近似值，遮罩没有 onClick 点外关闭
适用范围：Dialog 主题 Activity 迁成 Dialog 形态页或弹窗时的遮罩、窗口底和关闭行为
做法：
- 按规格里从主题查出的值写：暗化 0.6 写成遮罩 '#99000000'（CustomDialog 用 maskColor），窗口宽、inset、底色、圆角照主题；点外关闭为 true 时遮罩 onClick 关闭（Dialog 形态页里 pop，CustomDialog 用 autoCancel: true）
- 规格里写着「未知」或查不到真值的项向上报，不自行取近似值
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Theme.MaterialComponents.Light.Dialog 下改为 0.6 暗化、95% 宽 + 16 inset、白底、圆角 2，遮罩点击 pop：返修后的写法（出处：卡里修好并验证过）
- CustomDialogControllerOptions.maskColor 默认 0x33000000：不写 maskColor 时暗化只有约 0.2，和安卓的 0.6 不一样（出处：ts-methods-custom-dialog-box.md，CustomDialogControllerOptions 的 maskColor）
- CustomDialogControllerOptions.autoCancel 默认 true（点遮障层关闭）：对应安卓 windowCloseOnTouchOutside 为 true（出处：ts-methods-custom-dialog-box.md，CustomDialogControllerOptions 的 autoCancel）
- maskColor?: ResourceColor：同族接口：promptAction.BaseDialogOptions 的蒙层颜色，openCustomDialog 的选项用它（出处：鸿蒙 SDK 的 ets/api/@ohos.promptAction.d.ts，BaseDialogOptions.maskColor）
- <item name="backgroundDimAmount">0.6</item>：安卓平台基础主题的暗化比例（出处：Android SDK 平台资源 data/res/values/themes.xml，Theme 的 backgroundDimAmount（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 这个 Dialog 主题的暗化、宽度、inset、底色、圆角、点外关闭：规格里写窗口形态的那一节；没写时按主题的 parent 链查依赖库 appcompat / material 包内 res/values/values.xml 和平台 themes.xml；暗化比例 × 255 换成遮罩颜色的 alpha（0.6 → 0x99）
