# 复刻平台对话框卡片要写 floating_window_z 投影，不因无截图就不写

审的是：代码
触发（任一种）：
- 读到：源对话框用平台 Material 对话框主题（windowElevation 为 @dimen/floating_window_z）；写错的样子：自绘对话框卡片只有底色和圆角，没有 .shadow(...)，注释写「无截图校准不写阴影」
适用范围：自绘卡片复刻框架 Material 对话框外观时
做法：
- 卡片按 elevation 16dp（floating_window_z）加投影，经工程共享的 elevation→shadow 函数写入（vp 值用 vp2px 换成 ShadowOptions 要的 px），各对话框都调同一个函数；没有截图时登记为需校准的视觉近似项
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- floating_window_z = 16dp；Material 对话框主题 windowElevation = @dimen/floating_window_z：源端对话框窗口的高度（出处：Android SDK 平台资源 data/res/values/dimens_material.xml，floating_window_z；data/res/values/themes_material.xml，windowElevation（按应用的 compileSdk 取对应平台））
- shadow(value: ShadowOptions | ShadowStyle): T：给卡片组件加投影（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.shadow）
- ShadowOptions.radius 单位是 px：由 vp 推算的模糊半径要先换成 px（出处：鸿蒙 SDK 的 ets/component/common.d.ts，ShadowOptions.radius）
- 列表框和选项框补上共享函数的投影后，各对话框投影一致：修法（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
