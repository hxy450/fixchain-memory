# 叠加层自绘 Snackbar 时提供底部偏移，按源 Scaffold 的 bottomBar 和 FAB 传入

审的是：代码
触发（任一种）：
- 读到：源页面 Scaffold(bottomBar = …, floatingActionButton = …, snackbarHost = { SnackbarHost(…) })；写错的样子：叠加层实现的 Snackbar 固定贴底、没有底部偏移参数，显示时盖住底栏或 FAB
适用范围：用叠加层（不在页面布局里）自绘 Snackbar，而源页面的 Scaffold 有 bottomBar 或 floatingActionButton 时
做法：
- 叠加层 Snackbar 组件加一个底部偏移参数；调用方按源页面 Scaffold 传值：有 bottomBar 传底栏高度，有 FAB 传 FAB 高 56 + 间距 16（vp）
针对本应用要查的：
- 源页面底栏的高度：源工程里这个页面的 Composable：Scaffold 的 bottomBar 参数传入的组件；读底栏组件的高度（显式的 height 修饰或所用组件的默认高度），转成 vp 作为偏移
