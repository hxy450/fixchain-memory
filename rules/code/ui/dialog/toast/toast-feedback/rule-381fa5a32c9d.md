# 源调用继承自基类的方法时，读完基类实现，把开关守卫、默认值和参数照迁

审的是：代码
触发（任一种）：
- 读到：源方法调用本类没定义、继承自基类的方法（如基类 Activity 里封装 Toast.makeText 的提示方法，调用时传 Toast.LENGTH_LONG），基类实现里先判偏好开关再显示；写错的样子：目标直接换成平台调用 promptAction.showToast({ message })，没有基类实现里的偏好开关守卫，也没传源端给的时长
适用范围：源 Activity、Fragment 调用父类公共方法（提示、权限辅助等），迁成目标页面方法时
做法：
- 打开被调的基类方法读完整实现，把其中的守卫（偏好开关，按源端默认值读取）、默认值和源调用传入的参数（如时长）原样写进目标方法，不按方法名猜
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 返修把提示方法改为先按源默认值读偏好开关，开着才 showToast 并传入长时长：返修后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 基类方法里的守卫条件、偏好 key 和默认值：源工程里这个类 extends 的基类 Java 或 Kotlin 文件中的同名方法；偏好默认值看 getBoolean/getString 的第二个参数和 res/xml 偏好定义的 android:defaultValue；把守卫条件、key、默认值逐项抄到目标方法里，目标读偏好时用同一个默认值
