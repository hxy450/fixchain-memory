审的是：代码
触发（任一种）：
- 读到：源端 Scaffold 里只有一个 SnackbarHost(hostState = …)，各操作的结果都调 showSnackbar(…) 显示；写错的样子：目标页 build() 里有多个各自条件渲染的底部浮层（每种结果一个分支、各配定时器），互不排斥，可以同时出现；新提示出现时不清旧的成功状态
适用范围：Compose 页面用单个 SnackbarHost 显示操作结果，迁成 ArkUI 页面里的底部提示浮层时

- 写一个统一的清除方法：清掉旧定时器、把各结果状态和计数复位；每次开始新操作或显示新提示前先调它
