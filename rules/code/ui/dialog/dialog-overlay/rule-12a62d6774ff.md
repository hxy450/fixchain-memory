# 源端会叠放多个对话框时，遮罩由宿主统一画一层，浓度取主题 backgroundDimAmount

审的是：代码
触发（任一种）：
- 读到：源端先后 show() 两个以上 AlertDialog，或规格要求两层弹窗同时可见；写错的样子：每个弹窗组件的根 Stack 里自带一层全屏半透明遮罩（如复用应用里碰巧有的半透明黑色资源），宿主又把几个实例叠在一起
适用范围：用页内自绘面板复刻会同时显示多个的对话框时
做法：
- 宿主根画一层全屏遮罩 .backgroundColor('#<AA>000000')，AA 是 backgroundDimAmount × 255 取整的十六进制（0.6 → '#99000000'）；不复用应用里碰巧存在的半透明颜色资源
- 面板组件只画面板、不带遮罩；叠放顺序、点外部关闭和关闭顺序由宿主管理
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- When FLAG_DIM_BEHIND is set, dimAmount 是变暗量，1.0 完全不透明，0.0 不变暗：源端变暗是窗口层（WindowManager.LayoutParams）的效果，浓度由 dimAmount 定（出处：android.view.WindowManager.LayoutParams#dimAmount）
- params.dimAmount 取窗口主题的 backgroundDimAmount（缺省 0.5f）；Theme.Holo 为 0.6：遮罩浓度的出处（出处：com.android.internal.policy.PhoneWindow#generateLayout；Android SDK 平台资源 data/res/values/themes_holo.xml，Theme.Holo 的 backgroundDimAmount（按应用的 compileSdk 取对应平台））
- 宿主统一画一层 #99000000，面板组件只画面板，两层弹窗同时出现时背景只暗一次，与源端一致：返修后的落法（出处：卡里修好并验证过）
- backgroundColor(value: ResourceColor): T；argb 字符串如 '#ff000000'：遮罩色的写法（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.backgroundColor；ts-types.md，ResourceColor）
针对本应用要查的：
- 遮罩浓度：源工程应用主题继承的框架主题，到 Android SDK 平台资源 themes_*.xml 里读它的 backgroundDimAmount（按应用的 compileSdk）；乘 255 取整转成两位十六进制作 alpha；例：Theme.Holo 下 0.6 → '#99000000'
