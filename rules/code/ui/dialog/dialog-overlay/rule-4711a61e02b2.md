# 框架 AlertDialog 的遮罩、圆角、标题取平台值（60%、2、20 号 Medium），不套鸿蒙卡片惯例

审的是：代码
触发（任一种）：
- 读到：源端是框架生成的 AlertDialog（ListPreference 等 DialogPreference），应用主题没改 backgroundDimAmount、dialogCornerRadius 和对话框标题样式；写错的样子：目标遮罩写 #66000000（40%），卡片 .borderRadius(24)，标题 fontSize(18)，报告里把这些标成「框架默认外观估计…待核」
适用范围：用页内遮罩加卡片落地框架默认 AlertDialog（Material 主题一族）时的遮罩、卡片和标题外观
做法：
- 遮罩 .backgroundColor('#99000000')（60% 黑）；卡片 .borderRadius(2) 并加投影；标题 .fontSize(20).fontWeight(FontWeight.Medium)
- 这些值查平台资源（下列各项）得出，查过仍取不到才在报告里标待核；不用鸿蒙卡片的 24 圆角、40% 遮罩代替
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- backgroundDimAmount = 0.6：遮罩 60% 黑，ARGB 写 #99000000（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material 的 backgroundDimAmount（按应用的 compileSdk 取对应平台））
- dialog_corner_radius = 2dp（dialogCornerRadius 引用它）：卡片圆角 2（出处：Android SDK 平台资源 data/res/values/dimens.xml，dialog_corner_radius；values/themes_material.xml，dialogCornerRadius（按应用的 compileSdk 取对应平台））
- TextAppearance.Material.DialogWindowTitle 继承 TextAppearance.Material.Title：textSize = 20sp，fontFamily = sans-serif-medium：标题 20 号 Medium（出处：Android SDK 平台资源 data/res/values/styles_material.xml，TextAppearance.Material.Title；values/dimens_material.xml，text_size_title_material（按应用的 compileSdk 取对应平台））
- 实测遮罩 60%，2dp 圆角加投影，标题 20sp Medium；改成这些值后与源端一致：修好后的外观（出处：卡里修好并验证过）
针对本应用要查的：
- 应用主题是否覆写了对话框外观：源工程 res/values 下的 styles/themes XML，按应用主题的 parent 和 backgroundDimAmount、dialogCornerRadius、alertDialogTheme 找；有覆写取覆写值；没有就取上面平台值（按应用 compileSdk 对应的平台核一遍）
