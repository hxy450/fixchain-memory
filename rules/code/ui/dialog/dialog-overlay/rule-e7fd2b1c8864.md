# 工程已有平台 AlertDialog 复刻的共享弹窗时，偏好对话框交给它承载，不在页面另起自绘面板

审的是：代码
触发（任一种）：
- 读到：工程里已有或计划有按平台 AlertDialog 外观复刻的共享弹窗组件，它的用途清单只列了 AlertDialog.Builder 构造的对话框；写错的样子：设置页里为 EditTextPreference / ListPreference 另写一套自绘面板和按钮条（自建 @Component 按钮栏、Stack 覆层面板）
适用范围：页面实现时复刻偏好对话框，而工程里已有平台对话框的共享复刻件
做法：
- 偏好对话框也交给共享弹窗承载，只把「消息 + 输入框」「单选列表」做成它的内容槽（@BuilderParam），不在页面里另起面板和按钮条
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 在共享的平台对话框复刻件上新增「消息 + 输入框」和「单选列表」两种内容，三处调用改用它们，删掉页内按钮条和无引用的颜色后与源端一致：修好的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 工程里有没有平台对话框的共享复刻件：目标工程的公共组件目录和规格的共享件清单（feature-base 一类）；找用途写着「android.app.AlertDialog 平台外观」的组件，看它是否支持内容槽
