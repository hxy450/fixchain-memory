# Activity 级 Dialog 改写成页内覆层时，挂在覆盖整个窗口的宿主根 Stack，不挂在 Tab 子组件

审的是：代码
触发（任一种）：
- 读到：弹窗是 Dialog 子类，构造时传 getActivity() 或 Activity 创建，样式继承 Theme.Dialog、windowIsFloating=true；写错的样子：Tabs 子页或嵌套组件把根改成 Stack，在里面用 if 条件渲染全幅遮罩覆层；宿主页根 Stack 没挂这个覆层，遮罩盖不到底部 Tab 栏
适用范围：用条件渲染的全幅 Stack 覆层替代安卓 Dialog、触发入口在 Tabs 子页或嵌套组件里时
做法：
- 覆层挂在覆盖整个窗口的宿主页（@Entry 页）根 Stack 里，和其他全屏覆层同一层
- 子组件通过共享状态（如 @ObservedV2 单例）或回调请求宿主显示、关闭覆层；返回键拦截写在宿主页的 onBackPress 里
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Dialog 构造：The supplied context is used to obtain the window manager and base theme used to present the dialog：用 Activity 创建的 Dialog 是挂在 Activity 窗口上的独立窗口，遮罩范围是整个窗口，不是某个 Fragment 的视图（出处：android.app.Dialog#Dialog(Context)）
- Theme.Dialog：windowIsFloating = true；基础主题 backgroundDimAmount = 0.6：浮动窗口，背后整窗变暗（出处：Android SDK 平台资源 data/res/values/themes.xml，Theme.Dialog、backgroundDimAmount（按应用的 compileSdk 取对应平台））
- onBackPress?(): void | boolean：只对 @Entry 组件生效；返回 true 表示页面自己处理返回（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CustomComponent.onBackPress）
- 覆层挪到宿主根 Stack、Tab 内的覆层删掉后，遮罩盖住包括底部 Tab 栏在内的整个窗口：挂载层级决定遮罩范围（出处：卡里修好并验证过）
