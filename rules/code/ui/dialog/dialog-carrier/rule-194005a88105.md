# 对话框带 setView 自定义布局时用自定义弹窗承载，不往 AlertDialog.show 塞 builder

审的是：代码
触发（任一种）：
- 读到：MaterialAlertDialogBuilder / AlertDialog.Builder 在 setTitle、setMessage 和正负按钮之外还调了 setView(...)（如「不再提示」复选框）；写错的样子：目标写成 AlertDialog.show({ title, builder: () => {…}, primaryButton, secondaryButton })：AlertDialogParam 没有 builder 字段，必填的 message 也没传
适用范围：把安卓 AlertDialog / MaterialAlertDialogBuilder 确认框迁成 ArkUI 弹窗时
做法：
- 只有标题、正文、按钮时才映射 AlertDialog.show({ title, message, primaryButton, secondaryButton })，message 必填
- 带 setView 自定义内容时改用 @CustomDialog + CustomDialogController({ builder: … })，或 UIContext 的 getPromptAction().openCustomDialog({ builder: … })；同一自定义构建里放正文、复选框和按钮，复选状态交给确认回调
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- AlertDialogParam：title?: ResourceStr、subtitle?: ResourceStr、message: ResourceStr（必填），没有 builder 字段：AlertDialog.show 的参数只能放文字内容，放不了自定义构建（出处：鸿蒙 SDK 的 ets/component/alert_dialog.d.ts，AlertDialogParam）
- static show(value: AlertDialogParamWithConfirm | AlertDialogParamWithButtons | AlertDialogParamWithOptions)：AlertDialog.show 的签名，三种参数都继承 AlertDialogParam（出处：鸿蒙 SDK 的 ets/component/alert_dialog.d.ts，AlertDialog.show）
- constructor(value: CustomDialogControllerOptions)；CustomDialogControllerOptions.builder: any：自定义弹窗控制器，builder 传 @CustomDialog 组件（出处：鸿蒙 SDK 的 ets/component/custom_dialog_controller.d.ts，CustomDialogController.constructor、CustomDialogControllerOptions.builder）
- openCustomDialog(options: promptAction.CustomDialogOptions): Promise<number>；CustomDialogOptions.builder: CustomBuilder：UIContext 的 PromptAction 打开自定义弹窗，builder 放自定义内容，返回弹窗 id（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，PromptAction.openCustomDialog；ets/api/@ohos.promptAction.d.ts，CustomDialogOptions.builder）
- setView(View view)：Sets a custom view to be the contents of the alert dialog：源端 setView 的内容是对话框主体，迁移时不能丢（出处：android.app.AlertDialog.Builder#setView）
未核实：卡里没有上机验证自定义弹窗版的等价实现（修复只降级成 message 弹窗）；卡里工程的 SDK 是 6.1.1(24)，本机按 API 23 核对
