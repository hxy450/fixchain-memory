# 还原居中 DialogFragment 的点外关闭时，模态内自绘遮罩加居中卡片，不用 bindSheet(CENTER)

审的是：代码
触发（任一种）：
- 读到：源端是居中显示、点外部可关闭的 DialogFragment；写错的样子：目标用 bindSheet 配 preferType: SheetType.CENTER 挂在 0 尺寸节点上代替
适用范围：居中对话框迁成 ArkUI 模态、要保留点外关闭时
做法：
- 在 bindContentCover(show, builder, ModalTransition.NONE) 的 builder 里画全屏遮罩 Stack（例：backgroundColor('#80000000')），遮罩 .onClick(() => 关闭)，中间放卡片
- 卡片本身加空的 .onClick(() => {}) 消费点击，防止点卡片冒泡到遮罩误关
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- bindContentCover(isShow: boolean, builder: CustomBuilder, type?: ModalTransition): T：全屏模态，遮罩和卡片都画在 builder 里（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.bindContentCover；ts-universal-attributes-modal-transition.md，bindContentCover）
- 改成 bindContentCover(ModalTransition.NONE)，builder 里自绘全屏遮罩、居中卡片，遮罩点击关闭，卡体补空 onClick 防冒泡：卡里的最终写法（出处：卡里修好并验证过）
未核实：卡里环境是 API 24，按本机 API 23 的声明核实
