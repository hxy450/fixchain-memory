# Preference 或 MaterialDialog 弹窗写成 bindSheet 时，改成居中对话框按库几何

审的是：代码
触发（任一种）：
- 读到：源端 ListPreference、EditTextPreference 或 MaterialDialog 单选列表，或规格写着「bindSheet 弹层」；写错的样子：目标用 .bindSheet(…, { detents: [SheetSize.MEDIUM, SheetSize.LARGE] }) 承载这些弹层，宽度用自造的比例常量，TextInput 没有 preference_dialog_edittext 的边距
适用范围：偏好项和库对话框迁成 ArkUI 弹窗时
做法：
- 改成居中对话框（openCustomDialog），内容按 preference_dialog_edittext.xml 写：上下 48dp，说明文字左右 24dp、下 48dp，输入框左右 20dp、最小高 48dp，再加 AppCompat 输入框的 inset
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- EditText android:layout_marginStart="20dp" android:layout_marginEnd="20dp" android:minHeight="48dp"：输入框的边距和最小高度（出处：androidx.preference:preference 包内 res/layout/preference_dialog_edittext.xml（按应用依赖的版本））
- ScrollView 上下 48dp，message 左右 24dp、下 48dp：内容区和说明文字的边距（出处：androidx.preference:preference 包内 res/layout/preference_dialog_edittext.xml（按应用依赖的版本））
- openCustomDialog(options: promptAction.CustomDialogOptions): Promise<number>：居中自定义弹窗的打开方式之一（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，PromptAction.openCustomDialog）
- 返修后为居中对话框 + 库几何：返修后的写法（出处：卡里修好并验证过）
未核实：ListPreferenceDialogFragmentCompat 等用 AlertDialog 出自卡，本机没有库源码核对
来源：1 张卡，1 个应用
