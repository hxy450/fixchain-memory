# 从 bindSheet 内部打开的弹窗用 bindContentCover 承载，不写成页内 Stack 条件浮层

审的是：代码
触发（任一种）：
- 读到：源端 BottomSheetDialogFragment 内部点击后直接 show() 出居中 DialogFragment，或调工具方法弹窗；写错的样子：目标从 bindSheet 内容的回调打开的弹窗，写成页面根 Stack 里 if 条件渲染的全屏遮罩 Column；头注写「规避全局弹窗跨页覆盖（P-27）」或照本页已有浮层先例
适用范围：目标页的底部弹层用 bindSheet 承载、二级弹窗从 sheet 内部触发时
做法：
- 二级弹窗改用全屏模态：在宿主节点上 .bindContentCover(show, builder, ModalTransition.NONE)，或用全局级自定义弹窗；并在 sheet 打开状态下实测层级
- 引用「避免全局弹窗」一类规则前先核它的负向守卫：不跨路由的定时、输入类弹窗无需页面级；复用本页已有浮层写法前，核对触发点是否在另一个半模态之内
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- bindContentCover(isShow: boolean, builder: CustomBuilder, type?: ModalTransition): T：给组件绑定全屏模态页（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.bindContentCover；ts-universal-attributes-modal-transition.md，bindContentCover）
- ModalTransition.NONE = 1：模态无转场动画：居中弹窗不要转场动画时用它（出处：鸿蒙 SDK 的 ets/component/common.d.ts，ModalTransition.NONE）
- 从 sheet 内打开的二级弹窗改成 bindContentCover(ModalTransition.NONE) 承载后，显示在 sheet 之上：卡里的修法（出处：卡里修好并验证过）
- bindContentCover(isShow: boolean, builder: CustomBuilder, options?: ContentCoverOptions): T：同族接口：带 ContentCoverOptions 的重载（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.bindContentCover）
未核实：卡里环境是 API 24，按本机 API 23 的声明核实；页内 Stack 条件浮层恒在 bindSheet 半模态层之下：卡里由出错现象（浮层被 sheet 盖住）得出，不是修法本身的验证
