# 调用方接入弹层时对照安卓调用点 show()，用弹层入口，不 pushPathByName

审的是：代码
触发（任一种）：
- 读到：安卓调用点以 fragment.show(childFragmentManager, tag, …) 弹出这个弹层；写错的样子：目标调用方写 navPathStack.pushPathByName('<弹层路由名>', …) 打开它，因为已转换的组件只暴露了路由页
适用范围：调用方集成阶段接入已转换的弹层组件时
做法：
- 对照安卓调用点确认目标组件提供的是弹层入口（调用 openCustomDialog 的打开函数等），调用方改调它
- 目标组件只暴露路由页时，先反馈或修正组件的呈现方式，不直接 pushPathByName
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 各入口改为调用同一个打开弹层的函数；旧路由注册只留作兼容入口：修复后调用方的接法（出处：卡里修好并验证过）
