# 对话框改成页内 Stack 弹层时，宿主 NavDestination 补 onBackPressed 先关弹层

审的是：代码
触发（任一种）：
- 读到：源端 AlertDialog、ListPreference 对话框或 popup 面板（可被 Back 关闭）；规格映射写 showDialog / CustomDialog / bindSheet / Select；写错的样子：改成 Stack 里按可见状态条件渲染的页内弹层，宿主 NavDestination 上没有 .onBackPressed(...)，或注释写返回由 NavDestination 默认 pop 处理
适用范围：把源端可被 Back 关闭的对话框、弹出面板改写成 NavDestination 页面里的页内覆盖层时
做法：
- 在同一宿主 NavDestination 上写 .onBackPressed(() => { 按弹层优先级逐个判断，关掉一个就 return true；没有弹层才 return false 交给栈 pop })；页面里每个弹层可见状态都要有关闭分支
- 或者改用自带返回关闭的方案：openCustomDialog 传 levelMode: LevelMode.EMBEDDED，或页面级弹窗用 NavDestination().mode(NavDestinationMode.DIALOG)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onBackPressed(callback: () => boolean): NavDestinationAttribute：NavDestination 的返回键回调（文档标 10+）（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.onBackPressed）
- 返回 true 表示重写返回键逻辑，返回 false 表示回退到上一个页面：关了弹层要返回 true，否则页面会被一起弹出（出处：ts-basic-components-navdestination.md，onBackPressed）
- LevelMode.EMBEDDED = 1（在当前页面内显示），levelMode 默认 LevelMode.OVERLAY（@since 15）：openCustomDialog 等弹窗选项的显示层级（出处：鸿蒙 SDK 的 ets/api/@ohos.promptAction.d.ts，LevelMode）
- mode(value: NavDestinationMode): NavDestinationAttribute；NavDestinationMode.DIALOG = 1：弹窗模式的 NavDestination，默认透明，入栈出栈不影响下层页面的生命周期（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.mode、NavDestinationMode.DIALOG）
- 各设置页加关闭弹层的方法并绑定 onBackPressed 后，按 Back 先关弹层：修好后的写法（出处：卡里修好并验证过）
