# 源 activity 声明 sensorLandscape 时，页面进入设横屏方向、离开恢复

审的是：代码
触发（任一种）：
- 读到：AndroidManifest.xml 的 <activity> 有 android:screenOrientation="sensorLandscape"；写错的样子：对应页面没有调 setPreferredOrientation，进入后仍是竖屏；或设了横屏但离开时不恢复
适用范围：单窗口应用里某个页面（NavDestination）对应的源 Activity 声明了横屏方向时
做法：
- 页面进入时 window.getLastWindow(context) 取窗口后调 win.setPreferredOrientation(window.Orientation.AUTO_ROTATION_LANDSCAPE)；aboutToDisappear 里 setPreferredOrientation(window.Orientation.UNSPECIFIED) 恢复
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- getLastWindow 后 setPreferredOrientation(AUTO_ROTATION_LANDSCAPE)、aboutToDisappear 恢复 UNSPECIFIED 后横屏正确：修复后的写法（出处：卡里修好并验证过）
- getLastWindow(ctx: BaseContext): Promise<Window>：取当前应用内最上层窗口（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，window.getLastWindow）
- setPreferredOrientation(orientation: Orientation): Promise<void>：window.Window 设置窗口方向（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，window.Window.setPreferredOrientation）
- Orientation.AUTO_ROTATION_LANDSCAPE = 7（忽略旋转锁）、UNSPECIFIED = 0：进入和离开用的两个值（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，window.Orientation）
- sensorLandscape = 6：横屏，可按传感器切换正反横向：源端取值的含义（出处：Android SDK 平台资源 data/res/values/attrs_manifest.xml，screenOrientation 的 sensorLandscape（按应用的 compileSdk 取对应平台））
