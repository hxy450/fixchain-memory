# 源页关了标题（FEATURE_NO_TITLE）时，目标页 hideTitleBar(true)，不加标题栏

审的是：代码
触发（任一种）：
- 读到：源 Activity 调 requestWindowFeature(Window.FEATURE_NO_TITLE)，页面只承载一个全屏视图（如 AMapNaviView）；写错的样子：目标页加了自定义白色标题栏，或 NavDestination 没写 .hideTitleBar(true)、露出系统标题栏
适用范围：源 Activity 关掉标题、只放全屏视图，迁成 NavDestination 页时
做法：
- 写成 NavDestination() { 全屏承载 }.hideTitleBar(true)，不另加自定义标题栏
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- FEATURE_NO_TITLE = 1：关掉屏幕顶部的标题（出处：android.view.Window#FEATURE_NO_TITLE）
- hideTitleBar(value: boolean): NavDestinationAttribute（默认 false）：隐藏 NavDestination 的系统标题栏（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.hideTitleBar）
- hideTitleBar(value: boolean): NavigationAttribute：同族接口：Navigation 根容器的标题栏隐藏（出处：鸿蒙 SDK 的 ets/component/navigation.d.ts，NavigationAttribute.hideTitleBar）
未核实：卡里的页面在 API 24（6.1.1）上，本机核对用 API 23 的声明
