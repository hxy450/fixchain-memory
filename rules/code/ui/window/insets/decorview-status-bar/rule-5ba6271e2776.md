# 页面自绘状态栏底色时，系统栏 statusBarColor 设透明，不给系统栏着色

审的是：代码
触发（任一种）：
- 读到：源端状态栏区域底色由 DecorView.setBackgroundColor 绘制；规格或派工要求「核验系统栏配色是否含 #…，缺则补」；写错的样子：EntryAbility 里 setWindowSystemBarProperties({ statusBarColor: '#ff…' }) 把底色交给系统栏，页面容器却没有底色和顶部 padding
适用范围：源端底色由根视图自绘、页面有带遮罩的弹窗，目标为全屏沉浸窗口时的系统栏配置
做法：
- statusBarColor 写 '#00000000'（透明），底色由页面容器 .backgroundColor(…) + 顶部 padding 绘制
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- statusBarColor?: string：SystemBarProperties 里状态栏的颜色（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，SystemBarProperties.statusBarColor）
- statusBarColor 改回 '#00000000'、页面容器自绘底色后，确认框打开时状态栏区域随遮罩压暗：修好后的表现（出处：卡里修好并验证过）
