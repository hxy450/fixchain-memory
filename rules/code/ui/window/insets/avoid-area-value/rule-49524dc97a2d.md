# TYPE_NAVIGATION_INDICATOR 避让取 bottomRect.height，不取 topRect

审的是：代码
触发（任一种）：
- 读到：派工或参考写「getWindowAvoidArea(TYPE_SYSTEM / TYPE_NAVIGATION_INDICATOR) 测量写入」，没指定取哪个矩形；已有页面片段里两类避让都读 topRect.height；写错的样子：getWindowAvoidArea(window.AvoidAreaType.TYPE_NAVIGATION_INDICATOR).topRect.height 被写进 bottomPadding（页面级或全局共享窗口模型），带导航指示条的设备上 bottomPadding 恒为 0
适用范围：全屏布局下测量状态栏和导航指示条避让值，写进页面或全局共享窗口模型时
做法：
- TYPE_SYSTEM 取 .topRect.height 作顶部避让，TYPE_NAVIGATION_INDICATOR 取 .bottomRect.height 作底部避让；值是 px，用 px2vp 或除以 density 转成 vp
- 把页面里的测量收敛进全局共享窗口模型时，不照搬页面片段，按避让区所在方位逐个核矩形字段；复制上一行只改 AvoidAreaType 常量时同时改矩形字段
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- getWindowAvoidArea(type: AvoidAreaType): AvoidArea：Window 上按类型取避让区，返回 leftRect / topRect / rightRect / bottomRect 四个矩形（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.getWindowAvoidArea）
- AvoidAreaType.TYPE_SYSTEM = 0、AvoidAreaType.TYPE_NAVIGATION_INDICATOR = 4：状态栏等系统区和底部导航指示条区的类型常量（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，window.AvoidAreaType）
- 避让区按所在方位放进对应的 Rect；底部导航区域表示为 [bottomRect, (0, H-h2, W, h2)]：导航指示条在窗口底部，高度只在 bottomRect 里，topRect 为空（出处：immersive-window-feature.md，避让区域AvoidArea的计算方式）
- Rect.height：矩形区域的高度，单位为 px，整数：用于布局前要转成 vp（出处：arkts-apis-window-i.md，Rect）
- 改读 bottomRect.height / density 后，底部按钮离屏底由 10vp 抬到 37.4vp：取对矩形后 bottomPadding 不再为 0（出处：卡里修好并验证过）
- getWindowAvoidAreaIgnoringVisibility(type: AvoidAreaType): AvoidArea：同族接口：Window 上不管该类避让区当前是否可见都返回（@since 22），同样按方位取矩形（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.getWindowAvoidAreaIgnoringVisibility）
- on(type: 'avoidAreaChange', callback: Callback<AvoidAreaOptions>): void：同族接口：Window 上监听避让区变化，回调里的 area 同样按方位取矩形（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.on('avoidAreaChange')）
