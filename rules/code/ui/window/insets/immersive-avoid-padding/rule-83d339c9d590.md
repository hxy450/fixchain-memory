# 全屏铺到底边的页面要把底部导航条避让加到底部内容容器上，不用固定 padding

审的是：代码
触发（任一种）：
- 读到：页面规格标 page_type = full_screen_page、needs_immersive_safearea = true；入口 Ability 调 setWindowLayoutFullScreen(true)，或外层容器对 SafeAreaEdge.BOTTOM 做了 expandSafeArea；写错的样子：页面根容器只写固定的 .padding({ bottom: 8 })，没读入口 Ability 发布到 AppStorage 的底部避让值（@StorageProp），也没取 getWindowAvoidArea，底部按键行或 Tab 栏落进导航指示条区
适用范围：目标窗口全屏布局、页面内容铺到屏幕底边时
做法：
- 页面用 @StorageProp 读入口 Ability 发布的底部避让值（或自己取 TYPE_NAVIGATION_INDICATOR 的 bottomRect.height 并换成 vp），加到底部按键区、Tab 栏或底部按钮所在容器上：.padding({ bottom: inset + 原有间距 })
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- setWindowLayoutFullScreen(isLayoutFullScreen: boolean): Promise<void>：主窗口全屏布局，页面内容会延伸到导航指示条下方（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.setWindowLayoutFullScreen）
- expandSafeArea(types?: Array<SafeAreaType>, edges?: Array<SafeAreaEdge>): T：容器向安全区外延伸；外层对 BOTTOM 延伸后，里面的页面要自己避让底部（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.expandSafeArea）
- getWindowAvoidArea(window.AvoidAreaType.TYPE_NAVIGATION_INDICATOR).bottomRect.height 发布到 AppStorage，页面底部容器 padding bottom 写 px2vp(底部避让) + 间距：官方示例的底部避让写法（出处：immersive-window-feature.md，适配沉浸式布局实现沉浸式效果）
- 根容器只写固定 bottom 间距时底部按键行落进导航指示条区；改成读发布的底部避让值加原间距后不再遮挡：改前改后的现象（出处：卡里修好并验证过）
针对本应用要查的：
- 入口 Ability 发布底部避让值用的 AppStorage 键名和单位：目标工程入口 Ability 的 .ets 文件里 getWindowAvoidArea 与 AppStorage.setOrCreate 那几行；页面 @StorageProp 用同一个键；看发布前有没有 px2vp，决定页面端是否还要换算
