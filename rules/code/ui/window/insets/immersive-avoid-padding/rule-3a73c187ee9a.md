# 作为宿主 Tab 子组件的页面，宿主已加安全区时不在根容器上重复叠加

审的是：代码
触发（任一种）：
- 读到：宿主页面的 `Tabs` 容器已经 `.padding({ top: …, bottom: … })` 加了顶部、底部安全区；写错的样子：Tab 子组件的根 `Column` 又加了同样的底部安全区 `.padding({ bottom: … })`
适用范围：页面作为宿主 Tabs 的子组件嵌入时处理窗口安全区
做法：
- 写前看宿主是否已处理顶部、底部安全区；已处理的，子组件根容器不再加同一侧的安全区 padding
针对本应用要查的：
- 宿主已经处理了哪几侧的安全区：目标工程里嵌入这个子组件的宿主页面，找 Tabs 容器及其外层的 padding；看 padding 的 top、bottom 是否已用窗口避让值；已用的一侧子组件不再加
