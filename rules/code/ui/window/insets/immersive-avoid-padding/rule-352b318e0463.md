# 底部 Tab 栏固定高度已含底部留白时，导航条避让替代这段留白，不整额叠加

审的是：代码
触发（任一种）：
- 读到：Tabs 原有 .barHeight(固定值)，tabBar 的自定义构建函数内容顶对齐、图标文字下方留有空白；避让值取自 getWindowAvoidArea(AvoidAreaType.TYPE_NAVIGATION_INDICATOR).bottomRect.height；写错的样子：.barHeight(原固定值 + px2vp(避让高度))，把整额避让加在已含留白的高度上
适用范围：窗口 setWindowLayoutFullScreen(true) 全屏沉浸、底部 Tab 栏要避开导航条时
做法：
- 先把原固定高度拆成内容高度和内容下方的留白，写成 .barHeight(内容高度 + px2vp(bottomRect.height))：避让高度替代这段留白（或从中抵扣），不在原总高上整额相加
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- getWindowAvoidArea(type: AvoidAreaType): AvoidArea：取窗口当前的避让区（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.getWindowAvoidArea）
- AvoidAreaType.TYPE_NAVIGATION_INDICATOR = 4：导航条区域（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，AvoidAreaType.TYPE_NAVIGATION_INDICATOR）
- AvoidArea.bottomRect: Rect，Rect.height 单位 px、整数：要先 px2vp 再和 vp 的布局值相加（出处：arkts-apis-window-i.md，Rect；鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，AvoidArea.bottomRect）
- barHeight(value: Length): TabsAttribute：Tab 栏高度；小于 0 或大于 Tabs 高度时用默认值（出处：鸿蒙 SDK 的 ets/component/tabs.d.ts，TabsAttribute.barHeight）
- 同一台设备上三键和手势两种模式的 TYPE_NAVIGATION_INDICATOR 都报 84px（28vp），手势小白条只占距底约 9–13vp：避让值不区分导航模式，整额叠加会让手势模式下底部间距过大（出处：卡里修好并验证过）
- getWindowAvoidAreaIgnoringVisibility(type: AvoidAreaType): AvoidArea（Window，@since 22）：同族接口：不论该类避让区当前是否可见都返回（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.getWindowAvoidAreaIgnoringVisibility）
- on(type: 'avoidAreaChange', callback: Callback<AvoidAreaOptions>): void（Window）：同族接口：避让区变化时回调（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.on('avoidAreaChange')）
未核实：卡里的行为在 API 16（HarmonyOS 5.0.4）上观察，本机按 API 23 的声明核实；避让替代留白后，手势模式下仍多出约 15vp，卡里没有完全消除；两种模式避让值相同只在一款真机上观察，其他设备未核
