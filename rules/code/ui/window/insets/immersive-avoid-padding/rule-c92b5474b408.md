# 全屏布局页面按 getWindowAvoidArea 的高度补 padding，不靠 expandSafeArea

审的是：代码
触发（任一种）：
- 读到：规格标了 `needs_immersive_safearea=true` 或 `page_type=full_screen_page`；源端是 `enableEdgeToEdge` 加 `safeDrawingPadding`；写错的样子：EntryAbility 里 `setWindowLayoutFullScreen(true)`，页面只在容器上加 `.expandSafeArea([SafeAreaType.SYSTEM], …)`，没有 `getWindowAvoidArea` 读取和基于避让高度的 padding
适用范围：开启全屏布局的入口页（根 Navigation 加 Tabs / NavDestination 壳），落实状态栏和底部导航条避让时
做法：
- aboutToAppear 里取窗口，win.getWindowAvoidArea(window.AvoidAreaType.TYPE_SYSTEM).topRect.height 作顶部、TYPE_NAVIGATION_INDICATOR 的 bottomRect.height 作底部，经 this.getUIContext().px2vp() 换成 vp 后给根 Navigation 加 .padding({ top, bottom })
- win.on('windowSizeChange', …) 里重新读避让区更新 padding；全屏布局和 expandSafeArea 只让背景延伸进系统栏，前景仍靠这份 padding
- 自查：开了全屏布局却搜不到 getWindowAvoidArea 或基于避让高度的 padding，即安全区未落实
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 移除容器上的 expandSafeArea，按 TYPE_SYSTEM / TYPE_NAVIGATION_INDICATOR 测得的高度经 px2vp 给根 Navigation 加 top/bottom padding 后，标题落在状态栏下方：修好的避让写法（出处：卡里修好并验证过）
- setWindowLayoutFullScreen(isLayoutFullScreen: boolean): Promise<void>：设置主窗口或子窗口为沉浸式布局，内容延伸到整个窗口（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.setWindowLayoutFullScreen）
- expandSafeArea(types?: Array<SafeAreaType>, edges?: Array<SafeAreaEdge>): T：设置组件要扩展到的安全区，只扩展组件区域，不替前景避让（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.expandSafeArea）
- getWindowAvoidArea(type: AvoidAreaType): AvoidArea；AvoidAreaType.TYPE_SYSTEM = 0、TYPE_NAVIGATION_INDICATOR = 4：取状态栏、底部导航条的避让区（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.getWindowAvoidArea、window.AvoidAreaType）
- AvoidArea.topRect: Rect、AvoidArea.bottomRect: Rect；UIContext.px2vp(value: number): number：取 Rect 的 height，再换成 vp 作 padding（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，AvoidArea；ets/api/@ohos.arkui.UIContext.d.ts，UIContext.px2vp）
- on(type: 'windowSizeChange', callback: Callback<Size>): void：窗口尺寸变化时重新读避让区（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.on('windowSizeChange')）
- getWindowAvoidAreaIgnoringVisibility(type: AvoidAreaType): AvoidArea（@since 22）：同族接口：Window 上不论该类区域当前是否可见都返回避让区（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.getWindowAvoidAreaIgnoringVisibility）
- 沉浸式布局下要在组件布局时做额外的布局避让，可加 padding 或占位组件：官方说法：全屏布局本身不做避让（出处：immersive-window-feature.md，布局避让）
未核实：卡里的观察出自 HarmonyOS 6.1.1(24)，本机声明按 API 23 核实；Rect.height 的单位声明里没写，按卡里修好的做法当 px 用 px2vp 换算
