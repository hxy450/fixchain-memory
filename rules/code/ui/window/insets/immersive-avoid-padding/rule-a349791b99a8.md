# 开 setWindowLayoutFullScreen(true) 前逐个 NavDestination 页核顶部避让

审的是：代码
触发（任一种）：
- 写错的样子：EntryAbility 里开启 `setWindowLayoutFullScreen(true)`，注释写「各页已接」，但有 NavDestination 页没有 windowTopPadding 一类的顶部避让
适用范围：收尾阶段打开窗口全屏布局时
做法：
- 开启前枚举全部 NavDestination 页（含其他组的页面），逐页 grep 顶部避让落点；缺的先补，不根据个别页面推定各页已接
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- setWindowLayoutFullScreen(isLayoutFullScreen: boolean): Promise<void>：设为 true 后窗口内容延伸到状态栏和导航栏区域，各页要自己避让（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.setWindowLayoutFullScreen）
