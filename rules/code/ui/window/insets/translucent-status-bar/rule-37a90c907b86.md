# 源端透明状态栏下的固定顶距，路由页只补「源顶距 − 已消费 inset」

审的是：代码
触发（任一种）：
- 读到：源页面在透明状态栏（QMUIStatusBarHelper.translucent）下用 layout_marginTop 给标题栏留位，顶距从屏幕顶部量起、包含状态栏；写错的样子：全屏窗口下的路由页（NavDestination / HMRouter 页）照搬源顶距写 .margin({ top: 源值 })，页面内容其实已从状态栏下沿排布，顶部多出一块空白
- 读到：同工程已修过的兄弟路由页注释写「Navigation already contributes the platform inset」或「路由页已在系统顶部 inset 之下」，顶部只补剩余量；写错的样子：新路由页在没有 expandSafeArea 的根节点上整页 .padding({ top: 状态栏高度 })，inset 又算了一次
适用范围：窗口 setWindowLayoutFullScreen(true)、只在 Navigation 宿主上 expandSafeArea，页面由 NavDestination（含 HMRouter）承载时
做法：
- 不凭宿主 Navigation 上的 expandSafeArea 推断路由页已铺满窗口；默认按路由页内容从状态栏下沿开始排布处理
- 二选一：路由页已在 inset 之下，就写 .margin({ top: Math.max(0, 源顶距 − 状态栏高度vp) })；或页面根先 .expandSafeArea([SafeAreaType.SYSTEM], [SafeAreaEdge.TOP])，再完整加状态栏高度。inset 只计一次，状态栏高度是 px 时先 px2vp
- 新增或重写路由页时沿用同工程已修复兄弟页的 inset 处理和注释结论；要反着做，在注释里写明依据
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 顶距写成 Math.max(0, 源顶距 − 状态栏高度) 后顶部空白消失；状态栏高度一度是 px，统一 px2vp 后公式按 vp 计算：修复后的顶距写法和单位（出处：卡里修好并验证过）
- NavDestination 从 API 11 起默认 expandSafeArea([SafeAreaType.SYSTEM], [SafeAreaEdge.TOP, SafeAreaEdge.BOTTOM])，默认支持安全区避让：路由页内容默认避开状态栏，所以从状态栏下沿排布（出处：ts-basic-components-navdestination.md，开头的说明）
- expandSafeArea 只作用于当前组件，不向父组件或子组件传递：宿主 Navigation 上的 expandSafeArea 管不到路由页里的节点（出处：ts-universal-attributes-expand-safe-area.md，expandSafeArea 说明）
- expandSafeArea(types?: Array<SafeAreaType>, edges?: Array<SafeAreaEdge>): T；不传参时 types 为 SYSTEM、CUTOUT、KEYBOARD，edges 为四边：扩展安全区的签名和默认值（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.expandSafeArea）
- SafeAreaType.SYSTEM = 0（状态栏和导航条）、CUTOUT = 1、KEYBOARD = 2；SafeAreaEdge.TOP = 0、BOTTOM = 1、START = 2：两个枚举的取值（出处：鸿蒙 SDK 的 ets/component/common.d.ts，SafeAreaType、SafeAreaEdge）
- getWindowAvoidArea(type: AvoidAreaType): AvoidArea；状态栏高度取 AvoidAreaType.TYPE_SYSTEM 的 topRect.height，单位 px，用 getUIContext().px2vp(...) 转 vp：状态栏高度的取法和单位（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，window.Window.getWindowAvoidArea；immersive-window-feature.md，避让系统界面元素）
针对本应用要查的：
- 源顶距是否从屏幕顶部量起：源工程 Activity / Fragment 里设置状态栏的调用（如 QMUIStatusBarHelper.translucent）和页面布局 XML 里标题栏的 layout_marginTop；状态栏透明且没有 fitsSystemWindows 或额外 padding 时，顶距含状态栏，目标端要减去已消费的 inset
未核实：路由页内容从状态栏下沿起排是卡里真机 dump 看到的（只在宿主上 expandSafeArea 的工程）
