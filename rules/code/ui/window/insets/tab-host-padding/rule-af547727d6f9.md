# Tab 子页自带延伸到顶的背景时，宿主内容容器不再统一加顶部 padding

审的是：代码
触发（任一种）：
- 读到：源端 Tab 子页（Fragment）的头图背景顶对父容器、用状态栏占位只下推前景；写错的样子：宿主承载各 Tab 和底栏的内容 Column 上有 .padding({ top: <顶部避让值> })，把子页背景和前景一起下移
适用范围：宿主页接线 Tab 子页、子页自己消费顶部避让值时
做法：
- 删掉宿主内容容器的统一顶部 padding，改由子页前景容器消费同一避让值
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 删掉宿主内容 Column 的顶部 padding、子页前景单独避让后判为修好：修好后的分工（出处：卡里修好并验证过）
