# sub_component 只跳过窗口级沉浸设置，页内状态栏占位改成前景容器消费宿主避让值

审的是：代码
触发（任一种）：
- 读到：源嵌入页用 ImmersionBar.statusBarView(占位) 撑出状态栏高度，内容约束在占位之下；页面元数据 page_type=sub_component、needs_immersive_safearea=false；写错的样子：目标 Stack 里头图背景和前景 Column 都没有状态栏偏移，前景只有源端的 margin；或者给背景和前景一起加了 .padding({ top: … })
适用范围：嵌入宿主的子页面实现页头、源端有页内状态栏占位时
做法：
- 只跳过窗口级沉浸式四件套；页内占位按层级转换：子页用 @Consumer('<宿主提供的顶部避让别名>') 接收避让值，只给前景内容 Column 加 .padding({ top: <避让值> })，背景不加偏移
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Consumer: (aliasName?: string) => PropertyDecorator：@Consumer 按别名匹配，找最近的同名 @Provider（出处：鸿蒙 SDK 的 ets/component/common.d.ts，Consumer）
- Provider: (aliasName?: string) => PropertyDecorator：宿主用 @Provider 以同一别名提供顶部避让值（出处：鸿蒙 SDK 的 ets/component/common.d.ts，Provider）
- 子页 @Consumer 接收顶部避让值、只给前景 Column 加顶部 padding，同时删掉宿主内容容器的顶部 padding 后判为修好：修好后的写法（出处：卡里修好并验证过）
未核实：卡里没写环境版本；@Provider / @Consumer 的声明按本机 API 23 核实
