# 底部避让 padding 加在占据屏幕底边的那层容器上，不加在背景色不同的根容器上

审的是：代码
触发（任一种）：
- 写错的样子：根容器（自带背景色、height('100%')）上写 .padding({ top: 顶部避让, bottom: 底部避让 })，而延伸到底边的是它里面背景色不同的 layoutWeight(1) 内容层，底部避让区被根容器的背景色填充
适用范围：全屏页面的根容器与延伸到底边的内容层背景色不同时
做法：
- 先看屏幕底边由哪一层背景占据（padding 区显示的是承载它的容器背景）：底部 inset 加到这一层的 .padding({ bottom: … }) 上，根容器只承担顶部状态栏区的 top 避让
- 底部是 Tab 栏时保持 Tab 栏的内容高度不变，把 inset 加在 Tab 栏容器的 padding 上，让它的背景延伸覆盖避让区
- 没有真机时，在交付说明里写明底部避让区由哪一层背景填充
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 顶部容器 padding top 加状态栏避让，底部容器 padding bottom 加导航区避让，各自带自己的 backgroundColor：官方示例把上下避让分别放在占据上下边的容器上（出处：immersive-window-feature.md，适配沉浸式布局实现沉浸式效果）
- bottom inset 从根容器移到延伸到底边的内容层后，底部不再出现根容器颜色的色块：改前改后的现象（出处：卡里修好并验证过）
