# 给固定 height 的容器加顶部 padding 前，按可见高度 = height − paddingTop 核对

审的是：代码
触发（任一种）：
- 写错的样子：固定 .height(N) 的标题栏或工具栏上又加了 .padding({ top: … })（安全区或其他顶距），没有同步增高
适用范围：ArkUI 里给固定高度的容器加 padding 时
做法：
- 算可见内容高度 = height − paddingTop；小于源工具栏高度时，改成外层容器加 padding，或把 height 同步加上这段 padding
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ArkUI 固定 .height() 包含 padding，有状态栏时 height(52)+padding({ top: topInset }) 的可见高度变成 52 − topInset：盒模型：padding 画在固定尺寸之内（出处：卡里修好并验证过）
- 示例：宽 80、高 80 的组件，上下左右内边距 5、15、10、20 画在这 80×80 之内：文档示例里的内边距在固定宽高以内（出处：ts-universal-attributes-size.md，示例1（设置组件的宽高和边距））
- padding(value: Padding | Length | LocalizedPadding): T，默认 0，单位 vp：内边距接口（出处：ts-universal-attributes-size.md，padding）
