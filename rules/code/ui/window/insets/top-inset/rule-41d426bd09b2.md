# 根布局 fitsSystemWindows=true 时，顶部安全区放标题栏外层，标题栏保持源高度

审的是：代码
触发（任一种）：
- 读到：全屏页根布局 android:fitsSystemWindows="true"，里面的工具栏 FrameLayout / Toolbar 是固定 layout_height（如 52dp），自身没有 paddingTop；写错的样子：标题 Row 写成 .height(<源高度>).padding({ top: <顶部安全区值> })，把安全区塞进固定高度里；或者外层和 Scroll 又各加一层顶部安全区
适用范围：Android 全屏页由根布局 fitsSystemWindows 承担状态栏避让、迁成 ArkUI 自绘标题栏时
做法：
- Column() { Row() { … }.height(<源高度 vp>) … }.padding({ top: <顶部安全区值> })：安全区放在标题栏外层容器，标题 Row 保持源高度（52dp → 52vp）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- fitsSystemWindows 为 true 时调整这个 view 的 padding，给状态栏等系统窗口留出空间：源端的避让在根布局这一层，工具栏本身不缩（出处：Android SDK 平台资源 data/res/values/attrs.xml，fitsSystemWindows（按应用的 compileSdk 取对应平台））
- ArkUI 固定 .height() 包含 padding；标题 Row 包进外层 Column、安全区移到外层后，工具栏可见高度恢复为源高度：修好的结构（出处：卡里修好并验证过）
