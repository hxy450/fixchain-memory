# 根 Navigation 只作路由容器、栏位自绘时，hideTitleBar 和 hideToolBar 写 true

审的是：代码
触发（任一种）：
- 读到：源端外壳没有系统标题栏或工具栏：Compose Scaffold 只传 bottomBar 和 snackbarHost（topBar 为空），自绘底部导航贴屏幕底；规格把 ComponentActivity 映射为 @Entry + Navigation(Stack) + pageMap；写错的样子：根 Navigation 的属性链只有 .mode(NavigationMode.Stack).navDestination(...).expandSafeArea(...)，没有 .hideTitleBar(true) 和 .hideToolBar(true)；内容区比 NavBar 短一截，自绘底栏离屏幕底悬空
适用范围：@Entry 页以 Navigation 作根路由容器、承载 tab 内容和自绘底栏，详情页走 NavDestination 时
做法：
- 根 Navigation 显式写 .hideTitleBar(true).hideToolBar(true)；自绘标题栏的 NavDestination 另写 .hideTitleBar(true)
- 不以「未设 title() / toolbarConfiguration 就不占位」为由省略这两个属性
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- hideTitleBar(value: boolean): NavigationAttribute，默认 false（显示）：Navigation 的标题栏默认显示（出处：鸿蒙 SDK 的 ets/component/navigation.d.ts，NavigationAttribute.hideTitleBar）
- hideToolBar(value: boolean): NavigationAttribute，默认 false（显示）：Navigation 的工具栏默认显示（出处：鸿蒙 SDK 的 ets/component/navigation.d.ts，NavigationAttribute.hideToolBar）
- Navigation 内部默认包含标题栏、内容区和工具栏：不隐藏时这两栏参与布局（出处：ts-basic-components-navigation.md，开头的说明）
- 根 Navigation 加 .hideTitleBar(true).hideToolBar(true) 后，NavBarContent 高度恢复到与 NavBar 相同（修复前短 112vp），自绘底栏贴底：修复前后的布局（出处：卡里修好并验证过）
- hideTitleBar(value: boolean): NavDestinationAttribute，默认 false：同族接口：NavDestination 的标题栏隐藏（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.hideTitleBar）
- hideToolBar(hide: boolean, animated?: boolean): NavDestinationAttribute：同族接口：NavDestination 的工具栏隐藏（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationAttribute.hideToolBar）
未核实：修复同时加了 hideTitleBar 与 hideToolBar，没有分开验证内容区短的那一截来自哪一项
