# 子组件按约定豁免 Layer 3 时，Tab 宿主给内容区和抽屉面板补顶部和底部避让

审的是：代码
触发（任一种）：
- 读到：页面规格 needs_immersive_safearea=true；沉浸约定的责任分层表写子组件/overlay 不订阅窗口避让、安全区由宿主全屏页统一负责（子组件豁免 Layer 3）；写错的样子：Tab 宿主头注释写「Tab 内容区顶部避让由各 Tab 页自行处理」，内容区 Stack 和抽屉面板 Column 都没有 .padding({ top: windowTopPadding })；Tab 子页又写「由宿主统一处理」
适用范围：窗口全屏铺满、Tab 宿主内嵌组件页和抽屉面板时的顶部、底部避让
做法：
- 宿主给 Tab 内容区加 .padding({ top: windowTopPadding })，底栏隐藏时内容区加 .padding({ bottom: windowBottomPadding })，抽屉面板上下都加避让
- 若按源码结构把避让交给子页，先 grep 子页确有 windowTopPadding 的消费再写注释；宿主和子页不能互相推给对方
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- expandSafeArea(types?: Array<SafeAreaType>, edges?: Array<SafeAreaEdge>): T：根容器延伸进安全区后，前景内容不会自动避让，要各层手动加 padding（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.expandSafeArea）
- 宿主内容区 padding.top = 顶部避让、底栏隐藏时 padding.bottom、抽屉面板上下避让：修复后的宿主避让（出处：卡里修好并验证过）
未核实：修复后宿主和子页是否对同一 Tab 双重避让，卡里没核
