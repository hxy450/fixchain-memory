# 源端画中画自动进入，目标用 PiPWindow.create 加 setAutoStartEnabled

审的是：代码
触发（任一种）：
- 读到：源端 PictureInPictureParams.Builder().setAutoEnterEnabled(true)、onUserLeaveHint 进入画中画，onPictureInPictureModeChanged 写画中画状态；写错的样子：目标没有 PiPWindow 相关代码，画中画状态写成恒 false，设置里的画中画开关是死键、没有可用性判定
适用范围：源 Activity 用画中画承载计时、播放等内容，迁到 HarmonyOS 时
做法：
- PiPWindow.create({ context, componentController, templateType: PiPWindow.PiPTemplateType.VIDEO_PLAY, customUIController }) 得 PiPController，源端 setAutoEnterEnabled(true/false) 对应 controller.setAutoStartEnabled(true/false)
- controller.on('stateChange', (state, reason) => …) 写入画中画状态（替代 onPictureInPictureModeChanged）；设置项可用性用 PiPWindow.isPiPEnabled()
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- function create(config: PiPConfiguration): Promise<PiPController>：创建画中画控制器；设备不支持时抛 801（出处：鸿蒙 SDK 的 ets/api/@ohos.PiPWindow.d.ts，PiPWindow.create）
- PiPConfiguration：context: BaseContext、componentController: XComponentController 必填，templateType?、customUIController?: NodeController 等可选：create 的参数（出处：鸿蒙 SDK 的 ets/api/@ohos.PiPWindow.d.ts，PiPWindow.PiPConfiguration）
- setAutoStartEnabled(enable: boolean): void：回桌面时是否自动进入画中画，对应源端 setAutoEnterEnabled（出处：鸿蒙 SDK 的 ets/api/@ohos.PiPWindow.d.ts，PiPController.setAutoStartEnabled）
- on(type: 'stateChange', callback: (state: PiPState, reason: string) => void): void：画中画生命周期状态变化回调（出处：鸿蒙 SDK 的 ets/api/@ohos.PiPWindow.d.ts，PiPController.on）
- PiPTemplateType.VIDEO_PLAY：视频播放模板，修复时配自定义 UI 使用（出处：鸿蒙 SDK 的 ets/api/@ohos.PiPWindow.d.ts，PiPWindow.PiPTemplateType.VIDEO_PLAY）
- VIDEO_PLAY 模板 + 自定义 UI + setAutoStartEnabled；状态由 stateChange 写入；设置行可用性用 isPiPEnabled()：修复时接入的写法（出处：卡里修好并验证过）
