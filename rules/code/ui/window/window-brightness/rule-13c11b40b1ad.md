# 前屏补光开启时同时提亮窗口和打开全屏白色覆盖层，拍照结束等路径两者一起复位

审的是：代码
触发（任一种）：
- 写错的样子：VM 的补光处理只调 setWindowBrightness 提亮，预览门面接口没有开白色覆盖层和结束拍照的转发方法，页面也没绑定；拍照结束时只恢复亮度
适用范围：迁移前置摄像头的前屏补光（提亮屏幕 + 预览上画全屏白）时，规格验收条目只写了亮度、锚点指向源端开补光的函数
做法：
- 开补光时提亮一次窗口亮度并打开全屏白色覆盖层；预览门面接口加「开补光」「结束拍照」两个转发方法，并在页面绑定
- 拍照结束、相机关闭、页面进后台、重新被拉起、销毁等路径都复位亮度和白层
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- setWindowBrightness(brightness: number): Promise<void>：设置窗口亮度（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.setWindowBrightness）
- brightness 取 [0.0, 1.0] 或 -1.0；1.0 最亮，-1.0 恢复成设置窗口亮度前的系统亮度：开补光写 1.0，复位写 -1.0（出处：arkts-apis-window-Window.md，setWindowBrightness）
- 提亮一次并开白层、多路径复位后实测有白屏，亮度能复位，进后台时取消：修好后的表现（出处：卡里修好并验证过）
