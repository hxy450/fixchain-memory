# 源主题和代码都没设浅色状态栏标志时，statusBarContentColor 写 '#ffffff'

审的是：代码
触发（任一种）：
- 读到：源主题（含 Theme.AppCompat.Light.NoActionBar 一类「Light」主题）和 values-vNN 覆盖里没有 android:windowLightStatusBar，代码里没有 SYSTEM_UI_FLAG_LIGHT_STATUS_BAR、APPEARANCE_LIGHT_STATUS_BARS；写错的样子：setWindowSystemBarProperties 里 statusBarContentColor 写成深色（如 '#776e65'），注释按「浅色主题」或「对比足够」论证；或只设了 statusBarColor、navigationBarColor，没写 statusBarContentColor
适用范围：在 EntryAbility 等处用 setWindowSystemBarProperties 配状态栏，源端是安卓 View 主题时
做法：
- 查主题（含 values-vNN 覆盖）的 windowLightStatusBar 和代码里的 SYSTEM_UI_FLAG_LIGHT_STATUS_BAR、setSystemBarsAppearance(APPEARANCE_LIGHT_STATUS_BARS)；都没有时安卓图标是白色，显式写 statusBarContentColor: '#ffffff'
- 主题名里的「Light」不让状态栏图标变深，不从浅色主题或浅底色推深色图标；「对比足够」只在源端没有可迁移设定时兜底，并在注释写明依据
- 改状态栏底色时回源主题复核内容色，按另一底色论证的旧注释不沿用
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- windowLightStatusBar（boolean）：设了才把状态栏画成适配浅底的样式，对应 View.SYSTEM_UI_FLAG_LIGHT_STATUS_BAR 和 WindowInsetsController.APPEARANCE_LIGHT_STATUS_BARS：源端图标变深的三种写法（出处：Android SDK 平台资源 data/res/values/attrs.xml，windowLightStatusBar（按应用的 compileSdk 取对应平台））
- 平台主题里只有 Theme.Material.Light.LightStatusBar 等变体写了 windowLightStatusBar=true，Theme.Material.Light 本身没写：「Light」主题默认仍是白色状态栏图标（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material.Light.LightStatusBar（按应用的 compileSdk 取对应平台））
- APPEARANCE_LIGHT_STATUS_BARS = 1 << 3：源码里用 setSystemBarsAppearance 设浅色状态栏时的标志（出处：android.view.WindowInsetsController#APPEARANCE_LIGHT_STATUS_BARS）
- setWindowSystemBarProperties(systemBarProperties: SystemBarProperties): Promise<void>；SystemBarProperties.statusBarContentColor?: string：目标设状态栏内容色的接口（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.setWindowSystemBarProperties、SystemBarProperties.statusBarContentColor）
- statusBarContentColor 默认 '#E5FFFFFF'；设了它之后 isStatusBarLightIcon 无效：显式写才确定图标颜色（出处：arkts-apis-window-i.md，SystemBarProperties）
- systemBarStyle(style: Optional<SystemBarStyle>): NavigationAttribute；SystemBarStyle.statusBarContentColor?: string：同族接口：Navigation 上设状态栏内容色（出处：鸿蒙 SDK 的 ets/component/navigation.d.ts，NavigationAttribute.systemBarStyle；ets/api/@ohos.window.d.ts，SystemBarStyle）
- AppCompat 主题继承链上没有 windowLightStatusBar，改成 '#ffffff' 后与安卓截图一致：白色图标是截图核对过的结论（出处：卡里修好并验证过）
- 补 statusBarContentColor '#FFFFFFFF' 后状态栏时间和图标不再是深色：源主题没设 windowLightStatusBar 时漏写内容色的修法（出处：卡里修好并验证过）
针对本应用要查的：
- 源端状态栏图标明暗：源工程 res/values* 下主题文件里应用和 Activity 主题的 android:windowLightStatusBar，顺 parent 到依赖库或平台主题；再搜 Java/Kotlin 里的 SYSTEM_UI_FLAG_LIGHT_STATUS_BAR、APPEARANCE_LIGHT_STATUS_BARS；有一处为 true 就是深色图标，写深色内容色；都没有就是白色，写 '#ffffff'
