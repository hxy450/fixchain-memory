# 系统栏内容色按源端状态栏图标深浅定，不照搬模板的浅色 #FFFFFFFF

审的是：代码
触发（任一种）：
- 读到：参考模板或派工里写 setWindowSystemBarProperties「透明背景 + 浅色文字」、statusBarContentColor 设 #FFFFFF，没有给出源端状态栏图标的深浅；写错的样子：UIAbility 里 statusBarContentColor / navigationBarContentColor 写成 '#FFFFFFFF'，而源端基类 Activity 或主题设的是深色状态栏图标、白色状态栏
适用范围：开启 setWindowLayoutFullScreen 沉浸式、在 UIAbility 里用 setWindowSystemBarProperties 设系统栏内容色时
做法：
- 先读源端基类 Activity 和主题里状态栏图标的深浅设置及页面顶部背景色：深色图标、浅色背景时 statusBarContentColor 和 navigationBarContentColor 写深色（如 '#FF000000'）；浅色图标、深色背景才写 '#FFFFFFFF'。模板里的浅色只是默认，不能代替源端对照
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- setWindowSystemBarProperties(systemBarProperties: SystemBarProperties): Promise<void>：Window 上设状态栏、导航栏属性的接口（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.setWindowSystemBarProperties）
- statusBarContentColor?: string；navigationBarContentColor?: string：SystemBarProperties 里的状态栏、导航栏文字颜色；设了以后 isStatusBarLightIcon / isNavigationBarLightIcon 无效，默认值 '#E5FFFFFF'（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，SystemBarProperties；arkts-apis-window-i.md，SystemBarProperties）
- 源端深色图标、白色状态栏时内容色写 '#FF000000'：改成深色后状态栏文字和图标与源端一致（出处：卡里修好并验证过）
- windowLightStatusBar 的 format 是 boolean：设为 true 时状态栏按浅色背景绘制（深色图标），对应 SYSTEM_UI_FLAG_LIGHT_STATUS_BAR / APPEARANCE_LIGHT_STATUS_BARS（出处：Android SDK 平台资源 data/res/values/attrs.xml，windowLightStatusBar（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 源端状态栏图标是深色还是浅色、状态栏背景是什么颜色：源工程主题 XML（styles / themes）里的 android:windowLightStatusBar、android:statusBarColor，以及基类 Activity 里设置状态栏图标深浅的调用；windowLightStatusBar 为 true 或基类打开了深色图标，内容色写深色；否则写浅色
未核实：卡里环境是 API 24（6.1.1），本机按 API 23 的声明核对
