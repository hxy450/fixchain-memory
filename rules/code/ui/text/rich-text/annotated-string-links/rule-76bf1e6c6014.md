# 源码里有、验收项没写的可见行为照源码实现；做不了就登记占位、报告写明降级

审的是：代码
触发（任一种）：
- 读到：源码对展示内容有可见加工（如 buildAnnotatedStringWithUrls 生成链接），而功能验收项只写了空值隐藏、折叠展开这类布局行为；写错的样子：代码只落实验收项、把源码行为删掉，结构化报告的 `low_confidence_uncertain_regions` 为空，也没有登记占位
- 读到：派工只允许写页面文件，源码调用的共享工具类（…Utils.kt 这类 util）还没有目标文件；写错的样子：页面的 build() 里仍是直接显示原始字符串的 Text，既没实现等价逻辑，也没登记前向引用，静默省略了工具类带来的行为
适用范围：界面实现阶段，源码行为超出规格验收项或派工允许的文件范围时
做法：
- 验收项没列不是删掉源码可见行为的依据：按源码实现；派工只许写页面时，在页面内实现等价逻辑
- 做不了时登记占位或前向引用交给后续切片，在报告的未决项里写明这次降级，并指出规格缺口
