# 源端 Text 的文本带 LinkAnnotation 时，目标用 StyledString 加 UrlStyle

审的是：代码
触发（任一种）：
- 读到：Compose 组件把原始字符串先交给 buildAnnotatedStringWithUrls 这类工具函数，得到带 LinkAnnotation 的 AnnotatedString，再 Text(text = …) 显示；写错的样子：目标写成 Text(this.text) 这类直接显示原始字符串的 Text，链接不着色也不可点
适用范围：把 Compose 里经工具函数加工过的展示文本（链接识别、着色、点击）迁成 ArkUI Text 时
做法：
- 先确认传给 Text 的是原始字符串还是加工后的 AnnotatedString；是加工过的，读工具函数的定义，弄清链接怎么识别、什么样式、点了做什么
- 目标端对每个识别出的链接生成 { start, length, styledKey: StyledStringKey.URL, styledValue: new UrlStyle(url) }，组成 new StyledString(text, styles)，在 Text('', { controller: this.textController }) 上用 this.textController.setStyledString(…) 设置
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- TextController.setStyledString + Text('', { controller })：修好后能编译、能显示链接的写法（出处：卡里修好并验证过）
- constructor(value: string | ImageAttachment | CustomSpan, styles?: Array<StyleOptions>)：StyledString 的构造；StyleOptions 有 start?、length?、styledKey、styledValue（出处：鸿蒙 SDK 的 ets/component/styled_string.d.ts，StyledString.constructor、StyleOptions）
- UrlStyle constructor(url: string)，StyledStringKey.URL = 7，声明 @since 14：超链接样式：点击所附文字时尝试打开该 URL（出处：鸿蒙 SDK 的 ets/component/styled_string.d.ts，UrlStyle、StyledStringKey.URL）
- UrlStyle 默认颜色 '#ff0a59f7'、字号 16fp、FontWeight.Regular；设了 TextStyle 时 TextStyle 优先：链接默认就着色；要和源端链接色一致时另加 TextStyle（出处：ts-universal-styled-string.md，UrlStyle）
- setStyledString(value: StyledString): void：TextController 设置属性字符串，MutableStyledString 也可传（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextController.setStyledString）
- setStyledString(styledString: StyledString): void：同族接口：RichEditorStyledStringController 的设置方法（实现 StyledStringController）（出处：鸿蒙 SDK 的 ets/component/rich_editor.d.ts，RichEditorStyledStringController.setStyledString）
针对本应用要查的：
- 源端链接的识别规则、样式和点击行为：源工程里被调用的那个工具函数（按函数名 grep 定义），看它的正则和构建 LinkAnnotation 时传的样式；正则照搬成目标端的识别逻辑；链接色与默认 '#ff0a59f7' 不同时，同一区间再加一个 TextStyle
