# setSpan(start, end) 拆成 Span 时按 end 开区间逐字算着色范围

审的是：代码
触发（任一种）：
- 读到：SpannableString.setSpan(颜色 span, start, end, flags) 按索引给一段文字着色，end 常写成「前缀字数 + 值长度 + 后缀」的表达式；写错的样子：Text 里拆出的着色 Span 少了区间末尾的字（如后缀字落在基色 Span 里），或多吞了区间外的字
适用范围：把安卓 SpannableString 按索引着色迁成 ArkUI Text + Span 时
做法：
- 按 [start, end) 半开区间算：着色 Span 的文字是 str.substring(start, end)，前后剩余部分各成基色 Span
- 用前缀字数和一个样例值把每个字符的颜色写出来核对，确认首尾字是否在着色段内
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- public void setSpan(Object what, int start, int end, int flags)：把 span 挂到 start…end 这段文字上（出处：android.text.Spannable#setSpan）
- (value: string | Resource): SpanAttribute：Span 的构造，作为 Text 的子组件逐段给样式（出处：鸿蒙 SDK 的 ets/component/span.d.ts，SpanInterface）
- end 是开区间终点：把着色段终点并入区间内最后一个字后与源端一致：修法（出处：卡里修好并验证过）
未核实：Spannable 源码注释只写 start…end，半开区间按卡里修好的结果和 Java 下标惯例写
