# ListPreference 的 summary 串含 %s/%1$s 时，目标摘要要代入当前选项的显示文字

审的是：代码
触发（任一种）：
- 读到：偏好 XML 里 ListPreference（或它的子类）带 android:summary="@string/…"，这个字符串的值里有 %s 或 %1$s；写错的样子：目标摘要写成 $r('app.string.…') 不传参数，界面直接显示 %1$s；或者因为子类里没有 setSummary 就当成静态文字
适用范围：安卓 ListPreference（框架或 androidx.preference，含应用里的子类）的摘要迁到 ArkTS 设置页时
做法：
- 先读 summary 引用的字符串资源的实际值；含 %s 或 %1$s 时，代入点就是 ListPreference#getSummary：代入当前值在 entryValues 里的下标所对应的 entries 项，没有匹配时代入空串
- 目标写成 $r('app.string.名称', 当前选项标签)（或 getStringSync(resId, 当前选项标签)），选项改变后摘要随状态刷新
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- return String.format(mSummary, entry == null ? "" : entry);：ListPreference 自己在 getSummary 里代入当前 entry，子类不需要 setSummary（出处：android.preference.ListPreference#getSummary）
- getEntry() = index >= 0 && mEntries != null ? mEntries[index] : null，index = findIndexOfValue(mValue)：代入的是当前值在 entryValues 里的下标对应的 entries 显示文字（出处：android.preference.ListPreference#getEntry）
- declare function $r(value: string, ...params: any[]): Resource;：带参数的资源引用，params 依次替代字符串里的占位符（出处：鸿蒙 SDK 的 ets/component/common.d.ts，$r）
- getStringSync(resId: number, ...args: Array<string | number>): string：同族接口：按资源 ID 取字符串并用 args 格式化（ResourceManager）（出处：鸿蒙 SDK 的 ets/api/@ohos.resourceManager.d.ts，ResourceManager.getStringSync）
- getStringByNameSync(resName: string, ...args: Array<string | number>): string：同族接口：按资源名取字符串并格式化（ResourceManager）（出处：鸿蒙 SDK 的 ets/api/@ohos.resourceManager.d.ts，ResourceManager.getStringByNameSync）
- 支持 %d、%f、%s、%%、%数字$d、%数字$f、%数字$s：目标字符串资源里可以保留安卓的 %s、%1$s 写法（出处：js-apis-resource-manager.md，getStringSync10+）
针对本应用要查的：
- summary 字符串的实际值和选项的 entries / entryValues：源工程 res/values*/strings.xml 里 android:summary 引用的那个 string；偏好 XML 里这个 ListPreference 的 android:entries、android:entryValues 引用的 string-array；看值里有没有 %s / %1$s；有就按当前值在 entryValues 的下标取 entries 的显示文字作参数
未核实：androidx.preference.ListPreference#getSummary 的代入写法本机只有编译产物，按框架源码和卡里的结论写
