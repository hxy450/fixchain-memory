# stringResource 带参数时映射成 $r('app.string.x', a, b)，不手工拼接

审的是：代码
触发（任一种）：
- 读到：源端 Compose 用 stringResource(R.string.<键>, a, b) 套 %1$s / %2$s 模板；写错的样子：目标把 ResourceStr 类型的参数直接 + ' ' + 拼接，没走资源模板：显示出对象字符串，模板里的固定词（如 ago）丢了
适用范围：把带格式参数的字符串资源调用迁到 ArkTS 时
做法：
- 写成 $r('app.string.<键>', a, b)；参数本身是 Resource 的，先用 getStringSync 解析成字符串再传
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- $r('app.string.label', 'aaa', 444)：string.json 的值里有 %1$s、%2$d 占位符时，按顺序传参替换（出处：resource-categories-and-access.md，资源访问）
- getStringSync(resource: Resource, ...args: Array<string | number>): string：格式参数只收 string 或 number，Resource 参数要先解析（出处：鸿蒙 SDK 的 ets/api/@ohos.resourceManager.d.ts，ResourceManager.getStringSync）
- getStringByNameSync(resName: string, ...args: Array<string | number>): string：同族接口：按资源名取带格式参数的字符串（出处：鸿蒙 SDK 的 ets/api/@ohos.resourceManager.d.ts，ResourceManager.getStringByNameSync）
- getStringSync(resId: number, ...args: Array<string | number>): string：同族接口：按资源 ID 取带格式参数的字符串（出处：鸿蒙 SDK 的 ets/api/@ohos.resourceManager.d.ts，ResourceManager.getStringSync）
