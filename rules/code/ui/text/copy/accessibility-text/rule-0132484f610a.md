# accessibilityText 不传 string 与 $r 混合的三元，先统一成 string

审的是：代码
触发（任一种）：
- 读到：派工要求文案经 $r 资源绑定；已有页面的 accessibilityText 有的传 string、有的传 $r(...)；写错的样子：写成 .accessibilityText(<条件> ? <字符串> : $r('app.string.…')) 这种一支 string、一支 Resource 的三元
适用范围：ArkUI 组件设置无障碍文本，候选文案来自字符串和资源两种来源时
做法：
- 先把三元两边统一成 string 再传：.accessibilityText(<条件> ? <字符串> : <字符串>)；没有必要的无障碍文本可以删掉
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- accessibilityText(value: string): T：string 重载，默认值 ""（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.accessibilityText）
- accessibilityText(text: Resource): T：Resource 重载，和 string 重载分开，不接受 string | Resource 联合（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.accessibilityText）
- accessibilityDescription(value: string): T；accessibilityDescription(description: Resource): T：同族接口：无障碍说明，同样 string 与 Resource 分开重载（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.accessibilityDescription）
- accessibilityText 改为纯 string 或删除后编译通过：修好后的写法（出处：卡里修好并验证过）
未核实：卡里的编译报错出自 API 26（target_sdk 26.0.0），本机核对用的是 API 23
