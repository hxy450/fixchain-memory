# 选空态等文案时以页面调用链为准，不取 docs 截图和 @Preview 的示例文案

审的是：代码
触发（任一种）：
- 读到：仓库里有 docs/assets 截图和 @Preview 函数，里面的示例文案和页面调用链里 stringResource(R.string.…) 用的不一样；写错的样子：目标的空态或提示文案取自截图或 @Preview 的示例字符串（应用代码里零引用），与已读到的调用点不一致
适用范围：修复与视觉核对阶段选定字符串和图标时
做法：
- 以页面实际调用链为真值：选定字符串 key 前先搜它在应用代码里的真实引用；只出现在 @Preview 或截图里的不是应用文案
- 与已读到的调用点不一致时以调用点为准，图标也取调用点用的那个
针对本应用要查的：
- 某段文案的真实来源：源工程里该区块调用链上的 stringResource(R.string.…) 调用，以及对字符串 key 的全仓搜索；引用只在 @Preview 函数或 docs 下出现的，不当作应用文案
来源：1 张卡，1 个应用
