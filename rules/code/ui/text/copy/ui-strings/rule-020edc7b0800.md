# 给既有 UI 模型展示字段填值时保留构建器的空值回退，不用状态描述或计数顶替标签

审的是：代码
触发（任一种）：
- 读到：安卓列表项布局里该 TextView 的 android:text 是静态占位文案；目标构建器写 Text(item.field.length > 0 ? item.field : $r('app.string.…')) 这类空值回退；写错的样子：数据映射把该字段填成另一条状态文案（如「暂无时间」）或计数 `${list.length}`，或把构建器改成 Text(item.field) 删掉回退
适用范围：数据层给已有 UI 模型的展示字段接真实数据时
做法：
- 填值前先读该字段在构建器里的渲染分支和空值回退，并对照安卓对应控件的布局和绑定；没有对应源数据时字段留空串，让构建器显示回退文案
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 无源数据时字段改回占位文案资源（与安卓布局的静态文案一致）后显示正确：修好后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 字段为空时该显示什么：源工程列表项布局 XML 里对应 TextView 的 android:text，以及适配器里有没有给它 setText；适配器没设值时显示的就是布局里的静态文案，目标回退要和它一致
来源：1 张卡，1 个应用
