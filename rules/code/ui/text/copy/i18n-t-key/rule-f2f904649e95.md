# 要随语言刷新的页面里 Text 写死中文字面量、没有 i18n 引用时，改成经键取文案

审的是：代码
触发（任一种）：
- 读到：源页面文案来自运行期 i18n 键 `t('…')`，spec 写语言切换后刷新全部文案；写错的样子：页面各处 `Text('…')` 散写中文字面量，文件里没有 i18n 服务或 `tr(` 的引用，registry 里也没有对应的 `FWD-REF`
适用范围：需随应用内语言切换刷新文案的页面，转换和收口阶段
做法：
- i18n 服务已就绪：导入 i18n 服务和它的状态，页面持有 i18n 状态，文案全部换成 tr(键)；源端本来就不随语言变的串保留字面量
- i18n 服务还没落地：文案先集中到一张可整体替换的键表，不散在各个 Text 里，并登记 FWD-REF
- 收口时 grep i18n 服务、tr( 引用和用户可见中文字面量：零引用又没有登记 P-ID 就判未接线，注释自称已有决策也不放行
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 补 i18n 服务和状态的导入、i18n 状态与 tr()，18 处字面量换键，保留源端恒定的串，切到另一语言后全页刷新：修复后的接线方式（出处：卡里修好并验证过）

- 目标端 i18n 服务的取文案函数和语言状态：目标工程里 i18n 切片提供的服务文件（.ets），以及已接线页面对它的用法；照已接线页面的写法导入服务、持有状态、用它的翻译函数取键
