# 注释里不拿 D- 编号给过渡做法当依据，核对 ledger 原文后按延期占位登记

审的是：代码
触发（任一种）：
- 读到：decision-ledger 里被引用的 `D-` 条目原文只规定别的事（如 i18n 声明式状态刷新），没批准页面文案用字面量；写错的样子：页面头注释（以及页面 spec）写「`D-…` 文案取单一语言字面量（i18n 服务接管前）」，把过渡做法包装成 ledger 决策
适用范围：转换阶段在代码注释或规格里引用决策台账编号时
做法：
- 引 D- 编号前核对 ledger 原文；「××接管前 / 落地后替换」这类过渡做法删掉 D- 引用，改按延期占位登记（FWD-REF）
