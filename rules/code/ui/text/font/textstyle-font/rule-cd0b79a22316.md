# Compose 文本用 typography 命名样式时，按令牌表查字号再找值一致的 float 键，不借别页键

审的是：代码
触发（任一种）：
- 读到：源 Compose Text 的 style = MaterialTheme.typography.titleMedium / bodyMedium 这类命名样式；写错的样子：目标 Text 写 .fontSize($r('app.float.…')) 按「标题 / 正文」语义复用别页前缀的键，键值和令牌表里该样式的字号不同
适用范围：源端 Compose 文本经 MaterialTheme.typography 取字号、目标用 float.json 字号令牌时
做法：
- 用源码的样式名（如 titleMedium）在设计令牌表查到字号，再到 float.json 找值相同的键，写 .fontSize($r('app.float.键名'))
- 没有值一致的键时，在 float.json 追加按样式或本页命名的新键，value 写令牌表的字号（fp）；或报告 design_tokens_missing，不拿别页键代替
- 写完逐个 Text 核对「源码样式名 → 令牌表字号 → 所引用 float 键的值」三者一致
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- fontSize(value: number | string | Resource): TextAttribute：Text 的字号；传 number 时单位是 fp，默认 16fp（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.fontSize）
- { "float": [ { "name": "font_hello", "value": "28.0fp" } ] }：float.json 的写法：name 是键名，value 带 fp 单位（出处：resource-categories-and-access.md，资源文件示例）
- fontSize(value: number | string | Resource): SpanAttribute：同族接口：Span 的字号（出处：鸿蒙 SDK 的 ets/component/span.d.ts，SpanAttribute.fontSize）
- fontSize(value: Length): TextInputAttribute：同族接口：TextInput 的字号（出处：鸿蒙 SDK 的 ets/component/text_input.d.ts，TextInputAttribute.fontSize）
- 按样式追加本页字号键并改引用：改后视觉验收判定标题和正文字号与源端一致（出处：卡里修好并验证过）
针对本应用要查的：
- 这个排版样式在应用里的字号：设计令牌表；令牌表的来源是源工程里定义 Typography(...) 的 Kotlin 主题文件；按样式名读出 fontSize = N.sp；应用没在 Typography(...) 里覆写的样式取 Material3 默认值
