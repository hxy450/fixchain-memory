# 源 FontFamily 一族多字重文件时，按「族-字重」逐文件 registerFont，入口调一次

审的是：代码
触发（任一种）：
- 读到：Compose FontFamily(Font(R.font.x, FontWeight.y), …) 为同一族声明多个字重文件，目标 rawfile/fonts 下有对应 ttf；写错的样子：全工程没有 registerFont，Text 的 .fontFamily 引用未注册的通用族名；或同族多个文件都注册成同一个 familyName
适用范围：源端用自定义字体文件的 FontFamily、目标在 ArkUI 里用 fontFamily 引用 rawfile 字体时
做法：
- 每个字体文件注册独立的 familyName：this.getUIContext().getFont().registerFont({ familyName: '<族>-<字重>', familySrc: $rawfile('fonts/<文件>.ttf') })
- 排版令牌引用注册名：.fontFamily('<族>-<字重>')，fontWeight 设为这个文件本身的字重
- 注册函数由应用入口页的 aboutToAppear 调用一次
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- registerFont(options: font.FontOptions): void：UIContext 的 Font 对象上注册自定义字体（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，Font.registerFont）
- getFont(): Font：从 UIContext 取 Font 对象（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.getFont）
- familyName: string | Resource；familySrc: string | Resource：FontOptions 的注册名和字体文件路径，familySrc 可传 $rawfile(…)（出处：鸿蒙 SDK 的 ets/api/@ohos.font.d.ts，font.FontOptions）
- function registerFont(options: FontOptions): void（@deprecated since 18，@useinstead ohos.arkui.UIContext.Font#registerFont）：同族接口：模块级 font.registerFont，已废弃（出处：鸿蒙 SDK 的 ets/api/@ohos.font.d.ts，font.registerFont）
- 该接口为异步接口，不支持并发调用：注册放在入口统一调一次（出处：js-apis-font.md，font.registerFont(deprecated)）
- 按「族-字重」逐文件注册、字重改为文件本身字重，入口 aboutToAppear 调用注册，各页文本补 .fontFamily 后字体生效：修好后的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 每个字体文件对应的族和字重：源工程 Compose 主题里 FontFamily(Font(R.font.<文件>, FontWeight.<字重>), …) 的声明；逐个 Font(...) 读出文件名和 FontWeight，得到「族-字重」注册名和文件本身的字重
未核实：「一个族名只绑一个文件」是卡里的判断，没在知识库里核到
