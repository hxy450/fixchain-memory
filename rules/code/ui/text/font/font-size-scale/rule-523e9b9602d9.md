# 新增文本测量或 Paragraph 绘制时，字号按源端 dp 公式乘 vp2px(1)，几何比例单独传

审的是：代码
触发（任一种）：
- 读到：源端文本的 textSize 由 dp 值乘文字倍率得到，不含根尺寸或设计宽度比例；写错的样子：新增的 measureTextSize 或 text.TextStyle 的 fontSize 照搬了已有组件里乘画布比例的表达式，或写成 fontSize * vp2px(画布比例)
适用范围：目标端为动态布局文本新增测量（MeasureUtils.measureTextSize）或原生排版绘制（@ohos.graphics.text 的 Paragraph）路径时
做法：
- 字号回到源端公式（dp 值 × 文字倍率）重新推导，不照搬现有组件的字号表达式；measureTextSize 用和 Text 上同一个源端 vp 值
- Paragraph 的 TextStyle.fontSize 写成 源端 vp 值 × uiContext.vp2px(1)，px 换算只用 vp2px(1)
- 描边宽度等几何量要按画布比例时，把比例作为单独参数传入，只乘在几何量上
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- text.TextStyle.fontSize?: number，单位 px，默认 14.0：Paragraph 排版用的字号是 px，源端 vp 值要乘 vp2px(1)（出处：鸿蒙 SDK 的 ets/api/@ohos.graphics.text.d.ts，text.TextStyle.fontSize）
- vp2px(value: number): number：UIContext 上的 vp 转 px（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.vp2px）
- measureTextSize(options: MeasureOptions): SizeOptions：UIContext 的 MeasureUtils 上测文本宽高（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，MeasureUtils.measureTextSize）
- MeasureOptions.fontSize 为 number 时从 API 12 起按 fp：测量的字号单位和 Text.fontSize 一致，源端 dp 值同样写成带 vp 后缀的字符串（出处：js-apis-measure.md，MeasureOptions）
- 字号与 paragraph 用 vp2px(1) 换算，描边宽度等几何仍用含画布比例的 px 倍率：修复后的特效文本写法（出处：卡里修好并验证过）
- declare function vp2px(value: number): number（since 18 弃用，改用 UIContext#vp2px）：同族接口：全局 vp2px（出处：鸿蒙 SDK 的 ets/component/common.d.ts，vp2px）
