# 源端用 Locale.getDisplayName(自身) 生成语言名时，按 ICU 实际输出建表，不凭记忆改大小写

审的是：代码
触发（任一种）：
- 读到：Kotlin 里 map.put(it, it.getDisplayName(it)) 一类，用 Locale.getDisplayName(本 locale) 生成语言自称；写错的样子：目标手写语言表，把 Français、Español、Dansk、Italiano、Русский 这类自称写成首字母大写（ICU 自称是 français、español、dansk、italiano、русский）
适用范围：Android 运行时生成的显示文本（语言自称等）迁到目标端时
做法：
- 按 ICU 实际输出建表（法语、西语等自称首字母小写），或在运行时取值，不凭记忆手写大小写
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Locale.getDisplayLanguage 取 LocaleNative.getDisplayLanguage(this, locale) 的结果，不做大小写处理：安卓的语言自称直接是 ICU 输出（出处：java.util.Locale#getDisplayLanguage）
