# 源端未设语言回退 English 时，另记显式设置的 tag，不只靠 getAppPreferredLanguage

审的是：代码
触发（任一种）：
- 读到：Locale.lookup(AppCompatDelegate.getApplicationLocales()…) ?: Locale.ENGLISH，未设置应用语言时回退 English；写错的样子：目标用 i18n.System.getAppPreferredLanguage() 匹配当前语言，最后回退 en，没有「未设置 → English」这一分支
适用范围：迁移应用内语言切换、当前语言判断时
做法：
- 用 Preferences 单独记录用户显式设置的语言 tag；没有记录时按 English 处理，有记录时才用该 tag 匹配
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- static getAppPreferredLanguage(): string：获取应用偏好语言（出处：鸿蒙 SDK 的 ets/api/@ohos.i18n.d.ts，System.getAppPreferredLanguage）
- getAppPreferredLanguage() 在未设置应用语言时返回系统语言，区分不出「未设置」：所以要另记显式 tag（出处：卡里修好并验证过）
- setAppPreferredLanguage 设为 'default' 后应用语言跟随系统语言，冷启动生效：鸿蒙的「未设置」语义是跟随系统，不是 English（出处：js-apis-i18n.md，setAppPreferredLanguage）
未核实：卡里环境是鸿蒙 6.1.1(24)，本机按 API 23 核对；声明和文档都没写未设置时的返回值
