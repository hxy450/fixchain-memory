# 转写 Typography 常量表时，同时给出单行自然高度和多行行距两个派生值

审的是：代码
触发（任一种）：
- 读到：Compose `Typography` 里各 `TextStyle` 的 `fontSize` / `lineHeight`，未设 `lineHeightStyle`；写错的样子：目标主题文件里的 TextStyle 常量只有 `lineHeight` 字段，没有单行自然高度、行间距派生值，也没注释说明不能原样传给 `.lineHeight()`
适用范围：设计令牌转写阶段，把 Compose Typography 落成 ArkTS 主题常量表时
做法：
- 每个样式常量加两个派生字段：单行自然高度（字号 × 字体高度系数）和行间距（lineHeight − fontSize），并注释写明 lineHeight 不能原样传给 ArkUI .lineHeight()，各页共用这两个值
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 主题样式类增加行间距与自然高度两个字段后，各页单行删 .lineHeight、多行用 lineSpacing、空串用 minHeight 都引用它们：修好的令牌结构（出处：卡里修好并验证过）
针对本应用要查的：
- 每种字体的高度系数：源工程 res/font 里的字体文件，hhea 表的 ascender、descender 和 head 表的 unitsPerEm；(ascender + |descender|) / unitsPerEm
