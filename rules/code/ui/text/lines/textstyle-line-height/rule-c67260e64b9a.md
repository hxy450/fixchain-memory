# TextStyle 行高迁成 lineSpacing(lineHeight − fontSize)，只加在行间

审的是：代码
触发（任一种）：
- 读到：Compose `TextStyle(fontSize = …, lineHeight = …)`，没设 `lineHeightStyle`；写错的样子：Text 上（或 AttributeModifier<TextAttribute> 的 applyNormalAttribute 里对所有 Text）写了 .lineHeight(…)
- 读到：Compose TextStyle 带 lineHeight（sp），同一样式用于单行和多行；写错的样子：.lineSpacing(LengthMetrics.vp(lineHeight − 自然行高), …)，减的是字体 hhea 算出的自然行高
适用范围：Compose TextStyle 带 lineHeight、未设 lineHeightStyle，迁成 ArkUI Text 或统一的 AttributeModifier 时（带 options 的 lineSpacing @since 20）
做法：
- 不写 .lineHeight，改成 .lineSpacing(LengthMetrics.fp(lineHeight − fontSize), { onlyBetweenLines: true })，两值取源 TextStyle 的 sp 数值；单行盒高由字体自然高决定
- 间距减的是 fontSize，不是 hhea 自然行高；另两张卡用 LengthMetrics.vp(…)，单位之争见未核实
- 落地前拿一个单行 Text 的实测高（Android dump 盒高，或 hhea 比 × fontSize）核对 modifier 输出，不只比对令牌数值
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 多行行距 = fontSize + lineSpacing；间距取 lineHeight − fontSize 后多行行距与安卓一致，单行仍是自然高：ArkUI Text 多行行距的合成规则（两张卡分别由 dump 反推复验、在设备上标定）（出处：卡里修好并验证过）
- modifier 改为 .lineSpacing(LengthMetrics.vp(…), { onlyBetweenLines: true }) 并按 ttf hhea 比算自然行高后，双端单行盒高对上：去掉无条件 .lineHeight 后的写法（出处：卡里修好并验证过）
- lineSpacing(value: LengthMetrics, options?: LineSpacingOptions): TextAttribute（@since 20）：Text 的行间距，带选项的重载（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.lineSpacing）
- onlyBetweenLines?: boolean：true 时只在行与行之间生效；默认 false，不配置 LineSpacingOptions 时首行上方和尾行下方也有行间距，单行会被撑高（出处：鸿蒙 SDK 的 ets/component/text_common.d.ts，LineSpacingOptions.onlyBetweenLines；ts-text-common.md，LineSpacingOptions20+对象说明；ts-basic-components-text.md，lineSpacing20+）
- static fp(value: number): LengthMetrics：按 fp 构造间距（出处：鸿蒙 SDK 的 ets/api/arkui/Graphics.d.ts，LengthMetrics.fp）
- static vp(value: number): LengthMetrics：按 vp 构造间距（出处：鸿蒙 SDK 的 ets/api/arkui/Graphics.d.ts，LengthMetrics.vp）
- lineSpacing(value: LengthMetrics, options?: LineSpacingOptions): TextAreaAttribute：同族接口：TextArea 的行间距（出处：鸿蒙 SDK 的 ets/component/text_area.d.ts，TextAreaAttribute.lineSpacing）
针对本应用要查的：
- 字体的自然行高比：目标工程 rawfile 里该排版令牌用的 ttf 字体的 hhea 表（ascender、descender）和 head 表的 unitsPerEm；(ascender − descender) / unitsPerEm 得比值，乘 fontSize 得单行自然高；与 Android dump 里单行 Text 的盒高 / fontSize 对照
- 换了字体或 SDK 后行间距是否仍是 lineHeight − fontSize：源端 TextStyle 的 lineHeight、fontSize，和双端同一段多行 Text 的 dump；多行时相邻行距应等于源端 lineHeight；用一段两行文本在设备上比对确认
未核实：间距的单位卡与卡不同：case-d9d5f51887ff5d7afd17 写 LengthMetrics.fp(lineHeight − fontSize)，case-04c6d6166ebb2bcc3dfa、case-4056358e68946ac061c6 写 LengthMetrics.vp(…)；系统字体缩放不为 1 时两者结果不同，哪个对卡里没有核对；合成规则只由 Karla、Montserrat 16fp 的 dump 反推，其他字号、字体，以及 minLineHeight / maxLineHeight（@since 22）路径未核；lineHeight − fontSize 是在一个工程的设备上标定的；换字体或 SDK 时先用一段两行文本在设备上核对；自然行高比是否要计入 hhea 的 lineGap 卡里没写
