# 单行用户内容用 maxLines(1)+Ellipsis 时，补 wordBreak(BREAK_ALL) 按字符省略

审的是：代码
触发（任一种）：
- 读到：`getSupportActionBar().setTitle(title)` 等工具栏标题，或 android:singleLine / android:ellipsize="end" 的单行文本，内容是用户输入（笔记标题、分类名）；写错的样子：`Text(…).maxLines(1).textOverflow({ overflow: TextOverflow.Ellipsis })` 没有 .wordBreak(WordBreak.BREAK_ALL)，长英文标题在词边界就省略
适用范围：Android 单行文本按字符省略（Toolbar 标题、单行 TextView），迁成 ArkUI Text 单行省略时
做法：
- 单行省略写成 Text(…).maxLines(1).textOverflow({ overflow: TextOverflow.Ellipsis }).wordBreak(WordBreak.BREAK_ALL)
- 自检：用含多个长词的标题在两端比对省略位置
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- wordBreak(value: WordBreak): TextAttribute，默认 WordBreak.BREAK_WORD；与 Ellipsis、maxLines 一起用时 BREAK_ALL 可在字母间断行再省略：Text 的断行规则（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.wordBreak）
- WordBreak.NORMAL = 0、BREAK_ALL = 1、BREAK_WORD = 2、HYPHENATION = 3（@since 18）：BREAK_ALL：非 CJK 文本可在任意字符处断行（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，WordBreak）
- 不调用 wordBreak 或设 BREAK_WORD 时截断按字进行，英文以单词为最小单位：ArkUI 默认按词省略（出处：ts-basic-components-text.md，wordBreak）
- Toolbar 标题 setSingleLine() 并 setEllipsize(TextUtils.TruncateAt.END)：源端工具栏标题是单行末尾省略（出处：android.widget.Toolbar#setTitle）
- wordBreak(value: WordBreak): TextAreaAttribute：同族接口：TextArea 的断行规则（出处：鸿蒙 SDK 的 ets/component/text_area.d.ts，TextAreaAttribute.wordBreak）
- wordBreak(value: WordBreak): TextInputAttribute：同族接口：TextInput 的断行规则（出处：鸿蒙 SDK 的 ets/component/text_input.d.ts，TextInputAttribute.wordBreak）
- 加 wordBreak(BREAK_ALL) 后省略位置与参照机一致（「Alpha beta gamma delt…」而非「Alpha beta …」）：卡里的修法（出处：卡里修好并验证过）
