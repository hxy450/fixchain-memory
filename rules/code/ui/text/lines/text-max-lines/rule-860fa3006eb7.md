# Compose Text 有 maxLines 没写 overflow 时，目标用 TextOverflow.Clip

审的是：代码
触发（任一种）：
- 读到：Compose `Text(…, maxLines = …)` 没有传 overflow 参数；写错的样子：对应的 ArkUI Text 上写了 `.textOverflow({ overflow: TextOverflow.Ellipsis })`，多出省略号
适用范围：源 Compose Text 限了行数、没显式设 overflow，迁成 ArkUI Text 时
做法：
- 写 Text(...).maxLines(<源 maxLines>).textOverflow({ overflow: TextOverflow.Clip })；源端显式写了 overflow 的按源值对应 TextOverflow 的同名枚举
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- textOverflow(options: TextOverflowOptions): TextAttribute：Text 的截断方式，参数是 { overflow: TextOverflow }（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.textOverflow）
- TextOverflowOptions.overflow 的 @default 是 TextOverflow.Clip：不写时就是裁切；写 Ellipsis 才出省略号（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextOverflowOptions.overflow）
- TextOverflow：None、Clip、Ellipsis、MARQUEE；None 与 Clip 效果相同；None、Clip、Ellipsis 要配合 maxLines 才生效：枚举取值和生效条件（出处：鸿蒙 SDK 的 ets/component/enums.d.ts，TextOverflow；ets/component/text.d.ts，TextAttribute.textOverflow）
- textOverflow(value: TextOverflow): TextInputAttribute：同族接口：TextInput 的截断方式，直接传枚举（出处：鸿蒙 SDK 的 ets/component/text_input.d.ts，TextInputAttribute.textOverflow）
- textOverflow(value: TextOverflow): TextAreaAttribute：同族接口：TextArea 的截断方式，直接传枚举（出处：鸿蒙 SDK 的 ets/component/text_area.d.ts，TextAreaAttribute.textOverflow）
未核实：Compose Text 的 overflow 参数默认是 Clip 出自卡，本机没有 Compose 源码可核；卡里的行为出自鸿蒙 SDK API 24，本机核实用的是 API 23
