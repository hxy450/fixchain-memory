# 控件引用 style 或 Material 控件时，先查样式里的行数、字号字重和 trackColor 再写

审的是：代码
触发（任一种）：
- 读到：TextView 写 style="@style/…" 或 android:textAppearance，XML 本身没写 maxLines / textSize；写错的样子：目标按「XML 没写即默认」推断成 maxLines(1)，次要文字用一个通用字号键
- 读到：LinearProgressIndicator 没写 app:trackColor，靠主题默认样式；写错的样子：Progress 的 .backgroundColor 用了和选中 / 正在播放行底色同一个颜色键，轨道看不出来
适用范围：源控件的外观来自 style、textAppearance 或主题默认控件样式时
做法：
- 先在 res/values 的 styles / themes 里顺着 style 和 parent 查出 maxLines / lines、TextAppearance 的字号、字重、行高，再写 .maxLines / .fontSize / .fontWeight / .lineHeight
- 进度轨道色取源主题里 LinearProgressIndicator 样式的 trackColor，单独建颜色键；从已有组件照搬颜色前先核对源端是否同色
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- TextView 的 mMaximum 初值是 Integer.MAX_VALUE（行数不设上限）：XML 和样式都没写 maxLines 时不是 1 行（出处：android.widget.TextView#mMaximum）
- Widget.Material3.LinearProgressIndicator 的 trackColor = @macro/m3_comp_progress_indicator_track_color；Legacy 样式为 ?attr/colorSurfaceContainerHighest：应用主题没有覆写时轨道色的来源（出处：com.google.android.material:material 包内 res/values/values.xml，Widget.Material3.LinearProgressIndicator（按应用依赖的版本））
- 标题 maxLines(2) + lineHeight(20)，次要文字按样式另建扩展样式，轨道用单独的颜色键：修复时按源样式查出的值改写（出处：卡里修好并验证过）
针对本应用要查的：
- 控件实际生效的 maxLines、字号字重行高、trackColor：源工程 res/values*/styles.xml、themes.xml 里控件引用的 style 及其 parent 链；主题里 linearProgressIndicatorStyle 指向的样式；逐层找到最先给出该属性的那一项；都没写的，回到 Android 平台或 material 库的默认样式读值
未核实：卡里没在派工、规格里核到这几个样式的具体值，只按写者见到样式引用却没解析来归因
