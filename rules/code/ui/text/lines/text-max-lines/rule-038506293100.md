# DialogTitle 单行放不下时改中号字两行，目标标题不只写 maxLines(1)

审的是：代码
触发（任一种）：
- 读到：对话框标题是 com.android.internal.widget.DialogTitle（android:singleLine="true"、ellipsize=end）；写错的样子：目标标题写死 .fontSize(20).maxLines(1)，放不下时只省略，没有改小字号两行的分支
适用范围：复刻框架 AlertDialog 或 DialogPreference 的标题时
做法：
- 标题先按标题字号单行排；单行放不下（会出省略号）时改用 textAppearanceMedium 的字号并 .maxLines(2)（Material 主题下即 20fp 放不下改 18fp 两行），做成共享的标题组件供各对话框复用
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- DialogTitle.onMeasure：最后一行有省略时 setSingleLine(false)、setMaxLines(2)，字号改取 textAppearanceMedium 的 textSize：singleLine 只是初值，框架运行期会改成两行小一号（出处：com.android.internal.widget.DialogTitle#onMeasure）
- 改成标题组件「20fp 放不下切 18fp 两行」后与源端一致：Material 主题下的修法（出处：卡里修好并验证过）
针对本应用要查的：
- 标题字号和放不下时的中号字号：Android SDK 平台资源 data/res/values/themes_material.xml（或应用主题链）里对话框主题的 windowTitleStyle 和 textAppearanceMedium，再到 styles_material.xml、dimens_material.xml 解析到 textSize；读出两个 sp 值，目标写成同值 fp。例：Material 主题下 textAppearanceMedium → TextAppearance.Material.Medium → text_size_medium_material 18sp，标题 text_size_title_material 20sp
