# android:lines="N" 写成 minLines(N) 加 maxLines(N)，不只写 maxLines

审的是：代码
触发（任一种）：
- 读到：TextView 写 android:lines="2" 这类固定行数；写错的样子：目标 Text 只写 .maxLines(2)，单行内容时控件变矮
适用范围：源 TextView 用 android:lines 固定行高、目标是 ArkUI Text 时；minLines 声明标 @since 22
做法：
- 写成 Text(…).minLines(N).maxLines(N)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- setLines(int lines) 把最少和最多行数都设成 lines：android:lines 是固定高度，不只是上限（出处：android.widget.TextView#setLines）
- minLines(minLines: Optional<number>): TextAttribute（@since 22）：Text 的最少行数（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.minLines）
- maxLines(value: number): TextAttribute：Text 的最多行数（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextAttribute.maxLines）
- minLines(lines: Optional<number>): TextAreaAttribute：同族接口：TextArea 的最少行数（出处：鸿蒙 SDK 的 ets/component/text_area.d.ts，TextAreaAttribute.minLines）
