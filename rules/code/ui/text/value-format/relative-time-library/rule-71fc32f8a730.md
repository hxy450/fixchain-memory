# 源函数只是委托第三方格式化库时，按库的实际行为移植并对拍，做不到就登记占位

审的是：代码
触发（任一种）：
- 读到：源端共享工具函数体只是 PrettyTime(Locale.getDefault()).formatDuration(...)，另有只在 en 生效的缩写分支、纯数字时回退英文；写错的样子：目标写成固定英文的相对时间：不到 1 分钟返回固定词、按 30 / 365 天分档、Math.round 或 floor 凭记忆取整、不看 locale；没有登记占位或决策缺口
适用范围：共享工具迁移阶段，源函数委托第三方库生成用户可见文本、目标平台没有同名库时
做法：
- 按库的实际行为移植单位表、舍入容差和各语言文案，locale 按应用当前 locale 取；源端的英文回退、仅 en 缩写这些分支照写
- 用源端样例对拍；暂时做不到等价时登记占位或决策缺口，不把英文近似当完成交付
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 直译库源码：12 个单位、舍入容差、多语言数据和 locale 候选链，按应用 locale 计算：修好后的移植范围（出处：卡里修好并验证过）
针对本应用要查的：
- 库的单位表、舍入和各语言文案：按源工程依赖坐标的版本，取本机 Gradle 缓存 modules-2/files-2.1 下该库的 sources jar（或 jar 里的各语言资源类）；逐个单位读出阈值和舍入规则、逐个语言读出文案，移植成目标端数据表
