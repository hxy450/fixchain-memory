# 迁移 DecimalFormat 时保留 HALF_EVEN 和当前 locale 符号，不用 toFixed

审的是：代码
触发（任一种）：
- 读到：源端用 new DecimalFormat("#,###.#") 格式化计数缩写（如千、百万）；写错的样子：目标写成 value.toFixed(...) 或 toLocaleString('en-US', …)：1250 出 1.3K、1200 出 1K，小数点和分组符号固定成英文
适用范围：把源端 DecimalFormat 的数值格式化迁到 ArkTS 时
做法：
- 保留 DecimalFormat 的默认 HALF_EVEN 舍入和默认 locale 的小数点、分组符号，最多一位小数、尾零不出
- 输出前用边界值核对：1200 → 1.2K、1250 → 1.2K、22 → "22 "
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- DecimalFormat 默认 RoundingMode.HALF_EVEN：1.25 这类恰好一半的值取偶数位，1250 缩写成 1.2K（出处：java.text.DecimalFormat（类注释 Rounding 一节））
- DecimalFormat(String pattern) 用默认 FORMAT locale 的符号：小数点和分组符号随 locale 变（出处：java.text.DecimalFormat#DecimalFormat(String)）
- 改成最短十进制加 HALF_EVEN、用当前 locale 的符号后与源端一致：修好后的写法（出处：卡里修好并验证过）
