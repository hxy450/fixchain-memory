# 共享格式工具里已有函数与源码笔记的舍入语义不符时，owner 一并修正，不只补点名的函数

审的是：代码
触发（任一种）：
- 读到：源码笔记或规格写「DecimalFormat "0.#"，默认 HALF_EVEN」，派工只点名共享工具里的某一个函数；写错的样子：同一工具文件里其他格式函数仍是 Math.round / toFixed 实现，只新增或改了派工点名的那个
适用范围：共享数值工具的 owner 修改该工具时
做法：
- 对照规格和自己的源码笔记逐个函数核对；同文件里已有实现与源语义不符的，一并修正，修不了就登记
