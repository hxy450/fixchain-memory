# 复刻源端格式化函数时按源签名核对默认参数，优先调用已实现的工具函数，不在页内重写

审的是：代码
触发（任一种）：
- 读到：源端 Kotlin 格式化函数签名带 Boolean 默认参数（如分钟不补零、秒补零），调用处不传参只用默认值；写错的样子：目标在页内另写同名格式化函数，默认值和源不同（如分钟也 padStart(2, '0')），注释里写错源端默认值
适用范围：实现阶段复刻源端的时长、数字等格式化函数时
做法：
- 按源签名逐个核对默认参数，调用处不传参的就按源默认格式输出；优先调用工程里已实现的对应工具函数，不在页内重写
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 毫秒先 roundToInt 再用默认参数格式化，得到不补零分钟的 m:ss：修好后步骤时长与源一致（出处：卡里修好并验证过）
