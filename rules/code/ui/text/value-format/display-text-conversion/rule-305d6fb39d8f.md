# 数据网关遇到接口里的数值状态码时，经源端同表映射成文案，不用 toString()

审的是：代码
触发（任一种）：
- 读到：源端工具类用穷举表（`when` / `switch`）把接口返回的数值码（如天气码、AQI、风向码）映射成文案；规格 AC 要求按源端同表映射；写错的样子：网关里写 `code.toString()` 直接当描述，或把数值字段直接赋给描述字段，没有调用映射函数
适用范围：实现运行时数据网关、把接口里的状态码字段转成展示模型时
做法：
- 把源端工具类的映射表逐项搬成目标端的映射函数（每个码一项，含默认分支），网关里每个码字段都经它转成文案
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 按源端表映射天气、AQI、风向及小时字段后，展示文案与源端一致：验证过的做法（出处：卡里修好并验证过）
针对本应用要查的：
- 每个码字段的映射表：源工程里把码转文案的工具类（Kotlin 的 when、Java 的 switch，或数组 / Map 常量），以及文案引用的字符串资源；逐项抄出码值和文案（字符串资源取对应语言的值），连同默认分支一起实现
