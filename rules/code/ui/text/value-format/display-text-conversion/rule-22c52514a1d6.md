# 复刻目标侧没有的源端格式化 helper 时，先读函数体，按原式实现除数、小数和单位后缀

审的是：代码
触发（任一种）：
- 读到：源端调用点把一个静态格式化 helper 的返回值直接拼进显示文案，只补括号不补单位（形如 `" (" + helper(w, h) + ")"`），单位后缀和小数规则在 helper 内部（如 String.format("%.2f")）；写错的样子：目标自写的等价 helper 除数和小数位凭记忆写（如 toFixed(1)），返回值没有单位后缀，注释里的公式和表达式对不上
适用范围：为显示文案复刻源端被调用、目标工程尚不存在的格式化 helper 时
做法：
- 复刻前打开源 helper 的函数体及它内部调用的格式化函数，按原式实现除数、小数规则（如整数直出、否则两位小数）和单位后缀，不凭记忆补「%.1f」之类格式
- 调用方只拼括号不拼单位时，单位后缀算 helper 返回值的一部分；写完把 helper 输出代回调用点，对照规格样例核对完整显示串
- 用当前任务的典型尺寸做最小核算，并检查注释里的公式和表达式一致（注释写 1e6、代码却除以 1e7 再除以 10 就要改）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 按源 helper 原式改写（除数、整数直出否则两位小数、加单位后缀）并加测试后，显示串与源端一致：修好后的做法（出处：卡里修好并验证过）
针对本应用要查的：
- 源 helper 的除数、小数规则和单位后缀：源工程里调用点引用的那个类的静态方法函数体，以及它内部调用的格式化函数；逐行照抄运算和格式化分支，后缀在 helper 里加的就在目标 helper 里加；例：百万像素 helper 为 (w*h)/1e6、整数直出否则两位小数再加 MP 时，1280×720 得 0.92MP、4000×3000 得 12MP
