# 源码把 Float 直接格式化进字符串时，按 Float.toString 输出并保留 .0

审的是：代码
触发（任一种）：
- 读到：stringResource(R.string.x, floatValue) 或字符串模板里直接放 Float（如 roundToDecimals() 的结果）；写错的样子：目标写成 `${value}` 模板串或 toStringShort(value)，12.0 显示成「12」
适用范围：源端 Float 值直接转成显示文本、迁成 ArkTS 数字格式化时
做法：
- 按 Float.toString 语义写一个格式化函数：整数值补「.0」（如 Number.isInteger(v) ? v.toFixed(1) : String(v)），不用 toStringShort 或 `${v}`；源端是 roundToInt() 的分支照整数输出
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Float.toString：数量级在 [10^-3, 10^7) 时用定点写法且至少一位小数（123×10^2 写成 12300.0），之外用科学计数法（如 1.0E23）：整数值也带「.0」；很大或很小的值要另处理（出处：java.lang.Float#toString）
- 改为保留「.0」的格式化后与源端一致：修法（出处：卡里修好并验证过）
未核实：Kotlin 在 JVM/安卓上的 Float.toString 委托 java.lang.Float.toString，本机没有 Kotlin 标准库源码核对
