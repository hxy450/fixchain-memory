# 首页等数据驱动页面按源 ViewModel 接真实数据并保留加载、空、错误三态，不写死假数据

审的是：代码
触发（任一种）：
- 读到：源首页由 ViewModel / Repository 驱动：hiltViewModel()、collectAsState() 取网络列表状态，Banner、分类、商品都来自实体数据；写错的样子：目标页把分类写成固定字符串数组、Banner 用本地图标循环、商品卡片写死名称和价格，没有数据加载，也没有加载、空、错误状态
适用范围：源端页面内容来自网络或数据源的页面转换
做法：
- 按源 ViewModel / Repository 确定接口和数据模型，目标页接入真实数据请求，并保留源端的加载、空、错误三种状态
针对本应用要查的：
- 页面的数据接口和状态：源工程里该页 ViewModel 调用的 Repository / Service 接口，以及 ViewModel 暴露的 UI 状态类；读出请求路径、参数和返回的数据模型，以及状态类里加载、空、错误各分支
来源：1 张卡，1 个应用
