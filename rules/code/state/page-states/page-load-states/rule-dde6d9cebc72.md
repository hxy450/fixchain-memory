# 数据层的 return [] 只代表有效查询成功返回空，坐标未知、未授权、定位失败用 Result 联合单独返回

审的是：代码
触发（任一种）：
- 读到：规格或决策台账写着「失败保持显式错误与最近成功数据、不伪造空成功」、选定显式 `Result` 联合类型，或要求未知坐标标 `known=false`、定位拒绝与失败分为不同分支；写错的样子：数据层在坐标未知、未授权或定位失败时 `return []`，调用方把它当作成功的空列表
适用范围：目标端数据层（Repository、Service）里依赖定位或权限的查询的返回值
做法：
- 逐个检查 `return []`：只有查询条件有效且服务成功返回空时才返回空态
- 坐标未知、未授权、定位失败以 Result 联合或状态枚举单独返回（结果区分 Content / Empty / Partial / Error 这几种），并和「不伪造空成功」这类决策逐条对照
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 返回区分 Content / Empty / Partial / Error 的结果：修好后的数据层结果契约，Empty 只给有效查询成功返回空（出处：卡里修好并验证过）
