# 页面规格列了加载、失败、空态和问候语时，ViewModel 和页面要逐项有落点

审的是：代码
触发（任一种）：
- 读到：页面规格写了问候语按时间段显示、loading / failed（含重试）/ 空态（含创建按钮）面板，UiState 含 loading、failed 字段；写错的样子：ViewModel 只有数据字段和 loadData / refresh，没有 isLoading、isFailed；页面没有加载、失败面板和重试按钮，空态只有文字没有创建按钮，标题固定不随时间问候
适用范围：功能实现阶段按切片计划写页面、ViewModel 前，规格里有多状态页面描述时
做法：
- 按规格的状态清单逐项建立对照：问候语、loading / failed / empty 面板及其按钮、选中项字段与切换回调、列表过滤条件、数据集合的状态范围
- 写完逐项核对代码落点：ViewModel 有对应的状态字段，页面 build() 里有对应分支，面板上的按钮接了回调（重试调重新加载，创建按钮跳到创建页）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 重写页面加入问候语、加载/失败/空态面板和创建按钮，ViewModel 补 isLoading、isFailed 和选中项：修好的做法（出处：卡里修好并验证过）
