# 附近列表的 ViewModel 状态要分出定位不可用、失败、真空数据和有内容，空态文案只绑真空数据

审的是：代码
触发（任一种）：
- 写错的样子：ViewModel 对外只有 `isLoading` / `errorMessage` / `items` 几个字段，没有定位不可用的状态；页面用 `items.length === 0` 出「附近无内容」的空态
适用范围：目标端依赖定位的列表页的 ViewModel 状态和页面空态分支
做法：
- ViewModel 对外暴露的附近状态写成联合类型或枚举，至少区分定位不可用、加载失败、真空数据（有效查询成功返回空）和有内容
- 页面改为消费这个状态；「附近无内容」这类空态文案只绑定真空数据那一态，其他各态各有文案
