# 调用方注入的必填设置参数，接线前的占位初值取源端默认值常量，不取 @Preview 示例实参

审的是：代码
触发（任一种）：
- 读到：源 Composable 的设置参数没有默认值、由调用方（Activity 壳层）下传，同文件 @Preview 函数里另给了一组示例实参；写错的样子：目标页面的本地设置字段照搬 @Preview 的示例实参，注释写「接线前取 Android 默认」
适用范围：把壳层下传的显示设置迁到页面、设置存储接线前先写占位初值时
做法：
- 占位初值只取源端默认值常量（如数据库或设置类里的 DEFAULT_* 常量）或规格枚举表的默认项；注释写「默认」前对照默认值常量逐项核对
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 初值改成源端 DEFAULT_* 常量对应的枚举默认项：修复后首页初值与安卓默认一致（出处：卡里修好并验证过）
针对本应用要查的：
- 每个设置的源端默认值：源工程里设置表或设置数据类的默认值常量（DEFAULT_* 一类），以及规格的枚举表；按设置名找到常量，整型枚举按枚举类的声明顺序换成枚举项
未核实：卡里上机的目标 SDK 是 6.1.1(24)，本机核实用的是 API 23
