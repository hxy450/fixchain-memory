# 设置类字段直接读设置存储的实时值，页面不另存一套本地副本

审的是：代码
触发（任一种）：
- 读到：源端设置由 Activity 从设置存储读出、作为 Composable 参数下传；写错的样子：页面里有一整块本地设置字段，只在 aboutToAppear 取一次快照，或照抄兄弟页的字段块和判断式
适用范围：目标端页面改为各自读取设置存储时
做法：
- 在 build 里或订阅回调中读设置存储的实时值，不在页面里另存本地副本
- 复制兄弟页的字段块或判断式前，回到源端枚举与默认值核对一次
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 各页改在 build 内读设置存储的实时值：修复后设置变化能反映到页面（出处：卡里修好并验证过）
