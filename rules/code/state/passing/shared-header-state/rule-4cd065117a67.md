触发（任一种）：
- 读到：安卓共享页头绑定同时设名称、图标、按条目颜色的浅色背景和图标着色（PorterDuff.Mode.SRC_ATOP）；目标抽屉已用条目的 color 画图标背景和图标着色；写错的样子：页头回调或页头更新方法只传 `id`、`title`、`icon` 三个参数，同一数据对象里的 `color` 没进回调和主容器的 @State

- 回调和页头更新方法补上颜色参数，恢复时传条目的 color，统一的页头组件渲染颜色背景和图标着色：修好后的写法（出处：卡里修好并验证过）
