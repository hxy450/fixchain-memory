# 共享页头传递的视觉字段

agent 会看到什么：读到安卓共享页头绑定同时设名称、图标、按条目颜色的浅色背景和 setColorFilter 着色；产物里页头回调、页头更新方法和主容器的 @State 只带 id、title、icon，没带 color

## 规矩

- rule-4cd065117a67｜传递或恢复页头等共享视觉状态时带上安卓共享绑定的全部字段，含颜色｜读到：安卓共享页头绑定同时设名称、图标、按条目颜色的浅色背景和图标着色（PorterDuff.Mode.SRC_ATOP）；目标抽屉已用条目的 color 画图标背景和图标着色；写错：页头回调或页头更新方法只传 `id`、`title`、`icon` 三个参数，同一数据对象里的 `color` 没进回调和主容器的 @State
