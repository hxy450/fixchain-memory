# 从首页 push 的子流程成功后要发布刷新事件，不只 pop 回首页

审的是：代码
触发（任一种）：
- 读到：源端子流程（登录、保存记录、删除记录）成功后 EventBus.getDefault().post(刷新事件)，或 setResult 后 finish 让首页的 ActivityResult 回调重拉；写错的样子：目标子页保存或删除成功后直接 pop()，没有发布记录刷新事件
适用范围：流程闭环阶段新增从首页 push 进入、结果会影响首页数据的子流程时
做法：
- 在登录成功、记录保存成功、记录删除成功处发布对应的刷新事件（与首页订阅的是同一个事件名），再 pop 返回
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 记录保存和删除处发布刷新事件后，返回首页统计无需重进即更新：返修后的结果（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
