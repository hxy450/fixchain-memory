# 数据网关写完后，按 UI 数据模型逐字段核对每个字段都有来源

审的是：代码
触发（任一种）：
- 读到：源 `Fragment` 由宿主同步首页缓存的多日数据，UI 数据模型里有当日详情之外的列表字段（日期带、趋势、农历、小时等）；写错的样子：网关只给模型的一部分字段赋值（如只填当日详情），列表类字段保持空数组 `[]`，组件只剩空的列表区段
适用范围：实现运行时数据网关、构造组件的展示模型时
做法：
- 按 UI 数据模型逐字段列出：每个字段从哪个接口字段或缓存构造，逐个赋值；源端从首页缓存同步的数据，目标也从同一缓存构造
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 网关从首页缓存构造日期带、趋势和农历后，组件各区段都有数据：验证过的做法（出处：卡里修好并验证过）
针对本应用要查的：
- 每个模型字段的数据来源：源端这个 Fragment 的数据加载代码（接口调用、宿主同步过来的缓存），规格里的数据流说明；字段名对字段名列清单，没有来源的标出来补上
