# 多个 RecyclerView 绑定不同列表时，ArkUI 各分组绑定各自的数组，并实现逐级推进与回退

审的是：代码
触发（任一种）：
- 读到：布局里有几个 RecyclerView（热门、全量、当前层级），各自的 adapter 绑定 ViewModel 发布的不同列表；点击回调推进到下一层，返回回调退回上一层；写错的样子：ArkUI 里几个分组的 ForEach 渲染同一个数组；点击任一项即提交，没有逐级推进和返回退层
适用范围：源端一个页面里几个列表各自绑定不同数据、并有层级推进的选择页迁成 ArkUI 时
做法：
- 按源 adapter 的绑定逐个对应：每个 RecyclerView 对应一个 Grid / List，它的 ForEach 数据源绑定源端对应的那个列表（热门对热门、全量对全量、层级面板对当前层级的子列表），不复用同一数组
- 用状态变量记当前层级：点上层项显示它的子列表、点返回退回上一层，到末级才提交
针对本应用要查的：
- 每个列表控件绑定的是哪份数据、点击和返回怎样改层级：源工程的 Activity / Fragment 里给各 RecyclerView 设 adapter、observe 数据的地方，以及 ViewModel 里的点击和返回方法；列出「控件 → 数据」和「点击 → 下一层」的对应，逐项在 ArkUI 里写出
