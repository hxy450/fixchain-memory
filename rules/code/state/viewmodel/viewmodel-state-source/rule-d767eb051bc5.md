# 源 ViewModel 把单独持久化的一项和列表合并展示时，目标 load() 同时读它，删除和设置走它自己的路径

审的是：代码
触发（任一种）：
- 读到：源 `ViewModel` 的加载方法把单独持久化的一项（如定位得到的当前城市）和收藏列表一起交给 `LiveData` 展示，并为这一项另有删除、设为推送的方法；写错的样子：目标 VM 的 `load()` 只读收藏列表，这一项只在主动触发时才赋值；对它的删除沿用列表的 delete，设置只在列表里查找，查不到就抛错
适用范围：源端一个页面合并展示「单独持久化的一项 + 列表」并对两者分别操作，迁成 ArkTS ViewModel 和服务层时
做法：
- 目标 VM 的 load() 同时读取已持久化的这一项（服务层公开读取它的方法），和列表一起交给界面
- 这一行的删除接到它专用的清除方法；设为推送等操作在列表里查不到时回退到这一项（按 id 匹配），不沿用只查列表的通用路径
