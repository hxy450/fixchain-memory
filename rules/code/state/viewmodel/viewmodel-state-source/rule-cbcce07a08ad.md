# 首屏由本地登录态、XML 静态内容、配置开关和远端接口组成时，按来源分开加载，静态内容同步首帧渲染

审的是：代码
触发（任一种）：
- 读到：源 Fragment 的 onResume 同步读本地登录态；布局 XML 里提醒区默认 visible、带静态 android:text 和图标，之后才被远端请求覆盖；另有配置开关和远端接口；写错的样子：目标组件把账户态、开关、提醒和远端数据全放进一个快照，只留一个异步加载钩子（一个 `FWD-REF`）；提醒默认 []，空时只显示加载或「错误 + 重试」
适用范围：把由多个互相独立来源组成的安卓首屏转成 ArkUI 组件时
做法：
- 按来源分别建立加载入口或 forward-ref 并写明归属切片：本地登录态在组件出现时同步读，配置开关单独读，远端接口各自一个入口
- XML 里已有的文案和图标作为首帧默认值同步放进状态，远端结果到了再覆盖；空数组不退化成加载或错误态
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 先同步放入 XML 里的默认提醒，在远端请求之前独立加载账户态：修好的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 首帧要显示的静态默认内容：源工程该 Fragment 的布局 XML 里默认 visible 的区域及其 android:text、android:src / drawable 引用；把引用的字符串和图片资源迁成目标资源，作为状态初始值
