# 计数类状态请求失败时保留旧值并显示失败可重试，不在 catch 里置 0

审的是：代码
触发（任一种）：
- 读到：源 `ViewModel` 只在 success 回调里写 `LiveData`，失败走错误处理、不覆盖旧值；规格写「失败可见、可重试、不伪造数据」；写错的样子：目标 VM 的 `catch` 里把计数写成 `0`（如 `this.count = 0`），界面显示「0 天」一类的假数据
适用范围：迁移首页等处由网络请求得到的计数类状态时
做法：
- 请求失败时不改计数的旧值，另设加载、失败状态（如 `loadState`），界面在失败时显示可重试的入口
