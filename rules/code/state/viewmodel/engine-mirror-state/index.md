# 引擎持有的模式在界面上的镜像状态

agent 会看到什么：读到源端某个模式（如是否录像）只存在引擎里，冷启动时引擎按偏好恢复、Intent 入口也能设；产物里 VM 另设的 @State / @Trace 镜像状态的默认值，以及就绪回调里有没有从引擎回读

## 规矩

- rule-fa9be5fad5c2｜与引擎并行的 UI 镜像状态要在就绪回调里从引擎回读，覆盖冷启动恢复偏好的路径｜读到：源端模式（如是否录像）只存在引擎里，冷启动时引擎按偏好恢复模式，Intent 入口也能设模式；写错：目标另设的 UI 镜像状态默认 `false`，只在用户切换或意图入口写入，就绪回调里不从引擎回读
