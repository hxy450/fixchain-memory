# 与引擎并行的 UI 镜像状态要在就绪回调里从引擎回读，覆盖冷启动恢复偏好的路径

审的是：代码
触发（任一种）：
- 读到：源端模式（如是否录像）只存在引擎里，冷启动时引擎按偏好恢复模式，Intent 入口也能设模式；写错的样子：目标另设的 UI 镜像状态默认 `false`，只在用户切换或意图入口写入，就绪回调里不从引擎回读
适用范围：目标端在 VM 里另设与引擎并行的 UI 镜像状态时
做法：
- 在引擎就绪回调的开头从引擎回读实际模式写进镜像状态；用户切换、意图入口之外，冷启动恢复偏好的路径也经这一回读同步
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 就绪处理开头同步镜像状态：修好后冷启动按偏好恢复的模式与界面一致（出处：卡里修好并验证过）
