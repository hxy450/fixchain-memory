# 定义 VM 到 UI 的门面时，把源端回调会调的 UI 方法列入门面并在 sink 里调用

审的是：代码
触发（任一种）：
- 读到：源端回调实现类的 @Override 回调里调用 UI 类的方法（显示界面控件、刷新屏上图标）；写错的样子：VM 定义的 UI 门面接口里没有这些方法，对应的 sink 只处理别的事，下游接线者只能按缺项的接口接线
适用范围：目标端在 VM 和页面之间另设 UI 门面接口、由页面注入实现时
做法：
- 把源回调里会调用的 UI 方法逐个列进门面接口，并在对应的 sink 里调用它们
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 门面加入源端回调调用的显示控件方法，拍摄期 sink 改为调用它：修好后拍摄期间界面控件按源端显隐（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
