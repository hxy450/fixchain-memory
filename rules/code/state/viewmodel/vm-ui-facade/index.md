# VM 到 UI 的门面接口

agent 会看到什么：读到源端回调实现类的 @Override 回调里直接调 UI 类的方法（显示控件、刷新屏上图标）；产物里 VM 定义的 UI 门面 interface 和 sink 缺了这些方法，下游只能按缺项的接口接线

## 规矩

- rule-3c18a3d060a9｜定义 VM 到 UI 的门面时，把源端回调会调的 UI 方法列入门面并在 sink 里调用｜读到：源端回调实现类的 @Override 回调里调用 UI 类的方法（显示界面控件、刷新屏上图标）；写错：VM 定义的 UI 门面接口里没有这些方法，对应的 sink 只处理别的事，下游接线者只能按缺项的接口接线
