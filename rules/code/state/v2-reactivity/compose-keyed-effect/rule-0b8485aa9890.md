# LaunchedEffect(key1, key2) 驱动的弹窗调度，目标只在键值变化时重评

审的是：代码
触发（任一种）：
- 读到：LaunchedEffect(key1, key2) { … } 里按两个布尔键决定是否弹出启动弹窗；写错的样子：目标的调度函数在每次设置或其它状态变化（如 @Watch、aboutToAppear 之后的回调）时都重评，关闭后因无关状态更新再次弹出
适用范围：Compose LaunchedEffect 带 key 的副作用迁成 ArkTS 状态回调时
做法：
- 记录上次的键值，只有键值变化时才重评和弹出；无关状态更新时直接返回
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 弹窗调度按两个布尔键去重后，关闭后不再重复弹出：修法（出处：卡里修好并验证过）
