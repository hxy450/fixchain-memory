# 源端 ViewModel 会改的字段，ArkTS 模型不写 readonly，写成 @Trace 并去掉「从不修改」注释

审的是：代码
触发（任一种）：
- 读到：源端 ViewModel 有改这个字段的方法（增减、更新），界面也显示它；模型本身是不可变的 data class；写错的样子：ArkTS 模型类把它写成 readonly、类上没有 @ObservedV2，头注释写「静态 mock」「从不修改」「无有态需求」这类没核实的说法
适用范围：把源端不可变 data class 模型迁成 ArkUI V2 状态类、决定字段要不要可观察时
做法：
- 按源端 ViewModel 和界面对这个字段的读写来定：会被改的字段写成 @Trace 字段（类加 @ObservedV2），不写 readonly
- 删掉没核实过的「静态 mock / 从不修改」注释，不让它成为后续实现的契约
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- declare const ObservedV2: ClassDecorator；declare const Trace: PropertyDecorator：可变字段所在的类和字段用这两个装饰器（出处：鸿蒙 SDK 的 ets/component/common.d.ts，ObservedV2、Trace）
- 模型类加 @ObservedV2、数量字段改 @Trace 后修好：原来的 readonly 加「静态 mock」注释被后续实现当成不需观察的依据（出处：卡里修好并验证过）
针对本应用要查的：
- 这个字段在运行期会不会被改：源工程 ViewModel 的 .kt 文件里对这个字段的写入：copy(字段 = …)、增减或更新方法；有写入就是可变字段，要写成 @Trace；没有写入才能写 readonly
