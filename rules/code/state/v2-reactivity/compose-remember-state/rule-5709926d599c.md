# 源端 remember(key) 派生输入状态时，目标只在 key 真正变化时重置，同值赋值不动

审的是：代码
触发（任一种）：
- 读到：Compose 里名称输入用 `remember(…, 类型名) { mutableStateOf(…) }` 派生：只有类型名变化才重置名称；写错的样子：目标的类型选择 onClick 每次都给 @Local 名称字段重新赋值，没有比较新旧类型，重选当前类型也会清掉用户已改的名称
适用范围：把 Compose 里以 remember 的 key 驱动重置的输入状态迁成 ArkUI 事件处理时
做法：
- handler 先比较新旧值：if (newType === this.pickedType) return；只有类型改变才重置名称（编辑态恢复原名，新增态填类型名）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 类型选择遇同类型直接 return 后，重选同类型不再清掉已改的名称：卡里的修法（出处：卡里修好并验证过）

- 派生状态依赖哪些 key：源工程 Compose 代码里该状态的 remember(…) 括号内参数；逐个列出，目标 handler 里只在其中某个值变化时重置
