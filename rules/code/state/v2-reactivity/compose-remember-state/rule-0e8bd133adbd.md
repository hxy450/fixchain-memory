# 条件挂载对话框里的 remember 状态提到页级时，每次打开都重置并重跑初始化

审的是：代码
触发（任一种）：
- 读到：源端对话框 Composable 内用 remember 保存选择状态（每次打开都是新状态）；写错的样子：目标端选择状态放在页面级 @State / @Local，打开对话框时不清空上次的选择
- 读到：对话框只在 show 标志为真时组合，内部 remember { mutableStateListOf() } 声明选择集合，LaunchedEffect 做初始化（如全选）；写错的样子：目标把这些集合提为页级 @Local / @State，打开对话框的方法里不清空，初始化只在集合为空时执行
适用范围：源端在条件挂载的对话框（Compose 子组件）内部持有临时选择、目标端把这份状态提升到页面上时
做法：
- 每个打开对话框的方法里先把这些页级选择状态清空、重置为初值，源端 LaunchedEffect 里有初始化的再重跑一遍（如全选），等同于源端每次挂载重建
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 在打开对话框的方法里清空页级选择状态并重跑初始化（如重新全选）：修复后每次打开都是初始选择（出处：卡里修好并验证过）
