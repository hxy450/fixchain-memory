# 源端无键 remember 只在首次组合求值，目标按条目缓存一次，不写成每次重算的 @Computed

审的是：代码
触发（任一种）：
- 读到：val x by remember { derivedStateOf { … } } 没有 key，只在首次组合时求值（如是否显示小数位）；写错的样子：目标写成 @Computed getter 或每次调用都重新判断的方法，依赖变化（如倍率变化）时结果跟着变
适用范围：转写 Compose 的 remember / derivedStateOf 到 ArkTS 状态时
做法：
- 先看 remember 有没有 key：无键时按条目只求值一次并缓存（如在每个步骤条目首次出现时算出结果存成成员），之后不随依赖重算；有 key 时才在 key 变化时重算
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- @Computed：计算中用到的状态变量改变时，计算属性会重新计算：@Computed 不是一次性求值，不能对应无键 remember（出处：arkts-new-Computed.md，@Computed 装饰器的说明表（被执行的时机））
- 改为每个步骤条目只确定一次是否显示小数后，与源端一致：修法（出处：卡里修好并验证过）
未核实：卡里观察到的行为出自鸿蒙 SDK API 24（6.1.1），本机核实用 API 23
来源：1 张卡，1 个应用
