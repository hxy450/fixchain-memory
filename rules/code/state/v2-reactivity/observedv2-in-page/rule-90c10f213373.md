# @ComponentV2 子组件不用 onPageShow，也不退回手动 Refresh 按钮，改用响应式绑定

审的是：代码
触发（任一种）：
- 读到：页面组件是 @ComponentV2 子组件（不是 @Entry），数据来自会被异步加载或回调更新的 store；写错的样子：写了 onPageShow() 刷新（子组件里不触发），或删掉 onPageShow 后只留 aboutToAppear 和 Refresh 按钮上的手动 refresh() 拷贝
适用范围：非 @Entry 的 @ComponentV2 页面需要随共享数据更新时
做法：
- 不在子组件里依赖 onPageShow；改成持有 store 引用、在 build 里读 @Trace 字段的响应式绑定，不用手动 Refresh 按钮代替自动刷新
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onPageShow?(): void —— It works only for the custom components decorated by @Entry：@ComponentV2 子组件里写 onPageShow 不会被调用（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CustomComponent.onPageShow）
- @ObservedV2 类中 @Trace 属性变化会触发绑定的 UI 刷新：响应式绑定不需要页面级生命周期（出处：arkts-new-observedV2-and-trace.md，观察变化）
