# 错误特征或错误上报方法带对象参数时，目标保留对象参数，不用 boolean 或空对象占位

审的是：代码
触发（任一种）：
- 读到：源端错误特征方法接收对象参数（如当次录制档位），按它的多个字段和偏好判定后用 R.string 标签以「/」拼接；停录出错时以 getter 取当次对象上报；写错的样子：目标把参数简化成 boolean 并推字面量，或上报时用 `null as object`、无参 new 出的空对象占位；下游控制器不保存、不传递当次对象
适用范围：迁移错误特征、错误上报这类按对象字段拼提示文案的接口时
做法：
- 保留源签名的对象参数，按源谓词逐项判定，标签取对应的本地化资源并按源分隔符拼接
- 出错上报传当次对象；对象由下游控制器持有时，引擎 API 预留该参数，控制器在开始时保存、停止或中止时清除，并在异常分支传入
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 引擎方法改收对象参数并按源谓词拼接，控制器保存当次对象并传给停录异常上报后，提示文案与源一致：修法（出处：卡里修好并验证过）
