# 页面只存当前媒体 id 折算行的在播态时，同时存播放态并在事件和 aboutToAppear 里一起重算

审的是：代码
触发（任一种）：
- 读到：源列表项的次级按钮是否显示暂停、条目是否 `activated` 高亮，由「当前媒体匹配且服务在运行且状态为播放中」的谓词决定；写错的样子：页面只保存当前播放媒体的 id，行组件 `@Param` 的在播标志写成 id 相等；状态事件处理和 `aboutToAppear` 只重查 id，不查播放状态
适用范围：目标页面用页面级状态折算列表行、卡片的播放显示态，再传给共享行组件时
做法：
- 页面同时保存当前媒体 id 和是否在播（服务在运行且状态为播放中），或直接调用仓内已有的完整条件 helper；行的在播 = 同一媒体 && 正在播放
- 播放状态事件的处理函数和 aboutToAppear 里两者一起重算
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- @Param 与父组件传入的 @Local 或 @Param 数据源同步，数据源变化时把修改同步给子组件：在播标志由页面状态算出后经 @Param 传给行组件，页面状态重算行就会刷新（出处：arkts-new-param.md，@Param 的同步规则）
- 加上播放态并在事件与 aboutToAppear 里重算后，暂停后卡片回到播放按钮且无高亮：验证过的写法（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
