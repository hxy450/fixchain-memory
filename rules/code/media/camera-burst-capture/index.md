# 相机的多帧拍照（连拍、HDR、包围曝光）

agent 会看到什么：读到源端按 burst 类型（HDR、包围曝光、降噪、快速连拍）定一次快门的帧数、结果经整组回调交付；产物里拍照处 PhotoOutput.capture() 调了几次、保存请求的 images 列表放了几帧

## 规矩

- rule-92c0892aec5a｜多帧拍照模式下拍照图元按模式发起多帧并整组交付，不只调一次 capture｜读到：源端按 burst 类型（HDR、包围曝光、降噪、快速连拍）决定一次快门的帧数，结果经整组回调一次交付；写错：编排器已按模式算出帧数，拍照图元却只调一次 PhotoOutput.capture()；保存请求 images = [data] 单图入队，算出的连拍标志用 void 表达式丢弃
