# 源端单次 onPlayerError 迁到 AVPlayer 时，只由 on('error') 发错误事件

审的是：代码
触发（任一种）：
- 读到：源端只注册一个错误回调（ExoPlayer 的 `onPlayerError` 或 `setOnErrorListener`），出错时发一次错误事件弹一个对话框；写错的样子：目标在 `on('stateChange')` 收到 `'error'` 和 `on('error')` 里各自上报一次，一次失败弹出两个错误对话框
适用范围：把源端播放器的错误回调映射到 AVPlayer 的错误通道时
做法：
- 只在 `avPlayer.on('error', (err) => {...})` 里发错误事件（它带具体原因）；`stateChange` 收到 `'error'` 只做状态处理（reset 或 release），不再上报
- 同一实例只上报一次（记一个已上报标记），上报时作废在途装载
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- on(type: 'error', callback: ErrorCallback): void：AVPlayer 的错误事件（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.media.d.ts，AVPlayer.on('error')）
- on(type: 'stateChange', callback: OnAVPlayerStateChangeHandle): void：状态机切换事件，出错时也会切到 'error'（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.media.d.ts，AVPlayer.on('stateChange')）
- 错误事件仅用于提示；若 AVPlayerState 也切到 error，要用 reset() 或 release() 退出播放：两条通道同源：on('error') 负责提示，stateChange 的 error 负责状态处理（出处：arkts-apis-media-AVPlayer.md，on('error')）
- on(type: 'error', callback: ErrorCallback): void（AVRecorder）：同族接口：AVRecorder 的错误事件（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.media.d.ts，AVRecorder.on('error')）
未核实：ExoPlayer 一次错误只回调一次 onPlayerError，属于依赖库代码，本机没有源码，按卡写
