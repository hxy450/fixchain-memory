# 选图回填配置时，取消保留旧值、失败给可见错误，不留空 catch

审的是：代码
触发（任一种）：
- 写错的样子：选图结果回调或复制、写配置的步骤用 `catch (e) {}` 吞掉异常，页面只回到空态；或者用户取消（photoUris 为空）时把配置覆盖成空值
适用范围：复用现有选择页或服务、把选择结果回填到配置的代码
做法：
- photoUris 为空（用户取消）时直接返回，保留原配置值
- 复制或写配置失败时把错误写进界面可见的错误状态（如 errorMessage），catch 里不留空
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 取消保留原背景，失败写 errorMessage：卡里最终保留的取消和失败分支（出处：卡里修好并验证过）
