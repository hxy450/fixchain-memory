# Camera2 纳秒曝光时长迁到微秒的 ManualExposure 时，下发 /1000、读回 ×1000

审的是：代码
触发（任一种）：
- 读到：源端 CaptureRequest.SENSOR_EXPOSURE_TIME、CameraCharacteristics.SENSOR_INFO_EXPOSURE_TIME_RANGE（Long，纳秒），能力字段按 ns 存；写错的样子：setExposureDuration 下发时 /1000，而 getSupportedExposureDurationRange() 或 getExposureDuration() 的返回值原样写进 ns 字段，范围和显示差 1000 倍
适用范围：把 Camera2 手动快门迁到 HarmonyOS 相机会话的 ManualExposure（文档标 API 24+）时，能力探测、读回和下发三处
做法：
- 下发：setExposureDuration(ns / 1000)；读回：getSupportedExposureDurationRange() 两端和 getExposureDuration() 写进 ns 字段前都 ×1000，同一接口两侧用同一换算
- 最小检查：mock 范围 [10, 1000000] µs，能力字段应为 [1e4, 1e9] ns
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- getSupportedExposureDurationRange(): Array<number>，单位微秒：ManualExposureQuery 的能力范围（出处：arkts-apis-camera-ManualExposureQuery.md，getSupportedExposureDurationRange）
- getExposureDuration(): number，单位微秒：ManualExposure 读回当前曝光时长（出处：arkts-apis-camera-ManualExposure.md，getExposureDuration）
- setExposureDuration(exposureDuration: number): void，单位微秒；仅在 ExposureMode.EXPOSURE_MODE_MANUAL 下生效：ManualExposure 下发曝光时长（出处：arkts-apis-camera-ManualExposure.md，setExposureDuration）
- SENSOR_EXPOSURE_TIME、SENSOR_INFO_EXPOSURE_TIME_RANGE 的 Units: Nanoseconds：源端是纳秒（出处：android.hardware.camera2.CaptureRequest#SENSOR_EXPOSURE_TIME；android.hardware.camera2.CameraCharacteristics#SENSOR_INFO_EXPOSURE_TIME_RANGE）
- 能力范围 ×1000、读回曝光时长 µs×1000，下发 /1000：修好的换算（出处：卡里修好并验证过）
未核实：本机 SDK 是 API 23，没有 ManualExposure 的声明，签名和单位按文档副本核；文档写 setExposureDuration 只在 EXPOSURE_MODE_MANUAL 下生效，卡里没提这一前置条件
