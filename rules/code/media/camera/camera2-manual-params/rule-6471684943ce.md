# Camera2 曝光补偿档位迁到 setExposureBias 时按步长换成 EV，读回范围折回档位

审的是：代码
触发（任一种）：
- 读到：源端 CONTROL_AE_COMPENSATION_RANGE（Range<Integer> 档位）和 CONTROL_AE_COMPENSATION_STEP（Rational 步长），能力字段 min/max 是档位；写错的样子：getExposureBiasRange() 的 EV 值原样当档位存，setExposureBias(档位) 直接传档位
适用范围：把 Camera2 曝光补偿迁到 HarmonyOS 相机会话的 AutoExposure 时，能力探测和下发两处
做法：
- 能力：step = getExposureBiasStep()，min 档 = Math.ceil(range[0] / step)，max 档 = Math.floor(range[1] / step)
- 下发：setExposureBias(档位 * step)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- setExposureBias(exposureBias: number): void：AutoExposure 下发曝光补偿，参数是 EV 值（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，camera.AutoExposure.setExposureBias；arkts-apis-camera-AutoExposure.md，setExposureBias）
- getExposureBiasRange(): Array<number>：AutoExposureQuery 查曝光补偿范围（EV）（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，camera.AutoExposureQuery.getExposureBiasRange）
- getExposureBiasStep(): number：ManualExposureQuery 查曝光偏置步长（文档标 API 24+）（出处：arkts-apis-camera-ManualExposureQuery.md，getExposureBiasStep）
- CONTROL_AE_COMPENSATION_STEP 是档位的单位：步长 1/2 时档位 -2 即 -1 EV：源端档位 × 步长 = EV（出处：android.hardware.camera2.CameraCharacteristics#CONTROL_AE_COMPENSATION_STEP）
- 按 getExposureBiasStep 取 ceil/floor(bias/step)，以 档位*step 下发：修好的换算（出处：卡里修好并验证过）
未核实：本机 SDK 是 API 23，没有 getExposureBiasStep 的声明，按文档副本核
