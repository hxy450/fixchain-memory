# 接线时发现桥接只有单帧且无完成回调，登记 FWD-REF 回编排器补契约，不在保存侧单图入队

审的是：代码
触发（任一种）：
- 读到：源端或目标端的应用接口已声明接收 ArrayBuffer[] 的整组结果回调，和「所有图片回调返回后调用」的完成回调；写错的样子：接线时保存侧把多帧模式按单图入队（images = [data]，注释写多帧后缀却只给一张）、失败只弹 toast，没有登记 FWD-REF
适用范围：接线、收尾的写者读到上游桥接只有单帧拍照、无完成回调时
做法：
- 登记 FWD-REF 指回编排器，要求补上完成回调和整组结果通道；保存侧不按单图入队凑合
