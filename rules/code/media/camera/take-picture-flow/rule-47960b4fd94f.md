# 移植构造回调对象的拍照函数时，逐个给回调列出目标端落点，桥接契约带上它们要的查询和事件

审的是：代码
触发（任一种）：
- 读到：源函数本体里构造回调对象（含多个 on… 回调，如补光开启、完成），在函数尾交给 takePicture(…) 之类的拍照调用；写错的样子：目标函数只剩阶段置位和一句 takePicture() 调用，源回调对象里的分支在目标端没有落点；桥接接口里没有这些回调要用的查询或事件成员
适用范围：把源端在函数体内构造回调对象再交给拍照调用的函数，移植成目标编排器和桥接契约时
做法：
- 读完源函数本体，逐个列出它构造的回调对象里每个回调在目标端的落点（由谁实现、何时调用）
- 桥接契约接口加上这些回调所需的查询或事件成员（如是否需要补光的查询、补光触发），页面接线按契约逐个绑定
