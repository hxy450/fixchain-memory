# 目标端缺 DNG 封装时，RAW 保存在建媒体资产前返回失败，RAW 能力位置 false

审的是：代码
触发（任一种）：
- 读到：源端用 DngCreator 把 RAW_SENSOR 数据写成 DNG；规格把 DngCreator 映射为「RAW 流 + DNG 封装自实现」并列为平台缺口候选；写错的样子：把传感器原始缓冲直接写成 .dng / image/dng 媒体资产并返回成功；能力探测因有 DNG profile 就上报支持 RAW，图片尺寸列表混进 DNG 尺寸
适用范围：目标端没有 DNG 头和元数据封装、而源端支持 RAW 保存时的保存管线和能力探测
做法：
- 封装层缺失时，RAW 保存在创建媒体资产前返回 false 并提示不支持；能力探测同步把 RAW 能力位置 false，图片尺寸列表只列 JPEG photoProfiles
- FWD-REF 或 PD 候选登记不能代替失败路径；补一条「伪 RAW 成功」的回归测试
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- DngCreator 提供把原始像素数据写成 DNG 文件的函数：源端 DNG 由框架封装头和元数据，原始缓冲本身不是 DNG（出处：android.hardware.camera2.DngCreator）
- RAW 能力位恒置 false、尺寸只收 JPEG，RAW 保存在建资产前返回 false 并提示不支持：修好后的写法（RAW / DNG 仍是缺口，只是明确拒绝）（出处：卡里修好并验证过）
