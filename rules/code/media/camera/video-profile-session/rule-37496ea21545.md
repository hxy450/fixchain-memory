# 录像会话的预览和视频档取 NORMAL_VIDEO 能力面按尺寸加帧率匹配，并启动 videoOutput

审的是：代码
触发（任一种）：
- 读到：源端录像按尺寸和帧率选档（视频档含 videoFrameRate 和捕获率），MediaRecorder 的 surface 进会话；写错的样子：预览档沿用 NORMAL_PHOTO 能力面；视频档只比尺寸、没匹配就回落 profiles[0]、不看 frameRateRange；commitConfig 后只有 session.start()，没有 videoOutput.start()
适用范围：源端录像迁成 CameraKit VideoSession 加 AVRecorder 时
做法：
- previewProfiles、videoProfiles 都取自 getSupportedOutputCapability(camera, camera.SceneMode.NORMAL_VIDEO)，按尺寸加 frameRateRange 匹配；没匹配返回失败，不回落首项
- createVideoOutput(videoProfile, await avRecorder.getInputSurface()) 加进会话；commitConfig、session.start() 之后 videoOutput.setFrameRate(min, max)、await videoOutput.start()，再 avRecorder.start()
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- SceneMode.NORMAL_PHOTO = 1、SceneMode.NORMAL_VIDEO = 2：拍照与录像两个能力面（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，SceneMode）
- readonly frameRateRange: FrameRateRange（min、max，单位 fps）：VideoProfile 的帧率范围，选档时和源端帧率比（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，VideoProfile.frameRateRange）
- createVideoOutput(profile: VideoProfile, surfaceId: string): VideoOutput：用 AVRecorder 的输入 surface 建视频输出（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，CameraManager.createVideoOutput）
- getInputSurface(): Promise<string>：AVRecorder 的输入 surfaceId（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.media.d.ts，AVRecorder.getInputSurface）
- setFrameRate(minFps: number, maxFps: number): void：VideoOutput 设帧率范围（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，VideoOutput.setFrameRate）
- start(): Promise<void>：VideoOutput 启动录像输出流；会话未配置时报 7400103（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，VideoOutput.start）
- 先 videoOutput.start() 启动录像输出流，再 avRecorder.start() 开始录像：两者的先后顺序（出处：camera-recording.md，开发步骤）
- NORMAL_VIDEO 的 preview/video 档、按帧率范围匹配且无匹配返回 null，setFrameRate 后 await videoOut.start()：修复后的录像会话（出处：卡里修好并验证过）
未核实：卡里的行为出自目标 SDK 6.1.1(24)，声明按本机 API 23 核实
