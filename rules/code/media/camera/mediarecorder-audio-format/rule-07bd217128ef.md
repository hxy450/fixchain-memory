# 源端音源 CAMCORDER 映射成 AUDIO_SOURCE_TYPE_CAMCORDER，不回落成 MIC

审的是：代码
触发（任一种）：
- 读到：源端 setAudioSource(MediaRecorder.AudioSource.CAMCORDER)，或规格的音源映射写「默认/camcorder → CAMCORDER」；写错的样子：camcorder 和默认值被映射成 AudioSourceType.AUDIO_SOURCE_TYPE_MIC，文件头注释写「CAMCORDER 无对应枚举」
适用范围：安卓 MediaRecorder 录像迁到 AVRecorder 时的音源映射（AUDIO_SOURCE_TYPE_CAMCORDER 按声明 @since 12）
做法：
- AVRecorderConfig 写 audioSourceType: media.AudioSourceType.AUDIO_SOURCE_TYPE_CAMCORDER（值 13）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- AUDIO_SOURCE_TYPE_CAMCORDER = 13，注释 Audio source in camera recording scenarios，@since 12：录像场景的音源，对应安卓 CAMCORDER（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.media.d.ts，media.AudioSourceType.AUDIO_SOURCE_TYPE_CAMCORDER）
- audioSourceType?: AudioSourceType：AVRecorderConfig 上设音源的字段，录音时必填（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.media.d.ts，media.AVRecorderConfig.audioSourceType）
- MediaRecorder.AudioSource.CAMCORDER = 5：Microphone audio source tuned for video recording：源端常量的含义，和目标的 CAMCORDER 是同一种场景（出处：android.media.MediaRecorder.AudioSource#CAMCORDER）
- CAMCORDER 映射为 13 后录制正常：修好的映射（出处：卡里修好并验证过）
未核实：卡的环境是 API 24，声明按本机 API 23 核实
