# 源端读录音振幅和捕获结果 ISO/曝光时，目标接 AVRecorder 和 PhotoSession 的读接口

审的是：代码
触发（任一种）：
- 读到：源端用 MediaRecorder.getMaxAmplitude() 采样录音振幅画振幅表；写错的样子：目标振幅源保留基类默认（恒 0），注释写「AVRecorder 无 getMaxAmplitude 等价 API」
- 读到：源端从 Camera2 的 capture result（CaptureResult）读当前 ISO 和曝光时间显示在取景覆盖层；写错的样子：目标 ISO / 曝光行为空，捕获结果数据源保留基类默认，注释写「photo session 无 capture-result 元数据回调」；没有调用 PhotoSession 的读接口
适用范围：取景覆盖层或录像界面要显示实时 ISO、曝光时间、录音振幅，目标用 Camera Kit 的 PhotoSession 和 Media Kit 的 AVRecorder 时
做法：
- 录像引擎里用 avRecorder.getAudioCapturerMaxAmplitude() 采样，单飞（上一次 Promise 没返回不再发起），结果交给振幅源
- 相机控制器补读 ISO 和曝光的 getter：photoSession.getIso()、photoSession.getExposureDuration()，交给覆盖层的捕获结果数据源
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- getAudioCapturerMaxAmplitude(): Promise<number>；返回值是从上次获取到本次调用之间的最大振幅：和安卓 getMaxAmplitude 同样按「自上次调用以来」取值（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.media.d.ts，AVRecorder.getAudioCapturerMaxAmplitude）
- getMaxAmplitude()：Returns the maximum absolute amplitude that was sampled since the last call：源端振幅的语义（出处：android.media.MediaRecorder#getMaxAmplitude）
- getIso(): number（ManualIso，API version 24 起）：当前 ISO 值（出处：arkts-apis-camera-ManualIso.md，getIso）
- getExposureDuration(): number，单位微秒（ManualExposure，API version 24 起）：当前曝光时长；安卓 CaptureResult.SENSOR_EXPOSURE_TIME 的单位是纳秒，两边单位不同（出处：arkts-apis-camera-ManualExposure.md，getExposureDuration；android.hardware.camera2.CaptureResult#SENSOR_EXPOSURE_TIME）
- 控制器补 getIso / getExposureDuration 的 getter、录像引擎按 getAudioCapturerMaxAmplitude 单飞采样后，ISO / 曝光行和振幅表有值：修好后的写法（出处：卡里修好并验证过）
未核实：本机 SDK 是 API 23，没有 ManualIso / ManualExposure 的声明，getIso、getExposureDuration 按文档副本写；卡里环境是 6.1.1(24)
