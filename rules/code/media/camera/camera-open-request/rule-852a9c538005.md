# 入口标志归另一切片时，引擎回调留可注入的消费 hook 并登记 FWD-REF，不写常量 false

审的是：代码
触发（任一种）：
- 读到：源端相机打开回调里读取一次性标志，作为参数传给后续的相机设置方法；派工或骨架说这个标志通道归另一个切片，要用 FWD-REF / HANDOFF 交接；写错的样子：引擎回调里把源端读取写成常量 `= false` 并注释“通道归别的切片”，没有注入点，也没登记 FWD-REF 或 HANDOFF，后面的延时拍照分支成了死分支
适用范围：跨切片分工时，源端读取点落在本切片的引擎回调里、而标志本身归另一切片实现时
做法：
- 在引擎回调原本读取标志的位置留一个可注入的读取 / 消费 hook（未注入时返回 false），与同批其他 hook 写法一致，并登记 FWD-REF 或 HANDOFF 交给标志所属切片
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 引擎回调里写成常量 false 后，按对焦模式延时拍照的分支始终不触发；改成在打开相机、预览启动后经注入的消费入口读取后恢复：返修后的写法（出处：卡里修好并验证过）
