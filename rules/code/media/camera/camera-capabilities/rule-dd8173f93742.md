# 源端读 SENSOR_ORIENTATION 时，目标读 cameraOrientation，不写死角度

审的是：代码
触发（任一种）：
- 读到：源端用 `CameraCharacteristics.SENSOR_ORIENTATION` 的值参与预览或拍照的旋转计算；写错的样子：目标端按前后摄写死 90 / 270，或注释写鸿蒙没有传感器角度属性；没有读 `cameraOrientation`
适用范围：把安卓相机的传感器朝向迁到鸿蒙 CameraKit（@ohos.multimedia.camera）时
做法：
- 从打开的那个 `camera.CameraDevice` 读 `device.cameraOrientation`（0–360 度，不随屏幕旋转），代替源端 SENSOR_ORIENTATION 进旋转公式
- 下「目标平台没有某属性」的结论前，读完整个 `interface CameraDevice` 的声明，截断的片段不能作否定依据
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- readonly cameraOrientation: number：相机安装角度，不随屏幕旋转，取值 0–360 度（声明 @since 12）（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，CameraDevice.cameraOrientation）
- SENSOR_ORIENTATION：输出图像在设备自然方向下转正需要的顺时针角度：源端这个值和目标端 cameraOrientation 对应（出处：android.hardware.camera2.CameraCharacteristics#SENSOR_ORIENTATION）
未核实：卡里的行为出自鸿蒙 SDK API 24（6.1.1），本机按 API 23 核对声明
