# 源端按硬件等级推出录像中拍照能力位时，目标按 NORMAL_VIDEO 能力和 canAddOutput 判定

审的是：代码
触发（任一种）：
- 读到：源端按硬件等级（如 `LIMITED`）推出录像中拍照的能力位，录像中快照按这个能力位门控；写错的样子：目标把这个能力位恒置 true；或录像会话里已 removeOutput 掉 photoOutput，快照门控和按钮仍按静态能力位为真
适用范围：录像中拍照（录像会话里并发照片输出）的能力判定和门控
做法：
- 能力位按真实可加输出判定：getSupportedOutputCapability(camera, SceneMode.NORMAL_VIDEO).photoProfiles 非空，且录像会话配置时 session.canAddOutput(photoOutput) 返回 true，才为真
- canAddOutput 接受时加并发快照 PhotoOutput，失败就释放它、照常录像；快照的门控和按钮查询会话里实际挂上的 PhotoOutput
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- canAddOutput(cameraOutput: CameraOutput): boolean：Session 上判断输出能否加入，只在 addInput 之后、commitConfig 之前有效（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，Session.canAddOutput）
- readonly photoProfiles: Array<Profile>：CameraOutputCapability 里的拍照档；在 NORMAL_VIDEO 下非空才可能录像中拍照（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，CameraOutputCapability.photoProfiles）
- INFO_SUPPORTED_HARDWARE_LEVEL_LIMITED = 0：源端硬件等级常量，只是源端推能力位的依据，目标不照搬（出处：android.hardware.camera2.CameraMetadata#INFO_SUPPORTED_HARDWARE_LEVEL_LIMITED）
- canAddOutput 接受时加并发快照 PhotoOutput、失败释放仍录像，门控改按会话实际输出：修复后的能力判定（出处：卡里修好并验证过）
未核实：卡里的行为出自目标 SDK 6.1.1(24)，声明按本机 API 23 核实
