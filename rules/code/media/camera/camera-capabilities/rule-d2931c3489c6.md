# 白平衡预设按 WhiteBalanceMode 逐个查询后暴露，解锁时恢复所选模式和色温

审的是：代码
触发（任一种）：
- 读到：源端白平衡可选值来自 CONTROL_AWB_AVAILABLE_MODES（auto、cloudy-daylight、incandescent、fluorescent、daylight 等），解锁白平衡时回到用户所选的模式；写错的样子：白平衡值只暴露 ['auto','manual']；解除白平衡锁时固定 setWhiteBalanceMode(WhiteBalanceMode.AUTO)
适用范围：迁移相机白平衡设置和白平衡锁时（声明 @since 20）
做法：
- 按 WhiteBalanceMode 逐个 isWhiteBalanceModeSupported(mode)，只把支持的预设暴露出来
- 解锁和会话重建时用 setWhiteBalanceMode(<所选模式>) 恢复用户所选的预设，手动模式再 setWhiteBalance(<所选色温>)，不固定回 AUTO
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- setWhiteBalanceMode(mode: WhiteBalanceMode): void；setWhiteBalance(whiteBalance: number): void：设白平衡模式和手动色温（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，WhiteBalance.setWhiteBalanceMode、WhiteBalance.setWhiteBalance）
- WhiteBalanceMode：AUTO = 0、CLOUDY = 1、INCANDESCENT = 2、FLUORESCENT = 3、DAYLIGHT = 4、MANUAL = 5、LOCKED = 6：逐个查询的候选（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，WhiteBalanceMode）
- 白平衡值按会话支持列出 auto / cloudy-daylight / incandescent / fluorescent / daylight / manual，解锁和会话重建时恢复所选预设与色温：修好后的写法（出处：卡里修好并验证过）
未核实：卡里观察到的行为出自鸿蒙 SDK 6.1.1(24)，本机声明按 API 23 核实
