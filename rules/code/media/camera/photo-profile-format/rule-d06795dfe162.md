# 拍照字节只按 JPEG 组件取时，为非 JPEG profile 接上 photoAssetAvailable 通路

审的是：代码
触发（任一种）：
- 读到：拍照回调 on('photoAvailable') 里用 photo.main.getComponent(image.ComponentType.JPEG) 取字节；写错的样子：选出的拍照 profile 可能是 CAMERA_FORMAT_RGBA_8888，代码却只有 getComponent(ComponentType.JPEG) 这一条取数据通路，没有非 JPEG 的处理
适用范围：鸿蒙相机实现里拍照 profile 接受非 JPEG 格式（如 RGBA_8888）时的拍照结果处理
做法：
- 非 JPEG profile 时注册 photoOutput.on('photoAssetAvailable', (err, photoAsset: photoAccessHelper.PhotoAsset) => { … }) 走资产通路取照片；JPEG profile 仍可用 on('photoAvailable') 加 getComponent(image.ComponentType.JPEG)
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- on(type: 'photoAssetAvailable', callback: AsyncCallback<photoAccessHelper.PhotoAsset>): void：PhotoOutput 的资产回调，拿到的是媒体库资产而不是 JPEG 组件（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，PhotoOutput.on('photoAssetAvailable')）
- on(type: 'photoAvailable', callback: AsyncCallback<Photo>): void；Photo.main: image.Image：PhotoOutput 的照片回调，字节在 main 里（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，PhotoOutput.on('photoAvailable')、Photo.main）
- getComponent(componentType: ComponentType): Promise<Component>；ComponentType.JPEG = 4：按组件类型取图像数据，JPEG 组件只适用于 JPEG 格式的输出（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.image.d.ts，Image.getComponent、ComponentType.JPEG）
未核实：卡里的环境是 HarmonyOS SDK 6.1.1(24)，签名按本机 API 23 的声明核实
