# 选拍照 profile 时不把 JPEG 当打开相机的硬门槛，JPEG 优先、RGBA_8888 兜底

审的是：代码
触发（任一种）：
- 读到：getSupportedOutputCapability 返回的 capability.photoProfiles；拍照字节通路按 getComponent(image.ComponentType.JPEG) 取数据；写错的样子：photoProfiles.filter(...) 只留 CAMERA_FORMAT_JPEG，没有 JPEG 时在打开相机、能力探测会话或建会话时 throw（如 'no JPEG photo profile'）
适用范围：鸿蒙相机实现按 photoProfiles 选拍照输出、建能力探测会话时，目标环境可能是只报告 RGBA_8888 拍照 profile 的模拟器
做法：
- 选 profile 时接受 camera.CameraFormat.CAMERA_FORMAT_JPEG 和 CAMERA_FORMAT_RGBA_8888 两种，JPEG 优先，没有 JPEG 取 RGBA_8888；两种都没有才报 'no supported photo profile'
- 无法上设备核对 photoProfiles 时，保留原有的格式无关选择（按尺寸匹配、无匹配回落 profiles[0]），不把拍照字节格式的假设写成打开相机或探测会话的失败
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- CAMERA_FORMAT_RGBA_8888 = 3、CAMERA_FORMAT_YUV_420_SP = 1003、CAMERA_FORMAT_JPEG = 2000、CAMERA_FORMAT_YCRCB_P010 = 2002、CAMERA_FORMAT_HEIC = 2003：camera.CameraFormat 的取值，拍照 profile 不限于 JPEG（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，CameraFormat）
- readonly format: CameraFormat；readonly size: Size：Profile 的格式和尺寸，按 format 判断、按 size 匹配（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，Profile.format、Profile.size）
- getSupportedOutputCapability(camera: CameraDevice, mode: SceneMode): CameraOutputCapability：取某相机在某场景下的输出能力，photoProfiles 在返回值里（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.camera.d.ts，CameraManager.getSupportedOutputCapability）
- 只报 RGBA 拍照 profile 的模拟器上，加了 JPEG 过滤后相机打开即探测失败、会话被释放、预览黑屏；改成 JPEG|RGBA_8888、JPEG 优先后恢复：收窄格式过滤的后果和修好后的写法（出处：卡里修好并验证过）
未核实：卡里的环境是 HarmonyOS SDK 6.1.1(24)，取值按本机 API 23 的声明核实
