# 源共享组件内聚选图上传回填链时，ArkTS 组件内建这条链，宿主回调写成可选

审的是：代码
触发（任一种）：
- 读到：源 @Composable 共享组件的参数里带账号对象，组件内的选图 launcher 回调里完成选图、上传、上传中状态和把图片回填进文本；写错的样子：ArkTS 共享组件去掉了账号参数，组件里只剩 picker，选到的图经必传的 @Event 回调抛给宿主页去上传
适用范围：把组件内聚了副作用链（选图、上传、回填、上传中状态）的 Compose 共享组件迁成多个宿主页复用的 ArkUI 组件时
做法：
- 共享组件里保留完整的链：选图 → 上传 → 上传中状态 → 把结果回填进文本；宿主页只传组件需要的入参（如账号）
- 要给宿主留接管口时写成可选 @Param（如 @Param <回调>: ((…) => void) | undefined = undefined），组件内判断为 undefined 就走内置链；宿主中间层只做可选透传
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- @Param 允许本地初始化，若不在本地初始化，则需要和 @Require 一起使用、必须从外部传入：可选的 @Param 要本地初始化（如 = undefined）（出处：arkts-new-param.md，装饰器说明）
- @Event 没有初始化时，会自动生成一个空的函数作为默认回调：用 @Event 时宿主不传也有一个空回调，组件分不出宿主传没传，判断不了该不该走内置链（出处：arkts-new-event.md，概述）
