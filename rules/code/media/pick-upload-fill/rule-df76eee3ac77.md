# 宿主页自建图片上传时，保留源端的匿名门控、选图时文本快照和失败提示原文

审的是：代码
触发（任一种）：
- 读到：源组件的选图回调里：账号是匿名时不上传；回填追加到选图那一刻的文本上；失败分支各自 Toast 一句原文；写错的样子：目标页的上传回调不判断匿名就上传；回填追加到上传完成时的当前文本状态上；两种失败都弹同一个通用 $r('app.string.…') 文案
适用范围：宿主页或其他调用方自己写一条图片上传链、替代源组件里的内置上传时
做法：
- 上传前照源端判断账号是否匿名，匿名时不上传
- 选图时取一份文本快照，上传完成后把图片追加到这份快照上再回写
- 各失败分支照源端的提示原文 Toast，不合并成一个通用文案
