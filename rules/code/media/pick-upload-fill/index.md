# 选图后上传并回填文本的链路

agent 会看到什么：读到源 @Composable 共享组件带账号参数、rememberLauncherForActivityResult 的选图回调里完成匿名判断、上传、上传中状态、按选图时的文本回填和各自的失败 Toast；产物里共享组件只剩 PhotoViewPicker、选到的图经必传 @Event 抛给宿主页，或宿主页的上传回调少了这些步骤

## 规矩

- rule-ceb8e16349fa｜源共享组件内聚选图上传回填链时，ArkTS 组件内建这条链，宿主回调写成可选｜读到：源 @Composable 共享组件的参数里带账号对象，组件内的选图 launcher 回调里完成选图、上传、上传中状态和把图片回填进文本；写错：ArkTS 共享组件去掉了账号参数，组件里只剩 picker，选到的图经必传的 @Event 回调抛给宿主页去上传
- rule-df76eee3ac77｜宿主页自建图片上传时，保留源端的匿名门控、选图时文本快照和失败提示原文｜读到：源组件的选图回调里：账号是匿名时不上传；回填追加到选图那一刻的文本上；失败分支各自 Toast 一句原文；写错：目标页的上传回调不判断匿名就上传；回填追加到上传完成时的当前文本状态上；两种失败都弹同一个通用 $r('app.string.…') 文案
