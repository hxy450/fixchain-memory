# Kotlin 先 mapNotNull 再 groupBy、maxWith 的管道，ArkTS 保持先过滤后选优

审的是：代码
触发（任一种）：
- 读到：源码里 `mapNotNull { … }` 或 `filter { … }` 剔除不完整的项，之后 `groupBy { … }` 分组，再用 `maxWith` 或自定义的选优函数挑最佳；写错的样子：ArkTS 里先在全部候选上比较出最佳（循环取最大下标或 `reduce`），之后才做完整性检查，最佳那项不完整就把整组丢弃
适用范围：把 Kotlin 集合管道（过滤 → 分组 → 选优）改写成 ArkTS 的数组操作或循环时
做法：
- 按源码顺序写：先 `list.filter(x => 完整(x))`（条件照搬 mapNotNull/filter 里的判断），再按源码的键分组，最后在每组剩下的候选里选最佳
- 完整性判断不挪到选优之后，也不只对选出的那一项做判断
