# 仓库聚合方法按规格的状态集合取数据，不用日期比较近似、不另截条数

审的是：代码
触发（任一种）：
- 读到：规格写聚合结果按状态集合取（如「即将开始与进行中」），待办按所属项分组成 Map；写错的样子：仓库聚合方法用 startDate >= today 一类日期比较过滤再 slice(0, N)，进行中的被排除；待办汇总全部而不按所属项分组
适用范围：实现仓库或 ViewModel 的聚合方法，规格写了数据集合的状态范围时
做法：
- 按规格列出的状态值过滤（status 属于规格写的那几种），按规格写的字段排序，不用日期比较近似状态，不另加 slice 截断
- 规格写按所属项取的数据，按项分组返回

- 聚合改为按两种活跃状态取并按开始日期排序：修好的做法（出处：卡里修好并验证过）
