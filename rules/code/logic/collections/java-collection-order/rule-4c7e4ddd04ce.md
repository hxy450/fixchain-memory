# 多选导出时按源集合的勾选顺序导出，不用展示列表 filter 代替

审的是：代码
触发（任一种）：
- 读到：源码用 mutableStateListOf 维护选中集合，勾选时 add、取消时 remove，导出时 selected.forEach 依次 put；写错的样子：目标导出用 this.list.filter(item => isSelected(item.id)) 取选中项，导出顺序变成列表顺序
适用范围：多选后批量导出、分享、删除等依赖选择顺序的操作
做法：
- 保留并按源端那份选中集合的插入（勾选）顺序取数据导出；展示列表只用来查找对象，不决定顺序
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 改为按勾选顺序取选中项后，导出顺序与源端一致：修复后的写法（出处：卡里修好并验证过）
