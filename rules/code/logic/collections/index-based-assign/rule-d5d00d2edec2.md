# 源端按位置给列表项赋键时，目标保持位置映射，按键查找失败回退同一下标

审的是：代码
触发（任一种）：
- 读到：源端按下标循环 `indices`，把常量数组第 i 项赋给列表第 i 项的字段（按位置赋值）；写错的样子：目标改成用 `find(` 按列表项某字段 `===` 键来查找，服务端缺这个字段时全部落空、显示占位
适用范围：移植「按位置赋值」的源逻辑，数据来自服务端、字段不一定返回时
做法：
- 保持位置映射；或者按键查找失败时回退同一下标：find(...) ?? source[index]
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 按键查找后加 ?? source[index] 回退：修复后的写法，与源端位置映射一致（出处：卡里修好并验证过）
