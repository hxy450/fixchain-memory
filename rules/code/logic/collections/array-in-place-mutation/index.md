# 按引用原地改写的数组参数

agent 会看到什么：读到源码把调用方传入的 String[] 等数组按引用原地改写（arr[i] = …，改动写回调用方持有的数组）；产物里调用时传 arr.slice() 副本，或服务另存一份副本

## 规矩

- rule-459bc71ca5fe｜源码经数组引用原地改调用方数据时，目标不要传 .slice() 副本切断这个副作用｜读到：源码把调用方传入的 String[] 等数组按引用原地改写（如 arr[i] = 替换后的值，写回调用方持有的数组）；写错：目标调用时传 arr.slice() 副本，或服务另存一份副本，改写不再回到调用方的数组
- rule-7f4bc351d78c｜源端把同一个 List 引用交给另一对象再就地 remove 时，目标保持同一引用，不用 slice 拷贝｜读到：源端把一个 getter 返回的 List 直接传给另一个对象的 setter（没有 new ArrayList<>(...)），后续任务对这个 List 调 contains / remove 就地修改；写错：目标写成 .slice() 或 [...list] 拷贝后再赋值，或对拷贝出来的副本 splice，源端共享引用、就地删除的数据流被切断
