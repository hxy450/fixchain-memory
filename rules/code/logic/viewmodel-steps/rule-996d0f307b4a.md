# 源端按 id 在仓库层查出的派生值，目标也按 id 查，不改成调用方传入或写死空串

审的是：代码
触发（任一种）：
- 读到：源端用 id 到仓库层（Repository）查出派生值，如按 id 取显示标题作快捷入口 label；写错的样子：目标深链分支把该值写死成 `''`，或改成由调用方传入；风险里承认值为空，却没登记占位
适用范围：源端某个展示值由 id 在数据层派生、目标在服务层或深链路径上要用到它时
做法：
- 目标在服务里同样按 id 到仓库层取派生值（id>0 时查仓库取显示标题），深链分支也走这条，不由调用方传
- 数据层还没就绪时登记 FWD-REF 占位，不只写进风险
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 改为 id>0 时由仓库取对象再取显示标题后，深链打开时 label 不再为空：修法（出处：卡里修好并验证过）
针对本应用要查的：
- 派生值在源端怎么算：源工程仓库层（Repository、DAO）里由 id 查对象并生成展示值的方法；目标数据层照同一规则实现，服务层按 id 调用
