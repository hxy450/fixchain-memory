# 源弹窗展开后才加载数据时，目标先打开弹层再在弹层内异步加载，带加载中和失败重试

审的是：代码
触发（任一种）：
- 读到：源端弹窗组件的 onExpanded 回调里才调用 ViewModel 的加载方法，打开只置 visible，失败可重试（onRetry）；写错的样子：目标在页面初始化（aboutToAppear 的加载函数）里就请求、catch 后静默置空无重试；或打开前先 await 网络再把 showSheet 置 true

- 弹层内容按加载中、失败（带重试按钮，重试再发请求）、成功三态渲染；不在页面初始化静默加载，也不在打开前 await
