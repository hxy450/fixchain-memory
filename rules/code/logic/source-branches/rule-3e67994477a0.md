# 源端 switch 只把部分返回码判失败时，目标逐值照写，其余走成功分支

审的是：代码
触发（任一种）：
- 读到：Java 源码 `switch (result)` 只列出 `case 2`、`case -1` 等几个失败码，其余返回码走成功提示；写错的样子：ArkTS 写成 `if (result !== 0)` 判失败（从相邻方法照搬），源端按成功处理的返回码变成失败
适用范围：迁移写入、认证等操作的返回码分支时
做法：
- 逐值对照源 switch：只把源码列出的 case 写成失败分支（`if (result === 2) {…} else if (result === -1) {…} else {成功}`），其余返回码走成功分支
