# 源端的分支条件和执行时机

agent 会看到什么：读到源端 switch 只列几个失败码、if 守卫没有 else、成功分支先 close() 再 Toast 和 finish()、只在特定方法里重建列表，或有看似缺陷的可观察行为；产物里改成 !== 0、新增清空分支、调了先后、改成渲染时派生，或注释里自定「缺陷不移植」

## 规矩

- rule-3e67994477a0｜源端 switch 只把部分返回码判失败时，目标逐值照写，其余走成功分支｜读到：Java 源码 `switch (result)` 只列出 `case 2`、`case -1` 等几个失败码，其余返回码走成功提示；写错：ArkTS 写成 `if (result !== 0)` 判失败（从相邻方法照搬），源端按成功处理的返回码变成失败
- rule-49e8d06a4b88｜源端计算入口的空输入守卫没有 else 时，目标不新增清空界面的分支，页面在调用前直接 return｜读到：源端计算入口只有 if (mA != null && mB != null) { … } 分支、没有 else；输入校验失败时只 Toast 并把该侧置 null；写错：目标在 null 分支里把结果清空（`= []`、`= ''`），或页面无条件用服务层对 null 输入返回的空结果覆盖界面
- rule-7cd82e01b927｜源端成功分支先 close() 再 Toast 和 finish() 时，目标成功分支也要先关闭｜读到：源端写循环结束的成功分支依次调用读写器的 close()、cancel()、Toast.makeText(...).show()、finish()；写错：目标只在失败或 catch 分支 close()，成功分支直接提示并关闭页面（router.back() / pop）
- rule-b46027fc68d1｜源端只在特定方法里重建列表时，目标在同一时机更新状态，不改成渲染时派生｜读到：Java 源码只在某个重建方法里、且条件真正变化时才重建列表（否则跳过），解析失败分支 Toast 后提前 return、不调用重建；写错：ArkTS 用 @Monitor 或在 build() 里按状态即时派生列表项，称「响应式等价」；解析失败后显示新条目而不是源端留下的旧条目
- rule-5c98f504b473｜源码行为像缺陷时，目标照搬可观察结果，不在注释里自定「缺陷不移植」｜读到：Java 源码有可观察的缺陷：数组元素没赋值就用、NullPointerException 被 catch 后返回 false；字段在输入校验前赋值；后缀无条件追加；非法输入转成 null 后照样交给下层调用得到失败码；写错：代码注释或源码笔记写「源缺陷不移植」「行为增强，非回归」「防御」，改成 indexOf 保序去重、endsWith 防重、首元素补空串后写入成功、遇 null 静默 return，或把校验前的赋值挪到校验之后
- rule-329f781a18c5｜仓储契约写明抑制判定在调用侧时，源端被调方法里的每个标志守卫都写进调用点条件｜读到：源端写盘方法体首行自带 if(...) 标志守卫，外层 save 只判另一个标志；退出分支依次是置标志 A → 初始化方法（会把 A 改回）→ 删档 → 置守卫标志为 false → onBackPressed()；目标仓储的写入方法不判标志，注释或契约写着抑制判定在调用侧；写错：目标调用仓储写入前的 if(...) 条件只有另一个标志和非空判断，没有源端写盘方法首行守卫的那个标志
- rule-3a5c59ebcae5｜已选城市列表为空时走显式分支，不以空编码调天气接口｜读到：源端用 mapNotNull { it.firstOrNull()?.code } 取首个城市编码，没有城市就不发请求；写错：页面以 `?.code ?? ''` 把空编码传给天气服务；城市仓储初始 `[]`、只从进程内静态存储加载，没有首启分支
- rule-e8946eb7f1ce｜源端断点写 width > N.dp 时目标照抄 > N，不按与源码相反的验收条目改成 >=｜读到：源码断点写 width > N.dp（恰好等于阈值时走窄布局）；写错：目标代码写成 `width >= N`，或按某条与源码相反的验收条目把 `>` 改成 `>=`
- rule-ee782bad215e｜源解析和搜索流程的每个条件分支逐项迁过来，null 落入的 else 和 isLeft 回退都不能丢｜读到：源端 when (x?.type) { "text" -> …; else -> 报错 }，值为 null（如响应缺 Content-Type）时落入 else；写错：目标端写成 `contentType.length > 0 && 不是期望类型` 才报错，空或缺失的值被放行
