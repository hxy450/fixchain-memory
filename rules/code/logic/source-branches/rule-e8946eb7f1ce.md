# 源端断点写 width > N.dp 时目标照抄 > N，不按与源码相反的验收条目改成 >=

审的是：代码
触发（任一种）：
- 读到：源码断点写 width > N.dp（恰好等于阈值时走窄布局）；写错的样子：目标代码写成 `width >= N`，或按某条与源码相反的验收条目把 `>` 改成 `>=`
适用范围：按宽度断点切换列数或布局时的比较符
做法：
- 目标照抄源端比较符：源端 width > N.dp 就写 width > N（vp），恰好 N 仍走窄布局；验收条目与源码相反时按源码，并把条目记为待改
