# Kotlin 的 when 加 ?: 回退链改写成 ArkTS 时，每个分支保留链上每一步

审的是：代码
触发（任一种）：
- 读到：源码 `when` 按条件分支，其中通用分支是 `a() ?: b()` 这样的回退链（先查一张映射表，查不到再走 Locale 解析）；写错的样子：ArkTS 里链上前一项只放在某个条件的 `if (...)` 分支里调用，另一分支直接走最后的回退，少了 `?:` 链里的那一步
适用范围：把 Kotlin 里 `when` 分支加 `?:` 回退链（映射表查找、解析、默认值依次尝试）改写成 ArkTS 时
做法：
- 逐个对照源码 `when` 的每个分支和 `?:` 链的每一项，照源码顺序依次尝试：前一项得到 null/undefined 才走下一项，ArkTS 写成 `a() ?? b()` 或逐项判空
- 源码通用分支里也调用的那一项（如映射表查找），ArkTS 的通用分支同样先调用，查不到才走 Locale 一类的解析回退；不要把它只留给某个特定条件的分支
