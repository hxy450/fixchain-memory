# 派生判定按源 ViewModel 谓词的完整取值集实现，不按页面可见单选项推导

审的是：代码
触发（任一种）：
- 读到：源 ViewModel 的布尔派生谓词对一组常量（含页面上不可见的取值）逐个返回 false、其余返回 true；写错的样子：目标端只声明页面可见单选项对应的常量，把「默认」写成 `x !== A && x !== B && x !== C`，漏掉不可见的取值
适用范围：把源 ViewModel 里按常量集合判定的派生谓词写成 ArkTS 页面逻辑时
做法：
- 谓词照源端的完整取值集写，排除的常量一个不少，常量值取源端定义处的原值
- 同一谓词出现在两个以上页面时抽成共享函数，各页共用，或逐项核对两页一致
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 两页改为共用一个解析函数后判定一致：改法的依据（出处：卡里修好并验证过）
针对本应用要查的：
- 谓词排除的全部常量及其值：源工程 ViewModel 里的谓词函数，以及常量定义处（设置存储类的 const val）；把谓词里出现的每个常量和它的值抄成目标端常量，判定式逐项排除
