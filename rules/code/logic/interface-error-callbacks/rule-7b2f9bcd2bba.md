# 实现应用接口子类时以源 @Override 全集核对，基类空默认的回调补覆写或登记缺口

审的是：代码
触发（任一种）：
- 读到：源实现类 @Override 了基类的多个 on* 错误回调（基类是空默认实现），各自 showToast(R.string.…)；写错的样子：目标子类（extends 空默认基类）只覆写规格点名的几个 `on*` 回调并接了对应 sink，其余错误回调继承空实现，引擎和控制器调用它们时静默
适用范围：实现继承空默认基类的应用接口子类、并为其错误回调接页面提示时
做法：
- 以源实现类的覆写全集核对目标子类，不只以规格点名为准；基类空默认而源子类有覆写的方法，补覆写并接上提示，或登记缺口
- 按方法签名 grep 定位源锚点窗口，确认 on* 回调所在区段确实读到
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 补齐其余错误回调的覆写，经 sink 由页面 ViewModel 取本地化文案提示后，各失败路径都有提示：修法（出处：卡里修好并验证过）
