# 源码调用的第三方 jar 在工程里没有源文件时，按坐标取发布版源码迁真实正则和常量

审的是：代码
触发（任一种）：
- 读到：源码用到依赖 jar 里的 Pattern 常量或方法（如标签、链接识别），源工程里搜不到它的源文件；写错的样子：目标按单元测试用例反推出 RegExp（锚定 ^、单字符可识别、用 \p{N}），注释称「契约」
适用范围：源端行为来自第三方依赖库代码、源工程里不含其源码时
做法：
- 按依赖坐标取发布版源码（sources jar 或发布仓库），从真实正则和常量迁移，保留原正则的最小长度和非锚定 find 语义
- 不从单元测试用例反推契约；取不到源码时标 GAP
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 同批另一个 worker 按坐标拉到了依赖库的常量文件，说明依赖源码可取：取源码是可行的（出处：卡里修好并验证过）
针对本应用要查的：
- 依赖库的真实正则和常量：源工程 build 文件里的依赖坐标（group:artifact:version），到 Gradle 缓存 modules-2/files-2.1/<group>/<artifact>/<version> 下找 -sources.jar，没有就取该版本的发布源码；在源码里按被调用的类名和常量名找到原始正则串，原样迁到目标
