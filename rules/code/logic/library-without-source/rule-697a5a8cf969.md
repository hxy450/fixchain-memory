做法：
- speed / maxSpeed 按每帧位移（dp/帧），按 60 步/秒推进，不再除以 60；每帧 acc += (0, 0.02) / mass，v += acc，v *= damping，pos += v
- 未传的外观取库缺省：尺寸 6 / 8 / 10dp、质量 4 / 5 / 6 ×(1 + 0.2·rand)；形状 Square / Circle 随机；timeToLive 2000ms 后每帧 alpha −5；颜色 0xFCE18A / 0xFF726D / 0xF4306D / 0xB48DEF
