# 自研替代三方库动效或物理组件前，从库制品反汇编更新与发射方法，确认时间域、重力和寿命

审的是：代码
触发（任一种）：
- 读到：源码 import 三方库的粒子或动效组件（如 Party、Emitter），只传速度、阻尼、发射器等部分参数；写错的样子：目标组件常量凭记忆写（把每帧速度当每秒再除以 60、用固定下沉漂移代替重力、没有寿命淡出），文件头或占位登记写「仅 classes.jar、库默认值不可核」，交给真机视觉核验
适用范围：目标端用 Canvas 等自研替代二进制三方库的动效或物理组件时
做法：
- 写常量和步进前，从库制品用 javap 反汇编更新与发射方法，确认参数的时间域（每帧还是每秒）、帧率归一化、重力与质量、阻尼、寿命与淡出
- 上游提醒或注释写「库源不可核」时先自己核一次；不以「待真机视觉核验」占位代替读取
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 只有编译 jar 也能读：JDK 的 javap；本机没装 JDK 时用 Android Studio 自带 jbr/bin/javap：读库代码的工具（出处：卡里修好并验证过）
针对本应用要查的：
- 库的运动模型和缺省参数：Gradle 缓存 modules-2/files-2.1/<group>/<artifact>/<version>/ 下的库 jar，或 transforms 目录里解包后的 classes.jar；javap -p -c -constants 看更新方法每步怎么改速度、加速度和透明度，以及构造器缺省分支里的常量
