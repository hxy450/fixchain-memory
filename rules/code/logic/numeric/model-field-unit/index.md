# 两端模型同名数值字段的单位

agent 会看到什么：读到源端 Builder().setDuration(x) 一类链式构造逐字段直传数值，目标端来源模型和目标模型对同名数值字段注明不同单位（ms / 秒）；产物里 new 目标模型(…, src.字段, …) 原样传值，没有 / 1000 或 * 1000 换算

## 规矩

- rule-e88b137fd595｜逐字段照搬源端 Builder 构造时，两端模型数值字段单位不同就在构造处显式换算｜读到：源端用 Builder().setDuration(x) 一类的链式构造逐字段直传数值；目标端来源模型和目标模型对同名数值字段注明了不同单位（如一个注 ms、一个注「秒」）；写错：目标端 new <目标模型>(…, src.duration, …) 把来源字段原样传进单位不同的参数，没有 / 1000 或 * 1000 换算
