# 调用实参里的字面数值

agent 会看到什么：读到源端调用的实参里直接写字面数值或换算式（如 角度 * 0.01745329252f）；产物里 seam 接口删了这些参数、只在注释里留参数名，或绑定处传了来源不明的数值（Math.PI / 18.0 一类）

## 规矩

- rule-7fdf80fe06da｜源调用带字面参数时，seam 接口和绑定处都传源端原值，不留注释参数名、不自拟数值｜读到：源端调用把字面参数直接写在实参里，如 `角度 * 0.01745329252f` 这类度转弧度原式；写错：seam 接口签名删掉了这些参数，只在注释里留参数名；或绑定处传入来源不明的数值（如 Math.PI / 18.0 之类自拟的角度）
