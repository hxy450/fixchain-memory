# 源调用带字面参数时，seam 接口和绑定处都传源端原值，不留注释参数名、不自拟数值

审的是：代码
触发（任一种）：
- 读到：源端调用把字面参数直接写在实参里，如 `角度 * 0.01745329252f` 这类度转弧度原式；写错的样子：seam 接口签名删掉了这些参数，只在注释里留参数名；或绑定处传入来源不明的数值（如 Math.PI / 18.0 之类自拟的角度）
适用范围：把源端一次调用拆成 seam 接口、由别的切片或 closer 绑定时
做法：
- 持有源码的一侧在实现里传值，或把值写死在接口里，按源端原式写（角度 × 0.01745329252），不只在注释保留参数名
- 绑定 seam 时所需数值不在已读输入里，就回源锚点查值，不自拟
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 阈值改为源端原式后，对齐判定与源端一致：字面参数要原值穿过 seam（出处：卡里修好并验证过）
针对本应用要查的：
- 源端调用的字面参数：源工程里该调用所在的方法，及它引用的常量；照原式写进实现或接口
