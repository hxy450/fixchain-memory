# 源端给出图表上下界偏移时，目标的极值函数保留这项偏移再算曲线坐标

审的是：代码
触发（任一种）：
- 读到：源 ViewModel 或规格的数据流里写明图表上下界是 `max + 2` / `min - 2` 这类偏移；写错的样子：目标里求上界、下界的函数直接返回数据极值，没有 `+ 2` / `- 2`，曲线坐标按极值换算
适用范围：迁移折线、曲线等图表，源端代码或规格对坐标上下界加了偏移时
做法：
- 目标里求上界、下界的函数照源端写成极值加减同样的偏移（如 max + 2、min - 2），曲线的纵坐标用这个上下界换算
针对本应用要查的：
- 上下界偏移的数值：源工程 ViewModel 或图表 View 里计算最大、最小值的代码，或规格的数据流和实现映射表；读出加减的常量，原样写进目标的极值函数
