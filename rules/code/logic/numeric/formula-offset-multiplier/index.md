# 源端算式里的倍率和偏移项

agent 会看到什么：读到源端算式在调用点或数据流里带倍率、偏移（实参写成进度 × 倍率、derivedStateOf，图表上下界写 max + 2 / min - 2）；产物里内联或重写的算式只照被调组件内部公式或数据极值写，少了这一项

## 规矩

- rule-449fd299598e｜宿主调用点的实参带乘数时，内联或重建被调组件也要保留调用点的乘数｜读到：宿主 @Composable 调用共享组件时把实参写成表达式（如进度 × 倍率，或 remember { derivedStateOf { 进度 * 倍率 } }），被调组件内部只乘传入的进度；写错：页面方法或 @Builder 里只照被调组件内部公式写，直接用 @State 里的原始进度，少乘了调用点的倍率
- rule-cda4dadc5dc3｜源端给出图表上下界偏移时，目标的极值函数保留这项偏移再算曲线坐标｜读到：源 ViewModel 或规格的数据流里写明图表上下界是 `max + 2` / `min - 2` 这类偏移；写错：目标里求上界、下界的函数直接返回数据极值，没有 `+ 2` / `- 2`，曲线坐标按极值换算
