# 宿主调用点的实参带乘数时，内联或重建被调组件也要保留调用点的乘数

审的是：代码
触发（任一种）：
- 读到：宿主 @Composable 调用共享组件时把实参写成表达式（如进度 × 倍率，或 remember { derivedStateOf { 进度 * 倍率 } }），被调组件内部只乘传入的进度；写错的样子：页面方法或 @Builder 里只照被调组件内部公式写，直接用 @State 里的原始进度，少乘了调用点的倍率
适用范围：把被宿主调用的共享 Compose 组件转写成页面内联方法或公共组件时
做法：
- 同时转写调用点的实参表达式和被调组件的内部公式；内联到页面方法时，调用点上的乘数一并写进去
- 写完按调用链逐项核对每个显示值的乘数，并用一个倍率不为 1 的样例（如倍率 2、进度 0.5）算一遍，看是否得到满程值
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 页内两处计时文本都丢了调用点的 ×倍率；改由共享组件按源公式计算、删除页内分叉后正确：错误表现和修法（出处：卡里修好并验证过）
针对本应用要查的：
- 显示值的完整公式：源工程里宿主 Composable 调用该组件的那一行实参，以及被调组件内部的计算；把两段乘起来写成一个公式，逐项对应到目标的状态和参数
未核实：卡里观察到的行为出自鸿蒙 SDK API 24（6.1.1），本机核实用 API 23
