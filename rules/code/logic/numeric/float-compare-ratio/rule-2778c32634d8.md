# 源码用 == 比较 Float 时目标保持精确相等，不自加容差，增删和选中用同一比较

审的是：代码
触发（任一种）：
- 读到：源端 ToggleButton(checked = value == other.toFloat())，增删用 it.toFloat() == / != value；写错的样子：目标写 Math.abs(parseFloat(v) - value) < 0.05 一类容差比较，源端和规格都没给容差
适用范围：迁移源端 Float 精确相等判断（选中、去重、移除）时
做法：
- 写成 Math.fround(parseFloat(v)) === value 精确相等；选中判断、是否已存在、移除过滤都用这同一个比较函数
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Math.fround(parseFloat(value)) === wm：按 32 位 Float 取值后精确相等，对应源端 Float 的 ==（出处：卡里修好并验证过）
