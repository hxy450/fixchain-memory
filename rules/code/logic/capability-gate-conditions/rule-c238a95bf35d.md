# 契约缺某个判断入口时，在能力类构造里留注入点或登记 FWD-REF，不写恒 false 删门控

审的是：代码
触发（任一种）：
- 读到：源端能力门先判是否由拍照 Intent 启动，目标端的应用接口契约里搜不到对应的判断入口；写错的样子：能力类注释写 `无入口，恒 false 近似`，各能力门里这条判断整条删掉；能力类和上层控制器的构造参数里没有它的来源，也没有登记 FWD-REF
适用范围：实现阶段移植能力门或其他判断，契约暂缺其中某个判断入口时
做法：
- 在能力类的构造参数里给这个判断留注入点，上层控制器、页面逐层传入；或按发号协议登记 FWD-REF 交给契约的拥有者
- 并行切片已经实现同一判断（应用接口上的同名判断、陀螺仪服务）时直接复用，不另写一套
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 给能力类注入启动方式判断，控制器、页面逐层传入后，各能力门恢复这条条件：修好的做法（出处：卡里修好并验证过）
