# 源端 Instant.parse 的严格 ISO 解析，不用宽松的 Date.parse 代替

审的是：代码
触发（任一种）：
- 读到：源端用 Instant.parse(text) 解析时间串，并捕获 DateTimeParseException 走失败分支；写错的样子：目标用 Date.parse(...) 或 new Date(str) 宽松解析，非 ISO 的串也被接受，源端的失败分支没了
适用范围：迁移源端 java.time 的时间串解析时
做法：
- 按 ISO-8601 instant 格式严格校验后再解析，格式不符时走源端捕获 DateTimeParseException 的那个分支
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Instant.parse 用 DateTimeFormatter.ISO_INSTANT 解析，串必须是有效的 UTC 时刻：源端的解析是严格 ISO 语义（出处：java.time.Instant#parse）
