# 月历查询范围按页面实际格子的首尾日期计算，不按自然月 1 日到月底截断

审的是：代码
触发（任一种）：
- 写错的样子：ArkTS 月历的查询范围写成自然月 1 日到月底（如 new Date(y, m, 1) 到 new Date(y, m + 1, 0)），月格里补位的上月尾、下月头没有数据
适用范围：按整周格子显示的月历查询事件或装饰数据时
做法：
- 查询范围取该页第一格到最后一格的日期：复用源端按格子算首尾日期的方法，或用 Canvas 自己的格子算法算出
针对本应用要查的：
- 月格首尾日期的算法（每周从哪天起、显示几行）：源工程里给月历算查询范围的工具方法，以及月历控件取首日星期的设置；读出首格 = 本月 1 日所在周的周首日、末格 = 最后一行周末，照写成目标端的范围计算
