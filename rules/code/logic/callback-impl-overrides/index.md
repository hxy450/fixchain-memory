# 回调接口实现类覆写的回调

agent 会看到什么：读到源端回调接口的实现类 @Override 了一组回调；产物里实现类 extends 回调全是空默认的 Basic 基类、没覆写源端覆写过的回调，VM 上承接这些回调的方法没有调用者

## 规矩

- rule-b39afb9e7b3e｜实现回调接口具体类时对照源实现类的 @Override 清单覆写，基类空默认不能当终态｜读到：源端回调接口的实现类 @Override 了若干回调（如相机就绪、拍摄进行中），目标端实现类继承一个回调全是空默认的 Basic 基类；写错：目标实现类没覆写源端覆写过的回调，引擎调来的回调落到基类的空实现；VM 上承接这个回调的同名方法在工程里没有调用者
