# 用代码替代 ExifInterface 时 tag 号和字符串转换从库源码取，删除项不置 -1

审的是：代码
触发（任一种）：
- 读到：源码只用 ExifInterface.TAG_* 名，removeExifTags 删除 TAG_CFA_PATTERN、TAG_TRANSFER_FUNCTION、TAG_XMP、TAG_INTEROPERABILITY_INDEX；写错的样子：tag 号凭记忆填（如 CFAPattern 写 0x828E、TransferFunction 写 0x0120），XMP、InteroperabilityIndex 置 -1，删除成了空操作
- 读到：源码把 TAG_GPS_TIMESTAMP 设成 'HH:mm:ss' 字符串，或调 exif.setGpsInfo(location)；写错的样子：GPSTimeStamp 的 'HH:mm:ss' 交给通用有理数解析；setGpsInfo 用保存时刻 new Date() 写 GPS 时间，不写 GPSSpeed / GPSSpeedRef
适用范围：自写 EXIF 写入器替代 androidx ExifInterface 的 tag 表和 setAttribute / setGpsInfo 语义时
做法：
- tag 号从库源码的 tag 表取（见下方取值）；源端要删的 tag 给真实号或子 IFD（Interop IFD 经 0xA005 指针）并参与删除
- GPSTimeStamp 的 'HH:mm:ss' 写成三个有理数 H/1,M/1,S/1；setGpsInfo 取定位自带的时间（location.timeStamp），速度按 m/s × 3.6 写成 km/h 并写 GPSSpeedRef = 'K'
- 库源码查不到的语义登记为待验证，不凭记忆补
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- TAG_TRANSFER_FUNCTION = 301、TAG_XMP = 700、TAG_CFA_PATTERN = 41730、TAG_INTEROPERABILITY_IFD_POINTER = 40965、TAG_INTEROPERABILITY_INDEX = 1（Interop IFD）：要删除的几项的真实 tag 号（出处：android.media.ExifInterface（EXIF_TAGS 各 IFD 的 ExifTag 表））
- TAG_GPS_TIMESTAMP = 7（URATIONAL）、TAG_GPS_SPEED_REF = 12（STRING）、TAG_GPS_SPEED = 13（URATIONAL）：GPS IFD 里时间和速度的 tag 号和类型（出处：android.media.ExifInterface（GPS IFD 的 ExifTag 表））
- setAttribute 对 GPSTimeStamp 按 ^([0-9][0-9]):([0-9][0-9]):([0-9][0-9])$ 匹配，转成 "h/1,m/1,s/1"：字符串到三个有理数的转换（出处：android.media.ExifInterface#setAttribute）
- setGpsInfo 写定位时间、速度 m/s × 3.6 写 km/h、GPSSpeedRef = 'K'：库内语义（卡里从库源码查到并按此修复）（出处：卡里修好并验证过）
针对本应用要查的：
- 应用依赖版本的 ExifInterface 语义：源工程模块依赖里 androidx.exifinterface:exifinterface 的版本，对应版本库源码里的 ExifInterface 类；按版本读 tag 表、setAttribute 的字符串转换和 setGpsInfo 写入的字段
未核实：tag 号按 Android 平台 android.media.ExifInterface 核实，应用依赖的是 androidx.exifinterface；setGpsInfo 的语义只在 androidx 版里有，本机没有源码，按卡写
