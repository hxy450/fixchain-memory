# Android 正则走 ICU：\s 是 White_Space、\p{L} 不含 \p{M}、交替替换单遍

审的是：代码
触发（任一种）：
- 读到：源码正则含 \s（如 s.matches("\\s")、".*(\\s|^)tag(\\s|$).*"），或 replaceAll("(" + Pattern.quote(a) + "|" + Pattern.quote(b) + ")", "")；写错的样子：目标写 /[ \t\n\f\r]/ 并注释「Java \s 仅 ASCII 空白」，字母类写 [\p{L}\p{M}]，或把交替替换拆成两遍 split / join
适用范围：把在 Android 上运行的 Java 正则（java.util.regex，后端是 ICU）翻译成 JS RegExp 时
做法：
- \s 用 Unicode White_Space 集合，JS 写 /\p{White_Space}/u；字母只用 \p{L}，不并入 \p{M}
- Pattern.quote 交替替换写成一个 new RegExp(<转义 a> + '|' + <转义 b>, 'g') 单遍替换，不分两遍
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- \s 是 \p{IsWhite_Space}：Android 上 \s 是 Unicode 空白，含全角空格（出处：java.util.regex.Pattern（类注释的预定义字符类表））
- Android 2.3 起正则实现的后端是 ICU4C：行为照 ICU，不照 OpenJDK 或 JS（出处：java.util.regex.Pattern（类注释））
- 修好后改为 ICU White_Space 集、\p{L} 和单遍交替扫描：修好后的做法（出处：卡里修好并验证过）
