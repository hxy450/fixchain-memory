# Java split / split("") / trim 移植时去尾随空串、按码点切、只去 ≤U+0020

审的是：代码
触发（任一种）：
- 读到：源码 String.split(",")、text.split("")、String.trim()；写错的样子：目标直接用 JS split(',') 保留尾随空串，split('') 或 charCodeAt 按 UTF-16 单元切（emoji 计 2），JS trim() 去 Unicode 空白
适用范围：把 Java String 的切分和去空白调用翻译成 ArkTS 时
做法：
- split(regex) 切完去掉末尾的空串："a,b,," → ["a", "b"]
- split("") 按码点切，写 Array.from(text)；trim 只去两端码点 ≤ U+0020 的字符，写 s.replace(/^[\u0000-\u0020]+|[\u0000-\u0020]+$/g, '')
- 用 emoji、全角空格、尾随逗号自测后再写「等价」注释
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- split(regex) 等于 limit 为 0 的 split，尾随空串不包含在结果里：JS split 会保留尾随空串（出处：java.lang.String#split(String)）
- trim 去掉两端码点 ≤ U+0020 的字符：全角空格等 Unicode 空白不去（出处：java.lang.String#trim）
- JS trim() 去掉两端的空白和行终止符：范围比 Java trim 大（出处：鸿蒙 SDK 的 ets/build-tools/ets-loader/node_modules/typescript/lib/lib.es5.d.ts，String.trim）
- 修好后改为码点切分，并分别实现 Java 语义的 split 和 trim：修好后的做法（出处：卡里修好并验证过）
未核实：split("") 在 Android 上按码点切出自卡（ICU 正则后端），本机文档未单独写明
