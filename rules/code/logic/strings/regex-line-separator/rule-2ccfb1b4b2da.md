# 正则字面量里要匹配 U+2028/U+2029 时写 \u2028 转义，不放原字符

审的是：代码
触发（任一种）：
- 写错的样子：ArkTS 的正则字面量 `/…/`（如 `.replace(/…/g, …)`）里直接放了 U+2028 或 U+2029 原字符
适用范围：ArkTS/TS 代码里写正则字面量处理行分隔符、段分隔符时
做法：
- 写成转义 `/\u2028/g`、`/\u2029/g`；做 Gson 等价转义时改成逐字符写出，不在正则里放原字符
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- TS 正则字面量禁止行终止符，放入 U+2028/U+2029 原字符时编译错误：原字符写进正则字面量过不了编译，且编辑工具难以匹配含原字符的行（出处：卡里修好并验证过）
