# java.net.URL(url).host 移植时取不带 userinfo 和端口的主机名，解析失败返回 null

审的是：代码
触发（任一种）：
- 读到：源码 URL(url).host（java.net.URL），catch MalformedURLException 返回 null；写错的样子：目标用 `^scheme://([^/?#]+)` 一类 RegExp 取 authority：结果带 userinfo 和端口，任意协议都接受
适用范围：把依赖 java.net.URL 的主机名工具函数移植成 ArkTS 时
做法：
- 按 java.net.URL 语义写：返回主机名，不含 userinfo 和端口；没有协议或协议未知时按解析失败返回 null
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- URL#getHost 返回主机名；userInfo、port 各有 getUserInfo、getPort，authority 才包含它们：host 不是 authority（出处：java.net.URL#getHost、java.net.URL#getUserInfo、java.net.URL#getPort）
- 构造时没有协议或协议未知抛 MalformedURLException：源端这时返回 null，目标不能照样解析出主机名（出处：java.net.URL#URL(String)）
- 修好后按 java.net.URL 语义重写了取主机名的函数：去掉 userinfo 和端口，未知协议返回 null（出处：卡里修好并验证过）
