# 源码用 isNotBlank/isBlank 筛选时，trim() 只用于判断，返回原串

审的是：代码
触发（任一种）：
- 读到：Kotlin 源码 `firstOrNull(String::isNotBlank)`、`filter { it.isNotBlank() }` 或 `isBlank()` 只拿来筛选，返回的是原行；写错的样子：目标端返回 `lines[i].trim()` 这类 trim 之后的串，原行首尾的空格丢了
适用范围：把 Kotlin 的 isNotBlank / isBlank 筛选翻译成 ArkTS 时
做法：
- 判断用 s.trim().length > 0，返回保留原串：lines.find((l: string) => l.trim().length > 0) ?? ''；后续的截断（take(n) → slice(0, n)）作用在原串上
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- trim(): string：去掉首尾空白和行终止符后返回新串，只拿来判断是否为空（出处：鸿蒙 SDK 的 ets/build-tools/ets-loader/node_modules/typescript/lib/lib.es5.d.ts，String.trim）
- 首个非空白行保留原文不 trim，仍截断到原长度上限：修好后的取行规则（出处：卡里修好并验证过）
