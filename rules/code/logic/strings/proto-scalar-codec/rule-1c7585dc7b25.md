# 手写 proto3 编解码按 wire type 选读写法，wire 0 的 int32 不用 fixed32 读

审的是：代码
触发（任一种）：
- 读到：字段表（字段号 | wire type | 标量类型）里有 wire type 0 的 `INT32` 字段（可能为负），同时有 fixed32/sfixed32 定长字段；写错的样子：encode 写 `w.int32(N, …)`，decode 对同一字段写 `r.fixed32()`；或 decode 用无符号 `r.varint()` 读负值字段
适用范围：目标端没有 protobuf 运行时、按字段表手写编解码时
做法：
- 按 wire type 而不是值有无符号选方法：wire 0 用 varint 族（int32/uint32/enum/bool），wire 5 用 fixed32/sfixed32/float，wire 1 用 fixed64 族
- int32 解码按 varint 读完全部字节（负值线上占 10 字节），取低 32 位后用 `value | 0` 还原符号，读指针推进与 varint 一致
- 每个 message 写完逐字段对照 encode 的 `w.xxx(N,` 与 decode 里字段 N 分支的 `r.xxx()`，并用「负值有符号字段后接更高字段号」的 round-trip 用例检查后续字段不错位
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- WIRETYPE_VARINT = 0，WIRETYPE_FIXED64 = 1，WIRETYPE_LENGTH_DELIMITED = 2，WIRETYPE_FIXED32 = 5；TAG_TYPE_BITS = 3：wire type 取值，tag 低 3 位是 wire type（出处：com.google.protobuf.WireFormat#WIRETYPE_VARINT 等（Android SDK 源码））
- readInt32() 返回 readRawVarint32()；readEnum() 同样：int32、enum 按 varint 读（出处：com.google.protobuf.CodedInputStream#readInt32）
- readFixed32()、readSFixed32() 都返回 readRawLittleEndian32()；readFloat() 是 Float.intBitsToFloat(readRawLittleEndian32())：wire 5 的三种标量都读 4 字节小端（出处：com.google.protobuf.CodedInputStream#readFixed32、readSFixed32、readFloat）
- int32 负值：computeInt32SizeNoTag 走「Must sign-extend」返回 MAX_VARINT_SIZE = 10：负的 int32 在线上是 10 字节 varint（出处：com.google.protobuf.CodedOutputStream#computeInt32SizeNoTag；com.google.protobuf.WireFormat#MAX_VARINT_SIZE）
