# 用脚本把原始控制字符改成转义时逐层算反斜杠，落盘后逐字节核对

审的是：代码
触发（任一种）：
- 写错的样子：字符串常量里是 `'Exif\\u0000\\u0000'`、`'ASCII\\u0000\\u0000\\u0000'` 这类字面反斜杠加 u0000，不是 NUL 字节
适用范围：写入工具把代码里的 \0 变成原始 NUL 后，用脚本替换成转义的时候
做法：
- 逐层计算反斜杠：Python bytes 字面量里的四个反斜杠落盘成两个；替换后用 repr 或逐字节检查目标文件，确认恰好是一个反斜杠加 u0000，不凭 print 输出推断
- 也可以改用 String.fromCharCode(0) 或显式字节数组表示 NUL
