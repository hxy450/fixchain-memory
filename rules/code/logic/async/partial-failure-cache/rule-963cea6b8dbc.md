# 决策要求失败保持最近成功数据时，catch 不清空列表，页面只在成功时整体替换

审的是：代码
触发（任一种）：
- 读到：决策台账写「失败保持显式错误与最近成功数据，不伪造空成功」（显式 Result + 最近成功缓存 + 重试）；写错的样子：ViewModel 的列表加载 catch 里把已成功的 items / groups 清空，或页面同步状态时无条件用 ViewModel 的列表整体替换（replaceAll）
适用范围：列表页的 ViewModel 和页面状态同步，失败后数据源是否保留
做法：
- ViewModel 的 catch 只记录错误，不清空已成功的列表；页面只在成功结果到达时整体替换，ViewModel 返回空列表且有错误时不覆盖页面已有目录
- 重载失败后目录仍可见，在目录上方显示非阻塞的失败提示和重试入口
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 同步状态时 ViewModel 返回空列表且有错误则不覆盖已有目录，并在目录上方加非阻塞失败提示和重试入口：修好后的同步规则（出处：卡里修好并验证过）
