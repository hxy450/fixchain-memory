# 详情网关先取同城首页缓存构造基础数据再用详情覆盖，失败返回带缓存的结果，不返回 FAILED 加空模型

审的是：代码
触发（任一种）：
- 读到：源端加载流程先从缓存读首页数据（列表、逐小时、实时、趋势），详情接口只补选中日，ViewModel 只在 Result.Success 时替换选中日；决策台账要求网络失败优先读有效缓存；写错的样子：网关只调详情接口，catch 分支返回 FAILED 加 new 出来的空数据模型，不读首页缓存，也不回填日期列表
适用范围：功能接线阶段实现依赖首页缓存的详情数据网关时
做法：
- 网关先取同城首页缓存（先 load 首页）构造基础数据，再用单日详情覆盖选中日
- 详情请求失败时返回 SUCCESS 并带上缓存构造的数据和一条提示，不返回 FAILED 加空模型
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 先 loadHome 再补单日详情；失败时返回 SUCCESS，用首页的多日列表、逐小时、实时、日出日落数据构造内容，只做轻提示：修好的网关写法（出处：卡里修好并验证过）
针对本应用要查的：
- 目标端首页缓存在哪里、按什么键取：目标工程里首页数据的运行时或缓存模块（.ets），按城市 id 之类的键找读取方法；网关里先调它拿同城数据，再发详情请求
