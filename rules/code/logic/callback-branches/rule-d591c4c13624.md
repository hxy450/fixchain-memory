# 注释写「对齐源端回调」前核对已覆盖全部分支，省略的要写明

审的是：代码
触发（任一种）：
- 读到：源端回调有多个分支（如 result.on(true) 继续、result.on(false) 中止）；写错的样子：代码注释写「对齐源端…回调」，实现里只有其中一部分分支（如只有拦截和 `return` 中止），注释和完成报告都没说明省略了哪一步
适用范围：迁移源端带多分支的回调、并在注释或完成报告里声称对齐源端时
做法：
- 写「对齐源端」前逐个分支核对实现；有意简化时在注释和完成报告里写明省略的分支和原因
