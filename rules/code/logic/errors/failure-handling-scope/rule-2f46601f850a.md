# 回填返回 Either 或 Result 的调用时，按源端 onLeft 消费返回值，不只 await

审的是：代码
触发（任一种）：
- 读到：Kotlin 调用链 `.onLeft { Log.e(TAG, "… ${it.code}, ${it.body}") }`；目标签名返回 Promise<Either<错误, 结果>>；槽位注释写「Left 错误只记录」；写错的样子：只有一行 await 调用、不接返回值，Left 分支没有任何 hilog.error / console.error 日志
适用范围：回填或迁移返回 Either / Result 的调用，源端在 onLeft 分支里有处理时
做法：
- const r = await 调用()；按目标 Either 的判别方法（卡里是 isLeft）判断 Left，至少记录错误码与正文，对应源端 onLeft 里的 Log.e
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- function error(domain: number, tag: string, format: string, ...args: any[]): void：鸿蒙的错误级日志接口，对应源端 Log.e（出处：鸿蒙 SDK 的 ets/api/@ohos.hilog.d.ts，hilog.error）
- 检查 isLeft 并记录 code 和 body：修好的写法（出处：卡里修好并验证过）
