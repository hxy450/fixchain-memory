# 源端构造期 runBlocking 完成初始化时，目标设显式初始化门禁并让所有入口先 await

审的是：代码
触发（任一种）：
- 读到：源端客户端在 init { runBlocking { initialize() } } 里同步初始化，业务方法经一个守卫在未就绪时返回错误码；写错的样子：目标逐次守卫在未初始化时自己从数据库解码密钥并照常发请求，没有 `initialized` 门禁；后台同步入口没有先 await initialize()
适用范围：实现阶段，把源端构造期同步初始化的客户端迁成异步初始化时
做法：
- 加显式 initialized 标志：初始化、创建、加入等流程完成后置位；每个业务方法先查它，未完成就返回源端的未就绪错误码，不在守卫里顺手解码密钥
- 逐个检查 UI、后台同步等所有入口，在首个请求前 await 初始化（后台链路公开一个从数据库初始化的方法并先调它）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 加门禁后后台同步若不先初始化会永久返回未就绪；让同步链阶段先 await 从数据库初始化后恢复：修复后保留的写法（出处：卡里修好并验证过）
