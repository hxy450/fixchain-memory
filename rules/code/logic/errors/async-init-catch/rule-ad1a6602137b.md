# 加载门用 LoadingProgress 切换时，initialize().then 必须配 catch 并离开加载态

审的是：代码
触发（任一种）：
- 读到：目标端 ViewModel 的 initialize() 返回 Promise，加载链可能 reject（偏好封装里有 throw 或异步读取）；写错的样子：页面在 aboutToAppear 里写 initialize().then(...) 没有 .catch，build 里用已加载标志在正式内容和 LoadingProgress() 之间切换，没有失败分支
适用范围：页面用“已加载”标志在 LoadingProgress 和正式内容之间切换、加载由异步 initialize() 完成时
做法：
- 写成 initialize().then(() => { 置已加载 }).catch(() => { 复位首次出题等一次性守卫; 置失败标志 })
- build 里加失败分支：if (已加载) 正式内容 else if (失败) 错误文案和“重试”按钮（重走同一初始化入口） else LoadingProgress()；或按源端行为用默认设置继续，让页面可用；新文案加进 string.json
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- aboutToAppear?(): void：生命周期回调是同步的，不能 await；里面调的 Promise 要自己接 then 和 catch（出处：鸿蒙 SDK 的 ets/component/common.d.ts，BaseCustomComponent.aboutToAppear）
- 失败标志 + 错误文案 + 重试按钮重走初始化，catch 中复位一次性守卫：按此改后 reject 时页面离开加载态并可重试（出处：卡里修好并验证过）
