# 改写台账点名边界上的日志调用时，补上类型、阶段、耗时等定位字段并脱敏

审的是：代码
触发（任一种）：
- 写错的样子：改写后的失败日志只有一句文字加 error.message，或网络诊断只有 method、statusCode、durationMs，缺类型、阶段、失败分类、数量；或者把 token、ID、正文、完整请求/响应写进日志
适用范围：按计划搬移或改写决策台账点名的边界（卡片刷新、网络诊断、同步各阶段、导入、本地增删改等）上的日志调用时
做法：
- 对照源端同一边界的日志，在目标日志里写出定位所需字段：类型、阶段、失败分类、耗时（durationMs）、数量；只替换调用者、保留原来那句文字不算完成
- 只记类型、状态、数量、耗时这类字段，不记 token、ID、正文和完整请求/响应
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 失败日志补上 type 和 durationMs；网络、同步六阶段、导入、本地增删改等按源端同一边界补齐，只记类型、状态、数量、耗时：修好后的日志字段（出处：卡里修好并验证过）
针对本应用要查的：
- 源端同一边界日志记了哪些字段：源工程对应业务代码里的写文件日志调用（同步每一步、请求结束、刷新失败等分支）；把日志串里的类型、阶段、计数、耗时等变量列出来，在目标日志里写同样的字段
