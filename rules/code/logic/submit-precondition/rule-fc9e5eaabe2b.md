# 源端选项为空即提示失败时，目标前置条件照写成未选即拒绝，不加列表非空的条件

审的是：代码
触发（任一种）：
- 读到：ViewModel 的提交方法开头校验参数，选项为 null 时直接提示失败并返回；写错的样子：目标的前置判断在「未选」之外加了 .length > 0 之类的条件，列表为空时可以不选就提交
适用范围：安卓 ViewModel 写操作前的空值校验，迁成 ArkUI 页面确认分支的前置条件时
做法：
- 前置条件只写源端校验的那几项：选中值为 undefined 就提示失败并 return，不论选项列表是否为空
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 前置条件改为「选中值为 undefined 即拒绝」：去掉列表长度条件后与源端一致（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
