# 为修某条编译错误整文件重写时，没报错的组件用法原样保留

审的是：代码
触发（任一种）：
- 读到：构建错误只指向导入/导出或 @Entry 一类问题（如 declares 'X' locally, but it is not exported）；写错的样子：整文件重写后的版本里，未被报错的组件用法换了写法（如删掉 @Builder 页签方法、把 .tabBar(this.…) 改成对象字面量）
适用范围：编译修复阶段对页面做整文件重写时
做法：
- 只改报错定位到的行和符号；必须整文件重写时先与上一版逐段对照，未被报错的组件用法（如 TabContent.tabBar 的 @Builder / CustomBuilder 形式）原样保留
未核实：上一版 @Builder 写法是否完全通过编译卡里无法直接核实，只确认没有指向它的报错
来源：1 张卡，1 个应用
- case-11c15d99c36e52d8aa59（星途清单）：做法第 1 步 ← 建议 1
