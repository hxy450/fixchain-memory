# 禁编译时一次写出的整页文件

agent 会看到什么：读过的派工写「禁止任何编译/构建」、要一次写出整页 @ComponentV2 文件；交回的代码引用了没有 const 声明的大写常量，或没有 @Local / @Param / private 声明的 this. 成员

## 规矩

- rule-ccc04e84f195｜禁编译生成的页面，引用的大写常量和 this 成员逐个对照声明，缺的补定义｜读到：派工写「禁止任何编译/构建」，要求一次写出整页 `@ComponentV2` 文件；写错：代码引用了文件里没有 `const` 声明的大写常量（如多处 `.width(…)` / `.height(…)` 的参数），或没有 `@Local` / `@Param` / `private` 声明的 `this.` 成员；写后自检只查了括号平衡、禁用词、占位登记
