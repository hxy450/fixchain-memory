# 禁编译生成的页面，引用的大写常量和 this 成员逐个对照声明，缺的补定义

审的是：代码
触发（任一种）：
- 读到：派工写「禁止任何编译/构建」，要求一次写出整页 `@ComponentV2` 文件；写错的样子：代码引用了文件里没有 `const` 声明的大写常量（如多处 `.width(…)` / `.height(…)` 的参数），或没有 `@Local` / `@Param` / `private` 声明的 `this.` 成员；写后自检只查了括号平衡、禁用词、占位登记
适用范围：生成期禁止编译、一次写出大型 ArkTS 页面并做写后自检时
做法：
- 写后用正则提取文件里所有 this\.标识符 和大写常量名，与 const、@Local / @Param / private 声明行做差集；缺的补定义或改引用
- 设计里定下的尺寸（如图标按钮 48vp 命中区）用具名常量引用时，写入调用点的同时在文件常量区加上 const 名 = 值
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 补上缺的 const 声明、把未声明的 this 成员改成已声明对象上的字段后，探针编译通过：两处未定义引用都是编译错误，禁编译时只能靠自检发现（出处：卡里修好并验证过）
