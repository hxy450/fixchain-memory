# Kotlin object 或静态工具类改成顶层 export function 时，调用处改具名导入并去掉类名前缀

审的是：代码
触发（任一种）：
- 读到：Kotlin `object X { fun … }` 或 Java 静态工具类，调用处写成 X.method(...)；写错的样子：工具文件导出的是顶层 `export function`，调用处却写 import { X } from '…' 和 X.method(...)；编译报 10505001 has no exported member
适用范围：把 Kotlin object 或 Java 静态工具类迁成 ArkTS 模块、并在别的文件里接线调用时
做法：
- 工具文件导出顶层函数时，调用处写 import { method1, method2 } from '…'，调用写 method1(...)，去掉 X. 前缀
- 要保留 X.method(...) 写法，就在工具文件里导出 export class X { static method… } 或 export namespace X { export function method… }
- 写完跨文件接线后，用 grep '^export' 核对每个被导入的名字确实导出
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 改为具名导入 { 函数名… }、去掉两处类名前缀后，工具文件不动，clean 后全量编译通过：修法（出处：卡里修好并验证过）
- 命名空间可以 X.member 访问，但不能被用作对象（不能赋给变量），错误码 10605114：选 export namespace 时的限制（出处：typescript-to-arkts-migration-guide.md，命名空间不能被用作对象）
- 10505001 是 TSC 原生报错，常见原因含类型或变量未定义：has no exported member 归在这一类，按报错描述改导入导出（出处：errorcode-tsc.md，10505001 TSC原生报错）
- 命名空间中不支持非声明语句，错误码 10605116：namespace 里只能放声明（函数、变量声明），初始化写进函数（出处：typescript-to-arkts-migration-guide.md，不支持命名空间中的非声明语句）
未核实：卡里观察到的编译行为出自鸿蒙 SDK API 24/21，本机核实用 API 23
