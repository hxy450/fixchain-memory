# 对象字面量作实参、返回值或回调返回值时，落到已声明的 class/interface

审的是：代码
触发（任一种）：
- 写错的样子：`.map((item) => ({ … }))` 或没标返回类型的箭头函数里 `return { … }`，或用 `{ … } as T` 充当返回值
- 写错的样子：把内联对象字面量直接传给形参是 `Record<string, string>` 或 `Object` 的方法（如请求工具的查询参数、请求体）
适用范围：目标工程启用 ArkTS 严格检查，写请求参数、接口解析结果和回调返回值时
做法：
- 每个对象字面量都对应已声明的 class/interface：回调写明返回类型（`.map((item): <元素类> => …)`），或先 `new` 类实例再赋值返回
- 形参是 Record 或 Object 时也不传内联字面量，改传已声明类型的实例（查询参数见 Map 的写法）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- arkts-no-untyped-obj-literals，级别错误，错误码 10605038：对象字面量要显式标注类型；初始化 any、Object、object 类型，带方法的类或接口，带含参构造函数的类，带 readonly 字段的类时都不能用字面量（出处：typescript-to-arkts-migration-guide.md，需要显式标注对象字面量的类型）
- 函数实参用字面量时，先声明 class T 并把形参写成 (v: T) => void，字面量才有类型：官方的建议改法（出处：arkts-more-cases.md，函数实参使用了object literal）
- 解析函数和回调的返回值改为显式类后通过编译：修好后的写法（出处：卡里修好并验证过）
