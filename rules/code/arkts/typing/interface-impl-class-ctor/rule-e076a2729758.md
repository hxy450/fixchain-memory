# 按编译报错新写类时不用 constructor(public x)，改字段声明加构造体赋值

审的是：代码
触发（任一种）：
- 写错的样子：新类写成 `constructor(public id: number, …) {}` 这类构造参数属性
适用范围：目标工程启用 ArkTS 严格检查，按编译报错把匿名对象改成类时
做法：
- 写成字段声明加构造体赋值：`id: number; constructor(id: number) { this.id = id; }`
- 改完全局搜同类写法：`{ id:`、`Array<{`、`constructor(public`、`[key: string]`、调用里直接写 `{` 的参数
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- arkts-no-ctor-prop-decls，级别错误，错误码 10605025：禁止在构造函数里声明类字段，字段都要在 class 作用域内显式声明（出处：typescript-to-arkts-migration-guide.md，不支持在`constructor`中声明字段）
- class Person { public name: string constructor(name: string) { this.name = name; } }：官方的建议改法（出处：arkts-more-cases.md，arkts-no-ctor-prop-decls）
