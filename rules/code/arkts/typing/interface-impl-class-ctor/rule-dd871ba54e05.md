# 只含方法签名的依赖接口，传 implements 它的具名类实例，不用箭头函数对象字面量

审的是：代码
触发（任一种）：
- 读到：依赖接口（`interface`）里只声明方法签名；修编译错的参考对 `arkts-no-untyped-obj-literals` 只给「赋给类型变量」的修法；写错的样子：把箭头函数属性的对象字面量（`{ name: () => … }`）直接作实参传给要该接口的方法，或先赋给标了该接口类型的变量再传
适用范围：ArkTS 里给只含方法签名的接口提供实现（如收口接线时给运行时传依赖）时
做法：
- 写一个 class <实现类> implements <接口> { <方法>(): <返回类型> { … } }，把 new <实现类>() 作实参传入；不用对象字面量，也不靠先赋给类型变量
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 在以下上下文中不支持使用字面量初始化类和接口：…初始化带有方法的类或接口：规则 arkts-no-untyped-obj-literals，级别错误，错误码 10605038（出处：typescript-to-arkts-migration-guide.md，需要显式标注对象字面量的类型）
- 对象字面量先赋给类型变量仍报同一规则；改为 implements 接口的具名类后通过：修好后的写法（出处：卡里修好并验证过）
未核实：卡里的编译报错出自 API 26（target_sdk 26.0.0）的工具链，文档副本没有标 API 版本
