# @BuilderParam 的默认值引用 @Builder 函数或方法，不用箭头函数

审的是：代码
触发（任一种）：
- 读到：组件要提供可选的内容插槽（挂载点），设计或派工里写了插槽默认为空、用 @BuilderParam 接收；写错的样子：写成 @BuilderParam 插槽名: () => void = (): void => {} 这类箭头函数默认值；编译报 @BuilderParam property can only initialized by @Builder function；或全局 @Builder 插在 @ComponentV2 和 struct 之间
适用范围：自定义组件里声明带默认值的 @BuilderParam 插槽时
做法：
- 默认值引用组件内的 @Builder 方法（@Builder emptySlot() {} 后写 = this.emptySlot）或全局 @Builder 函数（@Builder function emptySlot() {} 后写 = emptySlot）
- 新增的全局 @Builder 函数放在 @ComponentV2 装饰器之前，不插进装饰器和 struct 之间
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- @BuilderParam装饰的方法只能被自定义构建函数（@Builder装饰的方法）初始化：默认值只能是 @Builder 函数或方法（出处：arkts-builderparam.md，初始化@BuilderParam装饰的方法）
- @BuilderParam customBuilderParam: () => void = this.doNothingBuilder; @BuilderParam customOverBuilderParam: () => void = overBuilder;：组件内 @Builder 方法和全局 @Builder 函数两种默认值写法（出处：arkts-builderparam.md，初始化@BuilderParam装饰的方法）
- declare const BuilderParam: PropertyDecorator; declare const Builder: MethodDecorator;：@BuilderParam 裸写；@Builder 装饰方法或函数（出处：鸿蒙 SDK 的 ets/component/common.d.ts，BuilderParam、Builder）
