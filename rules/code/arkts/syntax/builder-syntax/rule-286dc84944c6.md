# 普通方法里写了 Column / Row 等组件语法时，改为 @Builder 并用 this.方法() 调用

审的是：代码
触发（任一种）：
- 写错的样子：组件语法写在不带 @Builder 的普通 private 方法里（方法体内有 Column() {...}、Row() {...} 等尾随闭包），build() 里以 this.方法(x) 调用；编译报 UI component 'Column' cannot be used in this place
适用范围：ArkTS 自定义组件里抽出来复用的 UI 片段
做法：
- 方法体里出现 Column / Row / Text 等组件语法，就加 @Builder（显式写 : void），在 build()、ListItem、Repeat.each 里以 this.方法() 调用；普通 private 方法只放数据逻辑
- 交付前搜未加 @Builder 却含组件尾随闭包的方法，逐一改正
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 10905236：UI component 'xxx' cannot be used in this place.：不在 @Builder 方法或 build() 方法里使用组件时的编译错误；处理是把组件放进 @Builder、build() 或页面间转场方法（出处：_ark_ui_compile.md，10905236 组件使用校验异常）
- 自定义组件内可定义一个或多个 @Builder 函数，是组件私有的特殊成员函数；允许在 build 函数和其他自定义构建函数中调用：@Builder 的定义和调用位置（出处：arkts-builder.md，私有自定义构建函数）
- 改为多行 @Builder 方法、条件块补花括号后编译通过：修好的写法（出处：卡里修好并验证过）
