# 资源写完交构建前，对输出目录里每个 media 文件名和 element name 校验 [a-zA-Z0-9_]

审的是：资源
触发（任一种）：
- 写错的样子：resources 下 media 文件名或 element 的 name 含 `$`、`-`、`.` 等 [a-zA-Z0-9_] 以外的字符；复查只看了转换失败清单，没看输出目录
适用范围：批量生成 resources（media、element）之后、交给构建之前
做法：
- 列出输出目录里实际写出的 media 文件名（去扩展名）和 element 各 json 的 name，逐个匹配 ^[a-zA-Z0-9_]+$，不合法的改名或剔除；对象是输出目录清单，不只是转换失败清单
- 改名前确认代码里没有引用旧名，有引用的同步改 $r('app.media.<新名>')
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 资源名要匹配 [a-zA-Z0-9_]，不合法时构建报 Resource Pack Error：Invalid resource name：校验用的字符集（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
