# 为 ?attr/xxx 新建颜色键时分别查各主题的值，base 和 dark 各写各的

审的是：资源
触发（任一种）：
- 读到：源布局 android:textColor="?attr/colorOnSecondary" 这类引用主题属性的颜色，styles.xml 里浅色、深色主题各有一块；写错的样子：resources/base/element/color.json 和 resources/dark/element/color.json 里这个颜色键写了同一个值（凭「accent 底上偏白」推断）
适用范围：为源端 ?attr 颜色属性在目标端新建 color 资源键时
做法：
- 在 styles.xml 的浅色主题块和深色主题块里分别查这个属性（检索模式不能把目标属性名排除在外），浅色值写进 base/element/color.json，深色值写进 dark/element/color.json
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 颜色模式限定词：dark 深色模式，light 浅色模式：深色值放 dark 限定词目录（出处：resource-categories-and-access.md，限定词目录）
- 深色主题里该属性的值和浅色不同，按 Android 主题改正 dark 值后显示正确：验证过的做法（出处：卡里修好并验证过）
针对本应用要查的：
- 这个主题属性在各主题里的值：源工程 res/values 的 styles.xml / themes.xml 里应用的浅色、深色（及纯黑）主题块；主题块里没写时沿 parent 链到依赖库主题；逐个主题读 <item name="colorOnSecondary"> 这类条目，顺着 @color / @android:color 引用解析到色值，按主题分别写进对应限定词目录
