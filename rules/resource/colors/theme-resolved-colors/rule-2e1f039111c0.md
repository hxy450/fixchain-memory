# 图标或控件引用主题属性时，color.json 在 base 和 dark 各写一个键，值取主题解析值

审的是：资源
触发（任一种）：
- 读到：源图标或控件着色引用主题属性：矢量 android:fillColor="?attr/…"、app:foregroundColor="?attr/…"、Toolbar 主题的 colorControlNormal；写错的样子：resources/base/element/color.json 里没有对应的键，或者只有 base 值、resources/dark/element/color.json 里没有深色值
适用范围：资源前置阶段导出颜色资源时，被图标或控件引用的主题属性
做法：
- 每个被引用的主题属性在 resources/base/element/color.json 和 resources/dark/element/color.json 各写一个同名键，值是浅色、深色主题下解析出的颜色
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- {"color": [{"name": "<键>", "value": "#AARRGGBB"}]}：color.json 的结构；八位十六进制，前两位是透明度（出处：resource-categories-and-access.md，资源文件示例）
- 颜色模式限定词：dark 深色、light 浅色；dark 的 element 目录是 dark/element：深色值放 resources/dark/element/color.json（出处：resource-categories-and-access.md，限定词目录；创建资源目录和资源文件）
针对本应用要查的：
- 主题属性在浅色、深色主题下的值：源工程 res/values/styles.xml、themes.xml 和 res/values-night/ 下应用主题的 <item name="…">；顺着 ?attr/、@color/ 引用解到颜色字面量，浅色写进 base，深色写进 dark
来源：1 张卡，1 个应用
