# M3 主题的对话框遮罩色资源按 0.32 黑写成 #52000000，不用平台旧默认 0.6 的 #99000000

审的是：资源
触发（任一种）：
- 读到：styles.xml 的应用主题沿 parent 链继承 `Theme.Material3.*`，主题里有 `android:backgroundDimEnabled`=true；写错的样子：base 或 dark 的 color.json 里新增的遮罩色是 `#99000000`（按平台默认 backgroundDimAmount 0.6 推出）
适用范围：为对话框、底部面板的遮罩新增颜色资源时，源端主题基底是 Theme.Material3.*
做法：
- 遮罩色的 alpha 取源主题 backgroundDimAmount × 255 取整：M3 是 0.32 → 0x52，写 "#52000000"；base 和 dark 的 color.json 各一项，同名
- 旧的 #99000000 若已被别处当阴影色复用，不改它的值，另新增遮罩专用的颜色资源
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- m3_comp_scrim_container_opacity = 0.32，Material3 对话框主题的 android:backgroundDimAmount 引用它：M3 对话框遮罩不透明度（出处：com.google.android.material:material 包内 res/values/values.xml，m3_comp_scrim_container_opacity、Base.ThemeOverlay.Material3.Dialog（按应用依赖的版本））
- backgroundDimAmount = 0.6：平台基础主题的旧默认，Material3 主题已覆盖（出处：Android SDK 平台资源 data/res/values/themes.xml，Theme 的 backgroundDimAmount（按应用的 compileSdk 取对应平台））
- 新增 #52000000 的遮罩色（浅、深色都加），旧 #99000000 保留给阴影用：返修后保留的资源写法（出处：卡里修好并验证过）
针对本应用要查的：
- 源主题实际的 backgroundDimAmount：源工程 styles / themes 里应用主题及对话框主题的 parent 链上的 android:backgroundDimAmount；没覆写时查 Material 库 values.xml 里对应 Theme.Material3 的值；alpha = round(值 × 255) 转两位十六进制，拼成 #AA000000
