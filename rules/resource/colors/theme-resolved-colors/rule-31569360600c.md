# 平台主题提供的 ActionBar 外观，从本机 Android SDK 平台资源取值和原图，不凭记忆近似

审的是：资源
触发（任一种）：
- 读到：主题 parent 链止于 android:Theme.Holo，ActionBar 是主题提供的窗口装饰、不在布局 XML 里；写错的样子：color.json 里写凭记忆的近似底色（如 #FF333333，注「待核」）；media 里没有 Up 尖角和溢出按钮的原图
适用范围：源端平台主题（Theme.Holo 等）提供 ActionBar 外观和图标、目标端自绘标题栏时的颜色与图片资源
做法：
- 按 actionBarStyle → Widget.Holo.ActionBar 解析：背景取 @drawable/ab_transparent_dark_holo（透明底，顶部 1dp 白色 10%，底部 2dp #33B5E5），不写成纯色
- Up 尖角 homeAsUpIndicator → ic_ab_back_holo_dark → ic_ab_back_holo_dark_am、溢出 → ic_menu_moreoverflow_holo_dark → ic_menu_moreoverflow_normal_holo_dark，从平台 drawable-xxhdpi 复制原图进 media
- 查过本机 SDK 仍缺的才标待核
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- <item name="background">@drawable/ab_transparent_dark_holo</item>：Holo 深色 ActionBar 的背景 drawable（各密度目录是 .9.png）（出处：Android SDK 平台资源 data/res/values/styles_holo.xml，Widget.Holo.ActionBar（按应用的 compileSdk 取对应平台））
- ab_transparent_dark_holo：透明底，顶部 1dp 白色 10%，底部 2dp #33B5E5：按 9-patch 原图读出的外观（出处：卡里修好并验证过）
- <item name="homeAsUpIndicator">@drawable/ic_ab_back_holo_dark</item>；ic_ab_back_holo_dark 是 <bitmap android:src="@drawable/ic_ab_back_holo_dark_am" android:autoMirrored="true">：Up 尖角原图是 ic_ab_back_holo_dark_am，带自动镜像（出处：Android SDK 平台资源 data/res/values/themes_holo.xml，homeAsUpIndicator；data/res/drawable/ic_ab_back_holo_dark.xml（按应用的 compileSdk 取对应平台））
- Widget.Holo.ActionButton.Overflow 的 src = @drawable/ic_menu_moreoverflow_holo_dark，它是 selector，item 为 @drawable/ic_menu_moreoverflow_normal_holo_dark：溢出按钮原图（出处：Android SDK 平台资源 data/res/values/styles_holo.xml，Widget.Holo.ActionButton.Overflow；data/res/drawable/ic_menu_moreoverflow_holo_dark.xml（按应用的 compileSdk 取对应平台））
- actionBarSize = @dimen/action_bar_default_height（values 48dip、values-land 40dip）：标题栏高度（出处：Android SDK 平台资源 data/res/values/themes_holo.xml，Theme.Holo actionBarSize；data/res/values*/dimens.xml，action_bar_default_height（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 应用 compileSdk 对应平台里的这些资源：Android SDK 的 platforms/android-<compileSdk>/data/res：values/themes_holo.xml、styles_holo.xml、dimens.xml，values-land、values-sw600dp、values-w480dp，drawable-xxhdpi；按上面的资源名逐级解析到 drawable 或 dimen；图片从 drawable-xxhdpi 复制进目标 media，尺寸值按限定词分别记下
未核实：ab_transparent_dark_holo 的线宽和颜色是读 9-patch 图得出的，本机没有文字出处
