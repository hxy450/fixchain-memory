# 源端依赖 appcompat 或 material 时，把库限定目录的尺寸导出到 base 和 horizontal

审的是：资源
触发（任一种）：
- 读到：模块构建脚本声明 androidx.appcompat:appcompat / com.google.android.material:material，布局或主题引用 ?attr/actionBarSize 等库主题属性；应用自己的 res 里没有 values-land 覆盖；写错的样子：只在 resources/base/element/float.json 写标题栏高度、字号的单值，没有 resources/horizontal/element/float.json 覆盖；资源映射表写「零外部资源依赖库」
适用范围：资源迁移阶段，源工程依赖 UI 库、横竖屏差异来自库的限定目录时
做法：
- 不写「零外部资源依赖库」；先构建 APK、用 apktool 取含依赖库的合并资源；构建不了时，从 Gradle 缓存里对应版本 aar 的 res/values-land 等目录取被布局、主题属性引用的尺寸（如 abc_action_bar_default_height_material、abc_text_size_title_material_toolbar）
- 导出成同名的 base 与 horizontal 资源：resources/base/element/float.json 写竖屏值、resources/horizontal/element/float.json 写横屏值，并在映射表列出这些库资源键供页面引用
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 限定词「横竖屏」取值 vertical（竖屏）、horizontal（横屏）：对应安卓的 port / land 限定目录（出处：resource-categories-and-access.md，限定词目录）
- 匹配优先级：移动国家码和移动网络码 > 区域 > 横竖屏 > 设备类型 > 颜色模式 > 屏幕密度：horizontal 目录里的同名资源在横屏时覆盖 base（出处：resource-categories-and-access.md，限定词目录与设备状态的匹配规则）
- abc_action_bar_default_height_material：values 56dp、values-land 48dp；abc_text_size_title_material_toolbar：values 20dp、values-land 14dp：要导出的两组值（出处：androidx.appcompat:appcompat 包内 res/values/values.xml、res/values-land/values-land.xml（按应用依赖的版本））
- 新增 horizontal/element/float.json（高度 48vp、标题字号 14fp），base 里竖屏值，页面改引资源键：修好后上机核对的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 依赖库在各限定目录里被引用到的尺寸：Gradle 缓存里按应用依赖版本解包的 aar（transforms 下的 appcompat-<版本>、material-<版本>）的 res/values*/ 目录，按资源名找；读出各限定目录的数值，竖屏写进 base、横屏写进 horizontal
