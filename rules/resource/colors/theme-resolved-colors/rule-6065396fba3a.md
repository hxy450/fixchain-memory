# 启动窗底色取源主题的背景色，Light 主题无 values-night 时 dark 也写同一浅色

审的是：资源
触发（任一种）：
- 读到：源主题继承 Theme.AppCompat.Light 等 Light 系主题、没有 values-night，主题里没写 android:windowSplashScreenBackground；写错的样子：start_window_background 在 base/element/color.json 保留脚手架 #FFFFFF、dark/element/color.json 保留 #000000，资源映射里记为「模板保留」
适用范围：为鸿蒙启动窗选底色、源端 targetSdk ≥ 31 走系统启动画面时
做法：
- base 下的 start_window_background 写源主题解析出的 windowBackground 颜色
- 源主题是 Light 系且没有 values-night 时，dark 下的 start_window_background 写同一浅色，不保留模板 #000000
- 底色依赖 AppCompat 等库的默认值时，到库资源里查出确定值；暂时查不到就在资源映射里登记为待核项，不写「模板保留」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- windowSplashScreenBackground 不写时，系统从 windowBackground 计算启动画面背景色：源端启动底色的来源（出处：Android SDK 平台资源 data/res/values/attrs.xml，Window 的 windowSplashScreenBackground（按应用的 compileSdk 取对应平台））
- v21 起 Platform.AppCompat.Light → Platform.V21.AppCompat.Light，父主题是 android:Theme.Material.Light.NoActionBar：AppCompat Light 主题在 Android 5.0+ 上的背景来自平台 Material Light（出处：androidx.appcompat:appcompat 包内 res/values-v21/values-v21.xml，Platform.V21.AppCompat.Light（按应用依赖的版本））
- Theme.Material.Light：windowBackground = ?attr/colorBackground，colorBackground = @color/background_material_light：解析顺序：windowBackground 指向 colorBackground（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material.Light（按应用的 compileSdk 取对应平台））
- background_material_light = @color/material_grey_50 = #fffafafa：主题没覆盖时的最终底色（出处：Android SDK 平台资源 data/res/values/colors_material.xml，background_material_light、material_grey_50（按应用的 compileSdk 取对应平台））
- startWindowBackground：启动页面背景颜色资源的索引，如 $color:start_window_background：目标端启动窗底色的配置位置（出处：module-configuration-file.md，abilities 标签 startWindowBackground）
- base 与 dark 的 start_window_background 都改为 #fffafafa 后，冷启（含深色模式）与源端一致：修复后的观察（出处：卡里修好并验证过）
针对本应用要查的：
- 源主题最终的 windowBackground 颜色：源工程 AndroidManifest 的 android:theme → res/values*/styles.xml 或 themes.xml 里该主题及其 parent 链；应用自己没写的，到依赖库（如 appcompat 包内 res/values*/values*.xml）和平台 themes_material.xml 顺着 parent 找；按 Activity 主题 → 应用主题 → 库主题 → 平台主题的顺序找第一个 android:windowBackground（或它引用的 colorBackground），再把 @color 引用解析到色值；例：Theme.AppCompat.Light 没被覆盖时是 #fffafafa
