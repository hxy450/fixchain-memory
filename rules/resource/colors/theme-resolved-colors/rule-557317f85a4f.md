# 落 @android:color 和 ?android:attr 的值时，从本机 SDK 平台资源取实值并注明来源

审的是：资源
触发（任一种）：
- 读到：源 XML 引用 @android:color/darker_gray、?android:attr/expandableListPreferredItemPaddingLeft 这类平台值；写错的样子：color.json / float.json 里写的是凭记忆的值（如 darker_gray 写成 #FF444444、缩进写成 60vp），或报告写「依据为 AOSP attr 默认值，待真机校对」
适用范围：资源迁移时为平台或库提供的颜色、尺寸落定目标端资源值
做法：
- 从本机 Android SDK 平台资源（data/res/values 下的 colors.xml、themes_material.xml、styles_material.xml）或依赖库 aar 的 res 取实值，写进 color.json / float.json，并在注释注明来源文件
- 下游发现资源值和平台不符时，在本任务内改值，或登记带确定值的移交项；不只沿用错误的键
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- darker_gray = #aaa：平台颜色的实值（出处：Android SDK 平台资源 data/res/values/colors.xml，darker_gray（按应用的 compileSdk 取对应平台））
- expandableListPreferredItemPaddingLeft = 40dip；expandableListPreferredChildPaddingLeft = ?attr/expandableListPreferredItemPaddingLeft：组头和子项缩进都是 40dip（Theme 和 Theme.Material 系相同）（出处：Android SDK 平台资源 data/res/values/themes_material.xml，expandableListPreferredItemPaddingLeft（按应用的 compileSdk 取对应平台））
- 修复把两个缩进改为 40vp、darker_gray 改为 #AAAAAA：按平台资源改值后与源端一致（出处：卡里修好并验证过）
针对本应用要查的：
- 其他 ?android:attr/* 和 @android:color/* 的值：Android SDK 平台资源 data/res/values/ 下：颜色在 colors*.xml，主题属性在 themes*.xml（按应用主题族），控件默认样式在 styles*.xml；@android:color/x 直接读 <color name="x">；?android:attr/x 先找应用主题族里 <item name="x">，再顺着引用解析到具体值
