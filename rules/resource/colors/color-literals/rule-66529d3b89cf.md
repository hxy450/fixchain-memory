# 源色值没有等值资源时，color.json 追加专属键，不改共享 token 的值

审的是：资源
触发（任一种）：
- 读到：源布局元素的 android:textColor 等写了字面色值，工程颜色 json 里同前缀、同色系 token 的 value 与它不同；写错的样子：color.json 里没有 value 等于源色值的项（同一批其他颜色都按源值建了键，唯独漏了这一个），或把被其他页面共享的 token 的 value 改成了本页色值
适用范围：界面转换者可以向共享资源文件追加颜色键时
做法：
- 重读最新的颜色 json 后追加一项 { "name": 页面或元素专属名, "value": "#FF" + 源 RRGGBB }
- 不修改被其他页面共享的 token
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- #RRGGBB 解析时 alpha 置为 FF，与 #FFRRGGBB 相同：新键的 value 可写成 #FF 加源端 RRGGBB（出处：android.graphics.Color#parseColor）
- 追加按源值补 alpha 的等值专属键后页面颜色与源一致，共享 token 保持原值：修法（出处：卡里修好并验证过）
