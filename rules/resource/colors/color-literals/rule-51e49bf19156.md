# 源端渐变用到的调色板色阶在 color.json 缺条目时，按调色板名补上同值条目

审的是：资源
触发（任一种）：
- 读到：源端主题里 val 名字 = Color(0xAARRGGBB) 定义了渐变用到的色阶，组件经 Brush 用它们着色；写错的样子：color.json 里没有这些色阶的 name 或同值条目（只补了别的条目），代码改用了值不同的已有条目
适用范围：目标工程要求颜色走 color.json 资源引用、源端渐变来自主题调色板时
做法：
- 在 resources/base/element/color.json 的 color 数组里按调色板名新增 {"name": 调色板名的小写下划线写法, "value": "#aarrggbb"}，值照源端 0xAARRGGBB 逐位抄
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- {"color": [{"name": "…", "value": "#ffff0000"}]}：color.json 的结构；value 是 8 位十六进制，前两位透明度（出处：resource-categories-and-access.md，资源文件示例）
- 补上缺的色阶条目后，渐变引用的值和源端一致：缺条目是借用错值令牌的起因（出处：卡里修好并验证过）
针对本应用要查的：
- 渐变实际用到的色阶和它们的值：源工程主题 Kotlin 文件里渐变列表 listOf(...) 的元素，再顺着元素名找 Color(0x…) 常量；逐个色阶写成 #aarrggbb，和 color.json 已有条目比，没有同值的就新增
