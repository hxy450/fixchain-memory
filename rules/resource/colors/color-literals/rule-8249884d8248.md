# 深色 color.json 的值从浅色结果派生时，逐项对照安卓深色源值

审的是：资源
触发（任一种）：
- 读到：源 res/values-night*/colors.xml（或同义的 *_dark / *_light 颜色对）给出深色值；写错的样子：目标 dark/element/color.json 的值是从 base 的 color.json 转换结果复制或派生来的（如把 *_dark 复制成 *_light），和安卓同名源值不一致
适用范围：生成鸿蒙 dark 目录颜色资源时，有值是从 base 转换结果派生而不是从安卓深色源值直接转换的
做法：
- dark/element/color.json 的每个值按安卓 values-night 同名（或同义）源值写；从 base 派生的值逐项复核，与源值归一化后相等才保留
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 颜色模式限定词：dark（深色模式）、light（浅色模式）：深色值放在 dark 限定目录（出处：resource-categories-and-access.md，限定词目录（表5 限定词取值要求））
- 派生时把 base 里已经出错的值复制进 dark；按安卓深色源值改正后一致：派生会把上游错误带过去（出处：卡里修好并验证过）
针对本应用要查的：
- 每个深色键对应的安卓源值：源工程 res/values-night*/colors.xml 里的同名 <color>；没有同名键时找同义的 *_dark 颜色；按 #AARRGGBB 原样作为 dark color.json 里这个键的值
来源：1 张卡，1 个应用
