# strings.xml 的值跨多行书写时，转换先按 aapt2 折叠引号外空白再处理转义

审的是：资源
触发（任一种）：
- 读到：源 res/values*/strings.xml 或 plurals 里的 <string> / <item> 值跨多行书写：正文后有物理换行和缩进，下一行行首再写 \n 转义；写错的样子：目标 string.json 的 value 里出现 \n\n 双换行或残留的缩进空格（转换只 strip() 了首尾就把 \n 转成换行）
适用范围：用脚本把安卓 strings.xml / plurals 批量转成鸿蒙 element 下 string.json、plural.json 时的取值
做法：
- 取值按 aapt2 语义：引号外的连续空白（含物理换行和缩进）先折叠成一个空格并去掉首尾，再处理 \n、\t、\uXXXX 等转义；不要只 strip 首尾
- 写完后逐语言对照源 XML，凡目标值含连续 \n\n 的都列出来和源值复核
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 按 aapt2 语义重写 string / plural 值后，多行源值不再出现空行：修好后的取值方式（出处：卡里修好并验证过）
未核实：aapt2 的空白折叠规则按卡写，本机来源里没有原文
