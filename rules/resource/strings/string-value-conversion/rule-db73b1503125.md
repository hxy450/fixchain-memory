# strings.xml 的值带反斜杠转义时，转成 string.json 前全部还原，不留反斜杠

审的是：资源
触发（任一种）：
- 读到：values*/strings.xml 的 <string> 值里有 \'、\"、\@、\?、\#、\\、\n、\t、\uXXXX 这类反斜杠转义；写错的样子：element/string.json 的 value 里还留着反斜杠加字符（文件里是 \\@、\\? 这样），或者只还原了 \' 和 \" 两种
适用范围：资源迁移阶段用脚本把 strings.xml（含各 locale）转成 element/string.json 时，去掉外层引号之后的转义还原
做法：
- 去掉外层引号后把反斜杠转义还原成字符：\' → '、\" → "、\@ → @、\? → ?、\# → #、\\ → \、\n → 换行、\t → 制表符、\uXXXX → 对应字符；遇到不认识的转义也不把反斜杠原样写进目标值
- 写完对全部 locale 核对：目标值里仍含反斜杠加字符的条目为 0；补位用的 base 值也先过这项核对
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 带 \@ 的值去掉反斜杠后显示正确：返修时修正了残留 \@ 的那一条（出处：卡里修好并验证过）
