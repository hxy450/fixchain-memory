# 说明文案写死在布局 android:text 时，string.json 逐字照抄源文、保留分行

审的是：资源
触发（任一种）：
- 读到：布局 XML 的 TextView 上 android:text 是写死的长文案（不是 @string/ 引用）；写错的样子：目标 resources/base/element/string.json 里对应条目的 value 是概括、改写或通用的说明文字，或者源文的分行没了
适用范围：静态说明页、图文页的正文和标题直接写在源布局 XML 里时
做法：
- 每段 android:text 原文逐字写进 string.json 一个条目的 value，不改字、不合并；源文里的分行在 JSON 字符串里写成 \n
- 某个布局的正文没读到时，不写概括或自拟的替代文案，在交回的报告里写明缺的是哪个布局的哪几段
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- {"string": [{"name": "<名>", "value": "<原文>"}]}：string.json 的结构（出处：resource-categories-and-access.md，资源文件示例）
- $r('app.string.<名>')：页面里引用字符串资源的写法（出处：resource-categories-and-access.md，资源访问）
