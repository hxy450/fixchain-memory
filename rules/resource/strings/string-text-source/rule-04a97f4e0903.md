# 弹窗文案迁到 string.json 时按源布局引用的 strings 逐条写，不只写自拟的标题和按钮

审的是：资源
触发（任一种）：
- 读到：源弹窗布局里标题、前缀、说明文字都以 @string/… 引用 strings.xml；写错的样子：目标 base 和 en_US 的 string.json 只写了自拟的标题和按钮键，缺源布局里的说明、前缀文案，标题文案也和源不同
适用范围：迁移源端弹窗的文案资源时
做法：
- 按源布局里每个 @string/… 引用，从对应语言的 strings.xml 取原文，逐条写进目标各语言的 string.json（base、en_US 等）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 修复时补齐双语的标题、前缀和说明文案：修好的结果（出处：卡里修好并验证过）
针对本应用要查的：
- 每段文案的原文和各语言版本：源工程 res/values/strings.xml 及 values-en 等语言目录下的 strings.xml，按布局里的 @string 名找；逐条照抄到目标 resources/base/element/string.json 和对应语言目录
