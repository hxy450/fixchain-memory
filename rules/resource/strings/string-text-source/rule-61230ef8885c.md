# 偏好对话框用平台 cancel 文案时，string.json 按源端语言建多语言资源，不写死英文

审的是：资源
触发（任一种）：
- 读到：<ListPreference> 或 <EditTextPreference> 没写 android:negativeButtonText，按钮文案取平台 @android:string/cancel；写错的样子：目标各语言目录的 element/string.json 里没有对应的 cancel 文案，或只在 base 写死 "Cancel"，或代码里直接写 'Cancel' / "CANCEL" 字面量
适用范围：源端 DialogPreference 的负按钮沿用框架 cancel 文案时，目标工程 resources 下各语言目录的 element/string.json
做法：
- 在 resources/base/element/string.json 和源端支持的每个语言限定目录（如 resources/de、resources/zh_CN）的 element/string.json 里各加一条同名取消文案，值取 Android SDK 平台资源对应 values-<语言>/strings.xml 里 name="cancel" 的译文（base 为 "Cancel"，de 为 "Abbrechen"）
- 对话框负按钮只用 $r('app.string.<取消文案名>') 引用这条资源，不写文案字面量
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- <string name="cancel">Cancel</string>：默认语言的取消文案（出处：Android SDK 平台资源 data/res/values/strings.xml，cancel（按应用的 compileSdk 取对应平台））
- values-de：Abbrechen；values-zh-rCN：取消；values-ja：キャンセル：各语言译文的例子，其余语言照同名资源取（出处：Android SDK 平台资源 data/res/values-de/strings.xml、values-zh-rCN/strings.xml 等各语言目录，cancel（按应用的 compileSdk 取对应平台））
- 语言限定词由 2~3 个小写字母组成，如 zh、en：目标资源目录按语言命名（出处：resource-categories-and-access.md，限定词）
- 语言限定词用下划线连接，如 resources/zh_CN/element/string.json：目标语言目录的写法（出处：resource-categories-and-access.md，限定词目录）
针对本应用要查的：
- 源端支持哪些语言、各语言的平台 cancel 文案：源工程 res 下的 values-<语言> 目录列表；Android SDK 平台资源 data/res/values-<语言>/strings.xml 的 string/cancel；对源端有的每个语言目录，在目标建对应的 <语言>_<地区> 限定目录，读出平台 cancel 的译文写进它的 string.json
