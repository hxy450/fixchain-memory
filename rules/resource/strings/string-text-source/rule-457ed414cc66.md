# 接入 App 内分享渠道时各语言 string.json 都补上渠道名称

审的是：资源
触发（任一种）：
- 读到：源端分享面板的 App 内渠道有自己的显示名称；写错的样子：各语言的 string.json 只新增分享不可用一类提示，没有这个渠道的名称条目
适用范围：分享面板新增或补回渠道时的字符串资源
做法：
- 在 base 和各语言目录的 string.json 里都加上渠道名称条目，分享弹窗的选项引用它
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 三份 string.json 补上渠道名称条目：修好的资源（出处：卡里修好并验证过）
针对本应用要查的：
- 渠道名称在源端各语言的文案：源工程 res/values*/strings.xml 里分享渠道的名称；按语言目录逐个照抄到目标对应语言的 string.json
