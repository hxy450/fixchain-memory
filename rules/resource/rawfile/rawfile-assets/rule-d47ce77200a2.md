# 把预置数据 JSON 拷进 rawfile 时，交回里写明覆盖范围并和运行期输入比对

审的是：资源
触发（任一种）：
- 读到：源工程 `assets/` 下按日期等键查表的预置 JSON；写错的样子：原样拷进 resources/rawfile/，交回只写行数和 SHA256 校验，没写覆盖的起止范围，也没和运行期输入域比对
适用范围：资源转换阶段迁移预置数据资产（JSON、DB）时
做法：
- 拷贝时读出首末记录的键和条数，在交回里写明覆盖范围，并与运行期输入域（当前日期、可选年份）比对；覆盖不足要在交回里写明，交给规格写替代算法或降级方案
针对本应用要查的：
- 预置资产的覆盖范围：源工程 assets/ 下那份 JSON；读首条和末条记录的键（如日期）和总条数
