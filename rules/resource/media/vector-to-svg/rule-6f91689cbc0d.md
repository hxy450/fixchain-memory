# 宣告图标转换通过前逐个产物做结构检查，抽样比对要覆盖含弧段的图标

审的是：资源
触发（任一种）：
- 读到：AAR 里的图标路径是 PathBuilder 调用，转换靠自写字节码解析；写错的样子：映射表写「bbox + 锚点 + 交叉比对 PASS」，抽样只用了不含弧段的图标；产物里有只含 `M`/`m` 的子路径
适用范围：批量转换图标后写转换结论和资源映射表时
做法：
- 逐个 SVG 检查：每个子路径至少有一条绘制指令，解析到的 PathBuilder 调用数等于输出指令数
- 与官方 SVG 抽样比对时样本覆盖实际出现过的每类指令（含弧段）；比出的差异先排除比对器和转换器自身的问题，再记为版本漂移
未核实：子路径中间丢掉弧段时不会留下只移动的子路径，这项结构检查查不出，要靠调用数与指令数相等那一项
来源：1 张卡，1 个应用
