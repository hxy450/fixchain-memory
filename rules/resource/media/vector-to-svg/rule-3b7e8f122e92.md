# VectorDrawable 转 SVG 时 viewBox 只取 viewport，宽高取去 dp 的显示尺寸

审的是：资源
触发（任一种）：
- 读到：<vector> 的 android:width / android:height（dp 显示尺寸）和 android:viewportWidth / android:viewportHeight 不相等，如 48dp/24、12dp/24、24dp/960、20×30dp/3×4.5；写错的样子：SVG 根元素的 viewBox 等于 width/height（如 viewBox="0 0 48 48"），path 的 d 仍是原 viewport 坐标；图标只占画布一角或近乎空白
适用范围：资源迁移阶段把安卓 VectorDrawable 转成 media 下的 SVG 时（含批量转换脚本）
做法：
- SVG 根元素写 width="<android:width 去 dp>" height="<android:height 去 dp>" viewBox="0 0 <viewportWidth> <viewportHeight>"；转换脚本里两组值分开传，不让同一字段同时生成显示尺寸和坐标系
- 转完对全部 vector 机械对账：每个 SVG 的 viewBox 宽高 = 同名源 vector 的 viewportWidth/Height；抽查样本要含 width ≠ viewport 的图标，不能只查 viewBox 存在或只看组合件
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- viewportWidth / viewportHeight：format="float"，The width (height) of the canvas the drawing is on：pathData 的坐标系，对应 SVG viewBox 的宽高（出处：Android SDK 平台资源 data/res/values/attrs.xml，VectorDrawable 的 viewportWidth、viewportHeight（按应用的 compileSdk 取对应平台））
- width / height：The intrinsic width (height) of the Vector Drawable：dp 显示尺寸，对应 SVG 的 width / height（出处：Android SDK 平台资源 data/res/values/attrs.xml，VectorDrawable 的 width、height（按应用的 compileSdk 取对应平台））
- 按同名源 vector 比对 viewport，把不一致的 viewBox 改成 viewport 后复查为 0 不一致；抽查确认路径是未缩放的原路径：修复时的对账做法（出处：卡里修好并验证过）
