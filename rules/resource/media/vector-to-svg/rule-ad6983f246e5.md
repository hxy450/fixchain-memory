# 源端用 AppCompat 默认返回箭头时，从 AAR 取 pathData 生成 media svg

审的是：资源
触发（任一种）：
- 读到：源码 `setDisplayHomeAsUpEnabled(true)`，主题没覆盖 `homeAsUpIndicator`，用的是 AppCompat 默认的 `abc_ic_ab_back_material`；写错的样子：目标 `resources/base/media` 里没有返回箭头的 svg，转换报告写「无箭头位图资产，用系统符号」
适用范围：源控件依赖 AppCompat / Material 库自带 drawable（返回箭头、复合按钮图形）时
做法：
- 到应用依赖版本的 appcompat AAR 里取 res/drawable/abc_ic_ab_back_material.xml，按它的尺寸、viewport 和 pathData 生成 media 下的 svg，颜色按主题着色
- 库资源确实取不到时才用系统符号，并把这个替代登记进占位登记
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- homeAsUpIndicator = @drawable/abc_ic_ab_back_material：AppCompat 主题默认的返回箭头（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，Base.V7.Theme.AppCompat 的 homeAsUpIndicator（按应用依赖的版本））
- 24dp × 24dp，viewport 24 × 24，android:autoMirrored="true"，android:tint="?attr/colorControlNormal"，pathData M20,11L7.8,11l5.6,-5.6L12,4l-8,8l8,8l1.4,-1.4L7.8,13L20,13L20,11z：abc_ic_ab_back_material 的矢量定义，照它生成 svg（出处：androidx.appcompat:appcompat 包内 res/drawable/abc_ic_ab_back_material.xml（按应用依赖的版本））
- 从 appcompat AAR 取 abc_ic_ab_back_material 生成 media svg 后，箭头形状与源端一致：验证过的做法（出处：卡里修好并验证过）
针对本应用要查的：
- 箭头的着色：源 Activity 主题链上的 colorControlNormal（主题 XML 和库 values.xml 里顺着 parent 找）；解析到色值，写进 svg 的 fill 或目标 Image 的着色；例：暗色 MaterialComponents 主题下为白色
