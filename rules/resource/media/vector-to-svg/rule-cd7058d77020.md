# vector 的 fillColor 是 ?attr 且解析不出时，SVG 写可见默认色并登记，不写成透明

审的是：资源
触发（任一种）：
- 读到：<path android:fillColor="?attr/…">，引用主题属性；写错的样子：转换脚本的主题属性表没收这个属性，SVG 的 <path> 写成 `fill="none"`，未解析的记录只在转换清单的备注里，映射文档没写
适用范围：VectorDrawable 转 SVG 时颜色引用主题属性（?attr/…、?android:attr/…）的 path
做法：
- 主题属性表覆盖源 vector 实际引用的全部 ?attr；按 lookups 解析出颜色写进 fill
- 解析不出时写可见默认色（修复里是 fill="#000000"），并在映射文档逐项列出，注明代码层要给显示它的 Image 加 .fillColor(...) 按主题着色
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- fillColor(value: ResourceColor): ImageAttribute（只对 SVG 生效）：代码层给 SVG 叠加填充色，所以资源里写可见默认色、再在 Image 上按主题着色（出处：鸿蒙 SDK 的 ets/component/image.d.ts，ImageAttribute.fillColor）
针对本应用要查的：
- ?attr/… 在应用主题里的颜色：源工程 AndroidManifest 里 Activity 或 application 的 android:theme 所指主题，及其在 res/values*/themes.xml、styles.xml（含 values-night）里的父主题链；找 <item name="属性名">，顺着 @color/… 或 ?attr/… 解析到具体颜色；日夜不同时分别记下
