# app.json5 的 vendor 仍是 example 时，开发期就从安卓来源落地，不随 bundleName 延后

审的是：资源
触发（任一种）：
- 读到：安卓模块 Gradle 构建脚本里的 namespace / applicationId（反域名形式，第二段是组织），或源工程 README 里的作者、组织；写错的样子：AppScope/app.json5 的 app.vendor 仍是 "example"，理由写成与签名或 AGC 绑定、部署期再改
适用范围：鸿蒙工程由 DevEco 脚手架生成、应用身份落地阶段决定哪些身份字段开发期替换时
做法：
- app.vendor 写成源端的组织：取 namespace / applicationId 的组织段，或源工程 README 等处的作者、组织名
- 只有 bundleName 这类真正与签名、上架绑定的字段才按签名策略延后；vendor 是描述字段，不并入延后
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- vendor：对应用开发厂商的描述，长度不超过 255 字节的字符串，可缺省，缺省值为空：只用于展示开发厂商信息，是描述字段（出处：app-configuration-file.md，配置文件标签 vendor）
- 配置文件示例里 "vendor": "example"：脚手架的模板值（出处：app-configuration-file.md，配置文件示例）
- 只改 vendor、不动 bundleName 后，重建的签名 HAP 仍安装成功：改 vendor 不影响签名装机（出处：卡里修好并验证过）
针对本应用要查的：
- 源端的组织或作者名：源工程模块的 Gradle 构建脚本（Groovy 或 Kotlin DSL）里的 namespace、defaultConfig.applicationId；README 或仓库信息里的作者、组织；取包名的组织段（第二段），或 README 写明的作者 / 组织名
