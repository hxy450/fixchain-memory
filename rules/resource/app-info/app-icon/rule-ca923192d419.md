# adaptive-icon 转 layered-image 时，前景和背景生成同尺寸 PNG，纯色底不用小图

审的是：资源
触发（任一种）：
- 读到：源端 <adaptive-icon> 的 android:background 是 @color/… 纯色（或 108dp 图层），android:foreground 是 @mipmap/… PNG；写错的样子：layered_image.json 引用的 background PNG 是 1×1、108×108 这类小尺寸纯色图，与 foreground PNG（如 432×432）尺寸不一
适用范围：资源迁移阶段把安卓 adaptive-icon 转成鸿蒙 layered-image 的前景、背景两层 PNG 时
做法：
- 前景、背景两层生成相同像素尺寸，按 1024×1024px；@color 背景生成与前景同尺寸的纯色 PNG，颜色取源端颜色资源的值
- 交付前核对 layered_image.json 引用的两层 PNG 尺寸相等，不只核颜色和字节
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 前景图：显示大小 450×450px、资源大小 1024×1024px 的透明图层；背景图：1024×1024px：文档推荐的分层图标规格（写在快捷方式 icon 一项里）（出处：module-configuration-file.md，shortcuts 标签的 icon）
- Both foreground and background layers should be sized at 108 x 108 dp.：源端两层本来就同尺寸（出处：android.graphics.drawable.AdaptiveIconDrawable（类注释））
- 四个图层重新生成为 1024×1024px 后图标正常，layered_image.json 不用改：改后的做法（出处：卡里修好并验证过）
针对本应用要查的：
- 背景色：源工程 adaptive-icon XML 里 android:background 引用的 @color 资源，到 res/values*/colors.xml 找同名 color；取它的 #RRGGBB（或 #AARRGGBB）值填满整张背景 PNG
