# 启动窗图标按源端显示尺寸乘目标密度准备像素，不直接拷贝小尺寸栅格图

审的是：资源
触发（任一种）：
- 读到：源端启动画面用自适应图标前景层（无底板），targetSdkVersion ≥ 31；写错的样子：startIcon.png 直接拷贝 xxhdpi 的 144px 栅格图，像素远小于启动图标显示尺寸乘目标密度
适用范围：准备鸿蒙启动窗图标 startIcon.png 的像素尺寸时
做法：
- 鸿蒙启动窗图标按原始像素居中绘制：按安卓启动图标显示尺寸（无底板约 288dp）乘目标设备密度准备像素（如密度 3.5 时 288 × 3.5 = 1008px），前景层等比放大到这个尺寸
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 前景层等比放大到 1008×1008（288vp × 3.5）后启动画面图标大小与源端一致：修复后的观察（出处：卡里修好并验证过）
针对本应用要查的：
- 目标设备的屏幕密度：目标设备或模拟器的显示参数（如 display 模块读出的 densityPixels）；图标像素 = 安卓启动图标显示尺寸（dp）× 密度
未核实：约 288dp 的启动图标尺寸是返修实测推得；平台 dimens.xml 里 starting_surface_icon_size 是 160dp、starting_surface_default_icon_size 是 108dp，与 288dp 的换算关系未核；鸿蒙启动窗图标按原始像素居中绘制出自卡，文档里没查到原文
