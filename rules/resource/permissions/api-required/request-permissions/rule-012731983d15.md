# 代码发网络请求时，module.json5 要声明 ohos.permission.INTERNET

审的是：资源
触发（任一种）：
- 读到：源 AndroidManifest.xml（合并清单）有 uses-permission android.permission.INTERNET 或 ACCESS_NETWORK_STATE；写错的样子：module.json5 没有 requestPermissions 块，或其中缺 ohos.permission.INTERNET 或 GET_NETWORK_INFO
- 写错的样子：代码里有 http.createHttp( 或 Web( 组件，requestPermissions 只落了某个功能草稿里的权限项、没有 INTERNET
- 写错的样子：代码用 connection.hasDefaultNet / getDefaultNet 判断连接状态，requestPermissions 缺 ohos.permission.GET_NETWORK_INFO
适用范围：目标工程 module.json5 的 requestPermissions，源端声明了网络权限或目标代码发请求、读网络状态时
做法：
- 和 HTTP 封装同一轮，在 module.requestPermissions 里加 { "name": "ohos.permission.INTERNET" }；源端有 ACCESS_NETWORK_STATE 或代码判断连接状态时再加 { "name": "ohos.permission.GET_NETWORK_INFO" }
- 首次创建 requestPermissions 时对照规格的权限映射表逐项落，并搜工程里的 http.createHttp 和 Web 组件补齐网络类 system_grant 权限
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- request(url: string, options?: HttpRequestOptions): Promise<HttpResponse>，标注 @permission ohos.permission.INTERNET，缺权限抛 201 - Permission denied：http.createHttp() 得到的 HttpRequest 发请求要 INTERNET 权限，不声明时请求发不出（出处：鸿蒙 SDK 的 ets/api/@ohos.net.http.d.ts，HttpRequest.request）
- hasDefaultNet(): Promise<boolean>、getDefaultNet(): Promise<NetHandle>，都标注 @permission ohos.permission.GET_NETWORK_INFO：读默认网络和连接状态要 GET_NETWORK_INFO 权限（出处：鸿蒙 SDK 的 ets/api/@ohos.net.connection.d.ts，connection.hasDefaultNet、connection.getDefaultNet）
- 使用 Web 组件访问在线网页时需添加 ohos.permission.INTERNET：Web 组件加载在线页面同样要 INTERNET（出处：web-component-overview.md，需要权限）
- INTERNET、GET_NETWORK_INFO 都是 normal 级、system_grant；system_grant 权限的 reason 和 usedScene 选填，reason 只在 user_grant/manual_settings 权限时必填：这两项只写 name 即可，不必配 reason/usedScene，也不用运行时弹窗申请（出处：permissions-for-all.md，ohos.permission.INTERNET；declare-permissions.md，在配置文件中声明权限、声明样例）
未核实：卡里环境是 HarmonyOS 6.1.1(24) / 6.0.1(21)，声明按本机 API 23 核实
