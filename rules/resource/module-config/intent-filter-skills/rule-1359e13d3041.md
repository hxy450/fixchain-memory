# 深链 host 和 wants.bundleName 写包名前，先确认 app.json5 已是最终值

审的是：资源
触发（任一种）：
- 读到：源端 AndroidManifest 的深链 intent-filter 或快捷方式用到应用自己的包名；目标 app.json5 的 bundleName 读出来是 com.example.* 模板值；写错的样子：module.json5 skills 的 uris 里 host 是 com.example.* 模板包名，shortcuts 的 wants.bundleName 同样是模板值
适用范围：module.json5 里必须写包名字面量的位置（uris 的 host、shortcuts 的 wants.bundleName）
做法：
- 写入前读 app.json5 的 bundleName；已是最终值就照抄进 host 和 wants.bundleName
- 仍是 com.example.* 模板占位时，把这几处和 bundleName 的占位登记在一起，回填时一并改
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- uris 的 host：URI 的主机地址部分，只有配置了 scheme 时才生效：深链 host 写成包名时是包名的一份副本（出处：module-configuration-file.md，skills标签）
- shortcuts 的 wants.bundleName：快捷方式的目标包名：要和 app.json5 的 bundleName 一致（出处：module-configuration-file.md，wants标签）
