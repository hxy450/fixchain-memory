# 申请 AUDIO_PLAYBACK 长时任务时，module.json5 补 backgroundModes 和权限

审的是：资源
触发（任一种）：
- 写错的样子：代码里有 startBackgroundRunning(…BackgroundMode.AUDIO_PLAYBACK…)，module.json5 的 abilities 项没有 "backgroundModes": ["audioPlayback"]，requestPermissions 里没有 ohos.permission.KEEP_BACKGROUND_RUNNING
适用范围：目标工程要在后台继续播放音频时的 module.json5
做法：
- 在发起播放的那个 UIAbility 的 abilities 项里加 "backgroundModes": ["audioPlayback"]
- 在 module 的 requestPermissions 里加 { "name": "ohos.permission.KEEP_BACKGROUND_RUNNING" }
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- abilities 的 backgroundModes：当前 UIAbility 的长时任务集合，字符串数组，可缺省：音频播放填 audioPlayback（出处：module-configuration-file.md，abilities标签）
- AUDIO_PLAYBACK 对应的配置项是 audioPlayback：backgroundModes 里写的字符串（出处：continuous-task.md，使用场景（长时任务类型表））
- ohos.permission.KEEP_BACKGROUND_RUNNING：权限级别 normal，授权方式 system_grant：只需在 requestPermissions 声明，不用运行时弹窗申请（出处：permissions-for-all.md，ohos.permission.KEEP_BACKGROUND_RUNNING）
