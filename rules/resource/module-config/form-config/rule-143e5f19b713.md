# appwidget-provider 转 form_config 时，按格数和拉伸范围写规格、resizable 和刷新

审的是：资源
触发（任一种）：
- 读到：appwidget-provider 的 android:targetCellWidth / android:targetCellHeight、android:minResizeWidth / android:maxResizeWidth、android:resizeMode，没有 android:updatePeriodMillis；写错的样子：form_config.json 的 supportDimensions / defaultDimension 和源格数不符，缺 "resizable"，或源无刷新周期却写了 "updateEnabled": true 和 updateDuration / scheduledUpdateTime
适用范围：把安卓 appwidget-provider 配置迁成 ArkTS 卡片的 form_config.json 时
做法：
- defaultDimension 写「targetCellHeight*targetCellWidth」（鸿蒙规格是「行*列」，源宽 4 格高 2 格写 "2*4"）；supportDimensions 列出 minResize 到 maxResize 覆盖的各档，含默认档
- resizeMode 允许拉伸时写 "resizable": true；源没有 updatePeriodMillis 时写 "updateEnabled": false，不配 updateDuration / scheduledUpdateTime
- 源端有预览、台账也批了静态预览时写 previewImages，与 supportDimensions 一一对应
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- "2 * 4"：2 行 4 列；supportDimensions 取值还有 1*2、2*2、4*4、6*4（2*3、3*3 只用于手表）：鸿蒙规格写成「行*列」（出处：arkts-ui-widget-configuration.md，配置文件字段说明 supportDimensions）
- defaultDimension 必须在 supportDimensions 的列表里：默认档也要列进 supportDimensions（出处：arkts-ui-widget-configuration.md，配置文件字段说明 defaultDimension）
- "resizable": true —— 可拖拽调整大小，调整值必须在 supportDimensions 里；API 20 起支持，缺省 false：对应源端 resizeMode 允许拉伸（出处：arkts-ui-widget-configuration.md，配置文件字段说明 resizable）
- "updateEnabled": false —— 不支持周期性刷新：源端没有 updatePeriodMillis 时的写法（出处：arkts-ui-widget-configuration.md，配置文件字段说明 updateEnabled）
- previewImages：卡片预览图，与 supportDimensions 一一对应，缺省 []：每档一张预览（出处：arkts-ui-widget-configuration.md，配置文件字段说明 previewImages）
- targetCellWidth、targetCellHeight 是以桌面格为单位的默认宽高（integer）：源端默认格数，Width 是列数、Height 是行数（出处：Android SDK 平台资源 data/res/values/attrs.xml，AppWidgetProviderInfo 的 targetCellWidth（按应用的 compileSdk 取对应平台））
- resizeMode 的 flag：none = 0x0、horizontal = 0x1、vertical = 0x2，可用 | 组合：非 none 时目标写 resizable: true（出处：Android SDK 平台资源 data/res/values/attrs.xml，AppWidgetProviderInfo 的 resizeMode（按应用的 compileSdk 取对应平台））
- updatePeriodMillis：刷新周期毫秒数，0 表示小部件自己刷新：没写或为 0 时目标不开周期刷新（出处：Android SDK 平台资源 data/res/values/attrs.xml，AppWidgetProviderInfo 的 updatePeriodMillis（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 源端的默认格数和拉伸范围：源工程 res/xml 下的 appwidget-provider 文件及它引用的 dimens；读 targetCellWidth/Height 定默认档；minResizeWidth/Height 与 maxResizeWidth/Height 的 dp 值换算成格数，定 supportDimensions 的上下界
未核实：minResize/maxResize 的 dp 值换算成格数的方法卡里没有写，只给了结果
