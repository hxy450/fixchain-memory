# 源端文本随系统字号缩放时，app.json5 引用 profile 设 followSystem

审的是：资源
触发（任一种）：
- 读到：源端有 AlertDialog.Builder(...) 系统对话框、Toast 或 sp 单位文本，或决策台账判大字体为迁移；写错的样子：AppScope/app.json5 里没有 "configuration" 字段，AppScope/resources/base/profile 下也没有对应的 configuration.json
适用范围：目标 HarmonyOS 应用的 AppScope/app.json5 和应用级 profile
做法：
- app.json5 的 app 里加 "configuration": "$profile:configuration"，在 AppScope/resources/base/profile/configuration.json 写 { "configuration": { "fontSizeScale": "followSystem", "fontSizeMaxScale": "<源端系统字号上限>" } }
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- "configuration": "$profile:configuration"：app.json5 里引用 profile 的写法，文件名和标签值要对应（出处：app-configuration-file.md，configuration标签）
- fontSizeScale：followSystem / nonFollowSystem，缺省 nonFollowSystem：是否跟随系统字号（出处：app-configuration-file.md，configuration标签）
- fontSizeMaxScale：1、1.15、1.3、1.45、1.75、2、3.2，缺省 3.2；nonFollowSystem 时不生效：跟随系统后的最大放大倍数（出处：app-configuration-file.md，configuration标签）
- fontSizeScale = followSystem、fontSizeMaxScale = "2"（对应安卓 14 起 200% 的系统字号上限）后，改系统字号时有配置回调和重建，对话框文字随之放大：返修的写法（出处：卡里修好并验证过）
未核实：fontSizeMaxScale 取 2 对应安卓 14 起的 200% 上限，出自卡，本机安卓资源里没核到这个上限
