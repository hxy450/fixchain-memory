# 未声明 screenOrientation 时，module.json5 补 orientation

审的是：资源
触发（任一种）：
- 读到：源 `AndroidManifest.xml` 的 `<activity>` 都没有 `android:screenOrientation`（安卓缺省 `unspecified`，随传感器和系统旋转开关旋转），常伴有 `layout-land` / `values-land` 资源或 `android:configChanges` 含 `orientation`；写错的样子：`module.json5` 的 `abilities` 里 EntryAbility 没有 `orientation` 字段（保持模板原样），常见页面却用 `mediaquery` 或 `onConfigurationUpdate` 写了横屏分支
适用范围：手机形态的目标工程，把源 activity 的方向声明（含未声明时的缺省）落到 module.json5 的 abilities 时
做法：
- 在 module.json5 的 abilities[] 里给 EntryAbility 写 "orientation": "auto_rotation_restricted"（受系统旋转锁控制、随传感器旋转），不留模板缺省；另一种修好过的写法是 "auto_rotation_unspecified"，取哪个有争议（见未核实）
- 落 module.json5 工程级配置时读全 abilities 段，对照方向决策核对 orientation，和 requestPermissions 等声明一起作为必做项，不只改 requestPermissions
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 不写 orientation 时解除旋转锁、转屏后鸿蒙窗口仍不旋转（保持 Rotation 0）；加 "orientation": "auto_rotation_restricted" 后窗口随转屏变为横屏、布局随宽度切换：鸿蒙手机上模板缺省不随传感器旋转（出处：卡里修好并验证过）
- "orientation": "auto_rotation_unspecified" 加到 EntryAbility 后横屏可达：另一张卡修好时用的取值（出处：卡里修好并验证过）
- auto_rotation_restricted：传感器开关打开时，方向可随传感器旋转：与安卓 unspecified 跟随系统旋转开关的语义对应（出处：module-configuration-file.md，abilities标签）
- auto_rotation_unspecified：受开关控制和由系统判定的自动旋转模式：有争议的另一个取值的含义（出处：module-configuration-file.md，abilities标签）
- orientation 可缺省，缺省值 unspecified（未指定方向，由系统自动判断显示方向）：不写时由系统决定，手机上不会随传感器转（出处：module-configuration-file.md，abilities标签）
- screenOrientation 不写时取 SCREEN_ORIENTATION_UNSPECIFIED（enum unspecified = -1）：让系统决定；用户没关自动旋转时随设备旋转：源端不写 screenOrientation 时的行为（出处：Android SDK 平台资源 data/res/values/attrs_manifest.xml，screenOrientation（按应用的 compileSdk 取对应平台）；com.android.internal.pm.pkg.component.ParsedActivityUtils#parseActivityOrReceiver）
- window.Orientation.AUTO_ROTATION_RESTRICTED = 8：同族接口：运行时窗口方向枚举里的同名取值，随传感器旋转、受旋转锁控制（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，window.Orientation.AUTO_ROTATION_RESTRICTED）
针对本应用要查的：
- 每个 activity 的方向声明：源工程 AndroidManifest.xml 里各 <activity> 的 android:screenOrientation；都没写的补成可随传感器旋转的取值（见上，取值有争议）；写了锁定方向的取 module.json5 orientation 枚举里对应的值
未核实：取值有争议：case-c6c056189eaa36176e28 和 case-11ff372c001b24f1dce2 修好时写 auto_rotation_restricted，case-69a2766b2050118ebd5a 修好时写 auto_rotation_unspecified，三张卡都只验证了横屏可达；两个取值（受旋转锁控制 / 受开关控制且由系统判定）在手机上的表现差别没有对比过；case-69a2766b2050118ebd5a 上机所用 SDK 是 API 24（6.1.1）
