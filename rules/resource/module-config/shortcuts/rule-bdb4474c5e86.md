# 快捷方式图标在 1024×1024 透明画布里把图形缩放居中到约 450×450px，不整张拉伸

审的是：资源
触发（任一种）：
- 读到：源端快捷方式图标只有 res/drawable-xxhdpi 下 72×72 的透明 PNG；写错的样子：目标 shortcuts 的 icon 资源是把整张源图直接放大到 1024×1024（如 PIL 的 `resize((1024, 1024))`），图形随画布同比放大、占满画布，没收进 450×450px 显示区
适用范围：把源端快捷方式图标转换成鸿蒙 module.json5 shortcuts 引用的图标资源时
做法：
- 新建 1024×1024 透明画布，把图形按比例缩放到约 450×450px 后居中贴上，不把整张源图拉伸成画布尺寸
- 宣告合规前用 alpha 通道的 getbbox 量墨迹范围和最大墨迹半径，确认图形落在约 450px 的显示区内，不只打印尺寸和 mode
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 前景图：图标显示大小为 450×450px，资源大小为 1024×1024px 的透明图层；背景图：大小为 1024×1024px：shortcuts 的 icon 推荐配置；单层图标时图形也按这个显示区布局（出处：module-configuration-file.md，shortcuts标签）
- 1024×1024、透明底、图形居中约 45%（墨迹约 450px 量级）：最终保留的图标资源形态（出处：卡里修好并验证过）
未核实：透明底在快捷方式菜单里是否会被系统垫底色，卡里没核实；卡里的环境是 5.0.4(16)，规格参数按文档副本核实
