# 完整复刻且 Gate 无人值守时，按默认政策排除功能簇的台账条目标成待确认

审的是：规格
触发（任一种）：
- 读到：默认迁移原则写「排除桌面 Widget、穿戴 / 电视等独立扩展入口」并要求「默认裁定不是静默生效」，用户 prompt 给出 headless 预授权「所有阶段审阅/继续 gate 自动批准并继续」，产出定位 D0 为完整复刻；写错的样子：决策台账写「排除桌面 Widget…不迁移｜approved｜default-policy + headless 预授权」，Gate 摘要没有呈现确认表就自动批准，阶段报告里也没有这条决策缺口
适用范围：规格提取阶段的决策拷问里，产出定位为完整复刻、审批 Gate 由预授权自动通过时，按默认政策排除用户可见功能簇（C2 类）的台账条目
做法：
- 把这条排除写成 proposed / 待确认，不写 approved
- 在阶段报告和 migration-report 的决策缺口里显式列出这条排除，不静默传给计划和执行
