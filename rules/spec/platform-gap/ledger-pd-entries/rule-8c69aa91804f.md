# 铸「平台无对等」的 PD 时，依据只引本会话读过的 skill 段落或声明、文档条目

审的是：规格
触发（任一种）：
- 读到：参考里有「使用 Scroll 的 onScroll 回调手动计算 AppBar 高度和透明度」或「需组合模拟 AppBar 折叠效果」这类说明；写错的样子：决策台账的 PD 写「HMOS 无滚动联动折叠标题栏对等」，依据只写一个 skill 名或「@kit.ArkUI d.ts」，没有具体条目原文，且本会话没读过这些文件
适用范围：规格阶段铸 PD-*、以「目标平台无对等能力」为由降级时
做法：
- PD 的依据写到具体条目：读过的 skill 段落、d.ts 的类和方法、官方文档的小节，附原文；引用前先读原文
- 参考里已有 nestedScroll、滚动回调或「onScroll 回调手动计算 AppBar 高度」一类说明时，不把折叠几何判为不可迁移
