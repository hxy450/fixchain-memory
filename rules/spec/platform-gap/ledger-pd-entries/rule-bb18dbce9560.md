# 台账自动批准时，标「替代形态待批」「待查证」的条目保留 pending，不落成具体替代方案

审的是：规格
触发（任一种）：
- 读到：规格里某个 PD 条目写着「替代形态待批（候选：…，grill 拍板）」或「待查证」；写错的样子：决策台账在无人值守自动批准下，把它直接写成某个具体替代方案并标 approved，没有要求实现前做平台验证
适用范围：决策台账在无人值守模式下自动批准 PD 条目时
做法：
- 这类条目在台账里保留 pending，写明实现前要做的平台验证（最小探针或 SDK 查证）
- 台账里同时注明：实现者遇到 pending 决策时按源行为实现，不按候选替代方案
