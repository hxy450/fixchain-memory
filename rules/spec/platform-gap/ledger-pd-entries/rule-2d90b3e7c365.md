# 写决策台账时，worker 标出的行为不确定项登记为带用户可见后果的决策项，不用「不改变 X」锁死

审的是：规格
触发（任一种）：
- 读到：worker 回执摘要里写了行为差异（如「某类设备源端显示 A、目标显示 B」）；写错的样子：decision-ledger 只把它登记为 API 用法查证，还写「不改变 X 规格行为」把有争议的行为锁死
适用范围：主线汇总 worker 回执、写 decision-ledger 时
做法：
- 把行为不确定项登记为决策项，写明两种结果各自的用户可见后果；API 用法查证另列一项，不和行为决策混在一起
