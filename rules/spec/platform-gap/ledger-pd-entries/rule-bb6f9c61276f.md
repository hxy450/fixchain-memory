# 无人值守的 gate 自动批准不等于 PD 已改判，默认阻断的 PD 保持 proposed，不写成 approved

审的是：规格
触发（任一种）：
- 读到：default-policy 的确认表里某类 PD 默认「阻断，本行必须改判」，只有无法等价复刻时才记 PD 并保持 proposed；运行处于所有 gate 自动批准的模式；写错的样子：决策台账把这类 PD 写成 approved，依据只是「gate 自动批准」，没有用户改判记录
- 读到：默认策略写明 C6/C8 类无鸿蒙对等默认阻断、C9 需实时确认；写错的样子：决策台账里这类 PD 是 approved，替代写成恒 false 常量或无效设置行，没有平台查证记录
适用范围：无人值守、gate 自动批准模式下落盘决策台账时，默认阻断或需实时确认（含判为「无鸿蒙对等」要降级替代）的 PD 条目
做法：
- gate 自动批准只表示流程继续，不等于用户已改判；确认表里「默认阻断、必须改判」或需实时确认的 PD 保持 proposed，并在 Gate 摘要里单列披露，不自行写成 approved
- 能等价复刻的按完整复刻落实；只有完成平台查证、确认确实没有 API 后，才批准降级替代（恒 false 常量、无效设置行）
