# 规格写「无对等」「已查证」时要附查证记录，查不到就登记待定交决策关口

审的是：规格
触发（任一种）：
- 读到：上游的功能基线把这项能力列为待决策关口收口的不确定项；写错的样子：平台差异决策的依据栏写「…查证」「无对等」，却没写查了哪个 SDK 声明、哪份知识参考、工程里哪处现有 startAbility / ohos.want.action.viewData 用法及结果；或决策关口收口后同类外跳的裁决不一致（一处保留浏览器外跳、一处删掉）
适用范围：规格和决策台账里登记平台差异、写明依据时
做法：
- 依据栏写出实际查证的记录：查的哪个 SDK 声明文件和符号、哪份知识参考、工程内哪处现有 startAbility / viewData 用法，以及查到的结果；查不到就登记为待定，交决策关口，不引用没执行的查证
- 决策关口收口时核对这条依据确实存在，并与同类外跳（如在线转换器保留浏览器外跳）的裁决保持一致
来源：1 张卡，1 个应用
- case-e5655934c3f8870c44d9（MifareClassicTool）：做法第 1 步 ← 建议 2；做法第 2 步 ← 建议 2
