# 目标能用 Canvas/Path 自绘的视觉效果不登记为平台无对等 PD，写成实现项并附源参数

审的是：规格
触发（任一种）：
- 读到：源端用 Material3 Expressive 这类自绘视觉组件，如按偏好在 CircularWavyProgressIndicator 与 CircularProgressIndicator 之间切换；产出定位写着「完整复刻」；写错的样子：skip-list 或决策台账把它登记为「实现降级」的 `PD-` 条目，平台约束写「可移植但复杂度高 / 成本高 / 首版无必要 / 暂不」，并列进「直接砍掉范围」
适用范围：规格决策阶段（skip-list 登记、决策台账落盘），为源端没有同名原生组件、但目标可自绘的视觉效果定方案时
做法：
- 先判定拟降级项是否确实「平台无等价能力」：目标能用 Canvas / Path2D / 动画 API 自绘实现的，不登记为平台无对等 PD，写成实现项，并附上源实现的参数（波长、波速、描边宽度等及其计算式）
- 落盘前逐条检查 PD 的平台约束措辞：出现「可移植、成本高、复杂度高、首版无必要、暂不」等理由的，是产出定位上的裁剪；产出定位为完整复刻时撤销该降级，不列入「直接砍掉范围」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- (context?: CanvasRenderingContext2D | DrawingRenderingContext): CanvasAttribute：Canvas 组件，可在其上自绘（出处：鸿蒙 SDK 的 ets/component/canvas.d.ts，CanvasInterface）
- arc(x: number, y: number, radius: number, startAngle: number, endAngle: number, counterclockwise?: boolean): void；stroke(path: Path2D): void：画弧、描边路径，波浪环这类效果可由此拼出（出处：鸿蒙 SDK 的 ets/component/canvas.d.ts，CanvasPath.arc、CanvasRenderer.stroke）
- ProgressType.Ring = 1：原生环形进度条，只是普通环，不是波浪环的等价物（出处：鸿蒙 SDK 的 ets/component/progress.d.ts，ProgressType.Ring）
- 按依赖库源码复刻 CircularWavyProgressIndicator 与普通 M3 环，并按偏好开关切换：修好后的实现（出处：卡里修好并验证过）
针对本应用要查的：
- 源端波浪环的参数和计算方式：源工程调用 CircularWavyProgressIndicator 的 Kotlin 文件（按组件名 grep），以及 androidx.compose.material3 对应版本的源码；抄出传给组件的 wavelength、waveSpeed、stroke 等参数及其计算式，写进实现项
