# 规格以「知识库无条目」判 HARD-DIV 时，改为引 SDK d.ts 证据，查不到写「待验证」

审的是：规格
触发（任一种）：
- 读到：源端用 BetterLinkMovementMethod 按触点找 ClickableSpan 再派发点击或长按；规格模板要求平台能力结论以 SDK d.ts、knowledge-verifier 查证或参考条目为据；写错的样子：规格以「arkts-knowledge-verifier 无 span 级手势条目」为据判 HARD-DIV，替代路径写「命中域=整个文本组件 → URL 提取」，并作废 span 级触摸 AC
适用范围：规格里判定「平台无对等能力」（HARD-DIV）的决策
做法：
- 判 HARD-DIV 前在项目 SDK 的 d.ts 里查相关能力并在决策里引文件和符号；span 级链接手势查 styled_string.d.ts 的 GestureStyle（onClick / onLongPress）和 TextController.getLayoutManager() 的布局查询
- 查不到证据时把这条决策写成「待验证」，不以「知识库无条目」批准退化替代
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- constructor(value?: GestureStyleInterface)：StyledString 上给一段文字挂手势的样式，@since 12（出处：鸿蒙 SDK 的 ets/component/styled_string.d.ts，GestureStyle.constructor）
- onClick?: Callback<ClickEvent>；onLongPress?: Callback<GestureEvent>：GestureStyleInterface 的点击和长按回调，@since 12（出处：鸿蒙 SDK 的 ets/component/styled_string.d.ts，GestureStyleInterface.onClick、GestureStyleInterface.onLongPress）
- getLayoutManager(): LayoutManager：TextController 取布局管理器，@since 12（出处：鸿蒙 SDK 的 ets/component/text.d.ts，TextController.getLayoutManager）
- getGlyphPositionAtCoordinate(x: number, y: number): PositionWithAffinity：按坐标取最近字形的位置，@since 12（出处：鸿蒙 SDK 的 ets/component/text_common.d.ts，LayoutManager.getGlyphPositionAtCoordinate）
