# spec gap 写「安卓是 X、规格要求 Y、按规格实现」时，按忠实迁移原则复核，非批准修正以安卓为准

审的是：规格
触发（任一种）：
- 读到：源码理解笔记写明安卓固定行为 X，且与规格验收清单冲突；决策台账有忠实迁移、禁止无审批产品重设计的原则；写错的样子：spec gap 条目的处置语句写成「按 Feature Spec 实现 Y 并记录显式差异」，验收清单保留与安卓不同的 Y
适用范围：规格、源码理解笔记和验收清单里登记源端与规格差异时
做法：
- 按决策台账的忠实迁移原则复核：Y 不属于已批准的缺陷修正就以安卓为准，把处置语句改成按安卓 X，并同步修改验收清单与测试断言
