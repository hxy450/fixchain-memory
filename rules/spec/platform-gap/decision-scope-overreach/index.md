# 转述平台差异决策时超出它列明的范围

agent 会看到什么：读到台账或规格的平台差异决策（PD、显式退化）只列了某几项能力或出口；台账汇总行把别的能力一并写成「执行 approved unavailable UX」，或源码笔记把它扩成整段富文本、全部链接都不实现，decision_gaps 里没有这项偏离

## 规矩

- rule-32b32807da1b｜台账汇总行把某能力并入「执行 approved unavailable UX」时，逐项核对所引决策是否覆盖它｜读到：台账的留桩范围和显式退化决策只列了少数能力（如认证、广告、微信），规格把地图等列为核心功能；写错：台账的汇总行（如「Plan 待修订项」）把多个切片的能力合并写成「统一 capability adapter；执行 approved unavailable UX」，其中包含所引决策并未批准降级的能力
- rule-beb0cb4d3c10｜规格的平台差异决策只收敛它列明的出口，源码笔记不能扩成整段富文本或全部链接都不实现｜读到：规格的平台差异决策（PD）只列了某几个出口（如商店跳转、系统设置深链），同时要求正文链接可点；写错：源码笔记把这条决策扩大成「正文原样 Text 渲染；span 可点性不在本 Slice 恢复」，交回的 decision_gaps 里没有这项偏离
