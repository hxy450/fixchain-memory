# 台账汇总行把某能力并入「执行 approved unavailable UX」时，逐项核对所引决策是否覆盖它

审的是：规格
触发（任一种）：
- 读到：台账的留桩范围和显式退化决策只列了少数能力（如认证、广告、微信），规格把地图等列为核心功能；写错的样子：台账的汇总行（如「Plan 待修订项」）把多个切片的能力合并写成「统一 capability adapter；执行 approved unavailable UX」，其中包含所引决策并未批准降级的能力
适用范围：决策台账里汇总「已批准不可用降级」范围的行
做法：
- 写汇总行前逐项核对所引的 D/PD 是否真的覆盖每项能力；不在留桩范围和显式退化决策里的能力，不并入降级行
- 未获批的能力单列为 SDK 接入任务，或另铸一个 PD 写明待批
来源：1 张卡，1 个应用
