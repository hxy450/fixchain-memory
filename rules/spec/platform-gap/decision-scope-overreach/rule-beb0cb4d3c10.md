# 规格的平台差异决策只收敛它列明的出口，源码笔记不能扩成整段富文本或全部链接都不实现

审的是：规格
触发（任一种）：
- 读到：规格的平台差异决策（PD）只列了某几个出口（如商店跳转、系统设置深链），同时要求正文链接可点；写错的样子：源码笔记把这条决策扩大成「正文原样 Text 渲染；span 可点性不在本 Slice 恢复」，交回的 decision_gaps 里没有这项偏离
适用范围：实现者在源码笔记或决策台账里引用规格的平台差异决策、决定哪些行为降级时
做法：
- 平台差异决策只作用于它列明的出口，其余行为照规格实现
- 确需降级时登记为显式偏离或占位，写进 decision_gaps，不写成已实现
