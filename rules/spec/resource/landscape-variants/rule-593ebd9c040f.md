# 页面有 layout-land 变体时，规格写出横竖屏不同的控件属性和运行时覆盖范围

审的是：规格
触发（任一种）：
- 读到：源页面有 layout-land 等布局变体，同一控件在不同变体里背景不同；Activity 代码只对部分控件调用 setBackgroundResource；写错的样子：页面规格的结构段只描述竖屏控件属性（如按钮背景是某圆角 shape），没写横屏变体的不同，也没写运行时代码覆盖了哪些控件的哪些属性
适用范围：规格提取阶段描述带布局变体的页面结构时
做法：
- 结构段列出横屏与竖屏不同的控件属性（包括背景形状），并注明哪些属性在运行时被代码覆盖、覆盖的是哪些控件
