# 进入公式的 R.integer 等资源有限定词覆盖时，取值表写各配置的值和运行期读取

审的是：规格
触发（任一种）：
- 读到：源码在绘制或首帧几何里用 getResources().getInteger(R.integer.x)（或 R.dimen、R.bool）读资源，该资源在 res/values-land 等限定词目录有覆盖值；写错的样子：规格的精确取值表或公式只写一个字面值（如「名 | 2 | R.integer.名」），没写横屏等配置下的另一个值，也没写运行期读取
适用范围：规格里为自绘几何公式确定资源常量取值的精确取值表
做法：
- 按资源名在全部 res/values* 目录检索（如 grep -rn 'name="资源名"' res/），不只查 res/values
- 有限定词覆盖时，取值表写成「base 2 / land 1，运行期按当前方向读取」这样的形式，列出每个限定词目录的值
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 安卓资源系统靠成套的替代资源适配不同设备配置：getResources() 读到的值随当前配置的限定词目录变化（出处：android.content.res.Resources）
- 横竖屏限定词：vertical（竖屏）、horizontal（横屏）：鸿蒙资源目录里对应 values-land 的限定词（出处：resource-categories-and-access.md，限定词目录）
- 系统按当前设备状态先从匹配的限定词目录找资源，找不到才去 base：目标端同样按方向解析资源（出处：resource-categories-and-access.md，资源匹配）
针对本应用要查的：
- 这个资源在各限定词目录下的值：源工程 res/ 下所有 values* 目录的 XML，按 name="资源名" 检索；每个命中的目录名就是它的限定词（values-land 即横屏），读出各自的值
