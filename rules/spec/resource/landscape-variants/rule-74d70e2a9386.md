# 几何随方向重算且所用资源有横屏覆盖时，几何验收补横屏样例

审的是：规格
触发（任一种）：
- 读到：源端资源在 res/values-land 有覆盖值，页面有 layout-port / layout-land 两套布局或旋转重建 Activity；写错的样子：几何验收条目只写竖屏的取值（如「资源名=2」），没有横屏下的样例
适用范围：规格里随屏幕方向重算的几何验收条目
做法：
- 几何验收里补一个横屏样例，写明横屏下该资源的值和它带来的几何结果（如横屏下某间距少一列）
来源：1 张卡，1 个应用
