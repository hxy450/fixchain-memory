# 工程里有几个含同一颜色词的颜色资源时，规格色表按资源名逐行列，不合并近名资源

审的是：规格
触发（任一种）：
- 读到：源工程 res/values*/ 的 XML 里有几个名字含同一颜色词的 <color> 资源（如一个不带前缀、一个带用途前缀），分别被不同的方法或绘制项通过 R.color.名 引用；写错的样子：规格色表把近名资源合成一行，或两行标成同一个 hex；某一行只写颜色词，缺资源名、定义文件或消费点
适用范围：规格里列颜色表（渲染色表、常量表）时
做法：
- 色表每个资源一行，列出：资源名 | 定义文件 | hex | 消费点（方块绘制、弹字等哪个方法或绘制项用它）；名字含同一颜色词的近名资源各占一行，不合并
针对本应用要查的：
- 名字含同一颜色词的各个颜色资源的值和消费点：源工程 res/ 下 values 及 values-* 目录里的全部 XML，按颜色词搜 <color name=；源码里按 R.color.资源名 搜引用处；每个 name 记下定义所在的文件和 hex，再记下引用它的方法，各成一行
