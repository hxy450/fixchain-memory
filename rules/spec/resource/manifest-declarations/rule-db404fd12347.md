# 承载 module.json5 声明的功能规格，把屏幕方向与权限并列写成验收条目

审的是：规格
触发（任一种）：
- 读到：页面规格的「Manifest 解析」行或参考规格的平台目标值表写着「未声明 screenOrientation → module.json5 EntryAbility orientation: auto_rotation_restricted」，而页面规格的输出文件不含 module.json5；写错的样子：功能规格里 module.json5 相关的验收条目只有权限声明和备份声明，没有 orientation 条目，或写成「页面规格已定、引用不重写」；有的还把旋转列为 onConfigurationUpdate 要重放的配置变化，却没有让窗口随传感器旋转的条目
适用范围：规格提取阶段，负责 module.json5 权限、备份等声明的功能规格
做法：
- 与权限、备份条目并列写一条验收条目：module.json5 的入口 UIAbility 写 "orientation": "auto_rotation_restricted"（由源 manifest 未声明 screenOrientation 解析出），判定方式为静态检查 EntryAbility 的这个字段；不以「页面规格已定、引用」代替
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- "orientation": "auto_rotation_restricted"：验收条目里要检查的目标值：传感器开关打开时方向随传感器旋转（出处：module-configuration-file.md，abilities标签的 orientation）
- orientation 缺省值为 unspecified：没人写这个字段时脚手架模板就是这个值，窗口不随转屏旋转（出处：module-configuration-file.md，abilities标签的 orientation）
