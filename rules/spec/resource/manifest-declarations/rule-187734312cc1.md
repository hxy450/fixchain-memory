# 源 activity 声明 screenOrientation 时，规格写进页方向验收条目，不只写全屏

审的是：规格
触发（任一种）：
- 读到：AndroidManifest.xml 的 <activity> 声明 android:screenOrientation="sensorLandscape" 等方向值；onCreate 里另有 FLAG_FULLSCREEN；写错的样子：页面或功能规格只有「FLAG_FULLSCREEN 全屏」一条，没有屏幕方向的验收条目
适用范围：规格提取阶段为每个 Activity 写页面或功能规格时
做法：
- 为每个 Activity 读 AndroidManifest 里它的 <activity> 声明，把 screenOrientation 等窗口级属性写进页面或功能规格，不只凭 onCreate 里的 FLAG_FULLSCREEN 写「全屏」
- sensorLandscape 写成验收条目：「进入页 setPreferredOrientation(window.Orientation.AUTO_ROTATION_LANDSCAPE)，离开时恢复 window.Orientation.UNSPECIFIED」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- screenOrientation 的 sensorLandscape = 6：横屏，可按传感器在正反两个横向之间切换：源端取值的含义（对应 ActivityInfo.SCREEN_ORIENTATION_SENSOR_LANDSCAPE）（出处：Android SDK 平台资源 data/res/values/attrs_manifest.xml，screenOrientation 的 sensorLandscape（按应用的 compileSdk 取对应平台））
- Orientation.AUTO_ROTATION_LANDSCAPE = 7：跟随传感器、只在横向内旋转、忽略旋转锁；UNSPECIFIED = 0 为默认，由系统决定：目标端进入和离开时用的两个值（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，window.Orientation）
- setPreferredOrientation(orientation: Orientation): Promise<void>：window.Window 设置窗口方向（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，window.Window.setPreferredOrientation）
