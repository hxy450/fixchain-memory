# 决策写横竖屏双布局时，把 EntryAbility 的 orientation 列为 module.json5 必做项

审的是：规格
触发（任一种）：
- 读到：源 `AndroidManifest.xml` 的 activity 没有 `android:screenOrientation`；源有 `layout-land` / `values-land` 或「两个方向都可用」类文案；写错的样子：规格或决策台账只写「横竖屏双布局全支持」「无 screenOrientation（双方向）」这类安卓语义，技术必做项和 feature-base 的 module.json5 节只列 requestPermissions，没有 ability orientation 条目
适用范围：规格提取与决策台账阶段，把源 activity 方向声明（含未声明的缺省）映射成目标配置时
做法：
- 逐个 activity 核对 screenOrientation：未声明的写目标值「EntryAbility orientation = auto_rotation_restricted」，锁定方向的写对应 orientation；只写安卓语义或只迁 land/port 布局不算目标值
- 把这一项列进技术必做项和 feature-base 的 module.json5 节，与权限并列
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- auto_rotation_restricted：传感器开关打开时，方向可随传感器旋转：未声明 screenOrientation 时的目标值（出处：module-configuration-file.md，abilities标签）
