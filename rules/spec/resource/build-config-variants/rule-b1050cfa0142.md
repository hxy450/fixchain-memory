# 同一功能有新旧两套源实现时，规格的 races / 生命周期规则标明适用页面

审的是：规格
触发（任一种）：
- 读到：同一功能有两套源 Activity：旧版在 surfaceCreated 里按「面已创建 ∧ 正在播放」双守卫挂面，新版在 MediaController 就绪后直接 setPlayer；写错的样子：规格 races 节或验收条目把一套实现的守卫（如「videoSurfaceCreated ∧ status==PLAYING 双 guard」）写成通用规则，没限定适用页面
适用范围：规格提取阶段，同一功能在源端有两套实现、分别迁成两个目标页时
做法：
- races / 生命周期规则逐条标明出自哪个源 Activity、适用哪个目标页；另一套实现按它自己的源写（如新版「controller 就绪即 setPlayer」）
来源：1 张卡，1 个应用
