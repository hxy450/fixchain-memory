# 资源映射文档的 flavor 来源照台账指定的写，不自定默认 flavor

审的是：规格
触发（任一种）：
- 读到：源工程有多个 productFlavors，各 flavor 自带 app_name / app_package；决策台账或派工写了默认 flavor；写错的样子：资源映射文档里身份串一节写成另一个 flavor 的值和 flavor 源（如「play flavor app_name=…，flavor 源 src/play」），或转换脚本注释写「play = default flavor」、默认取第一个 flavor
适用范围：资源迁移阶段写资源映射文档里应用身份串（app_name、app_package 等）那一节时
做法：
- 动笔前读决策台账里的 flavor 指定，映射文档写明「flavor：<台账指定的 flavor>，来源 src/<该 flavor>/res」，各身份串都按这个 flavor 填
来源：1 张卡，1 个应用
