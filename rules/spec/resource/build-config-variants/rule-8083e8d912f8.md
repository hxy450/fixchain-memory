# API 清单只给地址键名时，规格回源码写出各套接口各环境的 host、环境枚举和默认环境

审的是：规格
触发（任一种）：
- 读到：API 清单的 base_urls 只给出地址常量的键名（指向源文件里的常量），没有任何 host 和环境取值；写错的样子：规格写「BASE_URL（…配置，多环境 dev/staging/prod）」这类没有出处的环境词表，只列一个 Base URL；源端分新旧两套接口时漏掉另一套地址
适用范围：规格提取阶段写网络层服务地址、环境枚举和默认环境的那一节
做法：
- 沿键名打开常量定义和取址逻辑：地址常量所在的类 → 按 BuildConfig.BUILD_TYPE 或环境工具选址的方法 → 环境工具的取值和默认分支；把每套接口在各环境的 host、环境枚举值和默认环境规则写进规格
- 查不到的写「未解析，待核」并注明要查的源文件，不填自拟的环境名或域名
针对本应用要查的：
- 每套接口在各环境的 host、环境枚举值、默认环境规则：源工程里键名指向的常量类，引用这些常量的取址方法（常在依赖注入模块或网络模块里），以及它调用的环境工具类；app 模块 Gradle 构建脚本里的 buildTypes；逐个读出常量的字符串值；读取址方法按什么分支（构建类型或环境工具返回值）选哪个常量；读环境工具的取值集合和各构建类型下的默认值
