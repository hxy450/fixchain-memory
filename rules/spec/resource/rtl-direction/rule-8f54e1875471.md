# 源 Manifest 写 supportsRtl=true 时，规格把 RTL 镜像列为全局契约传给各页

审的是：规格
触发（任一种）：
- 读到：AndroidManifest 的 <application> 写了 android:supportsRtl="true"，源码用 start / end 和 Icons.AutoMirrored；写错的样子：页面规格没有 RTL 镜像契约，资源映射把 AutoMirrored 记成普通媒体资源
适用范围：规格阶段写全局契约、页面规格时
做法：
- 规格写一条全局契约「支持 RTL：start / end 用 LengthMetrics 逻辑方向，AutoMirrored 图标用 matchTextDirection(true)」，并传进每份页面规格
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- supportsRtl：Declare that your application will be able to deal with RTL (right to left) layouts. The default value is false.：源应用显式声明支持 RTL（出处：Android SDK 平台资源 data/res/values/attrs_manifest.xml，AndroidManifestApplication 的 supportsRtl（按应用的 compileSdk 取对应平台））
