# RTL 验收除 RTL 资源语言外，还要覆盖回落英文的 RTL 系统语言，查句末标点和按钮顺序

审的是：规格
触发（任一种）：
- 读到：资源里有 values-fa 等 RTL 语言目录，manifest 未声明 `android:supportsRtl`；写错的样子：RTL 验收条目只比 fa 截图「同为左对齐」，或以「全仓 grep bidi/rtl/mirror 零命中」判等价落地
适用范围：带文字绘制或对话框的功能，规格里 RTL 相关的验收条目
做法：
- 验收条目同时列 RTL 资源语言（如 fa）和没有对应资源、回落英文的 RTL 系统语言（如 ar），判据写明句末标点位置和对话框按钮顺序
- 判据里写明：grep 不到 rtl、bidi 不算等价证据
