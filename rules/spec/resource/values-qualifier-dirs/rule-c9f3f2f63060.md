# 规格盘点 values-* 时，宽度限定目录覆盖的 dimen 写进全局约定并指派运行时判定

审的是：规格
触发（任一种）：
- 读到：源工程 res 下有 values-w<N>dp 或 values-sw<N>dp 目录，覆盖了布局共用的 @dimen；源码理解笔记或设计文档里写了宽屏下的覆盖值；写错的样子：ui-manifest 只把宽度限定目录记成“非语言目录”，全局约定里没有被覆盖的 dimen；引用它的页面 meta.json 的 style_sources 只列 values/dimens.xml；feature-base 和各页 spec 里没有宽度断点
适用范围：规格提取阶段盘点源工程 res 下的 values-* 目录时
做法：
- 宽度限定目录和语言、夜间目录一样逐个处理：把被覆盖的 dimen（键名、基础值、覆盖值、阈值）写进 ui-manifest 全局约定，并加进引用它的页面 meta.json 的 style_sources
- 在 feature-base 里指派一个运行时判定：窗口宽扣除左右避让后 ≥ 阈值 vp 取覆盖值，否则取基础值，窗口尺寸变化时重新计算；源码笔记已写出宽屏覆盖值的，baseline 要承接下来
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- HarmonyOS 限定词只有移动国家码和移动网络码、语言、文字、国家或地区、横竖屏、设备类型、颜色模式和屏幕密度：宽度限定的覆盖不能靠资源目录承接，规格里必须写成运行时判定（出处：resource-categories-and-access.md，限定词目录）
针对本应用要查的：
- 被宽度限定目录覆盖的 dimen 和引用它的布局：源工程 res/values-w<N>dp、values-sw<N>dp 下的 dimens.xml；再在 res/layout 的 XML 里搜 @dimen/<键名>；每个覆盖键记下基础值、覆盖值、阈值 N；搜到的布局就是要把这份 dimens.xml 加进 style_sources 的页面
