# 「文案随语言切换」的验收写成两种语言配置下对比画布与组件文本，不只看代码引用

审的是：规格
触发（任一种）：
- 读到：安卓自绘 View 用 getResources().getString 取文案画到画布上，同一屏还有普通控件的文案；写错的样子：「文案随语言切换」的验收条目或核验记录只看代码里有没有引用 $r / getStringSync，或写「无应用内语言切换，无需 setPreferredLanguage」就判通过
适用范围：国际化验收条目和核验记录，页面里既有代码内取值的文本、又有声明式 $r 文本时
做法：
- 验收条目写成：在系统语言和应用偏好语言两种配置下，分别对比画布上代码内取值的文本和组件上声明式 $r 的文本，两者切到同一种语言才算通过
- 核验记录里写明两种配置各自看到的画布和组件文本，不以「grep 到 $r / getStringSync 引用」作为落地依据
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- static setAppPreferredLanguage(language: string): void（i18n.System）：设置应用偏好语言，冷启动后按它加载资源；传 default 时跟随系统语言；声明标 @since 20（出处：鸿蒙 SDK 的 ets/api/@ohos.i18n.d.ts，System.setAppPreferredLanguage）
针对本应用要查的：
- 用哪个 locale 做应用偏好语言的对比：目标工程 resources 下除 base 以外的语言目录（如 zh_CN、fa 之类的限定词目录）；挑一个有对应 string 资源的语言目录，用它的语言 ID 设成应用偏好语言
