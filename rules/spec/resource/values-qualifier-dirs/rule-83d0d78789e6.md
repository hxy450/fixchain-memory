# 规格登记语言资源范围时按源 res 下全部 values-* 目录，不自设只迁双语的默认值

审的是：规格
触发（任一种）：
- 读到：源工程 res/ 下有多个 values-xx 语言目录（如 values-es、values-zh-rTW），应用内按 supported_locales 提供语言切换；写错的样子：规格全局约定或决策台账写「默认迁 values + values-zh」「其余语言 fallback base，行为可接受」，没有用户或任务的裁剪来源
适用范围：规格提取阶段确定要迁移哪些语言资源目录时
做法：
- 列出源 res/ 下实际存在的全部 values-* 语言目录，逐个登记为迁移范围，并写出对应的目标限定词目录
- 只有用户或任务明确裁剪时才缩小范围，并在台账里写明裁剪的来源
针对本应用要查的：
- 源端有哪些语言目录：源工程模块的 res/ 目录，列出 values-<语言>[-r<地区>] 形式的子目录；每个目录登记一行：源目录 → 目标限定词目录
