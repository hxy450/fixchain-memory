# 透明层下的页面底色取主题 windowBackground，不把无引用的颜色写成窗口背景

审的是：规格
触发（任一种）：
- 读到：颜色资源 XML 里定义了某个 <color>，layout、style、Java 里都没有引用它；写错的样子：设计系统色彩表或规格把这个颜色写成某页的窗口背景 / 根布局背景
- 读到：布局根没有 android:background，SurfaceView 或自定义 View 为 android:background="@null"；写错的样子：规格写「背景 #某色 透出」并定成契约或 AC，没写透出的是主题 windowBackground
适用范围：规格提取时写设计系统色彩表、页面根背景和透明层「透出」的说法
做法：
- 写色彩表前在 layout、style、Java 里检索每个颜色的引用；查不到引用的标「定义未使用」，不写成任何页的窗口背景或根布局背景
- 写「X 透出」前核对透明层下方：布局根没有 android:background 时，透出的是 Activity 主题的 windowBackground，规格写这个提供方和解析出的值
