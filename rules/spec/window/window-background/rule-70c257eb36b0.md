# 透明主题页的规格写明「下层页面保持可见、仅压暗」和透明路由

审的是：规格
触发（任一种）：
- 读到：源 Activity 用 Translucent 主题（`android:windowIsTranslucent` 为 true、透明 `android:windowBackground`、`android:backgroundDimEnabled`）；写错的样子：规格只写「半透明 Activity → 全屏 NavDestination + 半透明背景遮罩」或「主题级透明 → 页面级蒙层」，没写下层页面要可见、目标路由要透明
适用范围：规格提取阶段处理透明主题的 Activity 时，规格页的转换决策和验收条目
做法：
- 写成可验收的一条：「下层页面保持可见、仅被压暗」
- 写明目标路由需透明：NavDestination 用 `.mode(NavDestinationMode.DIALOG)` 且背景透明，不只写「全屏 NavDestination + 蒙层」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- NavDestinationMode.DIALOG = 1：页面默认透明，入栈出栈不影响下层页面的生命周期；默认的 STANDARD 不透明（出处：鸿蒙 SDK 的 ets/component/nav_destination.d.ts，NavDestinationMode）
