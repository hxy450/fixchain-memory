# 嵌入页有状态栏占位 View 时，规格写明背景延伸到窗口顶、只有前景列避让状态栏

审的是：规格
触发（任一种）：
- 读到：源嵌入页（Fragment 等）布局里头图背景和一个占位 View 都 app:layout_constraintTop_toTopOf="parent"，内容容器 layout_constraintTop_toBottomOf 该占位；代码里 ImmersionBar.with(this).statusBarView(占位) 把占位撑成状态栏高度；写错的样子：规格把占位 View 写成「Android 沉浸式定位锚点，鸿蒙由宿主统一处理安全区」，安全区节写「由承载本页的宿主负责」；没写背景延伸、前景避让的分层，也没写避让值由谁提供、页内哪一层消费
适用范围：规格提取阶段，给嵌入 Tab 的子页面（sub_component）翻译状态栏占位和安全区分工时
做法：
- 规格里写明：页头背景从窗口顶端铺开、不偏移；只有前景内容列让出状态栏高度；顶部避让值由哪个宿主提供、在页内哪一层（前景容器）作顶部内边距消费
