# 源码有 ImmersionBar 等沉浸调用时，页面规格按源码判定需要沉浸，不按 page_type 推断

审的是：规格
触发（任一种）：
- 读到：源码有 `ImmersionBar.with(this).titleBarMarginTop(...)`、`fitsSystemWindows` 等沉浸调用；写错的样子：页面规格按 `page_type=sub_component` 自动写 `needs_immersive_safearea=false`，「沉浸式 + 安全区」节写成 converter 跳过本契约
适用范围：Tab 子组件、Fragment 等被判为子组件的页面规格的沉浸与安全区一节
做法：
- 以源码判定：出现 ImmersionBar、titleBarMarginTop、fitsSystemWindows 的页面写 `needs_immersive_safearea=true`，并写明内容延伸到状态栏下、标题栏下移状态栏高度
