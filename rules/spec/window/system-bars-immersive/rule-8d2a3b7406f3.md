# 定 needs_immersive_safearea 前先核源窗口是否延伸到系统栏，全无信号写非全屏和 false

审的是：规格
触发（任一种）：
- 读到：源主题链（如 parent=android:Theme.Holo / Theme.Black）和代码里没有 windowFullscreen、windowTranslucentStatus / Navigation、透明 statusBarColor、FLAG_FULLSCREEN、SYSTEM_UI_FLAG_LAYOUT_*、setDecorFitsSystemWindows(false) / enableEdgeToEdge，targetSdk 低于 35；写错的样子：规格的沉浸式节写 needs_immersive_safearea=true、「全屏页必须显式四件套」、四层架构和底部避让落点，照 page_type 默认值填
适用范围：规格阶段为迁移页面写窗口是否全屏、系统栏底色与内容避让方式时
做法：
- 先逐项核源窗口信号：主题链的 windowFullscreen、windowTranslucentStatus / Navigation、透明 statusBarColor；代码的 FLAG_FULLSCREEN、SYSTEM_UI_FLAG_LAYOUT_*、setDecorFitsSystemWindows(false) / enableEdgeToEdge；targetSdk≥35
- 全都没有时规格写「非全屏窗口：系统栏不透明，底色和图标色照源，内容在两栏之间，页面不做 inset 避让」，needs_immersive_safearea=false，不沿用 page_type 推出的默认 true
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- windowFullscreen：Flag indicating whether this window should fill the entire screen，对应 FLAG_FULLSCREEN：主题里要有这一项才是全屏窗口（出处：Android SDK 平台资源 data/res/values/attrs.xml，Window 的 windowFullscreen（按应用的 compileSdk 取对应平台））
- windowTranslucentStatus：请求半透明状态栏，对应 FLAG_TRANSLUCENT_STATUS：有这一项时内容才延伸到状态栏下（出处：Android SDK 平台资源 data/res/values/attrs.xml，Window 的 windowTranslucentStatus（按应用的 compileSdk 取对应平台））
- FLAG_FULLSCREEN：hide all screen decorations (such as the status bar) while this window is displayed：代码里设了它才隐藏状态栏（出处：android.view.WindowManager.LayoutParams#FLAG_FULLSCREEN）
- Theme.Holo + targetSdk 17、无上述标志：各页内容在黑色状态栏和导航栏之间，目标还原为非全屏 + 黑色系统栏后一致：非全屏源窗口的实际样子（出处：卡里修好并验证过）
针对本应用要查的：
- 源窗口是否延伸到系统栏下：源工程 AndroidManifest 的 targetSdkVersion 与 Activity / application 的 android:theme，沿 res/values*/styles.xml、themes.xml 的 parent 查到平台主题；Activity 代码里的 getWindow().addFlags / setSystemUiVisibility / setDecorFitsSystemWindows；上面任一信号存在才按全屏处理；都没有就按非全屏，系统栏底色取主题的 statusBarColor / navigationBarColor 或平台主题默认
