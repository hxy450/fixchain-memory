# 用户说明某个导航模式正常时，验收条目写明该模式下底部布局不变

审的是：规格
触发（任一种）：
- 读到：用户请求写「隐藏虚拟导航栏时没有问题，开启时底部 Tab 被遮挡」，只要求某一导航模式下避让；写错的样子：验收条目只写了被遮挡的模式要避开导航条，没写用户说正常的模式（如手势导航）下底部栏高度和间距保持不变
适用范围：全屏沉浸窗口底部栏避让导航条这类改动的验收条目
做法：
- 验收条目并列两项：遮挡的模式下底部栏不被导航条遮住；用户说正常的模式下底部栏高度、文字到底边的距离和改动前一致
