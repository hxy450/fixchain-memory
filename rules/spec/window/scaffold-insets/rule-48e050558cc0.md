# 同一内容区的列表、顶栏、浮层共用一个避让口径，改一处 inset 时同区规格一并改

审的是：规格
触发（任一种）：
- 读到：源端同一个 Box 里叠着列表、顶栏和浮层（scrim + 居中卡片，Modifier.fillMaxSize()），整体在 Scaffold innerPadding 之内；写错的样子：列表首项、顶栏的规格按 statusBarHeight 避让，浮层规格却写「needs_immersive_safearea=false → 跳过本契约；scrim 覆盖整个区域（含顶部状态栏占位区）」，状态接口没有 statusBarHeight；或收到 inset 纠正后只改了一页的规格
适用范围：规格提取时同一内容区内多个层（列表、顶栏、浮层、对话框）分在不同规格页的情形
做法：
- 同一内容区的所有层写同一个避让口径，浮层规格的状态接口里带上 statusBarHeight，不因 needs_immersive_safearea=false 就写「跳过」
- 收到某页的 inset 纠正时，搜引用同一区域的其他页面规格和功能规格（含 needs_immersive_safearea=false 的浮层页）一并改；「宿主 padding 还是子页自理」写成一条可引用的决策
