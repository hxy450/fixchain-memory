# 根视图按状态栏 insets 设顶部 padding 时，规格写内容区从状态栏下沿开始、布局高度扣除状态栏

审的是：规格
触发（任一种）：
- 读到：源 Activity 给 DecorView（根视图）setPadding(0, statusBarInsets.top, 0, 0)，内容 View 在 onSizeChanged(width, height) 里按自身尺寸调 getLayout 之类的布局方程；写错的样子：规格写「状态栏沉浸 + 顶部安全区避让，布局方程沿用全屏尺寸」，或要求在布局输出上整体做 Y 平移
适用范围：规格里写页面避让方式和内容区尺寸契约的那一节，源端用根视图 padding 避让状态栏时
做法：
- 契约写明：父视图 padding 缩小子视图尺寸，内容区从状态栏下沿开始，布局高度 = 窗口高 − 状态栏高；目标端用页面容器的顶部 padding 实现，内容组件直接用自己收到的宽高
