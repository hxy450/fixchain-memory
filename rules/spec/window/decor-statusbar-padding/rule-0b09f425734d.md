# DecorView 自绘状态栏底色且页面有遮罩弹窗时，规格映射为页面容器背景加顶部 padding、系统栏透明

审的是：规格
触发（任一种）：
- 读到：源端（如 Android 15+ 分支）在 DecorView 上 setBackgroundColor(color) 并 setPadding(top=statusBarInsets.top)，状态栏区域的底色由应用根视图绘制；页面里有带遮罩的弹窗；写错的样子：规格、验收条目或台账把这处底色映射为 window.setWindowSystemBarProperties({ statusBarColor })，写「系统栏底色 #…」
适用范围：源端状态栏区域底色由根视图背景绘制（不是 window.setStatusBarColor），且页面有弹窗遮罩时，规格里的平台等价映射
做法：
- 映射写成：页面容器 .backgroundColor(底色资源) + .padding({ top: 顶部避让高度 })，系统栏 statusBarColor 设透明 '#00000000'；只有源端调 window.setStatusBarColor 的分支才对应系统栏属性
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 页面容器自绘底色时，弹窗遮罩能把状态栏区域一起压暗；系统栏着色时遮罩压不到状态栏：两种映射在有遮罩弹窗时看得出差别（出处：卡里修好并验证过）
- setWindowSystemBarProperties(systemBarProperties: SystemBarProperties): Promise<void>：设置系统栏属性（含 statusBarColor）的接口，由系统栏窗口绘制（出处：鸿蒙 SDK 的 ets/api/@ohos.window.d.ts，Window.setWindowSystemBarProperties）
