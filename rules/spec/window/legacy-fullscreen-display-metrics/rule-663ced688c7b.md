# 基准高经整数截断决定格数行数时，AC 写参照机尺寸下两端一致的派生整数

审的是：规格
触发（任一种）：
- 读到：源公式把基准宽高整数截断成格径、底栏、起始空行等（如 (int)(y·40%/格径)）；写错的样子：AC 只断言基准公式或「非全窗高」，没写参照机尺寸下派生出的格径、行数等整数，也没写参照机实测的应用窗口尺寸
适用范围：为按屏幕像素整数截断计算的几何写验收项时
做法：
- AC 写成参照机尺寸下的派生整数两端一致（如格径、起始空行），并写明参照机实测的应用窗口宽高，用它核对目标端基准
