# DisposableEffect 挂在承载多屏的外层 Composable 时，规格把清理归到外层生命周期

审的是：规格
触发（任一种）：
- 读到：同一个 Composable 里先声明 DisposableEffect(Unit) { onDispose { …cancel(); player.stop() } }，再用状态变量 if (screen == …) 切换两个屏幕；写错的样子：目标拆成两个页面后，规格范围只写一个页面，对接点写「页面销毁：取消播放任务并 stop()」、判据写「页面退出后无持续音频」；没写切到另一屏时播放继续
适用范围：规格提取时，把源端一个 Composable 内多屏共享的资源清理映射成目标端多页面的生命周期契约
做法：
- 对照源码确认 onDispose 的真实触发：只有承载这些屏的外层 Composable 离开组合时；只改 screen 状态的切屏不触发
- 清理归属写成外层生命周期（目标端通常是 Ability 或 Navigation 宿主页），跨页对接点写「切到另一屏不停止播放，Ability 销毁时 stop()」
- 逐个列出源码里改 screen 状态的入口，确认它们对应的目标导航动作没有被写成释放条件
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 切到另一屏只改 screen，外层 Composable 仍在组合中，onDispose 不触发，播放任务和播放器继续存在：源端的实际行为（出处：卡里修好并验证过）
- 非栈顶页面 push 进栈时 NavDestination 触发 onHidden；aboutToDisappear 只在自定义组件析构销毁前执行：目标端推入子页时下层页面不销毁（出处：arkts-navigation-navdestination.md，页面生命周期）
未核实：卡里没有设备复现「播放中切到另一屏」时音频是否被打断
