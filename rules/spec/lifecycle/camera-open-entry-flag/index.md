# 相机打开回调里读的一次性入口标志

agent 会看到什么：读到源端在相机打开或预览建立的回调里读桌面小部件、快捷入口置位的一次性拍照标志并读后即清；规格 AC 正文写「相机打开完成后读取」，`标:` 锚点和对接点却写成 aboutToAppear / onPageShow，计划的 cross_slice_edits 挂到页面生命周期

## 规矩

- rule-78137143175c｜源端在相机打开回调里读一次性入口标志时，规格锚点和对接点落在目标相机就绪回调｜读到：源端在相机打开或预览建立的回调里读取一次性入口标志（桌面小部件、快捷入口置位的拍照标志）并读后即清，再进入按对焦模式延时拍照的设置流程；写错：AC 正文写“相机打开完成后读取、先开后拍”，`标:` 锚点和对接点却写成 aboutToAppear / onPageShow；计划的 cross_slice_edits 照此挂到页面生命周期
