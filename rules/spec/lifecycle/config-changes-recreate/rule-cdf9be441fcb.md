# 规格把语言重读写成「$r 自动重解析」时，要求列出代码内文案快照及页面侧重取订阅

审的是：规格
触发（任一种）：
- 读到：源端 Activity 未声明 configChanges，语言变化走 recreate 重读全部文案；写错的样子：验收条目或计划把「语言变化重读文案」写成「全应用 $r 重解析」或「随语言存储同链刷新」，页面订阅清单只列弹层关闭、计数重判等，没有代码内取值的文案快照
适用范围：规格或切片计划设计配置变化重放（语言、深色模式、字号）时
做法：
- 同时要求实现方列出页面代码里取值写进状态的文案快照（getStringSync 等），每个快照点都要有页面侧重取订阅，写进验收条目
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 设置应用偏好语言后应用界面切换为目标语言：只说明界面资源随偏好语言加载，不包括代码里已取成字符串的值（出处：i18n-preferred-language.md，开发步骤）
