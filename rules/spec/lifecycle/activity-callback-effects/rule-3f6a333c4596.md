# 源页面只在 onNewIntent 里刷新时，规格不把它映射成 onActive

审的是：规格
触发（任一种）：
- 读到：源页面只在 onCreate 和 onNewIntent（先 super.onNewIntent 再刷新）里刷新，没有 onResume 刷新；写错的样子：规格把「onNewIntent 刷新」映射成「页面 onActive / 回到前台即刷新」，验收条目写成「源:…onNewIntent → 标:…onActive」
适用范围：规格里写源端 onNewIntent 对应的目标时机时
做法：
- 规格写成：首次进入时刷新一次；新标签投递给本页、基类默认处理之后再刷新；页面重新显示时不刷新

- case-3735da03c6e544339df6（MifareClassicTool）：做法第 1 步 ← 诊断
