# 同一源方法出现在几份功能规格里时先核对口径，矛盾时按用户可见终态的 AC 修正服务层契约

审的是：规格
触发（任一种）：
- 读到：同一个源方法（如重启方法）被几份功能规格引用：有的 AC 写「点击通知后应用重启进入主页」，有的写「ApplicationContext 重启」；写错的样子：本份规格的服务层契约写「退出应用（terminateSelf），不附加重启」，与别的规格里描述用户可见终态的 AC 相反
适用范围：写规格时引用的源方法已出现在其他功能规格里
做法：
- 写 spec 前搜其他功能规格里对同一源方法的说法，核对口径一致
- 矛盾时以描述用户可见终态的 AC（如重启后进入主页、抽屉状态保持）为准修正服务层契约
