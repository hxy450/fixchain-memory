# 实现时读到源码注释与规格契约相反，要在 source-notes 差异项里登记并上报，不沉默沿用

审的是：规格
触发（任一种）：
- 读到：源码注释写「Performs a full app restart」，规格的服务层契约却写「退出应用（terminateSelf），不附加重启」；写错的样子：source-notes 的差异项里没有这一条，代码头注释只复述规格的判断（「注释称 full restart 实为退出」）
适用范围：实现阶段写源码理解笔记、对照源码与规格契约时
做法：
- 在 source-notes 差异项中登记：源码注释与调用点表明是重启，规格契约写的是退出，并上报请求修正规格；或按注释与调用点核实后直接实现重启
