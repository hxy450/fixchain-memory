# 源端没自定义转场时，transition_anim 写 platform-default，不写 none

审的是：规格
触发（任一种）：
- 读到：源码没有 overridePendingTransition，也没有 res/anim 下的转场引用；写错的样子：ui-graph 导航边的 transition_anim 一律填 "none"
适用范围：写 ui-graph 导航边的转场字段时
做法：
- 源端没调 overridePendingTransition 时，transition_anim 写 "platform-default(<主题名>)"，不写 "none"
针对本应用要查的：
- 主题名：源工程 AndroidManifest.xml 里该 Activity（或 application）的 android:theme；取 @style/ 后面的名字填进括号
来源：1 张卡，1 个应用
- case-6f936bc6ca2d4ec18528（Bubble Shooter）：做法第 1 步 ← 建议 1
