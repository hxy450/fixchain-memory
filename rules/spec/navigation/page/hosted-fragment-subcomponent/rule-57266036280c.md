# meta 标 sub_component 且源端壳内压栈打开的页面，规格不推荐 NavDestination 全屏页

审的是：规格
触发（任一种）：
- 读到：meta.page_type=sub_component；源码用 hide + add + addToBackStack 在宿主 Activity 内容区打开这个 Fragment；写错的样子：页面规格备注推荐「实现为 NavDestination 全屏页」，转换表写 NavDestination 标题栏；或 handback 宣称这些子页将实现为 NavDestination
适用范围：规格提取阶段写子 Fragment 页面的页面形态和转换表时
做法：
- 页面形态写成：「可嵌入组件（@Param 传参），由宿主壳内容区按 tag 承载，返回走壳的子栈弹出」；不拿已有页面的先例覆盖 meta 和源码加载方式
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- @Param 表示组件从外部传入的状态，初始化自定义组件时从外部传入：嵌入组件的参数写法（出处：arkts-new-param.md，概述）
