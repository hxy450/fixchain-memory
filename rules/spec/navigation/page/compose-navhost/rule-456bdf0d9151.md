# 源端起始目的地无 BackHandler 时，导航规格写明“栈底返回=退出/移至后台”验收项

审的是：规格
触发（任一种）：
- 读到：源端 NavHost 的 startDestination 页面没有 BackHandler，栈底返回依赖 Activity 默认行为；写错的样子：导航规格、全局约定和页面规格都没写栈底返回的语义，返回拦截只写了编辑页等个别页面
适用范围：规格提取阶段写导航规格，源端起始目的地的返回交给 Activity 默认处理时
做法：
- 导航规格加一条可验收项：只剩起始页时按返回 = 退出或移至后台，不出现空白的 Navigation 首页；不因源码里没有对应代码就省略
- 写明对齐的是哪种源端行为：Android 12 起任务根的启动 Activity 移到后台（目标端对应 moveAbilityToBackground），更早的版本是结束
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 从 Android 12（S）起，任务根且声明 ACTION_MAIN + CATEGORY_LAUNCHER 的 Activity 按返回时连同任务移到后台；更早版本结束当前 Activity：验收项里“退出”还是“移至后台”的依据（出处：android.app.Activity#onBackPressed）
针对本应用要查的：
- 起始 Activity 是否满足“移到后台”的条件：源工程 AndroidManifest.xml 里承载起始目的地的 Activity 的 intent-filter；声明了 android.intent.action.MAIN 和 android.intent.category.LAUNCHER 的，Android 12 起按返回移到后台
