# 页面对接点只从该页布局和 Fragment 实际绑定的控件推导，不收共享 ViewModel 里没调用的方法

审的是：规格
触发（任一种）：
- 读到：Fragment 只给部分控件挂 setOnClickListener；登录 SDK 类、事件类只出现在 import；共享 ViewModel 里有登录等方法，但该页没有调用；写错的样子：规格「对接点」一节把共享 ViewModel 的方法写成该页入口（如「某页: 登录入口消费…」），或 AC 以 ViewModel 方法为源写成该页要有的功能
适用范围：规格提取时写某个页面的对接点、入口和相关 AC
做法：
- 对接点只列该页布局里的控件和 Fragment 实际绑定的点击、调用；共享 ViewModel 里该页不调用的方法、只被 import 的 SDK/事件类不列，需要时注明「源端该页无入口」
