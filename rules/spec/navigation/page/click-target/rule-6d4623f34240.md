# 源端弹窗里有跳转回调时，源码理解笔记和 Spec Gap List 记下每个回调和目标

审的是：规格
触发（任一种）：
- 读到：源端弹窗配置里有打开 WebView 页的链接回调；页面规格的导航表列着到 WebView 页的跳转；写错的样子：源码理解笔记和 Spec Gap List 没记弹窗里的跳转回调，验收条目也没单列协议链接跳转
适用范围：切片的源码理解笔记、Spec Gap List 和验收条目里关于弹窗交互的部分
做法：
- 源码理解笔记逐条记弹窗内的回调：回调 → 目标页 → URL 来源；验收条目没覆盖的，记进 Spec Gap List 并在交付时列出，供 closer 或路由核验补齐
