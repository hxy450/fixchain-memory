# SDK 隐私弹窗配置带协议链接回调时，规格逐条写成验收项，并在导航表登记目标页

审的是：规格
触发（任一种）：
- 读到：源码用 SDK 的隐私弹窗配置对象（如 PrivacyConfig）以回调属性声明行为：同意、拒绝之外还有 goServiceLink / goPrivacyLink 这类协议链接回调，打开 WebView 页；或者参考规格的对话框目录写着隐私概要框含「协议链接」；写错的样子：功能规格的隐私验收只覆盖显示、外部点击不可关闭、同意持久化、拒绝退出、已同意不重复弹出，没有协议入口；页面导航表没有到 WebView 页的去向；「协议链接」只留在页面结构描述里
适用范围：规格提取阶段为首启隐私概要弹窗写验收条件和页面导航表时
做法：
- 配置对象的每个回调属性各写一条验收项，与同意、拒绝并列，例如「点击《用户协议》→ 打开 WebView 页加载服务协议 URL」「点击《隐私政策》→ 打开 WebView 页加载隐私政策 URL」
- 页面导航表给这两个入口各登记一行：弹窗所在页 → WebView 页，参数是对应的协议 URL
针对本应用要查的：
- 隐私弹窗配置对象上有哪些回调属性、各自打开什么：源工程里构造隐私弹窗配置对象的那段代码（启动页的显示隐私弹窗方法），按回调属性名逐个找；每个回调读出它调用的页面启动方法和传入的 URL 来源，写成一条验收项和一行导航
