# 源结果页按启动来源出的继续动作，规格逐个列出 onClick* 及其来源分支，写明来源由谁携带

审的是：规格
触发（任一种）：
- 读到：源结果页读启动方传入的来源类型，某个 onClick* 方法只在特定来源时进入编辑页等跨功能页面；写错的样子：功能契约的范围、AC 和状态交接只写结果保存，没列这个继续动作；路由参数写成只带稳定媒体 ID，没写来源类型由谁携带
适用范围：规格提取阶段确定结果页一类页面的动作和路由参数契约时
做法：
- 对源结果页逐个列出 onClick* 动作和它依赖的启动参数分支（如只有相机来源才进入编辑页），把结果页 → 编辑页这类继续动作写进范围或跨功能边
- 路由只传稳定 ID 时，在契约里写明来源类型由谁携带（随路由参数，或由哪个 store 提供）
针对本应用要查的：
- 结果页的动作和来源分支：源工程结果页 Activity/Fragment 的 onClick* 方法和打开它的静态 start(...) 调用，以及布局 XML 里的按钮；每个按来源类型的 if 分支记一条：哪个来源、出现什么按钮、进入哪一页
未核实：契约形成时规格作者是否读到源结果页的继续动作和按钮，卡里没能核实
