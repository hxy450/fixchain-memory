# 规格的页面导航表和 AC 里要打开的目标页，都要在页面清单里

审的是：规格
触发（任一种）：
- 读到：源码里截图页入口 startActivity 到二级页；写错的样子：页面导航表写「顶部入口 → 对应规则页 push」「查看更多 → 记录页」，AC 要求「关于/反馈打开对应页」，页面清单和决策却说本轮不建这些页
适用范围：规格写完页面导航表、AC 和页面清单之后的自查
做法：
- 逐条核对导航表和 AC 里要 push 或打开的目标页都在页面清单里；不在的，先把冲突消解（列入清单，或经用户确认后改导航表和 AC），再交出规格
