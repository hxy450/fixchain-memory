# 跳转目标页和页面清单

agent 会看到什么：读到截图页或入口页的 startActivity / start(url) 打开二级页、WebView 页；规格的页面导航表和 AC 里有要打开的页，页面清单、决策台账或目标路由里却没有、标成 pending 或本轮不生成

## 规矩

- rule-e8634dc8b871｜截图页入口直达的二级页，规格按源码导航取可达闭包列入页面清单，不自拟范围外｜读到：用户只附截图，要求按图片和安卓源码迁移、修到可交付并跳过确认；截图页源码的点击监听 startActivity 到说明页、记录页、关于、反馈等独立 Activity；写错：决策台账自填「仅截图页面，不含其他独立 Activity」「本轮不生成清单外页面，入口保持路由契约」，C2 迁移范围、C5 清单外页这类必问类目没问用户就定了
- rule-680a3823b05a｜规格的页面导航表和 AC 里要打开的目标页，都要在页面清单里｜读到：源码里截图页入口 startActivity 到二级页；写错：页面导航表写「顶部入口 → 对应规则页 push」「查看更多 → 记录页」，AC 要求「关于/反馈打开对应页」，页面清单和决策却说本轮不建这些页
- rule-b02840a13928｜规格阶段核对目标页和路由是否存在，不把 pending/forward-ref 当作对齐结果｜读到：源端入口点击后打开固定 URL 的 WebView 页或静态详情长图页，目标端工程里还没有对应页面和路由；写错：规格写「目标路由沿用现有注册或登记为 pending」，验收条目允许「无目标路由时保留 pending/forward-ref」，目标页是否存在留作待确认
