# 截图页入口直达的二级页，规格按源码导航取可达闭包列入页面清单，不自拟范围外

审的是：规格
触发（任一种）：
- 读到：用户只附截图，要求按图片和安卓源码迁移、修到可交付并跳过确认；截图页源码的点击监听 startActivity 到说明页、记录页、关于、反馈等独立 Activity；写错的样子：决策台账自填「仅截图页面，不含其他独立 Activity」「本轮不生成清单外页面，入口保持路由契约」，C2 迁移范围、C5 清单外页这类必问类目没问用户就定了
适用范围：规格提取阶段确定迁移范围（C2）和处置截图页入口直达的清单外页（C5）时
不适用的情形：用户明确说「只做这几页」时才排除二级页
做法：
- 以截图页为根，从源码的点击监听和 Intent 抽出每个入口的直达目标，把可达的二级页列进本轮页面清单或某个 feature
- 必问类目没法问用户时，按「按源码修到可交付」取可达闭包写决策，不取最窄解释；「跳过确认」不当作缩小范围的授权
针对本应用要查的：
- 截图页上每个入口的直达目标：源工程里截图页对应的 Activity/Fragment 源码：setOnClickListener、onClick 里的 startActivity(Intent(...)) 和菜单回调；每个 Intent 的目标 Activity 记成一个二级页，列进页面清单或 feature
未核实：派发规格作者的消息是否明确要求排除二级页，卡里没能核实
