# 规格阶段核对目标页和路由是否存在，不把 pending/forward-ref 当作对齐结果

审的是：规格
触发（任一种）：
- 读到：源端入口点击后打开固定 URL 的 WebView 页或静态详情长图页，目标端工程里还没有对应页面和路由；写错的样子：规格写「目标路由沿用现有注册或登记为 pending」，验收条目允许「无目标路由时保留 pending/forward-ref」，目标页是否存在留作待确认
适用范围：规格提取时为可点击入口定导航契约、而目标端缺目标页的情形
做法：
- 规格阶段就查目标端工程有没有对应页面和路由；目标只是固定 URL 的 WebView 页或静态详情长图这类小页面时，写进本次范围
- 确实超出已批准范围的，规格里逐项写「这些入口点击后将无反应」作为决策缺口交用户确认；验收条目不写 pending/forward-ref 也算对齐
