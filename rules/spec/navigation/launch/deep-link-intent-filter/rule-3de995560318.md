# 深链规格的 anchors 含 manifest 的 intent-filter，逐项列 scheme 和 host

审的是：规格
触发（任一种）：
- 读到：AndroidManifest 的 <intent-filter android:autoVerify="true"> 含 VIEW / BROWSABLE 和多个 <data android:scheme>（如 https 与 http）、android:host；写错的样子：深链规格的 anchors 不含 AndroidManifest.xml，uri 域只写 https 或自拟 scheme，漏掉 manifest 里的 http
适用范围：规格提取阶段写深链能力、作为 module.json5 skills uris 依据时
做法：
- anchors 列上 AndroidManifest 的 intent-filter，逐项写出每个 scheme（https 与 http 各一）、host、path 与 autoVerify，作为 module.json5 skills uris 的唯一依据
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- autoVerify 只在 ACTION_VIEW、CATEGORY_BROWSABLE 且 data scheme 为 http 或 https 时生效，用 data 里的 URI 做校验：源端 autoVerify 对应目标 skills 的 domainVerify（出处：Android SDK 平台资源 data/res/values/attrs_manifest.xml，autoVerify（按应用的 compileSdk 取对应平台））
- domainVerify：是否开启域名校验，缺省 false：目标 skills 里对应 autoVerify 的标签（出处：module-configuration-file.md，skills标签）
未核实：平台资源按本机 android-37.0 核实
