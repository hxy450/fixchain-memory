# 启动决策加了源端没有的 token 拦截分支时，台账标为相对源端的新增行为

审的是：规格
触发（任一种）：
- 读到：用户或产品方要求冷启动时拦截「有用户信息但 token 为空」；源端启动判定里没有这个分支；写错的样子：决策台账或迁移记录里没有这条相对源端的新增行为；或者把「取不到用户信息」的组合也一并改成去登录页
适用范围：目标端启动决策在源端分支之外新增拦截分支时
做法：
- 新分支放在决策首位：已登录且 token 为空 → 登录页；台账里写成「相对源端的新增行为」并注明来由
- 无用户信息的各组合仍按源端原有去向，不并入登录页
