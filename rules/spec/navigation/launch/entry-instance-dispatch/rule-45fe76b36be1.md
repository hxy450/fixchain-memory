# 入口分发 AC 照抄源端前置条件：源端在锁屏密码门之后才处理入口，落库动作写明「门之后」

审的是：规格
触发（任一种）：
- 读到：源端入口 Intent 的处理在密码门受理之后才被调用；写错的样子：规格的快存、分享落库 AC 只写「无 UI 落库」，没写「密码门之后」，实现把落库放进 EntryAbility 冷启 dispatch 里
适用范围：规格为入口分发（快存、分享、深链）写 AC 时
做法：
- AC 照抄源端分发的前置条件：快存、分享等落库动作写明「密码门之后」，并写明实现者不得把落库放进 EntryAbility 冷启 dispatch 内
