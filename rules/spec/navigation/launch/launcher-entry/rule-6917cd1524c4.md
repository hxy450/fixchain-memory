# 外部入口 Intent 带 FLAG_ACTIVITY_CLEAR_TOP 时，规格写出热启动先清上层页的后果

审的是：规格
触发（任一种）：
- 读到：桌面卡片等外部入口的显式 Intent 带 FLAG_ACTIVITY_CLEAR_TOP | FLAG_ACTIVITY_NEW_TASK 拉起主 Activity；写错的样子：规格只保留 flag 字面，或后果只写「进入某 tab」「冷启动与运行期 want 均覆盖」，没写应用在前台压着详情页时要先清掉详情栈
适用范围：规格提取阶段，为外部入口深链写导航契约和验收条目时
做法：
- 对每个 Intent flag 写出可观察后果，或登记 PD 豁免；CLEAR_TOP 写成：应用已在前台且压着详情页时，深链热启动先清空详情栈再落到目标 tab
- 对接点写明 onNewWant 里落 tab 前要 NavPathStack.clear()，不只写「onNewWant → 切 tab」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- FLAG_ACTIVITY_CLEAR_TOP：被启动的 Activity 已在当前任务里运行时，关掉它上面的所有 Activity，把 Intent 交给它：源端深链会清掉主 Activity 上已打开的页面（出处：android.content.Intent#FLAG_ACTIVITY_CLEAR_TOP）
- 打开详情后触发卡片深链，落到目标 tab 且详情已清：修复后上机验证的结果（出处：卡里修好并验证过）
