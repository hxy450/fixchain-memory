# 桌面小组件等系统表面的应用内替代页

agent 会看到什么：读到源端的 AppWidgetProvider 桌面小组件等系统表面在应用内没有入口，决策把它降级为新的应用内页面；决策台账或规格只写了替代页的加载和跳转，没写入口位置、形式和对已对等页面的影响

## 规矩

- rule-d87c1df43bb3｜批准把系统表面改为应用内页面时，台账同时写明入口位置、形式和对对等页面的影响｜读到：源端的系统表面（如桌面 Widget）在源应用内没有入口，决策把它降级为新的应用内页面；写错：决策台账或规格只写了替代页向外的动作（加载、跳转），没写用户从哪里进入、入口是什么形式、对已对等复刻页面布局的影响，也没列为决策缺口
