# 批准把系统表面改为应用内页面时，台账同时写明入口位置、形式和对对等页面的影响

审的是：规格
触发（任一种）：
- 读到：源端的系统表面（如桌面 Widget）在源应用内没有入口，决策把它降级为新的应用内页面；写错的样子：决策台账或规格只写了替代页向外的动作（加载、跳转），没写用户从哪里进入、入口是什么形式、对已对等复刻页面布局的影响，也没列为决策缺口
适用范围：决策或规格阶段批准「系统表面改为应用内页面」一类平台替代时
做法：
- 替代决策里写明入口的位置与形式，以及它对已对等页面布局的影响；未写明时列为决策缺口，不留给下游修复者临场选择
