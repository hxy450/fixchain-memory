# 规格描述侧栏分类页时写明内容区的展示范围，不写「对应分类分组」这类两可说法

审的是：规格
触发（任一种）：
- 读到：安卓侧栏分类页：左侧一级分类列表，右侧内容组件在同一个滚动列表里依次展示全部一级分类及其二级分类，左侧选中项随滚动位置变化；写错的样子：规格写「右侧展示对应分类分组」这类可作两种理解的说法，没写内容区是全部一级分组依次排列，还是只显示当前选中项
适用范围：规格提取阶段描述分栏页（左侧导航、右侧内容区）的结构时
做法：
- 照安卓源码二选一写明内容区范围：「全部一级分组在同一个滚动列表里依次排列，侧栏选中项与滚动位置联动」，或「只显示当前选中的一级分组」
- 不用「对应分类分组」这类两可的说法
针对本应用要查的：
- 内容区是全部分组还是只有选中分组：源工程分类页代码里父组件引用的右侧内容子组件；看它遍历的是全部一级分类还是只取选中项
