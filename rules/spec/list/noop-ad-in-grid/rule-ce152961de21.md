# 广告定为 no-op 时，规格对 Grid、WaterFlow 等多列容器写明广告位是否参与排布

审的是：规格
触发（任一种）：
- 读到：源端 GridLayoutManager 多列、SpanSizeLookup 让广告通栏；全局决策或派工把广告定为 no-op 空容器；写错的样子：规格的转换决策只写「广告项通栏：Grid columnsTemplate '1fr 1fr' + columnSpan 等价实现」或「零高塌陷与 Android 一致」，没写 no-op 广告位在多列容器里参不参与排布
适用范围：规格或全局决策把广告定为 no-op、页面里有 Grid、WaterFlow 等多列容器时的转换决策
做法：
- 对每个多列容器单独写一句：广告位恒为空，不生成 GridItem（或 FlowItem）、不参与排布，ForEach 只渲染内容项；数据层保留广告位时写明点击下标按过滤后的列表换算
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 零高的通栏项在多列宫格里仍独占一行：只写「零高塌陷」不能说明排布结果（出处：卡里修好并验证过）
