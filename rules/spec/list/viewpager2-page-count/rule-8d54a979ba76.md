# ViewPager2 的适配器恒为 1 页时，规格写「静态单页、不可横滑」，不按类型映射成 Swiper

审的是：规格
触发（任一种）：
- 读到：ViewPager2 + FragmentStateAdapter，getItemCount 返回只含一个元素的 listOf(…) 的 size；切页入口（currentItem = 1 之类）在单页下无效或隐藏；写错的样子：规格的容器映射写「ViewPager2 → Swiper」，理由是页面元数据的 navigation_mode 或组件类型；还写了为源端不存在的页「预置 Swiper index」，没有「单页、不可横滑」这条行为约束
适用范围：规格提取阶段为源端 ViewPager / ViewPager2 选目标容器并写手势行为时
做法：
- 先核适配器实际页数、isUserInputEnabled、切页入口是否可见和有效，再按运行时行为写容器契约
- 页数恒为 1 时，规格写明「静态单页、不可横滑，目标用普通容器（如 Column）直嵌内容」，不写 Swiper，也不为源端不存在的页预置 index
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 单页 ViewPager2 改成 Column 直嵌内容后，用力横滑内容不再位移：修好后的容器（出处：卡里修好并验证过）
针对本应用要查的：
- ViewPager2 实际有几页、能不能手滑：源工程里设置这个 ViewPager2 的 Activity / Fragment：adapter 的 getItemCount 和它背后的列表、对 isUserInputEnabled 的赋值、改 currentItem 的点击入口；列表元素个数恒为 1 或 isUserInputEnabled = false 即不可横滑；切页入口指向的页号超出页数即无效
未核实：安卓单页 ViewPager2 的过度滚动表现卡里没另证
