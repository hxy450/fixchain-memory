# 源页面用 ViewPager（含三方壳封装）时，规格写出释放定页、归位时长曲线和 offscreenPageLimit

审的是：规格
触发（任一种）：
- 读到：源码 import androidx.viewpager.widget.ViewPager（OnPageChangeListener、setOffscreenPageLimit），或 Activity 继承基于 ViewPager 的三方壳（如 AppIntro2），库是 AAR、仓内无源码；写错的样子：规格只写「ViewPager → Swiper 标准映射」「Swiper 为翻页标准容器」「默认即可对齐」「三方库无源码 → 按 Swiper 自研」，没有释放阈值、归位时长和曲线
适用范围：规格提取阶段，为源页面的 ViewPager 确定目标翻页容器和要保留的交互行为时
做法：
- 行为约束里写：位移 > 25dp 且速度 > 400dp/s 按速度方向翻页，否则当前页 + 页内偏移 + 0.4（前进）/ 0.6（后退）截断；归位时长有速度时 4×distance/velocity，否则 (pageDelta+1)×100ms，上限 600ms，五次缓出；以及 offscreenPageLimit
- 三方 AAR 没有源码时，先确认它的翻页容器是不是原生 ViewPager（反编译或库文档）再选容器；Swiper 给不了这些阈值时写成 Scroll + 自定义定页，或登记待核占位，不写「默认即可对齐」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- MAX_SETTLE_DURATION = 600 ms；MIN_DISTANCE_FOR_FLING = 25 dips；MIN_FLING_VELOCITY = 400 dips：归位上限和快划翻页的两个阈值（出处：com.android.internal.widget.ViewPager（框架内部的同源实现；androidx ViewPager 本机只有编译产物））
- determineTargetPage：|deltaX| > mFlingDistance 且 |velocity| > mMinimumVelocity 时按速度方向；否则 truncator = currentPage >= mCurItem ? 0.4f : 0.6f：释放定页规则（出处：com.android.internal.widget.ViewPager#determineTargetPage）
- Swiper 的 curve 默认 interpolatingSpring(-1, 1, 328, 34)：Swiper 缺省是弹簧曲线，不是五次缓出（出处：鸿蒙 SDK 的 ets/component/swiper.d.ts，SwiperAttribute.curve）
- 照 ViewPager 规则改成 Scroll 跟手加自定义定页和归位后，慢拖 55% 停留、65% 翻页、快划翻页、末页回弹两端一致：规格写出这些规则才能对齐（出处：卡里修好并验证过）
针对本应用要查的：
- 三方壳的翻页容器是不是原生 ViewPager：源工程依赖的三方库 AAR（Gradle 缓存里的 classes.jar 反编译）或库文档，找壳类的父类和有没有自定义 Scroller；父类是 ViewPager 且没有自定义 Scroller 的，按 ViewPager 的规则写
未核实：卡里记的是鸿蒙 SDK API 24，本机核实用的是 API 23
