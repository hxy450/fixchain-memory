# 页面启用加载更多时，规格的竞态或状态契约写明「加载中不重入、刷新中不派发加载更多」

审的是：规格
触发（任一种）：
- 读到：源页面用 SmartRefreshLayout 并 setEnableLoadMore(true)；ViewModel 的刷新和加载更多共用 pageNum；写错的样子：规格只把 SmartRefreshLayout→Refresh(onRefreshing / onReachEnd) 标为「官方等价」，竞态文档没有列表分页互斥条目；或写成「刷新与触底加载可交错，鸿蒙侧不做守卫（忠实还原）」
适用范围：规格提取阶段，为启用加载更多的列表页写竞态（races）或状态契约时
做法：
- 在竞态或状态契约里写一条：「加载更多进行中不重入；刷新中不派发加载更多（SmartRefreshLayout 单飞语义）」，不把共用 pageNum 推成两路可交错
- 把这一条和「翻页追加后无重复 id、增量等于本页数据长度」这类 AC 绑定
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- onReachEnd 在子组件未撑满列表时首次加载也会触发，弹簧效果下一次滑动可触发两次：目标端触底事件本身不保证单飞，契约要写门闩（出处：ts-container-list.md，onReachEnd）
未核实：SmartRefreshLayout「刷新中不派发加载更多」的状态机行为出自卡里对源码的判断，依赖库代码本机只有编译产物，没核原文
