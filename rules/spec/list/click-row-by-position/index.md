# 按 position 从当前数据表取行的列表点击回调

agent 会看到什么：读到源端列表点击回调（onListItemClick 等）按 position 从当前数据表取行，加载函数每次新建整张表；规格写了「每次整表重建」「ForEach 键含内容字段」，点击分发只写按状态分发、语义照抄，没写条目闭包里怎样定位当前行

## 规矩

- rule-6b85ccad4639｜规格写了整表重建和内容键时，点击分发契约里写明按唯一键查当前表定位行｜读到：源端点击回调（onListItemClick 等）按 position 从当前数据表取行，加载函数每次新建整张表；写错：规格写了「每次整表重建」「ForEach 键含内容字段、不用纯下标」，点击分发只写按状态分发、语义照抄，没写条目闭包里怎样定位当前行
