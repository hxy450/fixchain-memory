# 规格写了整表重建和内容键时，点击分发契约里写明按唯一键查当前表定位行

审的是：规格
触发（任一种）：
- 读到：源端点击回调（onListItemClick 等）按 position 从当前数据表取行，加载函数每次新建整张表；写错的样子：规格写了「每次整表重建」「ForEach 键含内容字段、不用纯下标」，点击分发只写按状态分发、语义照抄，没写条目闭包里怎样定位当前行
适用范围：规格里写列表整表重建与 ForEach 键契约、并描述条目点击分发时
做法：
- 点击分发契约里加一项行定位方式：与源端 position 等价，按行内唯一键在当前表里查（findIndex），不用对象身份 indexOf，也不用 ForEach 生成时的 index；不只写键
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 非首次渲染时键值已存在就不创建新组件，直接渲染该键值对应的组件：键写对了，同键行的闭包仍持有整表重建前的旧对象，所以行定位要单独写（出处：arkts-rendering-control-foreach.md，非首次渲染）
- 按唯一字段查当前表替代 indexOf(row) 后，子页返回再点击不再崩溃：契约里该写的定位方式（出处：卡里修好并验证过）
针对本应用要查的：
- 行内唯一键是哪个字段：源工程里列表数据类的字段和加载函数（看哪个字段在整表重建前后不变且不重复）；把这个字段写进规格的点击分发契约；源端有内置行等特殊行时一并写明它的唯一键取值
