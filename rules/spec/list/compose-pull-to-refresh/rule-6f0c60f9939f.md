# PullToRefreshBox 包住整个 Tab 区时，规格照原范围映射，不拆成每个 Tab 一个 Refresh

审的是：规格
触发（任一种）：
- 读到：源端一个 `PullToRefreshBox` 包住加载条和 `TabRow` + Pager 整体；写错的样子：转换决策表写「PullToRefreshBox → Refresh 包裹 List」，或者规格让每个 Tab 各放一个 Refresh
适用范围：规格里给包着多个 Tab 的 PullToRefreshBox 写转换决策时
做法：
- 转换决策里写明 Refresh 的包裹范围与源端一致：一个 Refresh 包住整个 Tabs 区（含加载条），不写成「包裹 List」
