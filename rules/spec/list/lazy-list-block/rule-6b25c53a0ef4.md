# 规格每页列出空态和加载态清单，写明源位置、字符串 key 和图标，并留在完成摘要里

审的是：规格
触发（任一种）：
- 读到：源页面或其子组件有列表为空、加载中时的内联状态（图标 + 标题 + 提示）；写错的样子：页规格没有空态/加载态清单，或完成摘要里列了各 UI 区块却没有空态条目
适用范围：规格交付时，每页的状态清单和交给实现者的完成摘要
做法：
- 每页列一份空态/加载态清单：每项写源文件位置、字符串 key 和图标
- 完成摘要里保留这份清单的条目（如“+ 空态”），供实现者逐项核对
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 完成摘要写了“+ 空态”的页面，实现者就实现了空态；摘要没写的页面漏了：空态是否被实现取决于摘要里有没有（出处：卡里修好并验证过）
