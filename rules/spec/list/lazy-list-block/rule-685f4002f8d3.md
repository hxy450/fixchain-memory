# 页面把列表区块交给另一文件的子 Composable 时，规格要打开正文写出各条件分支

审的是：规格
触发（任一种）：
- 读到：页面 Composable 把整块区域交给另一个文件里的子 Composable（带参数调用一次），子组件里是按类型分区的 LazyColumn；写错的样子：规格里这块只有一行“LazyColumn → List + ListItem + LazyForEach”，没写空列表、加载中、分区标题、扫描开关等分支，也没标 UNCLEAR
适用范围：规格提取阶段处理委托给独立文件子组件的区块，尤其是承载列表的区块
做法：
- 打开子 Composable 的正文，把条件分支逐条写进规格：空列表时显示什么、加载中、分区标题、扫描开关
- 没读正文时这块写 UNCLEAR，不写成只有一行组件映射的确定结论
针对本应用要查的：
- 子组件里每个分区的空态和其他条件分支：源工程里被页面调用的子 Composable 所在文件，搜 isEmpty()、EmptyState、if/when 分支；每个分支记下条件、显示的图标、标题和提示文案的字符串 key
