# 源是 LazyRow/LazyColumn 时，规格映射写带方向的可滚动容器和恒在槽位，不写成普通 Row

审的是：规格
触发（任一种）：
- 读到：Compose 源码里有 LazyRow / LazyColumn，item 个数固定、item 内用 AnimatedVisibility 控制显隐；写错的样子：规格映射表写成「LazyRow → Row + …」这类普通 Row / Column，没写滚动方向、排列方式，也没写 item 是否恒在
适用范围：规格里给 Compose 惰性行、惰性列写目标容器映射的那一项
做法：
- 映射写成带方向的可滚动容器（Scroll 加 .scrollable(ScrollDirection.Horizontal) 包 Row，或 List），并写明源端的排列方式（如 Arrangement.SpaceEvenly → FlexAlign.SpaceEvenly）和「item 恒在」
- item 内是 AnimatedVisibility 的，写明「隐藏时保留零宽槽位，槽位容器恒在、只有内容按条件出现」，不写成普通 Row 加条件分支
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- (scroller?: Scroller): ScrollAttribute；scrollable(value: ScrollDirection): ScrollAttribute，默认 ScrollDirection.Vertical：Scroll 的构造只收 Scroller，方向用 scrollable 设，不写默认竖向（出处：鸿蒙 SDK 的 ets/component/scroll.d.ts，ScrollInterface、ScrollAttribute.scrollable）
- listDirection(value: Axis): ListAttribute，默认 Axis.Vertical：用 List 承接惰性行时要显式写 Axis.Horizontal（出处：鸿蒙 SDK 的 ets/component/list.d.ts，ListAttribute.listDirection）
