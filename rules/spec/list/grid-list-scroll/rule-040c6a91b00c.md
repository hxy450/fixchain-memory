# 列表/网格页规格写明按压态、滚动条、越界效果的主题来源，以及会不会滚动

审的是：规格
触发（任一种）：
- 读到：源 GridView / ListView 没改 listSelector、scrollbars、overScrollMode；Activity 主题在多个 values-vNN/styles.xml 里定义；写错的样子：页面规格只写了列数和间距，没写条目按压态、滚动条、越界效果来自哪个主题和框架默认，也没写会不会滚动
适用范围：规格提取阶段为列表或网格页写外观和交互时
做法：
- 逐项写出按压态、滚动条、越界效果各自的来源：主题名、parent 链、对应 styles.xml 位置和框架默认；按行高 × 行数写明会不会滚动
