# 源端用厂商账号 SDK 时，规格先查目标是否有系统 Kit，有就写平台 API，不归三方无等价

审的是：规格
触发（任一种）：
- 读到：源端通过 HMS 账号 SDK 发起华为账号授权（反射装载实现、Empty 回退控制按钮可见性），产出 authorizationCode 交后端绑定；映射参考或 UI 规格写着「可映射华为 Account Kit」；写错的样子：规格把这个通道归入「三方无等价」HARD-DIV，写「无 1:1 等价 → 占位」，替代路径写「Account Kit vs 占位，grill #N 裁决」
适用范围：规格提取阶段为源端厂商账号、渠道 SDK 的登录通道确定鸿蒙侧实现路径时
做法：
- 先判断目标平台是否由系统 Kit 原生提供同类能力：华为账号对应 @kit.AccountKit 的 authentication.HuaweiIDProvider；有就把平台 API 和产出写进规格（authorizationCode → 后端绑定接口），不归 HARD-DIV
- 拿不准时到鸿蒙 SDK 的 hms/ets/kits 或 hms/ets/api 目录检索 d.ts 再定
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- @kit.AccountKit 导出 authentication、extendService、LoginPanel、LoginWithHuaweiIDButton 等：华为账号能力随系统提供，不需要另行入仓（出处：鸿蒙 SDK 的 hms/ets/kits/@kit.AccountKit.d.ts）
- HuaweiIDProvider.createAuthorizationWithHuaweiIDRequest(): AuthorizationWithHuaweiIDRequest（@since 5.0.0(12)）：创建华为账号授权请求（出处：鸿蒙 SDK 的 hms/ets/api/@hms.core.authentication.d.ts，authentication.HuaweiIDProvider.createAuthorizationWithHuaweiIDRequest）
- AuthorizationWithHuaweiIDCredential.authorizationCode?: string：交给后端的授权码（出处：鸿蒙 SDK 的 hms/ets/api/@hms.core.authentication.d.ts，AuthorizationWithHuaweiIDCredential.authorizationCode）
