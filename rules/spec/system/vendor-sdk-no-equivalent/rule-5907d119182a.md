# 规格对闭源三方 SDK 写「鸿蒙无等价」前，先查 ohpm 和厂商鸿蒙版，没查只能标待确认

审的是：规格
触发（任一种）：
- 读到：源端用闭源三方 SDK（如微信 OpenSDK：WXAPI.sendReq / handleIntent、WXEntryActivity、WXPayEntryActivity 回调）；写错的样子：页面规格的转换决策写「鸿蒙端无某 SDK 官方适配，回调链路不可复刻，仅保留状态接口」，没有 ohpm 或厂商鸿蒙版的查询结果
适用范围：规格提取阶段判断三方 SDK 在鸿蒙侧是否可用时
做法：
- 写结论前查 ohpm（微信是 @tencent/wechat_open_sdk）和厂商鸿蒙版状态，把查询结果和出处写进规格
- 没有查证时只标「待确认」，不写成转换决策
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 鸿蒙侧微信 OpenSDK 是 ohpm 包 @tencent/wechat_open_sdk，接入后登录和支付链路可实装：「鸿蒙无微信 OpenSDK」不成立（出处：卡里修好并验证过）
针对本应用要查的：
- 某个三方 SDK 有没有鸿蒙版：ohpm 仓库按厂商包名搜（如 @tencent/…），以及厂商开放平台的鸿蒙接入文档；查到包名和版本就写进规格作为正选；查不到也写明查过哪里，状态标待确认
