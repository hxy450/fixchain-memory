# 宿主生命周期不停播放器时，规格的 AVPlayer 映射写明切后台续播并登 HARD-DIV/PD

审的是：规格
触发（任一种）：
- 读到：宿主 Activity/Fragment 的 onPause、onStop、onDestroy 里不调用 MediaPlayer（或 ExoPlayer）的 pause/stop/release，只有显式退出或再次点击才停，播放会在退后台后继续到 onCompletion；写错的样子：规格的跨栈映射行把「MediaPlayer 内联播放 → AVPlayer」判为「行为等价」，生命周期 AC 里没有「切后台继续播放至结束」，也没有 HARD-DIV 或 PD 登记
适用范围：安卓用 MediaPlayer/ExoPlayer 播放音频、迁成 AVPlayer 时，规格里的跨栈映射行和生命周期 AC
做法：
- 先核对宿主 onPause/onStop/onDestroy 是否调用播放器的 pause/stop/release；都不调用时，在 AC 里显式写一条「切后台继续播放至结束」，并把这一映射行标为 HARD-DIV/PD，不写「行为等价」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 后台播放媒体类型（STREAM_USAGE_MUSIC、STREAM_USAGE_MOVIE、STREAM_USAGE_AUDIOBOOK）时，必须接入 AVSession 并申请 AUDIO_PLAYBACK 类型长时任务：前台 AVPlayer 本身不能退后台续播，规格里这一行不是行为等价（出处：continuous-task.md，使用场景（关于AUDIO_PLAYBACK（音视频播放）说明））
- 不满足接入规范时，退至后台播放会被系统静音并冻结，切回前台才解除静音并恢复：漏写这条 AC 时目标端的实际表现（出处：continuous-task.md，使用场景（关于AUDIO_PLAYBACK（音视频播放）说明））
- 只接前台 AVPlayer 时，目标端退后台被系统静音暂停，源端继续播放到结束：双机对照看到的差异（出处：卡里修好并验证过）
未核实：卡里上机对照出自 HarmonyOS 6.1.1(24)，本机文档副本和声明按 API 23 核对
