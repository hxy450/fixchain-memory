# 目标录制器缺原生限额时，映射表登记替代方式及其暂停、停止语义

审的是：规格
触发（任一种）：
- 读到：源端调 MediaRecorder.setMaxDuration / setMaxFileSize，由录制器自己计时、停止并回调 onInfo；写错的样子：规格映射表没有 setMaxDuration、setMaxFileSize 的行，只把 MEDIA_RECORDER_INFO_* 的语义交给实现层
适用范围：规格提取阶段写录制功能的映射表、目标平台没有对等的原生限额时
做法：
- 映射表为每个原生限额登记一行：目标替代方式（AVRecorderConfig 没有文件大小上限 → 轮询文件大小），暂停区间计不计入，到达上限后停止还是重启
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 源端 setMaxDuration 单位毫秒，AVRecorderConfig.maxDuration 单位秒（@since 18）：映射行里要写明单位换算（出处：android.media.MediaRecorder#setMaxDuration；鸿蒙 SDK 的 ets/api/@ohos.multimedia.media.d.ts，AVRecorderConfig.maxDuration）
- AVRecorderConfig 里只有 maxDuration，没有文件大小上限字段：文件大小上限要登记应用层替代方式（出处：鸿蒙 SDK 的 ets/api/@ohos.multimedia.media.d.ts，AVRecorderConfig）
