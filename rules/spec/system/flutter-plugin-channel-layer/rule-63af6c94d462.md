# 通道契约除 Dart 枚举外再列源原生 handler 全部分支，标出「原生已处理、Dart 未调用」

审的是：规格
触发（任一种）：
- 读到：源原生侧 when (call.method) / switch 的分支比 Dart 侧方法枚举多（如日志类方法），Dart 侧有字符串字面量的 invokeMethod 或被注释的调用；写错的样子：通道契约只按 Dart 侧方法枚举列方法，写「鸿蒙侧只需实现这 N 个方法即可」，没有源原生侧处理而枚举没有的方法
适用范围：混合工程提取 MethodChannel 通道契约时
做法：
- 除 Dart 枚举外，再 grep 源原生侧 when(call.method) / switch 的全部分支，以及 Dart 侧 invokeMethod 的字符串字面量（含被注释的调用），在契约里标出「原生已处理、Dart 当前未调用」的方法
- 日志类方法若 Dart 侧 release 分支的调用被注释，把「是否恢复调用」作为一条决策记下，不在原生侧直接省略
针对本应用要查的：
- Dart 侧对这个通道的全部调用：源工程 lib/ 下的 Dart 文件，按通道名和 invokeMethod( 搜，连注释掉的行一起看；列出每个方法名字面量和它是否处在被注释或只在某个构建分支里的调用
