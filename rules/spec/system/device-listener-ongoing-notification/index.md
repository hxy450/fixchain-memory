# Fragment 里常驻的设备监听和它发的常驻通知

agent 会看到什么：读到 Fragment 里注册一次、不注销的设备监听，连接、断开、电量回调在开关为真时以固定通知 ID、setOngoing(true) 更新通知，二级页另有随页面注销的监听；规格只写「监听按页面生命周期订阅/注销」，把常驻通知也归进页面生命周期，没指定唯一发布服务

## 规矩

- rule-38fe791c5257｜同一源监听有多个消费者时，规格按生命周期拆开写契约，常驻通知随开关与许可、指定唯一发布服务｜读到：Fragment 里注册一次设备监听且不注销，连接、断开、电量回调在开关为真时以固定通知 ID、setOngoing(true) 更新通知；二级页的监听随页面注销且不发通知；写错：规格只写「监听按页面生命周期订阅/注销」，把常驻通知也归进页面生命周期；没有单列「随通知开关 + 系统许可、冷启动恢复、关开关才撤销」的应用级契约，也没指定唯一发布服务
