# 平台做不到的只收敛那一步，源端外跳按钮和失败回退链在规格里照原样保留

审的是：规格
触发（任一种）：
- 读到：源端对话框按钮发 market://details?id=… 的 Intent、ActivityNotFoundException 时转 https 网页，startActivity(new Intent(Settings.ACTION_NFC_SETTINGS))，或拉起其他应用；同一流程里另有查询他包安装、运行状态的判断；写错的样子：规格的平台差异决策把整条分支改成「说明文本」「设置主页或引导文案」，删掉商店跳转、拉起他应用或设置深链按钮，并作废对应的验收条目
适用范围：规格提取阶段，为源端平台专有出口（商店跳转、系统设置深链、跨应用拉起）登记平台差异决策时
做法：
- 平台差异只写确实做不到的那一步（如查询他包安装、运行状态，目标端恒为未知），其余出口写成「尝试 + 失败回退」：商店链接失败转 https 网页、NFC 设置页失败退设置首页、拉起他应用失败静默；按钮和验收条目都保留
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Settings.ACTION_NFC_SETTINGS 的说明要求防范没有匹配 Activity 的情况：源端这类深链本来就是「尝试 + 回退」，规格照这个形态写（出处：android.provider.Settings#ACTION_NFC_SETTINGS）
- 保留「他包状态恒未知（false/-1）」，恢复全部按钮出口：market:// 失败转网页、拉起他应用失败静默、NFC 设置失败退设置首页：修好后的平台差异范围（出处：卡里修好并验证过）
