# 只能用系统分享面板替代应用内面板时，作为 UX 差异单独写进台账请用户确认

审的是：规格
触发（任一种）：
- 读到：项目规则把“系统组件 vs 应用内”列为须查台账的 UX 差异；用户批准的只是“接入现有能力，有既有目标时保留入口和原动作”；写错的样子：决策台账里没有“应用内渠道面板 → 系统分享面板”这项替换，核对表直接把系统面板写成既有目标
适用范围：源端是应用内分享面板、目标端只能改用系统分享面板时
做法：
- 台账单列一条“系统组件 vs 应用内”UX 差异：源端应用内渠道面板 → 目标系统分享面板，写明差异（渠道列表、入口形态）并请用户确认；不在“复用现有能力”的笼统批准下默认替换
来源：1 张卡，1 个应用
