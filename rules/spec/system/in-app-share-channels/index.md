# 源端自建的应用内分享渠道面板

agent 会看到什么：读到源端分享入口截图后调自建分享工具的 shareImage(...)、传渠道项列表、回调按 platformName 分发到各渠道；外部入口核对表把既有目标定为 systemShare.ShareController 系统面板，没列源端交互形态，也没找目标工程里的「分享至」Sheet

## 规矩

- rule-26bb7e03e3e7｜源端分享走应用内渠道面板时，核对表先列交互形态，再在目标工程找同形面板｜读到：源端分享入口截图后调用自建分享工具的 shareImage(...)，传入渠道项列表，回调按 platformName 分发到 QQ 空间、动态、蓝牙等渠道；写错：外部入口核对表把这项分享的既有目标定为系统分享封装（构造 systemShare.ShareController 再 show 系统面板），没列源端交互形态，也没检索应用内的“分享至”Sheet 组件
- rule-10621c459b94｜只能用系统分享面板替代应用内面板时，作为 UX 差异单独写进台账请用户确认｜读到：项目规则把“系统组件 vs 应用内”列为须查台账的 UX 差异；用户批准的只是“接入现有能力，有既有目标时保留入口和原动作”；写错：决策台账里没有“应用内渠道面板 → 系统分享面板”这项替换，核对表直接把系统面板写成既有目标
