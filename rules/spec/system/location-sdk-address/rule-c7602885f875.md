# 源端能力由第三方 SDK 隐式附带时，规格的服务接口写明名称来源和降级顺序

审的是：规格
触发（任一种）：
- 读到：源端定位 SDK 的结果同时带地址（district、city），业务直接用它作地名；写错的样子：规格的定位服务接口只写 locate(): GeoPoint，没有写名称从哪里来、为空时取什么
适用范围：规格阶段为目标定位等服务写接口，源端第三方 SDK 顺带给出附加数据时
做法：
- 在目标服务接口里写明名称来源（如逆地理编码 getAddressesFromLocation）和降级顺序（district 为空取 city），接口返回坐标和名称，不只保留 locate(): GeoPoint
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- function getAddressesFromLocation(request: ReverseGeoCodeRequest): Promise<Array<GeoAddress>>：目标端由坐标取地名的接口（出处：鸿蒙 SDK 的 ets/api/@ohos.geoLocationManager.d.ts，geoLocationManager.getAddressesFromLocation）
