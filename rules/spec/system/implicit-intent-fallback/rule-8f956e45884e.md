# 规格断言目标平台没有某能力前先查声明，未核实前保留源端回退和重启语义

审的是：规格
触发（任一种）：
- 读到：源码用 ACTION_VIEW 打开 geo: URI，可用性检查为假时改开网页地图 URL（两级回退）；写错的样子：规格断言「HMOS 无 geo: scheme 隐式 intent 体系」，把两级回退的验收条目标 superseded，另立 PD 改成固定网页 URL 单级 startAbility
- 读到：方法注释「Performs a full app restart」、方法体 System.exit(0)，调用点在语言切换、恢复数据之后；写错的样子：服务层契约写「System.exit(0) 忠实迁移 = 退出应用（terminateSelf），不附加重启」
适用范围：规格提取时，把源端系统交互（隐式意图、进程重启等）翻成目标契约、想写「目标平台没有 X」的地方
做法：
- 写「目标没有 X」前先在 SDK 声明里核：隐式拉起有 bundleManager.canOpenLink 加 module.json5 querySchemes，整应用重启有 ApplicationContext.restartApp；并读源方法的调用点确认期望行为
- 没核实之前，规格保留源端的两级回退和重启语义，不用 PD 把回退裁成单级、把重启降级成退出
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- canOpenLink(link: string): boolean：判断链接能否打开，scheme 要在 querySchemes 里（出处：鸿蒙 SDK 的 ets/api/@ohos.bundle.bundleManager.d.ts，bundleManager.canOpenLink）
- restartApp(want: Want): void：重启应用并拉起指定 UIAbility，@since 12（出处：鸿蒙 SDK 的 ets/api/application/ApplicationContext.d.ts，ApplicationContext.restartApp）
