# 源端容器 ViewModel 组装列表、容器恢复选中页时，规格要认领组装规则并写进验收条目

审的是：规格
触发（任一种）：
- 读到：源码清单里的容器 ViewModel 在 init 里组装列表（取已存列表，再把定位项 add(0, …) 插到首位并去重），容器 Fragment 加载后按持久化选中项 setCurrentItem、onPageSelected 里回写；写错的样子：各功能规格的锚点都不含这个容器 ViewModel，或声明「不认领」它和容器 Fragment，对接点只写「容器消费某列表、某选中项」；验收条目里没有首项插入、去重、重启后恢复当前页、切页回写这几项
适用范围：多页容器（ViewPager2 + 每页一个 Fragment）的列表由容器 ViewModel 组装、迁成 Swiper 时，规格里的源码归属和验收条目
做法：
- 规格把容器 ViewModel 的列表组装规则明确归到一个功能，写出列表的来源、哪一项插到首位、按什么键去重，以及加载后按哪个持久化项恢复当前页、切页回写哪个持久化项
- 验收条目加一条：预置持久化选中项为非首项且存在定位项，重启后首屏停在该项、列表首项是定位项；滑到另一项后再重启，停在新的那一项
针对本应用要查的：
- 容器的列表组装规则和选中项的读写：源工程里容器 ViewModel 的 init 和加载方法的函数体（不只看签名大纲），以及容器 Fragment 的加载观察者和 onPageSelected；找出对列表的 add(0, …)、去重条件和读写持久化选中项的调用，逐条写进认领它的那个功能的规格和验收条目
