# 按 feature 划分所有权时，委托出去的步骤写成跨 feature 契约，写明提供方接口和「输入可能只有 ID」

审的是：规格
触发（任一种）：
- 读到：源端请求前按 ID 查本地库补齐参数，规格把对应 DAO 划给另一个 feature；写错的样子：本 feature 规格只写「消费当前选择对象」「仅通过对方服务契约消费」，没有写提供方的查询接口、调用时机和输入只有 ID 的情形；对方规格也只发布选择对象
适用范围：规格按 feature 拆分所有权、把某一步委托给别的 feature 时
做法：
- 被委托出去的步骤写成跨 feature 契约：提供方接口（如按 ID 查询的仓储方法）、调用时机（请求前）、输入只有 ID 时的处理，双方规格都写
来源：1 张卡，1 个应用
