# 每局重开的复位 AC

agent 会看到什么：源端 Java 类里带初始化器的 static 字段、宿主 View / Activity 的实例字段，和每局重开函数体里实际赋值的字段；规格里重开函数的复位 AC

## 规矩

- rule-e03d10023927｜每局重开的复位 AC 只列重开函数体实际赋值的字段，类静态和宿主实例字段写成初值说明｜读到：源端 Java 类里带初始化器的 `static` 字段、宿主 View / Activity 的实例字段；每局重开函数体内只 new 循环对象并给部分字段赋值；写错：规格里重开函数的复位 AC 把类静态字段或宿主实例字段的初值写成每局重开的初值断言（「字段=常量」列在这条 AC 里）
