# 每局重开的复位 AC 只列重开函数体实际赋值的字段，类静态和宿主实例字段写成初值说明

审的是：规格
触发（任一种）：
- 读到：源端 Java 类里带初始化器的 `static` 字段、宿主 View / Activity 的实例字段；每局重开函数体内只 new 循环对象并给部分字段赋值；写错的样子：规格里重开函数的复位 AC 把类静态字段或宿主实例字段的初值写成每局重开的初值断言（「字段=常量」列在这条 AC 里）
适用范围：规格提取阶段，为源端每局重开（重开函数里新建循环对象）写复位验收条目时
做法：
- 写复位 AC 前逐字段标出声明位置和生命周期；每局复位只列重开函数体实际赋值的字段，以及函数里 new 出的对象的实例字段初始化器
- `static` 字段和宿主实例字段写进「常量 / 初值」说明，不写成每局复位断言
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- `static` 字段初始化器只在类加载时执行一次；宿主实例字段只随宿主构造初始化；每局 new 出的对象的实例字段随 new 重置：三类字段的生命周期，决定它们是否属于每局复位（出处：卡里修好并验证过）
