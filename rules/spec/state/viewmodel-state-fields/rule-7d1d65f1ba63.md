# 源端文案模板插入格式化文本字段时，规格写明插值的源 getter、类型和格式

审的是：规格
触发（任一种）：
- 读到：源端文案写成 "${x}…"，x 来自观察一个 text 前缀、返回 LiveData<String> 的 getter；同一 ViewModel 另有同名的 LiveData<Integer> 原始数值字段；写错的样子：规格状态契约只写了原始数值字段（如 xxx: number），格式化字段清单（@Computed）里没有它，验收条目只留「{x}…」占位，没写 x 是什么格式
适用范围：规格提取阶段转写源端 UI 文案模板中插入的观察值
做法：
- 文案模板里每个插值写明源 getter、类型和格式（例：某 text 字段 = 源格式化器(剩余秒) → MM:SS，≥1 小时为 HH:MM:SS）
- 状态契约暴露原始数值时，同时列出对应的格式化 getter 或格式化规则，和其他已格式化的时间字段放在一处
针对本应用要查的：
- 插值字段的类型和格式化方式：源工程 ViewModel 里这个 text 字段的 getter，及它调用的格式化函数；看 getter 的返回类型（LiveData<String> 还是 LiveData<Integer>）和格式化函数的各个分支（小时、封顶值、≤0）
