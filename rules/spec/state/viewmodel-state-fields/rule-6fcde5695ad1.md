# 多状态页面的规格列出状态变量、各状态可见节点、Tab 顺序和列表项字段

审的是：规格
触发（任一种）：
- 读到：源页面由 ViewModel 的布尔状态切换两套覆盖层，Tab 文案来自 ViewModel 的数组常量，列表项来自 item 布局；写错的样子：页面规格只是通用模板，只列可见文本并指向布局文件，没写状态变量、各状态的可见节点、Tab 顺序和列表项字段；功能 AC 列举模式的顺序和源数组不同
适用范围：规格提取阶段写多状态页面的页面规格和功能验收条目时
做法：
- 页面规格写出：状态变量、每个状态下可见的节点、Tab 顺序、列表项字段
- 功能 AC 列举模式时按源 ViewModel 数组的顺序写，免得实现者把列举顺序当成界面顺序
