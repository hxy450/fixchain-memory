# Activity 实例字段和 static 字段的作用域

agent 会看到什么：读到源端状态分散在类 static 字段、Activity / 宿主 View 的实例字段和每局新建对象的字段里；规格的状态管理节并成一个「实例态」列表，服务层写成单例或「重置全局态」

## 规矩

- rule-9a6b5c0283a6｜Activity 实例字段承载的会话态，规格里要写成页面实例作用域，不写成单例｜读到：源 Activity 用非 static 的实例字段存会话数据（已读的数据、密钥、待写内容等）；只有另外的工具类用 static 保存全局状态；写错：规格的服务层接口把承载这些会话态的服务写成「页面编排单例」或 getInstance() 单例，没有区分 Activity 实例态和静态全局态
- rule-061ddbc5b4c6｜规格的状态管理节按生命周期分组列字段，服务层写明重开时复位哪些、保留哪些｜读到：源端状态分散在类 `static` 字段、宿主 View / Activity 的实例字段和每局新建对象的字段里；写错：规格把这些字段并成一个「实例态」列表（宿主字段和每局新建对象的字段并列），服务层用「重置全局态」概括重开函数
