# Activity 实例字段承载的会话态，规格里要写成页面实例作用域，不写成单例

审的是：规格
触发（任一种）：
- 读到：源 Activity 用非 static 的实例字段存会话数据（已读的数据、密钥、待写内容等）；只有另外的工具类用 static 保存全局状态；写错的样子：规格的服务层接口把承载这些会话态的服务写成「页面编排单例」或 getInstance() 单例，没有区分 Activity 实例态和静态全局态
适用范围：规格提取时为页面和服务层定状态作用域
做法：
- 规格里写明：Activity 实例字段承载的会话态是页面实例作用域，服务若持有它，按页面实例创建（每个页面实例 new 一个）；只有源端本就是静态全局的状态才映射为单例
针对本应用要查的：
- 哪些状态是 Activity 实例字段、哪些是静态全局：源工程 Activity 类开头的字段声明，以及它调用的工具类里的 static 字段和 static 方法；没有 static 修饰的成员归页面实例作用域；static 的归全局，可映射为单例
未核实：多个页面实例同时存在的实际路由卡里没有复现
