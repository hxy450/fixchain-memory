# 规格的状态管理节按生命周期分组列字段，服务层写明重开时复位哪些、保留哪些

审的是：规格
触发（任一种）：
- 读到：源端状态分散在类 `static` 字段、宿主 View / Activity 的实例字段和每局新建对象的字段里；写错的样子：规格把这些字段并成一个「实例态」列表（宿主字段和每局新建对象的字段并列），服务层用「重置全局态」概括重开函数
适用范围：规格提取阶段，目标架构要把多个源对象的状态合并进同一个模块级静态引擎时，规格的状态管理节和服务层说明
做法：
- 状态管理节按「类静态 / 宿主实例 / 每局新建对象实例」三组列出字段，不并成一个「实例态」列表
- 服务层对重开函数逐项写明复位哪些字段、保留哪些字段，不用「重置全局态」概括
