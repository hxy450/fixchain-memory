# §状态管理里新拟的 AppStorageV2 / PersistenceV2 键名

agent 会看到什么：读到源端只有成员字段、回调或单例状态，没有现成的存储键，规格模板的 §状态管理 要求写出 AppStorageV2 / @Local 键名和类型；交回的规格里新拟的键带「.」或「-」写成「领域.字段」式命名空间，或只写了分组的逻辑名
