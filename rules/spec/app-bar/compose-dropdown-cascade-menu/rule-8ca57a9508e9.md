# 规格写「ArkUI 不支持级联/子菜单」这类平台能力判断前先查文档，不确定就列待验证

触发（任一种）：
- 读到：源端菜单项带 children 子层（CascadeDropdownMenu）；写错的样子：规格里写「ArkUI Menu 不支持嵌套子菜单」「无 ArkUI 等价」，并据此把形态降级为两级下拉、底部弹层或平铺

做法：
- 写平台能力判断前查组件声明或文档，或做一次最小验证；查不清的在规格里列为待验证项，不据此降级形态
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- MenuItemOptions.builder?: CustomBuilder（Create the submenu）：MenuItem 能挂子菜单，「Menu 不支持子菜单」不成立（出处：鸿蒙 SDK 的 ets/component/menu_item.d.ts，MenuItemOptions.builder）
- subMenuExpandingMode(mode: SubMenuExpandingMode): MenuAttribute：Menu 的子菜单展开方式（@since 12）（出处：鸿蒙 SDK 的 ets/component/menu.d.ts，MenuAttribute.subMenuExpandingMode）
- SubMenuExpandingMode.SIDE_EXPAND = 0（主菜单旁展开）、EMBEDDED_EXPAND = 1（嵌在主菜单内展开）、STACK_EXPAND = 2（覆盖在主菜单上展开）：子菜单三种展开方式（出处：鸿蒙 SDK 的 ets/component/menu.d.ts，SubMenuExpandingMode）
