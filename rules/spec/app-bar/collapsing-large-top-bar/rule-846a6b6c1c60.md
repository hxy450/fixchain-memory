# 源 TopAppBar 带 enterAlways scrollBehavior 时，规格写成必须还原的折叠契约

审的是：规格
触发（任一种）：
- 读到：Compose 页面 Scaffold + TopAppBar，val scrollBehavior = TopAppBarDefaults.enterAlwaysScrollBehavior(rememberTopAppBarState())，Scaffold 挂 Modifier.nestedScroll(scrollBehavior.nestedScrollConnection)；写错的样子：页面规格的转换决策写「滚动收起可选」「或降级固定，差异登记」「简化决策允许降级为固定顶栏」，或转换表里没单列 scrollBehavior
适用范围：把带 scrollBehavior 的 Compose TopAppBar 页面迁成自绘 ArkUI 顶栏时的页面规格
做法：
- 规格写成必须还原的行为契约：上推先收顶栏、下拉先展开顶栏、停止时按半高（collapsedFraction 0.5）吸附、内容离顶后容器色 surface → surfaceContainer
- 转换决策里不写「可选」「或降级固定」；确需降级的走决策台账并登记占位，不在页面规格里预先授权
来源：1 张卡，1 个应用
