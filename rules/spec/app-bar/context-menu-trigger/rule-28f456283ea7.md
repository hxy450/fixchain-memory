# 规格区分上下文菜单的两种触发：点击 openContextMenu 是居中模态列表，长按是触点浮动菜单

审的是：规格
触发（任一种）：
- 读到：源码对视图 registerForContextMenu(view)，点击时 openContextMenu(view)（不带坐标），onCreateContextMenu 里 setHeaderTitle / setHeaderIcon；写错的样子：规格写“openContextMenu 锚定在按钮上弹出”或“长按/点击 → Menu 弹出列表”，不区分两种形态，也没写标题和图标
适用范围：规格提取阶段描述安卓上下文菜单的交互形态时
做法：
- 分两条写：点击（openContextMenu）→ 居中模态列表，带 header 标题和图标；已 registerForContextMenu 的视图长按 → 在触点处弹出的浮动菜单
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- openContextMenu(View view) 以程序方式为已 registerForContextMenu 的视图打开上下文菜单：点击入口来自程序调用，不是锚定按钮的下拉（出处：android.app.Activity#openContextMenu）
- registerForContextMenu(View view) 为视图登记上下文菜单：登记过的视图另有长按入口（出处：android.app.Activity#registerForContextMenu）
