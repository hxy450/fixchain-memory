# ModalNavigationDrawer 映射成 SideBarContainer 时，规格写明打开方式和内置按钮

审的是：规格
触发（任一种）：
- 读到：Compose 的 ModalNavigationDrawer 只经 gesturesEnabled 手势和页内菜单图标的 openDrawer 回调打开；写错的样子：规格的转换决策只写「ModalNavigationDrawer → SideBarContainer(Overlay)」，没写抽屉的打开入口，也没写内置控制按钮保留还是关掉
适用范围：规格提取时为源端模态抽屉写转换决策的那一项
做法：
- 转换决策里写明抽屉的全部打开方式（哪些页的菜单图标回调、边缘手势），以及内置控制按钮：源端没有悬浮切换按钮时写「.showControlButton(false)」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- showControlButton(value: boolean): SideBarContainerAttribute，默认值 true：不写时内置控制按钮会显示（出处：鸿蒙 SDK 的 ets/component/sidebar.d.ts，SideBarContainerAttribute.showControlButton；ts-container-sidebarcontainer.md，showControlButton）
