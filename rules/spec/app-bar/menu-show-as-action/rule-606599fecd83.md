# 框架 ActionBar 有 showAsAction=never 项时，规格给溢出面板写可见契约

审的是：规格
触发（任一种）：
- 读到：菜单 XML 里有 android:showAsAction="never" 的项；Activity 用框架 ActionBar，主题 parent=android:Theme.Holo 一类平台主题，源码里没有面板样式；写错的样子：规格只写「溢出菜单（Menu + MenuItem）」一行，没写面板底色与边线、宽度、行高、字号与左右内边距、行间分隔线、有无圆角、锚定位置，也没写点外部与返回键的模态语义
适用范围：规格提取阶段，溢出菜单由平台主题绘制的下拉面板承载、任务要求与源端逐屏一致时
做法：
- 像 AlertDialog 一样给溢出面板写可见契约：面板底色与边线、宽度（Holo 取 popup_menu_item_layout 的 minWidth 196dp）、行高 48dp、字号与左右内边距、行间分隔线、有无圆角、锚定位置（贴 ActionBar 下沿、右缘偏移），以及点外部只关闭且不触发下层、返回键关闭
- 取值来自源主题实际提供方（平台资源的 themes_holo.xml、styles_holo.xml、布局等）或源端截图实测，取不到的标「待核」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- popup_menu_item_layout 的 android:minWidth="196dip"，行高 ?attr/dropdownListPreferredItemHeight：溢出面板每行的最小宽度和行高来源（出处：Android SDK 平台资源 data/res/layout/popup_menu_item_layout.xml（按应用的 compileSdk 取对应平台））
- Theme.Holo：dropdownListPreferredItemHeight = ?attr/listPreferredItemHeightSmall，listPreferredItemHeightSmall = 48dip：Holo 下溢出面板行高 48dp（出处：Android SDK 平台资源 data/res/values/themes_holo.xml，Theme.Holo 的 dropdownListPreferredItemHeight、listPreferredItemHeightSmall（按应用的 compileSdk 取对应平台））
- Widget.Holo.PopupMenu 继承 Widget.Holo.ListPopupWindow，popupBackground 为 @drawable/menu_panel_holo_dark：面板底色和边线来自这个 drawable（九宫格图，颜色要截图实测）（出处：Android SDK 平台资源 data/res/values/styles_holo.xml，Widget.Holo.ListPopupWindow、Widget.Holo.PopupMenu（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 溢出面板的底色、边线和分隔线颜色：按「控件 style → Activity 主题 → 应用主题」找到 popupMenuStyle / dropDownListViewStyle 的提供方，再看它引用的 drawable（平台资源 drawable-*dpi 下的 menu_panel_holo_dark 等）；drawable 是九宫格图的，颜色按源端截图实测；取不到就在规格里标「待核」
未核实：卡里返修的面板数值来自双端截图实测和 AOSP 默认值，没核实生成期能否直接取得同样精确的数值
