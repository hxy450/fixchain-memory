# 规格把工具类归到功能时按真实调用点（grep 调用者），不凭名字挂到不调用它的页面

审的是：规格
触发（任一种）：
- 读到：源码里有一个文本或格式化工具类（…Utils.kt），只在少数几个组件里被调用；写错的样子：规格把这个工具类挂到一个并不调用它的功能上，真正调用它的功能的锚点里却没有它
适用范围：规格提取阶段分配工具类、共享 util 到各功能时
做法：
- 对每个工具类 grep 调用者，按真实调用点把它归到对应功能的 android_source_anchors；不调用它的功能不挂
针对本应用要查的：
- 工具类的真实调用点：源工程的 Kotlin / Java 源码，按工具类名或它的函数名 grep；列出调用它的文件，再看这些文件属于哪个功能
