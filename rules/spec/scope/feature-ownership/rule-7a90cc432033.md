# 规格把设置位的行为推给另一个 feature 时，先核对方规格有行为 AC，没有就本规格认领

审的是：规格
触发（任一种）：
- 读到：源码里某个设置位决定显示行为（例如切换全局 ImageLoader），它的读写和界面行为分在两个 feature 的源码里；写错的样子：规格写「这个设置位 → 另一个 feature」把行为整体推走，而对方规格只有开关持久化的 AC，没有这个设置位在各界面上的行为 AC，两边都没认领
适用范围：规格里把某个设置位的行为归给另一个 feature 的地方
做法：
- 在对方 feature 的规格里找到这个设置位的行为 AC（不只是开关持久化），核到了才写「→ 对方 feature」并引那条 AC
- 核不到就由本规格认领：写出设置位每个取值（含默认值）下，本 feature 每类界面的显示行为
来源：1 张卡，1 个应用
