# 规格给拍照完成回调和多帧采集执行指定归属 AC，不只写「归某功能」而该功能只覆盖触发侧

审的是：规格
触发（任一种）：
- 读到：源端拍照完成回调里复位状态、续拍、暂停预览，失败回调恢复预览；burst 类型决定帧数并整组回调；写错的样子：一份规格写「拍照 / 连拍归 F00x」「下发消费归 F00x」，被指向的那份规格只写触发侧，没有 AC 覆盖完成回调和多帧采集执行
适用范围：规格提取时把拍照功能拆到多份功能规格、互相指派归属时
做法：
- 为拍照完成回调（状态复位、续拍、暂停预览、错误恢复）和多帧采集执行（burst 类型 → 帧数 → 整组回调）各写明归属的 AC，落在同一份负责的规格里
