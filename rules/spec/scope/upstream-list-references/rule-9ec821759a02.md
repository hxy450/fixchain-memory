# 规格把取值写成「见某数据源」时，先确认那里真有值，查不到写「未核」并给源码位置

审的是：规格
触发（任一种）：
- 读到：查询接口清单的结果显示某类常量（如业务状态码）为 0 条；写错的样子：规格仍写「业务状态码：见接口清单的常量表（某码 登录过期…）」，指向的数据源里没有这些值，括号里留着推断出的码
适用范围：规格里把码值、常量、配置值指向另一份数据源而不直接写出时
做法：
- 写「见某数据源」前在该源里查到这些值；查不到时改写成「未核：见源码 <类名>」，给出定义和使用它的源码位置，删掉推断值
