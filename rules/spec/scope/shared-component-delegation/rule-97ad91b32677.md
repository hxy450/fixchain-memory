# 源端入口委托给共享组件时，审计和真值整理把「复用目标端共享组件及其动作」写成实现契约

审的是：规格
触发（任一种）：
- 读到：源端入口把点击委托给跨页面共享的详情对话框或分享弹层；写错的样子：审计或真值整理里按当前页面自有 API 逐项判定，把内嵌详情的更多、附件、前序、添加后续等动作写成「应禁用或显式报未实现」
适用范围：审计 / 真值整理阶段，写源端委托共享组件那些入口的实现契约时
做法：
- 对这类入口写一条实现契约：「复用目标端共享组件 X，接它的动作回调」，不按本页 API 表逐项判缺契约
