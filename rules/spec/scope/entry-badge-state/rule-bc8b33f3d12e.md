# 圈定迁移范围时反查功能的全部安卓入口，入口页上的红点、数量、角标写进规格或列为待确认排除项

审的是：规格
触发（任一种）：
- 读到：源码搜索把另一页面（如「我的」页 Fragment）列为含功能关键词的文件；该入口除跳转外还按独立接口字段显示数量、红点或角标；写错的样子：安卓基准只列功能页 Activity 和接口类；导航表把入口记为「既有路由」，写「不在规格中要求改造入口页」，入口状态及其接口字段、显示 / 隐藏条件一项都没有
适用范围：按单个功能增量迁移到已有鸿蒙工程、目标已有该功能入口时，规格划定安卓源码范围
做法：
- 从被迁移功能的页面反查安卓全部启动点，打开每个入口所在页面里与该功能相关的片段，再划定安卓基准文件
- 把入口上的数量、红点、角标写进规格：驱动它的接口和字段、显示 / 隐藏条件（含未登录、请求失败）；不纳入的列为待用户确认的排除项，不把「鸿蒙已有入口」直接记为「既有路由，无需对齐」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 入口红点由入口页单独请求的接口字段（值为 1 时显示，未登录或失败时隐藏）驱动，补上服务方法和入口页刷新后与安卓一致：入口状态不在功能页的接口里，只看功能页会漏（出处：卡里修好并验证过）
针对本应用要查的：
- 功能入口上的附加状态：源工程里启动该功能页的各处（startActivity 指向功能页的 Activity / Fragment），看入口视图附近的 setVisibility、红点或数量控件；顺着设置这些视图的方法找到请求的接口和字段、显示条件，写进规格
