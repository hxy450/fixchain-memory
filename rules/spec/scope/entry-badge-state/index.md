# 功能入口页上的红点、数量和角标

agent 会看到什么：安卓入口页（如「我的」页 Fragment）除了 startActivity 跳转，还按接口字段、登录状态 setVisibility 显示这个功能的红点、数量或角标，规格、Gate 摘要和验收清单只覆盖功能页内部、把入口记成「既有路由」

## 规矩

- rule-bc8b33f3d12e｜圈定迁移范围时反查功能的全部安卓入口，入口页上的红点、数量、角标写进规格或列为待确认排除项｜读到：源码搜索把另一页面（如「我的」页 Fragment）列为含功能关键词的文件；该入口除跳转外还按独立接口字段显示数量、红点或角标；写错：安卓基准只列功能页 Activity 和接口类；导航表把入口记为「既有路由」，写「不在规格中要求改造入口页」，入口状态及其接口字段、显示 / 隐藏条件一项都没有
- rule-66ccd4ac5b0b｜Gate 摘要和验收清单列出入口页上与功能相关的状态及其双态检查｜读到：安卓入口页上有该功能的红点、数量或角标，随接口结果、登录状态显示或隐藏；写错：Gate 摘要和验收清单只覆盖功能页内部链路，没有入口状态的有 / 无、未登录、请求失败检查项
