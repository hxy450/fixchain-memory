# Gate 摘要和验收清单列出入口页上与功能相关的状态及其双态检查

审的是：规格
触发（任一种）：
- 读到：安卓入口页上有该功能的红点、数量或角标，随接口结果、登录状态显示或隐藏；写错的样子：Gate 摘要和验收清单只覆盖功能页内部链路，没有入口状态的有 / 无、未登录、请求失败检查项
适用范围：写功能迁移的 Gate 摘要、验收条目时
做法：
- 验收清单为入口页上与功能相关的每个状态各列双态检查：有红点 / 无红点、未登录、请求失败时的显示；Gate 摘要里同样列出这些入口状态
