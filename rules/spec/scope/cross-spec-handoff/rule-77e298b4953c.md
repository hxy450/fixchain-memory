# 消费页规格引用源端共享谓词时，内联完整条件或指向定义它的 AC

审的是：规格
触发（任一种）：
- 读到：源端多个页面共用一个判定谓词（如列表项是否在播），它的完整条件只在某一份规格的 AC 里写过；写错的样子：消费页的规格只写了谓词的函数名，没写它的完整条件，也没指向定义它的 AC
适用范围：规格提取阶段，消费页引用别的功能规格里定义的共享谓词时
做法：
- 在消费页规格里内联谓词的完整条件（逐条用「且」连起来），或写明「见 <定义它的规格>-AC<编号>」
