# 源端同步序列的步骤

agent 会看到什么：源端同步在保存、排序之后还有写全局状态的步骤（保存当前选中项、更新全局当前 id）；源码笔记或审计总结里列出的同步顺序

## 规矩

- rule-db43cd521eeb｜审计或规格总结源端同步顺序时，写全局状态的步骤逐项列出，不省略｜读到：源端同步序列在保存、排序之后还有写全局状态的步骤（保存当前选中项、更新全局当前 id）；写错：源码理解笔记或审计总结里的同步顺序只列了保存、排序、发事件，漏掉写全局状态和持久化当前项的那一步
- rule-c1fda5722ce9｜同步链路的行为审计报告逐条写每个界面通知事件的发布位置和前置条件｜读到：安卓同步代码里发进度 0、进度 100、失败等界面通知事件，有的带前置条件（如已登录且同步 cursor 为 0）；写错：安卓行为审计的同步事实报告只列推拉顺序和触发入口，没逐条写进度 0、进度 100、失败各在哪发、前置条件是什么
