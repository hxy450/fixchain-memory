# 审计或规格总结源端同步顺序时，写全局状态的步骤逐项列出，不省略

审的是：规格
触发（任一种）：
- 读到：源端同步序列在保存、排序之后还有写全局状态的步骤（保存当前选中项、更新全局当前 id）；写错的样子：源码理解笔记或审计总结里的同步顺序只列了保存、排序、发事件，漏掉写全局状态和持久化当前项的那一步
适用范围：源码理解笔记、审计报告里总结源端同步或初始化顺序的部分
做法：
- 按调用顺序逐步列出同步序列，每个写全局状态或持久化的步骤单独一条，写明写的是哪个全局字段或键、在什么条件下写
