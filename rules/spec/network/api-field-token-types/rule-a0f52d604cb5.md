# 接口字段表记线上 token 类型和量级，雪花类长整数 id 在响应契约写按字符串保真

审的是：规格
触发（任一种）：
- 读到：Android 模型把 id、*_id 声明为 String，golden 响应或探针里同一字段是 JSON 数值；写错的样子：接口字段表只记 Android 声明类型 String，没有线上 JSON token 类型和取值量级；响应契约里没写超过 2^53 的数值按字符串保真
适用范围：规格里写接口字段表和公共响应契约的那几节
做法：
- 字段表除 Android 声明类型外，再记线上 JSON token 类型和取值量级
- 遇到雪花类长整数 id，在公共响应契约里写明「超过 2^53 的数值按字符串保真」，交给网络层
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 数值超出 -(2^53 – 1) 到 (2^53 – 1) 时，普通 number 不能逐位表示：契约里保真的界限（出处：鸿蒙 SDK 的 ets/api/@ohos.util.json.d.ts，BigIntMode.PARSE_AS_BIGINT）
