# 规格写「Gson → 显式 decoder」契约时，写明要保留的宽松转换

审的是：规格
触发（任一种）：
- 读到：源端用 Gson 反序列化 BaseResponse<T> 和各 Bean；真实响应样例还没采集（golden 标 needs_capture）；写错的样子：规格只写「Gson BaseResponse<T> → 显式 JSON decoder，保留名称、可空性和泛型边界」「decoder 必须显式校验字段」，没写数字↔字符串、布尔转字符串的宽松转换
适用范围：规格里写反序列化映射和共享 DTO 契约的那一节
做法：
- 契约里除字段名、可空性和声明类型外，写明要保留的宽松转换：数字 ↔ 字符串、布尔转字符串
- 真实响应尚未采集时，写明按源解析器的接受范围设计兼容，不按声明类型收紧
