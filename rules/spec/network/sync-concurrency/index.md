# 同步任务的并发调度

agent 会看到什么：源端每次同步触发都 scope.launch 新任务、在 Mutex.withLock 里排队先推后拉；规格里「并发触发复用当前任务」「单飞」这类调度说法

## 规矩

- rule-e4492a2f827a｜同步调度的规格写清源端每次触发怎么执行；目标单飞合并时写明运行中请求要尾随补跑｜读到：源端每次同步触发都 scope.launch 新任务，在 Mutex.withLock 内先推送队列再拉取，不复用在途任务；写错：规格写「并发触发复用当前任务」「全量同步、定向刷新共用一个 active task」，没写运行中到达的请求会触发尾随补跑
