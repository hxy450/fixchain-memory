# 解密失败时回退原文的响应钩子

agent 会看到什么：源端 beforeResponse 一类响应钩子调用解密函数、catch 里原样返回 content，接口清单里「是否全接口返回密文」仍是 open；规格网络层和决策台账写的解密失败语义

## 规矩

- rule-be1e2e1c5729｜源端解密函数 catch 回退原文时，规格写明失败回退原文、按业务码判定｜读到：源端响应转换钩子（beforeResponse 一类）调用解密工具函数，函数的 catch 分支原样返回传入的 content；写错：规格网络层写「解密失败显式返回错误，不伪造成功」，或只写「与源端等价的解密」而没写失败语义
