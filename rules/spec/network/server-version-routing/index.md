# SDK 按服务端版本分的路由表

agent 会看到什么：读到 SDK 的版本路由代码：宽松 semver 解析服务端版本、按 minor 分到各版本路由表、不支持的 minor 抛异常，另有 MIN_SUPPORTED_VERSION 一类常量；规格把整个 minor 写成单个补丁号、写「未知版本落最新分支」、省略解析规则，或把端点下限一律写成最新大版本

## 规矩

- rule-5a5c340ab7b8｜SDK 按服务端版本分路由时，端点下限取最早出现的版本，minor 分支写成 x.y.x｜读到：SDK 的版本路由代码：宽松 semver 解析服务端版本，按 minor 分到各版本路由表，不支持的 minor 抛不支持异常，另有 MIN_SUPPORTED_VERSION 一类常量；写错：规格把整个 minor 的分支写成单个补丁号、写「未知版本落最新分支」、省略解析规则，或无门控的端点下限一律写成最新大版本
