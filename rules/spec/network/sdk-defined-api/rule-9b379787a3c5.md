# 网络行为在三方 SDK 里时，规格的端点表从 SDK 路由注解机械导出，不凭方法名推断

审的是：规格
触发（任一种）：
- 读到：安卓应用源码只调用三方 HTTP SDK 的方法、看不到路由；SDK 的 sources jar 或字节码里路由以 @GET / @POST 注解或常量给出；写错的样子：规格的端点表里有凭方法名或记忆推出的路径（和 SDK 路由注解不一致），或上下文压缩、分批续写之后端点表漏了条目
适用范围：目标平台没有等价库、要手写网络客户端，而三方 HTTP SDK 的源码包或字节码可以取得时，规格里的端点清单
做法：
- 在解包的 SDK 源码里 grep @GET( / @POST( 等路由注解和路由常量，机械生成端点表：方法名、HTTP 方法、路径、版本门控逐条照抄；没有源码时用 javap 看字节码
- 上下文压缩或分批续写之后，把手写进规格的每条端点逐条和路由文件重新对一遍
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 修复时用 javap 核对 SDK 字节码，改回路由注解里的路径：取不到源码时字节码同样能导出路由（出处：卡里修好并验证过）
针对本应用要查的：
- 每个 SDK 方法对应的 HTTP 方法和路径：三方 SDK 的 sources jar（或 aar/jar 里的 class）中的路由接口文件，按 @GET( / @POST( / @PUT( / @DELETE( 注解搜；注解参数就是相对路径，注解所在的方法名就是应用调用的 SDK 方法；各版本的路由接口各导一份
