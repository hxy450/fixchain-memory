# SDK 表单校验让两个参数互斥时，规格的参数表写明二选一和各版本发哪个

审的是：规格
触发（任一种）：
- 读到：SDK 请求数据类型里有表单校验或转换函数（如 toValidatedForm()）：新的游标参数显式给出时丢弃旧的页码参数，旧版本服务端只发页码；注释写某参数只为旧版本保留；写错的样子：规格的请求参数表把两个互斥参数都列为可选，只写「双轨」，没写二选一和按服务端版本发哪个
适用范围：要手写客户端替代三方 HTTP SDK 时，规格里各请求的参数表
做法：
- 把 SDK 请求类型的表单校验函数逐个读出写进参数表：哪些参数互斥、显式给出哪个时丢弃哪个、各服务端版本只发哪个
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 修好后按服务端版本只发游标参数或页码参数之一：两个参数同时上送是错的（出处：卡里修好并验证过）
针对本应用要查的：
- 每个请求的参数互斥和版本差异：三方 SDK 源码里请求数据类型所在的文件（datatypes 一类的包），看校验和转换函数以及字段注释；看函数里哪个字段有值时把另一个置空、各版本转换时丢弃哪个字段，照此写成参数表里的规则
来源：1 张卡，1 个应用
