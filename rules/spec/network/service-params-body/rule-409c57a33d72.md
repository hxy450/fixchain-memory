# 源端参数是 Long 的 id / userId，规格的 ArkTS 目标签名写 bigint，不照模板写 number

审的是：规格
触发（任一种）：
- 读到：源码方法参数 userId: Long、@Query("userId") userId: Long；写错的样子：规格「服务层（ArkTS 目标接口）」写成 (userId: number)，或照模板示例写 (feedItemId: number)
适用范围：规格提取时写服务层 ArkTS 目标签名、源端参数是 Long 的 id 或 userId
做法：
- 目标签名里这些参数写 bigint，或注明「64 位，禁用 number」
