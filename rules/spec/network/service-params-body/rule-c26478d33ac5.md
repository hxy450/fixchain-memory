# API 清单和端点目录为每个 POST 端点写明 Content-Type，不只列参数名

审的是：规格
触发（任一种）：
- 读到：Android Retrofit 接口里同时有 @FormUrlEncoded + @FieldMap 的重载和 @Body 的重载；写错的样子：API 清单或规格的接口一节只列方法、路径和参数名（如 POST /path 加参数 keyword），没有写请求编码或 Content-Type
适用范围：规格、源码理解笔记或 API 清单里列接口的那一节
做法：
- 每个端点记一项请求编码：@FieldMap / @Field 写「application/x-www-form-urlencoded（表单）」，@Body 写「application/json」，并注明依据的 Retrofit 重载
针对本应用要查的：
- 每个端点在 Android 端实际用的重载：源工程 Retrofit 接口的方法注解，和调用点传入的参数类型；带 @FormUrlEncoded 的记表单，带 @Body 的记 JSON
