# 规格写 token 刷新策略前先找源端刷新接口的调用方，不凭推断写「自动刷新」

审的是：规格
触发（任一种）：
- 读到：源端响应拦截器里没有刷新 token 的调用，刷新接口在别的页面或初始化方法里调用；写错的样子：规格写「401/某码 刷新」或「自动刷新」，没写源端刷新接口的调用方和发起时机
适用范围：规格提取阶段写 token 刷新策略时
做法：
- 写刷新策略前先找源端刷新接口的调用方：拦截器不做自动刷新的，规格里不写「自动刷新」，写明刷新由哪个页面或时机发起
针对本应用要查的：
- token 刷新接口的调用方：源工程里刷新接口方法的所有调用处（接口清单里端点的 callers，或全文搜该方法名）；记下调用它的类和方法、在什么时机调用、刷新后怎么更新 token
