# 「未提供测试 base_url / 测试账号」的适用范围

agent 会看到什么：读到决策台账写「未提供测试 base_url / 测试账号」并限定了作用域、另有「密钥构建期私有注入」；契约文档把它写成「配置缺失时网络返回明确失败」，当成装配空配置的依据
