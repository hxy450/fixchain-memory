# 「未提供测试环境/账号」只影响联调，不能写成装配空配置、请求一律失败的依据

审的是：规格
触发（任一种）：
- 读到：决策台账写「未提供测试 base_url / 测试账号」并限定作用域（不得外延为把请求失败当成功），另有「密钥不进源码、构建期私有注入」；写错的样子：契约文档写「仓库未保存测试 Base URL 或签名材料；配置缺失时网络返回明确失败」，把这两条当成装配空配置的依据
适用范围：写基础设施契约、引用决策台账里带作用域限定的条目时
做法：
- 契约里分开写：无测试环境/测试账号只影响联调和设备级 PASS；生产配置来源存在（源端 gradle / BuildConfig）仍须接线；带作用域限定的决策照原作用域引用，不外延为允许请求永久失败
