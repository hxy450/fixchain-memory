# 规格描述同步失败语义时核对队列选取条件，源端不按状态过滤就写明 fail 项下轮重推

审的是：规格
触发（任一种）：
- 读到：源端待推送队列的查询只按资源类型选取（只有 equal(…) 一个条件，再按 id 排序），不按同步状态过滤；失败只置 fail 不删除；写错的样子：规格或源码审计写「业务失败标记 fail 后继续」「永久置 FAIL、没有自动恢复」，没说下一轮会重选 fail 项
适用范围：源码审计和规格阶段，描述同步队列的失败与重试语义时
做法：
- 核对队列选取条件本身（按资源类型还是按同步状态），不只看置 fail 的分支；源端选取不过滤状态，就写明 fail 项在下一次同步自动重推、目标端选取同时取 pending 与 fail
