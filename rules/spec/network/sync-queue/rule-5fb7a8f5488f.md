# 源码的批次继续语义已确定时，规格照写，不改成「由实现决定」

审的是：规格
触发（任一种）：
- 读到：源端 chunked(N).forEach { 发送一批 } 忽略每批的失败结果，循环结束后返回成功；写错的样子：races 或验收条目写「后续批次是否继续由实现决定」
适用范围：规格提取阶段写批次或循环的继续 / 中断语义时
做法：
- 照源码原样写进验收条目或 races 条目：单批失败忽略、继续下一批、最后返回成功
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 每批独立 try / continue，结束后返回成功：修复后按源码恢复的语义（出处：卡里修好并验证过）
