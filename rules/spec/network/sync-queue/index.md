# 同步队列的选取条件和失败项

agent 会看到什么：读到待推送队列的查询只按资源类型 equal(…) 选取、不按同步状态过滤，失败只置 fail 不删除；规格或源码审计写「永久置 FAIL、没有自动恢复」

## 规矩

- rule-f6b6cff33c31｜规格描述同步失败语义时核对队列选取条件，源端不按状态过滤就写明 fail 项下轮重推｜读到：源端待推送队列的查询只按资源类型选取（只有 equal(…) 一个条件，再按 id 排序），不按同步状态过滤；失败只置 fail 不删除；写错：规格或源码审计写「业务失败标记 fail 后继续」「永久置 FAIL、没有自动恢复」，没说下一轮会重选 fail 项
- rule-5fb7a8f5488f｜源码的批次继续语义已确定时，规格照写，不改成「由实现决定」｜读到：源端 chunked(N).forEach { 发送一批 } 忽略每批的失败结果，循环结束后返回成功；写错：races 或验收条目写「后续批次是否继续由实现决定」
