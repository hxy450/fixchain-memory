# 同一源控件既有只构造的实例又有经绘制方法刷新的实例时，规格按层分别写可见状态

审的是：规格
触发（任一种）：
- 读到：源码为某一层逐个 new 自定义 View 并 addView，之后没有调用绘制方法或 setVisibility（或 setVisibility(View.INVISIBLE) 被注释掉）；另一层经绘制方法刷新，绘制方法在值为 0 时 setVisibility(View.INVISIBLE)；写错的样子：规格只写绘制方法的映射（「空块隐藏、非空块可见」），没写只构造的那一层保持构造态（可见、构造时设的背景和底色、空文本）
适用范围：规格里给同一个源控件的多个使用层（如底格层、活动层）写视图契约的那一项
做法：
- 按层分别写可见状态：只构造、从不调绘制方法的那一层写「保持构造态：VISIBLE + 构造时的背景、底色、圆角 + 空文本」，经绘制方法刷新的那一层再写绘制方法的映射
