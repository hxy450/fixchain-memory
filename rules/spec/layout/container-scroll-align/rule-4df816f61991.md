# 规格的转换决策写明滚动范围：哪些栏固定、NestedScrollView 只包哪些内容

审的是：规格
触发（任一种）：
- 读到：源布局里顶部用户栏或工具栏在 NestedScrollView 之前、带固定 marginTop，滚动容器只包下方内容；写错的样子：规格只写「NestedScrollView → Scroll + Column」的组件映射和「顶部 N vp 起始」，没写哪些栏固定不随滚动、Scroll 包含哪些子节点
适用范围：规格提取阶段为含滚动容器的页面写转换决策时
做法：
- 转换决策里写一句滚动范围，例如「顶部栏固定、距顶 <源端 marginTop>，不随滚动；NestedScrollView 只包含 A、B、C 三块」，不只写组件映射
针对本应用要查的：
- 固定区和滚动区的划分：源工程这个页面的布局 XML，按 NestedScrollView / ScrollView 的开、闭标签找；开标签之前的兄弟节点是固定区，标签之间的是滚动区；固定区的 marginTop 一并写进规格
