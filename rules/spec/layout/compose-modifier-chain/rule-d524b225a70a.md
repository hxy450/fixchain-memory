# M3 IconButton 外层写 .size(x) 且 x<48 时，规格按实绘 48 记并以圆心描述位置

审的是：规格
触发（任一种）：
- 读到：Compose 源码 IconButton(onClick = …, modifier = Modifier….size(x.dp)….background(…, CircleShape))，x < 48（如 36.dp）；写错的样子：转换决策表把修饰符字面当实绘尺寸，写成 .width(36).height(36) 或「size 36 圆底按钮」，位置按左上角（距左 16、距状态栏 10）描述，没标低置信
适用范围：规格提取时为 Material3 交互组件（IconButton、Button、Checkbox、Switch 等）定目标尺寸和位置的转换决策
做法：
- 转换决策表分两栏写「修饰符字面」和「实绘尺寸」：.size(x) 且 x < 48 时按 minimumInteractiveComponentSize 记实绘 48，位置写成圆心（源码左上角偏移 + x/2），不写左上角
- 定不下来时把这一行列为 low_confidence，写明待真机 dump 复核
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- M3 IconButton 外层 .size(36.dp) 时背景圆实绘 48dp，圆心不变：Android 截图量得 48dp；目标按 48、圆心不变改后与安卓一致（出处：卡里修好并验证过）
未核实：IconButton 内部套 minimumInteractiveComponentSize、最小 48dp 出自 Compose Material3 库代码，本机没有源码，按卡写
