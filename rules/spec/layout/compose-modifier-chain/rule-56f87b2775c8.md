# 规格描述 LazyRow/LazyColumn 时，把 contentPadding 写成「内容内距（滚动时不裁切）」

审的是：规格
触发（任一种）：
- 读到：Compose 的 LazyRow / LazyColumn 写了 contentPadding = PaddingValues(start = …, end = …)；写错的样子：规格只写「左右 padding」，没区分列表的内容内距和普通外框 padding
适用范围：规格提取阶段描述 Compose 滚动列表的留白时
做法：
- 写成「内容内距（contentPadding，滚动时不裁切）start/end 各多少」，和 Modifier.padding 的外框留白分开写
来源：1 张卡，1 个应用
