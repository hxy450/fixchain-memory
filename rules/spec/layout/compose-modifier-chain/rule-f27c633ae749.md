# 规格描述带背景的组件时，按修饰符顺序写明内距或 inset 在背景之内还是之外

审的是：规格
触发（任一种）：
- 读到：Compose 源码里 Modifier 链的 padding、statusBarsPadding 与 background、shape（或 Surface 包装）有先后顺序；写错的样子：规格把 padding、底色、圆角写成并列属性（「高 …dp，…padding：Surface 容器（…底色，…圆角）」「minHeight …、statusBarsPadding、…底」），没写内距在背景之内还是之外
适用范围：规格提取阶段描述 Compose 源端带背景或形状的组件时
做法：
- 按修饰符顺序写明：「padding / statusBarsPadding 在背景之外，背景只画在内距以内的区域」，或「在背景之内」；不把 padding、底色、圆角写成并列属性
