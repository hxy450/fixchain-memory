# 单视图四向锚 parent、兄弟只挂其下时，规格写单视图居中，容器选 RelativeContainer

审的是：规格
触发（任一种）：
- 读到：源布局 ConstraintLayout：一个子视图 start/end/top/bottom 四向锚定 parent，兄弟视图只有 constraintTop_toBottomOf 指向它，兄弟之间没有反向约束；写错的样子：规格把根布局概括成“N 个子元素的垂直居中链”，转换决策写 Column 整组居中、理由“无相对约束需求”；或跨栈映射基线写“ConstraintLayout（居中约束链）→ Column”
适用范围：规格提取阶段把 ConstraintLayout 约束翻译成 ArkUI 容器选择和子组件定位决策时
做法：
- 逐个子视图记下纵向锚点是 parent 还是兄弟视图；只有兄弟之间双向互相约束才算 chain
- 单视图四向锚 parent、兄弟只锚它底部时，写成“该视图在内容区自身居中，兄弟悬挂其下 N vp”，容器决策取 RelativeContainer + alignRules，不写 Column 整组居中
- 写完决策与同文件“页面结构”段对照，项目级映射基线表按同一规则复核；最小检查：Column 整组居中会让被居中视图中心上移 (间距 + 兄弟高度)/2，源中只有一个视图被居中时这个偏移应为 0
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- layout_constraintTop_toBottomOf 的 format 是 reference|enum，枚举只有 parent：取值是兄弟视图 id 时锚兄弟，是 parent 时锚父容器；据此区分单视图居中和链（出处：androidx.constraintlayout:constraintlayout 包内 res/values/values.xml，layout_constraintTop_toBottomOf（按应用依赖的版本））
- RelativeContainer 的标识默认为 __container__，子组件以它为锚点相对父容器定位：单视图对父容器居中的写法依据（出处：arkts-layout-development-relative-layout.md，设置锚点）
