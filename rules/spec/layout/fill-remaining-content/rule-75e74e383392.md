# 规格描述排在固定高度兄弟之后的内容区时，写「占其后的剩余高度」，不写「全屏」

审的是：规格
触发（任一种）：
- 读到：Compose Column 里内容区排在搜索栏、分隔线之后，用 fillMaxSize 或 LazyColumn 占满；写错的样子：规格把这个内容区（如无结果的居中提示）写成「全屏居中」「全屏 Column」
适用范围：规格提取阶段描述 Column 中排在固定高度节点之后的内容区高度时
做法：
- 写成「占搜索栏和分隔线之后的剩余高度」这类说法，写明它前面有哪些固定高度的兄弟
