# 规格给整除公式写用例和等价声明时，放非整数 vp 宽与对应 px 宽，两个域各算一遍

审的是：规格
触发（任一种）：
- 读到：Compose 自定义 Layout 里在 constraints.maxWidth 上做 Int 整除来分配槽宽；写错的样子：公式的用例只用整数宽（如 W=360、361）；或者写「W 不能被 n 整除时右侧留 W mod n vp 空白，Android 原样」这类等价性声明，没有按 px 和 vp 各算一遍
适用范围：规格里给源端整数几何公式写单元用例和「与 Android 一致」声明的地方
做法：
- 用例至少放一行非整数 vp 宽和它对应的 px 宽（如密度 3.5 时 377.14vp 对 1320px），逼出运算域问题
- 等价性声明按 px 与 vp 各算一遍再写：源端的余量是 W_px mod n 个 px，不是 vp；px 宽能整除时源端不留空白
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Area.width：目标元素的宽度，单位 vp：onAreaChange 给出的 vp 宽一般不是整数，用例要覆盖（出处：ts-types.md，Area）
- 1320px 宽按 5 份整除正好 264，不留余量；同一宽度在 vp 域是 377.14，floor 后每份少约 0.43vp、右侧留空：两个域算出来不同的例子（出处：卡里修好并验证过）
