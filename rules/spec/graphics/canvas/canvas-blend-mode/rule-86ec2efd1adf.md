# SDK 文档没说清混合基底范围时，规格把依赖画布状态的混合映射标为待真机核验，不定 HARD

审的是：规格
触发（任一种）：
- 读到：SDK 文档对 blendMode 只说「与其下方画布已有内容混合（possibly offscreen canvas）」，skill 参考里搜不到 blendMode 指引；写错的样子：规格把依赖画布状态的混合映射定为 HARD 统一决策，回退条件写「真机偏色则退回」，而本流程不编译、不上机，回退永远触发不了
适用范围：规格里依据措辞含糊的平台文档做渲染映射决策时
做法：
- 这类映射标为待真机核验项，写明核验方法（在哪个页面截图比对什么）；不定 HARD
- 已有不依赖画布状态的等价方案（如离屏组内 SRC_IN 蒙版）时，把它写成主方案，依赖画布状态的方案写成回退
