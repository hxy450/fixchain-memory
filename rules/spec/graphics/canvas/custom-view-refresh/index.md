# 自绘 View 的状态读取和重绘时机

agent 会看到什么：读到自定义 View 在构造、onSizeChanged、onDraw 里取文案或 firstRun 一类一次性状态，或把画面预渲染成位图缓存；规格写「每帧矢量，行为等价」，或没标哪些内容随配置重建刷新

## 规矩

- rule-a4d0a901f877｜源 View 在构造、onSizeChanged、绘制时取文案或一次性状态的，规格标「随配置重建刷新」｜读到：源 View 在构造函数、onSizeChanged、onDraw 里经 getResources().getString 取文案，或在构造时读 firstRun 一类一次性状态决定是否显示帮助；写错：规格没把这些文案和状态标成「随配置重建刷新」，目标映射里没写刷新入口，或者只写「尺寸变化时重算」
- rule-6d58330ef47d｜缓存改每帧绘制而称「行为等价」时，按源端顺序写出状态写者和元素出现消失的时机｜读到：源端缓存生成函数读的状态，在缓存生成后还有别的写者（如新开局流程里重置这个字段）；写错：源码笔记或差异表写「位图缓存策略 = 每帧矢量，行为等价」，等价核对只比元素集合、绘制顺序和颜色
