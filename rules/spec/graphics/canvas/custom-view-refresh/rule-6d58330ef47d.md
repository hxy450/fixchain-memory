# 缓存改每帧绘制而称「行为等价」时，按源端顺序写出状态写者和元素出现消失的时机

审的是：规格
触发（任一种）：
- 读到：源端缓存生成函数读的状态，在缓存生成后还有别的写者（如新开局流程里重置这个字段）；写错的样子：源码笔记或差异表写「位图缓存策略 = 每帧矢量，行为等价」，等价核对只比元素集合、绘制顺序和颜色
适用范围：源码理解笔记、差异表里论证缓存策略改写等价的那一项
做法：
- 列出这些状态在缓存生成后的全部写者，按源端顺序走一遍（首启 → 新游戏 → 重建视图），逐步写出元素何时出现、何时消失；目标端每一步结果相同才写「行为等价」
