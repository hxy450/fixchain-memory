# 源端尺寸带计数或密度分支时，规格写明所取分支、源函数和换算出的 vp 值

审的是：规格
触发（任一种）：
- 读到：源端角标 / 红点的尺寸函数按计数分支和 DisplayMetrics.density 分支返回不同的 dp 值；写错的样子：规格或规格补充只写一个 vp 数值（如「红点 N vp 直径」），没有源尺寸函数、所取的计数分支和密度分支、换算过程，或数值是参照入口大小估出来的
适用范围：规格里写小视觉元素（红点、角标、指示点）尺寸的条目
做法：
- 条目写成：源尺寸函数名、所取的计数分支和密度分支、该分支的半径或直径 dp 值、换算成的 vp 值，以及和承载入口尺寸的对照
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- DisplayMetrics.density：dp 的缩放系数，约 160dpi 屏上为 1：密度分支按它区分，dp 数值对应 vp 数值（出处：android.util.DisplayMetrics#density）
