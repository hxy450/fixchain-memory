# Paint→Canvas 映射行写明属性不能读回、font 的 px 是物理像素、drawImage 尺寸

审的是：规格
触发（任一种）：
- 读到：安卓源码用 Paint 的 setter/getter 管理绘制状态（setTextSize、getTextAlign），字号按 scaledDensity 算，用 drawBitmap + Matrix 画位图；写错的样子：规格的映射行只写“Paint 属性映射 Canvas 等价属性”，没写上下文属性不能当状态读回、font 串里 px 的含义、三参数 drawImage 的绘制尺寸
适用范围：规格里 Canvas+Paint → ArkUI CanvasRenderingContext2D 的实现映射行
做法：
- 映射行写明三点：CanvasRenderingContext2D 的 font、textAlign 等属性只写、读回是 undefined，状态要自己记录；font 字符串里的 px 是物理像素，sp 字号要先经 fp2px 换算；三参数 drawImage 按图片原始像素尺寸绘制，要用五参数显式给 dw/dh
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- font、textAlign 等上下文属性是只写属性，读取返回 undefined：映射行第一点的依据（出处：ts-canvasrenderingcontext2d.md，font）
- px 是屏幕物理像素单位：映射行第二点的依据（出处：ts-pixel-units.md，基本像素单位）
- 三参数 drawImage 按 PixelMap 原始像素尺寸绘制：映射行第三点的依据（出处：卡里修好并验证过）
