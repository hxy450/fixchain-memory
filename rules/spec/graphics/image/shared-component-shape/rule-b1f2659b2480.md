# 共享组件自带形状时，规格在每个使用位置写出形状、裁剪和填充，决策表不只写 Image 加容器 clip

审的是：规格
触发（任一种）：
- 读到：页面源码调用项目自定义组件（如自定义图片组件），形状和填充写在组件定义里；写错的样子：页面规格只写「100.dp 商品图片」这类尺寸，没写形状、裁剪和填充方式；`compose_sources` 没列组件定义文件
- 读到：源页面多处调用同一个共享 composable，它自己的定义里有 Surface(shape = CircleShape) 一类形状；写错的样子：规格只在其中一处（如结果行）写「圆形」，另一处的转换决策表写成「Stack（Image + 容器 .clip 裁切）」，没提子组件自己的形状
适用范围：规格提取时，页面规格里描述共享组件实例的各个使用位置和转换决策表
做法：
- 每个使用这个共享组件的位置都写出组件定义里的视觉契约：形状、裁剪、填充方式（如「圆形裁剪 + Crop 填充的共享图片组件」），不只写尺寸
- 转换决策表里父容器另有 .clip 的，写成 Image + 自身圆形裁切 + 容器 clip，不只写 Image + 容器 clip
- 把组件定义所在文件列进 compose_sources
