# 共享组件定义里自带的形状和裁剪

agent 会看到什么：页面源码调用项目自定义的共享 composable，形状和填充（Surface(shape = CircleShape)、ContentScale）写在组件定义里，规格只写尺寸、只在一处写形状，或决策表写成 Image 加容器 .clip

## 规矩

- rule-b1f2659b2480｜共享组件自带形状时，规格在每个使用位置写出形状、裁剪和填充，决策表不只写 Image 加容器 clip｜读到：页面源码调用项目自定义组件（如自定义图片组件），形状和填充写在组件定义里；写错：页面规格只写「100.dp 商品图片」这类尺寸，没写形状、裁剪和填充方式；`compose_sources` 没列组件定义文件
