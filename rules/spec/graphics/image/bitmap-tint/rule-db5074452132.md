# 规格写位图着色的转换决策时，注明资源格式，只给对它生效的 API 并写明前提

审的是：规格
触发（任一种）：
- 读到：源端 ColorFilter.tint(color) / tint / setColorFilter 作用在 drawable 位图上；上游页规格写「.fillColor / .colorFilter（染色矩阵或同色 SVG 资源）」；写错的样子：规格的转换决策或验收条目只写「ColorFilter.tint → Image .fillColor」，没写资源格式和「fillColor 仅 SVG」的前提，或把 fillColor / colorFilter 列成并列任选项
适用范围：规格提取和汇总阶段，为图片着色写转换决策和验收条目时
做法：
- 转换决策写成一行：「PNG 位图 → Image.colorFilter（drawing.ColorFilter.createBlendModeColorFilter(color, drawing.BlendMode.SRC_IN)）；fillColor 仅 SVG」，资源格式和前提在同一行
- 下游汇总或改写规格时保留这条前提；验收条目写 colorFilter 着色，不写 fillColor
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Image.fillColor 只对 SVG 图源生效；png 改色用 colorFilter：转换决策里的前提（出处：鸿蒙 SDK 的 ets/component/image.d.ts，ImageAttribute.fillColor；ts-basic-components-image.md，fillColor）
针对本应用要查的：
- 被着色的图源是什么格式：源工程 res/drawable* 目录里该资源的文件扩展名，和目标工程 resources/base/media 里对应资源的扩展名；png / jpg / webp 是位图，决策写 colorFilter；xml 矢量转成的 svg 才能写 fillColor
来源：1 张卡，1 个应用
