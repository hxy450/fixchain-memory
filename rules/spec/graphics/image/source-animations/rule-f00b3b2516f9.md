# 行为提取时列出窗口类里每个 Animator 的触发分支和时长，不把手势分支概括成上滑收起

审的是：规格
触发（任一种）：
- 读到：源窗口类 getView 里定义多组 Animator，各自 setDuration(...)；触摸回调里上滑超过阈值时 cancel() 主动画、只播另一个 Animator；写错的样子：行为笔记只记主时序「入场 … ms、停留 … ms、出场 … ms」，手势分支只写「上滑超过 …dp 收起」，没有它自己的时长
适用范围：Android 行为提取阶段，从全局横幅、浮层一类窗口类整理动画时序和手势分支时
做法：
- 逐个列出窗口类里的全部 Animator：各自的触发分支（自动播放、手势收起、取消）和 setDuration 的值，手势分支单独成行
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ValueAnimator 的 mDuration 默认 300（ms）；setDuration(long duration) 改写它：没调 setDuration 的 Animator 按 300ms 记（出处：android.animation.ValueAnimator#setDuration）
