# 应用侧 Configuration 常量引用库的动画资源时，映射行写出动画的时长和插值器

审的是：规格
触发（任一种）：
- 读到：应用侧 Style / Configuration 常量类里有 Configuration.Builder().setInAnimation(R.animator.…).setOutAnimation(R.animator.…)；写错的样子：映射行把常量类当作完整的样式锚点，只写配色和时长常量，没写进出动画资源的实际时长和插值器
适用范围：规格提取时，第三方 UI 库的样式由应用侧常量类配置、常量里引用了动画资源
做法：
- 顺着 setInAnimation / setOutAnimation 的 R.animator 引用找到 res/animator/ 下的 XML，把 android:duration（毫秒）和 android:interpolator 一并写进映射行
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Animator 的 duration：Amount of time (in milliseconds) for the animation to run：动画资源里的时长单位是毫秒（出处：Android SDK 平台资源 data/res/values/attrs.xml，Animator 的 duration（按应用的 compileSdk 取对应平台））
- Animator 的 interpolator：Defines the interpolator used to smooth the animation movement in time：插值器在同一个 XML 上，要和时长一起转写（出处：Android SDK 平台资源 data/res/values/attrs.xml，Animator 的 interpolator（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 进出动画的时长和插值器：源工程或依赖库 AAR 的 res/animator/ 下，setInAnimation / setOutAnimation 引用的那个 XML；读根元素上的 android:duration 和 android:interpolator；插值器是 @android:interpolator/… 时到平台资源里找同名文件
