# 规格的资源清单要覆盖容器背景和嵌套 ImageView 的 src，按元素写出对应

审的是：规格
触发（任一种）：
- 读到：源布局里一个元素由容器 android:background 位图加嵌套 ImageView 的 android:src 图标组成（如悬浮入口）；写错的样子：规格的元素→资源表只列了背景图，漏了嵌套 ImageView 的图标
适用范围：规格提取时列元素→资源对应表的那一节
做法：
- 资源闭包按元素逐个写全：容器背景 drawable 和其中每个嵌套 ImageView 的 src 都列出，写成「元素：背景 X + 图标 Y」
来源：1 张卡，1 个应用
