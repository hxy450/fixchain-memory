# 布局用 progressDrawable 等 @drawable 引用时，规格打开该文件写出高度、圆角、轨道色和渐变

审的是：规格
触发（任一种）：
- 读到：布局 XML 里 ProgressBar 写 android:progressDrawable="@drawable/…"，或控件 android:background 引用 @drawable/…；写错的样子：规格里这个进度条只写了边距和初值，没有高度、圆角、轨道色和进度色（渐变）
适用范围：规格提取时，布局里外观由 @drawable 引用决定的控件（进度条的 progressDrawable、background 等）
做法：
- 打开被引用的 drawable XML，把高度、圆角半径、轨道色（@android:id/background 项）和进度色或渐变（@android:id/progress 项）的数值写进规格
- 没见到被引用的资源文件就不成稿
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- progressDrawable 的 layer-list 里 android:id="@android:id/background" 是轨道，android:id="@android:id/progress" 是进度层（套在 clip 里）：轨道色和进度色分别从这两项读（出处：Android SDK 平台资源 data/res/drawable/progress_horizontal.xml，layer-list 的 @android:id/background 和 @android:id/progress 项（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 进度条的高度、圆角、轨道色和进度色：源工程 res/drawable 下 progressDrawable 引用的那个 XML；高度读 shape 的 <size android:height> 或 item 的 android:height；圆角读 <corners android:radius>；background 项读 <solid android:color> 或 <gradient>；progress 项读 <gradient android:startColor / endColor> 或 <solid>
