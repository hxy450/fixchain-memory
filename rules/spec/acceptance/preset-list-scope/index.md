# 对话框列出预置项时的列表范围和过滤条件

agent 会看到什么：读到源端对话框用 items(…) 列出全部预置项、参考规格写了空库时的反例；AC 里的列表范围、过滤条件和源码不一致，或漏了反例

## 规矩

- rule-e36eb7c7a46d｜AC 里列表范围和过滤条件照所引源码写，并带上参考文档的反例｜读到：源端对话框用 items(<全部预置项>) 列出全部，保存时 copy(id = 0) 插入；参考规格写「数据库为空且非首次建库→空白列表」；写错：AC 写成「只列当前数据库里没有的项」并标了源码出处，服务接口多出 missingDefaults() 一类过滤；或 AC 没写「非首次建库、数据库为空时保持空列表」
