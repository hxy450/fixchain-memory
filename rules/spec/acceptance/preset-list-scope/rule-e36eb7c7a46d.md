# AC 里列表范围和过滤条件照所引源码写，并带上参考文档的反例

审的是：规格
触发（任一种）：
- 读到：源端对话框用 items(<全部预置项>) 列出全部，保存时 copy(id = 0) 插入；参考规格写「数据库为空且非首次建库→空白列表」；写错的样子：AC 写成「只列当前数据库里没有的项」并标了源码出处，服务接口多出 missingDefaults() 一类过滤；或 AC 没写「非首次建库、数据库为空时保持空列表」
适用范围：规格提取阶段写列表、对话框的验收条目，条目标了源码出处时
做法：
- 列表范围和过滤条件照源码写：源码列出全部就写列出全部，不加「只列缺失项」
- 参考文档里的反例写进 AC，如「数据库为空且非首次建库时保持空列表」
针对本应用要查的：
- AC 所引的源码语义：AC 标的源码出处那一段（列表的 items(…) 数据源和保存时的插入写法）；读出列的是哪个集合、有没有过滤，照写进 AC
