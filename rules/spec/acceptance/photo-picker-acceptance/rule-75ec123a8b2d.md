# 选图验收只有构建、注册器和首屏证据时，不判 PASS，标为待真机验证

审的是：规格
触发（任一种）：
- 读到：规格里选图功能的验收条目要求「允许权限并选中图片后收到真实可读图片」「受限时不进伪成功」；写错的样子：验收报告凭静态锚点把选图功能判 PASS，真机检查只覆盖宿主首屏，选图链没有走过；插件也因此记为 verified
适用范围：带图片选择的功能，验收状态的判定
做法：
- 选图 AC 在没有真机走通前写成待真机验证，并列出要走的三条路径：选中后返回可读图片、取消、拒绝或受限时返回可处理结果
