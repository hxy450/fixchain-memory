# RDB 共享写入口的验收条目要求一次真实写入，只做 unit 判定时标明设备能力未验证

审的是：规格
触发（任一种）：
- 读到：计划要求用当前 API 支持的 @kit.ArkData RDB，插入与删除在事务完成后才返回、异常回滚；写错的样子：共享写入口的验收条目判定方式只写 unit（如「判:unit」）或签名比对，没有一次在真机或模拟器上的真实 RdbStore 写入，也没注明设备能力未验证
适用范围：数据层 RDB 共享写入口（各 DAO 都经它写库）的验收条目
做法：
- 验收条目写明至少一次在真机或模拟器上经共享写入口的真实 RdbStore 写入
- 只能用 unit 或签名比对判定时，条目里注明「设备能力未验证」
