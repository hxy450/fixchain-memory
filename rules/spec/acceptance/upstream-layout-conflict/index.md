# 上游说有而源布局里没有的组件

agent 会看到什么：派工职责或功能索引说某页有某组件（如常驻的底部栏），读到的源布局 XML 里却没有承载它的容器或 include；验收条目和它挂的真值锚

## 规矩

- rule-e95038a844a7｜上游说某页有某组件而源布局没有容器时，验收条目登记待决冲突，不改挂真值锚｜读到：派工职责或功能索引写某页有某组件（如「底部 MiniBar 常驻」），而读到的源布局 XML 里没有承载它的容器或 include；写错：验收条目仍写「该组件在此页常驻、各 Tab 均可见」，真值锚改挂到源布局里一个无关的节点（如 Tab 栏容器那一行）；待决项、待裁决清单里没有这条
