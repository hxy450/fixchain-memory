# 上游说某页有某组件而源布局没有容器时，验收条目登记待决冲突，不改挂真值锚

审的是：规格
触发（任一种）：
- 读到：派工职责或功能索引写某页有某组件（如「底部 MiniBar 常驻」），而读到的源布局 XML 里没有承载它的容器或 include；写错的样子：验收条目仍写「该组件在此页常驻、各 Tab 均可见」，真值锚改挂到源布局里一个无关的节点（如 Tab 栏容器那一行）；待决项、待裁决清单里没有这条
适用范围：写验收标准（AC）时，上游文档对某页组件的说法和源布局对不上的条目
做法：
- 这条 AC 不写成已定的要求，登记为待决冲突交给裁决：写明上游的说法，以及源布局里缺的容器或 include
- 真值锚只指向确实承载该组件的源行；源布局里没有的，不拿相邻或无关的节点当锚来保住这条 AC
