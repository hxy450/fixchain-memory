# 阈值类验收条目照抄源端比较符并给边界两侧样例，和同规格的同类条目对齐

审的是：规格
触发（任一种）：
- 读到：源码里的断点或阈值比较，如 width > N.dp；写错的样子：验收条目的边界和源端比较符相反（源端 > N.dp，条目却写「恰好 N 得宽布局」或要求 >=），或和同一规格里另一条同类条目说法不一
适用范围：规格提取阶段写断点、阈值类验收条目时
做法：
- 条目照抄源端比较符，并给出边界两侧样例：如 width > N.dp 写成「恰好 N 仍为窄布局，略大于 N 才是宽布局」
- 和同一规格内写同一阈值的条目对齐，说法冲突时以源码那一行为准改掉
