# 源码里的断点和阈值比较（width > N.dp）

agent 会看到什么：读到源码里的断点或阈值比较，如 width > N.dp；验收条目的边界和源端比较符相反（源端 >，条目写「恰好 N 得宽布局」或要求 >=），或和同一规格里另一条同类条目说法不一

## 规矩

- rule-df17b7ea94dd｜阈值类验收条目照抄源端比较符并给边界两侧样例，和同规格的同类条目对齐｜读到：源码里的断点或阈值比较，如 width > N.dp；写错：验收条目的边界和源端比较符相反（源端 > N.dp，条目却写「恰好 N 得宽布局」或要求 >=），或和同一规格里另一条同类条目说法不一
- rule-5ee4310ceb5f｜源端分支条件带比较符和边界时，规格转述保留比较符，判定列补边界另一侧的用例｜读到：源端按带比较符的条件选分支，如 `toLocalDate() >= today` 时用时间格式、否则用中等日期格式；写错：规格或验收条目把它转述成「当日 / 往日」这类二分短句，判定列只写「当日/往日分支正确」，没有落在边界另一侧（未来日期）的用例
