# 规格作者发现文档化意图与实际运行行为冲突时，不在 AC 写死争议分支，写成待决项

审的是：规格
触发（任一种）：
- 读到：参考规格或派工清单写的「文档化意图」与源码实际运行结果不一致（如一个分支写了但因竞态不生效）；写错的样子：AC 判据写死了有争议的分支，冲突只在回执摘要里作为「残留不确定项」出现，没写进 spec 和回执 JSON
适用范围：规格提取阶段，源端意图和实际行为不一致时
做法：
- AC 里不写死争议分支；把两种结果及各自的用户可见后果写成待决项，同时写进 spec 和回执 JSON，交 Gate 裁决
来源：1 张卡，1 个应用
- case-b3a0f2338f5f2dd14ef8（Countdate）：做法第 1 步 ← 建议 3
