# 规格描述新 UI 入口时，验收项写明关键视觉要素，不只写行为

审的是：规格
触发（任一种）：
- 读到：源布局里菜单行是 ImageView 加 TextView，分组标题用 drawableLeft 图标和专用颜色资源；写错的样子：差异清单或规格的验收项只写展开、请求、跳转等行为，没有图标加文字的结构、标题图标和颜色资源这些视觉要素
适用范围：规格提取阶段描述新的 UI 入口（菜单、分组标题、操作栏）时的验收条目
做法：
- 验收项写明关键视觉要素：如「菜单每行为图标加文字，行高、宽度按源端」「分组标题带图标，文字用源端颜色资源」「操作栏按钮为图标在上、文字在下」
