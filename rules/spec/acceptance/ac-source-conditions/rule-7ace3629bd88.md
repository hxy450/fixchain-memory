# 怪癖台账里已批准照源复刻的条目，规格要写成验收条目，不被一般约定覆盖

审的是：规格
触发（任一种）：
- 读到：参考设计的怪癖台账有条目（如「监听器为普通字段不入保存状态，旋转后托管对话框重显但按钮空操作」），决策台账批准照源复刻；写错的样子：规格的验收条目里没有这条；规格照经验或全局约定里的一般说法（如「托管对话框保留」）写了与该怪癖相反的契约
适用范围：参考设计带怪癖台账、决策台账批准照源复刻时，规格的生命周期契约和验收条目
做法：
- 把批准照源复刻的怪癖条目逐条写成 AC，写明触发操作和可见结果（如转屏后哪个按钮只关闭、列表是什么内容）
- 规格里的一般约定（如「托管保留」）与已批准的怪癖条目说法不同时，这一项按怪癖条目写
