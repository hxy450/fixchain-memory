# AC 要照抄的源端条件和已批准的怪癖

agent 会看到什么：读到源码锚点所在的函数有多重条件（启动方式、内存阈值、能力支持），或怪癖台账里有决策台账批准照源复刻的条目；规格的 AC、阈值表只写了单个条件，或照一般约定写了与怪癖相反的契约

## 规矩

- rule-7268b7cf40ca｜能力门组的 AC 要逐项抄全源函数里的条件，不只写内存阈值｜读到：源码锚点所在的能力门函数有多重条件（启动方式、内存阈值、预览是否支持连拍或曝光时间）；写错：规格的 AC 或阈值表对某个能力门只写了「≥512MB」这类单个内存条件，漏掉源函数里的其他条件
- rule-7ace3629bd88｜怪癖台账里已批准照源复刻的条目，规格要写成验收条目，不被一般约定覆盖｜读到：参考设计的怪癖台账有条目（如「监听器为普通字段不入保存状态，旋转后托管对话框重显但按钮空操作」），决策台账批准照源复刻；写错：规格的验收条目里没有这条；规格照经验或全局约定里的一般说法（如「托管对话框保留」）写了与该怪癖相反的契约
