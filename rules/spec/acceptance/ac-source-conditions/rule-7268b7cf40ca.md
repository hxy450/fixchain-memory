# 能力门组的 AC 要逐项抄全源函数里的条件，不只写内存阈值

审的是：规格
触发（任一种）：
- 读到：源码锚点所在的能力门函数有多重条件（启动方式、内存阈值、预览是否支持连拍或曝光时间）；写错的样子：规格的 AC 或阈值表对某个能力门只写了「≥512MB」这类单个内存条件，漏掉源函数里的其他条件
适用范围：规格提取阶段写能力门组的验收条目和阈值表时
做法：
- AC 里按源函数逐条列出这个能力门的每个条件，和源码锚点一起写；阈值表只列阈值时，另注明其余条件
