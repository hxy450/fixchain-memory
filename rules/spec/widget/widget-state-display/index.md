# 源码里控件的状态切换和展示加工

agent 会看到什么：读到源码里按状态改控件可点、图标、文字色的 setter，点击后成功回调才设选中态，展示文本先经工具函数加工成带链接的文本，标题行名称后带图标和跳转；规格或验收条目只写了文案、数值和颜色

## 规矩

- rule-9b653f30265e｜控件封装类按状态改禁用、图标和文字色时，规格把这些写成该状态的契约条目｜读到：源端控件封装类里有按状态切换的方法（如 setEnabled，或带状态名的 setter），里面解除点击、setImageResource 换图标、setTextColor 改文字色；写错：规格只把状态名列成某个跳转的参数，没有一条写该状态下哪个控件不可点、换成哪个图标、文字什么颜色；资源清单里也没有替换用的图标
- rule-70775ddacd7f｜源码在成功回调里才设选中态而规格要求乐观更新时，笔记或决策里写明采用哪种｜读到：安卓源里点击监听先调网络接口、成功回调里才设选中态；规格验收却写「点击后翻转且 UI 即时刷新（乐观更新）」；写错：源码笔记或决策记录里没有这处差异的条目，没写明采用乐观更新还是成功后才翻转、失败时回滚与否
- rule-e868421f4461｜UI 组件的验收项逐项覆盖源码对展示文本的加工，并把组件源文件写进 android_source_anchors｜读到：组件源码把展示文本先交给工具函数生成带 LinkAnnotation 的 AnnotatedString；设计文档写着「URL 提取…构建 AnnotatedString LinkAnnotation」；写错：功能规格的验收项只写空值隐藏、超过 N 行折叠、展开不限行，没有链接识别、着色和点击；`android_source_anchors` 里没有这个组件的源文件
- rule-4a075cfc0793｜图例或标题行的验收要比照源端同类条目的完整呈现：名称、后缀图标、点击跳转｜读到：源端同类条目在图例或标题行里名称后带图标（如问号说明入口），点击跳转说明页；写错：验收条目或核对记录只核对数值和颜色，没有名称后缀图标和点击跳转这两项
