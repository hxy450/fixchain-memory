# 控件封装类按状态改禁用、图标和文字色时，规格把这些写成该状态的契约条目

审的是：规格
触发（任一种）：
- 读到：源端控件封装类里有按状态切换的方法（如 setEnabled，或带状态名的 setter），里面解除点击、setImageResource 换图标、setTextColor 改文字色；写错的样子：规格只把状态名列成某个跳转的参数，没有一条写该状态下哪个控件不可点、换成哪个图标、文字什么颜色；资源清单里也没有替换用的图标
适用范围：规格提取阶段读安卓控件封装类，类里有随状态变化的禁用和外观切换
做法：
- 规格的组件条目为每个状态写一项：状态从哪个入参来；该状态下哪些控件解除点击或禁用；图标换成哪个资源；文字颜色取哪个值。资源清单列上替换用的图标
针对本应用要查的：
- 每个状态下的禁用范围、替换图标和文字颜色：源工程里控件封装类的状态方法（setEnabled、带状态名的 setter）及其调用处；读出方法里对点击监听、setImageResource 的资源名、setTextColor 的颜色值的改动，逐项抄进规格
