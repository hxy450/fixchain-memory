# 源码在成功回调里才设选中态而规格要求乐观更新时，笔记或决策里写明采用哪种

审的是：规格
触发（任一种）：
- 读到：安卓源里点击监听先调网络接口、成功回调里才设选中态；规格验收却写「点击后翻转且 UI 即时刷新（乐观更新）」；写错的样子：源码笔记或决策记录里没有这处差异的条目，没写明采用乐观更新还是成功后才翻转、失败时回滚与否
适用范围：收藏、点赞这类切换按钮，源码的状态设置时机和规格验收不一致时的源码笔记和决策记录
做法：
- 在决策记录或源码笔记里加一条：源端在成功回调里设选中态，规格要求点击即翻转；写明采用哪一种，以及接口失败时回滚与否
