# UI 组件的验收项逐项覆盖源码对展示文本的加工，并把组件源文件写进 android_source_anchors

审的是：规格
触发（任一种）：
- 读到：组件源码把展示文本先交给工具函数生成带 LinkAnnotation 的 AnnotatedString；设计文档写着「URL 提取…构建 AnnotatedString LinkAnnotation」；写错的样子：功能规格的验收项只写空值隐藏、超过 N 行折叠、展开不限行，没有链接识别、着色和点击；`android_source_anchors` 里没有这个组件的源文件
适用范围：规格提取阶段给 UI 组件写验收项和源码锚点时
做法：
- 验收项逐项覆盖组件源码对展示文本的加工：链接识别范围、链接样式、点击行为各写一条
- 把这个组件的源文件和它调用的工具类同步写进该功能的 android_source_anchors
来源：1 张卡，1 个应用
