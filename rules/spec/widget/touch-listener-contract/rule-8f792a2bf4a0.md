# 源码有显式触摸状态机时，规格写成行为 AC，不以平台内建为由登记无需迁移

审的是：规格
触发（任一种）：
- 读到：源 `onTouch` / `onInterceptTouchEvent` 里 `MotionEvent.ACTION_DOWN` 记坐标置按下、`ACTION_MOVE` 位移超过阈值取消、`ACTION_UP` 仍按下才 click；写错的样子：规格写「ArkUI 原生点击/滑动天然分离，无需自判阈值」，转换决策表把这段触摸拦截登记为「无需迁移」，和同一规格里保留阈值的 AC 矛盾
适用范围：规格提取阶段，把源码里显式的 MotionEvent 处理（阈值、按压时序、拖动后取消）翻译成目标交互契约时
不适用的情形：已核实目标事件模型确有同样语义（如 Swiper 开始拖动后子节点 onClick 不再触发）时，可以登记无需迁移
做法：
- 把状态机落成行为 AC：写出阈值和单位、DOWN / MOVE / UP 各自的判定、拖动开始后取消点击；转换决策表里对应的行和 AC 一致，不写「无需迁移」
