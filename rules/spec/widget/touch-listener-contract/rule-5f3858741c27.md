# 预览表面有手势入口或跨 feature 读面时，规格对接点段要把它们列出来

审的是：规格
触发（任一种）：
- 读到：源端预览 View 的 onTouchEvent 直接转给别的类，再经 GestureDetector / ScaleGestureDetector 分派；别的组件调用源类的公开读方法；写错的样子：规格「对接点」段只列按钮、滑条回调，没列预览表面的手势入口和被其他 feature 读的读面；验收里有「源:…touchEvent → 标:…touchEvent」式入口，对接点里却没有对应项
适用范围：写带预览表面（或其他自带触摸入口的 View）、又有跨 feature 读面的功能规格时
做法：
- 对接点段除按钮回调外再列两类：预览表面的手势入口（源 View.onTouchEvent → 目标 XComponent 的 .onTouch / .parallelGesture(PinchGesture) → 分派器 → 各处理函数），以及被其他 feature 读的读面（源端外部调用点 ↔ 目标公开方法）
- 验收里每个「标:」入口都在对接点里有一项，收口时按这些入口核对 UI 调用方，不只按对接点计数
来源：1 张卡，1 个应用
