# 规格把 InputFilter.AllCaps 写成「无直接等价、放到校验时大写化」时，改写成输入时拦截

审的是：规格
触发（任一种）：
- 读到：源码里 EditText 挂 InputFilter.AllCaps；写错的样子：规格的转换决策写「ArkUI 无直接等价，校验/大写化放 ViewModel」，把输入时的过滤降级成保存或校验时
适用范围：规格提取时映射源端输入过滤（InputFilter）
做法：
- 转换决策写成「输入时拦截：RichEditor 的 aboutToIMEInput 里转大写后自行插入并 return false，粘贴同样处理」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- aboutToIMEInput(callback: Callback<RichEditorInsertValue, boolean>): RichEditorAttribute：输入前拦截的接口（出处：鸿蒙 SDK 的 ets/component/rich_editor.d.ts，RichEditorAttribute.aboutToIMEInput）
