# 规格给每个迁移控件列一行「源端未显式设置、由框架默认决定的行为」及目标显式设置

审的是：规格
触发（任一种）：
- 读到：源端控件只写了少数属性，其余靠框架默认：WebView 只 loadUrl 不调 getSettings，单行 EditText 不写 imeOptions，setError 只调一次；写错的样子：规格转换决策只写组件对应（如「Web 组件加载 $rawfile」），没有「源端默认行为 vs 目标默认」一行，也没写目标要显式设置的属性
适用范围：规格提取阶段给 EditText、WebView、弹窗等控件写转换决策时
做法：
- 每个迁移控件加一行「源端未显式设置、由框架默认决定的行为」：单行 IME Next 链、setError 呈现、弹窗初始焦点、WebView 的 JS / 缩放 / viewport / 文字自动放大；对照目标组件默认值，不同的写出显式设置（showPasswordIcon(false)、enterKeyType(EnterKeyType.Next)、defaultFocus、javaScriptAccess(false) 等）
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ArkWeb 的 javaScriptAccess、zoomAccess、overviewModeAccess、metaViewport、textAutosizing 默认都是 true：与源端 WebSettings 默认相反（出处：鸿蒙 SDK 的 ets/component/web.d.ts，WebAttribute.javaScriptAccess 等）
- TextInput 的 showPasswordIcon 默认 true，enterKeyType 默认 EnterKeyType.Done：与源端普通密码框、单行框默认不同（出处：鸿蒙 SDK 的 ets/component/text_input.d.ts，TextInputAttribute.showPasswordIcon / TextInputAttribute.enterKeyType）
