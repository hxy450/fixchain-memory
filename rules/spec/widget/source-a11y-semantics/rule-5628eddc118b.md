# 规格把源组件的语义属性写进组件验收条目：role、enabled、合并或独立按钮、对话框模态

审的是：规格
触发（任一种）：
- 读到：源端组件 Modifier.clickable(role = Role.Button, enabled = …)、整卡合并的点击区、独立 IconButton、Dialog 独立窗口；写错的样子：组件验收条目只写结构、样式与回调，没写按钮角色、enabled 条件、合并朗读与独立按钮、对话框模态
适用范围：规格提取阶段给可点击组件和对话框写验收条目时
做法：
- 验收条目逐项写语义属性：角色（按钮）、enabled 条件、整卡合并朗读与卡内独立按钮、对话框是否为独立窗口的模态
来源：1 张卡，1 个应用
