# 派生状态要喂给 accessibilityText 这类分开声明重载的属性时，规格里状态类型只写 string

审的是：规格
触发（任一种）：
- 读到：源端 android:contentDescription="@string/…" 初值取字符串资源，代码里 contentDescription = … 改成运行时拼出的字符串；写错的样子：状态接口表把喂给 .accessibilityText() 的派生状态（@Computed）类型写成 string | Resource，转换决策没写资源串怎么取成字符串
适用范围：规格提取阶段为 ArkUI 属性方法定义派生状态、源端同一个文本属性既有资源串又有普通字符串时
做法：
- 先查目标属性方法在当前 SDK 声明里的重载；string 与 Resource 分开声明（如 accessibilityText(value: string) 和 accessibilityText(text: Resource)）时，状态接口只写其中一种，统一为 string
- 转换决策写明取值方式：资源串在运行时用 getUIContext().getHostContext() 的 resourceManager.getStringSync($r('app.string.…').id) 取成 string
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- accessibilityText(value: string): T；accessibilityText(text: Resource): T：两个重载分开声明，没有接受 string | Resource 的重载（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.accessibilityText）
- accessibilityDescription(value: string): T；accessibilityDescription(description: Resource): T：同族接口：无障碍描述同样分开声明（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.accessibilityDescription）
- getStringSync(resId: number): string：按资源 id 同步取字符串，传 $r(...).id（出处：鸿蒙 SDK 的 ets/api/@ohos.resourceManager.d.ts，ResourceManager.getStringSync）
