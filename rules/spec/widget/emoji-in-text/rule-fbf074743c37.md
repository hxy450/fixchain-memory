# 源界面 Text 里的 emoji 是字面文本，规格写原样保留为 Text，不按 SymbolGlyph 规则替换

审的是：规格
触发（任一种）：
- 读到：源端 ListItem 的 leadingContent 等处写 Text("⭐") 这类 emoji 字面文本；上下文里另有「图标用 SymbolGlyph、不把 emoji 塞进 Text」的规则；写错的样子：规格写「emoji 替换为已验证 symbol」，转换决策表写 emoji → SymbolGlyph
适用范围：规格提取阶段处理源界面里的 emoji 文本时
做法：
- 规格区分源矢量图标映射和源界面字面文本：Text 里的 emoji 写成「Text('<原 emoji>') 原样保留」；SymbolGlyph 规则只用于图标资源映射，两者冲突时在规格里记录，不替换
