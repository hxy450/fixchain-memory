# Compose Text 没传 color 时，规格写出宿主提供的 contentColor

审的是：规格
触发（任一种）：
- 读到：Compose `Text(...)` 只给 `style`、没传 `color`，颜色取 `LocalContentColor`；写错的样子：规格写「文本颜色走默认 onSurface 色（未显式指定色 token）」这类结论，没有写宿主提供的 contentColor，也没标待核
适用范围：规格提取阶段，写 Compose 界面里没显式设色的文本颜色时
做法：
- 沿调用链找最近的 `Surface`、`Scaffold`（含应用自己包装的这两类）或 `CompositionLocalProvider(LocalContentColor provides …)`，读出它提供的 contentColor，把解析到的主题颜色写进规格
- 没核到宿主时把这一项标成待核，不写「默认 onSurface」
针对本应用要查的：
- 无色文本实际拿到的 contentColor：源工程 Kotlin 文件里这个页面外层的 Surface/Scaffold 调用，以及应用包装的 Scaffold、Surface 函数的参数默认值 contentColor = …；页面传了 contentColor 就取传入值，没传取包装函数参数的默认值，再解析到主题颜色名（例：包装 Scaffold 的 contentColor 默认取主题的次要文字色）
