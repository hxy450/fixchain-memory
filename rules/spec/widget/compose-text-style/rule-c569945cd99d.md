# 规格描述排版令牌时，写明 lineHeightStyle 和单行文本高度等于字体自然高度

审的是：规格
触发（任一种）：
- 读到：Compose `TextStyle` 带 `lineHeight`、没设 `lineHeightStyle`；写错的样子：规格里排版令牌只列字号和行高数值（或只写样式名），没写源端 lineHeightStyle（未设即默认裁剪），也没写单行文本高度等于字体自然高度
适用范围：规格提取阶段描述 Compose 排版令牌时
做法：
- 每个排版令牌除字号、行高外写一句：「lineHeightStyle：未设置（默认裁剪）；单行文本高度 = 字体自然高度，多行行距 = lineHeight − fontSize」
