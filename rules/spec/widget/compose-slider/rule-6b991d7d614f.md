# Compose Slider 的 steps 在规格和验收条目里写成完整取值列表，取值数为 steps + 2

审的是：规格
触发（任一种）：
- 读到：源端 material3 Slider(valueRange = a..b, steps = N)；写错的样子：规格或验收条目写「steps=N（N+1 个离散停靠点）」，映射写 step = (b - a) / N，没有列出完整取值
适用范围：规格提取阶段把 Compose Slider 的离散刻度写进映射和验收条目时
做法：
- 按 steps 是两端之间的离散值个数换算：取值数 = steps + 2，步长 = (max - min) / (steps + 1)；映射写 Slider({ min, max, step: (max - min) / (steps + 1) })
- 把完整取值列表（从 min 起每隔一个步长到 max）写进映射和验收条目，不只写「N 个停靠点」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- SliderOptions.step?: number，@default 1，取值范围 [0.01, max - min]：目标端是步长，要由 steps 换算（出处：鸿蒙 SDK 的 ets/component/slider.d.ts，SliderOptions.step）
- 步长改回 (max - min) / (steps + 1) 后，源端和目标端刻度数一致（源端实测为 steps + 2 个刻度）：换算公式已上机核对（出处：卡里修好并验证过）
针对本应用要查的：
- Slider 的 steps 和 valueRange：源工程 Compose 文件里 Slider(valueRange = …, steps = …) 的实参；代入取值数 = steps + 2、步长 = (max - min) / (steps + 1)，列出全部取值
