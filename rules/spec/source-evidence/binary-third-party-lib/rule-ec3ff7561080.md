# 源端功能由二进制三方库决定、库实现取不到时，规格把库行为标为待核，不写成确定契约

审的是：规格
触发（任一种）：
- 读到：源端调用二进制三方库完成导出导入（如 RoomDBExportImport(...).export(ctx, uri) / import(ctx, uri, true)），库源码和 AAR 本地查不到；写错的样子：规格把库内部行为（归档条目名、参数语义、调用后的链路）写成精确常量、AC 真值或跨端工件契约，没有登记待核或阻塞
适用范围：规格提取阶段，转写源端经二进制三方库实现的文件格式、参数语义和调用后行为时
做法：
- 先取得库实现（构建缓存里的 AAR/jar 反编译、源码包或官方仓库）再写归档格式、参数含义与调用后副作用
- 取不到时把这些项标为待核或阻塞，不写成精确常量、AC 真值或跨端工件契约
针对本应用要查的：
- 库的坐标、版本和实现：源工程构建脚本 dependencies 里的 group:artifact:version；Gradle 用户缓存 caches/modules-2/files-2.1/<group>/<artifact>/<version>/ 下的 aar、jar 或 sources jar；没有时到库的官方仓库同版本 tag；反编译或读源码，找出归档里写入的条目名、各参数的名字和分支行为，再写进规格
