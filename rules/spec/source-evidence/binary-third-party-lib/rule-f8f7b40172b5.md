# 三方手势控件在仓库里没源码时，规格去 AAR 核对交互或登记缩放双击缺口

审的是：规格
触发（任一种）：
- 读到：源布局用三方库的缩放图片或画廊控件（如 `TouchImageView`、自定义 `ViewPager`），仓库里找不到它的源码；写错的样子：规格写「三方库无源码 → Swiper + Image 自渲染」，没写缩放、双击行为，也没登记行为缺口
适用范围：规格提取阶段遇到依赖库提供的交互控件时
做法：
- 到 Gradle 缓存或 AAR 里取出 classes，用 javap 或反编译核对它的缩放、双击、拦截行为，写进规格的交互 AC
- 核对不了时在规格里登记「缩放/双击行为缺口」，不静默降级成 Swiper + Image
针对本应用要查的：
- 三方控件的交互行为：Gradle 缓存 modules-2/files-2.1/<group>/<artifact>/<version>/ 下的 aar 或 jar（按应用依赖的版本）；解出 classes.jar，用 javap -c -p 看 onTouchEvent、onScale、onDoubleTap 等方法里的阈值和分支
