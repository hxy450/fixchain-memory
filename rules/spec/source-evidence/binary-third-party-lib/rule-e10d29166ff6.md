# 源调用只给二进制三方库组件部分参数时，规格写库缺省的实值，不标「待核自由度」

审的是：规格
触发（任一种）：
- 读到：源码调用三方库组件（Kotlin 类构造带缺省参数）只显式传了几个参数，其余外观与运动参数没传；仓库里没有库源码；写错的样子：规格映射行或验收写「库内部默认参数源码未出现——待核自由度，不写成判据（未在本机核对）」，没有缺省颜色、形状、尺寸、寿命等实值
适用范围：规格提取阶段为 AAR / jar 承载的三方库组件写缺省参数契约时
做法：
- 按构建脚本和版本目录里的依赖坐标，在 Gradle 缓存 modules-2/files-2.1/<group>/<artifact>/<version>/ 下找 jar 或 aar，解包后用 javap -p -c -constants 读构造器缺省分支与 companion 常量
- 把缺省颜色、形状、尺寸、寿命等实值连同类名、库版本写进规格映射行和验收；确实取不到制品时才登记阻塞缺口，不写「不构成判据」的自由度
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 只有编译后的 jar、没有 sources jar 也能读：javap -p -c -constants 反汇编出缺省值和常量；本机没装 JDK 时用 Android Studio 自带 jbr/bin/javap：「库源不可查」不成立（出处：卡里修好并验证过）
针对本应用要查的：
- 三方库的坐标和版本：源工程的 Gradle 构建脚本 dependencies 和版本目录（libs.versions.toml），以及源文件的 import 包名；读出 group:artifact:version，到 Gradle 缓存的 modules-2/files-2.1/<group>/<artifact>/<version>/ 下取对应 jar 或 aar
