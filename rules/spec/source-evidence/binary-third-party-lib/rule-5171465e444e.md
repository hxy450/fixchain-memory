# 三方 UI 库布局不在仓库时，规格记依赖坐标并盘点 aar 里的 layout-land 等变体

审的是：规格
触发（任一种）：
- 读到：源工程依赖三方 UI 库（选择器、弹窗等），它的布局不在仓库源码里，只在 aar 资源中；写错的样子：规格没记这个库的依赖坐标，也没盘点它的 layout-land、layout-w<N>dp、values-h<N>dp 等变体；以「源码不在本仓库」当作没有横屏分支的依据
适用范围：规格提取阶段，涉及三方 UI 库界面的页面
做法：
- 在 spec 记录依赖坐标（group:artifact:version），从 aar 或反编译资源盘点 layout-land / values-h<N>dp / layout-w<N>dp，再逐个决定随迁或显式登记不迁移
针对本应用要查的：
- 三方库有哪些布局限定符变体：源工程模块 Gradle 构建脚本的 dependencies 里取坐标和版本；Gradle 缓存 transforms 下 transformed/<库名>-<版本>/res/ 里的 layout-*、values-* 目录（缓存了几个版本时按应用依赖的版本取）；列出带 land、w<N>dp、h<N>dp、sw<N>dp 的目录和其中的文件，与 base 目录的同名文件对照，记入 spec
