# 实体继承二进制依赖里的基类时，规格逐项写基类契约，查不到的标「未知」

审的是：规格
触发（任一种）：
- 读到：源实体 `class X extends` 一个来自 Maven/JitPack 二进制依赖的基类，主工程里没有基类源码；写错的样子：规格字段表和序列化契约只写「主仓无源码」，基类的字段类型、无参构造缺省值、equals/isChanged/toString、JSON 键序与类型既没有给出契约，也没有标「未知」，后面靠可见的子类代码推断
适用范围：规格提取阶段，为继承外部库基类的实体写字段表与序列化契约时
做法：
- 先取得该库再写：从 Gradle 缓存（或 Maven/JitPack 下载、公开源码）拿到对应版本的 jar，用 `javap -c -p` 或源码核对基类的字段类型、无参构造缺省值、equals/toString、JSON 序列化
- 取不到时在规格里对这些项逐项写「未知」，不写成只有「主仓无源码」一句
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 返修时用 javap 读基类字节码，才查实 Double 语义、Gson 键序、Boolean 写法、equals/isChanged/toString：这些契约从子类源码里看不出来，要读基类本身（出处：卡里修好并验证过）
针对本应用要查的：
- 基类所在库的坐标和版本，以及它的 jar：源工程 Gradle 构建脚本 dependencies 里的坐标；Gradle 缓存 modules-2/files-2.1 下按 group/artifact/version 找 jar；解开 jar，对基类跑 `javap -c -p`，读字段声明、构造器里的赋值、equals/hashCode/toString 的实现
未核实：规格阶段那份 jar 是否已经在本机 Gradle 缓存里、能否离线取到
