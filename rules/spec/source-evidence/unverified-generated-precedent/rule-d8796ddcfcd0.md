# 源码理解笔记不把未运行验证的生成代码写成「已验」先例

审的是：规格
触发（任一种）：
- 读到：要照着写的兄弟实现是同一次迁移里生成的代码，没有运行验证的记录；写错的样子：源码理解笔记或注释把这套写法称作「已验」的形态或先例，后来的写者据此照抄
适用范围：源码理解笔记、注释里引用同工程已有实现作先例的地方
做法：
- 没有运行验证过的生成代码，笔记里写明「未运行验证」，不写「已验」；要引先例时引按契约实现的同模式入口，并写出对照过的项（标志在哪里置位、在哪里清除）
