# RecyclerView 页面的规格要把全部 item 布局登记进必读的布局清单

审的是：规格
触发（任一种）：
- 读到：源页面主体是 RecyclerView，Adapter 用 addItemType / onCreateViewHolder 引用多个 item 布局；写错的样子：meta.json 的 recycler_item_layouts 为空，layout_sources 里没有 item 布局，页面规格只列 Adapter 源码锚点
适用范围：规格提取阶段处理以 RecyclerView 承载主体内容的页面时
做法：
- 在 meta.json 的 recycler_item_layouts 和 layout_sources 里登记 Adapter 引用的全部 item 布局，让转换者的必读清单覆盖实际可见区块
针对本应用要查的：
- Adapter 引用的全部 item 布局：源工程 Adapter 类里 addItemType(类型, R.layout.…) 或 onCreateViewHolder 里 inflate 的布局资源；每个类型对应的布局名都列进清单
