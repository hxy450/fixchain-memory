# 合成 meta.json 时 DataBinding 点击要计入 clickable_elements，不写空数组

审的是：规格
触发（任一种）：
- 读到：源布局用 DataBinding 点击 android:onClick="@{page::方法}"，跳转写在 Fragment 代码里；写错的样子：合成的 meta.json 里 clickable_elements 是 []、节点 clickable=false、navigation_targets 为 {}，也没标「未知」
适用范围：规格提取阶段用脚本从布局合成 meta.json 和 view.xml 快照时
做法：
- DataBinding 的点击绑定（android:onClick="@{…::方法}"）计入 clickable_elements，记下节点和绑定的方法名
- 解析不出时写成未知并注明原因，不写空数组
