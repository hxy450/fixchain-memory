# 快照自述无真机 dump 时，「近乎不可见、parity 保留」类结论降级为待真机核对项

审的是：规格
触发（任一种）：
- 读到：基线快照 meta.json 标注 `view_xml_synthesized`、bounds 为空、无真机 UIAutomator dump；写错的样子：规格或决策台账写「浅色近乎不可见」「parity 保留」「忠实复刻」，把它当已知缺陷要求实现者原样画出
适用范围：没有真机 dump、页面结构由源码合成时，规格和决策台账里关于元素可见性的结论
做法：
- 这类结论在规格里改成「待真机核对」项，写明依据只是源码颜色推导、缺真机 dump；不写进 D0 或决策台账当已知缺陷
