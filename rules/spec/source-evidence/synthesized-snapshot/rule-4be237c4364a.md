# ui-snapshot 是合成的时，带具体 dp 的视觉验收条目标 confidence=medium

审的是：规格
触发（任一种）：
- 读到：没有真机 UIAutomator dump，ui-snapshot 由源码合成、bounds 为空（meta 标 confidence medium）；写错的样子：功能规格里「判:visual」的验收条目直接把源码字面 dp 写成判据（如「36×36 圆形、距状态栏 10vp、距左 16vp」），没带 confidence=medium
适用范围：规格提取时，源端只有合成快照、写功能规格视觉验收条目的情形
做法：
- 凡是「判:visual」且带具体 dp 的验收条目加 confidence=medium 标记，并写明 verify 阶段用真机 dump 或截图量出的值取代源码字面
来源：1 张卡，1 个应用
- case-6eec56e15cefd5c659cb（Jetsnack）：做法第 1 步 ← 建议 2
