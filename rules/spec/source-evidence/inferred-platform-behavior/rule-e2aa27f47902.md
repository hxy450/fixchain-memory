# 规格里标「[推断]」写入的平台行为，附核对来源，没有就列为待核

审的是：规格
触发（任一种）：
- 写错的样子：规格条目标「[推断：框架…标准行为]」，没写核对来源（框架源码的类和方法，或平台资源文件和资源名），也没列为待核
适用范围：规格提取阶段写入推断出的平台行为时
做法：
- 每条推断附核对来源（如 android.widget.ActionMenuPresenter#flagActionItems、平台 data/res/values/styles_material.xml 的样式名）；查不到就列进待核清单
