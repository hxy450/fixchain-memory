# 源码理解笔记里写了没读到定义的辅助谓词含义时，改为读定义，读不到就按规格转移表写

审的是：规格
触发（任一种）：
- 读到：读到的源码片段只有辅助谓词（如「是否在播放态」）的调用，没有它的定义；写错的样子：源码理解笔记写「谓词 = state == PLAYING || PAUSED」这类凭名称推断的谓词定义，没标未读到定义
适用范围：写源码理解笔记、翻译源端以辅助谓词分派分支的方法时
做法：
- 先读到谓词定义再写它的含义；读不到定义就在笔记里标「未读到定义」，分支语义以规格转移表和验收用例为准，不凭名称推断它覆盖 PAUSED
针对本应用要查的：
- 辅助谓词的真实定义：源工程里调用它的类及其父类（Java / Kotlin 源文件）中同名方法的定义；读出它判断的状态集合，写进笔记；找不到时以规格转移表为准
