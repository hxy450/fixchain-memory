# 为常量取值域补 AC 时，逐个写出每个取值的源端调用方和目标承接位置

审的是：规格
触发（任一种）：
- 读到：源端有一组来源常量（如几种检测触发来源），分别由不同调用点传入同一个业务方法；写错的样子：AC 只写“N 种触发场景分别传对应值上送”这类取值域，没写每个取值由谁在什么条件下传入；某个取值没有承接方也没有迁移或裁剪决定
适用范围：规格里为常量取值域写验收条目、补 lint 报的未覆盖常量时
做法：
- 逐个列出每个取值的源端调用方（文件和触发条件）和目标承接位置（服务方法或监听）
- 某个取值在目标端没有承接方时，写明迁移或裁剪决定，不只列取值
针对本应用要查的：
- 每个常量取值的调用点：源工程里对该常量的全仓引用；每个引用处记下所在类、所在回调和调用条件
