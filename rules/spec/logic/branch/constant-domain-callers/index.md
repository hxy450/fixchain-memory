# 由不同调用点传入的一组来源常量

agent 会看到什么：读到源端一组来源常量（如几种检测触发来源）分别由不同调用点传入同一个业务方法；AC 只写「N 种场景分别传对应值」，没写每个取值由谁在什么条件下传入

## 规矩

- rule-ad3e46352805｜为常量取值域补 AC 时，逐个写出每个取值的源端调用方和目标承接位置｜读到：源端有一组来源常量（如几种检测触发来源），分别由不同调用点传入同一个业务方法；写错：AC 只写“N 种触发场景分别传对应值上送”这类取值域，没写每个取值由谁在什么条件下传入；某个取值没有承接方也没有迁移或裁剪决定
- rule-360687635318｜功能规格写对接点参数时，从该 UI 的实际调用处取值，不套别的流程｜读到：源码里同一函数有两类调用：UI 处用默认参数，另一流程（如失效恢复）显式传了非默认值；写错：规格「对接点」一节写的参数取自另一流程（如把恢复流程的 true 套到 UI 的退出操作上），和该 UI 的实际调用不符
