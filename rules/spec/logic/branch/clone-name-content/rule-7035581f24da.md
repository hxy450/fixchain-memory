# 克隆类验收项写明名称变换和内容来源，不只写 duplicates fields

审的是：规格
触发（任一种）：
- 读到：源码或分析参考文档里写了克隆名用后缀字符串格式化原名、克隆内容取编辑草稿和重排后的子项；写错的样子：验收项只写「duplicates fields and nested steps with new IDs and returns to rebuilt list」，没有名称变换和内容来源
适用范围：规格提取阶段转写克隆、复制类功能的验收项时
做法：
- 验收项写：名称 = 带占位符的字符串资源格式化原持久化名；内容取编辑草稿字段和当前顺序的子项（新 id）；完成后重建以列表为根的栈
来源：1 张卡，1 个应用
