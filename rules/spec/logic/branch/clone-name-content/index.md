# 克隆操作的名称变换和内容来源

agent 会看到什么：读到源码或分析参考里克隆名用后缀格式化原名、克隆内容取编辑草稿和重排后的子项；验收项只写「duplicates fields … with new IDs」

## 规矩

- rule-7035581f24da｜克隆类验收项写明名称变换和内容来源，不只写 duplicates fields｜读到：源码或分析参考文档里写了克隆名用后缀字符串格式化原名、克隆内容取编辑草稿和重排后的子项；写错：验收项只写「duplicates fields and nested steps with new IDs and returns to rebuilt list」，没有名称变换和内容来源
