# 源码理解笔记把零分母、钳制、空集合这些边界保护记成行为要点，不只记调用接线

审的是：规格
触发（任一种）：
- 读到：源端辅助方法里有 if (total == 0) 分支、coerceIn / clamp 钳制或空集合判断；写错的样子：源码理解笔记里只记了辅助类的构造和调用接线，没有记零分母分支、钳制范围、空集合这些边界保护
适用范围：写源码理解笔记（source-notes）时，源端计算带边界保护的地方
做法：
- 在笔记的行为要点里逐条写出边界保护：分母为零时返回什么、结果钳制到什么范围、空集合时怎么处理
