# 规格描述源码重连循环时保留源码退出条件，新增取消出口要登记为显式偏离并同步 AC

审的是：规格
触发（任一种）：
- 读到：源码重连循环 while (!isConnected()) { sleep(500); connect(); }，循环内不检查取消；写错的样子：规格附录写「页面销毁必须能终止该循环」「以取消标志为唯一出口」，主规格 AC 却写「循环 connect 直到成功」，决策台账里没有这条偏离
适用范围：规格提取阶段描述源码里的等待、重连循环及其退出条件时
做法：
- 规格照写源码循环的退出条件，例如「只在重新连上后退出，循环内不响应取消，取消在下一轮检点生效」
- 确需按平台理由新增取消或超时出口时，在决策台账写一条显式偏离（源码行为、新行为、理由），并同步改对应 AC；不在附录里直接写成实现要求
