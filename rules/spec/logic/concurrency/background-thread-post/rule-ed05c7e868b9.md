# 返回、撤销、重试这类可重复操作的验收，连续写第 1、2、3 次的结果和不同起点

审的是：规格
触发（任一种）：
- 读到：源端返回、撤销、重试的处理里有后台线程写入参与；写错的样子：验收只断言第一次操作的结果（如「返回回到上一项，再返回退出」），没有逐次写第 1、2、3 次，也没区分重试后、切换后这类起点
适用范围：规格里返回、撤销、重试等可重复操作的验收条目
做法：
- 连续走第 1、2、3 次并逐次写出结果，分别从重试后、切换后两种起点写；源端有后台写参与时，按设备上实测的序列定验收
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 切换后连续返回在两项之间交替，重试后返回停在本项：修复时设备实测出的源端序列（形如这样的逐次结果才能写成验收）（出处：卡里修好并验证过）
