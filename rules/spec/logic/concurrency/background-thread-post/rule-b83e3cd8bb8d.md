# 串行写执行契约的验收条目除提交顺序外，还要有任务内嵌套写能完成的一条

审的是：规格
触发（任一种）：
- 读到：源端写执行器有「调用方已在执行线程则同步内联、不再排队」的重入分支；写错的样子：规格的验收条目只写「并发提交 N 个写任务后结果等于某串行顺序」，没有覆盖重入分支：队列任务内调用另一个写方法、外层 Promise 能完成
适用范围：规格里给串行写执行器（写仓库、数据库写线程）定的验收条目
做法：
- 验收条目加一条：在队列任务内调用另一个写方法，外层 Promise 能完成，结果与源端内联执行一致
来源：1 张卡，1 个应用
- case-e2f82d2a4d27325abe09（AntennaPod）：做法第 1 步 ← 建议 3、诊断
