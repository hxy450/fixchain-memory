# 源端后台工作映射成目标同步调用时，契约列出异步体与调用方都写的字段，写明调用方的写挪到前面

审的是：规格
触发（任一种）：
- 读到：源端方法在后台线程成功后写字段，调用方发起后又同步写同一字段；写错的样子：实现映射把这个方法定为事件循环内同步顺序执行，称单线程「天然消除」源端竞争，没列出两处都写的字段，也没写调用方的写要挪到同步调用之前
适用范围：规格的实现映射或契约里，把源端后台线程工作改成目标同步调用的那一项
做法：
- 契约里列出异步体内写入、且调用方发起后还会再写的字段，写明：目标端把调用方的那次写挪到同步调用之前，保持源端的最终值
