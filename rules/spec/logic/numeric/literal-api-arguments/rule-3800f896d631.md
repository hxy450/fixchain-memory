# 规格常量清单收录源端传给平台或传感器 API 的字面参数，不只写单位域

审的是：规格
触发（任一种）：
- 读到：源端调用平台或传感器 API 时把字面参数直接写在实参里，如角度乘 0.01745329252f 的度转弧度原式；写错的样子：规格常量清单里没有这些参数，只写「弧度域」之类的单位说明
适用范围：规格提取阶段整理常量清单时
做法：
- 常量清单逐个写出源端传给平台或传感器 API 的字面参数：名字、原式（如 角度 × 0.01745329252f）和单位
针对本应用要查的：
- 源端调用的字面参数：源工程里调用平台或传感器 API 的那一行，以及它引用的局部常量；照抄原式和单位进常量清单
