# 源端联动对照表要写每个跟随字段的格式化精度，不只写哪些字段跟随

审的是：规格
触发（任一种）：
- 读到：源端十字光标或高亮联动代码里，每个跟随字段的格式化都带小数位参数；写错的样子：源码理解笔记或对照表只列了「哪些字段跟随高亮」，没写各字段的格式化精度
适用范围：整理源端十字光标、高亮联动行为，写对照表或源码理解笔记时
做法：
- 对照表每个跟随字段一行，写明字段名和源端格式化用的小数位参数（如现价 3 位、涨跌额 3 位），和「是否跟随」写在一起
针对本应用要查的：
- 各跟随字段的小数位：源端行情视图的高亮回调和非高亮刷新里的格式化调用；读出每个调用传入的小数位参数，写进对照表
