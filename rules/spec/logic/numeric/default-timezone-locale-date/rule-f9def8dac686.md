# 偏离源端随区域变化的语义时，登记为待确认决策，不只写在注释或源码笔记里

审的是：规格
触发（任一种）：
- 读到：源码用 Calendar.getInstance()、Locale.getDefault() 等随区域变化的调用；映射或验收要求「数值域同 Android」「与 Android 同日」；写错的样子：源码笔记或代码注释里写「确定性取舍」「取确定性 ISO 语义」「有意偏差」，决策台账里没有对应的待确认决策
适用范围：规格、源码理解笔记和决策台账里记录目标端对源端语义的取舍时
做法：
- 不以「确定性」为由改用 ISO 等固定语义；确需偏离源码时，在决策台账登记一条待确认决策：源端调用和语义、目标打算的语义、偏离后可见的差异（如周起止日期在 en-US 下偏移）
