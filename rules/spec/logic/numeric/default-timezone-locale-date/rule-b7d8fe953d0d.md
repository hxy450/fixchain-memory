# 时间显示的验收只给 UTC 偏移 0 样例时，补一个非零偏移时区的样例

审的是：规格
触发（任一种）：
- 读到：源端的时间显示经 SimpleDateFormat、GregorianCalendar 或 Calendar 在默认时区下格式化；写错的样子：验收条目里时间显示的样例只有 UTC 偏移 0 下的（毫秒值 → HH:mm:ss），没写在哪个时区下，也没有非零偏移时区的样例
适用范围：源端时间显示依赖默认时区时，规格里时间显示类的验收条目
做法：
- 验收至少加一个非零偏移时区的样例并写明时区：如 Asia/Shanghai（UTC+8）下毫秒值 0 → 08:00:00，America/New_York 下 → 19:00:00
- 源端有按 1970 年时刻探测偏移的，再加一个 1970 年偏移和现在不同的时区样例（Europe/London 1970 年偏移为 +1）
未核实：America/New_York、Europe/London 的样例值按推算，卡里只上机对照了 UTC+8
来源：1 张卡，1 个应用
