# 规格给 System.nanoTime 等计时 API 写映射时，写明所需语义并以 SDK 声明为目标 API 的证据

审的是：规格
触发（任一种）：
- 读到：源端用 System.nanoTime() 做动画或帧计时；写错的样子：规格的实现映射写「System.nanoTime() → performance.now()（ms）」并标「低难度 / 行为等价」，没写单调、是否含深睡眠、精度这些语义，也没有引用 SDK 声明证明目标 API 存在
适用范围：规格提取阶段给源端系统计时 API 写目标映射的那一行（实现映射表、决策台账里的时钟条目）
做法：
- 映射行写成：System.nanoTime()（单调、不含深睡眠、ns）→ systemDateTime.getUptime(systemDateTime.TimeType.ACTIVE, true)，除以 1000000 换算成 ms（@kit.BasicServicesKit）
- 映射行注明证据来自 SDK 的 @ohos.systemDateTime.d.ts；performance.now 这类 Web API 先在 ArkTS SDK 里核实存在，没有声明就不写进映射
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- function getUptime(timeType: TimeType, isNanoseconds?: boolean): number：单调计时的目标 API，TimeType.ACTIVE 不含深睡眠，isNanoseconds 为 true 返回纳秒（出处：鸿蒙 SDK 的 ets/api/@ohos.systemDateTime.d.ts，systemDateTime.getUptime）
- @kit.PerformanceAnalysisKit 的导出里没有 performance：performance.now 在 ArkTS SDK 里没有声明（出处：鸿蒙 SDK 的 ets/kits/@kit.PerformanceAnalysisKit.d.ts 的 export）
- System.nanoTime() 只用于量经过的时间，不计深睡眠：源端语义，映射行里要写出来（出处：java.lang.System#nanoTime）
