# 同一协议常量在规格里只留一种权威写法，验收条目和伪代码都引用它

审的是：规格
触发（任一种）：
- 读到：源码里一个定长 byte[] 常量（如扇区尾块 KeyA | 访问位 | GPB | KeyB）在规格的常量清单、验收条目和伪代码里都要出现；写错的样子：规格里同一常量有几种写法且互相矛盾：常量行写「FF0780」，验收条目或伪代码简写成「0780」「07 80」
适用范围：规格里一个常量被常量清单、验收条目、伪代码多处引用时
做法：
- 只保留一条权威写法，如「KeyA FF×6 | AC FF 07 80 | GPB | KeyB FF×6」；验收条目和伪代码引用这一条，或逐处与它对齐，不另写简写片段
