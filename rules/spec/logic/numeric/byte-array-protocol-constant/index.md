# 源码里的定长 byte[] 协议常量

agent 会看到什么：Java 源码用有符号 byte[] 字面量定义定长协议块（如 MIFARE 扇区尾块 KeyA | 访问位 | GPB | KeyB），规格的常量清单、验收条目或伪代码里写的是 hex 片段或几种不一致的简写

## 规矩

- rule-1992fc88c2d7｜源码有定长 byte[] 协议常量时，规格按下标列全字节并换成无符号，再核总长｜读到：Java 源码用有符号 byte[] 字面量定义定长协议块（如 {-1, -1, …, 7, -128, 105, …}，MIFARE Classic 扇区尾块 KeyA 6 | 访问位 3 | GPB 1 | KeyB 6）；写错：规格把常量写成 hex 片段（如「FFFFFFFFFFFF + 0780 + 69 + FFFFFFFFFFFF」），漏了字节，总长不等于块长；没写有符号到无符号的换算
- rule-5279318b42eb｜同一协议常量在规格里只留一种权威写法，验收条目和伪代码都引用它｜读到：源码里一个定长 byte[] 常量（如扇区尾块 KeyA | 访问位 | GPB | KeyB）在规格的常量清单、验收条目和伪代码里都要出现；写错：规格里同一常量有几种写法且互相矛盾：常量行写「FF0780」，验收条目或伪代码简写成「0780」「07 80」
