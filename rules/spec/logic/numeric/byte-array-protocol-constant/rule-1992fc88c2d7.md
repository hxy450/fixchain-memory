# 源码有定长 byte[] 协议常量时，规格按下标列全字节并换成无符号，再核总长

审的是：规格
触发（任一种）：
- 读到：Java 源码用有符号 byte[] 字面量定义定长协议块（如 {-1, -1, …, 7, -128, 105, …}，MIFARE Classic 扇区尾块 KeyA 6 | 访问位 3 | GPB 1 | KeyB 6）；写错的样子：规格把常量写成 hex 片段（如「FFFFFFFFFFFF + 0780 + 69 + FFFFFFFFFFFF」），漏了字节，总长不等于块长；没写有符号到无符号的换算
适用范围：规格提取时把源码里的定长字节数组常量转写成规格常量、验收条目或伪代码
做法：
- 按下标列出全部字节，并写明有符号到无符号的换算（-1→FF、-128→80、105→69、-68→BC），各段标明字节数
- 核对总长等于块长，扇区尾块是 6 + 3 + 1 + 6 = 16 字节
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Byte.toUnsignedInt(x) = ((int) x) & 0xff：负的 byte 映射成 x + 256：有符号 byte 到无符号的换算规则（出处：java.lang.Byte#toUnsignedInt）
- MifareClassic.BLOCK_SIZE = 16；KEY_DEFAULT = 6 个 0xFF：块长和出厂默认密钥（出处：android.nfc.tech.MifareClassic#BLOCK_SIZE、#KEY_DEFAULT）
