# 功能 spec 的 algo-io 登记常量时，一并登记它经库序列化后的字符串形态

审的是：规格
触发（任一种）：
- 读到：源码把常量交给库序列化，如 new RRule(new Recur(freq, new DateTime(<毫秒常量>))).toString()；写错的样子：algo-io 只登记毫秒常量，验收条目写「输出含 UNTIL=<毫秒数>」，没写序列化后的串是 UTC Z 还是设备时区浮动时间
适用范围：功能 spec 的 algo-io 和验收条目登记要经库序列化的常量时
做法：
- 常量旁边写出库序列化后的字面串（时区形态、分隔符、结尾），验收判据写这个字面串，不写毫秒数
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- UNTIL 由 ical4j 按设备时区格式化成浮动时间 yyyyMMddTHHmmss，不是 UTC Z 形态：同一个毫秒常量的序列化结果（出处：卡里修好并验证过）
来源：1 张卡，1 个应用
