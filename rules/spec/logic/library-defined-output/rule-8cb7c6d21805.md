# 依赖库语义的工具函数，规格 AC 写入边界样例并引用源仓库单测

审的是：规格
触发（任一种）：
- 读到：源码工具函数依赖库语义（String.replaceFirst、java.net.URL.host、Patterns.WEB_URL.matcher().matches()、io.ktor.http.Url），源仓库 src/test 下有对应单测；写错的样子：AC 只有标准绝对 URL 的样例，没有无 scheme、带端口或 userinfo、句中含 URL、畸形转义这些边界样例，也没引用源仓库单测
适用范围：规格提取阶段，依赖库语义的字符串和 URL 工具函数的验收判据
做法：
- AC 判据写入边界样例：无 scheme、带端口或 userinfo、句中含 URL、畸形转义，各写期望输出
- 引用源仓库对应的单测文件作为 unit 判据来源
针对本应用要查的：
- 这些函数的单测用例：源仓库 src/test 下按被测类名加 Test 找到的单测文件；把其中输入和期望输出抄进 AC，作为 unit 判据
