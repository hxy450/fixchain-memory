# 解析类规格写完后，用几个具体输入手算源端输出，核对服务层、验收条目和示例一致

审的是：规格
触发（任一种）：
- 读到：源端用 split、下标、字符串拼接或子串查找解析深链或 URL；写错的样子：同一规格里服务层公式、验收条目文字和示例互相矛盾：有的条目照源写 `"?" + x.split("?")[1]`，服务层写守卫空串；示例写的结果和按源算出的不一样
适用范围：规格提取阶段，转写源端字符串解析函数的规格交付前
做法：
- 挑 2–3 个具体输入（不含分隔符的、未注册路径的、词中含匹配子串的），逐个按源代码手算输出
- 把手算结果对照服务层签名、各验收条目文字和示例三处，矛盾的地方在交付前改成和源端一致
