# 规格遇到平台库调用时，把迭代序、切分、正则引擎、舍入、解码容错写成契约

审的是：规格
触发（任一种）：
- 读到：源方法体直接调 HashMap、String.split / trim、正则、(float) 运算、Base64.decode、Uri.parse、ContentResolver.getType；写错的样子：规格只写口语描述（「拒绝 /data 前缀与 ../」「非空白字符数」「后继非纯数字词」「其余→file/*」），没写迭代序、分隔截断、正则引擎、浮点舍入、解码容错、未知值默认
适用范围：规格提取阶段，给依赖 Java / ICU / AOSP 库语义的方法写服务层契约时
做法：
- 契约写明：迭代序依赖、分隔和截断规则、正则字符集所属引擎（ICU 还是 JS）、浮点精度与舍入、解码容错规则、未知值的平台默认（如 application/octet-stream）
- 这类条目标注「需逐语义移植」
