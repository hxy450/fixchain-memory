# 规格映射 Color.GREEN 等框架颜色常量时按色值对令牌，没有同值令牌就写明新增

审的是：规格
触发（任一种）：
- 读到：源码里 setTextColor(Color.GREEN)、Color.RED 等 android.graphics.Color 常量；写错的样子：规格的颜色映射写成「Color.GREEN → light_green」这类按名字对到色值不同的应用色令牌
适用范围：规格里把 android.graphics.Color 常量映射成目标颜色令牌的那几项
做法：
- 映射项按色值写：Color.<常量> = 它的 ARGB 值 → 同值的令牌；没有同值令牌就写明新增一个该值的令牌，不用名字相近、色值不同的应用色
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- BLACK 0xFF000000、DKGRAY 0xFF444444、GRAY 0xFF888888、LTGRAY 0xFFCCCCCC、WHITE 0xFFFFFFFF、RED 0xFFFF0000、GREEN 0xFF00FF00、BLUE 0xFF0000FF、YELLOW 0xFFFFFF00、CYAN 0xFF00FFFF、MAGENTA 0xFFFF00FF、TRANSPARENT 0：框架颜色常量的 ARGB 值（出处：android.graphics.Color 的常量（BLACK … TRANSPARENT））
