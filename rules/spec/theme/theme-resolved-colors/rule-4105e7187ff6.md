# 规格写主题链时写明状态栏图标明暗，状态栏外观的验收同时列底色和图标色

审的是：规格
触发（任一种）：
- 读到：源主题继承 Theme.AppCompat.Light.NoActionBar 一类主题，用 colorPrimaryDark 或 setStatusBarColor 设状态栏底色；写错的样子：规格的主题链和映射只写底色（如「contentColor 同步」「状态栏配色 parity」），没写 windowLightStatusBar 或运行时标志是否存在、图标是白是深；状态栏验收条目只判底色
适用范围：规格提取时写主题与样式链、以及状态栏外观的验收条目
做法：
- 主题与样式链里写明：windowLightStatusBar、SYSTEM_UI_FLAG_LIGHT_STATUS_BAR、APPEARANCE_LIGHT_STATUS_BARS 各自是否存在，以及结论「状态栏图标白色」或「深色」；状态栏外观的验收同时列出底色和图标色
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- windowLightStatusBar 对应 View.SYSTEM_UI_FLAG_LIGHT_STATUS_BAR 和 WindowInsetsController.APPEARANCE_LIGHT_STATUS_BARS：规格里要逐项写明有无的三种写法（出处：Android SDK 平台资源 data/res/values/attrs.xml，windowLightStatusBar（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 源端状态栏图标明暗：源工程 res/values* 下主题文件里应用和 Activity 主题的 android:windowLightStatusBar，顺 parent 到依赖库或平台主题；再搜代码里的两个运行时标志；有一处为 true 写「深色图标」，都没有写「白色图标」
