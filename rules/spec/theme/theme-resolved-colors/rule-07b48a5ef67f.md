# 资源映射表记主题属性时，写明浅深解析值和对应的颜色键，不只用文字记值

审的是：规格
触发（任一种）：
- 读到：源图标、控件引用了主题属性（?attr/…）着色；写错的样子：资源映射文档里只用文字记了「属性=浅色值/深色值」，没写对应的 color.json 键名，或者写了 SVG 固定取浅色值却没写深色怎么适配
适用范围：资源前置阶段写资源映射表、记录被引用的主题属性时
做法：
- 映射表每个主题属性一行：属性名、浅色和深色的解析值、对应的 $r('app.color.<键>')，并注明图标用 fillColor 引用这个键
来源：1 张卡，1 个应用
