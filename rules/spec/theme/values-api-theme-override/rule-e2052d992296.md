# 规格写按压反馈时，按 values-v21 实际父主题写出提供方 drawable、类型和半径

审的是：规格
触发（任一种）：
- 读到：源主题在 values/ 继承 Theme.Light、在 values-v21 继承 android:Theme.Material.Light.DarkActionBar 等；列表 listSelector、标题栏按钮背景都来自主题；写错的样子：规格只写「按压色取平台资源」「stateStyles pressed 底色层」，按 values/ 的 Theme.Light 写，没写 drawable 是 ripple 还是 selector、有界无界和半径
适用范围：规格提取时写列表行、标题栏按钮、对话框按钮的按压反馈那一节
做法：
- 按 values-v21 的实际父主题，逐类控件写出提供方 drawable（如 list_choice_background_material、action_bar_item_background_material、btn_borderless_material）、类型（ripple / selector）、有界或无界及半径
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Theme.Material：listChoiceBackgroundIndicator = list_choice_background_material（有界 ripple）；actionBarItemBackground = action_bar_item_background_material（无界 ripple，radius 20dp）：Material 主题两类控件的提供方（出处：Android SDK 平台资源 data/res/values/themes_material.xml，listChoiceBackgroundIndicator / actionBarItemBackground（按应用的 compileSdk 取对应平台））
- Material.Light 主题 colorControlHighlight = @color/ripple_material_light：涟漪着色输入（出处：Android SDK 平台资源 data/res/values/themes_material.xml，colorControlHighlight（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 设备实际走的父主题：源工程 res/values-v21（及更高 vNN）和 res/values 下 styles/themes 里应用主题的 parent；按设备 API 取最高匹配的 values-vNN；父主题是 Theme.Material* / DeviceDefault 时按压背景多为 <ripple>
