# 按钮子类用自动字号时，规格写出内容区（尺寸减内边距）、两向约束和按钮字体，不只抄字号区间

审的是：规格
触发（任一种）：
- 读到：源码在继承 Button / AppCompatButton / MaterialButton 或带 style 的 TextView 上调用 setAutoSizeTextTypeUniformWithConfiguration，或写 autoSizeTextType="uniform"；构造里只 setBackgroundResource 换了背景；写错的样子：规格映射行只写字号区间（「字号域 [min,max]」）加一句「自适应块宽 / 容器」，把按钮说成「仅为可点击+背景着色」，具体自适应属性留给实现期对 d.ts，风险标「低」
适用范围：规格里映射安卓自动字号（autoSize）的行为契约那一行，尤其是按钮子类
做法：
- 契约写明：可用区域 = 控件尺寸减实际内边距，按宽、高两向取单行放得下的最大 sp；行高和字宽按控件字体测（Button 文字外观是 sans-serif-medium，含 includeFontPadding）
- 写明内边距的来源：查主题 buttonStyle 与背景 drawable 是否带 padding；setBackgroundResource 换成无 padding 的 shape 不会清掉样式内边距
- 内边距从资源推不出来时标「待实测」，写出实测方法（临时日志打印 getPaddingTop / getTextSize），风险不标「低」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 可用宽 = getMeasuredWidth() - getTotalPaddingLeft() - getTotalPaddingRight()；可用高 = getMeasuredHeight() - getExtendedPaddingBottom() - getExtendedPaddingTop()：自动字号在这块区域里用 findLargestTextSizeWhichFits 取放得下的最大字号（出处：android.widget.TextView#autoSizeText）
- 新背景的 getPadding 返回 true 时才改写内边距：换成不带 padding 的 shape 背景时，原样式带来的内边距保留（出处：android.view.View#setBackgroundDrawable）
- TextAppearance.Material.Button 的 fontFamily = @string/font_family_button_material = sans-serif-medium，textAllCaps = true：平台按钮文字外观的字体（出处：Android SDK 平台资源 data/res/values/styles_material.xml，TextAppearance.Material.Button；data/res/values/donottranslate_material.xml，font_family_button_material（按应用的 compileSdk 取对应平台））
- mIncludePad 默认 true：TextView 默认含字体上下留白（includeFontPadding）（出处：android.widget.TextView#mIncludePad）
- Widget.Material.Button 的 background = @drawable/btn_default_material，textAppearance = ?attr/textAppearanceButton：平台按钮的内边距来自背景 drawable，字体来自 textAppearanceButton（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.Button（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 按钮的实际内边距：源工程主题（清单的 android:theme 指的 themes.xml）里的 buttonStyle，顺着 parent 到平台的 styles_material.xml 或 androidx.appcompat:appcompat、com.google.android.material:material 包内 res/values/values.xml，找提供 background / padding 的那一项；写死的 padding 直接读；来自背景 drawable 的读它的 inset 与 shape padding 相加；读不出就标待实测，用临时日志打印 getPaddingTop / getPaddingLeft
- 按钮文字的字体：同一条 buttonStyle 链上的 textAppearance（平台是 ?attr/textAppearanceButton）；读出 fontFamily 与 textStyle，写进契约的字体一项
未核实：AppCompat 在 API 27 以下用自己的自动字号实现，作用区域是否与平台一致
