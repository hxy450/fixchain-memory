# 生效主题提供窗口级外观时，规格逐项写出状态栏色、窗口底色、标题栏投影并指派承接者

审的是：规格
触发（任一种）：
- 读到：生效主题是 Material 系（如 Theme.Material.Light.DarkActionBar），布局 XML 里没有窗口背景、状态栏色和标题栏投影，窗口用框架 ActionBar；写错的样子：全局约定或页面规格写「仅做系统栏默认避让」「系统栏默认」，没有状态栏底色与图标深浅、窗口底色、ActionBar 背景/标题色/投影的条目，也没写由谁承接
适用范围：目标保持非全屏窗口、源端窗口外观由生效主题提供时，规格的全局约定和页面规格
做法：
- 主题行之后逐项写出并指派承接者：状态栏底色（Material 系为 statusBarColor → colorPrimaryDark）与图标深浅 → 入口 Ability；windowBackground → colorBackground → 每个页面根容器；窗口 ActionBar 的背景、标题色与 elevation → 共享标题栏组件及其宿主的层叠
- 非全屏时写「按源设置系统栏底色与图标色」，不写「系统栏默认」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- <item name="statusBarColor">?attr/colorPrimaryDark</item>：Material 系主题的状态栏底色取 colorPrimaryDark（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material.Light 的 statusBarColor（按应用的 compileSdk 取对应平台））
- <item name="windowBackground">?attr/colorBackground</item>；Theme.Material.Light 的 colorBackground 是 @color/background_material_light：窗口底色的解析链（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material.Light 的 windowBackground、colorBackground（按应用的 compileSdk 取对应平台））
- background_material_light = @color/material_grey_50 = #fffafafa：Material.Light 系没覆写时的窗口底色（出处：Android SDK 平台资源 data/res/values/colors_material.xml，background_material_light、material_grey_50（按应用的 compileSdk 取对应平台））
- Widget.Material.ActionBar 的 elevation = @dimen/action_bar_elevation_material = 4dp：窗口 ActionBar 的投影高度（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.ActionBar；data/res/values/dimens_material.xml，action_bar_elevation_material（按应用的 compileSdk 取对应平台））
- Theme.Material.Light.DarkActionBar 把 colorPrimaryDark 设为 @color/primary_dark_material_dark：应用没覆写 colorPrimaryDark 时状态栏取这个值（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material.Light.DarkActionBar（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 生效主题覆写的 colorPrimaryDark、colorPrimary、colorBackground、windowBackground、statusBarColor：源工程 values-vNN/styles.xml 里生效主题的 item；没覆写的到平台 themes_material.xml 里父主题的同名 item；顺着 ?attr/… 和 @color/… 引用解析到 #AARRGGBB，写进对应条目
