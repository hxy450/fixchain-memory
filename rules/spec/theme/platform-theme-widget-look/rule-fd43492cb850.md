# ListView 没声明 divider 时，规格按实际主题写出 listDivider 的颜色、高度和末行

审的是：规格
触发（任一种）：
- 读到：<ListView>（或 ListActivity 的 @android:id/list）没写 android:divider、android:dividerHeight，Activity 主题继承 Theme.Holo / Theme.Material 等框架主题，分隔线由主题 listDivider 隐式提供；写错的样子：规格的列表转换决策只写「List + ForEach，简单两行列表」或 List + ListItem、edgeEffect、滚动条、按压态，没有主题分隔线的颜色、高度、是否含末行；或者写成由 List.divider 承担分隔线
适用范围：规格阶段为未声明分隔线的 ListView / ListActivity 写列表转换决策时
做法：
- 沿 Activity 主题的 parent 查出 listDivider 指向的 drawable，把颜色、高度（dp）、宽度（ListView 左右 padding 以内的全宽）和末行写进列表的转换决策行：项与项之间各一条，末行底边高于列表底边时末行之后也画一条（ListView.dispatchDraw 的 bottom < listBottom）
- 同一项里注明 ArkUI List.divider 只画项间，不能单独承担这份契约，末行那条另由行内 Divider 承担
- 同时把分隔线颜色列进要新增的颜色资源，不只列文字色、背景色
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Widget.Holo.ListView / Widget.Material.ListView：divider = ?attr/listDivider：ListView 没写 divider 时取主题的 listDivider（出处：Android SDK 平台资源 data/res/values/styles_holo.xml，Widget.Holo.ListView；data/res/values/styles_material.xml，Widget.Material.ListView（按应用的 compileSdk 取对应平台））
- Theme.Holo：listDivider = @drawable/list_divider_holo_dark；Theme.Holo.Light：@drawable/list_divider_holo_light；Theme.Material 与 Theme.Material.Light：@drawable/list_divider_material：各主题族的列表分隔线 drawable（出处：Android SDK 平台资源 data/res/values/themes_holo.xml、data/res/values/themes_material.xml，listDivider（按应用的 compileSdk 取对应平台））
- list_divider_material：<shape android:tint="?attr/colorListDivider">，<solid android:color="?attr/opacityListDivider" />，<size android:height="1dp" …/>；Material 主题族里 colorListDivider = ?attr/colorForeground，opacityListDivider = @color/list_divider_opacity_material（#1f000000）：Material 下分隔线高 1dp，颜色由这两个主题属性决定（出处：Android SDK 平台资源 data/res/drawable/list_divider_material.xml；data/res/values/themes_material.xml，colorListDivider、opacityListDivider；data/res/values/colors_material.xml，list_divider_opacity_material（按应用的 compileSdk 取对应平台））
- setDivider 时 mDividerHeight = divider.getIntrinsicHeight()：没写 dividerHeight 时，高度取 drawable 自身高度（出处：android.widget.ListView#setDivider）
- bounds.left = mPaddingLeft; bounds.right = mRight - mLeft - mPaddingRight：分隔线横向是 ListView 左右 padding 以内的全宽（出处：android.widget.ListView#dispatchDraw）
- if (drawDividers && (bottom < listBottom) && !(drawOverscrollFooter && isLastItem))：每个子项底边低于列表底边就在其后画线，末行也一样；列表填满并滚到底时末行那条不画（出处：android.widget.ListView#dispatchDraw）
- List 的分割线画在主轴方向两个子组件之间，第一个子组件上方和最后一个子组件下方不画：List.divider 承担不了末行之后那条（出处：ts-container-list.md，divider）
- list_divider_holo_dark：白 15%（#26FFFFFF），xxhdpi 下 2px ≈ 0.76dp，每行下方都画，含末行：Theme.Holo 暗色下、行数不满一屏时的实际分隔线（出处：卡里修好并验证过）
针对本应用要查的：
- 主题 listDivider 的颜色和高度：源工程 AndroidManifest.xml 里 Activity（或应用）的 android:theme，顺着 res/values*/styles.xml 的 parent 链到对应平台 data/res/values/themes*.xml 的 listDivider，再到它指向的 drawable（drawable 下的 shape xml，或 drawable-<密度>/ 下的同名图）；shape xml 读 size 高度和最终颜色（含 tint 与透明度）；9-patch 图读像素颜色和高度，px 除以密度系数得 dp。例：Theme.Material.Light 下为 1dp、#1F000000；Theme.Holo 暗色是 #26FFFFFF、xxhdpi 下 2px
