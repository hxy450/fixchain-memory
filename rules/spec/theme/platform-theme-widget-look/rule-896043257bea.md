# 源端用 Theme.Holo 且带 ActionBar 时，规格每页写一条 ActionBar 外观决策行

审的是：规格
触发（任一种）：
- 读到：styles.xml 的主题 parent 链止于 android:Theme.Holo（未用 NoActionBar / FEATURE_NO_TITLE、未自定义 actionBarStyle）；代码有 setDisplayHomeAsUpEnabled(true)；菜单项 android:showAsAction="ifRoom|withText"；manifest 有 android:icon；写错的样子：规格只写「标题栏 + 返回箭头 → pop」或「图标+文字」，没有背景 drawable、应用图标、标题字号、Up 与溢出图标、values-land / values-w480dp 差异，也没登记为多页共享组件
适用范围：规格提取时，源端 ActionBar 由平台主题提供、不在布局 XML 里的每个页面
做法：
- 每页写一条 ActionBar 决策行：高度、背景 drawable、该 Activity 或 application 的 manifest android:icon、标题 label 及字号、是否显示 Up 及其平台图标、动作项与溢出图标
- 注明限定词差异：values-land 的高度和标题字号、values-w480dp 下 withText 文字是否显示；多页共用时登记为共享组件
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Theme.Holo 的 actionBarStyle = @style/Widget.Holo.ActionBar，actionBarSize = @dimen/action_bar_default_height：ActionBar 外观由这两项提供（出处：Android SDK 平台资源 data/res/values/themes_holo.xml，Theme.Holo（按应用的 compileSdk 取对应平台））
- Widget.Holo.ActionBar 的 background = @drawable/ab_transparent_dark_holo，titleTextStyle = TextAppearance.Holo.Widget.ActionBar.Title：背景是 drawable，不是纯色（出处：Android SDK 平台资源 data/res/values/styles_holo.xml，Widget.Holo.ActionBar（按应用的 compileSdk 取对应平台））
- action_bar_default_height：values 48dip、values-land 40dip、values-sw600dp 56dip；action_bar_title_text_size：values 18dp、values-land 16dp：决策行里要写的横竖屏差异（出处：Android SDK 平台资源 data/res/values*/dimens.xml，action_bar_default_height、action_bar_title_text_size（按应用的 compileSdk 取对应平台））
