# styles 父链止于平台主题时，规格里的文字色先在 SDK 平台资源解析到值，不写「暗底白字」

审的是：规格
触发（任一种）：
- 读到：源 styles 的 parent 链止于 android:Theme.Holo / Theme.Material / Theme.DeviceDefault，文字控件只写 textAppearanceLarge / Medium / Small，或既不写 textColor 也不写 textAppearance；EditText 没写 textColorHint；写错的样子：规格写「文字色（Theme.Holo 暗底白字）| 显式 .fontColor('#FFFFFF')」这类概括，或把次色、提示色写成半透明白并标「待核」
适用范围：规格里为没有显式颜色的文字控件写转换决策行时，颜色由 Android 平台主题提供
做法：
- 按主题 textColorPrimary / textColorSecondary / textColorHint → color/ 下的 selector（如 primary_text_holo_dark.xml，取默认项）→ values/colors_holo.xml 的顺序解析到具体色值，写进各控件的决策行
- 逐个控件按来源写：textAppearanceLarge / Medium 取主色；textAppearanceSmall，或既无 textColor 也无 textAppearance 的 TextView 取次色；EditText 没写 textColorHint 取提示色；源端显式写的颜色照写显式值
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Theme.Holo：textColorPrimary = @color/primary_text_holo_dark，textColorSecondary = @color/secondary_text_holo_dark，textColorHint = @color/hint_foreground_holo_dark：Holo 暗色主题的三种文字色引用（出处：Android SDK 平台资源 data/res/values/themes_holo.xml，Theme.Holo 的 textColorPrimary 等（按应用的 compileSdk 取对应平台））
- bright_foreground_holo_dark = @color/background_holo_light = #fff3f3f3；dim_foreground_holo_dark = #bebebe；hint_foreground_holo_dark = #808080：Holo 暗色主色 #F3F3F3、次色 #BEBEBE、提示色 #808080（selector 默认项解析到这些色）（出处：Android SDK 平台资源 data/res/values/colors_holo.xml，bright_foreground_holo_dark 等（按应用的 compileSdk 取对应平台））
- Widget.TextView：textAppearance = ?attr/textAppearanceSmall；TextAppearance.Small：textColor = ?textColorSecondary：不写颜色也不写 textAppearance 的 TextView 取次色（出处：Android SDK 平台资源 data/res/values/styles.xml，Widget.TextView、TextAppearance.Small（按应用的 compileSdk 取对应平台））
- TextAppearance：textColor = ?textColorPrimary；TextAppearance.Large、TextAppearance.Medium 只改 textSize：Large / Medium 取主色（出处：Android SDK 平台资源 data/res/values/styles.xml，TextAppearance、TextAppearance.Large（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 应用主题实际止于哪个平台主题、是否覆盖了文字色：源工程 AndroidManifest 的 android:theme 和 res/values*/styles.xml，顺着 parent 找到 android:Theme.*；主题自己覆盖了 textColorPrimary 等就取覆盖值；否则到 Android SDK 平台资源 data/res/values/themes_*.xml 里该平台主题的条目，按上面的顺序解析。例：Theme.Holo 暗色下主色是 #F3F3F3
