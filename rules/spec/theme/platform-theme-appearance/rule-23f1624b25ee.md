# 主题提供控件外观时，规格的决策行写出提供方资源、各状态、内边距和高度

审的是：规格
触发（任一种）：
- 读到：源控件没写 android:background 等样式属性，应用主题父类是 android:Theme.Holo / Material / DeviceDefault；写错的样子：规格的转换决策行只写“Holo 下划线样式”“取不到精确值处标待核”，没写提供方资源、各状态外观、内容内边距和高度
适用范围：规格提取阶段写由 Android 框架主题提供外观的控件的转换决策行时
做法：
- 在该控件的转换决策行写出提供方资源（如 editTextBackground → edit_text_holo_dark → textfield_default / textfield_activated_holo_dark）、各状态外观、内容内边距与高度
- 这些值先查 Android SDK 平台资源；查过仍缺的才标待核，并注明已查的资源文件
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Theme.Holo：editTextBackground = @drawable/edit_text_holo_dark：框架主题的值就在平台资源里，查得到（出处：Android SDK 平台资源 data/res/values/themes_holo.xml，Theme.Holo 的 editTextBackground（按应用的 compileSdk 取对应平台））
- edit_text_holo_dark：聚焦 → textfield_activated_holo_dark；未聚焦 → textfield_default_holo_dark：规格里要写的两个状态（出处：Android SDK 平台资源 data/res/drawable/edit_text_holo_dark.xml，selector（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 主题提供的外观资源：源工程 res/values/styles.xml 的主题 parent 链，到 Android SDK 平台资源 data/res/values/themes_*.xml、styles*.xml 和 drawable 选择器；找到控件样式里引用的主题属性，解析到 drawable 或颜色，记下各状态对应的资源名
