# 布局里没写 background/style 的框架控件，规格沿主题父链定生效主题，写明默认背景、内距与按压态

审的是：规格
触发（任一种）：
- 读到：布局里 ImageButton、Button 等框架控件只写 src、padding、margin、onClick，没有 android:background 或 style；写错的样子：规格的转换决策行只写「图标按钮 / Image + onClick」「按压反馈 stateStyles 补」，没有主题默认样式带来的按钮底、背景内距
适用范围：规格提取阶段为没写 background/style 的安卓框架控件确定外观时
做法：
- 按目标设备 API 沿 values-vNN 的主题父链确定生效主题（如 API 21 起取 values-v21 里的定义）
- 把控件默认样式带来的静态背景、背景内距与按压态写进该控件的转换决策行；不只写「图标按钮 + onClick」「按压反馈补」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Theme.Material：imageButtonStyle = @style/Widget.Material.ImageButton；Theme.Material.Light：@style/Widget.Material.Light.ImageButton（parent 为 Widget.Material.ImageButton）：Material 主题下 ImageButton 的默认样式（出处：Android SDK 平台资源 data/res/values/themes_material.xml，imageButtonStyle；data/res/values/styles_material.xml，Widget.Material.Light.ImageButton（按应用的 compileSdk 取对应平台））
- Widget.Material.ImageButton 的 background = @drawable/btn_default_material：Material 主题下没写背景的 ImageButton 有可见按钮底（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.ImageButton（按应用的 compileSdk 取对应平台））
- Widget.ImageButton 的 background = @drawable/btn_default：Theme / Theme.Light 下 ImageButton 同样有按钮底，不是透明（出处：Android SDK 平台资源 data/res/values/styles.xml，Widget.ImageButton（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 生效主题：源工程 AndroidManifest 里 application / activity 的 android:theme，再到 res/values*/styles.xml（按目标设备 API 选 values-vNN）里该主题的 parent 链；沿 parent 走到 android:Theme.* 的框架主题，再到 Android SDK 平台资源的 themes*.xml 找该主题的 imageButtonStyle、buttonStyle
