# 裁定来源冲突时只有带资源文件锚点的结论标「查证」，台账依据栏只写打开过的文件

审的是：规格
触发（任一种）：
- 读到：几条来源对同一外观说法冲突：参考文档里没有锚点的句子、经验提醒；写错的样子：决策台账的依据栏写某布局「查证回执」，但读过的东西里没有打开过这个文件；或者把参考文档里没有锚点的句子当成查证；或者判为误记的来源里另一些片段（如「按钮条右对齐」）未经核对仍留在契约里
适用范围：规格整合者在几条来源之间裁定外观契约、写决策台账时
做法：
- 只有带资源文件或行号回执的结论标「查证」；参考文档里没有锚点的句子按推断处理，标待核
- 判为误记的来源，其余片段逐条回资源文件核对后才能留在契约里
- 台账的依据栏只写确实打开过的文件
