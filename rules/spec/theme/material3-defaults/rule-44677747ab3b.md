# 源用 M3 small TopAppBar 时，规格写明源码里看不到的默认度量

审的是：规格
触发（任一种）：
- 读到：Compose 源码只有 TopAppBar(title = …, navigationIcon = …)，没写高度和内边距；写错的样子：页面规格没写顶栏容器高、水平内边距、导航图标和标题起点，或写成 56 高、把状态栏 inset 算进顶栏高度
适用范围：把 Material 3 small TopAppBar 迁成自绘 ArkUI 顶栏时的页面规格
做法：
- 页面规格写出默认度量：small TopAppBar 容器 64dp（不含状态栏，状态栏 inset 加在外层）、水平内边距 4dp、导航图标 48dp、标题起点 4+48+4=56dp
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 容器高 64dp（不含状态栏）、水平内边距 4dp、导航图标 48dp、标题起点 56dp：M3 small TopAppBar 的默认度量（出处：卡里修好并验证过）
针对本应用要查的：
- 应用所用 material3 版本里 small TopAppBar 的默认度量：源工程 Gradle 里 compose BOM 决定的 androidx.compose.material3:material3 版本，查该版本源码里 small TopAppBar 容器高和水平内边距的常量；读出 dp 值写进规格；和上面的值不同时以该版本为准
未核实：默认度量出自卡，本机没有 material3 的源码，没核到原文
