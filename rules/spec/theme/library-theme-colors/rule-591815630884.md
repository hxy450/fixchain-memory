# AppTheme 只继承 Theme.AppCompat.DayNight 时，规格列出框架色浅深取值作成对 token

审的是：规格
触发（任一种）：
- 读到：styles.xml 里 AppTheme 只有 parent="Theme.AppCompat.DayNight"，没有 colorPrimary / colorAccent 覆写，资源目录没有 values-night；写错的样子：跨栈映射写成「DayNight 主题 → resources/dark（业务色双目录）| colors.xml 转 color.json」，没列框架主题浅/深两态的窗口、ActionBar、按钮、文字、强调色等取值
适用范围：源工程主题是未覆写的 AppCompat DayNight，规格里写主题和颜色映射的那一节
做法：
- 规格里列出框架主题浅/深两态的窗口、对话框、ActionBar、状态栏、按钮（常态/按下）、主/次文字、提示、禁用、强调色、分隔线取值，作为 base/dark 成对 token
- 业务调色板（colors.xml）单列，不镜像到 dark 当作深色适配
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Theme.AppCompat.DayNight：values 下 parent="Theme.AppCompat.Light"，values-night-v8 下 parent="Theme.AppCompat"：浅色取 Light 主题的值，深色取 Theme.AppCompat 的值（出处：androidx.appcompat:appcompat 包内 res/values/values.xml 与 res/values-night-v8/values-night-v8.xml，Theme.AppCompat.DayNight（按应用依赖的版本））
- 例：appcompat 1.7.1 下 colorAccent 浅色 → @color/accent_material_light → material_deep_teal_500 = #ff008577；深色 → accent_material_dark → material_deep_teal_200 = #ff80cbc4：框架强调色要按依赖版本解析，不凭记忆写（出处：androidx.appcompat:appcompat 包内 res/values/values.xml，accent_material_light、material_deep_teal_500（按应用依赖的版本））
- 修复在 base/dark 两套 color.json 成对新增 action_bar_background、status_bar_background、button_normal/pressed、dialog_background、text_secondary/hint/disabled、list_divider、progress_track 等，页面改引这些 token：框架色 token 的清单（出处：卡里修好并验证过）
针对本应用要查的：
- 框架主题浅/深两态各项颜色的取值：androidx.appcompat:appcompat 包内 res/values/values.xml 的 Base.V7.Theme.AppCompat.Light 和 Base.V7.Theme.AppCompat 两个 style；平台属性到 Android SDK 平台资源 data/res/values/themes_material.xml；读 colorAccent、colorPrimary、android:colorBackground 等 item，顺着 @color/… 和 ?attr/… 引用解析到色值；按应用依赖的 appcompat 版本和 compileSdk 取
未核实：卡里的环境是 HarmonyOS 6.1.1（API 24），本机是 API 23
