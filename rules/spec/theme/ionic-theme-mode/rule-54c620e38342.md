# Ionic 应用设了全局 mode 时，规格写入各组件该 mode 的 host 样式，不只列 inline

审的是：规格
触发（任一种）：
- 读到：源 App.tsx 里 setupIonicReact({ mode: 'ios' }) 固定了模式；页面用 IonCard、IonCardHeader（IonCardSubtitle + IonCardTitle）、IonToolbar + IonButtons，tsx 里只有少量 inline style（如 fontSize）；写错的样子：规格只按 DOM 顺序和 inline 字号写组件（如「副标题 1.2rem + 主标题 2.8rem」），把 IonCard 决策成「Column 卡片（borderRadius + padding）」，没写渲染顺序、大写、字重、字距、阴影、工具栏内距；样式来源只列应用自己的 css
适用范围：规格提取阶段处理 Ionic 应用（设置了全局 mode）页面里用到的 Ionic 组件
做法：
- 对页面用到的每种 Ionic 组件，读源工程 @ionic/core 里 <组件>.<mode>.css 的 :host 规则，把渲染顺序（如 flex-direction: column-reverse）、text-transform、font-weight、letter-spacing、阴影、圆角、工具栏内边距写进规格
- inline style 只当作覆盖它声明的那几个属性，其余属性取组件 mode 样式
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- iOS 模式下 card-header 是 column-reverse：IonCardTitle 渲染在 IonCardSubtitle 上方：DOM 序和渲染序相反（出处：卡里修好并验证过）
- iOS 模式 card-subtitle：uppercase、font-weight 700、letter-spacing 0.4px；card-title：font-weight 700：卡头文字的默认样式（出处：卡里修好并验证过）
- iOS 模式 ion-card：圆角 8px，阴影 0 4px 16px rgba(0,0,0,.12)；iOS 工具栏右侧内距约 4px + 2px：卡片和工具栏的默认外观（出处：卡里修好并验证过）
针对本应用要查的：
- 每种 Ionic 组件在应用所设 mode 下的默认样式：源工程 node_modules/@ionic/core/dist/collection/components/<组件>/<组件>.<mode>.css 的 :host 规则（按应用依赖的 Ionic 版本）；读出 flex-direction、text-transform、font-weight、letter-spacing、box-shadow、border-radius、padding，再用应用 css 和 inline style 覆盖
未核实：Ionic 组件的默认样式出自卡里查到的 @ionic/core，卡里没记 Ionic 版本，本机知识库里没有这个库
