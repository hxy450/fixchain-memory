# 源控件外观全来自第三方库默认时，规格的实现映射写明库名、版本和默认视觉值

审的是：规格
触发（任一种）：
- 读到：源组件只引入第三方库默认 CSS（如 swiper/css/navigation、swiper/css/pagination），没有主题变量或样式覆盖；写错的样子：实现映射只写「ArkTS Swiper + indicator（可点跳页）+ 自定义左右导航按钮」这类行为描述，没有库名、版本、默认颜色尺寸形状或 CSS 出处
适用范围：规格提取阶段，给外观来自第三方库默认样式的源控件写实现映射时
做法：
- 实现映射里写明库名和源工程锁定的版本，以及默认视觉值（主题色、箭头形状和尺寸、分页点直径和颜色、位置）或它们所在的 CSS 文件和变量
针对本应用要查的：
- 库名、版本和默认视觉值：源工程 package.json（或锁文件）里的库版本，node_modules 里同版本库的 CSS 变量；把版本号和读出的默认值逐项写进实现映射；例：swiper 12.2.0 的 --swiper-theme-color 是 #007aff
