# 规格描述 Button 行时，写明未被覆写的控件默认外观，不只写字号字色背景

审的是：规格
触发（任一种）：
- 读到：源 `<Button>` 只写了 `android:background`、`android:textColor`、`android:textSize`，没写 `android:textAllCaps`、`android:stateListAnimator`、`style=`，主题是 `Theme.AppCompat` 一族；写错的样子：规格的 Button 控件行只列「textSize、白字、背景 drawable」，没写全大写、Medium 字重、投影与按压反馈这些默认外观
适用范围：规格提取阶段写页面里 Button 控件的外观行时
做法：
- Button 行除显式属性外，写明未被覆写的控件默认外观：「全大写（按 locale）、Medium 字重、2dp 投影按下 6dp、源背景无 pressed 态时按下不变色」
