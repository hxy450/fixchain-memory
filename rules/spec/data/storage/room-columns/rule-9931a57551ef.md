# 源码笔记为手写 DDL 列 Room 列清单时，附原始 createSql 或标出关键字列名

审的是：规格
触发（任一种）：
- 读到：Room 导出 schema 的 <version>.json 里每张表有 createSql；@ColumnInfo(name = …) 的列名含 to、order、group 这类 SQL 关键字；写错的样子：数据层的源码笔记或 brief 只给逐列清单（表、列名、类型、可空），没附 createSql，也没标出属于 SQL 关键字的列名
适用范围：侦察或规格阶段为目标端手写建表 SQL 整理 Room 表结构时
做法：
- 列清单旁附该表的原始 createSql，或在属于 SQL 关键字的列名旁标「SQL 关键字，DDL 里须加引号」
针对本应用要查的：
- 每张表的原始 createSql：源工程 Room 导出目录 schemas/<Database 类全名>/<version>.json 的 entities[].createSql；整句抄进笔记，标明 ${TABLE_NAME} 是表名占位
