# 规格把固定演示数据当可观察行为，写出完整数据表和主题 key 原值

审的是：规格
触发（任一种）：
- 读到：源工程用种子类、模板类构造固定演示数据（固定标题、日期偏移、主题 key、note、完成集合与完成时间）；写错的样子：规格只概括记录数、项数和完成比例，主题写成颜色的中文译名而不是 key 原值，没逐项列出清单项标题、分类、优先级、完成状态和完成偏移
适用范围：规格提取阶段写演示数据、预置数据那一节时
做法：
- 写出完整数据表：每条记录的标题、目的地、日期偏移、主题 key 原值、note，每个清单项的标题、分类、优先级、完成状态和完成偏移
