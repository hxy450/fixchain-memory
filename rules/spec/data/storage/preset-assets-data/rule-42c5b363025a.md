# 规格引用预置数据资产时写明覆盖范围并和运行期输入比对，不足时写替代算法

审的是：规格
触发（任一种）：
- 读到：源工程 assets/ 下有按日期等键查表的预置 JSON 或 DB；运行期输入是当前日期或用户可选的年份；写错的样子：规格引用了这份资产，却没写它覆盖的起止范围和条数，没和运行期输入域比对；覆盖不足时没写替代算法或降级方案
适用范围：规格里把预置数据资产写成数据来源或数据来源之一时
做法：
- 规格里写明资产实际覆盖范围（起止键值、条数），并与运行期输入域（当前日期、可选年份）比对
- 覆盖不足时在规格里写明替代算法或降级方案
针对本应用要查的：
- 预置资产的覆盖范围：源工程 assets/ 下那份 JSON（或预置 DB 的对应表）；读出首条和末条记录的键（如日期）和总条数，写成「起–止，共 N 条」；例：只覆盖某一年前几个月时，当前日期多半落在范围外
