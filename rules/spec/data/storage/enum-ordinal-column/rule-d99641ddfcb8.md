# 多值枚举列在规格的数据模型里写成 ordinal 枚举并引用枚举表，不写 0/1

审的是：规格
触发（任一种）：
- 读到：feature 规格的枚举表写了三值枚举（如 Auto(0)/Always(1)/Never(2)），回执备注把几列写成「Int（ordinal/0-1）」；写错的样子：基座规格或数据模型说明把该列写成「Int=0/1」，或把两列的 ordinal 与 0/1 对调
适用范围：规格 / 基座阶段写设置表、数据模型里的整型枚举列时
做法：
- 该列写成「Int=ordinal，取值见 <feature 规格> 枚举表」并列出各值；按他人回执修订时逐列对照枚举表分配类型，不按备注字面顺序套用
