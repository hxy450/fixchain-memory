# 基础层规格写明偏好存储封装须先 init(context)、在哪个生命周期 init

审的是：规格
触发（任一种）：
- 读到：源端全局静态键值工具保存 token、用户信息，原生页面和 MethodChannel 回调都读写它；写错的样子：基础层规格只写偏好存储封装「已实现」和键对齐表，没写必须先 init(context)、init 放在哪个生命周期、启动期有哪些读写方
适用范围：基础层规格里写应用级键值持久化封装的那一节
做法：
- 规格写三项：封装必须先 init(context)；init 放在 UIAbility.onCreate 最前面（或 AbilityStage.onCreate），插件、通道、页面只读写；启动期读写方清单，都晚于 init
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- function getPreferences(context: Context, name: string): Promise<Preferences>：首选项实例要用 context 取，这就是封装需要先 init 的原因（出处：鸿蒙 SDK 的 ets/api/@ohos.data.preferences.d.ts，preferences.getPreferences）
