# 源端同类偏好拆成多组独立集合时，AC 按写入它的页面分到各功能，括注不超出本行源锚点

审的是：规格
触发（任一种）：
- 读到：源端偏好仓库的键表里同类数据有几个独立键（按来源、目标等分组），各由不同页面或 ViewModel 写入；术语表写明某一组归另一个页面；写错的样子：某功能的 AC 写成「…持久化（A/B 两组）」，而同一行的源锚点只列了其中一组的字段或方法，目标方法也只对应这一组
适用范围：规格提取时把源端按页面分组的持久化偏好映射成各功能的验收条目、指定目标方法
做法：
- 逐组确认写入它的页面或 ViewModel（在源码里找写这个键的地方），再按功能分别写 AC：每组只写进它所属功能的 AC
- AC 括注里的范围不超出本行源锚点列出的集合；另一组在它所属功能里单独成条
针对本应用要查的：
- 每组偏好由哪个页面写：源工程偏好仓库的键定义，以及各 ViewModel 里读写这些键的方法；按键名搜写入点，记下所在的页面或 ViewModel，对到规格里的功能划分
未核实：规格作者写「两组」是笼统概括还是有意归入，卡里无法确认
