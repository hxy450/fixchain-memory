# 偏好默认值按 DataStore getter 的映射写，不从一个 null 判断推出三态偏好键

审的是：规格
触发（任一种）：
- 读到：DataStore getter 写成 preferences[KEY] == true（或 ?: 默认值），返回非空 Boolean；写错的样子：偏好表把该键默认值写成「null（未初始化，区分首启）」，或同一份规格里既写「Boolean 默认 false」又写「== null 表示未写入」，契约里出现 boolean | null 的参数
适用范围：规格或跨栈基线里写偏好键类型和默认值时
做法：
- 默认值照 getter 的实际映射写（== true 映射即默认 false）；规格里出现「默认 false」和「== null 表示未写入」这类矛盾时回源码裁决，不新增三态键或 hasKey 语义
针对本应用要查的：
- 偏好键的默认值：源工程里该键的 DataStore getter（data.map { preferences[KEY] … } 一类表达式）；== true 映射 → 默认 false；?: 后的值就是默认值；只有直接返回 preferences[KEY] 时才是可空
