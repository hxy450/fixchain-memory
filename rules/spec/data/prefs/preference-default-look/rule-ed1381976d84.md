# ListPreference 对话框只留 Cancel，按钮集合按框架默认推导

审的是：规格
触发（任一种）：
- 读到：<ListPreference> 没写 android:negativeButtonText；<EditTextPreference> 写了或没写 positiveButtonText / negativeButtonText；写错的样子：规格给 ListPreference 写「双按钮 OK/Cancel」或「无按钮」，或照别的对话框类推按钮集合
适用范围：规格提取时为偏好对话框写按钮集合和按钮文案来源
做法：
- DialogPreference 默认 positive=@android:string/ok、negative=@android:string/cancel；XML 写了 positiveButtonText / negativeButtonText 时用字面值
- ListPreference 去掉 positive，点项即写入并关闭，只保留 negative；未写 negativeButtonText 时按钮文案是平台 cancel 字符串，随系统语言本地化
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Preference.Holo.DialogPreference：positiveButtonText = @string/ok，negativeButtonText = @string/cancel：按钮的框架默认值（Preference.DialogPreference、Preference.Material.DialogPreference 同）（出处：Android SDK 平台资源 data/res/values/styles.xml，Preference.Holo.DialogPreference（按应用的 compileSdk 取对应平台））
- ListPreference.onPrepareDialogBuilder 里 builder.setPositiveButton(null, null)；点项模拟 BUTTON_POSITIVE 并 postDismiss()：单选对话框没有 OK，点项即写入并关闭（出处：android.preference.ListPreference#onPrepareDialogBuilder）
- positiveButtonText / negativeButtonText：Set to @null to hide the button：XML 写 @null 才隐藏按钮（出处：Android SDK 平台资源 data/res/values/attrs.xml，DialogPreference 的 positiveButtonText、negativeButtonText（按应用的 compileSdk 取对应平台））
- 平台 cancel：values 里是 Cancel，values-de 里是 Abbrechen：未写 negativeButtonText 时的按钮文案随系统语言变（出处：Android SDK 平台资源 data/res/values/strings.xml 与 values-de/strings.xml，string/cancel（按应用的 compileSdk 取对应平台））
