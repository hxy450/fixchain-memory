# DialogPreference 的对话框，规格写平台 AlertDialog 可见契约，不写 Select 或自绘弹窗

审的是：规格
触发（任一种）：
- 读到：偏好 XML 里有 ListPreference 等 DialogPreference，由 PreferenceFragment 的 addPreferencesFromResource 加载，没设 dialogLayout；源码里看不到 AlertDialog.Builder；写错的样子：转换决策写成「Select 组件或 bindSheet 选项单」，没有遮罩、卡宽、圆角、标题、单选行、按钮和取消路径
- 读到：PreferenceActivity 的偏好 XML 里有 <EditTextPreference>（android:dialogTitle、android:dialogMessage）或 <ListPreference>，源码里没有对话框代码；写错的样子：规格只写「点击弹自定义输入弹窗」或「单选弹窗」，没有平台对话框外观、dialogMessage、打开即聚焦
适用范围：规格为 DialogPreference 一族弹出的对话框定转换决策和可见契约时
做法：
- DialogPreference 的对话框与 AlertDialog.Builder 构造的同等对待：转换决策写「页内遮罩加居中卡片，复刻平台默认 AlertDialog」，进同一份契约和共享复刻件的用途清单
- 契约逐项写：遮罩、卡宽、圆角、标题字号字重、dialogMessage、单选行高和圆环、按钮（ListPreference 无确定钮，负按钮 android.R.string.cancel 全大写，选中即关）、EditText 打开即聚焦弹键盘、CANCEL / 点外 / 返回三种取消
- 数值按应用主题对应的平台资源写（下列取自 Theme.Material），查不到才标待核
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- backgroundDimAmount = 0.6：遮罩是 60% 黑（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material 的 backgroundDimAmount（按应用的 compileSdk 取对应平台））
- dialog_min_width_minor = 95%；dialog_background_material 的 inset = 16dp，圆角取 dialogCornerRadius（dialog_corner_radius = 2dp）：竖屏窗口宽 95% 屏宽，背景四周内缩 16dp，可见卡宽 = 95% × 屏宽 − 32dp，卡片圆角 2dp（出处：Android SDK 平台资源 data/res/values/dimens.xml，dialog_min_width_minor、dialog_corner_radius；data/res/drawable/dialog_background_material.xml（按应用的 compileSdk 取对应平台））
- text_size_title_material = 20sp；font_family_title_material = sans-serif-medium：标题 20sp Medium（TextAppearance.Material.DialogWindowTitle 继承 TextAppearance.Material.Title）（出处：Android SDK 平台资源 data/res/values/dimens_material.xml，text_size_title_material；values/donottranslate_material.xml，font_family_title_material（按应用的 compileSdk 取对应平台））
- 单选行 minHeight = ?attr/listPreferredItemHeightSmall（48dip），圆环 drawableStart = ?attr/listChoiceIndicatorSingle：单选行高 48，圆环是 Material 的 btn_radio（出处：Android SDK 平台资源 data/res/layout/select_dialog_singlechoice_material.xml；values/themes_material.xml，listPreferredItemHeightSmall（按应用的 compileSdk 取对应平台））
- Preference.Material.DialogPreference 的 negativeButtonText = @string/cancel；ListPreference 在 onPrepareDialogBuilder 里 setPositiveButton(null, null)，点选一项即按确定处理并关闭：无确定钮、有取消钮、选中即关（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Preference.Material.DialogPreference；android.preference.ListPreference#onPrepareDialogBuilder）
- TextAppearance.Material.Button：14sp、sans-serif-medium、textAllCaps = true：CANCEL 按钮的字号、字重和全大写（出处：Android SDK 平台资源 data/res/values/styles_material.xml，TextAppearance.Material.Button（按应用的 compileSdk 取对应平台））
- DialogPreference 用 setPositiveButton(mPositiveButtonText, this).setNegativeButton(mNegativeButtonText, this) 构造平台 AlertDialog；EditTextPreference.showDialog 里调 mEditText.requestFocus() 并显示输入法：偏好对话框就是平台 AlertDialog；输入框一打开就聚焦、弹键盘（出处：android.preference.DialogPreference#showDialog；android.preference.EditTextPreference#showDialog）
- 实测：遮罩 60%，卡宽 95% × 屏宽 − 32dp，2dp 圆角加投影，标题 20sp Medium，单选行 48dp（圆环 20dp、环宽 2dp、内点 10dp），标签 18sp，CANCEL 为 colorAccent、14sp Medium、全大写：和平台资源一致（出处：卡里修好并验证过）
针对本应用要查的：
- 应用主题有没有改对话框外观：源工程 res/values 下的 styles/themes XML，按应用主题的 parent 和 alertDialogTheme、backgroundDimAmount、dialogCornerRadius、colorAccent 这几个 item 找；有覆写的取覆写值，没有的取平台默认；colorAccent 决定按钮和选中圆环的颜色
