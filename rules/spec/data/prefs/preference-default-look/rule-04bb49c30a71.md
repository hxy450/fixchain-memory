# PreferenceActivity 配 Theme.Holo 时，规格先查平台偏好布局和样式写出几何，查过仍无才标待核

审的是：规格
触发（任一种）：
- 读到：Activity 继承 android.preference.PreferenceActivity，应用主题 parent 是 android:Theme.Holo*，页面没有布局 XML，只有 res/xml 偏好项（CheckBoxPreference、PreferenceCategory、带 android:icon 的 Preference）；写错的样子：规格写「Holo 小字分类头样式——精确样式值待核」「值取不到处标待核」，没写列表内边距、行高、分隔线规则和按压色，也没写检索过哪里
适用范围：规格提取阶段，把 PreferenceActivity 偏好列表（含关于、帮助列表页）转成 ArkUI 列表行时
做法：
- 先在 Android SDK 平台资源 platforms/android-N/data/res 检索 layout/preference_holo.xml、preference_category_holo.xml、styles 里的 Widget.Holo.TextView.ListSeparator，以及 drawable 下 btn_check_*_holo_dark、list_selector_holo_dark、list_divider_holo_dark、list_section_divider_holo_dark
- 规格写进：列表左右 16dp；行最小 64dp、行左右 8/10dp、文字列右 8dp、摘要 maxLines 10；分类头 14sp 粗体全大写加 2dp 线；分隔线 2px 白 15%，与分类头相邻不画、末项后画；按压色
- 检索过仍找不到的才标待核，并写明检索路径
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- LinearLayout android:minHeight="?android:attr/listPreferredItemHeight"、paddingStart="@dimen/preference_item_padding_side"、paddingEnd="?android:attr/scrollbarSize"；文字列 paddingEnd="@dimen/preference_item_padding_inner"；摘要 android:maxLines="10"：偏好行的几何来源（出处：Android SDK 平台资源 data/res/layout/preference_holo.xml（按应用的 compileSdk 取对应平台））
- Theme.Holo 里 listPreferredItemHeight = 64dip、scrollbarSize = 10dip；preference_item_padding_side = 8dip、preference_item_padding_inner = 8dip：行最小 64dp、行左 8dp 右 10dp、文字列右 8dp（出处：Android SDK 平台资源 data/res/values/themes_holo.xml，Theme.Holo；data/res/values/dimens.xml，preference_item_padding_side（按应用的 compileSdk 取对应平台））
- Widget.TextView.ListSeparator：textStyle bold、textSize 14sp、textColor ?textColorSecondary；Widget.Holo.TextView.ListSeparator 加 textAllCaps true、background list_section_divider_holo_dark：分类头样式（Theme.Holo 的 listSeparatorTextViewStyle）（出处：Android SDK 平台资源 data/res/values/styles.xml，Widget.TextView.ListSeparator；data/res/values/styles_holo.xml，Widget.Holo.TextView.ListSeparator（按应用的 compileSdk 取对应平台））
- PreferenceFragmentList 的 paddingStart / paddingEnd = @dimen/preference_fragment_padding_side（16dp）：列表左右 16dp（出处：Android SDK 平台资源 data/res/values/styles.xml，PreferenceFragmentList；data/res/values/dimens.xml，preference_fragment_padding_side（按应用的 compileSdk 取对应平台））
- 分类头下 2dp 线；行间分隔线 2px、白色 15%，与分类头相邻不画、末项后画：两种 9-patch 线图的取值和分隔线规则（出处：卡里修好并验证过）
针对本应用要查的：
- 用哪一版平台资源、暗色还是亮色变体：源工程 Gradle 构建脚本的 compileSdk；源工程 res/values 里应用主题的 parent；取 platforms/android-<compileSdk>/data/res；parent 是 Theme.Holo 用 *_holo_dark，Theme.Holo.Light 用 *_holo_light
