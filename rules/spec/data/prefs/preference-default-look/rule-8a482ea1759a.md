# AndroidX Preference 没有 widgetLayout 时，规格里的行组成不写行尾箭头

审的是：规格
触发（任一种）：
- 读到：偏好 XML 里 <Preference> 节点只有 key、title、summary、icon，没有 android:widgetLayout 或 app:widgetLayout；写错的样子：规格的行组成或转换决策写「Preference 行 + 箭头」「chevron_right」「右箭头 SymbolGlyph」，理由是「Material 列表行样式」这类源端没有的依据
适用范围：规格阶段描述由 AndroidX Preference 树转来的设置列表行时
做法：
- 规格只按源 XML 写行组成：icon（节点有才写）+ title + summary；节点没有 widgetLayout 时行尾为空，不写箭头或 chevron
- 不以「Material 列表行样式」「对齐常见设置页」为由新增源端没有的元素
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 行尾只有空的 LinearLayout @android:id/widget_frame，注释 Preference should place its actual preference widget here.：Preference 默认行布局的行尾是给 widgetLayout 填控件的空位，没填就什么都不显示（出处：androidx.preference:preference 包内 res/layout/preference_material.xml，@android:id/widget_frame（按应用依赖的版本））
- widgetLayout：The layout for the controllable widget portion of a Preference：行尾控件只来自 widgetLayout 属性（出处：androidx.preference:preference 包内 res/values/values.xml，declare-styleable Preference 的 widgetLayout（按应用依赖的版本））
- Preference.SwitchPreference、Preference.CheckBoxPreference 样式里写了 android:widgetLayout：开关、勾选这类子类的行尾控件由样式给出，普通 Preference 没有（出处：androidx.preference:preference 包内 res/values/values.xml，Preference.SwitchPreference（按应用依赖的版本））
