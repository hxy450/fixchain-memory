# SwitchPreference 只靠平台默认外观时，规格写开关可见契约，不写「Toggle 等价」

审的是：规格
触发（任一种）：
- 读到：PreferenceFragment / addPreferencesFromResource 加载的 SwitchPreference（或 Switch、CheckBoxPreference）没写 android:widgetLayout、style、android:thumb、android:track；写错的样子：转换决策写成「SwitchPreference | Toggle({ type: ToggleType.Switch }) | 开关行等价」，没写轨道和拇指尺寸、两态颜色、拇指投影、切换动画、点击归属
适用范围：源开关的外观和点击归属全部来自平台框架默认、迁移要求外观与交互和源一致时，规格里这个控件的转换决策
做法：
- 转换决策写开关的可见契约：轨道（窄胶囊，高 14dp、圆角 7dp）、拇指（比轨道高、外凸的圆，带投影）、两态颜色（开态取主题 colorControlActivated；关态轨道取 colorForeground、拇指取 colorSwitchThumbNormal）、拇指位移动画时长、命中归属（框架开关自身不可点，整行切换）
- 决策写成「自绘复刻」或「Toggle 显式定制」，不写等价；数值取自本机 Android SDK 平台资源，取不到的标待核
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- <Switch android:focusable="false" android:clickable="false" />：SwitchPreference 右侧的开关自身不接收点击和焦点，点击由整行处理（出处：Android SDK 平台资源 data/res/layout/preference_widget_switch.xml，Switch（按应用的 compileSdk 取对应平台））
- Widget.Material.CompoundButton.Switch：track = @drawable/switch_track_material，thumb = @drawable/switch_thumb_material_anim：框架 Material 开关的轨道和拇指图（出处：Android SDK 平台资源 data/res/values/styles_material.xml，Widget.Material.CompoundButton.Switch（按应用的 compileSdk 取对应平台））
- 轨道 shape：高 14dp、圆角 7dp，左右各内缩 4dp：框架开关的轨道是窄胶囊（出处：Android SDK 平台资源 data/res/drawable/switch_track_material.xml（按应用的 compileSdk 取对应平台））
- 轨道颜色：state_checked → ?attr/colorControlActivated；其余 → ?attr/colorForeground：轨道两态颜色取主题属性（叠加轨道 shape 自身的半透明）（出处：Android SDK 平台资源 data/res/color/switch_track_material.xml（按应用的 compileSdk 取对应平台））
- 拇指 tint：state_checked → ?attr/colorControlActivated；其余 → ?attr/colorSwitchThumbNormal：拇指两态颜色取主题属性（出处：Android SDK 平台资源 data/res/drawable/switch_thumb_material_anim.xml（按应用的 compileSdk 取对应平台））
- THUMB_ANIMATION_DURATION = 250（毫秒）：拇指位移动画时长（出处：android.widget.Switch#animateThumbToCheckedState）
- ToggleType.Switch 默认尺寸 {width:'36vp', height:'20vp'}，拇指半径按组件高度推算、在轨道内：ArkUI Toggle 默认是拇指在内的胶囊，和框架开关的几何不同，不能写等价（出处：ts-basic-components-toggle.md，ToggleType枚举说明）
- 框架开关拇指是 20dp 的圆、带投影、外凸于轨道：契约里拇指的尺寸和外观（出处：卡里修好并验证过）
针对本应用要查的：
- 主题里 colorControlActivated（Material 主题默认是 ?attr/colorAccent）、colorForeground、colorSwitchThumbNormal 的实际颜色：源工程 AndroidManifest.xml 里 activity 或 application 的 android:theme，顺着 parent 到源工程 res/values 的主题项；没写的落到平台 data/res/values/themes_material.xml 的对应主题；读出颜色，@color 引用解析到 #AARRGGBB。例：Theme.Material.Light 下 colorSwitchThumbNormal 是 switch_thumb_material_light，正常态 #fff1f1f1
