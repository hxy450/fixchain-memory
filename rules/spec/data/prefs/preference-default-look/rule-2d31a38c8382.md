# ListPreference、EditTextPreference 的弹窗，规格写居中对话框不写 bindSheet

审的是：规格
触发（任一种）：
- 读到：源端 ListPreference、EditTextPreference（由 preference / preference-ktx 库运行时构建，项目里没有对应布局 XML），或 MaterialDialog 的单选列表；写错的样子：规格的转换决策表写成「→ bindSheet 弹层」「bindSheet + TextInput 表单弹层」「bindSheet 单选列表」
适用范围：规格里把偏好项和库对话框的弹窗翻成目标组件的那几行
做法：
- 规格写成居中对话框：ListPreference → 居中单选列表对话框，EditTextPreference → 居中输入对话框（库里都是 AlertDialog）
- 输入对话框的几何照 preference_dialog_edittext.xml 写进规格：滚动区上下 48dp，说明文字左右 24dp、下 48dp，EditText 左右 20dp、最小高 48dp
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ScrollView android:layout_marginTop="48dp" android:layout_marginBottom="48dp"：输入对话框内容区的上下边距（出处：androidx.preference:preference 包内 res/layout/preference_dialog_edittext.xml（按应用依赖的版本））
- EditText android:layout_marginLeft="20dp" android:layout_marginRight="20dp" android:minHeight="48dp"：输入框的左右边距和最小高度（出处：androidx.preference:preference 包内 res/layout/preference_dialog_edittext.xml（按应用依赖的版本））
- message 的 TextView android:layout_marginLeft="24dp"、android:layout_marginBottom="48dp"：说明文字的边距（出处：androidx.preference:preference 包内 res/layout/preference_dialog_edittext.xml（按应用依赖的版本））
- 返修解包 preference AAR 后重写为居中对话框 + 库几何：返修后的写法（出处：卡里修好并验证过）
未核实：ListPreferenceDialogFragmentCompat、EditTextPreferenceDialogFragmentCompat 用 AlertDialog 出自卡，本机没有库源码核对
