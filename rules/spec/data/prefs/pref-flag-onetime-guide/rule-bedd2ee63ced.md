# 由偏好标记控制的一次性引导，行为提取时列为独立项，写明资源、显示条件、关闭方式和标记

审的是：规格
触发（任一种）：
- 读到：源码里引导图只在某个偏好标记为真时 VISIBLE、点击隐藏，显示后随即调 setter 写回标记；布局里引导 ImageView 为 match_parent 加 android:scaleType="fitXY"；写错的样子：行为笔记或规格里没有这个首次引导项
适用范围：Android 行为提取阶段，源端有由偏好标记控制、只显示一次的 UI 时
做法：
- 列为独立行为项：引导资源、显示条件（标记为真）、关闭方式（点击隐藏）、持久化标记（显示后写回）
