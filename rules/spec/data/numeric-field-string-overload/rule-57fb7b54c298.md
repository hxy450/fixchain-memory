# 源字段已有 Double/Long 真值时，规格不因 String 重载或 Parcel 写法改成 string

审的是：规格
触发（任一种）：
- 读到：参考文档或 getter 给出字段是 `Double` / `Long`，同时有 `setX(String)` 重载，或 Parcel 里写 `String.valueOf(getX())`、读 `setX(in.readString())`；写错的样子：规格字段表把存储类型写成 string，或写「setter 同时接受 String 与数值」并建议目标用 `string | null` 存储；String 入口的解析规则没有写
适用范围：规格提取阶段为实体字段定类型、可空性时
做法：
- 字段表的存储类型照真值写（Double → `number | null`，装箱可空）
- String 入口另写一条访问器契约：按源码解析成数值（如 Double.parseDouble），解析失败 → null
