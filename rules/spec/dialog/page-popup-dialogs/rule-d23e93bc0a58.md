# 页面会弹出库渲染的弹窗时，页面规格补一节弹层结构，写明源调用锚点和配置字段

审的是：规格
触发（任一种）：
- 读到：源页面通过 Helper 加配置对象弹出弹窗，弹窗布局不在页面 XML 里；写错的样子：页面规格只列页面自身的 layout_sources，合成快照里也没有弹窗节点；没有弹层结构一节，也没写弹窗的源调用锚点和配置字段
适用范围：规格提取阶段，页面会弹出由库渲染、布局不在本页 XML 里的弹窗
做法：
- 在 page spec 里补一节弹层结构：源调用锚点（哪个类的哪个方法弹出）、配置对象的各字段（标题、说明条目、勾选两态、协议链接、同意/拒绝分支）
来源：1 张卡，1 个应用
