# 页面上弹出、布局不在页面 XML 里的弹窗和底部面板

agent 会看到什么：读到 Activity 只一句委托辅助类的 show…Dialog、通过 Helper 加配置对象弹出库渲染的弹窗，或在当前页 show 一个 Dialog / BottomSheet；规格只列页面自身的布局，没有弹层结构、源调用锚点和配置字段，或把底部弹层改写成 HMRouter 路由页

## 规矩

- rule-e8f9d2a3ac17｜Activity 只委托辅助类弹窗时，规格展开辅助类和它的布局，写明点击反馈、延时和回调顺序｜读到：Activity 里只有一句对辅助类 show…Dialog 方法的委托调用（带同意回调 lambda，里面持久化并 dismiss），勾选控件和延时都在辅助类和它 inflate 的布局里；写错：验收条目只写「显示同意弹窗；接受后先持久化再继续」，android_source_anchors 里没有这个辅助类和它 inflate 的主弹窗布局，没写点击后的选中反馈、延时和回调顺序
- rule-d23e93bc0a58｜页面会弹出库渲染的弹窗时，页面规格补一节弹层结构，写明源调用锚点和配置字段｜读到：源页面通过 Helper 加配置对象弹出弹窗，弹窗布局不在页面 XML 里；写错：页面规格只列页面自身的 layout_sources，合成快照里也没有弹窗节点；没有弹层结构一节，也没写弹窗的源调用锚点和配置字段
- rule-db11b7916fc0｜源端在当前页 show 底部弹窗时，规格写叠层契约，不因「路由统一用 HMRouter」改成路由页｜读到：源码在当前 Activity 上 show 一个 Dialog / BottomSheet（全宽底部面板），面板里还可能再弹同类底部日历；工程另有「路由统一使用 HMRouter」的基座约束；写错：规格写「可以用 HMRouter 页面承载等价的底部弹层」，映射表、数据流写成宿主页 → HMRouter 路由页，验收以 route 判定，没写宿主页可见、点背景关闭、不入返回栈
- rule-1d17dde33646｜界面只由外部库方法加 Config 渲染时，规格写明布局来自依赖库、列全配置字段和结构基准｜读到：源端只调用外部库或 SDK 的模板方法，传入 Config / Builder 对象（标题、条目数组、图标、勾选/未勾选图、链接色、链接回调）；工程 layout 和合成的 view.xml 里都没有这个界面的结构；写错：页面规格只写界面大意（如「隐私概要弹框、协议链接与同意/拒绝操作」）和「SDK … Dialog → CustomDialogController」一类映射；没写布局由依赖库提供，没列配置字段，也没列实现前要取得的结构基准
