# 对话框几何由第三方库或 Dialog 主题决定时，规格的跨栈基线写出窗口宽度公式和出处

审的是：规格
触发（任一种）：
- 读到：共享组件表或跨栈基线写着对话框由 material-dialogs（MaterialDialog.Builder）包装，或 Activity 的 android:theme 是 Theme.*.Dialog；源码树里只有库名或主题名，没有数值；写错的样子：跨栈基线只写「material-dialogs → ArkUI CustomDialog」「Dialog 主题 Activity → Dialog 形态页」，没有窗口宽高公式和出处，也没登记取不到库资源的缺口
适用范围：规格提取时，写对话框（库封装的对话框、Dialog 主题 Activity）的跨栈映射基线那一节
做法：
- 在基线里写出窗口宽度公式和出处：material-dialogs 为 min(md_dialog_max_width, 屏宽 − 2×md_dialog_horizontal_margin)；MaterialAlertDialog 为屏宽 × windowMinWidthMinor（竖）/ windowMinWidthMajor（横）再减背景 inset；Theme.*.Dialog 的 wrap_content Activity 为 min(config_prefDialogWidth, 屏宽)
- 库不在源码树时从 Gradle 缓存的 AAR 或 APK 资源取值；取不到就登记为缺口，不能只写库名
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- material-dialogs 0.9.6.0：md_dialog_max_width = 356dp，md_dialog_horizontal_margin = 28dp，窗口宽 min(356, 屏宽 − 56)：库对话框的窗口宽度公式（出处：卡里修好并验证过）
- config_prefDialogWidth = 320dp：wrap_content 浮动窗口先按这个宽度试排（出处：Android SDK 平台资源 data/res/values/config.xml，config_prefDialogWidth（按应用的 compileSdk 取对应平台）；android.view.ViewRootImpl#measureHierarchy）
- dialog_min_width_minor = 95%，dialog_min_width_major = 65%：主题 windowMinWidthMinor / windowMinWidthMajor 引用的平台默认值（出处：Android SDK 平台资源 data/res/values/dimens.xml，dialog_min_width_minor / dialog_min_width_major（按应用的 compileSdk 取对应平台））
针对本应用要查的：
- 库对话框的窗口几何 dimens：Gradle 缓存里应用依赖版本的 material-dialogs AAR 解包后的 res/values/values.xml，按 md_dialog_max_width、md_dialog_horizontal_margin 找；读出 dp 值写进公式；缓存里没有这个版本时登记为缺口
- 主题实际的 windowMinWidthMinor / windowMinWidthMajor 和背景 inset：源工程 res/values 下应用主题及其父主题（MaterialComponents 的在 com.google.android.material:material 包内 res/values/values.xml），没有覆盖时取 Android SDK 平台资源；顺着 @dimen/… 解析到百分比和 inset 值写进公式
未核实：material-dialogs 的 md_dialog_max_width、md_dialog_horizontal_margin 本机 Gradle 缓存里没有这个库，取自卡
