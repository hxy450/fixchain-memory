# 源端循环里每个命中各弹一窗时，规格把多窗行为写进怪癖清单，AC 写到弹窗个数和确认次数

审的是：规格
触发（任一种）：
- 读到：源端判定方法双层循环不 break，每个命中元素都落盘统计并 show 一个不可取消的 AlertDialog；写错的样子：规格和 AC 只写「弹一次」，页面状态接口写成布尔，怪癖清单里没有这一条
适用范围：规格提取阶段描述按命中次数弹窗的源端行为
做法：
- 怪癖清单写进这条多窗行为；AC 判据写到次数，如「一次合成出两个命中 → 两个叠放弹窗、确认需点两次、统计落盘两次」
- 页面状态接口写成计数，不写布尔
