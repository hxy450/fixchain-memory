# 源端系统弹窗只靠平台默认外观时，规格写出可见契约和取值来源，不写「系统组件 1:1」

审的是：规格
触发（任一种）：
- 读到：源端用 android.app.AlertDialog.Builder 内联构造，只设 setTitle / setMessage / setPositiveButton / setNegativeButton，没有自定义布局或样式；写错的样子：转换决策表写「AlertDialog.show()（primaryButton/secondaryButton）｜系统对话框 1:1」或「行为等价」，只写文案和按键行为
- 读到：源端 AlertDialog.Builder 没有自定义布局或样式，外观完全取平台默认；写错的样子：规格或映射基线里 AlertDialog 的契约只写「negative 左 / positive 右、cancelable(false)」，验收只核对文案和左右槽位
适用范围：规格里为外观全由平台默认样式决定的源端系统组件（AlertDialog.Builder、Toast、Snackbar 等）定目标实现、写可见契约和验收条目时
做法：
- 按应用主题确定源端实际渲染的平台样式，把可见契约逐项写进规格：负键在左、正键在右、靠末端；按钮 14sp Medium、全大写、accent 色；标题左对齐与字号字重（框架 Material 为 20sp Medium）；面板宽度与圆角、正文区最小高度、按钮条位置；遮罩、位置、进出场；点外部和返回键是否关闭
- 目标系统弹窗的固有版式对不上而又要一比一还原时，规格里直接定用自定义弹窗（openCustomDialog + 自绘面板），并写明各数值取自哪个平台资源文件及其版本
- 验收条目覆盖上面每一项，不只核对文案和左右槽位
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Theme.Material.Light 的 alertDialogTheme = @style/ThemeOverlay.Material.Dialog.Alert，backgroundDimAmount = 0.6：应用主题没另设时框架 AlertDialog 用的样式，以及遮罩浓度（出处：Android SDK 平台资源 data/res/values/themes_material.xml，Theme.Material.Light 的 alertDialogTheme、backgroundDimAmount（按应用的 compileSdk 取对应平台））
- windowBackground = @drawable/dialog_background_material，windowAnimationStyle = @style/Animation.Material.Dialog（进出场 popup_enter_material / popup_exit_material），windowCloseOnTouchOutside = @bool/config_closeDialogWhenTouchOutside：弹窗面板背景、进出场、点外部关闭的来源（出处：Android SDK 平台资源 data/res/values/themes_material.xml，ThemeOverlay.Material.BaseDialog；styles_material.xml，Animation.Material.Dialog（按应用的 compileSdk 取对应平台））
- 按钮条从左到右是 button3（中性）、spacer（占满剩余）、button2、button1；button1 是正键、button2 是负键；layoutDirection = locale，paddingStart / paddingEnd = 12dp：按钮靠末端对齐，负键在左、正键在右，按语言方向排（出处：Android SDK 平台资源 data/res/layout/alert_dialog_button_bar_material.xml（按应用的 compileSdk 取对应平台）；com.android.internal.app.AlertController#setupButtons）
- TextAppearance.Material.Button 的 textAllCaps = true：按钮文字全大写（出处：Android SDK 平台资源 data/res/values/styles_material.xml，TextAppearance.Material.Button（按应用的 compileSdk 取对应平台））
- alertTitle：layout_width = match_parent，textAlignment = viewStart：平台标题占满宽度并靠起始边（出处：Android SDK 平台资源 data/res/layout/alert_dialog_title_material.xml，alertTitle（按应用的 compileSdk 取对应平台））
- contentPanel：minHeight = 48dp：正文区最小高度（出处：Android SDK 平台资源 data/res/layout/alert_dialog_material.xml，contentPanel（按应用的 compileSdk 取对应平台））
- dialog_corner_radius = 2dp（框架 Material 主题的 dialogCornerRadius）：Material 主题下对话框圆角（出处：Android SDK 平台资源 data/res/values/dimens.xml，dialog_corner_radius；themes_material.xml，dialogCornerRadius（按应用的 compileSdk 取对应平台））
- 按平台资源取值用自定义弹窗复刻面板、按钮条和进出场；卡片宽 0.95 × 屏宽 − 左右各 16、圆角 2、正文区最小高 48、标题 Medium、按钮 14sp Medium 全大写：返修后与平台外观一致的写法（出处：卡里修好并验证过）
针对本应用要查的：
- 源端警告框实际用的主题样式：源工程 AndroidManifest 引用的应用主题，顺着 styles.xml 里的父主题链找 android:alertDialogTheme；都没写时取平台主题（AppCompat 的 Light 主题在新平台上落到 Theme.Material.Light）；从该样式及其隐式父样式读 windowBackground、windowAnimationStyle、backgroundDimAmount 和按钮样式，再顺着引用解析到 dimens、drawable、anim 里的具体值
- 应用主题下对话框的圆角和 accent 色：源工程 res/values 下应用主题的 style；没有覆盖时取 Android SDK 平台资源 data/res/values/themes_material.xml 或 themes_device_defaults.xml 里对应主题的 dialogCornerRadius、colorAccent；顺着 @dimen/… 或 @color/… 解析到值写进契约。例：框架 Material 主题下圆角取 dialog_corner_radius；DeviceDefault 主题下取 config_dialogCornerRadius，值不同
未核实：平台资源按本机 android-37.0 / android-36 核实；卡片宽 0.95 × 屏宽 − 32 的出处卡里没写明，只有返修后的结果
