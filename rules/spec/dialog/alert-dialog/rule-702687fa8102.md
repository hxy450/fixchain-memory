# 平台默认 AlertDialog 的取消契约按返回键和点外部两路分别写，不写「仅返回键可关」

审的是：规格
触发（任一种）：
- 读到：源端 AlertDialog.Builder(...).show()，没有调用 setCancelable 或 setCanceledOnTouchOutside；写错的样子：取消契约或平台缺省表只写「系统返回键可关闭」，没写点对话框外部这一路
- 读到：参考文档写「对话框为平台默认可取消（cancelable），系统返回键可关闭」；写错的样子：验收条目写成「仅可返回键关闭」，判据只测返回手势
适用范围：规格为源端未显式设置取消方式的平台 AlertDialog 写取消契约和验收条目时
做法：
- 取消契约分两路写，各写关闭哪一层、关闭后的状态：返回键（setCancelable，未调用时为 true）；点窗口外部（setCanceledOnTouchOutside，未调用时取对话框主题的 windowCloseOnTouchOutside，targetSdk ≥ 11 才生效）
- 只有源码显式调用 setCancelable(false) / setCanceledOnTouchOutside(false)，或平台资源查到 false 时才写排他句；没有依据的标待核
- 验收判据同时覆盖返回键和点对话框外部两种操作
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- Dialog 的 mCancelable 初值为 true；AlertDialog.Builder.setCancelable 的说明写 Default is true：没调用 setCancelable 时返回键可取消（出处：android.app.Dialog#mCancelable；android.app.AlertDialog.Builder#setCancelable）
- setCanceledOnTouchOutside(true) 时若还不可取消，会顺带设为可取消：点外部取消是独立于返回键的另一路（出处：android.app.Dialog#setCanceledOnTouchOutside）
- targetSdkVersion >= HONEYCOMB 时，窗口主题的 windowCloseOnTouchOutside 为 true 就 setCloseOnTouchOutsideIfNotSet(true)：没调用 setCanceledOnTouchOutside 时由对话框主题决定，targetSdk 11 起才生效（出处：com.android.internal.policy.PhoneWindow#generateLayout）
- Theme.Holo.Dialog 的 windowCloseOnTouchOutside = @bool/config_closeDialogWhenTouchOutside；Theme.Holo.Dialog.Alert 继承 Theme.Holo.Dialog.BaseAlert：Holo 系对话框主题的点外部默认值出处（出处：Android SDK 平台资源 data/res/values/themes_holo.xml，Theme.Holo.Dialog、Theme.Holo.Dialog.Alert（按应用的 compileSdk 取对应平台））
- config_closeDialogWhenTouchOutside = true：上面引用的布尔值（出处：Android SDK 平台资源 data/res/values/config.xml，config_closeDialogWhenTouchOutside（按应用的 compileSdk 取对应平台））
- Theme.Holo.Dialog.NoFrame 的 windowCloseOnTouchOutside 为 false：同一族里也有关掉的主题，必须沿实际主题的父链查，不能一概而论（出处：Android SDK 平台资源 data/res/values/themes_holo.xml，Theme.Holo.Dialog.NoFrame（按应用的 compileSdk 取对应平台））
- 未设置取消方式的 Builder 对话框，安卓上点外部依次关掉叠放的两个对话框：契约要写点外部这一路的依据（出处：卡里修好并验证过）
针对本应用要查的：
- 对话框实际主题的 windowCloseOnTouchOutside 取值：源工程 AndroidManifest 的 android:theme 和 values 下 themes/styles 里的 alertDialogTheme 覆盖；再到 Android SDK 平台资源 data/res/values/themes_*.xml 沿对话框主题的 parent 链找 windowCloseOnTouchOutside，引用 @bool/… 的到 values/config.xml 解析；先看源码有没有调用 setCancelable / setCanceledOnTouchOutside；没调用再按父链取第一个出现的值；同时确认 targetSdk ≥ 11。例：应用主题继承 Theme.Holo 时，Theme.Holo.Dialog.Alert → BaseAlert → Theme.Holo.Dialog，值解析为 true
