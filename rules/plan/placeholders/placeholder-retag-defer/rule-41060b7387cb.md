# 主题切片禁碰 pages/ 时，把页面报告里的「深色未建」类延后项转成有归属的任务

审的是：计划与派工
触发（任一种）：
- 读到：页面转换报告写「深色配色未建」「端点由主题切片统一」一类延后项；写错的样子：主题切片的派工写盘边界是「禁碰 pages/」，延后项没有转成任何人的任务；派工已告知共享顶栏、主题文件可引用，页面仍另写页内顶栏
适用范围：编排主题切片和页面转换切片的派工时
做法：
- 汇总页面报告里的延后项，逐条转成有归属的任务（写明谁、在哪个切片、改哪些页面）；主题切片禁碰 pages/ 时另派页面侧收尾任务
- 派工点名共享顶栏和主题可引用时，写明页面必须复用共享顶栏，不另写页内顶栏
