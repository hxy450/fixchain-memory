# 收口时把 FWD-REF 改挂为集成期延期前，先确认代码在缺口下 fail-closed

审的是：计划与派工
触发（任一种）：
- 读到：占位登记里有平台缺口的 FWD-REF（如 DNG 封装待 PD 决策），注释写「直写缓冲字节」；写错的样子：收口时把这条 FWD-REF 的 resolve_by 改挂成「集成期 PD 决策」，对应代码仍在缺口下返回成功
适用范围：收口或过债务门时改动占位登记的 resolve_by
做法：
- 改挂为集成期延期之前，先读对应代码，确认缺口下走失败路径（fail-closed）；还是伪成功的，先改代码或保留原 resolve_by
来源：1 张卡，1 个应用
