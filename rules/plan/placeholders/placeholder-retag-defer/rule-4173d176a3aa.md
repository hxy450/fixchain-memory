# 派给本 Slice 的 forward-ref 点名了源端实现类时，判「规格没给端点」前先读该类

审的是：计划与派工
触发（任一种）：
- 读到：派工把某条 FWD-REF / 占位列为本 Slice 待接，登记行点名了源端实现类；写错的样子：回执里以「功能规格 API 表没列端点，建未指定端点即发明」为由保持 registered，或把它改交 closer 的跨 Slice 草稿，而没读过登记点名的类
适用范围：Slice 实现阶段决定派给本 Slice 的 forward-ref 当场移植还是继续延后时
做法：
- 先读登记行点名的源端实现类及其 API 声明，拿到路径、请求体和规则后当场实现并在回执里 resolve；源码是真值，功能 API 表漏列不能当作延后理由
