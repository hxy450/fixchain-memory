# 收尾遇到动画类待办时派给有写权的实现步骤，不只把 resolve_by 改成外部视觉核验

审的是：计划与派工
触发（任一种）：
- 读到：registry 里有动画类的登记项（如源端 AnimatedContent 切换被降级为直切），resolve_by 指向某个切片步骤；写错的样子：收尾或编排把它的 resolve_by 统一改成外部视觉核验（如 a2h-verify），债务闸按外部延迟放行，源行为明确却没有实现步骤接手
适用范围：收尾和编排阶段处理动画类待办、登记项时
做法：
- 源行为明确时，把这项派给有写权的实现步骤，写明文件和源端动画行为；不只改 resolve_by 让债务闸放行
来源：1 张卡，1 个应用
