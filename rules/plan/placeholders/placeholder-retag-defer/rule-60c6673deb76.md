# packet 里的 AC 因写权不足做不了时按阻塞范围缺口上报，closer 派有写权的人修，不只记 deferred

审的是：计划与派工
触发（任一种）：
- 读到：slice 的返回信封里把本 packet 的 AC 判为「跨切面，交主题 slice / group-closer」，只列为风险；写错的样子：closer 派工或迁移报告写「本组不做，记入 deferred」，该 AC 没有指派执行者，也没有补写权或补 packet
适用范围：slice 实现与收尾阶段，处理本 packet 内因写权不足没做完的 AC
做法：
- slice 在返回里按阻塞的范围缺口上报：写明缺哪个文件的写权，请求补写权或补 packet
- closer 收到这类缺口时派给有写权的 repair worker 并写明文件范围，不只记 deferred
