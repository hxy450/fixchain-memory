# 页面转换先于多语言服务时，先登记「页面文案接入 i18n t()」的 FWD-REF 再写字面量

审的是：计划与派工
触发（任一种）：
- 读到：源页面文案来自运行期 i18n 键（如 i18next 的 `t('…')`），页面 spec 写语言切换后刷新全部文案；目标端的 i18n 服务由后续切片提供；通用规范要求合法延期必须是已登记的占位，「待接入 xxx 后替换」式散文一律 FAIL；写错的样子：placeholder-registry 新登记的 P-ID 里没有页面文案接 i18n 的一行，页面里只有「i18n 服务接管前先用字面量」的散文注释
适用范围：页面 UI 转换阶段，多语言服务由后续切片实现、页面先行转换时
做法：
- 可以先用单一语言字面量，但写 marker 前在 placeholder-registry 登记 `FWD-REF`：内容写「页面文案接入 i18n 服务 t()」，location 指向文案键表或页面，resolve_by 指向 i18n 切片或页面接线步骤
