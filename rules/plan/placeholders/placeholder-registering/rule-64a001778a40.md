# 计划让找不到目标的点击登记 pending/forward-ref 时，改成实现任务，空点击记为未对齐

审的是：计划与派工
触发（任一种）：
- 读到：规格里每个可点击入口已有源码目标（WebView 页 URL、详情页参数）；写错的样子：计划写「找不到目标时登记 pending/forward-ref」，或占位登记里登记的是可见入口的点击处理（`FWD-REF` 编号），回报里概括成「点击语义已对齐」
适用范围：计划、占位登记和回报里涉及页面可见入口点击处理的条目
做法：
- 计划里每个可见入口写成一项实现任务，带上规格里的目标页、URL 和参数，不给「登记 pending/forward-ref」这条出路
- 点击处理函数为空（只有 return 或 FWD-REF 注释）的入口一律记为未对齐，回报里逐项列出入口名，不用「点击语义已对齐」概括
来源：1 张卡，1 个应用
