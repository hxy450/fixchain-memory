# 源码已写明、ArkUI 能直接实现的行为不登记 forward-ref-uncertain，按源码实现

审的是：计划与派工
触发（任一种）：
- 读到：页面规格标 Confidence: medium；源码已写明这项行为（如 collapsedFraction 连续折叠），pitfall 条目也给了 ArkUI 的实现方向；写错的样子：占位登记或代码注释里出现 `UNC` 编号的 forward-ref-uncertain 条目（如「// TODO: …-UNC-… this page approximates it」），登记的是源码已写明的行为，理由是 confidence medium 或「与兄弟页一致」
适用范围：界面转换时登记 forward-ref-uncertain 占位的那一步
做法：
- forward-ref-uncertain 只登记输入确实定不下来的值（如合成快照缺 bounds 时的尺寸）；源码写明、ArkUI 能实现的行为当场按源码实现，删掉对应 UNC 条目和 TODO
- 页面 confidence=medium 不要求产出 UNC 标记；引用 pitfall 条目时核对它给的修复方式和自己的实现一致
