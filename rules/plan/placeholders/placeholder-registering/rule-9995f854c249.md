# FWD-REF 和登记里引用的源方法名要读过完整定义，不写拼出来的名字

审的是：计划与派工
触发（任一种）：
- 读到：源码里要移交的判断或动作调用了某个方法，查的时候 grep 只命中一行分支（如菜单分支里的那一行调用）；写错的样子：`FWD-REF` 说明或登记表（registry）里写的源方法名在源码里不存在（由两个真实方法名拼成），或只写了动作的方法、漏了可见性判断的前置条件
适用范围：写移交项和占位登记、引用源方法说明下游要实现什么时
做法：
- 写 `FWD-REF` 或登记项前，读完被引用方法的定义和调用处前后的代码（不只看 grep 命中的那一行），写源码里真实存在的类名加方法名
- 同一功能的可见性判断和点击动作各写各引用的源方法，可见性判断里的前置条件一并写上
