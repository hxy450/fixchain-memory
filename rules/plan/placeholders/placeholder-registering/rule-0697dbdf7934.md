# 跳转先用同形本地参数类时，FWD-REF 写明收口改为 import 目标页导出的参数类

审的是：计划与派工
触发（任一种）：
- 读到：写跨页跳转时目标页由别的 converter 并行生成，它的参数类还不能 import；写错的样子：跳转类 FWD-REF 只写「目标页注册后确认路由名与参数字段」「生成后路由名生效」，没写收口时要改为 import 目标页导出的参数类
适用范围：页面转换阶段写跨页 pushPathByName、目标页参数类尚不可 import 而先写同形本地类并登记 FWD-REF 时
做法：
- FWD-REF 里写明：收口时删掉本地同形类，改为 import 目标页导出的参数类（写出类名），字段按源路由参数名（写出字段名）；不只写确认路由名
来源：1 张卡，1 个应用
- case-9d077ec16cc976090144（real-estate-hmos）：做法第 1 步 ← 建议 1
