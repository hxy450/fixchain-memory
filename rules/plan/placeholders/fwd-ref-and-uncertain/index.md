# 占位登记里的前向引用和不确定项

agent 会看到什么：规格或派工里有由后续切片提供的依赖、用自拟正则近似的校验，交回的占位登记里缺前向引用条目，或 UNC 不确定项的说明只有猜测

## 规矩

- rule-d26a776d234f｜协议 URL 等依赖资源由后续切片提供时，保留入口并登记前向引用到提供方切片｜读到：规格或派工说明协议 URL（或网页页）由后续功能切片提供，当前切片要实现隐私弹窗；写错：占位登记和交接项里没有协议入口这一条，没有指向提供 URL 那个切片的前向引用；弹窗里的入口被静默省略
- rule-185982d6d3d1｜校验正则登记为不确定项前，先用各分支代表输入对照源端，说明里写具体会判错的输入｜读到：源端用平台正则常量（如 Patterns.WEB_URL）做校验；写错：占位登记里把自拟正则登记成 `UNC` / forward-ref-uncertain 的「简化等价式」，说明只列猜测的差异、没写具体会判错的输入；或被改判为「近似方案已实现并确认」而没有输入对照记录
