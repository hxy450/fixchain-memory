# 协议 URL 等依赖资源由后续切片提供时，保留入口并登记前向引用到提供方切片

审的是：计划与派工
触发（任一种）：
- 读到：规格或派工说明协议 URL（或网页页）由后续功能切片提供，当前切片要实现隐私弹窗；写错的样子：占位登记和交接项里没有协议入口这一条，没有指向提供 URL 那个切片的前向引用；弹窗里的入口被静默省略
适用范围：隐私弹窗这类页面依赖的资源（协议 URL、网页页）尚未就绪时的占位登记和交接
做法：
- 在占位登记里写一条前向引用：入口位置（隐私弹窗的两个协议入口）、缺的资源（服务协议 URL、隐私政策 URL）、提供方切片；代码里入口保持可点击，不因资源未到而省略
来源：1 张卡，1 个应用
