# 布局里 gone 的元素与规格明示的可见元素冲突时登记待核，不写平台不显示

审的是：计划与派工
触发（任一种）：
- 读到：框架布局 XML 里某元素 android:visibility="gone"，而规格或派工明示要有这个可见元素（如「标题线」）；写错的样子：登记项写「平台不显示」「Material 无标题分隔线」后不渲染；或下游没有新证据就把 UNC 待核项改成「确认不补」
适用范围：按框架布局资源复刻平台控件、登记待核项和处理上游待核项时
做法：
- 先查该元素的运行期显示条件（框架源码里改写它可见性的那段）；查不清就保留为 UNC 待核并要求实测，不写成「平台不显示」
- 下游接手时，没有新证据不把待核项改成「确认不补」
针对本应用要查的：
- gone 元素的运行期显示条件：Android SDK 框架源码里使用该布局的类（如 com.android.internal.app.AlertController 的 setupView）中按 id 改 setVisibility 的地方；读出在哪些槽位组合下设为 VISIBLE，按组合分别写进契约
