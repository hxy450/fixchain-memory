# 占位登记里库行为不确定的 UNC 项，不以「解析侧容忍」「无相等性断言」自行宣告 resolved

审的是：计划与派工
触发（任一种）：
- 读到：占位登记里有一条 UNC 项，写着库内行为不可见、此处先固定某种形态，交后续切片确认；写错的样子：后续切片的报告在 uncertain_regions_resolved 里列出这条 UNC，理由是「解析侧多形态容忍消化」「全工程无跨栈相等性断言」，没有用库真值核对
适用范围：后续切片清偿占位登记里库行为不确定的 UNC 项时
做法：
- UNC 项只有拿库真值核对过输出才标 resolved；没有真值时保持 registered 并写明缺什么
