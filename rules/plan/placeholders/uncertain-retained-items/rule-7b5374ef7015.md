# 派工里对已登记的近似项不预写「保留」，要求执行者对照同工程已有实现复核后再裁决

审的是：计划与派工
触发（任一种）：
- 读到：决策台账或登记里已有 retained 近似项（P-S 编号的「无对应 / 近似」登记）；写错的样子：slice 工单或二次审视的派工里对这项直接写「……近似——保留」，没要求执行者复核可行性
适用范围：派发 slice 工单或二次审视时，涉及已登记为降级或近似的条目
做法：
- 派工里对每个已登记的近似项写明「对照同工程已有实现（如别处已用的回文 repeating 渐变）复核可行性后再裁决保留或改写」，不预写结论
