# 占位登记带明确升级条件且条件已成立时，升级实现并改造先前页面，不登记为 retained

审的是：计划与派工
触发（任一种）：
- 读到：派工里 `UNC` 占位的处置规则带升级条件（如「AVPlayer 缓冲回调可用则升级真实实现」），执行者已确认该能力可用；写错的样子：决议或登记写成「`UNC` … retained：先前页面为既定架构，本 slice 不推翻」，可实现的 AC 继续保留为占位
适用范围：写 source-notes、决策记录和占位登记，处置带升级条件的 uncertain 占位时
做法：
- 核对占位登记里的升级条件；条件成立就把该项登记为升级，写明本次改造的范围包括先前用同一占位写法的页面，不以「不推翻先前架构」为由保留 retained
