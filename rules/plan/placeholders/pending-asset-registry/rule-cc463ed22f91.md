# 源图远小于目标显示区时，交付说明把它列为待设计方提供的大图，不以插值放大充当正式资源

审的是：计划与派工
触发（任一种）：
- 读到：源端只有远小于目标显示尺寸的位图（如 72px 对 450px 显示区）；写错的样子：交付说明写「72px→1024px 放大，保留透明背景，符合规范」，没把源图分辨率不足列为待确认或待提供的资源
适用范围：资源迁移交付时，源端位图分辨率达不到目标规范的显示尺寸
做法：
- 交付说明里单列一项：哪些资源源图分辨率不足，需设计方提供矢量或大图，并附规范原文参数（如显示 450×450px、资源 1024×1024px 透明图层）
- 插值放大的图只能作占位，不在说明里写成合规的正式资源
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 前景图：图标显示大小为 450×450px，资源大小为 1024×1024px 的透明图层；背景图：大小为 1024×1024px：要附在待提供项里的规范参数（出处：module-configuration-file.md，shortcuts标签）
