# 登记资源为 pending 前在写入时刻重列资源目录，沿用别人的 pending 先执行其触发条件

审的是：计划与派工
触发（任一种）：
- 读到：占位登记表里有资源未就绪的 pending 条目（如 `P-RES-ASSET-…`，触发条件「某字体就绪」）；写错的样子：登记表把已经在 rawfile/fonts 下的字体登记成待定，或沿用这类条目时没执行它的触发条件
适用范围：页面转换阶段登记或沿用 resource-pending-asset 这类资源占位条目时
做法：
- 登记 resource-pending-asset 前，在写入时刻重新列出目标资源目录（如 ls entry/src/main/resources/rawfile/fonts），文件已在就不登记
- 沿用别人登记的 pending 条目前，先执行它的可机读触发条件；条件已满足就按资源已就绪处理
来源：1 张卡，1 个应用
