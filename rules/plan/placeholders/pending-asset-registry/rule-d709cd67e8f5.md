# 确需延后接线的位图层，移交登记写明 owner 和可机械检查的断言，不只写「资产就绪」

审的是：计划与派工
触发（任一种）：
- 读到：派工规则把 resource-pending-asset 定义为「fallback 资产引用加 marker」，代码里留了 `FWD-REF` 资产类登记；写错的样子：移交或占位登记行的 owner / resolve_by 留空，触发条件只写「资产就绪」「就绪后补 Image 层」，没有能机械检查的断言
适用范围：转换阶段确需把位图层的接线延后、登记成资产类移交项时
做法：
- 登记行写明 owner（由哪个批次或角色接线）和机械断言，例如「全工程存在 $r('app.media.<资源名>') 引用」或指定某个 slice 必须渲染该图
