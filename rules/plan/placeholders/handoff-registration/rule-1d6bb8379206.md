# 转换者确认行为归宿主文件实现时，登记 FWD-REF/handoff，不只写头注释

审的是：计划与派工
触发（任一种）：
- 读到：规格要求某行为由宿主页实现（如「宿主页 onBackPress 需优先判定侧栏开合」）；写错的样子：转换产物只在头注释写「归宿主 onBackPress」，FWD-REF / handoff 登记里没有指向宿主文件的条目
适用范围：界面转换阶段，转换者判定某行为不在本文件实现、归宿主或其他文件时
做法：
- 登记一条 FWD-REF（或 handoff），写明要实现的行为、源码出处和宿主文件，让宿主文件的写者能收到
