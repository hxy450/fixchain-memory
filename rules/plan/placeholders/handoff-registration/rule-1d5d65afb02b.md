# AC 的目标符号落在他切片或共享文件时，登记 FWD-REF 或 HANDOFF，不写散文

审的是：计划与派工
触发（任一种）：
- 读到：规格的 AC 把入口标在别的切片或共享文件的符号上（「标:某页面 VM 的长按处理方法」），占位协议规定跨文件移交须登记 FWD-REF / HANDOFF、散文注释一律 FAIL；写错的样子：只在文件头写「长按手势识别归某 VM」这类散文，或推理里决定 Skip；依赖他方状态的方法写成 `return false; // … 注入后升级` 的散文桩，registry 里没有对应 P-ID
适用范围：切片实现阶段，AC 的实现跨切片或落在共享文件时
做法：
- 按占位协议登记 FWD-REF 或带 verify 的 HANDOFF，写清 owner、入口签名和门控条件（如模式、分辨率、RAW 限制）
- 依赖他方状态的方法同样登记，不写「注入后升级」式散文桩
