# 要靠别的文件或 slice 补调用点才生效时，登记 HANDOFF，不用散文注释代替

审的是：计划与派工
触发（任一种）：
- 读到：占位规则写着要靠别处调用点才算完成的，须写 `// HANDOFF: owner/what/verify` 并登记；写错的样子：文件头只写散文说明“转发由某入口装配或接线阶段决定”，或报告里只列 open_question，没有 `// HANDOFF:` 行，登记表里也没有对应条目
适用范围：页面实现阶段，功能要靠另一个文件或另一个 slice 补调用点才能生效时
做法：
- 写 // HANDOFF: owner=<调用点所在文件所属的 slice>、what=<要补的调用>、verify=slice:<N> 或能区分实现的 grep 断言，并登进移交登记
- 断言难写时改用 slice 级断言，移交本身保留，不因“不可机械实现”删掉
