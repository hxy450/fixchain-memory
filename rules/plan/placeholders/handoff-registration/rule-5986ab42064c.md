# 内容组件发现宿主缺遮罩、焦点兜底等承载参数时，登记占位并写入确定值

审的是：计划与派工
触发（任一种）：
- 读到：内容组件由宿主页的 openCustomDialog 承载，宿主那边的承载参数（遮罩、打开后聚焦）还没设；写错的样子：宿主侧要补的参数只写在转换报告的 Handoff 表或 handback 建议里，占位登记里没有对应的占位（如 P-S4 一类），后续宿主接线切片的派工也没带上
适用范围：内容组件和宿主页分属不同切片、内容组件的转换者发现宿主缺参数时；主线程收到 handback 里的宿主侧建议时
做法：
- 按工程约定登记占位：resolve_by 指向宿主接线切片，写入确定值（如 maskColor '#99000000'、打开后对输入框 requestFocus）
- 主线程把 handback 里的宿主侧建议转进对应切片的派工或账本
