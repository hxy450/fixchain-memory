# Base 自检把文档里「由 X 调用 / 待闭环」逐条对上源码 HANDOFF 或 registry

审的是：计划与派工
触发（任一种）：
- 写错的样子：handoff 文档或交付说明里有「由启动装配 owner 调用」「待闭环」「Suggested P-ID Allocations…未写入源码 marker、未修改共享 registry」，自检却以 HANDOFF 计数为 0 报通过
适用范围：基础模块交付前的自检和 handoff 文档
做法：
- 把文档中每条「由 X 调用 / 待闭环 / Suggested P-ID」与源码 HANDOFF 或 registry 条目逐一对应，对不上的补成源码 HANDOFF
- HANDOFF 计数为 0 不当作干净的证据，先确认没有未机械化的跨文件义务
来源：1 张卡，1 个应用
