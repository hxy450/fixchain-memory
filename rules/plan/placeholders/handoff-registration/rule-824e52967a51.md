# 上游报告点名“由某 slice 决定”的问题，要写进该 slice 的派工

审的是：计划与派工
触发（任一种）：
- 读到：上游报告的 open_question 或子文件头写着某项转发“由某入口装配 / 接线阶段决定”；写错的样子：被点名 slice 的派工里没有这一项，只要求直嵌子组件且“其余逐字不动”
适用范围：接线与编排阶段，上游报告留下指向后续 slice 的未决问题时
做法：
- 把该问题写进被点名 slice 的派工：要实现的转发（如 @Entry 页 onBackPress 转调子组件的返回裁决）和怎么验收；实现不了的作为阻塞项上报
