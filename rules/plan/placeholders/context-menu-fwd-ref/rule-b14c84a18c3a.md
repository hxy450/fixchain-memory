# 页面规格写了「长按 ContextMenu」而交互归功能切片时，登记 FWD-REF 占位，不写成长按进多选

审的是：计划与派工
触发（任一种）：
- 读到：页面规格的菜单或导航表写「长按 ContextMenu」，交互实现留给后面的功能切片；写错的样子：占位登记里没有这一长按上下文菜单的 FWD-REF 项，页面代码里长按已照兄弟页写成直接进入多选的真实实现
适用范围：UI 转换阶段转页面、长按交互按计划留给功能切片实现时的占位登记
做法：
- 在占位登记里为这一交互登记一条 FWD-REF，写明源端是 onCreateContextMenu 弹出的上下文菜单、由哪个功能切片实现；页面上的长按只留占位，不照兄弟页接成进入多选
