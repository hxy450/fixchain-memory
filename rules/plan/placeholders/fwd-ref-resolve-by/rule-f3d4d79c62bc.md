# 占位推给后续批次时，标成阻塞项并核对派工里有承接它的实际批次

审的是：计划与派工
触发（任一种）：
- 读到：实现报告说某分支依赖另一片或共享组件扩展才能完整，先降级实现并登记占位；写错的样子：占位登记写着推给某个后续批次（如「组件完整化」批次），派工计划里没有这个批次的实际派工；报告没把它标成阻塞项、没写必须的派工
适用范围：实现阶段登记的、依赖其他片或共享组件扩展的占位，及派发者对这类占位的核对
做法：
- 这类占位在报告里标为阻塞项，写明必须的派工（哪个组件扩展什么参数）
- 派发者逐条核对此类占位都有实际批次承接，没有的补派工
未核实：那个批次为何从未派发，卡里没有追到派发者记录
来源：1 张卡，1 个应用
