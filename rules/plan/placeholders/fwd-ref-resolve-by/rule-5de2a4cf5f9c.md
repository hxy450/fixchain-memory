# 共享组件的服务占位，resolve_by 指向规格里真正拥有该服务的 feature 切片

审的是：计划与派工
触发（任一种）：
- 读到：spec 里某项服务（如图片上传）归某个 feature；实现共享组件时这项服务还没就绪；写错的样子：占位登记的 resolve_by 指向一个不拥有该服务的切片，或者写成「由各宿主页承接」，把职责下推给每个宿主
适用范围：共享组件依赖的服务尚未就绪、要登记占位时
做法：
- 按 spec 找到拥有这项服务的 feature 切片，占位的 resolve_by 写那个切片
- 占位说明里写明接通后由共享组件内部完成，不写成由宿主页承接
来源：1 张卡，1 个应用
- case-f63ccb39dd60e2abb04b（jerboa）：做法第 1 步 ← 建议 3；做法第 2 步 ← 建议 3
