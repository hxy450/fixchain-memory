# 收口把文案类 P-ID 翻成已解除前，除了 marker 消失，还要查页面接了翻译服务、没留固定语言字面

审的是：计划与派工
触发（任一种）：
- 读到：worker 回执报某个文案类 P-ID 已解除，页面上的 FWD-REF marker 已消失；写错的样子：收口只核了 marker 消失就把它翻成已解除，closer 的接线清单里没有这一页的翻译接线
适用范围：主线程或 closer 收口时核验 worker 报的 resolved 前向引用
做法：
- 对文案类 P-ID，除了看 marker 是否消失，还要检查页面是否 import 了翻译服务、是否还残留固定语言的字面文案；有残留就不翻已解除，列进 closer 的接线清单
