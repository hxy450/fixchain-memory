# 占位登记同时列「引导」和源端「设置成功」Toast 时，按规格决策只留引导再解除

审的是：计划与派工
触发（任一种）：
- 读到：规格或已批决策写明能力降级为保存到相册＋引导手动设置，不产出「已设置」状态；写错的样子：占位登记或 FWD-REF 的同一项同时列出「引导…」和源端「Toast 设置成功/失败」回执，没注明 Toast 已被决策取代；或这一项已解除，而对应入口成功路径没有引导、仍有与决策冲突的成功文案
适用范围：占位登记、移交项里由能力降级决策改了产出语义的那些项，以及解除它们时
做法：
- 登记项以 feature 规格和决策为准：源端成功回执注明被引导取代，逐项落实到代码后再解除占位
- 解除前核对并写明两点：成功路径出现了引导；没有与决策冲突的成功文案
