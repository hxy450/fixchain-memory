# 发现同形参数类不命中后全工程配对修完，点名的统一项未做完不标 resolved

审的是：计划与派工
触发（任一种）：
- 读到：占位登记点名了上游参数类统一项（owner、范围写明要与 canonical 参数类统一）；写错的样子：收尾时把这一项记进 resolved，移交说明只列了其中一部分；或已确认打不开的跳转只记 to-verify，交给生成期不运行的验证阶段
适用范围：收尾阶段一旦发现同形参数类 instanceof 不命中时，回执和移交登记里的处理
做法：
- 全工程配对检查：grep 'class \w*Param' 和 pushPathByName 找出所有生产端，逐一对照目标页 onReady 接受的类型，已确认断裂的路径在同一轮修完
- 登记点名的上游统一项没有逐一完成的不标 resolved，移交说明逐项列全；已确认的断裂不能只记 to-verify
