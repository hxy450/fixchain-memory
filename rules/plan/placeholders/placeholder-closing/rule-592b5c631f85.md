# 收口跨切片移交项时每个子要求都落地才标已解除，缺一项不翻 resolved

审的是：计划与派工
触发（任一种）：
- 读到：brief 的一条移交项里写了几件事，例如「订阅补线」和「图片加载经带进度的下载函数接线」；写错的样子：移交项被记为已解除（resolved），实际只落了其中一件：只写了订阅，没有任何生产者发该键的事件
适用范围：收尾者或接手的切片收口跨切片移交项时
做法：
- 把移交项拆成逐个子要求，各自在代码里核对已落地（订阅方和生产方都在），全部落地才标 resolved；缺的继续留在移交登记里
来源：1 张卡，1 个应用
