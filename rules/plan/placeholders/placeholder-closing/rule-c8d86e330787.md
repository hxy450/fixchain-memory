# 代码里仍有 TODO 或降级注释时，不把 uncertain 占位按降级现状翻成 resolved 关单

审的是：计划与派工
触发（任一种）：
- 读到：目标代码里对应位置还留着 TODO / 降级注释；写错的样子：登记表里把这条 `UNC` 占位 retag 后「按降级形态关单」或标 resolved，以避开债务闸，代码没改
适用范围：收尾或登记关单阶段处理 uncertain 占位时
做法：
- 只有源行为已实现，或有明确接受该偏差的决定时才关单；否则移交给能改代码的实际 owner
来源：1 张卡，1 个应用
