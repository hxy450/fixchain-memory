# 接线或路由核验不能凭被调方法名或注释判定已接通，要打开方法体确认服务调用和收口

审的是：计划与派工
触发（任一种）：
- 读到：占位登记把某个页面入口对应到源端的整条业务链（P-S6- 一类编号的条目），被调方法的注释写「由 … busy 态承接」；写错的样子：接线或路由核验记录只按方法名把入口记成已接通的完整链路，没有写服务调用和收口在方法体的哪里
适用范围：接线、路由核验和占位登记的回填
做法：
- 核验每条接线时打开被调方法体，记下服务调用和终态收口所在的位置；找不到就记为未接通，不按方法名或注释记成已接通
