# 收口跳转类 marker 前核对发送方 new 的就是目标页 instanceof 的导出类，不只看路由名

审的是：计划与派工
触发（任一种）：
- 读到：占位登记里同类跳转的先例写着「改用目标页导出的参数类 | resolved」；发送页的参数类和目标页 instanceof 的类名不同；写错的样子：跳转类 marker 被改写成「已接线」「resolved」「目标页已注册 + 参数字段对齐」，而发送页 new 的仍是本地 class，或类名与目标页 onReady 里 instanceof 的不同
适用范围：跨文件接线收口阶段解除跳转类 FWD-REF 或占位登记时
做法：
- 解除前打开目标页 onReady：确认发送方 new 的类和 instanceof 的类是同一个 import 进来的导出符号、字段名一致；发送方仍是本地 class 或类名不同，先改为 import，再把 marker 标为已接线
