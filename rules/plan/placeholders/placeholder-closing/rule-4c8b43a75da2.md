# 解除 FWD-REF 前确认被调方真有登记的语义，不用名字相近的接口顶替后标已解除

审的是：计划与派工
触发（任一种）：
- 读到：registry 里的占位写着要由被调方的某个能力接管（如「连续快拍停止入口接管，松手即停」），被调文件里找不到这个能力；写错的样子：接线者把占位改成调用名字相近的接口（如重复拍照的取消方法）并在 registry 标为已解除
适用范围：group-closer 接线阶段解除跨切片占位时
做法：
- 解除前在被调文件里确认有 registry 描述的那个语义；找不到时保留或升级这个缺口，不用名字相近的接口顶替
来源：1 张卡，1 个应用
