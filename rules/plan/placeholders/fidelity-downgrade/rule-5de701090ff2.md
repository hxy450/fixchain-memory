# 转换报告不把简化的动效记成「等价」「spec 认可」，与先例冲突时记成待修差异

审的是：计划与派工
触发（任一种）：
- 读到：规格或映射参考写「AnimatedVisibility expand/shrinkVertically → animateTo + transition（高度/透明）」，工程里已有页面只用透明度转场；写错的样子：转换报告或代码注释把只做透明度 / scale(y) 的转场写成「展开收起动画等价」「spec 转换决策认可」「同族先例」「documented as 降级」，没有列成待修差异
适用范围：转换报告、移交项和差异登记里写动效实现状态的那一项
做法：
- 已有页面的写法和本页规格、源码冲突时以规格和源码为准，把先例记成待修差异；输出前逐个核对每个 AnimatedVisibility：高度是否随动画变化、切换时是否在 animateTo 里，没做到的如实写成差异
