# 单层 ShadowOptions 近似 Compose 平台阴影时，登记为需截图校准的视觉近似项

审的是：计划与派工
触发（任一种）：
- 读到：源端用 Compose elevation 投影（Modifier.shadow、Surface elevation）；写错的样子：报告的近似项登记里没有这处阴影，代码注释把单层 .shadow 写成与 elevation「等价」的映射
适用范围：界面实现阶段交回的报告里，登记视觉近似项、待截图校准项的那一节
做法：
- 报告里为每处 elevation 阴影登记一项「需截图校准的视觉近似」：元素、源端 elevation、目标用的 ShadowOptions 写法；注释写成近似，不写等价
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- light_y 0dp、light_z 500dp、light_radius 800dp；ambient_shadow_alpha 0.039、spot_shadow_alpha 0.19：平台阴影由环境光和主光两层组成，主光在屏幕顶端上方，投影随元素位置变化；单层 ShadowOptions 只能近似（出处：Android SDK 平台资源 data/res/values/dimens.xml，light_z、ambient_shadow_alpha、spot_shadow_alpha（按应用的 compileSdk 取对应平台））
- 换算单位后屏幕上部的投影仍比源端偏重 1.5–2.5 倍，按主光位置拟合后仍有偏差：固定映射只能近似，要靠截图校准（出处：卡里修好并验证过）
