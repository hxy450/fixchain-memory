# 可折叠文本组件只登记了溢出近似一项时，把链接、overflow、按压、容器色逐项实现或登记

审的是：计划与派工
触发（任一种）：
- 读到：源 Compose 可折叠文本组件同时有 onTextLayout 溢出判定、LinkAnnotation 链接、maxLines 未设 overflow、toggleable 按压反馈和容器色；写错的样子：占位登记里这个组件只有「溢出判定用字符数阈值近似」一项；链接、overflow、按压反馈、容器色既没实现，也没有登记和注释
- 读到：共享组件参考了页面里已有的同类实现；写错的样子：共享组件照搬了页面实现里的近似和遗漏（字符数阈值、Ellipsis、纯文本、无按压态），共享组件下没有重新登记这些近似和原因
适用范围：把源端可折叠文本这类多项契约的组件迁成 ArkUI 组件或共享组件时，占位和近似的登记
做法：
- 按源组件列逐项契约：溢出判定依据、文本注解/链接、overflow 默认值、交互反馈、容器色；每项要么写目标实现，要么登记成一条占位并写明原因
- 参考已有页面实现时，以源文件为契约逐项核对；复制过来的近似连同原因在共享组件下登记，不把页面里的遗漏一并复制
