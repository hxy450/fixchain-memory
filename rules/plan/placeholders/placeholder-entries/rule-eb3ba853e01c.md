# 占位登记写「等价于源端谓词」时，列出谓词的完整条件或定义它的 AC

审的是：计划与派工
触发（任一种）：
- 读到：页面转换时留了要在接线阶段闭合的占位，内容是复刻源端某谓词；写错的样子：占位登记的条目只写「等价于源端某谓词（函数名）」，没列出谓词的完整条件，也没写定义它的 AC 编号
适用范围：登记要由后续切片闭合的「等价于源端谓词」类占位时
做法：
- 占位条目里写全谓词的条件（逐条），或写「条件见 <规格>-AC<编号>」，让闭合的人不用凭记忆
