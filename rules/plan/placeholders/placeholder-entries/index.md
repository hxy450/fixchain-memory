# 占位登记里的条目

agent 会看到什么：占位登记里某组件只记了一项近似（如溢出判定用字符数阈值），源组件的其他能力（链接、overflow、按压反馈、容器色）既没实现也没登记；或者条目只写「等价于源端某谓词」，没列条件和出处

## 规矩

- rule-d49ed82866f3｜可折叠文本组件只登记了溢出近似一项时，把链接、overflow、按压、容器色逐项实现或登记｜读到：源 Compose 可折叠文本组件同时有 onTextLayout 溢出判定、LinkAnnotation 链接、maxLines 未设 overflow、toggleable 按压反馈和容器色；写错：占位登记里这个组件只有「溢出判定用字符数阈值近似」一项；链接、overflow、按压反馈、容器色既没实现，也没有登记和注释
- rule-eb3ba853e01c｜占位登记写「等价于源端谓词」时，列出谓词的完整条件或定义它的 AC｜读到：页面转换时留了要在接线阶段闭合的占位，内容是复刻源端某谓词；写错：占位登记的条目只写「等价于源端某谓词（函数名）」，没列出谓词的完整条件，也没写定义它的 AC 编号
