# 登记或移交前向占位时，resolve_by 要指向账本里确实计划产出该工件的切片

审的是：计划与派工
触发（任一种）：
- 读到：计划和各切片账本里没有任何切片承接该工件（grep 计划与工程都找不到）；写错的样子：占位登记（FWD-REF、P-S… 编号）的 resolve_by 写成自身切片的某一步，或指向一个账本和派工里都没有这一项的切片
- 写错的样子：closer 把占位改成 resolve_by=另一切片，接收切片的账本和派工里却没有这一项，派工还写「已收口，禁碰」
适用范围：切片 worker 登记前向占位、closer 移交占位时的占位登记、账本和派工
做法：
- 登记前在账本里找到实际计划产出该工件的切片，resolve_by 写那个切片和步骤
- 计划里没人承接、而实现只依赖本地平台 API 或现有端点模式时，不登记占位，在本切片直接实现
- closer 把占位移交给其他切片时，同步写进接收切片的派工清单和账本
