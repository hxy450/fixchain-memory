# 为入口级门控留占位注释时，照抄源回调的适用范围和例外动作

审的是：计划与派工
触发（任一种）：
- 读到：源端 onActionItemClicked 或基类回调入口对除少数例外外的全部动作统一做门控；写错的样子：页面里的占位注释（FWD-REF 等移交项）把门控写成只针对删除、清空等个别动作，没写“除哪些动作外全部动作”，也没写源回调名
适用范围：页面壳转换时为 CAB、菜单分发写移交占位，留给后续切片接门控时
做法：
- 占位注释照抄源回调的适用范围：写“除 <例外动作> 外的全部动作在入口先过门控”，并写明源回调函数名和位置，不把入口级门控缩写成个别动作
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 接线的人照着缩窄后的占位注释，只把门控接到了删除和清空两个分支：占位写窄的后果（出处：卡里修好并验证过）
