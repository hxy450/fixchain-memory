# 切片不做的来源分支只写在说明里时，要登记 FWD-REF 或占位并在回执列出

审的是：计划与派工
触发（任一种）：
- 读到：源端目标页的结果处理有按来源的多个分支（setResult 回传、跳下一页）；写错的样子：说明或源码笔记里写了「选中后去向由后续切片决定」一类的话，回执里 `resolved_fwd_refs` 写无，FWD-REF 和占位登记里都没有这个分支
适用范围：功能切片只实现了共享目标页的部分来源分支、其余留给后续切片时的登记和回执
做法：
- 本切片不实现的每个来源分支登记一条 FWD-REF（或占位），写明源端的分支条件和去向（哪个 extra 为何值时回传、跳哪一页），并在回执的 FWD-REF 列表里列出
来源：1 张卡，1 个应用
- case-914a0da87d6ea90ab419（android-panorama-map-vest7）：做法第 1 步 ← 建议 1
