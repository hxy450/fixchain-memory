# 页面转换把跳转延后给接线时，占位登记和事件注释里写明规格给出的目标页

审的是：计划与派工
触发（任一种）：
- 读到：UI 规格的「导航关系」表或源端监听器的 Intent 已给出触发后的目标 Activity；写错的样子：导航类前向占位的 registry 行、`FWD-REF` 标记和事件枚举注释只写了事件名和 resolve_by，没写目标页
适用范围：页面转换阶段按协议只产出子组件、把导航延后到接线步骤时的占位登记
做法：
- 在 registry 行、`FWD-REF` 标记和事件枚举注释里写明「触发值 → 规格页号 目标页名」，让只读账本的下游接线者也能拿到目标
来源：1 张卡，1 个应用
- case-5dc757ad90507a893798（话费流量查询助手）：做法第 1 步 ← 建议 3、诊断
