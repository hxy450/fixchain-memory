# 登记跨切片的拍照入口通道时，按源端调用链指向编排器的同一入口，不指向对焦后的拍照步

审的是：计划与派工
触发（任一种）：
- 读到：源端按键（音量键等）和屏幕快门都进入同一个「按下拍照」入口函数，由它做定时、重复、全景等判断；写错的样子：占位登记（P-S… 行）把按键拍照通道指向引擎里对焦后才执行的拍照钩子，接线时按键直接拍照，跳过定时 / 重复 / 全景判断
适用范围：在占位登记或移交项里登记跨切片的入口通道时
做法：
- 照源端调用链登记：几个入口在源端汇到同一个函数时，通道都指向编排器里对应的那个入口，不指向它下游的对焦后拍照步骤
