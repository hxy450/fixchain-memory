# 点击效果留作 FWD-REF 时，标记和注册表行写进已读到的源端确定值和出处

审的是：计划与派工
触发（任一种）：
- 读到：源端点击里有确定值，如 uriHandler.openUri("https://…") 的固定网址或常量；写错的样子：页面里的 FWD-REF 标记和占位注册表那一行只写「更新卡外链」一类泛称，没有确切网址或常量，也没有源码出处
适用范围：UI 转换阶段把外链、常量类点击效果留作前向引用、交给后续切片补值时
做法：
- FWD-REF 标记和注册表描述里写出源端确定值原文（完整网址或常量）以及出处（源文件和行），不只写泛称
