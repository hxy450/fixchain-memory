# 延后交互的占位登记内容

agent 会看到什么：源端的点击、跳转、来源分支、外部入口和数据钩子被延后给别的切片时，FWD-REF 标记、占位登记和移交项里写了什么（槽名、resolve_by、目标页、源端行为）

## 规矩

- rule-2d33f0fda88e｜把交互留给后续切片的占位登记，写明源端行为，不只登记槽名｜读到：源 Fragment 里的交互行为（如选中后切回某个 Tab、列表为空时进入添加页）只有界面转换者读过；写错：`FWD-REF` 占位登记只有槽名和编号（如 `P-S2-007`），没写源端在这里做什么
- rule-e2ac5f6e5683｜页面转换把跳转延后给接线时，占位登记和事件注释里写明规格给出的目标页｜读到：UI 规格的「导航关系」表或源端监听器的 Intent 已给出触发后的目标 Activity；写错：导航类前向占位的 registry 行、`FWD-REF` 标记和事件枚举注释只写了事件名和 resolve_by，没写目标页
- rule-521f45235d95｜把数据接线推迟成 FWD-REF 钩子时，钩子说明里写明已读到的加载、恢复、回写行为｜读到：源端容器 Fragment 在列表加载完成的观察者里按持久化的选中项算下标再 setCurrentItem，OnPageChangeCallback.onPageSelected 里把当前项写回持久化，容器 ViewModel 组装列表时把某一项 add(0, …) 插到首位；写错：骨架里的 `FWD-REF` 注释或转换报告里的移交项只写 P-ID、resolve_by 和归属切片，钩子被概括成「数据加载」「切页后同步」，没写加载后恢复当前页、切页回写选中项、首项插入和去重这些行为
- rule-9937ae63fbce｜切片不做的来源分支只写在说明里时，要登记 FWD-REF 或占位并在回执列出｜读到：源端目标页的结果处理有按来源的多个分支（setResult 回传、跳下一页）；写错：说明或源码笔记里写了「选中后去向由后续切片决定」一类的话，回执里 `resolved_fwd_refs` 写无，FWD-REF 和占位登记里都没有这个分支
- rule-45e12d7c76b4｜页面只能经外部入口进入时，把入口声明、want 分支、参数键和参数形态作为草稿或 forward-ref 交出｜读到：页面规格的导航关系把桌面快捷方式、本地通知点击、推送深链（外部 intent 携带参数）列为本页入口，或写明快捷方式由鸿蒙侧 shortcuts 配置承担；写错：页面注释写「由基座（EntryAbility want 解析）pushPathByName 进入」，但交回的 cross_slice_edits 和 forward-ref / handoff 登记里都没有入口声明和 want 分发这一项
- rule-327d00034143｜登记或移交前向占位时，resolve_by 要指向账本里确实计划产出该工件的切片｜读到：计划和各切片账本里没有任何切片承接该工件（grep 计划与工程都找不到）；写错：占位登记（FWD-REF、P-S… 编号）的 resolve_by 写成自身切片的某一步，或指向一个账本和派工里都没有这一项的切片
- rule-72ff71ddbe15｜点击效果留作 FWD-REF 时，标记和注册表行写进已读到的源端确定值和出处｜读到：源端点击里有确定值，如 uriHandler.openUri("https://…") 的固定网址或常量；写错：页面里的 FWD-REF 标记和占位注册表那一行只写「更新卡外链」一类泛称，没有确切网址或常量，也没有源码出处
- rule-d47c4838c63d｜宿主回调留成前向引用时，登记写全参数来源、字段变换和完成后导航｜读到：源端宿主回调用编辑草稿字段做克隆，名称用 getString(R.string.…, 原名) 格式化，完成后 navigate(root) { popUpTo(root) { inclusive = true } }；写错：占位登记（P-S… 编号）的触发条件只写「可复制…并重建 list 栈」这类动作摘要，没写参数来自持久化值还是编辑草稿、名称怎么变换、完成后怎么导航
- rule-f1cbf0ccf920｜文案重取交给别的切片时，占位和交接里写出具体字段和取值函数，不只写「文案重读」｜读到：页面规格写「语言变化重读文案」，页面代码在 aboutToAppear 里用 getStringSync 取文案存进状态；写错：交接报告和占位登记只照抄通用条目「onConfigurationUpdate 重放清单（……文案重读……）→ 某切片」，没有点名哪个字段是代码取值的快照、由哪个函数重取
- rule-7af92382e4ee｜登记跨切片的拍照入口通道时，按源端调用链指向编排器的同一入口，不指向对焦后的拍照步｜读到：源端按键（音量键等）和屏幕快门都进入同一个「按下拍照」入口函数，由它做定时、重复、全景等判断；写错：占位登记（P-S… 行）把按键拍照通道指向引擎里对焦后才执行的拍照钩子，接线时按键直接拍照，跳过定时 / 重复 / 全景判断
- rule-9aacf0ffd276｜规格或账本已把外部意图入口归给别的 feature 时，不判「平台无入口」，登记 FWD-REF｜读到：决策账本或规格写意图协议（ACTION_VIDEO_CAPTURE、EXTRA_OUTPUT、EXTRA_VIDEO_QUALITY 等）由另一个 feature 实现；写错：文件头或源码笔记写「目标平台无第三方 intent 入口」「运行时无注入路径」，意图参数只留默认空的注入函数，没有登记跨切片 FWD-REF
- rule-d1859efa8707｜为入口级门控留占位注释时，照抄源回调的适用范围和例外动作｜读到：源端 onActionItemClicked 或基类回调入口对除少数例外外的全部动作统一做门控；写错：页面里的占位注释（FWD-REF 等移交项）把门控写成只针对删除、清空等个别动作，没写“除哪些动作外全部动作”，也没写源回调名
