# 把交互留给后续切片的占位登记，写明源端行为，不只登记槽名

审的是：计划与派工
触发（任一种）：
- 读到：源 Fragment 里的交互行为（如选中后切回某个 Tab、列表为空时进入添加页）只有界面转换者读过；写错的样子：`FWD-REF` 占位登记只有槽名和编号（如 `P-S2-007`），没写源端在这里做什么
适用范围：界面转换者把交互留成 FWD-REF 占位交给后续切片时
做法：
- 每个 FWD-REF 占位的说明里写出源端行为：触发条件、调用的源方法、结果（如「选城后调用源端切回天气 Tab 的方法」「列表与定位都为空时进入添加页」）
来源：1 张卡，1 个应用
- case-2906493a39c662495a11（app_hnaccurateweather_live_android）：做法第 1 步 ← 建议 5、诊断
