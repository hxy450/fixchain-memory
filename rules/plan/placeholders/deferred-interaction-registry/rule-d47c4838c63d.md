# 宿主回调留成前向引用时，登记写全参数来源、字段变换和完成后导航

审的是：计划与派工
触发（任一种）：
- 读到：源端宿主回调用编辑草稿字段做克隆，名称用 getString(R.string.…, 原名) 格式化，完成后 navigate(root) { popUpTo(root) { inclusive = true } }；写错的样子：占位登记（P-S… 编号）的触发条件只写「可复制…并重建 list 栈」这类动作摘要，没写参数来自持久化值还是编辑草稿、名称怎么变换、完成后怎么导航
适用范围：界面转换阶段把宿主的克隆、删除等回调留桩并登记为前向引用时
做法：
- 登记条目写三项：参数来自哪个状态（持久化值还是编辑草稿，含重排后的子项）；字段变换（名称用哪个带占位符的字符串资源格式化原名、子项 id 清零）；完成后导航（navigate 到根并 popUpTo 根 inclusive，即重建以根为底的栈）
