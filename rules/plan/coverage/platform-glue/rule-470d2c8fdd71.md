# 把被引用但未锚定的文件归入平台胶水或 skip-list 前，先打开本体确认没有业务调用

审的是：计划与派工
触发（任一种）：
- 读到：覆盖检查列出被引用但没有锚定到任何 feature 的源文件（如广播接收器类）；写错的样子：skip-list 里把它按引用计数归为“平台胶水”，没有核对它的回调里是否调用了业务检测或上报
适用范围：覆盖检查和跳过清单的归类时
做法：
- 归为平台胶水或写进 skip-list 前，打开文件本体，确认其中没有业务方法调用；有的改为锚定到对应 feature
来源：1 张卡，1 个应用
