# 路由 parity 校验要比对跳转前的状态写入，源端有、目标缺不能判为一致

审的是：计划与派工
触发（任一种）：
- 读到：源端跳转处理在 startActivity 之前有共享状态写入（如把播放队列交给播放器）；写错的样子：路由校验把这条路由判为一致或记成 android_source_parity wontfix，比对项只有目标页和参数，没有跳转前的状态写入
适用范围：路由校验阶段对源端和目标端跳转链路做 parity 比对、写判定和跳过清单时
做法：
- 每条路由的比对项写三栏：目标页、参数、跳转前的状态写入；源端有状态写入而目标端缺失时判为不一致，不记 wontfix
未核实：卡里只记了校验期只比目标页而漏判的经过，没有按三项比对的校验做法复核过
