# 覆盖审计判定活 ViewModel 已被承接时，逐项对照它的调用面找到具体 AC

审的是：计划与派工
触发（任一种）：
- 读到：源端 ViewModel 是活码，被 Fragment 调了多个方法（如缓存统计、清理、检查更新）；写错的样子：跳过清单或覆盖审计写「已承接」，依据只是规格范围节的对接点注释或某一条 AC，没有逐项列出调用面各方法对应的 AC
适用范围：编覆盖清单、跳过清单时，对源端活 ViewModel 是否已被规格承接的判定
做法：
- 按源端调用面逐个方法写出承接它的 AC 编号；有方法找不到 AC 的，不判为已承接
来源：1 张卡，1 个应用
