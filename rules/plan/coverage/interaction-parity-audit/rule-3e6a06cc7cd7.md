# 对齐审计遇到注释写「已裁定/集成点」的偏差，核运行行为，不一致就列为差异

审的是：计划与派工
触发（任一种）：
- 读到：目标代码注释写「裁定」「集成点」「决锚」，同时自述源码为死码（如「源码已注释为死码——按集成点接线」）；安卓源码里对应回调体为空或被注释；写错的样子：审计报告或差异清单写「属已裁定偏差，不列差异」，把这项归进已裁定项，后续修复清单里没有它
适用范围：1:1 对齐审计列差异、出修复清单时
做法：
- 对注释写明裁定的偏差，先核该裁定下的运行行为是否和安卓一致；注释自述源码为死码而目标已接活的，列为差异或单列给用户裁决，不以「已裁定」静默排除
