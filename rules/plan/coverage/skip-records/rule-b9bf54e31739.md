# 登记「无 ArkUI 等价」降级前，写明在 SDK .d.ts 里搜过的枚举或方法和结论

审的是：计划与派工
触发（任一种）：
- 读到：源端用了某种绘制能力（如 BlendMode 混合、渐变描边、渐变着色），实现者打算降级；写错的样子：降级登记写了「无 ArkUI 等价」「ArkUI 不支持…」，没写查过哪个声明文件、搜了什么；或者「保留」裁决照搬组件注释里的降级理由
适用范围：页面转换和降级登记阶段登记降级、做保留裁决时
做法：
- 登记前在 SDK .d.ts 里 grep 对应的枚举或方法（如 BlendMode、blendMode(），把搜的词、文件和结论写进登记
- 后续做「保留」裁决时复核同一条证据，不照搬组件注释里的降级理由
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- BlendMode 枚举、CommonMethod.blendMode 在 ets/component/common.d.ts：混合类能力在声明里的位置，降级前先搜这里（出处：鸿蒙 SDK 的 ets/component/common.d.ts，BlendMode、CommonMethod.blendMode）
