# 按政策排除的功能簇在计划里的去向

agent 会看到什么：决策台账把某个功能簇（如桌面 Widget）按政策排除；计划把它的 parity AC 批量打上「superseded by」决策编号的墓碑、从 plan-coverage 的批次映射里删掉，没单列 deferred 批次

## 规矩

- rule-26a9b8cab5f1｜排除决定落到计划时保留可逆性：单列 deferred 批次，不批量打墓碑删映射｜读到：决策台账把某个功能簇（如桌面 Widget）按政策排除；写错：计划把该功能的 parity AC 全部批量打上「superseded by」决策编号的墓碑，并从 plan-coverage 的批次映射里删掉
