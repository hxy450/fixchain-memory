# 被引用的 Activity 报未归属时补 page spec，不登记跳过清单

审的是：计划与派工
触发（任一种）：
- 读到：覆盖检查对截图页引用的 Activity 报 SPEC.MANIFEST_ACTIVITY_UNACCOUNTED，建议补 page spec 或锚入 feature；写错的样子：skip-list 把这些 Activity 逐条登记为「首页可达说明页，路由契约保留」「个人中心可达目标，页面视觉后续增量」来关掉阻断
适用范围：覆盖检查报 Activity 未归属、而该 Activity 被本轮范围内页面的入口引用时
做法：
- 给这个 Activity 补一份 page spec，或在引用它的 feature 里写上锚点；不用自拟的范围决策写进 skip-list 来关阻断
