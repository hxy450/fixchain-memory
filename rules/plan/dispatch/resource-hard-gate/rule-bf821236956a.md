# 资源 HARD-GATE 通过前不派页面转换器；必须并行时派工写明资源仍在迁移

审的是：计划与派工
触发（任一种）：
- 读到：执行规程要求 Stage 0 资源 HARD-GATE 先跑；写错的样子：Stage 0 还在运行时就派出页面转换器，派工里没写资源仍在迁移、以 Stage 0 回报为准
适用范围：编排阶段派页面转换任务，而资源迁移阶段尚未回报时
做法：
- 等 Stage 0 资源 HARD-GATE 通过、回报到了再派页面转换器
- 必须并行时在派工里写一句：「资源仍在迁移，资源是否就绪以 Stage 0 回报为准」
