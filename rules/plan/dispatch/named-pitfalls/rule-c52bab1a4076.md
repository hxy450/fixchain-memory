# 派工点名迁移陷阱时，涉及横向滚动行或覆盖式选中态的切片同时点名定高和百分比子层两条

审的是：计划与派工
触发（任一种）：
- 读到：切片里有横向滚动的 Tab 行或标签条（PrimaryScrollableTabRow、horizontalScroll），或贴合内容的选中指示器（matchContentSize、fillMaxSize）；写错的样子：派工说明按编号列出须遵守的迁移陷阱，却没有点名“横向滚动容器须显式定高”（P-22）和“不用 100% 子层填父级、描边画在容器自身”（P-20）这两条
适用范围：派工阶段给界面切片列出须遵守的迁移陷阱条目时
做法：
- 切片涉及横向滚动行或覆盖式选中态时，在派工的须遵守陷阱里同时写上 P-20（不用 100% 子层填父宽高，描边、背景画在容器自身，由内容定大小）和 P-22（横向滚动容器不随内容定高，须显式 .height）
针对本应用要查的：
- 两条陷阱在当前流水线里的编号：流水线迁移陷阱表（ui-migration-pitfalls）里讲百分比子层和横向滚动定高的条目；按条目内容核对编号；编号变了就按内容点名
