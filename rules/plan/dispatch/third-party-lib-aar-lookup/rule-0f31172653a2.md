# 派工给出安卓源码路径而控件形制来自三方库时，一并给出库 AAR 的缓存位置和解包查值的提示

审的是：计划与派工
触发（任一种）：
- 读到：规格或映射里登记了三方库名和版本（如 material-dialogs → CustomDialog、preference-ktx 运行时构建），控件形制来自库资源、项目 res/ 里没有；写错的样子：派工只列了安卓源码路径，没写该库 AAR 在 Gradle 缓存里的位置，也没提示可以解包查 values 和 layout 的真值
适用范围：派发界面实现任务、目标组件锚定三方库或 AppCompat 控件时的派工说明
做法：
- 派工里写上库坐标和版本、AAR 在 Gradle 缓存 modules-2/files-2.1 下的位置（或 transforms 下解包后的 res/ 目录），并写明「可 unzip 查 res/values/values.xml 与 layout 的真值」
针对本应用要查的：
- 库 AAR 在本机的位置：Gradle 缓存 modules-2/files-2.1/<group>/<artifact>/<version>/ 下的 .aar；较新的 Gradle 解包在 <gradle 版本>/transforms/<hash>/transformed/<artifact>-<version>/res/；按应用依赖的版本取那一个目录，写进派工
