# 增量还原派实现前先做页面级行为对比；并行派发时派工写明安卓 Screen/ViewModel 并要求写前读

审的是：计划与派工
触发（任一种）：
- 读到：用户要求「对比安卓，还原某功能」；安卓端是 Compose，列表层级、模式切换、按钮可用条件只写在 Screen/ViewModel 里，数据层（DAO、Repository、Entity）看不到；写错的样子：对比和实现被同时派出，实现派工没写安卓 Screen/ViewModel 的路径、没要求写前读；派工列的安卓重点只有持久化、数量、删除等数据层行为，没有列表层级和编辑态
适用范围：增量还原阶段，编排者派发页面对比和页面实现子代理时
做法：
- 先完成页面级行为对比（列表项层级、模式状态、按钮可用条件），再派实现
- 若要并行，实现派工里写明安卓 Screen 和 ViewModel 的路径，要求实现者写前自行读取并列出顶栏动作、分组结构、底栏各模式控件和 enabled 条件
来源：1 张卡，1 个应用
- case-38718a95ad1839df7084（青商城）：做法第 1 步 ← 建议 2；做法第 2 步 ← 建议 1、建议 2
