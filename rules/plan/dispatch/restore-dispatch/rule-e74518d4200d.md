# 派发还原任务时派工写明源工程路径和相关源文件，派后读到的源端要点要转交

审的是：计划与派工
触发（任一种）：
- 读到：用户要求「对比安卓」还原某页面；安卓工程在目标工程同级的独立目录里，执行子代理要自己定位源端 Screen/ViewModel/Service；写错的样子：派工里没有源工程路径和相关源文件；或协调者派后自己读到了源端接口和交互要点，却没转交执行子代理，就按子代理回执宣告完成
适用范围：增量还原的协调阶段，派发和收口还原任务时
做法：
- 派工里写明源工程路径和对应的 Screen、ViewModel、Service 文件
- 派后读到的源端接口与交互要点转交执行子代理；转交失败时不按子代理回执宣告完成
来源：1 张卡，1 个应用
