# 还原任务的派工

agent 会看到什么：用户要求「对比安卓，还原某功能」时，派工里交给执行子代理的源工程路径、Screen / ViewModel 文件、页面行为要点和派发先后

## 规矩

- rule-a54ee1e4ccec｜增量还原派实现前先做页面级行为对比；并行派发时派工写明安卓 Screen/ViewModel 并要求写前读｜读到：用户要求「对比安卓，还原某功能」；安卓端是 Compose，列表层级、模式切换、按钮可用条件只写在 Screen/ViewModel 里，数据层（DAO、Repository、Entity）看不到；写错：对比和实现被同时派出，实现派工没写安卓 Screen/ViewModel 的路径、没要求写前读；派工列的安卓重点只有持久化、数量、删除等数据层行为，没有列表层级和编辑态
- rule-e74518d4200d｜派发还原任务时派工写明源工程路径和相关源文件，派后读到的源端要点要转交｜读到：用户要求「对比安卓」还原某页面；安卓工程在目标工程同级的独立目录里，执行子代理要自己定位源端 Screen/ViewModel/Service；写错：派工里没有源工程路径和相关源文件；或协调者派后自己读到了源端接口和交互要点，却没转交执行子代理，就按子代理回执宣告完成
