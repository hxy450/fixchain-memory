# 台账有「含缺陷忠实复刻」决策时，派工说明写进这条要求并让 worker 查台账原文

审的是：计划与派工
触发（任一种）：
- 读到：决策台账里有「忠实复刻原版行为含缺陷；例外仅平台合规必需项」一类决策；写错的样子：派给 slice worker 或 closer 的说明里没有这条决策原文或「含缺陷复刻」要求，只让 grep 个别 PD-/D- 条目
适用范围：派发实现切片和收尾任务的说明
做法：
- 派工说明里写入含缺陷复刻决策的原文（或「含缺陷复刻，例外仅平台合规必需项」），并要求 worker grep 台账里这一条
