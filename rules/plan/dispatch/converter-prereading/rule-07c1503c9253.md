# 派发页面转换器时，前置必读清单纳入 @Builder 复用一节（含动态状态不能作值参）

审的是：计划与派工
触发（任一种）：
- 读到：页面转换任务要把源端带状态参数的子控件转成 ArkUI 复用写法；写错的样子：派工的前置 skill 清单只有 ui-graph-query、ui-alignment、design-tokens-extractor、navigation-builder 这类，没有 arkts-component-builder 的「@Builder / @Styles / @Extend 复用」一节
适用范围：派发页面转换器和公共组件抽取任务时的前置必读清单
做法：
- 前置必读清单加上 arkts-component-builder 的「@Builder / @Styles / @Extend 复用」一节，并点明其中「动态状态不能作 @Builder 值参」这一条
未核实：转换器与公共组件任务的派工正文是加密的，没能核对派工是否点名这条规则
来源：1 张卡，1 个应用
