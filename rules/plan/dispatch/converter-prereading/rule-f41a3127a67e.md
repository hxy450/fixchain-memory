# 本会话刚出现过 ArkTS 语法报错时，派同类页面的派工点名该错误模式并要求先读语法约束

审的是：计划与派工
触发（任一种）：
- 读到：本会话刚出现过同类页面的 ArkTS 编译报错（';' expected、Only UI component syntax can be written here、does not meet UI component syntax）；写错的样子：派同类页面实现的派工没有点名这类错误模式，没要求实现者先读组件语法约束（arkts-component-builder），也没要求交付后按该模式复查
适用范围：协调者派发同类 ArkTS 页面实现的派工说明
做法：
- 派工里写明刚出现的错误模式（如块后分号、普通方法写组件、无花括号 if），要求实现者先读 arkts-component-builder 的语法约束，交付后按该模式复查

- case-daad0f4a891d962cfb25（青商城）：做法第 1 步 ← 建议 5
