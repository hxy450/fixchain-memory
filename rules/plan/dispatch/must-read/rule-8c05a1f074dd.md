# 派工限读页面材料时，仍把交互映射参考里本页相关的表列为必读

审的是：计划与派工
触发（任一种）：
- 读到：页面有弹层、遮罩、叠层这类要定命中测试模式（hitTestBehavior）的交互；写错的样子：派工里写了「效率纪律」之类的限读要求，必读清单只有 pitfalls，没有交互映射参考的「触摸测试控制」表
适用范围：给页面转换者派工、并对读材料加了限量或提速要求时
做法：
- 派工的必读清单点名交互映射参考里和本页交互相关的表（如「触摸测试控制」），并写明效率纪律不豁免这几张表
