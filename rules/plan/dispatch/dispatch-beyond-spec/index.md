# 派工里规格之外的余地和限制

agent 会看到什么：派工给执行者另加规格映射行里没有的交互形态（如「或改用外链按钮」），或设「禁新造网络端点」这类和规格 AC 冲突的限制

## 规矩

- rule-29eb61898dd8｜派工不加规格映射行里没有的交互形态（如独立外链按钮）｜读到：规格映射行写「Text + TextSpan（链接色 + .onClick 打开浏览器）或 RichText」，验收要求正文链接可点；写错：派工另给「或改用外链按钮」之类规格里没有的交互形态作余地
- rule-7812a9b9a8c9｜规格要求的端点在收尾时仍缺，修复派工不设「禁新造端点」的限制｜读到：规格 AC 写明的端点在目标工程里还没建，收尾闭环报出这个占位；写错：修复派工写「禁新造网络端点，缺端点只接已有部分并在信封披露」
- rule-ac7d8d39e26a｜规格照源保留崩溃时，派工里不派「入口补 errorManager 观察器」这一项｜读到：规格的验收项或决策台账把源端未捕获异常导致的崩溃定为照源复刻；写错：派工条目写「EntryAbility.onCreate 补 errorManager.on('error')…」，依据只是项目经验编号或「工程健壮性既定项」，验收规则和用户需求里没有这项要求
