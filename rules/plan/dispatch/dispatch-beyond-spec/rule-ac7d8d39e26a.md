# 规格照源保留崩溃时，派工里不派「入口补 errorManager 观察器」这一项

审的是：计划与派工
触发（任一种）：
- 读到：规格的验收项或决策台账把源端未捕获异常导致的崩溃定为照源复刻；写错的样子：派工条目写「EntryAbility.onCreate 补 errorManager.on('error')…」，依据只是项目经验编号或「工程健壮性既定项」，验收规则和用户需求里没有这项要求
适用范围：基础装配的计划和派工里，给入口 UIAbility 派全局异常观察器的条目
做法：
- 删掉这条派工；验收规则或用户需求原文确有要求时，改成指向待批差异的条目，写明和哪条照源崩溃复刻冲突、目标端这些路径会进程不退出
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 观测器捕获到该异常时应用不退出：派这项就等于改变照源复刻的崩溃行为（出处：js-apis-app-ability-errorManager.md，errorManager.on('error')）
