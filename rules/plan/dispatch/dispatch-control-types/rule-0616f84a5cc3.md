# 编排者写派工补充前先读已审规格，不在派工里改写规格定下的控件类型

审的是：计划与派工
触发（任一种）：
- 读到：已审规格写 CheckBoxPreference → Row + Checkbox；源 XML 的带图标 Preference 没有箭头；写错的样子：派工写「CheckboxPreference→Toggle」「→箭头行」「PreferenceActivity → Column+Row+Toggle/Slider/TextInput 复刻」，与已审规格的控件类型不一致
适用范围：编排阶段给页面转换写派工补充说明时
做法：
- 写派工补充前先读该页已审规格；派工里的控件类型照规格写（CheckBoxPreference 是方形复选框、SeekBarPreference 数值与滑条叠放、带图标的 Preference 没有箭头），不另行改写
来源：1 张卡，1 个应用
