# 派工把基类行为转成某页义务时附上该页布局含守卫 id 的证据，拿不出不写成义务

审的是：计划与派工
触发（任一种）：
- 读到：规格的基类副作用表里某项带守卫条件（子类布局须含某 id）；写错的样子：派工或切片计划写「某页承接基类淡入钩子（移交义务）」，没附该页布局含守卫 id 的证据
适用范围：派工、切片计划和移交登记把基类横切行为转成某个页面的义务时
做法：
- 义务旁附上该页源布局（含横竖屏变体）含守卫 id 的证据；拿不出证据的不写成义务
