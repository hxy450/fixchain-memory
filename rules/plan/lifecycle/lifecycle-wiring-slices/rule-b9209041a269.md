# 跨 slice 的生命周期接线在派工里列成接线项并登记占位，不只留在代码注释

审的是：计划与派工
触发（任一种）：
- 读到：前一 slice 交回的引擎代码注释写「页面退后台接线入口（由后面的 slice 调用）」，派工的 engine_api 列出 onStop()/onResume()；写错的样子：slice 计划和派工里没有生命周期接线项，跨 slice 的占位登记里也没有这两个入口，只有代码注释提到
适用范围：引擎和页面分属不同 slice、引擎把生命周期回调暴露成 onStop / onResume 入口时的计划和派工
做法：
- 给负责页面的 slice 的派工列出接线项：哪个页面、在 NavDestination 的 .onShown / .onHidden 哪个 reason 和应用前后台时调用 onStop / onResume
- 暴露入口的 slice 在跨 slice 占位登记里登记这两个入口和预定的调用方，不只写在代码注释里
