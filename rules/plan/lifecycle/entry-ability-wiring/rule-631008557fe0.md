# 接收“由入口宿主兜底”的返回移交前先确认回调可达，不可达就改登记

审的是：计划与派工
触发（任一种）：
- 读到：上游页面实施记录写“本页不加 onBackPress，栈深≤1 退后台的兜底归入口壳/根页”；写错的样子：占位或移交登记把“栈深≤1 退后台”的兜底指到承载 Navigation 的 @Entry 入口页，派工照此要求在入口页 onBackPress 里实现
适用范围：收尾或接线阶段接收返回键兜底的移交、入口 @Entry 页承载 Navigation 时
做法：
- 先核返回事件的分发：Navigation 栈内有页时返回先交栈顶 NavDestination.onBackPressed，返回 false 即出栈，@Entry.onBackPress 收不到
- 不可达时把实现落回栈底 NavDestination 的 onBackPressed（或其共享裁决函数），并改写移交登记里的目标文件和回调
