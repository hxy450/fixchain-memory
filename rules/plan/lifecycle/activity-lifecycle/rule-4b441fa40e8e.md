# 公共基座用组合式基座替代业务基类时，逐页登记接线占位，契约写成每页必须调用

审的是：计划与派工
触发（任一种）：
- 读到：源端各页面统一继承业务基类、由基类自动做生命周期副作用；规格映射写「页面级埋点改为基座的钩子」，ArkUI struct 不能继承，目标改成需每页调用的组合式基座；写错的样子：占位登记里只有基座自身的条目，没有逐页的基座 / 生命周期埋点接线行；as-built 契约只把基座列为可用 API，接线指针里没有逐页接线
适用范围：公共基座阶段用组合式基座替代源端业务基类、而页面先于基座生成时的占位登记和 as-built 契约
做法：
- 列出源端继承该基类的全部页面，与已生成页面是否调用做差集：源码搜「: 基类名」，目标页搜埋点调用或基座调用
- 对没有调用的页面逐页登记接线占位，resolve_by 指向页面所属的切片
- as-built 契约里把它写成「每页必须调用」的义务，不只列为可用 API
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 自定义组件基于 struct 实现，不能有继承关系：组合式基座只有页面自己调用才生效，必须逐页登记接线（出处：arkts-create-custom-components.md，struct）
