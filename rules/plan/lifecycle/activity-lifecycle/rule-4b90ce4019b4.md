# 划分功能与切片时，宿主 Activity 的初始化请求要归到某个功能或登记未迁

审的是：计划与派工
触发（任一种）：
- 读到：源端已登录主页的宿主 Activity 在初始化方法里发多个请求（刷新 token、拉配置、检查版本、保存登录信息）；写错的样子：功能清单和切片账本里没有功能认领这个 Activity 的初始化请求：功能只锚到其他模块，切片的接线只到闪屏和引导页
适用范围：按功能划分迁移切片、写覆盖清单时
做法：
- 拆分时逐个检查宿主 Activity 的初始化请求归到哪个功能；用接口清单里每个端点的 callers 反查调用它的 Activity，没有归属的请求补进某个功能或登记为未迁
来源：1 张卡，1 个应用
