# 执行总结声称启动时自动执行某行为前，grep 确认该函数在启动路径上有调用者

审的是：计划与派工
触发（任一种）：
- 读到：规格或源端写明某行为在首次启动时自动执行；写错的样子：执行总结写「首次运行会自动初始化…」，而 grep 该函数只有设置页一个调用者，启动路径上没有调用
适用范围：实现阶段交回执行总结、声明某个自动触发的行为已实现时
做法：
- 写「已实现」前 grep 该函数的调用者，确认 EntryAbility.onCreate 或数据管理器初始化等启动路径上有实际调用；只有设置页调用时记为未实现
