# 派工提示不写未核实的「源端缺陷照搬」结论，写成待核问题并给源码锚点

审的是：计划与派工
触发（任一种）：
- 读到：源码里判定在 setContent 的组合副作用里、写入在 onCreate 尾部，按行序看像是首启就会命中；写错的样子：派工提示或规格写「注意首启也命中——照源码」这类源端行为结论，没标待核、没给源码锚点，也没对照参考文档的用例
适用范围：规格提取与派工阶段，要提醒源端边界行为（看似缺陷、要照搬）时
做法：
- 要提醒边界时写成待核问题，给出源码锚点（判定所在组件、写入所在语句），不写结论
- 把结论写成「源端看似缺陷、照搬」之前，先和参考设计文档的用例交叉核对
来源：1 张卡，1 个应用
- case-aac91310ef7e70c88957（GameOfLife）：做法第 1 步 ← 建议 2；做法第 2 步 ← 建议 2、诊断
