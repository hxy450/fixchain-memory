# wiring map 指派宿主页 onBackPressed 的负责切片

审的是：计划与派工
触发（任一种）：
- 读到：规格里有页内弹层或根页的返回语义，返回链分散在 VM 和宿主页面；写错的样子：wiring map 没有列宿主页 onBackPressed，没有指派负责切片
适用范围：规划阶段写 wiring map、分派跨页接线时
做法：
- 在 wiring map 里为每个有返回语义的宿主页列出 onBackPressed 接线项，并指派负责的切片
来源：1 张卡，1 个应用
