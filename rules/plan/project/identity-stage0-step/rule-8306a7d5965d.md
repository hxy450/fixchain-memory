# Stage 0 的预期产物和完成报告要列身份映射，没执行就不进 Stage 1

审的是：计划与派工
触发（任一种）：
- 读到：执行流程的 Stage 0 说明要求资源迁移后、进 Stage 1 前由主线程调用 arkts-app-identity（scope=dev-identity）；写错的样子：Stage 0 预期产物清单只列资源映射和占位登记，完成报告宣告 Stage 0 完成却没提身份映射，Stage 1 已经派发
适用范围：迁移执行编排在 Stage 0 收口、派发 Stage 1 前
做法：
- Stage 0 预期产物里写上 arkts-app-identity（scope=dev-identity）的身份映射报告，完成报告逐项列 app_name、EntryAbility_label、versionName、versionCode、图标各自的安卓来源
- 没执行或没返回身份映射报告时不派发 Stage 1；bundleName、vendor 不在这一步改，单独登记为部署期决策
来源：1 张卡，1 个应用
