# 推进到下一阶段前，核对阶段规范划给主线程的收尾步骤已实际调用，没调用就阻断

审的是：计划与派工
触发（任一种）：
- 读到：阶段规范写明某收尾步骤由主线程在子任务返回后单独执行（如资源迁移后、进入页面转换前自动调用应用身份落地，scope=dev-identity），子任务返回里也写着「最终装配归属」这一步；写错的样子：编排记录在子任务返回后直接进入下一阶段，没有这一步的调用记录，报告里也没有登记为阻断项
适用范围：执行编排阶段，子任务返回后决定推进阶段时
做法：
- 推进前逐项列出阶段规范里划给主线程的收尾子步骤，逐项核对已调用；没执行的不进入下一阶段，或在报告里登记为阻断项
针对本应用要查的：
- 这一阶段划给主线程的收尾步骤：执行规范里这一阶段的说明（资源阶段之后的应用身份等小节）；列成清单，推进前逐项对调用记录
