# 网络层任务的写权限不含 module.json5 时，返回信封要把网络权限列为跨文件改动草稿

审的是：计划与派工
触发（任一种）：
- 读到：派工把写权限限定在网络层目录；检查清单或代码模板注释写着「前置：必须在 module.json5 声明 INTERNET」；写错的样子：返回信封的风险、登记项、跨文件改动里都没有 module.json5 的 ohos.permission.INTERNET，只在代码注释或自查清单里提到
适用范围：交付 HTTP 封装等网络层代码、写权限不包括 module.json5 的任务的回执
做法：
- 交付前查 module.json5 的 requestPermissions 有没有 ohos.permission.INTERNET；代码判断连接状态时还要有 ohos.permission.GET_NETWORK_INFO
- 缺而又不能自己改时，在返回信封里列一条跨文件改动草稿或风险：「module.json5 requestPermissions 补 ohos.permission.INTERNET（判断连接状态时加 GET_NETWORK_INFO）」，不能只留在代码注释或自查清单里
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- HttpRequest.request 标注 @permission ohos.permission.INTERNET：网络层一发请求就要这项权限，回执里漏报就没人补（出处：鸿蒙 SDK 的 ets/api/@ohos.net.http.d.ts，HttpRequest.request）
