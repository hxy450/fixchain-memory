# 页面迁入 HAR 或在 feature 间移动时，迁移清单列上页面的资源闭包

审的是：计划与派工
触发（任一种）：
- 读到：页面源码里有 `$r('app.string/media/color.X')`，或用 getStringByNameSync / getMediaByNameSync / 封装的按名取字符串函数引用资源；写错的样子：迁移范围表或计划只列页面、VM、模型、Service、Repository，没列 resources/*/element 条目和 media 文件；资源清单只按 app.(string|media|color).X 静态写法扫描，漏掉按名引用的字面量
适用范围：架构重构、模块拆分阶段，把页面迁入某个 HAR 模块或在 feature 之间移动页面时的迁移清单
做法：
- 以页面（及其直接组件）为单位列资源闭包：静态的 $r('app.string/media/color.X')，加上 getStringByNameSync / getMediaByNameSync 等按名引用里的名字字面量
- 把这些名字对应的 resources/*/element 条目和 media 文件列入同一份迁移清单，和 model / VM / service 一起搬
来源：1 张卡，1 个应用
