# 延后某个身份字段时，核对决策台账确有条目，并在报告里列出保留的模板值和理由

审的是：计划与派工
触发（任一种）：
- 读到：技能或派工以「与签名 / AGC 绑定，属部署期决策」并带一个决策编号为由要求保留 vendor、bundleName 的脚手架值；写错的样子：迁移报告或占位登记里没有列出保留的模板值及理由，引用的决策编号在本工程决策台账里不存在或内容不符
适用范围：应用身份落地阶段确需延后某些身份字段时
做法：
- 核对决策台账里是否真有批准保留该模板值的条目；有则在迁移报告里列出保留的字段、模板值和对应条目
- 技能里引用的决策编号与台账不符时以台账为准，并在报告里记为缺口
来源：1 张卡，1 个应用
- case-15465539e78d3d899b47（CleanSweep）：做法第 1 步 ← 建议 3；做法第 2 步 ← 建议 3
