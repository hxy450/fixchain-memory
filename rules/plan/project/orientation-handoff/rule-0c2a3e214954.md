# module.json5 的移交项要带方向配置；页面有横屏分支而没有 orientation 时登记为缺口

审的是：计划与派工
触发（任一种）：
- 读到：决策台账有横竖屏方向的决策；页面实现里有 `mediaquery` 的 orientation 分支或 `onConfigurationUpdate` 重选横屏布局；写错的样子：派给收尾者的 module.json5 移交项只有 requestPermissions；收尾或实现者的报告说 module.json5「无新增需求」，没有把缺 orientation 登记为缺口
适用范围：派工和收尾阶段，交代和核对 module.json5 工程级配置时
做法：
- 移交项里写明 EntryAbility 的 orientation 目标值，与权限并列；收尾时页面已有横屏分支而 module.json5 没有 orientation，就登记为缺口交回主流程
