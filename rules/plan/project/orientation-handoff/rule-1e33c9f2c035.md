# 计划逐项核对 Manifest 解析和平台目标值表，每个配置项落进某个 slice，没取用的列为待指派

审的是：计划与派工
触发（任一种）：
- 读到：页面规格「Manifest 解析」行、参考规格平台目标值表里同一行列了几项落在配置文件或窗口级 API 的目标值（如 module.json5 的 orientation 与窗口的 RESIZE 同行）；写错的样子：计划只取用了其中一部分（如只把 RESIZE 写进某个 Step），其余项（如 module.json5 EntryAbility 的 orientation）没有出现在任何 slice 或 Base step 的 scope 里，也没列为待指派
适用范围：计划阶段，把页面规格和参考规格里写到具体配置文件或窗口级 API 的目标值分派给 slice 时
做法：
- 对「Manifest 解析」和平台目标值表逐项核对，每个写到具体配置文件或窗口级 API 的项各自写进某个 slice 或 Base step 的 scope，写明文件和字段（如 module.json5 入口 UIAbility 的 "orientation": "auto_rotation_restricted"）
- 同一行只取用部分项时，其余项列为待指派，不静默丢弃
来源：1 张卡，1 个应用
- case-11ff372c001b24f1dce2（GameOfLife）：做法第 1 步 ← 建议 2；做法第 2 步 ← 建议 2
