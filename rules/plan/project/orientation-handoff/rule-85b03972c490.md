# orientation、launchType 要指定步骤认领，派工不能整体写 module.json5 不改

审的是：计划与派工
触发（任一种）：
- 读到：AndroidManifest.xml 的 <activity> 带 android:configChanges 含 orientation、android:launchMode，未写 android:screenOrientation；写错的样子：派工写「app.json5 / module.json5 不改」，或把 module.json5 的改动限定在身份字段（名称、版本、图标），而 EntryAbility 的 orientation、launchType 没有任何步骤认领
适用范围：计划阶段拆任务、写派工时，对 module.json5 里 ability 配置的归属
做法：
- 为 module.json5 里对应 ability 的 orientation、launchType 指定认领步骤：派工里写明由哪个切片改、改成规格映射节给出的值
