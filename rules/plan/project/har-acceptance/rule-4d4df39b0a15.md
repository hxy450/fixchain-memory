# 资源迁移的验收只写整包 assembleHap 或真机跑通时，补上逐模块的资源闭包检查

审的是：计划与派工
触发（任一种）：
- 读到：页面或资源在 HAR 模块之间迁移；写错的样子：计划或验收只写「整包 assembleHap 通过」「真机一跳正常」，没有逐个 HAR 核对 $r 名称
适用范围：架构重构阶段验收页面、资源跨模块迁移时
做法：
- 对每个 HAR 抽取 $r 名称，与该模块及其声明依赖的资源并集比对，缺失即失败；也可以按 hvigor 的 module 模式单独构建该 HAR
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 构建 HAP 时会从 HAP 模块及依赖的模块收集资源并合并：整包构建和真机运行掩盖模块级资源缺失（出处：har-package.md，导出资源）
