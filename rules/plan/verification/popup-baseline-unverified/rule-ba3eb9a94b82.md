# 视觉校验时基线截图没拍到弹层本体、view.xml 无 bounds，弹层内几何标未核，不判 PASS

审的是：计划与派工
触发（任一种）：
- 读到：Android 基线截图没有拍到弹层展开后的本体，view.xml 是合成的、bounds 为空；写错的样子：校验结论按源结构把这个弹层判为 PASS，弹层内卡片几何没有标为未核
适用范围：视觉校验结论清单里，涉及基线截图没拍到的弹层、浮层时
做法：
- 这类弹层在校验清单里把卡片几何标为「未核」而不是 PASS，并登记为待补拍弹层展开后截图的项；写明仓内源码与实装可能不一致
