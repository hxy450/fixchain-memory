# 生成期无法真机核对打开系统设置时，交付报告登记「需真机确认」并写检查

审的是：计划与派工
触发（任一种）：
- 读到：派工禁止编译或没有设备，代码用显式 Want 指定系统设置应用的 bundleName；写错的样子：交付报告或验证清单里没有「打开系统设置需真机确认」这一项，也没有点击后确认设置应用处于前台的检查
适用范围：生成期不能上机核对系统应用包名、跳转结果只能留到验证期时
做法：
- 在交付报告或验证清单登记「打开系统设置需真机确认」，检查写明：点击后用 aa dump -l 确认设置应用处于前台
来源：1 张卡，1 个应用
- case-5aa1e2ae875c4bef3df1（CleanSweep）：做法第 1 步 ← 建议 2
