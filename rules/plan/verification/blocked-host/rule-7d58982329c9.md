# 验证时功能点因宿主不可达记 BLOCKED 的，回流成待补项或用静态检查覆盖

审的是：计划与派工
触发（任一种）：
- 读到：功能点清单里有依赖某个宿主页面才能走到的功能点；写错的样子：验证汇总把这些功能点多轮记为 BLOCKED（宿主不可达），没有对应的待补项、负责批次或静态检查结论，汇总里静默消失
适用范围：功能验证阶段写验证汇总和回流清单时
做法：
- 每个 BLOCKED 的功能点写进待补项（负责批次和要补的实现），或者用静态检查覆盖并写结论，例如确认对应偏好键在目标代码里有读和写两端的调用方
