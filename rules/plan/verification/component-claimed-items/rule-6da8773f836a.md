# 差异清单不能用「由组件承担」注销验收项，每条要落方法和调用点或登记占位

审的是：计划与派工
触发（任一种）：
- 读到：规格的性能类验收项要求「预加载后续 3 张缩略图到内存缓存」，源锚点是源 ViewModel 的预取方法；映射表写「→ Image 预加载（页面态）」；写错的样子：差异清单或最终报告写「无对等低层 API，由页面态 Image 组件缓存承担（不额外建服务）」，目标文件里没有对应方法和调用，也没有占位或 FWD-REF
适用范围：实现阶段写差异清单、覆盖清单或最终报告，处理性能类验收项（预加载、缓存预热）时
做法：
- 逐条对照规格验收项（含性能类）：每条在目标文件里写出对应方法和调用点，或登记可追踪的占位（FWD-REF 或占位登记条目）
- 要写「平台组件可替代」时比较作用对象和触发时机：源端在显示前主动预取后续 N 项，Image 组件只缓存已渲染的项，二者不等价，不能据此注销
来源：1 张卡，1 个应用
