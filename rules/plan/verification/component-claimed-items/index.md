# 差异清单里「由组件承担」的验收项

agent 会看到什么：规格的性能类验收项有源 ViewModel 的预取方法作锚点，差异清单或最终报告写「无对等低层 API，由页面态 Image 组件缓存承担」，目标文件里没有对应方法和调用，也没有占位

## 规矩

- rule-6da8773f836a｜差异清单不能用「由组件承担」注销验收项，每条要落方法和调用点或登记占位｜读到：规格的性能类验收项要求「预加载后续 3 张缩略图到内存缓存」，源锚点是源 ViewModel 的预取方法；映射表写「→ Image 预加载（页面态）」；写错：差异清单或最终报告写「无对等低层 API，由页面态 Image 组件缓存承担（不额外建服务）」，目标文件里没有对应方法和调用，也没有占位或 FWD-REF
