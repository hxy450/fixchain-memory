# 页面临时占位时登记为未完成项，完成判定检索占位特征，不以文件存在和编译通过打勾

审的是：计划与派工
触发（任一种）：
- 读到：阶段完成标记只要求报告文件存在，执行者以页面文件齐全和编译通过自检；写错的样子：阶段报告、覆盖清单把全部页面打 ✔，其中有正文只写「开发中」、只有标题、或写死样例数据的页面，没有登记为未完成项
适用范围：迁移执行阶段写阶段报告、覆盖清单和占位登记、判定阶段完成时
做法：
- 确需临时占位的页面，把页面、缺失功能和对应源文件登记为未完成项并写入阶段报告，不计入完成数
- 完成判定检索占位特征：「开发中」、只有标题的页面、写死的样例数据（固定分类、假商品卡片）
