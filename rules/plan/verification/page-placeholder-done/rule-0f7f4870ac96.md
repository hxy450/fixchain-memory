# 验证报告宣告页面完成前，对入口页做内容级断言，只写真实执行过的检查

审的是：计划与派工
触发（任一种）：
- 读到：验证阶段的检查项只比页数、文件数，或只看文件存在、编译通过；写错的样子：验证报告写「入口页（主界面 + 各 Tab）已完成」「全部 PASS」，但没有重新读取入口页内容，或写了没有执行回执的检查结果
适用范围：验证阶段写 verify 报告、宣告页面或阶段完成时
做法：
- 报告页面完成前对入口页做内容级断言：grep -c 'Hello World' 为 0，grep 'Tabs'（或计划的根组件）命中，把命令和输出写进报告
- 只写本阶段真实执行过的检查结果；文件存在、页数相等、编译通过不作为页面已迁移的依据
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 模板入口页可编译、存在性检查也通过：这些检查区分不了模板与已迁移页面（出处：卡里修好并验证过）
