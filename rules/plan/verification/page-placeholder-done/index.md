# 临时占位的页面和完成标记

agent 会看到什么：阶段完成只要求报告文件存在，交回的阶段报告、覆盖清单把正文只写「开发中」或写死样例数据的页面也打了 ✔

## 规矩

- rule-4c9623bf9de4｜页面临时占位时登记为未完成项，完成判定检索占位特征，不以文件存在和编译通过打勾｜读到：阶段完成标记只要求报告文件存在，执行者以页面文件齐全和编译通过自检；写错：阶段报告、覆盖清单把全部页面打 ✔，其中有正文只写「开发中」、只有标题、或写死样例数据的页面，没有登记为未完成项
- rule-0f7f4870ac96｜验证报告宣告页面完成前，对入口页做内容级断言，只写真实执行过的检查｜读到：验证阶段的检查项只比页数、文件数，或只看文件存在、编译通过；写错：验证报告写「入口页（主界面 + 各 Tab）已完成」「全部 PASS」，但没有重新读取入口页内容，或写了没有执行回执的检查结果
