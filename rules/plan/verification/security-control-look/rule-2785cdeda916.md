# 安全控件外观没经编译或真机核对时，交付里列为待真机核对项，不写成范式

审的是：计划与派工
触发（任一种）：
- 读到：派工要求把自绘外观的按钮改用 SaveButton 等安全控件，同时禁止编译或没有真机；写错的样子：交付说明或移交项里没有「安全控件外观待真机核对」这一项，代码注释却把未核对的外观写法定为范式，供后续页面当作同款沿用
适用范围：生成期不能编译、不能上真机，又给安全控件设了自定义外观（底色、圆角、背景场景）时的交付
做法：
- 在交付的移交项里列一项待真机核对：哪个安全控件、设了哪些外观属性、处在什么背景上，待核对按钮中心和四角有无深色外露；注释里不把它写成已定范式
