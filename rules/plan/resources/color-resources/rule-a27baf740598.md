# 令牌缺失时补条目或报 design_tokens_missing，PASS 报告里不静默改色

审的是：计划与派工
触发（任一种）：
- 读到：工作提示要求颜色一律走 $r('app.color.*')，令牌缺失或不匹配时报告 `design_tokens_missing`，不得自行发明后静默继续；写错的样子：PASS 报告没提令牌缺失，也没有 `design_tokens_missing`，而代码里有色值被换成了值不同的已有令牌
适用范围：界面和共享组件写者交回的完成报告里关于颜色令牌的那一项
做法：
- 每个缺失或不匹配的令牌，要么已在 color.json 补上同值条目，要么在报告里列一条 `design_tokens_missing`（原色值、用处、建议名）；两样都没有不能报 PASS
来源：1 张卡，1 个应用
