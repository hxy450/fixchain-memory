# 交付说明里逐项写明每个图标资源的来源，不把近名资源称作原始资源

审的是：计划与派工
触发（任一种）：
- 读到：规格里有元素→资源表，计划写明资源从 Android 原图提取；写错的样子：交付说明或实施记录写「项目中已有的原图标并统一着色」「统一使用 Android 视觉中的黄色选中态」，没有逐项列出资源和来源
适用范围：子代理交回界面实现时的交付说明、实施记录
做法：
- 逐行列出菜单 builder 里每个 $r('app.media.*') 和 sys.symbol.*，与规格的元素→资源表逐项对照，每项写明来源是「Android 原图复制」还是「工程既有资源」
来源：1 张卡，1 个应用
