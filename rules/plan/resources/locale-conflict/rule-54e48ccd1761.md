# 通用多语规则和规格冲突时，资源映射报告写明冲突和取舍

审的是：计划与派工
触发（任一种）：
- 读到：规格写「资源默认文案为英文，迁移不擅自翻译」，资源转换 skill 写「至少生成 2 套语言资源」「默认英文时生成 base + zh_CN」；写错的样子：资源映射报告把非 base 语言的值记成显式译文（如「explicit Chinese locale values」），没写和规格的冲突与取舍，只报键一致
适用范围：资源迁移阶段交回的资源映射报告
做法：
- 报告里写明冲突的两条原文（skill 的多语规则、规格的不翻译要求）和按规格、源码取舍的结果（只生成 base，或第二语言目录只留脚手架键）；键一致不作为语言取值正确的依据
