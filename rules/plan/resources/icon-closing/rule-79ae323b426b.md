# 能靠复制闭合的 AppScope 图标项不记成「非阻断」附注移交验证，当场改好

审的是：计划与派工
触发（任一种）：
- 读到：资源迁移的回报把 AppScope 图标交给身份落地这一步，entry 侧已有可直接复制的前景、背景和 layered_image.json；写错的样子：迁移报告或移交清单里写着 AppScope 的 app.json5 icon 仍是脚手架 $media:app_icon、AppScope media 没有图标文件，并记为「非阻断」附注留给验证阶段
适用范围：应用身份落地后写迁移报告、登记移交项时，关于 AppScope 应用级图标的条目
做法：
- 先做最小核验：读 app.json5 的 icon 值，列 AppScope media 的文件和大小，确认 layered_image.json 的两个引用在 AppScope media 里能解析
- 核验不过、又能靠复制 entry 侧文件和改 icon 闭合的，当场改好，不以「非阻断」附注移交到验证阶段
