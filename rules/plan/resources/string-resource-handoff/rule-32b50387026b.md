# 派发资源或应用身份任务时，应用名写「取源 @string/app_name 的值」，不写字面值

审的是：计划与派工
触发（任一种）：
- 写错的样子：派工正文写「app_name=某个名字（@string/app_name 按各语言）」这类字面值，且没有引用决策 ID
适用范围：编排者给资源迁移、应用身份落地的 worker 写派工时
做法：
- 派工里写「应用名取源 @string/app_name 的值（各语言）」；确需改名时写明引用的决策 ID
来源：1 张卡，1 个应用
