# 应用身份裁决按语言列出显示名，并写明 AppScope 与 entry 都覆盖源端语言集合

审的是：计划与派工
触发（任一种）：
- 读到：源端 android:label 引用的应用名在 values-<语言> 有译名；派工要求语言目录镜像源端实际集合；写错的样子：计划或派工的身份裁决只写「app_name 两处（AppScope + entry Ability label）= <base 名>」，没有按语言列显示名，也没说 AppScope 是否跟随语言集合
适用范围：计划与派工阶段写应用身份裁决时
做法：
- 身份裁决按语言列出显示名（base = <源默认名>，<语言> = <源译名>…），并写一句「AppScope 与 entry 的资源目录都覆盖源端语言集合」
针对本应用要查的：
- 源端应用名的语言集合和译名：源工程 res/ 下各 values-<语言>/strings.xml 里 android:label 引用的字符串；逐语言读出值，填进身份裁决的语言列表
来源：1 张卡，1 个应用
