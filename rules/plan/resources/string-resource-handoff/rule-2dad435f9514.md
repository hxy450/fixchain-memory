# 转换报告把缺的专属文案列为待补资源或占位，不写「所有引用资源都已存在」

审的是：计划与派工
触发（任一种）：
- 读到：源布局里有页面专属文案，目标 string.json 检索不到对应条目；写错的样子：转换报告写「所有引用资源都已存在」「未新增共享资源」，没有把缺的专属文案列为需收尾者补充的资源或登记资源占位
适用范围：页面转换者不写共享资源文件、缺失资源交给收尾者统一补齐的流水线
做法：
- 在报告的待补资源（或资源占位登记）里列出：新 key、源文案原文、出自哪个源布局控件
