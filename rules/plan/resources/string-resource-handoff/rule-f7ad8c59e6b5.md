# 派发字符串转换时照台账原文带入值语义，不缩成「外层引号剥离」

审的是：计划与派工
触发（任一种）：
- 读到：决策台账里 strings.xml → string.json 的值语义写着「按 aapt2 编译语义计算值」「未转义双引号剥离」；写错的样子：派发资源转换的说明或转换脚本的注释里删掉了引号剥离这一项，或改写成「成对引号剥离」「去掉外层引号」「strip outer quotes」
适用范围：派发资源转换（strings.xml → string.json）任务、或写转换脚本说明时
做法：
- 派工说明和脚本注释原样引用台账里值语义那一条的全文，其中要有「值中任何位置的未转义双引号剥离；\" 还原成 " 保留」，不转述成成对或外层引号
来源：1 张卡，1 个应用
