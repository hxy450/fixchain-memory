# 派页面清单或侦察任务时，导航目的地和页面标题字段同时要资源键和解析后的字面值

审的是：计划与派工
触发（任一种）：
- 读到：源端导航目的地和页面标题都经资源键引用（枚举 label、路由标题资源、顶部栏 title）；写错的样子：派工自定的清单字段（如 top_level_destinations）只有枚举名、route、icon，没有 label 资源键，也没有解析后的字面值
适用范围：主会话派发页面清单、侦察任务并定清单字段时
做法：
- 清单字段里导航目的地和页面标题各要求两项：源资源键，和从 strings.xml 解析出的逐字字面值
