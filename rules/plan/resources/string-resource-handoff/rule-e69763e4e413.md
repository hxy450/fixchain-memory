# 把字面量改成他人单写的资源引用时，交接逐项给「键名=原值」

审的是：计划与派工
触发（任一种）：
- 读到：页面里有来自安卓布局 `android:text` 的字面量（如徽标里的纯数字序号），资源文件归另一个 agent 单写；写错的样子：交接只写「添加共享字符串 <键名> 至 <键名>」，没给每个键的原值
适用范围：切片 worker 把页面字面量改成 $r 引用、由收口 agent 在共享 string.json 里补值时的交接
不适用的情形：纯数字序号不需要翻译、保留字面量没有新建键时，不涉及这项交接
做法：
- 交接里逐项写「键名=原值」，值取自安卓布局的 android:text、strings.xml，或被替换掉的原字面量
针对本应用要查的：
- 被替换字面量的原值：替换前的目标代码字面量，或源工程该页布局 XML 里对应控件的 android:text、res/values/strings.xml；原样抄进交接的「键名=原值」
未核实：收口者的任务正文是加密内容，无法确认它是否另外拿到过原值
