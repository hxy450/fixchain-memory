# worker 发现共享资源是转换器的同类缺陷时，回执写系统性根因和范围，编排者安排全量审计

审的是：计划与派工
触发（任一种）：
- 读到：页面 worker 判定共享资源错在转换器（如「converter used dp size as viewBox instead of viewport」）；写错的样子：回执只写「修复 N 处 SVG viewBox 错配」，没写转换器的系统性根因和疑似范围；编排记录里记成顺手修复，没有全量审计或重跑脚本的任务
适用范围：页面转换与编排阶段，worker 修了转换器批量产出的共享资源时
做法：
- worker 回执写明：根因在转换器的哪一步、同类资源的疑似范围（例：全部 width ≠ viewport 的 vector）；编排者据此派全量审计，或修正转换脚本后重跑，不只修当前页面引用的文件
