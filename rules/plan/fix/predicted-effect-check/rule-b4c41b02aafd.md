# 上一轮预期效果里的可量化预测测出不符时，即使页分达标也单独立单

审的是：计划与派工
触发（任一种）：
- 读到：上一轮修复报告 §6「预期效果」里有可量化预测（如某段落行距仍为某值）；写错的样子：判读测出与预测不符、能指到具体公式，却记成 residual_low_not_ticketed，理由是页分 ≥0.95 关页
适用范围：视觉对齐的判读阶段核对上一轮修复效果时
做法：
- 把上一轮 §6 的可量化预测列为本轮必核项；测出不符且能指到具体公式时，单独立单或标为修复引入的回归，不只记 residual 随页关闭
