# 计划拆分时把深链的 skills.uris 列为单独交付项并指定归属切片

审的是：计划与派工
触发（任一种）：
- 读到：规格里有源端 intent-filter 深链的映射；写错的样子：切片计划只把「onCreate / onNewWant → 解析 → 路由」派给某切片，没有 module.json5 skills.uris 这一项；唯一涉及 module.json5 的配置任务派工写「其余字段零改动」
适用范围：计划拆分和派工阶段，深链涉及代码和 module.json5 两处时
做法：
- 在计划里把 skills.uris 声明列为单独交付项，指定归属切片（通常是拥有深链入端的切片）；涉及 module.json5 的配置任务不要用「其余字段零改动」把它排除
来源：1 张卡，1 个应用
- case-6b58da0df30e3479800e（Countdate）：做法第 1 步 ← 建议 2
