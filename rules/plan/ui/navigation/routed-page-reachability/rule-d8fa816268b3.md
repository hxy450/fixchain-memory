# 目标页没有回传字段或加载/选中仍是 FWD-REF 时，完成信封登记未闭合，不把入口标成出口

审的是：计划与派工
触发（任一种）：
- 读到：目标页的参数类只携带初始值、没有结果回传字段，或它的加载 / 选中处理仍是 `FWD-REF` 前向引用；写错的样子：完成信封把「打开选择器」的入口当成已完成的真实出口，没有登记回传缺口或未闭合的 `FWD-REF`
适用范围：接入别的切片拥有的目标页、交回完成信封时
做法：
- 接入前先读目标页参数类和其中的 `FWD-REF`；在授权范围内能改就补齐两端（参数回调 + 选中处调用），不能改就在完成信封里登记为未闭合（写明缺回传字段、哪条前向引用未解析）
