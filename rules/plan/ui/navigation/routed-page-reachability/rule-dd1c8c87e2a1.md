# 已转换并在 pageMap 注册的死码页，页内占位要兑现或撤销注册，不改标成永久披露

审的是：计划与派工
触发（任一种）：
- 读到：页面被判为死码，但目标的路由 pageMap 里注册了它，可以按名进入；写错的样子：收口时把页内功能占位改成「死码域披露……永久保留——合法外部延迟」，债务闸不再报 GAP，功能仍是空壳
适用范围：收口时处置死码页里的前向占位
不适用的情形：确定不转换、不注册的死码页不适用
做法：
- 二选一：撤销这页的转换和 pageMap 注册；或者用工程已有的 helper 按源码流程把占位兑现，再翻成 resolved
