# 规格机制要页面侧接线时，计划把页面绑定列入写盘额度，派工不写定制或默认二选一

审的是：计划与派工
触发（任一种）：
- 读到：规格的转场机制要求各 NavDestination 页面绑定共享转场状态；写错的样子：计划只给各页路由注册（pageRegister）额度、限定每页只改几行，派工写「定制转场或 NavDestination 默认」二选一，页面绑定不在写权内
适用范围：计划与派工阶段处理需要多页面配合接线的规格机制时
做法：
- 把这些页面的绑定改动列入 cross_slice_edits 或写盘额度，写明每页要加的绑定
- 派工只写规格选定的机制，不写「定制或默认」二选一
来源：1 张卡，1 个应用
