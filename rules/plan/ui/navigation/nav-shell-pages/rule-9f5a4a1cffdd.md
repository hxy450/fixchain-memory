# 壳分发交给不拥有目标页的切片时，派工列出各目标页参数类和壳契约

审的是：计划与派工
触发（任一种）：
- 读到：壳规格写“深链参数 {path, title?, date?} → 目标页参数预填”，源端深链监听把 pathname + search 整体交给路由；写错的样子：壳分发的派工输入只有分发方本 feature 的规格，没有列出各目标页的参数类，也没带目标页功能规格里的壳契约（如“壳 push(path + query)”“页面状态全部来自路由参数”）
适用范围：规划或派工把壳的深链/路由分发交给一个切片、目标页归其他切片实现时
做法：
- 派工输入里按路由列出：目标页、它导出的参数类、对应功能规格里写的壳契约（push 时带哪些 query 键）
来源：1 张卡，1 个应用
