# 并行派发页面转换前，先定下唯一的路由参数类文件，并在每份派工里写明一律 import 它

审的是：计划与派工
触发（任一种）：
- 读到：源端路由是带 {id} 占位的字符串模板，多个页面将由不同 agent 并行或分批生成；写错的样子：计划和派工说明里没有规定路由参数类的唯一来源文件和字段，页面转换派工只说「路由注册归某切片」
适用范围：计划或路由宿主阶段，在并行派发页面转换、切片接线任务之前
做法：
- 先固定 canonical 路由参数类的唯一文件与各类字段（该文件不 import 任何页面），再在每个转换、切片派工里写明「导航参数一律 import 该文件里的类，不新建同形类」
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- ArkTS 不支持 structural typing：各页各写一个同形类时 instanceof 互不命中，所以要在派工前定下唯一来源（出处：typescript-to-arkts-migration-guide.md，不支持structural typing）
