# 全局约定登记了布局方向镜像时，每个 UI worker 的派工都带上这一条

审的是：计划与派工
触发（任一种）：
- 读到：ui-manifest 全局约定里有布局方向镜像（RTL）要求，或源清单 android:supportsRtl="true"；写错的样子：写界面的 worker 的派工说明里没有布局方向镜像、start/end 边距这一条
适用范围：给写界面组件、页面的 worker 派工时
做法：
- 每份 UI 派工里写明：布局随方向镜像，源端 Start/End 属性写 start/end（LengthMetrics），对齐与边距同用逻辑键
来源：1 张卡，1 个应用
