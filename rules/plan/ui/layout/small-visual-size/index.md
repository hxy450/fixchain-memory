# 小视觉元素尺寸的转述和对齐说法

agent 会看到什么：源码里小视觉元素的尺寸由计数分支和密度分支算出，派工、消息或交付报告里只写「改成 N vp」「按 Android 真机密度对应为 N vp」「已按真机对齐」，没有源函数依据或编译、截图对照

## 规矩

- rule-a6a4a7c8e4c2｜协调者转述或改写小视觉元素尺寸时，附上源函数和所取分支作依据｜读到：协调者读过的源码里，这个元素的尺寸由计数分支和密度分支算出；写错：给子代理的派工或消息里只写「改成 N vp」「按 Android 真机密度对应为 N vp」这类结论，没有源函数和分支依据
- rule-efe4cac4e3d9｜小视觉元素没编译或截图对照时，报告按未验证登记，不写「按真机密度对应」｜写错：交付报告或回复里写「尺寸按 Android 真机密度对应为 N vp」「已按真机对齐」，而这一轮没有编译，也没有真机或截图对照
