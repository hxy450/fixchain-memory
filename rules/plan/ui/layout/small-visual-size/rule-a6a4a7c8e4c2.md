# 协调者转述或改写小视觉元素尺寸时，附上源函数和所取分支作依据

审的是：计划与派工
触发（任一种）：
- 读到：协调者读过的源码里，这个元素的尺寸由计数分支和密度分支算出；写错的样子：给子代理的派工或消息里只写「改成 N vp」「按 Android 真机密度对应为 N vp」这类结论，没有源函数和分支依据
适用范围：主会话或协调者给实现子代理下发、改写尺寸数值时
做法：
- 派工或转述里写明：尺寸出自哪个源函数、走的是哪个计数分支和密度分支、dp 到 vp 的换算；说不出依据的数值不下发
来源：1 张卡，1 个应用
