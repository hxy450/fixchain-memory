# 派工里转述的位图固有尺寸

agent 会看到什么：规格映射写位图「固有 px（按密度换算）」、资源迁移回报写了图块取自哪个密度目录（如 drawable-xxxhdpi），派工把它改写成 getWidth / getHeight 一类具体取值 API，丢了换算条件，或用这些位图做几何计算的派工没带来源密度目录

## 规矩

- rule-e1a1b5220f0a｜派工转述位图固有尺寸映射时保留密度换算条件，带上资源的来源密度目录｜读到：规格映射写「固有 px（按密度换算）」，资源迁移回报写了图块取自哪个密度目录（如 drawable-xxxhdpi 的 px 对应多少 vp）；写错：派工把它改写成「固有尺寸 getWidth/getHeight 供格尺寸」这类具体取值 API，丢了换算条件；用这些位图做几何计算的派工里没有来源密度目录
