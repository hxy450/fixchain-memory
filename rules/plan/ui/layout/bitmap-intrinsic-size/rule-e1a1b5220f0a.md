# 派工转述位图固有尺寸映射时保留密度换算条件，带上资源的来源密度目录

审的是：计划与派工
触发（任一种）：
- 读到：规格映射写「固有 px（按密度换算）」，资源迁移回报写了图块取自哪个密度目录（如 drawable-xxxhdpi 的 px 对应多少 vp）；写错的样子：派工把它改写成「固有尺寸 getWidth/getHeight 供格尺寸」这类具体取值 API，丢了换算条件；用这些位图做几何计算的派工里没有来源密度目录
适用范围：派发用位图固有尺寸参与几何计算的自绘视图任务时
做法：
- 派工照原样保留规格里的换算条件（按来源目录 dpi 换算到设备 dpi），不改写成 getWidth/getHeight 等具体取值 API
- 资源迁移回报已给出来源密度目录的，把目录和 dpi 写进使用这些位图做几何计算的派工
来源：1 张卡，1 个应用
