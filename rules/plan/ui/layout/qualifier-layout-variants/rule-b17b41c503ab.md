# 「随迁」的限定符变体要点名文件并归属到页面 spec 或 slice，未入图的要有人接手

审的是：计划与派工
触发（任一种）：
- 读到：ui-graph 回报「layout-sw600dp / layout-v21 未入图」，或源 res 下有 layout-sw600dp/ 等变体目录；写错的样子：决策台账或计划写「sw600dp 仅 1 布局变体随迁」之类，没点名文件、没归属到任何页面 spec、slice 或派工；未入图的变体没有步骤接手
适用范围：计划阶段登记布局限定符变体的去向时
做法：
- 「随迁」决策点名每个变体文件，并归属到具体页面 spec 或 slice；ui-graph 未入图的变体登记给某个步骤接手；做不到的视为未分配
来源：1 张卡，1 个应用
