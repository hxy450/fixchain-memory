# 页面登记了横屏布局变体且由共享组件承载时，把变体写进该组件的产出和验收

审的是：计划与派工
触发（任一种）：
- 读到：页面 meta 登记了 layout_variants_landscape，或计划的资源段写「layout-land/*.xml 由 ArkUI 声明式重建，下游承接」；写错的样子：派工和计划里承载该布局的共享组件，产出只写竖屏骨架（「…结构」「数据驱动消除重复」），横屏变体只出现在资源扫描任务里
适用范围：计划与派工阶段，源布局的横屏或宽屏变体由另一任务的共享组件承载时
做法：
- 在该组件的产出和验收里写变体路径和要求，例：「组件含 layout-land/<布局名>.xml 横屏分支」；不只放进资源扫描任务
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- base目录、限定词目录、rawfile目录、resfile目录称为资源目录，element、media、profile称为资源组目录：目标端没有 layout 资源组，资源任务承接不了布局变体（出处：resource-categories-and-access.md，资源分类）
