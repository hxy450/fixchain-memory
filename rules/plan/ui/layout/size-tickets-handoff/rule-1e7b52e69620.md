# 派修等高问题时把「两卡等高」写成验收条件，不只给「改固定高度对齐 Android」

审的是：计划与派工
触发（任一种）：
- 读到：验收报告写着 Android「两卡等高一行」，修法候选写「右列去掉 weight 改固定 / 与左卡等高」；写错的样子：派工只写「移除 layoutWeight 或改固定高度（对齐 Android 卡片的实际高度）」，没有把两卡等高写成验收条件
适用范围：验收后派修布局问题、源端语义是兄弟跟随等高时的派工说明
做法：
- 派工和修法候选里写明验收条件：右卡高度始终等于左卡实测高度（两卡等高），不只给出可被理解为常量的「改固定高度」修法
来源：1 张卡，1 个应用
