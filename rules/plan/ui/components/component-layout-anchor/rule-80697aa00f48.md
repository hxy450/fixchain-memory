# brief 写回 PASS 前，每个公共组件都要能指回一条安卓布局或现有框架组件

审的是：计划与派工
触发（任一种）：
- 读到：派工里给了共享组件表，每行标着安卓 Adapter/item 布局，或标着归属现有框架组件；写错的样子：brief 写回了 `final_state: PASS`，但没有逐个组件写明它对应的安卓布局或现有组件，或者有组件指不回表里任何一行
适用范围：基础层公共组件任务的 brief 写回完成状态时
做法：
- 标 PASS 前逐个组件写一行来源：对应共享组件表的哪一行，取自哪份安卓 item 布局或哪个现有框架组件
- 有组件指不回任何安卓布局或现有组件的，状态不写 PASS，把这几行记成未完成
来源：1 张卡，1 个应用
