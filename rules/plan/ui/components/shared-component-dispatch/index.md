# 公共组件库和共享原语的派工清单

agent 会看到什么：派工要逐个写公共组件或把页面内联原语收敛到共享实现，读写顺序把被依赖的 Modifier 源文件排在后面，或清单只点名了规格 mapping 里的部分共享原语小节

## 规矩

- rule-08ab5b378f6c｜派工公共组件库时，把被依赖的 Modifier 源文件排在消费它的组件前面，或随组件一起读｜读到：Compose 源组件用的自定义 Modifier 扩展（渐变描边等）定义在另一个源文件里；写错：派工要求「逐组件读源 → 立即写」，却把被依赖的 Modifier 源文件排在消费它的组件之后，写组件时还没读到边宽等参数
- rule-b7a8fef5dc3f｜收敛派工的清单逐条列出 mapping 里的全部共享原语，含阴影映射节｜读到：规格 mapping 里有多节共享原语（Surface、Divider、Button、阴影映射等），派工要把页面里内联的原语换成共享实现；写错：收敛派工的清单只点名部分小节，漏了阴影映射节；没要求 worker 对读到的 mapping 节逐项对账
