# 派工公共组件库时，把被依赖的 Modifier 源文件排在消费它的组件前面，或随组件一起读

审的是：计划与派工
触发（任一种）：
- 读到：Compose 源组件用的自定义 Modifier 扩展（渐变描边等）定义在另一个源文件里；写错的样子：派工要求「逐组件读源 → 立即写」，却把被依赖的 Modifier 源文件排在消费它的组件之后，写组件时还没读到边宽等参数
适用范围：派发公共组件库的转换任务、排组件顺序和读源要求时
做法：
- 派工清单里把被组件依赖的 Modifier 源排在消费它的组件之前，或在该组件条目里写明随它一起读哪个源文件
来源：1 张卡，1 个应用
