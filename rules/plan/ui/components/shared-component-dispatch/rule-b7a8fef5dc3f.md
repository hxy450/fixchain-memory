# 收敛派工的清单逐条列出 mapping 里的全部共享原语，含阴影映射节

审的是：计划与派工
触发（任一种）：
- 读到：规格 mapping 里有多节共享原语（Surface、Divider、Button、阴影映射等），派工要把页面里内联的原语换成共享实现；写错的样子：收敛派工的清单只点名部分小节，漏了阴影映射节；没要求 worker 对读到的 mapping 节逐项对账
适用范围：把页面内联写法替换成共享组件和令牌的收敛派工
做法：
- 派工清单逐条列出 mapping 中的全部共享原语，包括阴影映射节和它覆盖的组件
- 派工里写明：worker 对读到的 mapping 节逐项对账，替换完成前不整文件重写
来源：1 张卡，1 个应用
