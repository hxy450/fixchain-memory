# 页面转换先于公共组件库派发时，派工列出该页应消费的共享组件并要求页内副本登记 forward-ref

审的是：计划与派工
触发（任一种）：
- 读到：UI 清单的共享组件表把某组件列为多页共用，公共组件库的派发排在页面转换之后；写错的样子：页面转换派工写「公共组件库未完成，同页内联等价实现优先」，没列该页应消费的共享组件，也没要求页内副本登记 forward-ref 待替换
适用范围：编排派工阶段，页面转换先于公共组件库派发、页面会用到共享组件时
做法：
- 派工里列出该页应消费的共享组件，要求页内的等价实现登记 forward-ref，写明共享组件就绪后替换
- 或者调整顺序，先完成共享组件再派页面转换
