# 多页共用的自定义组件

agent 会看到什么：源码里同一个自定义组件（@Composable）被多个页面调用，或 UI 清单把它列为共享组件；页面转换派工或巡检单只顾到眼前这一处调用点

## 规矩

- rule-a92dd93f2fc1｜页面转换先于公共组件库派发时，派工列出该页应消费的共享组件并要求页内副本登记 forward-ref｜读到：UI 清单的共享组件表把某组件列为多页共用，公共组件库的派发排在页面转换之后；写错：页面转换派工写「公共组件库未完成，同页内联等价实现优先」，没列该页应消费的共享组件，也没要求页内副本登记 forward-ref 待替换
- rule-9d045fdaa952｜巡检发现共享组件某个调用点偏离时，按组件名查全部调用点逐一核对｜读到：源码里同一个自定义组件在多个页面被调用；写错：巡检单只列出报告里的那一处调用点（如搜索结果图缺圆形裁剪），没列同一组件的其他调用点
