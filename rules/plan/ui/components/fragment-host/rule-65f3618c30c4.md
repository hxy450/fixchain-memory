# 子组件改不到宿主的沉浸时，移交项登记宿主 Tab 顶部 padding 和状态栏图标颜色

审的是：计划与派工
触发（任一种）：
- 读到：源码宿主 Fragment 有 `ImmersionBar.with(this).titleBarMarginTop(...)`，目标把该 Tab 拆成子组件、宿主页面另由别人写；写错的样子：转换报告只写 `immersive_safearea_skipped`，移交项里没有「宿主对该 Tab 取消顶部 padding、切换状态栏图标颜色」的交接
适用范围：Tab 子组件的转换报告和移交项登记
做法：
- 移交项登记一条宿主交接：哪个 Tab 不加顶部避让 padding、标题栏需加状态栏高度、切到该 Tab 时状态栏图标用什么颜色
来源：1 张卡，1 个应用
- case-0dd25455d592a77ed652（app_hnaccurateweather_live_android）：做法第 1 步 ← 建议 2
