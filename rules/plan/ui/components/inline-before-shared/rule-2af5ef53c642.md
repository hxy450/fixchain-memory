# 页面先于共享弹窗组件落盘时，页内副本登记待收敛，不关为 resolved

审的是：计划与派工
触发（任一种）：
- 读到：派工写「共享组件未落盘则页内内联实现，改 resolved」；多个弹窗共用平台对话框外观；写错的样子：页内照抄兄弟页的弹窗框体，占位登记项被关成 resolved，没有登记待收敛，也没有安排共享件就绪后替换
适用范围：多个页面的弹窗共用平台对话框外观、共享弹窗组件与页面由不同任务并行或先后实现时
做法：
- 标题、按钮和投影由共享组件导出的原语提供；共享件晚于页面落盘时，页内副本登记为待收敛项
- 共享件就绪后在本任务或收口任务把页内副本替换成共享原语，再关闭登记项；不按派工直接关为 resolved
来源：1 张卡，1 个应用
