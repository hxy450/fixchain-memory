# 页面先于共享工具落盘时内联的副本，要登记 FWD-REF 并指向具体切片，不只写「随后收敛」

审的是：计划与派工
触发（任一种）：
- 读到：页面转换时共享工具还没落盘，页面需要同名的格式化函数；写错的样子：页面里内联了共享函数的副本，只在转换报告或注释里写「收敛归某切片」「随后切换 import」；占位登记里没有 `FWD-REF`，被点名的切片计划里也没有这一项
适用范围：页面转换早于共享工具落盘、页面内联共享函数副本时
做法：
- 登记占位 `FWD-REF`，resolve_by 指向具体切片和步骤，并确认那个切片的计划里有这一项；或者直接引用共享实现
