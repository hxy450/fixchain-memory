# 公共组件未完成时的页内等价实现

agent 会看到什么：公共组件库还没完成，派工写「同页内联等价实现优先」，没附 feature 规格里的显示公式条目，也没安排之后改用公共组件

## 规矩

- rule-5c442a522d17｜派工允许页内内联等价实现时，附上规格的显示公式条目并安排之后改用公共组件｜读到：公共组件库还没完成，页面依赖其中的显示组件；写错：派工写「公共组件未完成时同页内联等价实现优先」，没附 feature 规格里的显示公式条目（如显示进度换算），也没安排公共组件就绪后页面改用它
- rule-2af5ef53c642｜页面先于共享弹窗组件落盘时，页内副本登记待收敛，不关为 resolved｜读到：派工写「共享组件未落盘则页内内联实现，改 resolved」；多个弹窗共用平台对话框外观；写错：页内照抄兄弟页的弹窗框体，占位登记项被关成 resolved，没有登记待收敛，也没有安排共享件就绪后替换
- rule-2a2a92ae3fa6｜页面先于共享工具落盘时内联的副本，要登记 FWD-REF 并指向具体切片，不只写「随后收敛」｜读到：页面转换时共享工具还没落盘，页面需要同名的格式化函数；写错：页面里内联了共享函数的副本，只在转换报告或注释里写「收敛归某切片」「随后切换 import」；占位登记里没有 `FWD-REF`，被点名的切片计划里也没有这一项
