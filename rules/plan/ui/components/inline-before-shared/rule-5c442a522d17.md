# 派工允许页内内联等价实现时，附上规格的显示公式条目并安排之后改用公共组件

审的是：计划与派工
触发（任一种）：
- 读到：公共组件库还没完成，页面依赖其中的显示组件；写错的样子：派工写「公共组件未完成时同页内联等价实现优先」，没附 feature 规格里的显示公式条目（如显示进度换算），也没安排公共组件就绪后页面改用它
适用范围：派工允许页面先内联实现公共组件的等价逻辑时
做法：
- 派工附上对应 feature 规格里的显示公式条目（写明条目号）
- 或在计划里安排公共组件就绪后页面改用该组件，删掉页内副本
来源：1 张卡，1 个应用
