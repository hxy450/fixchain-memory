# 计划要求直调归零时，把公共能力的建立落到具体批次、产物路径和验收命令

审的是：计划与派工
触发（任一种）：
- 读到：审计列出吐司直调散落，要求建立统一 ToastService；写错的样子：计划只写「对应业务完成时调用数归零」，没有写哪个批次产出 ToastService、放在哪个模块路径并导出，也没有调用归零的验收命令
适用范围：规划阶段，计划里要求建立横切的公共能力（如统一吐司）并让业务侧直调归零时
做法：
- 在计划里把公共能力的建立落到具体批次和产物路径（如公共模块批次产出 ToastService 并从 Index.ets 导出），排在依赖它的业务批次之前
- 同时给出调用归零的验收命令（rg 统计各种吐司直调，结果为 0）
