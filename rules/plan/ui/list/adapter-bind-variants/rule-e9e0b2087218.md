# 列表页的源布局清单要列全各类 item 布局和动态 inflate 的布局

审的是：计划与派工
触发（任一种）：
- 读到：列表页源码的 Adapter 有多个 viewType，holder 运行时 inflate 或 addView 别的布局；写错的样子：页面 meta.json 的 layout_sources 只列了部分类型（如推广项）的布局，recycler_item_layouts 为空，没交付普通项 item 布局和它动态 inflate 的预览布局
适用范围：规格 / 数据准备阶段为列表页生成交给转换者的源布局清单时
做法：
- layout_sources / recycler_item_layouts 列全每个 viewType 的 item 布局，以及 holder 动态 inflate 或 addView 的视图布局
来源：1 张卡，1 个应用
- case-5b1b0e2ce03be0dc6d37（组件岛Widget Island）：做法第 1 步 ← 建议 4
