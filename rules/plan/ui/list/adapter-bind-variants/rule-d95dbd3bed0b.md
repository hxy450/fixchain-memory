# 共享组件缺覆盖参数、本任务又不能改它时，登记跨文件交接，不把占位记为已闭合

审的是：计划与派工
触发（任一种）：
- 读到：源端子类 adapter 改配了按钮外观，共享行组件不在本任务的写盘范围内；写错的样子：占位登记把 P-S… 记为已闭合，没有登记给共享组件作者的交接项，按钮外观仍是默认
适用范围：消费页需要共享组件新增参数、但无权改共享文件时的占位和移交登记
做法：
- 登记一条跨文件交接（要共享组件补哪个覆盖参数），占位保持未闭合，直到共享组件补上并接线
来源：1 张卡，1 个应用
