# 数据接线切片的派工带上列表键复用陷阱，或在页面键契约旁写明更新方式约束

审的是：计划与派工
触发（任一种）：
- 读到：转换阶段的陷阱清单里有列表键复用条目（键只含 id 时同 id 新实例不刷新，如 pitfalls 的 P-05），页面的键契约只写了键的组成；写错的样子：负责事件处理或数据接线的切片派工只列状态管理、数据层等技能，没有这条陷阱，页面键契约旁也没注明「换实例要变键 / 只在原实例上改 @Trace 字段」；续收或重试的转换器只 grep 了个别条目
适用范围：编排派工阶段，列表页由转换器写键、由后续切片写条目更新时
做法：
- 给负责事件处理或数据接线的切片派工附上列表刷新的陷阱条目，或在页面键契约旁注明更新方式约束
- 续收或重试的转换器派工要求重新加载完整陷阱清单，不只 grep 个别条目
