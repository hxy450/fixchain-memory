# 批量重构的验收把受影响列表页纳入真机冒烟，数据没加载出来的记为未验证

审的是：计划与派工
触发（任一种）：
- 读到：重构计划的验收写模块编译、静态审计、该域测试和至少一个主链 smoke；写错的样子：验收只看编译通过和旧符号 grep 计数归零，冒烟清单里没有被改写的列表页；页面停在加载中看不到列表，却记为通过
适用范围：批量改写列表渲染方式的重构任务的验收和冒烟覆盖清单
做法：
- 冒烟清单逐个列出被改写列表所在的页面，每页要看到列表实际渲染出内容
- 页面因数据未加载而看不到列表时，在报告里记为「未验证」，不记为通过
