# 派工让一个页面承载多个半模态弹层时，写明一组件只挂一个 bindSheet、各用零尺寸锚点

审的是：计划与派工
触发（任一种）：
- 读到：规格把同一页面的多个弹窗列为各自独立的弹出目标；写错的样子：派工只列 sheet 槽位（如「某某 Sheet + 某某 Dialog 槽位留给后续切片」），没有写「一组件只能有效挂一个 bindSheet，每个 sheet 挂独立零尺寸锚点」这条约束
适用范围：页面转换和接线的派工里，一个页面要挂多个半模态弹层时
做法：
- 在派工里写上：「一组件只能有效挂一个 bindSheet；每个 sheet 挂在独立的零尺寸锚点 Column().width(0).height(0) 上，不在同一组件上连写」
来源：1 张卡，1 个应用
