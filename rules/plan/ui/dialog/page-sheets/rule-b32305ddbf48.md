# 源端是当前页弹窗时，计划任务不写「保留 HMRouter 路由和返回栈」

审的是：计划与派工
触发（任一种）：
- 读到：规格或源码说明入口是在当前页 show 的底部弹窗（Dialog / BottomSheet）；写错的样子：计划任务要求「保留 HMRouter 路由和返回栈」，或者让宿主带参数 push 一个路由页来打开这个面板
适用范围：给当前页弹窗类入口拆任务、写派工说明时
做法：
- 任务写成宿主页内叠层（或 bindSheet / CustomDialog），关闭回调由宿主持有；验收写宿主页可见、点背景关闭、不入返回栈
