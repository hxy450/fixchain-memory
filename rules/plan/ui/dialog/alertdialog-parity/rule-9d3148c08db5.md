# 目标偏离源端可观察行为时，按次数核对等价性，要偏离就写进 decision_gaps 或决策台账待批

审的是：计划与派工
触发（任一种）：
- 读到：源码里弹窗、回调或副作用按命中次数发生多次；写错的样子：source-notes 差异清单或代码注释写「收敛」「幂等」「罕见路径」「可观察等价（用户只见前窗）」，目标触发次数少于源端；handback 的 decision_gaps 为空，决策台账里没有这一项
适用范围：切片实现交回时，目标相对源端有收敛或省略的行为
做法：
- 判断等价时按交互次数、回调与副作用次数核对：要点几次、落盘几次、遮罩是否叠加，不以视觉印象代替
- 仍要偏离源端时，写进 handback 的 decision_gaps 或决策台账作为待批决策；source-notes 和代码注释里的登记不算批准，无人值守的自动批准也不算用户改判
