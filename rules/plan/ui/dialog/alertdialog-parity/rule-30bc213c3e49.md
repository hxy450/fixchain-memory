# 共享弹窗晚于页面就绪时，收敛评估要按源端平台外观逐项比对，不只比遮罩和按钮顺序

审的是：计划与派工
触发（任一种）：
- 读到：占位登记里有一项「页内弹窗改用共享平台对话框件」，共享件晚于页面就绪；写错的样子：评估只写「与共享件行为一致」「更贴源」就保留页内实现，比的只是遮罩、按钮顺序，没有逐项比对源端平台外观
适用范围：收敛评估页内弹窗要不要换成共享的平台对话框复刻件时
做法：
- 按源端平台外观逐项比对：标题、消息、内容布局、输入框底、按钮集合与文案、打开时聚焦；有一项不符就按占位登记换成共享件，不以行为一致收口
