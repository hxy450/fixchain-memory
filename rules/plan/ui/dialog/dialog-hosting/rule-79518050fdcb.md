# 批量改造弹层前先生成逐项弹层矩阵，移交和日志原样引用映射目标 API

审的是：计划与派工
触发（任一种）：
- 读到：已批准的计划要求先生成逐项弹层矩阵，映射写「BottomPopup → showBindSheet / 系统半模态」；写错的样子：批量宿主化前没有弹层矩阵；handoff 或执行日志把目标改述成「page-hosted popup/sheet」「恢复关闭、返回、遮罩」，不再写 showBindSheet
适用范围：一批弹层（底部弹窗、对话框）迁移或改造的计划、派工和移交
做法：
- 动手前生成弹层矩阵，每个弹层一行：Android 基类、目标 API（如 showBindSheet）、mask / back / drag 行为
- handoff 和执行日志里目标 API 照映射原样写，不改述成泛化的说法；「去掉路由、能关闭」不算完成映射
来源：1 张卡，1 个应用
