# 系统栏底色和深色适配的派工

agent 会看到什么：规格或台账要求状态栏底色、交付风险里有系统栏内容色未适配深色，派工限定只改配置文件、禁碰页面文件，或事项只留在交付风险里，没进 decision_gaps、负责切片的派工或账本

## 规矩

- rule-79399f8ec1eb｜派工要求系统栏底色又禁碰页面文件时，先确认能否在边界内正确实现，冲突写进 decision_gaps｜读到：规格或台账要求状态栏底色，skill 的沉浸方案要求透明系统栏、由页面铺底色；写错：派工写「核验系统栏配色是否含 #…，缺则补」，同时把写盘边界限定为配置文件、禁碰页面文件；或交回的信封里 decision_gaps 没报这个冲突、只改了 statusBarColor
- rule-0529806b0b98｜推迟系统栏深色适配时，把事项写进负责主题切换的切片派工或账本｜读到：入口装配者的交付风险里写了系统栏内容色未适配深色，主会话批注「不要修（主题管线归属）」；写错：负责主题切换的切片派工里没有带上这一事项，账本里也没有登记；事项只留在交付风险里
