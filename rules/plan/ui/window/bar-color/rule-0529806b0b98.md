# 推迟系统栏深色适配时，把事项写进负责主题切换的切片派工或账本

审的是：计划与派工
触发（任一种）：
- 读到：入口装配者的交付风险里写了系统栏内容色未适配深色，主会话批注「不要修（主题管线归属）」；写错的样子：负责主题切换的切片派工里没有带上这一事项，账本里也没有登记；事项只留在交付风险里
适用范围：主会话把某个已知缺口推给后续切片处理时
做法：
- 推迟的事项写进接手切片的派工（写明要改的入口文件和要求：系统栏内容色按生效 colorMode 计算并在 onConfigurationUpdate 重设），并在账本登记，接手切片交回时核对是否已处理
来源：1 张卡，1 个应用
- case-e1b1f9786e31a8d527cc（AntennaPod）：做法第 1 步 ← 建议 3、诊断
