# 派工要求系统栏底色又禁碰页面文件时，先确认能否在边界内正确实现，冲突写进 decision_gaps

审的是：计划与派工
触发（任一种）：
- 读到：规格或台账要求状态栏底色，skill 的沉浸方案要求透明系统栏、由页面铺底色；写错的样子：派工写「核验系统栏配色是否含 #…，缺则补」，同时把写盘边界限定为配置文件、禁碰页面文件；或交回的信封里 decision_gaps 没报这个冲突、只改了 statusBarColor
适用范围：派工里限定写盘边界、同时要求状态栏底色这类视觉项时，以及 worker 交回的信封
做法：
- 派工限定写盘边界前，确认状态栏底色能否只在允许的文件里正确实现；需要页面自绘时把页面文件列进边界
- worker 遇到这种冲突时，在返回信封的 decision_gaps 里报告，不只改 statusBarColor 去满足验收截图
