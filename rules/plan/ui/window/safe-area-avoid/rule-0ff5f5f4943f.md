# 安全区前向引用的登记写明顶、底两侧，解除时两侧都核对，不只兑现写到的一侧

审的是：计划与派工
触发（任一种）：
- 读到：WindowModel 契约写明前景避让统一读 windowTopPadding / windowBottomPadding；写错的样子：Layer 3 前向引用的登记文本只写一侧（如「列表底部 padding 消费 inset」），或写「顶部避让随基座兑现」；派工照登记只要求接底部
适用范围：页面实现和切片接线阶段，登记、派发、解除沉浸式安全区的前向引用时
做法：
- 登记 Layer 3 前向引用时把顶、底两侧的落点都写进触发文本，不写「随基座兑现」
- 解除时按 WindowModel 契约核对顶、底两侧是否都已在本页消费，不只兑现登记文本写到的那一侧
来源：1 张卡，1 个应用
