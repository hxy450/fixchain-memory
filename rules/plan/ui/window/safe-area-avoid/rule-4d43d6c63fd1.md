# 标题栏避让前向项标已解除前，确认页面里顶部避让值确实用在 padding 上

审的是：计划与派工
触发（任一种）：
- 读到：前向项登记里有标题栏避让项（暂用系统标题栏，待改 hideTitleBar 加自绘工具栏）；写错的样子：回报、信封或前向项登记里把这项写成已解除，而对应页面文件里顶部避让值没出现在任何 padding 里（只声明或 connect 了窗口模型）
适用范围：兑现标题栏避让前向项后，更新前向项状态和写回报时
做法：
- 标已解除前在页面文件里搜顶部避让值，至少出现在一处 .padding({ top: … }) 里才标已解除；搜不到就保持未解除，回报里照实写没接上
