# 各导航模式避让值相同、视觉占用不同时，交付说明标明未验证的模式，不下「视觉不受影响」结论

审的是：计划与派工
触发（任一种）：
- 读到：避让值只取 getWindowAvoidArea(TYPE_NAVIGATION_INDICATOR).bottomRect.height 一个 px 值，代码不区分三键和手势模式；写错的样子：交付说明写「手势模式仅有微小增量，视觉不受影响」一类没有实测依据的结论，没列出哪些导航模式未验证
适用范围：底部避让改动的交付说明、移交项
做法：
- 交付说明逐个导航模式写明是否实测、实测的避让值；没测的标「未验证」
- 同一避让值在不同模式下视觉占用不同时，写明要另找模式信号或请用户取舍，不自行下结论
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 同一台设备上两种导航模式的 TYPE_NAVIGATION_INDICATOR 避让值相同（84px），但手势小白条视觉上只占约 9–13vp：避让值本身区分不了导航模式（出处：卡里修好并验证过）
未核实：两种模式避让值相同只在一款真机上观察
