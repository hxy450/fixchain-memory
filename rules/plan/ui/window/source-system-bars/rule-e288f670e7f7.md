# 派工把沉浸字段缺失当 false 跳过时，改为按页面规格 page_type 判定的值实施

审的是：计划与派工
触发（任一种）：
- 读到：页面规格按 page_type=full_screen_page 判定 needs_immersive_safearea=true；派发模板写「仅当 meta.json needs_immersive_safearea: true 时实施，false 时跳过」；写错的样子：派工写「needs_immersive_safearea 缺失→按 false 处理」「false/缺失时跳过本契约」
- 写错的样子：转换报告或页头注释写「meta.json 无 needs_immersive_safearea，按 false 跳过」，而页面规格判定为 true，报告里没标冲突
适用范围：派工和转换阶段决定某页是否实施沉浸避让契约时
做法：
- 派工的沉浸需求以页面规格按 page_type 判定的值为准；meta.json 缺这个字段时不翻译成 false
- 转换者遇到派工与页面规格冲突时，按规格 / page_type 实施，并在报告里标出这条冲突
