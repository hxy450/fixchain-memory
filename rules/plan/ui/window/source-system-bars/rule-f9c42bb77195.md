# 派工只写源端逐边的系统栏形态，不预写与之冲突的系统栏 API 参数

审的是：计划与派工
触发（任一种）：
- 读到：源 Activity 只有 FLAG_FULLSCREEN + FEATURE_NO_TITLE，导航栏可见；写错的样子：派工里预写了 setWindowSystemBarEnable([]) 等隐藏全部系统栏的参数，或写「游戏全屏就隐藏系统栏」
- 读到：写者交回报告把「与源端可见系统栏不一致」列为风险；写错的样子：派工和规格没按源码逐边形态改，以游戏全屏惯例或经验摘要收口
适用范围：派工里写入口窗口和页面系统栏、安全区要求，以及处理写者回报的系统栏风险时
做法：
- 派工只写源端逐边形态（状态栏隐藏、导航栏可见、应用窗口止于导航栏之上），不预写与之冲突的系统栏 API 参数
- 写者回报「与源端可见系统栏不一致」时，回到源码逐边形态改派工或规格，不以全屏惯例或经验摘要维持原判
