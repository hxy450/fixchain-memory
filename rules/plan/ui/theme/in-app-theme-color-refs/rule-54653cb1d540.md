# 关闭「全局主题切换」占位或定主题合流范围时，按全部 UI 文件的取色检索命中收敛

审的是：计划与派工
触发（任一种）：
- 读到：规格写主题对象驱动全组件令牌、验收要求换调色板后全局令牌切换；写错的样子：「全局主题」「调色板选择 + 全局主题」一类占位被记为已解除，而 UI 文件里仍有调色板角色色的 $r('app.color.…') 或 getColorSync
- 读到：某切片回报「只改一处会与其余页面制造混合状态」；写错的样子：主题合流的派工范围只列了部分页面的组件，其余页面和弹层没有分派
适用范围：主题负责切片关闭全局主题类占位、或编排者确定主题收敛范围时
做法：
- 对全部 UI 文件检索 $r('app.color.' 与 getColorSync(，命中的调色板角色色逐个改成主题令牌；超出本切片写盘边界的登记给负责方，没收完不把占位记为已解除
- 收敛范围定为检索出的全部消费点，逐个分派到负责方
来源：1 张卡，1 个应用
