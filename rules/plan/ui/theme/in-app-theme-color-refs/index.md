# 应用内主题切换和页面里的 $r 取色点

agent 会看到什么：规格或主题层写主题由应用内设置、调色板驱动，页面渲染期读主题对象令牌、不走 $r，而已生成的页面和组件里有 $r('app.color.…')、getColorSync 取色；占位登记、移交项、「全局主题」占位的关闭或主题合流的派工没有按文件覆盖这些取色点

## 规矩

- rule-814516b80fbc｜主题对象还没建、页面先用 $r 色时，逐文件登记改读主题令牌的移交项｜读到：页面规格写主题由应用内设置驱动、多套调色板切换全局主题；资源映射写动态色归主题对象运行期承接；color.json 只有一套 base/dark 键；写错：页面写满 $r('app.color.…') 和 getColorSync 取色，却没登记改读主题令牌的移交项；只在转换报告或低置信区写「应用内覆盖随某占位接线」，而那个占位的触发文本不含页面色
- rule-54653cb1d540｜关闭「全局主题切换」占位或定主题合流范围时，按全部 UI 文件的取色检索命中收敛｜读到：规格写主题对象驱动全组件令牌、验收要求换调色板后全局令牌切换；写错：「全局主题」「调色板选择 + 全局主题」一类占位被记为已解除，而 UI 文件里仍有调色板角色色的 $r('app.color.…') 或 getColorSync
- rule-8b048ab5c356｜主题层写下「页面读令牌、不走 $r」约定时，盘点已生成页面的取色点并逐文件登记收敛项｜读到：主题层自己写的消费约定：页面和组件渲染期读主题对象令牌、不走 $r（$r 色键只有一套值，跟不上调色板切换）；写错：登记的占位只覆盖壳层过渡件，已生成页面里的 $r 色键和 getColorSync 取色点没有逐文件登记收敛项和负责切片
