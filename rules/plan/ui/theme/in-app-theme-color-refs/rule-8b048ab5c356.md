# 主题层写下「页面读令牌、不走 $r」约定时，盘点已生成页面的取色点并逐文件登记收敛项

审的是：计划与派工
触发（任一种）：
- 读到：主题层自己写的消费约定：页面和组件渲染期读主题对象令牌、不走 $r（$r 色键只有一套值，跟不上调色板切换）；写错的样子：登记的占位只覆盖壳层过渡件，已生成页面里的 $r 色键和 getColorSync 取色点没有逐文件登记收敛项和负责切片
适用范围：主题层（Base）建立主题对象和消费约定、而页面已先行生成时
做法：
- 检索已生成页面里的 $r('app.color.' 和 getColorSync( 命中，逐文件登记「改读主题令牌」的收敛项并写负责切片；派工不允许改页面时也要登记
