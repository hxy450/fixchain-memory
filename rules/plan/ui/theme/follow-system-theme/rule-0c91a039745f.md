# AC 的标侧文件或「后续阶段接线」没落到任何 packet 的写权里时，单独排一个接线 packet

审的是：计划与派工
触发（任一种）：
- 读到：规格的验收条目标侧写着某个主题文件（如跟随系统深色、darkTheme 选 DarkColors / LightColors），决策台账里对应的平台差异已批准；写错的样子：没有任何 packet 的输出或可写清单包含该标侧文件；只挂了 suggested_skills，或只在覆盖清单里把 AC 编号记到某个 slice，没补文件范围
- 写错的样子：派工或基础契约写「深色判断由 Stage 3 / 页面接线」「选色接线在后续阶段」，没写接收的 slice、要建或改的文件和写权；各 slice 的单写者范围都不含主题文件和公共组件
适用范围：计划与编排阶段，为跨页面和公共组件的能力（如主题、深色模式）分配执行单元、目标文件和写权时
做法：
- 逐条核对每个 AC 的标侧文件落在某个 packet 的输出或可写清单里；只挂 suggested_skills 或只在覆盖清单里记需求编号不算认领
- 把能力说成由后续阶段完成时，同时写明接收的 slice、要新建或修改的文件和写权；各 slice 都不含主题文件和公共组件时，单独排一个主题接线 packet：新建共享主题状态、应用壳订阅系统 colorMode、改组件与页面取色
