# 主题切片写盘范围外的静态主题引用逐文件登记交接，不以「下游自行消费」收尾

审的是：计划与派工
触发（任一种）：
- 读到：规格写主题「共享至全部页面」，已有页面用 $r('app.color.…') / $r('app.float.…') 静态绑定主题色和字号；写错的样子：交付说明或源码笔记写「不在此轮全量换绑」「下游消费 feature 归各 spec」，跨文件交接和 FWD-REF 里没有主题项
适用范围：负责主题运行时的切片交付时的交接登记
做法：
- 按全工程统计结果，把超出本切片写盘范围的静态主题引用逐文件登记交接（文件和要改成的主题读取方式），不写「下游 feature 自行消费」
来源：1 张卡，1 个应用
