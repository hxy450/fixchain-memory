# 验收要求页面底/文字/卡片随深浅切换时，计划里要有任务产出这些键的 base+dark 资源

审的是：计划与派工
触发（任一种）：
- 读到：验收条目写「背景/文本/卡片面色随深浅资源限定符切换」「页面配色令牌由深浅资源限定符自动生效」；写错的样子：计划把设计令牌任务收窄成 accent 色板，深色机制切片只做 ColorMode 切换，页面背景、文字、卡片、分隔线的 base+dark 色资源没有任何任务负责；派工没写键清单和深色取值来源
适用范围：计划阶段划分设计令牌、深色机制和页面转换的职责时
做法：
- 指定一个任务产出页面中性色键的 base/element/color.json 和 dark/element/color.json，派工里写明键清单和每个键深色值的来源（源主题的哪个深色块）
- 机制切片和页面转换的派工里写清谁出这些键，不让双方互相假定对方负责
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- resources 下建 dark 限定词目录并新建 color.json，与 base/element/color.json 定义同名颜色、给不同色值：跟随系统深浅色的自定义资源做法，每个要切换的键都要两份（出处：ui-dark-light-color-adaptation.md，应用跟随系统的深浅色模式）
来源：1 张卡，1 个应用
