# 台账列出的日志边界

agent 会看到什么：决策台账写「Android 日志对应边界统一改用该封装」并列出生命周期、网络、同步等边界，审计结论或整改计划里日志只有库版本、保留天数、等级这类配置条目

## 规矩

- rule-2a187595e26f｜台账要求按源端日志边界改用封装时，计划为每个边界写日志点和验收，不只写库配置｜读到：决策台账写「Android 日志对应边界统一改用该封装」，并列出生命周期、网络诊断、同步、推送、卡片刷新、日历导入、日志上传等边界；源端在同步各阶段、网络请求、卡片刷新、导入、本地增删改处调用写文件日志；写错：审计结论或整改计划里日志只出现日志库版本、保留天数（如「BqLog=7天」）、等级、异步、控制台这类配置条目，没有逐个边界的日志点和验收项
