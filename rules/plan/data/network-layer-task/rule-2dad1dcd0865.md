# 计划里的网络层任务没有 API 清单作依据时，先产出清单再派基础设施实现

审的是：计划与派工
触发（任一种）：
- 读到：源工程有独立的网络模块（Retrofit Service、BuildConfig.BASE_URL、鉴权拦截器、统一响应壳），流程要求先产出 API 清单（spec/baseline/api-inventory/）；写错的样子：规格产物里没有 API 清单；计划的网络层任务只写「网络层 (HTTP 请求封装)」，没有基址、接口路径、响应壳（成功码、message/data 字段）、鉴权头和网络权限
适用范围：规格提取到基础设施实现之间，安排 HTTP 请求封装和登录注册等调用的任务时
做法：
- 先跑 API 清单提取（子代理派发失败时按 skill 的降级条款在主线程前台跑），清单里要有 base_urls、各 endpoint 路径、统一响应壳的成功码和 message/data 字段、鉴权头
- 清单齐了才进 Gate B 或派基础设施实现；网络层任务引用清单，写明基址、路径、成功码、鉴权头和 INTERNET 权限
