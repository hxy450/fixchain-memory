# 系统契约的偏好接口清单要给一次性引导标记配读写方法

审的是：计划与派工
触发（任一种）：
- 读到：行为提取里有由偏好标记控制、显示后写回标记的一次性 UI；写错的样子：系统契约或计划里偏好类的公共接口只列各设置开关的 get/set，没有引导标记的读写方法，单写者约定又不许别的 worker 改这个文件
适用范围：计划阶段写偏好类公共接口和单写者约定时
做法：
- 在偏好接口清单里给出该标记的读写方法：读「引导是否待显示」、写「引导已显示」，注明持久化键
