# 拆分或重派任务时，上游指派给原任务的全局动作（如 registerFont）逐条抄进新派工

审的是：计划与派工
触发（任一种）：
- 读到：上游交接写明某个全局动作由某任务落地（如「字体注册由主题任务执行，资源阶段只负责资产就位」）；写错的样子：拆分后的各段派工都没有这项要求（只要 Typography 常量表的 fontName、size、weight），也没写由哪一段承接
- 读到：子任务回报「字体文件注册不在本段范围」这类风险；写错的样子：下一段派工只写「文字用主题 Typography」，入口装配也没放注册，这项风险没有承接者
适用范围：编排阶段拆分、重派主题令牌或公共组件任务，并装配应用入口时
做法：
- 拆分或重派时，把原任务的全局动作逐条抄进新派工，写明由哪一段落地（如「本段负责 registerFont 注册函数，并在入口页 aboutToAppear 调用」）
- 子任务回报某项「不在本段范围」时，当场指定承接任务，或在入口装配时自己落地；收尾前 grep -rn registerFont entry/src/main/ets 核对
