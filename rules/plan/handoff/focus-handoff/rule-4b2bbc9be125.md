# 接手「焦点获取归本片」这类移交时，改挂页面根或落地获焦代码，只改返回值不算完成

审的是：计划与派工
触发（任一种）：
- 读到：转换报告或移交登记写「焦点获取细节归 Slice N」，规格写「onKeyDown → 页面 onKeyEvent」；写错的样子：接手方报告把这项记为完成，但 .onKeyEvent 仍挂在原子组件上、没有获焦代码，只把回调改成返回 boolean 或加了 KeyType.Down 守卫
适用范围：输入接线阶段接收的、关于按键挂载点或获焦的移交项
做法：
- 把这类移交当作显式验收项：要么把 .onKeyEvent 改挂到页面根节点，要么落地获焦代码并在报告里给出焦点证据
- 两样都没做的，移交项保持未完成，不因改了返回值或加了守卫就关闭
