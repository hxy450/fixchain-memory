# UI 转换先留业务占位时，TODO 写清源端成功和失败的全部动作，不只写调用名

审的是：计划与派工
触发（任一种）：
- 读到：源 Activity 点击后调 ViewModel，结果观察者里成功时写本地标记、跳页并 finish()，失败时 Toast；写错的样子：页面留的 `TODO` 只写「某某登录（调用名）」，头注释只写「成功跳某页」，没有写本地标记、关闭当前页和失败提示
适用范围：UI 转换阶段按「转 UI + 业务占位」留 TODO、把业务交给后面的接线阶段时
做法：
- TODO 里写清源端完整的成功和失败动作：写哪个本地标记、跳哪一页、是否关闭当前页、失败提示什么，并写出源端结果观察者所在的类和方法
针对本应用要查的：
- 点击调用在源端的结果处理：源工程里该 Activity/Fragment 的 LiveData 观察代码，按 ViewModel 的完成事件名找；把成功、失败分支的每个动作抄进 TODO
