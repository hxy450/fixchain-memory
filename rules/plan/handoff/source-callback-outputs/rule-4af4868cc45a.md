# 实现计划按分支列全源端副作用，失败分支不只写导航或留页

审的是：计划与派工
触发（任一种）：
- 读到：源页面结果回调（LiveData observe）的失败分支同时有 showToast 和跳转或留页；写错的样子：计划的迁移方案里失败分支只剩导航（「失败 → push(登录页)」「失败留当前页」），源端小节写过的 toast 在方案步骤里丢了
适用范围：实现计划里写源页面结果回调的迁移步骤时
做法：
- 每个结果分支写成一行副作用清单：导航目标、toast 或弹窗及其文案资源、标记写入、finish；迁移步骤逐项与源端小节对照，缺一项补一项
