# 交接摘要把多分支源方法写成只剩一个分支时，对照源方法原文复核并补全

审的是：计划与派工
触发（任一种）：
- 读到：源方法原文有几个分支（url 图片、单色、渐变、为空恢复默认）；写错的样子：交接摘要或覆盖说明把源方法记成只剩一支（如「uses url globally」），没提其余分支
适用范围：子代理写交接摘要、覆盖说明，描述多分支源方法的迁移范围时
做法：
- 写摘要前对照源方法原文复核措辞，列出每个分支及其落地情况（已实现 / 未实现）；摘要只剩一个分支时回查是否漏了其余分支
