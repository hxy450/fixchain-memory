# 修复补范围外降级时，报告逐一核对下游消费字段，没填到的写明仍缺

审的是：计划与派工
触发（任一种）：
- 读到：下游区块消费的字段是一组（如公历、农历、宜、忌），源端由同一个计算入口一起给出；写错的样子：修复报告写「区域已接入」「已接入详情路由」，而降级路径只填了其中几个字段，没列出仍缺的字段
适用范围：修复阶段为数据模型补范围外降级、写修复报告时
做法：
- 报告里把下游实际消费的字段逐一列出，标明每个字段在降级路径里是否已填
- 没填到的字段写明仍缺，不把「区域已接入」当成完成
