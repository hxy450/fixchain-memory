# 契约摘要里的资源读取函数

agent 会看到什么：Base 代码里资源读取函数的注释写着「横屏取另一个值，运行期须经读取函数按方向取」，契约摘要只列了 export function 的签名，没带使用约束

## 规矩

- rule-7251d6a65285｜契约摘要只摘 export 行时，为资源读取函数补一行运行期用法说明｜读到：Base 代码里资源读取函数或常量的注释写着「横屏取另一个值，运行期须经读取函数按方向取」；写错：契约摘要只列了 export function …(context: common.Context): number 的签名，没带使用约束；消费该值的派工也没点名
