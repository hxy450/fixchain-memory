# 契约摘要只摘 export 行时，为资源读取函数补一行运行期用法说明

审的是：计划与派工
触发（任一种）：
- 读到：Base 代码里资源读取函数或常量的注释写着「横屏取另一个值，运行期须经读取函数按方向取」；写错的样子：契约摘要只列了 export function …(context: common.Context): number 的签名，没带使用约束；消费该值的派工也没点名
适用范围：汇总 Base 契约摘要、给消费资源值的切片派工时
做法：
- 契约摘要里给资源读取函数保留一行用法说明（该值随方向变化，须在重算入口运行期读取，不用同名常量），或在消费该值的派工里点名
来源：1 张卡，1 个应用
