# 组件写给宿主的义务要登记进移交登记，编排者把 Host-side 项写进接线切片派工

审的是：计划与派工
触发（任一种）：
- 读到：子任务回执或组件头注里有 Host-side 项（要宿主补的调用，如打开弹层后 requestFocus）；写错的样子：移交登记表里没有这条；接线切片的派工正文只写「接通打开 / 回调 / 预填 / 取消」，没有这条宿主项
适用范围：组件转换和宿主接线分在不同切片时
做法：
- 组件转换者把写给宿主的义务登记进工程的移交登记，写明负责切片和验证方式
- 编排者把子任务回执里的 Host-side 项逐条写进对应接线切片的派工正文
