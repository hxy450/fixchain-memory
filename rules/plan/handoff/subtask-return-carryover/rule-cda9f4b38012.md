# 子任务回报「写权不属本批（交接项）」时，写进下游派工的穷举清单或登记点名负责方的待办

审的是：计划与派工
触发（任一种）：
- 读到：子任务的回报里写着某项「写权不属本批（交接项）」（如 module.json5 的 orientation）；写错的样子：之后派给下游功能规格或计划的派工说明里，穷举清单没有这一项，也没有登记点名负责方的待办
适用范围：编排阶段，子任务回报交接项后派下游任务时
做法：
- 把该项写进下游功能规格或计划派工的穷举清单，或登记待办并点名负责方，然后再推进阶段
