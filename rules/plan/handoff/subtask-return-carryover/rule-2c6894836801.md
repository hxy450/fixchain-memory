# 向 closer 转述 worker 信封时，原样保留 decision_gaps 和跨文件注入项及其值域

审的是：计划与派工
触发（任一种）：
- 读到：worker 信封里有 `decision_gaps` 和跨文件注入项（如入口的 want 解析注入点及其键域、优先级）；写错的样子：派给 closer 的摘要只列已登记的 `P-…` 编号，丢了 decision_gaps、注入项和值域，只给计划路径让它「顺链接读 spec」
适用范围：主线程把切片 worker 的交回信封转述给收口或集成 agent 时
做法：
- 摘要里原样保留 decision_gaps 与跨文件注入项，连同值域（键名、类型、取值、优先级），不只列已登记的 P- 编号
来源：1 张卡，1 个应用
- case-7621afac5fee30a13731（opencamera-hmos）：做法第 1 步 ← 建议 2
