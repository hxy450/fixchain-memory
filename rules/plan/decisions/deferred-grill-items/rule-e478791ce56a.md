# 决策闸门逐条列出 PD 卡里「由 grill #N 裁决」的条目，出题或关闭，自检按内容对 registry 行

审的是：计划与派工
触发（任一种）：
- 读到：PD 决策卡里写着「由 grill #N 裁决」「形态未定」的条目；写错的样子：grill 的预知清单没有列出这一条，HARD-GATE 自检把另一通道的 registry 行（如别的渠道的占位）按编号对到这张 PD 上，这项延后裁决既没出题也没关闭
适用范围：决策闸门和计划阶段的 grill、HARD-GATE 自检
做法：
- 把各 PD 卡里「由 grill #N 裁决 / 形态未定」的条目逐条列出，每条出题或明确关闭
- HARD-GATE 自检按 PD 的内容和通道对应 registry 行，不按编号凑对
