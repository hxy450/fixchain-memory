# 源码每轮 new 循环线程而派工要求单句柄时，把分歧写进 handback 的 decision_gaps

审的是：计划与派工
触发（任一种）：
- 读到：派工或规格要求「setInterval 单句柄」、在 startLoop 里清掉旧句柄，而写前读到的源码每轮 new 循环线程；写错的样子：handback 的 decision_gaps 里没有这条规格分歧，实现直接按单句柄写
适用范围：切片实现阶段源码与规格或派工的循环结构不一致时的回报
做法：
- 在 handback 的 decision_gaps 写一项：源码每轮 new 循环实例、停止只作用于最新实例，与规格的单句柄要求不一致；回报规格分歧，不直接按单句柄实现
