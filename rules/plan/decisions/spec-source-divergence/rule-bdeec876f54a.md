# 上游审计写了源码没有的去重或上限时，按源码实现，并在交接里写明冲突

审的是：计划与派工
触发（任一种）：
- 读到：上游审计或规格写「前台限定有界去重队列」一类的防护，读到的源码里只有 addAll 整批入队、remove(0) 逐个出队；写错的样子：交接报告把去重、条数上限写成实现特性（「有界串行队列」「去重记录」「每响应最多 N 条」），没写它和源码冲突，也没标成适配策略
适用范围：实现阶段的交接报告、移交项里写队列语义的那几项
做法：
- 按源码和主计划实现，交接里写一条冲突：「审计写的是……，源码是……（源文件加方法），按源码实现」，不在两者之间折中自加上限
- 确需鸿蒙侧资源保护时，单列为「适配策略」，写明对用户可见的影响（会不会丢广播），标为待主线程确认，确认前不实现
