# 构建通过后又改了源码，收尾报告写「最终构建通过」前要重跑并等到结果

审的是：计划与派工
触发（任一种）：
- 写错的样子：收尾或验收报告写「最终构建通过」「ArkTS 0 errors」，引用的 BUILD SUCCESSFUL 开始时间早于最后一次源码写入，或者派出的复核构建还没有结果（被中断、未返回）
适用范围：编排、收尾阶段写构建结论时
做法：
- 构建通过后又改过源码就重新执行构建并等这次的结果；只有开始时间晚于最后一次源码写入的 BUILD SUCCESSFUL 才能写成「最终构建通过」
来源：1 张卡，1 个应用
- case-50230743abdc791d2a68（android-train-ticket-vest7）：做法第 1 步 ← 建议 3、诊断
