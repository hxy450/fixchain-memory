# 派工禁止 worker 编译时，ArkTS 限制清单列上 implements-only-iface 这类规则

审的是：计划与派工
触发（任一种）：
- 读到：修复任务要向系统 API 传观察者或回调对象（如 errorManager.on('error', ...)）；写错的样子：派工写「不跑 hvigor，由主线程统一编译」，附的 ArkTS 限制清单只有无 Record、无 in、无 any 等，没有 arkts-implements-only-iface
适用范围：派发禁止 worker 自行编译的实现或修复任务时
做法：
- 限制清单写上 arkts-implements-only-iface（类不能被 implements，SDK 里声明为 class 的观察者用标注类型的对象字面量），并说明 arkts-no-untyped-obj-literals 要求字面量有显式类型、不是禁止字面量
- 上一轮收尾构建因会话中断没跑时，下一轮先编译再派工
来源：1 张卡，1 个应用
- case-28990049b25bf1086836（DeepAI全能PPT）：做法第 1 步 ← 建议 3、建议 2；做法第 2 步 ← 建议 3
