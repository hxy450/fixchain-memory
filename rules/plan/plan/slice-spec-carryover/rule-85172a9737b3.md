# 派页面接线任务时，把该页 UI spec 的导航关系和状态接口一并交给接线者

审的是：计划与派工
触发（任一种）：
- 读到：页面的 UI spec（spec/baseline/ui 下的页面规格）写了导航表（如「Skip → 主页」）和状态接口（如「登录成功 ← ViewModel 的完成事件」）；写错的样子：接线派工逐按钮列交互时漏了某个按钮，也没把该页的 UI spec 交给接线者；slice 的 integration_points 里也没有这条跳转
适用范围：主会话派发页面接线（Step 3d）任务、逐按钮列交互时
做法：
- 派工里给出该页的 UI spec 路径，并把其中的导航关系和状态接口逐条列进交互清单，每个按钮都要有一项
来源：1 张卡，1 个应用
- case-9618601c4a21f2f18560（polypal-app-ohos）：做法第 1 步 ← 建议 3、诊断
