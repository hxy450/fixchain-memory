# 规格写了首次启动自动触发和设置里手动重置时，切片契约落成启动路径和设置入口两条接线

审的是：计划与派工
触发（任一种）：
- 读到：功能规格写「播种时机：首次启动时自动播种／设置中可手动重置」，验收含「首次启动自动播种」；写错的样子：切片的 scope 只写「…重置功能」，acceptance 只写「…正常重置」，integration_points 只有设置页重置的 slot，没有启动路径上的首次触发
适用范围：把功能规格里的触发时机（首次启动自动执行、设置里手动执行）写进切片的 scope、acceptance、integration_points 时
做法：
- 写切片的 scope、acceptance、integration_points 前重读它 spec_ref 指向的功能规格全文，不只看 feature-index 或摘要里的功能名
- 触发时机分别落成两条接线：启动路径上的首次自动执行（带门控条件）和设置入口的手动重置，各有验收条目
