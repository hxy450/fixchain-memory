# 写切片验收时，从功能规格的验收标准完整带入，不只留概括项

审的是：计划与派工
触发（任一种）：
- 读到：功能规格的业务规则和验收里写有具体交互（如「点击复选框切换完成状态」「能够切换完成状态」）；写错的样子：切片计划的 acceptance 只剩「正常显示」「轮播流畅」这类概括项，功能规格里的交互验收没带进来
适用范围：规划阶段给每个切片写 acceptance 时
做法：
- 按切片的 spec_ref 打开功能规格，把它的验收标准逐条带入切片 acceptance，交互类条目（勾选切换、整项点击跳转）一条不省
来源：1 张卡，1 个应用
