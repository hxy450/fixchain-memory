# 规格里登记了桥接事件通道时，切片要有实现它的具体 Step

审的是：计划与派工
触发（任一种）：
- 读到：feature spec 里有原生↔Flutter 事件通道或桥接 Model 的条目；写错的样子：切片只保留服务层和状态管理，事件通道、宿主监听和推送没有进入任何 Step
适用范围：按 feature spec 拆切片、写派工时
做法：
- 把通道注册、事件分发、推送点和桥接 Model 写进切片的具体 Step，Step 里带上通道名和宿主锚点
