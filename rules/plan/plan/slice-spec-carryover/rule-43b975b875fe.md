# 规格写明的算法要求在转换时被推迟，后续切片的移交项要显式承接并对照完整条件

审的是：计划与派工
触发（任一种）：
- 读到：规格的验收条目写明「判定算法保留」一类算法要求（如末项可见判定、触发恰一次）；写错的样子：转换报告或代码注释写「精确算法随后续接线」把它推迟，后续切片的派工和移交项里没有承接这条验收条目；或后续切片只补了局部守卫就删掉推迟说明
适用范围：转换阶段推迟规格里的算法要求、由后续切片接线时
做法：
- 推迟时在移交项登记验收条目编号和它的完整条件，后续切片的派工里显式写「承接该条目」
- 后续切片修改该片段时，对照验收条目的完整条件逐项核对，不能只补局部守卫
