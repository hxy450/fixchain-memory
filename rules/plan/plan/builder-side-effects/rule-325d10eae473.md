# 源端新条目经公共构建器注册时，计划里列出构建器对每个条目附加的副作用并逐项映射

审的是：计划与派工
触发（任一种）：
- 读到：源端新条目和同类兄弟条目一样，经同一个公共构建器函数注册（调用处只传分组和少量显式配置），构建器定义不在调用所在的文件里；写错的样子：迁移计划的改动清单只映射了调用处看得到的显式配置（图标、样式等），没有列出构建器内部统一附加的能力，如说明页链接、名称后的问号入口、回调
适用范围：增量迁移的调查与计划阶段，为源端新注册的按 key 配置的条目列改动清单时
做法：
- 打开构建器定义（调用所在文件里搜不到就扩大到整个模块），列出它对每个条目附加的副作用，在计划里逐项写出目标端对应的改动
针对本应用要查的：
- 公共构建器对每个条目附加了什么：源工程整个模块里该构建器函数的定义（.kt/.java，按函数名全模块搜）；逐行看它在条目上设置的字段（链接、图标、点击回调等），每一项都要在目标端找到对应的登记点
