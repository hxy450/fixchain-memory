# 经公共构建器注册的新条目的按 key 登记表

agent 会看到什么：目标端同类能力按 key 登记在多个文件的白名单或映射表里，计划的改动清单漏了含同构建器兄弟 key 的某张表

## 规矩

- rule-85a4e0a86652｜计划改动清单前，用同构建器同分组的兄弟 key 在目标工程全量 grep，列出所有按 key 的表｜读到：目标端把同类能力拆在多个文件里的按 key 白名单或映射表登记，与新条目同构建器、同分组的兄弟 key 已在其中几张表里；写错：计划只按功能点逐个找登记点，改动清单漏了含兄弟 key 的某张白名单或映射表（如说明问号白名单），也没写不加入的源端依据
