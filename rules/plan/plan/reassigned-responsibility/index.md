# 换了承接方的源端职责

agent 会看到什么：源端一项职责在目标里交给另一切片的服务或换成平台替代（WorkManager 聚合状态、三方 MapView），承接方的派工或计划里没有对应的任务和验收条款

## 规矩

- rule-3db4a1d8d45f｜源端聚合器的职责移交给另一切片时，映射验收条款写进承接切片的派工｜读到：源端由宿主 Activity 观察 WorkManager 聚合状态并广播，目标里这一职责移交给另一切片的服务；状态映射规则写在壳层的某条 AC 里；写错：承接切片的派工和 slice 文件里没有引用那条映射 AC，只在移出方的源码笔记里写了「聚合发布侧交给 Slice N」
- rule-aac73442cd2f｜三方地图改平台替代时，计划写成具体任务：组件依赖、key 注入、坐标系转换、未配置态验收｜读到：源端用第三方地图 SDK 的 MapView；规格或决策只写「地图承载组件」「可验证地图承载」；写错：计划里没有单独的地图接入任务，没写目标组件和依赖、key / client_id 怎么注入、GCJ-02 与 WGS-84 的转换和未配置态的验收
- rule-babfbe145f87｜拍照管线跨功能划分时，为控制器侧的 JPEG 取帧指明归属｜读到：源端拍照链路分成控制器侧（取帧、复制、close）和保存服务两部分；写错：功能拆分里两边都把控制器侧的 JPEG 取帧和缓冲释放划为 out of scope，补图元的派工只要求补 capture 调用
