# 源端聚合器的职责移交给另一切片时，映射验收条款写进承接切片的派工

审的是：计划与派工
触发（任一种）：
- 读到：源端由宿主 Activity 观察 WorkManager 聚合状态并广播，目标里这一职责移交给另一切片的服务；状态映射规则写在壳层的某条 AC 里；写错的样子：承接切片的派工和 slice 文件里没有引用那条映射 AC，只在移出方的源码笔记里写了「聚合发布侧交给 Slice N」
适用范围：规格或计划阶段，把源端聚合器（WorkManager 观察、LiveData 汇总等）的职责从一个切片移交给另一个切片时
做法：
- 把对应的映射验收条款（作业状态→目标状态的映射 AC 编号和原文）写进承接切片的 spec 引用或派工池，不只记在移出方的笔记里
来源：1 张卡，1 个应用
- case-02008ba6db4e6a0ddfa2（AntennaPod）：做法第 1 步 ← 建议 4
