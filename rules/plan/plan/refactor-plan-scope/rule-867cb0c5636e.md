# 制定迁移计划时把 planned 增量规格里的退出清理要求写进账户批次验收

审的是：计划与派工
触发（任一种）：
- 读到：仓库里有状态仍为 planned 的增量规格，写明了退出登录前停止并等待同步、清理账号业务数据、通知刷新这类行为要求；写错的样子：计划的范围只列到已完成的规格编号，漏掉 planned 的增量规格；账户批次的验收只写「登录/退出/游客重建」，完成定义只写「符合 Android 行为」，没有停同步、清账号业务表、广播刷新这几项
适用范围：制定或合并迁移计划、给账户或同步批次写验收条件和完成定义时
做法：
- 逐条核对仓库里状态为 planned 的增量规格，把其中已写明的行为要求写进对应批次的验收条件，例如「退出登录前停止并等待同步 → 清理按账号归属的业务表 → 广播数据变化」
- 验收和完成定义写出具体行为，不只写「符合源端行为」
针对本应用要查的：
- 有哪些仍为 planned 的增量规格、各自写了哪些行为要求：目标仓库的规格目录里各增量规格的状态字段和需求小节；状态是 planned 的逐条读，涉及哪个批次的域就把要求写进那个批次的验收
