# 重写计划时把已批准未执行的规格逐条映射成批次任务和验收项，不用「页面级输入」带过

审的是：计划与派工
触发（任一种）：
- 读到：spec-index 里有已过 Gate 1、状态仍为 planned / pending 的 BF / F 规格；用户要求整体重审并替换原有局部计划；写错的样子：新计划或审计写「原 BF… 不再独立执行，作为后续计划的页面级输入」，批次任务和验收项里找不到这些规格的编号、要求或关键键名，也没有显式 deferred 决策
适用范围：迁移规划阶段替换或重写总体计划，而之前已有获批但未执行的规格时
做法：
- 把每条已批准未执行的规格映射到新计划的具体批次：写任务编号和对应验收项；决定合并、推迟或放弃的，写明去向和负责批次
- 定稿前做一次追溯核对：列出 spec-index 中 planned / pending 的 BF / F 条目，逐条确认在新计划里有任务编号或显式 deferred 决策
来源：1 张卡，1 个应用
