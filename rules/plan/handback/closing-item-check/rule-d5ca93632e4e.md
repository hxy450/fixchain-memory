# 处理巡检 BLOCKER 时派发失败要重试，关闭前逐项核对每个 BLOCKER 已落地

审的是：计划与派工
触发（任一种）：
- 读到：巡检报告列出多个 `BLOCKER` 项和修复方向；写错的样子：修复派工因线程上限等原因失败后没有重派；收口时只修了同批次顺手的几项，报告里其余 `BLOCKER` 没有对应的修复或核对记录
适用范围：编排者处理巡检报告、派发修复并收口时
做法：
- 派发失败（如 agent thread limit reached）就重试或就地修复；关闭前把报告里的每个 BLOCKER 列成清单，逐项写明修复位置，或仍未处理的原因
