# 回执里识别了但没实现的源端行为

agent 会看到什么：写前已读到源端有某项行为（如左右滚动联动、程序滚动保护），子任务回执写「……均保留」，没列出识别到却没实现的行为

## 规矩

- rule-211c1d93646f｜子任务回执要列出已识别但未实现的源端行为，不用「均保留」概括｜读到：写前已读到源端有某项行为（如左右滚动联动、程序滚动保护）；写错：回执写「……均保留」，没列出识别到却没实现的源端行为
- rule-1972926d9e96｜遗留的源端行为降级要登记占位并指定负责的 slice，「可补」「可选增强」不算｜读到：源码要求的行为（如 enterAlwaysScrollBehavior 折叠顶栏）在本片没有实现；写错：报告或规格写「联动实现留待接线轮可选增强」「Slice N 接入时可补」「差异已登记页面 spec」，占位登记里没有对应条目和负责的 slice
