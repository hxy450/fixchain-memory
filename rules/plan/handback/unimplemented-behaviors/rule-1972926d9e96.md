# 遗留的源端行为降级要登记占位并指定负责的 slice，「可补」「可选增强」不算

审的是：计划与派工
触发（任一种）：
- 读到：源码要求的行为（如 enterAlwaysScrollBehavior 折叠顶栏）在本片没有实现；写错的样子：报告或规格写「联动实现留待接线轮可选增强」「Slice N 接入时可补」「差异已登记页面 spec」，占位登记里没有对应条目和负责的 slice
适用范围：转换或接线阶段把源端行为留到后续做时的占位登记和交回报告
做法：
- 遗留的降级在占位登记里写一条：缺的是哪项行为、源端出处、负责补齐的 slice；「可补」「可选增强」这类说法不算登记
