# 迁移报告把功能记为已接线已验证前，与账本里 approved 的实现类决策逐条对照

审的是：计划与派工
触发（任一种）：
- 读到：决策账本里该功能的实现类决策为 approved（选定等价实现，未选仅前台）；写错的样子：迁移报告把功能记为 WIRED+VERIFIED，并以决策编号为由写成「前台常亮 + 显式不可后台」之类，实际代码是桩
适用范围：收尾阶段写迁移报告、覆盖清单时
做法：
- 逐条对照账本里 approved 的实现类决策和代码：对应函数里有恒 false、恒定枚举返回或「? X : X」的，不记 WIRED+VERIFIED，记为未实现并列出缺口
