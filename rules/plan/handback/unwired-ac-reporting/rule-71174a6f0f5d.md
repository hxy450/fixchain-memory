# 页面转换把失败界面留给接线阶段时，占位登记写明 error 态要渲染失败提示

审的是：计划与派工
触发（任一种）：
- 读到：规格状态接口有 error 结果态，验收条目要求失败报错；写错的样子：占位登记里只写状态绑定和计数、状态回填，没有一项写「error 态需渲染失败提示（验收条目编号）」
适用范围：页面转换阶段没做完失败态的渲染、要交给功能接线阶段时
做法：
- 在占位登记里单列一项：「error 态需渲染失败提示（对应的验收条目编号）」，不只登记状态回填
来源：1 张卡，1 个应用
