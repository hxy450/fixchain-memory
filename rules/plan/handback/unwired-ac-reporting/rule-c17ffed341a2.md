# P0 规格的 AC 目标符号在代码里搜不到且台账无 skip 时，记为缺口，不记 scope 外

审的是：计划与派工
触发（任一种）：
- 读到：feature 规格的 P0 验收条目写了深链数据流和目标符号（want.uri → 深链处理函数、module.json5 uris）；写错的样子：verify 报告只查静态规则和路由注册数，没有逐条核对 P0 验收条目的目标符号；或以 MVP 一类理由把深链登记为 scope 外，而决策台账里没有对应 skip 决策
适用范围：verify 阶段的覆盖核对和跳过登记
做法：
- 对每个 P0 feature 的验收条目目标符号做存在性检查：在代码里搜深链处理函数，在 module.json5 里搜 uris
- 命中 0 且决策台账没有对应 skip 时，在覆盖清单里记为缺口待补，不以 MVP 为由记成 scope 外
