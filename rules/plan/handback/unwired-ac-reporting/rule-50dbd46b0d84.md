# 规格里的遥控验收条目没实现时，登记带 owner 的 FWD-REF，不只在笔记写「归另一 feature」

审的是：计划与派工
触发（任一种）：
- 读到：规格的验收条目要求遥控选择态、按键导航（如曝光面板的行顺序、up/down/ok 三键）；写错的样子：源码笔记或报告只写「归另一 feature」「屏上路径不可达」，移交项里没有带 owner 的 FWD-REF
适用范围：实现阶段交回的移交项、占位登记里，涉及没实现的遥控、按键导航验收条目时
做法：
- 这类验收条目要么实现，要么登记一条 FWD-REF：写明条目编号、owner（哪个 feature 或任务）、要实现的内容
针对本应用要查的：
- 被推给的那个 feature 是否真的定义了这项职责：对方 feature 的规格里的验收条目；看它是只调用这些动作，还是定义了行导航；只调用的，owner 不能写它
