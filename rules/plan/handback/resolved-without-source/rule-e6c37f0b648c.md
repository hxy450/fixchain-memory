# 「对比安卓」任务的完成回执没引用任何源端文件时，按未完成对比处理

审的是：计划与派工
触发（任一种）：
- 读到：任务写明「对比安卓」还原某功能；写错的样子：完成回执称「已补齐」，却没列出任何实际对照过的安卓源文件，也没有逐项行为对照；源码查找命令曾返回 no matches 或空结果
适用范围：增量还原阶段，要求对比安卓的实现任务交回时
做法：
- 回执要列出实际读过的源端 Screen、ViewModel、Service 文件和逐项行为对照（数据来源、分页、刷新、条目样式）；没有源端文件引用的退回重做
