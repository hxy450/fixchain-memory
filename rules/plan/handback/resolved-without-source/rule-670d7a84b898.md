# 地图接入缺口要登记为未关闭项，巡检的地图承载 BLOCKER 不以静态占位标为已解决

审的是：计划与派工
触发（任一种）：
- 读到：巡检报出「定位成功态只是白色容器加 marker 图片，没有地图承载」一类 `BLOCKER`；写错的样子：巡检报告或占位登记把「地图态与空态互斥」等项标成 resolved / 已解决，实现仍是静态占位；地图接入缺口没登记成未关闭项，BLOCKER 也没派给功能层修复
适用范围：巡检收口、更新占位和未关闭项登记时，涉及地图承载的条目
做法：
- 地图 SDK、key 或配置缺失接不上时，把接入缺口登记为未关闭项，不把对应巡检项标为 resolved
- 巡检报出地图承载 BLOCKER 时派给功能层修复，收口时不沿用占位
