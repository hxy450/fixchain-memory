# 回执和 marker 里的已实现、已解决标记

agent 会看到什么：回执、巡检报告或接线 marker 标「已实现」「已补齐」「resolved」，而源布局没读到、没对照任何源端文件，或目标只是静态占位、通用确认弹窗代替

## 规矩

- rule-e6c37f0b648c｜「对比安卓」任务的完成回执没引用任何源端文件时，按未完成对比处理｜读到：任务写明「对比安卓」还原某功能；写错：完成回执称「已补齐」，却没列出任何实际对照过的安卓源文件，也没有逐项行为对照；源码查找命令曾返回 no matches 或空结果
- rule-d4c12c4a09b9｜没读到源布局就交付了弹窗时，回执里标注视觉缺口｜读到：查找源布局的命令输出不全（串联命令只见到第一段），子代理没读到弹窗的布局 XML；写错：回执照常报告弹窗已实现，没有标注源布局未读到、视觉待核
- rule-da76b5d5ea46｜目标弹窗缺源布局的任一项时，接线 marker 不标 resolved，要登记未决项写明缺口｜读到：派工或接线项要求接一个源端专用布局弹窗（标题、图标、单个按钮、关闭图标）；写错：接线 marker 标成 resolved，但目标用通用确认弹窗代替，缺标题、图标或关闭图标；只在代码注释里写“视觉由通用确认弹窗承载”，没有登记未决项
- rule-670d7a84b898｜地图接入缺口要登记为未关闭项，巡检的地图承载 BLOCKER 不以静态占位标为已解决｜读到：巡检报出「定位成功态只是白色容器加 marker 图片，没有地图承载」一类 `BLOCKER`；写错：巡检报告或占位登记把「地图态与空态互斥」等项标成 resolved / 已解决，实现仍是静态占位；地图接入缺口没登记成未关闭项，BLOCKER 也没派给功能层修复
