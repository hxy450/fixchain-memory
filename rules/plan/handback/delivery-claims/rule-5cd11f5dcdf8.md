# 改了页面模块导出或新增组件到页面模块的导入而没跑 UI 套件时，交付说明登记未验证

审的是：计划与派工
触发（任一种）：
- 读到：本轮改动改了 pages/ 下页面模块的导出，或新增了组件从页面模块的导入；用户说明本轮不跑真机；写错的样子：交付说明只写了 assembleHap 编译通过，没有拉起主 Ability 的 UI 套件冒烟结果，也没有登记「UI 测试进程加载未验证」
适用范围：实现或修复轮交付时，改动涉及页面模块的导出面或跨页面模块导入
做法：
- 交付说明里写一项：「改动了页面模块导出 / 组件→页面模块导入，只过了编译门，UI 测试进程加载未验证」，并列出改动的模块
