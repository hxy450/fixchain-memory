# 无法运行验证时，回执的 API 假设分开写「签名已确认」和「运行能力未确认」

审的是：计划与派工
触发（任一种）：
- 读到：派工要求在回执里报告 API 假设；写错的样子：回执的 API 假设或风险里只写「签名已在本地 SDK 确认」，没说明所用变体（如声明带 801 的能力受限接口）在目标环境能否运行，也没列成首轮设备测试要核对的风险
适用范围：子代理没有运行验证就交回、回执里报告 API 假设和风险时
做法：
- 回执的 API 假设逐项写两栏：签名是否已在 SDK 确认、运行能力是否已确认；能力受限的公共封装列为首轮设备测试优先核对的风险，不写成已验证
