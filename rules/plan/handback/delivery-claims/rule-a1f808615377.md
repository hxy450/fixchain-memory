# 页面交付自检要逐个 ForEach 写明 key 覆盖了哪些可变字段，不只核有选中态的列表

审的是：计划与派工
触发（任一种）：
- 读到：ui 迁移陷阱清单里有「同 id 新值重建时 key 须含可变字段」这一条（P-05）；写错的样子：交付报告的自检只列出有选中态的列表符合 P-05，没有逐个列出页面里每个 ForEach 的 key 覆盖了哪些可变字段
适用范围：页面转换交付时写自检清单
做法：
- 自检清单对页面里每一个 ForEach / LazyForEach 各写一行：key 的组成、覆盖了哪些可变展示字段、源端的刷新方式
