# 回执写「几何全部取自 SDK 实值」前逐个组件核对，查不到的登记待核并写检索路径

审的是：计划与派工
触发（任一种）：
- 读到：派工要求平台框架提供外观的组件「几何从本机 Android SDK platform res 取实值，查过仍无才登记 `UNC` 待核」；写错的样子：回执写「几何全部本机 SDK platform res 实值」，但某个组件（如吐司封装）的位置等几何参数没传，也没有登记 `UNC` 待核项；或以「两端都在底部」带过偏移
适用范围：公共组件库、页面实现阶段，派工要求平台外观从本机 SDK 资源取值时
做法：
- 回执前逐个组件列出几何参数和取值出处（平台资源名）；思考里提到过的平台 dimen（如 toast_y_offset）先 grep 再决定，「两端都在底部」只说明重力方向相同，不说明偏移相同
- 查不到的才登记 `UNC` 待核，并写明检索过的路径
来源：1 张卡，1 个应用
