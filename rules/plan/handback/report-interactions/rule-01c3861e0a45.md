# 跳板 Activity 的转换报告写明各分支实际目标、要求调用方直达，改成点击后跳转须标为行为改变

审的是：计划与派工
触发（任一种）：
- 读到：源 Activity 的 onCreate 或 initView 开头无条件 startActivity 到别的页并 finish()；写错的样子：转换报告把它写成可见页、点击后才 replacePathByName，并用「对应 Android 启动后 finish」之类的说法带过；或报告里没写实际目标页，也没要求调用方直接路由过去
适用范围：页面转换阶段迁移入口或路由用的 Activity 后交回的转换报告和移交项
做法：
- 报告里写明：源 Activity 是路由跳板，列出每个条件分支和对应的实际目标页，并作为移交项要求调用方直接路由到实际目标页
- 实现没有照源码一进入就跳走（例如做成点击后替换）时，在报告里单列为行为改变，写出源端行为和鸿蒙端行为，不用「对应 finish」带过
已核实的写法和取值（核实时用的是鸿蒙 SDK API 23）：
- 在 onCreate 里调用 finish() 时，onCreate 之后直接 onDestroy，onStart、onResume 都不执行：据此判断源端这页从不显示，做成可见页就是行为改变（出处：android.app.Activity#onCreate 的说明）
