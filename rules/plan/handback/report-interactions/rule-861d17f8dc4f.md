# 交付报告的「已实现交互」按源端调用逐条列，不只写概括

审的是：计划与派工
触发（任一种）：
- 读到：源文件里有多处 setOnClickListener、currentItem 等交互调用；写错的样子：交付报告的「已实现交互」只写「tab 切换 + Swiper 横滑联动」这类概括，没按源端行号和调用逐条列出对应的目标实现
适用范围：页面转写完成后交付报告里的交互覆盖清单
做法：
- 「已实现交互」每条写：源文件和行号、源端调用（如 setOnClickListener → currentItem = 1）、目标组件和写法（如 tab 项 .onClick 写回 index）
来源：1 张卡，1 个应用
