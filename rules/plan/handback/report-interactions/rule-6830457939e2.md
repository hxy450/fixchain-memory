# 入口按决策留成占位时，交付总结逐项列出未实现的入口，不报「占位符 0、可交付」

审的是：计划与派工
触发（任一种）：
- 读到：决策或巡检单把某些入口标为范围外，要求「保留路由合同或明确不可用反馈」；写错的样子：代码里这些入口是「暂不可用」Toast、无响应或合规链接 kind 兜底，交付报告却写「TODO/占位符/FWD-REF 0、可交付」，没列出这些入口
适用范围：实现与巡检阶段遇到决策标为范围外的入口、写移交和交付总结时
做法：
- 把这些入口逐项汇总回协调者，并在交付总结里列一张未实现入口表（入口、源端目标、目标端现状）；Toast、无响应、占位回调都不算完成
