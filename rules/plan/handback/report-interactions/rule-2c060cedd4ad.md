# 偏离规格指定的组件映射时，转换报告逐项写交互差异，不写「行为等价」

审的是：计划与派工
触发（任一种）：
- 读到：规格或 render 契约指定了组件映射（如 stickyHeader → ListItemGroup StickyStyle.Header）；写错的样子：转换报告或回执写「行为等价」「等价实现」，而代码换了规格指定的结构（如把吸顶内容移到 List 外）；没逐项写拖动起点、点击命中、测量口径的差异
适用范围：转换报告和回执里，对偏离规格映射的那些片段的说明
做法：
- 报告逐项写出与源端的交互差异：拖动起点、点击命中、测量口径；自己已察觉差异的不写「行为等价」
