## 本级经验

- [引用安卓框架默认值时查框架定义，不凭记忆或估算](lesson-123546ef008afdb2affe.lesson.md)
  - 时机：规格提取与界面实现阶段，需要写出@android:color/*、主题默认窗口背景、对话框窗口宽度等框架默认值时
  - 情境：源工程只引用框架资源名或依赖主题/框架默认，项目源码里没有该数值，目标端需要具体值。
- [映射参考或记忆给出的ArkUI属性与枚举值，先核本机SDK声明](lesson-1e48740817ba53f3fc92.lesson.md)
  - 时机：界面实现阶段，按映射参考、技能示例或记忆选用ArkUI通用属性或字符串枚举（如对齐属性、Canvas合成模式）时
  - 情境：参考或记忆中有“某安卓属性映射为某ArkUI属性/枚举值”的条目，但该属性的适用容器、枚举的允许取值没有在本机SDK中核实；工程compatibleSdkVersion已知。
