# 映射参考或记忆给出的ArkUI属性与枚举值，先核本机SDK声明

ID：`lesson-1e48740817ba53f3fc92` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，按映射参考、技能示例或记忆选用ArkUI通用属性或字符串枚举（如对齐属性、Canvas合成模式）时

## 适用情境

参考或记忆中有“某安卓属性映射为某ArkUI属性/枚举值”的条目，但该属性的适用容器、枚举的允许取值没有在本机SDK中核实；工程compatibleSdkVersion已知。

## 原因

参考条目可能把相似属性的语义写错（组件自身内容对齐不等于容器内子项定位）；字符串枚举的未声明值不报编译错误，运行时静默按默认处理；仅凭API版本号推定可用，错误会一直留到设备上才暴露。

## 做法

1. 在本机SDK的ets/component声明（如common.d.ts、canvas.d.ts）中查该属性或取值的声明与注释：作用于哪个容器的子项、@since版本、枚举允许列表。
2. 参考条目与SDK声明不一致时以SDK为准，并在回执中指出参考条目有误。
3. 取值不在声明列表中就视为不可用，改用与源语义等价的实现路线。
