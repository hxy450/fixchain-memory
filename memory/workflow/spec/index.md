## 本级经验

- [裁定横切能力与平台差异时，区分源端默认行为和需额外资源的能力](lesson-4a81d8bc99d629325e79.lesson.md)
  - 时机：规格决策阶段，填写目标平台、横切能力（深色/大字体/方向等）条目和技术必做项时
  - 情境：源端某项行为由平台默认提供、无需代码或资源（sp文字随系统字号缩放、未声明screenOrientation时随传感器转屏、主题默认系统栏外观），目标平台对应默认值不同；决策参考只按源端是否有额外资源目录或显式代码判断能力有无。
- [跨栈映射写“行为等价”前，先核对决定行为的量与目标API是否一致](lesson-2ba5c5fb362ab027304a.lesson.md)
  - 时机：规格提取阶段，编写跨栈映射基线、页面转换决策，或给候选实现标“等价/HARD”时
  - 情境：源端行为由某个隐含量决定（资源限定符的判档量、绘制单位、帧节奏、Drawable默认填充、窗口方向等），目标端准备用看似相近的机制代替（窗口宽断点、vp单位、固定间隔定时器、Cover、只做响应式布局、未核实的合成模式）。
  - 例外：当前任务已批准与源端不同的产品行为，并在台账中登记为有意差异
