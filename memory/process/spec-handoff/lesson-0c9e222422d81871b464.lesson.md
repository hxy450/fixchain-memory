# 规格把源码资源引用（getColor/getInteger/getDimension(R.x)）转成具体值时，按精确资源名在全部 res/values* 检索：近名资源不合并，限定词覆盖（values-land 等）写成分支并在运行期按配置读取

ID：`lesson-0c9e222422d81871b464` · 版本：1

[本主题](index.md)

## 何时使用

规格提取阶段，把源码中经资源 ID 读取的颜色、整数、尺寸、布尔值写进验收条目与精确取值表时；实现阶段在规格字面量与运行期资源读取之间选择时

## 适用情境

源方法通过 getColor(R.color.X)、getResources().getInteger(R.integer.X) 等读取资源；工程里有名称相近、用途不同的资源（如 yellow 与 square_yellow），或该资源在 values-land 等限定词目录有覆盖值；目标页面支持横竖屏并在旋转后重算几何。

## 原因

按颜色词或近名推断会取到另一个资源的值；只在 res/values 检索会漏掉限定词覆盖，规格写成固定常量后实现照抄，横屏几何偏离。来源中规格作者没打开定义该颜色的 colors.xml，把方块色写成了弹字色；另一处只查了 res/values，把横屏为 1 的列间距写成常量 2，实现者也没读同名的按方向读取函数。

## 做法

1. 按精确资源名在全部 res/values*/ XML 中检索 name="X"（如 grep -rn 'name="X"' res/），把定义文件:行号与值写进验收和常量表；有限定词覆盖时写成“base 2 / land 1，运行期按当前配置读取”，并在验收中补一个限定词条件下的样例。
2. 同一工程有含相同词的多个资源时，色表按资源名逐行列出定义与消费点，不合并成一行；grep 结果被截断时确认目标条目已返回，否则按行号定点再读。
3. 实现时规格给字面量、而已迁移的同名资源键或 Base 契约里需要 context 的读取函数也存在时，先核对注释与资源值；不一致按源端资源实现并回报规格，旋转后重算几何的入口里做运行期读取。
