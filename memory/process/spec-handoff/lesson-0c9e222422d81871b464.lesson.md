# 经资源 ID 或 @dimen/@color 取值时按精确名检索全部 res/values*，限定词覆盖写成按配置取值的分支并指定承接方

ID：`lesson-0c9e222422d81871b464` · 版本：4

[本主题](index.md)

## 何时使用

规格提取阶段，把源码中经资源 ID 读取的颜色、整数、尺寸、布尔值写进验收条目与精确取值表时；资源迁移阶段处理 values-w<N>dp、values-sw<N>dp、values-h<N>dp 等无法映射的限定目录时；实现阶段为引用 @dimen 的边距取值，或在规格字面量与运行期资源读取之间选择时

## 适用情境

源方法通过 getColor(R.color.X)、getResources().getInteger(R.integer.X) 等读取资源，或布局以 @dimen/X 引用；工程里有名称相近、用途不同的资源，或该资源在 values-land、values-w<N>dp、values-sw<N>dp 等限定词目录有覆盖值（基础值与覆盖值从源 res/values*/ 下的 XML 读取）；目标页面支持横竖屏并在旋转后重算几何。也包括 HarmonyOS 资源限定词没有可用宽度维度，资源转换规则要求整目录跳过并标 unmapped。

## 例外与边界

- 源端横屏变体是 layout-land 等整份布局：布局变体的运行期分支按布局经验处理，本条管 values* 中的值覆盖

## 原因

只在报告里标 unmapped、写“由某任务处理”而不核对对方是否承接，被覆盖的值就没有承接方，各页只拿到基础值；按近名资源合并或只取 base 值，限定词条件下的取值同样丢失。

## 做法

1. 按精确资源名在全部 res/values*/ XML 中检索 name="X"（如 grep -rn 'name="X"' res/），把定义文件:行号与值写进验收和常量表；有限定词覆盖时写成分支（例：“base 2 / land 1，运行期按当前配置读取”），并在验收中补一个限定词条件下的样例。
2. 同一工程有含相同词的多个资源时，色表按资源名逐行列出定义与消费点，不合并成一行；grep 结果被截断时确认目标条目已返回，否则按行号定点再读。
3. 实现时规格给字面量、而已迁移的同名资源键或 Base 契约里需要 context 的读取函数也存在时，先核对注释与资源值；不一致按源端资源实现并回报规格，旋转后重算几何的入口里做运行期读取。
4. 资源迁移跳过无法映射的尺寸限定目录前，逐键列出被覆盖的值（键名、基础值、覆盖值、限定词与阈值），在映射表与移交登记中写成“运行时断点”需求并指定承接方（共享窗口模型或具体任务）；写“由某任务处理”前先 grep 对方规格确认已有条目，没有就登记。
5. 界面实现引用 @dimen 时查源 res 下全部 values-*/dimens.xml 是否覆盖同名键；按限定词分别取值：values-w<N>dp 按当前可用宽、values-sw<N>dp 按最小宽（横竖两向中较小的宽，旋转不变）、values-h<N>dp 按可用高（android-36.1 Configuration.screenWidthDp/smallestScreenWidthDp/screenHeightDp 说明），组合限定词按 Android 资源匹配优先级选择。目标资源限定词能表达的（如横竖屏）优先用目标资源目录，表达不了的由共享窗口模型在运行期按配置取值并在窗口尺寸变化时重算，不用单值 $r；水平与垂直边距即使基础值相同也分开取。
