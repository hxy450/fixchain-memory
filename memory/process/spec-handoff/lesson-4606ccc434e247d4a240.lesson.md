# 源端行为经 helper、DAO、适配器、子组件或基类层层委托时，追到最终实现再写规格与代码，不以调用点推断

ID：`lesson-4606ccc434e247d4a240` · 版本：9

[本主题](index.md)

## 何时使用

规格提取与页面、数据层实现阶段，源端调用点只是一行委托（Activity 调 DialogHelper.showXxx、Repository 经 DAO 调 Helper、Fragment 的分页适配器再建 item 适配器、Compose 页面把整块列表或交互交给子 Composable 或共享组件、条目经公共构建器注册、页面类继承共享基类）时

## 适用情境

源端真正的布局、点击时序、数据来源、选中样式或空列表分支写在被委托的方法、类或子组件里：调用点只剩 DialogHelper.showXxxDialog(ctx) { 回调 }、repository.query → dao → Helper、分页适配器 → item 适配器，或带参数的子 Composable 调用（其 LazyColumn 按分区渲染、列表为空时显示内联空态）；规格按页面切分，锚点只列到调用方。也包括 Compose 页面调用项目自定义组件或共享弹层，形状、选中切换、数量步进与按钮可用条件写在组件定义里；源端条目经公共构建器注册，构建器为每个条目附加说明链接、图标或回调；页面 Adapter/Fragment 继承共享基类，基类用代码创建 UI（startActionMode 的标题、关闭键、溢出菜单）并登记返回键回调；或规格锚点列出 EmptyViewHandler 一类辅助类，挂载规则写在其中。

## 例外与边界

- 委托对象只是谓词、getter、格式化器或带默认参数的工具函数：按读到定义再翻译语义的经验处理

## 原因

只看调用点会把调用方 lambda 当成全部行为，把 DAO 名称当成数据来源，把中间适配器当成样式来源，把子组件调用当成单纯的列表，把构建器调用当成单纯注册；只读子类会漏掉基类以代码创建的上下文操作栏和返回键出口。规格锚点只列调用方时，被委托文件里的分支、时序、空态与延时不会进入下游，实现者只能自拟或以“无入口”收口。

## 做法

1. 调用点委托给 helper 或工具方法时，打开该方法全文和它 inflate 的布局或 Binding，列出控件、按钮分支和点击时序（状态变化 → 延时 → 回调 → dismiss，延时取源码 postDelayed 或动画参数）后再写。
2. 数据经 Repository、DAO、Helper 逐层委托时，追到最终实现确认来源（算法库、预置库、网络）；读取被截断就补读，规格的数据流与验收条目只写已核实的来源。
3. 列表或网格样式沿适配器链追到实际 item 适配器的 convert/onBind，按分支确认选中、当天、周末、节日等样式。
4. 规格提取时把被委托的实现文件与它用到的布局一并登记进源码锚点和页面契约，不只列调用方。
5. 页面把某块区域交给另一文件的子 Composable 时，打开其正文写出条件分支：空列表、加载中、分区标题与开关；空态注明图标、标题与提示文案的字符串 key 和源行号，并保留在交给实现者的规格与摘要里。子组件定义在工程内就必须打开；只有定义在无源码的外部库时，才按依赖坐标取源，取不到就写明缺口与已查路径，不只写一行组件映射。
6. 页面调用项目自定义组件或共享组件时，打开组件定义取视觉与交互契约（形状、裁剪、填充方式；点击切换、数量步进、按钮可用条件），写进页面规格或实现清单，并把定义文件列入源码锚点。
7. 源端条目经公共构建器注册时，打开构建器定义（调用所在文件未命中就扩大到整个模块），列出它对每个条目附加的副作用（说明链接、图标、回调）并逐项映射到目标。
8. 页面类继承共享基类时，打开基类核查 startActionMode、菜单膨胀、setTitle 与回调登记，把操作栏标题格式、关闭键、溢出项和全部退出触发（返回键、ActionMode 关闭、菜单动作完成）写成验收条款，规格引用某标志时写明由谁置位；实现时发现被消费的标志“无入口”，先在源码中找置位者，找到就实现，找不到就登记规格缺口，不以“契约位保留”收口。
