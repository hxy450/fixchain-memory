# 从源端窗口或控件封装类提取行为时，把按触发源或状态分叉的可见行为逐项写入契约：各动画分支时长、一次性引导、离线禁用与换图

ID：`lesson-5948050d3b6dc39239a4` · 版本：1

[本主题](index.md)

## 何时使用

规格提取或 Android 行为分析阶段，从窗口类、控件封装类（浮层窗口、底栏 FootBar 一类）整理动画、手势与状态相关表现时

## 适用情境

源端在同一类中为不同触发源定义独立动画与时长（自动入场、驻留、出场与手势收起各用一组），以偏好标记控制首次全屏引导（显示后写回标记），或由 setOffline、setEnabled 一类方法切换禁用、图标与文字颜色；契约容易只摘主时序和主流程。

## 原因

只摘主流程会丢掉分支：手势专用的退出时长、一次性引导图、离线禁用换图都会在下游实现中消失，实现者照摘要写也很难察觉。来源中两份规格分别漏写了上滑专用的 500ms 动画与首次引导、离线时禁用发弹幕并换灰图，写规格的分析者都已读到这些分支。

## 做法

1. 逐个列出类中的动画及其触发分支（自动、手势、取消）和各自时长，不用“上滑收起”一类说法概括手势分支。
2. 偏好标记控制的一次性 UI（如首次引导）列为独立行为项：显示条件、资源、关闭方式与写回的标记，并在偏好接口清单里给出读写方法。setOffline、setEnabled 一类状态方法切换的禁用、替换图标与文字颜色写进对应控件的契约条目，不只把状态名列为某个跳转的参数。

来源支持：2 张卡 · 1 次迁移 · 1 个应用
