# 源码默认值写的是符号常量时，先解析其定义取值再写进规格或模型常量，不按“未设置=-1”的习惯填数

ID：`lesson-40ee4d9782ae3cb4aa88` · 版本：1

[本主题](index.md)

## 何时使用

规格提取阶段把实体字段默认值、偏好缺省值落成具体数值时；模型实现阶段声明与源端同名的常量时

## 适用情境

源端实体或偏好的默认值引用另一文件定义的符号常量（如 var id: Long = ID_UNSET、sp.getLong(key, ID_UNSET)），规格表或目标代码要写出具体值；目标把该常量作为共享哨兵，被偏好缺省、列表行 id 等多个模块复用。

## 原因

只读到符号引用、没解析定义就按习惯值填写；规格表的值被模型层固化为全局常量，偏好缺省与对外 id 一起偏离。下游即使读到给出正确值的功能规格，也可能以“不改基础层、分支选择等价”为由放行，对外可观察的值仍然错误。

## 做法

1. 规格提取遇到符号常量时检索其定义（如 const val ID_UNSET）取得实际值再写入；未解析到定义时写符号名并标未核及源文件，不填推断值。
2. 模型层声明与源端同名的常量时打开定义文件核对数值；与规格表冲突时以源定义为准并回报规格。
3. 功能实现发现功能规格给出的哨兵值与基础层常量不一致时，对外暴露的值（偏好缺省、列表行 id）按功能规格投影，并在返回中上报冲突。
