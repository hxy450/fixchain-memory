# 用户只给出部分页面截图时，迁移范围包含这些页面入口直达的二级页面；范围类必问项无法询问时不自行取最窄解释

ID：`lesson-91c89aff3f8c5c47bd2a` · 版本：1

[本主题](index.md)

## 何时使用

规格提取阶段，确定本轮迁移范围并处置截图页入口直达的清单外 Activity 时；以及实现、交付阶段遇到被排除在范围外的入口时

## 适用情境

用户附若干页面截图，要求“按图片和源码迁移、修到可交付”并跳过确认；截图页上的按钮、菜单在源码中 startActivity 到说明页、记录页、关于/反馈、设备连接等独立页面；覆盖检查对这些被引用的 Activity 报未计入。

## 例外与边界

- 用户明确限定只迁移截图中的页面本身；此时仍按最后一条汇报未实现入口

## 原因

截图说明的是这些页面长什么样，不是“只做这些页面”。把截图当范围边界并自行登记排除项，会让入口只剩占位 Toast、未注册路由，覆盖检查被 skip-list 关闭，交付报告仍写“占位符 0、可交付”。来源中规格作者读过要求逐项询问的范围类目、源码里各入口的导航目标和覆盖阻断，仍自填“仅截图页、不生成清单外页面”，导航表与验收条目要打开的目标页不在页面清单里；下游按这条决策写出 Toast 与只注册截图页的路由，用户随后要求补齐全部二级流程。

## 做法

1. 以截图页为根，从源码点击监听与 Intent 抽出每个入口的直达目标，列入本轮页面清单或功能；跳过确认不等于授权缩小范围，必问的范围类目无法询问时取入口可达闭包，而不是最窄解释。
2. 覆盖检查报被范围内页面引用的 Activity 未计入时，补页面规格或功能锚点，不用自拟的范围决策登记跳过；写完核对导航表和验收条目要打开的目标都在页面清单里，冲突先消解。
3. 范围确被限定时，入口不以“暂不可用”Toast、无响应或其他入口兜底冒充完成；把未实现入口汇总给协调者，并在交付总结中逐项列出。
