# 决策把系统表面（桌面 Widget 等）替换为应用内页面时写明入口位置与形式；受保护的对等页面不新增可见控件

ID：`lesson-238588d3cceaf707ccfe` · 版本：1

[本主题](index.md)

## 何时使用

决策与规格阶段批准平台替代方案时；巡检与修复阶段为替代页补可达入口时

## 适用情境

源端某能力依附系统表面（桌面 Widget、快捷方式等），决策降级为新的应用内页面；源应用内没有对应入口；决策账本限定该替代只作用于本功能，不得改变其他已对等复刻页面的布局与导航。

## 例外与边界

- 决策明确批准在某个对等页面加可见入口

## 原因

替代页只定义了自身行为而没有入口，实现后无人调用；巡检写出“在合适的现有页面加可见入口”，修复者就在对等页面加按钮，破坏逐屏对齐，还自称未越界。来源中决策作用域写明不得改变购物车与导航行为，巡检与修复者都读到了这句，仍在购物车配送栏加了源端没有的圆形按钮、挤压地址文本，直到视觉复核才改为配送栏长按。

## 做法

1. 批准替代时同时写明替代页入口的位置与形式，以及它对对等页面布局的影响；没写就登记为决策缺口，不留给下游临场选择。
2. 巡检发现替代页不可达时，修法先对照决策作用域；任何可见入口都会改动受保护页面时，给出不改变可见结构的入口（如给已有区域加长按手势），或标为决策冲突上报。
3. 在对等页面加入口前，列出该区域在源端的全部子元素；出现源端没有的可见控件即视为越界。
