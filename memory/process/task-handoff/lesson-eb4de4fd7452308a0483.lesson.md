# 删除前向占位或需核验标记前，按源码核对登记的触发文本并逐项兑现：只接一半、写成常量或删掉标记都不算闭合

ID：`lesson-eb4de4fd7452308a0483` · 版本：10

[本主题](index.md)

## 何时使用

切片实现或接线阶段，把页面转换留下的前向占位（FWD-REF、TODO）替换成实现并删除标记时；收敛阶段解除“不确定、待真机核验”一类前向标记时

## 适用情境

页面转换阶段按“只输出 UI”约束留下前向占位，登记表或 TODO、文件头注释写有触发文本（例：“持久化并触发主题立即切换”“由服务提供版本号”“游客登录（登录成功跳主页）”），或钩子只写占位编号与归属切片，由后续切片或接手者实现。也包括 forward-ref-uncertain、“需实测校正”一类需核验标记，收尾者以“共享件已由另一切片定型”或“实现可行”为由删除；导航类钩子只带触发动作的枚举或事件名、未写目标页，而路由表注册了名称相近的候选页（如 Xxx 与 XxxReal）；关闭共享能力的占位时同一能力还有其他文件消费，或未完成的部分被注释指向另一文件已登记的占位编号。

## 原因

标记删掉后，结构闭包审计和收口勾选只看标记与局部证据（如结果已写入 Store），触发文本里没做的那部分要到验证或用户操作才暴露；触发文本与钩子说明由上游转写，可能漏掉源端的结果分支或恢复、回写等行为。导航类钩子没写目标页时，只看账本和路由表会在名称相近的已注册页里按字面挑一个，正确目标页成了孤儿。

## 做法

1. 删标记前读出该占位在登记表、页面规格、TODO 与所属切片计划里的完整触发文本，并回读页面规格源码锚点中对应的源端方法（结果观察者，加载、恢复、切换回写等）；把两者合成动作清单（持久化、运行期消费方、反馈、值来源、导航），触发文本漏写的源端动作按源码补齐，不只按钩子名称接线；每一项都能在代码里指出实现位置后再删。设置项、版本号、平台能力的具体闭合写法分别见 lesson-4d0f0176b3d09c33f1eb、lesson-a6ed8a9c6017ddb73beb、lesson-efb94f2d70d4df1c65d7。
2. 触发文本要求服务或 ViewModel 提供值时，写入常量或复制配置文件里的值不算闭合，改由触发文本指定的服务或 ViewModel 提供；删除标记后 grep 同一函数，恒定返回（return false、两支相同的三元表达式）与配置文件相同的字面量都是没闭合的信号。
3. 只接上了调用、没处理结果分支（成功后的跳转、失败提示）时保留标记，不算接线完成。
4. 删除标记前，逐项核对组件里每个 available/可选区块开关都有真实的赋值来源；源端在选中项变化时附带的查询（如按选中日查历法）迁到网关或 ViewModel，不留默认值让条件渲染把整块隐藏。
5. 导航类钩子的目标页按触发控件到 UI 规格的导航关系表或源端监听器的 Intent/startActivity 追溯；路由表有同前缀的候选页时先确认各自对应的源页面，确认不了就登记缺口，不按名称相似度选择。
6. 解除“不确定、需实测”类标记须附核验证据（截图、dump 或等价单测）；生成期无法实测时保留标记，写明待测字段与预期值。“共享件已由其他切片定型”“实现可行”不能作为删除理由；能从源码查明并直接实现的项不必等真机，当场实现并解除（登记门槛见 lesson-a2f6a4ae9a72be740de6）。
7. 闭合时对照登记原条目逐项核对（装载参数、清洗、主题等是否一并迁移）；未完成的部分在本文件登记新占位，不在注释里借用另一文件的占位编号；关闭共享能力的占位时，把检索命中的所有消费方逐个接上或重新登记。
