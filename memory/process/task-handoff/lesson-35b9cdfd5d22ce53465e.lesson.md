# 规格把实现路径写成“由后续决策轮裁决”时，后续决策轮逐条出题或关闭；自检按内容对应通道，不按编号凑对

ID：`lesson-35b9cdfd5d22ce53465e` · 版本：1

[本主题](index.md)

## 何时使用

规格与决策闸门阶段，决策卡或规格条目写有“形态未定、由下一轮决策裁决”时；实现阶段遇到写着“X 还是占位，待裁决”的条目时

## 适用情境

规格把某通道的实现路径延后裁决（如“系统 Kit 还是占位，由第二轮问答裁决”），闸门批准了这张卡；后续决策轮有预列的题目清单，并按编号把决策卡与占位登记行对照自检。

## 原因

延后的裁决没进入下一轮题目清单、自检又按编号把别的通道的登记行对上时，这项决定既没出题也没关闭，原文带着“待裁决”进入实现，实现者按最保守的占位落地。

## 做法

1. 决策闸门把各卡中“由第 N 轮裁决、形态未定”的条目逐条列出，出题或明确关闭；自检按卡片内容与通道对应登记行，不按编号凑对。
2. 实现阶段遇到“待裁决”条目，先查决策账本有无结论；没有结论而能力可由平台或已知依赖提供时，按可用路径实现并回报，不登记基于未核实前提的占位。
