# process/task-handoff

跨任务移交：留给别的文件、切片或编排者兑现的工作如何登记、分派、接收与闭合（含拆分重派时全局动作的承接与阶段放行门），派工的必读清单、阅读顺序与对接清单，各类占位（含“无等价”“资源未就绪”）的使用边界与登记前核查，重新规划时已批准未执行规格的承接，子代理派发失败后的重试与降级条款，规格中“待后续决策轮裁决”条目的出题与关闭，修复轮核出但延后不修的偏差登记，worker 超时仍在运行时是否由编排者接管其契约产物；页面先于共享组件实现时页内副本的登记与收敛

## 本级经验

- [“不确定”“待补资源”“无等价”“延期”“契约未确认”这类占位只登记输入确实缺值的情况：登记前查源码、SDK 与写入时刻的目录，能实现的当场实现](lesson-a2f6a4ae9a72be740de6.lesson.md)
  - 时机：页面转换阶段决定是否登记 forward-ref-uncertain、resource-pending-asset 等占位，以及收口或验收阶段把这些占位改成 deferred 时；接线阶段决定尚未接通的页面动作是实现还是给出不可用提示时；把源端效果登记为“无等价/保留近似”，或派发对已登记近似项的复审时；收尾闭环处理指向本组或“集成期”的占位、准备按降级形态关单时
  - 情境：工程提供多种占位类型（不确定值、待补资源、延期），页面规格置信度为 medium 或同名资源看似存在；源码和规格其实已给出行为或所需图形。也包括接线者给尚未接通的页面动作统一写 fail-loud 兜底（如“契约未确认，暂不可用”），而源端这些动作已有实现、目标工程也已有承担它们的共享组件。也包括实现者认为目标框架缺少对应能力（混合模式、端点渐变平铺等）而写入“无等价、保留近似”登记，复审派工又预写“保留”；或页面转换与资源迁移并行，转换者在资源复制完成前列目录看到空目录，就登记“资源未就绪”并改用降级。也包括写者只按对称方法名检索就把平台能力判为“无对等 API”，把可在本地实现的变换、自有端点引擎或页内权限链挂成依赖未建工件，以及收尾者为避开债务闸把占位改挂“集成期”“死码域披露”或按降级现状关单。也包括写者以“目标没有对等能力”为由删去源端构建标志条件分支（工程源码内检索不到生成文件引用），或未查 Options 类型字段（如气泡整体底色）就用近似替代且未登记。也包括把源有动画、目标写成静态的已知永久降级登记为 resolve_by 后续切片的前向引用，或编排派工统一要求把动画、视觉保真类占位 retag 为外部视觉核验阶段，而本轮流水线不运行该阶段。
  - 例外：缺的确实是输入里没有的值，例如合成快照缺少尺寸、资源映射表里没有对应资产
- [删除前向占位或需核验标记前，按源码核对登记的触发文本并逐项兑现：只接一半、写成常量或删掉标记都不算闭合](lesson-eb4de4fd7452308a0483.lesson.md)
  - 时机：切片实现或接线阶段，把页面转换留下的前向占位（FWD-REF、TODO）替换成实现并删除标记时；收敛阶段解除“不确定、待真机核验”一类前向标记时
  - 情境：页面转换阶段按“只输出 UI”约束留下前向占位，登记表或 TODO、文件头注释写有触发文本（例：“持久化并触发主题立即切换”“由服务提供版本号”“游客登录（登录成功跳主页）”），或钩子只写占位编号与归属切片，由后续切片或接手者实现。也包括 forward-ref-uncertain、“需实测校正”一类需核验标记，收尾者以“共享件已由另一切片定型”或“实现可行”为由删除；导航类钩子只带触发动作的枚举或事件名、未写目标页，而路由表注册了名称相近的候选页（如 Xxx 与 XxxReal）；关闭共享能力的占位时同一能力还有其他文件消费，或未完成的部分被注释指向另一文件已登记的占位编号。
- [同一产物只能有一个写者：并行任务可能写同一共享文件时指定唯一作者；worker 超时仍 running 时不凭旧观测接管](lesson-39e7e31b88e3d6176022.lesson.md)
  - 时机：执行编排阶段，安排多个并行任务、其中几个可能创建或改写同一共享文件时；派发的 worker 多次等待超时，或尚未派发某项任务，编排会话考虑自己写入本应由 worker 产出的契约产物时
  - 情境：流水线 skill 的收口协议规定完成信号是 list_agents 的 completed 而不是产物文件存在，连续超时先核对状态、句柄消失才断点重派，契约产物须出自承担任务的子代理、禁止派发方代写；worker 已重派且仍为 running，编排者早些时候查过目标目录为空。也包括编排者不派发 Base 任务、自写产物后直接以 PASS 写回；以及多个并行转换任务都会创建同一共享组件。
- [子代理派发失败先按报错修正参数重试；确需改由主线程执行时，按 skill 降级条款补跑被派发的步骤](lesson-ae78da6f1a3669f6ef59.lesson.md)
  - 时机：执行编排阶段，spawn_agent 等子代理派发返回错误、准备改由编排会话自己完成时
  - 情境：流水线 skill 要求派发子代理完成 API 清单等步骤，并写有子代理不可用时的降级条款（如在汇合点前台串行跑一次）；派发因参数类型错误（如布尔参数传成字符串）失败，编排者准备把它当成环境限制。
- [子任务回报把工作指给其他负责方，或拆分、重派任务时，编排者把待接事项与原派工里的全局动作逐条写进负责方的派工](lesson-10572ff247350f1ecafe.lesson.md)
  - 时机：执行编排阶段，收齐子任务返回、为下游切片或接线任务写派工，或拆分、重派子任务时；实现子代理运行期间编排者读到新的源端证据时
  - 情境：子任务返回的 open_questions、风险项或文件头说明，把某项工作指给另一个阶段、切片或编排者本人（如返回键转发交给“入口装配或后续接线决定”，或回报某项“不在本段范围”）；上游交接把字体注册、主题模式同步、入口接线等全局动作指派给某个任务，该任务随后被拆分或重派；基础模块文档写着“由某负责方调用”“待闭环”“建议 P-ID”；派发页面接线任务时，页面规格里有导航关系与状态接口。也包括对比子代理只把结论回给编排者，或编排者自己读到源端界面与接口，而实现子代理仍在运行。
- [把 fragment 内容交给共享组件、宿主页另建容器时，fragment 根布局的 padding 与背景只由一方实现，并写进移交项](lesson-8a7d25959b954ffb9215.lesson.md)
  - 时机：页面转换与接线阶段，把 fragment 拆成宿主页容器与共享组件、确定根内边距与背景的归属时
  - 情境：源 fragment 根 LinearLayout 带 padding（ViewPager 等宿主本身无 padding）；目标页面转换者在宿主 TabContent 等容器上写了这份 padding，又把 fragment 内容交给共享组件，组件按源在根上再加一次。
- [派工的必读清单、阅读顺序与对接清单要覆盖任务依赖的语义来源（框架约束、源工程路径、移交的验收条款），附加提速要求时也保留](lesson-8598e0af342dd5c8ba28.lesson.md)
  - 时机：执行编排阶段，给页面转换、公共组件或收敛替换任务写派工，附加“效率纪律”、规定逐项“读源→立即写”的顺序，或列出要换成共享原语的对接点时；派发“对比源端还原某功能或页面”的实现任务时；维护共享踩坑参考、在切片之间移交职责时
  - 情境：派工为提速限制阅读范围，或按组件清单规定阅读顺序；被写的组件依赖 Modifier 扩展、交互映射参考中的 API 语义表等外部定义；收敛任务要把页面私有写法替换成映射文档里的共享原语（阴影、排版等），并允许整文件重写。也包括并行派发对比与实现子代理，派工没写源工程路径与对应 Screen/ViewModel/Service。也包括某些框架约束只出现在某页注释、某个 skill 或移出方笔记里（一个组件只挂一个半模态、列表键须随实例变化、百分比宽度叠加外边距溢出、深色模式专项 skill、聚合器状态映射条款），接收方的写前输入里没有。
  - 例外：多个并行任务会写同一共享文件：按单一写者的经验指定作者
- [派工转述规则或把某任务的局部做法推广为派工规则时，连同原文的替代写法、适用范围与配套要求一起下发](lesson-73a7dd4f78cb747f7e7e.lesson.md)
  - 时机：编排或返修阶段，把规则清单、决策台账条目或上一批子任务回报的做法转述进后续 worker 派工时
  - 情境：编排者收到的规则原文带有替代写法（例如“禁止 Record，改用具名字段或 HashMap”），派给多个并发 worker 时压缩成一句禁令。也包括首批子任务回报了按某参考条目采用的局部做法（如把弹窗写成页内覆盖层），编排者把它写成“全部照此处理”的后续派工规则；以及把决策台账里替代某一源模块的技术参数（如替代后台任务的固定 tick 周期）写进另一模块（如前台动画引擎）的派工，派工前没读该 feature 规格的映射行，并按印象概括源码锚点的内容。
  - 例外：派工同时禁止 worker 构建：收尾构建责任按交付前编译的经验处理
- [编排者推进阶段或派发依赖上游的下游任务前，核对约定产物、划给编排者的子步骤、放行门与子任务回执，缺项不推进](lesson-5754b7be28238f1bdf57.lesson.md)
  - 时机：执行编排阶段，子任务返回后决定推进到下一阶段、派发依赖上游产物的下游任务、关闭巡检报告，或按子任务回执向用户报告完成时
  - 情境：执行规范把某些收尾步骤（如资源阶段之后的应用身份落地）留给编排者亲自调用；后台子任务回报 completed，但约定产物（如清单 JSON）没有落盘、回报文字被截断，或回报提到一个需要在别处调用的入口（如网络初始化函数）却没写调用点；子任务回执只写“已补齐”“均保留”，不列对照过的源文件；资源迁移等阶段设有放行门（HARD-GATE），下游页面转换准备与之并行；巡检报告列出多个 BLOCKER，派发修复失败（如线程上限）或只修了其中一部分。
- [要靠其他文件或任务补实现的功能，登记成带负责方、验证方式和源端确定值的移交项，不只写在注释或动作摘要里](lesson-4f81eeea17b94190c2de.lesson.md)
  - 时机：页面转换、切片实现、基础设施实现或接线阶段，本文件的功能需要别的文件补调用点、或要由后续步骤补值才完整时（包括留下前向引用、TODO 占位、需要在入口调用的初始化函数），以及读到上游留给本文件的移交说明时；以及修复轮核出、但决定本轮不修的相邻偏差时
  - 情境：写码者确认某项行为在当前文件里无法闭合（例如非入口组件的平台回调要由入口页转发、宿主回调留给接线切片、脚手架身份值留给后续步骤、新建的 init 要由入口调用、UI 转换阶段先留业务占位），工程提供了移交登记约定（如带 owner/what/verify 的 HANDOFF 标记、前向引用登记表、返回信封中的字段）；或接线者在上游文件头读到要求本文件转发的说明。也包括写者读到源端宿主或子类对共享组件的改写、自己不能改共享文件，只在转换报告里记“保真缺口”；以及 UI 阶段规格写明交互留给后续切片，写者准备照兄弟页写成真实但不符合源端的实现。
  - 例外：页面先于共享件实现、写页内等价副本：按待收敛项登记的经验处理（共享件就绪后按源比对并替换）
- [规格把实现路径写成“由后续决策轮裁决”时，后续决策轮逐条出题或关闭；自检按内容对应通道，不按编号凑对](lesson-35b9cdfd5d22ce53465e.lesson.md)
  - 时机：规格与决策闸门阶段，决策卡或规格条目写有“形态未定、由下一轮决策裁决”时；实现阶段遇到写着“X 还是占位，待裁决”的条目时
  - 情境：规格把某通道的实现路径延后裁决（如“系统 Kit 还是占位，由第二轮问答裁决”），闸门批准了这张卡；后续决策轮有预列的题目清单，并按编号把决策卡与占位登记行对照自检。
- [重新规划或替换计划时，把已批准未执行的规格逐条映射到新计划的批次与验收，或写明合并、推迟、放弃的去向](lesson-b843621a5b9c279b1b2b.lesson.md)
  - 时机：迁移规划阶段，全量重审后以新计划替换原有局部计划，或制定、合并迁移计划时
  - 情境：增量迁移中已有获用户批准、尚未执行的局部缺陷规格（如某项偏好持久化），随后重新盘点并按模块、批次重写总体计划。
- [页面先于共享组件或共享工具实现时，页内等价实现登记为待收敛项；共享件就绪后按源比对并改用共享实现，不让两套实现并存到交付](lesson-447ba5818e4e203272e8.lesson.md)
  - 时机：执行编排阶段决定页面转换与公共组件、共享工具的派发顺序时；页面转换阶段在共享件尚未就绪时写页内等价实现时；切片实现或收口阶段，验收目标指向的共享件已存在而页面仍用页内副本时
  - 情境：源端组件或格式化工具被多页共享（列表行组件、计时文本、数值格式化等），目标计划或组件清单已把它列为共享件；页面转换先于共享件派发，派工写“共享件未完成，页内内联等价实现优先”而没有要求登记回收；后续切片的修改范围只含本页或只要求解除标记。
