# process/task-handoff

跨任务移交：留给别的文件、切片或编排者兑现的工作如何登记、分派、接收与闭合（含拆分重派时全局动作的承接与阶段放行门），派工的必读清单、阅读顺序与对接清单，各类占位（含“无等价”“资源未就绪”）的使用边界与登记前核查，重新规划时已批准未执行规格的承接，子代理派发失败后的重试与降级条款，规格中“待后续决策轮裁决”条目的出题与关闭

## 本级经验

- [“不确定”“待补资源”“无等价”“延期”“契约未确认”这类占位只登记输入确实缺值的情况：登记前查源码、SDK 与写入时刻的目录，能实现的当场实现](lesson-a2f6a4ae9a72be740de6.lesson.md)
  - 时机：页面转换阶段决定是否登记 forward-ref-uncertain、resource-pending-asset 等占位，以及收口或验收阶段把这些占位改成 deferred 时；接线阶段决定尚未接通的页面动作是实现还是给出不可用提示时；把源端效果登记为“无等价/保留近似”，或派发对已登记近似项的复审时；收尾闭环处理指向本组或“集成期”的占位、准备按降级形态关单时
  - 情境：工程提供多种占位类型（不确定值、待补资源、延期），页面规格置信度为 medium 或同名资源看似存在；源码和规格其实已给出行为或所需图形。也包括接线者给尚未接通的页面动作统一写 fail-loud 兜底（如“契约未确认，暂不可用”），而源端这些动作已有实现、目标工程也已有承担它们的共享组件。也包括实现者认为目标框架缺少对应能力（混合模式、端点渐变平铺等）而写入“无等价、保留近似”登记，复审派工又预写“保留”；或页面转换与资源迁移并行，转换者在资源复制完成前列目录看到空目录，就登记“资源未就绪”并改用降级。也包括写者只按对称方法名检索就把平台能力判为“无对等 API”，把可在本地实现的变换、自有端点引擎或页内权限链挂成依赖未建工件，以及收尾者为避开债务闸把占位改挂“集成期”“死码域披露”或按降级现状关单。
  - 例外：缺的确实是输入里没有的值，例如合成快照缺少尺寸、资源映射表里没有对应资产
- [子代理派发失败先按报错修正参数重试；确需改由主线程执行时，按 skill 降级条款补跑被派发的步骤](lesson-ae78da6f1a3669f6ef59.lesson.md)
  - 时机：执行编排阶段，spawn_agent 等子代理派发返回错误、准备改由编排会话自己完成时
  - 情境：流水线 skill 要求派发子代理完成事实树、API 清单等步骤，并写有子代理不可用时的降级条款（如在汇合点前台串行跑一次）；派发因参数类型错误（如布尔参数传成字符串）失败，编排者准备把它当成环境限制。
- [派工的必读清单、阅读顺序与对接清单要覆盖任务依赖的语义来源，附加提速要求时也保留](lesson-8598e0af342dd5c8ba28.lesson.md)
  - 时机：执行编排阶段，给页面转换、公共组件或收敛替换任务写派工，附加“效率纪律”、规定逐项“读源→立即写”的顺序，或列出要换成共享原语的对接点时；派发“对比源端还原某功能或页面”的实现、修复任务时
  - 情境：派工为提速限制阅读范围，或按组件清单规定阅读顺序；被写的组件依赖同目录的 Modifier 扩展、交互映射参考中的 API 语义表等外部定义；收敛任务要把页面私有写法替换成映射文档里的共享原语（阴影、排版、颜色映射函数等），并允许整文件重写。 也包括并行派发对比与实现子代理，派工没写源工程路径与对应 Screen/ViewModel/Service，实现者未读源界面就写页面。
- [派工转述规则或把某任务的局部做法推广为派工规则时，连同原文的替代写法、适用范围与配套要求一起下发；禁止并发构建的 worker 改动汇总后立即全量构建](lesson-73a7dd4f78cb747f7e7e.lesson.md)
  - 时机：编排或返修阶段，把规则清单或上一批子任务回报的做法转述进后续 worker 派工，并决定 worker 能否自行构建时
  - 情境：编排者收到的规则原文带有替代写法（例如“禁止 Record，改用具名字段或 HashMap”），派给多个并发 worker 时压缩成一句禁令，并要求 worker 不跑全量构建。也包括首批子任务回报了按某参考条目采用的局部做法（如把弹窗写成页内覆盖层），编排者把它写成“全部照此处理”的后续派工规则。也包括禁编译的 worker 写出 TS 习惯写法（implements SDK class、按类名调用顶层函数），而收尾构建因会话中断没有执行。
- [编排者推进阶段、拆分重派或派发下游前，核对约定产物与放行门，把回报里的待接事项和原派工里的全局动作逐项落到负责方](lesson-5754b7be28238f1bdf57.lesson.md)
  - 时机：执行编排阶段，子任务返回后决定推进到下一阶段，为下游切片、接线任务写派工，拆分、重派或合并子任务派工时，以及处理巡检报告中的阻断项时
  - 情境：执行规范把某些收尾步骤（如资源阶段之后的应用身份落地）留给编排者亲自调用；子任务返回的 open_questions、风险项或文件头说明，把某项工作指给另一个阶段、切片或编排者本人；也包括后台子任务回报 completed，但约定产物（如清单 JSON）没有落盘、回报文字被截断，或回报提到一个需要在别处调用的入口（如网络初始化函数）却没写调用点；以及巡检报告列出多个 BLOCKER，编排者派发修复失败（如线程上限）或只修其中一部分。也包括上游交接把字体注册、主题模式同步、入口接线等全局动作指派给某个任务，该任务随后被拆分或重派；或资源迁移等阶段设有放行门，下游页面转换准备与之并行。 也包括编排者在实现子代理运行期间自己读到源端界面与接口，或对比子代理只把结论回给编排者，等待与转发调用又因参数错误失败。
- [要靠其他文件或任务补实现的功能，登记成带负责方、验证方式和源端确定值的移交项，不只写在注释或动作摘要里](lesson-4f81eeea17b94190c2de.lesson.md)
  - 时机：页面转换、切片实现、基础设施实现或接线阶段，本文件的功能需要别的文件补调用点、或要由后续步骤补值才完整时（包括留下前向引用、TODO 占位、需要在入口调用的初始化函数），以及读到上游留给本文件的移交说明时
  - 情境：写码者确认某项行为在当前文件里无法闭合（例如非入口组件的平台回调要由入口页转发、宿主回调留给接线切片、脚手架身份值留给后续步骤、新建的 init 要由入口调用、UI 转换阶段先留业务占位），工程提供了移交登记约定（如带 owner/what/verify 的 HANDOFF 标记、前向引用登记表、返回信封中的字段）；或接线者在上游文件头读到要求本文件转发的说明。
- [规格把实现路径写成“由后续决策轮裁决”时，后续决策轮逐条出题或关闭；自检按内容对应通道，不按编号凑对](lesson-35b9cdfd5d22ce53465e.lesson.md)
  - 时机：规格与决策闸门阶段，决策卡或规格条目写有“形态未定、由下一轮决策裁决”时；实现阶段遇到写着“X 还是占位，待裁决”的条目时
  - 情境：规格把某通道的实现路径延后裁决（如“系统 Kit 还是占位，由第二轮问答裁决”），闸门批准了这张卡；后续决策轮有预列的题目清单，并按编号把决策卡与占位登记行对照自检。
- [解决前向占位时按登记的触发文本逐项兑现：只接一半、写成常量或删掉标记都不算闭合](lesson-eb4de4fd7452308a0483.lesson.md)
  - 时机：切片实现或接线阶段，把页面转换留下的前向占位（FWD-REF、TODO）替换成实现并删除标记时；收敛阶段解除“不确定、待真机核验”一类前向标记时
  - 情境：页面转换阶段按“只输出 UI”约束留下前向占位，登记表或 TODO、文件头注释写有触发文本，例如“持久化并触发主题立即切换”“切换步骤时重触觉”“由服务提供版本号”“通知授权由平台服务实现”“游客登录（登录成功跳主页）”，由后续切片或接手者实现。也包括 forward-ref-uncertain 一类待核验标记，收尾者以“共享件已由另一切片定型”为由删除。也包括导航类钩子只带触发动作的枚举或事件名（如某入口奖励完成），未写目标页，而路由表注册了名称相近的候选页（如 Xxx 与 XxxReal）。
- [重新规划或替换计划时，把已批准未执行的规格逐条映射到新计划的批次与验收，或写明合并、推迟、放弃的去向](lesson-b843621a5b9c279b1b2b.lesson.md)
  - 时机：迁移规划阶段，用户要求全量重审、以新计划替换原有局部修复计划时
  - 情境：增量迁移中已有获用户批准、尚未执行的局部缺陷规格（如某项偏好持久化），随后重新盘点并按模块、批次重写总体计划。
