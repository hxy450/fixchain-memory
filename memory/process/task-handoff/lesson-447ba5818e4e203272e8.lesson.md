# 页面先于共享组件或共享工具实现时，页内等价实现登记为待收敛项；共享件就绪后按源比对并改用共享实现，不让两套实现并存到交付

ID：`lesson-447ba5818e4e203272e8` · 版本：3

[本主题](index.md)

## 何时使用

执行编排阶段决定页面转换与公共组件、共享工具的派发顺序时；页面转换阶段在共享件尚未就绪时写页内等价实现时；切片实现或收口阶段，验收目标指向的共享件已存在而页面仍用页内副本时

## 适用情境

源端组件或格式化工具被多页共享（列表行组件、计时文本、数值格式化等），目标计划或组件清单已把它列为共享件；页面转换先于共享件派发，派工写“共享件未完成，页内内联等价实现优先”而没有要求登记回收；后续切片的修改范围只含本页或只要求解除标记。

## 原因

页内副本与共享件由不同写者各自转写，偏差各不相同（格式默认参数、字重、行数限制、调用点乘数）；没有回收登记时，后续切片以修改范围为由不替换，两套实现并存到交付，共享件无人消费，问题要在两处分别发现和修复。

## 做法

1. 编排派工时，页面转换先于共享件派发就在派工中列出该页应消费的共享组件或工具，附上对应规格中的显示公式与格式条目，并要求页内等价实现登记待收敛项（指向共享件与负责切片）；能调整顺序时先完成共享件再派页面。
2. 页面写者写页内等价实现时按源码逐项转写（调用点实参、被调函数的默认参数与格式），并登记待收敛项；“已知近似”的说明不能代替语义复刻和回收登记。
3. 共享件就绪且验收目标指向它时，页面 owner 在本切片按源比对页内副本与共享件，差异先修进共享件，再删除页内副本、改为调用共享实现；修改范围不允许时登记差异、回收任务与负责方，不让两套实现并存到交付。
