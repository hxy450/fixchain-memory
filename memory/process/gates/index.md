# process/gates

结构检查与自动修复的收口：会改写源码的自愈脚本运行后审阅改动（含图标尺寸自愈的密度换算），按关键字判定的检查要真实落实而不是迎合检查器，用共享组件替换页面已实现片段（关闭孤儿组件检查或按计划收口）前的完整读取与视觉核对，功能对齐与验收结论以代码中的实际落点为准，执行已批准计划时替换清单的逐行收口，交互问题的复现与分层定位，未验证与被点名风险项的“未验证”标注，写文件以真实执行回执为准与模板入口页的内容断言

## 本级经验

- [交互问题先复现并分层定位、确认触摸可达再改约束；未经设备验证、被阻断、不可观察或被点名为风险的结论标为未验证并回流，修复前已存在的字符串不作 RED/GREEN 依据](lesson-afae8d13e00941efe808.lesson.md)
  - 时机：缺陷修复与验证阶段，修复“点击没有反应”“滑不动”一类交互问题并选择回归验证方式时；验证阶段功能点因宿主不可达或数据未加载而无法观察时；收尾或收敛时，准备把被点名为风险、只能界面判定的验收项写进已实现清单时
  - 情境：页面菜单项、按钮已绑定 onClick 却点击无效；设备可连接，但 UI 测试在启动 Ability 阶段超时，修复者考虑用 grep 结构契约代替设备断言。或验证阶段某些功能点因宿主不可达被 BLOCKED、页面因数据未加载看不到内容。也包括弹层、卡片内一片控件全部不响应点击或滑动，候选原因同时有祖先节点的命中测试设置与滚动容器的尺寸约束；或执行者已把只能靠界面判定的验收项点名为风险，生成期不能编译运行、没有真机。
- [修复安全区等按关键字判定的结构检查时逐页落实实现，不用含检查关键字的注释让检查通过](lesson-f6b95d7d6d0159cb0436.lesson.md)
  - 时机：结构修复阶段处理安全区 Layer 3 等按关键字或 grep 判定的检查失败时
  - 情境：结构检查按关键字或 grep 判断页面是否处理了安全区等要求；修复者面对多页 FAIL，工程有共享窗口模型（顶部/底部避让值），skill 要求每个全屏 NavDestination 页实际加 padding。
- [写文件以真实执行回执为准：只有文本形式的工具调用即未写入；覆盖模板入口页后按内容断言读回](lesson-776ed5eb216833c6b002.lesson.md)
  - 时机：执行阶段写入或覆盖文件并据此记录进度、宣告页面或阶段完成时；验证阶段报告入口页已迁移时
  - 情境：写文件依赖 shell heredoc、apply_patch 等工具调用，运行环境可能把未解析的调用当作普通文本输出后结束回合；目标工程由模板创建，入口 Ability 的 loadContent 指向仍为 Hello World 的模板页；阶段完成标记只检查报告文件是否存在。
- [功能对齐与验收结论逐项以代码落点为准：按规格验收项与导航出口检索实际组件和调用，空回调与只含注释的回调不算实现](lesson-9147be4d87153de9c5b6.lesson.md)
  - 时机：验证阶段核对功能完成度，或实现、返修后向用户报告“已实现/已对齐”时；执行阶段宣告页面转换或流水线阶段完成时；协调者收到子任务“已接入真实接口”“已补齐”的回执时
  - 情境：验证检查只 grep TODO: 与占位登记表；实现者或返修者按功能点列对齐表并逐项打 ✅；规格写有验收条目、页面导航出口与启动触发条件。 也包括执行者用同一模板循环批量写出只有“内容开发中”或标题的页面、用写死的样例数据顶替接口、把接口响应 JSON.stringify 后整段显示，再以文件齐全、页数相等和编译通过判定完成；子任务回执只写“已补齐”“均保留”，不列对照过的源文件。
- [执行已批准计划的批次与全量收口时，把替换清单逐行转成本批检查项；横切项与当前批次同等对待，公共门面先建立再搬页面](lesson-af15c43279110b3b7692.lesson.md)
  - 时机：迁移执行与全量收口阶段，按已批准计划迁移页面、下沉公共工具或执行替换清单时；规划阶段为公共能力安排批次时
  - 情境：计划或审计已要求用统一门面（如 ToastService）替换散落的直调，并在业务完成时把直调数量归零；当前批次正在移动页面、导出公共工具或做 LazyForEach → Repeat 等静态收口，门面本身还不存在。
- [用共享组件替换页面已实现片段前（关闭孤儿组件检查或按计划收口），完整读取被替换片段并逐项比对源码视觉；组件不符先修组件，不覆写参数保留旧外观](lesson-ad6f23b88f09b55dd92a.lesson.md)
  - 时机：结构收口或接线阶段，为消除未被引用的公共组件（orphan component）发现，或按计划、切片要求用共享组件替换页面中已实现的片段时
  - 情境：结构检查报告若干公共组件没有被任何页面引用，或计划要求页面改用某个共享组件（如统一弹窗组件）；修复者或收口者准备把页面里自写的标题行、图片、弹窗操作区等片段换成共享组件调用；共享组件与页面片段由不同 agent 生成，样式和变体完整度可能不一致，替换者可能只读了页面的部分行段。
- [运行会改写源码的自愈脚本后先审阅其改动；异常尺寸、与已有显式尺寸重复或按错误密度换算的追加要回滚](lesson-bdb97da6a6eb8d68435f.lesson.md)
  - 时机：结构收口阶段运行含图标尺寸自愈等会改写 .ets 的检测管线、决定是否接受其结果时；构建或验证阶段读到同一组件出现两组尺寸修饰时
  - 情境：迁移管线在收口时自动运行图标尺寸自愈（icon-sizing 一类），会直接给 .ets 中的 Image 追加 .width/.height；页面 Image 已在同一行链式写好尺寸（如 '18vp'、'100%'），资源可能是 jpg 启动图标。也包括图标尺寸自愈按“媒体像素 ÷ 源密度”换算由 vector drawable 转来的 SVG，源 drawable 在无密度限定目录时回退到默认密度（如 3x），把图片写成约三分之一大小。
