# process/gates

结构检查与自动修复的收口：会改写源码的自愈脚本运行后审阅改动（含图标尺寸自愈的密度换算），按关键字判定的检查要真实落实而不是迎合检查器，用共享组件替换页面已实现片段（关闭孤儿组件检查或按计划收口）前的完整读取与视觉核对，功能对齐与验收结论以代码中的实际落点为准，执行已批准计划时替换清单的逐行收口，交互问题的复现与分层定位，未验证与被点名风险项的“未验证”标注，写文件以真实执行回执为准与模板入口页的内容断言，定性为服务端问题前的源端调用条件核对与真机对照；孤儿检测报出已登记页面时保留并上报而不删除

## 本级经验

- [交付或收尾时，未完成设备验证、被 BLOCKED、数据未加载不可见或被点名为风险的验收项标为未验证，回流为必测项](lesson-421a758d591aed4a1389.lesson.md)
  - 时机：验证与收尾阶段，汇总功能点结果、写交付说明或已实现清单，而部分项没有完成设备验证或无法观察时
  - 情境：编译被阻断、UI 测试超时或没有做真机验证；或某些功能点因宿主不可达被 BLOCKED、页面因数据未加载看不到内容；或执行者、收尾者已把只能靠界面判定的验收项点名为风险；或批量重构后只有编译通过与旧符号 grep 归零。
- [修复安全区等按关键字判定的结构检查 FAIL 时逐页落实避让，不用含检查关键字的注释让检查通过](lesson-f6b95d7d6d0159cb0436.lesson.md)
  - 时机：结构修复阶段处理安全区 Layer 3 等按关键字或 grep 判定的检查失败时
  - 情境：结构检查按关键字或 grep 判断页面是否处理了安全区等要求；工程已用 setWindowLayoutFullScreen 开启全屏、根 Navigation 设了 expandSafeArea，NavDestination 页需自行在前景避让；修复者面对多页 FAIL，工程有共享窗口模型（顶部/底部避让值），skill 要求全屏 NavDestination 页实际加 padding。
  - 例外：页面已由上层（父容器、NavDestination 根或共享组件）正确避让时，不再叠加 padding；在修复记录里写明避让落在哪个文件和组件，把这个 FAIL 作为检查器误报上报，而不是用注释或标记迎合检查
- [修复点击或滑动无响应前先在设备复现并分层定位，确认触摸可达再改约束；修复前已存在的字符串不作 RED/GREEN 依据](lesson-afae8d13e00941efe808.lesson.md)
  - 时机：缺陷修复阶段，修复“点击没有反应”“滑不动”一类交互问题、决定改哪一层并选择回归验证方式时
  - 情境：页面菜单项、按钮已绑定 onClick 却点击无效；或弹层、卡片内一片控件全部不响应点击或滑动，候选原因同时有祖先节点的命中测试设置（hitTestBehavior）与滚动容器的尺寸约束；设备可连接，但 UI 测试可能在启动 Ability 阶段超时，修复者考虑用 grep 结构契约代替设备断言。
- [写文件以真实执行回执为准：只有文本形式的工具调用即未写入；覆盖模板入口页后按内容断言读回](lesson-776ed5eb216833c6b002.lesson.md)
  - 时机：执行阶段写入或覆盖文件并据此记录进度、宣告页面或阶段完成时；验证阶段报告入口页已迁移时
  - 情境：写文件依赖 shell heredoc 等工具调用，运行环境可能把未解析的调用当作普通文本输出后结束回合；目标工程由模板创建，入口 Ability 的 loadContent 指向仍为 Hello World 的模板页；阶段完成标记只检查报告文件是否存在。
- [处理孤儿检测报出的无调用方页面或弹窗时，已登记为范围内的产物不删除：保留规格允许的纯 UI 与宿主回调并上报缺失的触发点；确需退役先取得范围决策并同步全部登记](lesson-8390913de64b0adc00fc.lesson.md)
  - 时机：结构收口阶段，处理孤儿或无引用检测报出的 pages、dialogs 组件，决定补接线、保留上报还是删除文件时
  - 情境：检测器报告某页面或弹窗没有导入方（NO_IMPORTER）；该组件在页面规格中有指定的 ArkTS 产出，在页面清单（ui-manifest）、功能索引中登记为已转换或 verified；源码里找不到真实调用方，或调用链属于决策排除的会员、支付、权益一类行为，决策只排除了这些行为，没有移除页面。
- [执行已批准计划的批次与全量收口时，把替换清单逐行转成本批检查项；横切项与当前批次同等对待，公共门面先建立再搬页面](lesson-af15c43279110b3b7692.lesson.md)
  - 时机：迁移执行与全量收口阶段，按已批准计划迁移页面、下沉公共工具或执行替换清单时；规划阶段为公共能力安排批次时
  - 情境：计划或审计已要求用统一门面（如 ToastService）替换散落的直调，并在业务完成时把直调数量归零；当前批次正在移动页面、导出公共工具或做 LazyForEach → Repeat 等静态收口，门面本身还不存在。
- [把接口 404 或静默返回定性为服务端问题前，核源端在当前账号条件下是否调用该接口，并用源端真机同账号对照](lesson-341f7c963b16ad78081e.lesson.md)
  - 时机：缺陷诊断阶段，目标点击无响应、接口返回 404 或静默返回，准备定性为“服务端问题、两端同样失败、保真勿修”时
  - 情境：目标调用了某接口，在测试服务器上收到 404 页面或无响应；诊断者已比对源端收到异常响应后的处理分支，但源端调用点带地区、用户类型、新用户等门控条件。
- [报告功能已实现或已对齐前，按规格验收项与导航出口在代码里找到实际组件与调用：空回调、只含注释的回调与模板空壳页不算实现](lesson-9147be4d87153de9c5b6.lesson.md)
  - 时机：验证阶段核对功能完成度，或实现、返修后向用户报告“已实现/已对齐”时；执行阶段宣告页面转换或流水线阶段完成时
  - 情境：验证检查只 grep TODO: 与占位登记表；实现或修复后按功能点列对齐表并逐项打 ✅；规格写有验收条目、页面导航出口、事件订阅锚点与启动触发条件。也包括执行者用同一模板批量写出只有标题或“内容开发中”的页面、用写死的样例数据顶替接口、把接口响应 JSON.stringify 后整段显示，再以文件齐全、页数相等和编译通过判定完成。
  - 例外：源端同处本身就是空点击、写死数据或把响应整段显示成文本，且当前验收以源端行为为准：按源保留，不判为未完成
- [用共享组件替换页面已实现片段前（关闭孤儿组件检查或按计划收口），完整读取被替换片段并逐项比对源码视觉；组件不符先修组件，不覆写参数保留旧外观](lesson-ad6f23b88f09b55dd92a.lesson.md)
  - 时机：结构收口或接线阶段，为消除未被引用的公共组件（orphan component）发现，或按计划、切片要求用共享组件替换页面中已实现的片段时
  - 情境：结构检查报告若干公共组件没有被任何页面引用，或计划要求页面改用某个共享组件（如统一弹窗组件）；修复者或收口者准备把页面里自写的标题行、图片、弹窗操作区等片段换成共享组件调用；共享组件与页面片段由不同 agent 生成，样式和变体完整度可能不一致，替换者可能只读了页面的部分行段。
  - 例外：共享件尚未就绪、页面先写页内等价实现：按待收敛项登记处理；本条用于执行替换时
- [运行会改写源码的自愈脚本后先审阅其改动；异常尺寸、与已有显式尺寸重复或按错误密度换算的追加要回滚](lesson-bdb97da6a6eb8d68435f.lesson.md)
  - 时机：结构收口阶段运行含图标尺寸自愈等会改写 .ets 的检测管线、决定是否接受其结果时；构建或验证阶段读到同一组件出现两组尺寸修饰时
  - 情境：迁移管线在收口时自动运行图标尺寸自愈（icon-sizing 一类），会直接给 .ets 中的 Image 追加 .width/.height；页面 Image 已在同一行链式写好尺寸，资源可能是 jpg 启动图标。也包括自愈脚本按“媒体像素 ÷ 源密度”换算由 vector drawable 转来的 SVG，或源 drawable 位于无密度限定的 drawable/ 目录时脚本自行假定一个高密度回退，把图片写小。
