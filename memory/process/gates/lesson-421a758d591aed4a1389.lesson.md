# 交付或收尾时，未完成设备验证、被 BLOCKED、数据未加载不可见或被点名为风险的验收项标为未验证，回流为必测项

ID：`lesson-421a758d591aed4a1389` · 版本：2

[本主题](index.md)

## 何时使用

验证与收尾阶段，汇总功能点结果、写交付说明或已实现清单，而部分项没有完成设备验证或无法观察时

## 适用情境

编译被阻断、UI 测试超时或没有做真机验证；或某些功能点因宿主不可达被 BLOCKED、页面因数据未加载看不到内容；或执行者、收尾者已把只能靠界面判定的验收项点名为风险；或批量重构后只有编译通过与旧符号 grep 归零。

## 原因

BLOCKED 与看不到的页面在汇总中消失，或凭结构派生写进已实现清单，缺陷就留到用户手里；静态检查只能确认代码存在，不能代替界面上的状态变化。

## 做法

1. 编译被阻断、没有完成设备验证、功能点因宿主不可达被 BLOCKED 或页面因数据未加载不可见时，在交付说明中逐项标为未验证，并回流为验证阶段必测项；静态检查（如确认偏好键有读写调用方）只作补充，不替代设备断言，也不写成已修复或通过。
2. 被点名为风险、只能界面判定的验收项不凭结构派生写进已实现清单；列入验证阶段必测往返，或在收尾前做一次真机或模拟器往返核对。
3. 批量重构的验收把受影响的页面纳入真机冒烟；编译通过与旧符号 grep 归零不算验证。
