# 为颜色差异立单时，用像素均值和源端算式给出期望值，再建议混合方式

ID：`lesson-aae5f345ed2ced099757` · 版本：1

[本主题](index.md)

## 何时使用

视觉判读阶段，为字形、线条的颜色差异立单并写期望值和修法建议时

## 适用情境

有源端基线 PNG 与目标截图（可能是有损压缩），差异来自着色或混合造成的色相、亮度偏差；判读者手头有图像处理工具。

## 原因

只凭目测写“渐变清晰、饱和”这类期望，修复者会按字面选择混合方式，漏掉源算式里的加数项；改用像素测量并写出算式后，问题才能定量。判读者之间容差口径不一致时，同一组件会一页判已修、一页判仍开。

## 做法

1. 在同一张图里取已知一致的像素（如描边环）对照以排除压缩噪声，给出字形中心区域的均值与容差。
2. 用源端算式核算目标色后再建议混合方式；同一组件在多页判读时使用同一种测量方法。
