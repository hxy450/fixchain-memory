# 修复阶段替换共享渲染公式时，分开已核部分与假设，并以当前已正确的场景作回归基线

ID：`lesson-cf92f65492e41a03ed8a` · 版本：1

[本主题](index.md)

## 何时使用

视觉修复阶段，改写主题层或共享组件的度量、混合等渲染公式，且当轮不能重编实测时

## 适用情境

待改属性同时服务多个场景（如单行文本与多行段落），其中一部分当前表现已经正确；新公式里有 SDK 未说明、当前测量也没有样本的合成规则。

## 原因

修复者只盯着出问题的场景推导公式，把没有依据的合成规则写成既定事实，原本正确的场景被一起改坏；这类偏差在修复中新生，下一轮若只按阈值关页就发现不了。

## 做法

1. 在代码注释和修复记录里把“已核”（有 dump、字体度量等支撑）与“假设”分开，假设部分给出下一轮必测的具体数值。
2. 替换一条已有正确表现的渲染路径前，先在同轮测量里找出它当前正确的样本记为回归基线；改完同时核出问题的场景和基线场景。
3. 不能当场实测时，优先选不改变已正确行为的方案（只改出问题的场景，或运行期测量后再计算），不要让一个公式同时依赖两个未知量。
