# 按源端截图复刻框架控件尺寸时，先分清实测值是内容宽还是框架 min/max 约束：约束写 constraintSize，并按最长译文核对

ID：`lesson-42364ad323112c3342ae` · 版本：3

[本主题](index.md)

## 何时使用

界面实现或返修阶段，按安卓实测几何复刻框架控件（弹出菜单、对话框、按钮）的宽高时

## 适用情境

实测宽度大于“文字宽 + 内边距”，源控件来自框架（例：AppCompat 1.8.0 弹出菜单项的最小宽来自 abc_popup_menu_item_layout.xml 的 minWidth 196dip，上限由 StandardMenuPopup 取 max(屏宽/2, abc_config_prefDialogWidth)，该版本默认 values 为 320dp、values-large 为 440dp、values-sw600dp 为 580dp；主题或版本不同要重查）；控件文字是有多种译文的字符串资源，而对比截图只取了英文。

## 原因

把最小宽写成固定 width，较长译文就会折行；英文截图对上不能证明约束正确。

## 做法

1. 实测宽大于“文字宽 + 内边距”时，查控件 style 与布局的 minWidth/maxWidth，确认实测宽来自框架最小宽约束后，写 constraintSize({ minWidth, maxWidth }) 并按框架规则补上限，单行与省略按源端；注释写的是 minWidth/maxWidth 时，代码里同一元素不应出现 width(N)。值从当前依赖的 AAR 资源或本机 SDK 读取；其他菜单实现（Compose DropdownMenu、Material 菜单）另查其自身约束。
2. 复刻前列出该字符串在全部 values-*/strings.xml 的译文，用最长译文（按字体测量宽度，不按字符数）做两端对比截图。
