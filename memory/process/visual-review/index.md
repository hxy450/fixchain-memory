# process/visual-review

视觉判读与修复轮次：按相似度阈值关页时仍需立单的残差（上轮预测不符、同根、几何铺不满），颜色差异的定量期望值，替换共享渲染公式时已核与假设的分离及回归基线

## 本级经验

- [为颜色差异立单时，用像素均值和源端算式给出期望值，再建议混合方式](lesson-aae5f345ed2ced099757.lesson.md)
  - 时机：视觉判读阶段，为字形、线条的颜色差异立单并写期望值和修法建议时
  - 情境：有源端基线 PNG 与目标截图（可能是有损压缩），差异来自着色或混合造成的色相、亮度偏差；判读者手头有图像处理工具。
- [修复阶段替换共享渲染公式时，分开已核部分与假设，并以当前已正确的场景作回归基线](lesson-cf92f65492e41a03ed8a.lesson.md)
  - 时机：视觉修复阶段，改写主题层或共享组件的度量、混合等渲染公式，且当轮不能重编实测时
  - 情境：待改属性同时服务多个场景（如单行文本与多行段落），其中一部分当前表现已经正确；新公式里有 SDK 未说明、当前测量也没有样本的合成规则。
- [按源端截图复刻控件尺寸时，先判断实测值是内容测量结果还是框架 min/max 约束：落在最小值上就写 constraintSize（并补框架上限），不写 width(实测值)；含多语言文案的控件用最长译文核对](lesson-42364ad323112c3342ae.lesson.md)
  - 时机：界面实现或返修阶段，按安卓实测几何复刻框架控件（弹出菜单、对话框、按钮）的宽高时
  - 情境：实测宽度大于“文字宽 + 内边距”，源控件来自框架（如 AppCompat 弹出菜单项 minWidth 196dp、上限 max(屏宽/2, 320dp)）；控件文字是有多种译文的字符串资源，而对比截图只取了英文。
- [按相似度阈值关页时，与上轮修复预测不符、与已修单同根或几何铺不满的残差仍要立单](lesson-494c9b596df7e7e788f9.lesson.md)
  - 时机：视觉判读阶段，按页面相似度阈值决定是否关页、哪些残差立单时
  - 情境：测量已发现与上一轮修复预测不符的数值、判为与已修单同根的残差，或布局总宽没有铺满容器，但页面分数仍高于阈值。
  - 例外：项目明确接受阈值以下的残差，且不再进入更严口径的下一轮
