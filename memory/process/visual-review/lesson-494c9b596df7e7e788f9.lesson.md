# 按相似度阈值关页时，与上轮修复预测不符、与已修单同根或几何铺不满的残差仍要立单

ID：`lesson-494c9b596df7e7e788f9` · 版本：1

[本主题](index.md)

## 何时使用

视觉判读阶段，按页面相似度阈值决定是否关页、哪些残差立单时

## 适用情境

测量已发现与上一轮修复预测不符的数值、判为与已修单同根的残差，或布局总宽没有铺满容器，但页面分数仍高于阈值。

## 例外与边界

- 项目明确接受阈值以下的残差，且不再进入更严口径的下一轮

## 原因

阈值规则让这些残差随页面一起关闭，上一轮修复写下的可量化预测无人核销；修复引入的回归、同根未修的兄弟页、整体几何偏移，都拖到口径收紧的后几轮才立单。

## 做法

1. 把上一轮修复记录里的可量化预测列为本轮必核项；测出不符且能指到具体公式时，即使分数达标也单独立单，或标为修复引入的回归。
2. 判为“与已修单同根”的残差并入该单，同轮修复。
3. 布局几何差异看 dump 里的 px 总宽是否铺满容器，不只看相似度分数。
