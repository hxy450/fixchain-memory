# 增量迁移新注册条目时，用同构建器、同分组的已迁移兄弟 key 在目标工程全量检索，列出它所在的全部白名单与映射表

ID：`lesson-081caee9c02b394bef92` · 版本：3

[本主题](index.md)

## 何时使用

增量迁移阶段，为源端新增的注册条目（如按 key 配置的指标）列目标端改动清单、确定要登记的全部位置时

## 适用情境

源端条目经公共构建器统一附加说明链接、图标或回调等能力；目标端把这些能力拆成分散在多个文件、按 key 登记的白名单或映射表；计划按功能点逐个找登记点。

## 原因

按功能点逐个找登记点只能找到想到的那几张表，构建器隐式附加的能力在目标端对应的白名单会被漏掉，新条目缺少说明入口或图标，编译与运行都不报错。

## 做法

1. 选一个与新条目同构建器、同分组的已迁移兄弟 key，在目标工程全量检索，列出每个包含它的白名单或映射表，与改动清单逐项对照，确认新 key 已加入，或记录不加入的源端依据。
2. 核对图例或标题行时，比照源端同类条目的完整呈现（名称、后缀图标、点击跳转），不只核对数值和颜色。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
