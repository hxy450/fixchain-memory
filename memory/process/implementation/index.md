# process/implementation

把已读到的源端语义落成目标代码时的通用取舍：不补写源端没有的元素、输入规范化或交互步骤，看似缺陷或不够健壮的源端行为照搬（修正须登记决策），含布尔组合的条件表达式逐字翻译；内联被调组件时调用点实参与被调公式的整链转写，非空类型上的空判断（死分支）不译成可达触发

## 本级经验

- [不补写源端没有的元素、输入规范化或交互步骤](lesson-352b96f599237cd27403.lesson.md)
  - 时机：规格提取或界面、接线实现阶段，准备按“常见样式”“更稳妥”或项目惯例补写源端未声明的装饰、输入处理或流程步骤时
  - 情境：源 XML、回调或主题中不存在某元素或步骤（列表行无尾部箭头、校验与传递使用未 trim 的原文、选项弹层点击只重绘不关闭、批量动作无确认、搜索框无容器底色），写者凭通用样式或兄弟页加入。也包括源端计算入口只有 if (a != null &amp;&amp; b != null) 分支、没有 else，目标在输入无效时新增清空结果的分支。
  - 例外：当前任务有已批准的差异决策要求新增
- [内联或重建被宿主调用的组件时按“调用点实参 → 被调公式”整链转写：调用点上的乘数、换算与派生包装一并保留](lesson-4428ce765fcef294b004.lesson.md)
  - 时机：页面转换或公共组件实现阶段，把源端被宿主调用的共享组件（Composable、自定义 View、工具函数）转写为页面内联方法或目标公共组件，确定各显示值的实参与公式时
  - 情境：源端宿主以表达式作实参调用共享组件（如 TimeText(progress = animatedProgress.value * timeMultiplier)，或 remember { derivedStateOf { a.value * b } } 的结果），被调组件内部只对形参运算（如 time × progress）；目标准备在页面内联等价实现，或另建公共组件供多页调用；派工可能只把被调组件文件列为样式真源。
- [源端看似缺陷或不够健壮的可观察行为照原样迁移：失败返回、无条件回投、循环退出条件、副作用时序与异常作用域都按源码；确需修正时登记决策](lesson-14411595fd9ac1e17683.lesson.md)
  - 时机：规格提取与切片实现阶段，转写源码中看似缺陷、缺少防护或时序可疑的逻辑（未赋值导致的失败返回、无条件的结果回投、只在成功时退出的循环、在校验前置位的标志、整段一个 try 的循环），或 lint、评审建议补取消、竞态、防御条目时
  - 情境：迁移目标是行为等价，迁移原则（如默认策略文件）要求保留原有行为“包括缺陷、空点击和异常分支”，但续跑或补建的台账、派工里可能没有这条规则；写者认为源码“有缺陷”“不够确定”“不够健壮”，在源码笔记里写“源缺陷不移植/行为增强/防御/确定性取舍”，或规格为回应 lint 写入“页面销毁时丢弃迟到结果”“取消标志为唯一出口”一类源码没有的要求。
  - 例外：决策记录明确批准修正某项原版缺陷；源端崩溃路径按已登记的例外处理
- [翻译含布尔组合的条件表达式时保留括号并列真值表](lesson-381ebc5899e92cbd23a2.lesson.md)
  - 时机：实现阶段，翻译含异或、与或组合的三元或条件表达式（如气泡箭头位置、方向相关分支）时
  - 情境：源表达式形如 a + ((x ^ y) ? 0 : b)，转述时容易丢掉内层括号或取反分支。
- [翻译源端条件里的 == null / != null 前先核变量的声明类型与来源：非空类型上的空判断是恒定死分支，按“从不触发”迁移，不译成“未初始化/首启”触发或三态偏好](lesson-8c18bb22a8ecfe8c7f8a.lesson.md)
  - 时机：规格提取阶段把源端显示条件、弹窗或权限请求的触发条件写成页面契约与偏好默认值时；实现阶段按规格新增依赖该条件的弹窗、权限请求或协调服务时
  - 情境：Compose 页面用 collectAsState(initial = false) 收集 Flow&lt;Boolean&gt;（DataStore getter 映射为 preferences\[KEY\] == true 或带 ?: 默认值），显示条件里却把该状态与 null 比较；规格可能同时写着“该偏好 Boolean、默认 false”与“== null 表示从未写入/首次进入”。
