# process/implementation

把已读到的源端语义落成目标代码时的通用取舍：不补写源端没有的元素、输入规范化或交互步骤，看似缺陷或不够健壮的源端行为照搬（异常作用域与写回按运行时语义，修正须登记决策），含布尔组合的条件表达式逐字翻译；内联被调组件时调用点实参与被调公式的整链转写，非空类型上的空判断（死分支）不译成可达触发；用复位函数模拟源端每局重开时按字段生命周期取舍；菜单/ActionMode 回调入口统一门控落到分发入口

## 本级经验

- [不补写源端没有的元素、输入规范化或交互步骤：有没有某元素按源端最终渲染判断，框架与主题默认生成的元素（如 ListPreference 对话框的 CANCEL）算源端已有、必须保留；例外只认台账中带编号的已批准差异决策，派工措辞与转换表不算批准](lesson-352b96f599237cd27403.lesson.md)
  - 时机：规格提取或界面、接线实现阶段，准备按“常见样式”“更稳妥”或项目惯例补写源端未声明的装饰、输入处理或流程步骤时；规格、派工与转换表对某行元素或控件类型说法不一致时
  - 情境：源 XML、回调或主题中不存在某元素或步骤（列表行无尾部箭头、校验与传递使用未 trim 的原文、选项弹层点击只重绘不关闭、批量动作无确认、搜索框无容器底色），写者凭通用样式或兄弟页加入。也包括源端计算入口只有 if (a != null &amp;&amp; b != null) 分支、没有 else，目标在输入无效时新增清空结果的分支。也包括派工补充说明或转换表写了源端没有的元素或改了控件类型（如设置行尾部箭头、把复选框改成开关），实现者以“派工指定的例外”“最新指令”为由保留，甚至回写规格去迎合派工。也包括源控件的部分可见元素由框架默认生成、源码与 XML 里看不到（如 ListPreference 对话框的 android.R.string.cancel 负按钮），提醒却写成“弹层无确定/取消钮”。
  - 例外：决策台账或规格中有带编号的已批准差异决策（如 PD-*）要求新增；派工消息、转换表或兄弟页里出现的说法不算批准
- [内联或重建被宿主调用的组件时按“调用点实参 → 被调公式”整链转写：调用点上的乘数、换算与派生包装一并保留](lesson-4428ce765fcef294b004.lesson.md)
  - 时机：页面转换或公共组件实现阶段，把源端被宿主调用的共享组件（Composable、自定义 View、工具函数）转写为页面内联方法或目标公共组件，确定各显示值的实参与公式时
  - 情境：源端宿主以表达式作实参调用共享组件（如 TimeText(progress = animatedProgress.value * timeMultiplier)，或 remember { derivedStateOf { a.value * b } } 的结果），被调组件内部只对形参运算（如 time × progress）；目标准备在页面内联等价实现，或另建公共组件供多页调用；派工可能只把被调组件文件列为样式真源。
- [源端在菜单或 ActionMode 回调入口统一门控（验密、登录、权限）再分发动作时，目标在分发入口统一门控，例外动作照抄源列表](lesson-4d8932173d880e64635a.lesson.md)
  - 时机：页面实现与收口接线阶段，把源端 onActionItemClicked、onOptionsItemSelected 一类回调翻成目标动作分发表并为动作接门控时；页面转换阶段为分发表写占位注释时
  - 情境：源回调先对全部动作执行一次门控（如受保护内容先验密、未登录先拉登录），只把少数动作列为例外，再按菜单 id 分发；目标把分发写成按动作的 switch 或多个处理函数，门控实现由其他切片提供，页面占位注释或规格验收条目可能只点名其中几个动作。
- [源端看似缺陷或不够健壮的可观察行为照原样迁移并按次数核对：失败返回、异常作用域与副作用时序按源码，修正须作待批决策](lesson-14411595fd9ac1e17683.lesson.md)
  - 时机：规格提取与切片实现阶段，转写源码中看似缺陷、缺少防护或时序可疑的逻辑（未赋值导致的失败返回、无条件的结果回投、只在成功时退出的循环、在校验前置位的标志、整段一个 try 的循环、只捕获部分异常类型的 catch、以快照覆盖写回），或 lint、评审建议补取消、竞态、防御条目时
  - 情境：迁移目标是行为等价，迁移原则（如默认策略文件）要求保留原有行为“包括缺陷、空点击和异常分支”，但续跑或补建的台账、派工里可能没有这条规则；写者认为源码“有缺陷”“不够确定”“不够健壮”，在源码笔记里写“源缺陷不移植/行为增强/防御/确定性取舍”，或规格为回应 lint 写入“页面销毁时丢弃迟到结果”“取消标志为唯一出口”一类源码没有的要求。 也包括源端每轮初始化或重开都 new 一个循环线程或定时器对象，停止只经保存最新实例的字段，重开不关闭已有对话框，规格准备以“每局新实例不释放＝不可观察的资源累积”收敛成单实例。也包括目标端的 try/catch、可空类型、系统托管提醒或缺少后台提示通道，诱使规格或实现写成“返回空对象继续”“return false 后继续发完成通知”“DB 现值优先、已删跳过”“只记日志”。
  - 例外：决策记录明确批准修正某项原版缺陷；源端崩溃路径按已登记的例外处理
- [用一个复位函数模拟源端每局重开时，按字段声明位置与生命周期决定复位：只复位重开路径实际赋值或新建对象初始化的字段](lesson-e2a08b9a98504718cd24.lesson.md)
  - 时机：规格提取与引擎实现阶段，把源端每局重开（重开函数里 new 循环或状态对象）映射为模块级静态引擎或单例的复位函数，确定新局复位哪些字段、写复位验收时
  - 情境：源端状态分属不同生命周期：类静态字段只在类加载时初始化一次，宿主 View/Activity 的实例字段随宿主构造初始化，每局新建对象的字段随 new 重置；目标把这些字段合并进同一个模块级静态引擎或单例，用一个 initGame/reset 函数模拟每局重开。
  - 例外：源端重开本来就重建宿主（重新创建 Activity 或 View）时，宿主实例字段也随之重置，按实际重建范围复位
- [目标仓储把源端落盘方法内的守卫（如 saveStateToFile 首行 if (saveState)）移到调用侧时，逐条写进调用侧条件，并按各退出路径在执行时刻的标志值核对](lesson-06e3564e91948a2b05a3.lesson.md)
  - 时机：切片实现阶段，把源端 save()/落盘链迁到目标服务与页面、决定写入的抑制条件时
  - 情境：源端落盘方法体首行自带标志守卫，目标仓储改为纯服务、契约写明该抑制判定在调用侧；退出分支在置抑制标志前调用了会重置其他标志的初始化（如 initialize() 把 createNewGame 置回 false），使另一标志看似可以替代该守卫。
- [翻译含布尔组合的条件表达式时保留括号并列真值表](lesson-381ebc5899e92cbd23a2.lesson.md)
  - 时机：实现阶段，翻译含异或、与或组合的三元或条件表达式（如气泡箭头位置、方向相关分支）时
  - 情境：源表达式形如 a + ((x ^ y) ? 0 : b)，转述时容易丢掉内层括号或取反分支。
- [翻译源端条件里的 == null / != null 前先核变量的声明类型与来源：非空类型上的空判断是恒定死分支，按“从不触发”迁移，不译成“未初始化/首启”触发或三态偏好](lesson-8c18bb22a8ecfe8c7f8a.lesson.md)
  - 时机：规格提取阶段把源端显示条件、弹窗或权限请求的触发条件写成页面契约与偏好默认值时；实现阶段按规格新增依赖该条件的弹窗、权限请求或协调服务时
  - 情境：Compose 页面用 collectAsState(initial = false) 收集 Flow&lt;Boolean&gt;（DataStore getter 映射为 preferences\[KEY\] == true 或带 ?: 默认值），显示条件里却把该状态与 null 比较；规格可能同时写着“该偏好 Boolean、默认 false”与“== null 表示从未写入/首次进入”。
