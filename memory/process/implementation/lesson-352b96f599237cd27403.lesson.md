# 不补写源端没有的元素、输入规范化或交互步骤

ID：`lesson-352b96f599237cd27403` · 版本：1

[本主题](index.md)

## 何时使用

规格提取或界面、接线实现阶段，准备按“常见样式”“更稳妥”或项目惯例补写源端未声明的装饰、输入处理或流程步骤时

## 适用情境

源 XML、回调或主题中不存在某元素或步骤（列表行无尾部箭头、校验与传递使用未 trim 的原文、选项弹层点击只重绘不关闭、批量动作无确认、搜索框无容器底色），写者凭通用样式或兄弟页加入。

## 例外与边界

- 当前任务有已批准的差异决策要求新增

## 原因

新增的元素或步骤会改变可见结果或行为边界：多余箭头误导、trim 改变可接受输入、选中即关闭让同一面板内的后续操作不可达、额外确认改变批量流程。

## 做法

1. 规格只按源 XML 与源码描述组成和流程；以“Material 风格”“保持一致”为由新增的元素须有源依据。
2. 源端校验并传递原文时，目标也校验并传递原文，不额外 trim 或大小写归一。
3. 选项型弹层的选中回调按源端点击处理决定是否关闭：源只重绘并回调时，宿主回调不置 visible=false。
4. 复用兄弟页的确认弹窗、关闭语句或底色前，对照本页源码是否存在。

来源支持：5 张卡 · 1 次迁移 · 1 个应用
