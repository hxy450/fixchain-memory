# 写业务页面或按“对比源端”还原前，读到该页源 Screen、ViewModel 与 Service 并列出行为清单；源码查找落空先定位源工程路径

ID：`lesson-1997518f92b444368073` · 版本：1

[本主题](index.md)

## 何时使用

迁移执行或增量还原阶段，替换占位页、实现“查看全部”等子页，或按功能锚点还原页面前

## 适用情境

页面由源 ViewModel 与网络服务驱动；目标端已有占位页、详情预览或已聚合的数据模型，数据层检索（DAO、Repository、Entity）看不到列表分组、模式切换与按钮可用条件；源工程在目标工程同级的独立目录，查找命令可能返回 no matches。

## 原因

界面结构、分页方式与按钮条件只写在源 Screen/ViewModel 里；按功能名、数据层或目标端已有预览推测，会写出扁平列表、缺分页与编辑态或臆造接口的页面，甚至用模板循环批量生成。来源中购物车实现者未读源界面就写成扁平规格列表；评价页实现者源码查找落空后照详情预览拼装，缺分页与五星；执行代理未打开规格与源 Service，把地址页写成接口回显并调用不存在的保存接口；首轮生成者用同一模板批量生成业务页。

## 做法

1. 写页面前打开该页源 Screen 与 ViewModel/Service，列出顶栏动作、列表项分组、分页与刷新方式、各模式下的控件与按钮可用条件、接口路径与方法和实体字段，再映射到目标数据模型；接口名只取自源 Service 注解或已有服务。
2. 源码查找返回 no matches 或空结果时，先列出目标工程同级目录或查项目配置中的源工程路径再重试；没取到源码不进入写入，也不用目标端预览代替。
3. 每个业务页面单独按源转换，不用同一模板循环批量生成；数据驱动页按源接入真实数据并保留加载、空、错误状态，不用固定文本或假数据顶替。
