# process/input-loading

写前输入是否真的进入上下文：必读 skill、规格、参考与源码片段的读取方式（含 Windows PowerShell 5.1 读取 UTF-8 中文的编码），长会话上下文压缩后的重读，派工要求的源码核对，辅助谓词与 getter 的定义，以及编排者亲自实现切片时要加载的输入，写业务页面与对比源端还原前对源 Screen/ViewModel/Service 的读取，依据他文件返回语义改写调用方前的重读（文件已变更提示、并发会话），推断参考端默认值与过滤结果所需的决定性函数

## 本级经验

- [Windows PowerShell 5.1 读取 UTF-8 中文规格、账本与源码要显式 -Encoding UTF8；回执出现乱码就当作没读](lesson-6a3a7f46c8fec282affa.lesson.md)
  - 时机：规格提取、切片实现与接线阶段，在 Windows PowerShell 5.1 下用 Get-Content 读取功能规格、决策账本或中文注释源码时；诊断与修复阶段据读取回执判断代码结构时
  - 情境：迁移工程的规格、决策账本、计划与源码为 UTF-8（无 BOM）且含中文；读取者在 Windows PowerShell 5.1 中用 Get-Content 不带编码参数读取，回执里中文段落成片乱码，AC 编号、方法名、路径等 ASCII 片段仍然可读；系统 ANSI 为双字节代码页（如 cp936）时，含中文注释的代码行可能与下一行连在一起。
- [上下文压缩后续跑迁移流水线：把压缩前的规格与源码视为未读，按切片的 spec_ref、页面规格与源码锚点重读后再写计划和代码](lesson-f616adca9430826b1661.lesson.md)
  - 时机：计划与实现阶段，同一长会话经历上下文压缩后，为切片写 scope/验收/集成点，或写页面、ViewModel、数据层文件前；返修阶段长会话压缩后改写某页前
  - 情境：迁移流水线在一个会话里先产出逐页 UI 规格、功能规格与切片计划，随后发生上下文压缩；压缩摘要只保留功能名、规格路径或一句概括，切片计划、feature-index 或执行 skill 仍以 spec_ref、页面规格路径和源码类名指向这些输入。
  - 例外：压缩后已按原文完整重读了该切片对应的规格与源码片段
- [依据另一文件的返回语义改写调用方前，重读该文件当前版本；编辑回执提示文件已变更或有并发会话时，不沿用旧读取](lesson-35f4f9b3cf566d33e79c.lesson.md)
  - 时机：增量修复与实现阶段，依据另一文件（ViewModel、服务）回传数据的语义改写调用方（分页追加、合并、去重）时；顺带修复用户请求范围外的问题时
  - 情境：调用方与提供方之间的返回语义（当页还是累计、是否已去重）是跨文件约定；同一工程可能有多个会话并发修改，写前读取与实际写入相隔数分钟，或编辑工具回执已提示该文件在上次读取后被改动。
- [写业务页面或按“对比源端”还原前，读到该页源 Screen/Activity、ViewModel 与 Service，列出行为清单再写](lesson-1997518f92b444368073.lesson.md)
  - 时机：迁移执行或增量还原阶段，替换占位页、实现“查看全部”等子页，或按功能锚点还原页面前
  - 情境：页面由源 ViewModel 与网络服务驱动（View 体系为 Activity/Fragment 与其布局）；目标端已有占位页、详情预览或已聚合的数据模型，数据层检索（DAO、Repository、Entity）看不到列表分组、模式切换与按钮可用条件；源工程在目标工程同级的独立目录，查找命令可能返回 no matches。
- [批量读取被截断、命令只回部分输出或只读了前 N 行时：必读 skill、规格、参考文档与源布局/源码补读完整再写码](lesson-42df1ac4d4030421da34.lesson.md)
  - 时机：写码 worker 或规格作者开工时加载 skill、功能规格、预生成参考文档与源码，按源布局 XML 写页面、弹窗前读取源文件时，以及在回报中填写 loaded_skills 时
  - 情境：派工列出多份前置 skill 或多份规格、参考文档，读取者用一次命令批量 cat，或用 sed -n '1,Np' 按固定行数读取；工具对单次输出有长度上限，超出时会省略中段并给出 truncated 提示。也包括一次 exec 批量读取多个源布局、源码或自定义 View，回执中段被省略；串联的查找命令因 yield 超时只返回第一段输出；已加载的 skill 要求先读某份参考（如迁移陷阱表），读取者没有读，或只在 grep 回执里碰到片段。也包括按行号窗口读取源码时，窗口止于目标函数中间；以及只读了源端行号片段就判断该分支属于成功还是失败路径。
  - 例外：上下文压缩后续写：按压缩后重读规格与源码的经验处理，本条管单次读取被截断或只读了一部分
- [推断参考端的默认选中或过滤结果前，读到绑定的默认值回调、过滤函数与回退条件；限制字段追到消费处，不用目标端白名单或注释反推](lesson-e7a9842a56aa53621d27.lesson.md)
  - 时机：功能对齐阶段，为共用基类的某类页面决定是否覆写默认选中项，或判断某个选项会不会被参考端过滤、默认值会不会回退时
  - 情境：参考端多个页面共用同一默认值回调与选项构建函数，部分选项带限制类字段（如按对象类型限制的 type）；目标端基类提供可被子类覆写的默认值钩子，子类另有用途不同的类型白名单或注释。
- [源端行为依赖的辅助方法、谓词、getter 与框架约定，要读到定义再翻译，不按名字或记忆推断](lesson-b3f534eb740a768d95a6.lesson.md)
  - 时机：业务逻辑与界面实现阶段，翻译以辅助谓词分派的切换方法（playPause/toggle）、推导列表行的“正在播放”显示、转写把观察值插进文案模板的显示，或移植兜底链、格式化、名称暗示语义的辅助方法与框架行为时；闭合“等价于源端谓词/聚合器”的占位时；规格提取阶段写这类状态契约时
  - 情境：源码以 isPlayingState() 一类谓词分派 pause/play，或把 text 前缀的 LiveData&lt;String&gt;（格式化结果）拼进文案；读到的源码片段只含调用或相邻 getter，没有定义；同一 ViewModel 另有同名的原始数值字段。也包括写者只看到调用点、grep 命中行或方法名（链接兜底、文件大小格式化、名称暗示全高的展开方法），或依赖框架约定（偏好摘要的占位符代入），目标侧须自写等价函数；以及列表行、卡片的“正在播放”显示（暂停键、高亮）要等价于源端多条件谓词（媒体匹配、播放服务运行且状态为 PLAYING），页面只保存了正播媒体 id。也包括调用点依赖 Kotlin 默认参数的格式化函数（如时长格式化的补零开关），写者已读到定义，仍准备在页面里按记忆另写一份。
  - 例外：调用点把整块 UI、数据来源或交互委托给 helper、DAO、适配器、子组件或基类：按委托链追到最终实现的经验处理；本条管谓词、getter、格式化器与默认参数的语义
- [编排者亲自实现切片（子代理不可用、未按流程派发或与规格子代理并行）时，先加载切片 worker 本应拿到的全部输入，不凭占位登记表或摘要写代码](lesson-b90d7f55409a3a34253d.lesson.md)
  - 时机：执行编排阶段，子代理额度耗尽、限流或失败后，或执行 skill 规定按页派发转换子代理而编排会话决定直接代写时，编排者自己完成 Base/切片实现、页面转换、接线或解决前向引用时；以及编排者一边并行派发规格子代理、一边自己写应用壳、服务与页面时
  - 情境：编排会话原本只负责派工与收口，手上是占位登记表、feature-plan 的指针和子任务回报这类摘要；切片 worker 派工里列出的切片计划文件、功能规格验收条目、页面规格、决策账本正文和源码锚点，编排会话并没有打开过。也包括编排者并行派发功能与页面规格子代理、同时自己写代码，规格已落盘（列目录可见）或仍在生成，编排者只看了目录或完成通知。 也包括 Base 公共组件库：计划与 ui-manifest 共享组件表为每个组件指向安卓 Adapter/item 布局或现有框架组件，编排者没有派发对应任务，也没打开这些布局就直接写组件。
