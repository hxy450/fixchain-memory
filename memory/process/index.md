# process

迁移流程中的阶段交接与写前输入：迁移范围的确定，规格与二手产物的核对，必读材料与源布局是否读全、上下文压缩后的重读，跨任务移交的登记与兑现，结构检查、自愈脚本与功能对齐结论的收口，编译修复与构建结果判定，验证期单元测试的预期来源与失败分诊，视觉判读与修复轮次的立单口径

[上一级](../index.md)

## 子主题

- [build](build/index.md) — 编译修复循环与构建结果判定：只改报错定位处、不以删功能换取通过（确需删除承载行为的调用时同步注释并回报退化）、整文件重写时保留未报错写法，读全错误输出，失败构建不以警告或部分通过放行，最终结论只引用晚于最后改动的构建；缺项目根 hvigorw 时改用本机构建入口，确实不能编译时的模式扫描与如实声明；shell 一行命令替换含 $ 片段的引号与读回
- [gates](gates/index.md) — 结构检查与自动修复的收口：会改写源码的自愈脚本运行后审阅改动（含图标尺寸自愈的密度换算），按关键字判定的检查要真实落实而不是迎合检查器，用共享组件替换页面已实现片段（关闭孤儿组件检查或按计划收口）前的完整读取与视觉核对，功能对齐与验收结论以代码中的实际落点为准，执行已批准计划时替换清单的逐行收口，交互问题的复现与分层定位，未验证与被点名风险项的“未验证”标注，写文件以真实执行回执为准与模板入口页的内容断言
- [input-loading](input-loading/index.md) — 写前输入是否真的进入上下文：必读 skill、规格、参考与源码片段的读取方式（含 Windows PowerShell 5.1 读取 UTF-8 中文的编码），长会话上下文压缩后的重读，派工要求的源码核对，辅助谓词与 getter 的定义，以及编排者亲自实现切片时要加载的输入，写业务页面与对比源端还原前对源 Screen/ViewModel/Service 的读取
- [scope](scope/index.md) — 迁移范围的确定：截图或清单与源码可达页面的取舍，源模块入口能力（如深链）写入契约或登记 skip，范围类必问项的处理，平台替代页的入口位置，未纳入范围的入口如何呈现与汇报
- [spec-handoff](spec-handoff/index.md) — 规格、已生成代码等二手输入与源码之间的交接：规格条目的写法（含增量对齐时点击入口的导航契约、页面入口与对接点只取该页实际绑定）、沿 helper/DAO/适配器委托链追到最终实现、按 feature 切分归属时的跨 feature 契约、上游产物缺值时如何收口、概括出错、照搬前核对与冲突回报（含对齐既有页面骨架），多模块同名布局的解析，合成快照清单的可信度，生成期无法核验结论的置信标注，Application 初始化链注册的接收器与监听写入规格
- [task-handoff](task-handoff/index.md) — 跨任务移交：留给别的文件、切片或编排者兑现的工作如何登记、分派、接收与闭合（含拆分重派时全局动作的承接与阶段放行门），派工的必读清单、阅读顺序与对接清单，各类占位（含“无等价”“资源未就绪”）的使用边界与登记前核查，重新规划时已批准未执行规格的承接，子代理派发失败后的重试与降级条款，规格中“待后续决策轮裁决”条目的出题与关闭
- [testing](testing/index.md) — 验证阶段的单元测试：预期值与夹具从源端实现推出，失败用例分诊时对照源端，测试契约与源端语义冲突时上报而不改产品
- [visual-review](visual-review/index.md) — 视觉判读与修复轮次：按相似度阈值关页时仍需立单的残差（上轮预测不符、同根、几何铺不满），颜色差异的定量期望值，替换共享渲染公式时已核与假设的分离及回归基线
