# 用 shell 一行命令改写含 $ 的 ArkTS 片段（如 $r(...)）时用单引号脚本或字面替换，改后读回每一处

ID：`lesson-6dae0bf2657b0e339742` · 版本：1

[本主题](index.md)

## 何时使用

编译修复或批量改写阶段，用 perl -pi、sed -i 等一行命令替换含 $ 的 ArkTS 表达式时

## 适用情境

修复脚本在双引号包裹的 shell 命令里写 perl/sed 替换串，替换内容含 $r('app.float.xxx') 等以 $ 开头的标记；ArkTS 把字符串传给 Length、ResourceColor 类参数也能编译通过。

## 原因

双引号里的转义先被 shell 消费，perl 再把 $r 当未定义变量插值为空，写出 ('app.float.xxx') 这样的裸字符串；它是合法的 Length，重编译通过，资源却不会被解析，样式静默失效。

## 做法

1. 把 perl/sed 脚本放在单引号内，或改用编辑工具、Python 字面替换；替换后读回每一处被改的行，确认 $r( 仍在。
2. 收尾时对改动文件 grep 未被 $r 包裹的 ('app.float|color|string|media.xxx') 形态；编译通过不能证明资源引用正确。
