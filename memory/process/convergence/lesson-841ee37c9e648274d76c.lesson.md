# 结构收敛不等于行为核验：风险标记的 AC 与 forward-ref 占位不得凭收敛结果清除或写进 impl_claims

ID：`lesson-841ee37c9e648274d76c` · 版本：1

[本主题](index.md)

## 何时使用

收敛/收尾阶段，closer 或主会话把 worker 回执里点名的风险 AC 写进 impl_claims、或解除 forward-ref-uncertain 占位标记时

## 适用情境

worker/closer 已把某 AC 标为风险且只能 ui 判定（如 AC67 被 converter、Slice 5、closer 三次标记），或共享件带 forward-ref-uncertain 占位（P-S6-002 iconTintLayer）；生成期禁编译/无真机。

## 例外与边界

- 已有截图/dump 或等价单测证据

## 原因

closer 凭 HomePage isActiveTab 派生宣称 AC67 已处置并把 impl_claims 抄 plan-coverage，生成期无任何往返验证；P-S6-002 以「共享件已由 G1 定型」为由删 marker——两处风险都在 verify 阶段成为工单。

## 做法

1. 只能 ui 判定且被点名为风险的 AC 不进 impl_claims；列入 verify 阶段必测往返，或在 closer 收尾前做一次真机/模拟器往返核对。
2. forward-ref-uncertain 占位解除须附核验证据（截图/dump 或等价单测），不能因「共享件已由另一切片定型」而删 marker。

## 检查

- impl_claims 中每条 visual/behavior AC 能指到证据文件；attempts/marker 变更记录带证据路径。
