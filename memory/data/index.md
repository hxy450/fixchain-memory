# data

数据层：网络请求与鉴权（含请求体编码、计费网络判定与链接参数拼接）、数据同步调度与事件发布（含运行时作业聚合与落库后广播）、本地数据库的建表与版本迁移、预置数据播种、JSON 与 XML 解析（资源与接口响应层级、拉取解析器回调顺序、org.json 的宽松语法与空值）、手写二进制编解码与协议字节布局（protobuf wire 格式、定长字节常量、切片端点）、模型类型映射与查询层派生状态（含 64 位整数与字段单位）、文件系统操作与导入导出

[上一级](../index.md)

## 子主题

- [codec](codec/index.md) — 手写二进制编解码与协议字节布局：protobuf 字段 wire type 与读写方法的对称、varint 与负数补码的字节拆分，源码定长字节数组常量的逐下标转写，字面下标改命名常量时按用途选端点
- [files](files/index.md) — 文件系统操作与导入导出：fileIo 建目录、移动与复制在目标已存在时的行为与幂等写法；导入导出按源端运行时与库默认语义实现（OOM 兜底、选择数量上限、zip 压缩方式、picker 显示名解码）；源端后台线程里的拷贝与导入改用异步 IO 或 taskpool
- [model](model/index.md) — 模型类型之间的映射：持久化枚举字符串与页面本地类型，大整数 id（源端 Long 或 String 承接）的保精度解析，跨模型数值字段的单位，保存与查询的关联键（如按月份），以及查询层按源端判定函数派生完成态等状态（含名称谓词的归一位置），展示型 UI 模型字段的 code/ID 转换与缺省回退，协作完成态与子任务状态的写入键和撤销范围；字段类型真值、null 与空串、构造缺省值的建模，编辑会话脏检查的字段集与共享集合引用
- [network](network/index.md) — 网络层：服务地址与环境、运行配置的构建期注入、URL 拼接、拦截器注入的公共请求头、请求体字段与编码（表单或 JSON）、登录凭证来源与失效踢登，加解密工具的前置返回与异常回退、网关加密传输到 cryptoFramework 的移植，以及多路请求聚合结果的缓存写入与命中，拦截器读取的公共参数（设备标识、当前分组）的生产者，网络权限声明，请求通道内会话密钥前置门（ensureKey）的取舍与握手基址，按承载判定计费网络，链接 getter 追加的渠道等运行期参数
- [parsing](parsing/index.md) — JSON 与 XML 解析：打包资源的字段必填与空值语义，源解析器（如 Gson）的标量宽松转换与源数据实际类型，接口响应容器 Bean 的取值层级，自写 fromJson 的运行期类型收窄，以及 @ohos.xml 拉取解析的回调顺序与命名空间作用域，org.json 构造的宽松语法与取值类型校验；org.json 与 Gson 写侧（put(null) 删键、“/”转义；Gson 键序、省略 null 与 HTML 转义）与读侧取值强转
- [schema](schema/index.md) — Room 到 relationalStore 的库名、schema 版本、建表语句（含标识符加引号与关键字列名）与升级路径（基线建表与迁移重放一致），以及手写插入语句对自增主键的处理；SQLiteOpenHelper 的建库时机与打开契约（版本分派、失败后重试），Cursor.getString 读数值列的文本形态；relationalStore 共享写入口的单语句执行与事务接口选择（事务体含 await 时用 Transaction 对象）
- [seeding](seeding/index.md) — 预置、演示与参考数据：内容逐字段取自源端种子类或 assets 数据文件，资产覆盖范围与算法库实时计算字段的取舍，播种时机（建库回调或首次启动标记）与重置入口，主键写入与补充插入
- [sync](sync/index.md) — 数据同步与多阶段数据流程：多次触发的并发语义（排队、合并与尾随补跑）、失败队列的重推范围、同步进度与终态事件的发布粒度和前置条件，同步保存之后的当前选中项校验与持久化，扫描等流程收尾的缓存写入等副作用步骤，以及替代源端运行时作业聚合器（下载状态表）时的终态与事件载荷，异步落库与触发重查的事件广播的先后；事件总线（EventBus）迁移的投递契约：同步按引用、优先级与嵌套排队
