# 源端用 URLSearchParams.get 读 query 时，手写取值按表单编码：值先把 '+' 换成空格再 decodeURIComponent

ID：`lesson-83ce396a8881f15c44ad` · 版本：1

[本主题](index.md)

## 何时使用

功能实现阶段，把源端 URLSearchParams（或其他按表单编码读取 query 的 API）改写为目标端手写取值函数时

## 适用情境

源端用 new URLSearchParams(location.search).get(key) 读取深链或 URL query 参数（如预填标题、日期）；目标端不复用等价 API，而是手写 split('&')/split('=') 加 URI 解码。

## 原因

URLSearchParams 按 application/x-www-form-urlencoded 解析，'+' 表示空格；只做 decodeURIComponent 会把 ?title=A+B 读成 'A+B'。

## 做法

1. 手写取值时先 replace(/\+/g, ' ') 再 decodeURIComponent；缺键时的返回按源端调用方对 get() 结果的处理保持一致。
2. 把 query 解析放进可导出、可单测的工具函数，多个路由分支共用同一实现；用含 '+'、%20 与非 ASCII 的值各测一例，与源端结果一致再接线。
