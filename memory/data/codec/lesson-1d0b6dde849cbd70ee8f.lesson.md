# 同一定长记录在不同调用处按用途取不同切片区间时，命名常量按用途分开，不沿用相邻用途的端点

ID：`lesson-1d0b6dde849cbd70ee8f` · 版本：3

[本主题](index.md)

## 何时使用

服务层实现或重构阶段，把源端内联的定长记录切片（substring、subarray、slice）抽进服务并用共享命名常量替换字面下标时

## 适用情境

源码对同一行或同一块按用途取不同区间（例：同一记录一处取 (a,b) 只做着色，另一处取 (a,c) 提取字段并参与校验）；目标为切分点定义了一组共享常量，页面里可能已有正确的内联切片，规格也可能写了区间。

## 原因

命名常量只表达某一个用途的边界；拿一个用途的结束位去做另一用途的提取，会少取或多取字节，而函数注释仍写着原区间，代码与注释不一致却不报错。

## 做法

1. 替换字面下标时逐处读源调用的 substring/subarray 实参与记录格式定义，按调用用途选端点；常量名写清用途，不让两个用途共用一个结束位。
2. 把页面内联切片搬进服务时逐字核对搬移前后的区间与规格契约，写后用规格给出的字面区间核对表达式。
3. 写完核对代码与自身注释写的区间一致。

## 可选检查

- 规格标注区间字符精确的提取项，补一条最小断言：每项长度符合记录格式定义
