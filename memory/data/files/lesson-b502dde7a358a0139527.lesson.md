# 源端多选不限数量（EXTRA_ALLOW_MULTIPLE）时，DocumentViewPicker 显式设 maxSelectNumber 上限

ID：`lesson-b502dde7a358a0139527` · 版本：2

[本主题](index.md)

## 何时使用

数据层与页面实现阶段，把源端系统文件选择器的多选迁到 DocumentViewPicker、设置 DocumentSelectOptions 时

## 适用情境

源端以 ACTION_OPEN_DOCUMENT/ACTION_GET_CONTENT 加 EXTRA_ALLOW_MULTIPLE 选择文件，不限数量；目标用 DocumentViewPicker.select(DocumentSelectOptions)。

## 原因

DocumentSelectOptions.maxSelectNumber 默认为 1、取值范围 1–500（@ohos.file.picker.d.ts，API 10 与 API 12 的声明相同），不设就退化为单选；另定更小的“安全值”会截断源端允许的多选。

## 做法

1. 源端不限数量时，maxSelectNumber 设为当前 SDK @ohos.file.picker.d.ts 写明的上限，不另取更小值；源端单选（无 EXTRA_ALLOW_MULTIPLE）保持默认。
