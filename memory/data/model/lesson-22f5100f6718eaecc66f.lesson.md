# 宿主或适配层给展示型 UI 模型赋值时逐字段按源端绑定取值：code/ID 经源端格式化器或本地目录转换，颜色随图标一起下传，无源数据时保留构建器回退

ID：`lesson-22f5100f6718eaecc66f` · 版本：1

[本主题](index.md)

## 何时使用

界面接线与数据适配阶段，把仓库层领域数据映射成弹窗、列表项、页头等 UI 模型的展示字段（文案、图标、颜色、头像）时

## 适用情境

目标 UI 模型用字符串或图片字段直接渲染；数据层保存的是提醒 code 数组、重复规则类型与数据、分组图标或颜色 ID、成员 JSON；源端在详情页或适配器里经工具函数（code → 文案、规则 → 文案）或本地目录查表（ID → 图片、颜色）转换，并以布局中的静态文案作缺省。

## 原因

把 code/ID 当可展示值透传，或用数据状态描述、计数替代标签，编译与显示都“正常”，界面却出现原始值或错误文案；只传图标不传颜色，着色就丢失。来源为同一应用的多处：详情宿主把提醒 code 拼接、把重复规则类型直接当文案，并在交付中称“接线已补齐”；仓库聚合读到源端目录查表后仍返回原始图标与颜色 ID，还自行插入当前用户头像；待办接真实数据时把构建器的空值回退改成“暂无时间”和子任务数量；列表宿主直接用接口图标而不按分组 ID 查本地样式；页头恢复只传名称和图标，分组颜色没有进入各页。

## 做法

1. 赋值前逐字段确认数据层取值是 code、ID 还是可直接展示的值；凡是 code/ID，先在源端同一页面或适配器找到转换调用，迁成共用格式化器或目录查表后再赋值，不用 join、原值透传或自拟文案占位。
2. 源端按 ID 查本地表取图标与颜色时，目标同样按 ID 解析，并把颜色与图标一起交给子组件着色；共享页头等视觉状态按源端绑定列出全部字段（名称、图标、背景色、着色）一起进入回调与状态。
3. 既有 UI 模型字段带有构建器空值回退（与源布局静态文案一致）时，没有对应源数据就保留回退，不以数据状态描述或计数替代标签；展示条件与集合（如某行何时显示、头像列表是否插入当前用户）也按源端判断。

## 可选检查

- 对展示有疑问时，用含提醒、重复、成员等字段的真实记录核对可见文本与图标是源端文案，而非原始值。
