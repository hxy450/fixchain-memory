# 源端实体按时间键与归属键复合保存和查询时（如“本月”数据），目标模型与仓储参数照建复合关联键

ID：`lesson-6a95a3ae5f47a15892fc` · 版本：3

[本主题](index.md)

## 何时使用

数据层实现阶段，把源端实体的保存与查询迁移为目标模型字段和仓储方法参数时

## 适用情境

源端实体构造参数含时间键（月份、日期）与归属对象键，查询也用同一组复合条件取当期记录；目标准备在已有模型上只加一个单值字段。

## 原因

只加单值字段会丢掉时间键：切换月份或日期仍读到同一值，按当期计算的统计也随之失准。

## 做法

1. 把源端实体构造参数与查询条件逐项映射为目标模型字段和仓储方法参数；带“本月/当日”语义的数据要有对应时间键，页面按当前选中时间过滤。
2. 沿源端调用链核对保存、读取、展示三处使用同一组关联键，不只核对弹窗外观与校验文案。
