# data/model

模型类型之间的映射：持久化枚举字符串与页面本地类型，大整数 id（源端 Long 或 String 承接）的保精度解析，跨模型数值字段的单位，保存与查询的关联键（如按月份），以及查询层按源端判定函数派生完成态等状态（含名称谓词的归一位置），展示型 UI 模型字段的 code/ID 转换与缺省回退，协作完成态与子任务状态的写入键和撤销范围

## 本级经验

- [把以字符串持久化的模型枚举映射到页面本地类型时，按模型枚举成员逐一 switch，不用成员名字符串变换去匹配](lesson-b92a8a56aee6db5e9c52.lesson.md)
  - 时机：实现阶段把共享模型枚举（持久化为字符串）映射成页面本地枚举或资源时
  - 情境：模型枚举的持久化值是带下划线的大写串（如 FRENCH_PRESS），页面本地枚举用驼峰成员名。
  - 例外：展示型 UI 模型里 code/ID 字段的格式化与目录转换见同主题展示型模型字段赋值的经验；本条只管持久化枚举成员到页面本地类型的映射
- [把源端判定函数改写成名称谓词时，大小写等归一放在谓词内部，不依赖调用方先归一](lesson-0ac4dfb5731bf1559e78.lesson.md)
  - 时机：数据层实现阶段，把源端的系统目录、类型等判定改写成按名称或字符串匹配的谓词函数时
  - 情境：源端判定函数在内部对名称做 lowercase(Locale.ROOT) 等归一后比对；目标只能拿到显示名等字符串，改写为名称白名单谓词，该谓词被多个调用方使用，之后可能被公开或直接单测。
- [服务器下发的大整数 id 在 JSON.parse 前保真：源端 Long 用 bigint，String 承接的数值 id 保真为字符串](lesson-c066489fcf35ab37378c.lesson.md)
  - 时机：数据模型与网络层实现阶段，映射 Kotlin Long 字段或以 String 承接的数值标识、编写全局响应解析入口与序列化时；规格提取阶段写服务层签名与接口字段类型时
  - 情境：服务器生成的 id、hash、userId 以 JSON 数字下发，取值可达 19 位；源端用 Kotlin Long（Flutter 侧 Dart int）承载，或用 String 字段承接（Gson 把数值 token 直接读成字符串）；目标端 ArkTS 的 number 是双精度，JSON.parse 遇到超过 2^53 的整数直接舍入。
  - 例外：Java long 常量（Long.MAX_VALUE 等哨兵）拼进 SQL 或字符串时，见 arkts/numeric 的 long 常量安全整数经验
- [查询层重算源端派生状态时逐分支移植源判定函数；按审查意见修范围只改指明的条件](lesson-4ad956bab5fca6d7f418.lesson.md)
  - 时机：数据层实现、复核或按审查意见修正阶段，在查询层重算源端由判定函数给出的派生状态（完成态、计数），或修改该状态的写入键、删除范围时
  - 情境：源端由一个含多分支豁免的判定函数给出派生状态（例：完成态按完成模式、是否重复事件与发生日期分支判定），目标准备依据审计或交接摘要在查询层重算，仓内可能已有实现；或审查意见只要求收窄某个范围，修正时可能顺带改写共享状态的写入键。
- [源端实体按时间键与归属键复合保存和查询时（如“本月”数据），目标模型与仓储参数照建复合关联键](lesson-6a95a3ae5f47a15892fc.lesson.md)
  - 时机：数据层实现阶段，把源端实体的保存与查询迁移为目标模型字段和仓储方法参数时
  - 情境：源端实体构造参数含时间键（月份、日期）与归属对象键，查询也用同一组复合条件取当期记录；目标准备在已有模型上只加一个单值字段。
- [适配层把领域数据赋给展示型 UI 模型时逐字段按源端绑定取值：code/ID 经源格式化器或本地表转换，图标与颜色成对下传](lesson-22f5100f6718eaecc66f.lesson.md)
  - 时机：界面接线与数据适配阶段，把仓库层领域数据映射成弹窗、列表项、页头等 UI 模型的展示字段（文案、图标、颜色、头像）时
  - 情境：源端在 Adapter、详情页对数据层的 code/ID 先调格式化函数或查本地资源表，再 setText、设置图标或着色，并以布局里的静态文案作缺省；目标 UI 模型用字符串或图片字段直接渲染，由宿主或仓库聚合层赋值。例：提醒 code 数组、重复规则、分组图标或颜色 ID。
  - 例外：字段在源端本来就是可直接展示的值（setText(field) 无转换）；单个显示值经带空值兜底的访问器取得：按访问器取值的经验处理分支与登录判定
- [逐字段搬运 Builder 或构造调用时，同时核对两端模型字段的单位](lesson-c73deaf6f27d3426c4e9.lesson.md)
  - 时机：功能实现阶段，把源端模型 Builder 或构造调用逐字段翻译成目标端模型构造参数时
  - 情境：目标端两个模型对同名数值字段声明了不同单位（如本地音频时长为毫秒、播放队列时长为秒），源端在同一处直接传值；目标消费方按各自单位显示或换算。
