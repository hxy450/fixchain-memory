# “应用默认”一类排除式派生判定按源 ViewModel 谓词的完整取值集实现，不按页面可见选项推导；多页同一谓词共用一个函数

ID：`lesson-22032aef44d6cd2bdb08` · 版本：1

[本主题](index.md)

## 何时使用

页面转换与业务实现阶段，把源 ViewModel 中由枚举值集合定义的派生判定（如 isOpenItemWith*）写进页面或表单逻辑时

## 适用情境

源 ViewModel 用若干取值定义互斥选项，并以“不属于其他任何选项”派生默认项；目标页面只暴露其中部分选项，规格只列出可见单选项；同一谓词出现在新建与编辑等多个页面，由不同写者实现。

## 原因

按页面可见选项推导默认项，会把源端单独存在、但页面未展示的取值（如 webview）误判为默认；多页各自实现时判定还会不一致。

## 做法

1. 按源 ViewModel 谓词列出的全部取值实现派生判定，常量值取源端定义；同一谓词出现在多页时抽成共享函数，或与另一页逐项核对。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
