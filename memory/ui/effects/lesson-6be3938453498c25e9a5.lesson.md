# Modifier.blur(dp) 迁到 ArkUI blur 时先确认数值单位，并处理模糊边缘淡出

ID：`lesson-6be3938453498c25e9a5` · 版本：3

[本主题](index.md)

## 何时使用

界面实现阶段，把 Compose Modifier.blur(N.dp) 写成 ArkUI blur 时

## 适用情境

源端 blur 半径带 dp，默认 BlurredEdgeTreatment.Rectangle、边缘不淡出；ArkUI blur(value) 的类型注释没有写单位，文档写明模糊半径单位是 px。

## 例外与边界

- 源端模糊来自图片加载库的位图变换（如 BlurTransformation 的 radius）而不是 Modifier.blur 时，那个半径作用在解码后的位图上，不是组件滤镜半径，不按本条的 vp2px 换算照搬到 ArkUI blur

## 原因

照搬数值可能让模糊偏弱。来源修复经两端截图比对按 px 解释（写成 vp2px(N)），文档也写明 blur 半径单位是 px；ArkUI 模糊层在边缘还会淡出。

## 做法

1. blur 半径按 px 解释：源端 Modifier.blur(N.dp) 写成 blur(vp2px(N))（用 UIContext 的 vp2px），不照搬数字 N。
2. 源端边缘不淡出时，让模糊层大于显示区，再由外层 clip 裁掉。
