# Compose 渐变端点换算成 ArkUI linearGradient：默认对角按宽高算角度，stop 按周期缩放，Mirror 用回文

ID：`lesson-4ce3a1c186651285f362` · 版本：2

[本主题](index.md)

## 何时使用

界面实现阶段，把 Brush.linearGradient/horizontalGradient 翻成 ArkUI linearGradient，确定方向角、stop 位置与平铺、平移写法时

## 适用情境

源渐变或未指定 start/end（默认从组件左上 (0,0) 到右下 (w,h)），或以端点距离（startX/endX、start/end）定义图案周期并配 TileMode.Mirror 与随滚动、动画的平移；ArkUI linearGradient 只有角度或方向、按组件自身渐变线长取比例的 stop 和 repeating 开关；目标组件可能宽高不等（胶囊、卡片）。

## 原因

Compose 默认渐变轴沿组件自身对角线 (0,0)→(w,h)。ArkUI GradientDirection.RightBottom 在 enums.d.ts 只注明 Right Bottom、未给角度；已观察到它在宽胶囊上接近上下渐变，表现符合 CSS “to bottom right”（角度随宽高比变化），与固定 angle: 135 不同义，两者都只在宽高相等时与源端对角一致。ArkUI 的 stop 是相对组件渐变线长的比例，末 stop 为 1 时 repeating 不起作用；面板为覆盖显示区加宽后仍按 0–1 铺 stop，周期就被拉长。Mirror 的完整周期是端点距的两倍，按端点距铺回文 stop 会把图案压缩一半。

## 做法

1. 未指定端点的默认对角渐变：宽高不等时用 angle = 90 + atan2(h, w)（换算为度），宽高取 onAreaChange 实测；圆形、正方形可保留 RightBottom。
2. 端点定义周期时：设源端点距为 D（如 horizontalGradient 的 |endX − startX|），非 Mirror 平铺的周期为 D，stop 写成 D / 面板渐变线长 的比例，保证末 stop < 1，并与相位取模的周期一致。
3. TileMode.Mirror 的完整周期为 2D：颜色写成回文 stop，A 在 0、B 在 D、A 在 2D，再按面板渐变线长归一化并开 repeating；端点平移用比显示区大一个周期的面板做 position/translate，外层 clip。登记“无等价”前先试这组写法。

## 可选检查

- stop 有疑问时用“末 stop × 面板长度 = 周期”核一遍（Mirror 的周期为 2D）。
