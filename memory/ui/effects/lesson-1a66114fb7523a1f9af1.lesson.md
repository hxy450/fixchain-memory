# 位图着色（ColorFilter.tint、setColorFilter）用 Image.colorFilter：fillColor 只对 SVG 图源生效

ID：`lesson-1a66114fb7523a1f9af1` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段为源端着色的图片写 ArkUI Image 修饰链、选择着色 API 时；规格提取阶段为 ColorFilter.tint 一类着色写转换决策时

## 适用情境

源端 Compose Image 的 colorFilter = ColorFilter.tint(color)（默认 SrcIn），或 ImageView 的 tint、setColorFilter，作用在 png/jpg/webp 位图上（常见白色加透明通道、靠着色才可见的示意图）；目标资源仍是同一位图；规格转换行可能把 fillColor 与 colorFilter 列成并列选项。

## 例外与边界

- 资源已转成 SVG 时，fillColor 可以承担着色

## 原因

ArkUI Image.fillColor 只作用于 SVG 图源，对位图不改像素颜色，白色透明位图在浅色背景上几乎看不见（HarmonyOS 6.1.0(23) 工程实测）；位图着色要经 colorFilter。

## 做法

1. 位图用 Image.colorFilter：SrcIn 着色写 drawing.ColorFilter.createBlendModeColorFilter(色值, drawing.BlendMode.SRC_IN)（@kit.ArkGraphics2D，色值为 common2D.Color，可由 '#AARRGGBB' 主题色拆出），或等价的 4x5 矩阵（RGB 取着色色、alpha 取着色 alpha × 原 alpha）；颜色在渲染期按当前主题取值，不着色的分支不挂滤镜。
2. 修饰符对当前资源类型是否生效拿不准时，先查 SDK component/image.d.ts 中该属性的注释再写；规格写着色决策时注明源资源格式，只给对该格式生效的 API，并在同一行写出前提（如“PNG 位图 → colorFilter SRC_IN；fillColor 仅 SVG”），下游汇总规格时不丢掉这一前提。

## 可选检查

- 对着色是否生效有疑问时，在浅色与深色背景下各截图一次，核对白色透明位图是否显出着色。
