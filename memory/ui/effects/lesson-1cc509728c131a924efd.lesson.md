# 给位图（png/jpg/webp）着色用 Image.colorFilter（SRC_IN）：fillColor 只对 SVG 图源生效

ID：`lesson-1cc509728c131a924efd` · 版本：2

[本主题](index.md)

## 何时使用

界面实现阶段为源端着色的图片写 ArkUI Image 修饰链、选择染色 API 时；规格提取阶段为 ColorFilter.tint 一类着色写转换决策时

## 适用情境

源端 Compose Image 的 colorFilter = ColorFilter.tint(color)（默认 BlendMode.SrcIn），或 ImageView 的 tint、setColorFilter，作用在 drawable 位图上，常见是白色加透明通道、靠着色才在浅色背景上可见的示意图；目标资源仍是同一位图，没有转成 SVG。

## 例外与边界

- 目标资源已是 SVG（或改用同色 SVG 资源），此时 fillColor 可用

## 原因

ArkUI Image.fillColor 只替换 SVG 的填充色，对位图不起作用，白色透明位图照原样显示，落在浅色背景上几乎不可见。规格把 fillColor 与 colorFilter 列成并列选项、或下游汇总时丢掉“仅 SVG”的前提，实现者就会按 fillColor 写。

## 做法

1. 位图着色用 Image.colorFilter：SrcIn 语义用 drawing.ColorFilter.createBlendModeColorFilter(color, drawing.BlendMode.SRC_IN)（@kit.ArkGraphics2D），或等价的 4x5 矩阵（RGB 取着色色，alpha 为着色 alpha × 原 alpha）；颜色按当前主题在渲染期取值，只有部分条目着色时，不着色的分支不挂滤镜。
2. 规格写着色转换决策时注明源资源格式，只给对该格式生效的 API，并把前提写在同一行（例：PNG 位图 → colorFilter SRC_IN；fillColor 仅 SVG）。
3. 拿不准某个修饰符对当前资源类型是否生效时，先查 SDK component/image.d.ts 中该属性的注释再写。
