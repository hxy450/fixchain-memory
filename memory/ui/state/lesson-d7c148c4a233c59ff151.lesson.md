# 把源界面的生命周期回调迁入 ViewModel 刷新方法时逐条迁移全部赋值，成对状态的打开与关闭路径都要落地

ID：`lesson-d7c148c4a233c59ff151` · 版本：1

[本主题](index.md)

## 何时使用

功能实现阶段，把 Compose 界面中的局部状态与 ON_RESUME 等生命周期回调迁入 ViewModel 方法、由页面 onShown/onPageShow 调用时

## 适用情境

源界面用 remember 局部状态控制插页、弹窗等显隐，在 ON_RESUME 观察者里重查权限或数据，并按结果同时更新多个状态（如权限新获得时隐藏权限插页）；目标把这些状态集中到 ViewModel。

## 原因

回调里首个状态更新最显眼，其后的联动赋值容易在拆分时丢失；成对状态若只迁移了打开路径，界面能进入却退不出来。来源中实现者读到了源观察者“权限新获得即隐藏插页”，刷新方法只更新了授权标志；拒绝授权时显示插页的分支却已迁移，重新授权后插页一直不消失。

## 做法

1. 迁移前逐条列出源回调里的全部赋值及其条件，逐项对应到目标方法；对每组成对状态（显示/隐藏、开始/结束）确认打开与关闭两条路径都存在。
