# 源端只在断连等事件分支写入的占位文本不作状态初值：初值按源端尚未收到事件时的显示（常为空、不绘制）

ID：`lesson-ea759569c71526092f2b` · 版本：1

[本主题](index.md)

## 何时使用

服务层或 ViewModel 实现阶段，为事件驱动的状态显示（外设读数、连接状态行、OSD 文本）确定初值时

## 适用情境

源端显示内容只由事件回调写入，例如外设断连时写入“--”一类占位、收到读数时写入数值，字段初始为 null、绘制时跳过；目标把状态声明为带初值的 @Trace/@Local 字段，常量表里已有该占位串。

## 原因

初值与事件写入值是两种语义；把事件分支里的占位当初值，从未发生该事件的状态（如从未连接外设）也会显示断连占位。

## 做法

1. 按源端未收到任何事件时的表现设初值：源字段为 null 且绘制跳过时，目标用空串或可空值并不渲染；占位串只在对应事件到达时写入。

来源支持：1 张卡 · 迁移数未记录 · 应用数未记录
