# 页面向单例仓库或偏好注册监听时，把回调或句柄存成字段，在 aboutToDisappear 用同一引用移除

ID：`lesson-14b7f4090b7b83873b22` · 版本：1

[本主题](index.md)

## 何时使用

功能接线阶段，在页面 aboutToAppear 里向应用级单例仓库、数据库或偏好注册数据监听时

## 适用情境

目标数据层是应用级单例，用 addListener/removeListener（按回调引用移除）提供可观察数据；源端页面用 observeAsState、collectAsState 这类随界面生命周期自动结束的观察；ArkTS 子页出栈时不会自动注销。

## 原因

移除按引用比对，内联箭头函数事后无法注销，单例在页面出栈后仍持有页面闭包。来源中接手者自己写的仓库带有 removeListener，推理里也写了“需要存字段再移除”，填占位时五个页面仍传匿名回调，其中三页没有 aboutToDisappear；有一页刚为数据监听写了释放，偏好监听仍用匿名回调。

## 做法

1. 每写一次 addListener/on/subscribe，在同一次修改里把回调或返回的句柄存成字段，并在 aboutToDisappear 中移除；按引用移除的接口不要传内联箭头函数。
2. 把源端随生命周期自动结束的观察翻成手动订阅时，逐页列出注册点，与 aboutToDisappear 的释放清单一一对照。
3. 数据层设计监听接口时，优先让 addListener 返回可移除的句柄，迫使调用方持有它。

## 可选检查

- 交付前 grep 页面里 addListener( 后直接跟箭头函数的调用，以及有 addListener 却没有 aboutToDisappear 或 removeListener 的页面。
