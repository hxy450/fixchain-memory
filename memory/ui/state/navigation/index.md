## 本级经验

- [生命周期语义迁移应同时处理框架恢复的 UI 状态](lesson-471fc04acffdf0ebe0c5.lesson.md)
  - 时机：规格提取或实现阶段，把源端离开组合即销毁的页面状态迁移到会保活页面实例的导航容器时
  - 情境：源端非持久状态随页面离开而消失，目标端 Navigation、Tabs 或 Stack 保留页面实例，并可能在返回时恢复焦点、键盘、滚动或选区；业务显示分支又由这些框架事件驱动。
  - 例外：目标端确认每次离开都会销毁并重建页面，或已显式关闭相关框架状态恢复
