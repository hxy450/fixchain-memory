# 源端 data class copy/replaceAll 更新译为生成新实例替换并赋回 @Trace 状态；普通 DTO 不在下标元素或回调里原地改字段

ID：`lesson-3117bc9457610b1c2671` · 版本：1

[本主题](index.md)

## 何时使用

功能实现阶段，把源端不可变更新函数（findAndUpdateXxx、copy、replaceAll）与 ViewModel 的局部替换写成 ArkTS 时

## 适用情境

源端 Kotlin 用 toMutableList、replaceAll 与 data class copy 生成新元素再替换列表，Compose 任一字段变化即重组；目标 DTO 是未加 @ObservedV2/@Trace 的普通 class，列表经 V2 ForEach/@Param 渲染。

## 例外与边界

- 条目是 @ObservedV2 类且被改字段标了 @Trace，子组件绑定的仍是同一实例

## 原因

普通 class 实例上的字段写入不被观察：在下标元素或 forEach/map 回调里改字段后只做 slice() 或重包状态，界面不刷新或只部分刷新；逐字段 new 一个对象来“复制”，又会丢掉 DTO 未声明的运行期字段。注释里把原地修改写成与 copy 等价，后续读者就不再核对。

## 做法

1. 逐个对照源端 copy/replaceAll：生成同类新实例（保留全部运行期字段，可整体克隆后覆写目标字段），放入新数组再赋回 @Trace 状态，并按会变字段核对 ForEach 键。
2. 写完 ViewModel 与工具文件后检索 [idx].x =、forEach(... p.x = ...)、map(v => { v.x = ...; return v }) 这类原地赋值，逐条核对源端是否为 copy。
