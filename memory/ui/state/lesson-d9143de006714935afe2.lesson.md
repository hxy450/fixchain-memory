# 源端 Activity 实例字段承载的会话态映射为页面实例作用域，只有源端本就静态全局的状态才做单例

ID：`lesson-d9143de006714935afe2` · 版本：3

[本主题](index.md)

## 何时使用

规格提取与服务实现阶段，为页面编排服务确定作用域（单例还是页面实例），并迁移源 Activity 的实例字段（待写数据、密钥映射、挂起状态）时

## 适用情境

源 Activity 把本次会话的数据（待写数据、密钥映射、挂起状态）放在非 static 实例字段里，没有经 onSaveInstanceState、ViewModel 或外部共享对象恢复；目标规格把页面编排服务写成单例，实现者用 getInstance() 持有这些字段，并以 attach 时复位来近似实例重建。

## 例外与边界

- 源端该状态本就是静态全局的（如公共类的静态字段），此时可以映射为单例
- 字段由 savedInstanceState、ViewModel 或外部注入的共享对象恢复或持有：按该来源的生命周期映射，不当作每次全新
- 状态在源端就由多个页面共享读写：作用域定下后，跨页字段按显式传参、订阅或持久化重读处理

## 原因

单例让会话态跨页面实例共享：同一页面被打开两次、或从不同入口进入时，后一次可能读到前一次的残留，复位逻辑只能近似 Activity 重建。

## 做法

1. 先核字段的初始化、onSaveInstanceState/恢复路径和共享对象来源；只有真正由 Activity 实例独占的会话态才按页面实例作用域处理。
2. 规格把这类状态声明为页面实例作用域；页面持有自己的服务实例（new Service()）并在进入时初始化，只有源端静态全局的状态才映射为单例。
3. 实现时规格已定为单例、而源端是 Activity 实例字段：以源码为准按页面实例创建，并回报规格冲突。
