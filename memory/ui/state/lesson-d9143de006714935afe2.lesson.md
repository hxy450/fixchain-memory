# 源端 Activity 实例字段承载的会话态映射为页面实例作用域：服务需要持有会话态时按页面实例创建，只有源端本就静态全局的状态才做单例

ID：`lesson-d9143de006714935afe2` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与服务实现阶段，为页面编排服务确定作用域（单例还是页面实例），并迁移源 Activity 的实例字段（待写数据、密钥映射、挂起状态）时

## 适用情境

源 Activity 把本次会话的数据放在实例字段里，Activity 重建或另开一个实例就是全新状态；目标规格把页面编排服务写成单例，实现者用 getInstance() 持有这些字段，并以 attach 时复位来近似实例重建。

## 例外与边界

- 源端该状态本就是静态全局的（如公共类的静态字段），此时可以映射为单例

## 原因

单例让会话态跨页面实例共享：同一页面被打开两次、或从不同入口进入时，后一次可能读到前一次的残留，复位逻辑只能近似 Activity 重建。来源中规格作者已读到这些字段是 Activity 实例字段，仍把服务定为“页面编排单例”，实现照写。

## 做法

1. 规格把 Activity 实例字段承载的状态声明为页面实例作用域；页面持有自己的服务实例（new Service()）并在进入时初始化，只有源端静态全局的状态才映射为单例。
