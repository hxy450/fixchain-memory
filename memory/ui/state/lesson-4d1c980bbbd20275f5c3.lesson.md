# 判定模型字段不需要可观察之前，先读修改它的方法和显示它的界面

ID：`lesson-4d1c980bbbd20275f5c3` · 版本：1

[本主题](index.md)

## 何时使用

数据模型阶段，决定模型字段是否需要 @Trace 或其他可观察包装，或在模型注释里写“静态、不会修改”时

## 适用情境

源端模型是不可变数据类，字段值通过 copy 替换变化；只读模型定义看不出哪些字段会变，目标端要决定哪些字段可观察。

## 原因

只看模型定义会得出“字段不变”的结论，ViewModel 却可能通过复制替换改变它；写进模型注释的未核实约束会被后续实现者当作契约，进而删掉原本可用的刷新写法。

## 做法

1. 先读修改该字段的 ViewModel 方法和显示它的界面，再决定是否可观察；注释里只写已核实的约束。
