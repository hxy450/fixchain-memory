# 源端弹窗展开后才加载数据时，先打开弹层再在弹层内异步加载，带加载中与失败重试

ID：`lesson-5f8833721d3c4a11c60a` · 版本：1

[本主题](index.md)

## 何时使用

界面实现与修复阶段，为需要网络数据的底部弹层或弹窗确定数据加载时机时

## 适用情境

源端弹窗的数据请求放在展开回调里（如 Compose 弹窗的 onExpanded 调用 loadXxx），失败可在弹窗内重试；目标准备在页面初始化时预取，或在打开弹层前 await 网络。

## 原因

页面初始化时静默预取，首次失败后弹层一直为空且无法重试；打开前 await 网络，则接口慢或失败时弹层根本不出现。来源中整页写入把规格请求放进页面初始化并在失败时静默置空；修复者已收到“先展开、后请求”的源端契约，仍改成先 await 再打开，之后才改回先开后载。

## 做法

1. 点击触发时先把弹层状态置为打开，再在弹层内异步请求数据，显示加载中、空数据与失败重试；重试在弹层内完成，不要求关闭重开。
