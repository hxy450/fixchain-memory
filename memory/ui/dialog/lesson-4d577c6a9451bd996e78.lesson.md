# 源端每次调用都新建的对话框，目标按调用创建独立弹窗实例并只关闭自身，不收敛为单例句柄

ID：`lesson-4d577c6a9451bd996e78` · 版本：1

[本主题](index.md)

## 何时使用

服务层或页面实现阶段，把源端封装的“请求输入/确认”类对话框方法（每次调用 new Builder()…show()）翻译成目标弹窗时

## 适用情境

源端帮助方法每次调用都新建一个对话框并在其回调里交付结果；目标准备在服务单例里保存一个 ComponentContent 或弹窗控制器字段，新调用前先关闭旧弹窗再打开。

## 原因

源端多次调用会叠出多个对话框，各自的回调都会触发；单例句柄在新调用时静默关闭前一个，前一个调用方的回调永不到达，依赖回调推进的流程（验证后继续、取消后复位）就此悬空。

## 做法

1. 每次调用创建独立的 ComponentContent（或弹窗控制器），把关闭函数绑定到这次实例，回调与 dismiss 只作用于自身；源端确有“先关旧框”的代码时才照做。
