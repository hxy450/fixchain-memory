# 从 bindSheet 半模态里打开的弹窗必须叠在 sheet 之上：不用页内浮层，居中点外可关用模态内自绘遮罩

ID：`lesson-009212ca2c691b97d76c` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，为从底部 sheet 内部触发的二级弹窗（定时、新建输入等）选择承载层时

## 适用情境

Android 在 BottomSheetDialog 内再 show 居中 DialogFragment（点外可关）；目标底部弹层用 bindSheet；二级弹窗候选有页内 Stack 条件浮层、bindSheet(CENTER)、bindContentCover 与全局自定义弹窗。

## 原因

页内 Stack 浮层的 z 序恒低于 bindSheet 半模态层，从 sheet 内打开会被盖住；改成 bindSheet(CENTER) 又不能精确居中、也不支持点外关闭。修复时照搬本页已有浮层写法，会重新引入同一层级问题。

## 做法

1. 先确认触发点是否位于另一个半模态之内；是就用全屏模态（bindContentCover）或全局级自定义弹窗，并在 sheet 打开状态下实测层级。
2. 要还原居中、点外可关，在模态内容里自绘全屏遮罩并居中卡片，遮罩 onClick 关闭，卡体消费点击。
3. 引用“避免全局弹窗”一类规则前先核其负向守卫（不跨路由的普通弹窗无需页面级）；复用本页浮层写法前核对触发位置。
