# 同页多个工具面板逐个按源端容器类型、锚点与交互步骤实现：形态不同的面板不共用一个弹窗组件

ID：`lesson-21db515a505be4845497` · 版本：7

[本主题](index.md)

## 何时使用

界面实现与对齐阶段，为同页多个工具面板（如阅读页的设置、更多、发弹幕）确定容器、锚点与交互步骤，或准备用一个共享弹窗组件承载多个面板时

## 适用情境

源端同页多个工具面板容器各不相同（底部 PopupWindow 面板、锚定在标题栏右上角带箭头的弹出菜单、先编辑再在内容上拖动定位的多步弹层）；目标现有实现用一个固定高度、带拖动条与关闭按钮的 bindSheet 承载全部面板，或准备按类型切换内容合并成一个弹窗。

## 原因

共用一个弹窗组件再改底色与文字，位置、拖动条、关闭按钮、选中样式与后续步骤仍与源端不同；多步面板只改字数上限或标题时，拖动定位一类步骤一直缺失。

## 做法

1. 同页多个源面板逐个列出容器类型（底部面板、锚定弹出菜单、全屏覆盖层）、锚点、宽高，以及有无标题、拖动条和关闭按钮；只有这些一致时才共用一个弹窗组件，否则拆成各自布局与打开方式（多个底部面板的绑定节点见 lesson-b661a3a6a4c0a1e2a3c9）。各面板的呈现形态按源类选择，见 lesson-368c4592e4c7075c1871。
2. 源面板是多步交互（如编辑文字 → 在内容上拖动定位 → 确认或取消）时，每一步的状态与切换都要实现；只改字数上限、占位文案或标题不算对齐。

## 可选检查

- 交付前在双端用同一操作打开每个面板截图对比：弹出位置、底色、拖动条和关闭按钮、选中样式、后续步骤。
