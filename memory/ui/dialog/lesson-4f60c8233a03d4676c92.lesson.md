# 非全屏窗口用 openCustomDialog 承载源对话框窗口时，遮罩压不到系统绘制的状态栏、卡片按整窗居中：弹窗期间按 dim 切状态栏底色，按避让差下移卡片

ID：`lesson-4f60c8233a03d4676c92` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，用 openCustomDialog（或其他系统弹窗）承载 Android 对话框、确定遮罩与显示位置参数时，包括共享弹窗工具与各页宿主的打开处

## 适用情境

源主题由应用窗口绘制状态栏底色（Theme.Material 及以后 windowDrawsSystemBarBackgrounds=true、statusBarColor 不透明），对话框窗口 dim（主题 backgroundDimAmount，Material 为 0.6）覆盖整块屏幕，窗口在状态栏与导航栏之间居中；目标窗口保持非全屏，状态栏由系统按 statusBarColor 绘制，对话框用 openCustomDialog 加 maskColor 与 DialogAlignment.Center 打开。

## 原因

openCustomDialog 的遮罩只覆盖应用窗口；非全屏时状态栏由系统绘制，遮罩压不到，源端被压暗的状态栏（原底色 × (1 − dim)，图标不变）在目标保持原色。DialogAlignment.Center 以整窗为基准，源对话框窗口在系统栏之间居中，两者相差（顶部避让 − 底部避让）/ 2。把“遮罩浓度 + 居中”当作源对话框窗口的等价物，会漏掉这两个参照。

## 做法

1. 遮罩：源主题由应用窗口绘制状态栏底色时，在 openCustomDialog 的 onWillAppear/onWillDisappear 里按计数把状态栏底色切到“原底色 × (1 − dim)”（setWindowSystemBarProperties，图标色不变），最后一个弹窗关闭时恢复。
2. 位置：读主窗口 TYPE_SYSTEM 顶部与 TYPE_SYSTEM/TYPE_NAVIGATION_INDICATOR 底部（取较大值）避让，给 openCustomDialog 传 offset dy = (top − bottom)/2（px 换 vp），在 avoidAreaChange 时更新；非全屏页面不加避让 padding 的做法不变，对话框偏移仍要读取避让值。两项做成共享工具，所有弹窗打开处统一挂上。

## 可选检查

- 对话框打开时取样状态栏中段颜色与卡片上下边界：状态栏应为原底色 × (1 − dim)，卡片中心应为（状态栏下沿 + 导航栏上沿）/ 2；横屏与两种导航各看一次。
