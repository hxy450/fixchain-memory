# MaterialAlertDialogBuilder 对话框转自绘卡片时，卡片宽度、圆角、底色、高度上限与遮罩按源主题代际与 material 库版本取值

ID：`lesson-39077e6612d5f97b0731` · 版本：3

[本主题](index.md)

## 何时使用

界面实现与规格提取阶段，把 MaterialAlertDialogBuilder 对话框转换为 ArkUI 自绘卡片或弹层（含由转换器单独产出、呈现外壳留给后续切片的对话框组件），确定卡片宽度、圆角、底色、最大高度与遮罩时

## 适用情境

应用主题继承 Theme.Material3.*（或 MaterialComponents），对话框由 MaterialAlertDialogBuilder 构建；目标用 openCustomDialog、bindSheet 或页内遮罩自绘，工程中有被当作族先例的卡片，可能登记了按 M2 推断的值。也包括对话框组件只负责内容、呈现外壳未定，组件没有自带高度上限。

## 原因

按 M2 默认值或先例会得到全宽或固定比例宽度、4dp 圆角与错误底色。不设 maskColor 时 ArkUI 默认遮罩较浅，沿用框架旧默认的 0.6 又过深，都与源主题 dim 不符。对话框改为窗口级呈现后，组件若不自带最大高度，卡片会撑满全窗。

## 做法

1. 先沿 styles.xml 的 parent 链确认主题基底（Theme.Material3.* 还是 Theme.MaterialComponents.*），不凭组件 style 名或旧版经验推断；再核调用处 Builder 是否传了覆盖主题，以及主题是否改写 materialAlertDialogTheme（material 1.12 的 MaterialAlertDialogBuilder 按 overrideThemeResId 与 materialAlertDialogTheme 取对话框主题，Material3 主题默认指向 ThemeOverlay.Material3.MaterialAlertDialog，见 aar 的 classes.jar 与 res/values/values.xml），有覆盖就按覆盖后的样式取值。
2. 取值从依赖的 material aar 的 res/values 读（Gradle 缓存 transforms 下 material-<版本>/res/values/values.xml）：圆角 m3_alert_dialog_corner_size，底色 m3_comp_dialog_container_color，左右内缩 mtrl_alert_dialog_background_inset_start/end，遮罩 m3_comp_scrim_container_opacity（经 android:backgroundDimAmount）。例：material 1.12 的 Material3 下依次为 28dp、?attr/colorSurfaceContainerHigh、24dp、0.32。
3. View 体系对话框的窗口宽按主题 windowMinWidthMajor/Minor（例：appcompat 1.7.1 的 abc_dialog_min_width_major/minor 为 65%/95%），卡片再扣左右 backgroundInset；280–560dp 的宽度上下限出自 Compose material3 AlertDialog（例：1.4.0 的 DialogMinWidth/DialogMaxWidth），只用于 Compose M3 AlertDialog。
4. 每个 openCustomDialog、bindSheet 与手写遮罩显式设置 maskColor 或遮罩色，统一使用一个取自源主题 backgroundDimAmount 的 token。
5. 对话框组件自带尺寸契约：卡片 maxHeight 取窗口高减系统栏与上下 inset，内容 Scroll 用 constraintSize 限高，不用 layoutWeight(1) 把高度边界留给未定的宿主；外壳未定时随组件提供 show 封装。
6. 规格设计系统节写出对话框与底部面板的外观契约，页面规格的对话框映射行引用它。

来源支持：2 张卡 · 1 次迁移 · 1 个应用
