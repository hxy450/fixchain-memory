# MaterialAlertDialog 卡片外观按源主题代际取值，每个弹层显式设置取自源主题的遮罩

ID：`lesson-39077e6612d5f97b0731` · 版本：1

[本主题](index.md)

## 何时使用

界面实现与规格提取阶段，把 MaterialAlertDialogBuilder 对话框转换为 ArkUI 自绘卡片或弹层，确定卡片宽度、圆角、底色与遮罩时

## 适用情境

应用主题继承 Theme.Material3.*（或 MaterialComponents），对话框由 MaterialAlertDialogBuilder 构建；目标用 openCustomDialog、bindSheet 或页内遮罩自绘，工程中有被当作族先例的卡片，可能登记了按 M2 推断的近似值。

## 原因

按旧版默认或先例近似会得到全宽或固定比例宽度、4dp 圆角与错误底色；不设 maskColor 时 ArkUI 默认遮罩约 20%，沿用平台旧默认 0.6 又过深，都与源主题 dim 不符。

## 做法

1. 沿 styles.xml 的 parent 链确认主题基底（Theme.Material3.* 还是 Theme.MaterialComponents.*），不凭组件 style 名或旧版经验推断。Material3 基底：圆角 28dp；底色取主题 colorSurfaceContainerHigh 对应的 token；宽度为窗宽减左右各 24dp，并限制在 280–560dp；遮罩 0.32 黑。
2. 每个 openCustomDialog、bindSheet 与手写遮罩显式设置 maskColor 或遮罩色，统一使用一个取自源主题 backgroundDimAmount 的 token。
3. 规格设计系统节写出对话框与底部面板的外观契约，页面规格的对话框映射行引用它。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
