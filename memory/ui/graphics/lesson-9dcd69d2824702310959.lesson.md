# 源码调用项目自定义图片组件时先读组件定义：CircleShape + Crop 译为 Cover + borderRadius(边长/2) 并确认裁剪生效，不以裸 Image + Contain 代替

ID：`lesson-9dcd69d2824702310959` · 版本：1

[本主题](index.md)

## 何时使用

页面转换与巡检修复阶段，把 Compose 页面里的自定义图片组件调用翻译为 ArkUI Image，确定形状、裁剪与填充方式时

## 适用情境

Compose 页面通过项目自定义组件（ui/components 下的 XxxImage 一类）渲染图片，shape = CircleShape、contentScale = Crop 写在组件定义里，调用点只传资源与 size/modifier；页面规格只写图片尺寸；目标端的共享组件可能尚未生成，或页面选择内联 Image。

## 原因

调用点看不到形状与裁剪，把自定义组件当成平台 Image 翻译就会得到矩形或方形图，ImageFit.Contain 还会留边。来源中三个页面转换者都读到了自定义图片组件的调用却没打开定义，高亮卡、购物车行、搜索分类、详情头图全部写成 Image + Contain；巡检只报了其中一处，修复也只改了那一处。

## 做法

1. 调用的若是 import 自项目 ui/components 等位置的自定义组件，写前打开其定义，把 shape/clip 与 contentScale 一并翻译：CircleShape + Crop 对应 objectFit(ImageFit.Cover) + borderRadius(边长 / 2)，并确认圆形裁剪实际生效（来源最终同时加了 clip(true)）；目标已有对应共享组件时直接复用。
2. 巡检或返修发现某个组件调用点形状不对时，按组件名检索全部调用点逐一核对，不只修报告列出的那一处。
