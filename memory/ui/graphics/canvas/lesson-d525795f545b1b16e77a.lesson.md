# getTextBounds 取的文字高度按 actualBoundingBox 两项各自 ceil 映射，不用 fontBoundingBox 行框

ID：`lesson-d525795f545b1b16e77a` · 版本：1

[本主题](index.md)

## 何时使用

规格提取阶段写 Paint 文字度量到 TextMetrics 的映射行时；渲染实现阶段按映射计算 Canvas 文字行高、行距或自适应字号时

## 适用情境

源端自绘 View 用 Paint.getTextBounds(text, start, end, Rect) 取一段具体字符的墨迹包围盒，再用 rect.height() 定行高或间距（如标签与数值的行距、自适应字号循环）；目标用 CanvasRenderingContext2D.measureText 返回的 TextMetrics 计算。

## 例外与边界

- 源端用的是 Paint.ascent()/descent()/getFontMetrics() 的字体级度量：按字体级基线修正实测选字段

## 原因

getTextBounds 返回所测字符的墨迹紧包围盒（Skia roundOut 向外取整），随字符变化；fontBoundingBox* 是字体级行框，含整套字体的上下伸，通常明显大于墨迹盒，映射成行框会让行距吃掉组间留白。canvas.d.ts 的注释已区分两者：actualBoundingBox* 指渲染文字的矩形边界，fontBoundingBox* 指所有字体的最高矩形边界。

## 做法

1. 先按源 API 判断度量层级：出现 getTextBounds(…, rect)、rect.height()，或度量参数是一段具体字符时，映射为 Math.ceil(actualBoundingBoxAscent) + Math.ceil(actualBoundingBoxDescent)（两项各自向外取整，对应 Skia roundOut），不做 hhea 实测、不列 fontBoundingBox* 为候选。
2. 映射行写清所测子串（start/end 截出的字符）与取整方式；源式后续的加减常量或 (int) 截断原样保留。
3. 规格只给“候选字段 + 待实测”时，实现前先读 canvas.d.ts 中各候选字段的注释，按源 API 语义选字段，并在报告里标注与规格的差异。
