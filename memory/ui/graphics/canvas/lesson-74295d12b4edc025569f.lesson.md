# Canvas 字体串按注册字族名原样引用、不加源端没有的 bold；字体参与测宽布局时，首次布局前确认字体已就绪

ID：`lesson-74295d12b4edc025569f` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与渲染实现阶段，为源端自定义字体制定 ArkUI Canvas 的 ctx.font 串格式，并安排字体注册与首次 measureText 布局的先后时

## 适用情境

源端以 Typeface.createFromAsset 同步装载单一字面（如 Bold）的字体文件并 setTypeface 给 Paint，文本测宽参与布局计算；目标用 font.registerFont 注册字族，在 Canvas 中以 ctx.font 串引用并 measureText。

## 原因

源端字体同步可用、字面本身已是粗体；目标的字体串格式或注册时序不对时，Canvas 静默回落系统字体，测宽驱动的字号与布局随之改变，编译与粗看截图都不报错。来源工程实测：给字族名加引号的串在首次布局时都回落系统字体，去掉引号后仍有一次冷启需等待数十毫秒字体才可用；叠加源端未请求的 bold 还可能触发合成加粗。

## 做法

1. 字体串写成 `${size}px FamilyName`：字族名用注册名、不加引号；单一字面的字体文件按 normal 引用，不叠加源端没有的 bold/italic。
2. 首次测宽布局前做就绪检查：同字号下注册字族与 sans-serif 的 measureText 宽度不同即视为就绪；未就绪按帧重试，超时（如 1s）记日志后用系统字体继续。依赖布局结果的页面几何经布局完成回调同步，不在尺寸回调后立即同步读取。
3. 规格写明“首次测宽/布局前字体必须可用”，不把字体映射只归为字形风险交给视觉兜底。
