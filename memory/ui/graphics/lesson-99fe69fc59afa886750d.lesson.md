# 从源端自绘角标、圆点控件推导目标固定尺寸时，按调用实际进入的分支取尺寸函数，drawCircle 的半径换成直径，密度分支写明所取档

ID：`lesson-99fe69fc59afa886750d` · 版本：3

[本主题](index.md)

## 何时使用

界面实现阶段（含补齐遗漏元素的返修），把 Android 自定义 BadgeView、红点 View 等按计数与屏幕密度分支计算尺寸的控件改写为固定 vp 的 Circle 或 Text 时

## 适用情境

源端以自定义计数接口（如 setBadgeCount）显示红点或角标，尺寸由 dp 半径基数、计数分支（如无数字、带数字）和密度分支共同决定，绘制用 drawCircle(半径)；目标用固定 vp 的 Circle 复刻，常叠在高度很小的入口 chip 或图标上；协调者可能转述或改写尺寸。

## 原因

尺寸函数里同时出现半径基数、有数字时的高度（如基数×2）与无数字分支；不按实际分支取值，或把半径当直径，会得到成倍的尺寸。

## 做法

1. 先读当前控件的计数接口与绘制分支，确定调用值走哪个分支（0 是否表示无数字红点以该控件的分支为准，不沿用别的控件的约定）；再取该分支的尺寸函数与实际绘制量：drawCircle 用半径 r 时目标 Circle 宽高写 2r，不把半径基数或有数字角标的高度当作无数字红点的直径。
2. 源端尺寸有密度分支时，写明所取分支及换算结果，并与承载元素高度对照，比例明显失调时复查所取分支；转述或改写尺寸时附上源函数与分支依据。

## 可选检查

- 尺寸只经推导、未编译或未与源端截图对照时，报告中标为未验证，不以“按真机密度对应”作结论
