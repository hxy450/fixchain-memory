# 源端渲染方法按同一配置对象的字段分支（图片、纯色、渐变、空值恢复默认）时，逐分支迁移到目标渲染绑定

ID：`lesson-2dc88a09f6cfbbe3393c` · 版本：4

[本主题](index.md)

## 何时使用

渲染实现阶段，源端同一方法里按条件分支生成 ColorDrawable（单色）、按方向生成 GradientDrawable（渐变）或加载图片地址，目标准备把这个配置对象映射到运行时渲染属性时

## 适用情境

源端一个配置对象同时承载图片地址、颜色列表与方向（例：url、colors、orientation），渲染方法按“地址非空 → 图片、颜色数为 1 → 纯色、为 2 → 按方向渐变、对象为空 → 恢复默认”分支；目标外观配置模块已能保存与恢复这些字段。

## 原因

只实现首个分支时，图片背景能显示，纯色与渐变选择却没有效果；把多分支的源方法概括成“使用图片地址”，测试也只覆盖该用例，遗漏不会被发现。

## 做法

1. 迁移前把源方法的每个分支（图片、纯色、渐变、为空恢复默认）列成清单，逐项落到目标绑定（如地址为空且颜色非空时清空运行时图片并设置填充色与角度），未实现的分支明确标注。
2. 测试覆盖每种输入形态：图片地址、单个颜色、两个颜色加方向、配置对象为空；写交接摘要前对照源方法原文，摘要只剩一个分支时回查遗漏。
