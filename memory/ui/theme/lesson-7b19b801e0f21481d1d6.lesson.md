# 深浅主题状态放在可观察对象里并由入口同步，组件在渲染期读取主题色

ID：`lesson-7b19b801e0f21481d1d6` · 版本：1

[本主题](index.md)

## 何时使用

主题层实现深浅色切换，以及组件、页面读取主题色时

## 适用情境

源端 Theme(darkTheme = isSystemInDarkTheme()) 经 CompositionLocal 下发两套颜色，组件在组合期读取；目标用模块级主题函数与 $r 颜色资源实现，由入口读取系统 colorMode。

## 原因

Compose 靠组合期读取随系统切换重组。目标端用普通模块变量保存深浅状态、组件在字段初始化器或 @Param 默认值里取一次色时，界面不会随切换刷新；同步函数没有调用点时深色永远不生效，编译照常通过。

## 做法

1. 深浅状态放进 @ObservedV2 类的 @Trace 字段（或 AppStorageV2），入口 onCreate 与 onConfigurationUpdate 各调用一次同步。
2. 组件在 build() 或 get 访问器里读取主题色，不写进字段初始化器；颜色类 @Param 默认值设为 undefined，在 getter 里回落到主题色。

## 可选检查

- 有疑问时检索主题同步函数，确认 onCreate 与 onConfigurationUpdate 各有一处调用。
