# 委托 Material 库或框架主题（Theme.Holo 等）提供外观的组件，先确认库代际或框架主题，再从对应版本的库 Tokens、默认样式与源码或本机 SDK 平台资源取默认外观、几何与内部留白，检索过仍无才标待核；内部留白按库规则分侧落实

ID：`lesson-5a82d62ff7e087616968` · 版本：4

[本主题](index.md)

## 何时使用

规格提取与界面实现阶段，翻译只显式传入部分参数、其余外观交给 Material3 库默认的组件（Slider、Snackbar、TopAppBar 等），或源码没写 padding、留白由库组件内部布局提供时；为 View 体系的工具栏、底部导航、FAB、按钮、偏好分组标题确定高度、字号字重、圆角与配色，而布局 XML 未写具体值时；把 android.preference.PreferenceActivity（Theme.Holo 等框架主题）的偏好列表转成目标列表行，确定行几何、分类头、分隔线与行内控件类型时

## 适用情境

源组件只传少数颜色或尺寸，thumb 形状、留隙、刻度、容器高度、内距等来自库默认与 MaterialTheme；TopAppBar 等容器的标题槽、导航与动作槽留白由库内部布局决定，源码本身没有 padding 修饰符；目标组件的内置样式与之不同。也包括 View 体系源用 ?attr/actionBarSize、MaterialToolbar、BottomNavigationView、未写 style 的 FAB 或 OutlinedButton，取值由 Theme.Material3.* 或 MaterialComponents 父主题与组件默认样式决定。 也包括 View 体系 Activity 继承 android.preference.PreferenceActivity、主题为 Theme.Holo，页面没有布局 XML，复选框、分类头、行高与内边距、列表左右内边距、分隔线规则由平台 preference_holo 等布局与资源隐式提供；关于、帮助等同样继承 PreferenceActivity 的列表页也是如此。

## 原因

只记显式参数时，实现者会把目标框架的内置样式当作等价物，或凭不确定的记忆写死几何值并标成“库常量”。库的内部留白常是单侧规则（如标题起始侧 inset），凭记忆补值时容易写成两侧对称，或在标题槽内自行补末端内距，末端元素因此离屏缘多出一段。检索不到显式覆写就套用 M2/AppCompat 默认（56dp 工具栏、20sp Medium 标题、圆形 FAB），或沿用兄弟页数值，会系统性偏离 Material3 外观。框架主题与 Material 库的默认值不同：Holo 偏好分类头是 listSeparatorTextViewStyle（14sp 粗体全大写、次文字色、底部 2dp 线），不是 colorAccent；CheckBoxPreference 是方形复选框而不是开关。另一应用中规格作者把这些平台值全部标为待核，编排派工又写成“复选→Toggle、滑条→Slider、高级项→箭头行”，实现者凭记忆补成开关、细体灰字分类头与通栏分隔线，而本机 SDK 一直可查。

## 做法

1. 取值来源按提供方：Material 库组件的几何从对应 material3 版本的 Tokens 或源码取（例如 Snackbar 单行与多行容器高度不同）；框架主题（android:Theme.Holo/DeviceDefault）的组件与布局从本机 SDK platforms/android-<api>/data/res 的 values/styles.xml、themes.xml、layout/*.xml 与 drawable 取，检索过仍无才标待核并写明检索路径。未传入的颜色查主题文件，写明取 MaterialTheme.colorScheme 或主题属性的哪一项；不直接映射成目标内置样式。
2. 源码没写、由库内部布局提供的留白，按库的布局规则分侧写出：哪一侧有 inset、由哪个槽位撑开；不把单侧 token 扩成对称 padding，标题槽内的 Row 不自行补末端内距。
3. 规格已写入某组件的部分 M3 默认值（如容器高度）时，把同一组件的标题 inset 与槽位规则一并写出。
4. 思考中带问号或决定不深究的数值，不写成带库出处注释的常量；取不到时在规格或报告里标为缺口。
5. View 体系先读页面元数据列出的 styles.xml，沿 parent 链确认组件库代际或框架主题；检索不到覆写不等于采用 M2 默认。Material3 下常用默认：工具栏 actionBarSize 64dp、标题 TitleLarge 22sp 常规字重、标题起点 16dp（有导航图标时约 60dp）；底栏选中标签按 itemTextAppearanceActiveBoldEnabled 加粗，徽标宿主收至图标尺寸后右上锚定；FAB 为 16dp 圆角方形配 colorPrimaryContainer/onPrimaryContainer；OutlinedButton 文字 LabelLarge 14sp Medium；AppCompat/Material 偏好库的 PreferenceCategory 标题用 colorAccent。
6. PreferenceActivity + Theme.Holo 的偏好列表从 layout/preference_holo.xml、preference_category_holo.xml 与相关 drawable 取几何写进规格：列表左右 16dp、行最小 64dp、文字列右 8dp、摘要 maxLines 10；分类头 14sp 粗体全大写加 2dp 线；分隔线与分类头相邻不画、末项后也画；CheckBoxPreference 用方形复选框六态图，SeekBarPreference 按源布局叠放数值与 SeekBar，带 icon 的 Preference 只有 48dp 宽图标框与标题、没有尾部箭头。
7. 代码中镜像资源数值（如工具栏高度常量）从同一资源取值并注明来源主题；规格的设计系统节把这些组件度量写成具体值，供页面引用。

## 可选检查

- 补出库内部留白后有疑问时，用源端 dump 或截图核一次两端元素与屏缘的距离；没有 dump 时在注释写明取自哪条库规则、作用于哪一侧。
