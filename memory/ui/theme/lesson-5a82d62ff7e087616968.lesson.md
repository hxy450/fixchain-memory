# 委托 Material3 库的组件，默认外观、几何与内部留白从对应版本的库 Tokens 与源码取值，内部留白按库规则分侧落实

ID：`lesson-5a82d62ff7e087616968` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与界面实现阶段，翻译只显式传入部分参数、其余外观交给 Material3 库默认的组件（Slider、Snackbar、TopAppBar 等），或源码没写 padding、留白由库组件内部布局提供时

## 适用情境

源组件只传少数颜色或尺寸，thumb 形状、留隙、刻度、容器高度、内距等来自库默认与 MaterialTheme；TopAppBar 等容器的标题槽、导航与动作槽留白由库内部布局决定，源码本身没有 padding 修饰符；目标组件的内置样式与之不同。

## 原因

只记显式参数时，实现者会把目标框架的内置样式当作等价物，或凭不确定的记忆写死几何值并标成“库常量”。库的内部留白常是单侧规则（如标题起始侧 inset），凭记忆补值时容易写成两侧对称，或在标题槽内自行补末端内距，末端元素因此离屏缘多出一段。

## 做法

1. 几何值从对应 material3 版本的 Tokens 或源码取（例如 Snackbar 单行与多行容器高度不同）；未传入的颜色查主题文件，写明取 MaterialTheme.colorScheme 的哪一项；没有运行截图时标为待核，不直接映射成目标内置样式。
2. 源码没写、由库内部布局提供的留白，按库的布局规则分侧写出：哪一侧有 inset、由哪个槽位撑开；不把单侧 token 扩成对称 padding，标题槽内的 Row 不自行补末端内距。
3. 规格已写入某组件的部分 M3 默认值（如容器高度）时，把同一组件的标题 inset 与槽位规则一并写出。
4. 思考中带问号或决定不深究的数值，不写成带库出处注释的常量；取不到时在规格或报告里标为缺口。

## 可选检查

- 补出库内部留白后有疑问时，用源端 dump 或截图核一次两端元素与屏缘的距离；没有 dump 时在注释写明取自哪条库规则、作用于哪一侧。
