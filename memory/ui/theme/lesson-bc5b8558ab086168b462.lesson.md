# 引用 style 或抽成共享 @Builder 的控件：先展开共享默认值，再逐实例叠加元素自身的覆写（字号、圆角、间距）；圆角不按半高推，也不照抄相邻控件

ID：`lesson-bc5b8558ab086168b462` · 版本：6

[本主题](index.md)

## 何时使用

界面实现阶段（含返修期重写弹窗或按钮），为通过 style 继承形状、尺寸与渐变的控件确定修饰链时；把重复 XML 元素抽成 @Builder 时；为 TextView 的 maxLines/lines、TextAppearance 字号字重行高，或 LinearProgressIndicator 等 Material 控件的轨道色确定取值时

## 适用情境

源 XML 控件以 style="@style/X" 继承圆角、高度、渐变等属性，元素本身只覆写部分项；同一或相邻布局里有圆角更大的卡片，或同 style 但显式覆写成胶囊的按钮。或按键等控件以 style 给默认 textSize、单个控件再覆写不同字号；多个同构元素（分组标题）各自带不同的 layout_marginTop。也包括 maxLines/lines、TextAppearance 与 trackColor 来自 style 引用或 Material 控件默认样式，布局 XML 本身没写。也包括 TextView 只声明 textAppearance（如 ?android:attr/textAppearanceMedium）而没写 textColor，映射参考只说“展开为样式”，写者只取了字号。

## 原因

style 里的形状值不在元素上，不展开就只能猜：按高度一半推成胶囊、照抄外层卡片或相邻按钮的圆角；把某处的显式覆写当成 style 默认值，或把共享 @Builder 的参数写死，又会把一处的取值扩散到所有实例。

## 做法

1. 遇到 style 引用先展开其全部 item（圆角、高度、渐变起止色），再逐项叠加元素上的显式属性；元素没覆写的形状值取 style 值。
2. 在注释里写明每个形状值来自 style 还是哪一行覆写；写不出来源就先读 styles.xml，不用估算值占位。
3. 同一 style 多处复用时逐个控件核对有无显式覆写，覆写处保持覆写值，不把某处覆写当成 style 默认值。
4. 字号等文本属性同样逐控件取有效值：元素覆写优先于 style 默认；把重复元素抽成 @Builder 时，逐实例不同的属性（margin、字号）作为参数传入，写完逐条对照 XML 数值。
5. maxLines/lines、TextAppearance、trackColor 同样先在 res/values 的 styles/themes 查出再写，不按“XML 未写即默认”推断；android:lines=N 对应 minLines(N) 加 maxLines(N)，Text.minLines 自 API 22 起提供（text.d.ts），compatibleSdkVersion 更低时用 constraintSize({ minHeight: 行高 × N }) 配 maxLines(N)。
6. 展开 textAppearance 时字号、字重与 textColor 一起展开，按 textAppearance 解析到实际颜色属性再选令牌，不凭默认取主文字色或次文字色（例：appcompat 1.7.1 的 Platform.AppCompat 把 android:textAppearanceMedium 指向 TextAppearance.AppCompat.Medium，为 18sp、?android:textColorSecondary）；其他主题代际的默认链见 lesson-e9f02c6de64ad68b5b48。
