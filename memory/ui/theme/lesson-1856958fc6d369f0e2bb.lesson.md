# ?attr 主题色按各主题取值导出 base/dark 颜色键，并在 ArkUI 侧显式绑定

ID：`lesson-1856958fc6d369f0e2bb` · 版本：1

[本主题](index.md)

## 何时使用

资源前置或界面实现阶段，为引用 ?attr 的图标 fillColor、工具栏主题色、自绘组件前景色或文字色新建或选择颜色 token 时

## 适用情境

源图标与控件颜色来自主题属性（应用自定义的图标色属性、colorControlNormal=colorOnSurface、colorOnSecondary 等），各主题取值不同；目标 SVG 只保留浅色值，color.json 可能缺对应键。

## 原因

缺键时借用语义不同的灰色、按名称猜为强调色，或 base/dark 写同一个值，会让图标在某个主题下颜色错误，并随先例扩散。

## 做法

1. 查矢量 fillColor 或工具栏主题引用的属性，分别取各主题 style 中的值，在 base/dark 各写一个键；检索时不要把目标属性名排除在外。
2. 自绘组件的 foregroundColor=?attr 先查 attrs/styles 的实际值再定默认色，各调用点按自己布局传参。
3. 图标 Image 用 fillColor 绑定该 token，不沿用未着色的先例；资源前置阶段把被引用的主题属性连同解析值导出为颜色键并在映射表注明。
