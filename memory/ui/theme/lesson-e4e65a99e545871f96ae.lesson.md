# 视觉属性逐项取自源布局、item 布局与适配器分支，缺项就补读，不以近似值、通用卡片或自拟分隔线代替

ID：`lesson-e4e65a99e545871f96ae` · 版本：1

[本主题](index.md)

## 何时使用

界面转换与视觉返修阶段，确定标题栏背景、文字颜色与字号、周末与选中样式、item 尺寸、胶囊圆角、行高与分隔线时

## 适用情境

页面规格只给合成的结构（无颜色与尺寸），视觉数值分散在 Fragment 布局、include 布局、item 布局与适配器 convert 分支里；转换者可能只读到部分文件，或读到了却按经验取整。

## 原因

视觉属性一旦凭经验补齐，就会整体偏离源端：白底标题栏代替红底、统一灰色星期行代替红色周末、方块标签代替圆角胶囊、多出源端没有的横线与竖线、行高与内边距取近似值。来源为同一应用：月历页转换者在批量读取被截断后自拟配色与选中样式；15 日页生成者读到了 item 与 Fragment 布局的 dp 值，仍写成近似尺寸并额外加了分隔线；月历生成者读全了日期格 item 布局，仍把 46 高写成 48、用圆形与文字色块代替今日与班休图片角标。

## 做法

1. 写样式前从源布局、item 布局与适配器分支逐项摘出清单：背景色、主要文字颜色与字号、周末与节日颜色、选中与当天样式、item 宽高、圆角、行高与上下间距、分隔线的有无；某项在已读内容里找不到就回到对应文件补读。
2. 写完按清单逐个 dp 值对照，不用近似值，不自行增加源端没有的分隔线或卡片圆角。

来源支持：3 张卡 · 1 次迁移 · 1 个应用
