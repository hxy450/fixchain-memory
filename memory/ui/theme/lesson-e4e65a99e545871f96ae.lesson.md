# 视觉属性逐项取自源布局、item 布局与适配器分支，缺项就补读，不以近似值、通用卡片或自拟分隔线代替；菜单行与操作栏的图标、按状态切换的图与颜色同列清单

ID：`lesson-e4e65a99e545871f96ae` · 版本：2

[本主题](index.md)

## 何时使用

界面转换与视觉返修阶段，确定标题栏背景、文字颜色与字号、周末与选中样式、item 尺寸、胶囊圆角、行高与分隔线时；把弹出菜单行、列表分组标题与批量操作底栏转成组件时

## 适用情境

页面规格只给合成的结构（无颜色与尺寸），视觉数值分散在 Fragment 布局、include 布局、item 布局与适配器 convert 分支里；转换者可能只读到部分文件，或读到了却按经验取整。 也包括增量迁移的差异清单与规格只按功能行为描述新入口，菜单行或操作按钮由 ImageView 加 TextView 组成、标题用 drawableLeft 图标与专用颜色资源，部分图标随选中状态切换。

## 原因

视觉属性一旦凭经验补齐，就会整体偏离源端：白底标题栏代替红底、统一灰色星期行代替红色周末、方块标签代替圆角胶囊、多出源端没有的横线与竖线、行高与内边距取近似值。来源为同一应用：月历页转换者在批量读取被截断后自拟配色与选中样式；15 日页生成者读到了 item 与 Fragment 布局的 dp 值，仍写成近似尺寸并额外加了分隔线；月历生成者读全了日期格 item 布局，仍把 46 高写成 48、用圆形与文字色块代替今日与班休图片角标。 规格只承载行为时，写者容易只写出文字与点击。另一应用中写者已看过 Android 截图、读到菜单布局与按选中状态换图的源码，仍把更多菜单、推荐标题与批量底栏写成纯文字。

## 做法

1. 写样式前从源布局、item 布局与适配器分支逐项摘出清单：背景色、主要文字颜色与字号、周末与节日颜色、选中与当天样式、item 宽高、圆角、行高与上下间距、分隔线的有无；某项在已读内容里找不到就回到对应文件补读。
2. 写完按清单逐个 dp 值对照，不用近似值，不自行增加源端没有的分隔线或卡片圆角。
3. 清单同时覆盖图标元素：ImageView、drawableLeft/Start、按选中数量或模式切换的 drawable（如未选中用灰图、选中用高亮图）及对应文字颜色，按状态成组映射。差异清单或规格只描述行为时，实现者仍回到源布局补出可见元素；规格提取描述新 UI 入口时，把关键视觉要素（图标、标题颜色、“图标 + 文字”结构）写进验收项。
