# 把 Android 主题、Compose 宿主或依赖库隐式提供的外观写成目标控件的显式样式，取值来自实际提供方

ID：`lesson-47785524c7f132ea7efe` · 版本：4

[本主题](index.md)

## 何时使用

规格提取阶段写控件转换决策，或页面实现阶段写出按钮等控件的修饰链时；为未写 tint/color 的 Compose Icon、Text 着色，翻译未传 textStyle 的 BasicTextField，或迁移 GlanceTheme 等依赖库主题色时

## 适用情境

源布局中的 Button 等控件没有声明 background / backgroundTint / textColor / 圆角，外观来自应用主题（如 Theme.MaterialComponents 的 colorPrimary、colorOnPrimary）；目标工程已迁移同名语义色资源，而 ArkUI 对应组件不设样式时使用平台默认外观。也包括 Compose 的 Icon/Text 未写 tint/color、颜色来自宿主 Surface 的 LocalContentColor，而相邻页面或组件里有显式写 iconPrimary、brand 的图标可供照搬。也包括 foundation 的 BasicTextField 不传 textStyle（默认 TextStyle.Default，不读 Material 排版），以及颜色来自 GlanceTheme 一类依赖库主题、源码与规格里都没有具体色值。也包括 EditText/TextView 未声明 textColor、textSize，取值来自 Activity 主题（如 AppCompat Light 的 textColorPrimary）与 TextView 默认字号。

## 例外与边界

- 源控件已在布局或 style 中显式声明样式，此时按显式声明转换
- 决策记录明确要求目标端采用平台默认外观

## 原因

ArkUI 组件不会继承 Android 主题给控件的默认样式。规格只在全局写“颜色由资源系统负责”而不落到控件行，下游按控件行实现就得到平台默认外观。来源（API 24 工程）中不设样式的 ArkUI Button 呈默认蓝 #0A59F7 胶囊，与源端 Material 紫底白字小圆角按钮不符。另一应用中弹层的关闭图标与排序行首图标在源端都没写 tint（取宿主内容色，接近正文黑），写者统一套了 iconPrimary 令牌（该主题中为品牌紫）；同一文件里 Reset 文本显式写了 uiBackground 与禁用时 0.38 alpha，也被换成品牌色加 enabled()。实际提供方因组件而异：Scaffold、Surface 都可能提供 contentColor；foundation 组件不读 Material 的 LocalTextStyle；库主题色的回退值写在库资源里。凭“默认 onSurface”或另一设计体系的基线色填写，颜色和字号都会偏，还会被后续页面当先例照搬。另一应用中返修者见源 EditText 未声明 textColor，就把目标三个输入框统一硬编码为 #333333；另一处分数文字未声明 textSize，沿用了旧实现的 16；后续按主题默认主文字色与 TextView 默认 14sp 纠正。

## 做法

1. 规格提取时，对布局里没写样式的控件先查主题的父主题与语义色，把主题带来的背景色、字色、圆角、最小高度写进该控件自己的转换决策行，用已迁移的颜色资源名表达。
2. 实现时对照源主题语义色与目标颜色资源补齐修饰链：MaterialComponents 按钮对应 .backgroundColor($r('app.color.colorPrimary')) 与 .fontColor($r('app.color.colorOnPrimary'))，再按源按钮样式补 borderRadius 与最小高度；规格未写样式时同样补齐，并在转换报告注明依据来自主题。深浅色由 base/dark 资源自动切换。
3. Compose Icon/Text 未写 tint/color 时，沿调用链找最近的 Surface、Scaffold 或 CompositionLocalProvider，取它的 contentColor 对应的资源写进规格与实现；没核到宿主时标为待核，不写“默认 onSurface”或系统字色，也不照搬别处显式使用的 iconPrimary、brand 或其他页面的先例。源端显式写了 color 与禁用 alpha（如 uiBackground.copy(alpha = if (!enabled) 0.38f else 1f)）时，分别落实为 fontColor 与按状态的 opacity，不用品牌色加 enabled() 代替。
4. foundation BasicTextField 未传 textStyle 时按 TextStyle.Default 落实（14sp、黑色、系统字体）；bodyLarge 等 M3 排版只用于 M3 TextField/Text。
5. 依赖库主题色（如 GlanceTheme.widgetBackground）从库包的 res/values 与 values-night 取回退值（如 Gradle 缓存中的 aar）；取不到时登记待核，不用其他设计体系的基线色代替。
6. TextView/EditText 未声明 textSize/textColor 时按 TextView 默认值和 Activity 实际主题推导（如默认 14sp；AppCompat Light 主文字色 #DE000000，白底近似 #212121），不沿用旧实现、相邻组件或同组控件的硬编码值。
