# 布局引用的 @drawable（progressDrawable、背景 shape、标签背景、光标 shape）先打开文件取数值，再按消费它的属性落成目标写法

ID：`lesson-771d1ba1a032b769097a` · 版本：5

[本主题](index.md)

## 何时使用

规格提取与界面实现阶段，为进度条、搜索框、分组标签等引用 drawable 的控件确定高度、圆角、颜色与描边时

## 适用情境

源布局以 progressDrawable=@drawable/xxx、background=@drawable/bg_xxx 引用 drawable XML（如 shape），尺寸、圆角、轨道色、渐变和描边写在被引用文件里；目标工程可能已有名称相近、含义不同的颜色资源。也包括 EditText 用 textCursorDrawable 引用 shape 定义光标宽度与颜色，且只设在部分字段上。

## 原因

drawable 里的尺寸、圆角、颜色、渐变与描边不在布局上，不打开被引用文件就只能自定或沿用工程里已有的颜色；把 shape 转成固定尺寸 SVG 再以背景图铺到非方形容器，会把圆角底色缩放裁切；光标 shape 只设在部分字段上时，照同族页面统一设置也会偏。

## 做法

1. 遇到 @drawable 引用就打开被引用文件，把高度、圆角、轨道/前景色、渐变与描边值写进规格和修饰链；不自定高度，不按名称套用工程里含义不同的颜色。
2. 未读到被引用资源前不定稿；写后才读到的数值回写到已生成片段。
3. 先打开被引用文件判断类型：shape（solid + corners，有 stroke 再加描边）直接写成 backgroundColor + borderRadius（+ border），只有位图或九宫格才用 backgroundImage；不把转换得到的固定尺寸 SVG 以 backgroundImage + Cover 铺到非方形容器。
4. textCursorDrawable 引用的 shape 读出 solid 颜色与 size 宽度，写成 TextInput 的 caretStyle({ width, color })（text_input.d.ts，API 10 起）；只给源端声明了它的字段设置，未声明的字段不带入。
