# 源布局有 layout-land 等配置变体时逐控件逐属性对照，并在承载该布局的组件内按方向分支实现（ArkUI 没有布局资源限定词）；运行时 setBackgroundResource 只覆盖被调用的控件，其余控件取各变体 XML 的值

ID：`lesson-c8e645a542254d96997e` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，合并 layout 与 layout-land 变体，或实现替代带变体 fragment 的共享组件时；计划与派工阶段指派变体实现时

## 适用情境

源 res/layout-land/ 下有同名变体，控件的 background、weight、margin、textSize 或整体结构与竖屏不同；Activity 代码在运行时只对部分控件 setBackgroundResource；布局由另一任务的共享组件承载，派工只写竖屏结构，横屏要求只出现在资源任务或移交登记里。

## 原因

只按竖屏骨架实现，或把运行时覆盖推广到所有控件，横屏下结构与外观都会偏（来源中统计卡没有横屏分支，横屏主菜单的直角按钮被写成圆角）；资源任务承接不了布局变体。

## 做法

1. 开写前对每个被替代的源布局 ls res/layout-*/<name>.xml，按 android:id 逐控件 diff 各变体的属性；每个差异写成方向条件分支（窗口宽 > 高），或在报告注明被哪段运行时代码覆盖。
2. 先列出运行时 setBackgroundResource/setBackground 实际作用的控件变量，只有这些改用运行时背景，其余控件在每个变体里按该变体 XML 取形状与颜色。
3. 布局由共享组件承载时，把变体路径与差异写进该组件的产出与验收，不只放进资源任务；本任务确实不做时登记带负责方、变体路径与关键值的移交，关闭移交前逐条核对横屏要求。
