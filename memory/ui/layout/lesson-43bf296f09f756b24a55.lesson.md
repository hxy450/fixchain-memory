# 菜单项按生效的 showAsAction 分流到图标位或溢出：AppCompat 只读 app:showAsAction

ID：`lesson-43bf296f09f756b24a55` · 版本：2

[本主题](index.md)

## 何时使用

界面实现阶段，把选项菜单 XML（onCreateOptionsMenu 中 inflate 的 menu）转到自绘标题栏或工具栏，决定哪些项进图标位、哪些进溢出菜单、是否显示文字时

## 适用情境

源菜单项带 icon 与 showAsAction=ifRoom/always/never/withText，或带 checkable=true；Activity 可能基于 AppCompat，而菜单 XML 写的是 android:showAsAction（常带 tools:ignore="AppCompatResource"）；也可能是框架 ActionBar（Theme.Holo 等），读 android:showAsAction。

## 例外与边界

- 菜单项由代码 MenuItem.setShowAsAction 设置时，以代码设置的值为准

## 原因

全部放进溢出菜单或只设选中态，会丢掉工具栏图标位与勾选指示；反过来，AppCompat 只读 app: 命名空间，android:showAsAction 被忽略、所有项进溢出菜单，把它们做成标题栏图标会多出源端没有的入口。ifRoom 也不保证进入图标位：ActionMenuPresenter 按名额与剩余宽度依次分配。

## 做法

1. 先确定生效的属性：AppCompat 读 app:showAsAction，框架 ActionBar 读 android:showAsAction；AppCompat 下只写了 android:showAsAction 时全部项进右上溢出菜单，不转成标题栏图标或 NavDestination 图标菜单。
2. always 的项进图标位；ifRoom 的项按 ActionMenuPresenter 的名额与剩余宽度依次分配，放不下的进溢出菜单；never 与 collapseActionView 进溢出。目标窗口宽度变化时按同一顺序重新分配。
3. withText 的文字只在 ActionMenuItemView.shouldAllowTextWithIcon 为真时显示（android-36.1 的 ActionMenuItemView.java：screenWidthDp ≥ 480，或宽 ≥ 640 且高 ≥ 480，或横屏），框架 Holo 下样式取 TextAppearance.Holo.Widget.ActionBar.Menu；其余情况只显示图标。
4. checkable 项显式开启 selectIcon 等勾选指示，不只设选中态。
