# 源用 Theme.Holo 等框架主题提供的 ActionBar 时，按 SDK 平台资源写外观契约，并做成多页共享的标题栏组件

ID：`lesson-b3372bd24373e70e4485` · 版本：2

[本主题](index.md)

## 何时使用

规格提取与页面实现阶段，为框架主题（Theme.Holo/Material/DeviceDefault，未用 NoActionBar 或 FEATURE_NO_TITLE）提供的 ActionBar 自绘目标标题栏时

## 适用情境

ActionBar 是主题提供的窗口装饰，不在布局 XML 中；页面调用 setDisplayHomeAsUpEnabled、manifest 声明 android:icon、菜单带 showAsAction；目标用 hideTitleBar 自绘标题栏，多个页面需要同一外观并可能并行转换。

## 例外与边界

- 源主题为 AppCompat/MaterialComponents 的 ActionBar 或自建 Toolbar 时，取值来自对应依赖库的样式，不取框架平台资源

## 原因

框架 ActionBar 的背景、高度、标题字号、应用图标、Up 尖角与溢出图标都由平台主题资源提供，布局里看不到；各页凭记忆手绘会用字符、Polyline 或圆点代替平台图标，颜色与高度彼此不一，横屏下的取值差异也会丢失。

## 做法

1. 规格为每个带 ActionBar 的页面写一条外观契约：高度、背景 drawable、该 Activity 或 application 的 manifest android:icon、标题与字号、是否显示 Up、动作项与溢出图标，并注明 values-land 等限定目录的差异。
2. 取值查本机 Android SDK：platforms/android-<api>/data/res 的 styles_holo.xml、themes_holo.xml、dimens.xml、values-land 与 drawable-* 原图（Up 尖角、溢出按钮等）；把原图复制为目标资源，不用字符或图形自绘平台图标。
3. 多页共享时先建一个共享标题栏组件，各页只传 icon、title、是否 Up 与动作项；高度与标题字号按 values-land 等限定目录的取值随窗口方向切换。
