# 落地源码整除公式的纯函数：参数名带 px/vp，调用处做 vp2px→公式→px2vp 往返

ID：`lesson-86a32ca71a1965302635` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，用 onAreaChange / measureText 的返回值喂源码整数几何公式并写成纯函数时

## 适用情境

公式含 floor/trunc/Int 除法；输入来自 onAreaChange（vp 浮点）或 measureText（px）。

## 原因

converter 与 slice worker 都按 spec 在 vp 域取整（「All lengths are vp」），placeTextAndIcon 的 iconX 还在 vp 域 trunc(7.71)=7 再丢 0.71vp；修复把全部几何搬到 px 域后 Row 0..1320px、槽 528/264/264/264、图标中心 660/924/1188px 与 Android 一致。

## 做法

1. 把 px/vp 写进参数名（barWidthPx）；onAreaChange 的 vp 宽先 vp2px，公式在 px 域 floor/trunc，写入 .width/.translate/.position 前 px2vp。

## 检查

- dumpLayout 里 Row 总宽应等于容器 px 宽（1320 不是 1313）；每个槽位/图标中心的 px 与 Android dump 逐项相等。
