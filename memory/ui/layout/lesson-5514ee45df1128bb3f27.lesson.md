# match_parent加左右margin的控件在ArkUI中写成calc宽度

ID：`lesson-5514ee45df1128bb3f27` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把带左右margin的match_parent控件转成ArkUI宽度时

## 适用情境

源控件layout_width=match_parent并设左右margin，目标为Text、Divider等组件。

## 原因

ArkUI中width('100%')等于父宽，margin另加在外侧，组件会比源端宽出两侧margin并溢出父容器。

## 做法

1. 写width('calc(100% - 左右margin之和vp)')再设margin，或不设100%宽、由父容器拉伸。
2. 修正一处后，在同一文件里把同类兄弟节点（Text、Divider等）一并检查。
