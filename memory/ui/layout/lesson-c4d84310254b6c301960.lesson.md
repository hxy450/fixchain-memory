# 源视图在onMeasure中改写自身尺寸时，目标组件外框测成同一结果

ID：`lesson-c4d84310254b6c301960` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，迁移在onMeasure中自定尺寸的自定义View，并决定它在线性布局中的尺寸时

## 适用情境

源自定义View以wrap_content放置，在onMeasure中按可用宽高计算并setMeasuredDimension（如取min(宽,高)取整成正方形），兄弟控件紧随其后；目标用自定义组件包Canvas实现。

## 原因

用100%外壳加居中画布模拟时，只有画布是目标尺寸，组件外框仍占满剩余空间，兄弟控件被推开；只核对尺寸公式发现不了这个问题。

## 做法

1. 用onMeasureSize/onPlaceChildren（或确定的显式宽高）让组件本身测成源端onMeasure的结果；源为wrap_content的子项不加layoutWeight或100%宽高。
2. 需要把测得的边长交给兄弟或父布局时，通过事件回传，由父布局据此设宽。

## 可选检查

- 组件外框bounds等于画布bounds，后一个兄弟紧贴其边缘
