# Compose LazyColumn 默认无滚动条：ArkUI List/Scroll 显式 BarState.Off，自定义滚动条按参数复刻

ID：`lesson-29b42ac7502c0f284b9a` · 版本：2

[本主题](index.md)

## 何时使用

列表与滚动区实现阶段，把 Compose LazyColumn、verticalScroll 或自定义滚动条修饰符转成 ArkUI List/Scroll 时

## 适用情境

源端 Compose LazyColumn/verticalScroll 没有滚动条修饰符，或用自定义修饰符（如 simpleVerticalScrollbar：按项数绘制、滚动时淡入淡出）画滚动条；目标 ArkUI List/Scroll 默认按 BarState.Auto 显示系统滚动条。

## 原因

不写 scrollBar 时目标会显示源端没有的系统滚动条；把自定义修饰符标成“无等价”交给系统滚动条，宽度、颜色、出现时机与 thumb 计算方式都不同。

## 做法

1. 源端没有滚动条修饰符时显式写 .scrollBar(BarState.Off)；有自定义修饰符时关闭系统滚动条，按修饰符源码的宽度、颜色与透明度动画、按项数计算的 thumb 位置与长度复刻（如 List 外包 Stack，由 onScrollIndex、onScrollStart、onScrollStop 驱动）。
