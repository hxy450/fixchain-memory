# Lazy 列表 contentPadding 按主轴拆分：首尾值写 contentStartOffset/EndOffset，交叉轴值放进条目 padding

ID：`lesson-4030f978a230df37de2b` · 版本：3

[本主题](index.md)

## 何时使用

界面实现阶段为滚动列表确定首尾留白时；规格提取阶段描述 Lazy 列表留白时

## 适用情境

源 LazyRow/LazyColumn 用 contentPadding（PaddingValues）给首尾项留白；目标 ArkUI List 可写 .padding，也可写 contentStartOffset/contentEndOffset；映射参考只有通用的 padding → .padding()。

## 例外与边界

- 源码是 Modifier.padding（缩小视口，滚动内容裁在内距内）时，写 List.padding

## 原因

contentPadding 只偏移内容、视口不变，项可以滚进留白区；List.padding 缩小视口，项滚到内距处被裁切。contentStartOffset/contentEndOffset 只作用于主轴（list.d.ts：列表内容起点到显示区边界的偏移），LazyColumn 的 start/end 是交叉轴，照搬会把横向留白写成上下偏移。两者静止时一样，差异只在滚动时出现。

## 做法

1. 按主轴取首尾值：LazyRow 取 start/end，LazyColumn 取 top/bottom，写成 .contentStartOffset/.contentEndOffset；交叉轴分量放进 ListItem 内容的 padding。
2. 规格里写“内容内距（主轴首尾，滚动时不裁切）”，不只写“左右 padding”。

## 可选检查

- 有疑问时检索列表上的 padding，逐处对照源码是 contentPadding 还是 Modifier.padding。
