# 可滚动视图未写 overScrollMode 与滚动条属性时按平台默认映射：越界效果仅在内容可滚时出现，列表网格的滚动条进页先亮再淡出

ID：`lesson-80dd4e626e1c207028e6` · 版本：3

[本主题](index.md)

## 何时使用

界面转换阶段，把 ScrollView/NestedScrollView（含对话框内的滚动区）、GridView/ListView 转换为 ArkUI Scroll、Grid、List 并设置边缘效果与滚动条时

## 适用情境

源 ScrollView/NestedScrollView、GridView/ListView 没有声明 overScrollMode（View.java 默认 OVER_SCROLL_IF_CONTENT_SCROLLS：内容可滚时才显示越界效果；该效果在 API 31 起的设备上为拉伸、更早为光晕，EdgeEffect.java）；映射参考只列显式 overScrollMode，且把 ifContentScrolls 与 always 都映射为不带选项的 EdgeEffect.Spring；目标 Scroll 默认 EdgeEffect.None，选项 alwaysEnabled 默认 true（scroll.d.ts），Grid 同样默认 EdgeEffect.None、滚动条 BarState.Auto（grid.d.ts）。源列表或网格显示时由 View.initialAwakenScrollBars 先亮滚动条（scrollBarDefaultDelayBeforeFade×4，ViewConfiguration 默认 300ms，即约 1.2s）再淡出，滚动时再出现。

## 原因

不写 edgeEffect 时 Scroll 没有越界效果；写成不带选项的效果，内容不满一屏也会触发。两者都与源端不同；映射参考没有“未声明即 IF_CONTENT_SCROLLS”的规则时，各页会分别落到这两种写法。ArkUI 滚动条默认 Auto，进页时不亮；源端列表进页先亮一段再淡出，留在目标默认值就少了这段提示。

## 做法

1. 效果类型选 EdgeEffect.Spring 或 EdgeEffect.Fade 由项目统一约定（源端是拉伸或光晕，都不是回弹），全应用一致；alwaysEnabled 按 overScrollMode 定：未写或 ifContentScrolls 写 { alwaysEnabled: false }，always 写 { alwaysEnabled: true }，never 写 EdgeEffect.None。对话框内的 Scroll、由 GridView/ListView 转来的 Grid、List 同样处理。
2. 源列表或网格会滚动时（按源端条目高×行数判断，不按规格“全可见”推测），显式设置滚动条：页面显示时先 BarState.On，按上述初始淡出延时切回 BarState.Auto；宽度与颜色取源主题滚动条 drawable（SDK platforms/android-XX/data/res 下主题的 scrollbarThumbVertical）或参照机实测。
