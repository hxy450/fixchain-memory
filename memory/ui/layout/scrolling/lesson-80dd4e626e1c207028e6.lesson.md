# ScrollView 未写 overScrollMode 时按 IF_CONTENT_SCROLLS 映射，边缘效果 alwaysEnabled 为 false

ID：`lesson-80dd4e626e1c207028e6` · 版本：2

[本主题](index.md)

## 何时使用

界面转换阶段，把 ScrollView/NestedScrollView（含对话框内的滚动区）转换为 ArkUI Scroll 并设置边缘效果时

## 适用情境

源 ScrollView/NestedScrollView 没有声明 overScrollMode（View.java 默认 OVER_SCROLL_IF_CONTENT_SCROLLS：内容可滚时才显示越界效果；该效果在 API 31 起的设备上为拉伸、更早为光晕，EdgeEffect.java）；映射参考只列显式 overScrollMode，且把 ifContentScrolls 与 always 都映射为不带选项的 EdgeEffect.Spring；目标 Scroll 默认 EdgeEffect.None，选项 alwaysEnabled 默认 true（scroll.d.ts）。

## 原因

不写 edgeEffect 时 Scroll 没有越界效果；写成不带选项的效果，内容不满一屏也会触发。两者都与源端不同；映射参考没有“未声明即 IF_CONTENT_SCROLLS”的规则时，各页会分别落到这两种写法。

## 做法

1. 效果类型选 EdgeEffect.Spring 或 EdgeEffect.Fade 由项目统一约定（源端是拉伸或光晕，都不是回弹），全应用一致；alwaysEnabled 按 overScrollMode 定：未写或 ifContentScrolls 写 { alwaysEnabled: false }，always 写 { alwaysEnabled: true }，never 写 EdgeEffect.None。对话框内的 Scroll 同样处理。
