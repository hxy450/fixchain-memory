# LazyListState.scrollToItem/animateScrollToItem 把目标项滚到可视区起始边：映射 scrollToIndex(index, smooth, ScrollAlign.START)，不自选居中；同一函数里的其他滚动副作用一并迁移

[本主题](index.md)

## 何时使用

界面实现阶段，把 Compose LazyListState 的程序滚动（scrollToItem、animateScrollToItem）翻译成 ArkUI Scroller.scrollToIndex 并选择对齐方式时

## 适用情境

源端调用 animateScrollToItem(index) 或 scrollToItem(index)（scrollOffset 默认 0），同一函数可能还折叠顶栏等；目标 List 绑定 Scroller，scrollToIndex 的 align 可选 START、CENTER、END、AUTO。

## 原因

Compose 的 scrollToItem/animateScrollToItem 把目标项的起始边对齐到视口起始边（再加 scrollOffset），没有居中语义；按观感选 CENTER 或 AUTO 会改变滚动后的可见内容。

## 做法

1. 映射为 scroller.scrollToIndex(index, 是否动画, ScrollAlign.START)：animateScrollToItem 用平滑滚动，scrollToItem 不加动画；源端传了 scrollOffset 时按当前 SDK 的偏移参数另行表达。
2. 同一函数里伴随的副作用（如折叠顶栏）一并迁移；规格决定不实现时登记为差异。
