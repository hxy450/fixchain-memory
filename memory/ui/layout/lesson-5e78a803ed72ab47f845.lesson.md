# 子页处在wrap_content宿主容器中时，按内容收拢match_parent栏与权重

ID：`lesson-5e78a803ed72ab47f845` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与界面实现阶段，为被Fragment或布局槽位承载的子页确定栏宽、权重和整体对齐时

## 适用情境

宿主container为wrap_content（常配一个weight=1的Space留白），子页根为match_parent，内含match_parent的顶栏/底栏或带layout_weight的横屏列。

## 原因

在wrap_content宿主中，子页的match_parent收拢为最宽的wrap_content子项，layout_weight没有余量可分；只照抄子页XML的100%宽或权重，栏会在全宽中居中或按比例拉开。

## 做法

1. 子页规格写明宿主的wrap_content约束及其效果：栏宽等于最宽内容子项（如自测尺寸的视图），整体按宿主父布局的默认方向贴边，横屏权重列只取内容宽。
2. 实现时栏宽取该内容子项的实测尺寸，不写100%或layoutWeight；整体对齐按宿主决定。
