# 下发 statusBarHeight 参数时禁止写「本页不使用」；浮层与同 Stack 兄弟层拿同一 inset

ID：`lesson-90838f5b7e407e7c2e44` · 版本：1

[本主题](index.md)

## 何时使用

派工与界面实现阶段，向子页或浮层下发 statusBarHeight 参数、或把 needs_immersive_safearea=false 的浮层挂进宿主页自窗口顶起的 Stack 时

## 适用情境

宿主页按沉浸式取真实 statusBarHeight 下发；子页 @Param 已接线；浮层（scrim + 居中卡片，fillMaxSize）与列表、顶栏同挂一个 Stack。

## 例外与边界

- 目标父容器已替子页加了顶部避让并有源码位置可引用

## 原因

派工把「接受 @Param statusBarHeight（本页不使用）」写进指令，converter 照办写出 `.padding(24)` 与未消费的参数——参数已接线却无人消费；浮层 slot 契约与派工词只给 onDismiss，三层里只有浮层没拿到偏移。

## 做法

1. 若认为无需消费，必须给出 Android 侧父容器已消费该 inset 的源码位置；否则实现者收到「接线但不用」的参数时先核目标父容器，没有替它避让就必须消费。
2. 浮层若挂在自窗口顶起的 Stack，slot 契约与派工词都带 statusBarHeight，@Param 透传、根节点 padding top，与兄弟层同口径。

## 检查

- grep 每个 @Param statusBarHeight 的消费点；对照 Android 截图/dump 核遮罩起点 y 与内容块居中区间。
