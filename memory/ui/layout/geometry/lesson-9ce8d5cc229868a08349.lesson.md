# 整数布局公式应保留源端单位域与取整次序

ID：`lesson-9ce8d5cc229868a08349` · 版本：2

[本主题](index.md)

## 何时使用

规格提取或界面实现阶段，把源端自定义测量中的整数除法、截断和余数分配迁移到目标端时

## 适用情境

源公式运行在整数像素约束和整数 placeable 尺寸上，目标输入可能来自浮点 vp 的区域回调或返回 px 的文本测量 API。

## 例外与边界

- 已证明目标输入始终为与源公式等价的整数单位，且取整位置不影响几何结果

## 原因

在 vp 浮点域提前取整再换算到 px，会改变商、余数和累计宽度；即使单槽误差很小，多槽排列也会留下空隙或整体偏移。

## 做法

1. 保留源公式每个输入与中间值的单位，以及换算、整数运算、截断的次序。
2. 源公式在整数 px 上执行 `floor(Wpx / n)` 时，目标输入若是 vp，就先按当前密度转成 px，沿源顺序计算，再将结果换回 vp；不要换成 `floor(Wvp / n)` 后再转 px。
3. 在参数或类型上表达单位，沿用当前工程命名约定；余数分配也按源公式处理，不只保留最后的除法。

## 可选检查

不因读取本条经验而额外启动验证流程；项目原有必需测试照常执行。
