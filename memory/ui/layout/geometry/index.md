  - 时机：规格提取或界面实现阶段，把源端自定义测量中的整数除法、截断和余数分配迁移到目标端时
  - 情境：源公式运行在整数像素约束和整数 placeable 尺寸上，目标输入可能来自浮点 vp 的区域回调或返回 px 的文本测量 API。
  - 例外：已证明目标输入始终为与源公式等价的整数单位，且取整位置不影响几何结果
