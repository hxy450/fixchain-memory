# 源端按另一控件的实际位置或尺寸计算的值（动画终点、按按钮宽缩放的缩略图），目标取该控件的实测边界，不用布局常量推导或借用其他用途的尺寸

ID：`lesson-7f56d221132ccbf09955` · 版本：1

[本主题](index.md)

## 何时使用

界面与覆盖层实现阶段，移植依赖其他控件运行时几何（getLeft/getTop/getWidth 等）的绘制终点或缩放尺寸时

## 适用情境

源端以目标控件实际 left/top/width/height 计算动画终点，或按某按钮宽度等比缩放生成缩略图；目标中同一控件的摆位与尺寸随模式或配置变化，实现者手边有布局规格推导值、统一按钮尺寸常量或服务另一用途的尺寸档（如媒体库缩略图档）。

## 例外与边界

- 被参照的控件在触发时刻会平移或节点被复用：在触发回调里即时取坐标，onAreaChange 缓存只作兜底

## 原因

布局推导值与常量只对应其中一种摆位，借用的尺寸档服务的是另一用途；换摆位、换设备后终点与缩放比例都偏离源端，编译与静态审查都看不出。

## 做法

1. 在被参照控件上用 onAreaChange（或即时查询组件位置）取得实测边界，经共享状态或门面注入消费方（Canvas 覆盖层、缩略图生成），再按源端公式计算终点或缩放尺寸。

来源支持：1 张卡 · 迁移数未记录 · 应用数未记录
