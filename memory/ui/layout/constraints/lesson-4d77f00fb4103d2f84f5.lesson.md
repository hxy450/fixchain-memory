# ConstraintLayout 标题栏（返回贴 start、0dp 标题居中、操作贴 end）转成互斥三槽 Row 或 RelativeContainer

ID：`lesson-4d77f00fb4103d2f84f5` · 版本：2

[本主题](index.md)

## 何时使用

界面实现阶段，把 ConstraintLayout 标题栏（左返回、居中标题、右侧操作）转换为 ArkUI，或抽取公共标题栏组件时

## 适用情境

源标题栏中返回图标 constraintStart_toStartOf=parent，右侧文字或图标 constraintEnd_toEndOf=parent，标题宽 0dp、两端约束到 parent 并带左右 margin；工程里可能已有同类页面的标题栏代码可以照搬，或要按规格把该 include 布局抽成公共组件。

## 原因

标题的左右 margin 就是两侧入口的保留宽度；用 Stack({ alignContent: Alignment.Center }) 叠放后只给返回图标加 .align(Alignment.Start)，图标仍落在中央、压在标题上，后写的页面与公共组件以它为模板会一起出错。

## 做法

1. 按约束建互斥的水平槽位：Row 内左侧固定宽槽（宽取标题的 marginStart）放返回入口，标题 layoutWeight(1) 并按源 gravity 居中，右侧固定槽（宽取标题的 marginEnd）放操作入口；也可用 RelativeContainer + alignRules 对应 start/end 约束。
2. 复用工程内已有页面的标题栏或抽公共组件前，先按当前源布局约束核对片段的定位方式；以规格指定的源布局为准，不以页面级旧实现为模板。

## 可选检查

- 同时打开返回与右侧入口并用较长标题预览，确认三者不重叠、标题在两侧槽位之间居中。
