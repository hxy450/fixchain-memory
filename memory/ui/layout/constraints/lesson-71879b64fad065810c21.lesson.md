# Compose weight(1f).wrapContentWidth(End) 靠尾端的文本，译为权重槽内尾端对齐，不只写 layoutWeight

ID：`lesson-71879b64fad065810c21` · 版本：1

[本主题](index.md)

## 何时使用

页面转换阶段，翻译 Compose Row 中以 Modifier.weight(1f).wrapContentWidth(Alignment.End) 靠右（尾端）的标签、金额等文本时

## 适用情境

源 Row 里某个文本以 weight(1f) 占剩余宽，再用 wrapContentWidth(Alignment.End) 让文本按自身宽度贴槽位尾端；目标准备写 layoutWeight(1) 或 flexGrow(1)。

## 原因

wrapContentWidth 放开最小宽约束，让内容按自身宽度测量，再在权重分到的槽位里按 align 对齐（foundation-layout Size.kt 对 wrapContentWidth 的说明）；ArkUI 只写 layoutWeight(1) 时 Text 撑满槽位、文字仍按起始边排，靠尾端的效果丢失。

## 做法

1. 单行文本写 layoutWeight(1) + textAlign(TextAlign.End)。
2. 可能折行的文本：源端文本框按内容宽贴槽位尾端、框内各行仍按 Text 自身的 textAlign（默认 Start）排；目标用 Row().layoutWeight(1).justifyContent(FlexAlign.End) 包住不设宽度的 Text，保留其 textAlign。
