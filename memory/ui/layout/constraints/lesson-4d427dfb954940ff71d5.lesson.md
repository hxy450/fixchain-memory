# 列表页空态按源布局定纵向位置：wrap_content 未居中的空态靠上，weight 剩余区里与列表叠放的空态在有界区域内居中

ID：`lesson-4d427dfb954940ff71d5` · 版本：2

[本主题](index.md)

## 何时使用

界面实现阶段，为列表页或剩余区域的空态（无数据提示）确定在内容区中的纵向位置时；参照工程已有空态 Builder 写新页空态时

## 适用情境

源空态容器可能是 layout_height=wrap_content 的 NestedScrollView/LinearLayout，在父 RelativeLayout 中未声明居中，内层 gravity=center；也可能是 layout_height=0dp + layout_weight=1 区域里与 RecyclerView 叠放、按数据显隐的 match_parent + gravity=center TextView。工程里可能已有全高居中的空态 Builder 可供参照。

## 原因

内层 gravity=center 只在空态容器自己的高度内排列子项；wrap_content 且未在父容器居中的空态容器按它在父布局中的定位靠上，不等于在整个内容区居中。空态放进 ArkUI Scroll 的内容 Column 后，它的 height('100%') 落在纵向不受约束的滚动内容里，无法在扣除固定区后的剩余区域居中。

## 做法

1. 先看空态容器自身的 layout_height 和它在父布局中的定位：wrap_content 且未在父容器居中的，按源顺序靠上放置（justifyContent(FlexAlign.Start)），不写 height('100%') + justifyContent(FlexAlign.Center)；写完把空态容器的高度、justifyContent 与源容器的高度和父布局约束逐项比对。
2. 源端 layout_height=0dp + layout_weight=1 区域里与列表叠放的 match_parent、gravity=center 空态，放进对应的 layoutWeight(1) 有界区域内居中（Stack 叠放，或按数据条件渲染一个 layoutWeight(1) + justifyContent(FlexAlign.Center) 的 Column），不放在 Scroll 内容里靠 height('100%') 居中。
3. 参照工程已有空态 Builder 时只复用样式骨架；文案、纵向位置和外边距按本页源布局确定。
