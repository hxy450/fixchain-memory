# BottomSheetBehavior 面板映射：容器可见性与面板状态分离，位于底栏之上的面板用布局内实现

ID：`lesson-9f45b5d79206b5654aff` · 版本：2

[本主题](index.md)

## 何时使用

界面实现与规格提取阶段，把由 BottomSheetBehavior 管理、初始收起的播放器等面板翻译为 ArkUI 壳布局与状态机时

## 适用情境

源面板由 BottomSheetBehavior（app:layout_behavior、behavior_peekHeight）管理，位于 CoordinatorLayout 内、底部导航之上；app:behavior_hideable 未设或为 false，且代码未调用 setHideable(true)；可见性方法只切换容器 VISIBLE/GONE；目标可选窗口级 bindSheet 或 Stack 加 translate。

## 例外与边界

- behavior_hideable=true 或代码调用 setHideable(true) 时，面板可进入 STATE_HIDDEN，按源端的 HIDDEN 状态及其出口实现

## 原因

把 Hidden 作为没有出口的初值、或用窗口级大尺寸 bindSheet 盖住底栏，会让迷你条永不出现、展开面板覆盖导航；把收起当作停播还会改变行为。容器可见性与面板状态是两个变量，隐藏容器不必然重置面板状态。

## 做法

1. 分开容器可见性与面板状态：面板初值取源端 setState 的值（未调用时为 STATE_COLLAPSED，Material 1.12.0 BottomSheetBehavior 构造时的默认 state）；容器隐藏后再显示、以及 STATE_HIDDEN 回调后面板状态如何变化，按源端 setState、setHideable 与显隐方法的实际调用实现，源端没有重置就保留原状态。
2. 位于底栏之上的面板用布局内 Stack 加 translate 实现 peek、展开、收起，不用窗口级 bindSheet；规格写明面板边界与“收起不等于停播”。
