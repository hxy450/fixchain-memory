# 并排 wrap_content 图片列先核源父测量约束：已确认随可用宽度分配时按固有宽度比例分列，高度用 aspectRatio

ID：`lesson-0618cdf331560d389f0e` · 版本：3

[本主题](index.md)

## 何时使用

界面实现阶段，把 match_parent 父行中并排的 wrap_content 图片列转换为 ArkUI Row/Column 并确定列宽时；修复“右侧顶满/被遮挡”时

## 适用情境

源布局在 match_parent 的水平 LinearLayout 中并排放置 wrap_content 图片列，列宽来自 drawable 固有尺寸与左右、列间 margin，其总和接近或超过常见手机屏宽；目标要在宽度不同的设备上与源截图对齐。

## 原因

来源记录将该 wrap_content 列解释为受父容器可用宽度约束；这不是所有测量模式、最小宽度下都不溢出的保证。照抄固有 dp 写成固定 width 后，固有宽与边距之和超过设备可用宽度，右列被推出屏幕。来源中两列固有需求加边距约 388dp，生成者把原本按屏宽分配的列改成固定宽并在中间夹 Blank；前两轮修复只挪边距，第三轮改为按固有宽比例分列、图片 aspectRatio 才解决。

## 做法

1. 先核源父测量模式、子项最小宽度与实际列宽，再把各列固有宽和水平 margin 与可用宽度比较；已确认源端随可用宽分配时，按固有宽度比例用 layoutWeight（或百分比）分列，margin 改为外层 padding 与 Row space。
2. 图片宽取 '100%'，高度用 aspectRatio(原图宽/高) 随分得的宽度缩放；不在固定宽度子项之间夹 Blank().layoutWeight(1) 充当对齐。
3. 修复溢出时先求固定宽度与边距之和，只移动边距位置不能消除固定宽度造成的溢出。
