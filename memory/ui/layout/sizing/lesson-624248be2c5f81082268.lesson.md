# 将图片内容缩放与组件尺寸约束分别落实：wrap_content + adjustViewBounds 的图片按位图像素比确定高度

ID：`lesson-624248be2c5f81082268` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，为图片组件确定宽高约束时；校准阶段处理图片比例、宽度类的不确定占位时

## 适用情境

源 ImageView 为 wrap_content + adjustViewBounds（可带 layout_constrainedWidth 与 bias），宽度受同行兄弟和边距约束，高度应随位图固有比例跟随；目标用 Row 内的 Image 承接。

## 例外与边界

- 当前父布局或明确的尺寸规则已给出图片盒的宽高，此时只需设置盒内缩放

## 原因

objectFit 只描述内容如何放进图片盒；只有 Contain 加宽度分配（layoutWeight）不能确定组件高度，固定 height 又不随宽度变化。把 layoutWeight + Contain 登记为 adjustViewBounds 的“等价”再留待校准，校准者以“需渲染测量”推迟，比例约束就一直缺失。

## 做法

1. 分开确定图片盒的宽高与盒内缩放：读位图像素尺寸与密度桶换算本征 vp 宽高；用 aspectRatio(像素宽/像素高) 让高度跟随分得的宽度，constraintSize({ maxWidth: 本征宽 }) 对应 wrap_content 的上限，layoutWeight 或父容器剩余空间对应 constrainedWidth；objectFit 按内容缩放需求另设。
2. 校准阶段处理这类占位时，用资源文件头（sips、PIL、webp 头）读像素尺寸并结合源 XML 计算约束，不推迟到视觉验证；改后读回完整的 Image 修饰链。
