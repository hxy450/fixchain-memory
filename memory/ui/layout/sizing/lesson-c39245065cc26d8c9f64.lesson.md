# 随选中进度收放的图标与文本位置：源端为 0 的间距按同一选中条件归零

ID：`lesson-c39245065cc26d8c9f64` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把源端自定义 Layout 中随动画进度收放的图标、文本位置公式翻成 ArkUI 属性时

## 适用情境

源端导航项等按 animationProgress 计算文本宽度（含其两侧间距），未选中时为 0、图标在槽内居中；目标用 Row 居中加 constraintSize、opacity、scale 折叠文本来模拟。

## 原因

目标端只把文本宽度折叠为 0、保留固定 padding 时，未选中项仍多占一段间距，图标偏离槽中心，偏移等于残留宽度的一半。无法确认的框架行为（如 constraintSize 是否钳住 padding）被当作“很小、不可感知”接受时，已算出的偏差会留到验收。

## 做法

1. 把随进度缩放的每个量逐项对应到目标属性；源端未选中时为 0 的部分（包括间距），目标 padding、margin、space 也按同一选中条件取 0，并与宽度、透明度同一动画收放。
2. 遇到不能确认的框架行为时改用不依赖它的写法；确需保留近似时在报告里给出偏移值与复验位置。

## 可选检查

- 按未选中态手算一次：图标中心偏移 = −(图标之后仍占位的宽度)/2，结果应为 0。
