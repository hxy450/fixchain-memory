# 区分 Material IconButton 的布局占位、背景实绘与触控范围：按所用 material3 版本的内部修饰链判定

ID：`lesson-b73a1ac8908f74856a02` · 版本：2

[本主题](index.md)

## 何时使用

规格提取或界面实现阶段，确定 Material 按钮及包装容器的尺寸与位置时

## 适用情境

源组件含调用处 Modifier.size/background 与库内部的最小交互尺寸规则（IconButton 在调用方修饰符之后再套 minimumInteractiveComponentSize），或只是由内容撑开的 Surface/Box（如图标撑开的圆钮）；ui 快照由源码合成、bounds 为空时，调用处 size 数值最容易被当成实绘尺寸。

## 例外与边界

- 当前组件或 CompositionLocal 明确关闭（LocalMinimumInteractiveComponentSize 设为 0.dp）或改写了最小交互尺寸时，不套默认最小尺寸

## 原因

minimumInteractiveComponentSize 只在 LocalMinimumInteractiveComponentSize 非 0 时生效，作用结果又取决于修饰符顺序；布局留位、背景实绘、图标尺寸与触控范围是不同的量。普通 Surface/Box 不会自动继承按钮的最小交互规则。

## 做法

1. 普通 Surface/Box 没设尺寸时按内容和实际修饰符确定大小，不因里面有图标就补上 Material 按钮的最小交互尺寸或自加边距。
2. IconButton 按所用 material3 版本的内部修饰链判定。material3 1.4.0 版本 IconButton.kt 为：调用方 modifier → minimumInteractiveComponentSize()（默认值 48dp）→ size(IconButtonDefaults.smallContainerSize()，40dp 容器) → clip(shape) → background(容器色) → clickable；其他版本从对应 sources jar 读同一段。
3. 据此分别取三个量：布局占位 = 调用处 size（父级按它排布）；调用处 size 之后写的 background 按最小交互尺寸扩大后的盒、以槽位中心为圆心绘制；图标尺寸取 content 中 Icon 的 size（material3 1.4.0 版本 Icon 默认值 24dp）。
4. 目标需要背景围绕原中心扩大时，保持槽位中心并按差值补偿位置（外边距各减差值的一半）；规格以中心而非左上角描述位置，记录实际尺寸来源。

## 可选检查

- 仅当当前库配置或修饰符顺序不足以确定背景尺寸时，查看该组件局部实现或复用已有布局 dump、截图；无需遍历全部按钮。
