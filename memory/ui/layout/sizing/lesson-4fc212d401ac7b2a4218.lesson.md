# 网格里跨列数不同的卡片要同行等高时，用实际列宽与留边推导宽卡比例；组件自身的原生宽高比只用于卡内内容缩放

ID：`lesson-4fc212d401ac7b2a4218` · 版本：2

[本主题](index.md)

## 何时使用

列表或首页网格的界面实现阶段，为不同尺寸规格（如 2x2、4x2）的卡片确定外框高度或 aspectRatio 时

## 适用情境

源网格按规格分配 span（窄卡占 n 列、宽卡占 2n 列），卡片两侧有固定内边距或网格留边；参考截图里同一行的窄卡与宽卡外框等高；目标用百分比列宽加 aspectRatio 决定卡片高度，手头有组件自身的原生尺寸定义（取自对应资源或尺寸常量）。

## 例外与边界

- 源端或参考截图里不同规格的卡片本就按各自原生比例显示、不等高

## 原因

aspectRatio 作用在含内边距的外框上，宽卡外框也不是窄卡外框宽的整两倍；把组件原生比例直接当外框比例，宽卡与窄卡外框高度不等，同行不再对齐，且差值随屏宽变化。

## 做法

1. 先确定可见约束（同行等高），再按实际网格宽度推导：由 onAreaChange 取网格视口宽、扣除列表留边得到列宽；设窄卡外框宽 Wn、宽卡外框宽 Ww（各自扣除自身留边后的实际外框）、同行共同高度 H，各卡 aspectRatio = 外框宽 / H，即宽卡 aspectRatio = Ww / 窄卡外框高。H 由窄卡的源比例确定，例：窄卡外框为正方形且两侧留边合计 p 时，H = 列宽 − p，宽卡 aspectRatio = (2·列宽 − p)/(列宽 − p)；padding 属于外框内侧还是外侧按源布局确定。
2. 组件的原生宽高只用于卡片内部内容的缩放与定位，不作为网格单元的 aspectRatio。

## 可选检查

- 对比例有疑问时，用两种视口宽度（例如 360vp 与 392vp）代入列宽、内边距与 aspectRatio，算出窄卡与宽卡外框高度是否相等。
