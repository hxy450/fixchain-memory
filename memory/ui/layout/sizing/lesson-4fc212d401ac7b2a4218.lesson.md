# 网格里跨列数不同的卡片要同行等高时，用实际列宽与留边推导宽卡比例；组件自身的原生宽高比只用于卡内内容缩放

ID：`lesson-4fc212d401ac7b2a4218` · 版本：1

[本主题](index.md)

## 何时使用

列表或首页网格的界面实现阶段，为不同尺寸规格（如 2x2、4x2）的卡片确定外框高度或 aspectRatio 时

## 适用情境

源网格按规格分配 span（窄卡占 n 列、宽卡占 2n 列），卡片两侧有固定内边距或网格留边；参考截图里同一行的窄卡与宽卡外框等高；目标用百分比列宽加 aspectRatio 决定卡片高度，手头有组件自身的原生尺寸表（如 334.75×158）。

## 例外与边界

- 源端或参考截图里不同规格的卡片本就按各自原生比例显示、不等高

## 原因

aspectRatio 作用在含内边距的外框上，宽卡也不是窄卡内容宽的整两倍；把组件原生比例直接当外框比例，宽卡高度约为 (2·列宽 − 留边)/原生比，小于窄卡的 (列宽 − 留边)，同行不再对齐，且差值随屏宽变化。

## 做法

1. 先确定可见约束（同行等高），再按实际网格宽度推导：由 onAreaChange 取网格视口宽、扣除列表留边得到列宽，以窄卡内容宽为基准算宽卡比例，例如两侧内边距合计 p 时宽卡 aspectRatio = (2·列宽 − p)/(列宽 − p)，两者高度都等于列宽 − p。
2. 组件的原生宽高只用于卡片内部内容的缩放与定位，不作为网格单元的 aspectRatio。

## 可选检查

- 对比例有疑问时，用两种视口宽度（如 360vp、392vp）代入列宽、内边距与 aspectRatio，算出窄卡与宽卡外框高度是否相等。
