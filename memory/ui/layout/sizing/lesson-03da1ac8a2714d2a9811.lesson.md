# 调整包裹 Canvas 自绘组件的容器高度、裁剪或折叠范围时，与绘制端的行高等尺寸引用同一常量同步修改

ID：`lesson-03da1ac8a2714d2a9811` · 版本：1

[本主题](index.md)

## 何时使用

视觉修复或界面实现阶段，按差异单调整包裹自绘组件（Canvas 日历、图表等）的外层容器高度、clip 范围或折叠距离时

## 适用情境

自绘组件按固定行高等常量绘制，外层容器用“行数 × 行高 + 固定区”一类公式计算高度并 clip(true)，同一行高还决定上滑折叠的距离范围；差异单可能只给出“行高更大、下方内容被下推”的文字描述。

## 原因

外层高度、裁剪与折叠范围若独立于实际绘制尺寸修改，绘制内容会被截断，下方面板看起来盖住组件，偏差还随行数变化；拖动折叠的距离与进度映射也与实际行高失配。

## 做法

1. 改容器前先定位实际绘制尺寸的来源（如 Canvas 组件里的行高常量），再读源布局对应的尺寸资源（如 dimens 中的 item 高度）；外层容器高度、clip 范围与折叠距离引用同一常量同步修改，不单独压缩外层容器。
2. 源端与目标的行高已一致时，回头复核差异单的成因（截图密度、视口、安全区），不压缩行高迎合截图。

## 可选检查

- 改动带 clip 的自绘容器后，用行数不同的数据（例如 5 行与 6 行的月份）及折叠中间态截图，核对末行完整、相邻面板不遮挡。
