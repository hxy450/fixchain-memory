# “父尺寸减边距”或“扣除兄弟后的剩余空间”不写成 '100%'：match_parent/0dp 加同轴 margin 改用容器 padding 或 calc，Column 中占剩余高度的内容区用 layoutWeight(1)，等权重兄弟的间距改用 space

ID：`lesson-75f4743dff663f50966b` · 版本：7

[本主题](index.md)

## 何时使用

界面实现阶段，把 match_parent 或两侧约束 0dp 且带同轴 margin 的视图、或带 margin 的等权重兄弟翻译成 ArkUI 尺寸与间距时；按要求调整左右边距时；为 Compose Column 中排在搜索栏、分隔线等固定高度节点之后、占满剩余高度的内容区确定高度时；宿主页在固定标题栏下嵌入根节点为 height('100%') 的面板或弹层组件时

## 适用情境

源元素 match_parent（或约束到父两侧的 0dp）同时设 layout_marginHorizontal/Start/End 或 marginTop/Bottom；或水平 LinearLayout 中等权重（0dp + weight）的子项以 marginStart 作间距；目标用 width/height('100%') 或 layoutWeight。也包括 Compose Column 里内容区排在固定高度兄弟之后，靠 fillMaxSize、weight 或 Lazy 列表默认行为占满剩余高度，可能有空结果、加载、结果等多个状态分支。 也包括宿主页 Column 顶部有固定高度标题栏，下方直接放根节点 height('100%')、自带标题行与底部按钮栏的筛选面板；对应 Android 以 MATCH_PARENT 的 PopupWindow showAsDropDown(标题栏) 弹出，只占锚点以下的高度。

## 原因

Android 中这类元素的尺寸是父尺寸减去同轴边距，权重也在扣除 margin 后分配；ArkUI 的百分比尺寸按父尺寸计算、margin 再向外扩，layoutWeight 的份额也包含子项自身 margin。结果是横向右溢（没有右边距、行尾截断、贴屏）、纵向在 Stack 中超高并被默认居中顶穿、等权重卡片不等宽。映射参考只做逐属性对应、没有这条规则时，多个页面会重复同一偏差；用户要求加大边距时改子项 margin，溢出会更明显。又一应用的首页统计卡同样由 match_parent + 左右 18dp 写成 width('100%') 加左右 margin，修复改为 calc(100% - 36vp)。再一应用的计算器页，显示卡片与键盘同样写成 width('100%') 加左右 15 的 margin、按键 height('100%') 加上下 margin，真机上贴边且行间无留白，修复改为按比例宽居中与 calc(100% - 14vp)。Compose 测量 Column 中的 fillMaxSize 子项时，可用高度已扣除先测的兄弟；ArkUI height('100%') 取父容器全高，会多出兄弟的高度而溢出到底栏之下。 子组件根节点的 '100%' 取父容器全高，再叠上固定标题栏就超出窗口，底部按钮被挤出屏幕。另一应用的标签筛选面板如此：宿主写者已读到源端锚在标题栏下的弹出方式，后来也读到面板根节点是 height('100%')，仍保持标题栏加面板的 Column。

## 做法

1. 同轴有 margin 时，把边距放到父容器或新增包装容器的 padding 上，子项只保留 '100%'；父级还有需要贴边的兄弟时，用包装容器、layoutWeight 或 calc(100% - 边距之和)。
2. Stack 叠层中 match_parent 加纵向 margin 的层，用外包容器的 padding 承接内缩，内层 '100%' 相对其内容区。
3. 等权重兄弟以 margin 作间距时，删掉 margin，改用父 Row/Column 的 space（或固定宽的 Blank），让 layoutWeight 只分配扣除间距后的空间。
4. 写完 grep 同一修饰链里 width/height('100%') 与同轴 margin 的组合；意识到这条规则后把同页的按钮、卡片、列表行一起改；按要求加大边距时改容器 padding 的数值。
5. Column 中占剩余高度的内容区写成一个 .layoutWeight(1) 容器，各状态分支都放在这一层里，分支自身不写 height('100%')；规划过这层包裹容器时，写完回看 build() 确认它确实写出。规格里写“占某元素之后的剩余高度”，不写“全屏”。
6. 嵌入自带标题行与底栏、根节点为 height('100%') 的面板时，先读组件根尺寸声明，不在同一 Column 里再给它叠固定高度兄弟：给面板槽位 layoutWeight(1) 或外包有界容器，或放到外层 Stack 作覆盖层并去掉重复标题。源端 MATCH_PARENT + showAsDropDown(锚点) 对应锚点以下的剩余高度，不译成相对整页的 '100%'。并行拆分面板与宿主时，交接写明尺寸契约（面板满高、由宿主分配有界区域）。

## 可选检查

- 用布局 dump 或截图核对左右间距对称、右缘不越出父容器、等权重项宽度相等。
- 带底部操作栏的弹层打开最长内容态，核对底栏下边界不越出可视区、按钮可点。
