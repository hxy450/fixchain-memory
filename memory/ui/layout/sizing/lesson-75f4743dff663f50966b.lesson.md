# match_parent/0dp 加同轴 margin、或以 margin 作间距的等权重兄弟：边距移到父 padding、calc 或 space

ID：`lesson-75f4743dff663f50966b` · 版本：11

[本主题](index.md)

## 何时使用

界面实现阶段，把 match_parent 或两侧约束 0dp 且带同轴 margin 的视图、带 margin 的等权重兄弟（0dp + layout_weight）或 RecyclerView 项偏移翻译成 ArkUI 尺寸与间距时；按要求调整左右边距时

## 适用情境

源元素 match_parent（或约束到父两侧的 0dp）同时设 layout_marginHorizontal/Start/End 或 marginTop/Bottom；水平 LinearLayout 中等权重的子项以 marginStart 作间距；wrap_content 加 minWidth 实际占满可用宽；RecyclerView 用 ItemDecoration.getItemOffsets 给项留间距。目标用 width/height('100%')、layoutWeight 或容器 margin。

## 例外与边界

- 元素要占满的是扣除固定高度兄弟后的剩余区域，或是被宿主嵌入的满高组件时，按宿主有界槽位的规则处理

## 原因

Android 中这类元素的尺寸是父尺寸减去同轴边距，权重也在扣除 margin 后分配；ArkUI 的百分比尺寸按父尺寸计算、margin 再向外扩，layoutWeight 的份额也包含子项自身 margin。结果是横向右溢（没有右边距、行尾截断、贴屏）、纵向在 Stack 中超高并被默认居中顶穿、等权重卡片不等宽。用户要求加大边距时改子项 margin，溢出会更明显。

## 做法

1. 同轴有 margin 时，把边距放到父容器或新增包装容器的 padding 上，子项只保留 '100%'；父级还有需要贴边的兄弟时，用包装容器、layoutWeight 或 calc(100% - 边距之和)，边距之和由当前 XML margin 或 Compose 修饰符相加得到。
2. Stack 叠层中 match_parent 加纵向 margin 的层，用外包容器的 padding 承接内缩，内层 '100%' 相对其内容区。
3. 等权重兄弟以 margin 作间距时，删掉 margin，改用父 Row/Column 的 space（或固定宽的 Blank），让 layoutWeight 只分配扣除间距后的空间；写后按 (容器宽 − 间距)/权重和 核对各项宽度相等。
4. RecyclerView 用 ItemDecoration.getItemOffsets 给出的项偏移是列表内部间距：读出它给外缘与项间的偏移，落到容器 padding 或网格 gap，不转成容器外 margin。
5. 写完检索同一修饰链里 width/height('100%') 与同轴 margin 的组合；意识到这条规则后把同页的按钮、卡片、列表行一起改；按要求加大边距时改容器 padding 的数值。

## 可选检查

- 用布局 dump 或截图核对左右间距对称、右缘不越出父容器、等权重项宽度相等。
