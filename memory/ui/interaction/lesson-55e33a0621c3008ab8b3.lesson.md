# 迁移带点击绑定的控件时按源点击处理器的分支逐项迁移副作用，不只做状态取反和换图

ID：`lesson-55e33a0621c3008ab8b3` · 版本：3

[本主题](index.md)

## 何时使用

界面迁移阶段，为布局中带 onClick 绑定、状态选图或滑动面板的控件编写 ArkUI 事件与状态逻辑时

## 适用情境

源布局控件用 android:onClick/数据绑定声明点击，或按 ViewModel 状态选图；实际行为（按键音、振动、偏好持久化、历史面板展开与回填）写在 Fragment 统一点击处理器、ViewModel 或第三方面板组件中；目标页需复刻这些开关与面板。 也包括源端 ViewModel 的选择与写操作（再次点击同一项即取消、前置为空即失败、同商品同规格累加写入本地购物车）由页面弹层触发。

## 原因

布局只说明控件可点和怎样换图，副作用写在处理器里；只迁外观的开关会切换图标却没有功能，下拉指示图被当成静态装饰。来源中生成者补读到完整点击处理器（切换并持久化开关、按键播放对应音频、振动 50ms、历史面板初始化与回填），输出仍只有取反换图，交付汇报只列“两个模式图标”“下拉指示图”；随后用户多轮反馈无声、无振动、下拉无功能。另一应用中，复刻隐私弹窗的会话读到同意区先 setChecked(true, true) 播放勾选动画、postDelayed 700ms 再回调，却只画了静态未选中外观、点击直接跳转；它为避免写入授权状态没有在真机点同意，这条路径直到用户反馈才暴露。 另一应用的详情页写者读到 ViewModel 的取消选择与累加写入逻辑，仍只写直接赋值选中，确认分支只弹“已加入购物车”而不写任何存储，完成汇报也未说明。

## 做法

1. 对每个声明了点击或状态绑定的控件，在统一点击处理器（when 分支）与 ViewModel 找到对应分支，列出副作用（播放哪些音频、振动时长、写哪个偏好键、打开哪个面板）后再写 onClick；未迁移的副作用在报告中逐项列为缺口。
2. 源码读取被截断时，按控件 id 或状态名补读被截断段；补读到的行为逐条落实，不只同步默认值或命名。
3. 滑动面板、历史列表一类组件的展开、收起与数据回填按交互迁移，与规格中的相应验收项对应实现。
4. 迁移按键音与振动时，从源端 assets 定位实际音频复制到 rawfile，用媒体类音频流播放并在加载完成后才允许播放；振动声明 ohos.permission.VIBRATE，实际震感还受系统触感反馈设置影响。
5. 同意、确认类点击若先切换状态并播放动画、再延时回调（setChecked(true, true) → postDelayed），目标按“切到选中态 → 可取消的延时（取源码数值）→ 回调”实现，延时期间屏蔽重复点击，页面销毁时清理定时器；源码中直接回调的分支保持不延时。
6. 写操作类点击（加入购物车、收藏、保存）先落到下游页面可读取的状态或存储，再给成功提示；本轮不实现写入时，提示与完成汇报都写明“未写入”，不输出成功提示。同项再点取消、前置校验失败等状态转换逐条列入实现清单，并对照代码分支。
