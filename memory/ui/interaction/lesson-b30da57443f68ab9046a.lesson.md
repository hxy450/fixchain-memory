# 作拖拽柄或自绘手势起点的 Image 写 .draggable(false)：ArkUI Image 默认可系统拖拽，长按会接管输入

ID：`lesson-b30da57443f68ab9046a` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，在 Image 上挂 onTouch、PanGesture 实现拖拽柄、按下即起拖或其他自绘手势时

## 适用情境

源端 ImageView 作拖拽柄（OnTouchListener 在 ACTION_DOWN 即开始拖动），没有长按触发的系统拖拽；目标用 Image + onTouch 或 priorityGesture(PanGesture) 承接。

## 原因

ArkUI Image 默认可拖拽，长按后系统图片拖拽接管输入，自绘手势收到 Cancel，状态停在中途（如被拖条目保持隐藏）；源端 ImageView 没有这一默认行为。

## 做法

1. 作拖拽柄、按钮或手势起点的 Image 都写 .draggable(false)；工程同类页面已有该写法时照用。
