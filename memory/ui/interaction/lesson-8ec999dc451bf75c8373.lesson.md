# 安卓点击与触外取消按抬起判定实现，不直接映射为onClick

ID：`lesson-8ec999dc451bf75c8373` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与界面实现阶段，把setOnClickListener按钮、遮罩点按和对话框触外取消映射为ArkUI事件时

## 适用情境

源按钮用setOnClickListener（由View.onTouchEvent在抬起时判定），对话框依赖默认触外取消；目标准备用组件或遮罩的onClick。

## 例外与边界

- 产品明确接受按住超过约800ms不触发的差异

## 原因

安卓点击只要抬起时仍在控件内（外扩touch slop）就触发，与按住时长无关；ArkUI点击手势按住超过约800ms不触发。安卓触外取消只看抬起点是否落在窗口（可见面板外扩背景内缩）外再加slop，不限时长。直接用onClick，长按和拖动后的结果会与源端不同。

## 做法

1. 规格把交互契约写成“抬起触发”，并写出触外取消的判定规则；不把OnClickListener到onClick标为直接映射。
2. 实现一个可复用的抬起判定：Down进入按下态，移出组件外扩slop即取消，Up时仍按下才执行回调并停止冒泡；按下态切图与点击共用这一状态。
3. 遮罩用onTouch在Up时按抬起点与面板区域（含内缩与slop）判断是否取消；抽屉遮罩按按下到抬起的位移小于slop判定点按。

## 可选检查

- 两端各做按住1.5秒松手、按下后拖出控件松手、面板外不同距离点按，对比结果
