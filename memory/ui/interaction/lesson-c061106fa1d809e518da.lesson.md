# 接入已有专页时逐项兑现它的 @Event 回调契约：要求回传会话或结果的回调给出真实值或交父页分派，不用空值短路专页自带的导航

ID：`lesson-c061106fa1d809e518da` · 版本：3

[本主题](index.md)

## 何时使用

界面实现阶段，把源端编辑项 Fragment 对应的现有 ArkTS 专页接入容器、实现专页回调时

## 适用情境

源端工厂按 type 把同类数据分到不同 Fragment（如编辑页与选择页）；目标已有专页，经 @Event 要求父层回传会话或结果（回调参数里带 onReady 一类回调）再由专页自行导航，父容器里已有一个可复用的通用入口。

## 原因

用通用入口实现专页回调、再回传空值，会让专页按“没有会话”跳过它自带的导航，等于用旧路径覆盖了专页契约；不同 type 被合并到同一处理后，源端的去向区别也一并丢失。

## 做法

1. 逐项实现专页声明的 @Event：回调要求回传会话或结果时给出真实值，或新增事件交给能读到节点数据的父页分派；源工厂分开的类型各自保留去向，按节点属性分派时把相关标志原样透传给目标页，不写死为默认值。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
