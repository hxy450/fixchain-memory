# 源端用键盘或遥控逐行逐项导航弹层与面板时，行/项选择与展开态放进可观察模型由按键处理层驱动，不存在组件 @Local

ID：`lesson-583f996e5a7bad4f5735` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与菜单、弹层、参数面板实现阶段，迁移源端遥控或键盘导航模式（方向键在行间移动、确认键选中、行与项高亮）并确定选择态归属时

## 适用情境

源端以遥控模式一类状态在按键回调里调用 processRemoteUp/Down、commandMenu* 与 init*ForRemote 等方法，逐行、逐项高亮弹层与曝光面板并跳过不可见行；BLE 遥控与键盘共用这套导航。目标弹层把当前行索引、展开态写在组件 @Local 或不可观察的普通类里，按键分发与面板分属不同文件或 feature。

## 原因

选择与展开态只存在组件内部时，按键处理层读不到也改不了，遥控导航只能退化成开关弹层或回落到其他动作；行导航状态机分散在按键分发与面板两处，按 feature 拆分后双方都以为由对方实现。

## 做法

1. 规格阶段把遥控/键盘导航单列验收：进入条件、行序与跳过不可见行、上下移动、确认选中、高亮样式与退出，并在对接点写明状态机归哪一方。
2. 实现时把模式标志、当前行、当前项与展开态放进可观察模型（@ObservedV2/@Trace），由按键处理层的上/下/确认方法修改；面板组件只读模型渲染高亮并滚动到可见，不在组件 @Local 另存一份选择态。
3. 按源端按键分发表逐键映射：导航模式下方向键走行导航，不并入打开或关闭弹层的分支；遥控模式下确认键先走菜单命令。做不完的部分登记带负责方的移交项。
