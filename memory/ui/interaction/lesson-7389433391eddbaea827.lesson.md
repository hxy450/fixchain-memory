# Image 作拖拽柄或按钮并自绘触摸拖拽时设 draggable(false)：ArkUI Image 默认可被系统拖出，长按会接管输入

ID：`lesson-7389433391eddbaea827` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，用 Image 承载拖拽柄、按钮或可点图标，并在其上挂 onTouch、PanGesture 等自绘拖拽或按压逻辑时

## 适用情境

源端在 ACTION_DOWN 或 onTouch 中立即开始自定义拖拽（如清单条目拖拽排序），或图标只是点击按钮；目标用 Image 组件实现，未设置 draggable。

## 例外与边界

- 源端本就允许把图片拖出到其他位置或应用时保留系统拖拽

## 原因

ArkUI 的 Image 默认可拖出：长按后系统图片拖拽接管输入，自绘的 onTouch、PanGesture 收到 Cancel，按下时已隐藏的条目或拖拽阴影停在中间态；Android ImageView 没有这种默认拖拽。

## 做法

1. 作拖拽柄、按钮或图标使用的 Image 写 .draggable(false)，再挂自绘的 onTouch 或手势；源端只在按下时起拖、没有长按分支的，目标也不保留长按触发的系统拖拽。
