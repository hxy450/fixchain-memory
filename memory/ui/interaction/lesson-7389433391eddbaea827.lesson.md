# Image 承载点击/长按按钮或自绘拖拽柄时设 draggable(false)：ArkUI Image 默认可被系统拖出，按住会进入拖拽并接管输入

ID：`lesson-7389433391eddbaea827` · 版本：2

[本主题](index.md)

## 何时使用

界面实现阶段，用 Image 承载按钮、可点图标或拖拽柄时：在 Image 或其外层 Stack/Button 上挂 onClick、长按手势，或在其上挂 onTouch、PanGesture 等自绘拖拽或按压逻辑时

## 适用情境

源端在 ACTION_DOWN 或 onTouch 中立即开始自定义拖拽（如清单条目拖拽排序），或图标只是点击、长按按钮（ImageButton/可点 ImageView，如快门、缩略图入口、屏上开关图标），没有任何拖放行为；目标用 Image 组件实现（可外包挂点击的 Stack/Button），未设置 draggable。

## 例外与边界

- 源端本就允许把图片拖出到其他位置或应用时保留系统拖拽

## 原因

ArkUI 的 Image 默认可拖出（API 10 起 Image 自身的 draggable 默认为 true，与通用属性的默认值不同）：按住后系统图片拖拽接管输入，自绘的 onTouch、PanGesture 收到 Cancel，按下时已隐藏的条目或拖拽阴影停在中间态；只挂点击或长按的图标按钮也会进入拖拽识别与拖拽预览，点击响应卡顿，外层 Stack/Button 上的点击不会关闭子 Image 的默认拖拽。Android ImageView/ImageButton 没有这种默认拖拽。

## 做法

1. 作按钮、可点图标或拖拽柄使用的 Image 写 .draggable(false)：点击或长按挂在外层 Stack/Button 上时也写在内层每个 Image 上，再挂自绘的 onTouch 或手势时同样先关闭；源端只在按下时起拖、没有长按分支的，目标也不保留长按触发的系统拖拽。
