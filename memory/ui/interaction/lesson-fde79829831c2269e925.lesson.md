# Compose clickable、toggleable、Card(onClick) 自带的按压指示在 ArkUI onClick 上不会自动出现：用 stateStyles 的 pressed 态补状态层，不可点击时不显示

ID：`lesson-fde79829831c2269e925` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把带 Modifier.clickable/toggleable/selectable，或 Card、Surface(onClick) 的 Compose 容器转成挂 onClick 的 ArkUI 容器时

## 适用情境

源端容器经 clickable/toggleable（可带 role = Button、Switch）或 Card/Surface(onClick) 响应点击，没有把 indication 设为 null，按压时由主题提供涟漪或状态层；目标用 Column/Row/Stack 加 .onClick 实现，ArkUI 通用容器默认没有按压反馈（Button 自带的按压效果除外）。

## 例外与边界

- 源端显式 indication = null 或自定义 indication 时，按源端写法处理
- 目标用自带按压效果的 Button 承载点击时，不再叠加

## 原因

Compose 的点击修饰符默认带按压指示，调用处看不到任何反馈代码；只翻译 onClick 时点击可用但按压没有反馈，编译与结构检查都发现不了。

## 做法

1. 在承载点击的同一容器上加 stateStyles({ pressed: ... })，按压时叠加以该处内容色为底的半透明状态层（来源修复按 Material3 取约 10% 不透明度），叠层随容器圆角裁剪；纯色背景也可预混成按压色。
2. 按源端 enabled 条件决定是否出现：clickable/toggleable 的 enabled 为假时（如内容不足、无可展开项）既不响应点击也不显示按压态。
