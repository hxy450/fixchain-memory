# 源端可点击容器自带的按压反馈（Compose clickable、Card(onClick)，View 体系主题 listSelector 的列表行）在 ArkUI onClick 上不会自动出现：用通用属性 stateStyles 的 pressed 态补状态层（stateEffect 只属于 Button），不可点击时不显示；View 体系列表选择器按压色作底色画在内容下，不用 opacity 代替

ID：`lesson-fde79829831c2269e925` · 版本：3

[本主题](index.md)

## 何时使用

界面实现阶段，把带 Modifier.clickable/toggleable/selectable，或 Card、Surface(onClick) 的 Compose 容器转成挂 onClick 的 ArkUI 容器时；把 ListView、PreferenceActivity 中由主题 listSelector 提供按压态的可点击行转成 ArkUI 列表行时；把 GridView 条目转成 Grid/GridItem 时

## 适用情境

源端容器经 clickable/toggleable（可带 role = Button、Switch）或 Card/Surface(onClick) 响应点击，没有把 indication 设为 null，按压时由主题提供涟漪或状态层；目标用 Column/Row/Stack 加 .onClick 实现，ArkUI 通用容器默认没有按压反馈（Button 自带的按压效果除外）。 也包括 View 体系的 ListView、PreferenceActivity 行没有把 background 或 listSelector 设为 null，按压态由主题选择器（如 Holo 暗色 list_selector_holo_dark）提供；写者在 d.ts 里找不到通用容器的 stateEffect，就放弃了按压态。 也包括 GridView 条目：GridView 未改写 listSelector 与 drawSelectorOnTop，Activity 主题分散在 res/values 与 values-v11/v14 等多个 styles.xml，低 minSdk 的旧工程在新设备上走 values-v11+ 的 Holo 父主题。

## 例外与边界

- 源端显式 indication = null 或自定义 indication 时，按源端写法处理
- 目标用自带按压效果的 Button 承载点击时，不再叠加

## 原因

Compose 的点击修饰符默认带按压指示，调用处看不到任何反馈代码；只翻译 onClick 时点击可用但按压没有反馈，编译与结构检查都发现不了。stateEffect 只是 Button 的属性，通用容器的按压态要用 stateStyles 或 onTouch 状态驱动；以“查不到 stateEffect”为由省略，按压反馈整体缺失。 AbsListView（ListView、GridView）的 drawSelectorOnTop 默认 false（本机 android-36.1 源码 AbsListView.java），选择器的按压色画在条目内容下面，图标与文字像素不变；用 opacity 整体变暗会连内容一起变淡。只看 res/values 会认错主题代际：同名主题在 values-v11/v14 常改为继承 Theme.Holo，低 minSdk 不等于老式 list_selector_background。

## 做法

1. 在承载点击的同一容器上加通用属性 stateStyles({ pressed: ... })（任何容器可用；stateEffect 只属于 Button，查不到它不是省略按压态的理由），按压时叠加状态层：Compose 源按 Material3 取约 10% 的内容色，View 体系按源主题 listSelector 的实际按压色（如 Holo 暗色 #40CCCCCC）；叠层随容器圆角裁剪，纯色背景也可预混成按压色。 View 体系列表与网格的状态层是底色：选择器画在条目内容下面（drawSelectorOnTop 默认 false），pressed 态写 backgroundColor、normal 透明，不用 opacity、整体变暗或盖在内容上的叠层代替。取色前按设备 API 沿 res/values-vNN/styles.xml 找 Activity 主题的 parent 链确认主题代际，再从 SDK platforms/android-<api>/data/res 下该主题 listSelector 指向的 drawable 取按压色；取不到时在报告里写明缺口，不以 opacity 兜底。
2. 按源端 enabled 条件决定是否出现：clickable/toggleable 的 enabled 为假时（如内容不足、无可展开项）既不响应点击也不显示按压态。
