# 源端点击容器或列表行自带的按压反馈用 stateStyles 补：View 体系列表按 listSelector 取色画在内容下方，不用 opacity

ID：`lesson-fde79829831c2269e925` · 版本：6

[本主题](index.md)

## 何时使用

界面实现阶段，把带 Modifier.clickable/toggleable/selectable，或 Card、Surface(onClick) 的 Compose 容器转成挂 onClick 的 ArkUI 容器时；把 ListView、GridView、PreferenceActivity 中由主题 listSelector 提供按压态的可点击行或格子转成 ArkUI 列表行或网格项时

## 适用情境

源端容器经 clickable/toggleable（可带 role = Button、Switch）或 Card/Surface(onClick) 响应点击，没有把 indication 设为 null，按压时由主题提供涟漪或状态层；目标用 Column/Row/Stack 加 .onClick 实现，ArkUI 通用容器默认没有按压反馈（Button 自带的按压效果除外）。 也包括 View 体系的 ListView、GridView、PreferenceActivity 行没有把 background 或 listSelector 设为 null，按压态由主题选择器（如 Holo 暗色 list_selector_holo_dark）提供，主题代际要按 res/values-vNN 的 parent 链判断；写者在 d.ts 里找不到通用容器的 stateEffect 就放弃按压态，或取不到颜色就改用 opacity 整体变暗。

## 例外与边界

- 源端显式 indication = null 或自定义 indication 时，按源端写法处理
- 目标用自带按压效果的 Button 承载点击时，不再叠加

## 原因

Compose 的点击修饰符默认带按压指示，View 体系由主题 listSelector 提供按压态，调用处都看不到反馈代码；只翻译 onClick 时点击可用但按压没有反馈，编译与结构检查都发现不了。stateEffect 只是 Button 的属性，通用容器的按压态要用 stateStyles 或 onTouch 状态驱动；以“查不到 stateEffect”为由省略，按压反馈整体缺失。View 体系的列表选择器画在条目内容下面，用 opacity 整体变暗会连图标与文字像素一起改变。

## 做法

1. 先核源端按压反馈的实际来源：Compose 调用点的 indication、LocalIndication 与 Ripple 配置是否被覆盖；View 体系的 background、listSelector 是否被应用主题或布局改写。View 体系按设备 API 取 res/values-vNN/styles.xml 中 Activity 主题的 parent 链确认主题代际（values-v11/v14 常把同名主题改为继承 Theme.Holo 或 Theme.Holo.Light），低 minSdk 或 Eclipse 工程不等于老式 list_selector_background；颜色从 SDK platforms/android-XX/data/res 下该主题 listSelector 指向的 drawable 取。
2. 在承载点击的同一容器上加通用属性 stateStyles({ pressed: ... })。Compose 源按压时叠加状态层：取 Material3 按压状态层不透明度乘以内容色（StateTokens.PressedStateLayerOpacity，例：material3 1.4.0-alpha17 为 0.1）。View 体系按源主题 listSelector 解析到的按压资源取色：AbsListView（ListView、GridView）的 drawSelectorOnTop 默认 false，按压色画在条目内容下面，在承载点击的条目上写 pressed 态 backgroundColor、normal 透明（例：android-36.1 框架 Holo 暗色主题的 list_selector_holo_dark 按压项是 transition 资源 list_selector_background_transition_holo_dark，其首层 list_pressed_holo_dark.9.png 取样为 #40CCCCCC），不用 opacity、整体变暗或盖在内容上的叠层代替；取不到颜色时在报告中登记缺口，不以 opacity 兜底。
3. 按源端 enabled 条件决定是否出现：clickable/toggleable 的 enabled 为假时（如内容不足、无可展开项）既不响应点击也不显示按压态。
