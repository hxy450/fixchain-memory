# 修可侧滑行的按钮点击被内容层拦截时，把调整限定在按钮热区，不把承载滑动手势的整张内容层设为 HitTestMode.None

ID：`lesson-6677d286e690407d4af4` · 版本：1

[本主题](index.md)

## 何时使用

界面缺陷修复阶段，为可侧滑列表行解决展开后操作按钮点击被上层内容拦截的命中冲突时

## 适用情境

列表行用 Stack 叠放底层操作按钮与上层内容卡片，卡片以 translate 平移露出按钮，并在同一节点上绑定点击（未展开进详情、已展开则收起）与横向 PanGesture（展开或收起）。

## 原因

hitTestBehavior 作用于整个节点：给展开态内容层设 None 后，它上面的点击收起与横向手势一起失效，行展开后无法右滑关闭。来源中修复者写前读到了内容层上的收起手势，仍按修复单“按钮独占热区”把整张卡片设为 None，尝试记录只验证了点击按钮。

## 做法

1. 修复前列出内容层已绑定的全部交互（点击收起、横向 PanGesture），把改动限定在按钮区域：提高按钮层级，或只让按钮区域优先命中。
2. 确需在展开态禁用内容层命中时，先把横向滑动手势上移到整行容器，保证展开后从内容区或操作区都能右滑收起。

## 可选检查

- 改完回归三条路径：展开后右滑收起、点击卡片收起、未展开时点击进详情，再验证点击按钮进入目标页。
