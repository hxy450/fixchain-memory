# ui/feedback

操作结果反馈：异步结果各分支的副作用与提示（含按失败类型分派、权限拒绝的去设置引导），多来源页面按区块的失败隔离与缓存降级，Snackbar 一类提示的单一宿主、排队与默认时长，校验失败提示的承载与可见性，多入口 loading 的起链与收口，降级方案的成功引导，只经通知或 Toast 交给用户的接口返回数据的替代去向，公告与飘屏浮层的队列语义，Toast 时长按调用点映射

## 本级经验

- [修补源端响应回调的某个分支前，先写出到达该分支的完整判别路径（信封成功、data 键、data 层错误码）再逐层对照](lesson-70a6729138334ac77ac1.lesson.md)
  - 时机：修复或复核阶段，修补响应回调中某个分支的文案、常量或弹窗前；把多层判别的响应回调迁成目标分支时
  - 情境：源端回调先按信封 isSuccess 分流，成功分支内再按 data 是否含某键分流，错误码与附带标志从 data 层读取、位于成功分支的 else 中；目标把同名错误码判断放在成功分支之外，由服务层解析函数产出 success/errorCode 字段。
- [同一业务链有多个入口时，每个入口都要真正调用服务并在所有终态收口 loading](lesson-a87eaa08f98ea95d04d5.lesson.md)
  - 时机：界面接线阶段，为同一业务链实现“弹窗确认”与“无弹窗直调”等多个入口，并编写忙态（loading）的起链与收口时
  - 情境：源端工具方法显示 loading 后直接下载或设置，并在各终态关闭；目标把链路拆成弹窗组件加静态入口方法，服务调用需要 UI context，而 context 只在组件按钮回调里拿得到。
- [服务端下发的广播或飘屏消息由单例浮窗逐条播放时，按源端队列语义迁移：不自加去重、上限或点击清空](lesson-2cc8bcca579d597cb6a2.lesson.md)
  - 时机：界面与服务实现阶段，把单例浮窗逐条播放的广播、飘屏消息迁成浮层服务，确定入队、去重、上限与点击后的队列处理时；审计或规格阶段为这类浮层写最小实现链时
  - 情境：源端由单例窗口持有列表，逐个播放网络响应附带的广播或飘屏消息：addAll 入队、remove(0) 出队、动画结束回调里有剩余就继续，点击只跳详情、不动队列；上游审计或规格出现源码没有的“有界/去重队列”等防护性描述。
- [源端 Toast 调用混用 LENGTH_SHORT 与 LENGTH_LONG 时，公共 Toast 封装把时长做成每次调用的参数并逐调用点映射](lesson-8335bc404934f58c6f31.lesson.md)
  - 时机：服务层与页面实现阶段，把源端 Toast.makeText 调用翻译成目标 Toast 封装或 promptAction.showToast、确定每处显示时长时
  - 情境：Android 源码在同一文件或同一公共方法中混用 Toast.LENGTH_SHORT 与 LENGTH_LONG；目标用毫秒 duration 的 showToast 或自建公共 Toast 桥，封装准备只收 message 或只定义一个时长常量。
- [源端以 toast 提示的校验失败，目标用全局提示；页内错误文字放在固定可见行，不追加到可变高度区末尾](lesson-f97fc44e58a8d23333f0.lesson.md)
  - 时机：界面实现阶段，为弹层表单的确定按钮实现必填校验失败反馈时
  - 情境：Android 弹窗确认时依次校验必填项并以 toast 提示；目标用“遮罩 + layoutWeight 中间区 + 固定高度键盘”的弹层承载，校验失败只写一个页内错误文字状态。
- [源端单一 SnackbarHost 显示操作结果时，目标用唯一提示宿主按源端排队与时长展示](lesson-187c725b1bb9d8d1bf4d.lesson.md)
  - 时机：页面转换与功能接线阶段，把源端 SnackbarHostState.showSnackbar 的操作结果提示落成 ArkUI 提示宿主、决定排队、替换与显示时长时
  - 情境：源端页面只有一个 SnackbarHost(hostState)，多个操作结果先后调用 showSnackbar，可能带 actionLabel 或显式 duration；目标准备用多个条件渲染的底部浮层或单槽定时器实现提示。
- [源端只经通知、Toast 等平台通道交给用户的接口返回数据，推迟该能力时要为数据定义替代去向](lesson-9d54e42c44b0d3e78bb1.lesson.md)
  - 时机：规格与计划阶段决定推迟或替换通知等平台能力时；实现阶段调用返回非 void 的接口、准备丢弃返回值时
  - 情境：源端接口返回用户必需的数据（如测试环境下发的短信验证码），客户端只经本地通知或 Toast 展示；目标本轮不迁移通知能力，规格只保留接口签名与“请求成功”的验收条目。
- [源端登录拦截在登录成功后续做原操作、目标登录守卫没有成功回调时，暂存待执行动作并在返回可见时消费](lesson-f1af4e8b6546876046d2.lesson.md)
  - 时机：界面接线阶段，把源端“需登录才能继续”的操作（如点击付费项、添加自选）迁到目标登录拦截，决定登录成功后是否续做原操作时
  - 情境：源端拦截带结果回调：未登录时拉起登录（如 userService.login(...).observe），登录成功后继续原操作（如 result.on(true) 应用所点选项），失败或取消才中止；目标工程现成的登录守卫只负责跳转并返回 false，没有成功回调。
  - 例外：源端拉起登录后直接中止、登录成功后不续做原操作时，按中止实现
- [系统写入降级为“保存 + 引导手动设置”后，每个入口的成功反馈按降级语义实现，不沿用源端“设置成功”](lesson-e44d598230615f3f3262.lesson.md)
  - 时机：功能接线阶段，把源端设置壁纸一类系统写入的结果回执接到目标端降级后的保存链、决定成功反馈时
  - 情境：源端直接调用系统写入 API，并以 Toast 回执“设置成功/失败”；目标没有对应写入能力，已批准改为保存到相册后引导用户手动设置；同一保存服务被多个入口复用，成功时发全局事件供入口展示引导。
- [迁移源端异步结果回调时，按成功、失败分支（含失败类型）列出全部副作用并逐项落地，每个结果态都有渲染或提示](lesson-ac7a2e17b8d88c3cee7b.lesson.md)
  - 时机：界面、流程实现与页面接线阶段，把源页面对异步操作结果的观察（LiveData observe、回调）改成目标的 await 结果、try/catch 或状态监听，决定各分支的跳转、反馈、状态写入与资源收尾时；替换 TODO 或前向引用、按核查清单接线时
  - 情境：源 Activity、Fragment 或控制器在结果回调里按成功、失败（及失败类型）分支同时做几件事：写本地标记、跳页并 finish、showToast 或弹窗、更新计数、close 资源；目标 ViewModel 方法只更新状态、吞掉异常或只返回 boolean（失败类型另存），由页面决定导航和提示；页面可能留有“成功跳 X”的注释或 TODO，规格状态接口列出 error 等结果态，核查清单可能由抽取器生成、只列出部分弹窗调用。
- [页面由多个数据来源组成、源端各来源只在成功时更新自己的区块时，目标按区块保存结果与错误，局部失败不升级为整页错误](lesson-a82d821385bf8fb3feb0.lesson.md)
  - 时机：界面转换与数据接线阶段，为由多个数据来源（多个接口、首页缓存、本地登录态、XML 静态默认内容）组成的页面设计加载、失败与降级状态，或把 ViewModel 的错误状态绑定到整页错误态时
  - 情境：源页面的多个请求各自 launch/observe、只在成功时更新自己的数据；或先用缓存填充再请求详情；或首屏含 XML 静态默认文案与本地状态；或列表页的次级动作（定位、权限、选择）失败只给提示。目标准备用一个结果对象、CONTENT/ERROR 两态或单一错误信息字段驱动整页，加载失败时清空已成功的列表，或刷新时用全屏遮罩盖住其他分区。
  - 例外：缺少城市、参数等所有区块都依赖的前置条件，此时整页错误态是合理的；源端失败分支本身清空数据或切到整页错误（如 catch 里置空列表、显示全屏错误页）时照源端实现，不套用保留旧值
