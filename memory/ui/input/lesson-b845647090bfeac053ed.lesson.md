# 源端以只读字段加选择器一次回填的多级值（省市区等），目标实现选择流程并一次写入各级字段，不退化成并列自由输入

ID：`lesson-b845647090bfeac053ed` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，迁移表单中由选择器回填的地区等字段，确定输入方式与写回方式时

## 适用情境

源端表单字段是只读文本框，点击覆盖层打开级联选择弹窗，选中后通过回调把省、市、区等多级值一次写回模型；目标准备用多个 TextInput 分别绑定。

## 原因

并列的自由输入框不能保证多级值成套、合法，也丢掉了源端的选择交互，用户无从选择，保存时字段可能为空。来源中实现者读到源端只读字段加地区选择弹窗回填，仍写成三个独立输入框，用户报告无法选择省市区后才改为分级选择。

## 做法

1. 源端是选择器回填时，目标实现同样的选择流程（如省→市→区逐级选择），选中后在一次回调里写入模型的各级字段；选项数据沿用源端的数据来源，保存前确认请求体带上这些字段。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
