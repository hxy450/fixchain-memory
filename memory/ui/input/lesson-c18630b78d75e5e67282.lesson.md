# 源 EditText 未声明 background 时，按主题 editTextBackground 状态背景复刻底线与聚焦态，不用静态下边框近似

ID：`lesson-c18630b78d75e5e67282` · 版本：2

[本主题](index.md)

## 何时使用

界面实现或 1:1 对齐修复阶段，为未声明 background、padding 与高度的 EditText 写 TextInput 外观修饰链时；规格提取阶段写这类输入框的转换决策时

## 适用情境

源 EditText 未声明 android:background、padding 与高度，应用主题父链落到框架主题（android:Theme.*），外观来自主题的 editTextBackground：Holo 为 edit_text_holo_dark/light 选择器（聚焦与未聚焦两张 9-patch，含端头竖线与内容内边距），Material 为 edit_text_material（inset 包着按 colorControlNormal/colorControlActivated 着色的 9-patch，见 platforms/android-<api>/data/res/drawable/edit_text_material.xml）；目标用 ArkUI TextInput。

## 例外与边界

- 源端显式设置了 background 或 style：按该资源解析
- 应用主题继承 Theme.AppCompat、Theme.MaterialComponents 等库主题：editTextBackground 由库资源提供，不在 SDK platforms 的 res 里，本条的平台资源路径不适用，到该库 AAR 的 res 沿同一属性解析

## 原因

TextInput 自带填充底、圆角、内边距与默认高度；只写透明底加 bottom 边框和猜测色，会丢掉端头竖线、聚焦态切换与内容内边距，默认圆角还让底线两端上翘。这些外观由主题属性指向的 drawable 提供，源布局里看不到，只能沿主题查到资源。

## 做法

1. 先确认 Activity 主题的父链落到 android:Theme.*，到本机 SDK platforms/android-<api>/data/res 查 themes_*.xml 的 editTextBackground（以及 textCursorDrawable、editTextColor），沿选择器找到各状态资源。
2. 按状态（未聚焦、聚焦、禁用）随 onFocus/onBlur 切换背景；解析到 9-patch 时取其内容区作为 padding，外层有 inset 或 tint 时（如 edit_text_material）一并按其 inset 与着色属性绘制；改透明底时显式 borderRadius(0)。
3. 高度按源端 wrap_content 的结果设置（背景内边距 + 文字行高，并核 minHeight 与布局约束）；光标按主题 textCursorDrawable 解析。
4. 规格提取时在该控件的转换决策行写出提供方资源、各状态外观、内容内边距与高度，不只写“下划线样式”；查过平台资源仍缺的值，写明已查路径和缺的是哪一项。
