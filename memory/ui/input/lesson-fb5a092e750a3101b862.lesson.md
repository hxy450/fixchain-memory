# 源端未显式定制的光标外观以用户指定页面的真机取证为基准：不借其他页面代取样，用帧差分定位光标

ID：`lesson-fb5a092e750a3101b862` · 版本：1

[本主题](index.md)

## 何时使用

界面还原修复阶段，为输入框光标这类源端未显式定制、取决于页面主题或系统渲染的外观选取安卓基准，并写入 caretStyle 时

## 适用情境

源 EditText 没有 textCursorDrawable，外观取决于所在 Activity 的主题和系统渲染；同一应用其他页面已有不同的光标配置；需要真机像素取证；目标为 TextInput 的 caretStyle({ width, color })。

## 例外与边界

- 源端显式设置了 textCursorDrawable，此时打开该 drawable 取宽度与颜色

## 原因

光标的默认外观随 Activity 主题和着色而变，同一应用不同页面可能不同；用另一页面的输入框代取样再写成“安卓实测”，后续验证也只会和这个错误基准比较。来源中修复者读到登录页三个 EditText 无光标 drawable、其他页面显式用了黄色光标，却假定“默认光标各页相同”，在完善资料页取样得到灰色 1dp 写进登录页；用户三次追诉后才在登录页实测到主题蓝 2dp。按暗像素阈值扫描还曾漏掉蓝色光标。

## 做法

1. 以用户指定页面（同一 Activity、同一主题）的真机取证为基准；目标页一时到不了（如需退出登录）时请用户切到该页，或先不写入。确需借用其他页面时先核两个 Activity 的主题与控件着色相同，并在注释与报告写明基准来自哪个页面。
2. 像素取证光标时不预设颜色：先用闪烁 ON/OFF 两帧差分定位光标，再取色、量宽高；只扫暗像素会漏掉彩色光标。
3. 光标宽度与颜色用 caretStyle({ width, color }) 设置（当前 SDK 的 TextInput 没有 caretWidth）；写前在本地 SDK 声明核对属性名。
