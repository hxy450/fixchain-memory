# 截图可见的选项列表按源数据源（ViewModel、数组、素材目录）迁移，截图只核视觉；列表中的动作项按源接到对应页面并写回会话

[本主题](index.md)

## 何时使用

界面实现阶段，为选择区（色板、样式方案、素材列表等）确定选项列表与点击行为时，尤其任务要求“根据截图转换”时

## 适用情境

Android 选择区由 Fragment + ViewModel 以 RecyclerView 列表提供选项（例：编辑器的背景色含渐变方案与图片素材、边框为位图素材且首项是调色盘），Fragment 泛型参数或布局 data-binding 的 variable 指向对应 ViewModel；迁移任务同时给出设备截图作为视觉参考。

## 原因

截图只露出某一屏的少数选项，按截图估值会丢掉渐变两端与方向、素材文件和项数；动作项点击只切换选中标记、不写回会话配置时，选择看起来生效，实际不保存。

## 做法

1. 沿 Fragment 的泛型参数与布局 variable 打开对应 ViewModel 或数据源，按源列表的项数、顺序、颜色值（含渐变两端与方向）和素材文件原样迁移；截图只用于核对外观。
2. 源列表里的动作项（调色盘、相册、图库等），接到工程中已有的对应页面或弹窗，并把选中结果写入编辑会话配置，以便保存与恢复。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
