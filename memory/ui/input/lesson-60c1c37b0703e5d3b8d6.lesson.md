# 色板、渐变方案、边框素材这类选项列表按源 Fragment/ViewModel 的数据源迁移，截图只核视觉；调色盘、相册、图库等动作项按源接到对应页面并写回编辑会话

ID：`lesson-60c1c37b0703e5d3b8d6` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，为编辑页背景色、文字颜色、边框等选择区确定选项列表与点击行为时，尤其任务要求“根据截图转换”时

## 适用情境

Android 选择区由各自 Fragment + ViewModel 以 RecyclerView 列表提供（背景含渐变方案与图片素材、文字为纯色列表、边框为位图素材且首项是调色盘），Fragment 泛型参数或布局 data-binding 指向对应 ViewModel；迁移任务同时给出设备截图作为视觉参考。

## 原因

截图只露出某一屏的少数色块，估色会丢掉渐变两端与方向、素材文件和项数；点击只切换选中标记、不写回会话配置时，选择看起来生效，实际不保存。来源中写者已读到布局与 Fragment 指向 ViewModel 数据源，关键 Fragment 在批量读取里被截断后没有重读，转而按截图自拟色值与选项。

## 做法

1. 沿 Fragment 的泛型参数与布局 variable 打开对应 ViewModel 或数据源，按源列表的项数、顺序、颜色值（含渐变两端与方向）和素材文件原样迁移；截图只用于核对外观。
2. 源列表里的调色盘、相册、图库等动作项，接到工程中已有的对应页面或弹窗（如颜色面板、网络图库），并把选中结果写入编辑会话配置，以便保存与恢复。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
