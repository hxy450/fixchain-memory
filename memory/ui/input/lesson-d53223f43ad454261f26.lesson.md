# 源码用 selectable 行加条件尾部勾选表示选中时按同一结构实现，不按“单选”语义换成 Radio

ID：`lesson-d53223f43ad454261f26` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把 Compose 排序、筛选等选择列表行转换为 ArkUI 行组件并确定选中标记时

## 适用情境

源端每行是 Row(Modifier.selectable(selected) { ... })，行首图标加文字，选中时才出现尾部 Icon(ic_check, tint = brand)，未选中行不显示任何标记；目标有 ArkUI Radio 等现成单选控件可用。

## 例外与边界

- 源码本身使用 RadioButton/Radio 控件

## 原因

selectable 只提供可选语义，视觉由源码的条件分支决定；换成 Radio 会让每行都出现圆圈并改变选中样式，与源端“只有选中行有勾”的界面不同。来源中写者按行号窗口读取源文件，窗口恰好止于 selectable(...) 那行，没读到下方的条件勾选分支，就按单选语义写出 Radio({ group })。

## 做法

1. 读完该行 Composable 的完整函数体再定控件：源码是 if (selected) Icon(ic_check) 时，ArkUI 用同一条件渲染 Image(ic_check) 并按源 tint 着色，未选中行放同尺寸占位保持对齐；写前确认 ic_check 资源已迁移。
