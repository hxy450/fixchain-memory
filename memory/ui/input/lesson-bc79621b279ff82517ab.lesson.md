# 受控值含文本与选区（TextFieldValue）时，选区经 TextAreaController.setTextSelection 落到输入框

ID：`lesson-bc79621b279ff82517ab` · 版本：2

[本主题](index.md)

## 何时使用

公共组件实现阶段，把 Compose 受控输入组件（格式工具栏、插入链接、插图回填）转成 ArkUI 共享组件时

## 适用情境

源组件以 TextFieldValue 同时回写文本与选区（工具栏加粗、插入链接后光标落到末尾）；目标 ArkUI TextArea/TextInput 的选区只能经 controller 设置，组件内另有 @Local 记录选区。

## 原因

只回写文本、把算出的选区存进组件内部状态时，输入框的光标与选区不变，下一次格式操作作用在错误位置；controller 声明了却没调用，编译与检查都通过。

## 做法

1. 回写文本后用 TextAreaController.setTextSelection(start, end) 把计算出的选区落到输入框（光标即 start 等于 end），交付前确认 controller 确有调用，不只更新组件内状态。
2. 源组件的子对话框（AlertDialog）用系统弹窗实现；源组件内聚的副作用链（选图、匿名判定、上传、回填、上传中状态）在共享组件里保持内聚，服务未就绪时占位的负责切片指向真正拥有该服务的 feature，不下推给每个宿主页。
