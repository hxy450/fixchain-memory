# 把同页多组表单收集为执行请求时，按源执行方法实际读取的控件为每个模式设独立字段，不因同名复用其他表单的槽位

ID：`lesson-dee3401b34b8fab1a0fb` · 版本：3

[本主题](index.md)

## 何时使用

功能实现阶段，把 Android Activity 上多组输入表单的字段收集为服务层执行请求、接到写入或计算方法时

## 适用情境

源 Activity 在同一页面持有多组语义相近、同名的位置或数值输入控件，各执行方法分别读取自己那组控件；目标由页面收集参数构造一个请求对象交给共享服务，页面已为各表单建了独立状态。

## 原因

请求类型只有一组同名字段时，页面只能把某个表单的值填进去，其他模式就会用到别的表单的位置或数值，执行目标错误而界面没有异常。

## 做法

1. 定义请求前按源执行方法逐个列出它实际读取的控件，为每个模式设独立字段，或按模式拆成不同请求，不因字段同名合并。
2. 请求写完逐模式反查：从服务执行方法的参数追回页面表单变量，出现跨表单取值即修正。
