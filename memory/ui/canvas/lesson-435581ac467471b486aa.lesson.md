# 移植像素语义的自绘画布时显式使用PX单位

ID：`lesson-435581ac467471b486aa` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把Android自绘View（SurfaceView/Canvas）的测量、取整、位图缩放、逐帧位移和触摸换算移植到ArkUI Canvas/OffscreenCanvas时

## 适用情境

源端测量、整除取整、位图缩放和每帧±N位移都以物理像素计；目标Canvas上下文与OffscreenCanvas默认单位为vp，组件尺寸与触摸坐标也以vp给出。

## 原因

在vp域整除取整会得到非整像素的格宽，“每帧1单位”的步长被放大为密度倍数的像素，动画幅度和节奏随之改变；“差别可忽略”的判断忽略了逐帧累积效果。

## 做法

1. 先列出源端每个几何量（边长、格宽、位图尺寸、步长、触摸坐标）的单位和取整位置。
2. CanvasRenderingContext2D与OffscreenCanvas构造时传LengthMetricsUnit.PX；组件可用尺寸先vp2px，在像素域取整，组件宽高用px2vp回写；触摸坐标先vp2px再换算格子。
3. 规格中写出目标端单位契约（画布PX、像素域取整），不只保留源端示例数值。
