# Paint级透明度映射为画布状态时，画完复位到已知默认值

ID：`lesson-5511f322875beff3e87a` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把Android逐次绘制所用Paint的透明度或颜色滤镜映射为ArkUI CanvasRenderingContext2D共享状态时

## 适用情境

源端每次drawBitmap用独立Paint设透明度（如淡出），其他图层用默认Paint不透明绘制；目标用globalAlpha等共享上下文状态，同一画布还要连续绘制不应受影响的图层。

## 原因

Paint上的透明度只作用于那一次绘制，而globalAlpha是画布的持续状态；靠读回getter再写回来复位，读回值不可靠（如返回undefined）时复位失效，后续图层会带着上一次的透明度绘制。

## 做法

1. 画完把globalAlpha直接写回默认值1，或用成对的save()/restore()包住这一次绘制；不先读getter再写回。
2. 源端用默认Paint画的图层，绘制前显式设好所需状态（globalAlpha=1、默认合成模式）。

## 可选检查

- 淡出动画结束后对静态图层取样，确认仍不透明
