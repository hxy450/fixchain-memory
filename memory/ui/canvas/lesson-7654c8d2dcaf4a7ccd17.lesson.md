# 离屏位图按源端显示尺寸生成，不自行加超采样

ID：`lesson-7654c8d2dcaf4a7ccd17` · 版本：1

[本主题](index.md)

## 何时使用

界面实现与渲染功能实现阶段，为Canvas自绘的离屏位图（着色精灵、网格整图等）确定生成分辨率时

## 适用情境

源端把资源位图缩放到格子像素尺寸、按画布宽度生成整图后1:1绘制；目标用OffscreenCanvas离屏生成位图，并在帧循环中逐帧drawImage。

## 原因

额外采样倍数让位图面积按倍数平方增长，每帧缩放绘制这些大位图会让渲染服务单帧处理超时、缓存积压；目标帧循环没有lockCanvas那样的背压时，积压会持续增长直到渲染服务卡死。

## 做法

1. 位图尺寸直接取源端缩放或生成的目标尺寸（即显示像素尺寸）；先确认OffscreenCanvas尺寸参数的单位，再按显示像素生成并1:1绘制。
2. 密度换算规则（如“1vp约3px”）只用于布局尺寸换算，不作位图采样倍率；源码没有的“质量项”常量不添加。
3. 接手已有常量时先对照源码确认其依据；要把同一做法推广到更大位图前，先算出最终像素尺寸与显示尺寸之比。
