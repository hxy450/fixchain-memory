# 带参 $r 的 %s/%1$s 占位只传字符串：数值先 toString()，%s 收到数值时格式化结果为空串

ID：`lesson-cf670f808b1a42227083` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把 stringResource(R.string.x, n) 一类带参字符串资源写成 $r(app.string.x, …) 时

## 适用情境

Android 字符串资源用 %1$s 接收 Long/Int（如 “%1$s comments”），Kotlin 调用时自动转字符串；目标 $r 的格式化参数按占位符类型匹配。

## 原因

占位符是 %s 而实参是 number 时，格式化结果为空串，界面只剩模板其余文字（来源修复期设备实测）；编译与类型检查都不报错。写者怀疑类型问题时若假定隐式转换而不核实，偏差会进入所有同类调用。

## 做法

1. 写带参 $r 前查资源串的占位符：%s/%1$s 传 string（数值先 toString()），%d 才传数值；对类型有疑问时先检索工程已有用法或查资料核实。
2. 修好一处后，全工程检索带参 $r 调用，核对每个传给 %s 的实参类型。
