# ui/text/metrics

映射字体自然盒、行高和多行间距时进入。

## 本级经验

- [文本行高迁移应分别建模单行自然盒与多行行间距](lesson-4e8b8250476ba564b943.lesson.md)
  - 时机：规格提取或主题实现阶段，映射文本 lineHeight、lineSpacing 并据此推导文本容器尺寸时
  - 情境：源端文本样式同时携带字号与行高，目标端同名属性可能改变单行盒高；同一主题令牌又同时服务单行标签和多行段落，而目标框架的行距合成规则未必有文档或实测依据。
  - 例外：已用当前字体、框架版本和配置验证源端与目标端在单行盒高及多行块高上行为等价
