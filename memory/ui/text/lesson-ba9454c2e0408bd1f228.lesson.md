# 源端在 Button 子类或带 style 的 TextView 上开启自动字号时，契约写出作用区（控件尺寸减内边距）与测量字体，不只抄字号区间

ID：`lesson-ba9454c2e0408bd1f228` · 版本：2

[本主题](index.md)

## 何时使用

规格提取或界面实现阶段，把源端 setAutoSizeTextTypeUniformWithConfiguration 或 autoSizeTextType 的自动字号写成目标映射契约或 Text 自适应字号时

## 适用情境

源端在继承 Button/AppCompatButton/MaterialButton 或带 style 的 TextView 上调用 setAutoSizeTextTypeUniformWithConfiguration（或布局写 autoSizeTextType），可能同时换了背景；规格行只写了字号区间与“在块内自适应”。

## 原因

TextView 自动字号在“控件尺寸减内边距”的内容区内，按宽、高两个方向取能放下的字号，并按控件自身 textAppearance 的字体测量；按钮子类即使换了背景，样式里的内边距与字体仍然生效。只抄字号区间、写成“在整块内自适应”，目标文字会比源端更大或位置不同。

## 做法

1. 读源控件的类型、style/theme 与内边距来源（主题 buttonStyle 与背景 drawable 带来的 padding、textAppearance），在契约里写出自动字号的作用区 = 控件尺寸减内边距、宽高两向约束、测量用的字体与字号步长。
2. 目标实现按契约显式定字号：在源区间内取满足“行高 × 字号 ≤ 可用高、文本宽 × 字号 ≤ 可用宽”的最大值（在 px 域比较），补上与源端一致的内边距与字重（Button 的文字外观为 sans-serif-medium）；只在整块上挂 minFontSize/maxFontSize 时，ArkUI 按整块尺寸与系统字体自适应，与源端不等价。
