# 移植 Compose 文本组件时先确认 Text 收到的是原始字符串还是加工后的 AnnotatedString；链接识别、样式与点击要落到目标端

ID：`lesson-57a52be767730880cbba` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把源端 Compose Text 译成 ArkUI Text 时

## 适用情境

源组件先调用工具函数（如按正则识别 URL、附加 LinkAnnotation 的 buildAnnotatedStringWithUrls）生成 AnnotatedString 再交给 Text；目标页面规格和验收条目只写了空值隐藏、折叠展开等布局行为。

## 原因

只渲染原始字符串，描述里的链接既不着色也点不开，编译和结构审计都发现不了。来源中转换者读了组件源码，看到了加工调用，却以“验收项没列”为由写成纯 Text，也没有读工具函数的定义。

## 做法

1. 看传给 Text 的变量从哪来；经过工具函数加工的，读该函数定义，把识别规则、链接样式和点击行为一起移植。
2. ArkUI 可用 StyledString 配 TextStyle、DecorationStyle 与 UrlStyle 表达链接，通过 TextController.setStyledString 设给 Text({ controller })。
