# Compose FontWeight 按数值字重写入 ArkUI：SemiBold、Light 等没有同名枚举成员时写 fontWeight(600/300)，编译修复不就近换成 Medium、Lighter

ID：`lesson-605038b091e03c26c005` · 版本：1

[本主题](index.md)

## 何时使用

界面实现与主题排版阶段，把 Compose FontWeight 写成 ArkUI fontWeight 时；编译修复遇到 FontWeight 缺少某成员的报错时

## 适用情境

源端 Text 或 TextStyle 用 FontWeight.SemiBold、Light、ExtraBold、Thin、ExtraLight、Black 或 FontWeight(数值)；ArkUI 的 FontWeight 枚举只有 Lighter、Normal、Regular、Medium、Bold、Bolder，写成 FontWeight.SemiBold 会报 “Property 'SemiBold' does not exist on type 'typeof FontWeight'”；fontWeight 属性同时接受 100–900 的数值。

## 原因

Compose 字重是确定的数值（SemiBold 600、Light 300），ArkUI 枚举没有对应成员；按名称“最接近”换成 Medium 或 Lighter 能通过编译，但字重变了，标题等文字整体变细，批量替换还会把同一偏差带到每个用处。

## 做法

1. 按源字重的数值写 fontWeight(n)：Thin 100、ExtraLight 200、Light 300、SemiBold 600、ExtraBold 800、Black 900；Normal、Medium、Bold 可用同名枚举或 400、500、700。
2. 编译修复遇到 FontWeight 缺成员时同样改成对应数值，不换成名称相邻的枚举成员；批量替换前逐处确认原字重。
