# 自研 Markdown 或富文本把文本按多条规则切成 run 时，命中与间隔文本按原位置顺序输出；契约同时覆盖解析库的核心语法

ID：`lesson-25f9eea8c9ed9b361d4f` · 版本：1

[本主题](index.md)

## 何时使用

Markdown 渲染的规格提取与解析实现阶段，确定语法覆盖、文本切分后 run 的拼装顺序与自动链接规则时

## 适用情境

源端用 Markwon 一类库（CommonMark 核心解析，加 Linkify、提及简写等文本插件，按触点命中 span）渲染 Markdown；目标自研解析器，把文本切成有序 run 序列交给 StyledString/Span 渲染。

## 原因

在循环里先把每个命中推入结果、间隔文本留到循环结束才输出，链接会排到前文之前；正则逐行的块解析丢掉嵌套、惰性续行与松紧列表。只按插件清单写验收时，核心语法没有任何条目约束，单测只测正则命中也发现不了顺序错乱。

## 做法

1. 切 run 时单次扫描合并各规则的命中区间，按原位置依次输出间隔文本与命中；单测断言 run 文本拼接等于原文、链接位置不变。
2. 规格迁移整套 Markdown 库时，契约同时覆盖库的 CommonMark 核心语法（嵌套、惰性续行、松紧列表、引用内的块、行内元素按原文顺序）与插件，并给核心语法可断言的样例。
3. 验收写明平台匹配语义（如 Linkify WEB_URLS）时，移植源平台正则（含无协议域名与过滤规则），与其他规则重叠时按源端监听注册顺序处理，不缩窄匹配范围。
