# 系统语言映射按 BCP 47 的 script/region 逐类写到语言包，不把源端对裸 'zh' 等精确值的特判扩成前缀匹配

ID：`lesson-b853123dbef8142607fd` · 版本：2

[本主题](index.md)

## 何时使用

规格提取与实现阶段，把源端初始语言选择翻译成目标端系统语言解析函数及其验收判据时

## 适用情境

源端按设备返回的语言代码挑选语言包，并对某个精确值做特判（如 === 'zh' 时改用 zh-TW），或由 navigator.language 等检测结果直接匹配语言包名（如 zh-CN）；目标系统语言 API 返回 zh-Hans-CN、zh-Hant-TW 这类带 script/region 的标签。

## 原因

源端的精确比较只命中那一个值；改写成“主标签为 zh 的任意变体”后，简体系统也被映射到繁体包，整个应用的文案换成另一种书写系统。

## 做法

1. 列出目标 API 可能返回的标签类别（裸语言、带 script、带 region、两者兼有），对每类按源端实际得到的语言代码与可用语言包写映射（例：含 Hans 或以 -CN 结尾 → zh-CN，裸 zh → 源端特判结果），每类在验收判据里给一个样例。
2. 源端特判写的是严格相等时保留严格相等，不扩成前缀匹配；有源端实机截图或基线时，用它核对系统语言为简体、繁体时的实际显示。
