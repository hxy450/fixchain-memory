# 单个符号字形被当作图形用（如循环里按大字号生成 Html.fromHtml("&#8226;") 作页码点）时，按源字体下的可见几何画图形

ID：`lesson-e1293913e4905dc3055c` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与界面实现阶段，转换用文字字形充当图形的控件（翻页圆点、指示点、分隔点等）时

## 适用情境

源端在循环中逐个 new TextView、setText(Html.fromHtml("&#8226;")) 或直接设 “•”“●”“★” 一类单字符，并用远大于正文的 setTextSize 作页码点等指示器；内容只有一个符号、无标签无链接；可见尺寸、步进与垂直位置取决于源字体（如 Roboto）的字形度量；规格或映射可能把“字符 + 字号”写成跨栈硬映射。

## 例外与边界

- 符号是正文的一部分（列表符号后接文字、行内分隔），随文字一起排版：按普通文本或富文本移植

## 原因

目标默认字体中同一符号的字形大小、步进与在行框内的垂直位置都与源字体不同，同字号直接写成 Text 后，圆点大小、间距与纵向位置都会偏；它表达的是图形，不是文字内容。

## 做法

1. 先区分“文本内容”与“用字形画图形”：内容只有一个字符实体、无标签无链接、在循环里逐个生成且字号远大于正文时按图形处理，不写成 Text('•')。
2. 规格在组件契约里写出源字体下的可见几何（单点步进、直径、相对容器的垂直位置）及来源（源端截图实测，或按源字体字形度量与字号计算），并注明目标字体的同一字形度量不同；实现按这些值用 Circle 等图形绘制。
3. 实现前若仍打算用文字绘制，先在目标端量一次该字形在给定字号下的步进与位置（MeasureText 或截图），与源端几何不符就改为按几何绘制。
