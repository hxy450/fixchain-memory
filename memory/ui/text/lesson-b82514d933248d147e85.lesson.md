# 源端对资源字符串做 toLowerCase 等加工时，目标用 getStringSync 取得 string 后照样加工，不以 Resource 限制删掉

ID：`lesson-b82514d933248d147e85` · 版本：1

[本主题](index.md)

## 何时使用

界面与服务实现阶段，迁移源端 getString(R.string.x) 后接字符串加工（toLowerCase、拼接、格式化）的文案时；以“平台不支持”为由准备删掉加工时

## 适用情境

源端先取资源串再做 toLowerCase 等加工后显示或拼接；目标里 $r('app.string.x') 得到的是 Resource 对象，不能直接调用字符串方法，代码内可经 resourceManager.getStringSync 取得 string。

## 原因

Resource 对象不能做字符串加工，不等于资源文案不能加工；经 getStringSync 等接口取得的已是 string，删掉源码加工会改变显示的大小写或拼接结果。

## 做法

1. 以平台限制为由删除源码的字符串加工前，先查所用 API 在 .d.ts 中的返回类型；需要加工的文案在代码内用 resourceManager.getStringSync 取得 string（按数字 id 取值的写法见 lesson-22432022455bff6f849b），再照源码加工。
