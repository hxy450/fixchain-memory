# 主题 modifier 与容器定高不得把 lineHeight 当单行文本盒高

ID：`lesson-89f5064b1f821945e706` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，落地统一文本 AttributeModifier，或为包裹单行 Text 的容器（ArkUI 横向 List 等需显式交叉轴尺寸）推导固定高度时

## 适用情境

目标工程有统一排版令牌（fontSize/lineHeight 数值来自 Type.kt），页面里有需要显式高度的行容器，容器内文本多为单行。

## 原因

无条件 .lineHeight 会把单行撑到整行高；Feed 转换器又按「titleMedium lineHeight 24」把行高写成字面常量 176（Android 实测文本盒 ≈19.8dp），后来主题改法时该常量成为跨文件的隐含依赖。

## 做法

1. 统一 modifier 落地前，用任一单行 Text 的实测高（Android dump 或 ttf hhea 比 × fontSize）核对 modifier 输出；自检不能只比对令牌数值与 Kotlin 相等。
2. 为容器推导固定高度时，文本盒高取字体自然高或引用排版令牌的派生函数（如 Typography.titleMedium.naturalHeight()），不写含 lineHeight 的字面常量；注释写明文本高度来源，便于主题改法时被 grep 到并随之重推。

## 检查

- grep 工程内含 lineHeight 数值的字面高度常量，每一处都能指到派生函数或注释来源；单行 Text dump 高 ≠ lineHeight。
