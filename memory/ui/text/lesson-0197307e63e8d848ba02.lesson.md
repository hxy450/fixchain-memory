# 说明类静态页按源布局逐卡迁移：文案逐字取自源 XML，标题条背景与插图一并迁入

ID：`lesson-0197307e63e8d848ba02` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，依据源布局 XML 生成规则、说明、注意事项一类静态图文页时

## 适用情境

源静态页由多张卡片组成，标题条使用 drawable 背景，正文是写在布局 XML 里的长文案，卡内或页首尾有插图；规格只要求“展示说明并可返回”，不复述内容。

## 原因

规格不复述内容时，布局 XML 是唯一的内容来源；用概括文案、省略插图与标题条背景写出的页面能编译、能返回，却与源页面不一致。来源中实现者在批量读取被截断后，把可见的卡片简化成纯文字卡，没读到的页面写成通用介绍，协调者又把概括文本写进字符串资源；视觉检查后三页被整体重写。

## 做法

1. 写前从每个布局列出卡片数、标题、正文、标题条背景与插图 drawable 清单，写完逐项对照：卡片数一致，插图与背景已迁入 media。
2. 文案逐字写入字符串资源（保留分行）；读不到源文就停下报告缺口，不写概括或通用替代文案。
