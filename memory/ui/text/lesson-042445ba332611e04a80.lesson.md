# 复用基类的显示格式化 getter 前核对精度：品类精度不同（如 ETF 三位小数）时在子类覆写全部相关 getter，同一字段的各分支用同一精度

ID：`lesson-042445ba332611e04a80` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把源端十字光标、高亮联动等显示接入目标页面，决定复用基类 ViewModel 的格式化 getter 还是在子类覆写时；修改同一显示字段的任一分支（静态值、无数据兜底、高亮值）时

## 适用情境

多个品类详情页共用一个基类 ViewModel，基类显示 getter 用通用精度格式化（如 formatPrice 保留两位）；某一品类的静态字段与源端联动代码使用不同精度（如 getPrice(..., 3)），子类尚未覆写对应 getter。

## 原因

对照源端时只记“哪些字段跟随”而丢掉格式参数，接到基类 getter 后同一字段的静态值与联动值精度不一致；编译和显示都正常，只在联动时少一位小数，后续改该字段其他分支时也容易再次漏看。

## 做法

1. 对照源端联动代码时，把每个跟随字段的格式参数（如 getPrice(..., 3)、getValue(v, 3)）与字段范围一起列进对照表。
2. 复用基类显示 getter 前打开其格式化函数核对精度；品类精度不同时，在该品类子类覆写全部相关 getter（现价、涨跌额、最高、最低等），让竖屏与横屏等各处显示共用同一来源。
3. 修改同一显示字段的任一分支时，检查其他分支所用 formatter 是否同精度，可 grep 该字段在子类与基类中的 formatter 调用逐一比对小数位。
