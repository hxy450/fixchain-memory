# 复用基类显示格式化 getter 前核对源端各字段的格式参数，精度不同就在子类覆写同一字段的全部分支

ID：`lesson-042445ba332611e04a80` · 版本：4

[本主题](index.md)

## 何时使用

界面实现阶段，源端子类或调用处以不同于基类的小数位参数调用格式化函数（例：源端取值函数传 3 位小数、基类 getter 按 2 位格式化），目标准备复用基类 ViewModel 的显示 getter 时；修改同一显示字段的任一分支（静态值、无数据兜底、联动高亮值）时

## 适用情境

多个详情页共用一个基类 ViewModel，基类显示 getter 用通用精度格式化；某一子类的静态字段与源端联动代码使用不同精度，子类尚未覆写对应 getter。

## 原因

对照源端时只记“哪些字段跟随”而丢掉格式参数，接到基类 getter 后同一字段的静态值与联动值精度不一致；编译和显示都正常，只在联动时少一位小数，后续改该字段其他分支时也容易再次漏看。

## 做法

1. 对照源端显示代码时，把每个字段的格式参数（如 getPrice(..., 3)、getValue(v, 3)）与字段范围一起列进对照表。
2. 复用基类显示 getter 前打开其格式化函数核对精度；精度不同时，在该子类覆写同一字段的全部相关 getter，让各处显示（含横竖屏、联动值）共用同一来源。
3. 修改同一显示字段的任一分支时，检查其他分支所用 formatter 是否同精度，可 grep 该字段在子类与基类中的 formatter 调用逐一比对小数位。
