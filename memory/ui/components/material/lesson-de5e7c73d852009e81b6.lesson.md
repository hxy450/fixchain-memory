# Material 容器留白按侧和槽位映射，不把起始侧 inset 复制到末端

ID：`lesson-de5e7c73d852009e81b6` · 版本：1

[本主题](index.md)

## 何时使用

规格提取或界面实现阶段，将 Material TopAppBar 等容器的内部留白映射为目标布局时

## 适用情境

源组件通过标题、导航或动作槽提供单侧 inset，调用点未完整展示库内部布局。

## 例外与边界

- 当前工程明确覆写了库内留白规则，并已有相应组件契约

## 原因

库内 token 往往只作用于指定侧或槽位，将其写成左右对称 padding 会给另一侧添加源端没有的留白。

## 做法

1. 按当前组件实现分别写出起始侧、末端以及导航/标题/动作槽的占位关系，已有可靠规格可直接复用。
2. 最小映射：源规则只有 start = inset、end = 0 时，目标也按侧表达；不要简化成 horizontal = inset。方向按当前布局方向处理，数值来自当前库配置。
