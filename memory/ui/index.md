# ui

界面迁移：布局与尺寸约束（含布局方向）、安全区、主题样式、文本排版、状态刷新、输入控件、点击命中、手势与硬件按键、弹窗、分页与列表、图形资源与 Canvas 自绘视图移植、渲染效果（阴影、模糊、混合着色、渐变几何）、结果反馈、Web 页承载与多页面导航（含返回键）的跨栈转换、动画（显隐、尺寸、内容切换、条目位移与自驱帧循环）与无障碍语义

## 子主题

- [accessibility](accessibility/index.md) — 无障碍语义：可点击行与卡片的角色、可用态与合并朗读，图标无障碍文本按源 contentDescription 取值与多语言资源；页内遮罩弹窗的读屏模态见 dialog
- [animation](animation/index.md) — 动画：Compose 显隐、内容切换、容器尺寸与列表条目动画到 ArkUI animateTo、TransitionEffect 的落实，帧时钟动画改自驱帧循环时的进度计算、刷新节奏与前后台追平；动画矢量形变见 graphics，页面转场见 navigation/hosts

- [effects](effects/index.md) — 渲染效果：elevation 阴影是否投影及写入 ShadowOptions 的 px 换算与共享映射，blur 的单位与边缘，View 体系的图片模糊、LightingColorFilter 乘法压暗与 tint 渐变装饰层，TextView 文字阴影，blendMode 混合着色的离屏范围与预混，渐变描边的双层结构，以及 Compose 渐变端点几何到 linearGradient 角度、stop 周期与镜像平铺的换算
