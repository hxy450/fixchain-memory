# 为某个宿主改写共享组件时加默认保持原行为的覆盖入参，并检索全部宿主调用点

ID：`lesson-67e0a326dea085296fb9` · 版本：1

[本主题](index.md)

## 何时使用

列表页与弹层接线阶段，源宿主或子类 adapter 改配共享行内的按钮或显隐，或要给多页共享的组件新增宿主须接的事件时

## 适用情境

子类用另一动作按钮配置改写次级按钮（图标、文案、点击一起换），宿主按状态把按钮设为 GONE，或为某个宿主给共享面板新增回调事件；目标行组件或面板被多页共享，写者常受写盘边界限制。

## 原因

只改点击不改外观会出现“播放图标的按钮点下去执行删除”；新增事件只接当前宿主时，其他宿主的条目点击无响应；只在报告里记缺口则行为永远缺失。

## 做法

1. 在共享组件上加覆盖入参或事件（默认保持原行为），由宿主传值，图标、文案与点击一并迁移；当场改不了共享文件时登记跨文件交接，不把占位记为已闭合。
2. 新增宿主须接的事件或覆盖参数时，检索该组件的全部宿主调用点，逐一接线或交办。

来源支持：3 张卡 · 1 次迁移 · 1 个应用
