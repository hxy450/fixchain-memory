# LazyColumn stickyHeader 落成 List 内 ListItemGroup 头 + sticky(StickyStyle.Header)，不移到 List 外固定

ID：`lesson-43668515b938fc1c06f7` · 版本：2

[本主题](index.md)

## 何时使用

界面实现阶段，把 Compose LazyColumn 的 stickyHeader（含按开关在吸顶与普通项之间切换）落成 ArkUI 列表结构时；规格提取阶段为吸顶列写备选实现时

## 适用情境

源端 LazyColumn 内用 stickyHeader 放吸顶内容（可由开关在 stickyHeader 与 item 间切换），其余项随列表滚动；吸顶内容可能可点击，页面还可能按“内容是否超出视口”决定折叠顶栏。

## 原因

把吸顶内容放到 List 外、固定在其上方，外观相同，但它已不在滚动容器里：从吸顶区起拖不会滚动列表，依赖内容高度的判断也少算了头部。

## 做法

1. 写成 List { ListItemGroup({ header: 吸顶内容 }) { 其余 ListItem } }.sticky(StickyStyle.Header)；按开关切换吸顶与普通项时，两种状态都在同一个 List 内实现。
2. 依赖“内容是否超出视口”的逻辑把头部和其余项一起测，测量挂在 ListItemGroup 或等价容器上。
3. 规格给吸顶备选实现时写明“吸顶内容仍属滚动容器、从它起拖照常滚动”，不并列 Stack + offset 这类把头部移出滚动容器的方案。

## 可选检查

- 验收吸顶时从吸顶区起拖，确认列表滚动、吸顶区内点击照常命中。
