# 迁移 RecyclerView/Adapter 列表时连同条目点击与触摸监听一起实现：逐项在条目上接事件，不只迁渲染

ID：`lesson-46307bc26d725b4634ca` · 版本：2

[本主题](index.md)

## 何时使用

页面 UI 转换阶段，迁移 RecyclerView/Adapter 列表的条目交互时

## 适用情境

源 Fragment 经 adapter 的点击回调（setOnItemClickListener、ViewHolder 中的 setOnClickListener）或 RecyclerView.addOnItemTouchListener 把条目内容回填到输入框、跳转或切换状态；目标列表只迁了样式链。

## 原因

只迁样式链的条目没有 onClick，交互入口静默丢失；注释或报告写着已实现也不能代替事件代码。

## 做法

1. 每迁一个列表，先枚举源端 adapter 点击监听与 RecyclerView 触摸监听中的行为，在 ForEach/ListItem 条目上逐项接 .onClick 等事件；报告列为已实现前检索到对应事件代码。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
