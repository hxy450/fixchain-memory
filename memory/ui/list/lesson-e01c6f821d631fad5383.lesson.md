# ExpandableListView 未设组点击监听时组头仍按默认切换展开；按 isExpanded 切换的资源由可变展开状态驱动

ID：`lesson-e01c6f821d631fad5383` · 版本：1

[本主题](index.md)

## 何时使用

界面实现及对齐修复阶段，把 ExpandableListView + BaseExpandableListAdapter 翻译为 ArkUI 列表，确定组头交互与展开状态时

## 适用情境

源 Activity 只调用 expandGroup(n) 设定初始展开，没有 setOnGroupClickListener（或监听返回 false）；getGroupView 按 isExpanded 切换上下箭头等资源；目标用 List/ForEach 渲染分组。

## 例外与边界

- 源端注册了 OnGroupClickListener 并返回 true 拦截默认行为，此时按监听体实现

## 原因

“没有注册监听器”表示沿用框架默认交互，不表示没有交互：ExpandableListView 点击组头默认切换该组展开/折叠，expandGroup 只决定初始状态；getGroupView 按 isExpanded 取资源也说明展开状态会变。来源中修复者完整读到了 Activity、适配器与组头布局，仍把“未设监听”扩写成“组头不可点、保真”，只渲染组 0 子项、箭头写成 groupPos === 0 常量，经过两轮对齐才改成可切换。

## 做法

1. 翻译 Android 控件时先列出该控件的默认交互；源端未注册监听或监听返回 false，就在目标端补上默认行为（组头 onClick 切换本组展开）。
2. 适配器按 isExpanded 等运行时参数切换资源时，在目标端用可变的展开集合同时驱动子项渲染和箭头，初始值取 expandGroup 的组；不用下标常量代替。
