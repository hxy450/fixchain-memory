# 异步分页列表新增批量异步修补（如返回时逐条查询行内标记）时，按列表代次丢弃过期结果、按 ID 修补当前列表，不整表回写

ID：`lesson-4cfd4cbcecfb3de96037` · 版本：4

[本主题](index.md)

## 何时使用

列表页实现阶段，为触底分页、下拉刷新的列表新增返回后状态同步等批量异步查询时

## 适用情境

列表由分页回调异步追加、下拉刷新整体替换；返回页面时要逐条 await 本地查询来刷新行内标记；页面可能已有请求序号或 busy 锁保护了部分入口。

## 原因

在 await 前复制整张列表、结束后整体赋回，会用旧快照覆盖等待期间追加的分页或刷新后的新列表；同页已有的请求序号如果没用到新增的异步入口，保护就漏了一处。

## 做法

1. 新增批量异步查询时先记录列表代次（沿用页面已有的请求序号，若有），等待结束后代次已变就放弃；命中项按 ID 修补当前列表，不在 await 前复制整表再赋回。
2. 修补后的重绘按状态模型选择：条目是可观察对象时直接更新其字段；条目是普通对象时只能靠 key 变化触发重建，才把变化并入 key，并接受条目重建。
3. 页面已有请求序号或 busy 锁时，逐一核对分页回调、返回刷新、行内按钮等每个新增异步入口是否需要同类保护。
