# 列表长按上下文菜单按源 onCreateContextMenu 契约逐项移植

ID：`lesson-9975dd1d15f5c73758e8` · 版本：1

[本主题](index.md)

## 何时使用

功能切片接线阶段，为列表页与首页区段实现条目长按交互和上下文菜单时

## 适用情境

源经 registerForContextMenu 与 onCreateContextMenu 弹出菜单：选择模式中直接返回、设置标题、共享准备函数决定可见项、multi_select 默认隐藏仅子类开放；目标在多个页面、共享组件和区段组件中移植。

## 原因

照兄弟页把长按直接接到进入多选、自拟可见项与顺序、漏标题与选择态守卫、在区段内放页内浮层，都会让菜单与源不一致。

## 做法

1. 长按弹菜单，multi_select 才进多选；选择态长按提前返回；设标题；可见性调用已移植的共享准备函数，按菜单 XML 膨胀顺序输出（读 XML 时保留 android:visible）。
2. 区段、卡片组件用 openCustomDialog 等全局弹层承载菜单；宿主不开放多选时不渲染 multi_select。
3. 规格条款与 UI 阶段写法冲突时按条款与源码改，不以“已接受的简化”保留。
