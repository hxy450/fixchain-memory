# 列表长按上下文菜单按源 onCreateContextMenu 契约逐项移植：长按弹菜单、选择态早返回、标题、可见项与 XML 顺序

ID：`lesson-9975dd1d15f5c73758e8` · 版本：2

[本主题](index.md)

## 何时使用

功能接线阶段，为列表页、共享组件与区段组件实现条目长按交互和上下文菜单时

## 适用情境

源列表经 registerForContextMenu 与 onCreateContextMenu 弹出菜单：选择模式中直接返回、setHeaderTitle 设标题、共享准备函数决定可见项；部分菜单项在 XML 中 android:visible=false、只在特定页面或子类中 setVisible(true)（例如进入多选的动作项）；onContextItemSelected 处理点击；目标要在多个页面、共享组件和区段组件中移植。

## 原因

照兄弟页把长按直接接到进入多选、自拟可见项与顺序、漏标题与选择态守卫、在区段内放页内浮层，都会让菜单与源不一致。

## 做法

1. 以源 onCreateContextMenu/onContextItemSelected 为清单逐项实现：长按先弹菜单，进入选择模式的动作项被选中才进多选；选择态长按提前返回；设标题；可见性调用已移植的共享准备函数与子类开放规则，按菜单 XML 的膨胀顺序输出（读 XML 时保留 android:visible）。菜单项的 id 与行为从当前菜单 XML 与 handler 解析。
2. 区段、卡片组件用 openCustomDialog 等全局弹层承载菜单；宿主不开放某项（如多选）时不渲染该项。
3. 规格条款与 UI 阶段写法冲突时按条款与源码改，不以“已接受的简化”保留。
