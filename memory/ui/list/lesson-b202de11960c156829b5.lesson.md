# 列表项新增独立副行显示某字段时，主行的空值回退不再回退到同一字段

ID：`lesson-b202de11960c156829b5` · 版本：2

[本主题](index.md)

## 何时使用

界面实现阶段，迁移设备、联系人等列表项的主标题、副标题与空值回退文案时

## 适用情境

源端列表项只有一个名称控件，名称为空时回退显示地址或 ID；目标布局另加了一行地址/ID 副标题；名称来自平台接口，无名条目较多。

## 原因

源端的“回退到地址”只在单行里成立；加了副行后仍回退到同一字段，无名条目两行显示相同的值。来源中蓝牙设备列表的写者读过源端单行适配器与布局，却在新增 MAC 副行的同时保留主行回退到 MAC，真机上 8 个设备两行都是 MAC。修复者认为平台对无名设备会把 MAC 当名称返回，这一点未在 SDK 声明中核实。

## 做法

1. 新增副行后，把主行空值回退改为“未知设备”等占位文案，副行固定展示该字段。
2. 写完按“有名称 / 名称为空 / 名称等于副行字段”三种样本逐行自检，不出现两行相同。
3. 空白名称可按既定无名规则归一；只有已核平台接口确以地址作为无名回退、且当前字段属于该回退时，才把与地址相同（按实际地址语法忽略分隔符和大小写）的值归一为无名称。否则保留真实返回名并登记来源待核，不仅凭字符串相同删除可能的设备名；已核归一规则由模型或服务的单一入口供扫描、已配对、已连接来源共用。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
