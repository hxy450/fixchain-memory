# 侧栏分类页的右侧做成承载全部一级分组的 List + Scroller：点击 scrollToIndex、onScrollIndex 回写，并迁移程序滚动保护

ID：`lesson-7723af3766fb843a2577` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与界面实现阶段，迁移“左侧一级分类栏 + 右侧分组内容区”的分类页、确定右侧展示范围与左右联动时；按“对比源端”修复联动时

## 适用情境

源端左侧一级分类与右侧按一级分类分组的单一滚动列表双向联动：点击左侧滚到对应分组，滚动右侧回写左侧选中项，并用标志位屏蔽点击引发的程序滚动回调（如 LazyListState、animateScrollToItem、visibleItemsInfo）；规格可能只写“右侧展示对应分类分组”“用列表控制器表达选择与滚动联动”。

## 原因

按选中索引只渲染一个分组，或把全部分组堆进没有控制器的 Scroll，都无法联动；只补 scrollToIndex 与 onScrollIndex 而不加程序滚动保护时，动画滚动途中的中间索引会覆盖点击选中项。来源中实现者读源码时回执被截断，右侧只渲染选中分组；修复者读全源码后改成显示全部分组却仍未加 Scroller，点击左侧不再影响右侧；补联动的修复者没读源码，onScrollIndex 无条件回写，选中态抖动回跳。

## 做法

1. 右侧用带 Scroller 的 List，每个一级分类一个 ListItem（分组标题加二级分类网格）；左侧点击调用 scrollToIndex，右侧 onScrollIndex 回写选中项。
2. 迁移程序滚动保护：点击时记录目标索引，动画期间忽略 onScrollIndex 的中间索引，命中目标或超时后解锁，连续点击以最新目标覆盖。
3. 改变右侧展示结构或补联动前，读源端对应组件的状态与副作用代码（LaunchedEffect、可见项计算、标志位）；规格描述分栏页时写明内容区展示全部分组还是只显示选中项。

## 可选检查

- 提交前检索目标文件确有 Scroller、scrollToIndex 与 onScrollIndex；结构里只有按 selectedIndex 取出的单个分组时，判定未满足联动要求。

来源支持：2 张卡 · 1 次迁移 · 1 个应用
