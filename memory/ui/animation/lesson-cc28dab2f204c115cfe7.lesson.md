# 源端条件显隐块（AnimatedVisibility、if）只包住部分兄弟时，常驻折叠容器只放块内节点，块外兄弟写在容器外常驻

ID：`lesson-cc28dab2f204c115cfe7` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把源端 AnimatedVisibility 或条件块转写为常驻折叠容器（显式宽/高在 0 与内容尺寸间切换并 clip，或 if 分支），决定哪些兄弟节点放进容器时

## 适用情境

源端同一行或同一列里既有常驻节点，又有只包住其中一部分兄弟的 AnimatedVisibility(visible) 或 if 块；目标用常驻容器配显式宽/高与 clip(true) 实现显隐，展开尺寸按容器内节点手算成常量。

## 原因

折叠容器宽高为 0 时整个容器都看不见，clip(true) 又会静默裁掉超出展开尺寸的节点；把块外的常驻兄弟也放进容器，关闭态它跟着消失，打开态多出的节点被裁掉。注释与报告仍写“只有某节点受控”，编译与结构检查都发现不了。

## 做法

1. 建容器前按源码分出 lambda（或 if）内外的节点：只把块内节点（连同块内的 Spacer、间距）放进折叠容器；块外兄弟写在容器外常驻，源端间距在块内还是块外就跟着写在哪一侧。
2. 展开尺寸写成常量时按容器内实际子节点的尺寸与间距逐项加总核对；合计对不上，说明节点归属写错了。

## 可选检查

- 写完按开关的每个状态各数一遍可见控件，与源端对照。
