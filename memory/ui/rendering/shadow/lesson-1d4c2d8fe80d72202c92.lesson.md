# 进入像素字段的阴影参数应显式换算并收敛到共享映射

ID：`lesson-1d4c2d8fe80d72202c92` · 版本：1

[本主题](index.md)

## 何时使用

规格提取、实现或收敛阶段，把源端 dp 高程映射为目标端阴影半径、偏移和模糊参数时

## 适用情境

源端用 dp 高程表达阴影，目标 API 的数值字段以 px 为单位；工程同时存在共享高程映射和页面内联 shadow 调用。

## 例外与边界

- 项目明确采用经过当前设备与主题校准的预置阴影样式，并接受其与源端高程模型的差异

## 原因

把 dp 数直接写入 px 字段会随设备密度改变视觉强度；共享函数与内联配方并存还会让相同高程产生不同阴影，后续校准无法统一生效。

## 做法

1. 读取当前 SDK 字段的单位说明，把每个 dp 或 vp 来源到 px 字段的换算写进公式，并在调用边界使用当前 UI 上下文。
2. 所有源端高程阴影经同一共享映射生成，不用未校准的预置样式或页面内联常量绕过映射。
3. 收敛派工逐项列出共享渲染原语，替换完成前保留局部差异并核对，不整文件盲改。

## 检查

- 搜索全工程阴影调用，确认除共享映射定义外没有绕行通路；再用至少三个高程档位在当前密度下比较扩散、偏移与透明度。
