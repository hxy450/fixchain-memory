# 进入像素字段的阴影参数应显式换算并收敛到共享映射

ID：`lesson-1d4c2d8fe80d72202c92` · 版本：2

[本主题](index.md)

## 何时使用

规格提取、实现或收敛阶段，把源端 dp 高程映射为目标端阴影半径、偏移和模糊参数时

## 适用情境

源端用 dp 高程表达阴影，目标 API 的数值字段以 px 为单位；工程同时存在共享高程映射和页面内联 shadow 调用。

## 例外与边界

- 项目明确采用经过当前设备与主题校准的预置阴影样式，并接受其与源端高程模型的差异

## 原因

把 dp 数直接写入 px 字段会随设备密度改变视觉强度；共享函数与内联配方并存还会让相同高程产生不同阴影，后续校准无法统一生效。

## 做法

1. 把源端 dp 高程到目标阴影字段的单位写清；采用 ShadowOptions 等 API 时，依据当前 SDK 字段说明，在边界完成所需的 vp/px 换算，不按名称猜单位。
2. 相同源高程语义复用当前工程的共享映射；当前任务涉及的调用点采用该映射，避免另写一组未校准的常量。
3. 修改公共映射时保留原有语义差异，分清本次涉及的调用方；局部任务不自动扩为全工程收敛。

## 可选检查

仅在适用条件不确定、与当前输入冲突或需要验证关键假设时按需执行；优先复用已有证据和正常测试。
不因读取本条经验而额外启动验证流程；项目原有必需测试照常执行。

- 仅当字段单位不明或当前阴影结果与配方不一致时，复用 SDK 单位说明与正常测试中的相关高程样本；无需默认扫描全工程或新增多个档位截图。
