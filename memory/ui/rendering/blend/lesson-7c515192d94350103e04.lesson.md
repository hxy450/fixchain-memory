# 依赖已有画布内容的混合效果应先建立共同离屏组

ID：`lesson-7c515192d94350103e04` · 版本：1

[本主题](index.md)

## 何时使用

规格提取或界面实现阶段，把源端同一画布上的 draw-content 加 blend 操作映射为目标端节点树时

## 适用情境

源效果先绘制底盘或字形，再让渐变按 Plus、Darken 等模式与已有像素混合；目标实现把字形、渐变和底盘放成独立兄弟节点，并准备在单个节点上启用离屏混合。

## 例外与边界

- 目标框架文档和当前设备实测均确认该混合节点能读取预期的兄弟背景像素

## 原因

同名 blend mode 只定义像素运算，不保证参与运算的画布范围相同；独立节点的离屏缓冲若不含兄弟内容，依赖底色的加法或变暗效果会退化为色块或错误着色。

## 做法

1. 先列出参与混合的源像素与目标像素，再把需要共享像素上下文的字形、渐变及必要底盘放入同一离屏组。
2. 组内优先使用只依赖明确 alpha 掩码的 SRC_IN 或 DST_IN 结构；依赖目标框架画布状态的方案保留为经实测后才启用的分支。
3. SDK 只说明与下方画布混合、但未界定画布范围时，将结构标为待设备核验，不定为硬等价。

## 检查

- 用能区分底色参与与否的测试图分别验证浅色和深色分支，确认白底、深色字形与渐变区域的像素结果符合源端算式。
