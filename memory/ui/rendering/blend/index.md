迁移颜色混合、离屏分组与遮罩运算时进入。

## 本级经验

- [用遮罩替代颜色混合前，确认原颜色运算可被等价表达](lesson-5fabe0a98b69a73b9dc6.lesson.md)
  - 时机：视觉修复或实现阶段，用 SRC_IN 等 alpha 遮罩结构替代源端 Plus、Darken 等颜色混合时
  - 情境：准备把 Plus、Darken 等依赖已绘制颜色的运算，改为 SRC_IN 等 alpha 取形结构；字形颜色、透明度和背景合成会影响结果。
  - 例外：源效果本来只依赖 alpha 取形，或目标端仍使用经验证等价的同一颜色运算
- [迁移 blendMode 时先明确参与混合的画布范围](lesson-7c515192d94350103e04.lesson.md)
  - 时机：规格提取或界面实现阶段，把源端同一画布上的 draw-content 加 blend 操作映射为目标端节点树时
  - 情境：源效果先绘制底盘或字形，再让渐变按 Plus、Darken 等模式与已有像素混合；目标实现把字形、渐变和底盘放成独立兄弟节点，并准备在单个节点上启用离屏混合。
  - 例外：目标框架文档和当前设备实测均确认该混合节点能读取预期的兄弟背景像素
