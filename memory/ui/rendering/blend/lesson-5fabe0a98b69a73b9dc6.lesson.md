# 用遮罩替代颜色混合时，应把源运算预混进色标

ID：`lesson-5fabe0a98b69a73b9dc6` · 版本：1

[本主题](index.md)

## 何时使用

视觉修复或实现阶段，用 SRC_IN 等 alpha 遮罩结构替代源端 Plus、Darken 等颜色混合时

## 适用情境

源效果对已经着色并合成到背景的字形像素执行逐通道运算，目标结构改为不透明或半透明图形遮罩加渐变色标。

## 例外与边界

- 源效果本来只依赖 alpha 取形，或目标端仍使用经验证等价的同一颜色运算

## 原因

SRC_IN 只用源颜色乘目标 alpha，既不会自动执行加法或取最小值，也不能把半透明 tint 背后的合成色还原出来；直接换算子会保住形状却改变颜色。

## 做法

1. 写出源端逐通道公式，并把字形的内容色、alpha 与背景合成结果作为显式输入。
2. 采用 SRC_IN 取形时，先把源 blend 公式计算进渐变色标，再使用不透明遮罩；各主题分支分别计算，不假定结果相同。
3. 判定色差时从稳定区域采样像素，并用公式核对预期值，不只用亮暗或偏色等描述。

## 检查

- 分别测量浅色和深色主题中字形中心与相邻参考图形的像素，确认通道结果在当前容差内符合源端公式。
