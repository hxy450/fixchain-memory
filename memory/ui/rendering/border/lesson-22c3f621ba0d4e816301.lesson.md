# 绘制型修饰符迁移前应验证目标属性是否参与测量

ID：`lesson-22c3f621ba0d4e816301` · 版本：1

[本主题](index.md)

## 何时使用

映射或实现阶段，把源端不改变布局尺寸的 border、drawBehind 等绘制效果落到目标容器属性时

## 适用情境

源端描边绘制在调用方已定尺寸的盒内，目标容器本身没有显式宽高、依赖内容决定尺寸，而目标 border 属性可能计入容器测量。

## 例外与边界

- 目标容器已有明确外框尺寸，或当前框架版本已验证该绘制属性不会改变测量结果

## 原因

源端纯绘制效果若在目标端参与测量，会把内容盒连同描边一起撑大；视觉上只多出很小的边宽，却会改变对齐、间距和父容器布局。

## 做法

1. 映射前分别记录源端内容盒、外框和绘制区域，并确认目标属性在当前框架中的测量语义。
2. 无定尺容器上优先使用不参与测量的 overlay 绘制层，或先把预期外框尺寸提升到容器再应用描边。
3. 实现注释写明尺寸由谁决定，避免后续将内容定尺与描边定尺混为一谈。

## 检查

- 比较应用效果前后的布局 bounds，并与源端逐边核对；描边存在与否不应改变预期内容盒或外框尺寸。
