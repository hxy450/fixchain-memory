## 本级经验

- [绘制型修饰符迁移前应验证目标属性是否参与测量](lesson-22c3f621ba0d4e816301.lesson.md)
  - 时机：映射或实现阶段，把源端不改变布局尺寸的 border、drawBehind 等绘制效果落到目标容器属性时
  - 情境：源端描边绘制在调用方已定尺寸的盒内，目标容器本身没有显式宽高、依赖内容决定尺寸，而目标 border 属性可能计入容器测量。
  - 例外：目标容器已有明确外框尺寸，或当前框架版本已验证该绘制属性不会改变测量结果
