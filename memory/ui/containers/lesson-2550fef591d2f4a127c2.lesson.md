# AlertDialog类自定义弹窗做成页面根的整窗层，按框架规则定宽

ID：`lesson-2550fef591d2f4a127c2` · 版本：1

[本主题](index.md)

## 何时使用

规格提取、执行派工与界面实现阶段，为AlertDialog/DialogFragment自定义布局弹窗决定ArkUI挂载层级、遮罩范围与面板宽度时

## 适用情境

源以AlertDialog.Builder.setView承载自定义布局（独立窗口）；目标改为组件树中条件渲染的自定义弹层，而触发方与回调消费方是嵌在页面里的子组件。

## 例外与边界

- 改用CustomDialogController等本身即窗口级的弹窗能力时，挂载层级由框架负责，只需按框架规则核对宽度与遮罩

## 原因

弹层挂在子组件里时，遮罩只盖子组件区域，面板按子组件居中；把“回调由谁消费”当成“弹层挂在哪里”，派工就会把弹层放进子组件；宽度按百分比估算也会偏离框架规则。

## 做法

1. 契约写明窗口框架：整窗约60%变暗、面板在状态栏与导航条之间居中、宽度为窗宽95%（横屏65%）减两侧各16dp背景内缩。
2. 弹层由@Entry页面根Stack顶层渲染并持有状态，传入系统栏避让高度；结果经回调交回子组件；内容视图只放内容，遮罩由统一的整窗层承担。
3. 派工时把“回调消费方”和“弹层挂载位置”分开写；写盘边界不允许改页面时，把页面挂载列为后续接线项，而不是改挂到子组件。
