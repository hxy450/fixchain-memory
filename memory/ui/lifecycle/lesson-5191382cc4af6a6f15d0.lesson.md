# 条件渲染换出自绘组件时，按身份解除绑定，并在新实例挂上后重画

ID：`lesson-5191382cc4af6a6f15d0` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与界面实现阶段，把安卓转屏重建（横竖屏双布局加onPause存档、onResume恢复）映射为ArkUI按方向if/else切换布局，并为分支内的自绘组件设计控制器与重画时机时

## 适用情境

源Activity未声明configChanges，竖横屏各一套布局，转屏时Fragment经存档→恢复向新视图重新绘制；目标在build中按方向if/else切换两套布局，每套挂一个Canvas自绘组件，共用宿主持有的控制器。

## 原因

条件渲染换分支时，新旧实例aboutToAppear/aboutToDisappear的先后不应被依赖；单槽共享绑定若无条件清空，旧实例卸载会清掉新实例的绑定；新实例的画布和任务队列是空的，只切换布局状态不会有人重画。

## 做法

1. 共享控制器解绑时先比较身份，只在当前绑定的是自己时清空；也可给每个分支实例各配一个控制器。
2. 新实例挂上（bind）后，按源端转屏重建路径执行存档→恢复→重新入队绘制（含选中动画与视图态复位）。
3. 规格中保留源端“旋转屏幕”这一验收触发，写明目标端由哪个事件承接存档与恢复及其可见效果，不因“无配置重建”删掉它。
