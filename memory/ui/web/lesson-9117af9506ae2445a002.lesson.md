# WebviewController 装载以 onControllerAttached 为前提：未挂接时缓存参数，挂接后补发一次

ID：`lesson-9117af9506ae2445a002` · 版本：1

[本主题](index.md)

## 何时使用

实现阶段，在 Web 组件页面里用 WebviewController 装载内容（loadData、loadUrl）或调用其他控制器方法，且数据异步到达、可能早于组件挂接时

## 适用情境

目标页创建 WebviewController 并传给 Web 组件，正文数据由数据库或网络异步取得后调用 controller.loadData/loadUrl；源端 WebView 实例创建后即可调用 loadDataWithBaseURL，没有挂接时机。

## 原因

web.d.ts 注明控制器绑定成功前调用 Web 组件相关接口会抛 js-error；用“异步加载足够慢”推定已挂接，在数据先到或缓存命中时装载就失败。onControllerAttached 回调时网页尚未加载，只能调用 loadUrl、getWebId 一类与网页内容无关的接口。

## 做法

1. 在 onControllerAttached 中置挂接标志；数据到达时已挂接就直接 loadData，未挂接就缓存参数，挂接回调里补发一次，并记下已装载，避免重复装载。
