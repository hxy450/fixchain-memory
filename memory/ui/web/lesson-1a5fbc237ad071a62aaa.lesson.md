# 宿主原生标题栏与 H5 自带导航栏按 H5 当前状态双向决定显隐；单页 H5 的状态从页面内容判断

ID：`lesson-1a5fbc237ad071a62aaa` · 版本：3

[本主题](index.md)

## 何时使用

WebView 页面实现与修复阶段，决定宿主原生返回/标题栏在 H5 各页面状态下是否显示时

## 适用情境

目标页用 Web 加载第三方单页 H5，宿主自带返回与标题栏；H5 首页没有自己的导航栏，而结果、查单、选择城市等子状态自带返回栏，状态切换时 URL 可能不变。

## 原因

宿主栏该不该显示取决于 H5 当前状态；整体删除会让首页丢失返回与标题，只在命中子页时隐藏又不恢复会形成单向状态，按 URL 判断则漏掉 URL 不变的单页切换。

## 做法

1. 先对照源端参考截图与可读到的宿主代码，确认宿主栏在 H5 各状态下的显隐；宿主栏由外部库承载、子状态行为读不到时，在交接中写明这一未知，再按下面建立状态映射。
2. 列出 H5 各状态中哪些自带导航栏、哪些只靠宿主栏；只在自带导航栏的状态隐藏宿主栏，并把显隐写成当前状态的完整映射，每次判定都给出显示或隐藏，回到首页态时恢复宿主栏。
3. 第三方单页 H5 切换状态时 URL 可能不变，不只靠 URL 或 onOverrideUrlLoading 判断：用 runJavaScript 检测稳定的 DOM 特征（如结果页标题格式、页面特征文字），在页面事件与短周期探测中都更新，覆盖进入瞬间。

## 可选检查

- 需要确认时，在真机逐个状态核对：首页有返回和标题、每个子状态只有一层导航栏、从子状态返回后宿主栏恢复。
