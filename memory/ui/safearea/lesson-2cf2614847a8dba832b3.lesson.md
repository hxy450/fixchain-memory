# 向子页或页内浮层下发状态栏高度参数时写明消费方式，挂在同一 Stack 的每一层都拿到它

ID：`lesson-2cf2614847a8dba832b3` · 版本：1

[本主题](index.md)

## 何时使用

派工与界面实现阶段，向子页、页内浮层下发状态栏高度参数，或把浮层挂进从窗口顶起的宿主 Stack 时

## 适用情境

宿主页采用“子页自理”分工，以组件参数下发状态栏高度；子页或浮层（遮罩 + 居中卡片、铺满父容器）与列表、顶栏同挂一个 Stack；派工或槽位契约可能只列出回调参数，或写“接收但本页不使用”。

## 例外与边界

- 目标父容器已替该层加了顶部避让，且能指出对应代码位置

## 原因

参数接上却在派工里写“本页不使用”，实现者会照办，状态栏高度就无人消费；槽位契约和派工漏掉某一层时，只有这一层压到状态栏下、其他层正常，容易被当作局部偏差放过。

## 做法

1. 派工不写“接收但不使用”；认为某层无需消费时，给出源端父容器已消费该 inset 的源码位置。实现者收到未消费的参数时，先核目标父容器是否替它避让，没有就消费。
2. 浮层挂在从窗口顶起的 Stack 时，槽位契约和派工都带上状态栏高度，组件以参数透传，根节点加顶部 padding，与兄弟层同一基准。

## 可选检查

- 有疑问时检索每个状态栏高度参数的消费点；对照源端截图核浮层遮罩起点是否等于状态栏高。
