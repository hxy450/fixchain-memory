# 根为 DrawerLayout 且 NavigationView 自带 fitsSystemWindows 时，状态栏避让只给主内容列，抽屉头部画到状态栏下

ID：`lesson-84bcbad22600d3763029` · 版本：1

[本主题](index.md)

## 何时使用

界面实现与共享件收敛阶段，为抽屉页补状态栏避让、把 DrawerLayout + NavigationView + Toolbar 收进共享抽屉基座（SideBarContainer）时；规格提取阶段写抽屉页的沉浸与安全区段时

## 适用情境

源布局根是 DrawerLayout fitsSystemWindows=true，内容列（Toolbar + 主内容）在状态栏之下；NavigationView 自身 android:fitsSystemWindows="true" 并带 app:headerLayout。目标用共享抽屉基座（SideBarContainer 同时承载抽屉面板和工具栏/内容列），页面用窗口模型的顶部避让值做前景避让。

## 原因

两处 fitsSystemWindows 由不同子视图消费：内容列下移到状态栏之下，DrawerLayout 在其上方画状态栏底色；NavigationView 从窗口顶开始画，头部延伸到状态栏下并叠一层 insetForeground 前景。把避让加在同时包住抽屉面板的外层容器上，抽屉头部会跟着下移。

## 做法

1. 顶部避让只加在主内容列：在工具栏上方放一条高为顶部避让值的占位，颜色取源主题 colorPrimaryDark（DrawerLayout 状态栏底色的默认来源）；不加在 SideBarContainer 或包住共享抽屉基座的外层容器上。
2. 抽屉面板从窗口顶开始画，头部高度不变，顶部叠一条高为顶部避让值的 insetForeground 前景：颜色取当前主题或样式的 insetForeground，未覆盖时用 MDC 的 Widget.Design.ScrimInsetsFrameLayout 默认值（例：material 1.12.0 中定义为 #4000，即 #44000000）。
3. 收敛成共享抽屉基座时把这两处避让都放进基座，并在契约里写明宿主页不在外层加顶部 padding；规格按子视图逐个写出 fitsSystemWindows 由谁消费，不只写根节点。

## 可选检查

- 需要核对时打开抽屉截图：头部色块从窗口顶开始，状态栏区比头部底色暗。
