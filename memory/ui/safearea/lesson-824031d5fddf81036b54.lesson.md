# 系统栏图标深浅按源端状态栏配置设置，不照搬沉浸式模板的浅色文字默认值

ID：`lesson-824031d5fddf81036b54` · 版本：1

[本主题](index.md)

## 何时使用

沉浸式窗口配置阶段，调用 setWindowSystemBarProperties 设置 statusBarContentColor/navigationBarContentColor 时

## 适用情境

目标全屏窗口把系统栏背景设为透明，页面内容延伸到状态栏下；Android 源端 BaseActivity/主题用 ImmersionBar darkMode(true)、windowLightStatusBar 或白色状态栏配深色图标；沉浸式 skill 示意写“透明背景 + 浅色文字”。

## 原因

内容色决定时间、电量等系统图标的深浅；照模板写白色，浅色页面顶部的系统图标会看不见。来源中修复者只读了派工和沉浸式 skill（示意浅色文字、诊断表建议 #FFFFFF），没有读源端 BaseActivity/主题，就写成了白色。

## 做法

1. 设置内容色前读取源端基类/主题的状态栏配置（darkMode、windowLightStatusBar、状态栏颜色）和页面顶部背景色：浅色背景配深色图标（如 #FF000000），深色背景配浅色图标；页面间不同时按页切换。
