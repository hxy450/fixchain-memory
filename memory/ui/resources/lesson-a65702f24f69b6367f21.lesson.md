# nodpi与sw分档目录的位图按源目录语义换算显示尺寸

ID：`lesson-a65702f24f69b6367f21` · 版本：1

[本主题](index.md)

## 何时使用

界面实现与结构收尾阶段，为wrap_content显示的位图写ArkUI Image显式宽高、计算wrap_content容器宽度，或审核图标尺寸自愈脚本结果时

## 适用情境

源位图只放在drawable-nodpi，或只按最小宽度放在drawable-swNNNdp等无密度限定目录；资源转换已把单份位图拍平到base/media。

## 原因

nodpi位图不随密度缩放、按物理像素显示；sw目录无密度限定，按mdpi计dp并按设备最小宽度选档。把像素数当vp、拿大档位图当手机尺寸或按默认密度相除，都会得到错误尺寸，并传到依赖它的容器宽度计算。

## 做法

1. drawable-nodpi位图用px单位按源像素写宽高（如'220px'），不当作1dp=1px写成vp。
2. 只有sw分档、无密度限定的位图，按目标设备最小宽度选档（手机通常落在sw320dp档），取该档像素数作vp；只拷了更大档时，大图只作光栅源。
3. 计算wrap_content容器宽度时，先把每个子项按其资源目录换算成vp，再取最宽者加margin。
4. 图标尺寸自愈脚本补的尺寸，逐条核对图片的源目录；nodpi、sw分档等非密度目录不接受静默回退默认密度的结果。
