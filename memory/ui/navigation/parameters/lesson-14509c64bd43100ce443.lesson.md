# 源端带结果回调的选择器（show(..., 当前值) { result -> 写回 }）改为路由页或弹窗打开时，同一改动接通结果回传并写回当前编辑状态

ID：`lesson-14509c64bd43100ce443` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把源端带回调的选择弹层（文案库、素材库等）改成 ArkUI Navigation 跳转或弹窗，并接到编辑项时

## 适用情境

Android 以 DialogFragment.show(..., 当前值) { result -> 写回控件 } 打开选择器；迁移后调用页 pushPathByName 打开同名目的地，目标页参数类只带初始值，或其加载、选中仍是前向引用。

## 原因

只移植“打开”而不移植“回传”，选择器能打开，选中后只关闭，编辑器没有任何变化；目标页参数类没有回调字段时，调用方即使写好了更新方法也接不上。

## 做法

1. 在同一改动中定义并接通回传（参数带结果回调，或用 onPop 结果、结果令牌），调用方把结果写入当前编辑状态并刷新预览。
2. 接入目标页前先读它的参数类与前向引用：没有回传字段，或加载、选中仍是前向引用时，要么在授权范围内补齐两端，要么在完成回执里登记为未闭合，不把入口标成已完成。

## 可选检查

- 在调用页检索 pushPathByName 的目标页名，确认参数带结果回调或存在结果接收处理，并与源端回调里的写回动作逐项对应。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
