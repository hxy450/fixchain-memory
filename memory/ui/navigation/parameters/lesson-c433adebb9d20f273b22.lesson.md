# 页面路由参数的缺失哨兵值与有效性判定保持一致，错误态下隐藏依赖该参数的操作入口

ID：`lesson-c433adebb9d20f273b22` · 版本：2

[本主题](index.md)

## 何时使用

页面转换阶段为目的地参数写默认值、有效性判定和无效路由错误态时

## 适用情境

目标页从路由参数取 id，参数类有默认值；规格要求缺失 id 进入无效路由错误态、不渲染假数据；页面上有开始、编辑等依赖该 id 的按钮。

## 原因

默认值为 0 而判定只写 id < 0 时，缺参以 0 通过校验去加载不存在的数据；错误分支外的按钮仍然可点。来源中转换者读到了“缺失 id 进入错误态”的验收条目，仍这样写。

## 做法

1. 参数类默认值与判定用同一个哨兵规则（例如都把 ≤ 0、非整数视为无效）。
2. 开始、编辑等依赖该参数的入口放进与错误态相同的条件里，错误态不渲染。
