# 页面路由参数的缺失哨兵值与有效性判定保持一致，错误态下隐藏依赖该参数的操作入口

ID：`lesson-c433adebb9d20f273b22` · 版本：3

[本主题](index.md)

## 何时使用

页面转换阶段为目的地参数写默认值、有效性判定和无效路由错误态时

## 适用情境

目标页从路由参数取 id，参数类有默认值；规格要求缺失 id 进入无效路由错误态、不渲染假数据；页面上有开始、编辑等依赖该 id 的按钮。

## 原因

参数类默认值与有效性判定不一致时（如默认值 0、判定只写 id < 0），缺参会通过校验去加载不存在的数据；错误分支外的按钮仍然可点。

## 做法

1. 哨兵取源端的缺省语义：nav <argument> 的 android:defaultValue、getLongExtra/getIntExtra 的默认值或可空声明，并按业务查找接口确认有效域；参数类默认值与判定用同一个规则（例：源端默认 -1、有效 id 为正整数时都把 ≤ 0 视为无效；0 是合法 id 时改用 null 或域外值）。
2. 开始、编辑等依赖该参数的入口放进与错误态相同的条件里，错误态不渲染。
