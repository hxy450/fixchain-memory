# 源端 popUpTo(根){inclusive=true} 加 navigate(根) 映射为 NavPathStack 重建，不用 pop() 代替

ID：`lesson-96c890012b26b5cb32cd` · 版本：2

[本主题](index.md)

## 何时使用

接线阶段实现删除、克隆等操作完成后的导航时

## 适用情境

源端在操作完成后 navigate 到列表并 popUpTo 列表 inclusive，重建返回栈；目标用 Navigation + NavPathStack，列表是 Navigation 根内容。

## 原因

只 pop 一层会回到已失效的详情页（例如刚删除的条目），按返回还能继续进入。来源中接手者手上的登记表、两份弹窗回报和规格都写了“重建列表栈”，实现仍写成 pop()。

## 做法

1. 根是 Navigation 首页内容时用 navPathStack.clear() 回到根；根本身也在栈里时，清栈后再 push 根。
2. 写完在删除、克隆后各按一次返回，确认不会回到已失效的页面。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
