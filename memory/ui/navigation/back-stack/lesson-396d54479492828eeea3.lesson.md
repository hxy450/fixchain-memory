# 源端对话框、底部弹层或下拉菜单改成页内覆盖层后，在宿主 onBackPressed 里自顶向下逐层关闭，全部关闭后才进未保存门禁或出栈

ID：`lesson-396d54479492828eeea3` · 版本：8

[本主题](index.md)

## 何时使用

页面转换阶段，把源端 Dialog/AlertDialog/ModalBottomSheet/ExposedDropdownMenu（以及可能存在的 BackHandler）改写成 NavDestination 页内覆盖层、确定系统返回如何处理时

## 适用情境

源页的对话框、底部弹层或下拉菜单以 onDismissRequest 关闭；源页可能另有 BackHandler 处理行内编辑器或未保存门禁，也可能完全没有 BackHandler。目标把这些弹层做成 NavDestination 内 Stack 条件渲染的覆盖层或由 activeDialog 一类状态驱动的组件，而不是自带返回关闭的弹窗机制，系统返回统一交给宿主。也包括源端 ContextMenu 窗口、ActionMode 多选态被改写成页面 @Local 浮层或选择态，页面是嵌入宿主的组件。也包括 View 体系 AlertDialog（默认可取消、带 setOnCancelListener）被写成自带蒙层的共享页内浮层组件，只接蒙层点击，页面的返回拦截不感知弹窗。

## 例外与边界

- 弹层改用自带返回关闭的弹窗机制（openCustomDialog、bindSheet、NavDestinationMode.DIALOG 等）时，由弹窗自身处理返回

## 原因

Compose 的对话框与下拉菜单、View 体系的 Dialog、ContextMenu 与 ActionMode 都是独立窗口或模式，系统返回先交给它们（onDismissRequest、OnCancelListener、退出 ActionMode），页面的 BackHandler 只在没有弹层时才收到。搬进页面树后它们不再先收到返回；只翻译显式 BackHandler 或宿主不写返回处理时，覆盖层打开时按返回会走到保存或丢弃门禁，甚至整页出栈、退出应用。

## 做法

1. 列出本页所有可叠加的层（页内对话框、下拉或选项浮层、自绘底部弹窗、行内编辑器），先核各层源端的返回策略：可取消（默认，或 setCancelable(true)、DialogProperties 的 dismissOnBackPress 为 true）的层按返回调用它的关闭回调；不可取消（setCancelable(false)、dismissOnBackPress = false）的层消费返回但不关闭。onBackPressed 从上到下判断：最上层可见就按其策略处理并 return true；没有可见层时 return false 交给默认返回。“可见”用该层实际渲染的条件判断（含渲染时附加的数据条件），不只看打开标志。
2. 所有层都关闭后才进入未保存门禁或出栈。
3. 输出前对每个条件渲染的覆盖层（activeDialog 的每个取值、showXxx/pickerVisible 一类标志）和打开的编辑器各模拟一次返回，确认不会触发保存、丢弃或 pop；页内有这类覆盖层而宿主没有 onBackPressed 时先补上再交付。
4. 编排者把某个任务的页内覆盖层写法推广到后续派工时，同时写上“宿主 onBackPressed 按 onDismissRequest 关闭可见覆盖层”的配套要求。
5. 把 ContextMenu、ActionMode 等窗口型临时 UI 改写为页内状态时同步实现其返回语义：浮层打开时先关闭，多选态先退出，并消费本次返回；页面没有自己的返回钩子时，按 lesson-803ba029eea852122e77 经宿主的回调分发登记。
6. 返回键与点遮罩按源端各自的取消配置（setCanceledOnTouchOutside、dismissOnClickOutside 可与返回键不同）路由到同一取消处理，执行源端 OnCancelListener 的去向（如写首用标记、持久化勾选），不只关闭；共享浮层组件随组件交付返回键契约，消费它的页面逐个验证“弹窗打开时按返回只关弹窗、页面仍在、不叠弹”。
