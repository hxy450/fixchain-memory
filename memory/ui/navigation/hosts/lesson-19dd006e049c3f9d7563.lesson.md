# 源端在导航目的地内用 LocalLifecycleOwner 观察 ON_STOP/ON_RESUME 时，owner 是返回栈条目：导航离开与退后台都要触发，目标按 onHidden/onShown 接线，销毁前先调停止入口

ID：`lesson-19dd006e049c3f9d7563` · 版本：1

[本主题](index.md)

## 何时使用

规格提取阶段翻译 LifecycleEventObserver 的 ON_STOP/ON_RESUME 触发契约时；页面实现阶段把引擎或服务暴露的 onStop/onResume 一类入口接到 NavDestination 生命周期时

## 适用情境

源 Composable 用 DisposableEffect(LocalLifecycleOwner.current) 注册 LifecycleEventObserver，ON_STOP 时移交后台服务、暂停或保存，ON_RESUME 时取回；该 Composable 位于 navigation-compose 的目的地内。目标页面是 NavDestination，引擎是普通类，需由页面在 onShown/onHidden/aboutToDisappear 中显式调用入口；规格可能把触发写成“退后台/前后台切换”。

## 例外与边界

- 观察者挂在 Activity 或 ProcessLifecycleOwner 上：只对应应用前后台，按 Ability 或应用前后台回调接线

## 原因

目的地内的 LocalLifecycleOwner 是该页的 NavBackStackEntry：退后台、跳到其他目的地、返回出栈都会让它进入 ON_STOP，回到本页进入 ON_RESUME。把触发写成“退后台”，目标只接应用前后台或完全不接，导航离开时正在运行的任务会随页面销毁丢失，或在隐藏页里继续运行而不移交。出栈时 ON_STOP 先于观察者注销，这一顺序来自修复期对 navigation-compose 2.9.1 源码的查证，未在设备上复现源端。

## 做法

1. 规格提取时先确认 owner 是谁（Activity、进程、NavBackStackEntry），把会让它进入 ON_STOP/ON_RESUME 的用户路径逐条写成触发契约与验收：退后台、返回出栈、跳到其他目的地、回到本页。
2. 实现时把 ON_STOP 映射到 NavDestination.onHidden 的各类原因（被新页覆盖、出栈转场、应用退后台），ON_RESUME 映射到 onShown；离开路径要销毁引擎时（出栈、aboutToDisappear），先调用停止或移交入口，再 dispose。
3. 引擎把生命周期回调暴露为公开入口时，在页面规格与派工里写明各入口的调用位；本任务接不上就登记带负责方的移交项，不只写在代码注释里。

## 可选检查

- 对接线有疑问时，检索引擎每个公开生命周期入口都有调用方，并走一遍“运行中返回上一页”“运行中进入其他页”“运行中退后台再回来”三条路径。
