# 入口页 Navigation 宿主：NavDestination 首屏只在 navDestination 映射中注册并在空栈时压入同一栈，不作根内容；隐藏 navBar 时初始栈必须非空；.navDestination 直接传 @Builder

ID：`lesson-8953e390416a80d7dd8c` · 版本：4

[本主题](index.md)

## 何时使用

入口页实现或收尾接线阶段，创建 Navigation 宿主、决定首屏放在根内容还是压栈、编写 navDestination 分发时；为根 Navigation 决定是否设 hideNavBar 时

## 适用情境

目标入口页用 Navigation + @Provider NavPathStack 承载路由；首屏（启动页等）写成返回 NavDestination 的组件，在 onReady 取栈并按启动决策 pushPathByName 下一页；目的地由 @Builder 映射分发。也包括启动页以 NavDestination 为根、已在 pageMap 注册，入口却把它放进 Navigation 内容槽并加 hideNavBar(true)，初始栈为空；或首屏页依赖 onShown、onResult、onBackPressed（如接收文件选择结果），却作为 Navigation 首页内容承载。

## 例外与边界

- 首屏是普通组件（不返回 NavDestination）、作为 Navigation 根内容常驻，且不依赖 NavDestinationContext 取栈

## 原因

放在 Navigation 根内容里的 NavDestination 不在 NavPathStack 中，它的 context.pathStack 与宿主栈不一致，push 不产生新页（日志 current stack is not navPathStack）；把 .navDestination 写成箭头函数再调 Builder 会丢失 Builder 元数据（日志 Builder function is empty）。两者叠加时应用停在首屏。来源中收尾者读到首屏是 NavDestination 且在 onReady 取栈，仍把它直接放作根内容，并用箭头函数包装映射。放在首页内容里的 NavDestination 也收不到 onShown、onResult、onBackPressed；hideNavBar(true) 隐藏的正是承载首页内容的 navBar 槽，配合空栈启动时屏幕上没有任何业务节点（白屏）。

## 做法

1. 返回 NavDestination 的首屏只在 navDestination 映射中注册；根内容用空容器或普通组件，在入口 aboutToAppear（或根内容 onAppear）中、栈为空时用同一 NavPathStack pushPathByName 推入首屏（只推一次，指初始压栈；源端 NavHost 起点是在会重组的壳层里每次求值、会话内会变的表达式时，起点变化后要清栈并以新起点重压，见 lesson-43459cb01320674b2864）。依赖 onShown、onResult、onBackPressed 的页面都要由 NavPathStack 管理。
2. .navDestination 直接传 @Builder 方法，如 .navDestination(this.destination)，不再包一层箭头函数。
3. 只有确实不用 navBar 槽时才设 hideNavBar(true)，并同时保证初始栈非空；navBar 槽承载启动内容时不能隐藏它。

## 可选检查

- 冷启动日志中不应出现 Builder function is empty 或 current stack is not navPathStack。
- 入口接线的自检断言首屏可达（空栈初始压栈语句或一次启动截图）；编译通过、结构闭环或检索到启动 Builder 名都不能说明首屏可见
