# 返回 NavDestination 的首屏不作 Navigation 根内容：只在映射中注册并在空栈时压入同一栈，隐藏 navBar 时初始栈必须非空

ID：`lesson-8953e390416a80d7dd8c` · 版本：5

[本主题](index.md)

## 何时使用

入口页实现或收尾接线阶段，创建 Navigation 宿主、决定首屏放在根内容还是压栈时；为根 Navigation 决定是否设 hideNavBar 时

## 适用情境

目标入口页用 Navigation + @Provider NavPathStack 承载路由；首屏（启动页等）写成返回 NavDestination 的组件、已在 pageMap 注册，在 onReady 取栈并按启动决策 pushPathByName 下一页，或依赖 onShown、onResult、onBackPressed（如接收文件选择结果）；入口却把它放进 Navigation 内容槽，可能还加 hideNavBar(true)，初始栈为空。

## 例外与边界

- 首屏是普通组件（不返回 NavDestination）、作为 Navigation 根内容常驻，且不依赖 NavDestinationContext 取栈或页面生命周期回调

## 原因

放作 Navigation 根内容、不在根 NavPathStack 里的 NavDestination，其 context.pathStack 与宿主栈不一致，push 不产生新页（日志 current stack is not navPathStack），也收不到 onShown、onResult、onBackPressed。hideNavBar(true) 隐藏的正是承载根内容的 navBar 槽，配合空栈启动时屏幕上没有任何业务节点（白屏）。

## 做法

1. 返回 NavDestination 的首屏只在 navDestination 映射中注册；根内容用空容器或普通组件，在入口 aboutToAppear（或根内容 onAppear）中、栈为空时用同一 NavPathStack pushPathByName 推入首屏（只推一次）。依赖 onShown、onResult、onBackPressed 的页面都由 NavPathStack 管理。
2. 只有确实不用 navBar 槽时才设 hideNavBar(true)，并同时保证初始栈非空；navBar 槽承载启动内容时不能隐藏它。
3. 首屏压栈后，栈底页的系统返回按 lesson-efff93743d668b55b55a 接管，不让它出栈露出空白宿主。

## 可选检查

- 冷启动日志中不应出现 current stack is not navPathStack。
- 入口接线的自检断言首屏可达（空栈初始压栈语句或一次启动截图）；编译通过、结构闭环或检索到启动 Builder 名都不能说明首屏可见
