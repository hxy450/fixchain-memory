# 源 Activity 或其基类 onCreate 调 overridePendingTransition(0,0) 时，“进入无转场”是目的地页的属性：进入该页的每条路由（按钮跳转、引导完成、启动分流、抽屉）都关闭转场

ID：`lesson-9886f489045488c8b454` · 版本：1

[本主题](index.md)

## 何时使用

规格提取阶段写页面规格与路由契约时；实现阶段写 pushPathByName/replacePathByName 时

## 适用情境

源 Activity 或所继承的基类在 onCreate 调 overridePendingTransition(0,0)；目标用 Navigation 的 push/replace 进入该页，进入路径不止一条，规格可能只把转场禁用挂在抽屉基座等某一条路径上。

## 原因

把目的地属性当成某个基座的横切行为，其余路径按默认动画进入（来源中按钮进游戏页、教程完成进主菜单都出现滑入）。

## 做法

1. 对每个目的地 Activity 查它及所继承基类的 onCreate（grep overridePendingTransition 与 extends），把“进入无转场”写进该页页面规格，并在所有进入该页的路由契约里写 animated=false（或让目的地统一关闭系统转场）。
2. 实现时与工程已有路由保持一致：规格只给两参伪代码时，不据此省略第三参数。
