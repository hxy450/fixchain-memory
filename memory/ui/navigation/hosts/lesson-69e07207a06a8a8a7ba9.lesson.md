# 根 Navigation 只作路由容器时显式隐藏默认标题栏和工具栏

ID：`lesson-69e07207a06a8a8a7ba9` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，为入口页根 Navigation 编写属性链时

## 适用情境

源端外壳没有系统标题栏或工具栏（如 Compose Scaffold 只传自绘 bottomBar 与 snackbarHost），目标以 @Entry 页的 Navigation 作根路由容器，承载 tab 内容和自绘底栏，详情页走 NavDestination。

## 原因

来源中根 Navigation 未设 title 仍为默认栏保留了空间，内容区比 NavBar 短一截，自绘底栏悬空；“不设 title 就不占位”是未经核实的推断。该案例没有分开验证标题栏与工具栏各自的占位，两者一并隐藏后恢复。

## 做法

1. 根 Navigation 写 .hideTitleBar(true).hideToolBar(true)，自绘标题的 NavDestination 另写 .hideTitleBar(true)；对属性是否默认占位拿不准时先查导航参考，不凭推断删掉已拟写的属性。

## 可选检查

- 有设备时用 dumpLayout 核对 NavBarContent 与 NavBar 同高；内容区比 NavBar 短一个固定值时先查默认栏。
