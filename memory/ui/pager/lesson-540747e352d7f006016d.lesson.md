# ViewPager2 的适配器恒为一页时不写成 Swiper，按静态单页用普通容器直嵌

ID：`lesson-540747e352d7f006016d` · 版本：3

[本主题](index.md)

## 何时使用

规格提取阶段为 ViewPager/ViewPager2 选择目标容器并写明手势行为时；实现阶段落地该容器时

## 适用情境

源页面用 ViewPager2（+FragmentStateAdapter），但适配器实际只有一页（getItemCount 恒为 1、fragment 列表单元素），切页入口隐藏或在单页下无效；通用映射表或页面元数据只按类型给出 ViewPager2 → Swiper。

## 例外与边界

- 适配器页数随数据变化、可能多于一页时，按可滑分页容器处理

## 原因

按类型映射会把静态单页写成 Swiper，而 ArkUI 单页 Swiper 仍有横拖手势（可见平移回弹），源端实机不可滑；规格若还为不存在的页预置 index，实现者更会照写。

## 做法

1. 规格提取时核适配器实际页数与切页入口是否可见有效，按运行时行为写契约；页数恒为 1 时写明“静态单页、不可横滑”，目标用普通容器直嵌，不为不存在的页预置 index。
2. 实现时看到映射写 ViewPager2 → Swiper，对照源码确认容器确实多于一页且可滑；同时检查上层 HitTestMode.Transparent 是否把触摸透传到这个手势面。

## 可选检查

- 真机横滑页面主体，内容无位移、无回弹。
