# 自绘月历、周历的横向翻页由 Swiper 承载（每页一个 Canvas，关闭 Canvas 自带横向手势），“自绘”只约束格子绘制

ID：`lesson-d4e63d27885d9e348723` · 版本：1

[本主题](index.md)

## 何时使用

界面实现或缺陷修复阶段，为 Canvas 自绘的日、月、周历确定横向翻页容器时；需求点名 ViewPager 或 Swiper 效果时

## 适用情境

源端用 ViewPager2 逐页承载月、周视图，并在滑动回调中联动高度；目标用单个 Canvas 绘制月格，以 PanGesture 改写页偏移手动翻页；需求要求跟手分页、拖动中看到相邻页、快滑切页与回弹。

## 例外与边界

- 源端本身在单个自定义 View 里用手势翻页，没有分页容器

## 原因

单 Canvas 手动翻页在拖动中没有相邻页内容，快滑与回弹也要自己模拟，只调阈值、曲线和时长改善不了。来源中两位修复者都读到源端 ViewPager2 与用户“没有 Swiper 效果”的反馈：一位只换回弹曲线并称已支持连续横滑，另一位把“月格要自绘”理解成“翻页也必须在 Canvas 里做”，都在用户再次指出后才改成外层 Swiper。

## 做法

1. 源端用 ViewPager2 或 RecyclerView 逐页承载时，目标让 Swiper 承载三页（缓存前后页），每页放一个 Canvas，并关闭 Canvas 自带的横向拖动；高度联动放在 Swiper 的滑动回调里。
2. 需求点名分页容器效果时，先判断现有手动翻页能否在拖动中显示相邻页、支持快滑与回弹；做不到就换容器，不继续调阈值和曲线。

## 可选检查

- 慢拖过程中连续截图，确认相邻页在拖动中已有内容，落定前后不重绘。
