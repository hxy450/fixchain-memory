# 只禁手势的 ViewPager2 映射为 Swiper 的 disableSwipe(true)，不用 enabled(false)

ID：`lesson-a468f2cb12577cc1a774` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，把只禁手势滑动、由 Tab 点击切页的 ViewPager/ViewPager2 转成 Swiper 时；给承载可交互子页的容器设置交互属性时

## 适用情境

源端 ViewPager2 承载多个可交互 Fragment，以 isUserInputEnabled=false（或拦截 onTouch/onInterceptTouchEvent）只禁止手势滑动，由底部 Tab 点击 setCurrentItem 切页；目标用 Swiper 加自定义底栏实现同一主壳。

## 例外与边界

- 源端是 setEnabled(false) 禁用整个控件时，按禁用控件处理

## 原因

isUserInputEnabled=false 只关用户滑动手势，子页仍可交互；ArkUI 的 enabled(false) 作用于整个子树，承载可交互子页的 Swiper 会整页不可点。子页暂为空占位时看不出来，放入真实页面后才暴露。

## 做法

1. 只禁手势时在 Swiper 上写 .disableSwipe(true)；给承载可交互子页的容器（Swiper、Tabs、Stack）设置 enabled、hitTestBehavior 等交互属性前，确认该属性是否作用于整个子树。Tab 点击驱动切页与选中态回写按 lesson-27aa2e80a3a4d7724450 双向接通。

## 可选检查

- 子页放入禁滑容器后，真机 UI dump 中容器 enabled=true，并实际点击子页控件有响应。
