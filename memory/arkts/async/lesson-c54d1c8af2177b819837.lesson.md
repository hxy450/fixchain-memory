# 源端在后台线程执行的文件拷贝用异步 IO 或 taskpool 实现：async 函数包装 *Sync 调用不算后台执行

ID：`lesson-c54d1c8af2177b819837` · 版本：1

[本主题](index.md)

## 何时使用

实现阶段迁移 AsyncTask、线程池或 IO 调度器中的文件拷贝与附件导入时

## 适用情境

源端拷贝在 AsyncTask.doInBackground、THREAD_POOL_EXECUTOR 等后台线程执行，规格或并发说明写明后台或并发拷贝；目标准备用 fileIo.copyFileSync、openSync + readSync 实现，再在 async 函数里调用。

## 原因

async 只改变返回形态，函数体里的同步调用仍在调用线程（UI 主线程）上执行，多文件或大文件导入期间界面卡住。

## 做法

1. 拷贝链改用 fileIo 的 Promise 接口（open、copyFile、read、write 的非 Sync 版本），或把同步拷贝放进 taskpool.execute 的并发函数；多文件并发时保留源端的完成顺序与回到主线程收束的方式。

## 可选检查

- 该链路上出现的 *Sync 文件调用只应位于 taskpool 或 worker 执行的函数内。
