# ArkTS 里给对象字面量落到具名 class/interface 类型；去掉 Record 时键已知用具名字段类、键不定用 Map，不改成索引签名

ID：`lesson-1696967d1320c7735732` · 版本：6

[本主题](index.md)

## 何时使用

编码或返修阶段，为命名常量、主题令牌、键值集合、请求参数、路由参数或事件总线载荷确定类型声明，或按规范替换 Record/Object 时

## 适用情境

代码用对象字面量承载令牌、偏好或设置；把查询参数、请求体或路由参数写成内联对象字面量，传给声明为 Record<string, string> 或 Object 的形参；在未标返回类型的 map 等回调里 return 对象字面量；用 Array<{...}> 声明 @State 集合元素；调用泛型事件总线 emit<T extends Object>(name, payload) 时准备直接传 {}；为 toJson 或属性字典构造 Record<string, Object> 时写标识符键字面量，或把内联 { x, y } 当作 Object 值。

## 例外与边界

- 类型是只含方法签名的项目接口，或由 SDK 声明的观察者/回调类型时，按接口实现写法的经验（lesson-931ef95a3d0cf202fe5b）处理

## 原因

ArkTS 严格模式不接受无类型对象字面量（arkts-no-untyped-obj-literals），也禁止 [key: string] 索引签名（arkts-no-indexed-signatures）与 TS 风格的构造参数属性；给字面量标上数据属性的 interface 或 class 类型即可通过，而形参是 Record 或 Object 时，标识符键的内联字面量同样被拒。

## 做法

1. 给每个对象字面量一个具名类型：数据形状用 interface 或 class（如 class ThemeSpacing { small: number = 4 }），不照搬无类型的 static readonly X = {…} 示例。
2. 替换 Record 时，键集合已知就改成具名字段类，键不固定就用 Map，不写成 [key: string]: T；查询参数这类键值集合让请求封装接收 Map<string, string> 或具名参数类，调用方 new 后 set/赋值。
3. 对象字面量作为实参、返回值或 map 等回调的返回值时，落到已声明的 class/interface（回调写明返回类型，或 new 类实例后逐字段赋值）；路由参数与 @State 集合元素同样用显式类，不写 { id: x } 与 Array<{...}>。
4. 新增事件或 emit 调用时，与事件名同一补丁声明载荷接口（只作信号也给一个可选标记字段），调用处先写 const payload: XxxPayload = {...} 再传入。
5. 按报错新建类时用字段声明加构造体赋值，不写 constructor(public x)。
6. 需要保留 Record<string, Object>（序列化载荷、属性字典）时沿用工程已编译的写法：const x: Record<string, Object> = {}，再 x['key'] = value，嵌套值先建成有类型的变量；用字面量时键写成字符串字面量（如 'color': value as Object），带引号键能否通过只有同次编译旁证，以本工程编译结果为准。同一文件已被修复成某种写法后，新增代码沿用修复后的写法。

## 可选检查
