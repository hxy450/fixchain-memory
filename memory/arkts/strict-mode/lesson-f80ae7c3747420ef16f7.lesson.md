# 静态字段初始化器或模块级常量里把类当值使用时，该类要声明在使用者之前或从独立文件导入

ID：`lesson-f80ae7c3747420ef16f7` · 版本：1

[本主题](index.md)

## 何时使用

数据层或状态实现阶段，在服务类中用静态字段持有共享状态（AppStorageV2.connect、new Cls()）并安排同文件模型类的位置时

## 适用情境

服务类准备用 static 字段初始化器调用 AppStorageV2.connect(Cls, key, () => new Cls())、PersistenceV2.globalConnect 或 new Cls()，被引用的 @ObservedV2 类按原有布局追加在文件末尾；原先对它只有类型注解或方法体内的引用。

## 原因

类型注解和方法体内的引用不在类定义时求值，放在后面可以编译；static 初始化器在类定义时就需要被引用类的运行时值，类声明在后会报 Class 'X' used before its declaration。来源中实现者把购物车状态改为 static readonly 字段直接 connect，新状态类仍追加在文件末尾，编译失败；它没有可用的编译脚本，写后没有发现。

## 做法

1. 在 static 字段初始化器或模块级常量中把类当值使用前，确认该类在同一文件中声明在使用者之上，或拆到独立模型文件后 import；把原有类型级引用改成即时求值时，同步移动被引用类。
2. 共享状态也可以用静态 getter 或方法在首次调用时 connect；同一 key 返回同一实例，不会产生多份状态，也避免类定义期求值。
