# V2 组件成员装饰器裸写（@Local/@Param/@Once/@Event），@BuilderParam 的默认值只引用 @Builder 函数或方法

ID：`lesson-8b145360b447a10d52ef` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，在 @ComponentV2 自定义组件里声明 @Event 回调、@BuilderParam 插槽和状态字段时

## 适用情境

组件要向宿主暴露交互回调、提供带空默认的可选内容插槽；派工或 skill 只列出装饰器名单，写者准备凭记忆给装饰器补括号，或用箭头函数作插槽默认值；生成期不编译。

## 原因

@Event() 会被当成调用一个返回 void 的装饰器，编译报 Expected 2 arguments, but got 0 与 Type 'void' has no call signatures；@BuilderParam 只能由 @Builder 函数初始化，箭头函数默认值报 '@BuilderParam' property can only initialized by '@Builder' function。来源输入一律把 @Event 写成裸装饰器、只把 @Provider()/@Consumer() 标为需要括号，两个转换者仍凭记忆写出 @Event()；另一转换者的设计已写明默认值要引用空 @Builder，落盘却写成箭头函数，自检还判为合法。

## 做法

1. @Local、@Param、@Once、@Event、@Trace 裸写；只有 @Provider()、@Consumer()、@Monitor('path') 这类带参装饰器写括号。落盘前 grep '@Event()'、'@Local()'、'@Param()'，命中即改。
2. 可选插槽的默认值写成全局 @Builder function emptySlot() {} 或组件内的 @Builder 方法，再以 @BuilderParam slot: () => void = emptySlot 引用；新增的全局 @Builder 放在组件 @ComponentV2 装饰器之前，不插在装饰器与 struct 之间。
3. 这条只约束声明处的默认值；在调用方向子组件 @BuilderParam 传页面自己的 builder 时，箭头闭包包装仍是正确写法。
