# @ComponentV2 成员装饰器裸写，只有 @Provider()、@Consumer()、@Monitor('path') 这类带参装饰器写括号

ID：`lesson-8b145360b447a10d52ef` · 版本：3

[本主题](index.md)

## 何时使用

界面实现阶段，在 @ComponentV2 自定义组件里声明状态字段与 @Event 回调时

## 适用情境

组件要向宿主暴露交互回调与状态参数；派工或 skill 只列出装饰器名单，写者准备凭记忆给装饰器补括号；生成期不编译。

## 原因

common.d.ts 把 @Local、@Param、@Once、@Event、@Trace 声明为 PropertyDecorator，直接作装饰器使用；写成 @Event() 会先以零个参数调用它，再把返回的 void 当装饰器，编译失败。@Provider、@Consumer 声明为返回 PropertyDecorator 的工厂函数，@Monitor 为接收路径参数的 MonitorDecorator，只有这类工厂形态才带括号。

## 做法

1. @Local、@Param、@Once、@Event、@Trace 裸写；只有 @Provider()、@Consumer()、@Monitor('path') 这类带参装饰器写括号。落盘前 grep '@Event()'、'@Local()'、'@Param()'，命中即改。@BuilderParam 默认值的写法见 lesson-7d643db6ab406ae64c77。
