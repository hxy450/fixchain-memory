# 用 measureTextSize 按宽度判断折行时，constraintWidth 直接传 vp 数值，返回的宽高是 px，比较前换算到同一单位

ID：`lesson-b7b935e86195ed85927d` · 版本：1

[本主题](index.md)

## 何时使用

界面实现或返修阶段，用 UIContext.getMeasureUtils().measureTextSize 计算文本宽高、按列宽判断折行行数时

## 适用情境

源端 wrap_content 的 TextView 在列宽内折行会变高并下推后续内容；目标用 measureTextSize 先测单行高、再按列宽测折行高，列宽是布局里的 vp 数值。

## 原因

MeasureOptions.constraintWidth 以 number 传入时与组件长度一样按 vp 解析，而返回的 width/height 是 px（@ohos.arkui.UIContext.d.ts 的 measureTextSize 注释）；把 vp 列宽先 vp2px 再传，约束被放大数倍，永远测成一行。

## 做法

1. constraintWidth 直接传布局用的 vp 数值，或传带单位的字符串（如 `${w}vp`）消除歧义，不先 vp2px。
2. 返回值是 px：行数用两次返回值的比值，或 px2vp 后再与 vp 常量比较。
