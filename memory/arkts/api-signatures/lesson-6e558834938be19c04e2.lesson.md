# 写 SDK 调用前按本地 .d.ts 核对成员名、所属类型、调用链每一跳与返回可空性，不凭记忆写、不靠编译门兜底

ID：`lesson-6e558834938be19c04e2` · 版本：6

[本主题](index.md)

## 何时使用

页面或组件实现阶段，写组件构造选项、属性方法参数、需实现的 SDK 接口或 UIContext、状态存储一类调用时，尤其在禁止编译的批次里，或准备“先写、等编译门报错再改”时

## 适用情境

映射参考与规格只给组件、接口名而不给成员签名；写者准备凭记忆或 Android 命名填写选项字段名、参数类型、接口方法名或链式调用，或只看到一行 grep 命中的声明；本机 SDK 的 ets/component、ets/api 下 .d.ts 可以读取。也包括派工要求颜色、尺寸一律经 $r 资源绑定，或参照同批尚未编译的兄弟页、rg 到的零散用法改写参数。

## 原因

记忆中的字段名、接口成员名与所属类型常与当前 SDK 不符；禁编译只推迟错误，写后自检若只核 API 版本号或链尾方法，不存在的字段、错误的接口成员、并不存在的中间一跳和可空返回都会留到编译门，业务页尚未接入可达图时常规构建还会跳过这些文件。资源绑定惯例与兄弟页写法都是间接来源，参数接受什么类型仍由声明决定。

## 做法

1. 对本文件新引入、且未在已编译代码里出现过的每个 SDK 成员，写前在 ets/component/*.d.ts 或 ets/api/*.d.ts 找到声明，确认成员名、选项对象字段与必填项、参数类型和返回类型；有知识核验 skill 时也可以用它。禁止编译不等于禁止读声明；可编译时同样先查声明再写，不把编译门当作 API 查询手段。
2. grep 命中声明行后向上找到最近的 class/interface，确认成员属于哪个类型；同一个 d.ts（如 @ohos.arkui.UIContext.d.ts）包含多个类，不按文件名推定归属。链式调用逐跳核对，例如组件内解析字符串资源走 getUIContext().getHostContext()（可能为 undefined，先判空）再取 resourceManager.getStringSync，UIContext 本身没有 getResourceManager()。
3. 声明返回 T | undefined 的接口先判空再读写，AppStorageV2.connect 即使传了 defaultCreator 也一样；实现 ambient 接口时按接口体逐个成员实现，例如 LazyForEach 的 IDataSource 用 totalCount()、getData()、registerDataChangeListener()、unregisterDataChangeListener()，调用点统一用接口成员名。
4. 访问平台对象字段前在 d.ts 核对字段名，只核函数签名不足以证明字段存在（BundleInfo 的包名字段是 name）；系统 SDK 常量从其声明读取，三方 SDK 的常量（如微信 OpenSDK 的 Command.kCommandPay）从 oh_modules 中该包的声明读取，或按其文档用 instanceof 区分响应类型，不凭记忆写数值。
5. 资源绑定惯例只用于声明接受 Resource、Length、ResourceColor 的参数，只收数值的参数（如 blur、Swiper.itemSpace）保留数值常量；参照尚未编译的兄弟页或零散用法时回到声明核对，并看清所在回调的事件类型（ClickEvent 没有 stopPropagation）。
6. 写前可对照已核实的常见误写：MenuItem 图标字段是 startIcon；Slider.blockSize 接受 SizeOptions；AlertDialog 参数没有 builder 字段且 message 必填；TextInput 没有 caretWidth，用 caretStyle({ width, color })；换成 SymbolGlyph 后 fontColor 接收 ResourceColor 数组。写后自检按实际输出逐个复核新写的 SDK 调用，不只核 API 版本号。
