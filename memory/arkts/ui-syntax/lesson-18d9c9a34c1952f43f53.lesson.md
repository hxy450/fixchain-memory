# justifyContent/alignItems 只属 Column/Row：换容器时核对尾部修饰链，Stack 用 alignContent

ID：`lesson-18d9c9a34c1952f43f53` · 版本：2

[本主题](index.md)

## 何时使用

界面实现阶段，替换容器类型（如把 Column 改成 Scroll 包裹内容）或为 Scroll、Stack 等容器设置内容对齐时

## 适用情境

页面把占位 Column 改成 Scroll 包裹内容而补丁只替换了容器头，或把 Compose Box(contentAlignment)、FrameLayout 居中布局迁成 Stack，并在容器修饰链上写 justifyContent、alignItems。

## 原因

justifyContent/alignItems 属性方法只声明在 Column、Row 上（column.d.ts、row.d.ts）；Flex 写在构造参数 FlexOptions 里，Grid、GridRow 各有参数类型不同的 alignItems，Scroll、Stack 都没有。补丁只替换容器头时，原容器尾部的修饰链会落到新容器上，编译报 Property 'justifyContent' does not exist on type 'ScrollAttribute'/'StackAttribute'。

## 做法

1. 替换容器头时把原容器尾部整条修饰链纳入同一补丁逐项核对：Column/Row 专属的 justifyContent、alignItems 移到内部 Column 或删除，换成 Flex 时改写进 FlexOptions，只保留 layoutWeight 等通用属性。
2. Stack 的内容对齐写 Stack({ alignContent: Alignment.X })（不写即居中）；迁移 Box(contentAlignment) 时按此映射。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
