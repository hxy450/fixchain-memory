# justifyContent/alignItems 只属于 Column/Row/Flex：替换容器头时连同尾部修饰链核对，Stack 的内容对齐用 alignContent

ID：`lesson-18d9c9a34c1952f43f53` · 版本：1

[本主题](index.md)

## 何时使用

界面实现阶段，替换容器类型（如把 Column 改成 Scroll 包裹内容）或为 Scroll、Stack 等容器设置内容对齐时

## 适用情境

页面把占位 Column 改成 Scroll 包裹内容而补丁只替换了容器头，或把 Compose Box(contentAlignment)、FrameLayout 居中布局迁成 Stack，并在容器修饰链上写 justifyContent、alignItems。

## 原因

Scroll、Stack 的属性类型上没有 justifyContent/alignItems，编译报 Property 'justifyContent' does not exist on type 'ScrollAttribute'/'StackAttribute'。来源中一处补丁只替换了 Column() { 及子项，尾部的修饰链留下来落到 Scroll 上；另一处派发失败后改为本地实现，未加载布局参考就在 Stack 上写了 justifyContent。

## 做法

1. 替换容器头时把原容器尾部整条修饰链纳入同一补丁逐项核对：Column/Row 专属的 justifyContent、alignItems 移到内部 Column 或删除，只保留 layoutWeight 等通用属性。
2. Stack 的内容对齐写 Stack({ alignContent: Alignment.X })（不写即居中）；迁移 Box(contentAlignment) 时按此映射。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
