# 实现源端按返回码 switch 的分支时逐值对照源 case，只把源码列出的码判失败，不套用相邻方法的 result !== 0

ID：`lesson-9d56a6bbc436ff262d13` · 版本：1

[本主题](index.md)

## 何时使用

切片实现阶段，转写源端按返回码 switch/case 判定成功或失败的逻辑时

## 适用情境

源端 switch 只把部分返回码列为失败分支，其余落入 default 视为成功；同一文件的相邻方法用“非 0 即失败”判定，写者准备照搬。

## 原因

“非 0 即失败”会把源端判为成功的码当失败，改变可观察的结果与提示。

## 做法

1. 逐值对照源 switch：只把源码列出的 case 判失败，其余走 default 分支的语义；从相邻方法复制判定前，先核对两处源码的分支集合是否相同。
