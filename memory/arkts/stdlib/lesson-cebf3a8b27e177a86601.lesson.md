# 转写 Java byte 与 int 字面量的比较（如 b < 0x81）时，先把 0–255 的值换回 -128..127 再比较

ID：`lesson-cebf3a8b27e177a86601` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与实现阶段，转写 Java byte 变量与 int 字面量的比较、范围判断时

## 适用情境

源端把字节读入 byte 变量后与 0x81、0xFE 一类 int 字面量比较；目标从 Uint8Array 或 number 数组取到 0–255 的无符号值。

## 例外与边界

- 源端先做 b & 0xFF 再比较时，本来就是无符号语义，直接比较

## 原因

Java byte 有符号，参与比较时符号扩展为 -128..127：firstByte < 0x81 对任何 byte 都成立、firstByte > 0xFE 恒不成立；按 0–255 无符号比较时，0x81–0xFF 的结果与 Java 相反，条件可能从恒通过变成恒失败。

## 做法

1. 比较前把 0–255 的值换回有符号：v > 127 ? v - 256 : v（或 (v << 24) >> 24），再按源表达式比较。
2. 用 0x80–0xFF 的样例核对目标与源码同样恒真或恒假。
