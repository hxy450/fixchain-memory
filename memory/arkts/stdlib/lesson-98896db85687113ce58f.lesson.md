# 源端把 Float 直接转字符串（toString、模板、资源参数）时按 Float.toString 规则输出，不用 JS 数字串

ID：`lesson-98896db85687113ce58f` · 版本：2

[本主题](index.md)

## 何时使用

实现阶段把 Float 值的 toString()、"$f" 字符串模板、String.valueOf(f) 或作为字符串资源参数的显示翻译成 ArkTS 时；规格为这类显示写判例时

## 适用情境

源端变量为 Kotlin Float/Java float，不经格式化器直接转成文本显示（倍率、重量、滑杆标签、资源占位符参数）；目标 number 为双精度，准备用模板串、String(v) 或 toString()。

## 例外与边界

- 源端显示前已经过 DecimalFormat、String.format 等格式化：按对应格式化 API 实现

## 原因

Float.toString 以 float32 值为准输出能还原它的最短十进制，整数值保留“.0”，数量级在 [10^-3, 10^7) 之外用 E 记数；JS 数字串按双精度输出，float32 值会显示成 0.10000000149011612 一类长尾数，整数值少了“.0”。逐位 toPrecision 取第一个能往返的串也不等价：最短长度为 1 时 Java 在 1～2 位候选中取最接近者，-0.0 与 NaN 也要单独处理。

## 做法

1. 先把值按 float32 取值（Math.fround）；NaN、Infinity、-Infinity、0.0、-0.0 单独输出为 "NaN"、"Infinity"、"-Infinity"、"0.0"、"-0.0"（=== 区分不了 -0.0，用 Object.is）。
2. 其余值按 Float.toString 规范选十进制（android-36.1 Float.java 文档）：先求能往返到该 float32 的十进制的最短长度 p，在长度 p 的候选中取最接近原值者（并列取尾数为偶数者）；p 为 1 时候选扩到 1～2 位。往返判断用 Math.fround(parseFloat(s)) === 原值。例：Float.MIN_VALUE 输出 "1.4E-45"。本机核对的是 android-36.1 的规范，源端最低 API 设备上的实现是否逐值一致未在本机核实；个别值与源端设备输出不同时，以源端设备输出为准并在规格注明。
3. 格式化：10^-3 ≤ |v| < 10^7 时写普通小数，至少一位小数（30f → "30.0"）；其余写成尾数 + E + 指数（尾数至少一位小数，如 "1.0E7"、"1.4E-45"，正指数不带加号）。
4. 把这条规则实现为共享函数，toString、模板与资源参数的显示统一调用；规格判例写出整数值与非整数值各一例。
