# 翻页视图的相邻页数据按源端先合并、落定后一次提交，查询范围按页面实际格子的首尾日期

ID：`lesson-85b33ff729ab0514a20a` · 版本：4 · 阶段：execute/repair · 主题：[ui/list/pager](index.md)

概要：分页日历相邻页并发查询，Swiper 落定后一次提交

信号：`Swiper`, `Canvas`, `onAnimationEnd`, `onGestureSwipe`, `cachedCount`, `Promise.all`

## 何时使用

数据接线与修复阶段，为分页日历实现首次加载、按方向预加载与相邻页数据提交时

## 适用情境

源端并发查询当前页和前后页，合并后一次提交给视图，查询范围取自按格子计算的起止日期（含上月末与下月初）；目标在滑动手势回调中触发预加载，结果到达就写入正在移动的 Canvas。

## 原因

拖动中写入可见数据会让移动中的画布重绘，表现为闪烁；按自然月 1 日到月底查询，会让格子里的前后月日期缺数据。来源中修复者读到了源端的合并提交与范围函数，仍在滑动中直接写入并按自然月取范围，用户两次反馈后才改为落定后提交、按格子首尾查询。

## 做法

1. 并发查询当前页与前后页；拖动过程中只写缓存，Swiper 落定后一次替换可见数据；查询期间保留旧数据。
2. 查询范围按页面实际格子的首尾日期计算，复用源端的范围函数或与 Canvas 格子算法同源，不按自然月截断。
