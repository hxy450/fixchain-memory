# 按源端适配器绑定核对每个列表的数据源：不同分组不复用同一数组，级联选择实现逐级推进与回退

ID：`lesson-b6146f290e871c82e61d` · 版本：2 · 阶段：execute · 主题：[ui/list/data-sources](index.md)

概要：多个 Adapter 列表各绑各自数据源并实现级联推进回退

信号：`onPClick`, `onCClick`, `onBack`, `RecyclerView`, `Adapter`, `ForEach`, `Grid`

## 何时使用

界面与数据实现阶段，把源端多个 RecyclerView/Adapter（热门、全量、当前层级）迁移为 ArkUI 列表或网格时

## 适用情境

源端页面有多组列表分别绑定不同数据（热门城市、省份、当前层级子列表），点击推进到下一层级并支持返回上一级。

## 原因

多个网格渲染同一数组时页面看似完整，实际丢失了分组与层级语义。来源中执行者把热门城市与全量省份都绑定到同一组硬编码城市，点击任一城市即提交，没有省→市→区推进。

## 做法

1. 逐个列出源端适配器与其数据源、点击推进和回退逻辑（如 onPClick/onCClick/onBack），目标每个分组绑定各自的数据，并实现逐级推进与返回上一级。
