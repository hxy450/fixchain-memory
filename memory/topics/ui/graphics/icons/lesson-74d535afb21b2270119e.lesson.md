# Compose Material 图标（Icons.Rounded、AutoMirrored.Rounded 等变体）从可核来源提取同变体 pathData 并登记来源，不凭记忆写路径标称官方

ID：`lesson-74d535afb21b2270119e` · 版本：2 · 阶段：execute · 主题：[ui/graphics/icons](index.md)

概要：Material 图标按同变体从可核来源取 pathData

信号：`Icons.Rounded`, `Icons.AutoMirrored.Rounded`, `pathData`, `android.jar`, `material-icons`, `materialiconsround`, `MISSING_<name>`

## 何时使用

资源迁移或页面转换阶段，为源码引用的 Material 库图标生成目标 SVG 资源时

## 适用情境

源码通过 Compose Icons.Rounded.*、Icons.AutoMirrored.Rounded.*（或 Outlined、Sharp 等变体）引用 material-icons 库矢量，工程 res 下没有对应 drawable；派工要求使用官方 path 数据、缺失写 MISSING 占位；本机可能有 Android Studio 自带的 android.jar 或 Gradle 缓存中的 material-icons 包，生成环境能否读取需当场确认。

## 原因

同名图标的各变体几何不同：Rounded 的线端与拐角是圆弧，Filled/baseline 是直角折线。记忆中的路径多为 baseline 形状；凭记忆写入并标成官方 rounded 后，映射表与派工都显示已完成，偏差只在逐个比对几何时暴露。

## 做法

1. 按源码引用的变体与名称取矢量，例如 android.jar 中 images/material/icons/materialiconsround/<name>/round_<name>_24.xml 的 pathData，或 Gradle 缓存中的 material-icons 包；把来源路径写进资源映射表。
2. 可核来源取不到时，按派工写 MISSING_<name> 占位或登记为近似替代，不标“官方”。

## 可选检查

- 抽检一两个图标的变体特征：Rounded 版线端与拐角由弧段（c、a 指令）构成；Filled 版为直角折线，如 check 为 M9 16.17L4.83 12l-1.42 1.41L9 19 21 7l-1.41-1.42z
