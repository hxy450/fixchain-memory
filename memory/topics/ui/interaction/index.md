# ui/interaction

交互与输入：叠层命中与手势归属、点击绑定的归属与副作用、输入框属性、选择控件的选项与初值。

## 子主题

- [app-bar](app-bar/index.md) — 工具栏导航图标与菜单项：按实际生效者定汉堡或 Up，showAsAction 分流图标位与溢出（1 条）
- [click-binding](click-binding/index.md) — 点击绑定的归属与副作用：挂在源端真正持有点击的节点、按处理器分支迁副作用、回调契约兑现、被注释的监听视为死按钮。（6 条）
- [focus-ime](focus-ime/index.md) — 焦点链与输入法：按键事件挂载点、可获焦组件、软键盘收放 API、首屏获焦时机与搜索框状态（5 条）
- [gestures](gestures/index.md) — 触摸与手势移植：逐指派发过滤、自写状态机阈值、识别器默认参数、系统拖拽与长按触感（4 条）
- [hit-testing](hit-testing/index.md) — 叠放层的命中测试与手势归属：全尺寸覆盖层透传、Block 只放遮罩、侧滑行按钮热区、滑删方向与触发瞬间的坐标取值。（6 条）
- [input](input/index.md) — EditText 到 TextInput 的属性转换：默认装饰关闭、长度上限、小数输入、光标取证与掩码格叠层获焦。（9 条）
- [press-states](press-states/index.md) — 可点击控件的按压与禁用态外观：隐式按压反馈补齐、禁用外观来源与点击拦截（2 条）
- [selectors](selectors/index.md) — 选择控件的选项、初值与选中标记：选项按源数据源、自定义属性初值、级联回填、条件勾选不换 Radio、Slider 步数。（6 条）
