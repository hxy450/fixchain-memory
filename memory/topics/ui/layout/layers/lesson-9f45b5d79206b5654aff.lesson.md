# BottomSheetBehavior 面板映射：容器可见性与面板状态分离，位于底栏之上的面板用布局内实现

ID：`lesson-9f45b5d79206b5654aff` · 版本：2 · 阶段：spec/execute · 主题：[ui/layout/layers](index.md)

概要：底栏之上的 BottomSheet 面板用布局内 Stack

信号：`BottomSheetBehavior`, `STATE_COLLAPSED`, `HIDDEN`, `CoordinatorLayout`, `bindSheet`, `Stack`

## 何时使用

界面实现与规格提取阶段，把由 BottomSheetBehavior 管理、初始收起的播放器等面板翻译为 ArkUI 壳布局与状态机时

## 适用情境

源面板位于 CoordinatorLayout 内、底部导航之上，不可隐藏，可见性方法只切换容器 VISIBLE/GONE；目标可选窗口级 bindSheet 或 Stack 加 translate。

## 原因

把 Hidden 作为没有出口的初值、或用窗口级大尺寸 bindSheet 盖住底栏，会让迷你条永不出现、展开面板覆盖导航；把收起当作停播还会改变行为。

## 做法

1. 分开容器可见性与面板状态：初值取 STATE_COLLAPSED，隐藏和 HIDDEN 回调都回到 COLLAPSED。
2. 位于底栏之上的面板用布局内 Stack 加 translate 实现 peek、展开、收起，不用窗口级 bindSheet；规格写明面板边界与“收起不等于停播”。
