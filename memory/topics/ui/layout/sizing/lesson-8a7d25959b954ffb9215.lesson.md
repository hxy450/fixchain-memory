# 把 fragment 内容交给共享组件、宿主页另建容器时，fragment 根布局的 padding 与背景只由一方实现，并写进移交项

ID：`lesson-8a7d25959b954ffb9215` · 版本：2 · 阶段：execute · 主题：[ui/layout/sizing](index.md)

概要：fragment 根 padding 只由宿主或组件一方实现

信号：`LinearLayout`, `TabContent`, `ViewPager`

## 何时使用

页面转换与接线阶段，把 fragment 拆成宿主页容器与共享组件、确定根内边距与背景的归属时

## 适用情境

源 fragment 根 LinearLayout 带 padding（ViewPager 等宿主本身无 padding）；目标页面转换者在宿主 TabContent 等容器上写了这份 padding，又把 fragment 内容交给共享组件，组件按源在根上再加一次。

## 原因

两边各自按源实现同一来源的边距，接线后四边叠成两倍。

## 做法

1. 移交项写明 fragment 根的 padding 与背景由宿主还是组件承担；接线时对照宿主容器与组件根的 padding（如 grep 同一 dimen），发现同一来源的边距叠加就删去宿主一侧。
