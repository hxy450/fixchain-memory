# ui/theme

外观取值：颜色与字体令牌、主题与库隐式提供的样式来源，以及阴影模糊混合渐变等渲染效果。

[上一级](../index.md)

## 子主题

- [effects](effects/index.md) — 渲染效果换算：阴影 px 单位、模糊边缘、blendMode 离屏范围、渐变端点几何与角度、渐变描边与背景分支。（11 条）
- [sources](sources/index.md) — 控件外观数值的真实来源：应用主题、库默认 Tokens、style 继承、被引用 drawable 与截图取证。（6 条）
- [tokens](tokens/index.md) — 颜色与字体令牌的落地：按色值反查资源键、深色目录同步、深浅状态的可观察与系统栏图标、字族注册。（9 条）
