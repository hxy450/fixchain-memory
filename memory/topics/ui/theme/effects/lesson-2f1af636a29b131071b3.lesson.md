# TextView 的 shadowColor/shadowRadius 映射为 Text.textShadow

ID：`lesson-2f1af636a29b131071b3` · 版本：2 · 阶段：execute · 主题：[ui/theme/effects](index.md)

概要：文字阴影用 textShadow，不用组件 shadow

信号：`shadowColor`, `shadowRadius`, `textShadow`, `.shadow(`, `TextView`

## 何时使用

界面实现阶段，转换带文字阴影的 TextView 时

## 适用情境

源 TextView 设 shadowColor 与 shadowRadius，映射参考把它对应到 .shadow()。

## 原因

.shadow() 是组件框阴影，不产生文字阴影。

## 做法

1. 用 .textShadow({ radius, color })；映射参考与 API 语义冲突时以 API 语义为准，并记录参考错误。
