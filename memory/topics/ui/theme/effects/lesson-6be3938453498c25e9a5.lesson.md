# Modifier.blur(dp) 迁到 ArkUI blur 时先确认数值单位，并处理模糊边缘淡出

ID：`lesson-6be3938453498c25e9a5` · 版本：4 · 阶段：execute · 主题：[ui/theme/effects](index.md)

概要：blur 半径先确认 vp 单位，模糊层放大后裁边

信号：`Modifier.blur`, `BlurredEdgeTreatment`, `vp2px`

## 何时使用

界面实现阶段，把 Compose Modifier.blur(N.dp) 写成 ArkUI blur 时

## 适用情境

源端 blur 半径带 dp，默认 BlurredEdgeTreatment.Rectangle、边缘不淡出；ArkUI blur(value) 的类型注释没有写单位。

## 原因

照搬数值可能让模糊偏弱。来源修复经两端截图比对按 px 解释（写成 vp2px(N)），依据是截图而非文档；ArkUI 模糊层在边缘还会淡出。

## 做法

1. 照搬数字前先确认单位：查当前 SDK 注释，没有结论时用同一图案两端截图比对后决定是否 vp2px。
2. 源端边缘不淡出时，让模糊层大于显示区，再由外层 clip 裁掉。
