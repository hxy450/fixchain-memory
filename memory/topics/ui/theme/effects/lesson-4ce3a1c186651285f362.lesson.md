# Compose 渐变按端点几何换算成 ArkUI linearGradient：默认对角按宽高算角度，端点周期按渐变线长缩放 stop，Mirror 用回文 stop

ID：`lesson-4ce3a1c186651285f362` · 版本：4 · 阶段：execute · 主题：[ui/theme/effects](index.md)

概要：渐变端点几何换算成 linearGradient 角度与色标

信号：`Brush.linearGradient`, `horizontalGradient`, `TileMode.Mirror`, `linearGradient`, `onAreaChange`, `atan2`, `startX`

## 何时使用

界面实现阶段，把 Brush.linearGradient/horizontalGradient 翻成 ArkUI linearGradient，确定方向角、stop 位置与平铺、平移写法时

## 适用情境

源渐变或未指定 start/end（默认从组件左上 (0,0) 到右下 (w,h)），或以端点距离（startX/endX、start/end）定义图案周期并配 TileMode.Mirror 与随滚动、动画的平移；ArkUI linearGradient 只有角度或方向、按组件自身渐变线长取比例的 stop 和 repeating 开关；目标组件可能宽高不等（胶囊、卡片）。

## 原因

Compose 默认渐变轴沿组件自身对角线；ArkUI GradientDirection.RightBottom（angle 135）是 CSS “to bottom right” 语义，只在宽高相等时等价，宽胶囊上会变成接近上下渐变。ArkUI 的 stop 是相对组件渐变线长的比例，末 stop 为 1 时 repeating 不起作用；面板为覆盖显示区加宽后仍按 0–1 铺 stop，周期就被拉长。Mirror 与端点平移也有对应写法，登记“无等价”后改成转角动画等于换成另一种效果。

## 做法

1. 未指定端点的默认对角渐变：宽高不等时用 angle = 90 + atan2(h, w)（度），宽高取 onAreaChange 实测；圆形、正方形可保留 RightBottom。
2. 端点定义周期时：按源端点距离算出图案周期 P，stop 写成 P / 面板渐变线长 的比例，保证末 stop < 1，并与相位取模的周期一致。
3. TileMode.Mirror 把颜色写成首尾同色的回文 stop（A→B→A）并开 repeating；端点平移用比显示区大一个相位周期的面板做 position/translate，外层 clip。登记“无等价”前先试这组写法。

## 可选检查

- stop 有疑问时用“末 stop × 面板长度 = 周期”核一遍。
