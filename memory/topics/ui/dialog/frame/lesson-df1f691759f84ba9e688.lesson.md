# BottomSheetDialogFragment 或 Compose ModalBottomSheet 迁移为 bindSheet：按实际展开高度定高度档（跳过半展开仍随内容高），显式关掉源端没有的关闭钮与拖拽条

ID：`lesson-df1f691759f84ba9e688` · 版本：3 · 阶段：spec/execute · 主题：[ui/dialog/frame](index.md)

概要：底部面板按实际高度定档，显式关 showClose

信号：`BottomSheetDialogFragment`, `ModalBottomSheet`, `skipPartiallyExpanded`, `STATE_EXPANDED`, `setPeekHeight`, `bindSheet`, `SheetSize.FIT_CONTENT`, `SheetSize.LARGE`, `showClose`, `dragBar`, `maskColor`, `colorSurfaceContainerLow`

## 何时使用

规格提取、内容组件实现与宿主接线阶段，把 Material BottomSheetDialogFragment 或 Compose ModalBottomSheet 映射为 bindSheet，确定高度档、外壳参数与内容根高度时

## 适用情境

源面板有的在显示时调用名称暗示“全高”的展开方法（方法体只回填原 LayoutParams 并展开），有的不改 peek/state；根布局随内容；Material 面板没有关闭按钮与拖拽把手。目标外壳参数由宿主配置，内容组件被多个宿主复用。也包括 Compose ModalBottomSheet 以 rememberModalBottomSheetState(skipPartiallyExpanded = true) 跳过半展开态，规格写成“全展开 detent”或 SheetSize.LARGE。

## 原因

按方法名写成“全高”、把“跳过半展开”读成“全屏展开”，或用 MEDIUM/LARGE 多档近似，都会把面板撑高；ArkUI bindSheet 默认显示系统关闭按钮，不写 showClose 就多出关闭钮，缺项的参数块还会被复制到其他宿主。

## 做法

1. 看方法体或状态参数定高度：只 setState(STATE_EXPANDED)、LayoutParams 原样回填时写“按内容高度展开”，映射 height: SheetSize.FIT_CONTENT；Compose 的 skipPartiallyExpanded = true 只表示没有半展开档、直接展开到内容高度（超出可用高度时封顶），同样映射 FIT_CONTENT，不写 detents [SheetSize.LARGE]；只有实际改高度（setLayoutParams(MATCH_PARENT)、setPeekHeight、skipCollapsed）才写全高或多档；未改 peek/state 的面板不用多档近似拖拽，拿不准时把源根布局高度写进待核登记。
2. 源端没有关闭按钮与拖拽把手时（View 体系 Material 面板如此）宿主 options 显式写 showClose:false、dragBar:false；Compose ModalBottomSheet 按源 dragHandle 参数决定是否显示拖拽条。底色取 M3 BottomSheet 默认 colorSurfaceContainerLow 对应的 token，遮罩用统一 dim token；内容组件头注释已给宿主样例时以样例和源端为准，不直接复制邻近页面的 options。
3. 内容根不写 height('100%')；按 Material BottomSheet 的 paddingBottomSystemWindowInsets 补底部系统栏内边距，弹层不会自动避让。
4. 复用已有 bindSheet 参数块前核对 height/detents、showClose、dragBar、backgroundColor、maskColor 是否齐全。
