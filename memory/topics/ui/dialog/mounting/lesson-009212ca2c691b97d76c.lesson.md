# 从 bindSheet 半模态里打开的弹窗必须叠在 sheet 之上：不用页内浮层，居中点外可关用模态内自绘遮罩

ID：`lesson-009212ca2c691b97d76c` · 版本：3 · 阶段：execute · 主题：[ui/dialog/mounting](index.md)

概要：sheet 内二级弹窗用全屏模态承载，自绘遮罩居中卡片

信号：`bindSheet`, `bindContentCover`, `BottomSheetDialog`, `DialogFragment`, `SheetType.CENTER`, `Stack`, `onClick`, `MaterialAlertDialog`, `maxHeight`, `constraintSize`

## 何时使用

界面实现阶段，为从底部 sheet 内部触发的二级弹窗（定时、新建输入等）选择承载层时；为从窗口级面板内打开的对话框确定卡片高度上限时

## 适用情境

Android 在 BottomSheetDialog 内再 show 居中 DialogFragment（点外可关）；目标底部弹层用 bindSheet；二级弹窗候选有页内 Stack 条件浮层、bindSheet(CENTER)、bindContentCover 与全局自定义弹窗。也包括面板内 show() 的是 MaterialAlertDialog 类对话框，对话框组件由转换器产出、呈现外壳留给后续切片，组件没有自带高度上限。

## 原因

页内 Stack 浮层的 z 序恒低于 bindSheet 半模态层，从 sheet 内打开会被盖住；改成 bindSheet(CENTER) 又不能精确居中、也不支持点外关闭。修复时照搬本页已有浮层写法，会重新引入同一层级问题。改成窗口级呈现后，对话框若不自带最大高度，卡片会撑满全窗。

## 做法

1. 先确认触发点是否位于另一个半模态之内；是就用全屏模态（bindContentCover）或全局级自定义弹窗，并在 sheet 打开状态下实测层级。
2. 要还原居中、点外可关，在模态内容里自绘全屏遮罩并居中卡片，遮罩 onClick 关闭，卡体消费点击。
3. 引用“避免全局弹窗”一类规则前先核其负向守卫（不跨路由的普通弹窗无需页面级）；复用本页浮层写法前核对触发位置。
4. 源码在跳转回调里同时关闭对话框与父面板时，目标同样一并关闭。
5. 对话框组件自带尺寸契约：卡片 maxHeight 取窗口高减系统栏与上下边距，内容 Scroll 用 constraintSize 限高，不用 layoutWeight(1) 把高度边界留给未定的宿主；外壳未定时随组件提供 show 封装。
