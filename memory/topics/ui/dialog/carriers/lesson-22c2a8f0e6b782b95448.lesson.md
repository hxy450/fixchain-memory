# 半透明卡片式 Activity 迁移为透明 DIALOG 路由，遮罩只作页内一层

ID：`lesson-22c2a8f0e6b782b95448` · 版本：2 · 阶段：spec/execute · 主题：[ui/dialog/carriers](index.md)

概要：半透明卡片 Activity 迁 DIALOG 模式透明路由

信号：`windowIsTranslucent`, `backgroundDimEnabled`, `windowBackground`, `NavDestinationMode.DIALOG`, `Color.Transparent`, `NavDestination`

## 何时使用

界面实现与规格提取阶段，迁移 windowIsTranslucent 主题的卡片式 Activity 及其内嵌子页时

## 适用情境

源主题 windowIsTranslucent=true、windowBackground 透明、backgroundDimEnabled=true，以卡片内的容器承载 Fragment；目标为 Navigation/NavDestination。

## 原因

默认 STANDARD 模式的 NavDestination 有不透明背景，只铺遮罩也透不出下层页面；子页另建全屏页会离开卡片几何。

## 做法

1. 目标 NavDestination 用 mode(NavDestinationMode.DIALOG) 加 backgroundColor(Color.Transparent)，遮罩取源主题 dim（Material3 为 0.32）。
2. 规格写成“下层页面保持可见、仅压暗”，并写明路由需透明。
3. 卡片宿主内新增子页时，按源 replace(容器) 复刻卡片几何与透明路由，不另建不透明全屏页。

## 可选检查

- 写完核对遮罩下仍能看到下层页面和底栏
