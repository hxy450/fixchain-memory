# 演示、预置与参考数据逐字段取自源端种子工厂、模板常量或 assets 数据文件，不按功能名自拟样例，也不以少量硬编码代替全量

ID：`lesson-1c513fdf2cf212354aa0` · 版本：5 · 阶段：spec/execute · 主题：[data/storage](index.md)

概要：演示预置数据逐字段取自源种子工厂与 assets 不自拟

信号：`DemoDataFactory`, `rawfile`, `LocalDate.now()`, `plusDays`

## 何时使用

数据层或演示数据切片实现阶段编写演示、预置数据内容时；规格提取阶段描述固定演示数据时；实现依赖 assets 参考数据（行政区划、城市列表等）的页面与仓储时

## 适用情境

源端用种子工厂（如 DemoDataFactory）及其引用的清单模板、主题常量构造固定演示数据：标题、目的地、相对今天的日期偏移、主题 key、备注、条目标题/分类/优先级/顺序、完成集合与完成时间；目标端要重建同一数据集，手边可能只有依赖类名或规格里的数量概括。或源端从 assets 文本（如行政区划文件）按解析规则生成层级参考数据，目标准备先用少量硬编码条目顶替。

## 例外与边界

- 当前任务明确批准使用与源端不同的演示内容

## 原因

演示数据是首次打开即可见的行为，统计、进度、首页待办等派生展示都随它变化。只凭“演示数据”功能名或“2 条行程、10 项”的概括去写，会整套自拟：标题、日期、主题值与完成比例都偏离源端。来源中实现者手上有种子类名与规格指针却没打开，写出另一组行程、以颜色值代替主题 key、全部未完成的条目。另一应用的城市选择页，执行者读到源端从 assets 解析省→市→区、计划也写明“不能写死少量城市冒充全量”，仍写了 12 个硬编码城市并报告页面已完成。

## 做法

1. 打开种子工厂及其引用的模板与主题常量，逐字段搬运：标题、目的地、日期偏移、主题 key 原值（不换成颜色值或译名）、备注、条目标题/分类/优先级/排序、完成集合与完成时间偏移；源端按“今天±N”生成的，目标也按运行时的今天计算。
2. 规格提取时把这份数据表完整写进规格（每项的值，而非只写数量与比例），供实现阶段直接对照。
3. 源端从 assets 文件解析的参考数据，按源解析规则转换成目标资源或数据文件（保留层级与编码）；暂未接入时把对应验收标为未完成，不报告页面已完成。
