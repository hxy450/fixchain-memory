# 处理孤儿检测报出的无调用方页面或弹窗时，已登记为范围内的产物不删除：保留规格允许的纯 UI 与宿主回调并上报缺失的触发点；确需退役先取得范围决策并同步全部登记

ID：`lesson-8390913de64b0adc00fc` · 版本：2 · 阶段：repair/converge · 主题：[process/check-gaming](index.md)

概要：孤儿检测报出的已登记页面不删，上报缺失触发

信号：`NO_IMPORTER`, `ui-manifest`, `pages/`, `dialogs/`

## 何时使用

结构收口阶段，处理孤儿或无引用检测报出的 pages、dialogs 组件，决定补接线、保留上报还是删除文件时

## 适用情境

检测器报告某页面或弹窗没有导入方（NO_IMPORTER）；该组件在页面规格中有指定的 ArkTS 产出，在页面清单（ui-manifest）、功能索引中登记为已转换或 verified；源码里找不到真实调用方，或调用链属于决策排除的会员、支付、权益一类行为，决策只排除了这些行为，没有移除页面。

## 原因

“无调用方”只说明接线缺失，不说明页面出了范围；决策排除的是购买、扣点等行为，不等于授权删除展示页面。删除已登记产物后清单仍标 verified，结构闭环照样收敛，缺失要到后续按清单核对文件时才暴露；为过检测补一个调用方，又会造出源端没有的触发。

## 做法

1. 删除 pages、dialogs 下的文件前，先查页面清单、页面规格的 ArkTS output 与功能索引；已登记为范围内页面的产物不作为废弃文件删除。
2. 找不到可辩护的触发点、相关行为又被决策排除时，保留规格允许的纯 UI 与宿主回调（确认、取消、关闭），不主动弹出、不接被排除的行为，把缺失的宿主触发作为未决项或范围决策提案回传编排者。
3. 确需退役已登记页面时，先取得决策，并在同一次改动中同步页面清单、功能索引、计划、占位登记与迁移报告；编排者收到“已删除”回执时，先与页面清单对账再记为完成。
