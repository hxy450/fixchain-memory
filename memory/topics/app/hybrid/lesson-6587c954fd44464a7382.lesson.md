# FlutterBoostDelegate.pushNativeRoute 按源端 when(pageName) 建 Flutter 页面名到鸿蒙路由的映射，不直接透传

ID：`lesson-6587c954fd44464a7382` · 版本：4 · 阶段：execute · 主题：[app/hybrid](index.md)

概要：pushNativeRoute 按页面名建路由映射表不透传

信号：`FlutterBoostDelegate`, `pushNativeRoute`, `pageName`, `flutter_boost`, `when(pageName)`, `pushFlutterRoute`, `FlutterBoostRouteOptions`

## 何时使用

实现 flutter_boost 原生路由代理时，以及之后新增原生页面路由时

## 适用情境

Flutter 侧用 pageName（如 xxx_native）请求打开原生页，源端 pushNativeRoute 用 when(page) 把各 pageName 分流到对应 Activity、其余忽略；flutter_boost 示例把 pageName 直接交给路由。

## 原因

Flutter 侧的 pageName 是跨端约定的字符串，与目标端路由名不同；直接透传时路由查不到页面，Flutter 侧点击没有响应。来源中实现者按示例写了透传，随后读到源端的 when 分流也没改；目标页当时未迁，之后新增该页路由时也没人回填映射。

## 做法

1. 按源端 when(pageName) 建 pageName → 鸿蒙路由名的映射表，未知 pageName 记警告。
2. 目标页未迁时先 warn 占位，并在新增该页路由的任务里回填映射。
