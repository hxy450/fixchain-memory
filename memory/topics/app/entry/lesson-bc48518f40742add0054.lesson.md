# form_config 的规格、默认规格、缩放与刷新从源 appwidget-provider 换算，不凭默认档位填写

ID：`lesson-bc48518f40742add0054` · 版本：2 · 阶段：plan/execute · 主题：[app/entry](index.md)

概要：form_config 规格与刷新从源卡片声明换算，不填默认

信号：`form_config`, `supportDimensions`, `defaultDimension`, `updateEnabled`, `previewImages`, `appwidget-provider`, `minWidth`

## 何时使用

编排或服务卡片实现阶段，写 form_config 的 supportDimensions、defaultDimension、resizable、刷新与预览配置时

## 适用情境

源端 appwidget-provider 与 dimens 声明目标格数、最小/最大尺寸、可调尺寸、缩放模式和刷新周期，决策账本可能已批准静态预览；上游回报只说“具体档位待回填”。

## 原因

凭默认假设写规格档位，会与源端尺寸范围不符，并漏掉可缩放与预览；编排者在派工里写死的值会被实现者照抄。

## 做法

1. 写具体值前读源 appwidget-provider 与 dimens：由目标格数和最小、最大尺寸推出 supportDimensions 与 defaultDimension；源端可双向调整尺寸时 resizable 设为 true；源端没有刷新周期时 updateEnabled 设为 false；决策已批准的静态预览写成 previewImages（每档一项）。
2. 在派工里给出 form_config 值时附上源配置出处，并带上账本里与卡片配置相关的已批准条目。
