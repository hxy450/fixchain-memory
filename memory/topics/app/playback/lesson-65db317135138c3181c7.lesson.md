# 源宿主退后台不停播放时，AVPlayer 同时接入 AVSession、AUDIO_PLAYBACK 长时任务与 backgroundModes

ID：`lesson-65db317135138c3181c7` · 版本：3 · 阶段：spec/execute · 主题：[app/playback](index.md)

概要：退后台续播时接 AVSession 与音频长时任务

信号：`avSession.createAVSession`, `setAVPlaybackState`, `setBackgroundPlayMode`, `backgroundTaskManager.startBackgroundRunning`, `BackgroundMode.AUDIO_PLAYBACK`, `stopBackgroundRunning`, `backgroundModes`, `audioPlayback`, `ohos.permission.KEEP_BACKGROUND_RUNNING`, `ExoPlayer`, `MediaPlayer`

## 何时使用

规格提取为 MediaPlayer/ExoPlayer 写 AVPlayer 映射行时；实现阶段接入音频播放控制器并交接 module.json5 配置时

## 适用情境

源宿主的 onPause、onStop、onDestroy 不调用播放器的 pause、stop、release，只有离开页面或用户操作才停止，退后台时播放继续到结束；目标用 AVPlayer 播放音频，规格把映射判为“行为等价”，实现只覆盖前台的开始、停止与完成。

## 例外与边界

- 源端在 onPause/onStop 中暂停或释放播放器

## 原因

应用退后台后，未接入 AVSession 与音频播放长时任务的音频会被系统静音或暂停；只做前台三态等价，退后台行为就与源端不同，前台检查发现不了。

## 做法

1. 规格阶段先读宿主生命周期回调是否触碰播放器；不触碰时在验收写出“切后台继续播放至结束”，不判“行为等价”。
2. 进入播放后创建并激活会话（avSession.createAVSession(context, tag, 'audio')、setAVPlaybackState、activate），会话以成员变量持有；API 24 起可在退后台前用 setBackgroundPlayMode 显式设定后台播放模式（'audio' 会话缺省允许后台播放；HarmonyOS 文档 avsession-background-scene，访问于 2026-10-17；本机 SDK API 24 @ohos.multimedia.avsession.d.ts），同时 backgroundTaskManager.startBackgroundRunning(context, BackgroundMode.AUDIO_PLAYBACK, wantAgent)；停止、播完、出错与页面销毁时 stopBackgroundRunning 并销毁会话。
3. module.json5 中承载播放的 UIAbility 写 backgroundModes: ["audioPlayback"]，requestPermissions 加 ohos.permission.KEEP_BACKGROUND_RUNNING；不能改配置的实现者按所用 skill 的配置清单逐项交接，不只列运行时权限。
4. 把“接入后出现播控卡片”记为平台差异前，先确认源端退后台的行为；源端继续播放而目标被静音属于缺失功能，不是平台不可行。
