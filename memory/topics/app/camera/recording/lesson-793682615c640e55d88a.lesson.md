# 建录像会话时预览与录像档取自 NORMAL_VIDEO 按尺寸加帧率匹配，session.start 后先启 videoOutput 再启 AVRecorder

ID：`lesson-793682615c640e55d88a` · 版本：1 · 阶段：execute · 主题：[app/camera/recording](index.md)

概要：录像档取 NORMAL_VIDEO 按帧率匹配，先启输出再录

信号：`CamcorderProfile`, `MediaRecorder`, `NORMAL_VIDEO`, `VideoProfile`, `frameRateRange`, `setFrameRate`, `createVideoOutput`, `VideoOutput.start`, `getInputSurface`, `AVRecorder.start`, `canAddOutput`

## 何时使用

录像功能实现与跨文件接线阶段，为 CameraKit 录像会话选择预览与录像 profile、确定启动顺序，并接通录像中拍照时

## 适用情境

源端按尺寸与帧率选视频档，把 MediaRecorder surface 与预览、拍照 surface 一起建会话，硬件等级允许时支持录像中拍照；目标用 SceneMode.NORMAL_VIDEO 会话、AVRecorder.getInputSurface → createVideoOutput，VideoProfile 带 frameRateRange（camera.d.ts L359–L377）。

## 原因

沿用拍照模式的预览档、录像档只比尺寸并回落首项，会话可能配不出或帧率不符；只 session.start 而不启动 videoOutput，录制器拿不到帧；拆掉照片输出却仍报告支持录像中拍照，快照入口无效。

## 做法

1. 预览与录像档都从 getSupportedOutputCapability(camera, NORMAL_VIDEO) 取；录像档按尺寸加 frameRateRange 匹配源端所选，无匹配就返回失败，不回落 profiles[0]；所选尺寸与帧率（含捕获率）一路传到底层挂接接口。
2. 启动顺序：beginConfig → addInput → addOutput（预览、录像，以及可加的照片输出）→ commitConfig → session.start → 按需 videoOutput.setFrameRate → await videoOutput.start()（camera.d.ts L8580）→ AVRecorder.start()。
3. 录像中拍照：NORMAL_VIDEO 的 photoProfiles 有可处理格式且 canAddOutput 接受时才加并发照片输出并报告支持；加不上就释放该输出、照常录像。能力位与快照按钮的门控查询会话里实际挂上的照片输出，按钮在界面中实际渲染。
