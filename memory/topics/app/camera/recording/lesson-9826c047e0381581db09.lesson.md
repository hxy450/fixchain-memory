# 源端录像编码、容器、音源与帧率选项映射到 AVRecorderProfile 时按成员名核对枚举与编码器，确无对应的在建资产前报错，不静默换成别的

ID：`lesson-9826c047e0381581db09` · 版本：1 · 阶段：spec/execute · 主题：[app/camera/recording](index.md)

概要：录像选项按 AVRecorder 枚举映射，缺能力就报错

信号：`setVideoEncoder`, `setOutputFormat`, `setAudioSource`, `setCaptureRate`, `AVRecorderProfile`, `CodecMimeType`, `ContainerFormatType`, `AudioSourceType`, `AUDIO_SOURCE_TYPE_CAMCORDER`, `VIDEO_HEVC`, `getAvailableEncoder`

## 何时使用

录像服务实现与规格提取阶段，把源端视频编码、容器格式、音源、录音开关与采集/播放帧率映射到 AVRecorderConfig 时

## 适用情境

源端 MediaRecorder 可选 H264/HEVC 编码、MP4/3GP/WebM 容器、CAMCORDER 等多种音源，并可设独立采集速率；目标 AVRecorderProfile 用 CodecMimeType、ContainerFormatType、AudioSourceType 表达，部分编码能否录制取决于设备编码器。

## 原因

按截断的枚举读取或记忆断定“没有 HEVC/CAMCORDER”，会把可用选项静默换成 AVC、MIC 或语音识别音源，用户的选择被悄悄改掉；确实没有的容器只改扩展名，产出与声称的格式不符。

## 做法

1. 按成员名核对目标枚举（API 24 @ohos.multimedia.media.d.ts，grep 成员名或读到枚举闭合括号）：AudioSourceType.AUDIO_SOURCE_TYPE_CAMCORDER = 13（L7586，@since 12，相机录像场景）对应源端 CAMCORDER 与默认音源；CodecMimeType 有 VIDEO_AVC 与 VIDEO_HEVC（L8353、L8445），但 videoCodec 注释仍写 “Currently, VIDEO_AVC is supported”（L7937），选 HEVC 前先用 AVRecorder.getAvailableEncoder()（L5951）查询；ContainerFormatType 只有 mp4、m4a、mp3、wav、amr、aac（L7077–L7133）。
2. 源端选项在目标确无对应时（如 3GP/WebM 容器、AudioSourceType 中没有的音源、采集与播放帧率不同而 AVRecorderProfile 只有 videoFrameRate），在创建媒体资产前明确报错并提示，不换成另一选项或只改扩展名；差异登记进映射表。
3. 录音关闭时省略 audioSourceType 与音频编码参数，不论录音开关都下发音频字段。
