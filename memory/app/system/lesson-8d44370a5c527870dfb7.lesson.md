# 源文字随系统字号缩放时，目标应用声明fontSizeScale跟随系统

ID：`lesson-8d44370a5c527870dfb7` · 版本：1

[本主题](index.md)

## 何时使用

规格决策与应用配置落地阶段，裁定大字体能力、改写app.json5时

## 适用情境

源文字使用sp或textAppearance*主题样式（无需代码即随系统字号缩放）；目标AppScope/app.json5未声明configuration。

## 原因

鸿蒙应用默认不跟随系统字号，fp不随系统设置变化；把源端默认缩放记成“无大字体能力”，就不会写这项配置。

## 做法

1. 新建AppScope/resources/base/profile/configuration.json声明"fontSizeScale": "followSystem"，在app.json5写"configuration": "$profile:configuration"。
2. “不新增大字体适配”只表示不额外改布局，不应保留目标平台不跟随系统字号的默认值。

## 可选检查

- app.json5含configuration字段，且引用的profile文件存在
