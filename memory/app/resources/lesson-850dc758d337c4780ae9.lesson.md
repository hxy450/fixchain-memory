# 从 apktool 反编译 APK 转资源时，把 $父名__N 内联片段单独分类；库前缀按父名匹配，写后校验输出文件名只含字母、数字与下划线

ID：`lesson-850dc758d337c4780ae9` · 版本：1

[本主题](index.md)

## 何时使用

资源转换阶段，从反编译 APK 的 res/ 批量生成 media 文件并过滤库资源时

## 适用情境

资源源是 apktool 反编译的 APK，drawable 目录里有 aapt 从 animated-vector、animation-list、selector 等拆出的内联子资源 $<父名>__N.xml；转换脚本按原文件名输出 SVG，并用锚定在名称开头的前缀正则跳过库资源。

## 原因

HarmonyOS 资源名必须匹配 [a-zA-Z0-9_]，$ 开头的文件打包时报 Invalid resource name。锚定开头的库前缀正则被 $ 挡住，库的 avd 片段因此漏网；应用自有父资源的帧片段即使去掉 $ 也不命中库前缀，只能靠内联片段分类或文件名校验拦住。来源生成者首跑已看到 $ 条目漏过过滤并说明了原因，后续修补却没有处理，8 个 $ 文件留到编译门。

## 做法

1. 识别 $<父名>__N 形式的内联片段：它们只供父资源内部引用；父资源是 animated-vector、animation-list 等不直接映射的类型时整体跳过，确需保留时去掉 $ 并检查与已有文件重名。
2. 库资源过滤按去掉 $ 前缀和 __N 后缀后的父名匹配；过滤后分别列出被跳过与漏网的名字，核对带库前缀的都已跳过。
3. 写入 resources 后、交给构建前，对实际输出目录里的 media 文件名和 element 条目 name 逐个校验 [a-zA-Z0-9_]；复查对象是输出清单，而不只是转换失败清单。
