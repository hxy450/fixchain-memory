# 转换快捷方式等小图标时同时落实画布尺寸与图形显示区：测量墨迹范围后再宣告合规，低分辨率源图不插值放大充当正式资源

[本主题](index.md)

## 何时使用

资源迁移阶段，把源端快捷方式等小图标转换成目标规范尺寸的图标资源时

## 适用情境

源端只有低分辨率透明小图标（像素远小于目标规范的显示区）；目标图标规范同时规定画布尺寸与图形显示区（或分层前景加背景）。

## 例外与边界

- 启动器分层图标（adaptive-icon 转 layered-image）按其前景裁切与同尺寸图层规则处理，不套快捷方式的显示区参数

## 原因

只满足画布尺寸、把整张源图拉伸到画布，图形会超出规范显示区；只打印尺寸和 mode 就宣告“符合规范”，偏差要到装机才暴露；低分辨率位图插值放大后也不能作为正式资源。

## 做法

1. 先取目标图标类型的规范参数：快捷方式图标看 HarmonyOS 文档 module.json5 配置文件 shortcuts 标签的 icon 说明（例：HarmonyOS NEXT 离线文档该说明推荐分层图标，前景为 1024×1024px 透明图层、图形显示约 450×450px，背景 1024×1024px）；在规范画布内把图形缩放并居中到显示区，不把整张源图直接拉伸成画布尺寸。
2. 宣告合规前，用 alpha 通道外接框和最大墨迹半径核对图形是否落在显示区内，不只看尺寸与 mode。
3. 源图远小于目标显示尺寸时，先查源工程其他密度目录、矢量版本与依赖库中有无同图的高质量资源，有就用它生成；都没有才在交付说明中列为待设计方提供的矢量或大图资源，并附规范原文参数，不以插值放大充当正式资源。
