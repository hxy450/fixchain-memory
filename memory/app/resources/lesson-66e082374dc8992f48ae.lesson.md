# 转换快捷方式等图标资源时同时落实画布尺寸与图形显示区；测量墨迹范围后再宣告合规，低分辨率源图不插值放大充当正式资源

## 何时使用

资源迁移阶段，把源端快捷方式等小图标转换成目标规范尺寸的图标资源时

## 适用情境

源端只有低分辨率透明小图标（如 Android xxhdpi 72px 的快捷方式图标）；目标图标规范给出 1024×1024 透明图层且前景显示区约 450×450px（或分层前景加背景）。

## 原因

只满足画布尺寸、把整张源图拉伸到画布，图形会超出规范显示区；只打印尺寸和 mode 就宣告“符合规范”，偏差要到装机才暴露，低分辨率位图插值放大后也不能作为正式资源。来源中“显示为黑球、被圆形裁切”只有助手描述，最终保留的设计方图标仍为透明底、图形约占 45%，支撑的是显示区尺寸而非“必须不透明底”。

## 做法

1. 在规范画布内把图形缩放并居中到规范显示区（如 1024 画布内约 450×450px），不把整张源图直接拉伸成画布尺寸。
2. 宣告合规前，用 alpha 通道外接框和最大墨迹半径核对图形是否落在显示区内，不只看尺寸与 mode。
3. 源图远小于目标显示尺寸时，不以插值放大充当正式资源，在交付说明中列为待设计方提供的矢量或大图资源，并附规范原文参数。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
