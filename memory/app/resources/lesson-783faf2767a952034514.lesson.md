# 8 位颜色保持 #AARRGGBB 字节序，转换后与源逐项往返核对

ID：`lesson-783faf2767a952034514` · 版本：1

[本主题](index.md)

## 何时使用

资源迁移阶段，编写或运行 colors.xml 到 color.json 的转换逻辑（包括编排者降级自跑脚本）时

## 适用情境

源含带透明度的 8 位颜色；转换由自写脚本完成而不是直接按资源转换 skill 的规则执行，深色值可能从浅色转换结果派生，接手者可能被告知已完成部分“勿重做”。

## 原因

HarmonyOS 颜色与 Android 同为 #AARRGGBB，套用 CSS #RRGGBBAA 的直觉会互换字节；从已出错的浅色结果派生会把错误复制到深色目录。

## 做法

1. 自写或降级执行转换前，先加载规范指定的资源转换 skill 及其颜色规则，8 位值原样保留；深色值从同名或同义源值转换，不复制浅色转换结果。

## 可选检查

- 转换由自写脚本完成或中途换人接手时，把同名键的源值归一化为 #AARRGGBB 后与结果逐项比对，“首两位与末两位互换后才相等”即为字节序错误
