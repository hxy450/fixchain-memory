# strings.xml 中带内联标记或 CDATA 的键按消费入口输出：样式入口存 HTML，纯字符串入口取全部文字，不用 el.text 取值

ID：`lesson-2b6a8693ecc734e15912` · 版本：2

[本主题](index.md)

## 何时使用

资源转换阶段，编写 strings.xml 转 string.json 的脚本、处理含 <b>/<i>/<a>/<p> 子元素或 CDATA 的字符串键时

## 适用情境

源字符串键内联 <b>/<i>/<u>/<a href>/<br>/<p> 子元素（值可能以子元素开头）或用 CDATA 包裹 HTML；消费端有 getString/stringResource（取纯字符串）、getText/setMessage(resId)/布局 android:text（保留样式），或 getString 后交 Html.fromHtml；转换脚本准备用 ElementTree 的 el.text 或 itertext() 取值。

## 原因

内联标记被 aapt2 编成样式区间：getString/stringResource 取到去掉标记的全部文字，android:text、getText、setMessage(resId) 保留样式与链接；CDATA 内的标签是普通文本，留给 Html.fromHtml 解析。el.text 只取首个子元素之前的文本，值以标记开头时得到空串；itertext() 只取文字，用于样式入口会静默丢掉 <b>、<a href>。

## 做法

1. <string>/<item> 取完整内容，不用 el.text；先列出含子元素或 CDATA 的键，并在源码中查每个键的消费入口。
2. 经 android:text、getText、setMessage(resId) 等保留样式的入口显示的，按 HTML 保存（字面 < 与 & 转义）；经 getString、stringResource 取纯字符串的，输出去掉标记的全部文字（itertext() 或等价）；CDATA 内的标签按原文保留。
3. 同一键既经 getString 又经 getText/android:text 消费时，分别提供纯文字与 HTML 两种表示，或保存 HTML 并在纯文字消费处去标记。
4. 交付带标记键清单，标出各键的消费方式（Styled 资源或 Html.fromHtml，是否设 LinkMovementMethod），供界面实现阶段按富文本移植。

## 可选检查

- 逐语言列出源值非空而目标为空的键复核；含 <a href> 的键，目标值仍保留链接地址。
