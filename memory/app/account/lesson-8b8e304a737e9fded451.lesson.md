# 源端退出登录还清空本地业务库时，按源端清理契约实现退出钩子，不沿用只删偏好的旧实现

ID：`lesson-8b8e304a737e9fded451` · 版本：4

[本主题](index.md)

## 何时使用

账户域实现与重构计划阶段，确定退出登录、账号注销或游客重建要清理哪些本地状态时

## 适用情境

源端退出函数除清 token 与账号偏好外，还调用本地数据库清理（整库清理或逐表 delete）；目标把会话清理拆到仓库与宿主桥接，已有实现只删偏好与登录态；仓库里可能有状态仍为 planned 的增量规格写明退出前停同步并清理账号业务数据。

## 例外与边界

- 源端退出只清 token 与偏好、不动本地库时，目标同样只清会话状态

## 原因

只清偏好与 token 时，本地库里按账号归属的数据仍在，退出后页面重新查库，继续显示已退出用户的数据。已有目标实现只删偏好，不能作为完整清理的依据。

## 做法

1. 实现退出钩子前读源端退出实现及其调用的库清理，列出源端实际清理的、按账号归属的本地状态（例：业务表、游标、同步队列、搜索历史、订阅），与目标表逐项对照；源端没清的表保留（例：图标、节日等公共静态表）；旧目标实现只作待验证输入。
2. 按当前源端或明确批准的清理契约落实停止写入、清理范围与通知顺序：存在可能回写旧账号数据的同步任务时，先完成所需的停止与等待再清理；同一数据库内需要原子清理的关联表放在一个事务里，跨数据库、文件或其他存储的清理按各自的完成与失败契约处理；源端要求通知时，在相应清理完成后通知消费者，让存活页面刷新。
