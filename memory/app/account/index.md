## 本级经验

- [源端退出登录还清空本地业务库时，按源端清理契约实现退出钩子，不沿用只删偏好的旧实现](lesson-8b8e304a737e9fded451.lesson.md)
  - 时机：账户域实现与重构计划阶段，确定退出登录、账号注销或游客重建要清理哪些本地状态时
  - 情境：源端退出函数除清 token 与账号偏好外，还调用本地数据库清理（整库清理或逐表 delete）；目标把会话清理拆到仓库与宿主桥接，已有实现只删偏好与登录态；仓库里可能有状态仍为 planned 的增量规格写明退出前停同步并清理账号业务数据。
  - 例外：源端退出只清 token 与偏好、不动本地库时，目标同样只清会话状态
