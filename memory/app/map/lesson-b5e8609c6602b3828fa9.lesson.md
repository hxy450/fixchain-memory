# 用原生地图 SDK 替换占位地图时，把页面已有的定位出口接到相机与当前位置显示，地图就绪前暂存中心

ID：`lesson-b5e8609c6602b3828fa9` · 版本：2

[本主题](index.md)

## 何时使用

三方地图接入阶段，用高德等原生地图组件替换占位地图、决定定位结果如何驱动地图相机与当前位置显示时；从参考桥接裁剪能力时

## 适用情境

页面原先只有占位地图，定位按钮调用的地图 provider 只缓存中心坐标；参考工程的桥接类含 recenter/moveCamera、就绪前暂存中心与坐标适配器。

## 原因

替换底图只接了初始化与生命周期时，页面的定位出口仍指向缓存型 provider，按钮看似没有反应；有意裁剪参考桥接时，页面仍依赖的 recenter、坐标适配容易被一并裁掉。

## 做法

1. 列出页面现有的地图状态出口（中心更新、定位按钮回调、标记），逐一接到原生地图：定位成功后 moveCamera(newLatLngZoom(...)) 并启用当前位置显示（MyLocationStyle 与 setMyLocationEnabled）；地图尚未就绪时暂存中心，就绪后再应用。
2. 系统定位坐标进入高德相机前先做 WGS-84 → GCJ-02 转换。
3. 从参考桥接有意裁剪能力时，按用户可见入口逐项确认裁剪后仍有效；页面仍依赖的 recenter、坐标适配要保留，或登记为未完成。

来源支持：1 张卡 · 1 次迁移 · 1 个应用
