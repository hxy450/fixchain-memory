# 接入高德鸿蒙 SDK 的多个产品（地图、定位、搜索、导航）时，按产品单例分别设置隐私与 Key、分别初始化并判定就绪

ID：`lesson-9477f662ac13df03778c` · 版本：2

[本主题](index.md)

## 何时使用

三方 SDK 移植阶段，按参考桥接类与 SDK 声明编写高德地图、定位、搜索、导航的初始化时

## 适用情境

HarmonyOS 工程接入高德鸿蒙 SDK（map3d/location/search/navi 分包），各产品有自己的单例（MapsInitializer、AMapLocationManagerImpl、NaviSetting、ServiceSettings）；以另一工程的完整桥接类为参考裁剪成精简桥接，桥接可能被多个页面共用。

## 原因

高德各产品单例各自保存隐私状态；只设 Key、或与地图初始化共用一个 try 时，搜索就绪失败会让查询静默返回空结果。真机空结果也可能来自 Key 绑定的平台与应用不符（如 USERKEY_PLAT_NOMATCH），排查时与初始化问题分开核对。

## 做法

1. 按参考注释逐个核对本工程要用的产品单例，各自调用 updatePrivacyShow、updatePrivacyAgree 与 setApiKey；各单例分别初始化、分别记录成败，搜索就绪不依赖地图初始化是否成功。
2. 桥接实例由多个页面共用时，确认初始化是幂等的，不在每个 ViewModel 里重复 initialize。
