# 用高德鸿蒙 SDK 的 PoiQueryV2 搜索时 city 为必设参数：空值回退有效城市码，cityLimit 按源端查询设置

ID：`lesson-e4d79661c5168786a356` · 版本：2

[本主题](index.md)

## 何时使用

三方 SDK 移植或搜索实现阶段，构造高德 PoiQueryV2 关键词或周边查询参数时

## 适用情境

目标用高德鸿蒙 SDK search 包的 PoiQueryV2，其声明（PoiSearchV2.d.ets）写明 city 必须定义、不能为空；源端可能以空城市表示不限城市，页面也可能不传城市。

## 原因

PoiQueryV2 的声明要求 city 必须定义、不能为空，传空串违反该契约；城市限定与全国搜索由 setCityLimit 决定，统一改成全国或限定都会改变源端的搜索结果。

## 做法

1. 构造 PoiQueryV2 前查 d.ets 的必设参数：city 为空时回退为有效城市码（源端的默认城市码），不透传空串。
2. setCityLimit 按源端查询的城市限定设置，只在源端为全国搜索时置 false；周边搜索按声明带 location 与 bound，关键词提示等其他接口按各自声明补齐参数。
