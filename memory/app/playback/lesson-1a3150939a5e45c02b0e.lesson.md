# 源端同一 release() 用在不同作用域时，目标封装拆成两个方法：重载前只释放实例并作废令牌，宿主销毁时才清空宿主 context 与事件

ID：`lesson-1a3150939a5e45c02b0e` · 版本：1

[本主题](index.md)

## 何时使用

服务层实现阶段，把源端播放器等资源的释放调用（重载开头丢弃旧实例、宿主销毁时全清）映射到目标封装类的释放方法时

## 适用情境

源端在 loadMusic 一类重载方法开头用 player.release(); player = null 只丢弃旧实例，宿主引用只在整体 release() 中置空；目标把播放器实例、宿主 context、代数令牌封装进一个通道类，由同一类提供释放方法。

## 原因

重载路径调用全清方法后宿主 context 被置空，随后的 load 走失败分支且不打日志，资源永不装载；编译与静态检查都发现不了，只能靠设备音频流排查。

## 做法

1. 逐个源调用点判断调用后该对象是否还要继续 create/load：还要用的只调实例释放（作废令牌、释放当前实例），宿主销毁路径才调全清（再清空 context、反注册事件）；load 内已包含释放旧实例时，调用方不再重复。
2. 写完沿首次播放路径（start → load → 释放步 → load）走一遍，确认释放步之后 load 依赖的 context、factory、handlers 仍非空；因宿主已释放而短路的分支写告警日志。
