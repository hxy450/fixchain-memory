# 设置页由 addPreferencesFromResource/PreferenceFragment 挂载时，缺持久值的偏好会写入 android:defaultValue：目标在设置页出现时按 XML 顺序为缺键补写默认值并落盘，不只在读取时回退默认

ID：`lesson-4283cc343b875489b851` · 版本：1

[本主题](index.md)

## 何时使用

规格提取与设置页实现阶段，迁移带 android:defaultValue 的 PreferenceScreen XML 时

## 适用情境

源设置页由 PreferenceFragment/PreferenceActivity 以 XML 挂载偏好，各项有 defaultValue；目标偏好服务只在读取时回退默认值；偏好文件内容会被备份等流程读取。

## 原因

源端进入设置页后偏好文件就含这些键，读取时回退不会改变文件；备份内容、恢复校验与“键是否存在”的判断因此与源端不同。

## 做法

1. 规格写明“进入设置页后偏好文件含这些键”；实现时设置页出现时按 XML 顺序对缺失的键写入默认值并 flush，已有值不覆盖。
