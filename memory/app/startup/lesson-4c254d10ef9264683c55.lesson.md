# 源端启动固定进入主页、登录按需触发时，目标也固定进主页，登录页压在主页之上

ID：`lesson-4c254d10ef9264683c55` · 版本：1

[本主题](index.md)

## 何时使用

启动链路迁移或启动模块重构阶段，确定隐私同意后的启动目标与未登录用户的去向时

## 适用情境

源端启动页在同意隐私后固定进入主页，需要登录的功能再由登录检查按需跳到登录页；目标规格或已有代码可能写着按持久化 token 把启动分流到登录页或主页。

## 例外与边界

- 源端本身在启动时按登录态把用户分流到登录页

## 原因

按 token 把登录页当作根页面时，未登录用户一启动就进登录页，返回会露出空白根页面，主页上本可游客浏览的内容也看不到。来源中编排者读到源码与事实核查都说明固定进入主页，仍按规格清单的“进入登录或首页”改成 token 分流，真机看到冷启动进入登录页时也当作分流成立。

## 做法

1. 把启动路由与功能级登录门禁分开：启动固定进主页，token 只用于同步登录状态；受保护功能由登录守卫把登录页压在主页之上，登录页返回回到主页。
2. 未登录冷启动的验收按源端期望断言：进入主页，返回键退出应用。
