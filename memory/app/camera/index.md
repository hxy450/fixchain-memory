# app/camera

相机功能迁移（Camera2 → CameraKit）：会话的输入输出组合、能力探测与拆卸重建，拍照与录像产出链（拍照桥接与多帧、保存与原生缓冲、元数据、限额与缺口下的失败路径），取景控制（手动参数单位、预览居中与拍照旋转）

[上一级](../index.md)

## 子主题

- [capture](capture/index.md) — 拍照与录像产出链：拍照编排与图元的桥接回调和多帧/连拍、photoAvailable 字节的复制与释放、相机系统资产保存与媒体库写权限、录像时长与文件大小限额、目标确无能力的格式与选项的失败路径
- [controls](controls/index.md) — 取景控制：手动曝光、曝光补偿、ISO、对焦的单位、值域与前置条件，预览 surface 的缩放居中、传感器朝向与拍照旋转
- [session](session/index.md) — 相机会话：提交前配齐输入与输出、录像档位与帧率、拆卸与重建时 CameraInput 的复用、拍照 profile 格式选择、能力位按会话查询填写、能力与逐帧元数据的快照或事件缓存
