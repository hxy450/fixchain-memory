# 相机预览居中与拍照旋转落成真实调用：surface 用 setXComponentSurfaceRect，拍照用 getPhotoRotation

ID：`lesson-33cc1f6be3e707c17241` · 版本：1

[本主题](index.md)

## 何时使用

相机功能实现阶段，把 Android 预览的测量与矩阵变换、传感器朝向和拍照前的旋转下发移植到 XComponent 与 CameraKit 时

## 适用情境

源端 TextureView 子类在 onMeasure 按预览比例测量、setTransform 应用矩阵做 letterbox 与居中，尺寸变化时重配；拍照前 setRotation(getImageVideoRotation()) 写 JPEG_ORIENTATION（已含传感器角）；传感器角取 SENSOR_ORIENTATION。目标预览是 XComponent(SURFACE)，拍照经 PhotoOutput.capture(PhotoCaptureSetting)；规格验收可能把矩阵参数断言列为单测口径。

## 原因

只把缩放与偏移记进字段（满足参数断言）而不作用到 surface，预览拉伸或不居中；只读到截断的 CameraDevice 声明就断定没有传感器角而写死 90/270，换设备即错；拍照前不下发旋转，或把 Android 已含传感器角的绝对角度直接填进 PhotoCaptureSetting.rotation，原生层会再叠加传感器角，照片侧转。

## 做法

1. 预览测量与变换落到 XComponent：按预览比例算出 surface 宽高与偏移，经 XComponentController.setXComponentSurfaceRect 下发，并在 onAreaChange 时重算；单测断言的是这些调用的参数，不以只记录参数代替调用。
2. 传感器角读 CameraDevice.cameraOrientation；判断目标缺某属性前，按 interface 起止读完整段声明。
3. 每次 capture（单拍与连拍、序列拍）前按设备当前方向角调用 photoOutput.getPhotoRotation(deviceDegree)，前后摄分别计算 deviceDegree，把返回值填入 PhotoCaptureSetting.rotation；不把源端 getImageVideoRotation() 的结果换成 ImageRotation 直接下发。
