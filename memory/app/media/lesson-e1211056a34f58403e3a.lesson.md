# SaveButton 的底色与圆角设在控件自身，不设透明底再靠外层容器画外观

ID：`lesson-e1211056a34f58403e3a` · 版本：3

[本主题](index.md)

## 何时使用

界面实现阶段，用 SaveButton 等安全控件替代源端自绘样式按钮（渐变、半透明胶囊、圆角描边）时

## 适用情境

源端主操作按钮带渐变或半透明底、圆角或描边；迁移要求改成 SaveButton 安全控件（文案只能用系统预设，样式能力受限，如不支持渐变），实现者打算让外层容器画外观、控件自身设 Color.Transparent。

## 原因

SaveButton 设 Color.Transparent 后控件面渲染成默认深色底，从外层容器的圆角外露出方角黑底；这一结论来自真机像素取样，security_component.d.ts 的 backgroundColor 声明没有写透明度下限。这种写法编译正常，容易被当成项目范式复制到多个页面。

## 做法

1. 底色、圆角、描边直接设在 SaveButton 上；源端是渐变而 SaveButton 不支持渐变时，取渐变主色作纯色底，并把这一外观差异写进交付说明。
2. 对安全控件的样式能力没把握时，写前查 SDK 中 SaveButton 与安全控件公共属性的声明或安全控件文档；无法上机时在交付中列为需真机截图确认的外观项，不写成已定范式。

## 可选检查

- 沿用仓内已有的 SaveButton 样式前确认它经过真机截图；用在新背景上时取样按钮中心与四角像素，确认没有深色方块外露。
