# 锚定弹出的下拉（PopupWindow showAsDropDown 自定义下拉、框架 ActionBar 的溢出面板）按源样式与源主题锚定方式还原（Material 溢出面板盖住标题栏），遮罩与面板放同一承载层：不换成原生 Select、系统 Menu 或整页筛选视图

## 何时使用

界面实现阶段，为筛选栏、排序栏等下拉选项选择 ArkUI 弹出容器、呈现位置与菜单样式时；为工具栏溢出菜单（showAsAction=never 或未上栏的项）选择承载方式、锚定位置与外观时；把页内浮层（锚定面板与点外关闭层）搬进共享标题栏等组件时

## 适用情境

源端点击筛选项后用 PopupWindow 加载自定义布局（固定宽度、固定行高、箭头图、勾选图标），以 showAsDropDown 锚定在触发器或置顶筛选栏下方原位展开；同页可能另有整屏的“更多筛选”面板；目标有现成的 Select 组件或已写好的整页筛选组件可用。 也包括源 Activity 用框架 ActionBar（Theme.Holo，或 values-v21 的 Theme.Material*），溢出菜单项由平台主题绘制的 ListPopupWindow 面板承载，源码里没有面板样式；目标准备用 ArkUI Menu/bindMenu，任务要求逐屏一致。 也包括溢出面板由共享标题栏组件绘制（组件节点内或 .overlay()），点外关闭的全幅捕获层按组件契约留给宿主页，声明在标题栏之后的兄弟层里。 也包括溢出项带 <menu/> 子菜单（如排序），目标把它做成独立单选面板。 做法第 3 步的样式名与取值针对平台主题绘制的框架 ActionBar；源端走 AppCompat 的 Toolbar / ActionBar 时，溢出面板样式来自 AppCompat 包（Widget.AppCompat.PopupMenu.Overflow 同样 overlapAnchor=true、dropDownHorizontalOffset −4dip），底色、圆角、投影按应用自己的主题链解析，不直接套平台 Theme.Material 的取值。

## 原因

原生 Select 套用系统菜单外观，丢掉源布局的宽度、行高、箭头与勾选样式；把锚定下拉做成整页替换视图，会改变位置与容器，背景列表和置顶筛选栏也不再可见。来源中两位写者都已读到 PopupWindow 的布局与锚点，仍分别改成 Select 与“更多筛选”同款的整页面板。ArkUI Menu 是系统定位的圆角卡片、无分隔线，与框架主题的下拉面板（固定最小宽度、48dp 行与分隔线、外点只关闭）对不上；规格只写“Menu + MenuItem”通用映射时，实现只改底色与字色也不算对齐。 框架溢出面板的锚定方式随主题而变：Material 系的溢出 PopupWindow 设 overlapAnchor，面板盖住标题栏，底色取 colorPopupBackground；照 Holo 的“贴栏下沿”和白底写会错位、错色。遮罩与面板分属宿主与组件两个承载层时，宿主后声明的全尺寸捕获层在重叠区先命中，点面板项只触发关闭。

## 做法

1. 从布局 XML 取宽度、行高、背景、箭头与勾选资源，从代码取锚点与偏移，用 bindPopup（或锚点下方的 Stack 覆盖层）按这些值实现；当前项显示勾选或高亮，外点或再次点击收起。
2. 同一筛选栏有多个入口时按各自 show 方式区分：showAsDropDown 的快捷项做原位下拉（源端先置顶筛选栏并滚动列表的，同时保留置顶栏与背景列表），show(标题栏) 或整屏弹出的“更多筛选”才做独立面板。
3. 框架 ActionBar 的溢出面板先按源主题的 actionOverflowMenuStyle 与 colorPopupBackground 定锚定与底色：Material 系（Widget.Material.PopupMenu.Overflow：overlapAnchor=true、dropDownHorizontalOffset −4dip，平台资源 styles_material.xml）面板盖住标题栏，Material.Light 底色为 ?attr/colorBackground（#FAFAFA，不是白），投影按 popupElevation；Holo 没有 overlapAnchor，面板贴锚点下沿。再写可见契约并取平台值（SDK platforms/android-<api>/data/res 的弹出菜单样式与 popup_menu_item_layout：最小宽 196dp、行高 48dp、文字字号与左右内边距、行间分隔线、边线），上沿与右缘偏移以源端截图实测为准。要求一比一时用浮层：全屏遮罩只负责关闭并吞掉事件，遮罩与面板放在同一个承载层、面板后声明在上；面板由共享标题栏组件绘制而遮罩要覆盖页面时，组件经 UIContext.getOverlayManager() 把遮罩加面板整层挂到窗口级（可见态变化时增删节点，aboutToDisappear 移除），不把遮罩留给宿主页做后声明的兄弟层；宿主 onBackPressed 先关闭浮层。
4. 溢出面板里带 <menu/> 子菜单的项按 ListMenuItemView 在行尾显示子菜单箭头；由溢出项打开的子菜单面板带标题头（父项标题），由工具栏动作键直接打开的子菜单不带标题头。

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 android-36 的平台资源；android-36.1 的源码；androidx.appcompat:appcompat 1.8.0。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔做法第 1 步〕PopupWindow.showAsDropDown(anchor, xoff, yoff) 把弹窗锚在 anchor 的左下角，xoff、yoff 是以像素计的偏移；屏幕上放不下时会尝试滚动父级可滚动视图
- 〔做法第 1 步〕bindPopup 的 CustomPopupOptions.placement 不写时默认 Placement.Bottom（目标组件下方），当前位置放不下时自动调整位置
- 〔做法第 1 步〕CustomPopupOptions 不另设时：radius 默认 20vp；popupColor 默认透明色加 COMPONENT_ULTRA_THICK 模糊背景；enableArrow 默认 true，显示系统箭头
- 〔做法第 1 步〕CustomPopupOptions.autoCancel 默认 true：页面上有操作时气泡自动关闭
- 〔原因 / 做法第 3 步〕平台 Theme.Material.Light 的 actionOverflowMenuStyle 是 Widget.Material.Light.PopupMenu.Overflow，其父样式 Widget.Material.PopupMenu.Overflow 设 overlapAnchor=true、dropDownHorizontalOffset=-4dip：溢出面板盖住锚点（标题栏）
- 〔原因 / 做法第 3 步〕应用主题没有另设时，平台 Theme.Material.Light 的 colorPopupBackground 取 ?attr/colorBackground = @color/background_material_light = material_grey_50 #FFFAFAFA
- 〔原因 / 做法第 3 步〕Holo 的弹出菜单样式 Widget.Holo.PopupMenu 继承 Widget.Holo.ListPopupWindow：popupBackground 为 @drawable/menu_panel_holo_dark，dropDownVerticalOffset 0dip，没有 overlapAnchor，面板贴在锚点下沿
- 〔做法第 3 步〕平台菜单项布局 popup_menu_item_layout 的 minWidth 为 196dip，行高取 ?attr/dropdownListPreferredItemHeight；Theme.Holo 下它指向 listPreferredItemHeightSmall = 48dip
- 〔原因 / 做法第 3 步〕触摸测试中 HitTestMode.Default（不设 hitTestBehavior 时）的组件自身命中后会阻塞兄弟组件、不阻塞子组件；HitTestMode.Block 阻塞子组件的触摸测试，自身命中时还阻塞兄弟组件和父组件
- 〔做法第 3 步〕OverlayManager.addComponentContent 加入的节点默认在页面居中；index 不传、为负或为 null/undefined 时加在最高层
- 〔做法第 3 步〕自定义组件的 onBackPress 只对 @Entry 装饰的组件生效；返回 true 表示页面自己处理返回
- 〔做法第 4 步〕平台 ListMenuItemView 在菜单项有子菜单时显示子菜单箭头（mSubMenuArrowView 设为 VISIBLE，否则 GONE）；AppCompat 1.8.0 的 Base.Widget.AppCompat.ListMenuView 把 subMenuArrow 设为 @drawable/abc_ic_arrow_drop_right_black_24dp
- 〔做法第 4 步〕MenuPopupHelper.tryShow() 以 showTitle=false 打开，tryShow(x, y) 以 showTitle=true 打开；StandardMenuPopup 只在 showTitle 为真且菜单有 headerTitle 时加标题头
- 〔做法第 4 步〕从溢出面板里点带子菜单的项时，StandardMenuPopup.onSubMenuSelected 用 subPopup.tryShow(水平偏移, 垂直偏移) 打开子菜单（带标题头）；工具栏动作键直接打开子菜单时，ActionMenuPresenter.onSubMenuSelected 调 mActionButtonPopup.show()，内部走 tryShow()（不带标题头）
