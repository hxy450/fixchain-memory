# 非全屏窗口用 openCustomDialog 承载源对话框窗口时，遮罩压不到系统绘制的状态栏、卡片按整窗居中：弹窗期间按 dim 切状态栏底色，按避让差下移卡片

## 何时使用

界面实现阶段，目标窗口保持非全屏、用 openCustomDialog（或其他系统弹窗）承载 Android 对话框、确定遮罩与显示位置参数时，包括共享弹窗工具与各页宿主的打开处

## 适用情境

源主题由应用窗口绘制状态栏底色（Theme.Material 及以后 windowDrawsSystemBarBackgrounds=true、statusBarColor 不透明；且源应用 targetSdk 低于 35，35 及以上时主题里的 statusBarColor 被忽略，状态栏底色要另看源端怎么画），对话框窗口 dim（主题 backgroundDimAmount，Material 为 0.6）覆盖整块屏幕，窗口在状态栏与导航栏之间居中；目标窗口保持非全屏，状态栏由系统按 statusBarColor 绘制，对话框用 openCustomDialog 加 maskColor 与 DialogAlignment.Center 打开。

## 例外与边界

- 源对话框窗口不压暗（主题里 backgroundDimEnabled 为 false，或代码清掉了 FLAG_DIM_BEHIND）时，不切状态栏底色；源端改了对话框窗口的 gravity（不再居中，如贴底）时，第 2 步按系统栏之间居中算的偏移不适用

## 原因

openCustomDialog 的遮罩只覆盖应用窗口；非全屏时状态栏由系统绘制，遮罩压不到，源端被压暗的状态栏（原底色 × (1 − dim)，图标不变）在目标保持原色。DialogAlignment.Center 以整窗为基准，源对话框窗口在系统栏之间居中，两者相差（顶部避让 − 底部避让）/ 2。把“遮罩浓度 + 居中”当作源对话框窗口的等价物，会漏掉这两个参照。

## 做法

1. 遮罩：源主题由应用窗口绘制状态栏底色时，在 openCustomDialog 的 onWillAppear/onWillDisappear 里按计数把状态栏底色切到“原底色 × (1 − dim)”（setWindowSystemBarProperties，图标色不变），最后一个弹窗关闭时恢复。
2. 位置：读主窗口 TYPE_SYSTEM 顶部与 TYPE_SYSTEM/TYPE_NAVIGATION_INDICATOR 底部（取较大值）避让，给 openCustomDialog 传 offset dy = (top − bottom)/2（px 换 vp），在 avoidAreaChange 时更新；非全屏页面不加避让 padding 的做法不变，对话框偏移仍要读取避让值。两项做成共享工具，所有弹窗打开处统一挂上。

## 可选检查

- 对话框打开时取样状态栏中段颜色与卡片上下边界：状态栏应为原底色 × (1 − dim)，卡片中心应为（状态栏下沿 + 导航栏上沿）/ 2；横屏与两种导航各看一次。

来源支持：1 张卡 · 1 次迁移 · 1 个应用

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 android-37.0 的平台资源。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔适用情境〕平台主题 Theme.Material 与 Theme.Material.Light 里 windowDrawsSystemBarBackgrounds 为 true、statusBarColor 为 ?attr/colorPrimaryDark、backgroundDimAmount 为 0.6（android-37.0）
- 〔适用情境 / 原因〕窗口的 windowDrawsSystemBarBackgrounds 为 true 且窗口不浮动时，系统栏以透明背景绘制，由这个窗口在对应区域填 statusBarColor、navigationBarColor
- 〔适用情境〕应用 targetSdk 为 35（VANILLA_ICE_CREAM）及以上时，主题里的 statusBarColor 被忽略，Window.setStatusBarColor 也已废弃
- 〔原因〕openCustomDialog 等弹窗选项里的遮罩区域 maskRect 大小不能超出主窗口
- 〔原因〕非全屏窗口下状态栏由系统绘制在应用窗口之外，openCustomDialog 设了 maskColor 时状态栏不被压暗、保持原色
- 〔原因 / 做法第 2 步〕openCustomDialog 用 DialogAlignment.Center 时以整窗（含状态栏与底部手势条区域）为基准居中，卡片中心不在两条系统栏之间
- 〔做法第 1 步〕BaseDialogOptions.onWillAppear 在弹窗开场动画开始前回调，onWillDisappear 在关场动画开始前回调
- 〔做法第 1 步〕SystemBarProperties.statusBarColor 作入参时是十六进制 RGB 或 ARGB 字符串（不区分大小写，如 #00FF00、#FF00FF00），作返回值时固定为 ARGB；没设时取系统配置的颜色
- 〔做法第 2 步〕窗口避让区 AvoidArea 里各 Rect 的 left、top、width、height 单位都是 px（整数）
- 〔做法第 2 步〕BaseDialogOptions.offset 没写时为 { dx: 0, dy: 0 }，alignment 没写时为 DialogAlignment.Default；Offset 的 dx、dy 是 Length，写成 number 时按 vp 解释
