# BottomSheetDialogFragment 或 Compose ModalBottomSheet 迁移为 bindSheet：按实际展开高度定高度档（跳过半展开仍随内容高），显式关掉源端没有的关闭钮与拖拽条

## 何时使用

规格提取、内容组件实现与宿主接线阶段，把 Material BottomSheetDialogFragment 或 Compose ModalBottomSheet 映射为 bindSheet，确定高度档、外壳参数与内容根高度时

## 适用情境

源面板有的在显示时调用名称暗示“全高”的展开方法（方法体只回填原 LayoutParams 并展开），有的不改 peek/state；根布局随内容；Material 面板没有关闭按钮与拖拽把手。目标外壳参数由宿主配置，内容组件被多个宿主复用。也包括 Compose ModalBottomSheet 以 rememberModalBottomSheetState(skipPartiallyExpanded = true) 跳过半展开态，规格写成“全展开 detent”或 SheetSize.LARGE。 做法第 2、3 步的底色与系统栏内边距取自 Material3 的 BottomSheet 样式；应用主题是 MaterialComponents 基底时，面板底色取 colorSurface，系统栏内边距同样按应用实际的 BottomSheet 样式解析，不直接套 Material3 的设定。

## 原因

按方法名写成“全高”、把“跳过半展开”读成“全屏展开”，或用 MEDIUM/LARGE 多档近似，都会把面板撑高；ArkUI bindSheet 默认显示系统关闭按钮，不写 showClose 就多出关闭钮，缺项的参数块还会被复制到其他宿主。

## 做法

1. 看方法体或状态参数定高度：只 setState(STATE_EXPANDED)、LayoutParams 原样回填时写“按内容高度展开”，映射 height: SheetSize.FIT_CONTENT；Compose 的 skipPartiallyExpanded = true 只表示没有半展开档、直接展开到内容高度（超出可用高度时封顶），同样映射 FIT_CONTENT，不写 detents [SheetSize.LARGE]；只有实际改高度（setLayoutParams(MATCH_PARENT)、setPeekHeight、skipCollapsed）才写全高或多档；未改 peek/state 的面板不用多档近似拖拽，拿不准时把源根布局高度写进待核登记。
2. 源端没有关闭按钮与拖拽把手时（View 体系 Material 面板如此）宿主 options 显式写 showClose:false、dragBar:false；Compose ModalBottomSheet 按源 dragHandle 参数决定是否显示拖拽条。底色取 M3 BottomSheet 默认 colorSurfaceContainerLow 对应的 token，遮罩用统一 dim token；内容组件头注释已给宿主样例时以样例和源端为准，不直接复制邻近页面的 options。
3. 内容根不写 height('100%')；按 Material BottomSheet 的 paddingBottomSystemWindowInsets 补底部系统栏内边距，弹层不会自动避让。 内容可能超过 FIT_CONTENT 弹层上限（长列表、横屏、大字号）时，内容区 Scroll 写 .edgeEffect(EdgeEffect.Spring, { alwaysEnabled: false })：Scroll 默认 EdgeEffect.None（SDK component/scroll.d.ts），HarmonyOS 6.1.0 设备上观察到默认 None 的内容 Scroll 在 FIT_CONTENT 半模态里超高后拖不动，补上 edgeEffect 即可滚动（其他高度档与非半模态未核）。
4. 复用已有 bindSheet 参数块前核对 height/detents、showClose、dragBar、backgroundColor、maskColor 是否齐全。

来源支持：3 张卡 · 3 次迁移 · 3 个应用

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 com.google.android.material:material 1.14.0。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔原因 / 做法第 1 步〕SheetOptions.height 不写时默认 SheetSize.LARGE；底部弹窗竖屏时最大高度为距离状态栏 8vp；设了 detents 时 height 不生效
- 〔做法第 1、3 步〕SheetSize.FIT_CONTENT 让半模态容器高度去适应 builder 根节点的布局，此时 builder 根节点的高度不能用百分比
- 〔原因 / 做法第 2 步〕SheetOptions.showClose 不写时默认 true，显示系统关闭按钮
- 〔做法第 2 步〕SheetOptions.dragBar 默认 true，但只有 detents 设了多档且生效时才显示拖拽条
- 〔做法第 2 步〕半模态的 BindOptions.backgroundColor 不写时默认 Color.White
- 〔做法第 2 步〕material 1.14.0 的 Widget.Material3.BottomSheet 底色 backgroundTint 取 m3_comp_sheet_bottom_docked_container_color = ?attr/colorSurfaceContainerLow
- 〔做法第 3 步〕material 1.14.0 的 Widget.Material3.BottomSheet 设 paddingBottomSystemWindowInsets、paddingTopSystemWindowInsets 为 true，marginLeft/RightSystemWindowInsets 为 true：源端面板内容自动让出底部系统栏
- 〔做法第 3 步〕Scroll 的 edgeEffect 不设时默认 EdgeEffect.None
