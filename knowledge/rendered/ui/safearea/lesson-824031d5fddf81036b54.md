# 系统栏图标深浅按源端浅色状态栏标志推导：未设标志时安卓图标为白色，不照搬模板默认，也不按主题名或底色对比度自选

## 何时使用

沉浸式窗口配置阶段，调用 setWindowSystemBarProperties 设置 statusBarContentColor/navigationBarContentColor 或修改系统栏底色时；规格提取阶段整理主题与状态栏外观时

## 适用情境

Android 源端以主题、values-vNN 覆盖或代码决定状态栏图标深浅：windowLightStatusBar、SYSTEM_UI_FLAG_LIGHT_STATUS_BAR、setSystemBarsAppearance(APPEARANCE_LIGHT_STATUS_BARS)、ImmersionBar darkMode(true)、WindowInsetsControllerCompat.isAppearanceLightStatusBars = true 等表示深色图标；androidx.activity 的 enableEdgeToEdge() 用默认参数时按当前界面配置的深浅色设图标（浅色模式深色图标、深色模式白色图标，应用自己强制了深浅色时按应用的设定）；全都没有时为白色图标，即使主题是 Theme.AppCompat.Light 一类、状态栏底色偏浅；目标全屏窗口用 setWindowSystemBarProperties 设置系统栏，沉浸式 skill 示意写“透明背景 + 浅色文字”，规格可能只要求底色 parity。导航栏图标（navigationBarContentColor）由另一组标志决定：windowLightNavigationBar、SYSTEM_UI_FLAG_LIGHT_NAVIGATION_BAR、APPEARANCE_LIGHT_NAVIGATION_BARS，同样要窗口绘制系统栏背景且导航栏没设 windowTranslucentNavigation 才生效；按这组标志单独推导，不照状态栏的结论套用。

## 原因

内容色决定时间、电量等系统图标的深浅。照模板写白色，源端为深色图标的浅色页面顶部会看不见图标；按“Light 主题”或“浅底配深色”的对比度自选，又会把源端的白色图标改成深色。主题名里的 Light 只决定窗口与控件配色，不会让状态栏图标变深。来源中一处修复者只读派工和沉浸式 skill 就写成白色；另一应用的两位实现者都读到了未设浅色标志的 Light 主题，仍按底色对比度选了深色。

## 做法

1. 设置内容色前查源主题（顺着 parent 链查到底，平台的 Theme.Material.Light.LightStatusBar 一类父主题自带标志）、各 values-vNN 与 values-night 覆盖和代码中的浅色状态栏标志：有则用深色图标（如 #FF000000；主题里的 windowLightStatusBar 只在窗口绘制系统栏背景、且没有设 windowTranslucentStatus 时生效，否则按没有处理），全都没有则用 '#ffffff'；values-night 里取值不同、或源端用默认参数调用 enableEdgeToEdge() 时，按深浅色模式分别设置；页面间不同时按页切换。
2. “与底色对比足够”只作为源端没有可迁移设定时的兜底，并在注释写明依据；修改系统栏底色时按源主题同步复核内容色，不沿用按旧底色写的注释。
3. 规格在主题与样式链中写明状态栏图标明暗（相关标志是否存在及结论），状态栏外观验收同时列出底色与图标色。

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 android-36 的平台资源；android-36.1 的源码。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔适用情境 / 做法第 1 步〕windowLightStatusBar 为 true 时状态栏按浅色背景绘制（深色图标），对应 View.SYSTEM_UI_FLAG_LIGHT_STATUS_BAR 和 WindowInsetsController.APPEARANCE_LIGHT_STATUS_BARS；它只在窗口绘制系统栏背景（windowDrawsSystemBarBackgrounds）且状态栏没有设 windowTranslucentStatus 时生效
- 〔原因 / 做法第 1 步〕android-36 平台主题里，themes_material.xml 只有 Theme.Material.Light.LightStatusBar 写了 windowLightStatusBar=true，Theme.Material.Light 本身和基础 Theme 都没写：主题链只落到 Light 主题而没有设这个标志时，状态栏图标为白色
- 〔适用情境〕WindowInsetsController.APPEARANCE_LIGHT_STATUS_BARS（1 << 3）表示为浅色状态栏改变前景色，让栏上内容看得清，即浅色状态栏配深色图标
- 〔做法第 1 步〕SystemBarProperties 的 statusBarContentColor、navigationBarContentColor 文档写的默认值是 '#E5FFFFFF'；设置了它们之后 isStatusBarLightIcon、isNavigationBarLightIcon 不再生效
- 〔做法第 1 步〕setWindowSystemBarProperties 只设 statusBarColor、navigationBarColor 为 '#00000000'、不设 statusBarContentColor 时，设备上状态栏时间和图标显示为深色（与文档写的默认值 '#E5FFFFFF' 不同）
- 〔适用情境〕源主题继承 Theme.AppCompat.Light.NoActionBar 一类 Light 主题、且主题和代码都没有设浅色状态栏标志时，安卓设备截图上状态栏图标为白色
