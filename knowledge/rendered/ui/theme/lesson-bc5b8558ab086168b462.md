# 引用 style 或抽成共享 @Builder 的控件：先展开共享默认值，再逐实例叠加元素自身的覆写（字号、圆角、间距）；圆角不按半高推，也不照抄相邻控件

## 何时使用

界面实现阶段（含返修期重写弹窗或按钮），为通过 style 继承形状、尺寸与渐变的控件确定修饰链时；把重复 XML 元素抽成 @Builder 时；为 TextView 的 maxLines/lines、TextAppearance 字号字重行高，或 LinearProgressIndicator 等 Material 控件的轨道色确定取值时

## 适用情境

源 XML 控件以 style="@style/X" 继承圆角、高度、渐变等属性，元素本身只覆写部分项；style 自身还有父样式时（parent= 指定，或没写 parent 时按名字里点号前缀的隐式父样式），第 1 步的「全部 item」包括整条父链上的项，近的覆盖远的，不只看这一个 style 块；同一或相邻布局里有圆角更大的卡片，或同 style 但显式覆写成胶囊的按钮。或按键等控件以 style 给默认 textSize、单个控件再覆写不同字号；多个同构元素（分组标题）各自带不同的 layout_marginTop。也包括 maxLines/lines、TextAppearance 与 trackColor 来自 style 引用或 Material 控件默认样式，布局 XML 本身没写。也包括 TextView 只声明 textAppearance（如 ?android:attr/textAppearanceMedium）而没写 textColor，映射参考只说“展开为样式”，写者只取了字号。

## 原因

style 里的形状值不在元素上，不展开就只能猜：按高度一半推成胶囊、照抄外层卡片或相邻按钮的圆角；把某处的显式覆写当成 style 默认值也会扩散错误。来源中三处按钮的写者输入不同（有人读过 styles.xml 仍未应用，有人没读，返修时自问默认值却没有查），结果都写成胶囊。另一应用计算器按键 style 默认 36sp，各键覆写为 28/32sp，生成者统一写 36；新建账本页把两个分组标题抽成无 margin 参数的 @Builder，丢掉“账本类型”的 30dp 顶距。

## 做法

1. 遇到 style 引用先展开其全部 item（圆角、高度、渐变起止色），再逐项叠加元素上的显式属性；元素没覆写的形状值取 style 值。
2. 在注释里写明每个形状值来自 style 还是哪一行覆写；写不出来源就先读 styles.xml，不用估算值占位。
3. 同一 style 多处复用时逐个控件核对有无显式覆写，覆写处保持覆写值，不把某处覆写当成 style 默认值。
4. 字号等文本属性同样逐控件取有效值：元素覆写优先于 style 默认；把重复元素抽成 @Builder 时，逐实例不同的属性（margin、字号）作为参数传入，写完逐条对照 XML 数值。
5. maxLines/lines、TextAppearance、trackColor 同样先在 res/values 的 styles/themes 查出再写，不按“XML 未写即默认”推断；android:lines=N 对应 minLines(N) 加 maxLines(N)。
6. 展开 textAppearance 时字号与 textColor 一起展开（AppCompat 的 TextAppearance.Medium 为 18sp 加 ?android:textColorSecondary）；没写 textColor 的正文（style=、控件默认样式和主题里也都没给 android:textColor 时）按所引 textAppearance 的颜色属性取色令牌：AppCompat、Material 系主题下 Medium 取次级、Large 取主、Small 取三级文字色，旧版 Theme、Theme.Holo 下 Medium 取主文字色、Small 取次级；不一律默认用主文字色。

## 可选检查

- grep 注释含该 style 名的 borderRadius，与 styles.xml 及各处 XML 覆写逐一比对。

- 〔做法第 1、3、4 步〕安卓确定一个属性的最终值时依次看：控件 AttributeSet 里写的值 → AttributeSet 里 style 指定的样式 → defStyleAttr / defStyleRes 默认样式 → 主题的基础值，前者优先
- 〔做法第 6 步〕平台 Widget.TextView 的 textAppearance 为 ?attr/textAppearanceSmall，Widget.Material.TextView 和 AppCompat 的 Base.Widget.AppCompat.TextView 都继承它：TextView 没写 textAppearance、style 时取主题的 textAppearanceSmall
- 〔做法第 6 步〕AppCompat 主题下 android:textAppearanceMedium：API 14–20 由 Platform.AppCompat 设为 TextAppearance.AppCompat.Medium，API 21 起来自平台 Theme.Material 的 TextAppearance.Material.Medium；Base.TextAppearance.AppCompat.Medium 在 API 21 起的父样式也是 TextAppearance.Material.Medium
- 〔做法第 6 步〕平台 Material 文字外观：TextAppearance.Material.Large 为 22sp、?attr/textColorPrimary；Medium 为 18sp、?attr/textColorSecondary；Small 为 14sp、?attr/textColorTertiary
- 〔做法第 6 步〕旧版 Theme、Theme.Holo 的文字外观：基础 TextAppearance 的 textColor 为 ?textColorPrimary；TextAppearance.Large 22sp、Medium 18sp 只写字号（颜色沿用主文字色），Small 14sp 且为 ?textColorSecondary；TextAppearance.Holo.Large/Medium/Small 分别继承它们
- 〔做法第 5 步〕TextView 的最大行数初值 mMaximum 为 Integer.MAX_VALUE：控件、样式都没写 maxLines 时不限行数
- 〔做法第 5 步〕TextView.setLines(n) 把最少和最多行数都设成 n，高度固定为 n 行
- 〔做法第 5 步〕ArkUI Text 默认自动折行；设了 maxLines 后最多显示该行数，多余文本按 textOverflow 截断
- 〔做法第 5 步〕TextOverflowOptions.overflow 默认 TextOverflow.Clip（裁切，不出省略号）
- 〔做法第 6 步〕Text 不设 fontColor 时默认 '#e6182431'（穿戴设备 '#c5ffffff'），不随源端主题文字色
- 〔做法第 4 步〕Text 的 fontSize 为 number 时单位是 fp；不设置时默认 16fp（穿戴设备 15fp）
- 〔做法第 4 步〕ArkUI 长度数值不带单位时默认单位为 vp
- 〔原因 / 做法第 1 步〕borderRadius 默认 0、默认单位 vp，百分比按组件宽度计算；某个圆角值超过宽高最小值的一半时按值的比例绘制异形圆角
- 〔做法第 5 步〕material 1.12.0 的 Widget.Material3.LinearProgressIndicator 的 trackColor 取 @macro/m3_comp_progress_indicator_track_color（应用主题和控件没有另设 trackColor 时）
