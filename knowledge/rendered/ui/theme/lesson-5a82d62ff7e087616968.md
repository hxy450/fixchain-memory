# 委托 Material/AppCompat 库或平台框架（Theme.Holo、android.preference、框架 AlertDialog）提供外观的组件，先在本机 SDK 平台资源或依赖库 res（含 values-land、values-sw600dp 等限定目录）查默认外观与几何，查过仍无才标待核；内部留白按库规则分侧落实

## 何时使用

规格提取与界面实现阶段，翻译只显式传入部分参数、其余外观交给 Material3 库默认的组件（Slider、Snackbar、TopAppBar 等），或源码没写 padding、留白由库组件内部布局提供时；为 View 体系的工具栏、底部导航、FAB、按钮、TabLayout、偏好分组标题确定高度、字号字重、圆角与配色，而布局 XML 未写具体值时；把 android.preference 的 PreferenceActivity/PreferenceFragment 偏好列表与 ListPreference、框架 AlertDialog 转成目标行与对话框，确定行几何、分类头、分隔线、对话框几何与行内控件类型时；判断这些默认值是否随横竖屏或窗口宽度变化时

## 适用情境

源组件只传少数颜色或尺寸，thumb 形状、留隙、刻度、容器高度、内距等来自库默认与 MaterialTheme；TopAppBar 等容器的标题槽、导航与动作槽留白由库内部布局决定，源码本身没有 padding 修饰符；目标组件的内置样式与之不同。也包括 View 体系源用 ?attr/actionBarSize、MaterialToolbar、BottomNavigationView、TabLayout、未写 style 的 FAB 或 OutlinedButton，取值由 Theme.Material3.*、MaterialComponents 或 AppCompat 父主题与组件默认样式决定，且库在 values-land、values-sw600dp 下另有取值（如 AppCompat 横屏 actionBarSize 48dp、Toolbar 标题 14dp；TabLayout 横屏 tabGravity=center），应用自身 res 没有对应覆盖。也包括 PreferenceFragment（preference_material）行、ListView 分隔线、框架 AlertDialog 与 ListPreference 单选对话框，几何在本机 SDK 平台资源里。也包括 View 体系 Activity 继承 android.preference.PreferenceActivity、主题为 Theme.Holo，页面没有布局 XML，复选框、分类头、行高与内边距、列表左右内边距、分隔线规则由平台 preference_holo 等布局与资源隐式提供。

## 原因

只记显式参数时，实现者会把目标框架的内置样式当作等价物，或凭不确定的记忆写死几何值并标成“库常量”；“没有截图时标待核”还会被当成保留估计值的许可，或用目标平台的 sys 色、内置 Radio、圆角卡片代替。库的内部留白常是单侧规则（如标题起始侧 inset），凭记忆补值时容易写成两侧对称。检索不到显式覆写就套用 M2/AppCompat 默认，或沿用兄弟页数值，会系统性偏离 Material3 外观；应用 res 没有横屏覆盖也不代表库没有，按竖屏单值实现在横屏偏离。框架主题与 Material 库的默认值不同：Holo 偏好分类头是 listSeparatorTextViewStyle（14sp 粗体全大写、次文字色、底部 2dp 线），CheckBoxPreference 是方形复选框而不是开关；这些平台值在本机 SDK 一直可查。

## 做法

1. 取值来源按提供方并先查本机：Material 库组件的几何从对应版本的 Tokens、源码与 aar res 取；框架主题、android.preference 与框架 AlertDialog 从本机 SDK platforms/android-<api>/data/res 的 values/styles*.xml、themes*.xml、dimens_material.xml 与 layout/preference_material.xml、alert_dialog_material.xml、select_dialog_singlechoice_material.xml、drawable 取。同时列出这些资源在 values-land、values-sw600dp 等限定目录的覆盖值，目标用 base + horizontal 等同名资源或运行期按窗口取值承载。布局里 visibility=gone 的元素与框架控件（AlertController、DialogTitle 等）在运行期改写的属性，对照本机 SDK sources/android-<api> 的框架源码或参照机实测，不以 XML 初值为准。检索过仍无才标待核并写明检索路径；未传入的颜色查主题文件，写明取 MaterialTheme.colorScheme 或主题属性的哪一项；不直接映射成目标内置样式，也不以目标平台 sys 色代替。
2. 源码没写、由库内部布局提供的留白，按库的布局规则分侧写出：哪一侧有 inset、由哪个槽位撑开；不把单侧 token 扩成对称 padding，标题槽内的 Row 不自行补末端内距。
3. 规格已写入某组件的部分 M3 默认值（如容器高度）时，把同一组件的标题 inset 与槽位规则一并写出。
4. 思考中带问号或决定不深究的数值，不写成带库出处注释的常量；取不到时在规格或报告里标为缺口。
5. View 体系先读页面元数据列出的 styles.xml，沿 parent 链确认组件库代际或框架主题；检索不到覆写不等于采用 M2 默认。Material3 下常用默认：工具栏 actionBarSize 64dp、标题 TitleLarge 22sp 常规字重、标题起点 16dp（有导航图标时约 60dp）；底栏选中标签按 itemTextAppearanceActiveBoldEnabled 加粗（material 1.10.0 起才有这个属性，没设时默认加粗；1.9.0 及以前没有这个属性，1.8.0、1.9.0 的选中标签一律加粗），徽标宿主收至图标尺寸后右上锚定；FAB 为 16dp 圆角方形配 colorPrimaryContainer/onPrimaryContainer；OutlinedButton 文字 LabelLarge 14sp Medium；AppCompat/Material 偏好库的 PreferenceCategory 标题用 colorAccent。
6. AppCompat 与平台框架常用基准（来源中按 SDK/库资源核对，用前对照当前依赖版本）：AppCompat actionBarSize 竖屏 56dp、values-land 48dp、sw600dp 64dp，Toolbar 标题 20dp、values-land 14dp；Material TabLayout 竖屏 tabGravity=fill 均分，values-land 与 sw600dp 为 center（各 Tab 取最宽 Tab 宽并整体居中，放不下才退回 fill）；preference_material 行 minHeight 48dp、左右 16dp（values-sw600dp 为 24dp）、文字区上下 16dp、title 16sp、summary 14sp，ListView 分隔线 1dp 全宽且末项后也画；框架 Material AlertDialog 遮罩 60% 黑、卡宽竖屏至少 95%×屏宽 − 32dp、横屏至少 65%×屏宽 − 32dp（windowMinWidthMinor / windowMinWidthMajor 是最小宽度，按 screenWidthDp 算，内容更宽时随内容加宽；values-large、values-xlarge 另有比例）、2dp 圆角、标题 20sp Medium、单选行 48dp、按钮 14sp Medium 全大写 colorAccent；随槽位变化的项另写：有标题且有消息或列表时标题下 8dp（titleDividerNoCustom，运行期由 AlertController 显示，setView 自定义视图时不显示），contentPanel 最小 48dp，标题单行放不下时 DialogTitle 改 18sp（textAppearanceMedium）两行，按钮 minHeight 取 alert_dialog_button_bar_height：屏幕可用高度（Configuration.screenHeightDp，targetSdk 35 以下不含状态栏和导航栏）≥ 720dp 时（values-h720dp，多数手机竖屏）为 54dp，否则为 48dp，按方向分支写。
7. PreferenceActivity + Theme.Holo 的偏好列表从 layout/preference_holo.xml、preference_category_holo.xml 与相关 drawable 取几何写进规格：列表左右 16dp（values-sw600dp 24dp、values-sw600dp-w960dp 48dp、values-sw720dp 0）、行最小 64dp、文字列右 8dp、摘要 maxLines 10；分类头 14sp 粗体全大写加 2dp 线；分隔线与分类头相邻不画、末项后也画；CheckBoxPreference 用方形复选框六态图，SeekBarPreference 按源布局叠放数值与 SeekBar，带 icon 的 Preference 只有 48dp 宽图标框与标题、没有尾部箭头。
8. 代码中镜像资源数值（如工具栏高度常量）从同一资源取值并注明来源主题；规格的设计系统节把这些组件度量写成具体值，供页面引用。
