# 说明类静态页按源布局逐卡迁移：文案逐字取自源 XML，标题条背景与插图一并迁入

## 何时使用

界面实现阶段，依据源布局 XML 生成规则、说明、注意事项一类静态图文页时

## 适用情境

源静态页由多张卡片组成，标题条使用 drawable 背景，正文是写在布局 XML 里的长文案，卡内或页首尾有插图；规格只要求“展示说明并可返回”，不复述内容。

## 例外与边界

- 清单里的 drawable 若是 XML drawable（shape、selector、layer-list、vector 等），不能原样放进 media（media 只收 .jpg、.png、.gif、.svg、.webp、.bmp 文件）：shape 背景改用组件的背景色、圆角、渐变等属性还原同样效果，vector 先转成 svg 再放入；对照时这类资源算作效果已还原，不要因为 media 里没有同名文件就换成别的图或删掉标题条背景。

## 原因

规格不复述内容时，布局 XML 是唯一的内容来源；用概括文案、省略插图与标题条背景写出的页面能编译、能返回，却与源页面不一致。来源中实现者在批量读取被截断后，把可见的卡片简化成纯文字卡，没读到的页面写成通用介绍，协调者又把概括文本写进字符串资源；视觉检查后三页被整体重写。

## 做法

1. 写前从每个布局列出卡片数、标题、正文、标题条背景与插图 drawable 清单，写完逐项对照：卡片数一致，插图与背景已迁入 media。
2. 文案逐字写入字符串资源（保留分行）；读不到源文就停下报告缺口，不写概括或通用替代文案。

来源支持：1 张卡 · 1 次迁移 · 1 个应用

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 android-36.1 的源码。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔做法第 1 步〕安卓 xxhdpi 对应 480 dpi；鸿蒙资源的 xxldpi 限定词适用于 dpi 取值 (320, 480] 的设备，所以 drawable-xxhdpi 的图按密度放置时对应目标的 xxldpi 限定词目录
- 〔做法第 1 步〕鸿蒙 media 目录只收文件（不支持子目录），图片只支持 .jpg、.png、.gif、.svg、.webp、.bmp 六种后缀；安卓的 XML drawable（shape、selector 等）不在其中
