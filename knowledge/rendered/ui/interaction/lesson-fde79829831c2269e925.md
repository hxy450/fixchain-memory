# 源端可点击容器自带的按压反馈（Compose clickable、Card(onClick)，View 体系主题 listSelector 的列表行）在 ArkUI onClick 上不会自动出现：用通用属性 stateStyles 补状态层并成对写 normal 写回静止值（stateEffect 只属于 Button），不可点击时不显示；View 体系列表选择器按压色作底色画在内容下，不用 opacity 代替；选择器是 <ripple> 时不按原色整块平铺

## 何时使用

界面实现阶段，为任何可点击元素（列表行、对话框文字按钮、ImageButton/图标按钮、标题栏动作钮）用 stateStyles 写按压态时；把带 Modifier.clickable/toggleable/selectable，或 Card、Surface(onClick) 的 Compose 容器转成挂 onClick 的 ArkUI 容器时；把 ListView、PreferenceActivity 中由主题 listSelector 提供按压态的可点击行转成 ArkUI 列表行时；把 GridView 条目转成 Grid/GridItem 时

## 适用情境

源端容器经 clickable/toggleable（可带 role = Button、Switch）或 Card/Surface(onClick) 响应点击，没有把 indication 设为 null，按压时由主题提供涟漪或状态层；目标用 Column/Row/Stack 加 .onClick 实现，ArkUI 通用容器默认没有按压反馈（Button 自带的按压效果除外）。 也包括 View 体系的 ListView、PreferenceActivity 行没有把 background 或 listSelector 设为 null，按压态由主题选择器（如 Holo 暗色 list_selector_holo_dark）提供；写者在 d.ts 里找不到通用容器的 stateEffect，就放弃了按压态。 也包括 GridView 条目：GridView 未改写 listSelector 与 drawSelectorOnTop，Activity 主题分散在 res/values 与 values-v11/v14 等多个 styles.xml，低 minSdk 的旧工程在新设备上走 values-v11+ 的 Holo 父主题。 也包括 Material 主题（values-v21 的 android:Theme.Material*）下，列表选择器、标题栏按钮背景（?attr/actionBarItemBackground）与无边框按钮背景解析到 <ripple> drawable，规格或兄弟页只给出一个“按压色”。

## 例外与边界

- 源端显式 indication = null 或自定义 indication 时，按源端写法处理
- 列表或网格在布局、样式或代码里设了 drawSelectorOnTop=true 时，选择器画在条目内容之上，按压层按盖在内容上的叠层处理，不按底色
- View 体系的条目根布局自己设了不透明背景（纯色或不带按压项的 drawable）时，画在内容下面的列表选择器被盖住，源端按下没有可见变化，目标也不加按压态；条目背景本身是带 pressed 项的 selector 时按该项取色
- 目标用自带按压效果的 Button 承载点击时，不再叠加；确需在 Button 上用 stateStyles 写按压态时，先把 stateEffect 设为 false，否则内置按压色会叠在状态样式的底色上

## 原因

Compose 的点击修饰符默认带按压指示，调用处看不到任何反馈代码；只翻译 onClick 时点击可用但按压没有反馈，编译与结构检查都发现不了。stateEffect 只是 Button 的属性，通用容器的按压态要用 stateStyles 或 onTouch 状态驱动；以“查不到 stateEffect”为由省略，按压反馈整体缺失。 stateStyles 里只写 pressed、没有用 normal 写回被改属性时，松手后该属性停在按下值（实测按下底色一直残留），按钮与列表行都一样。 AbsListView（ListView、GridView）的 drawSelectorOnTop 默认 false（本机 android-36.1 源码 AbsListView.java），选择器的按压色画在条目内容下面，图标与文字像素不变；用 opacity 整体变暗会连内容一起变淡。只看 res/values 会认错主题代际：同名主题在 values-v11/v14 常改为继承 Theme.Holo，低 minSdk 不等于老式 list_selector_background。 Material 主题的选择器与按钮背景是 RippleDrawable：colorControlHighlight（highlight_alpha × 前景色）只是涟漪着色输入，屏上是有界径向层或无界圆，把原值整块平铺会偏深、形状也不同。

## 做法

1. 在承载点击的同一容器上加通用属性 stateStyles，pressed 与 normal 成对声明：pressed 改了哪些属性（如 backgroundColor），normal 就把这些属性写回静止值（无底色写 Color.Transparent，有底色写原色）；内联样式块与 @Styles 方法引用（如 { normal: this.released, pressed: this.pressedStyle }）都要成对。任何容器可用；stateEffect 只属于 Button，查不到它不是省略按压态的理由。按压时叠加状态层：Compose 源按 Material3 取约 10% 的内容色，View 体系按源主题选择器的实际按压外观（如 Holo 暗色 #40CCCCCC）；叠层随容器圆角裁剪，纯色背景也可预混成按压色。 View 体系列表与网格的状态层是底色：选择器画在条目内容下面（drawSelectorOnTop 默认 false），pressed 态写 backgroundColor、normal 透明，不用 opacity、整体变暗或盖在内容上的叠层代替。取色前按设备 API 沿 res/values-vNN/styles.xml 找 Activity 主题的 parent 链确认主题代际，再从 SDK platforms/android-<api>/data/res 下该主题 listSelector（按钮看其 background）指向的 drawable 先看根元素：<selector> 的纯色按压项取色；<ripple> 按下一步处理，不取 colorControlHighlight 原值整块平铺。取不到时在报告里写明缺口，不以 opacity 兜底。
2. drawable 根元素是 <ripple> 时（Material 主题 API 21+ 的 listChoiceBackgroundIndicator、selectableItemBackground、actionBarItemBackground、btn_borderless_material 等）按涟漪形状落实：含 mask 或内容层的有界涟漪在视图边界内画以视图中心为圆心、视图半对角线为半径的径向层；无 mask、无内容层的无界涟漪按 android:radius 画圆（圆心按源控件热区），圆外无色，不铺满按钮矩形。highlight_alpha 原值随 SDK 版本不同（本机 android-30/34/35 为 0.10/0.5/0.20），屏上稳态不透明度由对照设备 Android 版本的 RippleDrawable 绘制决定：按该版本实测按住稳态，或在报告里登记待实测；不按“与兄弟页同值”挑某一版本，也不在同一组件里混用不同版本的值。
3. 按源端 enabled 条件决定是否出现：clickable/toggleable 的 enabled 为假时（如内容不足、无可展开项）既不响应点击也不显示按压态。

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 android-36.1 的平台资源与源码（highlight_alpha 另比对 android-30、33、34、35、36、37.0）；androidx.compose.foundation:foundation-android 1.10.4、androidx.compose.material3:material3-android 1.4.0（字节码）。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔适用情境 / 原因〕Compose 的 Modifier.clickable 不传 indication 时取 LocalIndication；material3 1.4.0 的 MaterialTheme 把 LocalIndication 设为 ripple()，所以应用没有另设 indication 时，MaterialTheme 下的可点击容器按下显示涟漪
- 〔做法第 1 步〕material3 1.4.0 的涟漪在应用没有另设涟漪颜色或 LocalRippleConfiguration 时取 LocalContentColor，按压态不透明度 0.1（RippleDefaults.RippleAlpha：拖拽 0.16、聚焦 0.1、悬停 0.08、按压 0.1；StateTokens.PressedStateLayerOpacity 也是 0.1）
- 〔原因〕ArkUI 的 Column、Row、Stack 只挂 onClick、没写 stateStyles 时，设备上按下没有任何视觉变化
- 〔例外与边界〕Button 的 stateEffect 默认 true（按下有内置按压效果）；开着它又设了 stateStyles 时，内置按压色会在状态样式设好的背景色上再叠加一层，文档要求用多态样式写按压态时先把 stateEffect 设为 false
- 〔做法第 1 步〕StateStyles 的 normal、pressed 等字段都可选，只写 pressed 也能编译；设备上 stateStyles 只写 pressed（内联样式块或 @Styles 方法引用）时，松手后被 pressed 改过的 backgroundColor 停在按下时的值；同一 stateStyles 里 normal 也写了该属性时，松手后取样没有残留
- 〔做法第 1 步〕clicked 和 pressed 两种状态样式同时用在一个组件上时，只有后注册的那个生效
- 〔做法第 3 步〕组件没设 enabled 时默认可交互；enabled(false) 时组件不可交互，stateStyles 另有 disabled（不可用态）样式
- 〔做法第 1 步〕AbsListView（ListView、GridView）的 drawSelectorOnTop 在布局、样式、代码都没有另设时为 false，选择器画在条目内容下面，内容像素不被遮盖
- 〔适用情境 / 做法第 1 步〕Theme.Holo（暗色）下应用没有另设 listSelector 时：GridView 走 gridViewStyle=Widget.Holo.GridView，listSelector=?attr/selectableItemBackground=item_background_holo_dark；ListView 走 listViewStyle=Widget.Holo.ListView，listSelector=?attr/listChoiceBackgroundIndicator=list_selector_holo_dark；两个选择器的按下项都指向 list_selector_background_transition_holo_dark（list_pressed_holo_dark 过渡到 list_longpressed_holo_dark）
- 〔做法第 1 步〕Holo 暗色主题下没有另设 listSelector、drawSelectorOnTop 的 GridView 条目和 PreferenceActivity 偏好行，安卓参照机上按下时整个条目（含内边距空白）出现一层 #40CCCCCC，画在图标和文字下面，图标像素不变
- 〔适用情境 / 做法第 2 步〕Theme.Material 下应用没有另设时：Widget.Material.ListView 与 Widget.Material.GridView 的 listSelector=?attr/listChoiceBackgroundIndicator=list_choice_background_material，selectableItemBackground=item_background_material，Widget.Material.Button.Borderless 的 background=btn_borderless_material；这三个 drawable 都是带 @id/mask 子项的 <ripple>（有界涟漪）
- 〔做法第 2 步〕Theme.Material 下应用没有另设 actionBarItemBackground 时，它是 action_bar_item_background_material：只有 android:color=?attr/colorControlHighlight 和 android:radius=20dp、没有任何子层的 <ripple>（无界涟漪）
- 〔原因 / 做法第 2 步〕应用没有另设 colorControlHighlight 时：Theme.Material.Light、ThemeOverlay.Material.Light 取 ripple_material_light（黑色乘 highlight_alpha_material_light），Theme.Material、ThemeOverlay.Material.Dark 取 ripple_material_dark（白色乘 highlight_alpha_material_dark）；highlight_alpha 浅、深两项在 android-30、33 为 0.10，android-34 为 0.5，android-35、36、36.1、37.0 为 0.20
- 〔做法第 2 步〕RippleDrawable 有子层（mask 或内容层）时是有界的，涟漪按 mask（没有 mask 时按子层合成形状）遮罩；没有子层也没有 mask、又作为 View 背景时，涟漪画在层级中第一个可用的祖先背景上，绘制区可以超出 drawable 边界（android:radius 不超过热区宽、高的一半且热区在 drawable 边界内时不外投）
- 〔做法第 2 步〕RippleDrawable 的涟漪半径：设了 android:radius 时取该值；没设时取热区半对角线，即 sqrt((宽/2)²+(高/2)²)
- 〔做法第 2 步〕Android 12 对照设备、Material 浅色主题下按住不放的稳态：有界涟漪是以视图中心为圆心、半径为视图半对角线 R 的径向层，r≤0.6R 处约 8.6%、R 处约 6%，不等于任何一版 highlight_alpha 原值；标题栏按钮是半径 20dp 的白色无界圆，圆心在按钮内容区中心，圆外无色
- 〔做法第 2 步〕radialGradient 的 center 是相对组件左上角的坐标、radius 是半径，number 时单位都是 vp；radius 小于 0 按 0 处理，为 undefined 时按组件尺寸自动计算；colors 里的位置取值 [0, 1.0]，越界截到端点，非法颜色跳过；repeating 默认 false
