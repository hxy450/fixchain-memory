# Compose 渐变按端点几何换算成 ArkUI linearGradient：默认对角按宽高算角度，端点周期按渐变线长缩放 stop，Mirror 用回文 stop

## 何时使用

界面实现阶段，把 Brush.linearGradient/horizontalGradient 翻成 ArkUI linearGradient，确定方向角、stop 位置与平铺、平移写法时

## 适用情境

源渐变或未指定 start/end（默认从组件左上 (0,0) 到右下 (w,h)），或以端点距离（startX/endX、start/end）定义图案周期并配 TileMode.Mirror 与随滚动、动画的平移；ArkUI linearGradient 只有角度或方向、按组件自身渐变线长取比例的 stop 和 repeating 开关；目标组件可能宽高不等（胶囊、卡片）。 只有源端是 Repeated / Mirror 平铺时才开 repeating：源端用默认 TileMode.Clamp 时，端点之外延续端色、不重复，stop 照样按端点距离 / 渐变线长换算，但不开 repeating。horizontalGradient、verticalGradient 不给端点时铺满组件宽或高（startX 为 0、endX 为无穷大），ArkUI direction Right、Bottom 已经等价，不在角度换算范围内。

## 原因

Compose 默认渐变轴沿组件自身对角线；ArkUI GradientDirection.RightBottom（angle 135）是 CSS “to bottom right” 语义，只在宽高相等时等价，宽胶囊上会变成接近上下渐变。ArkUI 的 stop 是相对组件渐变线长的比例，末 stop 为 1 时 repeating 不起作用；面板为覆盖显示区加宽后仍按 0–1 铺 stop，周期就被拉长。Mirror 与端点平移也有对应写法，登记“无等价”后改成转角动画等于换成另一种效果。

## 做法

1. 未指定端点的默认对角渐变：宽高不等时用 angle = 90 + atan2(h, w)（度），宽高取 onAreaChange 实测；圆形、正方形可保留 RightBottom。
2. 端点定义周期时：按源端点距离算出图案周期 P，stop 写成 P / 面板渐变线长 的比例，保证末 stop < 1，并与相位取模的周期一致。
3. TileMode.Mirror 把颜色写成首尾同色的回文 stop（A→B→A）并开 repeating；端点平移用比显示区大一个相位周期的面板做 position/translate，外层 clip。登记“无等价”前先试这组写法。

## 可选检查

- stop 有疑问时用“末 stop × 面板长度 = 周期”核一遍。

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 未用。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔原因 / 做法第 1 步〕linearGradient 的 angle 单位为度：0 度时渐变方向从下往上，顺时针为正（90 为从左往右）；不写时默认 180；字符串格式非法时按 180 处理
- 〔原因 / 做法第 1 步〕linearGradient 的 direction 默认 GradientDirection.Bottom（从上向下）；angle 设为非 undefined 后 direction 不生效
- 〔原因〕宽高不等的宽胶囊上用 GradientDirection.RightBottom 时，渐变呈接近上下走向，不沿组件自身对角线；文档的 GradientDirection 表把 RightBottom 写作「从右下向左上」，运行时表现以卡里为准
- 〔原因 / 做法第 2 步〕linearGradient 的 colors 每项是 [颜色, 位置]，位置取值 [0, 1.0]（小于 0 按 0、大于 1.0 按 1.0），0 是渐变开始处、1.0 是结束处；后一项位置小于前一项时按前一项处理
- 〔原因 / 做法第 2、3 步〕LinearGradientOptions.repeating 默认 false；为 true 时渐变在组件范围内循环重复填充
