# TextView 的 shadowColor/shadowRadius 映射为 Text.textShadow

## 何时使用

界面实现阶段，转换带文字阴影的 TextView 时

## 适用情境

源 TextView 设 shadowColor 与 shadowRadius，映射参考把它对应到 .shadow()。

## 例外与边界

- 源端 shadowRadius 为 0 或没写时，安卓移除阴影层、文字没有阴影，即使写了 shadowColor、shadowDx、shadowDy 也不加 textShadow

## 原因

.shadow() 是组件框阴影，不产生文字阴影。

## 做法

1. 用 .textShadow({ radius, color, offsetX, offsetY })，radius、offsetX、offsetY 照搬源端 shadowRadius、shadowDx、shadowDy 的数值（两端都按像素，不换算 vp）；映射参考与 API 语义冲突时以 API 语义为准，并记录参考错误。

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 android-37.0 的平台资源；android-36.1 的源码。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔原因〕CommonMethod.shadow 给组件本身加阴影（组件框阴影）；文字阴影由 Text 的 textShadow 设置，textShadow 不支持 ShadowOptions 的 type、fill 字段
- 〔做法第 1 步〕ShadowOptions 的 radius、offsetX、offsetY 单位都是 px；offsetX、offsetY 没写时为 0；radius 小于 0 时按 0 处理、不绘制阴影（API 26.0.0 起取值规则变更，超出本机 SDK 的 API 23）
- 〔做法第 1 步〕TextView 的 shadowRadius、shadowDx、shadowDy 属性格式是 float，TextView 用 getFloat 原样读出交给 setShadowLayer，不做 dp 换算
