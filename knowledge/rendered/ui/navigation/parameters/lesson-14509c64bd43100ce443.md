# 源端带结果回调的选择器（show(..., 当前值) { result -> 写回 }）改为路由页或弹窗打开时，同一改动接通结果回传并写回当前编辑状态

## 何时使用

界面实现阶段，把源端带回调的选择弹层（文案库、素材库等）改成 ArkUI Navigation 跳转或弹窗，并接到编辑项时

## 适用情境

Android 以 DialogFragment.show(..., 当前值) { result -> 写回控件 } 打开选择器；迁移后调用页 pushPathByName 打开同名目的地，目标页参数类只带初始值，或其加载、选中仍是前向引用。

## 原因

只移植“打开”而不移植“回传”，选择器能打开，选中后只关闭，编辑器没有任何变化；目标页参数类没有回调字段时，调用方即使写好了更新方法也接不上。

## 做法

1. 在同一改动中定义并接通回传（参数带结果回调，或用 onPop 结果、结果令牌；用 onPop 时目标页要以带 result 的 pop、popToName 或 popToIndex 出栈，不带 result 的出栈不触发 onPop），调用方把结果写入当前编辑状态并刷新预览。写回照源端回调里的写法执行：源端先校验再写的（回调里先检查再 setText）保留这道校验，不改成无条件覆盖；用户没选就返回时不触发回传，当前值保持不变。
2. 接入目标页前先读它的参数类与前向引用：没有回传字段，或加载、选中仍是前向引用时，要么在授权范围内补齐两端，要么在完成回执里登记为未闭合，不把入口标成已完成。

## 可选检查

- 在调用页检索 pushPathByName 的目标页名，确认参数带结果回调或存在结果接收处理，并与源端回调里的写回动作逐项对应。

来源支持：1 张卡 · 1 次迁移 · 1 个应用

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 不涉及。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔做法第 1 步〕pushPathByName 带 onPop 的重载在入栈页出栈时回调 onPop 处理返回结果，但只在 pop、popToName、popToIndex 设置了 result 参数时触发；不带 result 的出栈（如系统返回）不触发 onPop
- 〔做法第 1 步〕NavPathStack.pop(result) 弹出栈顶页并调用 onPop 把 result 传回；栈为空时返回 undefined
