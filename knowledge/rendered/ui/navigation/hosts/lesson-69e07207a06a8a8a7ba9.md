# 根 Navigation 只作路由容器时显式隐藏默认标题栏和工具栏

## 何时使用

界面实现阶段，为入口页根 Navigation 编写属性链时

## 适用情境

源端外壳没有系统标题栏或工具栏（如 Compose Scaffold 只传自绘 bottomBar 与 snackbarHost），目标以 @Entry 页的 Navigation 作根路由容器，承载 tab 内容和自绘底栏，详情页走 NavDestination。根 Navigation 若用 title 或 toolbarConfiguration 承载源端确实有的标题、底部导航项，那一栏不隐藏，只隐藏没有承载内容的栏；用系统标题栏显示标题和返回钮的 NavDestination 也不加 hideTitleBar。

## 原因

来源中根 Navigation 未设 title 仍为默认栏保留了空间，内容区比 NavBar 短一截，自绘底栏悬空；“不设 title 就不占位”是未经核实的推断。该案例没有分开验证标题栏与工具栏各自的占位，两者一并隐藏后恢复。

## 做法

1. 根 Navigation 写 .hideTitleBar(true).hideToolBar(true)，自绘标题的 NavDestination 另写 .hideTitleBar(true)；对属性是否默认占位拿不准时先查导航参考，不凭推断删掉已拟写的属性。

## 可选检查

- 有设备时用 dumpLayout 核对 NavBarContent 与 NavBar 同高；内容区比 NavBar 短一个固定值时先查默认栏。

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 不涉及。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔原因 / 做法第 1 步〕Navigation 的 hideTitleBar、hideToolBar 不设时都为 false，即标题栏、工具栏默认显示；Navigation 内部默认包含标题栏、内容区和工具栏
- 〔原因〕Navigation 只在未设置 title 且 hideBackButton 为 true 时不显示标题栏；只是不设 title 并不会去掉标题栏
- 〔做法第 1 步〕NavDestination 的 hideTitleBar 不设时为 false（显示标题栏）
- 〔原因〕根 Navigation 未设 title、也未设 hideTitleBar、hideToolBar 时，屏幕上看不到标题栏，但 dumpLayout 里 NavBarContent 比 NavBar（776.9vp）短 112vp
