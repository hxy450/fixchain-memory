# 源端未显式定制的光标外观以用户指定页面的真机取证为基准：不借其他页面代取样，用帧差分定位光标

## 何时使用

界面还原修复阶段，为输入框光标这类源端未显式定制、取决于页面主题或系统渲染的外观选取安卓基准，并写入 caretStyle 时

## 适用情境

源 EditText 没有 textCursorDrawable，外观取决于所在 Activity 的主题和系统渲染；同一应用其他页面已有不同的光标配置；需要真机像素取证；目标为 TextInput 的 caretStyle({ width, color })。

## 例外与边界

- 源端显式设置了 textCursorDrawable，此时打开该 drawable 取宽度与颜色
- 一时无法真机取证时，可先按页面主题静态解析作为待核基准并注明：所在 Activity 主题属 Theme.Material 系且没有另设时，默认光标是 text_cursor_material（2dp 宽，颜色取 colorControlActivated，未设时取 colorAccent）；AppCompat、MaterialComponents 主题由依赖库覆盖，仍以取证为准

## 原因

光标的默认外观随 Activity 主题和着色而变，同一应用不同页面可能不同；用另一页面的输入框代取样再写成“安卓实测”，后续验证也只会和这个错误基准比较。来源中修复者读到登录页三个 EditText 无光标 drawable、其他页面显式用了黄色光标，却假定“默认光标各页相同”，在完善资料页取样得到灰色 1dp 写进登录页；用户三次追诉后才在登录页实测到主题蓝 2dp。按暗像素阈值扫描还曾漏掉蓝色光标。

## 做法

1. 以用户指定页面（同一 Activity、同一主题）的真机取证为基准；目标页一时到不了（如需退出登录）时请用户切到该页，或先不写入。确需借用其他页面时先核两个 Activity 的主题与控件着色相同，并在注释与报告写明基准来自哪个页面。
2. 像素取证光标时不预设颜色：先用闪烁 ON/OFF 两帧差分定位光标，再取色、量宽高；只扫暗像素会漏掉彩色光标。
3. 光标宽度与颜色用 caretStyle({ width, color }) 设置（当前 SDK 的 TextInput 没有 caretWidth）；写前在本地 SDK 声明核对属性名。

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 android-37.0 的平台资源。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔适用情境 / 做法第 3 步〕TextInput 应用没有另设 caretColor 时光标色为 '#007DFF'
- 〔原因〕同一应用里没写 textCursorDrawable 的 EditText，在不同 Activity 上真机取样的光标可以不同：一页为深灰约 1dp，另一页为主题蓝 2dp
- 〔原因 / 做法第 1 步〕安卓平台主题里，Theme.Material 的 textCursorDrawable 为 @drawable/text_cursor_material，根主题 Theme 为 @null
- 〔原因 / 做法第 1 步〕平台 text_cursor_material 是宽高各 2dp 的矩形（外加 2dp inset），颜色取主题属性 colorControlActivated 着色
- 〔原因 / 做法第 1 步〕应用主题没有另设 colorControlActivated 时，Theme.Material 系取 colorAccent：Theme.Material 下为 #ff80cbc4，Theme.Material.Light 下为 #ff008577（AppCompat、MaterialComponents 主题由依赖库另行覆盖，未核）
- 〔做法第 3 步〕CaretStyle 的 width 不支持百分比，没设时为 '2vp'；color 没设时为 '#ff007dff'（蓝色）
- 〔做法第 3 步〕Length 写 number 时默认单位 vp，caretStyle 的 width: 2 即 2vp
- 〔做法第 3 步〕同时设置 caretColor 和 caretStyle 的 color 时，后设置的生效
