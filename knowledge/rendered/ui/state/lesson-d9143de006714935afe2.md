# 源端 Activity 实例字段承载的会话态映射为页面实例作用域：服务需要持有会话态时按页面实例创建，只有源端本就静态全局的状态才做单例

## 何时使用

规格提取与服务实现阶段，为页面编排服务确定作用域（单例还是页面实例），并迁移源 Activity 的实例字段（待写数据、密钥映射、挂起状态）时

## 适用情境

源 Activity 把本次会话的数据放在实例字段里，Activity 重建或另开一个实例就是全新状态；目标规格把页面编排服务写成单例，实现者用 getInstance() 持有这些字段，并以 attach 时复位来近似实例重建。

## 例外与边界

- 源端该状态本就是静态全局的（如公共类的静态字段），此时可以映射为单例

## 原因

单例让会话态跨页面实例共享：同一页面被打开两次、或从不同入口进入时，后一次可能读到前一次的残留，复位逻辑只能近似 Activity 重建。来源中规格作者已读到这些字段是 Activity 实例字段，仍把服务定为“页面编排单例”，实现照写。

## 做法

1. 规格把 Activity 实例字段承载的状态声明为页面实例作用域；页面持有自己的服务实例（new Service()）并在进入时初始化，只有源端静态全局的状态才映射为单例。

来源支持：1 张卡 · 1 次迁移 · 1 个应用

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；安卓 Android SDK 源码 android-36.1。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔做法第 1 步〕router 跳转默认是 RouterMode.Standard：无论栈里有没有同 url 页面都新建实例压栈；用 RouterMode.Single 时，栈里已有同 url 页面就把那个已有实例移到栈顶、不新建实例，页面实例上的服务和状态保留（aboutToAppear 只在新建实例时执行，onPageShow 每次显示都执行）。〔成立范围：对 @ohos.router（含 UIContext.getRouter()）带 mode 参数的跳转成立；Single 下栈里有多个同 url 页面时移动离栈顶最近的那个，没有同 url 页面时按 Standard 新建。API 19 起被 Single 移到栈顶的已有页面会触发 @Entry 组件的 onNewParam，新传的参数从这里拿。onPageShow 只对 router 页面（@Entry 组件）生效，Navigation 子页对应 NavDestination 的 onShown。〕
- 〔做法第 1 步〕Navigation 的 NavPathStack 默认 LaunchMode.STANDARD 压入新 NavDestination；MOVE_TO_TOP_SINGLETON、POP_TO_SINGLETON 在栈里已有同名页面时复用那个实例（移到栈顶或弹掉它上方的页面）；连续调用多个栈操作时只按最终结果执行，在 Page1 先 pop 再 push Page1 会被视为没有变化、保留原实例，要强制新建须用 LaunchMode.NEW_INSTANCE。〔成立范围：依据是文档说明；对通过 NavigationOptions.launchMode 指定模式的 push 类操作成立，两种 SINGLETON 模式下的 replace 是把栈顶替换成指定页面。文档写明 NEW_INSTANCE 与 STANDARD 相比不复用栈中同名实例。〕
- 〔适用情境〕安卓 Activity 设了 launchMode="singleTop"，或启动时带 Intent.FLAG_ACTIVITY_SINGLE_TOP，在它已位于栈顶时再次启动不新建实例，而是在已有实例上调用 onNewIntent()，实例字段保留，getIntent() 仍返回原 Intent。〔成立范围：singleTop 只在目标 Activity 已位于任务栈顶时复用（javadoc 原话）。launchMode 为 singleTask、singleInstance 时，已有实例不在栈顶也会被带到前台并收到 onNewIntent（依据是 manifest 属性文档）。默认 standard 一般每次启动都新建实例，但 Intent 带 FLAG_ACTIVITY_CLEAR_TOP 时会关掉它上方的 Activity，同时带 FLAG_ACTIVITY_SINGLE_TOP 才在原实例上调 onNewIntent（不带则销毁重建）；带 FLAG_ACTIVITY_REORDER_TO_FRONT 时把已运行的实例移到栈顶、不新建。〕
- 〔例外与边界〕ArkTS 普通（非共享）模块在同一线程内只加载一次、在不同线程各加载一份，模块里的单例和静态字段在 Worker、TaskPool 线程里是另一份对象；要进程内唯一，只能用 "use shared" 标记的共享模块。〔成立范围：依据是文档说明；在同一线程（如 UI 主线程）内单例唯一。共享模块导出的变量必须是可共享（Sendable）对象。〕
