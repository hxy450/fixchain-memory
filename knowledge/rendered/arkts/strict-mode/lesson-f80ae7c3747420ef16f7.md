# 静态字段初始化器或模块级常量里把类当值使用时，该类要声明在使用者之前或从独立文件导入

## 何时使用

数据层或状态实现阶段，在服务类中用静态字段持有共享状态（AppStorageV2.connect、new Cls()）并安排同文件模型类的位置时

## 适用情境

服务类准备用 static 字段初始化器调用 AppStorageV2.connect(Cls, key, () => new Cls())、PersistenceV2.globalConnect 或 new Cls()，被引用的 @ObservedV2 类按原有布局追加在文件末尾；原先对它只有类型注解或方法体内的引用。

## 原因

类型注解和方法体内的引用不在类定义时求值，放在后面可以编译；static 初始化器在类定义时就需要被引用类的运行时值，类声明在后会报 Class 'X' used before its declaration。来源中实现者把购物车状态改为 static readonly 字段直接 connect，新状态类仍追加在文件末尾，编译失败；它没有可用的编译脚本，写后没有发现。

## 做法

1. 在 static 字段初始化器或模块级常量中把类当值使用前，确认该类在同一文件中声明在使用者之上，或拆到独立模型文件后 import；把原有类型级引用改成即时求值时，同步移动被引用类。
2. 共享状态也可以用静态 getter 或方法在首次调用时 connect；同一 key 返回同一实例，不会产生多份状态，也避免类定义期求值。

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；安卓 不涉及。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔做法第 2 步〕PersistenceV2 必须与 UI 实例关联，connect、globalConnect 等持久化操作要在 UI 实例初始化完成后（windowStage.loadContent 的回调触发后）调用。〔成立范围：对象：PersistenceV2.connect、PersistenceV2.globalConnect。条件：写在 static 字段初始化器或模块级常量里时在模块加载、类定义时就执行；所在模块若被 EntryAbility 等在 loadContent 回调之前运行的代码导入，调用就早于这一时机。文档的使用场景示例在 @ComponentV2 页面的成员初始化里调用 connect、globalConnect。不成立的情形：AppStorageV2 的文档只要求在 UI 线程配合 UI 使用，没有写 loadContent 之后这一条。依据是文档说明。〕
- 〔做法第 2 步〕AppStorageV2.connect 与 PersistenceV2.globalConnect 在给定 key 已存在时返回已存的那份数据，不再调用默认构造器；key 不存在时才用默认构造器创建、存入并返回。〔成立范围：对象：AppStorageV2.connect(type, key, defaultCreator)、PersistenceV2.globalConnect。条件：同一 key、类型一致；未指定 key 时以 type 的 name 作 key。不成立的情形：remove 掉该 key 后再 connect 会得到新对象，之前拿到的对象与存储失去关联。〕
- 〔适用情境〕同一个 key 用 connect（或 globalConnect）连接不同类型的数据会导致应用异常，类型匹配要由应用自己保证。〔成立范围：对象：AppStorageV2.connect、PersistenceV2.connect 与 globalConnect 的 key。条件：静态字段、页面、其他服务各自 connect 同一 key 却传入不同的类；未指定 key 时以 type 的 name 作 key，不同文件里同名的两个类都不传 key 也会落到同一个 key 上。同类情形：PersistenceV2 里 connect 与 globalConnect 混用同一 key 也会使应用 crash（API 23 起返回错误码 140105）。不成立的情形：各处显式传了不同的 key，或都不传 key 而类名不同时不冲突。依据是文档说明。〕
- 〔适用情境〕PersistenceV2 只有 @Trace 属性的改变会触发自动持久化；V1 状态变量、@Observed 对象和普通属性的改变不会持久化，需要时调用 PersistenceV2.save 手动保存。〔成立范围：对象：经 PersistenceV2.connect 或 globalConnect 关联的对象。条件：@ObservedV2 类里没加 @Trace 的属性，或非 @ObservedV2 的类；另外被持久化的类属性必须有初值，否则不支持持久化。不成立的情形：API 23 起 globalConnect 持久化顶层容器类型（Array、collections.Array 等）时，defaultCreator 返回经 UIUtils.makeObserved 包装的对象后其变化也会自动持久化（文档示例注明要这样包装）；AppStorageV2 只存在内存中，不涉及持久化。依据是文档说明。〕
