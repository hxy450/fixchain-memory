# 不能编译的生成或修复批次，写后把引用的常量、this 成员、跨文件导入名与 $r 资源键逐一对照声明、导出和资源定义；源端局部派生值改为经持有对象访问

## 何时使用

实现或修复阶段，在禁止编译的条件下一次写出大型 ArkTS 页面，或新建工具文件并在其他文件接线，并做写后自检时

## 适用情境

整页由一次写入生成，常量区与状态区由写者自拟；源码在方法里用局部派生值（如 isX = current instanceof Y）控制菜单显隐，目标把该对象建模为可空状态；设计里决定的尺寸以具名常量在调用点引用。也包括把 Kotlin object 或 Java 静态工具类改写为 ArkTS 顶层 export function，又在基类等其他文件按源端 ClassName.method 写法导入调用。 也包括页面转换先按源值预估的键清单向共享 element/*.json 追加资源，再写组件里的 $r('app.float|color|string.*') 引用；同一容器各方向的 padding/margin 可能用到清单之外的键。

## 原因

一次生成大文件时，调用点引用的具名常量可能从未写进常量区，源端局部变量名也可能被写成组件成员 this.isX；括号平衡、禁用词、装饰器版本、占位登记这类自检都查不出未声明标识符，错误要到首次编译才出现。来源两处缺陷都在首次写入里，不是后续编辑被截断。 资源追加先于组件写入时，组件实际引用的键可能不在追加清单里，悬空 $r 引用同样只在编译或资源审计时暴露；来源中“布局字面量均已资源化”的自检没有查键是否存在。

## 做法

1. 写后提取文件中所有 this.<名> 与大写常量引用，与 const、@Local/@Param/private 等声明做差集；差集非空就补定义或改引用。
2. 源端局部派生值迁到模型字段后，每个使用点写成经空值判断的持有对象访问（this.<对象> !== null && this.<对象>.<字段>），或显式声明同名 getter；不把源局部变量名直接当成组件成员。
3. 设计中决定用具名常量表示的尺寸（如按钮命中区），在写调用点的同一次写入里加入常量区。
4. 改写工具类的导出形态时同步全部调用处：顶层 export function 用具名导入 { fn } 并去掉类名前缀；要保留 ClassName.method 写法就导出 class 或 namespace；跨文件接线后 grep '^export' 核对被导入名确实导出。
5. 组件写完后，从文件中实际出现的 $r('app.<type>.<name>') 提取键清单，到 resources/base/element/*.json（media 键对 media 目录）逐个查定义，本模块查不到的再看 AppScope/resources 和所依赖 HAR 的资源，都没有才算缺失并补；从源布局抽尺寸时把同一容器各方向的内外边距一并列入，不只按写组件前预估的数值清单追加。

来源支持：3 张卡 · 3 次迁移 · 3 个应用

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-28（提交 4d3e2aa3）；安卓 不涉及。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔做法第 4 步〕ArkTS 的命名空间不能当对象用（规则 arkts-no-ns-as-obj，错误级，错误码 10605114）：可以用 X.member 访问成员，但不能把命名空间本身赋给变量或当值传递；命名空间里只能放声明，不能放非声明语句（规则 arkts-no-ns-statements，错误级，错误码 10605116），初始化逻辑要写进函数。
- 〔做法第 5 步〕$r 的参数是普通字符串字面量 'app.<类型>.<名>' 时，编译对照模块的资源表校验：第一段不是资源表里有的来源报 10903331「Unknown resource source」，类型不存在报 10903330「Unknown resource type」，名字不存在报 10903329「Unknown resource name」，都是错误级；参数写成不带 ${} 的模板字符串时做同样的校验，但只报警告、不让编译失败；带 ${} 的模板字符串不校验。引用 HSP 包资源的「[包名].<类型>.<名>」写法只在工程配置了 hspResourcesMap 时按警告校验，没配置时不校验。参数不是三段时报 10905332：不带 ${} 的模板字符串是警告，普通字符串字面量（包括「[包名]」写法）是错误。
- 〔做法第 5 步〕resources/<限定词或 base>/element 下按数据类型各用一个 JSON 文件（建议名 boolean.json、color.json、float.json、intarray.json、integer.json、plural.json、strarray.json、string.json），一个文件里只放同一类型；图片、音视频这类文件放 media 目录，用 $r('app.media.<名>') 引用。$r('app.<类型>.<名>') 能取到的不只本模块 resources 里的，还包括模块依赖的 HAR 的资源，以及编译时合入模块的 AppScope/resources（和模块里重名时编译后只保留 AppScope 的）。
- 〔做法第 5 步〕float.json 的条目写成 {"name": "<名>", "value": "<数值>"}，value 是字符串，可以带单位（文档示例 "28.0fp"；getNumber 的说明列了带 vp、带 fp 和不带单位三种）；资源名只是名字，数值以 value 为准。
