# OkHttp 缓存映射到 RCP ResponseCache 时，maxSize 按实测单位传入并实写确认，缓存指令名逐项保留

## 何时使用

网络层与图片策略实现阶段，把 OkHttp Cache(dir, N MiB) 的容量与 CacheControl 指令映射到 RCP ResponseCache 或请求缓存头时

## 适用情境

源端用 OkHttp Cache 提供自动 HTTP 缓存，并用 CacheControl.Builder().maxAge(...).maxStale(...) 控制图片缓存；目标用 @kit.RemoteCommunicationKit 的 rcp.ResponseCache / CacheConfiguration。

## 例外与边界

- 保留 max-age、max-stale 等指令名只决定请求里发出的缓存指令；ResponseCache 里记录多久过期由 CacheConfiguration.defaultExpirationPolicy 或记录自带的过期策略决定，两者都没设时隐式按 1 小时的滑动过期——源端靠 maxAge 定下的缓存时长要另配过期策略，不能当作指令名保留后自动生效。

## 原因

hms rcp.d.ts 对 CacheConfiguration.maxSize 注释为 Unit: MB，已观察到 API 26 运行时却按字节解释：按文档传 200 时 ResponseCache.set 报 item is too long for cache limits，缓存实际不写入；拦截器若空 catch 吞掉 set 的错误，问题一直不可见。maxStale 与 stale-while-revalidate 是不同指令，替换后过期响应的复用条件改变。

## 做法

1. CacheConfiguration.maxSize 在 API 26 运行时按字节传入（MiB×1024×1024）；其他运行版本以一次真实 2xx 写入后 cache.getState() 的 count>0 为准确定单位。
2. ResponseCache.set 失败至少记录错误信息，不空 catch。
3. CacheControl 指令逐项保留名称：maxAge 对应 max-age，maxStale 对应 max-stale，不用 stale-while-revalidate 代替 max-stale。

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 com.squareup.okhttp3:okhttp 4.12.0。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔原因 / 做法第 1 步〕CacheConfiguration.maxSize 的声明注释写「50 MBytes by default」、@default 50，即按 MB 解释；声明没有写超出时 set 报什么错
- 〔原因 / 做法第 1 步〕API 26 运行时，CacheConfiguration.maxSize 传 200 时约 216 字节的记录被 ResponseCache.set 以 item is too long for cache limits 拒绝、缓存不写入，说明该运行时按字节解释 maxSize；与 API 23 声明注释的 MB 说法不同，运行时表现以卡里实测为准
- 〔做法第 1 步〕ResponseCache.getState() 返回的 CacheState 里 count 是缓存中的响应条数，size 是已存响应大小之和
- 〔做法第 1 步〕new ResponseCache(configuration) 在数据目录路径为空或 maxSize、maxItems 等上限为负时抛 1007900401
- 〔做法第 2 步〕ResponseCache.set 参数校验失败抛 BusinessError 1007900401，文件系统 IO 错误抛 1007900985
- 〔适用情境 / 做法第 3 步〕CacheConfiguration 没有设 defaultExpirationPolicy、记录也没有自带过期策略时，按 1 小时的 SlidingTimeExpirationPolicy 隐式过期，不读源端 CacheControl 的 max-age
- 〔做法第 3 步〕OkHttp 4.12.0 的 CacheControl 生成和解析的指令名是 max-age、max-stale、min-fresh 等，maxStale 对应 max-stale，类里没有 stale-while-revalidate 指令
