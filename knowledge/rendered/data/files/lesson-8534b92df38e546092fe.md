# 文件导入导出按源端运行时与库默认语义实现：OOM 兜底不改成读前大小阈值，无数量上限就取目标 API 最大值，ZipOutputStream 默认 DEFLATED，picker URI 末段解码后作显示名

## 何时使用

规格提取与数据层实现阶段，把源端导入导出的异常兜底、压缩流、系统选择器返回值与数量限制映射为目标平台实现时

## 适用情境

Android 导入导出只在 catch(OutOfMemoryError) 时提示文件过大、没有大小阈值；用 ZipOutputStream 打包且未调用 setMethod；以 getFileName 一类 helper 取 DISPLAY_NAME；选择器用 EXTRA_ALLOW_MULTIPLE 不限数量。目标使用 DocumentViewPicker 返回的 URI，系统 zip API 不能控制 entry 名与时间而改手写容器；规格可能把 OOM 兜底写成“读前长度预检”，派工也写了“文件大小上限校验”。

## 例外与边界

- 确需上限或不同压缩方式时登记为有意偏离，并写明数值来源与可见影响

## 原因

读前阈值会拒绝源端能导入的大文件；自定的“安全”数量上限、不压缩的条目与对目录的静默跳过，都改变了导出结果或失败语义；picker 返回的 URI 末段是百分号编码的，直接当显示名会出现 %20 一类字符。来源中规格把 OOM 兜底译成预检，实现者按规格加了 16 MiB 阈值，又自定选择上限 100、因系统 zip API 不可控改成不压缩并跳过非普通文件，页面把未解码的 URI 末段当文件名。

## 做法

1. 源端用 catch(OutOfMemoryError) 兜底时照常读取，捕获目标平台的分配失败（如 RangeError）再提示，不新增读前大小阈值。
2. 源端没有数量限制时取目标 API 允许的最大值（如 DocumentSelectOptions.maxSelectNumber：API 20 及之前最大为 500；API 21 起文档写明取消文件选择数量上限，取值不必限制在 500 以内），不另定更小的“安全值”。
3. 手写 zip 容器时压缩方式仍按源端：ZipOutputStream 未 setMethod 即 DEFLATED，用 zlib 产出原始 deflate 流并加数据描述符；源端会失败的条目（如目录）同样判失败，不静默跳过。
4. 近似源端 helper（如取文件显示名）前先读完它的实现；picker 返回的 file://docs URI 去掉 query/fragment 后对末段 decodeURIComponent，并用含空格或中文的文件名自测。

已核实的平台事实（核实时用的是 HarmonyOS 6.1.0（API 23，SDK 6.1.0.105）；OpenHarmony 文档 master 2026-11-21（提交 e42bd18a）；安卓 android-36.1 的源码。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看）：
- 〔做法第 2 步〕DocumentSelectOptions.maxSelectNumber：本机 API 23 的声明注释写取值 1 到 500、默认 1；文档 master 写 API 20 及之前单次文件选择上限 500、默认 500，API 21 起取消文件选择数量上限（建议单次不超过 1 万个）；行为以文档为准
- 〔适用情境 / 做法第 2 步〕Intent.EXTRA_ALLOW_MULTIPLE 是布尔 extra，应用没有往 Intent 里放这个 extra 时按 false；为 true 时实现可以让用户选择并返回多项，这个 extra 本身不带数量上限
- 〔做法第 3 步〕java.util.zip.ZipOutputStream 没有调 setMethod、条目也没设 method 时，按 DEFLATED（压缩）写条目
- 〔做法第 3 步〕ZipOutputStream 写 DEFLATED 条目且事先没给出大小、压缩后大小和 CRC 时，通用标志置 8（使用数据描述符）；条目名按 UTF-8 编码时再或上 USE_UTF8（0x800），两者合起来是 0x0808
- 〔做法第 3 步〕zlib 的 deflateInit2 用 windowBits 同时指定窗口大小和数据格式：zlib 格式 [8, 15]，gzip 格式 [24, 31]，raw deflate 格式 [-15, -8]
- 〔做法第 3 步〕安卓上 FileInputStream 经 libcore 的 IoBridge.open 打开文件，路径是目录时以 EISDIR 报错（Java 不允许读目录），打开即失败
- 〔做法第 4 步〕DocumentViewPicker.select 返回的 file://docs URI，末段的文件名是百分号编码的（中文、空格等字符被编码）
