# 位图着色（ColorFilter.tint、setColorFilter）用 Image.colorFilter：fillColor 只对 SVG 图源生效

ID：`lesson-1a66114fb7523a1f9af1` · 版本：1

> 带知识的试验版（未并入 store）：正文按 `knowledge/lessons/lesson-1a66114fb7523a1f9af1.json` 改了 3 句，后面接了 17 条已核实的平台事实。原文、来源和证据卡见 [memory/ui/effects/lesson-1a66114fb7523a1f9af1.lesson.md](../../../../memory/ui/effects/lesson-1a66114fb7523a1f9af1.lesson.md)。

## 何时使用

界面实现阶段为源端着色的图片写 ArkUI Image 修饰链、选择着色 API 时；规格提取阶段为 ColorFilter.tint 一类着色写转换决策时

## 适用情境

源端 Compose Image 的 colorFilter = ColorFilter.tint(color)（默认 SrcIn），或 ImageView 的 tint、setColorFilter（XML android:tint 未写 tintMode 与 setColorFilter(int) 默认 SRC_ATOP，app:tint、setImageTintList 默认 SRC_IN），作用在 png/jpg/webp 位图上（常见白色加透明通道、靠着色才可见的示意图）；目标资源仍是同一位图；规格转换行可能把 fillColor 与 colorFilter 列成并列选项。

## 例外与边界

- 资源已转成 SVG 时，fillColor 可以承担着色

## 原因

ArkUI Image.fillColor 只作用于 SVG 图源，对位图不改像素颜色，白色透明位图在浅色背景上几乎看不见（HarmonyOS 6.1.0(23) 工程实测）；位图着色要经 colorFilter。

## 做法

1. 位图用 Image.colorFilter：SrcIn 着色写 drawing.ColorFilter.createBlendModeColorFilter(色值, drawing.BlendMode.SRC_IN)，源端是 SRC_ATOP 时换成 drawing.BlendMode.SRC_ATOP（着色色不透明时两者结果相同）（@kit.ArkGraphics2D，色值为 common2D.Color，可由 '#AARRGGBB' 主题色拆出），不改写成 4x5 矩阵（矩阵着色要把着色色写进第 5 列偏移量，偏移量的刻度平台没有规定）；颜色在渲染期按当前主题取值，不着色的分支不挂滤镜。
2. 修饰符对当前资源类型是否生效拿不准时，先查 SDK component/image.d.ts 中该属性的注释再写；规格写着色决策时注明源资源格式，只给对该格式生效的 API，并在同一行写出前提（如“PNG 位图 → colorFilter SRC_IN；fillColor 仅 SVG”），下游汇总规格时不丢掉这一前提。

## 可选检查

- 对着色是否生效有疑问时，在浅色与深色背景下各截图一次，核对白色透明位图是否显出着色。

## 已核实的平台事实

核实时用的是 HarmonyOS 6.1.0（API 23，openharmony ets 6.1.0.105；文档副本含到 API 26 的内容，超出 SDK 的已注明）；安卓 平台资源 android-34；框架源码 android-36.1；androidx Compose 1.10.3（foundation、ui、ui-unit、ui-graphics，按字节码核）。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看；每条下面的「写法」是在 SDK 声明里核过的导入语句、归属、签名和枚举成员，写代码时直接照抄。

- 〔适用情境〕Compose ColorFilter.tint(color, blendMode) 的 blendMode 默认 BlendMode.SrcIn（出处：androidx.compose.ui:ui-graphics 1.10.3，androidx.compose.ui.graphics.ColorFilter.Companion#tint 的默认参数）
- 〔适用情境〕ImageView 的 XML android:tint 在布局和 style 都没写 tintMode 时混合模式是 SRC_ATOP（兼容 L 以前），setColorFilter(int) 也按 SRC_ATOP（出处：android.widget.ImageView#ImageView(Context, AttributeSet, int, int)、android.widget.ImageView#setColorFilter(int)）
- 〔适用情境〕setImageTintList 与 AppCompat 的 app:tint 在没另设 tintMode（app:tintMode、setImageTintMode）时不改混合模式，用 Drawable 默认的 SRC_IN（出处：android.widget.ImageView#setImageTintList、#applyImageTint；android.graphics.drawable.Drawable#DEFAULT_TINT_MODE；androidx.appcompat:appcompat 1.8.0，AppCompatImageHelper#loadFromAttributes）
- 〔适用情境〕drawing.BlendMode.SRC_IN = 5（r = s × da）、SRC_ATOP = 9（r = s × da + d × (1 − sa)）：着色色不透明时两者结果相同，半透明时 SRC_ATOP 还透出原图（出处：鸿蒙 SDK 的 ets/api/@ohos.graphics.drawing.d.ts，drawing.BlendMode.SRC_IN、SRC_ATOP）
  写法：import { drawing } from '@kit.ArkGraphics2D'
        drawing.BlendMode：CLEAR=0、SRC=1、DST=2、SRC_OVER=3、DST_OVER=4、SRC_IN=5、DST_IN=6、SRC_OUT=7、DST_OUT=8、SRC_ATOP=9、DST_ATOP=10、XOR=11、PLUS=12、MODULATE=13、SCREEN=14、OVERLAY=15、DARKEN=16、LIGHTEN=17、COLOR_DODGE=18、COLOR_BURN=19、HARD_LIGHT=20、SOFT_LIGHT=21、DIFFERENCE=22、EXCLUSION=23、MULTIPLY=24、HUE=25、SATURATION=26、COLOR=27、LUMINOSITY=28
        全局 BlendMode（给 .blendMode 属性用）是另一个枚举，数值不同（全局 SRC_IN = 6）
- 〔原因〕ImageAttribute.fillColor 只对 SVG 图源生效（AnimatedDrawableDescriptor 也不生效），对 png 等位图不起作用（出处：鸿蒙 SDK 的 ets/component/image.d.ts，ImageAttribute.fillColor；文档 ts-basic-components-image.md，fillColor）
  写法：全局可用，不用导入：Image(src).fillColor(value: ResourceColor): ImageAttribute；API 15 起 fillColor(color: ResourceColor | ColorContent)，API 20 起再加 ColorMetrics
- 〔原因〕设备上 Image.fillColor 不改变 png 位图的像素颜色（白色透明位图仍是白色，在浅色背景上几乎看不见）；colorFilter(drawing.ColorFilter.createBlendModeColorFilter(色值, SRC_IN)) 会把位图不透明处染成该色（出处：卡里上机实测）
  写法：import { drawing } from '@kit.ArkGraphics2D'
        Image($r('app.media.step')).colorFilter(drawing.ColorFilter.createBlendModeColorFilter(color, drawing.BlendMode.SRC_IN))
- 〔做法第 1 步〕ImageAttribute.colorFilter(value: ColorFilter | DrawingColorFilter)；DrawingColorFilter 即 @ohos.graphics.drawing 的 ColorFilter（@since 12）；设了 colorFilter 后 renderMode 不生效（出处：鸿蒙 SDK 的 ets/component/image.d.ts，ImageAttribute.colorFilter、DrawingColorFilter）
  写法：全局可用，不用导入：Image(src).colorFilter(value: ColorFilter | DrawingColorFilter): ImageAttribute
        ColorFilter（4×5 矩阵类）与 DrawingColorFilter 类型都是全局的
- 〔做法第 1 步〕drawing.ColorFilter.createBlendModeColorFilter(color: common2D.Color, mode: BlendMode)（@since 11）；API 18 起 color 也可传 number（十六进制 ARGB 无符号整数）；drawing、common2D 从 @kit.ArkGraphics2D 导出（出处：鸿蒙 SDK 的 ets/api/@ohos.graphics.drawing.d.ts，ColorFilter.createBlendModeColorFilter；ets/kits/@kit.ArkGraphics2D.d.ts）
  写法：import { drawing, common2D } from '@kit.ArkGraphics2D'
        const f: drawing.ColorFilter = drawing.ColorFilter.createBlendModeColorFilter(color: common2D.Color | number, mode: drawing.BlendMode)
- 〔做法第 1 步〕common2D.Color { alpha, red, green, blue }，各为 0–255 的整数（出处：鸿蒙 SDK 的 ets/api/@ohos.graphics.common2D.d.ts，common2D.Color）
  写法：import { common2D } from '@kit.ArkGraphics2D'
        const c: common2D.Color = { alpha: 255, red: 0, green: 125, blue: 255 }
- 〔做法第 1 步〕矩阵写法：ArkUI 的 new ColorFilter(value: number[]) 是行优先的 4×5 RGBA 矩阵，四行依次为 R、G、B、A；或 drawing.ColorFilter.createMatrixColorFilter(matrix: Array<number>)（20 个数）（出处：鸿蒙 SDK 的 ets/component/units.d.ts，ColorFilter；文档 ts-types.md，ColorFilter；鸿蒙 SDK 的 ets/api/@ohos.graphics.drawing.d.ts，ColorFilter.createMatrixColorFilter）
  写法：new ColorFilter(value: number[])  // 全局类，20 个数，与 drawing.ColorFilter 不是同一个类
        drawing.ColorFilter.createMatrixColorFilter(matrix: Array<number>): drawing.ColorFilter  // import { drawing } from '@kit.ArkGraphics2D'
- 〔做法第 1 步〕平台没有规定 4×5 颜色矩阵第 5 列偏移量的刻度（0–255 还是 0–1），声明和文档都没写（出处：鸿蒙 SDK 的 ets/component/units.d.ts，ColorFilter；文档 ts-types.md，ColorFilter；文档 ts-basic-components-image.md，colorFilter）
  写法：new ColorFilter(value: number[])  // 第 5、10、15、20 个数是偏移量
- 〔做法第 1 步〕colorFilter 直接收 ResourceColor 的重载起始版本 26.0.0，按 createBlendModeColorFilter 的 SRC_ATOP 绘制；API 23 的 SDK 没有这个重载（出处：文档 ts-basic-components-image.md，colorFilter（起始版本 26.0.0））
  写法：colorFilter(value: ColorFilter | DrawingColorFilter | ResourceColor): ImageAttribute  // 26.0.0 起；API 23 SDK 没有
- 〔例外与边界〕SVG 图源：fillColor 替换 SVG 内所有可绘制元素的填充色；API 21 起 supportSvg2 为 true 时依赖 SVG 的 fill，fill='none' 时不生效；colorFilter 对 SVG 只在设了 stroke 时生效（supportSvg2 为 true 时作用于整图）（出处：文档 ts-basic-components-image.md，fillColor、colorFilter）
  写法：全局可用，不用导入：Image($r('app.media.icon_svg')).fillColor(Color.Blue)；.supportSvg2(enable: boolean): ImageAttribute（API 21）
- 〔适用情境〕Compose 的 Icon(painter / bitmap / imageVector) 在调用方没传 tint 时默认着色：material3 1.4.0–1.5.0-alpha08 的 tint 默认 LocalContentColor.current，material 1.6.2–1.12.0 默认 LocalContentColor.current.copy(alpha = LocalContentAlpha.current)；tint 不等于 Color.Unspecified 时按 ColorFilter.tint(tint)（SrcIn）绘制，只有显式传 Color.Unspecified 才不着色，所以经 Icon 显示的位图也属于本经验的着色情形（出处：androidx.compose.material3:material3-android 1.4.0、1.5.0-alpha08，androidx.compose.material3.IconKt#Icon 的默认参数与绘制（字节码）；androidx.compose.material:material-android 1.6.2、1.12.0，androidx.compose.material.IconKt#Icon（字节码））
- 〔适用情境〕安卓 setColorFilter(ColorFilter) 还可能传 LightingColorFilter（RGB 先乘 mul 再加 add，结果限制在 0..255，mul、add 的 alpha 被忽略，像素 alpha 不变）或 ColorMatrixColorFilter（4×5 矩阵，第 5 列偏移量按 0..255 刻度，结果逐通道截到 0..255）；PorterDuffColorFilter 与 BlendModeColorFilter（API 29 起）才对应 createBlendModeColorFilter（出处：android.graphics.LightingColorFilter；android.graphics.ColorMatrix；android.graphics.PorterDuffColorFilter；android.graphics.BlendModeColorFilter）
- 〔做法第 1 步〕drawing.ColorFilter 的其他静态工厂：createLightingColorFilter(mutColor, addColor)（API 20 起，RGB 乘 mutColor 再加 addColor、结果限制在 0–255，对应安卓 LightingColorFilter），createComposeColorFilter(outer, inner)（API 11 起，先 inner 后 outer），createLumaColorFilter()、createLinearToSRGBGamma()、createSRGBGammaToLinear()（API 11 起）；number 形式的颜色必须是十六进制 ARGB 无符号整数（出处：鸿蒙 SDK 的 ets/api/@ohos.graphics.drawing.d.ts，ColorFilter.createLightingColorFilter、createComposeColorFilter、createLumaColorFilter、createLinearToSRGBGamma、createSRGBGammaToLinear；文档 arkts-apis-graphics-drawing-ColorFilter.md，createLightingColorFilter）
  写法：import { drawing, common2D } from '@kit.ArkGraphics2D'
        static createLightingColorFilter(mutColor: common2D.Color | number, addColor: common2D.Color | number): drawing.ColorFilter  // API 20
        static createComposeColorFilter(outer: drawing.ColorFilter, inner: drawing.ColorFilter): drawing.ColorFilter
        static createLumaColorFilter(): drawing.ColorFilter；static createLinearToSRGBGamma(): drawing.ColorFilter；static createSRGBGammaToLinear(): drawing.ColorFilter
- 〔做法第 1 步〕把颜色资源按当前主题取成数值：resourceManager.getColorSync(resId: number) 返回十进制的 ARGB 整数（白色为 4294967295），普通资源管理对象按系统当前的深浅色等配置取值；可直接传给 API 18 起 createBlendModeColorFilter 的 number 形参；getColorSync(resource: Resource) 重载从 API 20 起废弃，改传 $r(...).id（出处：鸿蒙 SDK 的 ets/api/@ohos.resourceManager.d.ts，ResourceManager.getColorSync；ets/api/@ohos.arkui.UIContext.d.ts，UIContext.getHostContext；文档 js-apis-resource-manager.md，getColorSync）
  写法：import { drawing } from '@kit.ArkGraphics2D'
        const clr: number = this.getUIContext().getHostContext()!.resourceManager.getColorSync($r('app.color.tint').id)
        drawing.ColorFilter.createBlendModeColorFilter(clr, drawing.BlendMode.SRC_IN)  // number 形参 API 18 起
        getColorSync(resId: number): number；getColorByNameSync(resName: string): number；getUIContext().getHostContext(): Context | undefined（API 12）
