# 位图着色（ColorFilter.tint、setColorFilter）用 Image.colorFilter：fillColor 只对 SVG 图源生效

ID：`lesson-1a66114fb7523a1f9af1` · 版本：1

> 带知识的试验版（未并入 store）：正文按 `knowledge/lessons/lesson-1a66114fb7523a1f9af1.json` 改了 3 句，后面接了 13 条已核实的平台事实。原文、来源和证据卡见 [memory/ui/effects/lesson-1a66114fb7523a1f9af1.lesson.md](../../../../memory/ui/effects/lesson-1a66114fb7523a1f9af1.lesson.md)。

## 何时使用

界面实现阶段为源端着色的图片写 ArkUI Image 修饰链、选择着色 API 时；规格提取阶段为 ColorFilter.tint 一类着色写转换决策时

## 适用情境

源端 Compose Image 的 colorFilter = ColorFilter.tint(color)（默认 SrcIn），或 ImageView 的 tint、setColorFilter（XML android:tint 未写 tintMode 与 setColorFilter(int) 默认 SRC_ATOP，app:tint、setImageTintList 默认 SRC_IN），作用在 png/jpg/webp 位图上（常见白色加透明通道、靠着色才可见的示意图）；目标资源仍是同一位图；规格转换行可能把 fillColor 与 colorFilter 列成并列选项。

## 例外与边界

- 资源已转成 SVG 时，fillColor 可以承担着色

## 原因

ArkUI Image.fillColor 只作用于 SVG 图源，对位图不改像素颜色，白色透明位图在浅色背景上几乎看不见（HarmonyOS 6.1.0(23) 工程实测）；位图着色要经 colorFilter。

## 做法

1. 位图用 Image.colorFilter：SrcIn 着色写 drawing.ColorFilter.createBlendModeColorFilter(色值, drawing.BlendMode.SRC_IN)，源端是 SRC_ATOP 时换成 drawing.BlendMode.SRC_ATOP（着色色不透明时两者结果相同）（@kit.ArkGraphics2D，色值为 common2D.Color，可由 '#AARRGGBB' 主题色拆出），不改写成 4x5 矩阵（矩阵着色要把着色色写进第 5 列偏移量，偏移量的刻度平台没有规定）；颜色在渲染期按当前主题取值，不着色的分支不挂滤镜。
2. 修饰符对当前资源类型是否生效拿不准时，先查 SDK component/image.d.ts 中该属性的注释再写；规格写着色决策时注明源资源格式，只给对该格式生效的 API，并在同一行写出前提（如“PNG 位图 → colorFilter SRC_IN；fillColor 仅 SVG”），下游汇总规格时不丢掉这一前提。

## 可选检查

- 对着色是否生效有疑问时，在浅色与深色背景下各截图一次，核对白色透明位图是否显出着色。

## 已核实的平台事实

核实时用的是 HarmonyOS 6.1.0（API 23，openharmony ets 6.1.0.105；文档副本含到 API 26 的内容，超出 SDK 的已注明）；安卓 平台资源 android-34；框架源码 android-36.1；androidx Compose 1.10.3（foundation、ui、ui-unit、ui-graphics，按字节码核）。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看。

- 〔适用情境〕Compose ColorFilter.tint(color, blendMode) 的 blendMode 默认 BlendMode.SrcIn（出处：androidx.compose.ui:ui-graphics 1.10.3，androidx.compose.ui.graphics.ColorFilter.Companion#tint 的默认参数）
- 〔适用情境〕ImageView 的 XML android:tint 在布局和 style 都没写 tintMode 时混合模式是 SRC_ATOP（兼容 L 以前），setColorFilter(int) 也按 SRC_ATOP（出处：android.widget.ImageView#ImageView(Context, AttributeSet, int, int)、android.widget.ImageView#setColorFilter(int)）
- 〔适用情境〕setImageTintList 与 AppCompat 的 app:tint 在没另设 tintMode（app:tintMode、setImageTintMode）时不改混合模式，用 Drawable 默认的 SRC_IN（出处：android.widget.ImageView#setImageTintList、#applyImageTint；android.graphics.drawable.Drawable#DEFAULT_TINT_MODE；androidx.appcompat:appcompat 1.8.0，AppCompatImageHelper#loadFromAttributes）
- 〔适用情境〕drawing.BlendMode.SRC_IN = 5（r = s × da）、SRC_ATOP = 9（r = s × da + d × (1 − sa)）：着色色不透明时两者结果相同，半透明时 SRC_ATOP 还透出原图（出处：鸿蒙 SDK 的 ets/api/@ohos.graphics.drawing.d.ts，drawing.BlendMode.SRC_IN、SRC_ATOP）
- 〔原因〕ImageAttribute.fillColor 只对 SVG 图源生效（AnimatedDrawableDescriptor 也不生效），对 png 等位图不起作用（出处：鸿蒙 SDK 的 ets/component/image.d.ts，ImageAttribute.fillColor；文档 ts-basic-components-image.md，fillColor）
- 〔原因〕设备上 Image.fillColor 不改变 png 位图的像素颜色（白色透明位图仍是白色，在浅色背景上几乎看不见）；colorFilter(drawing.ColorFilter.createBlendModeColorFilter(色值, SRC_IN)) 会把位图不透明处染成该色（出处：卡里上机实测）
- 〔做法第 1 步〕ImageAttribute.colorFilter(value: ColorFilter | DrawingColorFilter)；DrawingColorFilter 即 @ohos.graphics.drawing 的 ColorFilter（@since 12）；设了 colorFilter 后 renderMode 不生效（出处：鸿蒙 SDK 的 ets/component/image.d.ts，ImageAttribute.colorFilter、DrawingColorFilter）
- 〔做法第 1 步〕drawing.ColorFilter.createBlendModeColorFilter(color: common2D.Color, mode: BlendMode)（@since 11）；API 18 起 color 也可传 number（十六进制 ARGB 无符号整数）；drawing、common2D 从 @kit.ArkGraphics2D 导出（出处：鸿蒙 SDK 的 ets/api/@ohos.graphics.drawing.d.ts，ColorFilter.createBlendModeColorFilter；ets/kits/@kit.ArkGraphics2D.d.ts）
- 〔做法第 1 步〕common2D.Color { alpha, red, green, blue }，各为 0–255 的整数（出处：鸿蒙 SDK 的 ets/api/@ohos.graphics.common2D.d.ts，common2D.Color）
- 〔做法第 1 步〕矩阵写法：ArkUI 的 new ColorFilter(value: number[]) 是行优先的 4×5 RGBA 矩阵，四行依次为 R、G、B、A；或 drawing.ColorFilter.createMatrixColorFilter(matrix: Array<number>)（20 个数）（出处：鸿蒙 SDK 的 ets/component/units.d.ts，ColorFilter；文档 ts-types.md，ColorFilter；鸿蒙 SDK 的 ets/api/@ohos.graphics.drawing.d.ts，ColorFilter.createMatrixColorFilter）
- 〔做法第 1 步〕平台没有规定 4×5 颜色矩阵第 5 列偏移量的刻度（0–255 还是 0–1），声明和文档都没写（出处：鸿蒙 SDK 的 ets/component/units.d.ts，ColorFilter；文档 ts-types.md、ts-basic-components-image.md，colorFilter）
- 〔做法第 1 步〕colorFilter 直接收 ResourceColor 的重载起始版本 26.0.0，按 createBlendModeColorFilter 的 SRC_ATOP 绘制；API 23 的 SDK 没有这个重载（出处：文档 ts-basic-components-image.md，colorFilter（起始版本 26.0.0））
- 〔例外与边界〕SVG 图源：fillColor 替换 SVG 内所有可绘制元素的填充色；API 21 起 supportSvg2 为 true 时依赖 SVG 的 fill，fill='none' 时不生效；colorFilter 对 SVG 只在设了 stroke 时生效（supportSvg2 为 true 时作用于整图）（出处：文档 ts-basic-components-image.md，fillColor、colorFilter）
