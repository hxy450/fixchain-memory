# 源端在整数 px 上取整的布局公式：规格写明运算域，实现在 px 域取整、写入布局属性前再换回 vp

## 何时使用

规格提取阶段，把自定义 Layout、MeasureScope 里的测量与整数几何公式翻成目标契约时；界面实现阶段，用 onAreaChange、measureText 等返回值驱动这类公式时；移植自绘 View 的绘制坐标、setBounds 边界、位移与文字基线修正中的 (int) 强转时

## 适用情境

源算法在约束或测量结果（Compose constraints、placeable 宽高等整数 px）上做整数除法、.toInt() 截断或取整；目标布局属性和尺寸回调（onAreaChange）使用 vp 等逻辑单位，回调值通常不是整数；UIContext.getMeasureUtils().measureText 返回 px，画布 CanvasRenderingContext2D.measureText 的结果与画布坐标同单位（默认 vp）。 也包括 Canvas 绘制代码中的 (int) 强转（setBounds 边界、int 位移、文字基线修正），其中的量可能为负。

## 例外与边界

- 公式本来作用于 Dp 常量（固定间距、固定尺寸），不涉及 constraints 或 placeable 时，按原单位保留；View 体系里经 getDimensionPixelSize / getDimensionPixelOffset 或 XML 布局读入的 dp 尺寸已是整数 px（前者四舍五入、后者截断），对它们做的整数运算仍在 px 域，不属于此例外

## 原因

单位缩放与取整不可交换：保留 floor 等函数名却把输入换成 vp，每次截断的小数按 vp 丢弃，槽宽总和铺不满容器、位置偏移；把 MeasureUtils.measureText 返回的 px 先转 vp 再进公式也改变了运算域。规格把 vp 回调值写成“整数”或把“源端余下 W mod n 空白”按 vp 复述时，错误的等价性声明看起来成立，并传给所有照做的实现者。

## 做法

1. 规格提取：写出公式输入输出的单位、整数或浮点类型、取整位置和换算边界，以源测量代码为准；例如源公式为 Wpx/(n+1) 时，契约写成 u_px = floor(Wpx/(n+1))、供布局使用时 u_vp = px2vp(u_px)，不要写成 floor(Wvp/(n+1))。用例至少放一个非整数 vp 宽与对应 px 宽的对照行。
2. 实现：参数名带单位（如 widthPx）；onAreaChange 的 vp 宽（Area.width 声明为 Length，按 number 取用）和默认 vp 画布上 measureText 的结果先 vp2px，MeasureUtils.measureText 的 px 直接使用，公式在 px 域取整，结果写入 width、translate、position 前再 px2vp。规格把回调值写成“vp、整数”时，先用一个真实回调值核对。
3. Java/Kotlin 的 (int)/toInt() 向零截断，用 Math.trunc；量可能为负（反向位移、扩张时的负边界）时不能换成 Math.floor。视觉验收看不出亚像素差也原样保留，偏移被乘倍使用时误差随之放大。

## 可选检查

- 单位或取整顺序有疑问时，代入一个实测宽度比较两种顺序；能 dump 时核对行总宽是否等于容器 px 宽。

## 已核实的平台事实

核实时用的是 HarmonyOS 6.1.0（API 23，openharmony ets 6.1.0.105；文档副本含到 API 26 的内容，超出 SDK 的已注明）；安卓 平台资源 android-34；框架源码 android-36.1；androidx Compose 1.10.3（foundation、ui、ui-unit、ui-graphics，按字节码核）。和具体应用无关，直接用，不用再查；其中的默认值只在应用自己的主题、样式、清单和代码没有另设时成立，应用有没有另设要到应用里看；每条下面的「写法」是在 SDK 声明里核过的导入语句、归属、签名和枚举成员，写代码时直接照抄。

- 〔适用情境〕Compose Constraints 的 minWidth/maxWidth 等是 Int（px），Placeable.width/height 是 Int（px）；Density.roundToPx 返回 Int、toPx 返回 Float（出处：androidx.compose.ui:ui-unit 1.10.3，androidx.compose.ui.unit.Constraints#getMaxWidth、Density#roundToPx；androidx.compose.ui:ui 1.10.3，androidx.compose.ui.layout.Placeable#getWidth）
- 〔适用情境〕Java 整数除法按向零取整（截断），Math.floorDiv 才向负无穷取整，负数时两者不同（出处：java.lang.Math#floorDiv 的注释）
- 〔适用情境〕Drawable.setBounds(int left, int top, int right, int bottom)：源端边界本身是 int，取整发生在传参处（出处：android.graphics.drawable.Drawable#setBounds）
- 〔做法第 2 步〕onAreaChange(event: (oldValue: Area, newValue: Area) => void)；Area.width/height 声明为 Length（string | number | Resource）、单位 vp，回调值一般不是整数（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.onAreaChange；ets/component/units.d.ts，Area；文档 ts-types.md，Area）
  写法：全局可用，不用导入（通用事件，Area 为全局类型）：.onAreaChange((oldValue: Area, newValue: Area) => { const wVp = newValue.width as number })
- 〔做法第 2 步〕UIContext.vp2px(value: number): number、px2vp(value: number): number（@since 12）；全局 vp2px/px2vp 自 API 18 废弃，声明指向 UIContext 上的同名方法（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.vp2px、UIContext.px2vp；ets/component/common.d.ts，全局 vp2px/px2vp（@deprecated since 18））
  写法：const ui: UIContext = this.getUIContext()  // 组件内；类型 import { UIContext } from '@kit.ArkUI'
        const wPx = ui.vp2px(wVp)；const uVp = ui.px2vp(uPx)
- 〔做法第 2 步〕MeasureUtils.measureText(options: MeasureOptions): number 返回 px；measureTextSize 的宽高也是 px；经 UIContext.getMeasureUtils() 取得（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，MeasureUtils.measureText、MeasureUtils.measureTextSize、UIContext.getMeasureUtils）
  写法：const wPx: number = this.getUIContext().getMeasureUtils().measureText({ textContent: '文字', fontSize: 16 })
        MeasureOptions：textContent: string | Resource 必填；另有 constraintWidth?、fontSize?、fontStyle?、fontWeight?、fontFamily? 等
- 〔做法第 2 步〕默认 vp 单位的画布上，CanvasRenderingContext2D.measureText 的 width/height 与 fillText、strokeRect 坐标同为 vp：文档写画布接口参数如无说明单位均为 vp，示例直接用测得的宽高画边框（出处：文档 arkts-drawing-customization-on-canvas.md，单位均为vp、measureText；文档 ts-canvasrenderingcontext2d.md，measureText）
  写法：全局可用，不用导入：this.context.measureText(text: string): TextMetrics
        TextMetrics 字段：width、height、actualBoundingBoxAscent、actualBoundingBoxDescent、actualBoundingBoxLeft、actualBoundingBoxRight、alphabeticBaseline、emHeightAscent、emHeightDescent、fontBoundingBoxAscent、fontBoundingBoxDescent、hangingBaseline、ideographicBaseline
- 〔做法第 2 步〕Length 的字符串可显式带单位，'10px' 按 px；number 或不带单位的字符串按 vp（出处：文档 ts-types.md，Length）
  写法：全局可用，不用导入：declare type Length = string | number | Resource；.width(`${uPx}px`)
- 〔做法第 2 步〕写回布局的三个属性：width/height 收 Length，translate 收 TranslateOptions（x、y、z 为 number | string，number 单位 vp），position 收 Position（x、y 为 Length）或 Edges（出处：鸿蒙 SDK 的 ets/component/common.d.ts，CommonMethod.width、CommonMethod.translate、CommonMethod.position、TranslateOptions、Position；文档 ts-universal-attributes-transformation.md，translate）
  写法：全局可用，不用导入（通用属性）：width(value: Length): T；translate(value: TranslateOptions): T；position(value: Position | Edges | LocalizedEdges): T
        .width(ui.px2vp(uPx)).translate({ x: ui.px2vp(dx) }).position({ x: ui.px2vp(xPx), y: 0 })
- 〔做法第 2 步〕画布坐标：CanvasRenderingContext2D(settings?, unit?: LengthMetricsUnit)，默认 DEFAULT（vp），传 LengthMetricsUnit.PX 后 fillRect、translate、drawImage 等按 px；构造后不能改（出处：鸿蒙 SDK 的 ets/component/canvas.d.ts，CanvasRenderingContext2D.constructor；ets/api/arkui/Graphics.d.ts，LengthMetricsUnit；文档 ts-canvasrenderingcontext2d.md）
  写法：import { LengthMetricsUnit } from '@kit.ArkUI'
        private context: CanvasRenderingContext2D = new CanvasRenderingContext2D(new RenderingContextSettings(true), LengthMetricsUnit.PX)
- 〔做法第 3 步〕Math.trunc(x) 去掉小数部分（向零）；Math.floor(x) 取不大于 x 的最大整数，负数时比 trunc 小 1（出处：鸿蒙 SDK 自带的 TypeScript 库 lib.es2015.core.d.ts，Math.trunc；鸿蒙 SDK 自带的 TypeScript 库 lib.es5.d.ts，Math.floor）
  写法：全局可用，不用导入：Math.trunc(x: number): number；Math.floor(x: number): number
- 〔做法第 3 步〕Java 的 (int) 强转把浮点向零截断：在负的非整数值上 Math.trunc 与它相同，Math.floor 比它小 1（出处：卡里上机实测）
- 〔例外与边界〕XML 里写成 dp 的 layout_width/height、padding、margin 读入时已经是整数 px：TypedArray.getLayoutDimension 与 getDimensionPixelSize 走 complexToDimensionPixelSize，按 (int)(f ± 0.5) 四舍五入（远离零），非零值至少 ±1 px；getDimensionPixelOffset 走 complexToDimensionPixelOffset，直接 (int) 向零截断；getDimension 才保留浮点。源端代码拿这些值做整数运算时，运算域已是 px（出处：android.util.TypedValue#complexToDimensionPixelSize、#complexToDimensionPixelOffset；android.content.res.TypedArray#getLayoutDimension；android.view.View#View(Context, AttributeSet, int, int)（padding 用 getDimensionPixelSize））
- 〔适用情境〕Compose 的 Dp.roundToPx() 先 toPx() 再 Math.round(float)（.5 向正无穷进位，-2.5 得 -2），toPx() 结果为无穷时返回 Constraints.Infinity（Int.MAX_VALUE）（ui-unit 1.10.3、1.12.0 字节码相同）（出处：androidx.compose.ui:ui-unit-android 1.10.3、1.12.0，androidx.compose.ui.unit.Density#roundToPx（字节码））
- 〔做法第 2 步〕UIContext 的单位换算成对出现（都是 API 12）：vp2px / px2vp（px = vp × 当前窗口像素密度），fp2px / px2fp（px = fp × 像素密度 × 字体缩放比例），lpx2px / px2lpx（px = lpx × 实际屏宽 / designWidth）；源端是 sp 的文字尺寸对应 fp，不能用 vp2px 换（出处：鸿蒙 SDK 的 ets/api/@ohos.arkui.UIContext.d.ts，UIContext.vp2px、UIContext.px2vp、UIContext.fp2px、UIContext.px2fp、UIContext.lpx2px、UIContext.px2lpx；文档 arkts-apis-uicontext-uicontext.md，vp2px、fp2px、lpx2px）
  写法：import { UIContext } from '@kit.ArkUI'  // 仅写类型注解时需要；组件内 this.getUIContext()
        vp2px(value: number): number；px2vp(value: number): number
        fp2px(value: number): number；px2fp(value: number): number
        lpx2px(value: number): number；px2lpx(value: number): number
- 〔做法第 2 步〕onAreaChange 回调的 Area 有四个字段：width、height（Length，单位 vp）；position 是组件左上角在父组件坐标系中的位置，globalPosition 是在当前窗口坐标系中的位置，都是 Position { x?, y? }（vp）；取 px 域的位置同样先 vp2px（出处：鸿蒙 SDK 的 ets/component/units.d.ts，Area.width、Area.position、Area.globalPosition；文档 ts-types.md，Area）
  写法：全局类型，全局可用，不用导入
        declare interface Area { width: Length; height: Length; position: Position; globalPosition: Position }
        .onAreaChange((oldValue: Area, newValue: Area) => { const xPx = this.getUIContext().vp2px(newValue.position.x as number) })
- 〔做法第 2 步〕MeasureUtils.measureText 的 MeasureOptions 全部字段：textContent（必填）、constraintWidth（默认单位 vp，不支持百分比）、fontSize（API 12 起 number 按 fp，之前按 vp；默认 16）、fontStyle、fontWeight、fontFamily、letterSpacing（默认 0）、textAlign、overflow、maxLines、lineHeight、baselineOffset（默认 0）、textCase、textIndent（默认 0）、wordBreak；返回值是 px（出处：鸿蒙 SDK 的 ets/api/@ohos.measure.d.ts，MeasureOptions；ets/kits/@kit.ArkUI.d.ts，MeasureOptions；文档 js-apis-measure.md，MeasureOptions）
  写法：import { MeasureOptions } from '@kit.ArkUI'
        interface MeasureOptions { textContent: string | Resource; constraintWidth?: number | string | Resource; fontSize?: number | string | Resource; fontStyle?: number | FontStyle; fontWeight?: number | string | FontWeight; fontFamily?: string | Resource; letterSpacing?: number | string; textAlign?: number | TextAlign; overflow?: number | TextOverflow; maxLines?: number; lineHeight?: number | string | Resource; baselineOffset?: number | string; textCase?: number | TextCase; textIndent?: number | string; wordBreak?: WordBreak }
        const wPx: number = this.getUIContext().getMeasureUtils().measureText({ textContent: s, fontSize: '16fp' })
